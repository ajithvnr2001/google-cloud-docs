#  App Optimize API Stay organized with collections  Save and categorize content based on your preferences. 

The App Optimize API provides developers and platform teams with tools to monitor, analyze, and improve the performance and cost-efficiency of their cloud applications.

## Service: appoptimize.googleapis.com

The Service name `appoptimize.googleapis.com` is needed to create RPC client stubs.

## `[google.cloud.appoptimize.v1beta.AppOptimize](https://docs.cloud.google.com/app-optimize/reference/rpc/google.cloud.appoptimize.v1beta#google.cloud.appoptimize.v1beta.AppOptimize)`

Methods  
---  
``[CreateReport](https://docs.cloud.google.com/app-optimize/reference/rpc/google.cloud.appoptimize.v1beta#google.cloud.appoptimize.v1beta.AppOptimize.CreateReport)`` |  Creates a new report.  
``[DeleteReport](https://docs.cloud.google.com/app-optimize/reference/rpc/google.cloud.appoptimize.v1beta#google.cloud.appoptimize.v1beta.AppOptimize.DeleteReport)`` |  Deletes the specified report.  
``[GetReport](https://docs.cloud.google.com/app-optimize/reference/rpc/google.cloud.appoptimize.v1beta#google.cloud.appoptimize.v1beta.AppOptimize.GetReport)`` |  Retrieves the details of a report configuration.  
``[ListReports](https://docs.cloud.google.com/app-optimize/reference/rpc/google.cloud.appoptimize.v1beta#google.cloud.appoptimize.v1beta.AppOptimize.ListReports)`` |  Lists reports within a given project.  
``[ReadReport](https://docs.cloud.google.com/app-optimize/reference/rpc/google.cloud.appoptimize.v1beta#google.cloud.appoptimize.v1beta.AppOptimize.ReadReport)`` |  Reads data within a specified report.

## `[google.longrunning.Operations](https://docs.cloud.google.com/app-optimize/reference/rpc/google.longrunning#google.longrunning.Operations)`

Methods  
---  
``[CancelOperation](https://docs.cloud.google.com/app-optimize/reference/rpc/google.longrunning#google.longrunning.Operations.CancelOperation)`` |  Starts asynchronous cancellation on a long-running operation.  
``[DeleteOperation](https://docs.cloud.google.com/app-optimize/reference/rpc/google.longrunning#google.longrunning.Operations.DeleteOperation)`` |  Deletes a long-running operation.  
``[GetOperation](https://docs.cloud.google.com/app-optimize/reference/rpc/google.longrunning#google.longrunning.Operations.GetOperation)`` |  Gets the latest state of a long-running operation.  
``[ListOperations](https://docs.cloud.google.com/app-optimize/reference/rpc/google.longrunning#google.longrunning.Operations.ListOperations)`` |  Lists operations that match the specified filter in the request.  
``[WaitOperation](https://docs.cloud.google.com/app-optimize/reference/rpc/google.longrunning#google.longrunning.Operations.WaitOperation)`` |  Waits until the specified long-running operation is done or reaches at most a specified timeout, returning the latest state.
