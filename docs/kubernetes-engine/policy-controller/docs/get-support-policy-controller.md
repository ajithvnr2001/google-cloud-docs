This page shows you how to get support for Policy Controller.

## Before contacting support

Before contacting support, you can try and resolve issues yourself. For troubleshooting tips, see [Troubleshoot Policy Controller](https://docs.cloud.google.com/kubernetes-engine/policy-controller/docs/how-to/troubleshoot-policy-controller).

## Support options

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

For open source Gatekeeper, you can get support by checking for existing issues or opening a new issue in the [public GitHub issue tracker](https://github.com/open-policy-agent/gatekeeper/issues).

## What Google doesn't support

Google doesn't support the following issues:

  * Issues with [self-authored constraints](https://docs.cloud.google.com/kubernetes-engine/policy-controller/docs/how-to/creating-policy-controller-constraints) and [constraint templates](https://docs.cloud.google.com/kubernetes-engine/policy-controller/docs/how-to/write-custom-constraint-templates).
  * Issues with customer-owned `YAML` file configurations.



### Related tools and resources

If you install open source products, such as Gatekeeper, you can get community support for these products:

  * [Gatekeeper](https://github.com/open-policy-agent/gatekeeper)
  * [kpt](https://kpt.dev/)
  * [Kustomize](https://kustomize.io/)



## Recommended version

We recommend that you use Policy Controller version 1.24.

## Version support policy

Google supports each Policy Controller minor version for the later of:

  * 12 months after the initial release of the minor version.
  * The release of the third subsequent minor version.



To learn more about version compatibility, including compatibility with Kubernetes versions, see [Version and upgrade support](https://docs.cloud.google.com/kubernetes-engine/enterprise/docs/version-and-upgrade-support).

The following table shows the supported versions of Policy Controller and the earliest end-of-life (EOL) date for a version:

Release version | Release date | Earliest end of life date  
---|---|---  
1.24 | [August 14, 2026](https://docs.cloud.google.com/kubernetes-engine/policy-controller/docs/release-notes#August_14_2026) | August 14, 2027  
1.23 | [February 23, 2026](https://docs.cloud.google.com/kubernetes-engine/policy-controller/docs/release-notes#February_23_2026) | February 23, 2027  
1.22 | [November 24, 2025](https://docs.cloud.google.com/kubernetes-engine/policy-controller/docs/release-notes#November_24_2025) | November 24, 2026  
  
If you are on an unsupported version of Policy Controller, then you must upgrade to a supported version to receive support. For information on how to upgrade, see [Installing Policy Controller](https://docs.cloud.google.com/kubernetes-engine/policy-controller/docs/how-to/installing-policy-controller#upgrading).

## File bugs or feature requests

You can submit a product issue by using one of the following procedures:

  * **Policy Controller issues and feature requests** : Check for [existing issues](https://issuetracker.google.com/issues?q=componentid:1161523%2B%20status:open%20&s=vote_count:desc&d=issue_id&d=type&d=status&d=vote_count&d=title&d=priority&d=severity&d=assignee&d=blocked_by_issue_id&d=created_time&d=modified_time) or [open new issues](https://issuetracker.google.com/issues/new?component=1161523).

  * **Gatekeeper issues and feature requests** : Check for existing issues or open new issues in the [public issue trackers](https://github.com/open-policy-agent/gatekeeper/issues).

  * **Documentation issues** : On the documentation page, select **Send feedback**. This action opens a feedback form. The Config Management team reviews and takes action on your comments.




## Billing questions

Use the following resources to get help with billing questions:

  * To learn more about billing, read the [Google Cloud billing documentation](https://docs.cloud.google.com/billing/docs).
  * Resolve billing concerns by using the [billing concerns troubleshooter](https://support.google.com/cloud/troubleshooter/7279311?ref_topic=6288636).
  * Request help with billing questions by using the [billing support form](https://support.google.com/cloud/contact/cloud_platform_billing?visit_id=1-636564925221770723-4170709031&rd=1).
