This page describes the platform logs created by Backup for GKE as part of [Google Cloud platform logs](https://docs.cloud.google.com/logging/docs/api/platform-logs).

## Overview

Logging receives, indexes, and stores log entries from [Google Cloud services](https://cloud.google.com/terms/services). Google Cloud platform logs are service-specific logs that can help you debug and troubleshoot issues, as well as better understand the Google Cloud services you're using.

The following types of platform logs are available for Backup for GKE:

  * Backup plan change: creates a log entry when a backup plan is modified, such as creating, updating, or deleting a backup plan.
  * Backup change: creates a log entry when a backup is modified, such as creating, updating, or deleting a backup.
  * Restore plan change: creates a log entry when a restore plan is modified, such as creating, updating, or deleting a restore plan.
  * Restore change: creates a log entry when a restore is modified, such as creating, updating, or deleting a restore.



For more information about Backup for GKE platform logging, see [Backup for GKE logging API](https://docs.cloud.google.com/logging/docs/api/platform-logs#backup_for_gke). For more information about using platform logs, see [Understand and manage platform logs](https://docs.cloud.google.com/logging/docs/api/platform-logs#managing-logs).
