## 1.37.1-gke.1697000

The following sections describe changes in this patch version when compared with the previous patch version, 1.37.1-gke.1552000. For information about upstream Kubernetes changes, see the [Kubernetes v1.37.1 changelog](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.37.md#v1371).

### Component updates

The following sections provide information about updates to specific GKE system components in this patch version.

#### accelerator-operator

Updated `accelerator-operator` component from version 1.37.1 to 1.37.2.

  * **Bug fixes** : 
    * Limited the controller-runtime informer cache to Nodes labeled `cloud.google.com/gke-gpudirect-tcpx=rdma` and to `kube-system` Pods labeled `gpudirect-controller-component=nccl-rdma-installer`, and stripped `managedFields`. Operator memory no longer grows with cluster size.
    * Increased leader election timeouts to 60s lease / 40s renew deadline / 5s retry period (configurable via `--leader-election-lease-duration`, `--leader-election-renew-deadline`, `--leader-election-retry-period`) to avoid restarts from lease renewal timeouts under apiserver load.
  * **Security fixes** : 
    * Updated `google.golang.org/grpc` from v1.83.1 to v1.83.2, and `golang.org/x/net` to v0.58.0, `golang.org/x/sys` to v0.47.0, `golang.org/x/text` to v0.41.0.



#### filestorecsi

Updated `filestorecsi` component from version 1.37.7 to 1.37.9.

  * **Features** : 
    * Added defensive rpc.statd verification, liveness probes, and writable /run mounts.
  * **Miscellaneous** : 
    * Updated internal infrastructure components.



#### gcsfusecsi

Updated `gcsfusecsi` component from version 1.37.17 to 1.37.19.

  * **Security fixes** : 
    * Updated container base images and google.golang.org/grpc to resolve [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445).
    * Updated container base images and OpenTelemetry Go modules (go.opentelemetry.io/otel) to resolve [CVE-2026-81870](https://www.cve.org/CVERecord?id=CVE-2026-81870).



#### gke-metrics-agent

Updated `gke-metrics-agent` component from version 2.137.3-gke.1 to 2.137.4-gke.0.

  * **Bug fixes** : 
    * Fix an issue where `prometheus-metrics-collector` stops emitting metrics due to transient STS token exchange errors falling back to permissionless node service accounts. Set `TOKEN_SOURCE_MODE` to `MODE_TOKEN_BROKER_NO_FALLBACK` when node P4SA is available.
  * **Security fixes** : 
    * Updated the autoscaling-metrics-pipeline Linux and Windows images from vpa-0.28.0-gke.4 to vpa-0.28.0-gke.6 (Go 1.26.8, gRPC 1.85.0-dev, OpenTelemetry SDK 1.45.0) to address [CVE-2026-84304](https://www.cve.org/CVERecord?id=CVE-2026-84304), [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445), [CVE-2026-84303](https://www.cve.org/CVERecord?id=CVE-2026-84303) and [CVE-2026-81870](https://www.cve.org/CVERecord?id=CVE-2026-81870).
  * **Miscellaneous** : 
    * The autoscaling-metrics-pipeline update also adds a "total" step to the scrape duration metric, a scraper_inter_scrape_interval_seconds metric, a warning log for metrics missing from scrape payloads, and pins the Windows Server 2019 base image to GKE node preloaded layers.

## 1.37.1-gke.1552000

The following sections describe changes in this patch version when compared with the previous patch version, 1.37.0-gke.3503000. For information about upstream Kubernetes changes, see the [Kubernetes v1.37.1 changelog](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.37.md#v1371).

### Kubernetes updates

#### k8s-api

Updated `k8s-api` cohort from version 1.37.0-gke.900 to 1.37.1-gke.300.

  * **Features** : 
    * Implemented a package-based installation method for the `crictl` tool on GKE nodes to facilitate automated binary updates.
    * Updated the Google Secrets Manager (GSM) endpoint to support private registries in Transparent Proxy Configuration (TPC).
    * Added the ability to override the IP address of the `kube-apiserver` to allow controllers to connect via an Internal Load Balancer (ILB).
    * Added support for certificates in `kubeconfig` within the configuration helper.
    * Added `zswap` configuration support, allowing `zswap` to be enabled and configured via `sysfs` during swap setup.
    * Extended the GKE AppPkg installer to support extracting the full contents of compressed release tarballs into a specified destination directory and preserving the original tarball for compliance.
    * Added support for the autonomous execution of custom configuration scripts during the AppPkg installation process via the `components.gke.io/configure-script-path` annotation.
  * **Bug fixes** : 
    * Updated the service account token audience configuration for Workload Identity image pulls to use the standard workload pool format (`${project_id}.svc.id.goog`). This resolves issues where image pulls were blocked by `NodeRestriction` admission control or rejected by Google STS with an `invalid_grant` error.
    * Updated Node Problem Detector custom plugins to v1.0.41 to resolve epoll stalls during `inotify` checks and fix a regex issue in the image pull monitor that caused false positives on successful pulls.
    * Forced `chronyd` to synchronize the system clock immediately upon VM resumption on COS and Ubuntu nodes to prevent time drift or stale pre-suspension time.
    * Resolved a resource leak in the host-level NFS wrapper where bind mounts accumulated in the host namespace, eventually preventing the node from creating new mounts and blocking Pod startup.
    * Fixed an issue where NFS unmount requests were incorrectly handled as mount commands, causing unmount operations to fail.
    * Improved the NFS wrapper node setup logic to reliably clear stale binds and help ensure the atomic installation of mount binaries.
    * Clamped the `sunrpc` port range during node bootstrap to improve configuration stability.
    * Fixed an issue where parts of the `ControllerRevision` outside of the `.spec` were incorrectly restored for `StatefulSet` objects.
    * Added a guard in the Windows kernel implementation of `kube-proxy` to handle load balancers that do not have port mappings.
    * Resolved an issue where Job Pods could not be removed if the finalizer removal process failed.
    * Prevented node-specific kubelet configurations from leaking into the `ConfigMap`.
    * Fixed a potential integer overflow in Dynamic Resource Allocation (DRA) during per-claim device-limit checks.
    * Updated Dynamic Resource Allocation (DRA) to help ensure that a nil `DeviceTaintSelector` correctly matches no devices.
    * Adjusted the execution order of legacy configuration scripts to help ensure they are skipped on EVE-based installations.
  * **Security fixes** : 
    * Fixed a confused deputy vulnerability in the `StatefulSet` controller by restoring only the `.Spec` field from `ControllerRevision`, which helps prevent unauthorized cross-namespace Pod creation ([CVE-2026-2270](https://www.cve.org/CVERecord?id=CVE-2026-2270)).
    * Improved security in Windows `subPath` resolution by refusing UNC symlink targets, which helps prevent potential forced NTLM authentication.
    * Enhanced system integrity by implementing cryptographic checksum validation of preserved installation tarballs and performing a fresh extraction of binaries on every reboot.
  * **Miscellaneous** : 
    * Removed the `--pod-sysctls` kubelet command-line flag, as this setting has moved to the kubelet configuration.
    * Refined logging for NFS and `rpcbind` operations to help ensure that degraded behavior and configuration issues are recorded at appropriate severity levels.
    * Updated Go runtime to v1.26.8 and updated container base images to use distroless iptables.
