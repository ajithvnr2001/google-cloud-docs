## 1.31.14-gke.2825000

The following sections describe changes in this patch version when compared with the previous patch version, 1.31.14-gke.2759000. For information about upstream Kubernetes changes, see the [Kubernetes v1.31.14 changelog](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.31.md#v13114).

### Component Updates

The following sections provide information about updates to specific GKE system components in this patch version.

#### filestorecsi

Updated filestorecsi component from version 0.15.49 to 0.15.50.

  * **Security Fixes** : 
    * Updated google.golang.org/grpc and golang.org/x/crypto to resolve [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445) and [CVE-2026-56854](https://www.cve.org/CVERecord?id=CVE-2026-56854).



#### gcp-controller-manager-combined

Updated gcp-controller-manager-combined component from version 31.0.36 to 31.0.37.

  * **Security Fixes** : 
    * Updated the Go runtime to version 1.26.6 to resolve standard library vulnerabilities.
    * Updated third-party Go dependencies to resolve [CVE-2026-33186](https://www.cve.org/CVERecord?id=CVE-2026-33186), [CVE-2026-84304](https://www.cve.org/CVERecord?id=CVE-2026-84304), [CVE-2026-78662](https://www.cve.org/CVERecord?id=CVE-2026-78662), [CVE-2026-56855](https://www.cve.org/CVERecord?id=CVE-2026-56855), [CVE-2026-39833](https://www.cve.org/CVERecord?id=CVE-2026-39833), [CVE-2026-39834](https://www.cve.org/CVERecord?id=CVE-2026-39834), [CVE-2026-39821](https://www.cve.org/CVERecord?id=CVE-2026-39821), [CVE-2026-33814](https://www.cve.org/CVERecord?id=CVE-2026-33814), [CVE-2026-29181](https://www.cve.org/CVERecord?id=CVE-2026-29181), and [CVE-2026-73500](https://www.cve.org/CVERecord?id=CVE-2026-73500).
  * **Miscellaneous** : 
    * Switched to native Go cross-compilation by disabling CGO, removing dependencies on host-system build tools and improving build resilience against external repository issues.



#### gpu-device-plugin

Updated gpu-device-plugin component from version 1.31.2-gke.0 to 1.31.2-gke.1.

  * **Miscellaneous** : 
    * Updated base images and sub-components, including nvidia-gpu-device-plugin and nvidia-partition-gpu to version v1.31.0-gke.19.



#### pdcsi

Updated pdcsi component from version 0.20.96 to 0.20.99.

  * **Bug Fixes** : 
    * Updated the driver to use `NewServerHandler` for OpenTelemetry gRPC instrumentation, replacing the deprecated `UnaryServerInterceptor` API to maintain compatibility with updated dependencies.
  * **Security Fixes** : 
    * Updated `google.golang.org/grpc` to v1.83.2 to resolve [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445).



#### tpu-device-plugin

Updated tpu-device-plugin component from version 1.31.0-gke.24 to 1.31.0-gke.25.

  * **Security Fixes** : 
    * Updated Go modules `google.golang.org/grpc` and `golang.org/x/crypto` to resolve [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445), [CVE-2026-56854](https://www.cve.org/CVERecord?id=CVE-2026-56854), and [CVE-2026-78662](https://www.cve.org/CVERecord?id=CVE-2026-78662).
    * Updated the container base image to resolve vulnerabilities in `openssl` ([CVE-2026-34182](https://www.cve.org/CVERecord?id=CVE-2026-34182) and [CVE-2025-69420](https://www.cve.org/CVERecord?id=CVE-2025-69420)) and `glibc` ([CVE-2026-0861](https://www.cve.org/CVERecord?id=CVE-2026-0861)).
    * Rebuilt the component with an updated Go toolchain to address seven vulnerabilities in the Go standard library.
