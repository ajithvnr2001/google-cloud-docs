## 1.36.4-gke.2202002

The following sections describe changes in this patch version when compared with the previous patch version, 1.36.4-gke.2046002. For information about upstream Kubernetes changes, see the [Kubernetes v1.36.4 changelog](https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.36.md#v1364).

### Component updates

The following sections provide information about updates to specific GKE system components in this patch version.

#### accelerator-operator

Updated `accelerator-operator` component from version 1.36.7 to 1.36.8.

  * **Bug fixes** : 
    * Limited the `controller-runtime` informer cache to nodes labeled `cloud.google.com/gke-gpudirect-tcpx=rdma` and to `kube-system` Pods labeled `gpudirect-controller-component=nccl-rdma-installer`, and stripped `managedFields`. Operator memory no longer grows with cluster size.
    * Increased leader election timeouts to a 60-second (`60s`) lease, 40-second (`40s`) renewal deadline, and 5-second (`5s`) retry period (configurable via `--leader-election-lease-duration`, `--leader-election-renew-deadline`, `--leader-election-retry-period`) to avoid restarts from lease renewal timeouts under apiserver load.
  * **Security fixes** : 
    * Updated `google.golang.org/grpc` from v1.83.1 to v1.83.2, and `golang.org/x/net` to v0.58.0, `golang.org/x/sys` to v0.47.0, `golang.org/x/text` to v0.41.0.



#### filestorecsi

Updated `filestorecsi` component from version 1.36.23 to 1.36.24.

  * **Security fixes** : 
    * Updated `google.golang.org/grpc` in `csi-provisioner` to resolve [CVE-2026-84304](https://www.cve.org/CVERecord?id=CVE-2026-84304) and [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445).



#### gcsfusecsi

Updated `gcsfusecsi` component from version 1.36.46 to 1.36.35.

  * **Bug fixes** : 
    * Allowed `ToLocalhost` egress in `StaticPodNetworkPolicy` for `gcsfusecsi-controller` to prevent SPNP firewall drops during local OAuth token exchange.
  * **Security fixes** : 
    * Updated `golang.org/x/mod` from v0.37.0 to v0.40.0 to address security vulnerability GO-2026-6179.
  * **Miscellaneous** : 
    * Updated the Go base image to version 1.25.13 for the CSI driver components.



#### gke-metrics-agent

Updated `gke-metrics-agent` component from version 2.136.20-gke.4 to 2.136.20-gke.5.

  * **Features** : 
    * Implemented Pressure Stall Information (PSI) collection for `node-daemons`.
  * **Security fixes** : 
    * Addressed security vulnerabilities in the `autoscaling-metrics-exporter`.



#### kube-addon-manager

Updated `kube-addon-manager` component from version 35.0.5 to 35.0.6.

  * **Features** : 
    * Added support for multi-architecture releases.



#### workloadautoscaler

Updated `workloadautoscaler` component from version 19.14.0 to 19.15.0.

  * **Security fixes** : 
    * Updated container images and Go dependencies to resolve [CVE-2026-78662](https://www.cve.org/CVERecord?id=CVE-2026-78662), [CVE-2026-81870](https://www.cve.org/CVERecord?id=CVE-2026-81870), [CVE-2026-84303](https://www.cve.org/CVERecord?id=CVE-2026-84303), [CVE-2026-84304](https://www.cve.org/CVERecord?id=CVE-2026-84304), and [CVE-2026-84445](https://www.cve.org/CVERecord?id=CVE-2026-84445).

    * Updated the Go runtime to 1.25.14 and gRPC library to v1.82.1 to resolve vulnerabilities, including [CVE-2026-33186](https://www.cve.org/CVERecord?id=CVE-2026-33186), [CVE-2026-39821](https://www.cve.org/CVERecord?id=CVE-2026-39821), and [CVE-2026-27144](https://www.cve.org/CVERecord?id=CVE-2026-27144).

    * Updated `go.opentelemetry.io/otel` from v1.43.0 to v1.44.0 to resolve GO-2026-5158.
    * Updated `golang.org/x/net` to v0.56.0, `golang.org/x/sys` to v0.46.0, and `golang.org/x/text` to v0.39.0 to resolve GO-2026-5942, GO-2026-5024, and GO-2026-5970.
  * **Miscellaneous** : 
    * Updated the Go base image to version 1.25.9.
    * Updated `go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp` from v0.53.0 to v0.61.0.



#### filestorecsi

Updated `filestorecsi` component from version 1.36.20 to 1.36.23.

  * **Security fixes** : 
    * Updated Go modules `golang.org/x/crypto` and `google.golang.org/grpc` to resolve [CVE-2026-78662](https://www.cve.org/CVERecord?id=CVE-2026-78662) and [CVE-2026-84304](https://www.cve.org/CVERecord?id=CVE-2026-84304).
  * **Miscellaneous** : 
    * Updated component configuration to include explicit certificate and key options for the webhook server.



#### gcsfusecsi

Updated `gcsfusecsi` component from version 1.36.43 to 1.36.46.

  * **Bug fixes** : 
    * Bumped GCSFuse binary to v3.11.3:
    * Disabled internal Go SDK retries for DirectPath connectivity verification.
    * Accelerated startup for Rapid buckets by skipping redundant DirectPath connectivity checks.
    * Fixed stat cache negative entry bug for implicit directories in windowed listing.



#### gke-metrics-agent

Updated `gke-metrics-agent` component from version 2.136.20-gke.3 to 2.136.20-gke.4.

  * **Features** : 
    * Implemented `node-daemon` Pressure Stall Information (PSI) collection.

#### gpu-device-plugin

  * **Features** :

  * **Miscellaneous** :

    * Bumped `nvidia-partition-gpu` to `v1.36.5-gke.0` for vulnerability fixes.
    * Bumped `nvidia-persistenced-installer` to `v1.36.5-gke.0` for vulnerability fixes.

#### pdcsi

Updated `pdcsi` component from version 1.36.25 to 1.36.28.

  * **Security fixes** : 
    * Updated Go modules and container base images to address security vulnerabilities.
    * Updated container base images and Go dependencies to resolve [CVE-2026-78662](https://www.cve.org/CVERecord?id=CVE-2026-78662) and [CVE-2026-84304](https://www.cve.org/CVERecord?id=CVE-2026-84304).
  * **Miscellaneous** : 
    * Updated container base images for `csi-provisioner`, `csi-node-driver-registrar`, `csi-snapshotter`, and `snapshot-controller`.



#### tpu-device-plugin

Updated `tpu-device-plugin` component from version 1.36.9-gke.0 to 1.36.9-gke.1.
