[Agones](https://agones.dev/site/docs/overview/) is an open source project for hosting, running, and scaling dedicated game servers on Kubernetes. Agones is developed and lead by Google.

Game Servers is a feature built on Kubernetes and Agones. This feature helps you deploy and manage dedicated game server fleets globally. This document provides information on how to get support for both Agones and Game Servers.

## Get support for Game Servers

Google Cloud offers different support packages to meet different needs, such as 24-7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

Support for Game Servers is offered under the Premium support package, which lets you take advantage of the corresponding [features and services](https://docs.cloud.google.com/support#premium-support).

If you're not sure whether you have a paid technical support package, check your Cloud Support console:

[Go to Support](https://console.cloud.google.com/support)

## Open an issue on GitHub

For issues with Agones, you can [open an issue on GitHub](https://github.com/googleforgames/agones/issues) to report a bug or request a new feature.

## Check the Agones community page and get troubleshooting advice

For questions and discussion about Agones, check the [Agones community page](https://agones.dev/site/community/) for public mailing lists, Slack, and monthly community meetings.

For general troubleshooting advice, see the Agones [troubleshooting documentation](https://agones.dev/site/docs/guides/troubleshooting/).
