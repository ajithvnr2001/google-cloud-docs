#  NodeLabels Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Collection of node-level [Kubernetes labels](https://kubernetes.io/docs/concepts/overview/working-with-objects/labels).

JSON representation  
---  
      
    
    {
      "labels": {
        string: string,
        ...
      }
    }  
  
Fields  
---  
`labels` |  `map (key: string, value: string)` Map of node label keys and node label values.
