#  Verified guest operating systems for VM Runtime on GDC Stay organized with collections  Save and categorize content based on your preferences. 

This document lists the guest operating systems (OSes) that have been tested by Google and verified to work with VM Runtime on GDC. Thorough tests validate that these OSes behave as expected in key areas. This isn't an exhaustive list and doesn't imply that operating systems that aren't listed don't work properly with VM Runtime on GDC.

**Note:** Minor releases within a verified OS major version are expected to work without issue. For example, if a given Red Hat Enterprise Linux (RHEL) 8.x is verified, then RHEL 8 minor releases such as RHEL 8.y or RHEL 8.z ought to work without any issues, even though they aren't explicitly tested and verified. We strongly recommend that you use only OS versions that are covered by the standard or extended lifecycle support plans offered by the OS vendor.

Verified guest operating systems:

  * RHEL 7 ([Extended Lifecycle Support available through June 2028](https://www.redhat.com/en/technologies/linux-platforms/enterprise-linux/rhel-7-end-of-maintenance))

  * RHEL 8 ([Extended Update Support available through May 2025](https://access.redhat.com/support/policy/updates/errata/#Extended_Update_Support))

  * Rocky Linux 8 ([reaches End of Life May 2029](https://wiki.rockylinux.org/rocky/version/))

  * Ubuntu 18.04 ([Expanded Security Maintenance ends April 2028](https://ubuntu.com/about/release-cycle))

  * Ubuntu 20.04 ([Expanded Security Maintenance ends April 2030](https://ubuntu.com/about/release-cycle))

  * Ubuntu 22.04 ([Expanded Security Maintenance ends March 2032](https://ubuntu.com/about/release-cycle))

  * Windows Server 2016 ([extended support ends January 2027](https://learn.microsoft.com/en-us/lifecycle/products/windows-server-2016))

  * Windows Server 2019 ([extended support ends January 2029](https://learn.microsoft.com/en-us/lifecycle/products/windows-server-2019))

  * Windows Server 2022 ([extended support ends October 2031](https://learn.microsoft.com/en-us/lifecycle/products/windows-server-2022))

  * Windows 10 Professional ([support ends October 2025](https://learn.microsoft.com/en-us/lifecycle/products/windows-10-home-and-pro))
