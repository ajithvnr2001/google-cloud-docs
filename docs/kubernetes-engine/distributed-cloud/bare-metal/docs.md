# Google Distributed Cloud software only for bare metal documentation

[Read product documentation](https://docs.cloud.google.com/kubernetes-engine/distributed-cloud/bare-metal/docs/concepts/about-bare-metal)

Google Distributed Cloud software only (formerly known as Google Distributed Cloud Virtual, previously known as Anthos clusters on bare metal) lets you deploy and operate enterprise Kubernetes clusters directly on your physical hardware infrastructure with direct control over performance, security, and network latency.
