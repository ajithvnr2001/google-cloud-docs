When you need help resolving issues with Config Sync, you can use self-service troubleshooting tools, contact Cloud Customer Care for direct assistance, or check community resources for open source components. Before opening a support case, reviewing version support policies and known issues helps you resolve common configuration problems faster and verify that your installation is on a supported release.

## Before contacting support

Before contacting support, you can try and resolve issues yourself. For troubleshooting tips, see [Troubleshoot Config Sync](https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/how-to/troubleshooting-config-sync).

## Support options

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

For open source Config Sync, you can get support by checking for existing issues or opening a new issue in the [public GitHub issue tracker](https://github.com/GoogleContainerTools/config-sync/issues).

### What Google doesn't support

Google doesn't support issues with customer-owned `YAML` file configurations.

### Related tools and resources

If you install open source products, such as open source Config Sync or other tools like kpt, you can get community support for these products:

  * [Open source Config Sync](https://github.com/GoogleContainerTools/config-sync)
  * [kpt](https://kpt.dev/)
  * [Kustomize](https://kustomize.io/)



## Recommended version

We recommend that you use Config Sync version 1.24.0.

## Version support policy

Google supports each Config Sync minor version for the later of:

  * 12 months after the initial release of the minor version.
  * The release of the third subsequent minor version.



To learn more about version compatibility, including compatibility with Kubernetes versions, see [Version and upgrade support](https://docs.cloud.google.com/kubernetes-engine/enterprise/docs/version-and-upgrade-support).

The following table shows the supported versions of Config Sync and the earliest end-of-life (EOL) date for a version:

Release version | Release date | Earliest end of life date  
---|---|---  
1.24 | [May 7, 2026](https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/release-notes#May_7_2026) | May 7, 2027  
1.23 | [December 4, 2025](https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/release-notes#December_4_2025) | December 4, 2026  
1.22 | [August 21, 2025](https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/release-notes#August_21_2025) | August 21, 2026  
  
If you are on an unsupported version, then you must upgrade to a supported version to receive support. For information on how to upgrade, see [Installing Config Sync](https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/how-to/installing-config-sync#upgrade).

## Shared responsibility model

Running a business-critical production application on GKE requires multiple parties to carry different responsibilities. These responsibilities are described at [GKE shared responsibility](https://docs.cloud.google.com/kubernetes-engine/docs/concepts/shared-responsibility).

## Community resources

Use the following resources to get support from the Config Sync community.

### Ask a question on Stack Overflow

If you use kpt or Kustomize, you can use Stack Overflow tags to receive responses from the Stack Overflow community. This community includes Google engineers, who monitor the tag and offer unofficial support. You can use the following tags:

  * [kpt](https://stackoverflow.com/questions/tagged/kpt)
  * [Kustomize](https://stackoverflow.com/questions/tagged/kustomize)



### File bugs or feature requests

You can submit a product issue by using one of the following procedures:

  * **Config Sync issues and feature requests** : Check for existing issues or open new issues in the [public issue trackers](https://github.com/GoogleContainerTools/config-sync/issues) For new issues, consider including a bug report by using the [`nomos bugreport`](https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/how-to/nomos-command#bug) command.

  * **Documentation issues** : On the documentation page, select **Send feedback**. This action opens a feedback form. The Config Management team reviews and takes action on your comments.




## Billing questions

Use the following resources to get help with billing questions:

  * To learn more about billing, read the [Google Cloud billing documentation](https://docs.cloud.google.com/billing/docs).
  * Resolve billing concerns by using the [billing concerns troubleshooter](https://support.google.com/cloud/troubleshooter/7279311?ref_topic=6288636).
  * Request help with billing questions by using the [billing support form](https://support.google.com/cloud/contact/cloud_platform_billing?visit_id=1-636564925221770723-4170709031&rd=1).
