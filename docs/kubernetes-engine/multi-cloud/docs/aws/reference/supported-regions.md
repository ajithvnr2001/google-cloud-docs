Because the GKE Multi-Cloud API is regional, you must select a Google region to manage your AWS clusters from. The Google Cloud region where the GKE Multi-Cloud API is deployed in determines which AWS regions it supports. If you do not see the region you need below, contact your Google Cloud account team.

---|---
