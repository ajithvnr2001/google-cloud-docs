# Supported regions

Because the GKE Multi-Cloud API is regional, you must select a Google region to manage your Azure clusters from. The Google Cloud region where the GKE Multi-Cloud API is deployed in determines which Azure regions it supports. If you do not see the region you need below, contact your Google Cloud account team.
