# GKE on Azure security bulletins

Security vulnerabilities are usually identified by using the [Common Vulnerabilities and Exposures (CVE)](https://cve.mitre.org/) system. When GKE on Azure is affected by software or service component flaws that have the potential to compromise the security of your clusters and the information they contain, patched versions or mitigations are issued to fix the corresponding vulnerabilities.

For information about CVEs prior to June 1, 2026, see the [GKE security bulletins](https://docs.cloud.google.com/kubernetes-engine/security-bulletins). For information about CVEs on or after June 1, 2026, see the GKE on Azure release notes.
