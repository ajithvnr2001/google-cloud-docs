# Prerequisites overview

Before creating any clusters or node pools, you need to perform the following steps to install tools and create resources in Azure:

  1. [Configure the Google Cloud CLI](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/configure-cloud-sdk)

  2. [Configure the Azure CLI](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/configure-azure-cli)

  3. [Create an Azure virtual network](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/create-azure-vnet)

  4. [Configure your firewall](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/reference/firewalls)

  5. [Create an Azure resource group](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/create-azure-resource-group)

  6. [Create an Azure AD application](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/create-azure-ad-application)

  7. [Create Azure role assignments](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/create-azure-role-assignments)

  8. [Create a client certificate](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/create-azure-client)

  9. [Create an SSH key pair](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/how-to/create-ssh-keypair)
