#  Troubleshooting attached clusters Stay organized with collections  Save and categorize content based on your preferences. 

This page explains how to get information that helps diagnose issues when running Google Cloud components on [attached clusters](https://docs.cloud.google.com/anthos/docs/setup/attach-kubernetes-clusters), and that you can send to Google Cloud Support as part of a support request.

## Share cluster state

If you have an issue with an Google Cloud component on an attached cluster, it's useful to know what's happening in the underlying cluster. You can find out more about how to give Google Cloud Support read-only access to your attached cluster, as well as how to share cluster state with Support, in [Google Cloud Support for registered clusters](https://docs.cloud.google.com/anthos/docs/support/support-cluster-access).

## Issues connecting to Google Cloud

See the [fleet management troubleshooting guide](https://docs.cloud.google.com/anthos/fleet-management/docs/troubleshooting) for any issues with connecting attached clusters to Google Cloud.
