# GKE on AWS documentation

[Read product documentation](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/aws/concepts/architecture)

GKE on AWS lets you manage GKE clusters running on AWS infrastructure through the GKE Multi-Cloud API. Combined with [Connect](https://docs.cloud.google.com/anthos/multicluster-management/gateway#why_use_the_connect_gateway), GKE on AWS lets you manage GKE clusters on both Google Cloud and AWS from the Google Cloud console. [Learn more about how GKE on AWS works.](https://docs.cloud.google.com/kubernetes-engine/multi-cloud/docs/aws/concepts/architecture)

When you create a cluster with GKE on AWS, Google creates the AWS resources you need and brings up a cluster on your behalf. You can then deploy your workloads with the `gcloud` and `kubectl` command-line tools.
