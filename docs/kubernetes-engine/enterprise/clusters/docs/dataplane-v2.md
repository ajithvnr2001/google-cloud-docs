#  Dataplane version support Stay organized with collections  Save and categorize content based on your preferences. 

[Dataplane V2](https://docs.cloud.google.com/kubernetes-engine/docs/concepts/dataplane-v2) is an opinionated dataplane for Google Kubernetes Engine (GKE) clusters that is optimized for Kubernetes networking.

The following table lists which cluster environments support Dataplane V2, and which cluster environments also let you choose to use the earlier Dataplane V1.

Cluster environment | Dataplane V2 | Dataplane V1  
---|---|---  
GKE on Google Cloud | Available in GKE version 1.20.6 and later. Enabled by default for Autopilot clusters from version 1.23. See [Using Dataplane V2](https://docs.cloud.google.com/kubernetes-engine/docs/how-to/dataplane-v2) for more details. |   
Google Distributed Cloud on VMware | Available in Anthos 1.7 and later for user clusters only. See the [user cluster configuration reference](https://docs.cloud.google.com/anthos/clusters/docs/on-prem/latest/how-to/user-cluster-configuration-file#enabledataplanev2-field) for more details. |   
Google Distributed Cloud on bare metal | Dataplane V2 is built in to Google Distributed Cloud bare metal software. |   
GKE on AWS | Dataplane V2 is built in to GKE on AWS |   
GKE on Azure | Dataplane V2 is built in to GKE on Azure |
