# Knative serving documentation

[Read product documentation](https://docs.cloud.google.com/anthos/run/docs/architecture-overview)

Knative serving is Google's managed and fully supported [Knative](https://knative.dev) offering. Knative serving abstracts away the complexity of Kubernetes, making it easy to build and deploy your serverless workloads across [hybrid and multi-cloud environments](https://docs.cloud.google.com/anthos/clusters).
