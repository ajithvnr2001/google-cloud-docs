This page describes gcloud CLI commands and APIs that can be used with Cloud DNS and DNS Armor. We recommend using the v1 API methods, though some methods are only available in v1beta. To manage your Cloud DNS resources securely, authenticate your access using client libraries, the Google Cloud CLI, or REST. 

## Authentication

  * ### [Authenticate to Cloud DNS  This document describes how to authenticate to Cloud DNS if you are using client libraries, Google Cloud CLI, or REST.  ](https://docs.cloud.google.com/dns/docs/authentication)
