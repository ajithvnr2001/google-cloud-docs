To get support for Cloud DNS, see the following resources.

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Customer Care support](https://docs.cloud.google.com/support).

## Get support from the community

Ask a question about Cloud DNS on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-dns). Use the tag `google-cloud-dns` for questions about Cloud DNS. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

Join the [cloud-dns-discuss](https://groups.google.com/forum/#!forum/cloud-dns-discuss) Google group to discuss Cloud DNS.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud DNS and other Google Cloud products. 

Join the [cloud-dns-announce](https://groups.google.com/forum/#!forum/cloud-dns-announce) Google group to receive Cloud DNS announcements and updates.

## File bugs or feature requests

From the Cloud DNS documentation, click **Send feedback** near the top right of the page or at the bottom of the page. This opens a feedback form. Your comments are reviewed by the Cloud DNS team.
