**Alpha**

This feature is subject to the "Pre-GA Offerings Terms" in the General Service Terms section of the [Service Specific Terms](https://docs.cloud.google.com/terms/service-terms#1). Pre-GA features are available "as is" and might have limited support. For more information, see the [launch stage descriptions](https://cloud.google.com/products/#product-launch-stages). 

The Vision API Alpha endpoint has been shut down in September 2021. Migrate any traffic from the Alpha endpoint to the [GA (v1) endpoint](https://cloud.google.com/vision/docs/reference/rest).

Alpha features that have been discontinued are not available on the GA endpoint. To continue using document parsing features, please review this [technical documentation](https://docs.cloud.google.com/document-ai/docs) and switch to Document AI.
