## Ask a question on Stack Overflow

Ask a question about Vision API on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-vision). Please use the tag `google-cloud-vision` for questions about Vision API. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

## Discuss Vision API and get updates

Join the [cloud-vision-discuss](https://groups.google.com/forum/#!forum/cloud-vision-discuss) Google group to discuss Vision API and receive Vision API announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Vision API and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

## Get a support package

Google Cloud Platform offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Platform Support](https://docs.cloud.google.com/support).
