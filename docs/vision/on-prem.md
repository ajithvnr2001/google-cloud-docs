## Overview

OCR On-Prem enables easy integration of Google optical character recognition (OCR) technologies into your on-premises solution. The OCR On-Prem solution gives you full control over your infrastructure and protected image data in order to meet data residency and compliance requirements. This best-in-class machine learning technology gives you access to next-generation character recognition models that are more accurate, smaller in size, and require fewer computing resources to run than existing solutions.

OCR On-Prem is a [Google Cloud Marketplace](https://cloud.google.com/marketplace/) application and can be deployed as a container to any GKE cluster using GKE Enterprise*. This gives you flexibility and greater control in deployment, whether you decide to deploy on Google Cloud with GKE or on-premises with GKE Enterprise. This allows you to take advantage of the simplicity, agility, and cost-effectiveness of Google's container hosting and management across hybrid environments.

Key capabilities |   
---|---  
High quality transcription | Apply Google's advanced deep learning neural network algorithms to automatic optical character recognition.  
Deployable anywhere | Run in any GKE (using GKE Enterprise) or GKE Enterprise cluster.  
Efficient models | Deploy efficiently with models that are less than 1 GB in size and consume minimal resources.  
Stackdriver integration | Export metadata logs to one centralized location.  
API compatible | Full compatibility with the [Vision API](https://docs.cloud.google.com/vision/docs) and its client libraries.  
Supported languages | Support your global user base with language support for many latin script-based languages.  
  
This is a limited access GA product. We recommend most customers consider [Google Distributed Cloud](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/overview) instead.
