#  Maintenance changelog and security updates overview Stay organized with collections  Save and categorize content based on your preferences. 

To track software updates, new features, bug fixes, and security patches applied to your AlloyDB for PostgreSQL instances, you can review the maintenance changelogs for each supported major PostgreSQL version.

AlloyDB regularly updates the software on AlloyDB instances through new maintenance versions. With new maintenance versions, AlloyDB releases new features, security patches, bug fixes, and performance improvements.

Your AlloyDB instances are kept up to date with the latest maintenance version through [self-service maintenance](https://docs.cloud.google.com/alloydb/docs/self-service-maintenance) or through [scheduled maintenance](https://docs.cloud.google.com/alloydb/docs/maintenance#timing), which AlloyDB performs every few months.
