Conversational analytics in AlloyDB for PostgreSQL lets you chat with data agents about your database data by using natural language. To get answers about your data, you create data agents for a selected set of knowledge sources, such as tables and views, and optionally provide domain context and instructions to tailor agent responses for specific use cases.

For more information, see [Conversational analytics for AlloyDB for PostgreSQL overview](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics/alloydb).
