This page provides links to the AlloyDB Omni documentation for earlier versions of the product. Each AlloyDB Omni release version corresponds to a specific major and minor version of the underlying PostgreSQL database engine, along with AlloyDB Omni advanced features, specialized database flags, and Kubernetes operator enhancements. Referencing the documentation for your specific database version is essential for verifying feature availability, ensuring operator compatibility, and planning upgrade paths. 

You can access AlloyDB Omni on [Docker Hub](https://hub.docker.com/r/google/alloydbomni/tags), [Artifact Registry](https://gcr.io/alloydb-omni/alloydbomni), [Google Cloud Marketplace](https://docs.cloud.google.com/marketplace/docs), and [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-sne7ttiby7nxi).
