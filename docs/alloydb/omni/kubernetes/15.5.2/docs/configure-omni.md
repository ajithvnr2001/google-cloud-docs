This page shows how to configure AlloyDB Omni after you have [installed it](https://docs.cloud.google.com/alloydb/omni/kubernetes/15.5.2/docs/install). You configure and control a Kubernetes-based AlloyDB Omni database cluster by pairing declarative manifest files with the `kubectl` utility, just like any other Kubernetes-based deployment. 

Some resources that you can configure are:

  * [Manage backup and restore](https://docs.cloud.google.com/alloydb/omni/kubernetes/15.5.2/docs/backup-kubernetes)
  * [Create read pool instance in Kubernetes](https://docs.cloud.google.com/alloydb/omni/kubernetes/15.5.2/docs/kubernetes-read-pool)
  * [Use a sidecar container in Kubernetes](https://docs.cloud.google.com/alloydb/omni/kubernetes/15.5.2/docs/kubernetes-sidecar-container)
