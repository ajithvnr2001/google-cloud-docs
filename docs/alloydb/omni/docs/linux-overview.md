#  AlloyDB Omni using RPM Stay organized with collections  Save and categorize content based on your preferences. 

AlloyDB Omni using RPM is a downloadable, self-managed version of AlloyDB for PostgreSQL, available as Red Hat Package Manager (RPM). You can install AlloyDB Omni using RPM directly onto a Red Hat Enterprise Linux (RHEL) or Red Hat-compatible environment using standard operating system package managers.

[Sign up to request access to this deployment option.](https://forms.gle/zxuHekMtV67Bw9Av9)

AlloyDB Omni using RPM supports the following:

  * RHEL 9 and Rocky Linux 9
  * Bare metal servers and virtual machines



Use the RPM deployment option if you have an environment where containerization isn't preferred or where deep integration with the host operating system is required.

## Use cases

The RPM deployment option supports the following use cases:

  * Modernizing legacy applications: upgrade existing PostgreSQL workloads running on Linux servers to AlloyDB Omni using RPM to gain performance and manageability improvements without replatforming to containers.
  * Edge computing: deploy high-performance databases in remote data centers where resource constraints or operational models favor direct operating system (OS) installation.
  * Development and testing: give developers a powerful, local database instance that mirrors the production AlloyDB for PostgreSQL environment, enabling consistent testing and rapid iteration.
  * Regulated environments: run workloads in strictly controlled environments where using container runtimes might be restricted by security policies.



You can also pair your RPM deployment with the optional [AlloyDB Omni web user interface](https://docs.cloud.google.com/alloydb/omni/linux/current/docs/install-web-ui) (`alloydbomni_ui`), a self-managed web console that provides observability dashboards for cluster instances, system telemetry charts, database sizes, active database flags, columnar engine statistics, and query insights.
