# Certificate Authority Service security and compliance

## Security

Certificate Authority Service supports the following Google Cloud security products:

  * [VPC Service Controls (VPC-SC)](https://docs.cloud.google.com/vpc-service-controls/docs/supported-products)
  * [Access Transparency](https://docs.cloud.google.com/cloud-provider-access-management/access-transparency/docs/supported-services)
  * [Access Approval](https://docs.cloud.google.com/assured-workloads/access-approval/docs/supported-services)
  * [Workforce identity federation](https://docs.cloud.google.com/iam/docs/federated-identity-supported-services)
  * [Data residency](https://docs.cloud.google.com/assured-workloads/docs/data-residency)



For information about the security measures in place for Google Cloud services, see [Google Cloud Security](https://docs.cloud.google.com/security).

## Compliance

Certificate Authority Service meets the following compliance standards:

  * [ISO 27001](https://docs.cloud.google.com/security/compliance/iso-27001)
  * [ISO 27017](https://docs.cloud.google.com/security/compliance/iso-27017)
  * [ISO 27018](https://docs.cloud.google.com/security/compliance/iso-27018)
  * [SOC1](https://docs.cloud.google.com/security/compliance/soc-1)
  * [SOC2](https://docs.cloud.google.com/security/compliance/soc-2)
  * [SOC3](https://docs.cloud.google.com/security/compliance/soc-3)
  * [VPAT](https://docs.cloud.google.com/security/compliance/vpat)
  * [PCI DSS](https://docs.cloud.google.com/security/compliance/pci-dss)
  * [Cloud Computing Compliance Controls Catalog (C5)](https://docs.cloud.google.com/security/compliance/bsi-c5)
  * [FedRAMP Moderate and FedRAMP High](https://docs.cloud.google.com/security/compliance/fedramp)
  * [IRAP](https://docs.cloud.google.com/security/compliance/irap)
  * [HIPAA](https://docs.cloud.google.com/security/compliance/hipaa-compliance)
  * [CJIS](https://docs.cloud.google.com/security/compliance/cjis)
  * [ITAR](https://docs.cloud.google.com/security/compliance/itar)
  * [ISMAP](https://docs.cloud.google.com/security/compliance/ismap)



You can read more about Google Cloud compliance on the [Compliance resource center](https://docs.cloud.google.com/security/compliance).
