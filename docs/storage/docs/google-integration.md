#  Integration with Google Cloud services and tools Stay organized with collections  Save and categorize content based on your preferences. 

This page describes some of the other Google Cloud products that are integrated with Cloud Storage.

For a list of Google Cloud products that are integrated specifically with Cloud Storage FUSE, see [Cloud Storage FUSE integrations with Google Cloud products](https://docs.cloud.google.com/storage/docs/gcsfuse-integrations).

Product | Links  
---|---  
[AI Hypercomputer](https://docs.cloud.google.com/ai-hypercomputer/docs/overview) | Use Cloud Storage to store large scale training data for GPU and TPU clusters, and use Cloud Storage FUSE for most artificial intelligence (AI) and machine learning (ML) use cases. For more information, see [Storage services](https://docs.cloud.google.com/ai-hypercomputer/docs/storage).  
[App Engine](https://docs.cloud.google.com/appengine/docs/an-overview-of-app-engine) | Use Cloud Storage to [store your static assets](https://docs.cloud.google.com/appengine/docs/standard/using-cloud-storage) when using App Engine.  
[BigQuery](https://docs.cloud.google.com/bigquery/docs/introduction) | Use Cloud Storage when querying, importing, or exporting data: 

  * [ Perform federated queries on data stored in a Cloud Storage bucket](https://docs.cloud.google.com/bigquery/external-data-sources)
  * [ Load data from Cloud Storage into BigQuery](https://docs.cloud.google.com/bigquery/docs/import)
  * [ Load data from Cloud Storage to BigQuery using Workflows](https://docs.cloud.google.com/architecture/serverless-orchestration-loading-data-from-cloud-storage-to-biquery-using-workflows)
  * [ Export data from BigQuery to Cloud Storage](https://docs.cloud.google.com/bigquery/exporting-data-from-bigquery)
  * [ Transfer data from Cloud Storage to BigQuery](https://docs.cloud.google.com/bigquery/docs/cloud-storage-transfer)

  
[Cloud Asset Inventory](https://docs.cloud.google.com/asset-inventory/docs/asset-inventory-overview) | Use Cloud Asset Inventory to help you manage large numbers of Google Cloud resources, such as Cloud Storage buckets: 

  * [ Use Cloud Asset Inventory to search the metadata of all your buckets using a custom query language](https://docs.cloud.google.com/asset-inventory/docs/searching-resources)
  * [ Export asset metadata from your Cloud Asset Inventory project to a Cloud Storage bucket](https://docs.cloud.google.com/asset-inventory/docs/exporting-to-cloud-storage)

  
[Cloud CDN](https://docs.cloud.google.com/cdn/docs/overview) | Use Google's global edge network to serve content closer to users, which accelerates your websites and applications: 

  * [ Set up Cloud CDN using a Cloud Storage bucket as the backend](https://docs.cloud.google.com/cdn/docs/setting-up-cdn-with-bucket)
  * [Configure private bucket access](https://docs.cloud.google.com/cdn/docs/configure-private-bucket-access)

  
[Cloud Load Balancing](https://docs.cloud.google.com/load-balancing/docs/load-balancing-overview) | Use a Cloud Storage bucket as a load balancer backend: 

  * [ Add a Cloud Storage bucket to an external HTTP(S) load balancer](https://docs.cloud.google.com/load-balancing/docs/https/setup-global-ext-https-buckets)
  * [ Enable Cloud CDN on a load balancer with a Cloud Storage backend bucket](https://docs.cloud.google.com/cdn/docs/setting-up-cdn-with-bucket)

  
[Cloud Logging](https://docs.cloud.google.com/logging/docs/overview) | Store logs in Cloud Storage: 

  * [ Export Compute Engine logs and App Engine logs to a Cloud Storage bucket](https://docs.cloud.google.com/logging/docs/install/logs_export)

  
[Cloud Run functions](https://docs.cloud.google.com/run/docs/overview/what-is-cloud-run) | Set up functions in response to events in Cloud Storage: 

  * [ Cloud Run functions tutorial using Cloud Storage](https://docs.cloud.google.com/functions/docs/tutorials/storage)

  
[Cloud SQL](https://docs.cloud.google.com/sql/docs/introduction) | Import and export data using Cloud Storage: 

  * [ Best practices for importing and exporting data using Cloud SQL for MySQL](https://docs.cloud.google.com/sql/docs/mysql/import-export)
  * [ Best practices for importing and exporting data using Cloud SQL for PostgreSQL](https://docs.cloud.google.com/sql/docs/postgres/import-export)
  * [ Best practices for importing and exporting data using Cloud SQL for SQL Server](https://docs.cloud.google.com/sql/docs/sqlserver/import-export)

  
[Cloud Storage FUSE](https://docs.cloud.google.com/storage/docs/gcs-fuse) | Mount Cloud Storage buckets onto your local file system so you can store data using file system semantics: 

  * [ Mount Cloud Storage buckets](https://docs.cloud.google.com/storage/docs/gcsfuse-mount)

  
[Compute Engine](https://docs.cloud.google.com/compute/docs/overview) | Use Cloud Storage from within a Compute Engine instance: 

  * [ Use Service Accounts with Applications](https://docs.cloud.google.com/compute/docs/access/create-enable-service-accounts-for-instances#authenticate-with-service-account)
  * [Export an image to Cloud Storage](https://docs.cloud.google.com/compute/docs/creating-custom-image#export_an_image_to_google_cloud_storage)
  * [Use a startup script](https://docs.cloud.google.com/compute/docs/howtos/startupscript#example) stored in Cloud Storage 
  * [Mount a bucket as a file system](https://docs.cloud.google.com/compute/docs/disks#gcsbuckets) on a virtual machine instance 

  
[Config Connector](https://docs.cloud.google.com/config-connector/docs/overview) | Configure your Cloud Storage buckets using Kubernetes tooling and APIs: 

  * [ Explore the `storageBucket` schema](https://docs.cloud.google.com/config-connector/docs/reference/resource-docs/storage/storagebucket)

  
[Dataflow](https://docs.cloud.google.com/dataflow/docs/overview) | Perform data processing tasks of any size and use a Cloud Storage bucket to hold staging files and temporary data: 

  * [ Write text data from Dataflow to Cloud Storage](https://docs.cloud.google.com/dataflow/docs/guides/write-to-cloud-storage)

  
[Managed Service for Apache Spark](https://docs.cloud.google.com/dataproc/docs/concepts/overview) | Run MapReduce jobs directly on data in Cloud Storage: 

  * [ Learn about the Cloud Storage connector](https://docs.cloud.google.com/dataproc/docs/concepts/connectors/cloud-storage)

  
[ Development Tools](https://cloud.google.com/products/tools) | Add extensions to your development tools for fast access to your Cloud Storage buckets and objects: 

  * [ Browse resources in Cloud Storage with Cloud Code for IntelliJ](https://docs.cloud.google.com/code/docs/intellij/gcs)

  
[ Error Reporting](https://docs.cloud.google.com/error-reporting/docs/grouping-errors) | Identify and understand your Cloud Storage errors: 

  * [ View errors from the Google Cloud console](https://docs.cloud.google.com/error-reporting/docs/viewing-errors)
  * [ Send error notifications to selected Cloud Monitoring notification channels](https://docs.cloud.google.com/error-reporting/docs/notifications)

  
[Firebase SDKs](https://firebase.google.com/docs/storage/) | Securely and efficiently access your mobile and web app data using Firebase SDKs for Cloud Storage: 

  * [ Get started with Cloud Storage on Android](https://firebase.google.com/docs/storage/android/start)
  * [ Get started with Cloud Storage on iOS](https://firebase.google.com/docs/storage/ios/start)
  * [ Get started with Cloud Storage on Web](https://firebase.google.com/docs/storage/web/start)

  
[Google Cloud Managed Lustre](https://docs.cloud.google.com/managed-lustre/docs/overview) | Use Managed Lustre to [transfer data to and from Cloud Storage](https://docs.cloud.google.com/managed-lustre/docs/transfer-data). This lets you treat Cloud Storage as your primary data source while using Managed Lustre for active computation.   
[Lakehouse](https://docs.cloud.google.com/lakehouse/docs/introduction) | Store open-format lakehouses in Cloud Storage: 

  * [ Store Apache Iceberg tables created by open source engines](https://docs.cloud.google.com/lakehouse/docs/lakehouse-iceberg-tables)

  
[Media CDN](https://docs.cloud.google.com/media-cdn/docs/overview) | Use Google's modern and extensible content delivery platform to deliver exceptional, planet-scale experiences to your users: 

  * [ Set up Media CDN with a Cloud Storage bucket](https://docs.cloud.google.com/media-cdn/docs/origins#cloud-storage-origins)

  
[Pub/Sub](https://docs.cloud.google.com/pubsub/docs/overview) | Pub/Sub Notifications allow you to track changes to your Cloud Storage objects: 

  * [ Learn about Pub/Sub Notifications for Cloud Storage](https://docs.cloud.google.com/storage/docs/pubsub-notifications)
  * [ Learn about Pub/Sub subscriptions that automatically write messages to a Cloud Storage bucket](https://docs.cloud.google.com/pubsub/docs/cloudstorage)

  
[Sensitive Data Protection](https://docs.cloud.google.com/sensitive-data-protection/docs/sensitive-data-protection-overview) | Use Sensitive Data Protection to detect and classify sensitive data stored in Cloud Storage objects: 

  * [ Inspect a Cloud Storage location](https://docs.cloud.google.com/sensitive-data-protection/docs/inspecting-storage#inspecting-gcs)

  
[Storage Transfer Service](https://docs.cloud.google.com/storage-transfer/docs/overview) | Transfer data between Cloud Storage and other storage providers or filesystems: 

  * [Transfer data between Cloud Storage buckets](https://docs.cloud.google.com/storage-transfer/docs/cloud-storage-to-cloud-storage)
  * [Transfer data to and from Cloud Storage](https://docs.cloud.google.com/storage-transfer/docs/create-transfers)
  * [Use event-driven transfers](https://docs.cloud.google.com/storage-transfer/docs/event-driven-transfers) to keep a Cloud Storage bucket in sync with an Amazon S3 or Cloud Storage source

  
[Vertex AI](https://docs.cloud.google.com/vertex-ai/docs) | Store your Vertex AI model data and output in Cloud Storage: 

  * [ Learn how to train and use models in Vertex AI](https://docs.cloud.google.com/vertex-ai/docs/datasets/create-dataset-console)
  * [ Import models to Vertex AI](https://docs.cloud.google.com/vertex-ai/docs/model-registry/import-model)
  * [ Get batch predictions](https://docs.cloud.google.com/vertex-ai/docs/predictions/batch-predictions)

  
[VPC Service Controls](https://docs.cloud.google.com/vpc-service-controls/docs/overview) | Create perimeters to protect the resources and data in Cloud Storage: 

  * [ Create a service perimeter to protect buckets](https://docs.cloud.google.com/vpc-service-controls/docs/create-service-perimeters)
  * [ Details and limitations of using VPC Service Controls with Cloud Storage](https://docs.cloud.google.com/vpc-service-controls/docs/supported-products#table_storage)
