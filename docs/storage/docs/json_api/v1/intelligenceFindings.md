# REST resources

This page provides an overview of the REST resources for Intelligence Findings.

## Intelligence findings

### `projects.locations.intelligenceFindings` resource

Methods  
---  
`[get](https://docs.cloud.google.com/storage/docs/json_api/v1/intelligenceFindings/projects.locations.intelligenceFindings/get)` | Gets the `IntelligenceFinding` resource for a project.  
`[list](https://docs.cloud.google.com/storage/docs/json_api/v1/intelligenceFindings/projects.locations.intelligenceFindings/list)` | Lists the `IntelligenceFinding` resources in the specified project.  
`[summarize](https://docs.cloud.google.com/storage/docs/json_api/v1/intelligenceFindings/projects.locations.intelligenceFindings/summarize)` | Summarizes the intelligence findings for the specified scope, such as an organization, folder, or project.  
  
### `projects.locations.intelligenceFindings.revisions` resource

Methods  
---  
`[get](https://docs.cloud.google.com/storage/docs/json_api/v1/intelligenceFindings/projects.locations.intelligenceFindings.revisions/get)` | Gets the `IntelligenceFindingRevision` resource.  
`[list](https://docs.cloud.google.com/storage/docs/json_api/v1/intelligenceFindings/projects.locations.intelligenceFindings.revisions/list)` | Lists all the revisions of an `IntelligenceFinding` resource.
