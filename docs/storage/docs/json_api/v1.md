#  Overview of resources and methods for the JSON API Stay organized with collections  Save and categorize content based on your preferences. 

This guide contains technical reference information for the Cloud Storage JSON API. Like the [XML API](https://docs.cloud.google.com/storage/docs/xml-api-overview), it is RESTful, but it has slightly different URI endpoints and request syntax, and is specifically intended to be used with the [Google Cloud Client Libraries](https://docs.cloud.google.com/storage/docs/reference/libraries).

This API reference is organized by resource type. Each resource type has one or more data representations and one or more methods.

URIs are relative to `https://storage.googleapis.com/storage/v1`, unless otherwise noted.

## AnywhereCache

For `AnywhereCache` Resource details, see the [resource representation](https://docs.cloud.google.com/storage/docs/json_api/v1/AnywhereCache) page.

Method | HTTP request | Description  
---|---|---  
[create](https://docs.cloud.google.com/storage/docs/json_api/v1/AnywhereCaches/create) | `POST /b/BUCKET/anywhereCaches/ANYWHERE_CACHE_ID` | Creates a [cache instance](https://docs.cloud.google.com/storage/docs/rapid/rapid-cache) in a specified bucket.  
[disable](https://docs.cloud.google.com/storage/docs/json_api/v1/AnywhereCaches/disable) | `POST /b/BUCKET/anywhereCaches/ANYWHERE_CACHE_ID/disable` | Disables a [cache instance](https://docs.cloud.google.com/storage/docs/rapid/rapid-cache) in a specified bucket.  
[get](https://docs.cloud.google.com/storage/docs/json_api/v1/AnywhereCaches/get) | `GET /b/BUCKET/anywhereCaches/ANYWHERE_CACHE_ID` | Retrieves a [cache instance](https://docs.cloud.google.com/storage/docs/rapid/rapid-cache) for a specified bucket.  
[list](https://docs.cloud.google.com/storage/docs/json_api/v1/AnywhereCaches/list) | `LIST /b/BUCKET/anywhereCaches` | Retrieves a list of [cache instances](https://docs.cloud.google.com/storage/docs/rapid/rapid-cache) for a specified bucket.  
[resume](https://docs.cloud.google.com/storage/docs/json_api/v1/AnywhereCaches/resume) | `POST /b/BUCKET/anywhereCaches/ANYWHERE_CACHE_ID/resume` | Resumes a [cache instance](https://docs.cloud.google.com/storage/docs/rapid/rapid-cache) in a specified bucket from being disabled.  
[update](https://docs.cloud.google.com/storage/docs/json_api/v1/AnywhereCaches/update) | `PUT /b/BUCKET/anywhereCaches/ANYWHERE_CACHE_ID` | Updates a [cache instance](https://docs.cloud.google.com/storage/docs/rapid/rapid-cache) in a specified bucket. Only caches in the `RUNNING` state can be updated.  
  
## BucketAccessControls

For `BucketAccessControls` Resource details, see the [resource representation](https://docs.cloud.google.com/storage/docs/json_api/v1/bucketAccessControls#resource) page.

Method | HTTP request | Description  
---|---|---  
[delete](https://docs.cloud.google.com/storage/docs/json_api/v1/bucketAccessControls/delete) | `DELETE /b/BUCKET/acl/ENTITY` | Permanently deletes the ACL entry for the specified entity on the specified [bucket](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets#resource).  
[get](https://docs.cloud.google.com/storage/docs/json_api/v1/bucketAccessControls/get) | `GET /b/BUCKET/acl/ENTITY` | Returns the ACL entry for the specified entity on the specified bucket.  
[insert](https://docs.cloud.google.com/storage/docs/json_api/v1/bucketAccessControls/insert) | `POST /b/BUCKET/acl` | Creates a new ACL entry on the specified [bucket](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets#resource).  
[list](https://docs.cloud.google.com/storage/docs/json_api/v1/bucketAccessControls/list) | `GET /b/BUCKET/acl` | Retrieves ACL entries on a specified [bucket](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets#resource).  
[patch](https://docs.cloud.google.com/storage/docs/json_api/v1/bucketAccessControls/patch) | `PATCH /b/BUCKET/acl/ENTITY` | Updates an ACL entry on the specified [bucket](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets#resource). This method supports [patch](https://docs.cloud.google.com/storage/docs/json_api#patch) semantics.  
[update](https://docs.cloud.google.com/storage/docs/json_api/v1/bucketAccessControls/update) | `PUT /b/BUCKET/acl/ENTITY` | Updates an ACL entry on the specified [bucket](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets#resource).  
  
## Buckets

For `Buckets` Resource details, see the [resource representation](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets#resource) page.

Method | HTTP request | Description  
---|---|---  
[delete](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/delete) | `DELETE /b/BUCKET` | Permanently deletes an empty bucket.  
[get](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/get) | `GET /b/BUCKET` | Returns metadata for the specified bucket.  
[getIamPolicy](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/getIamPolicy) | `GET /b/BUCKET/iam` | Returns an IAM policy for the specified bucket.  
[insert](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/insert) | `POST /b` | Creates a new bucket.  
**Required query parameters:** `project`  
[list](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/list) | `GET /b` | Retrieves a list of buckets for a given project.  
**Required query parameters:** `project`  
[lockRetentionPolicy](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/lockRetentionPolicy) | `POST /b/BUCKET/lockRetentionPolicy` | Irreversibly sets the retention policy on a bucket.  
**Required query parameters:** `ifMetagenerationMatch`  
[patch](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/patch) | `PATCH /b/BUCKET` | Updates a bucket. Changes to the bucket will be readable immediately after writing, but configuration changes may take time to propagate. This method supports [patch](https://docs.cloud.google.com/storage/docs/json_api#patch) semantics.  
[relocate](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/relocate) | `POST /b/BUCKET/relocate` | Initiates the [dry run](https://docs.cloud.google.com/storage/docs/bucket-relocation/relocate-buckets#dry-run) or the [initiate bucket relocation](https://docs.cloud.google.com/storage/docs/bucket-relocation/relocate-buckets#initiate-relocation) step of a [bucket relocation operation](https://docs.cloud.google.com/storage/docs/bucket-relocation/overview).  
[restore](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/restore) | `POST /b/BUCKET/restore` | Restores a soft-deleted bucket.  
[setIamPolicy](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/setIamPolicy) | `PUT /b/BUCKET/iam` | Updates an IAM policy for the specified bucket.  
[testIamPermissions](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/testIamPermissions) | `GET /b/BUCKET/iam/testPermissions` | Tests a set of permissions on the given bucket to see which, if any, are held by the caller.  
**Required query parameters:** `permissions`  
[update](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/update) | `PUT /b/BUCKET` | Updates a bucket. Changes to the bucket will be readable immediately after writing, but configuration changes may take time to propagate. This method sets the complete metadata of a bucket. If you want to change some of a bucket's metadata while leaving other parts unaffected, use the [PATCH](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/patch) method instead.

## Objects

For `Objects` Resource details, see the [resource representation](https://docs.cloud.google.com/storage/docs/json_api/v1/objects#resource) page.

Method | HTTP request | Description  
---|---|---  
[compose](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/compose) | `POST /b/BUCKET/o/DESTINATION_OBJECT/compose` | Concatenates a list of existing objects into a new object in the same bucket.  
[copy](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/copy) | `POST /b/SOURCE_BUCKET/o/SOURCE_OBJECT/copyTo/b/DESTINATION_BUCKET/o/DESTINATION_OBJECT` | Copies a source object to a destination object. Optionally overrides metadata.  
[delete](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/delete) | `DELETE /b/BUCKET/o/OBJECT` | Deletes an object and its metadata. Deletions are permanent if versioning is not enabled for the bucket, or if the `generation` parameter is used.  
[get](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/get) | `GET /b/BUCKET/o/OBJECT` | Retrieves an object or its metadata.  
[insert](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/insert) | `POST https://storage.googleapis.com/upload/storage/v1/b/BUCKET/o` and `POST /b/BUCKET/o` | Stores a new object and metadata. This method supports `simple`, `multipart`, and `resumable` upload types. For more information, see [Object uploads](https://docs.cloud.google.com/storage/docs/uploads).  
[list](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/list) | `GET /b/BUCKET/o` | Retrieves a list of objects matching the criteria.  
[patch](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/patch) | `PATCH /b/BUCKET/o/OBJECT` | Updates a data blob's associated metadata. This method supports [patch](https://docs.cloud.google.com/storage/docs/json_api#patch) semantics.  
[rewrite](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/rewrite) | `POST /b/SOURCE_BUCKET/o/SOURCE_OBJECT/rewriteTo/b/DESTINATION_BUCKET/o/DESTINATION_OBJECT` | Rewrites a source object to a destination object. Optionally overrides metadata.  
[update](https://docs.cloud.google.com/storage/docs/json_api/v1/objects/update) | `PUT /b/BUCKET/o/OBJECT` | Updates an object's metadata.
