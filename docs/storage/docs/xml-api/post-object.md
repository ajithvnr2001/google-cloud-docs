#  POST Object Stay organized with collections  Save and categorize content based on your preferences. 

Use a POST object request to:

  * [Initiate a resumable upload](https://docs.cloud.google.com/storage/docs/xml-api/post-object-resumable)
  * [Initiate a multipart upload](https://docs.cloud.google.com/storage/docs/xml-api/post-object-multipart)
  * [Complete a multipart upload](https://docs.cloud.google.com/storage/docs/xml-api/post-object-complete)
  * [Upload an object using an HTML form](https://docs.cloud.google.com/storage/docs/xml-api/post-object-forms)



For simple uploads with the XML API, you make a [`PUT` Object](https://docs.cloud.google.com/storage/docs/xml-api/put-object) request instead of using `POST` Object.
