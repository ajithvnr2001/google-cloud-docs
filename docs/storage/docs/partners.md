This page lists Google Cloud partner solutions for backing up workloads to Cloud Storage.

## Cohesity

Cohesity provides tools for data security, threat detection, backup, recovery, and analytics.

Learn more in Cloud Marketplace:

  * [Cohesity DataProtect](https://console.cloud.google.com/marketplace/product/cohesity-gcp-marketplace/cohesity-dataprotect)
  * [Cohesity NetBackup Enterprise Americas](https://console.cloud.google.com/marketplace/product/veritas-mp-americas-public/cohesity-netbackup-enterprise)
  * [Cohesity NetBackup Enterprise EMEA/Asia Pacific](https://console.cloud.google.com/marketplace/product/veritas-mp-ireland-public/cohesity-netbackup-enterprise-emea-apj)
  * [Cohesity Cloud Edition (BYOL)](https://console.cloud.google.com/marketplace/product/cohesity-gcp-marketplace/cohesity-cloud-edition-byol)



## Commvault

Commvault provides tools for data discovery, protection, and recovery.

Learn more in Cloud Marketplace:

  * [Commvault Backup and Recovery](https://console.cloud.google.com/marketplace/product/cvlt-marketplace-public/commvaultcomplete)
  * [Commvault Cloud Backup and Recovery for Google Workspace](https://console.cloud.google.com/marketplace/product/cvlt-marketplace-public/commvault-cloud-backup-recovery-for-google-workspace)
  * [Commvault Cloud Rewind](https://console.cloud.google.com/marketplace/product/appranix/appranix)



## Dell Technologies

Dell Technologies provides tools for data protection, backup, recovery, and replication.

Learn more in Cloud Marketplace:

  * [PowerProtect Data Domain Virtual Edition for Google](https://console.cloud.google.com/marketplace/product/dellemc-ddve-public/powerprotect-dd-virtual-edition)
  * [Dell Data Protection Suite](https://console.cloud.google.com/marketplace/product/dellemc-ddve-public/dell-dps-plus)



## HYCU

HYCU provides tools for automated data backup and recovery.

Learn more in Cloud Marketplace:

  * [HYCU R-Cloud](https://console.cloud.google.com/marketplace/product/hycu-saas/hycu-idp-gcp)



## Rubrik

Rubrik provides tools for data management, security, backup, recovery, replication, and migration to Google Cloud.

Learn more in Cloud Marketplace:

  * [Cloud Native Protection for Google Cloud](https://console.cloud.google.com/marketplace/product/rubrik-public/rubrik-cloud-data-management-for-google-cloud-platform)
  * [Rubrik Security Cloud](https://console.cloud.google.com/marketplace/product/rubrik-public/rubrik-security-cloud)



## Veeam

Veeam provides tools for data resiliency, backup, recovery, portability, security, and analytics.

Learn more in Cloud Marketplace:

  * [Veeam Universal License](https://console.cloud.google.com/marketplace/product/veeam-marketplace-public/veeam-universal-license)
