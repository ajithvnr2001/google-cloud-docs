# Create a connection

This page describes the generic steps to create a connection.

To create a connection, perform the following steps:

  1. In the [Cloud console](https://console.cloud.google.com/), go to the **Integration Connectors > Connections** page and then select or create a Google Cloud project. 

[ Go to the Connections page ](https://console.cloud.google.com/connectors/connections)

  2. Click **\+ Create new** to open the **Create Connection** page.



For information on creating a connection for a specific data source, refer to the corresponding connector page available in [all connectors reference](https://docs.cloud.google.com/integration-connectors/docs/connector-reference-overview). 

While most of the steps to create a connection are same for all the connectors, the authentication mechanism might vary from connector to connector.

**Note:** Your connection might be reset when the underlying infrastructure is restarted or updated. We recommend that you configure error handling strategies to re-establish the connection. For information about how to configure error handling strategies for Application Integration tasks, see [Configure error handling](https://docs.cloud.google.com/application-integration/docs/error-handling-strategy#configure-error-handling-strategies).
