# Delete a connection

To delete a connection do the following steps: 

  1. Open the **Connections** page. 

[ Go to the Connections page](https://console.cloud.google.com/connectors/connections)

  2. Locate the row containing the connection you want to delete.
  3. Click the **More** icon in the **Actions** column of the required connection, and then select **Delete** from the list of available actions. 
  4. Click **Delete** in the confirmation dialog.

**Note:** You can't delete a connectionn if there are active [event subscriptions](https://docs.cloud.google.com/integration-connectors/docs/eventsubscription) for the connection.
