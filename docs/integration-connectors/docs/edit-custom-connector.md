# Edit a custom connector

This page describes how to edit a custom connector. To understand what is a custom connector, see [Custom connectors](https://docs.cloud.google.com/integration-connectors/docs/custom-connectors).

## Edit a custom connector

To edit a custom connector, do the following steps:

  1. In the Console, go to custom connectors page. 

[ Go to the Custom connectors page](https://console.cloud.google.com/integrations/custom-connectors)

This displays the list of all the available custom connectors.

  2. Click the custom connector that you want to edit. This opens the connector details page.
  3. Click **Edit**.
  4. Edit the required details, and then click **Save**.
