# Integration Connectors locations

Integration Connectors is _regional_ , which means the infrastructure that runs your connectors is located in a specific region, and Google manages it so that it is available redundantly across [all the zones within a region](https://docs.cloud.google.com/docs/geography-and-regions). 

**Note:** Your [integration](https://docs.cloud.google.com/application-integration/docs/overview) and the connection used in the integration can be in different regions. However, if you want your data to reside in a single region, you can configure the same region for both your integration and the connection.

**Note:** You can use a maximum of 20 unique locations to configure all your connections. For example, if you have created 20 connections where each connection uses a different location, you can't create a new 21st connection in a different location. The new connection must use any one of your 20 locations that you are already using.
