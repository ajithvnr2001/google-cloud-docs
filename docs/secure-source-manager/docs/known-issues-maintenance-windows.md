#  Known issues and maintenance windows Stay organized with collections  Save and categorize content based on your preferences. 

This page lists scheduled downtime and known issues for Secure Source Manager.

## Maintenance windows

  * Cloud SQL: Every Sunday 4 - 5 AM EST 
    * Downtime is less than 60 seconds on average. For more information on Cloud SQL maintenance impact, see [Maintenance impact](https://docs.cloud.google.com/sql/docs/mysql/maintenance#maintenance_impact) on average.
  * Production rollout for Secure Source Manager is every Monday. 
    * If there are no major infrastructure updates, downtime is less than 1 minute per instance.
    * If a major infrastructure update is needed, downtime could be 1 hour or more.



## Known issues

  * Notifications: there are no email or chat notifications. Visit individual repository pages to view pull requests or issues assigned to you.
