Universal Ledger API.

## Service: universalledger.googleapis.com

The Service name `universalledger.googleapis.com` is needed to create RPC client stubs.

## `[google.cloud.location.Locations](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.location#google.cloud.location.Locations)`

Methods  
---  
``[GetLocation](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.location#google.cloud.location.Locations.GetLocation)`` |  Gets information about a location.  
``[ListLocations](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.location#google.cloud.location.Locations.ListLocations)`` |  Lists information about the supported locations for this service.  
  
## `[google.cloud.universalledger.v1.UniversalLedger](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger)`

Methods  
---  
``[GetEndpoint](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger.GetEndpoint)`` |  Gets the details of a specific endpoint.  
``[ListEndpoints](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger.ListEndpoints)`` |  Lists all endpoints for a given project and location.  
``[QueryAccount](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger.QueryAccount)`` |  Queries all the information stored about an account in the network.  
``[QueryData](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger.QueryData)`` |  Queries the network for information stored on the ledger, such as accounts and transactions.  
``[QueryTransactionState](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger.QueryTransactionState)`` |  Queries the state of a transaction.  
``[SubmitOperationalTransaction](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger.SubmitOperationalTransaction)`` |  Submits an operational transaction to the network.  
``[SubmitTransaction](https://docs.cloud.google.com/universal-ledger/reference/rpc/google.cloud.universalledger.v1#google.cloud.universalledger.v1.UniversalLedger.SubmitTransaction)`` |  Submits a transaction to the network.
