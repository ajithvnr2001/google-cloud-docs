#  Connect to Spanner from other Google Cloud services Stay organized with collections  Save and categorize content based on your preferences. 

This page describes some of the other Google Cloud products that are integrated with Spanner.

Product | Links  
---|---  
[App Engine flexible environment](https://docs.cloud.google.com/appengine/docs/flexible) | Use Spanner [client libraries](https://docs.cloud.google.com/spanner/docs/reference/libraries) in the App Engine flexible environment.  
[App Engine standard environment](https://docs.cloud.google.com/appengine/docs/standard/runtimes), second generation runtime | Use Spanner [client libraries](https://docs.cloud.google.com/spanner/docs/reference/libraries) in second generation runtimes.  
[App Engine standard environment](https://docs.cloud.google.com/appengine/docs/standard/runtimes), first generation runtime | Use the [REST API](https://docs.cloud.google.com/spanner/docs/reference/rest) in first generation runtimes.  
[Cloud Run](https://docs.cloud.google.com/run/docs/using-gcp-services#connecting_to_services_in_code) | Use Spanner [client libraries](https://docs.cloud.google.com/spanner/docs/reference/libraries) from Cloud Run.  
[Cloud Run functions](https://docs.cloud.google.com/run/docs/functions-with-run) | Use Spanner [client libraries](https://docs.cloud.google.com/spanner/docs/reference/libraries) from Cloud Run functions. See [Using Spanner with Cloud Run functions](https://docs.cloud.google.com/run/docs/tutorials/function-sends-query-to-spanner-database).  
[Dataflow](https://docs.cloud.google.com/dataflow) | See [Import, export, and modify data using Dataflow](https://docs.cloud.google.com/spanner/docs/dataflow-connector), [Export databases from Spanner to Avro](https://docs.cloud.google.com/spanner/docs/export), [Import databases from Spanner to Avro](https://docs.cloud.google.com/spanner/docs/import) and [Import and export data in CSV format](https://docs.cloud.google.com/spanner/docs/import-export-csv).  
[Cloud Storage](https://docs.cloud.google.com/storage) | Move Spanner databases to and from Avro or CSV files stored in Cloud Storage. See [Export databases from Spanner to Avro](https://docs.cloud.google.com/spanner/docs/export), [Import databases from Spanner to Avro](https://docs.cloud.google.com/spanner/docs/import) and [Import and export data in CSV format](https://docs.cloud.google.com/spanner/docs/import-export-csv).  
[Compute Engine](https://docs.cloud.google.com/compute) | Use Spanner [client libraries](https://docs.cloud.google.com/spanner/docs/reference/libraries) from within a Compute Engine instance. See [Using Spanner in a virtual machine instance](https://docs.cloud.google.com/spanner/docs/configure-virtual-machine-instance).  
[Data Agent Kit](https://docs.cloud.google.com/data-agent-kit) | Manage your Spanner database and execute queries directly in Visual Studio  
  
Code or a supported CLI using Google Cloud Data Agent Kit. See [Data Agent Kit overview](https://docs.cloud.google.com/data-agent-kit/overview). [GKE](https://docs.cloud.google.com/kubernetes-engine) | Use Spanner [client libraries](https://docs.cloud.google.com/spanner/docs/reference/libraries) with GKE. See [Connect Spanner with a Google Kubernetes Engine (GKE) cluster](https://docs.cloud.google.com/spanner/docs/connect-gke-cluster). [Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform/overview) | Use [Spanner Agent Platform integration](https://docs.cloud.google.com/spanner/docs/ml). [Looker](https://docs.cloud.google.com/looker/docs) | See [Connect Spanner to Looker](https://docs.cloud.google.com/spanner/docs/partners/looker) for an overview of how Looker relates to Spanner, or see Looker's [Spanner](https://docs.cloud.google.com/looker/docs/db-config-cloud-spanner) page for configuration instructions required within Looker.
