#  TAN Stay organized with collections  Save and categorize content based on your preferences. 

Returns the tangent of an angle.

## Sample usage

`TAN(Angle)`

## Syntax

`TAN( X )`

### Parameters

  * `X` \- a field or expression containing at least one field. This value must be in radians.



## Examples

Example formula  |  Input(Radians)  |  Output   
---|---|---  
` TAN(Angle) ` |  0  |  0   
` TAN(Angle) ` |  0.785  |  1
