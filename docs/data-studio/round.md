# ROUND

Rounds a number to a certain number of decimal places according to standard rules.

## Sample usage

`ROUND(Height,1)`

## Syntax

`ROUND( X , Y )`

### Parameters

  * `X` \- a field or expression containing at least one field.
  * `Y` \- a whole number specifying the number of decimal places in the result.



## Examples

Example formula | Input | Output  
---|---|---  
` ROUND(Height, 1) ` |  Height : 2.35  |  2.4   
` ROUND(Height, 2) ` |  Height : 2.35  |  2.35
