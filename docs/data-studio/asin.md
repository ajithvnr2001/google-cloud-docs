#  ASIN Stay organized with collections  Save and categorize content based on your preferences. 

Returns the inverse of the sine function in radians.

## Sample usage

```ASIN(Number)```

## Syntax

```ASIN( X )```

### Parameters

  * `X` \- a field or expression containing at least one field.



## Examples

Example formula | Input | Output (radians)  
---|---|---  
` ASIN(Number) ` |  0  |  0   
` ASIN(Number) ` |  1  |  1.57
