#  Report a problem with Data Studio Stay organized with collections  Save and categorize content based on your preferences. 

Are you having trouble with Data Studio? You can use this page as a template for reporting issues to the Data Studio team.

## Before reporting a problem

Your feedback is very important to improving Data Studio. However, before you report a problem, consider taking the following steps:

  1. Try to [troubleshoot the issue by using this guide](https://docs.cloud.google.com/data-studio/troubleshooting-guide).
  2. See if other people have resolved similar issues by searching in the [Data Studio Community](https://www.googlecloudcommunity.com/gc/Looker-Studio/bd-p/looker-studio-pro).



If the troubleshooting steps don't resolve your issue, and you can't find a solution in the Data Studio Community, create a new post, and provide as much of the requested information as possible. Instructions for submitting your problem report are at the end of this page.

### Error ID

Do you see an error ID? Include it here:

Error IDs are typically 8-character strings with a combination of letters and numbers. For example, "66894d57". To find the error ID, click the "See details" link, if one is included in the initial error message. The error ID will (may) appear in the details dialog. The dialog also displays two buttons: **SEND FEEDBACK** , which submits the feedback, and **MAYBE LATER** , which dismisses the dialog.

## Example report

Create a test report that demonstrates the issue you are reporting. This report should be as specific as possible. For example, make a copy of the original report, then remove extra pages, charts, filters, etc. that aren't required to demonstrate the problem. Review the [Troubleshooting guide](https://docs.cloud.google.com/data-studio/troubleshooting-guide#strategies_for_troubleshooting_more_complex_issues) for tips on troubleshooting more complex issues. for tips.

### Link to your report

Example: `https://datastudio.google.com/reporting/your-report-id`

### HOW TO SHARE YOUR REPORT WITH GOOGLE

Share your report with data-studio-help@google.com and grant **Can Edit** access.

**Note:** That address is an unmonitored alias our engineers can use to look for technical background issues with reports. You won't be able to ask questions or receive answers there.

**Please DO NOT SHARE reports that contain personal information (PII) about you or your users.** If necessary, create a new report without any PII that demonstrates the problem and share that one instead.

## Send your feedback

To report a problem with Data Studio, use the **Send feedback** option:

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. Click ![](https://docs.cloud.google.com/static/data-studio/images/helpbaselinep900fill0wght400grad0opsz24-2024-05-03.png)**Help options**.
  3. Click **Help**.
  4. Click ![Send feedback icon.](https://docs.cloud.google.com/static/data-studio/images/chatinfobaselinep900fill0wght400grad0opsz24-2024-05-03.png)**Send feedback**.
