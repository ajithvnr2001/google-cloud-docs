# REPLACE

Returns a copy of the original text, replacing all occurrences of the search text with the replacement text.

## Sample usage

`REPLACE(Campaign, "Summer", "Spring")`

## Syntax

`REPLACE( X, Y, Z )`

### Parameters

  * `X` \- a field or an expression of any type.
  * `Y` \- a field or an expression of any type.
  * `Z` \- a field or an expression of any type.



## Examples

Example formula | Input | Output  
---|---|---  
` REPLACE(Campaign,"Summer","Spring") ` |  Summer Sale  |  Spring Sale   
` REPLACE(Campaign,"Sale","Discount") ` |  Summer Sale  |  Summer Discount
