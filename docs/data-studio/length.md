#  LENGTH Stay organized with collections  Save and categorize content based on your preferences. 

Returns the number of characters in a specified text.

## Sample usage

`LENGTH(Campaign)`

## Syntax

`LENGTH( X )`

### Parameters

  * `X` \- literal text, a field, or an expression containing at least one field.



## Examples

Example formula | Input | Output  
---|---|---  
` LENGTH(Campaign) ` |  Summer Sale  |  11   
` LENGTH(Campaign) ` |  Summer @2019 Sale  |  17
