Here are the basic requirements to view and create reports in Data Studio:

## What you need to view reports

To view a Data Studio report, all you need is a browser and an internet connection. A Google Account is **not required** to view reports.

## What you need to create and edit reports and data sources

To create or edit a file in Data Studio, you must meet the following requirements:

  * Be signed into a Google Account 
    * Learn how to [sign in to your a non-Gmail address with another email address](https://support.google.com/accounts/answer/176347).
  * Be in one of the supported regions
  * Accept the [Looker Studio Terms of Service and Policies](https://cloud.google.com/terms/data-studio)



If you are a Google Workspace user, your administrator may need to enable Data Studio.

### Age restrictions

Data Studio is not available to users under age 18, unless you have a Google Workspace account.

## Supported browsers

We've tested Data Studio on the Chrome, Firefox, and Safari browsers. Editing reports and data sources on other browsers is not recommended at this time.

## Supported regions

You can use Data Studio anywhere, with the following exceptions:

### List of unsupported regions

  * Crimea
  * Cuba
  * Iran
  * Iraq
  * North Korea
  * People's Republic of China*
  * Russia
  * Syria



* You may view but not create reports in this country.

## Supported languages

Data Studio is available in 37 languages and supports number, date, and time formats in those languages. Data Studio can also handle 59 international currencies. To use Data Studio in a particular language, set your [Google account language preference](https://myaccount.google.com/personal-info) to that language.
