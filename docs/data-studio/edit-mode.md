#  Edit mode Stay organized with collections  Save and categorize content based on your preferences. 

The "modify" mode for a Data Studio report that lets you edit the report or create a new report. To switch from [view mode](https://docs.cloud.google.com/data-studio/view-mode) to edit mode, do the following:

> While viewing a report, click the **Edit** button in the toolbar.

**Note:** You must have edit permission to see the **Edit** button. This means you either need to have created the report or the creator must have shared the report with you with the edit permission.
