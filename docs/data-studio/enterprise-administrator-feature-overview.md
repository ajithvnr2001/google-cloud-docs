#  Data Studio enterprise administration Stay organized with collections  Save and categorize content based on your preferences. 

**Note:** Organization administrators manage Looker Studio's enterprise features using the Google Admin console.

As an enterprise administrator, you can review and control how Data Studio is used in your organization by using the Google Admin console. [Cloud Identity](https://docs.cloud.google.com/identity/docs/set-up-cloud-identity-admin) and [Google Workspace administrators](https://support.google.com/a/answer/2405986) can manage many administrative tasks by using the Data Studio **Enterprise admin** panel or by utilizing Data Studio's Cloud Identity integration. Google Workspace administrators can also [transfer ownership](https://support.google.com/a/answer/33314) of Data Studio assets.

> [Learn more about Data Studio enterprise features](https://support.google.com/a/answer/9706918).
