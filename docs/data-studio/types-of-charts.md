#  Types of charts in Data Studio Stay organized with collections  Save and categorize content based on your preferences. 

Data Studio's drag-and-drop editor lets you visualize data with various chart types, analyze information with your team, and share insights. You can visualize your data in Data Studio by using the following charts, graphs, and tables.

[Learn how to add charts and controls to your reports](https://docs.cloud.google.com/data-studio/add-charts-and-controls-to-your-report).

####  ![](https://docs.cloud.google.com/static/data-studio/images/scorecard-icon-2023-05-16.png) Scorecard 

Use a scorecard to display a summary of a single metric. [Learn more about scorecards](https://docs.cloud.google.com/data-studio/scorecard-reference).

**Chart variations:** Scorecard with compact numbers. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/table-icon-2023-05-16.png) Table 

Use a table to turn your data into a chart that can be sorted and paged. [Learn more about tables](https://docs.cloud.google.com/data-studio/table-reference). 

**Chart variations:** Table with bars, table with heatmap. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/table-icon-2023-05-16.png) Pivot table 

Use a pivot table to reorganize and summarize your data. [Learn more about pivot tables](https://docs.cloud.google.com/data-studio/pivot-table-reference).

####  ![](https://docs.cloud.google.com/static/data-studio/images/line-chart-icon-2023-05-16.png) Time series 

Use a time series chart to look at how your data changes over time. [ Learn more about time series charts](https://docs.cloud.google.com/data-studio/time-series-reference). 

**Chart variations:** Sparkline chart, smoothed time series chart. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/column-chart-icon-2023-05-16.png) Bar and Column 

Use a bar or column chart to show one or more categories, or groups, of data, especially if each category has subcategories. [ Learn more about bar and column charts](https://docs.cloud.google.com/data-studio/bar-chart-and-column-chart-reference). 

**Chart variations:** Bar chart, column chart, stacked column chart, 100% stacked column chart, stacked bar chart, 100% stacked bar chart. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/pie-chart-icon-2023-05-16.png) Pie 

Use a pie chart to show data as "slices of pie," or proportions of a whole. [ Learn more about pie charts](https://docs.cloud.google.com/data-studio/pie-chart-reference). 

**Chart variations:** Donut chart 

####  ![](https://docs.cloud.google.com/static/data-studio/images/combo-chart-icon-2023-05-16.png) Combo 

Use a combo chart to show each data series as a different marker type, either a column or a line. [ Learn more about combo charts](https://docs.cloud.google.com/data-studio/line-chart-and-combo-chart-reference). 

**Chart variations:** Stacked combo chart, line chart, smoothed line chart. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/geo-chart-icon-2023-05-16.png) Geo 

Use a geo chart to show a map of a country, continent, or region. The values for each location will be shown with colors. [ Learn more about geo charts](https://docs.cloud.google.com/data-studio/geo-chart-reference). 

####  ![](https://docs.cloud.google.com/static/data-studio/images/google-maps-icon-2023-05-16.png) Google Maps 

Use a Google Map to explore geographic data. [ Learn more about Google Maps](https://docs.cloud.google.com/data-studio/google-maps-reference).

**Chart variations:** Bubble map, filled map, heat map, line map.

####  ![](https://docs.cloud.google.com/static/data-studio/images/area-chart-splash-image-140-x-100.png) Area 

Use an area chart to emphasize graphically the differences of changes in value between categories of data. [Learn more about area charts](https://docs.cloud.google.com/data-studio/area-chart-reference). 

**Chart variations:** Stacked area chart, 100% stacked area chart. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/scatter-chart-icon-2023-05-16.png) Scatter 

Use a scatter chart to show numeric coordinates along the horizontal (X) and vertical (Y) axes and to look for trends and patterns between two variables. [Learn more about scatter charts](https://docs.cloud.google.com/data-studio/scatter-chart-reference). 

**Chart variations:** Bubble chart 

####  ![](https://docs.cloud.google.com/static/data-studio/images/bullet-chart-icon-2023-05-16.png) Bullet 

Use a bullet chart to track progress of a given metric towards a range of goals. [Learn more about bullet charts](https://docs.cloud.google.com/data-studio/bullet-chart-reference). 

**See also:** Gauge chart. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/gauge-chart-icon-2023-05-16.png) Gauge 

Use a gauge to see how well a given metric is performing against a target goal. [Learn more about gauge charts](https://docs.cloud.google.com/data-studio/gauge-chart-reference). 

**Chart variations:** Gauge with range. 

**See also:** Bullet chart. 

####  ![](https://docs.cloud.google.com/static/data-studio/images/tree-map-icon-2023-05-16.png) Tree map 

Use a tree map to show a data tree, where objects are organized into parent-child hierarchies. [Learn more about tree map charts](https://docs.cloud.google.com/data-studio/treemap-reference). 

####  ![](https://docs.cloud.google.com/static/data-studio/images/sankey-icon-2023-05-16.png) Sankey 

Use a sankey chart to display a flow from one set of values to another. [Learn more about sankey charts](https://docs.cloud.google.com/data-studio/sankey-chart-reference). 

####  ![](https://docs.cloud.google.com/static/data-studio/images/waterfall-icon-2023-08-01.png) Waterfall 

Use a waterfall chart to visualize how a sequence of positive and negative values adds up to a total. [Learn more about waterfall charts](https://docs.cloud.google.com/data-studio/waterfall-chart-reference).

####  ![](https://docs.cloud.google.com/static/data-studio/images/boxplot-icon-2023-08-01.png) Boxplot 

Use a boxplot chart to help you visualize the distribution and spread of values in your dataset. Boxplot charts can be especially useful for comparing values across categories. [Learn more about boxplot charts](https://data-studio/boxplot-chart-reference).

####  ![](https://docs.cloud.google.com/static/data-studio/images/candlestick-icon-2024-07-17.png) Candlestick 

Use a candlestick chart to help you visualize ranges in your data, including opening and closing values, and the highs and lows of each range. [Learn more about candlestick charts](https://docs.cloud.google.com/data-studio/candlestick-chart-reference).

####  ![](https://docs.cloud.google.com/static/data-studio/images/timeline-icon-2026-07-08.png) Timeline 

Use a timeline chart to help you visualize the relationships between groups of events and compare the timespans over which these events took place. [Learn more about timeline charts](https://docs.cloud.google.com/data-studio/timeline-chart-reference).

####  ![](https://docs.cloud.google.com/static/data-studio/images/funnel-icon-2026-07-08.png) Funnel 

Use a funnel chart to help you visualize how a metric changes over events in a sequential process. [Learn more about funnel charts](https://docs.cloud.google.com/data-studio/funnel-chart-reference).

####  ![](https://docs.cloud.google.com/static/data-studio/images/communitiesbaselinep200fill0wght400grad0opsz48-2023-05-16.png) Community visualizations 

Use a chart created by third-party developers to display your data in various ways. [Learn more about community visualizations](https://docs.cloud.google.com/data-studio/community-visualizations-developer-preview).
