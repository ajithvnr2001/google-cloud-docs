#  Trash Stay organized with collections  Save and categorize content based on your preferences. 

A location in Data Studio and Data Studio Pro for content that you have removed.

Content that you remove from another location goes into the **Trash.** That content no longer appears on the Data Studio home page, and it won't be accessible by you or anyone else. You can restore content in the Trash, which returns it to the home page and makes it accessible again. If you delete an item from the Trash, it's gone forever.
