#  Report a content violation Stay organized with collections  Save and categorize content based on your preferences. 

You can report content in Data Studio that you consider to be a violation of [Google's Terms of Service](https://www.google.com/drive/terms-of-service/) or program policies.

[Learn about Data Studio program policies and enforcement](https://docs.cloud.google.com/data-studio/abuse-policies).

## Report content

If you're signed in to a Google Account, follow these steps to report a content violation:

  1. View the Data Studio report.
  2. Click more_vert **More options**.
  3. Click **Report content**.
  4. Select the reason for reporting this content, and then click **Next**.
  5. Click **Report content**.



If you're not signed in to a Google Account, follow these steps to report a content violation:

  1. View the Data Studio report.
  2. Click more_vert **More options**.
  3. Click **Report content**.
  4. Provide an email address, and then click **Next**. We'll send you a one-time password (OTP).
  5. Check your email and copy the OTP.
  6. Enter the OTP, and then click **Submit report**.



## Actions we may take on abusive content

  * Remove the report from the owner's account.
  * Restrict sharing of a report.
  * Limit who can view the report.
  * Disable access to one or more Google products.
  * Delete the report owner's Google Account.
  * Report illegal materials to appropriate law enforcement authorities.



## Can I appeal a violation?

Because Data Studio is considered to be a Hosting Service, there is no formal appeals process for a content violation. If a report you own has a violation notice, you can ask questions on the Data Studio Community (for no-cost Data Studio customers), or raise a support request (for Data Studio Pro customers with a Cloud Support contract). For more information, visit [Data Studio help and support options](https://docs.cloud.google.com/data-studio/contact-us).
