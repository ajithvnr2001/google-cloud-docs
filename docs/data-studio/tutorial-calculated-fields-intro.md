#  Calculated fields tutorial introduction Stay organized with collections  Save and categorize content based on your preferences. 

The calculated field tutorials show you how to create and use calculated fields in Data Studio. Calculated fields are fields you create in your reports and data sources that can use math and functions to extend and transform your data. 

The [create calculated fields tutorial](https://docs.cloud.google.com/data-studio/tutorial-create-calculated-fields) is a general introduction to creating calculated fields.

The [create a ratio metric tutorial](https://docs.cloud.google.com/data-studio/tutorial-create-a-ratio-field-based-on-filtered-metrics) involves more advanced techniques using data blending.

Looking for more tutorials? Try the [report](https://docs.cloud.google.com/data-studio/tutorial-report-intro) and [data source](https://docs.cloud.google.com/data-studio/tutorial-data-source-intro) tutorials.
