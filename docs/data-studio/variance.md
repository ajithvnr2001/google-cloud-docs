#  VARIANCE Stay organized with collections  Save and categorize content based on your preferences. 

Returns the variance of a set of numbers.

## Sample usage

```VARIANCE(Page Views)```

## Syntax

```VARIANCE( X )```

### Parameters

  * `X` \- a numeric field or expression.



### Notes

  * `X` cannot be an aggregated field or the result of an aggregation function.



## Example

Example formula | Input | Output  
---|---|---  
` VARIANCE(Page Views) ` | 

  * 95 
  * 100 
  * 92 

|  10.89
