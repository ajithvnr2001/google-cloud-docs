#  Gemini in Data Studio overview Stay organized with collections  Save and categorize content based on your preferences. 

**Note:** Gemini in Data Studio Preview features are available at no additional cost for a limited time only. At the end of this Preview period, you may be required to purchase Gemini in Data Studio features for an additional fee.

Gemini in Data Studio represents a series of features in the [Gemini for Google Cloud](https://docs.cloud.google.com/gemini/docs/overview) portfolio that provides generative AI-powered assistance to help you analyze and gain valuable insights from your data.

Learn [how and when Gemini for Google Cloud uses your data](https://docs.cloud.google.com/gemini/docs/discover/data-governance).

## Available features in Data Studio

When Gemini in Data Studio is enabled for a Data Studio Pro subscription, users under that subscription can perform the following tasks:

  * [**Create calculated fields by using natural language**](https://docs.cloud.google.com/data-studio/create-calculated-fields-gemini) [[Preview](https://cloud.google.com/products/#product-launch-stages)]: Gemini in Data Studio lets you create [calculated fields](https://docs.cloud.google.com/data-studio/about-calculated-fields) in Data Studio by prompting you to describe the kinds of fields that you'd like to create. Based on your input, Gemini suggests a formula for a calculated field by using fields from your data source along with Data Studio functions and operators.

  * [**Add Data Studio content to your Slides presentation**](https://docs.cloud.google.com/data-studio/add-slides-gemini) [[Preview](https://cloud.google.com/products/#product-launch-stages)]: Gemini in Data Studio lets you import [components](https://docs.cloud.google.com/data-studio/configure-report-components) from your Data Studio Pro reports into your Slides presentations. Gemini inserts report charts as images, generates a textual summary of each image, and inserts the summary as a text element. You can generate a new Slides presentation by using all or selected visualizations in a Data Studio report, or you can add or update Data Studio content to an existing Slides presentation. You can also update the Data Studio data that has been imported in a Slides presentation.




Conversational Analytics is a chat with your data feature powered by [Gemini for Google Cloud](https://docs.cloud.google.com/gemini/docs/overview) that doesn't require Gemini in Data Studio to be enabled. For more information about Conversational Analytics in Data Studio, see the [Conversational Analytics overview](https://docs.cloud.google.com/data-studio/conversational-analytics-overview) documentation page.

## Toggle features in Data Studio

A user with the appropriate IAM or Google Workspace role must [enable Gemini in Data Studio](https://docs.cloud.google.com/data-studio/enable-and-disable-gemini-in-data-studio) in Data Studio. A user with such a IAM or Google Workspace role can use the same instructions to subsequently disable features.

### Grant permissions to use Gemini in Data Studio features in Data Studio

To use Gemini in Data Studio features, users must be granted the following roles or privileges:

  * To create calculated fields, users must be assigned an [Editor](https://docs.cloud.google.com/data-studio/roles-and-permissions#basic_roles) role.
  * To add Data Studio content to your Slides presentation, users must be assigned a Viewer or Editor role in Data Studio and have the [Editor or Owner](https://support.google.com/docs/answer/2494822#zippy=%2Cunderstand-share-permissions) permission level for the Slides presentation.



## Where to interact with Gemini in Data Studio features

After Gemini in Data Studio is enabled, you can seek Gemini assistance in the parts of Data Studio that are described in the following sections.

### Calculated field editor

To use Gemini assistance to write formulas for calculated fields, follow these steps from a Data Studio report:

  1. Edit the data source.
  2. Click **Add a field**.
  3. Select **Add calculated field**.
  4. Click the **Help me write** icon.



For more information, see [Create calculated fields with Gemini assistance](https://docs.cloud.google.com/data-studio/create-calculated-fields-gemini).

### Gemini panel

To use Gemini assistance to create a Slides presentation that includes all or selected visualizations in a Data Studio report, follow these steps:

  1. Open a Data Studio report in either view or edit mode.
  2. Select the Gemini panel in the panel manager.
  3. Select **Generate Slides**.



For more information, see [Adding Data Studio content to your Slides presentation with Gemini assistance](https://docs.cloud.google.com/data-studio/add-slides-gemini).

### Slides: **Data Studio Pro** panel

To use Gemini assistance to add Data Studio content to an existing Slides presentation, follow these steps:

  1. Open a Slides presentation.
  2. Click the Data Studio icon on the right-hand toolbar to open the Data Studio Pro panel.



For more information, see [Adding Data Studio content to your Slides presentation with Gemini assistance](https://docs.cloud.google.com/data-studio/add-slides-gemini).
