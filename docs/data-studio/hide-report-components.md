#  Hide report components for viewers Stay organized with collections  Save and categorize content based on your preferences. 

You can hide individual charts and components for all viewers, or for a subset of viewers.

## Configure control visibility

The **Control visibility** option lets you hide a chart or component so that some or no viewers can see it. You might want to hide a chart or component if it contains information that you want only other report editors to see.

Chart visibility is controlled by [variables](https://docs.cloud.google.com/data-studio/parameters). Pro users can create a group membership variable to specify a list of Google groups and email addresses that should be allowed to view a chart. You can create and group membership variables while managing control visibility, as described in the following sections, and you can also manage them from the **Resource > Manage variables (parameters)** page.

To control visibility for a chart or component, follow these steps:

  1. [Edit your report](https://docs.cloud.google.com/data-studio/edit-a-report).
  2. Hover over a specific chart or component.
  3. Click the ![More options.](https://docs.cloud.google.com/static/data-studio/images/icmorevertgrey2xweb24dp-2016-03-14-.png) three-dot menu icon.
  4. Click the **Control Visibility** option.
  5. Select an existing group membership variable, or click **Create new group membership variable**. 
     * Only Pro users can create new group membership variables.
     * A group membership variable should include one or more email addresses of Google Groups or users who should be able to view the component.
  6. Click **Confirm**.
