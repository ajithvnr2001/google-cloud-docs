#  Google Analytics property Stay organized with collections  Save and categorize content based on your preferences. 

The level of the Google Analytics account that determines which data is organized and stored together.

In the Google Analytics account hierarchy, a property represents an app or website, and is the collection point for data from the app or site. A property contains the reports you use to analyze that data, and includes options to set user permissions and create links to other products like Google Ads.

An account can contain one or more properties. A property can only belong to one account.
