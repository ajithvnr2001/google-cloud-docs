#  Delete a report Stay organized with collections  Save and categorize content based on your preferences. 

In Data Studio, removing an asset is temporary. You can restore assets that you've removed. Deleting an asset is permanent.

## Remove reports from the home page list

Removing a report moves it to the trash. That report no longer appears in the Reports tab of the Data Studio home page, and the report won't be accessible by you or anyone else.

You can remove a single report or multiple reports at once.

### Remove a single report

To remove a single report from the home page list, follow these steps:

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. Locate the report that you want to remove.
  3. In the report list, hold your pointer over the report name, then click **More options** ![More options.](https://docs.cloud.google.com/static/data-studio/images/icmorevertgrey2xweb24dp-2016-03-14-.png).
  4. Click **Remove** ![Remove.](https://docs.cloud.google.com/static/data-studio/images/deletegrey6002x48dp-2020-09-22.png).



### Remove multiple reports

To remove multiple reports from the home page list at once, follow these steps:

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. Locate the reports that you want to remove.
  3. To select multiple adjacent reports, hold down the Shift key and click the reports. To select multiple non-adjacent reports, hold down the Ctrl key (PC) or the command key (Mac) and click the reports.
  4. Click **Trash selected items** ![Remove.](https://docs.cloud.google.com/static/data-studio/images/deletegrey6002x48dp-2020-09-22.png).
  5. In the **Move items to the trash?** dialog, click **Confirm** to move the reports to the trash.



## Restore a report from the trash

Reports and data sources you remove remain in the trash. You can restore them at any time by visiting the TRASH tab on the home page.

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. On the left, select **Trash** ![](https://docs.cloud.google.com/static/data-studio/images/deletegrey6002x48dp-2020-09-22.png).
  3. On the top, select the **Reports** tab.
  4. Locate the report you want to restore.
  5. Hover your cursor over the report name, then click **More options** ![More options.](https://docs.cloud.google.com/static/data-studio/images/icmorevertgrey2xweb24dp-2016-03-14-.png).
  6. Click **Restore** ![Restore.](https://docs.cloud.google.com/static/data-studio/images/restoregrey6002x48dp-2020-09-22.png).



The report appears in the home page, and anyone with whom you've shared it will again have access.

## Permanently delete a report

Reports in the Trash remain undeleted unless you permanently delete them. You need to own the report to delete it.

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. On the left, select **Trash** ![](https://docs.cloud.google.com/static/data-studio/images/deletegrey6002x48dp-2020-09-22.png).
  3. On the top, select the **Reports** tab.
  4. Locate the report you want to delete.
  5. Hover over the report name, then click **More options** ![More options.](https://docs.cloud.google.com/static/data-studio/images/icmorevertgrey2xweb24dp-2016-03-14-.png).
  6. Click **Delete forever** ![Remove.](https://docs.cloud.google.com/static/data-studio/images/deletegrey6002x48dp-2020-09-22.png).

**Warning:** You can't undo this action.

### A note about version history

Restoring a report to a previous version restores any data sources that you've removed. However you may need to fix the data source connection. See [Manage added reports and data sources](https://docs.cloud.google.com/data-studio/manage-added-reports-and-data-sources) for more information.

Version history can't restore any data sources that have been permanently deleted.
