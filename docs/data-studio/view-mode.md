#  View mode Stay organized with collections  Save and categorize content based on your preferences. 

The "read-only" display mode for a Data Studio report.

View mode displays your report in a non-editable form. View mode lets you preview your report as others will see it (assuming you share it with them).

![](https://docs.cloud.google.com/static/data-studio/images/view-button-2024-02-21.png)

#### To switch from edit mode to view mode:

  * Click the **View** button in the toolbar.
