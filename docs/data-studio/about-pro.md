#  About Data Studio Pro Stay organized with collections  Save and categorize content based on your preferences. 

Data Studio Pro is the paid version of Data Studio. With Data Studio Pro, you get access to all the features of Data Studio that you already know, plus additional capabilities for teams and technical support.

## What you get with Data Studio Pro

![](https://docs.cloud.google.com/static/data-studio/images/migrate-enterprise-server-circle-graphic.svg) | 

### Own your organization's content

Your Data Studio Pro reports and data sources belong to your organization, rather than to individual users. Link your Data Studio Pro content to a Google Cloud project to ensure that your critical assets will continue to work even if the person who created them leaves the organization. In addition, Google Cloud administrators can set project-level permissions with IAM to control access to those assets.[Learn more about owning your organization's content with Data Studio.](https://docs.cloud.google.com/data-studio/link-pro-to-a-google-cloud-project-mau-version)  
---|---  
![](https://docs.cloud.google.com/static/data-studio/images/artboard-4-8-2023-07-17.svg) | 

### Collaborate at scale with team workspaces 

Team workspaces are shared locations for team collaboration that enable Data Studio Pro users to manage access and share Data Studio content. Members of a team workspace automatically get access to the content, and the specific permissions on workspaces depend on which role those members are granted: Manager, Content Manager, or Contributor.  [ Learn more about team workspaces. ](https://docs.cloud.google.com/data-studio/about-team-workspaces)  
![](https://docs.cloud.google.com/static/data-studio/images/artboard-8-8-2023-07-17.svg) | 

###  Automate report delivery 

Keep your colleagues, clients, and stakeholders up to date with enhanced features for scheduled report delivery.  As a Data Studio Pro customer, you can add up to 200 delivery schedules to a report and deliver reports to Google Chat. You can also set up alerts that will notify you and your stakeholders when a chart on your Data Studio report meets criteria that you specify.  [ Learn more about automating report delivery with Data Studio Pro. ](https://docs.cloud.google.com/data-studio/schedule-automatic-report-delivery)  
![](https://docs.cloud.google.com/static/data-studio/images/artboard-7-8-2023-07-17.svg) | 

###  Empower exploration with personal report links 

Democratize data exploration by sharing personal report links with your team.  A personal report link creates a copy of your report that is only accessible to the person who opens the link. Personal reports let other people edit and explore their copy of the report while preventing changes to your original report.  [ Learn more about using Data Studio Pro to empower exploration with personal report links. ](https://docs.cloud.google.com/data-studio/get-a-personal-report-link)  
![](https://docs.cloud.google.com/static/data-studio/images/cloud_security.svg) | 

###  Security and compliance 

Meet your organization's security and compliance needs with these features: 

  * **[Customer-managed encryption keys (CMEK)](https://docs.cloud.google.com/data-studio/cmek)** — Use your own cryptographic keys to protect Data Studio Pro assets. 
  * **[Customer-managed storage](https://docs.cloud.google.com/data-studio/cms)** — Store your file uploads in your own Cloud Storage bucket and your data extracts in your own BigQuery dataset. 
  * **[Data residency](https://docs.cloud.google.com/data-studio/data-residency)** — Keep your data physically within a geographical area. 

[ Learn more about security and compliance. ](https://docs.cloud.google.com/data-studio/security-and-compliance)  
![](https://docs.cloud.google.com/static/data-studio/images/migrate-collaboration-circle-graphic.svg) | 

### Looker mobile app 

The Looker mobile app lets users access Data Studio reports and data while on the go. [ Learn more about the Data Studio mobile app. ](https://docs.cloud.google.com/data-studio/how-to-use-the-mobile-app)  
![](https://docs.cloud.google.com/static/data-studio/images/artboard-6-2023-07-17.svg) | 

###  Get help with Cloud Customer Care 

Data Studio Pro customers have access to Google Cloud Cloud Customer Care's scalable and flexible support services. [ Learn more about getting help with Cloud Customer Care. ](https://cloud.google.com/support) **Note:** Data Studio support is not included in other premium Google Cloud services. To receive technical support for Data Studio Pro issues, you'll need both a Google Cloud support plan and a Data Studio Pro subscription.  
![Gemini icon blue spark](https://docs.cloud.google.com/static/data-studio/images/gemini-icon-spark-blue.png) | 

###  Gemini in Data Studio 

Gemini in Data Studio provides AI assistance to help Data Studio Pro users ask questions about their data, create calculated fields by using natural language prompts, and add Data Studio content to a Slides presentation. [ Learn more about Gemini in Data Studio](https://docs.cloud.google.com/data-studio/gemini-overview).  
  
## Try Data Studio Pro for 30 days

You can try Data Studio Pro in your organization at no cost for 30 days. You'll get all the standard features of Data Studio that you already know, plus the full capabilities of Data Studio Pro. There is no limit to the number of users that you can add to your trial subscription.

After the 30-day trial, billing will begin automatically. You can [cancel your Data Studio Pro subscription](https://docs.cloud.google.com/data-studio/cancel-a-pro-subscription) at any time during the trial and you won't be charged.
