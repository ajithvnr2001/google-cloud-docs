#  How to use the Looker mobile app to access Data Studio content Stay organized with collections  Save and categorize content based on your preferences. 

**Data Studio Pro feature**

The features and functionality described in this page are available to Data Studio Pro users.

[Get Data Studio Pro.](https://docs.cloud.google.com/data-studio/about-pro)

The Looker mobile application (app) lets users access Data Studio reports and data while on the go. This page provides information regarding how to use the Looker mobile app, including these functions:

  * Install the Looker mobile app
  * Sign in to the mobile app
  * Find reports
  * View and share reports
  * View app details
  * Report a problem

**Note:** The Looker mobile app uses the [roles, permissions, and access settings](https://docs.cloud.google.com/data-studio/roles-and-permissions) that are specified in the Data Studio web application.

## Install the Looker mobile app

The Looker mobile app is available for both Android and Apple iOS devices.

### Device requirements

To use the Looker mobile app, your mobile device must meet one of the following requirements:

  * Android device on Android 6 or higher
  * iOS device on iOS 14 or higher



### Install the app

To install the mobile app, follow these steps:

  1. Open the Play Store (Android) or App Store (iOS) on your mobile device: 
     * For Android devices, open the [Play Store link](https://play.google.com/store/apps/details?id=com.google.android.apps.cloud.cloudbi) or search for "Looker".
     * For iOS devices, open the App Store and search for "Looker".
  2. Follow the instructions on the app page to install the Looker mobile app.



Once you've installed the Looker mobile app, it's ready for you to use.

## Sign in to the mobile app

By default, the Looker mobile app uses Google OAuth to authenticate user accounts. Users can sign in to the mobile app using their Gmail or Google Accounts. To sign in to the Looker mobile app, follow these steps:

  1. Select **Data Studio Pro** when asked to select between Looker and Data Studio Pro.
  2. Choose the appropriate user account and select **Continue as`<user name>`.**



Once you've signed in, you can [configure biometric sign-in](https://docs.cloud.google.com/looker/docs/mobile-app-sign-in#signing_in_with_biometrics).

### Manage and switch accounts

Once you are logged in to the Looker mobile app, you can switch, add, or remove user accounts.

To manage your Data Studio account, follow these steps:

![The Data Studio mobile app navigation bar with the Google Account icon highlighted.](https://docs.cloud.google.com/static/data-studio/images/looker-studio-app-nav-bar-google-account.png)

  1. Select the Google Account icon on the right side of the application's top navigation bar.
  2. Select from the available options to manage your account or to add another account. Options include the following: 
     1. Manage your Google Account
     2. Add another account
     3. Manage accounts on this device
  3. To exit, tap outside the menu to, or select the **X** icon on the top left of the menu.



## Find reports

By default, the app displays the **Recents** view, which displays a list of reports that you have recently viewed.

### Change report views

In addition to reports that have recently been viewed, you can choose to display reports that are owned by you or that have been shared with you. To change views, follow these steps:

![The Data Studio mobile app navigation bar with three line menu icon highlighted.](https://docs.cloud.google.com/static/data-studio/images/looker-studio-mobile-app-nav-bar-hamburger-icon.png)

  1. Select the three line menu icon on the left hand side of the application's top navigation bar.
  2. Select the desired view option. Options include the following: 
     * **My Workspace** — This view displays a list of reports that you own and manage.
     * **Team Workspaces** — This view displays your team's workspaces. Select a workspace to see reports in that workspace.
     * **Recents** — The default view. This view displays a list of reports that you have recently viewed.
     * **Shared with me** — This view displays a list of reports that have been shared with you by other users.
  3. You can also choose the **Report a problem** option from the menu to report any issues you experience while using the Data Studio mobile app.



Tap outside the menu to close it.

### Sort and filter reports

To change the order in which reports appear, select the sort dialogue under the Google Account icon to open the **Sort by** options menu.

You can filter or sort the list of reports by the criteria available on the **Sort by** options menu. For example, on the **Recents** page, the default sort dialogue that is displayed is **Last opened by me**.

![Data Studio app sort dialogue displays the text Last opened by me on the Recents report view.](https://docs.cloud.google.com/static/data-studio/images/looker-studio-app-sort-dialogue.png)

The sort dialogue changes based on how the list of reports is sorted, including an upward-pointing or downward-pointing arrow to indicate ascending or descending order.

### View report details

In addition to viewing a list of reports, you can also view individual report details, including the following:

  * When a report was created, and by whom
  * Whether a report has been shared with other users
  * When a report was last modified
  * When a report was last opened



To view details about a report, follow these steps:

![A user selects the three-dot report options menu for a report called ISA Smart Analytics Dashboard to view its detail and activity.](https://docs.cloud.google.com/static/data-studio/images/looker-studio-mobile-app-report-three-dot-menu.png)

  1. Select the three-dot icon next to the desired report name to open the report options at the bottom of your mobile device screen.
  2. Select **Details & activity** from the available options.



Tap outside of the menu to close it and return to the list of reports.

## View and share reports

Once you have located a report that you would like to view, select the report name to open it.

Reports can be displayed as a web view (original version) or, when available, in a mobile friendly view like the following example:

![A report named Google Analytics Marketing Website displays time series charts, column charts, and scorecard charts in a compact columnar, mobile-friendly view.](https://docs.cloud.google.com/static/data-studio/images/mobile-friendly-report-example.png)

You can read more about switching between original and mobile friendly report views in the Switching between original and mobile friendly view section on this page.

**Important:** If you tap to open a report to which you do not have access, you will be directed to a page where you can request the desired report access permissions and add an optional message.

### View reports

**Important:** At this time, you can only view published versions of reports.

You can interact with reports in the following ways:

  * Tapping filters to change selected values
  * Scrolling down table columns and across table rows
  * Drilling (when available)
  * Tapping data points to display value details and tooltips
  * Zooming in or out to enlarge or minimize report data on your screen



#### Switch between original and mobile friendly view

By default, Data Studio reports are displayed as a web report (original version) in the mobile app. If a mobile friendly version of a report is available, a message at the top of the report will prompt you to switch to that view.

You can switch between mobile friendly and original version by selecting the three-dot menu at the top right side of the screen and selecting **Switch to mobile friendly report** to view the mobile friendly version, or **Switch to web report** to view the original version.

There are certain cases where the mobile friendly view may not preserve report details, including the following:

  * Reports that include [lines](https://docs.cloud.google.com/data-studio/add-text-images-lines-and-shapes-to-your-reports) (such as line, arrow, elbow, or curved).
  * Reports that have mind map or flow chart-like arrangements. These are not converted in order to preserve the order and layout of charts and elements.
  * Reports that include overlapping non-image items.



### Navigate reports

If the creator of your report has added [pages or report navigation](https://docs.cloud.google.com/data-studio/add-pages-and-report-navigation), you can select the report name at the top of the screen to open a navigation menu at the bottom of the screen. You can select sections and pages that are available on the menu.

On a report presented with mobile friendly view, navigation looks like the following:

![The Google Analytics Marketing Website report in mobile-friendly view displays the navigation options New user statistics, Summary, and User details at the bottom of the mobile device screen.](https://docs.cloud.google.com/static/data-studio/images/mobile-friendly-report-navigation.png)

You can tap outside the menu to close it and return to the report.

### Share reports

You can share reports with other users while using the Looker mobile app. To share a report, follow these steps:

![A user selects the three-dot menu for a report called ISA Smart Analytics Dashboard to display the share link and copy link options.](https://docs.cloud.google.com/static/data-studio/images/looker-studio-mobile-app-three-dot-menu-sharing.png)

  1. Select the three-dot icon next to the desired report name to open the report options at the bottom of your mobile device screen.
  2. Select [**Share link**](https://docs.cloud.google.com/data-studio/ways-to-share-your-reports) to select a sharing method (for example: email, iMessage, Google Chat).
  3. Alternatively, select [**Copy link**](https://docs.cloud.google.com/data-studio/get-a-link-to-your-report) to copy a report's link to your clipboard to paste externally.



Tap outside the menu to close it and return to the list of reports.

## View app details

To find the details about the Looker app on your mobile device, follow these steps:

![The Data Studio mobile app navigation bar with the Google Account icon highlighted.](https://docs.cloud.google.com/static/data-studio/images/looker-studio-app-nav-bar-google-account.png)

  1. Select the Google Account icon on the right hand side of the application's top navigation bar.
  2. Select the **About** option on the account options menu.
  3. Tap outside of the menu to exit, or select the **X** icon on the top left of the menu.



You can also view the Data Studio app **Privacy Policy** and **Terms of Service** by selecting those options from the account options menu.

For information about updating the Data Studio mobile app on your device to the latest version, see the [Google Play Help](https://support.google.com/googleplay/answer/113412) documentation for Android or the [Apple Support](https://support.apple.com/en-us/HT202180) documentation for iOS.

## Report a problem

If you encounter an issue or error while using the Looker mobile app, you can report it to the Looker team.

To report a problem specific to your report, follow these steps:

  1. Select the three dots menu icon on a report.
  2. Select the **Report a problem** option from the menu.
  3. Follow the prompts to describe and submit your report.



To report a general problem with the app, follow these steps:

  1. Select the three line menu icon on the left hand side of the application's top navigation bar.
  2. Select the **Report a problem** option from the menu.
  3. Follow the prompts to describe and submit your report.



Tap outside the menu to close it and return to the list of reports.
