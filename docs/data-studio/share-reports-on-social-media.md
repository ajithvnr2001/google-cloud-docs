#  Share reports on social media Stay organized with collections  Save and categorize content based on your preferences. 

You can share Data Studio reports on social media platforms that support the [Open Graph protocol](http://ogp.me/), including platforms such as Twitter, LinkedIn, Facebook, and Slack, as well as chat applications like iMessage and Google Chat.

## How sharing on social media works

To share your report on a social media platform, copy and paste the URL of your report into that site's posting field. You'll automatically get a screenshot image, the title and description, and a link to the report.

Here's an example of posting a Data Studio report to Facebook:

![A Facebook post displays a link to a Data Studio report called FAQ: Use Filter Controls with a thumbnail image of the charts and text on the report.](https://docs.cloud.google.com/static/data-studio/images/share-on-fb-2018-07-10.png)

## How to share your report on social media

  1. Make sure your report is [shared](https://docs.cloud.google.com/data-studio/invite-others-to-your-reports) so others can view it. For public platforms, you'll want to use one of the link sharing options.

**Note:** You don't need to share the data source, but for public reports, the credentials for the data source should be configured to use [Owner's credentials](https://docs.cloud.google.com/data-studio/data-credentials).
  2. View your report and copy the URL.

  3. Share the report URL with the social media platform just as you would any other web page.
