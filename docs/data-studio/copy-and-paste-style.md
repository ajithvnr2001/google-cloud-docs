#  Copy and paste style Stay organized with collections  Save and categorize content based on your preferences. 

You can copy styling from one Data Studio component to another component by following these steps:

  1. [Edit your report](https://docs.cloud.google.com/data-studio/edit-a-report).
  2. Select the component that has the styling that you want to apply.
  3. Right-click the component, and then select **Copy**.
  4. Right-click the component to which you want to apply that style.
  5. Select **Paste Special > Paste style only**.
