#  Recent Stay organized with collections  Save and categorize content based on your preferences. 

A location in Data Studio and Data Studio Pro for content that you have accessed.

The **Recent** location lists both content that you own, as well as content that has been shared with you. By default, the list is sorted by date, with the most recent items at the top. You can also sort the list by owner or location.
