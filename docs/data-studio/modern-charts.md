#  Modern charts in Data Studio Stay organized with collections  Save and categorize content based on your preferences. 

Modern charts provides new chart styling, new default chart configuration options, and new chart settings that give report creators greater control over how data is curated and presented to users. Improvements include support for rounded edges in column and bar charts, chart legend updates, axis and grid lightening, and an enhanced chart customization experience.

**Important:** The **Modern charts** feature is enabled by default for all _new_ reports. The **Modern charts** feature can be enabled individually on existing reports.

Modern charts improvements include the following:

  * New default color themes
  * New default chart displays, such as rounded edges for [column and bar charts](https://docs.cloud.google.com/data-studio/bar-chart-and-column-chart-reference)
  * New line gradient settings for [line charts](https://docs.cloud.google.com/data-studio/line-chart-and-combo-chart-reference) and [time series charts](https://docs.cloud.google.com/data-studio/time-series-reference)
  * New transparency options for bubbles on [scatter charts and bubble charts](https://docs.cloud.google.com/data-studio/scatter-chart-reference)
  * New chart padding control settings for [pie charts and donut charts](https://docs.cloud.google.com/data-studio/pie-chart-reference)
  * New grid line stroke and style settings
  * New individual axis line visibility, stroke, and color settings
  * New axis title style settings
  * New axis label rotation settings

**Note:** These features may not be available for all chart types. However, default color themes will apply to all chart types.

## Enabling modern charts

**Warning:** Once the **Modern charts** feature is enabled on a report, it cannot be disabled. Instead, you can choose a **Classic** theme for a report.

To upgrade an existing report to use modern charts, follow these steps:

  1. [Edit your report](https://docs.cloud.google.com/data-studio/edit-a-report).
  2. In the toolbar, click **Theme and layout** to open the **Theme and layout** panel.

Alternatively, you can click **Theme and layout** from the **File** menu options.

  3. In the **Theme and layout** panel, click the **Enable** button in the **Modern charts** section.

  4. In the **Enable modern charts** dialog, click **Yes, enable** to enable modern charts; or click **Cancel** to return to the report.




## Classic themes for reports

While you can't disable modern charts, you can choose to display a report in a **Classic** style theme that uses classic color schemes and contrasts.

To display a report in a **Classic** style theme, follow these steps:

  1. [Edit your report](https://docs.cloud.google.com/data-studio/edit-a-report).
  2. In the toolbar, click **Theme and layout** to open the **Theme and layout** panel.

Alternatively, you can click **Theme and layout** from the **File** menu options.

  3. Select a theme that has **(Classic)** in the theme name.
