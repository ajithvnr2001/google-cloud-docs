**Note:** While in preview, Gemini in Data Studio features are available at no additional cost. At the end of this Preview period, usage of Gemini in Data Studio features may require an additional fee.

Gemini in Data Studio represents a series of features in the [Gemini for Google Cloud](https://docs.cloud.google.com/gemini/docs/overview) portfolio that provides generative AI-powered assistance to help you analyze and gain valuable insights from your data.

Learn [how and when Gemini for Google Cloud uses your data](https://docs.cloud.google.com/gemini/docs/discover/data-governance).

This page describes the following topics as they relate to features in Data Studio that use Gemini assistance. These features include those under the [Gemini in Data Studio](https://docs.cloud.google.com/data-studio/gemini-overview) feature set and Conversational Analytics.

  * Known limitations, troubleshooting, and tips for writing better prompts for each task that is supported by Gemini in Data Studio
  * Troubleshooting that is related to Gemini in Data Studio enablement
  * How to submit in-product feedback about Gemini in Data Studio tasks
  * How to get support
  * Related resources



## Troubleshooting resources

As an early-stage technology, Gemini for Google Cloud products can generate output that seems plausible but is factually incorrect. We recommend that you validate all output from Gemini for Google Cloud products before you use it. For more information, see [Gemini for Google Cloud and responsible AI](https://docs.cloud.google.com/gemini/docs/discover/responsible-ai).

## How to submit in-product feedback

Submit in-product feedback to rate the quality and accuracy of Gemini in Data Studio previews.

You can submit in-product feedback about each Gemini in Data Studio task by using the thumb_up thumbs-up and thumb_down thumbs-down icons.

## How to get support

Reach out to Support if you encounter any of the following issues:

  * Gemini in Data Studio features are slow to respond or generate content.
  * Gemini in Data Studio features return blank or empty responses.
  * The instance, report, or chart returns a timeout error.
  * The instance or page returns an internal server error.



Be sure to include a clear description of the problem and the expected behavior, the steps that you took prior to encountering the issue, and any additional relevant details.

For details on how to contact Support, see the documentation for your Looker platform type:

  * [Data Studio Pro](https://docs.cloud.google.com/data-studio/contact-us)
  * Users of no-cost Data Studio can report issues in the [Data Studio Community](https://www.googlecloudcommunity.com/gc/Looker-Studio/bd-p/looker-studio-pro)
