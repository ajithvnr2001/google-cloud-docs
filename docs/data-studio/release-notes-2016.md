##  December 8, 2016 

###  Product updates 

  * No product updates this week 



###  Documentation & Help updates 

  * Added article to [ Firebase via BigQuery connector ](https://docs.cloud.google.com/data-studio/connect-to-firebase-via-bigquery). 
  * Added information about the [ Google Analytics Certified Partner Program ](https://docs.cloud.google.com/looker-studio/answer/7237700). 



##  November 28, 2016 

###  Product updates 

  * You can now create data sources that connect to DoubleClick Campaign Manager (DCM). [ Learn more ](https://docs.cloud.google.com/data-studio/connect-to-campaign-manager-360)
  * Data Studio 360 is now ISO 27001 certified. [ Learn more ](https://docs.cloud.google.com/data-studio/looker-studio-iso-27001-certification)



###  Documentation & Help updates 

Published [ chart references ](https://docs.cloud.google.com/looker-studio/topic/7059081). 

##  November 10, 2016 

###  Product updates 

  * Added support for new date formats in reports and data sources:  Format  |  Example   
---|---  
Day of Week (D)  |  Tuesday   
Month (MM)  |  August   
ISO Week (Www)  |  Week 35   
Day (DD)  |  23   
Hour (HH)  |  6PM   
Minute (mm)  |  52   
Month Day (MMDD)  |  Aug 23   
Quarter (Q)  |  Q3   
Year Quarter (QYYYY)  |  Q3 2016   



##  October 28, 2016 

###  Product updates 

  * YouTube data sources can now connect to YouTube Content Owners and Google+ Page channels. [ Learn more ](https://docs.cloud.google.com/data-studio/connect-to-youtube-analytics)
  * AdWords data sources can now connect to manager accounts (MCC). [ Learn more ](https://docs.cloud.google.com/data-studio/connect-to-google-ads)
  * Added new functions: 
    * WEEK 
    * YEARWEEK 



###  Documentation & Help updates 

  * Added [ Rename a data source field ](https://docs.cloud.google.com/data-studio/create-rename-copy-hide-and-remove-fields)



##  October 4, 2016 

###  Product updates 

  * Launched Data Studio in 21 additional countries. [ Learn more ](https://docs.cloud.google.com/looker/docs/studio)
  * You can now create reports from a template. 
  * Copying a report now lets you specify which data sources you want to use. 



###  Documentation & Help updates 

  * Added [ Report like a boss ](https://www.youtube.com/watch?v=C1w-yuTDUeM) Hangouts on Air video 



##  Sep 12, 2016 

###  Documentation & Help updates 

  * Improved the help and feedback user experience. 
  * You can now access the tutorial videos from within the product. 



##  August 29, 2016 

###  Product updates 

  * Improved Google Analytics connector: 
    * Added support for Google Analytics city geo mapping. 
    * Increased row limit for Google Analytics data sources to 1 million rows. 



##  August 22, 2016 

###  Product updates 

  * Launched connectors for MySQL and Google CloudSQL. [ Learn more ](https://docs.cloud.google.com/looker-studio/topic/6370347)
  * Improved data source refresh, reconnect, and reset functionality. [ Learn more ](https://docs.cloud.google.com/data-studio/refresh-data-source-fields)
  * You can now resize cartesian charts (Time Series, Bar, Area, Scatter) within their frames to make more room for truncated axis labels and chart legends. 



##  August 8, 2016 

###  Documentation & Help updates 

  * Published [ About charts ](https://docs.cloud.google.com/data-studio/add-charts-and-controls-to-your-report)
  * Added [ Data Studio: Insights, Vision and Product Highlights (Pt. 1) video ](https://www.youtube.com/watch?v=41IaGH8hmP4)



##  July 25, 2016 

###  Product updates 

  * Updated AdWords connector. [ Learn more ](https://docs.cloud.google.com/data-studio/connect-to-google-ads)
  * Added new functions: 
    * MEDIAN—returns the median of a set of values 
    * VARIANCE—returns the variance of a set of values 
    * REGEXP_REPLACE—replaces text in a field expression. [ Learn more ](https://docs.cloud.google.com/loo/data-studio/xpreplace)
    * REGEXP_MATCH (and other REGEXP_* functions) can now be used outside of CASE expressions 
  * CASE now supports NOT IN operator. [ Learn more ](https://docs.cloud.google.com/looke/data-studio/earched)



###  Documentation & Help updates 

Published [ Calculated fields video ](https://www.youtube.com/watch?v=dOMC3ArtTyU)

##  July 14, 2016 

###  Product updates 

  * You can now return a dimension as the result of a CASE expression. 
  * The Currency field type in the data source editor now supports a selection of international currencies. 



###  Documentation & Help updates 

Published [ Connect to Your Data video tutorial ](https://youtu.be/knrkCB6SrJM)

##  July 7, 2016 

###  Product updates 

  * Added new functions: 
    * UPPER—changes text to uppercase 
    * LOWER—changes text to lowercase 
  * Tables now can show bars and numbers in the same column 
  * Table headers now support wrapping text 
  * Donut-style pie charts now support labels 



###  Documentation & Help updates 

  * Updated [ Change the data source for a chart, page, or report ](https://docs.cloud.google.com/looker/do/data-studio/e-data-source-for-a-component-page-or-report)



##  June 27, 2016 

###  Product updates 

  * Report page links: You can now link to a specific page in a report. [ Learn more ](https://docs.cloud.google.com/looker/do/data-studio/page)



##  June 20, 2016 

###  Product updates 

  * Added new functions: 
    * ABS—Returns the absolute value of number 
    * ROUND—Rounds a number to the specified places 
    * REGEXP_EXTRACT—Extracts a portion of text 
  * You can now specify the axis for each series in a chart 
  * Added _Owned by me_ filter on the Home page 
  * Fixed report viewing on mobile devices

##  June 2, 2016 

###  Product updates 

    * **US Public Beta:** We launched Google's new data anal'sis and visualization platform that allows you to quickly access data, visualize into reports, and share across your organizations. All US users can create 5 reports and unlimited data sources. Data Studio can now access data from: AdWords, Google Analytics, BigQuery, Sheets, Attribution 360, YouTube. 
    * **Data Studio 360 US Public Beta:** GA360 Customers can now purchase Data Studio 360 in the United States. Contact your sales representative for details.
