#  Edit a report Stay organized with collections  Save and categorize content based on your preferences. 

View the report in Data Studio, then in the upper right, click **Edit**.

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. Browse or search for your report, then in the list, click the report name.
  3. In the upper right corner, click ![Edit icon.](https://docs.cloud.google.com/static/data-studio/images/icmodeeditgrey6002xweb24dp-2016-10-12.png)**Edit**.



You can [add charts, controls, and other components to the report](https://docs.cloud.google.com/data-studio/add-charts-and-controls-to-your-report).

To rename the report, click the report name and then edit the name.

To edit the report's description, click the three-dot menu and select **Details**. Then edit the **Description** field.

**Note:** Reports can be shared as read-only ("Can view"). If you don't see the edit button, then you don't have permission to edit that report.
