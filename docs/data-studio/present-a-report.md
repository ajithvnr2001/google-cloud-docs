#  Present a report Stay organized with collections  Save and categorize content based on your preferences. 

You can display a report as a presentation, similar to Google Slides. You can show the presentation in full screen or in a normal browser window. You can also choose to automatically display each page of the report for a specified amount of time. For example, you can present a 10-page report and choose to show each page for one minute before automatically advancing to the next page.

## Present a report

  1. View the report that you want to present.
  2. In the upper right, click **More options** ![More options.](https://docs.cloud.google.com/static/data-studio/images/icmorevertgrey2xweb24dp-2016-03-14-.png).
  3. Click **Present** ![Present icon.](https://docs.cloud.google.com/static/data-studio/images/gmsmartdisplaygrey60048dp-2021-04-07.png).
  4. If your report has more than one page: 
     1. Display the presentation controls by moving your mouse to the bottom left corner of the screen.
     2. Click **Play** ![Play icon.](https://docs.cloud.google.com/static/data-studio/images/gmplayarrowgrey60048dp-2021-04-07.png) to begin the presentation.
     3. Choose a specific page to present using the page menu.
  5. To choose a display option, click **Display options** ![Display options.](https://docs.cloud.google.com/static/data-studio/images/gmfitscreengrey60048dp-2021-05-03.png).
  6. To show the presentation in a browser window, click **Exit fullscreen** ![Exit fullscreen icon.](https://docs.cloud.google.com/static/data-studio/images/gmfullscreenexitgrey60024dp-2021-04-07.png).
  7. To exit the presentation, press **ESC** , or click **EXIT** in the presentation controls.



![](https://docs.cloud.google.com/static/data-studio/images/presentation-controls-2021-05-03.png)

## Set the frequency of page changes

To control how often a multi-page presentation advances to the next page:

  1. View the report that you want to present.
  2. In the upper right, click **More options** ![More options.](https://docs.cloud.google.com/static/data-studio/images/icmorevertgrey2xweb24dp-2016-03-14-.png).
  3. Click **Present** ![Present icon.](https://docs.cloud.google.com/static/data-studio/images/gmsmartdisplaygrey60048dp-2021-04-07.png).
  4. Move your mouse to the bottom left corner of the screen.
  5. In the presentation controls, click **Advance every … seconds** and select a new interval.

**Note:** After the last page is displayed, the presentation loops back to the first page and continues until you exit.

## Present a specific page

Use the presentation controls to navigate to a specific page while remaining in presentation mode.

## Display options

Use the presentation controls to choose how the report fits on the screen:

  * **Fit to screen** \- scales your report so it fits entirely on the screen.
  * **Fit to width** \- scales your report to the width of the screen. You may need to scroll vertically to see the entire report.
  * **Actual size** \- displays your report using its actual dimensions. You may need to scroll vertically and/or horizontally to see the entire report.



## Presentation mode and data freshness

When you're showing a presentation, Data Studio uses the freshness settings for the data sources in the report to make sure that the report is displaying fresh data. This ensures that even people who can't edit the report still see the freshest data available.

Learn more about [managing data freshness](https://docs.cloud.google.com/data-studio/manage-data-freshness).

## Presentation mode and auto refresh

When you're showing a presentation, Data Studio checks the freshness settings and refreshes the data for only the upcoming page in the presentation. To refresh the entire report at a set interval, consider using [auto refresh](https://docs.cloud.google.com/data-studio/manage-data-freshness).
