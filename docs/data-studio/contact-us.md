Use the following resources to get help and support for Data Studio and Data Studio Pro. These resources help you to resolve issues, ask and answer questions, and provide product feedback.

## No-cost help and support options

All Data Studio users can access these resources at no cost.

Resource | Description  
---|---  
**Troubleshooting guide** | Diagnose and resolve common technical issues with the self-service [troubleshooting guide](https://docs.cloud.google.com/data-studio/troubleshooting-guide).  
**Data Studio Community on Google Cloud** | Use the [Data Studio Community](https://discuss.google.dev/c/data-studio/data-studio-qa/214) forum to report problems, ask questions, and join discussions with product experts and other Data Studio users.  
**Developer resources** |  The [Data Studio Developer site](https://developers.google.com/data-studio) provides documentation, code labs, and other resources to help developers create new Data Studio connectors, visualizations, and integrations. Use the [Data Studio tag on Stack Overflow](https://stackoverflow.com/questions/tagged/data-studio) for developer-specific questions.  
**Feature requests** |  Vote and comment on [requested features](https://issuetracker.google.com/savedsearches/5492224?p=1&q=componentid:196095%20status:\(open%20%7C%20new%20%7C%20assigned%20%7C%20accepted\)%20votecount%3E0&s=vote_count:desc) to help the Data Studio team prioritize development. [Request new features](https://issuetracker.google.com/issues/new?component=196095&template=1100266) with the Data Studio issue tracker.  
**Cloud BI Customer Council** |  Join the Google Data Cloud Customer Councils for opportunities to give feedback and influence the future of Google Cloud Data and Analytics products by interacting with user research teams, engineers, and product managers. Submit your interest using [the Customer Council form](https://docs.google.com/forms/d/e/1FAIpQLSeVNzX5mUIg8x4bAGYTm7n3JRx1kKy1QS3p__lWvEbbhk_tnQ/viewform).  
  
## Report abusive content

Google content and product policies apply globally, but processes remove or restrict access to content based on local laws.

Use the [Report Content On Google intake form](https://support.google.com/legal/troubleshooter/1114905) and select "Data Studio" to report content for removal from Google services under Google policies or applicable laws.

## Paid technical support

Data Studio Pro customers purchase scalable and flexible support services with [Cloud Customer Care](https://console.cloud.google.com/support). A Standard Support plan is required to open support cases for Data Studio Pro.

**Note:** Data Studio Pro support is not included in other premium Google Cloud services. A Data Studio Pro subscription is required to receive technical support for Data Studio issues.

After you purchase an eligible support plan, submit tickets through the Google Cloud Support Console by following these steps:

  1. Sign in to the [Cloud Support Console](https://console.cloud.google.com/support).
  2. Select the project for which you'd like to open a support case.
  3. Open **Cases** and click **Create case**.
  4. Complete the required fields and submit the form.
