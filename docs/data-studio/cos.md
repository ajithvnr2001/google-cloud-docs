#  COS Stay organized with collections  Save and categorize content based on your preferences. 

Returns the cosine of an Angle.

## Sample usage

```COS(Angle)```

## Syntax

```COS( X )```

### Parameters

  * `X` \- a field or expression containing at least one field. This value must be in radians.



## Examples

Example formula | Input (radians) | Output  
---|---|---  
` COS(Angle) ` |  0  |  1   
` COS(Angle) ` |  1.57  |  0
