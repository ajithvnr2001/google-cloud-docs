## February 22, 2024

### Product updates

#### Show field descriptions in table chart headers

You can now let report viewers access field descriptions in tooltips when the **Show field descriptions** option is enabled for table charts. **Show field descriptions** is automatically enabled for charts that are connected to a [Looker ](https://docs.cloud.google.com/looker-studio/answer/12388266)or [Search Ads 360](https://docs.cloud.google.com/looker-studio/answer/9091956) data source.

Field descriptions are sourced from the [Description column](https://docs.cloud.google.com/looker-studio/answer/7178497#data-source-editor-interface) in the data source.

[Learn more about table chart header options](https://docs.cloud.google.com/looker-studio/answer/7189044#table-header-style-options).

### Announcements

#### **Data Studio release notes moving to Google Cloud**

We're changing how we deliver product release notes. Beginning in a few weeks, Data Studio release notes will be available solely on the Google Cloud release notes platform.

Cloud release notes offer enhanced features, such as RSS feed support and programmatic access using BigQuery. These features make it easier for customers to stay informed about feature updates. Additionally, Google Cloud customers will have the convenience of accessing updates for related products like Looker and BigQuery in a centralized location.

Release notes prior to this change are preserved in the [_historical release notes_](https://docs.cloud.google.com/data-studio/historical-release-notes) page.

[_Visit the Cloud Data Studio release notes now_](https://cloud.google.com/looker-studio/docs/release-notes).

## January 25, 2024

### Product updates

#### Custom value formatting

Custom value formatting lets you specify how dimension, metric, and calculated field values appear in charts without sending additional SQL queries to your database. Custom value formatting also includes the option for report creators and editors to specify a value format by using Google Sheets style notation.

[Learn more about custom value formatting](https://docs.cloud.google.com/looker-studio/answer/14295042).

#### Download and third-party access controls in Workspace admin console

As a Google Workspace or Cloud Identity administrator, you can control whether viewers in your organization can [download](https://docs.cloud.google.com/looker-studio/answer/14340636) Data Studio content. You can also restrict users from [enabling data sources that use third-party connectors](https://docs.cloud.google.com/looker-studio/answer/14339933) or from [adding third-party visualizations](https://docs.cloud.google.com/looker-studio/answer/14340728) to Data Studio reports.

[Learn more about Enterprise admin features](https://docs.cloud.google.com/looker-studio/answer/9706918).

## December 21, 2023

### Product updates

#### Connection map visualization

You can now visualize your location data as sequences of points that are connected by a line in a new Google Maps visualization, called a combo map.

[Learn more about connection maps.](https://docs.cloud.google.com/data-studio/google-maps-reference)

#### Add value to reference line or reference band label

You can now choose to display the value of a [reference line](https://docs.cloud.google.com/data-studio/add-reference-lines-and-reference-bands-to-charts) or the value range of a [reference band](https://docs.cloud.google.com/data-studio/add-reference-lines-and-reference-bands-to-charts) in visualizations.

#### Stepped lines for time series charts, line charts, and combo charts

You can now choose stepped lines for [time series charts](https://docs.cloud.google.com/data-studio/time-series-reference) and for [line charts and combo charts](https://docs.cloud.google.com/data-studio/line-chart-and-combo-chart-reference).

#### Updates to New Search Ads 360 connector field names

The display names for several fields in the New Search Ads 360 data source have been updated.

  * Google Ads conv. value / cost -> Actual ROAS
  * Cost / Google Ads conv. -> Google Ads actual CPA
  * Google Ads conv. value / click -> Conv. value / click
  * Value / Google Ads conv. -> Value / client account conv.
  * Google Ads conv. rate -> Client account conv. rate



New connections to the New Search Ads 360 data source will use the new display names. Existing connections to the New Search Ads 360 data source won't be affected. You can also [manually update](https://docs.cloud.google.com/data-studio/model-your-data) the display names for existing data source connections.

## November 2, 2023

### Product updates

#### Pro feature : Create alerts on a chart

Report viewers can set up an alert on a chart in a Data Studio report that will notify the alert creator and chosen recipients when the chart data meets the conditions specified in the alert.

[Learn more about the default viewport setting](https://docs.cloud.google.com/data-studio/google-maps-reference).

With enabled tilt and optimized graphics, you can now tilt and rotate Google Maps visualizations. You can tilt a combo map visualization to display a map layer in three dimensions.

You can now combine the properties of a filled map and a bubble map in a new Google Maps visualization called combo map. Combo maps have vector graphics and three-dimensional display features that are enabled by default.

## October 19, 2023

### Product updates

#### Table Drilling and Table Tooltips

The **Drill Actions** experience for table charts provides an updated drill experience for report creators and report viewers. With the new **Drill Actions** menu, report creators can perform the following tasks:

  * Add more than one dimension for users to **Drill Up** , **Drill Down** , or swap between dimensions for different insights into the data that is presented in table charts.
  * Set up **Drill Through** links to external URLs to provide users with quick navigation to additional context about the data that is presented in table charts.



With the new table chart **Drill actions** tooltip, report viewers can perform the following tasks:

  * More intuitively **Drill Up** , **Drill Down** , or swap between dimensions for additional context of the data presented in table charts.
  * Select **Drill Through** links to navigate to external sites that provide additional context about the data that is presented in table charts.



Visit the [Drill into your data article](https://docs.cloud.google.com/data-studio/drill-into-your-data) for more information about the report viewer experience, and visit the [Add drill actions to charts article](https://docs.cloud.google.com/data-studio/add-drill-actions-to-charts) for more information about setting up drill actions.

#### Visualize your Apigee API analytics data in Data Studio

Apigee is a platform for developing and managing APIs. The Data Studio Apigee connector lets you create reports and dashboards that are based on analytics and monetization data and share them with stakeholders and customers.

[Learn more about the Apigee connector.](https://docs.cloud.google.com/data-studio/connect-to-apigee)

## May 22, 2023

### Product updates

#### **Running percentage delta**

You can apply a running percentage of delta calculation to metrics in a chart. This calculation applies the following formula:

`(current value - previous value) / ABS(previous value)`

To apply a running calculation to your chart, follow these steps:

  1. [**Edit your report**](https://docs.cloud.google.com/data-studio/edit-a-report).
  2. Select a chart.
  3. On the right, in the properties panel, select the SETUP tab.
  4. Add a metric to the chart, and then click its edit pencil ![Edit icon](https://docs.cloud.google.com/static/data-studio/images/icmodeeditgrey6002xweb24dp-2016-10-12.png) .
  5. Click the **Running calculation** menu, and select the desired function.



For example, the following table shows the percentage change in class attendance for 1 week. Day 1 attendance is 95, while day 2 attendance is 101. The running percentage delta calculation for day 2 is:

`(101 - 95) / ABS(95)= 6.32%`.

![A table chart showing daily classroom attendance and the running percentage delta for 7 days.](https://docs.cloud.google.com/static/data-studio/images/running-percentage-delta-2023-05-25.png)[Learn more about running calculations](https://docs.cloud.google.com/data-studio/add-comparison-metrics-and-running-totals). 

## May 18, 2023

### Product updates

#### **Pause report updates**

You can pause updates to minimize the number of data requests made while building and editing your report. While the report is paused, changes made to the report's data settings are placed on hold until you resume updates. Pausing report updates can potentially save on query costs because Data Studio only requests the data needed to meet the report configuration as of the time you resumed updates.

[Learn more](https://docs.cloud.google.com/data-studio/pause-report-updates).

### Product updates

#### **More improvements to field search in the data panel**

Searching for a field in the report editor's data panel is contextual:

  * When no components are selected, you can search for fields in any data source that is added to the report.
  * When a component is selected, the search results are restricted to that component's data source.
  * When a group of components is selected, the search results are restricted to the grouped component's data sources.



When you search for a field, the data panel provides additional information about the results:

  1. The number of matches for each data source on the report appears on the right.
  2. The text matching your search appears in **bold**.
  3. If a data source doesn't contain your search term, a message appears below that data source.
