**Deprecated:**

#### Universal Analytics has gone away

**Caution:** [Google Analytics 4](https://support.google.com/analytics/answer/10089681) is our next-generation measurement solution, and it has replaced Universal Analytics. **Starting on July 1, 2023, standard Universal Analytics properties stopped processing new data, and all customers will lose access to the Universal Analytics interface and API starting on July 1, 2024**. To maintain your website measurement, you'll need a Google Analytics 4 property. If you haven't already, [make the switch to Google Analytics 4](https://support.google.com/analytics/answer/10759417).**Note:** Google Analytics 4 segments and comparisons are not available using the [Google Analytics connector](https://docs.cloud.google.com/data-studio/connect-to-google-analytics).
