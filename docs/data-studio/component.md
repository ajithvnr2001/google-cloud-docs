#  Component Stay organized with collections  Save and categorize content based on your preferences. 

Anything you can add to a report that can be styled or associated with a data source.

Specifically, components include the following objects:

  * The report itself
  * Pages
  * Charts, such as bar, line, pie, and table
  * Controls, such as the date range control, filter control, and data control
  * Text areas
  * Shapes
  * Images
