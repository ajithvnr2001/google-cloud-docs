#  CEIL Stay organized with collections  Save and categorize content based on your preferences. 

Returns the nearest integer, greater than or equal to the specified value.

## Sample usage
    
    
    CEIL(Height)
    

## Syntax
    
    
    CEIL( X )
    

### Parameters

  * `X` \- a field or expression containing at least one field.



## Note

  * `CEIL( X )` is always greater than or equal to `X`.



## Examples

Example formula | Input | Output  
---|---|---  
`CEIL(Height)` | 20.34 | 21  
`CEIL(Height)` | -40.3 | -40  
`CEIL(Height)` | 50 | 50
