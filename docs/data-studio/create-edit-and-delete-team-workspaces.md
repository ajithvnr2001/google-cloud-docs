#  Create, edit, and delete team workspaces Stay organized with collections  Save and categorize content based on your preferences. 

**Data Studio Pro feature**

The features and functionality described in this page are available to Data Studio Pro users.

[Get Data Studio Pro.](https://docs.cloud.google.com/data-studio/about-pro)

You can use team workspaces in Data Studio Pro to organize your assets, collaborate with others, and manage access effectively. This guide shows you how to create, edit, rename, and delete team workspaces, helping you streamline your data analysis projects.

## Create a team workspace

To create a new team workspace, follow these steps:

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. In the top left, select ![The Create icon.](https://docs.cloud.google.com/static/data-studio/images/rainbow-plus-2019-06-26.png)**Create;** then choose **Workspace** from the drop-down menu.
  3. Select the project in which you would like to create your team workspace.
  4. In the **New workspace** window, enter a name for your team workspace.
  5. Once you have entered a name for the workspace, select **Create**.



Your team workspace will be listed in the left navigation under the name of the project in which you created it.

Once your team workspace is created, you can organize and manage assets in folders and subfolders in the team workspace. See the [Organize assets with folders in team workspaces](https://docs.cloud.google.com/data-studio/organize-assets-with-folders-in-team-workspaces) page for more information about folders in team workspaces.

## Edit a team workspace

To edit an existing team workspace, follow these steps:

  1. [Sign in to Data Studio.](https://datastudio.google.com)
  2. Browse or search for the team workspace that you want to edit.
  3. Select the workspace from the list.



You can edit the assets that are in the team workspace. You can [move assets to different folders](https://docs.cloud.google.com/data-studio/organize-assets-with-folders-in-team-workspaces) that are in the team workspace. If you have the appropriate [role](https://docs.cloud.google.com/data-studio/roles-and-permissions), you can also [rename folders](https://docs.cloud.google.com/data-studio/organize-assets-with-folders-in-team-workspaces) in the team workspace or [delete folders](https://docs.cloud.google.com/data-studio/organize-assets-with-folders-in-team-workspaces) in the team workspace.

Rename an existing team workspace

To rename a workspace, follow these steps:

  1. Select the title of the workspace.
  2. From the drop-down menu, choose **Rename**.
  3. In the **Rename** dialog, enter a new name for the workspace.
  4. Select **Update** to change the name of the workspace.



### Permanently delete a team workspace

If you have the appropriate [role](https://docs.cloud.google.com/data-studio/roles-and-permissions), you can permanently delete an empty team workspace. When you delete a team workspace, the workspace permanently disappears for everyone. Deletion of a workspace cannot be undone.

To delete a workspace, follow these steps:

  1. Select the title of the workspace.
  2. From the drop-down menu, choose **Delete team workspace**. Only empty workspaces can be deleted. If the team workspace is not empty, you will be unable to select the **Delete team workspace** option.
  3. To confirm that you want to delete the team workspace, select the **Delete team workspace** option in the dialog.
