#  Explorer beta sunset Stay organized with collections  Save and categorize content based on your preferences. 

The experimental Data Studio Explorer feature is coming to an end. In its place, you can use the [data exploration and analysis features](https://docs.cloud.google.com/data-studio/explore-your-data) of the report editor.

**Important:** **NO ACTION is required on your part.** Existing explorations that were created using the Explorer Labs will be converted to reports automatically.

## What's changing?

Starting **Monday, September 15, 2025** :

  * You won't be able to create new explorations.



After **Monday, October 27, 2025** :

  * You'll no longer see the **Explorer** tab on the Data Studio home page.
  * Any exploration that you've saved in the past will be converted into a report automatically.
  * The converted report will be private to you until you share it directly or move it to a Data Studio Pro [team workspace](https://docs.cloud.google.com/data-studio/team-workspace).
  * Bookmarks and links to an existing exploration will be redirected to the converted report.
  * The converted report will have the same name as the original exploration.
