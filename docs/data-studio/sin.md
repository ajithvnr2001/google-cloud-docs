#  SIN Stay organized with collections  Save and categorize content based on your preferences. 

Returns the sine of an Angle.

## Sample usage

`SIN(Angle)`

## Syntax

`SIN(X)`

### Parameters

  * `X` \- A field or expression containing at least one field. This value must be in radians.



## Examples

Example formula | Input (radians) | Output  
---|---|---  
`SIN(Angle)` | 0 | 0  
`SIN(Angle)` | 1.57 | 1
