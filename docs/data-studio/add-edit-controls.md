#  Add and edit controls Stay organized with collections  Save and categorize content based on your preferences. 

In Data Studio, you can add and configure controls to create interactive reports. These controls let viewers filter data and customize their view, transforming your reports into flexible templates and letting your audience explore data and find what they need. To learn more about how controls work, see [About controls](https://docs.cloud.google.com/data-studio/about-controls).

## Add a control to the report

  1. Edit your report.
  2. In the toolbar, select ![Control icon.](https://docs.cloud.google.com/static/data-studio/images/filterlistgrey6002x48dp-2020-09-09.png)**Add a control**.
  3. Select the control type, and then position it on your chart.
  4. On the right, configure the chart with the settings in the [**Properties** panel](https://docs.cloud.google.com/data-studio/properties-panel). 
     1. To filter the report by selected dimension values, use a dimension for the **Control field**.
     2. To set the value of a parameter, use that parameter as the **Control field**.
     3. To change the appearance of the data control, use the options in the **Style** tab of the properties panel.



## Change the control type

You can switch an existing control on the report from one type to another:

  1. [Edit your report](https://docs.cloud.google.com/data-studio/edit-a-report).
  2. Select the control.
  3. In the **Properties** panel, open the control drawer ![](https://docs.cloud.google.com/static/data-studio/images/keyboardarrowdowngrey6002x48dp-2021-12-20.png).
  4. Select the new control type.



You may need to edit the control's settings to use the new type.

## Make a control appear on every page

You can make a control appear in the same location on every page of your report. Filters or parameters set on one page will carry over to all the pages in the report.

  1. [Edit your report](https://docs.cloud.google.com/data-studio/edit-a-report).
  2. Select the control.
  3. Select the **Arrange > Make Report-level** menu.

**Tip:** Can't find the control on other pages? It may be underneath other components on the page. Learn more about [report-level component position](https://docs.cloud.google.com/data-studio/report-and-page-layout).

## Apply a control to a specific component

To limit a control to a subset of the components on the page, [group the components with the control](https://docs.cloud.google.com/data-studio/apply-controls-to-specific-charts).
