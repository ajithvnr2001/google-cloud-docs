Data Studio maintains ISO 27001 certification for its systems, applications, and data centers. This internationally recognized security standard helps protect your data and workloads. Ernst & Young CertifyPoint, an accredited ISO certification body, independently certified Google's compliance with this standard. View the [Google Cloud ISO/IEC 27001 information page](http://cloud.google.com/security/compliance/iso-27001).
