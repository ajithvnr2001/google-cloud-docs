# Workload Manager documentation

[Read product documentation](https://docs.cloud.google.com/workload-manager/docs/overview)

Workload Manager provides a rule-based validation service for evaluating your workloads running on Google Cloud. The Guided Deployment Automation tool in Workload Manager allows you to configure and deploy your SAP system on Google Cloud.
