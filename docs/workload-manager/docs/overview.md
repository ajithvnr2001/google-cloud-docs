#  About Workload Manager Stay organized with collections  Save and categorize content based on your preferences. 

Workload Manager helps you manage and optimize your workloads that run on Google Cloud by automating configuration checks, simplifying deployment, and enhancing system visibility.

This document describes the key features of Workload Manager, which include evaluation, guided deployment automation, and observability.

## Evaluation

Workload Manager provides a rule-based validation service for evaluating your workloads that run on Google Cloud. Workload Manager scans your workloads to detect deviations from standards, rules, and best practices to improve system quality, reliability, and performance.

For more information about the supported workloads and the evaluation process, see [About Workload Manager Evaluation](https://docs.cloud.google.com/workload-manager/docs/about-evaluations).

## Guided deployment automation

The Guided Deployment Automation tool in Workload Manager lets you quickly customize and deploy your workloads on Google Cloud, without having to configure the infrastructure.

Workload Manager supports deploying SAP S/4HANA and SQL Server workloads on Google Cloud.

For more information, see [About Guided Deployment Automation](https://docs.cloud.google.com/workload-manager/docs/deploy/about-wlm-deployment).

## Observability

Workload Manager's observability service helps you improve issue detection, root cause analysis, and troubleshooting of your SAP workloads running on Google Cloud. The observability service combines metrics from your SAP applications, databases, and the underlying infrastructure into a unified view to help you correlate events and understand the health status of your SAP system across all its layers.

For more information, see [SAP observability overview](https://docs.cloud.google.com/workload-manager/docs/observe/sap/overview).
