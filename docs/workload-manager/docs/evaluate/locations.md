#  Supported regions Stay organized with collections  Save and categorize content based on your preferences. 

This document provides a list of supported regions where Workload Manager creates evaluation resources.

However, when you evaluate your workloads using [custom rules](https://docs.cloud.google.com/workload-manager/docs/evaluate/custom-rules/about-custom-rules), Workload Manager reads the `global` Cloud Asset Inventory data.

**Note:** If you use the [**Resource Location Restriction** organization policy](https://docs.cloud.google.com/resource-manager/docs/organization-policy/defining-locations) to allow creating resources in a specific region and if Workload Manager does not support that region, then you cannot create any evaluation using Workload Manager. Similarly, if the organization policy denies creating resources in a region, then you cannot create evaluations even if Workload Manager supports that region.

For more information about regions and zones, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions).
