This document provides the list of SQL Server systems that you can deploy using the Guided Deployment Automation tool in Workload Manager.

## Supported SQL Server systems

The following table lists the SQL Server systems and operating systems that Workload Manager supports.

**Operating system** | **SQL Server**  
---|---  
Windows Server 2019 | SQL Server 2019 Enterprise  
| SQL Server 2019 Standard  
| SQL Server 2019 Web  
| SQL Server 2022 Enterprise  
| SQL Server 2022 Standard  
| SQL Server 2022 Web  
Windows Server 2022 | SQL Server 2019 Enterprise  
| SQL Server 2019 Standard  
| SQL Server 2019 Web  
| SQL Server 2022 Enterprise  
| SQL Server 2022 Standard  
| SQL Server 2022 Web
