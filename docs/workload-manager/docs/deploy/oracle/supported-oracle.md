This document provides the list of Oracle Database versions that you can deploy using the Guided Deployment Automation tool in Workload Manager.

## Supported Oracle Database editions and versions

Operating Systems | Oracle versions | Oracle editions | 

  * Oracle Linux 8

| 

  * Oracle Database 19c

| 

  * Enterprise Edition

  
---|---|---  
  
## Supported machine types

Workload Manager supports deploying your Oracle database on the following General-purpose machine types:

  * N4 series
  * C4 series
  * M4N series



For more information, see [General-purpose machine family guide](https://docs.cloud.google.com/compute/docs/machine-resource#general-purpose_machine_family_guide).
