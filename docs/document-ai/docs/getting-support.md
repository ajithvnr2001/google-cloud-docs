## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Document AI on [Stack Overflow](http://stackoverflow.com/questions/tagged/cloud-document-ai). Use the tag `cloud-document-ai` for questions about Document AI. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Document AI

Join the [Google Cloud Developers](https://groups.google.com/forum/#!forum/google-cloud-dev) Google group to discuss Document AI and receive announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Document AI and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Document AI, join the [`#document-ai`](https://googlecloud-community.slack.com/messages/C03H2DCF58Q/) channel. 

## Bugs

If after you've tried the above options and you have determined that the cause of a problem is due to a bug in the service itself, you can [search our Issue Tracker](https://issuetracker.google.com/issues?q=status:open%20componentid:1132231%2B%20type:bug) to determine if it is a known issue. If it is, you can +1 the issue — we prioritize bugs that receive more activity. You can also add comments to existing issues, but you should only do this if you are adding context or additional information about the problem.

If the issue is completely new, you can [report it on our Issue Tracker](https://issuetracker.google.com/issues/new?component=1132231&template=1639002) as well. If you do, ensure you include the following information in your bug description:

  * A description of the problem, and the behavior you expected instead.
  * A list of steps and a small snippet of sample code that can be used to reproduce the problem.
  * A description of the output you expect and what actually occurred. Include any error messages you receive.
  * Information about your development environment, including programming language, library versions, etc.



Be aware that issues may be relatively quiet for a while. This does not mean we never fix an issue, only that there are no updates.

Search existing bugs [ Report a new bug](https://issuetracker.google.com/issues/new?component=1132231&template=1639002)

## Missing features

If there is a feature or functionality missing that you would like to use, you can [search our Issue Tracker](https://issuetracker.google.com/issues?q=status:open%20componentid:1132231%2B%20type:feature_request) to determine if others have requested it. If it has already been requested, please +1 the issue — we prioritize bugs that receive more activity. You can also add comments to existing issues, but you should only do this if you are adding context or additional information about the problem.

If the feature hasn't been requested yet, you can [file a feature request on our Issue Tracker](https://issuetracker.google.com/issues/new?component=1132231&template=1639052). Please describe the specific functionality you would like to see added, as well as reasons you think it's important. If possible, include specific details about your use case and the new opportunities the feature would allow for.

Search feature requests [ Request a new feature](https://issuetracker.google.com/issues/new?component=1132231&template=1639052)

## Documentation issues

From any Document AI documentation page, click **Send feedback** near the top right or bottom of the page. This opens a feedback form specific to the page you are viewing. Your comments are reviewed by the Document AI documentation team.
