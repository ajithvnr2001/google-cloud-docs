# Google Cloud SDK documentation

[Read product documentation](https://docs.cloud.google.com/sdk/docs/overview)

The Google Cloud SDK is a set of tools that you can use to manage resources and applications hosted on Google Cloud. These tools include command-line tools ([`gcloud`](https://docs.cloud.google.com/sdk/gcloud/reference), [ `gsutil`](https://docs.cloud.google.com/storage/docs/gsutil), and [`bq`](https://docs.cloud.google.com/bigquery/bq-command-line-tool)), language-specific client libraries, and IDE extensions. Try the [gcloud cheat sheet](https://docs.cloud.google.com/sdk/docs/cheatsheet).
