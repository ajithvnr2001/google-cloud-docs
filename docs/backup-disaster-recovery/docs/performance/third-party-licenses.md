#  Third-party licenses used by Backup and DR Stay organized with collections  Save and categorize content based on your preferences. 

**Caution:** Support for backing up and restoring workloads managed using the legacy appliance management console is deprecated. For more information, see [Feature deprecations](https://docs.cloud.google.com/backup-disaster-recovery/docs/deprecations).

Both the appliance management console and the backup/recovery appliances employ some licensed third-party software. You can download compressed files of these licenses.

  * **Third-party licenses used by the appliance management console** : In every page of the appliance management console, the **?** icon opens a menu of help and other resources. The **About** selection shows you the current version of the appliance management console. It also includes a **Third Party Licenses** link to download a compressed file of the license information for third-party software used in the Backup and DR appliance management console.

  * **Third-party licenses used by a backup/recovery appliance** : Go to **Manage Appliances** , select the appliance, and click **Configure Appliance**. In the **Appliance Configuration** page, click the **gear icon** > **Third Party Licenses** link to download a compressed file of the license information for third-party software used in that specific backup/recovery appliance.
