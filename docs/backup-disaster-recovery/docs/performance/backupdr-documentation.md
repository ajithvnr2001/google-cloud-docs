#  Backup and DR product documentation Stay organized with collections  Save and categorize content based on your preferences. 

**Caution:** Support for backing up and restoring workloads managed using the legacy appliance management console is deprecated. For more information, see [Feature deprecations](https://docs.cloud.google.com/backup-disaster-recovery/docs/deprecations).

In the appliance management console, the **?** icon opens a menu of help and other resources:

  * **Help** : This brings you to the page in the product documentation that most closely reflects your location within the appliance management console. For example, if you click the **Help** from the dashboard, the [appliance management console dashboard](https://docs.cloud.google.com/backup-disaster-recovery/docs/concepts/dashboard) page opens. If you click **Help** while editing a backup plan, the [Manage backup plans](https://docs.cloud.google.com/backup-disaster-recovery/docs/create-plan/create-template) page opens.

  * **API Documentation** : This opens the API reference documentation.

  * **Videos** : This selection brings you to the [How-to videos](https://docs.cloud.google.com/backup-disaster-recovery/docs/how-to-videos) page with helpful overview videos.

  * **About** : This selection shows you the current version of the appliance management console. It also includes a **Third Party Licenses** link to download a compressed file of the license information for third-party software used in the Backup and DR appliance management console.

  * **Guided Tour** : The Guided Tour brings you on a 10-step graphic tour through the appliance management console.
