#  Quickstarts overview Stay organized with collections  Save and categorize content based on your preferences. 

The following quickstart guides can help you learn how Backup and DR can secure your data and empower your organization. In each one, you are guided step-by-step through backing up and restoring a data resource in either the Google Cloud console or in the appliance management console:

  * [Protect and recover Compute Engine instances in Google Cloud console](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/gce-instances-backup-vault): Guides you through creating a backup vault, backing up a Compute Engine instance and storing the backup in the backup vault, and then restoring the instance from the backup, all from within the Google Cloud console.

  * [Protect and recover disks in Google Cloud console](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/disk-backup-vault): Guides you through creating a backup vault, backing up disks, storing the backup in the backup vault, and then restoring the disk from the backup, all from within the Google Cloud console.

  * [Protect and recover Cloud SQL instances in Google Cloud console](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/csql-quickstart): Guides you through creating a backup vault, backing up a Cloud SQL instance and storing the backup in the backup vault, and then restoring the instance from the backup, all from within the Google Cloud console.

  * [Protect and recover AlloyDB clusters in Google Cloud console](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/alloydb-quickstart): Guides you through creating a backup vault, backing up an AlloyDB cluster and storing the backup in the backup vault, and then restoring the instance from the backup, all from within the Google Cloud console.

  * [Protect and recover a Google Cloud VMware Engine VM from a backup vault](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/vmware-backup-recovery-bv): Uses the appliance management console to back up a Google Cloud VMware Engine VM into a backup vault and then restore it.

  * [Protect and recover a Google Cloud VMware Engine VM in the appliance management console](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/vmware-backup-recovery): Uses the appliance management console to back up a Google Cloud VMware Engine VM into self-managed storage and then restore it.

  * [Protect and recover SAP HANA databases on Compute Engine instances in the appliance management console](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/sap-hana-on-gce-backup-recovery): Guides you through backing up an SAP HANA database to a Persistent Disk snapshot and then restoring the database from the snapshot, in the appliance management console.

  * [Protect and recover IBM Db2 databases on Compute Engine instances in the appliance management console](https://docs.cloud.google.com/backup-disaster-recovery/docs/quickstarts/db2-on-gce-backup-recovery): Guides you through backing up an IBM Db2 database to a Persistent Disk snapshot and then restoring the database from the snapshot, in the appliance management console.
