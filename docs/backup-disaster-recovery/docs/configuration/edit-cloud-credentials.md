#  Edit Cloud credentials in the appliance management console Stay organized with collections  Save and categorize content based on your preferences. 

Use these instructions to edit an existing cloud credential:

  1. In the appliance management console click **Manage** and select **Credentials** from the drop-down menu.

The **Credentials** page opens listing all credentials saved on appliances managed by the appliance management console.

  2. Select the credential that you want to modify and then select **Edit**.

The **Edit Credential** page opens.

**Note:** You can also right-click on the credential and select **Edit** from the drop-down menu options.
  3. Make changes to the user using the instructions in [Add Cloud credentials](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/create-cloud-credentials).

**Note:** If you are updating either the name, the default region, or default zone attributes, you don't have to provide the cloud access information such as the JSON key file. However if you are updating the cloud credential information or adding additional appliances, you are asked to provide the cloud access information that was used to create the credential.
  4. Click **Save** to apply the changes.
