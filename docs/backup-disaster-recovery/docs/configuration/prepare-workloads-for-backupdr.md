**Caution:** Support for backing up and restoring workloads managed using the legacy appliance management console is deprecated. For more information, see [Feature deprecations](https://docs.cloud.google.com/backup-disaster-recovery/docs/deprecations).

The following pages list prerequisites to prepare your workloads for protection by Backup and DR:

  * [Configure Google Cloud VMware Engine for Backup and DR protection](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/prepare-vmware)
  * [Prepare Filestore and other file systems for Backup and DR](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/prepare-filesystems)
  * Backup and DR for self-managed databases: 
    * [Prerequisites for backing up an Oracle database](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/prepare-oracle-prerequisites)
    * [Prepare Oracle databases for Backup and DR](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/prepare-oracle)
    * [Prepare SAP HANA for Backup and DR](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/prepare-sap-hana)
    * [Prepare SQL Server databases for Backup and DR](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/prepare-sql-server)
    * [Prepare other self-managed databases for Backup and DR](https://docs.cloud.google.com/backup-disaster-recovery/docs/configuration/prepare-otherdb)
