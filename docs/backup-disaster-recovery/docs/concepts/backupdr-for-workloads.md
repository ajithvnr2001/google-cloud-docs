**Caution:** Support for backing up and restoring workloads managed using the legacy appliance management console is deprecated. For more information, see [Feature deprecations](https://docs.cloud.google.com/backup-disaster-recovery/docs/deprecations).

The following pages contain conceptual information about how Backup and DR backs up data for various workloads:

    * [Backup and DR for SAP ASE](https://docs.cloud.google.com/backup-disaster-recovery/docs/concepts/backupdr-for-sap-ase)
