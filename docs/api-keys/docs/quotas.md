#  Quotas and limits Stay organized with collections  Save and categorize content based on your preferences. 

Calls to API Keys are subject to the following quotas:

API call type | Limit  
---|---  
Read-only calls  | 240 API calls per minute.  
Write calls | 120 API calls per minute.  
  
To request an increase to these quotas:

  1. In the Google Cloud console, go to the **IAM & admin** > **Quotas** page. 

[Go to Quotas](https://console.cloud.google.com/iam-admin/quotas)

  2. Select the **API Keys API** quota that you want to increase: **Read requests per minute** and/or **Write requests per minute**.
  3. Click add **Edit Quotas**.
  4. Fill out the form on the right side.
  5. Click **Submit request**.
