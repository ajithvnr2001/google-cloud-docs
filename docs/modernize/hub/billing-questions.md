Google Cloud Modernization Hub is offered at no additional charge. However, you incur standard Google Cloud charges for the underlying tools and resources that you provision or run through Modernization Hub.

## Pricing for underlying services

Depending on the workflows you run in Modernization Hub, the following services incur charges in your Google Cloud project:

  * **Application code assessments (.NET and Java)** : Running containerized `codmod` assessment jobs uses Gemini models on Gemini Enterprise Agent Platform, executes jobs in Cloud Build, and stores source archives and reports in Cloud Storage. Token usage, compute, and storage charges apply. For cost estimates based on codebase size and model selection, see [App Modernization Assessment pricing](https://docs.cloud.google.com/migration-center/docs/app-modernization-assessment#pricing).
  * **Mainframe Assessment Tool (MAT)** : Provisioning Mainframe Assessment Tool resources creates dedicated Compute Engine VMs and Persistent Disks, and uses Agent Platform and Cloud Storage. Standard compute, storage, and Agent Platform charges apply. For more information, see [Mainframe Assessment Tool pricing](https://cloud.google.com/products/mainframe-assessment-tool/pricing).



To estimate your monthly Google Cloud charges, use the [Google Cloud Pricing Calculator](https://cloud.google.com/products/calculator).

## Billing resources

To get help with billing questions, use the following resources:

  * To view billing reports, see [View your billing reports and cost trends](https://docs.cloud.google.com/billing/docs/how-to/reports).

  * To learn more about billing, read the [Cloud Billing documentation](https://docs.cloud.google.com/billing/docs).

  * To resolve billing concerns, use the [Google Cloud Billing Troubleshooter](https://support.google.com/cloud/troubleshooter/7279311).

  * To request help with billing questions, contact [Cloud Billing Support](https://docs.cloud.google.com/support/billing).

  * To change or disable billing on a project, go to the **Billing** page in the Google Cloud console. For more information, see [Modify a project's billing settings](https://docs.cloud.google.com/billing/docs/how-to/modify-project).

**Caution:** When you disable billing for a project, you also disable all product resources in that project.
