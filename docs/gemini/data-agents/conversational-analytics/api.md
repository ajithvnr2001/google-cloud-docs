#  Conversational Analytics API Stay organized with collections  Save and categorize content based on your preferences. 

Developers can use the Conversational Analytics API, which is accessed through `geminidataanalytics.googleapis.com`, to build an artificial intelligence (AI)-powered chat interface, or _data agent_. 

The API uses natural language to answer questions about structured data in a number of Google Cloud data warehouse, business intelligence, data visualization, and database products.

With the Conversational Analytics API, you provide your data agent with business information and data (_context_), as well as access to tools such as SQL, Python, and visualization libraries. You can then render agent responses for the user and log them within your client application, creating a seamless and auditable data chat experience.

For more information, see [Conversational Analytics API: Build data agents and chat with your data](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics-api/overview).
