#  Conversational analytics overview Stay organized with collections  Save and categorize content based on your preferences. 

Conversational analytics is a chat-with-your-data feature that you can use to do the following: 

  * Create simple data agents to chat about your data using natural language.
  * Create data agents that include context and instructions to effectively answer questions for specific use cases.
  * Create data agents that you make available to users in your organization.
  * Call the underlying [Conversational Analytics API](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics-api/overview) directly to create customized data agents or agentic applications that integrate data from different products or address complex use cases.



Conversational analytics is available in the following Google Cloud products:

  * [AlloyDB for PostgreSQL](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics/alloydb)
  * [BigQuery](https://docs.cloud.google.com/bigquery/docs/conversational-analytics)
  * [Cloud SQL for MySQL](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics/sql-mysql)
  * [Cloud SQL for PostgreSQL](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics/sql-postgres)
  * [Looker](https://docs.cloud.google.com/looker/docs/conversational-analytics-overview)
  * [Spanner](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics/spanner)
