#  Gemini Code Assist sign-in failed Stay organized with collections  Save and categorize content based on your preferences. 

**Error:** The authentication flow did not complete successfully, and Gemini Code Assist is **not** authorized to access your account.

## More information

Try signing in again from your IDE. If authentication fails again, then try to [troubleshoot access to Gemini Code Assist features](https://docs.cloud.google.com/gemini/docs/codeassist/troubleshoot).

## Leave feedback

If you believe that you have received this message in error, leave feedback by performing the following steps in your IDE:

  1. In the status bar of your IDE, click spark **Gemini Code Assist** , and then in the menu, select **Submit feedback**.

  2. In the text field at the top of the form, enter your feedback.

  3. If you want to share your Gemini Code Assist logs, make sure that you select the log files.

  4. Click **Submit Feedback**.
