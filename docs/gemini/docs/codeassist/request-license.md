#  Request a Gemini Code Assist license Stay organized with collections  Save and categorize content based on your preferences. 

**Important:** This page discusses access to Gemini Code Assist using a Gemini Code Assist Standard and Enterprise license. Consumer account access to Gemini Code Assist features, such as through Gemini Code Assist for individuals, [has been deprecated](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals).

You must have a valid license to use [Gemini Code Assist Standard and Enterprise](https://docs.cloud.google.com/gemini/docs/codeassist/overview#supported-features). Contact your billing administrator to [assign you a license or renew one](https://docs.cloud.google.com/gemini/docs/codeassist/manage-licenses).

Licenses are available through Gemini Code Assist [subscriptions](https://docs.cloud.google.com/gemini/docs/admin). Licenses are assigned to specific people, not to Google Cloud projects, so after you are assigned a license you can use Gemini Code Assist in any Google Cloud project that's managed by your organization.

If all licenses in a subscription have been assigned, users not yet assigned a license are shown an error message stating that they need a license to access Gemini Code Assist from their account. Your billing administrator can [purchase additional licenses](https://docs.cloud.google.com/gemini/docs/admin#edit-subscription).
