#  Gemini Code Assist chat features overview Stay organized with collections  Save and categorize content based on your preferences. 

This document outlines the chat features that Gemini Code Assist supports.

To help you comply with any license requirements for your code, Gemini Code Assist provides source citations when its suggestions directly quote at length from a specific source. To learn more about how and when Gemini cites sources, see [How Gemini helps you generate code and cites sources](https://docs.cloud.google.com/gemini/docs/discover/works#how-when-gemini-cites-sources).

You can perform the following chat actions with Gemini Code Assist in any of the [supported IDEs](https://docs.cloud.google.com/gemini/docs/codeassist/supported-languages#supported_ides):

  * [Use Gemini Code Assist to explain your code](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#chat)
  * [Create multiple chats](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#create_multiple_chats)
  * [Select a Gemini model](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#select-model)
  * [Edit a prior prompt](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#edit_a_prior_prompt)
  * [Regenerate a prompt response](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#regenerate_a_prompt_response)
  * [Delete prompt and response pairs](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#delete_prompt_and_response_pairs)
  * [Configure code preview pane](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#configure_code_preview_pane)
  * [Prompt Gemini Code Assist with selected code using chat](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#prompt_with_selected_code_using_chat)
  * [Add selected code snippets to context](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#add_selected_code_snippets_to_context)
  * [Add terminal output to the chat context](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#prompt_with_selected_terminal_output_using_chat)
  * [Specify files and folders in your workspace context](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#specify-context)
  * [Revert to a checkpoint in chat](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#revert_to_a_checkpoint_in_chat)
  * [View code diffs](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#view_code_diffs)
  * [Generate a file outline](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#outline)
  * [Create custom commands](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#create_custom_commands)
  * [Create rules](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini#create_rules)
  * [Exclude files from your context with an `.aiexclude` or `.gitignore` file](https://docs.cloud.google.com/gemini/docs/codeassist/create-aiexclude-file)
  * [Use the Gemini Code Assist agent mode](https://docs.cloud.google.com/gemini/docs/codeassist/use-agentic-chat-pair-programmer)
  * [Configure local codebase awareness](https://docs.cloud.google.com/gemini/docs/codeassist/configure-local-codebase-awareness)



## What's next

  * [Set up Gemini Code Assist Standard or Enterprise](https://docs.cloud.google.com/gemini/docs/codeassist/set-up-gemini), if you haven't already.

  * To begin using Gemini Code Assist chat features in your IDE, see [Chat with Gemini Code Assist](https://docs.cloud.google.com/gemini/docs/codeassist/chat-gemini).

  * Learn [how and when Gemini Code Assist uses your data](https://docs.cloud.google.com/gemini/docs/discover/data-governance).
