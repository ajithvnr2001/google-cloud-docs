#  Control access to Gemini Code Assist for individuals Stay organized with collections  Save and categorize content based on your preferences. 

As an administrator for your Google Cloud organization, you can control access to [Gemini Code Assist for individuals](https://developers.google.com/gemini-code-assist/docs/overview), the free version of Gemini Code Assist service which includes [IDE support](https://docs.cloud.google.com/gemini/docs/codeassist/supported-languages#supported_ides), [Gemini CLI](https://geminicli.com/), and [Antigravity](https://antigravity.google/), by using the Google Admin console within Google Workspace.

## Before you begin

To change access settings for Gemini Code Assist for individuals, you must be a Google Workspace administrator with the [**Service Settings** privilege](https://support.google.com/a/answer/1219251#service_settings).

This privilege is available in [administrator roles](https://support.google.com/a/answer/2405986) such as the **Super Admin** role and the **Services Admin** role.

## Allow or block access to Gemini Code Assist for individuals

To toggle access to Gemini Code Assist for individuals, do the following:

  1. Go to the Google Workspace Admin console.

[Go to the Admin console](https://admin.google.com)

  2. If you're not already signed in, follow the steps to sign in to the Admin console.

  3. In the navigation menu, click **Apps**.

  4. In the pane that opens, click **Additional Google Services**.

  5. In the pane that opens, click **Google Cloud Platform**.

  6. In the **Code Assist settings** pane, use the checkbox for **Allow access to Code Assist for individuals** to allow or block access.

  7. Click **Save**.
