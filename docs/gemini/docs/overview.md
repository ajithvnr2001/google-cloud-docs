#  Google Cloud with Gemini overview Stay organized with collections  Save and categorize content based on your preferences. 

Gemini offers generative AI-powered assistance to a wide range of Google Cloud users, including developers and data scientists. To provide an integrated assistance experience, Gemini is embedded in many Google Cloud products.

If you want to use Gemini models to create your own generative AI application, see [Overview of Generative AI on Vertex AI](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/overview).

The following table shows the types of generative AI assistance that are available in Google Cloud, along with links to product overview information:

**Product** | **Type of assistance** | **Tasks**  
---|---|---  
[Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/overview) | 

  * Design, optimize, and operate cloud applications.

| 

  * Efficiently manage cloud applications.
  * Create, optimize, and troubleshoot resources quickly.
  * Manage resource security configurations.

  
[Gemini Code Assist](https://docs.cloud.google.com/gemini/docs/codeassist/overview) | 

  * Develop, deploy, and troubleshoot code.

| 

  * Generate and debug code, and generate unit tests.
  * Offer suggestions for code optimization.
  * Build integrations that connect enterprise applications like Salesforce, databases like MySQL, and event-driven systems like Pub/Sub.

  
[Gemini in BigQuery](https://docs.cloud.google.com/bigquery/docs/gemini-overview) | 

  * Prepare and analyze data.

| 

  * Discover, transform, query, and visualize data with data canvas.
  * Explore data patterns, quality, and statistics with data insights.
  * Generate, complete, and explain SQL and Python code.
  * Get recommendations to help prepare your data for analysis.

  
[Gemini in Colab Enterprise](https://docs.cloud.google.com/colab/docs/gemini-in-colab/overview) | 

  * Generate Python code in a Colab Enterprise notebook.

| 

  * Generate code completion suggestions while typing in a code cell.
  * Generate code by using the **Help me code** tool.

  
[Gemini in Looker](https://docs.cloud.google.com/looker/docs/gemini-overview-looker) | 

  * Analyze and export Looker data.

| 

  * Create custom Looker visualizations.
  * Generate LookML modeling parameters.
  * Ask questions about and converse with your data.
  * Build a custom data agent.
  * Create calculated fields.

  
[Gemini in Data Studio](https://docs.cloud.google.com/data-studio/gemini-overview) | 

  * Analyze and export Data Studio data.

| 

  * Ask questions about and converse with your data.
  * Build a custom data agent.
  * Create calculated fields.
  * Export report visualizations to Google Slides.

  
[Gemini in Security Command Center](https://docs.cloud.google.com/security-command-center/docs/gemini-overview) | 

  * Simplify search queries and interpret cases.

| 

  * Generate UDM search queries for threat investigations from your natural language questions.
  * Summarize cases that are opened for security issues and suggest steps to resolve the issues.
