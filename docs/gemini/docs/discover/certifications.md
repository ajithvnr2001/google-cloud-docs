#  Certifications and security for Gemini products in Google Cloud Stay organized with collections  Save and categorize content based on your preferences. 

Gemini for Google Cloud incorporates enterprise security controls and industry compliance standards to safeguard your data, help you satisfy regulatory requirements, and maintain governance across your organization.

## Certifications

**Important:** The certifications covered in this section don't apply to [Gemini Code Assist on GitHub](https://developers.google.com/gemini-code-assist/docs/review-repo-code).

The following table shows certifications for [Gemini products in Google Cloud](https://docs.cloud.google.com/gemini/docs/overview):

Certification | Compliant?  
---|---  
BSI C5:2020 | Yes  
CSA STAR | Yes  
FINMA | Yes  
HIPAA | Yes  
HITRUST CSF | Yes  
ISO 27001, ISO 27017, ISO 27018, ISO 27701 | Yes  
ISO 42001 | Yes  
Multi-tiered Cloud Computing Security Management System (MTCS) | Yes  
OSPAR | Yes  
PCI 3D Secure (PCI 3DS) v1.0 | Yes  
PCI-DSS v4.0.1 | Yes  
SOC1 | Yes  
SOC2 | Yes  
SOC3 | Yes  
  
## Security features

This section describes security-related features for different Gemini products in Google Cloud.

### Gemini Code Assist

The following table shows the security-related features for Gemini Code Assist:

Security feature | Gemini Code Assist support? | [Gemini Code Assist on GitHub](https://developers.google.com/gemini-code-assist/docs/review-repo-code) support?  
---|---|---  
[VPC Service Controls](https://docs.cloud.google.com/vpc-service-controls/docs/overview) | [Yes](https://docs.cloud.google.com/vpc-service-controls/docs/supported-products#table_gemini) | No  
[Access Transparency](https://docs.cloud.google.com/assured-workloads/access-transparency/docs/overview) | No | No  
[Customer-managed encryption keys (CMEK)](https://docs.cloud.google.com/kms/docs/cmek) | [Yes](https://docs.cloud.google.com/gemini/docs/codeassist/encrypt-data-cmek) | No  
[Data residency](https://cloud.google.com/terms/data-residency) at rest | Yes | No
