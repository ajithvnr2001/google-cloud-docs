#  Turn off Gemini products in Google Cloud Stay organized with collections  Save and categorize content based on your preferences. 

You can turn off Gemini features for certain Google Cloud products at the individual product level, and you can deactivate the Gemini for Google Cloud API, a core Gemini API for a number of Google Cloud products. The following table directs you to the deactivation guide for each supported product.

**Product** | **Guide**  
---|---  
[Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/overview) | [Turn off Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/turn-off)  
[Gemini Code Assist](https://docs.cloud.google.com/gemini/docs/codeassist/overview) | [Turn off Gemini Code Assist](https://docs.cloud.google.com/gemini/docs/codeassist/turn-off)  
[Gemini in BigQuery](https://docs.cloud.google.com/bigquery/docs/gemini-overview) | [Turn off Gemini in BigQuery](https://docs.cloud.google.com/bigquery/docs/gemini-set-up#turn-off)  
[Gemini in Colaboratory](https://docs.cloud.google.com/colab/docs/gemini-in-colab/overview) | [Turn off Gemini in Colab Enterprise](https://docs.cloud.google.com/colab/docs/gemini-in-colab/turn-off-gemini)  
[Gemini in Data Studio](https://docs.cloud.google.com/data-studio/gemini-overview) | [Enable and disable Gemini in Data Studio](https://docs.cloud.google.com/data-studio/enable-and-disable-gemini-in-data-studio)  
[Gemini in Looker](https://docs.cloud.google.com/looker/docs/gemini-overview-looker) | 

  * **Google Cloud core** : [Administer Gemini on your Looker (Google Cloud core) instance](https://docs.cloud.google.com/looker/docs/looker-core-admin-gemini)
  * **Original** : [Admin settings - Gemini in Looker](https://docs.cloud.google.com/looker/docs/admin-panel-platform-gil)

  
  
## Turn off the Gemini for Google Cloud API

After you turn off all Gemini products for your Google Cloud project, turn off the Gemini for Google Cloud API (`cloudaicompanion.googleapis.com`). For more information, see [Disable a service](https://docs.cloud.google.com/service-usage/docs/enable-disable#disabling).
