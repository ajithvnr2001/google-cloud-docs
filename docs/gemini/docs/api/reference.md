The Cloud AI Companion API, in conjunction with the Gemini Cloud Assist API, provides generative AI-powered assistance to a wide range of Google Cloud users, including developers and data scientists. To provide an integrated assistance experience, Gemini for Google Cloud is embedded in many Google Cloud products.

API reference documentation for Cloud AI Companion can be found at <https://docs.cloud.google.com/gemini/docs/api/reference/rest>.

If you want to learn more about Gemini for Google Cloud generally, see [Gemini for Google Cloud overview](https://docs.cloud.google.com/gemini/docs/overview).

If you want to explore the Gemini Cloud Assist API, see the [Gemini Cloud Assist API reference documentation](https://docs.cloud.google.com/cloud-assist/reference/rest).
