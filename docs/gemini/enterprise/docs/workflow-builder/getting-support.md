This page describes how to troubleshoot issues, contact support, and provide feedback for the Workflow Builder Early Access Program (EAP).

## Troubleshooting

If you encounter an issue, try the following steps:

  1. **Perform a hard refresh:** Refresh your browser to resolve intermittent issues. You won't lose any data.

     * Windows/Linux: `Ctrl + Shift + R` or `Ctrl + F5`
     * macOS: `Command + Shift + R`
  2. **Check known issues:** Review the [Known issues and limitations](https://docs.cloud.google.com/gemini/enterprise/docs/workflow-builder/known-issues) page to see if your issue is already documented with a workaround.




## Contact support

Use the [Report Workflow Builder EAP Issue or Bug](https://forms.gle/cXjSYmTX4rrQAoKB6) form to report an issue or send feedback to the Workflow Builder team.

### Send diagnostic information

Including diagnostic information helps the team debug and resolve issues more quickly.

To send the diagnostic information, perform the following steps for the type of issue you're experiencing:

#### Workflow execution issues

If you encounter an issue during a workflow agent run or simulation:

  1. In the **Preview** or **Run** tab, click bug_report **Show diagnostic info**. 

![Diagnostic info button in preview pane](https://docs.cloud.google.com/static/gemini/enterprise/docs/workflow-builder/images/debug1.png)

  2. In the **Diagnostic information** dialog, click content_copy **Copy info**. 

![Diagnostic info button in preview pane](https://docs.cloud.google.com/static/gemini/enterprise/docs/workflow-builder/images/debug2.png)

  3. Email the copied diagnostic information to the Workflow Builder team at [agent-designer-external@google.com](mailto:agent-designer-external@google.com).



#### Natural language interface issues

If you encounter an issue using the conversational designer to generate or edit a workflow:

  1. Within the chat interface, click adb **Show diagnostic info**. 

![Diagnostic info button in preview pane](https://docs.cloud.google.com/static/gemini/enterprise/docs/workflow-builder/images/debug1.1.png)

  2. In the **Diagnostic information** dialog, click content_copy **Copy info**. 

![Diagnostic info button in preview pane](https://docs.cloud.google.com/static/gemini/enterprise/docs/workflow-builder/images/debug2.png)

  3. Email the copied diagnostic information to the Workflow Builder team at [agent-designer-external@google.com](mailto:agent-designer-external@google.com).
