#  SiteSearchEngine Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



SiteSearchEngine captures DataStore level site search persisting configurations. It is a singleton value per data store.

JSON representation  
---  
      
    
    {
      "name": string
    }  
  
Fields  
---  
`name` |  `string` The fully qualified resource name of the site search engine. Format: `projects/*/locations/*/dataStores/*/siteSearchEngine`
