#  Compliance and security profile Stay organized with collections  Save and categorize content based on your preferences. 

AlphaEvolve supports Gemini Enterprise security controls, with some limitations.

For more information, see the Gemini Enterprise [security controls](https://docs.cloud.google.com/gemini/enterprise/docs/compliance-security-controls) documentation and the Gemini Enterprise [product limitations](https://docs.cloud.google.com/gemini/enterprise/docs/locations#product-limitations) for details.

  * Model Armor: AlphaEvolve does not support Model Armor integration.

  * Public sector restrictions: AlphaEvolve does not support Assured Workloads, FedRAMP, and Department of Defense (DoD) compliance requirements. If you have these requirements, then you don't have access by default and you should contact your account team to request access.




For more information, see the [FedRAMP and DoD compliance scope](https://docs.cloud.google.com/docs/security/compliance/fedramp-dod-compliance-scope) documentation.
