This page documents production updates to Cloud Hub. Check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality. 

You can see the latest product updates for all of Google Cloud on the [ Google Cloud](https://docs.cloud.google.com/release-notes) page, browse and filter all release notes in the [Google Cloud console](https://console.cloud.google.com/release-notes), or programmatically access release notes in [BigQuery](https://console.cloud.google.com/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table). 

To get the latest product updates delivered to you, add the URL of this page to your [feed reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the [feed URL](https://docs.cloud.google.com/feeds/cloudhub-release-notes.xml) directly. 

## August 10, 2026

Announcement

Starting September 15, 2026, the App Topology API transitions to a usage-based billing model that includes a daily free data usage allotment. For more information, see [App Topology pricing](https://docs.cloud.google.com/hub/docs/app-topology#pricing).

## July 17, 2026

Feature

The [Security & compliance](https://docs.cloud.google.com/hub/docs/security) page in Cloud Hub has launched to [General Availability](https://cloud.google.com/products#product-launch-stages).

## April 22, 2026

Feature

Cost optimization with Gemini Cloud Assist provides the following additional features:

  * In the Gemini Cloud Assist chat panel, get an explanation for cost changes for supported resources.
  * On the Optimization page in Cloud Hub, get insights about recent cost changes and related changes in resource usage.



For more information, see [Optimize costs with Gemini assistance](https://docs.cloud.google.com/hub/docs/optimize-gemini).

Feature

[App Topology ](https://docs.cloud.google.com/hub/docs/app-topology) is in [Preview](https://cloud.google.com/products#product-launch-stages). App Topology lets you query data about your resources and applications from multiple sources, and then view the correlated data as a topology graph.

## April 14, 2026

Feature

The Deployments page supports viewing [recent application deployments](https://docs.cloud.google.com/hub/docs/deployments#view-deployments) to Google Kubernetes Engine (GKE) and Cloud Run.

## April 10, 2026

Feature

The Maintenance page supports [viewing maintenance activities](https://docs.cloud.google.com/hub/docs/maintenance) for App Hub applications that you have created in [App Hub](https://docs.cloud.google.com/app-hub/docs/overview) or [Application Design Center](https://docs.cloud.google.com/application-design-center/docs/overview). This feature is in [Preview](https://cloud.google.com/products#product-launch-stages).

## April 09, 2026

Feature

[Security & compliance](https://docs.cloud.google.com/hub/docs/security) in Cloud Hub is in [Preview](https://cloud.google.com/products#product-launch-stages).

## December 16, 2025

Announcement

[Cloud Hub](https://docs.cloud.google.com/hub/docs/overview) is [generally available](https://cloud.google.com/products#product-launch-stages).

## November 14, 2025

Feature

You can now view [Active Assist cost optimization recommendations](https://docs.cloud.google.com/hub/docs/optimize) in Cloud Hub is now in [Preview](https://cloud.google.com/products#product-launch-stages).

## October 27, 2025

Change

All scheduled and started maintenance activities are now listed together on the [Maintenance page](https://docs.cloud.google.com/hub/docs/maintenance). You can use the more_vert **Settings** menu for scheduled activities that you can modify.

## July 24, 2025

Feature

[Cost optimization](https://docs.cloud.google.com/hub/docs/optimize) in Cloud Hub is now in [Preview](https://cloud.google.com/products#product-launch-stages).

## April 09, 2025

Announcement

Cloud Hub is available in [Preview](https://cloud.google.com/products#product-launch-stages).
