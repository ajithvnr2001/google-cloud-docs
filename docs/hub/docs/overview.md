#  Cloud Hub overview Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Hub provides you with a centralized view of operations data and insights for your Google Cloud applications and resources. Viewing this data together in one place helps you to take action on important issues, patterns, and trends.

  * View active events, including Google Cloud incidents and maintenance activities.
  * View health data, including Monitoring alerts and metrics for health and performance.
  * Access your security and compliance posture using data from Security Command Center.
  * View capacity data, including quota usage and Compute Engine resource usage.
  * View failed App Hub application deployments and available application updates.
  * View open support cases and Cloud Customer Care information.
  * Correlate data across multiple data sources.



Cloud Hub can display data for a selected Google Cloud project or _App Hub application_.

## View data by application

Many cloud applications evolve to include multiple infrastructure resources from one or more Google Cloud projects, which can make it harder for both developers and operators to manage and understand these resources. By organizing your resources as [App Hub](https://docs.cloud.google.com/app-hub/docs/overview) applications, you can better understand resource interactions and analyze, monitor, manage, and troubleshoot in an application-centric way.

You can use App Hub to create applications from existing Google Cloud workloads or use [Application Design Center](https://docs.cloud.google.com/application-design-center/docs/overview) to design and deploy new Google Cloud resources, which automatically provision App Hub applications.

To learn more about viewing data by project or by application, see [Application views and project views](https://docs.cloud.google.com/hub/docs/app-project-views).

## Find the information you need

Cloud Hub displays groups of related data on the following main pages:

[Home](https://docs.cloud.google.com/hub/docs/home)

Brings together top items from each of the categories of information in Cloud Hub so that you can get a summary of the health and performance of your Google Cloud resources on a single page.

[Deployments](https://docs.cloud.google.com/hub/docs/deployments)

  * View failed application deployments from Application Design Center and the identified cause of the failure.
  * View deployed applications with an available update.



[Health & troubleshooting](https://docs.cloud.google.com/hub/docs/health)

  * View open alerts based on alerting policies that you set up in Cloud Monitoring.
  * View active Google Cloud incidents for service outages or degradations.
  * View metrics about the health and performance of Google Cloud resources such as utilization, latency, or errors.



[Security & compliance](https://docs.cloud.google.com/hub/docs/security)

  * View top critical and high severity Security Command Center findings.
  * Monitor compliance frameworks.
  * Prioritize top failing cloud controls.



[Optimization](https://docs.cloud.google.com/hub/docs/optimize)

  * View the total cost and cost trend for a selected project or application.
  * View the top five resources or application workloads with the highest cost.
  * View the five most expensive resources or workloads with the lowest utilization.



[Quotas & reservations](https://docs.cloud.google.com/hub/docs/quotas-reservations)

  * View Google Cloud quotas and system limits with over 90% usage.
  * View historical and forecasted usage of Compute Engine resources.
  * View Compute Engine reservations.



[Maintenance](https://docs.cloud.google.com/hub/docs/maintenance)

  * View upcoming, in-progress, and completed maintenance activities and the affected resources. For some types of maintenance activities, you can reschedule the maintenance activity or apply an on-demand update.
  * View completed or canceled maintenance activities.



[Support](https://docs.cloud.google.com/hub/docs/support)

  * View open support cases, or open a new case.
  * View active Google Cloud incidents.
  * View in-progress maintenance.
  * Learn about your support package and other support package options.



[App Topology](https://docs.cloud.google.com/hub/docs/app-topology) ([Preview](https://cloud.google.com/products/#product-launch-stages))

  * Query data about your resources and applications across health and troubleshooting, security, and deployments, and then analyze the results as an interactive topology graph.
