#  Query and correlate data Stay organized with collections  Save and categorize content based on your preferences. 

App Topology lets you query data about your resources and applications from multiple sources, and then view the correlated data as a topology graph. For example, you can view all agents that have a specific vulnerability.

By bringing together data across multiple sources, App Topology helps you to understand relationships, dependencies, and context in one place.

In Cloud Hub you can view correlated data for several domains, including health and troubleshooting, deployment, and security. App Topology also provides topology graphs that are focused on specific uses in other areas of Google Cloud. To learn more, see [Types of topologies](https://docs.cloud.google.com/hub/docs/app-topology/run-queries#domains).

## App Topology pricing

Starting October 15, 2026, the App Topology API transitions to a usage-based billing model that includes a daily free data usage allotment.

For more information, see [App Topology pricing](https://cloud.google.com/products/app-topology/pricing).
