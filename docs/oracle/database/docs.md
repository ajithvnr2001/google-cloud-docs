# Oracle Database@Google Cloud documentation

[Read product documentation](https://docs.cloud.google.com/oracle/database/docs/overview)

Google Cloud's partnership with Oracle allows you to combine Oracle Cloud Infrastructure (OCI) and Google Cloud technologies. With native integration, you can deploy your Oracle database services in a Google Cloud data center running on Oracle Cloud Infrastructure (OCI) Exadata hardware with minimal latency. Workloads reside in Google Cloud and the Exadata systems are deployed in Google Cloud data centers.
