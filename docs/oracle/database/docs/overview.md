#  Oracle Database@Google Cloud overview Stay organized with collections  Save and categorize content based on your preferences. 

This page provides an overview of the Oracle Database@Google Cloud service.

Google Cloud's partnership with Oracle lets you combine Oracle Cloud Infrastructure (OCI) and Google Cloud technologies. With built-in integration, you can deploy your Oracle AI Database services in a Google Cloud data center running on OCI Exadata hardware with minimal latency. Workloads reside in Google Cloud and Exadata systems are deployed in Google Cloud data centers. Google Cloud provides the core infrastructure, the network, the physical and network security, and hardware monitoring capabilities for your OCI resources.

Oracle Database@Google Cloud supports the following Oracle Cloud Infrastructure (OCI) products on Google Cloud:

  * [Exadata Database Service](https://docs.oracle.com/en-us/iaas/exadatacloud/index.html#Exadata_DB_Systems)
  * [Autonomous AI Database Service](https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/autonomous-intro-adb.html)
  * [Base Database Service](https://docs.oracle.com/en/cloud/paas/base-database/about/index.html)
  * [Exadata Database Service on Exascale Infrastructure](https://docs.oracle.com/en/engineered-systems/exadata-database-exascale/exdxs/overview-exadb-xs-service.html)
  * [Goldengate](https://docs.oracle.com/en/cloud/paas/goldengate-service/druyg/)



For more information, see [Oracle Database@Google Cloud YouTube playlist](https://www.youtube.com/playlist?list=PLBgogxgQVM9tW2RIHIABzpJCTAyTBPdM4) and [Google Skills course: Running Oracle workloads on Google Cloud](https://www.skills.google/course_templates/1679).

## What Oracle Database@Google Cloud provides

Oracle Database@Google Cloud offers many services to allow you to seamlessly integrate and manage your OCI resources in Google Cloud:

  * ODB Network connectivity
  * Manage access using Identity and Access Management (IAM)
  * Create and manage Exadata Database Service resources
  * Create and manage Exascale Infrastructure resources
  * Create and manage Autonomous AI Database Service resources
  * Create and manage Base Database Service resources
  * Create and manage Goldengate resources
  * Observe and Troubleshoot resources



### ODB Network connectivity

Oracle Database@Google Cloud uses ODB Networks to manage connectivity to your resources. For more information about how ODB Networks work, see [Set up Oracle Database@Google Cloud environment](https://docs.cloud.google.com/oracle/database/docs/setup-oracle-database-environment).

### Manage access using Identity and Access Management

Oracle Database@Google Cloud uses Identity and Access Management integration to manage user and group access for your Exadata Infrastructure and Autonomous AI Database resources. For more information on how IAM works, see [IAM overview](https://docs.cloud.google.com/oracle/database/docs/iam-overview).

### Create and manage Oracle Exadata Database Service resources

Oracle Database@Google Cloud lets you create and manage [Exadata Infrastructure instances](https://docs.cloud.google.com/oracle/database/docs/create-instances) and [Exadata VM Clusters](https://docs.cloud.google.com/oracle/database/docs/create-clusters) using Google Cloud console, Google Cloud CLI, or the Oracle Database@Google Cloud API.

Exadata Databases can only be created in Oracle Cloud Infrastructure (OCI).

### Create and manage Exascale Infrastructure resources

Oracle Database@Google Cloud lets you create and manage [Exascale VM Clusters and Exascale Storage Vaults](https://docs.cloud.google.com/oracle/database/docs/create-exascale-clusters) on Exascale Infrastructure.

### Create and manage Autonomous AI Database Service resources

Oracle Database@Google Cloud lets you create and manage [Autonomous AI Database](https://docs.cloud.google.com/oracle/database/docs/create-databases) resources using Google Cloud console, Google Cloud CLI, or the Oracle Database@Google Cloud API.

### Create and manage Base Database Service resources

Oracle Database@Google Cloud lets you create and manage [DB system](https://docs.cloud.google.com/oracle/database/docs/create-base-db-system) resources using Google Cloud console, Google Cloud CLI, or the Oracle Database@Google Cloud API.

### Create and manage Goldengate resources

Oracle Database@Google Cloud lets you [create and manage Goldengate](https://docs.cloud.google.com/oracle/database/docs/deploy-and-connect) resources using Google Cloud console, Google Cloud CLI, or the Oracle Database@Google Cloud API.

### Observe and troubleshoot resources

You can monitor and troubleshoot your Oracle Database@Google Cloud resources using available [metrics](https://docs.cloud.google.com/oracle/database/docs/monitoring-metrics) and [logs](https://docs.cloud.google.com/oracle/database/docs/view-resource-logs).

## Networking prerequisites

Before you can create Exadata Infrastructure or Autonomous AI Database resources, you must set up [networking](https://docs.cloud.google.com/oracle/database/docs/configure-vpc) for your project.

## Available regions and zones

To see which regions and zones are available for Oracle Database@Google Cloud, see [Regions and zones](https://docs.cloud.google.com/oracle/database/docs/regions-and-zones).

## Get started with Oracle Database@Google Cloud

To get started with Oracle Database@Google Cloud and place an order, see [Purchase and billing](https://docs.cloud.google.com/oracle/database/docs/purchase-and-billing).
