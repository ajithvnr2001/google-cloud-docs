This page describes how to manage an Autonomous AI Database in Google Cloud.

In Oracle Database@Google Cloud, you can modify an Autonomous AI Database using Oracle Cloud Infrastructure (OCI). To create an Autonomous AI Database, see [Create databases](https://docs.cloud.google.com/oracle/database/docs/create-databases).

To learn more about Oracle Database@Google Cloud, see [Product overview](https://docs.cloud.google.com/oracle/database/docs/overview).

## Before you begin

  * [Set up the gcloud CLI and enable the API](https://docs.cloud.google.com/oracle/database/docs/set-up).

  * Enable the Oracle Database@Google Cloud API for the project.

[Enable the Oracle Database@Google Cloud API](https://console.cloud.google.com/apis/enableflow?apiid=oracledatabase.googleapis.com)

  * Confirm that you have the required roles necessary to read an instance: `autonomousDatabaseViewer`.

For more information on how to assign roles, see [Apply IAM roles](https://docs.cloud.google.com/oracle/database/docs/iam-roles).

  * Confirm that you have the required [OCI permissions](https://docs.oracle.com/en/cloud/paas/autonomous-database/serverless/adbsb/autonomous-database-iam-policies.html) necessary to manage an Autonomous AI Database.




## Manage database

### Console

  1. Go to the **Autonomous AI Database Service** page in the Google Cloud console.

[Go to Autonomous AI Database Service](https://console.cloud.google.com/oracle/autonomous-databases/)

  2. In the **Autonomous AI Databases** section, click the name of the database you want to modify.

  3. Click **Manage in OCI**.

You'll be redirected to the OCI page to modify your database. Modifying a database isn't supported in Google Cloud console.

For more information on how to manage an Autonomous AI Database, see [Using Oracle Autonomous AI Database](https://docs.oracle.com/en/cloud/paas/autonomous-database/serverless/adbsb/start-stop-grow.html#GUID-A7709630-F938-41DE-8CA0-3499D0F8FE2A).




## What's next

  * Configure [Identity and Access Management roles](https://docs.cloud.google.com/oracle/database/docs/iam-roles) for a database.
  * [Use monitoring metrics](https://docs.cloud.google.com/oracle/database/docs/monitoring-metrics) to monitor your databases.
