#  Manage DB systems Stay organized with collections  Save and categorize content based on your preferences. 

This page describes how to manage a DB system.

After you've provisioned a DB system, Oracle Database@Google Cloud lets you modify its settings through the Oracle Cloud Infrastructure (OCI) console.

## Before you begin

  * Make sure that you have the required Identity and Access Management (IAM) roles and permissions to view a DB system:

    * `roles/oracledatabase.dbSystemViewer`

For information on how to assign roles, see [Apply IAM roles](https://docs.cloud.google.com/oracle/database/docs/iam-roles).

  * Make sure that you have the required OCI permissions necessary to manage a DB system and its databases. Refer to the Oracle documentation.




## Manage database

  1. Go to the **Base Database Service** page.

[Go to Base Database Service](https://console.cloud.google.com/oracle/basedb/)

  2. Click the name of the DB system which you want to modify.

  3. On the **DB system details** page, click **Manage in OCI**.

  4. To modify the container database, do the following:

     1. Go to the **Databases** section.
     2. Click the name of the container database.
     3. On the **Database details** page, click **Manage in OCI**.



You're redirected to the OCI page to modify your DB system and its container database.

For information on how to manage a DB system, refer to the Oracle documentation.
