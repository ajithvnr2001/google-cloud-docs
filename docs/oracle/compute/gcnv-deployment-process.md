#  Oracle Database deployment process using NetApp Volumes Stay organized with collections  Save and categorize content based on your preferences. 

This page describes the Oracle Database deployment process using Google Cloud NetApp Volumes and Oracle Data Guard.

The deployment process consists of the following high-level steps:

  1. [Familiarize yourself with the deployment architecture](https://docs.cloud.google.com/oracle/compute/gcnv-oracle-deployment), if not already done so.
  2. [Complete the prerequisites](https://docs.cloud.google.com/oracle/compute/gcnv-prerequisites).
  3. [Provision Compute Engine instances](https://docs.cloud.google.com/oracle/compute/gcnv-provision-compute-instances).
  4. [Provision NetApp Volumes iSCSI volumes](https://docs.cloud.google.com/oracle/compute/gcnv-provision-gcnv-volumes).
  5. [Install Oracle software](https://docs.cloud.google.com/oracle/compute/gcnv-install-oracle-software).
  6. [Create the primary database](https://docs.cloud.google.com/oracle/compute/gcnv-create-primary-database).
  7. [Create the standby database](https://docs.cloud.google.com/oracle/compute/gcnv-create-standby-database).
  8. [Finalize the standby database for Oracle Data Guard](https://docs.cloud.google.com/oracle/compute/gcnv-finalize-standby).
  9. [Configure Data Guard Broker, Fast-Start Failover, and Observer](https://docs.cloud.google.com/oracle/compute/gcnv-configure-broker-fsfo-observer).
