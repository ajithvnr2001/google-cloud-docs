#  Announcement of upcoming network enhancements Stay organized with collections  Save and categorize content based on your preferences. 

This page covers upcoming network enhancements for IP address announcements by global external Application Load Balancer and Cloud CDN. This update enables optimal routing for global traffic.

The update will be performed iteratively on global external Application Load Balancer and Cloud CDN IPv4 and IPv6 address blocks over the period **beginning November 6, 2023 and ending November 17, 2023**.

## What do you need to do?

No action is required from you. However, you might experience a temporary increase in client reconnections to your global external Application Load Balancer or Cloud CDN instances. Depending on how client connections are performed, certain applications might experience a brief period (less than three minutes) of packet loss, higher-than-normal latency, or connection resets during the maintenance window while the network's IP address announcements are being upgraded.

Otherwise, this network enhancement is transparent to your applications.

For more information about these products, see the following topics:

  * [External Application Load Balancer overview](https://docs.cloud.google.com/load-balancing/docs/https)
  * [Cloud CDN overview](https://docs.cloud.google.com/cdn/docs/overview)
