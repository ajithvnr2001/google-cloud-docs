Use these general resources to check pricing, quotas, metrics, and support information for your Cloud Load Balancing deployments.

## General resources

  * ### [Pricing Pricing details for Cloud Load Balancing, including charges for forwarding rules, data processing, and network traffic.  ](https://cloud.google.com/vpc/network-pricing#cloud-load-balancing)
  * ### [Quotas and limits Quotas and limits for Cloud Load Balancing resources such as forwarding rules, backend services, and more.  ](https://docs.cloud.google.com/load-balancing/docs/quotas)
  * ### [Metrics Key performance and health metrics reported by Cloud Monitoring for Cloud Load Balancing resources.  ](https://docs.cloud.google.com/load-balancing/docs/metrics)
  * ### [Release notes Release notes, announcements, and feature updates for Cloud Load Balancing products.  ](https://docs.cloud.google.com/load-balancing/docs/release-notes)
  * ### [Points of presence Globally distributed Google points of presence (PoPs) where user connections terminate close to the client before routing traffic to your resources.  ](https://docs.cloud.google.com/load-balancing/docs/locations)
  * ### [Security bulletins Security bulletins, vulnerability reports, and mitigation details for Cloud Load Balancing-related infrastructure.  ](https://docs.cloud.google.com/load-balancing/docs/security-bulletins)
  * ### [Service Level Agreement Service Level Agreement (SLA) specifications and downtime compensation terms, which use the Compute Engine SLA.  ](https://docs.cloud.google.com/compute/sla)
