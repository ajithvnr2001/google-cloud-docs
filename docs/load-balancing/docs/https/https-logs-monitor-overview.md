#  External Application Load Balancer logging and monitoring overview Stay organized with collections  Save and categorize content based on your preferences. 

This document provides you an overview about logs and metrics generated by external Application Load Balancers.

To learn how to configure and use [Cloud Logging](https://docs.cloud.google.com/logging) and [Cloud Monitoring](https://docs.cloud.google.com/monitoring), list of metrics, log record formats, and other information, refer to the following pages:

  * [Global external Application Load Balancer and classic Application Load Balancer logging and monitoring](https://docs.cloud.google.com/load-balancing/docs/https/https-logging-monitoring).
  * [Regional external Application Load Balancer logging and monitoring](https://docs.cloud.google.com/load-balancing/docs/https/https-reg-logging-monitoring).
