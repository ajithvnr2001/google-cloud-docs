#  Locations Stay organized with collections  Save and categorize content based on your preferences. 

Google Cloud Application Load Balancers and proxy Network Load Balancers are implemented in software with points of presence (PoPs) distributed globally.

Google's PoPs contain software systems that load balance traffic in sync with each other by working with Google's global control plane. Your user traffic is directed to a single IP address. PoPs terminate traffic as near as possible to your users and direct load-balanced traffic to the closest healthy backend that has capacity.

PoPs are located in more than 100 locations. The set of PoPs in active use can change without notice. Equipment maintenance, equipment failure, the introduction of new PoPs, the removal of old PoPs, and other events mean that the list might not reflect the PoPs currently in use.

Many of the cities below have multiple PoPs to support service demand or to peer with different network partners.
