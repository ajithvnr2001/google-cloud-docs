Get details of a ProductSuite.

### HTTP request

`GET https://cloudproductregistry.googleapis.com/v1/{name=productSuites/*}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`name` |  `string` Required. The name of the ProductSuite to retrieve. Format: productSuites/{productSuite}  
  
### Request body

The request body must be empty.

### Response body

If successful, the response body contains an instance of `[ProductSuite](https://docs.cloud.google.com/product-registry/reference/cloudproductregistry-api/rest/v1/productSuites#ProductSuite)`.
