# Service Extensions documentation

[Read product documentation](https://docs.cloud.google.com/service-extensions/docs/overview)

Service Extensions is an extensibility product that enables the users of Google Cloud applications, such as Media CDN and Application Load Balancer, to provide programmability and extensibility at the edge and on load balancing data paths.
