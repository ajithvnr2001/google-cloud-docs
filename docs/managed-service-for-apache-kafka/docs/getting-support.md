Support offerings are available from Google Cloud that can include 24/7 coverage, phone support, and access to technical account services. For more information, see [Getting Cloud Customer Care](https://docs.cloud.google.com/support/docs).

## Request quota changes

To increase or decrease quotas, see [Quotas and limits](https://docs.cloud.google.com/managed-service-for-apache-kafka/quotas).

## Ask a development question

For help using Google Cloud Managed Service for Apache Kafka, you can post questions to the developer community on [Google Cloud community](https://www.googlecloudcommunity.com/gc/forums/filteredbylabelpage/board-id/cloud-data-analytics/label-name/Apache%2520Kafka). 

## File bugs or feature requests

For documentation feedback, click the **Send feedback** button found in the documentation page for which you want to provide feedback. This opens a feedback form.

For product feedback, you can use [Google Issue Tracker](https://issuetracker.google.com/issues?q=componentid:1684848%20status:open) to send us feedback on various issues, including bugs and feature requests.

If you're reporting a bug or defect with Managed Service for Apache Kafka, include the following information with your request:

  * What steps will reproduce the problem?
  * What is the expected output? What do you see instead?
  * Any additional information.
