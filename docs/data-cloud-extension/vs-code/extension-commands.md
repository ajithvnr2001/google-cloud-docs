# Google Cloud Data Agent Kit documentation

[Read product documentation](https://docs.cloud.google.com/data-agent-kit/overview)

Google Cloud Data Agent Kit is for data engineers, data scientists, and data app developers. Data Agent Kit lets you work with your Google Cloud resources to manage your data assets, run queries, and deploy data pipelines directly from your preferred development environment. Interfaces include an IDE extension that works with VS Code and VS Code-compatible IDEs, and a plugin for popular coding agents such as Claud Code and Codex CLI.
