This page lists the supported regions for Agent Identity and the Agent Identity auth manager (`agentidentity.googleapis.com` and `agentidentitycredentials.googleapis.com`).

For more information about regions and zones, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions).

## Supported regions

Agent Identity and Agent Identity auth providers are available in the following regions:

### Americas

Region name | Location | Launch stage  
---|---|---  
`us-central1` | Iowa | Generally Available (GA)  
`us-east1` | South Carolina | Generally Available (GA)  
`us-east4` | Northern Virginia | Generally Available (GA)  
`us-west1` | Oregon | Generally Available (GA)  
`us-west8` | Nevada | Preview  
`northamerica-northeast1` | Montréal | Generally Available (GA)  
`northamerica-northeast2` | Toronto | Generally Available (GA)  
`southamerica-east1` | São Paulo | Generally Available (GA)  
  
### Europe and the Middle East

Region name | Location | Launch stage
