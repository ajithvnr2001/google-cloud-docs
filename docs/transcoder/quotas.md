#  Quotas and limits Stay organized with collections  Save and categorize content based on your preferences. 

This page lists the quotas and limits that apply to Transcoder API.

All quotas apply to each Google Cloud project and are shared across all applications and IP addresses using that project.

## API request quotas

The following quotas apply to Transcoder API requests:

Quota | Value  
---|---  
Get requests per minute per region | 1000  
Mutation (Create/Delete) requests per minute per region | 100  
List requests per minute per region | 100  
  
## Interactive mode quotas

The following quotas apply to Transcoder API job counts:

Quota | Value  
---|---  
Concurrent job count per region | 20  
  
## Batch mode quotas

The following quotas apply to Transcoder API job counts:

Quota | Value  
---|---  
Batch concurrent job count per region | 10  
Batch pending job count per region | 10000  
  
## Manage quotas

To manage API-related quotas, do the following:

  1. Go to the [**Quotas**](https://console.cloud.google.com/iam-admin/quotas) page in the Google Cloud console.
  2. In the **Filter** box, select **Service: Transcoder API**.
  3. Select one or more rows.
  4. Click **EDIT QUOTAS**.



See [View and manage quotas](https://docs.cloud.google.com/docs/quotas/view-manage) for more information.

## Quota increases

If you want to increase any of your quotas for Transcoder API, you can use the Google Cloud console to request a quota increase. For details, see [Request a quota adjustment](https://docs.cloud.google.com/docs/quotas/help/request_increase).
