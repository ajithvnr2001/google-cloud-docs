#  Understanding log entries Stay organized with collections  Save and categorize content based on your preferences. 

This document provides reference information for the session logs generated by CCAI Platform. Session logs are either event log entries or activity log entries.

**Note:** Google might update log entries, including event log schemas. Refer back to this document for updates.

## Before you begin

Follow the instructions in [View log entries](https://docs.cloud.google.com/contact-center/ccai-platform/docs/view-log-entries) to make sure you can view log entries.

## Event log entries

Event logs represent user journey events that are logged with `logName` as `"projects/YOUR_PROJECT_ID/logs/contactcenteraiplatform.googleapis.com%2Fevents"`.

## Activity log entries

Activity logs align to the series of tasks that the CCAI Platform is responsible for performing throughout a session. They are logged with `logName` as `"projects/YOUR_PROJECT_ID/logs/contactcenteraiplatform.googleapis.com%2Factivity"`.

### Activity logs list

The resources in the application for the component that generated the activity are labeled in the `textPayload` of the activity logs. These values include the following:

  * `[Chatbot]`
  * `[VA Call / VA Chat]`
  * `[VA Call Latency]`
  * `[Virtual-Agent]`
  * `[VirtualAgent]`
  * `[Call]`
  * `[Chat]`
  * `[CRM-Server]`
  * `[External-Storage]`
  * `GCS upload`



To filter activity logs for a specific component, you can use a query similar to the following in [Logs Explorer](https://docs.cloud.google.com/logging/docs/view/logs-explorer-interface):
    
    
    logName="projects/YOUR_PROJECT_ID/logs/contactcenteraiplatform.googleapis.com%2Factivity"
    textPayload:"[CRM-Server]"
    

Replace the following:

  * `[YOUR_PROJECT_ID`: the ID of your project
  * `[CRM-Server]`: the tag from the list you're querying
