#  Create a dashboard from an existing metrics tile Stay organized with collections  Save and categorize content based on your preferences. 

You can create a dashboard from a metrics tile in an existing dashboard.

## Before you begin

Find a dashboard that contains a metrics tile that you want to base your new dashboard on. This can be one of the [advanced reporting dashboards](https://docs.cloud.google.com/contact-center/ccai-platform/docs/dashboards-overview) that are included with Contact Center AI Platform (CCAI Platform) or it can be a dashboard that you or a colleague created previously.

## Procedure

To create a dashboard from an existing metrics tile, follow these steps:

  1. In the CCAI Platform portal, click **Dashboard > Advanced Reporting**. If you don't see the **Dashboard** menu, expand the window horizontally until the **Dashboard** menu appears. The **Advanced Reporting Landing Page** appears.

  2. Do one of the following:

     * To start from a metrics tile in a CCAI Platform dashboard, click a dashboard with a metrics tile that you want to base your new dashboard on.

     * To start from a metrics tile in a user-created dashboard, do the following:

       1. Click folder **Open Folders**. The **Folders** pane appears. For more information, see [Manage folders](https://docs.cloud.google.com/contact-center/ccai-platform/docs/dashboards-manage-folders).

       2. Navigate to the dashboard with a metrics tile that you want to base your new dashboard on, and then click it. The dashboard appears.

  3. Hold the pointer over the metrics tile that you want to base your new dashboard on. The ![The Explore from here icon.](https://docs.cloud.google.com/static/contact-center/ccai-platform/docs/images/dashboards-explore-actions.png) **Explore from here** icon appears.

  4. Click ![The Explore from here icon.](https://docs.cloud.google.com/static/contact-center/ccai-platform/docs/images/dashboards-explore-actions.png) **Explore from here**. The **Explore** page appears.

  5. Optional: To customize the metrics tile in your new dashboard, make edits in the **Explore** page.

  6. Click ![The Explore actions icon.](https://docs.cloud.google.com/static/contact-center/ccai-platform/docs/images/dashboards-explore-actions.png) **Explore actions** , and then click **Save** > **As a new dashboard**. The **Save as a new dashboard** dialog appears.

  7. In the **Title** field, enter a name for your dashboard. This is also used to name the metrics tile in your dashboard.

  8. For **Folder** , select the folder where you want to save your dashboard.

  9. Optional: Click the **Filters** tab, and then choose the filters that you want to include in your dashboard.

  10. Click **Save**.

  11. Optional: Click **View dashboard**.




Your metrics tile has the same name as your new dashboard. You can [rename the metrics](https://docs.cloud.google.com/contact-center/ccai-platform/docs/dashboards-rename-tile) tile if it needs a more appropriate name.
