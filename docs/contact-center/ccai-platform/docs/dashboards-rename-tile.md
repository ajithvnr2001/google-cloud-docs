#  Rename a metrics tile Stay organized with collections  Save and categorize content based on your preferences. 

You can rename a metrics tile on a dashboard that you or a someone else created.

To rename a metrics tile, follow these steps:

  1. In the CCAI Platform portal, click **Dashboard > Advanced Reporting**. If you don't see the **Dashboard** menu, expand the window horizontally until the **Dashboard** menu appears. The **Advanced Reporting Landing Page** appears.

  2. Click folder **Open Folders**. The **Folders** pane appears. For more information, see [Manage folders](https://docs.cloud.google.com/contact-center/ccai-platform/docs/dashboards-manage-folders).

  3. Navigate to the dashboard with a metrics tile that you want to rename, and then click the dashboard. The dashboard appears.

  4. Click more_vert **Dashboard actions > Edit dashboard**. The dashboard enters edit mode.

  5. Hold the pointer over the metrics tile that you want to edit. The edit **Edit** icon appears.

  6. Click edit **Edit**. The **Edit Tile** page appears.

  7. Edit the tile name, and then click **Save**. The dashboard appears in edit mode.

  8. Click **Save**.
