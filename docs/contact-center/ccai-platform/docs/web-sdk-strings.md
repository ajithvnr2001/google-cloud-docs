#  Web SDK string reference Stay organized with collections  Save and categorize content based on your preferences. 

This page contains the strings used in the web SDK. You can customize these strings by using the `new UJET(option)` method with the translation field. The tables in this reference show the key and the default US English value for each string. For more information, see [Multiple language and visual message customization](https://docs.cloud.google.com/contact-center/ccai-platform/docs/web-sdk#UUID-09b85676-2e59-607c-dfaa-becce3a59ea0).
