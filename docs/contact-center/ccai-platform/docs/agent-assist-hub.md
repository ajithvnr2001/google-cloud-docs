#  Agent Assist hub Stay organized with collections  Save and categorize content based on your preferences. 

The Agent Assist hub is a panel in the agent desktop that combines generative knowledge assist and agent coaching capabilities. The Agent Assist hub includes a **Generative AI Knowledge Assist** module and an **Agent Coaching** module. These capabilities are available based on your conversation profile settings. For more information, see [Set up Agent Assist](https://docs.cloud.google.com/contact-center/ccai-platform/docs/agent-assist#set-up-agent-assist).

Agent Assist hub is only available in the agent desktop. It's not available in the agent adapter. If your contact center uses the agent adapter, configure Agent Assist for **Generative Knowledge Assist**. For more information, see [Configure Agent Assist for calls globally](https://docs.cloud.google.com/contact-center/ccai-platform/docs/agent-assist#aa-turn-on-calls) and [Configure Agent Assist for chats globally](https://docs.cloud.google.com/contact-center/ccai-platform/docs/agent-assist#aa-turn-on-chat).

## Before you begin

Before you use the Agent Assist hub, do the following:

  * By default, this capability is inactive. Contact Google Cloud Support to turn it on for your instance.

  * [Set up Agent Assist](https://docs.cloud.google.com/contact-center/ccai-platform/docs/agent-assist#set-up-agent-assist).




## Configure Agent Assist hub for calls

To configure Agent Assist hub for calls, follow the instructions in [Configure Agent Assist for calls globally](https://docs.cloud.google.com/contact-center/ccai-platform/docs/agent-assist#aa-turn-on-calls). At step 3, select **Agent Assist Hub**.

## Configure Agent Assist hub for chats

To configure Agent Assist hub for chats, follow the instructions in [Configure Agent Assist for chats globally](https://docs.cloud.google.com/contact-center/ccai-platform/docs/agent-assist#aa-turn-on-chat). At step 3, select **Agent Assist Hub**.

## Add an Agent Assist hub panel to the agent desktop

To add an Agent Assist hub panel to the agent desktop, follow the instructions in [Create a desktop layout](https://docs.cloud.google.com/contact-center/ccai-platform/docs/agent-desktop-create-desktop-layouts#create-desktop-layout). At step 11, drag the **Agent Assist Hub** widget into a panel.
