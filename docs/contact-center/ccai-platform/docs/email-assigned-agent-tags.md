#  Assigned agent tags Stay organized with collections  Save and categorize content based on your preferences. 

Assigned agent tags let you see at a glance which agent is assigned to each email in an [email list](https://docs.cloud.google.com/contact-center/ccai-platform/docs/email-adapter#email-lists) and which emails are unassigned. An agent assignment tag is a round tag containing an agent's initials that indicates the agent assigned to an email. Hold the pointer over the tag to see an agent's full name. Unassigned emails and drafts have no agent assignment tag.

## Turn on assigned agent tags

To turn on assigned agent tags, follow these steps:

  1. In the CCAI Platform portal, click **Settings > Email > Email Management**. If you don't see the **Settings** menu, click menu **Menu**.

  2. Select the **Enable Assigned Agent Initials on Email List View** checkbox, and then click **Save**.
