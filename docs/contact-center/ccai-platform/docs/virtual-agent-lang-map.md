#  Virtual agent language mapping Stay organized with collections  Save and categorize content based on your preferences. 

When CCAI Platform calls the Dialogflow API, it provides a language attribute to help Dialogflow determine the appropriate language to use for the agent. CCAI Platform determines the language attribute based on the queue language for the session.

The following table provides the mapping of CCAI Platform language to Dialogflow language.
