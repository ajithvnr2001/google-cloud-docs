#  Live Translation in the Chat Adapter Stay organized with collections  Save and categorize content based on your preferences. 

This page describes how to use live translation in the chat adapter.

## Default experience

Here is the default live translation experience in the chat adapter:

  * When a message from a customer (end user) comes through a queue in a language other than the adapter's default language, the incoming messages are automatically translated into the adapter's default language.

  * Your outbound messages are automatically translated for the end user but they appear in the chat adapter's default language, the way you type them.




## Language controls

To switch back and forth between the original and translated versions of a message in the chat adapter:

  * Click **View original** to see the original, untranslated message. The link changes to **View translation**.

  * Click **View translation** to see the translated message. The link changes to **View original**.




To send an untranslated outbound message, clear the **Translate to (queue language)** checkbox.
