#  Add metrics tiles to a dashboard Stay organized with collections  Save and categorize content based on your preferences. 

This page explains how to add metrics tiles to user-created dashboard.

Consider the number and complexity of tiles that you add to a dashboard. More tiles require more browser resources, which increases dashboard rendering time. If rendering becomes an issue, consider creating multiple dashboards with fewer tiles.

## Add a metrics tile to a dashboard from another dashboard

You can add a metrics tile to a user-created dashboard by starting from tiles in another dashboard. This other dashboard can be a CCAI Platform dashboard or it can be a different user-created dashboard.

To add a metrics tile to a user-created dashboard, follow these steps:

  1. In the CCAI Platform portal, click **Dashboard > Advanced Reporting**. If you don't see the **Dashboard** menu, expand the window horizontally until the **Dashboard** menu appears.

The **Advanced Reporting Landing Page** appears.

  2. Do one of the following:

     * To add a metrics tile from a CCAI Platform dashboard, click the dashboard with a metrics tile that you want to add to your dashboard.

     * To add a metrics tile from a user-created dashboard, do the following:

       1. Click folder **Open Folders**. The **Folders** pane appears. For more information, see [Manage folders](https://docs.cloud.google.com/contact-center/ccai-platform/docs/dashboards-manage-folders).

       2. Navigate to a dashboard with a metrics tile that you want to add to your dashboard, and then click it. The dashboard appears.

  3. Hold the pointer over the metrics tile that you want add to your dashboard. The ![The Explore from here icon.](https://docs.cloud.google.com/static/contact-center/ccai-platform/docs/images/dashboards-explore-actions.png) **Explore from here** icon appears.

  4. Click ![The Explore from here icon.](https://docs.cloud.google.com/static/contact-center/ccai-platform/docs/images/dashboards-explore-actions.png) **Explore from here**. The **Explore** page appears.

  5. Optional: To customize the metrics tile in your new dashboard, make edits in the **Explore** page.

  6. Click ![The Explore actions icon.](https://docs.cloud.google.com/static/contact-center/ccai-platform/docs/images/dashboards-explore-actions.png) **Explore actions** , and then click **Save** > **To an existing dashboard**. The **Add to a Dashboard in this folder** dialog appears.

  7. In the **Title** field, enter a name for your metrics tile.

  8. For **Folder** , select the folder where you want to save your tile.

  9. Click the dashboard that you want to add the tile to, and then click **Save to Dashboard**.

  10. Optional: Click your dashboard to view it.




## Create a new metrics tile in a dashboard

To create a new metrics tile in a user-created dashboard, follow these steps:

  1. In the CCAI Platform portal, click **Dashboard > Advanced Reporting**. If you don't see the **Dashboard** menu, expand the window horizontally until the **Dashboard** menu appears. The **Advanced Reporting Landing Page** appears.

  2. Click folder **Open Folders**. The **Folders** pane appears.

  3. Navigate to the dashboard that you want to create a new metrics tile in, and then click it. The dashboard appears.

  4. Click more_vert **Dashboard actions > Edit dashboard**. The dashboard enters edit mode.

  5. Click **Add > Visualization**. The **Choose an Explore** dialog appears.

  6. Select an Explore from the list. An Explore represents a query that explores a particular subject area. The **Edit Tile** dialog appears.

  7. Click **Metrics**. A list of measures appears.

  8. Click the measure that you want for your metrics tile. The **Data** menu appears along with the measure that you selected.

  9. In the **Visualization** menu, select the type of visualization that you want for your metrics tile, and then click **Run** to see the result. For more information about visualizations, see [Select the best visualization for your data](https://docs.cloud.google.com/looker/docs/visualization-guide#select_the_best_visualization_for_your_data).

  10. Optional: Click **Filters** , and then edit or add filters for the tile.

  11. In the **Untitled** field, enter a name for your metrics tile. For example, you could use the measure name for the name of your tile.

  12. Click **Save**. The dashboard appears in edit mode.

  13. Click **Save**.
