# Find recommendations in Active Assist

## Before you begin

Ensure that you have the [necessary roles and permissions](https://docs.cloud.google.com/recommender/docs/active-assist/find-active-assist#before_you_begin) to view recommendations.

## Find recommendations

You can find your recommendations from the Active Assist

**Note:** Some recommenders don't support using Active Assist to view and manage recommendations and insights. For details about recommenders and supported clients, see [Recommenders](https://docs.cloud.google.com/recommender/docs/recommenders).

Navigate to the Active Assist. To learn more about what's on this page, see [Dashboard overview](https://docs.cloud.google.com/recommender/docs/active-assist/dashboard-overview).

[Go to Active Assist](https://console.cloud.google.com/active-assist)

  * To view all of your recommendations, click **All recommendations** from the left-hand navigation.

  * To view recommendations for a specific value pillar, such as **Cost** or **Security** , click the name of the respective pillar. The list of pillars is displayed in the left-hand navigation, as well as in the **Category** column of the **All recommendations** card.




You should now see a table displaying your recommendations for the chosen pillar.

You can also adjust the recommendations the table displays by applying filters. You can apply multiple filters by selecting existing options or by creating your own using even partial strings.
