# Find Active Assist

This page shows you how to find Active Assist.

**Note:** Some recommenders don't support using Active Assist to view and manage recommendations and insights. For details about recommenders and supported clients, see [Recommenders](https://docs.cloud.google.com/recommender/docs/recommenders).

## Before you begin

Enroll in the [Recommender Viewer role](https://docs.cloud.google.com/iam/docs/roles-permissions/recommender#recommender.viewer) or Identity and Access Management [Basic Roles](https://docs.cloud.google.com/iam/docs/roles-overview#basic) to get access to view all recommendations available to you. Alternatively, you can reference the [recommender list page](https://docs.cloud.google.com/recommender/docs/recommenders) to determine what permissions you need for each recommender.

Note that each recommender has its own specific roles and permissions to control access, which may include some metadata about its resources.

You can only see recommendations at an organization or folder level if you have permissions for that organization or folder, regardless of your permissions for folders or projects within it.

## Navigate to Active Assist

There are a few options to find your recommendations in Google Cloud console.

  * Directly visit Active Assist.

[Go to Recommendations](https://console.cloud.google.com/active-assist)

  * Under the **Cloud overview** section in the left hand navigation in Google Cloud console, go to **Cloud overview** > **Recommendations**.

[Google Cloud console](https://console.cloud.google.com/)
