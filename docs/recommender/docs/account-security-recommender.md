# Account security recommender

The account security recommender prompts Google Cloud project owners to protect their account with their [phone's built-in security key](https://support.google.com/accounts/answer/9289445). If a project owner has an eligible device associated with their account and isn't using a [third party Identity provider for single sign-on](https://support.google.com/a/answer/60224), a notification shows in Google Cloud console's **Notifications** notifications menu. The project owner can then choose to enable their phone as a security key for their account, or dismiss the notification.

Certain roles can [opt out of this recommender](https://cloud.google.com/recommender/docs/opting-out) for the organization.

**Note:** The account security recommender can only be accessed through Google Cloud console. The gcloud CLI is not supported at this time.
