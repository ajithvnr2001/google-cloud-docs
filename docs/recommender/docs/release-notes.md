#  Recommender release notes Stay organized with collections  Save and categorize content based on your preferences. 

This page documents production updates to Recommender. Check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality. 

You can see the latest product updates for all of Google Cloud on the [ Google Cloud](https://docs.cloud.google.com/release-notes) page, browse and filter all release notes in the [Google Cloud console](https://console.cloud.google.com/release-notes), or programmatically access release notes in [BigQuery](https://console.cloud.google.com/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table). 

## March 08, 2024

v1beta1

Feature

[Recommendation Hub](https://console.cloud.google.com/home/recommendations) is a centralized page on Google Cloud that helps you view all of your recommendations in one place. We recently made improvements to the page, including enabling organization and folder-view of recommendations, custom sorting and filtering of recommendations, and more. For more information, see [documentation](https://docs.cloud.google.com/recommender/docs/quickstart-recommendation-hub)

## December 06, 2023

v1

Feature

[Change risk recommendations](https://docs.cloud.google.com/recommender/docs/change-risk-recommendations) are now available in Preview. These recommendations help you reduce the risk of cloud infrastructure misconfigurations.

v1

Feature

[Service limit (quota) recommender](https://docs.cloud.google.com/recommender/docs/service-limit-quota-recommender) is now generally available.

## May 25, 2023

v1

Feature

You can now [configure the observation period for your idle VM Recommender](https://docs.cloud.google.com/compute/docs/instances/configuring-idle-vm-recommendations).

v1

Feature

The [BigQuery partitioning and clustering recommender](https://docs.cloud.google.com/bigquery/docs/view-partition-cluster-recommendations) is now in [Preview](https://cloud.google.com/products#product-launch-stages). The recommender analyzes your BigQuery tables to identify partitioning or clustering opportunities for potential cost savings.

## April 20, 2023

v1

Feature

New [Service limit (quota) recommender](https://docs.cloud.google.com/recommender/docs/service-limit-quota-recommender) is now available in Preview. The recommendations help you identify resources that may be approaching their quota limits.

## April 14, 2023

v1

Feature

Recommendations can now be [exported](https://docs.cloud.google.com/recommender/docs/bq-export/export-recommendations-to-bq) to non-US regions.

## March 23, 2023

v1

Feature

The global [Recommender Viewer role](https://docs.cloud.google.com/iam/docs/roles-permissions/recommender#recommender.viewer) is now available to get view access to all insights and recommendations available.

v1

Feature

[The export to BigQuery feature](https://docs.cloud.google.com/recommender/docs/bq-export/export-recommendations-to-bq) now supports custom pricing and non-project scoped recommendations.

v1

Feature

[The ability to dismiss a recommendation is generally available](https://docs.cloud.google.com/recommender/docs/using-api) via Recommender API

## March 10, 2023

v1

Feature

Cloud Functions [minimum instances recommendations](https://docs.cloud.google.com/functions/docs/configuring/recommender) are now available in [Preview](https://cloud.google.com/products#product-launch-stages).

## April 28, 2022

v1

Feature

**Preview** : The Error Reporting [notification recommender](https://docs.cloud.google.com/recommender/docs/error-reporting/notification-recommender) looks for recent crashes in your Cloud project and provides recommendations if you have not configured [Error Reporting notifications](https://docs.cloud.google.com/error-reporting/docs/notifications).

## March 25, 2021

v1

Announcement

Recommender [pricing](https://cloud.google.com/recommender/pricing) is now generally available and determines how you can process and view recommendations using the API and BigQuery export. The pricing controls how much read and write [quota](https://docs.cloud.google.com/recommender/quotas) is provided to individual resources.

## February 26, 2021

v1beta1

Feature

The [product suggestion recommender](https://docs.cloud.google.com/recommender/docs/product-suggestion-recommender) helps you to optimize your Cloud usage by providing you with product suggestions. This can help you improve performance and security, and manage your resources better.

## December 09, 2020

v1

Announcement

The [committed use discount](https://docs.cloud.google.com/recommender/docs/committed-use-discount-recommender) (CUD) recommender helps you to optimize the resource costs of your Compute Engine virtual machine instances. The CUD recommendations are now generally available.

## November 20, 2020

v1

Announcement

Firewall Insights enable you to better understand and safely optimize your firewall configurations. These insights are now generally available and you can learn more about how to use these insights [here](https://docs.cloud.google.com/network-intelligence-center/docs/firewall-insights/how-to/using-firewall-insights).

## November 08, 2020

v1

Feature

Compute Engine now enables you to [view and apply recommendations](https://docs.cloud.google.com/compute/docs/viewing-and-applying-idle-resources-recommendations) associated with idle resources such as disk images and IP addresses. This helps to minimize the wastage of resources and reduce the Compute bill.

## July 27, 2020

v1

Feature

You can now [opt out of recommendations](https://docs.cloud.google.com/recommender/docs/opting-out) for a specific billing account.

## July 16, 2020

v1

Feature

You can use [insights](https://docs.cloud.google.com/recommender/docs/insights/using-insights) to focus on important patterns in resource usage. Insights are now generally available.

## May 26, 2020

v1

Feature

You can now view, prioritize, and apply recommendations in the Google Cloud Console using Recommendation Hub ([Beta](https://cloud.google.com/products/#product-launch-stages)).

[Get started with Recommendation Hub](https://docs.cloud.google.com/recommender/docs/recommendation-hub/getting-started).

## May 11, 2020

v1

Feature

The [Transparency and Control Center](https://docs.cloud.google.com/recommender/docs/transparency-and-control-center/audit-logging) helps an administrator download processed data to view insights and recommendations.

## March 30, 2020

v1beta1

Feature

Insights is now available in beta. See the [documentation](https://docs.cloud.google.com/recommender/docs/insights/using-insights) for details.

## January 21, 2020

v1

Feature

Recommender API is now generally available.

## September 23, 2019

v1beta1

Feature

Recommender API is now available in Beta.
