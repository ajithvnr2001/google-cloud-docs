#  IAM permissions for Enterprise Knowledge Graph Stay organized with collections  Save and categorize content based on your preferences. 

The following tables list the Identity and Access Management (IAM) permissions that are associated with Enterprise Knowledge Graph. IAM permissions are [grouped into roles](https://docs.cloud.google.com/enterprise-knowledge-graph/docs/access-control/iam-roles), and you assign roles to users and groups. 

## Location permissions

Location permission name | Description  
---|---  
`enterpriseknowledgegraph.locations.get` | Get locations  
`enterpriseknowledgegraph.locations.list` | List locations  
  
## Entity reconciliation jobs

Entity reconciliation permission name | Description  
---|---  
`enterpriseknowledgegraph.entityReconciliationJobs.create` | Create Job  
`enterpriseknowledgegraph.entityReconciliationJobs.delete` | Delete Job  
`enterpriseknowledgegraph.entityReconciliationJobs.cancel` | Cancel Job  
`enterpriseknowledgegraph.entityReconciliationJobs.get` | Get Job  
`enterpriseknowledgegraph.entityReconciliationJobs.list` | List Jobs  
  
## What's next

  * Learn about which IAM permissions are contained in each [Enterprise Knowledge Graph IAM role](https://docs.cloud.google.com/enterprise-knowledge-graph/docs/access-control/iam-roles).
