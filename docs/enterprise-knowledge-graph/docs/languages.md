#  Supported languages Stay organized with collections  Save and categorize content based on your preferences. 

Requests to the Enterprise Knowledge Graph API can be filtered by the language of the content using the optional [`language`](https://docs.cloud.google.com/enterprise-knowledge-graph/docs/reference/rest/v1/projects.locations.cloudKnowledgeGraphEntities/search#body.QUERY_PARAMETERS.languages) parameter.

Language code parameters conform to [`ISO-639-1`](https://en.wikipedia.org/wiki/ISO_639-1) identifiers.

If you do not specify a `language` parameter, only English results will be returned.
