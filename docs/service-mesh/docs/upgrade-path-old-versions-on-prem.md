# Upgrading from earlier versions

Upgrading Cloud Service Mesh across more than one minor version (that is, 1.4.x to 1.8.x) in one step is not officially tested or supported. This page provides links to the "Upgrading on-premises" guide for each Cloud Service Mesh version.

  * [Upgrading from 1.4 to 1.5](https://docs.cloud.google.com/service-mesh/v1.5/docs/gke-on-prem-upgrading)

  * [Upgrading from 1.5 to 1.6](https://docs.cloud.google.com/service-mesh/v1.6/docs/gke-on-prem-upgrading)

  * [Upgrading from 1.6 to 1.7](https://docs.cloud.google.com/service-mesh/v1.7/docs/gke-on-prem-upgrading)

  * [Upgrading from 1.7 to 1.8](https://docs.cloud.google.com/service-mesh/v1.8/docs/gke-on-prem-upgrading)

  * [Upgrading from 1.8 to 1.9](https://docs.cloud.google.com/service-mesh/v1.9/docs/on-premises-upgrade)

  * [Upgrading from 1.9 to 1.10](https://docs.cloud.google.com/service-mesh/v1.10/docs/on-premises-upgrade)

  * [Upgrading from 1.10 to 1.11](https://docs.cloud.google.com/service-mesh/v1.11/docs/unified-install/upgrade)

  * [Upgrading from 1.11 to 1.12](https://docs.cloud.google.com/service-mesh/v1.12/docs/unified-install/upgrade)

  * [Upgrading from 1.12 to 1.13](https://docs.cloud.google.com/service-mesh/v1.13/docs/unified-install/upgrade)

  * [Upgrading from 1.13 to 1.14](https://docs.cloud.google.com/service-mesh/v1.14/docs/unified-install/upgrade)

  * [Upgrading from 1.14 to 1.15](https://docs.cloud.google.com/service-mesh/v1.15/docs/unified-install/upgrade)

  * [Upgrading from 1.15 to 1.16](https://docs.cloud.google.com/service-mesh/v1.16/docs/unified-install/upgrade)

  * [Upgrading from 1.16 to 1.17](https://docs.cloud.google.com/service-mesh/v1.17/docs/unified-install/upgrade)

  * [Upgrading from 1.17 to 1.18](https://docs.cloud.google.com/service-mesh/v1.18/docs/unified-install/upgrade)


**Note:** Cloud Service Mesh 1.10 introduced networking changes that are different than 1.9 and earlier. After you upgrade to Cloud Service Mesh 1.10 or later, review [Am I Impacted?](https://istio.io/latest/blog/2021/upcoming-networking-changes/#am-i-impacted) to verify if you are impacted and for mitigation steps.
