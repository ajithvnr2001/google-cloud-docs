Gets details of a single HttpRoute.

### HTTP request

`GET https://networkservices.googleapis.com/v1beta1/{name=projects/*/locations/*/httpRoutes/*}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`name` |  `string` Required. A name of the HttpRoute to get. Must be in the format `projects/*/locations/*/httpRoutes/*`. Authorization requires the following [IAM](https://cloud.google.com/iam/docs/) permission on the specified resource `name`:

  * `networkservices.httpRoutes.get`

  
  
### Request body

The request body must be empty.

### Response body

If successful, the response body contains an instance of `[HttpRoute](https://docs.cloud.google.com/service-mesh/v1.28/docs/reference/network-services/rest/v1beta1/projects.locations.httpRoutes#HttpRoute)`.

### Authorization scopes

Requires the following OAuth scope:

  * `https://www.googleapis.com/auth/cloud-platform`



For more information, see the [Authentication Overview](https://docs.cloud.google.com/docs/authentication#authorization-gcp).
