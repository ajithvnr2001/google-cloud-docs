_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

This page lists the limits applicable to API hub.

Consider the following product configuration limits as you build, manage, and review your API hub implementation. We've designed API hub for stability and performance when configured within these limits. Customers are responsible for tracking and ensuring they stay within the configuration limits.

API hub resource | Limit  
---|---  
**Maximum size of searchable resources** | 2.5 MB  
**Maximum number of values for enum attributes** | 1000  
**Maximum number of values for an attribute** | 20  
**Maximum size of an API specification file** | 10 MB
