#  Settings overview Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

Through Settings, you can manage and configure the following API hub features:

  * [Attributes](https://docs.cloud.google.com/apigee/docs/apihub/manage-attributes)
  * [Project associations](https://docs.cloud.google.com/apigee/docs/apihub/auto-register-apigee-proxies)
  * [Plugins](https://docs.cloud.google.com/apigee/docs/apihub/plugins)
  * [Curations](https://docs.cloud.google.com/apigee/docs/apihub/curations)
  * [Linting](https://docs.cloud.google.com/apigee/docs/apihub/validate-spec)
  * [Actions](https://docs.cloud.google.com/apigee/docs/apihub/actions)



To view the available settings options, in the Google Cloud console, click **API hub > Settings**.
