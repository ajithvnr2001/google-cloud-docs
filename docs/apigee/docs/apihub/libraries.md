#  API hub client libraries Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

While you can use API hub by making direct REST over HTTP requests, we provide client libraries for several popular languages.

## Supported languages

API hub provides client libraries and guides for the following languages: 

  * [C#](https://docs.cloud.google.com/dotnet/docs/reference/Google.Cloud.ApiHub.V1/latest)
  * [Go](https://pkg.go.dev/cloud.google.com/go/apihub)
  * [Java](https://docs.cloud.google.com/java/docs/reference/google-cloud-apihub/latest/overview)
  * [Node.js](https://googleapis.dev/nodejs/apihub/latest/)
  * [PHP](https://docs.cloud.google.com/php/docs/reference/cloud-apihub/latest)
  * [Python](https://docs.cloud.google.com/python/docs/reference/google-cloud-apihub/latest)
