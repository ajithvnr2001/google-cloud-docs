_This page applies to**Apigee** and **Apigee hybrid**._

Apigee Advanced API Security is an add-on that can be enabled to govern the API security posture for a single Apigee X, hybrid, or Edge Public Cloud organization, or for multiple Apigee organizations, environments, and gateways. Depending on your Apigee organization license type and on where and how you enable the Advanced API Security add-on, the security capabilities offered and the pricing structure may vary. Use the following advisor tool to help you understand your options and pricing implications.
