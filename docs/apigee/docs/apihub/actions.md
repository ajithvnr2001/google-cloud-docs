#  Actions Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

Manage instance-level operations and global service integrations with **Actions**. Settings configured in the **Actions** tab affect the entire API hub instance.

## Required permissions

To view the **Actions** tab and its associated configurations, you must have a role that includes these IAM permissions:

  * `apihub.apiHubInstances.get`
  * `apihub.plugins.get`
  * `apihub.plugininstances.list`



**Note:** These permissions are included in the **Cloud API hub Admin** (`roles/apiHub.admin`) and **Cloud API hub Viewer** (`roles/apiHub.viewer`) predefined roles. 

For more information about roles and permissions, see [Roles and permissions](https://docs.cloud.google.com/iam/docs/roles-overview). For help choosing the most appropriate predefined roles, see [Predefined IAM roles](https://docs.cloud.google.com/apigee/docs/apihub/iam-roles) and [Choose predefined roles](https://docs.cloud.google.com/iam/docs/choose-predefined-roles). 

## Available actions

You can perform the following actions in API hub:

  * **Agent Registry integration:** Controls the automated synchronization of MCP tools and server metadata with Agent Registry. For more information, see [Manage Agent Registry integration](https://docs.cloud.google.com/apigee/docs/apihub/manage-agent-registry-integration).
  * **Deprovisioning API hub instance:** Permanently removes the API hub instance and data. For more information, see [Deprovision Apigee API hub](https://docs.cloud.google.com/apigee/docs/apihub/deprovision).
