#  Manage add-ons Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

Add-ons are optional, standalone features and services that you can use to enrich the way you manage and secure your API data in API hub. The **Add-on management** page lets you enable, disable, and manage the configurations of your add-ons. 

The following table lists the available add-ons and their pricing: 

Add-on | Pricing | Description  
---|---|---  
[Specification linter](https://docs.cloud.google.com/apigee/docs/apihub/validate-spec) | Free | Specification linter helps you to validate your OpenAPI specifications to ensure that your APIs meet your team style guidelines. For more information, see [Validate API specs using the specification linter](https://docs.cloud.google.com/apigee/docs/apihub/validate-spec).  
[Specification boost](https://docs.cloud.google.com/apigee/docs/apihub/spec-boost) | Free | Specification boost is an AI-powered add-on that lets you automatically enhance the readability and discoverability of your API specifications in API hub. For more information, see [Specification boost add-on](https://docs.cloud.google.com/apigee/docs/apihub/spec-boost).  
[Semantic search](https://docs.cloud.google.com/apigee/docs/apihub/search-apis) | Free | Semantic search helps you to find the details of an API resource quickly using natural language. For more information, see [Search APIs using semantic search](https://docs.cloud.google.com/apigee/docs/apihub/search-apis).
