This section describes common tasks that you perform during operation and administration of your Apigee hybrid cluster. These tasks include:

Section | Description  
---|---  
data_usage | **[Data collection](https://docs.cloud.google.com/apigee/docs/hybrid/v1.16/data-collection-overview)** | Describes the primary types of data: metrics, logs, analytics, and deployment status. This section also describes how the data are collected and how you can access the collected data.  
apps | **[Runtime services](https://docs.cloud.google.com/apigee/docs/hybrid/v1.16/service-config)** | Explains how to manage the hybrid runtime plane components running in your cluster.   
settings | **[Cluster management](https://docs.cloud.google.com/apigee/docs/hybrid/v1.16/cluster-overview)** | Explains how to configure multi-region clusters, scale services, configure environments, and perform other administration tasks.  
** quick_reference ** | **[Configuration property reference](https://docs.cloud.google.com/apigee/docs/hybrid/v1.16/config-prop-ref)** | Provides a reference of the overrides properties you can use to manage the hybrid runtime plane components.   
** service_toolbox ** | **[Helm charts reference](https://docs.cloud.google.com/apigee/docs/hybrid/v1.16/helm-reference)** | Provides an overview and reference of Helm charts, the tool you will use to manage the hybrid runtime plane components.
