#  Configurable API proxies (preview) deprecation Stay organized with collections  Save and categorize content based on your preferences. 

The public preview of Configurable API proxies was used to create and deploy a lightweight proxy using a declarative configuration model. The Configurable API proxy preview was deprecated on August 17, 2023.

We encourage Configurable API proxy (preview) users to back up any important data, including proxy configurations, before November 10, 2023. As part of the deprecation process, creation of new configurable proxies will be disabled on or around October 30, 2023.

## Shutdown schedule

The following table lists the shutdown schedule for the public preview of configurable proxies: 

Date | Event  
---|---  
August 17, 2023 | Configurable API proxies (preview) deprecated  
October 30, 2023 | Creation of new configurable proxies disabled  
November 10, 2023 | Configurable API proxies (preview) shut down
