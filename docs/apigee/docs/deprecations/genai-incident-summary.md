#  GenAI Incident Summary (Preview) deprecation Stay organized with collections  Save and categorize content based on your preferences. 

The GenAI Incident Summary (generative AI Insights) feature within Apigee Advanced API Security is deprecated and shut down as of July 10, 2026. 

This feature, currently in Public Preview, used Google Cloud generative AI large language models (LLMs) to provide automated summaries and mitigation guidance for security incidents identified by the Abuse Detection clustering tool. 

## Shutdown schedule

The following table lists the shutdown schedule for the GenAI Incident Summary feature: 

Date | Event  
---|---  
July 10, 2026 |  Deprecation and final shutdown of the GenAI Incident Summary feature.
