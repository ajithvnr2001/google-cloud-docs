#  Setting up navigation Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Set up navigation to link the pages that you have developed to your portal, as described in the following sections.

## Explore the Menus page

Set up and publish the navigation menus in your portal using the navigation menu editor on the Menus page.

To access the Menus page:

  1. In the Apigee in Cloud console, go to the **Distribution > Portals** page.  
  
[Go to Portals](https://console.cloud.google.com/apigee/portals)
  2. Click your portal.
  3. Click **Menus**.

![Click for larger image](https://docs.cloud.google.com/static/apigee/docs/api-platform/publish/images/menus-console.png)

![](https://docs.cloud.google.com/static/apigee/docs/api-platform/publish/images/menus-console.png)




The navigation menu editor lets you:

  * Select the menu you want to edit (header or footer) and view the menu item details
  * Add items to a navigation menu
  * Create submenus
  * Edit or delete a menu item
  * Rearrange menu items
  * Publish a menu



## About the default navigation menus

Two navigation menus are provided by default: **Header** and **Footer**. The default navigation menus appear in and link to the set of starter pages provided, as shown in the following figure.

![Default menus](https://docs.cloud.google.com/static/apigee/docs/api-platform/images/menus-about.png)

## Adding items to a navigation menu

**Note:** You can add a **maximum of 200** menu items.

To add an item to a navigation menu:

  1. Access the Menus page.
  2. Select the menu that you want to edit in the drop-down list (Header or Footer).
  3. Click **\+ Menu Item**.
  4. In the navigation menu dialog, enter the following details:

Field | Description | Required?  
---|---|---  
Name | Name of the menu item as it will appear in the portal. This value can be different from the actual page name. | Yes  
Page Path or URL | Enter an absolute URL to an external page, an absolute or relative URL to a page in your portal, or click the text field and select a page in your portal from the drop-down list. | Yes  
  5. Click **Create**.

  6. Click **Publish** to publish your changes to the live portal.




## Rearranging menu items

To rearrange an item in a navigation menu:

  1. Access the Menus page.
  2. Select the menu that you want to edit in the drop-down list.
  3. Move the menu item. Click the arrow_upward **Up arrow** on a row to move the item up. Or click the arrow_downward **Down arrow** on a row to move the item down.
  4. Click **Publish** to publish your changes to the live portal.



## Creating a submenu

A submenu displays as a drop-down menu when you overlay the parent item.

![Submenu](https://docs.cloud.google.com/static/apigee/docs/api-platform/images/submenu-sample-v2.png)

To create a submenu:

  1. Access the Menus page.
  2. Select the menu that you want to edit in the drop-down list.
  3. Add a menu item that will serve as the parent menu.
  4. Add additional menu items that will serve as the submenus.
  5. Rearrange the submenu items so that they are under the parent menu in the desired order that you want them to appear in the menu.
  6. Change a menu item to a submenu. Click more_vert **More** , **Convert to submenu item**.

To move a submenu item back to the top-level menu hierarchy:

Click more_vert **More** , **Convert to top-level item**.

The following figure shows how a submenu item appears in the menu list:

![Submenu example](https://docs.cloud.google.com/static/apigee/docs/api-platform/images/indented-menu-v2.png)

  7. Click **Publish** to publish your changes to the live portal.




## Editing a navigation menu item

To edit an item in the navigation menu:

  1. Access the Menus page.
  2. Select the menu that you want to edit in the drop-down list.
  3. Open the editor. For the item you want to edit, click more_vert **More** , edit **Edit**.
  4. Edit the menu item details.
  5. Click **Save**.
  6. Click **Publish** to publish your changes to the live portal.



## Publishing a navigation menu

To publish a navigation menu:

  1. Access the Menus page.
  2. Select the menu that you want to publish from the drop-down list.
  3. Click **Publish** to publish the navigation menu.



## Deleting an item from a navigation menu

To delete an item from a navigation menu:

  1. Access the Menus page.
  2. Select the menu that you want to edit from the drop-down list.
  3. Delete the menu item. For the item you want to delete, click more_vert **More** , delete **Delete**.

  4. Click **Delete** to confirm the delete operation.

  5. Click **Publish** to publish your changes to the live portal.




## Customizing the menu items and navigation bar

Customize the font size and style of the menu items and other aspects of the navigation bar appearance, as described in [Customizing the navigation toolbar](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/api-portal-themes#navbar).
