#  Quick tips for customizing the sample portal Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

The following figure highlights some quick tips for customizing the sample portal. (See also [About the sample portal](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/build-integrated-portal#sample-portal).)

![Quick tips](https://docs.cloud.google.com/static/apigee/docs/api-platform/images/portal-tips-v2.png)

As highlighted in the previous figure, the following table summarizes the quick customizations that you can make to the sample portal.

# | Customization | Description | More Info  
---|---|---|---  
1 | Logo | Customize the logos located on the desktop navigation bar, mobile navigation bar, Sign In page, or favicon with your company's logo. | [Customizing the logos](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/api-portal-themes#logo)  
2 | Header menus | Update the items in the header menu using the menu editor. | [Setting up navigation](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/portal-menus)  
3 | Background image | Customize the background image on the home page. Customize the SCSS styles for the background image and upload your own version of the image in file manager using the same relative file size. You can modify the name of the file used in the theme. | [Customizing the background image](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/api-portal-themes#background-image)  
4 | Style sheet | Update the style sheet to use your own comapny styles in the theme editor. | [Customizing your theme](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/api-portal-themes)  
5 | Page content | Edit the content of the portal pages in the page editor. | [Developing portal content using the page editor](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/page-editor)  
6 | Footer menus | Update the items in the footer menu using the menu editor. | [Setting up navigation](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/portal-menus)
