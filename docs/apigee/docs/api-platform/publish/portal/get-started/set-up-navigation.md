#  Step 5: Set up navigation Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Next, you'll update the top (header) and bottom (footer) navigation bars to include the **Get Started** page.

To set up navigation:

  1. Click **Menus** on the portals details page.   
First you'll update the top (header) navigation bar to add **Get Started** as a menu item. Notice that **Header** is selected by default in the menu drop-down.
  2. Click **\+ Menu Items**.
  3. In the navigation menu dialog, enter the following details: Field | Value  
---|---  
Name | Get Started  
Page Path or URL |  Click in the text field and then click **Get Started (/get-started)** in the list. (You may need to scroll.)   
  4. Click **Create**.
  5. Rearrange the **Get Started** menu item.

     1. Click the arrow_upward **Up arrow** on the **Get started** row to move it up.
     2. Click it repeatedly until **Get started** is after **Home** and before **APIs**.
  6. Click **Footer** in the menu drop-down to update the bottom (footer) navigation bar.

  7. Repeat steps 2 through 5 to add **Get Started** as a menu item in the bottom (footer) navigation bar.

  8. Click **Publish menu** to publish your changes to the live portal.

  9. Click **View Live Portal** to open the live portal in a new browser tab (or refresh the tab in which it is already open).

  10. Click **Get Started** in the top navigation bar to display the Get Started page.




Next, you'll publish an API to the portal.
