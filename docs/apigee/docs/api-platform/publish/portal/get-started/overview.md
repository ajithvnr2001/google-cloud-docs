_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

The [sample portal](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/build-integrated-portal#sample-portal), included when you create a new portal, consists of a set of starter pages with demo content to help inspire your own portal development. 

Step through this tutorial to discover how simple it is to create and customize a portal and showcase your APIs. As you follow the instructions, you'll change the look and feel, images, and text in the sample portal pages, and publish an API. Simply open the live portal in a browser to view your changes!

The sample portal theme uses [ material design theming ](https://material.angular.io/guide/theming) and [ Sassy Cascading Style Sheets (SCSS) ](https://sass-lang.com). For more information, see [About the sample portal](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/build-integrated-portal#sample-portal).

Step through the tips provided in the following sections to quickly create and customize a portal.

  1. [Create a portal](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/get-started/create-portal)
  2. [Customize the color palette](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/get-started/customize-color-palette)
  3. [Customize the logo](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/get-started/customize-logo)
  4. [Edit page content](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/get-started/edit-page)
  5. [Set up navigation](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/get-started/set-up-navigation)
  6. [Publish an API](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/get-started/publish-api)
