#  Step 2: Customize the color palette Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

In this step, you will customize the color palette. The style changes you make in this step will affect the top and bottom navigation bars, buttons, and terminal (code) font in the sample portal.

To customize the color palette:

  1. Go to the **Themes** page for the portal you just created.

     1. On the **Portals** page, click the name of the portal you just created. For example **My First Portal**.
     2. Click **Themes**.
     3. Click edit **Edit**.
  2. In the **Basic styles** pane:

     * Set the **Primary color** to **Red** to adjust the color of toolbars, card headers, and buttons.
     * Set the **Accent color** to **Blue** to adjust the color of `<pre>` and `<code>` text.
  3. Click **Save**.

  4. Click **Preview** to preview the portal changes in a new browser tab.

  5. Click **Publish** to publish the change to your portal. Confirm the operation when prompted.

  6. Click **View Portal** to open the live portal in a new browser tab.




Next, you'll **customize the logo** in the portal.
