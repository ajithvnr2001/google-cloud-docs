#  Support resources for the Apigee Developer Portal Kickstart solution Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Google does not offer support for the Apigee Developer Portal Kickstart solution.

Apigee customers can open a [Google Cloud Customer Care](https://cloud.google.com/support-hub/) ticket for any issues that arise during the initial deployment of the Apigee Developer Portal Kickstart solution. See the [ Support process for Apigee Drupal 10 modules](https://docs.cloud.google.com/apigee/docs/api-platform/publish/drupal/support-for-apigee-d8-modules) for any post-provisioning issues.

Customers seeking technical guidance for using the Apigee Developer Portal Kickstart solution can leverage the following sources: 

  * For questions about the Apigee open source Drupal modules and the Kickstart Distribution: 
    * Read about the [ Support process for Apigee Drupal 10 modules](https://docs.cloud.google.com/apigee/docs/api-platform/publish/drupal/support-for-apigee-d8-modules).
    * Search the [ Apigee Drupal Kickstart documentation](https://www.drupal.org/docs/8/modules/apigee-developer-portal-kickstart).
    * Open an issue in the GitHub issue queue for [Apigee Developer Portal Kickstart](https://github.com/apigee/apigee-devportal-kickstart-drupal/issues).
    * Reach out to the [Apigee Community](https://discuss.google.dev/) with questions.
  * For questions about Drupal core, connect with the Drupal [community forums](https://www.drupal.org/forum/).



Critical security patches are announced in the [Apigee security bulletins](https://docs.cloud.google.com/apigee/docs/security-bulletins/security-bulletins). Customers are encouraged to [subscribe](https://cloud.google.com/feeds/apigee-security-bulletins.xml) to the security bulletins feed.
