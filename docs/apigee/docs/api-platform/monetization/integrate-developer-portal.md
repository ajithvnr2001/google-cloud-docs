#  Integrating monetization with your developer portal Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

**Note:** Monetization is supported on Drupal-based developer portals only in this release.

Configure monetization in your Drupal developer portal to provide developers self-service access to rate plan subscription, automatic payment processing and billing, reports, product catalogs, and other monetization-specific settings. 

The Apigee Monetization module enables you to integrate a Drupal 8/9 developer portal with Apigee monetization. For more information, see [Apigee Monetization in the Drupal documentation](https://www.drupal.org/docs/8/modules/apigee-monetization).
