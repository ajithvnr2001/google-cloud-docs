#  Step 1: Create an Apigee workspace Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Create an Apigee workspace for developing your APIs.

  1. To access Apigee in Cloud Code, launch VS Code and click the ![Cloud Code icon in VS Code](https://docs.cloud.google.com/static/code/docs/vscode/images/cloudcode-icon.png) Cloud Code icon in the Activity bar, then select the **Apigee** section.

![Apigee in Cloud Code showing the icon in the activity bar](https://docs.cloud.google.com/static/apigee/docs/api-platform/local-development/vscode/images/vscode-access-tutorial.png)

  2. Click **Local Development** and then the **Create Apigee workspace** icon in that folder (![Create Apigee workspace icon](https://docs.cloud.google.com/static/apigee/docs/api-platform/images/create-workspace-icon.png)). Alternatively, you can select **View > Command Palette** to open the Command palette and select **Cloud Code: Open Apigee workspace**.

  3. Select the workspace type that matches your preferred development style. You can choose between a [single-repository workspace](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/manage-apigee-workspace#understanding_the_structure_of_an_apigee_single-repository_workspace) or a [multi-repository workspace](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/manage-apigee-workspace#understanding_the_structure_of_an_apigee_multi-repository_workspace).

  4. Enter **myapigeeworkspace** at the prompt and press **Enter**.

  5. Navigate to the directory where you want to save the Apigee workspace. If you are using source control management, select a location in your source control repository.

  6. Click **Select workspace folder**.




The Apigee workspace is created, stored in the specified local directory, and shown in the **Apigee** section:

![Apigee section showing Apigee workspace folders, including apiproxies, sharedflows, environments, and tests.](https://docs.cloud.google.com/static/apigee/docs/api-platform/local-development/vscode/images/vscode-workspace.png)

As shown, a set of folders is created for you to develop API proxies and shared flows, configure deployment environments, and build test resources.
