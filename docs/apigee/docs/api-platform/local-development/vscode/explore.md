_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Access and explore Cloud Code as described in the following sections.

**Note:** Before you can access Apigee in Cloud Code, you need to perform the steps described in [ Set up Apigee API Management in Cloud Code](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/setup).

## Access Apigee in Cloud Code for VS Code

To access Apigee in Cloud Code, launch VS Code, click the ![Cloud Code icon in VS Code](https://docs.cloud.google.com/static/code/docs/vscode/images/cloudcode-icon.png) Cloud Code icon in the Activity Bar, and select the Apigee section.

Alternatively, to open Apigee in Cloud Code using the command palette, select **View > Command Palette** and select **View: Show Cloud Code - Apigee**.

Apigee in Cloud Code lets you manage the Apigee workspace, develop and deploy your APIs, build and export test resources, and manage Apigee emulators. In Apigee in Cloud Code, you can also view and edit APIs in your [Apigee API hub](https://docs.cloud.google.com/apigee/docs/apihub/what-is-api-hub) if it is [provisioned for your Apigee project](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/setup).

Learn about the tasks that you can perform using each component in the following sections.

## Actions in the Apigee section

Use the Apigee section of Cloud Code to develop and deploy APIs and API proxies in your local environment.

![Apigee section of Cloud Code](https://docs.cloud.google.com/static/apigee/docs/api-platform/local-development/vscode/images/cloud-code-apigee-section.png)

The **Apigee** section lets you perform the following tasks:

  * [Manage the Apigee workspace](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/manage-apigee-workspace)  


  * [Design and manage APIs](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-design-edit-apis)  


  * Develop [API proxies](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-apiproxies) and [shared flows](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-sharedflows)

  * [Attach policies](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/manage-policies) to add features

  * [Manage the resources](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-sharedflows) required by policies

  * [Configure and deploy](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/deploy-environment) environments

  * [Build and export test resources](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/build-test-resources) for testing your APIs

  * [Install and manage emulators](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/manage-apigee-emulator) for deploying your APIs




## View and manage your API hub APIs

If you've provisioned API hub on your Apigee project you can also see, edit, and create new OpenAPI specs in the Apigee section of Cloud Code.

The API hub section lets you perform the following tasks:

  * View the list of API specs that are already part of your [Apigee API hub](https://docs.cloud.google.com/apigee/docs/apihub/what-is-api-hub).

  * [Edit an existing API spec](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-design-edit-apis#design-apis) by clicking the YAML filename in the folder for the API folder and version.

  * [Create a new OpenAPI spec](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-design-edit-apis#design-apis).

  * [Develop and edit APIs](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-design-edit-apis).

  * [Test your APIs using a mock server](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-design-edit-apis#mock-server)

  * Save edited or new APIs to API hub by [publishing to API hub](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-design-edit-apis#publish-apis-to-api-hub).




## Next steps

To get started using Apigee in VS Code:

  * Step through a guided tutorial to [build and deploy your first API proxy](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/get-started)

  * [Create or open your Apigee workspace](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/manage-apigee-workspace) and start developing your [API proxies](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-apiproxies) and [shared flows](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-sharedflows)

  * [Learn more about Cloud Code](https://docs.cloud.google.com/code/docs)

  * Learn about how you can use Gemini Code Assist in Apigee. See [Designing and editing APIs](https://docs.cloud.google.com/apigee/docs/api-platform/local-development/vscode/develop-design-edit-apis).
