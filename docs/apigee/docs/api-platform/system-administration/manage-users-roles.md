#  Manage users, roles, and permissions using the API Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

**More Information**  
For more information, see:

  * [Users and roles](https://docs.cloud.google.com/apigee/docs/api-platform/system-administration/users-roles-overview)



Manage users, roles, and permissions using the Apigee APIs described in the following table:

API method | Description  
---|---  
[Organizations list API](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations/list) | List all Apigee organizations, and the related projects for which a user has permissions.  
[Environments Get IAM Policy API](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments/getIamPolicy) | Gets the IAM policy on an environment.  
[Environments Set IAM Policy API](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments/setIamPolicy) | Sets the IAM policy on an environment. If the policy already exists, it will be replaced.  
[Environments Test IAM Permissions API](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments/testIamPermissions) | Tests the permissions of a user on an environment. Returns a subset of permissions that the user has on the environment.  
  
See also the following topics in the Google Cloud Identity and Access Management (IAM) documentation:

  * [Granting, changing, and revoking access to resources](https://docs.cloud.google.com/iam/docs/granting-changing-revoking-access)
  * [Method: roles.queryGrantableRoles](https://docs.cloud.google.com/iam/reference/rest/v1/roles/queryGrantableRoles)
