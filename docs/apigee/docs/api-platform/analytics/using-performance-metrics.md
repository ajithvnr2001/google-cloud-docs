_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

The Apigee Analytics API lets you monitor and manage API performance and health. The Analytics API is a valuable tool for troubleshooting problems. For example, if your API goes down, analytics charts can help illustrate whether the failure was sudden or involved a slow lead-in time. If your API is slowing down, simulated transactions can help you determine how and where the bottlenecks are. In addition, analytics can help you diagnose usage problems, such as a sudden spike in traffic, or the opposite, a sudden decrease in traffic. 

For more information on using analytics to troubleshoot problems, see:

  * [Apigee Analytics overview](https://docs.cloud.google.com/apigee/docs/api-platform/analytics/analytics-services-overview)
  * [Creating and managing custom reports](https://docs.cloud.google.com/apigee/docs/api-platform/analytics/create-custom-reports)
  * [Using the analytics dashboards](https://docs.cloud.google.com/apigee/docs/api-platform/analytics/using-analytics-dashboards)
