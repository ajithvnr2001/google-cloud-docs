#  Pay-as-you-go entitlements Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** , but not to **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

The following table outlines entitlements for the Apigee offering of Pay-as-you-go pricing:

### **Core Entitlements**  
  
---  
Annual Call Volume | Not applicable  
Network Data Entitlement | Not included Network data transfer charges from Apigee instance (up to 1 TB per month) are waived as a promotional offering until April 30, 2024.  
[Analytics Reports](https://docs.cloud.google.com/apigee/docs/api-platform/analytics/analytics-services-overview) | 14 months (not available during Preview)  
[Developer Portals](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/build-integrated-portal) | Included Limit of 3 custom domains  
[Orgs](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/organization-structure) | 1 per Google Cloud project  
[Environments](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/environments-overview) | Max of 85 environments per org  
[Shared flows](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/shared-flows) | Max of 75 shared flows, subject to restrictions per environment type  
[Hybrid](https://docs.cloud.google.com/apigee/docs/hybrid/latest/what-is-hybrid) Entitlements | Not included  
SLA | Pay-as-you-go aligns with [Apigee Enterprise SLA](https://docs.cloud.google.com/apigee/sla)  
  
### **Public Cloud Additional Features**  
  
[Apigee API hub](https://docs.cloud.google.com/apigee/docs/apihub/what-is-api-hub)  
| Included  
[API Monitoring](https://docs.cloud.google.com/apigee/docs/api-monitoring) | Included  
Add-ons | [Apigee API Analytics add-on](https://docs.cloud.google.com/apigee/docs/api-platform/reference/manage-analytics-add-on) available for purchase [Advanced API Security add-on](https://docs.cloud.google.com/apigee/docs/api-platform/reference/manage-security-add-on) available for purchase  
  
All offerings are subject to [Apigee product limits](https://docs.cloud.google.com/apigee/docs/api-platform/reference/limits).
