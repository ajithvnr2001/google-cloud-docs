## Apigee Subscription 2024 entitlements

The following table compares Subscription entitlements for the Apigee offerings for Subscription 2024 plans. For older plans, see the [Subscription 2021](https://docs.cloud.google.com/apigee/docs/api-platform/reference/subscription-entitlements#subscription-2021-entitlements) entitlements. For information on evaluation plans, see [ Compare evaluation and paid organizations in Apigee](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/compare-paid-eval). 

| Standard | Enterprise | Enterprise Plus  
---|---|---|---  
  
### **Core Entitlements**  
  
API proxy calls (annual)(1) | Up to 1.25 billion Standard or 250 million Extensible API proxy calls | Up to 7.5 billon Standard or 1.5 billion Extensible API proxy calls | Up to 75 billion Standard or 15 billion Extensible API proxy calls  
[Active environments](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/environments-working-with#about-environments) (2) | 3 | 6 | 12  
[Proxy deployment units (PDUs)](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/environments-overview#proxy-deployment-units) | 250 | 500 | 1,500  
[Analytics](https://docs.cloud.google.com/apigee/docs/api-platform/analytics/analytics-services-overview) | Up to 250 million annual Analytics calls (any API proxy call type), 14 months data retention | Up to 1.5 billion annual Analytics calls (any API proxy call type), 14 months data retention | Up to 15 billion annual Analytics calls (any API proxy call type), 14 months data retention  
Runtime SLA | >= 99% | >= 99.99% for environments provisioned in 2 or more Regions with a dual-region, multi-regional, or global [Cloud KMS](https://cloud.google.com/security-key-management) encryption key, or >= 99.9% for all other environments  
  
### **[Apigee](https://docs.cloud.google.com/apigee/docs/getstarted) additional features**  
  
[Apigee API hub](https://docs.cloud.google.com/apigee/docs/apihub/what-is-api-hub)  
| Included  
[API Observations (Shadow API discovery)](https://docs.cloud.google.com/apigee/docs/api-observation)  
| Available with the Advanced API Security add-on  
[API Monitoring Analytics Portal](https://docs.cloud.google.com/apigee/docs/api-monitoring) | Included  
[Developer Portals](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/build-integrated-portal)  
| Included  
  
### **[Hybrid](https://docs.cloud.google.com/apigee/docs/hybrid/latest/what-is-hybrid) entitlements (3)(4)**  
  
Environments Entitled | Not Included | Up to 85 environments per hybrid org (5)  
[Anthos](https://docs.cloud.google.com/anthos) (6) | Not Included | 300 vCPUs of Anthos | 800 vCPUs of Anthos  
  
### **Add-ons available for purchase**  
  
[Advanced API Security](https://docs.cloud.google.com/apigee/docs/api-security) | Available for purchase  
[Monetization](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/overview) | Available for purchase  
Proxy Deployment Unit Pack (7) | Each pack adds 50 PDUs (counted per region)  
Environment Pack | Each pack adds 3 environments (counted per region)  
  
All offerings and add-ons are subject to [Apigee product limits](https://docs.cloud.google.com/apigee/docs/api-platform/reference/limits).

(1) Additional call volume available for purchase. Standard API proxy calls are metered 1/5 of an Extensible API proxy call. See [API proxy types](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/understanding-apis-and-api-proxies#proxy-types) for information on Standard and Extensible proxy types. A customer can use API calls in Apigee, Apigee hybrid, and Apigee Adapter for Envoy use cases.  
(2) An Apigee Environment can be provisioned in one or more Google Cloud regions by [attaching them](https://docs.cloud.google.com/apigee/docs/api-platform/system-administration/multi-region#env) to one or more [Apigee instances](https://docs.cloud.google.com/apigee/docs/api-platform/system-administration/multi-region). Each region association is counted as an "active" environment. Customers have the flexibility to leverage their Env entitlements to attach the environment to a single instance or to multiple instances.  
(3) hybrid orgs do not differentiate Standard and Extensible proxies at this time. Proxy deployment units are tracked for hybrid orgs.  
(4) **Enhanced per environment proxy limit** feature for hybrid implementations is exclusively available as part of the 2024 subscription plan. Contact [Apigee Sales](https://pages.apigee.com/contact-sales-reg.html). See also [Enhanced limits](https://docs.cloud.google.com/apigee/docs/hybrid/latest/enhanced-proxy-limits).  
(5) No restriction on hybrid org creation.  
(6) Restricted for Anthos only to run/operate Apigee hybrid components listed here. Additional Anthos entitlements require an Anthos subscription.  
(7) Additional Proxy Deployment Unit packs available for purchase. PDU overages are calculated based on the 95th percentile of the total PDU usage in a minute. You can use Metrics Explorer to view usage of the Apigee resources that are key attributes in determining cost in your Subscription pricing plan. Please see [View Pay-as-you-go resource usage](https://docs.cloud.google.com/apigee/docs/api-platform/reference/pay-as-you-go-updated-usage#metricsexplorer) for details on viewing PDU consumption in your organization across your Google Cloud projects.  


## Apigee Subscription 2021 entitlements

The following table compares Subscription entitlements for the Apigee offerings for Subscription 2021 subscription plans. For newer plans, see [Subscription 2024](https://docs.cloud.google.com/apigee/docs/api-platform/reference/subscription-entitlements#subscription-2024-entitlements) entitlements.

| Standard | Enterprise | Enterprise Plus  
---|---|---|---  
  
### **Core Entitlements**  
  
Annual Call Volume (1)  
additional call volume available for purchase | 180 million calls | 1.2 billion calls | 12 billion calls  
Network Data Entitlement (2)  
additional network data available for purchase | 1 TiB | 10 TiB | 150 TiB  
[Analytics Reports](https://docs.cloud.google.com/apigee/docs/api-platform/analytics/analytics-services-overview) | 30 days | 3 months | 14 months  
[Developer Portals](https://docs.cloud.google.com/apigee/docs/api-platform/publish/portal/build-integrated-portal)  
entitlement limit of 3 custom domains | Included  
  
### **[Apigee](https://docs.cloud.google.com/apigee/docs/getstarted) Entitlements (non-hybrid)**  
  
[Orgs (9)/Environments](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/organization-structure)  
additional Org/Environment packs available for purchase | 1 org & 5 environments | 2 orgs & 10 environments | 6 orgs & 30 environments  
API proxy deployments  
additional Org/Environment packs available for purchase(10) | 250 | 500 | 1,500  
Combined API proxy and shared flow deployments  
additional Org/Environment packs available for purchase(11) | 300 | 600 | 1,800  
Runtime SLA | [See SLA](https://cloud.google.com/apigee/sla)  
  
### **[Apigee](https://docs.cloud.google.com/apigee/docs/getstarted) Additional Features**  
  
[Apigee API hub](https://docs.cloud.google.com/apigee/docs/apihub/what-is-api-hub)  
| Included  
[API Monitoring](https://docs.cloud.google.com/apigee/docs/api-monitoring) | Included  
  
### **[Hybrid](https://docs.cloud.google.com/apigee/docs/hybrid/latest/what-is-hybrid) Entitlements**  
  
Orgs/Environments Entitled | Not Included | 25 Orgs (up to 85 environments per org)  
[Anthos](https://docs.cloud.google.com/anthos) (3) | Not Included | 300 vCPUs of Anthos | 800 vCPUs of Anthos  
  
### **Add-ons available for purchase(4)**  
  
[Advanced API Security](https://docs.cloud.google.com/apigee/docs/api-security) | Available for purchase  
[Monetization](https://docs.cloud.google.com/apigee/docs/api-platform/monetization/overview) | Available for purchase | 12B calls included  
Org Pack | Each pack adds 1 org and 5 environments  
Environment Pack | Each pack adds 5 environments  
Analytics Data Pack | Increases Analytic Reports to 14 months | Increases Analytic Reports to 14 months | Not applicable (14 months included)  
[Application Integration  
](https://docs.cloud.google.com/apigee/docs/api-platform/integration/what-is-apigee-integration)(not supported for Apigee hybrid) | 24 million integration calls(5), 10 concurrent integrations(6) across Apigee Orgs (includes 2 orgs), 20 Class G connections(7) & 10 Class 1 connections included  
Application Integration Packs (requires Application Integration)  | Call Pack: 50M additional integration calls  
Org Pack: Enables Application Integration for 1 additional org  
Concurrency Pack: 10 additional concurrent integrations across orgs   
[Apigee Connection Packs](https://docs.cloud.google.com/apigee/docs/api-platform/connectors/about-connectors) (requires Application Integration)  | Connection Unit Pack : 50 Connection Units across all regions(8)  
  
All offerings and add-ons are subject to [Apigee product limits](https://docs.cloud.google.com/apigee/docs/api-platform/reference/limits).

(1) Additional call volume available for purchase. A customer can use API calls in Apigee, Apigee hybrid, and Apigee Adapter for Envoy use cases.   
(2) For information about pricing for Google Cloud networking products, see [All networking pricing](https://cloud.google.com/vpc/network-pricing).  
(3) Restricted for Anthos only to run/operate Apigee hybrid components listed here. Additional Anthos entitlements require an Anthos subscription.  
(4) Org Pack, Environment Pack, and Network Data Packs are only available for Apigee.  
(5) A successful integration call is the completion of an integration workflow without errors due to the incorrect functioning of the Application Integration platform. Call failures not attributable to the platform, such as failures to connect to targets (including other Cloud services) due to customer configuration errors or target server downtimes, do not count against the SLA. Integration UI and Management service requests are not included in this SLA.  
(6) Concurrent integrations are the number of integrations that are executing concurrently (at the same time). Total concurrency packs not to exceed a total of 10,000 concurrent integrations. Please contact sales for higher limits.  
(7) Class G covers 1st party Google Services (for example, BigQuery), and does not cover hosted/managed services (eg: CloudSQL MySQL). Class 1 covers some basic connectors (for example, REST and SOAP).  
(8) Technical limit of 250 Connections per region. Additional connections can be entitled upon request. Connection Units are an abstraction of Connection purchases, which can be used flexibly to consume various combinations of Connections, Connector Types, Classes, or All Classes. Purchased units may be allocated towards the connection options you choose. For example, with one Connection Unit Pack (50 units), you can use 15 units for three MySQL Connections (Class 2 Connectors are five units per connection) for the dev, test and prod instances of your database. In addition, you can use 20 units for the All Class G Connectors to configure as many connections for Google services as you need (up to any technical limits).  
(9) An Apigee Organization can be configured to span across one or more Google Cloud [regions](https://cloud.google.com/about/locations). Customers have the flexibility to leverage their Org entitlements to provision in a single region or expand the same Org to [multiple regions](https://cloud.google.com/apigee/docs/api-platform/system-administration/multi-region). When they are configured in a single region, it is counted as a single "Org unit". To expand their Org to more than one region, customers need entitlements to Org units. For example, with the Enterprise Plus tier, customers can provision a total of 6 Org units. It could be used to provision a single Org expanded across 6 regions or create 6 Apigee Orgs (or any combination in between). Additional Org units can be purchased via Org Packs.  
(10) Your account's total allowed proxy deployments is capped at 50 times the number of environments you've purchased or are entitled to. If you need to deploy more proxies than this limit allows, you'll need to purchase additional environments. Each purchased environment supports up to 50 API proxy deployments. This policy applies only to Subscription 2021 contracts. For pricing and purchase inquiries, contact [Apigee Sales](https://pages.apigee.com/contact-sales-reg.html). You can monitor your proxy and shared flow usage in the Metrics Explorer View resource usage in [ Metrics Explorer](https://docs.cloud.google.com/apigee/docs/api-platform/reference/pay-as-you-go-updated-usage#metricsexplorer).   
(11) Your account's total allowed combined proxy and shared flow deployments is capped at 60 times the number of environments you've purchased or are entitled to. If you need to deploy more proxies and shared flows than this limit allows, you'll need to purchase additional environments. Each purchased environment supports up to 60 combined API proxy and shared flow deployments. This policy applies only to Subscription 2021 contracts. For pricing and purchase inquiries, contact [Apigee Sales](https://pages.apigee.com/contact-sales-reg.html). You can monitor your proxy and shared flow usage in the Metrics Explorer View resource usage in [ Metrics Explorer](https://docs.cloud.google.com/apigee/docs/api-platform/reference/pay-as-you-go-updated-usage#metricsexplorer).
