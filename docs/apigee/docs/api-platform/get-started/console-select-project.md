This topic covers the prerequisite steps for provisioning an Apigee Pay-as-you-go organization using the Google Cloud console.

## Before you begin

  1. Make sure you have completed the steps described in [Prerequisites](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/prerequisites).
  2. In the Google Cloud console, select or create a Google Cloud project. **Note** : If you don't plan to keep the resources that you create in this procedure, create a project instead of selecting an existing project. After you finish these steps, you can delete the project, removing all resources associated with the project.

[Go to project selector](https://cloud.google.com/console/welcome)

  3. Ensure that billing is enabled for your Cloud project. Learn how to [check if billing is enabled on a project.](https://docs.cloud.google.com/billing/docs/how-to/verify-billing-enabled)
  4. Go to the **Welcome to Apigee API management** landing page. 

[Go to Welcome to Apigee API Management](https://cloud.google.com/console/apigee/welcome)

**Important usage note:** When using the Apigee UI with advanced data residency, you must use the jurisdictional Google Cloud console. For more information, see [Use the jurisdictional console](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/drz-concepts#jurisdictional-console). You can use the jurisdictional console with data residency (at rest only) if your control data location is set to one of the [supported locations](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/drz-provision#locations). 



## Provisioning options for Apigee Pay-as-you-go organizations

After you complete your pre-requisite steps and reach the **Welcome to Apigee API Management** page, you can choose how to provision your Apigee Pay-as-you-go organization.

### One click provisioning

To get started quickly with smart default configurations, click **Set up with defaults**. When you select this one-click provisioning option, Apigee enables the required Google APIs, creates the Google-managed resources required for your Apigee organization, and creates a default networking configuration. To learn more, see [Provision Apigee with one click](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/one-click).

### Customize your Apigee configuration

To customize your Apigee organization with the networking, access, routing, and encryption configuration options you select, click **Customize your setup**. For more information on the customized provisioning process, see the detailed information for each step: 

  * [Step 1: Enable required APIs](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/console-enable-apis).
  * [Step 2: Set up networking](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/console-configure-networking).
  * [Step 3: Configure hosting and encryption](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/console-configure-hosting).
  * [Step 4: Customize access routing](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/console-configure-access).
