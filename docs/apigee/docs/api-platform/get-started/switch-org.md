#  Switching between your organizations Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

If you are a member of multiple organizations, you can switch between them.

To switch between organizations using the Apigee UI:

  1. Sign in to the [Apigee UI](https://console.cloud.google.com/apigee).
  2. Open the drop-down menu in the upper-left corner of the UI. The menu shows your current organization and Google Cloud project name. Only the organizations to which you have access appear in the menu. 
  3. Select the organization to which you want to switch in the list.
