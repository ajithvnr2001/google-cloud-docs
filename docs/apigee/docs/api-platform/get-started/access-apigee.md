#  Accessing Apigee Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

To access Apigee, use one of the following methods.

Method | Description  
---|---  
[Apigee UI](https://docs.cloud.google.com/apigee/docs/api-platform/fundamentals/ui-overview) | Visually develop and deploy your API proxies, trace their execution, and manage other aspects of your organization and environments.  
[Apigee API](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/api-get-started) | Programmatically develop and manage APIs using a set of RESTful operations.  
[gcloud CLI](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/gcloud-get-started) | Programmatically develop and manage APIs using the `gcloud alpha apigee` CLI.
