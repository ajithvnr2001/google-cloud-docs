_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Access to high quality tools, such as enterprise APIs, is essential for agents to be effective. In addition to traditional API management capabilities, Apigee provides AI gateway related features to govern and optimize your AI traffic while transforming existing services into discoverable tools for your agents.

Apigee can secure, manage, and scale your APIs for agentic systems:

  * **Optimize and govern traffic:** Enforce AI gateway controls to secure traffic and tools against vulnerabilities, while enforcing compliance policies. Ensure LLM traffic is optimized to run efficiently and is cost-effective.
  * **Translate APIs into Tools:** Transform existing APIs into agent-optimized tools without writing new code so that agents can discover and interact securely with your enterprise APIs.
  * **Enable integrations:** Ensure your APIs and tools are discoverable through other agentic platforms.
