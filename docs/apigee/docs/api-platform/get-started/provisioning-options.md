#  Provisioning options Stay organized with collections  Save and categorize content based on your preferences. 

Once you are familiar with the [ differences between eval and paid organizations](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/compare-paid-eval), you can choose the most appropriate method for you for provisioning an org:

Method | Description | Next Step  
---|---|---  
Google Cloud console | 

  * Easiest
  * Less prone to error
  * Some details are hidden or obfuscated by the wizard or console

| 

  * [ Provisioning an eval org](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/eval-orgs) (with the Google Cloud console)
  * [ Provisioning a paid Subscription org](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/wizard-select-project) (with the Google Cloud console) 
  * [ Provisioning a paid Pay-as-you-go org](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/console-select-project) (with the Google Cloud console)

  
Command line instructions | 

  * High level of control
  * No hidden tasks -- you do them all

| 

  * [Provision a paid org with VPC peering](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/install-cli) (Subscription or Pay-as-you-go)
  * [ Provision a paid org without VPC peering](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/install-cli-non-peered) (Subscription or Pay-as-you-go)
  * [Provision an eval org with VPC peering](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/install-cli-eval)
  * [Provision an eval org without VPC peering](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/install-cli-non-peered-eval)

  
Apigee Trial Provisioning Script | 

  * One step: define the values; the script does the rest
  * Does not support Windows

| 

  * [apigee-x-trial-provision](https://github.com/apigee/devrel/tree/main/tools/apigee-x-trial-provision) (hosted on GitHub)

  
Apigee Infrastructure as Code (IaC) Resources |  Terraform modules and examples for management of Apigee resources, including organizations and add-ons. See [Terraform overview](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/terraform-overview).  | 

  * [Google Cloud Platform Cloud Foundation Fabric](https://github.com/GoogleCloudPlatform/cloud-foundation-fabric/tree/master/modules/apigee) (hosted on GitHub)
  * [Official HashiCorp Google Provider Documentation](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/apigee_organization)
