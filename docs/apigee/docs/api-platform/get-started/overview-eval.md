_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

The topics in this section explain how to provision a [ trial (evaluation)](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/provisioning-intro#provisioning-options) Apigee instance.

You can evaluate Apigee at no cost for 60 days with a trial (evaluation) Apigee organization. Evaluation organizations are an excellent way to test the functionality and feature offerings of Apigee, subject to the following limitations: 

  * Free trial (evaluation) organizations are limited to a 60-day lifespan, after which the organization is deleted.
  * Evaluation organizations are subject to Google's [Pre-GA Offerings terms](https://cloud.google.com/terms/service-terms) and should not be used for production workloads or to store sensitive data.
  * Apigee's evaluation organizations are not regularly updated with the latest Apigee features and security patches.
  * Evaluation organizations can't be converted to paid organizations. Any resources created in the evaluation organization must be exported in order to be used in a paid organization.



You can find steps for provisioning eval organizations using a UI or the command line, as noted in the table below.

Organization type | Provisioning method | Next Step  
---|---|---  
Eval | Apigee provisioning wizard | [Provisioning an eval org](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/eval-orgs)  
Eval | Command line interface | See one of the following: 

  * [ Provision an eval org with VPC peering](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/install-cli-eval)
  * [ Provision an eval org without VPC peering](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/install-cli-non-peered-eval) (Beta science)
