_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

![](https://docs.cloud.google.com/static/apigee/docs/api-platform/images/ng-saas/chevrons-1-setup.png)

The topics in this section explain how to provision a [paid (non-evaluation)](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/provisioning-intro#provisioning-options) Apigee instance.

You can find steps for provisioning Subscription and Pay-as-you-go organizations using a UI or the command line, as noted in the table below.

Organization type | Provisioning method | Next Step  
---|---|---  
Subscription | Google Cloud console | [Select a project in the Cloud console](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/wizard-select-project) (Subscription)  
Pay-as-you-go | Google Cloud console | [Select a project in the Cloud console](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/console-select-project) (Pay-as-you-go)   
Subscription or Pay-as-you-go | Command line interface | [Provision a paid org from the command line](https://docs.cloud.google.com/apigee/docs/api-platform/get-started/install-cli) (Subscription and Pay-as-you-go)
