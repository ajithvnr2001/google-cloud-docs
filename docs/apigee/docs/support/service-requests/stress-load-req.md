#  Stress/load/penetration test requests Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/troubleshoot/service-requests/stress-load-req) documentation._

It's a best practice to conduct periodic stress/load testing against your API endpoints to ensure the end-to-end solution is capable of handling your expected traffic volume based on your performance specifications. Apigee leverages autoscaling to properly handle incremental organic traffic increases; however, there are use cases that may require capacity or autoscaling tuning to meet your traffic demands. 

If you want to perform stress/load/penetration testing, file a support ticket with [Apigee Support](https://cloud.google.com/apigee/support/) and provide the necessary details. You must perform the tests yourself, but [Apigee Support](https://cloud.google.com/apigee/support/) requires prior notification about the tests. To address issues observed during the testing, users must create a new support ticket instead of using the same support ticket that was used to notify about the planned tests. 

**Note:** Stress/load/penetration test requests apply only to Apigee users. Users of Apigee hybrid can perform the tests themselves without notifying Support, as they have full access to their respective environments. Service request description | Can I do this myself? | How to perform this operation?  
---|---|---  
Apigee penetration test by users | No | Read through [ Customer security testing requests](https://docs.cloud.google.com/apigee/docs/api-platform/test/customer-security-testing-requests) for details and file a support ticket with [Apigee Support](https://cloud.google.com/apigee/support/) and provide the details requested in Customer security testing requests.  
Apigee stress and load test by users | No | Read through [ Performance testing](https://docs.cloud.google.com/apigee/docs/api-platform/test/performance-testing) details and file a support ticket with [Apigee Support](https://cloud.google.com/apigee/support/) and provide the details requested in Performance testing.
