#  Introduction to service requests Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/troubleshoot/service-requests/service-requests) documentation._

Service requests are a type of support requested by Apigee users for assistance required from Apigee Support on non-incident related tasks. In Apigee, the non-incident related tasks include creating or deleting organizations and environments, managing the capacity of the infrastructure, managing portal users, configuring resources, etc. 

In Apigee, many of these non-incident related tasks are self-serviceable. Apigee users should be able to perform many of the tasks if they have the appropriate permissions. However, assistance may be required from Google Cloud support to perform certain tasks, which are not yet self-serviceable. 

In Apigee hybrid, all tasks are self-serviceable, except for the initial entitlement request. 

This document describes which service request tasks are self-serviceable in Apigee and hybrid, and how you can perform them, and which service request tasks require you to create a new support case with Google Cloud support. 

Service requests are classified into the following categories based on the type of request: 

[ Portal user management requests Add users to or remove users from Support Portal. ](https://docs.cloud.google.com/apigee/docs/support/service-requests/portal-user-management-req)

[ Entitlement requests Get the entitlement to create paid org. ](https://docs.cloud.google.com/apigee/docs/support/service-requests/entitlement-req)

[ Provisioning requests Create and delete organizations, environments, and environment groups. Expand/decommission regions. ](https://docs.cloud.google.com/apigee/docs/support/service-requests/provisioning-req)

[ Stress/load/penetration test requests Stress/load/penetration test requests. ](https://docs.cloud.google.com/apigee/docs/support/service-requests/stress-load-req)

[ Infrastructure capacity management requests Manage capacity requirements. ](https://docs.cloud.google.com/apigee/docs/support/service-requests/capacity-management-req)
