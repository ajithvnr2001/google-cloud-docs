#  Entitlement requests Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

Apigee and hybrid users need to have the relevant entitlements to be able to create a paid organization. The following table provides information on how to get the required entitlements: 

**Note:** This applies to both Apigee and Apigee hybrid users. Service request description | Can I do this myself? | How to perform this operation?  
---|---|---  
Entitlement (license) to create paid Apigee or hybrid organization | No | Contact your **Sales representative** with the following information to get the entitlement: 

  * Google Cloud project ID 
  * Contract/subscription end date (required for Anthos) 
  * Google Cloud billing account number (required for Anthos)
