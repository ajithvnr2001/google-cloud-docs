#  Getting started with Google Cloud Support Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/troubleshoot/getting-started-with-support) documentation._

If you are an existing Apigee customer with a paid Apigee [support plan](https://cloud.google.com/support/docs), you can request help from Google Cloud Support. 

**Note:** This topic applies to Apigee **Subscription** customers with a paid Apigee [support plan](https://cloud.google.com/apigee/pricing). 

New Google Cloud Apigee customers and customers with an Apigee **Pay-as-you-go** pricing plan can access support by signing up for a Google Cloud support plan. More information and detailed descriptions of available support plans are available from [Cloud Customer Care](https://docs.cloud.google.com/support). Once enrolled, customers can use the console to submit support cases to [Google Cloud Support](https://cloud.google.com/support-hub). 

If you have a free trial Apigee **eval** account, you can post questions and find answers in the [ Apigee community](https://discuss.google.dev/c/google-cloud/cloud-apigee/104), where Apigee engineers are able to respond. 

The following documents describe how to access support services: 

  * [Getting support with Cloud Customer Care](https://docs.cloud.google.com/support/docs): Describes the support options, how to sign up for support, and how to contact support. 
  * [Access control with IAM](https://docs.cloud.google.com/support/docs/access-control): Describes how to control who (identity) has what access (roles) to which resource. 
  * [Customer Care procedures & support activities](https://docs.cloud.google.com/support/docs/customer-care-procedures): Describes how to complete support procedures and activities. 
  * [Managing support cases](https://docs.cloud.google.com/support/docs/manage-cases): Describes how to manage support cases using the Google Cloud console. 



To find the level of support you currently have for Apigee: 

  1. Sign in to the Google Cloud console Support page.

[Go to Google Cloud Support](https://console.cloud.google.com/support/)

  2. Your support service is shown near the top of the **Support** page.
