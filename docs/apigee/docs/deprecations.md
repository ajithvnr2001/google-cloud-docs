#  Feature deprecations Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Google Cloud's [terms of service](https://cloud.google.com/terms/) define the deprecation policy that applies to Apigee. The [deprecation policy](https://cloud.google.com/terms/deprecation) only applies to the features or services listed therein.

After an Apigee feature has been officially deprecated, the feature continues to be available for at least the period of time defined in the [terms of service](https://cloud.google.com/terms/). After this period of time, the feature or service is scheduled for shutdown.

The following table lists _current_ Apigee feature deprecations and the related shutdown schedules. This table is organized by shutdown date, with the earliest date at the top.

Feature | Shutdown announced | Shutdown date | Details  
---|---|---|---  
Apigee Classic UI | May 29, 2025 | August 29, 2025 | See [Apigee Classic UI shutdown](https://docs.cloud.google.com/apigee/docs/deprecations/apigee-classic-ui)  
  
The following table lists Apigee features that were deprecated and have been shut down. This table is organized by shutdown date, with the latest date at the top. 

Feature | Deprecated | Shutdown date | Details  
---|---|---|---  
GenAI Incident Summary (Preview) | July 10, 2026 | See [GenAI Incident Summary deprecation](https://docs.cloud.google.com/apigee/docs/deprecations/genai-incident-summary)  
Gemini Code Assist `@Apigee` tool | October 9, 2025 | October 14, 2025 | See [Gemini Code Assist @Apigee tool deprecation](https://docs.cloud.google.com/apigee/docs/deprecations/apigee-tool)  
`apigeectl` command line interface | April 17, 2024 | April 17, 2025 | See [`apigeectl` deprecation](https://docs.cloud.google.com/apigee/docs/deprecations/apigeectl)  
`ProxyV2` and `TargetV2` metrics | April 17, 2024 | April 17, 2025 | See [`ProxyV2` and `TargetV2` metrics deprecation](https://docs.cloud.google.com/apigee/docs/deprecations/proxyv2-targetv2-metrics)  
Configurable API proxies (Preview) | August 17, 2023 | November 10, 2023 | See [Configurable API proxies (preview) deprecation](https://docs.cloud.google.com/apigee/docs/deprecations/configurable-proxies)
