---  
  
### `[deploy](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments.apis.revisions.deployments/deploy)`

|  Deploys a revision of an existing API proxy to an environment.  
  
### `[generateDeployChangeReport](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments.apis.revisions.deployments/generateDeployChangeReport)`

|  Generates a report for a dry run analysis of a DeployApiProxy request without committing the deployment.  
  
### `[generateUndeployChangeReport](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments.apis.revisions.deployments/generateUndeployChangeReport)`

|  Generates a report for a dry run analysis of an UndeployApiProxy request without committing the undeploy.  
  
### `[get](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments.apis.revisions.deployments/get)`

|  Gets the deployment of an API proxy revision and actual state reported by runtime pods.  
  
### `[undeploy](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.environments.apis.revisions.deployments/undeploy)`

|  Undeploys an API proxy revision from an environment.
