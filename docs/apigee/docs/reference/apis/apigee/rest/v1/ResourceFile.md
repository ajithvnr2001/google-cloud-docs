#  ResourceFile Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Metadata about a resource file.

JSON representation  
---  
      
    
    {
      "name": string,
      "type": string
    }  
  
Fields  
---  
`name` |  `string` ID of the resource file.  
`type` |  `string` Resource file type. Valid types include `java`, `js`, `jsc`, `properties`, `py`, `wsdl`, `xsd`, or `xsl`. For more information, see [Resource types](https://docs.cloud.google.com/apigee/docs/api-platform/develop/resource-files#resourcetypes).
