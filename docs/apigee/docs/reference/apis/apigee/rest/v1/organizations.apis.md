## Resource: ApiProxy

Metadata describing the API proxy

JSON representation  
---  
      
    
    {
      "metaData": {
        object ([EntityMetadata](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/EntityMetadata))
      },
      "name": string,
      "revision": [
        string
      ],
      "latestRevisionId": string,
      "labels": {
        string: string,
        ...
      },
      "readOnly": boolean,
      "apiProxyType": enum ([ApiProxyType](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/ApiProxyType)),
      "space": string
    }  
  
Fields  
---  
`metaData` |  `object (`[EntityMetadata](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/EntityMetadata)`)` Output only. Metadata describing the API proxy.  
`name` |  `string` Output only. Name of the API proxy.  
`revision[]` |  `string` Output only. List of revisions defined for the API proxy.  
`latestRevisionId` |  `string` Output only. The id of the most recently created revision for this api proxy.  
`labels` |  `map (key: string, value: string)` User labels applied to this API Proxy.An object containing a list of `"key": value` pairs. Example: `{ "name": "wrench", "mass": "1.3kg", "count": "3" }`.  
`readOnly` |  `boolean` Output only. Whether this proxy is read-only. A read-only proxy cannot have new revisions created through calls to apis.create. A proxy is read-only if it was generated by an archive.  
`apiProxyType` |  `enum (`[ApiProxyType](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/ApiProxyType)`)` Output only. The type of the API proxy.  
`space` |  `string` Optional. The id of the space this proxy is associated with. Any IAM policies applied to the space will control access to this proxy.To learn how Spaces can be used to manage resources, read the [Apigee Spaces Overview](https://cloud.google.com/apigee/docs/api-platform/system-administration/spaces/apigee-spaces-overview).  
  
## Methods  
  
---  
  
### `[create](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.apis/create)`

|  Creates an API proxy.  
  
### `[delete](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.apis/delete)`

|  Deletes an API proxy and all associated endpoints, policies, resources, and revisions.  
  
### `[get](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.apis/get)`

|  Gets an API proxy including a list of existing revisions.  
  
### `[list](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.apis/list)`

|  Lists the names of all API proxies in an organization.  
  
### `[move](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.apis/move)`

|  Moves an API proxy to a different space.  
  
### `[patch](https://docs.cloud.google.com/apigee/docs/reference/apis/apigee/rest/v1/organizations.apis/patch)`

|  Updates an existing API proxy.
