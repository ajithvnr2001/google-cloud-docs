#  Get Apigee Edge release notifications Stay organized with collections  Save and categorize content based on your preferences. 

_This page applies to**Apigee** and **Apigee hybrid**._

_View[ Apigee Edge](https://docs.apigee.com/api-platform/get-started/what-apigee-edge) documentation._ ![](https://fonts.gstatic.com/s/i/googlematerialicons/help/v13/gm_grey-24dp/1x/gm_help_gm_grey_24dp.png)

Subscribe to a release notes feed to be notified when Apigee Edge releases are published. Each release notes page provides an Atom feed that you can read in any feed reader.

Release notes | Feed URL  
---|---  
[Apigee Edge for Public Cloud](https://docs.cloud.google.com/apigee/docs/edge-public-cloud/release-notes) | `https://docs.cloud.google.com/feeds/apigee-edge-public-cloud-release-notes.xml`  
[Apigee Edge for Private Cloud](https://docs.cloud.google.com/apigee/docs/edge-private-cloud/release-notes) | `https://docs.cloud.google.com/feeds/apigee-edge-private-cloud-release-notes.xml`  
  
To subscribe, copy the feed URL into your feed reader. You can also click the **Subscribe** link at the top of either release notes page.

For release notes covering every Apigee product, including Apigee and Apigee hybrid, see [Apigee all release notes](https://docs.cloud.google.com/apigee/docs/release-notes). Release notes published before September 2026 remain available in the [Apigee Edge release notes archive](https://docs.apigee.com/release/notes/apigee-release-notes).
