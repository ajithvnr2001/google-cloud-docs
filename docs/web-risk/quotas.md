# Quotas and limits

This document contains current content limits and rate quotas for Web Risk. This page will be updated to reflect any changes to these restrictions and usage limits.

## Rate quotas

The current API usage quotas for Web Risk are as follows (and are subject to change):

Quota | Value  
---|---  
ComputeThreatListDiff requests per minute | 600  
SearchUris requests per minute | 6000  
SearchHashes requests per minute | 6000  
EvaluateUri requests per minute | 600  
EvaluateDigest requests per minute | 600  
SubmitUri requests per day | 1000  
SubmitUri requests per minute | 100  
  
These limits apply to each Google Cloud console project and are shared across all applications and IP addresses using that project.
