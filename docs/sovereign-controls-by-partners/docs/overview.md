#  Overview of Sovereign Controls by Partners Stay organized with collections  Save and categorize content based on your preferences. 

Sovereign Controls by Partners provides sovereignty controls for Google Cloud workloads, operated by partners. Sovereign Controls by Partners helps enforce data residency and provides security configurations that encompass critical aspects of cloud infrastructure, such as encryption and key management.

Sovereign Controls by Partners data boundaries are generally available from the following partners:

  * [France Data Boundary by S3NS](https://docs.cloud.google.com/sovereign-controls-by-partners/docs/data-boundaries/france-data-boundary-s3ns)
  * [Germany Data Boundary by T-Systems](https://docs.cloud.google.com/sovereign-controls-by-partners/docs/data-boundaries/germany-data-boundary-tsi)
  * [Italy Data Boundary by Polo Strategico Nazionale (PSN)](https://docs.cloud.google.com/sovereign-controls-by-partners/docs/data-boundaries/italy-data-boundary-psn)
  * [Kingdom of Saudi Arabia Data Boundary Advanced by CNTXT](https://docs.cloud.google.com/sovereign-controls-by-partners/docs/data-boundaries/ksa-data-boundary-cntxt-advanced)
  * [Kingdom of Saudi Arabia Data Boundary Foundation by CNTXT](https://docs.cloud.google.com/sovereign-controls-by-partners/docs/data-boundaries/ksa-data-boundary-cntxt-foundation)
