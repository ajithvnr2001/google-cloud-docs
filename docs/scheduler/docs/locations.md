Cloud Scheduler lets you run scheduled jobs in various regions to support your workload requirements. You can select locations that colocate your jobs with target compute resources to optimize network performance and maintain data residency standards. For more information about regions, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions).
