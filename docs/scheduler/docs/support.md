Cloud Scheduler provides multiple support channels to help you troubleshoot issues, request features, and submit feedback. You can participate in community forums, track bug reports, or receive dedicated technical assistance through Google Cloud Support packages.

## Email discussion

For community insights, you can join the [email discussion group](https://groups.google.com/forum/#!forum/cloudscheduler).

## Slack discussion

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud Scheduler and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA).

## Issue tracker

Follow bugs and request features with the [issue tracker](https://docs.cloud.google.com/support/docs/issue-trackers).

## Stack Overflow

Google engineers monitor and answer Stack Overflow questions tagged `google-cloud-scheduler`. Use this tag when asking questions.

  * [Ask a question](https://stackoverflow.com/questions/ask/advice?tags=google-cloud-scheduler)
  * [See a list of all questions](https://stackoverflow.com/questions/tagged/google-cloud-scheduler)



## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Submit product or documentation feedback

You can submit product or documentation feedback for Cloud Scheduler by clicking the **Send feedback** widget at the top or bottom of each documentation page. After you click this feedback widget, click either the documentation or the product feedback icon, depending on whether your feedback is documentation or product related.

Your comments will be reviewed by the Cloud Scheduler team.
