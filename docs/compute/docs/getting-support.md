## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

Use the following resources to get support from the Compute Engine community. Review our [FAQ](https://docs.cloud.google.com/compute/docs/faq) before posting a new question.

### Ask a question on Stack Overflow

  * Ask questions about application programming and development on Compute Engine on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-compute-engine). For example, if you are using a Windows VM instance, the [google-compute-engine+windows](http://stackoverflow.com/search?q=google-compute-engine+windows) query returns questions tagged with both **Google Compute Engine** and **Windows**.
  * Ask questions about troubleshooting Compute Engine resources on [Server Fault](http://serverfault.com/questions/tagged/google-compute-engine).



### Discuss Compute Engine

Join the [gce-discussion](https://groups.google.com/forum/#!forum/gce-discussion) Google group to discuss Compute Engine with Google engineers and other users. Join the [gce-announce](https://groups.google.com/forum/#!forum/gce-announce) Google group to get Compute Engine announcements, and the [gce-operations](https://groups.google.com/forum/#!forum/gce-operations) Google group to get updates on Compute Engine operations.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Compute Engine and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Compute Engine, join the [`#compute-engine`](https://googlecloud-community.slack.com/messages/C0EM1FJKB/) channel. 

## File bugs or feature requests

### Where to file a report

Type of request | Where to file a report  
---|---  
Billing issues |  [ Billing support](https://support.google.com/code/bin/request.py?contact_type=cloud_platform_billing)  
Bugs, defects, and feature requests |  [Issues tracker](https://issuetracker.google.com/issues/new?component=187134&template=0)  
Documentation feedback (incorrect documentation, general feedback, suggestions) |  Documentation feedback form  
Production issues (including performance issues) |  [Issues tracker](https://issuetracker.google.com/issues/new?component=187134&template=0)  
Paid support |  If you are a [paid support](https://cloud.google.com/support/) customer, [ contact Google directly](http://www.google.com/support/enterprise/go/support_info#cloud).   
SLA violation |  [ Billing support](http://support.google.com/code/bin/request.py?hl=en&contact_type=cloud_platform_billing&ctx=go)  
Report abuse |  [ Abuse form](http://support.google.com/code/bin/request.py?contact_type=virtual_machines_abuse)  
  
### Bugs and defects

_Example: My instance is unable to attach additional disks_

If your issue is not answered by the [FAQ](https://docs.cloud.google.com/compute/docs/faq) or remains unresolved, post your question to the [Issues tracker](https://issuetracker.google.com/issues/new?component=187134&template=0) with the following information:

  * What steps will reproduce the problem?
  * What is the expected output? What do you see instead?
  * What version of the product are you using? On what operating system?
  * Please provide any additional information.



### File a feature request

_Example: Compute Engine should add feature X_

Your feature request might already have been filed on the [Issues tracker](https://issuetracker.google.com/issues/new?component=187134&template=0). If so, upvote the feature to indicate that you would like to see it added.

If not, gather the following information and post the feature request to the [Issues tracker](https://issuetracker.google.com/issues/new?component=187134&template=0):

  * What is the desired behavior of the feature? (Be specific!)
  * If relevant, why are current approaches or workarounds insufficient?
  * If relevant, what new use cases will this feature enable?



### Documentation feedback

_Example: Documentation for X is out of date_

If you run into issues while using the documentation, have general feedback, or want to make a suggestion, use the documentation feedback mechanism. From any page in the Compute Engine documentation, click the "Send feedback" link near the top right of the page. This will open a feedback form. Provide the following information (if applicable):

  * What URL are you reporting?
  * What was inaccurate?
  * General comments or suggestions



Your comments will be reviewed by the Compute Engine team.

### Production issues

_Example: My instance is running very slow_

If you have a paid support contract, [contact Google directly](http://www.google.com/support/enterprise/go/support_info#cloud).

If you experienced an [SLA](https://cloud.google.com/compute/sla) violation, contact [Billing support](http://support.google.com/code/bin/request.py?hl=en&contact_type=cloud_platform_billing&ctx=go).

You can also report [virtual machine abuse](http://support.google.com/code/bin/request.py?contact_type=virtual_machines_abuse).

You can file a [production issue report](mailto:gc-team@google.com) for your application. Google reads these reports but cannot reply individually. Operational support for individual applications is not provided via the issue tracker.
