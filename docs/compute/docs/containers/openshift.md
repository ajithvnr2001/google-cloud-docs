#  About OpenShift on Google Cloud Stay organized with collections  Save and categorize content based on your preferences. 

In partnership with Red Hat, Google Cloud provides solutions to help you run [Red Hat OpenShift](https://www.redhat.com/en/technologies/cloud-computing/openshift) clusters reliably, securely, and cost-effectively on Compute Engine instances.

You can use Google Cloud resources to run both self-managed and managed OpenShift clusters. With self-managed OpenShift clusters, you can also use Cluster Services for OpenShift, a service jointly engineered and supported by Google Cloud and Red Hat that provides built-in integrations with Google services.

For a more detailed conceptual overview, including the benefits of running OpenShift clusters on Google Cloud, see the following documentation:

  * [Overview of OpenShift on Google Cloud](https://docs.cloud.google.com/openshift-cluster/openshift-overview)
  * [Overview of Cluster Services for OpenShift](https://docs.cloud.google.com/openshift-cluster/overview)



To get started with running OpenShift clusters on Google Cloud, see the following documentation:

  * [Plan your OpenShift cluster installation](https://docs.cloud.google.com/openshift-cluster/plan-deployment)
  * [Create an OpenShift cluster](https://docs.cloud.google.com/openshift-cluster/create-clusters)
