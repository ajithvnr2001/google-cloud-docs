## Methods  
  
---  
  
### `[aggregatedList](https://docs.cloud.google.com/compute/docs/reference/rest/2026-09-01/globalVmExtensionPolicies/aggregatedList)`

|  Retrieves the list of all VM Extension Policy resources available to the specified project.  
  
### `[delete](https://docs.cloud.google.com/compute/docs/reference/rest/2026-09-01/globalVmExtensionPolicies/delete)`

|  Purge scoped resources (zonal policies) from a global VM extension policy, and then delete the global VM extension policy.  
  
### `[get](https://docs.cloud.google.com/compute/docs/reference/rest/2026-09-01/globalVmExtensionPolicies/get)`

|  Gets details of a global VM extension policy.  
  
### `[insert](https://docs.cloud.google.com/compute/docs/reference/rest/2026-09-01/globalVmExtensionPolicies/insert)`

|  Creates a new project level GlobalVmExtensionPolicy.  
  
### `[list](https://docs.cloud.google.com/compute/docs/reference/rest/2026-09-01/globalVmExtensionPolicies/list)`

|  Lists global VM extension policies.  
  
### `[update](https://docs.cloud.google.com/compute/docs/reference/rest/2026-09-01/globalVmExtensionPolicies/update)`

|  Updates a global VM extension policy.
