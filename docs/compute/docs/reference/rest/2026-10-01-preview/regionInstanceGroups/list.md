Retrieves the list of instance group resources contained within the specified region.

### HTTP request

`GET https://compute.googleapis.com/compute/v1/projects/{project}/regions/{region}/instanceGroups?$apiVersion=2026-10-01-preview`

The URLs use [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`project` |  `string` Project ID for this request.  
`region` |  `string` Name of the region scoping this request.

`items[].namedPorts[]` |  `object` Optional. Assigns a name to a port number. For example: `[{name: "app1", port: 8080}, {name: "app1", port: 8081}, {name: "app2", port: 8082}]` Named ports apply to all instances in this instance group.  
`items[].namedPorts[].name` |  `string` The name for this named port. The name must be 1-63 characters long, and comply with [RFC1035](https://www.ietf.org/rfc/rfc1035.txt).

`items[].network` |  `string` Output only. The URL of the network to which all instances in the instance group belong. If your instance has multiple network interfaces, then the network and subnetwork fields only refer to the network and subnet used by your primary interface (nic0).  
`items[].fingerprint` |  `string ([bytes](https://developers.google.com/discovery/v1/type-format) format)` Output only. The fingerprint of the named ports. The system uses this fingerprint to detect conflicts when multiple users change the named ports concurrently.A base64-encoded string.  
`items[].zone` |  `string` Output only. The URL of the [zone](https://cloud.google.com/compute/docs/regions-zones/#available) where the instance group is located (for zonal resources).  
`items[].selfLink` |  `string` Output only. The URL for this instance group. The server generates this URL.  
`items[].size` |  `integer` Output only. The total number of instances in the instance group.  
`items[].region` |  `string` Output only. The URL of the [region](https://cloud.google.com/compute/docs/regions-zones/#available) where the instance group is located (for regional resources).  
`items[].subnetwork` |  `string` Output only. The URL of the subnetwork to which all instances in the instance group belong. If your instance has multiple network interfaces, then the network and subnetwork fields only refer to the network and subnet used by your primary interface (nic0).
