#  OS Login POSIX groups support deprecation Stay organized with collections  Save and categorize content based on your preferences. 

Compute Engine offered OS Login POSIX groups support (Preview), which linked POSIX groups with supplementary Linux groups in your organization's VMs. As of September 26, 2024, you can no longer create new POSIX groups and existing POSIX groups will be removed on or after September 26, 2025. For more information, see [Use Linux groups with OS Login](https://docs.cloud.google.com/compute/docs/oslogin/manage-oslogin-in-an-org#linux-groups).

## Shutdown schedule

The following table lists the shutdown schedule for OS Login POSIX group support.

Date | Event  
---|---  
**September 26, 2024** | OS Login POSIX groups support was deprecated.  
**September 26, 2025** | OS Login POSIX groups support shutdown.
