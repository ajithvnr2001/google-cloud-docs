#  CloudEndure deprecation Stay organized with collections  Save and categorize content based on your preferences. 

CloudEndure was a third-party tool for migrating VMs to Compute Engine from other VM platforms. CloudEndure was deprecated as a migration tool on January 30, 2019. To migrate VMs, use Google's Migrate to VMs.

For information on Migrate to VMs, see the [Migrate to VMs documentation](https://docs.cloud.google.com/migrate/compute-engine/docs/latest).

## Shutdown schedule

The following table lists the shutdown schedule for CloudEndure.

Date | Event  
---|---  
**January, 2019** | CloudEndure deprecated.
