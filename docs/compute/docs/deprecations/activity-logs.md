#  Compute Engine activity logs deprecation Stay organized with collections  Save and categorize content based on your preferences. 

Compute Engine activity logs tracked certain events that affect your project, such as API calls and system events. Compute Engine activity logs were deprecated on September 30, 2019. To track Compute Engine events, use [Audit logs](https://docs.cloud.google.com/compute/docs/logging/audit-logging) instead.

## Shutdown schedule

The following table lists the shutdown schedule for Compute Engine activity logs.

Date | Event  
---|---  
**September 30, 2019** | Compute Engine activity logs deprecated.
