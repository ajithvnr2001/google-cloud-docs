#  TimeZone Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Represents a time zone from the [IANA Time Zone Database](https://www.iana.org/time-zones).

JSON representation  
---  
      
    
    {
      "id": string,
      "version": string
    }  
  
Fields  
---  
`id` |  `string` IANA Time Zone Database time zone. For example "America/New_York".  
`version` |  `string` Optional. IANA Time Zone Database version number. For example "2019a".
