Creates a new Configuration in a given project and location.

### HTTP request

`POST https://licensemanager.googleapis.com/v1/{parent=projects/*/locations/*}/configurations`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`parent` |  `string` Required. Value for parent.  
  
### Query parameters

Parameters  
---  
`configurationId` |  `string` Required. Id of the requesting object  
`requestId` |  `string` Optional. An optional request ID to identify requests. Specify a unique request ID so that if you must retry your request, the server will know to ignore the request if it has already been completed. The server will guarantee that for at least 60 minutes since the first request.For example, consider a situation where you make an initial request and the request times out. If you make the request again with the same request ID, the server can check if original operation with the same request ID was received, and if so, will ignore the second request. This prevents clients from accidentally creating duplicate commitments.The request ID must be a valid UUID with the exception that zero UUID is not supported (00000000-0000-0000-0000-000000000000).  
  
### Request body

The request body contains an instance of `[Configuration](https://docs.cloud.google.com/compute/docs/licensemanager/rest/v1/projects.locations.configurations#Configuration)`.

### Response body

If successful, the response body contains a newly created instance of `[Operation](https://docs.cloud.google.com/compute/docs/licensemanager/rest/v1/projects.locations.operations#Operation)`.

### Authorization scopes

Requires the following OAuth scope:

  * `https://www.googleapis.com/auth/cloud-platform`



For more information, see the [Authentication Overview](https://docs.cloud.google.com/docs/authentication#authorization-gcp).

### IAM Permissions

Requires the following [IAM](https://cloud.google.com/iam/docs) permission on the `parent` resource:

  * `licensemanager.configurations.create`



For more information, see the [IAM documentation](https://cloud.google.com/iam/docs).
