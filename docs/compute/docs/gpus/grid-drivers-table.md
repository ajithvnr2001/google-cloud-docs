#  Drivers for NVIDIA RTX Virtual Workstation (vWS) Stay organized with collections  Save and categorize content based on your preferences. 

Linux  Windows 

You can install NVIDIA RTX Virtual Workstation (vWS) GPU drivers on Compute Engine to run and optimize your graphics-intensive or AI/ML applications. These drivers apply to vWS instances running on Compute Engine. For drivers compatible with other platforms, find them on the [NVIDIA Driver Download](http://www.nvidia.com/Download/index.aspx) page.

**Caution:** These vWS GPU drivers don't support VM instances with fractional GPUs, such as `g4-standard-6`, `g4-standard-12`, and `g4-standard-24`. To install drivers for fractional GPU VM instances, see [Install vGPU drivers (fractional GPUs)](https://docs.cloud.google.com/compute/docs/gpus/install-drivers-gpu#fractional-vms).
