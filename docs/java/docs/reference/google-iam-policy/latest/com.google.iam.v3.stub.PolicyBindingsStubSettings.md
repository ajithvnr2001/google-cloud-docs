Settings class to configure an instance of [PolicyBindingsStub](https://docs.cloud.google.com/java/docs/reference/google-iam-policy/latest/com.google.iam.v3.stub.PolicyBindingsStub).

The default instance has everything set to sensible defaults:

  * The default service address (iam.googleapis.com) and default port (443) are used. 
  * Credentials are acquired automatically through Application Default Credentials. 
  * Retries are configured for idempotent methods but not for non-idempotent methods.
