Feature

Attached asset is available in [`SearchAllResources`](https://cloud.google.com/asset-inventory/docs/reference/rest/v1/TopLevel/searchAllResources). Attached assets are the assets attached to a primary resource, for example the OS Inventory contains runtime information of Compute Instance. It allows customers to search and filter by the attributes of the primary resource (e.g., Compute Instance) and the attached assets (e.g., OS Inventory) in a single query.
