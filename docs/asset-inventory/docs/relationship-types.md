#  Relationship types Stay organized with collections  Save and categorize content based on your preferences. 

These relationship types are supported in the export, list, search, and monitor APIs. The analysis APIs don't support relationship types.

**Note:** Relationship types require access to the [Security Command Center Premium or Enterprise tier](https://cloud.google.com/security-command-center/pricing#tier-pricing).

You can use these relationship types with the following Cloud Asset Inventory operations:

  * [Export to BigQuery](https://docs.cloud.google.com/asset-inventory/docs/export-bigquery)

  * [Export to Cloud Storage](https://docs.cloud.google.com/asset-inventory/docs/export-cloud-storage)

  * [List assets](https://docs.cloud.google.com/asset-inventory/docs/list-assets)

  * [Get asset histories](https://docs.cloud.google.com/asset-inventory/docs/get-asset-history)

  * [Monitor asset changes with Pub/Sub](https://docs.cloud.google.com/asset-inventory/docs/monitor-asset-changes)
