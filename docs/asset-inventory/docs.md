# Cloud Asset Inventory documentation

[Read product documentation](https://docs.cloud.google.com/asset-inventory/docs/overview)

Cloud Asset Inventory provides inventory services based on a time series database. This database keeps a five-week history of Google Cloud asset metadata. The Cloud Asset Inventory export service lets you export all asset metadata at a certain timestamp or export event change history during a timeframe.
