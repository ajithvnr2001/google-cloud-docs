You can use Pub/Sub and other Google Cloud services to help you create a production-ready, scalable, fault-tolerant, log export mechanism that streams logs and events from your resources in Google Cloud into Splunk.

To learn how to combine these services, see the [Stream logs from Google Cloud to Splunk reference architecture](https://docs.cloud.google.com/architecture/stream-logs-from-google-cloud-to-splunk).
