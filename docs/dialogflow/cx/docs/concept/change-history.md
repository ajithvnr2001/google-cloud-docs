#  Change history Stay organized with collections  Save and categorize content based on your preferences. 

Dialogflow maintains a change history for all agent modifications. Each entry identifies what was changed, when the update occurred, and who performed it.

## Access change history

Access the change history for an agent:

###  Console 

  1. Go to the [Dialogflow CX console](https://dialogflow.cloud.google.com/cx/projects).
  2. Select a project.
  3. Find your agent in the list.
  4. Select the **Manage** tab.
  5. Select **Change History**.
  6. View the results and filter as needed.

![A list of recent agent updates](https://docs.cloud.google.com/static/dialogflow/cx/docs/images/change-history.png)

  7. Select a change to open the diff view.

![Diff view comparing two versions of an agent configuration](https://docs.cloud.google.com/static/dialogflow/cx/docs/images/change-history-diff.png)


**Note:** In the [Conversational Agents console](https://conversational-agents.cloud.google.com), the **Change history** button is located in the upper-right menu ribbon of the project.
