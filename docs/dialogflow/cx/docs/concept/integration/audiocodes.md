Dialogflow CX integrates with the [AudioCodes](https://www.audiocodes.com/) telecommunications provider.

## Setup

To create a telephony integration with this system:

  1. Open the [Dialogflow CX console](https://dialogflow.cloud.google.com/cx/projects).
  2. Choose your project.
  3. Select your agent.
  4. Select the **Manage** tab.
  5. Click **Telephony Integrations** in the **Integrations** section of the **Manage** tab.
  6. Click the **Connect** button for the AudioCodes integration.
  7. You are redirected to AudioCodes. Provide the configuration information requested by AudioCodes.
  8. You are redirected back to the Dialogflow CX console, and the integration is now enabled for your agent.



For more information on this integration, see the [AudioCodes documentation](https://voiceaiconnect.audiocodes.com/google-dialogflow).

## Supported countries

This integration supports phone numbers in the following countries:

  * Austria
  * Brazil
  * Canada
  * Croatia
  * Denmark
  * Finland
  * Ireland
  * Israel
  * Lithuania
  * Mexico
  * Monaco
  * New Zealand
  * Poland
  * Slovakia
  * Slovenia
  * USA
  * UK



## Pricing and quotas

The [pricing](https://cloud.google.com/products/conversational-agents/pricing) and [quotas](https://docs.cloud.google.com/dialogflow/quotas) for this integration are applied as a voice session.

[Billing](https://docs.cloud.google.com/dialogflow/cx/docs/quick/setup#billing) must be enabled on your Dialogflow CX project for this integration.
