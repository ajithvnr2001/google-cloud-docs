#  Create a prebuilt agent Stay organized with collections  Save and categorize content based on your preferences. 

The first step in this tutorial is to create an agent. Rather than building an agent from scratch, you will import a telecommunications [prebuilt agent](https://docs.cloud.google.com/dialogflow/cx/docs/concept/agents-prebuilt). Using a prebuilt agent will accelerate your progress for this tutorial.

To import a prebuilt agent to your project:

  1. Go to the [Dialogflow CX console](https://dialogflow.cloud.google.com/cx/projects).
  2. Select the project where you would like to import the prebuilt agent or click **Create Project** to create a new project.
  3. Click **Use pre-built agents**.
  4. Click the **Telecommunications** prebuilt agent.
  5. Click **Import as agent**.
  6. A dialog box opens.
  7. Choose your desired [location](https://docs.cloud.google.com/dialogflow/cx/docs/concept/region#avail).
  8. Click **Create**.



![Prebuilt agent import screenshot](https://docs.cloud.google.com/static/dialogflow/cx/docs/tutorials/deploy/images/create-prebuilt-agent.png)

In the next step, you will create a webhook service required for this agent.
