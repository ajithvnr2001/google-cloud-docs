#  Compliance and security controls Stay organized with collections  Save and categorize content based on your preferences. 

This page provides information on compliance certifications and security controls that are supported by Dialogflow CX. Dialogflow is comprised of other Google Cloud services, such as Speech-to-Text and Text-to-Speech. Any certifications, security controls, and government authorizations cover Dialogflow in its entirety.

## Certifications

Dialogflow CX is compliant with the following:

Compliance Certification | Dialogflow CX (including [generative features](https://docs.cloud.google.com/dialogflow/cx/docs/concept/generative)) | Dialogflow ES  
---|---|---  
[HIPAA](https://docs.cloud.google.com/security/compliance/hipaa) | ✔ | ✔  
[ISO 27001](https://docs.cloud.google.com/security/compliance/iso-27001), [ISO 27017](https://docs.cloud.google.com/security/compliance/iso-27017), [ISO 27018](https://docs.cloud.google.com/security/compliance/iso-27018), and [ISO 27701](https://docs.cloud.google.com/security/compliance/iso-27701) | ✔ | ✔  
[SOC 1](https://docs.cloud.google.com/security/compliance/soc-1), [SOC 2](https://docs.cloud.google.com/security/compliance/soc-2), [SOC 3](https://docs.cloud.google.com/security/compliance/soc-3) | ✔ | ✔  
  
## Security controls

Dialogflow CX provides the following security controls:

Security controls compliance | Dialogflow CX (including [generative features](https://docs.cloud.google.com/dialogflow/cx/docs/concept/generative)) | Dialogflow ES  
---|---|---  
Data Residency | [Regionalization and location settings](https://docs.cloud.google.com/dialogflow/cx/docs/concept/region) | [Regionalization and data residency](https://docs.cloud.google.com/dialogflow/es/docs/how/region)  
Customer-managed encryption keys (CMEK) | [Customer-managed encryption keys (CMEK)](https://docs.cloud.google.com/dialogflow/cx/docs/concept/cmek) | -  
VPC Service Controls (VPC-SC) | [Using VPC Service Controls](https://docs.cloud.google.com/dialogflow/cx/docs/concept/vpc-service-controls) | [Using VPC Service Controls](https://docs.cloud.google.com/dialogflow/es/docs/vpc-service-controls)  
Access Transparency | [Access Transparency](https://docs.cloud.google.com/dialogflow/cx/docs/concept/access-transparency) | -  
  
## Government authorizations

Dialogflow CX has received the following authorizations:

Authorization | Dialogflow CX (including [generative features](https://docs.cloud.google.com/dialogflow/cx/docs/concept/generative)) | Dialogflow ES  
---|---|---  
FedRAMP High | [Authorization](https://docs.cloud.google.com/security/compliance/fedramp#section-6) | -
