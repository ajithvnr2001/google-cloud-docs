#  Integrations Stay organized with collections  Save and categorize content based on your preferences. 

Dialogflow integrates with many popular conversation platforms like Google Assistant, Slack, and Facebook Messenger. If you want to build an agent for one of these platforms, you should use one of the many _integrations_ options. Direct end-user interactions are handled for you, so you can focus on building your agent. Each integration handles end-user interactions in a platform-specific way, so see the documentation for your integration platform for details. 

**Note:** When using a third party integration, requests and end-user data are sent to both Google and the third party. The terms of service, SLA, pricing, and quotas [for your agent edition](https://docs.cloud.google.com/dialogflow/docs/editions) are applicable for Google's handling of these requests. The third party's terms of service, SLA, pricing, and quotas are applicable for the third party's handling of these requests. 

There are multiple types of Dialogflow integrations. See each type description below.

## Partner telephony integrations

These telephony integrations are created by Google partners in collaboration with Google. Google provides no support for these integrations. You should contact the integration owner for support. These integrations require one click to enable from Dialogflow, which is followed by configuration steps required by the partner. The following are available from Google partners:

  * [AudioCodes](https://docs.cloud.google.com/dialogflow/docs/integrations/audiocodes)
  * [Avaya](https://docs.cloud.google.com/dialogflow/docs/integrations/avaya)
  * [SignalWire](https://docs.cloud.google.com/dialogflow/docs/integrations/signalwire)
  * [Voximplant](https://docs.cloud.google.com/dialogflow/docs/integrations/voximplant)



## Dialogflow built-in integrations

These integrations are fully supported by Dialogflow and are configured with the Dialogflow Console. The following are available:

  * [Dialogflow Messenger](https://docs.cloud.google.com/dialogflow/docs/integrations/dialogflow-messenger)
  * [Dialogflow Phone Gateway](https://docs.cloud.google.com/dialogflow/docs/integrations/phone-gateway)
  * [Dialogflow Web Demo](https://docs.cloud.google.com/dialogflow/docs/integrations/web-demo)
  * [Messenger from Facebook](https://docs.cloud.google.com/dialogflow/docs/integrations/facebook)
  * [Workplace from Facebook](https://docs.cloud.google.com/dialogflow/docs/integrations/workplace)
  * [Google Assistant (legacy)](https://docs.cloud.google.com/dialogflow/docs/integrations/aog)
  * [Google Chat](https://docs.cloud.google.com/dialogflow/docs/integrations/google-chat)
  * [LINE](https://docs.cloud.google.com/dialogflow/docs/integrations/line)
  * [Slack](https://docs.cloud.google.com/dialogflow/docs/integrations/slack)
  * [Telegram](https://docs.cloud.google.com/dialogflow/docs/integrations/telegram)



## Google-contributed open source integrations

These open source integrations were contributed by Google. Feel free to fork, modify, and publish your own integrations. These integrations are legacy built-in integrations, so some of them can still be selected as platforms for intent responses. The following integrations were contributed by Google:

  * [Kik](https://github.com/GoogleCloudPlatform/dialogflow-integrations/tree/master/kik#readme)
  * [Skype](https://github.com/GoogleCloudPlatform/dialogflow-integrations/tree/master/skype#readme)
  * [Spark (Cisco Webex)](https://github.com/GoogleCloudPlatform/dialogflow-integrations/tree/master/spark#readme)
  * [Twitter](https://github.com/GoogleCloudPlatform/dialogflow-integrations/tree/master/twitter#readme)
  * [Viber](https://github.com/GoogleCloudPlatform/dialogflow-integrations/tree/master/viber#readme)



## Independent integrations

These integrations are not built-in and are created by other organizations and individuals. You can also create a custom integration by using the [Dialogflow API](https://docs.cloud.google.com/dialogflow/es/docs/api-overview). Google provides no support for these integrations. You should contact the integration owner for support.
