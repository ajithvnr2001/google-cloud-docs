## Google Cloud Support

If you have a paid [Google Cloud support plan](https://docs.cloud.google.com/support#support-plans) and use a [Dialogflow paid edition](https://docs.cloud.google.com/dialogflow/docs/editions), always open support cases through the [Google Cloud support console](https://console.cloud.google.com/projectselector/support/cases).

Before submitting your request, check if [Troubleshooting](https://docs.cloud.google.com/dialogflow/docs/support/troubleshooting), [FAQ](https://docs.cloud.google.com/dialogflow/docs/support/faq), or [Release Notes](https://docs.cloud.google.com/dialogflow/docs/release-notes) have answers to your questions.

When opening a case,

  * use the Dialogflow CX component if your report is about the [Dialogflow CX edition](https://docs.cloud.google.com/dialogflow/cx/docs);
  * use the Dialogflow ES component if your report is about the [Dialogflow ES edition](https://docs.cloud.google.com/dialogflow/es/docs).



The Google Cloud Support team offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Getting Google Cloud support](https://docs.cloud.google.com/support/docs).

## Community support

### Google Cloud Forums

Search the [Dialogflow Cloud Forum](https://www.googlecloudcommunity.com/gc/forums/filteredbylabelpage/board-id/cloud-ai-ml/label-name/dialogflow) to discuss all Dialogflow CX topics.

Cloud Forums are monitored by Google on a best-effort basis.

### Stack Overflow

Ask a question about Dialogflow CX on [Stack Overflow](https://stackoverflow.com/). See the [general guidelines](https://docs.cloud.google.com/support/docs/community).

  * Dialogflow CX (tagged as `dialogflow-cx`)

    * [Ask a question](http://stackoverflow.com/questions/ask?tags=dialogflow-cx)
    * [See a list of all questions](http://stackoverflow.com/questions/tagged/dialogflow-cx)
  * Dialogflow ES (tagged as `dialogflow-es`)

    * [Ask a question](http://stackoverflow.com/questions/ask?tags=dialogflow-es)
    * [See a list of all questions](http://stackoverflow.com/questions/tagged/dialogflow-es)



The questions are monitored by Google on a best-effort basis.

### File product issues or feature requests

You can report issues or file feature requests via Issue Trackers. See the [general guidelines](https://docs.cloud.google.com/support/docs/issue-trackers).

  * Dialogflow CX

    * Search the [existing list](https://issuetracker.google.com/issues?q=componentid:956347+%2B%20status:open) for a similar issue before filing a new one.
    * If you do not find a similar issue and would like to report it, you can [create a new issue](https://issuetracker.google.com/issues/new?component=956347).
  * Dialogflow ES

    * Search the [existing list](https://issuetracker.google.com/issues?q=componentid:501190%2B%20status:open) for a similar issue before filing a new one.
    * If you do not find a similar issue and would like to report it, you can [create a new issue](https://issuetracker.google.com/issues/new?component=501190).



### Slack

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Dialogflow CX and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Dialogflow CX, join the [`#dialogflow`](https://googlecloud-community.slack.com/messages/C83KUQCFM/) channel. 

## Documentation issues

From any Dialogflow documentation page, click **Send feedback** near the top right or bottom of the page. This will open a feedback form specific to the page you are viewing. Your comments will be reviewed by the Dialogflow documentation team.
