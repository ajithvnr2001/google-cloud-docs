Dialogflow integrates with the [Voximplant](https://voximplant.com/) telecommunications provider. 

## Setup

To create a telephony integration with this system: 

  1. Go to the [Dialogflow ES console](https://dialogflow.cloud.google.com). 
  2. Select your agent. 
  3. Click **Integrations** in the left sidebar menu. 
  4. Enable the **Voximplant** integration. 
  5. You are redirected to Voximplant. Provide the configuration information requested by Voximplant. 
  6. You are redirected back to the Dialogflow console, and the integration is now enabled for your agent. 



For more information on this integration, see the [Voximplant documentation](https://voximplant.com/solutions/dialogflow-connector).
