#  Dialogflow Web Demo Stay organized with collections  Save and categorize content based on your preferences. 

Dialogflow Web Demo provides a simple text chat user interface for your agent. For more information, see the [quickstart guide](https://docs.cloud.google.com/dialogflow/docs/quick/integration) for this integration.

## Limitations

This integration only supports single text responses. Rich messages (including sequential text responses, line breaks, hyperlinks, images etc) are not supported.

To use [rich response messages](https://docs.cloud.google.com/dialogflow/docs/intents-rich-messages) and customizations, see the [Dialogflow Messenger](https://docs.cloud.google.com/dialogflow/docs/integrations/dialogflow-messenger) integration.

Only the [default agent language](https://docs.cloud.google.com/dialogflow/es/docs/agents-settings#lang) is supported by this integration.
