#  Prebuilt agents Stay organized with collections  Save and categorize content based on your preferences. 

Prebuilt agents are a collection of agents provided by Dialogflow for common use cases. These agents can be used to establish a base for building conversations for dining out, hotel booking, navigation, etc.

Prebuilt agents include intents and entities for their use cases, but you need to provide intent responses. Responses often depend on your specific scenario or need to be retrieved via [fulfillment](https://docs.cloud.google.com/dialogflow/docs/fulfillment-overview).

**Note:** Importing a prebuilt agent creates a new agent. If you want to include prebuilt agent functionality in an existing agent, you can [copy or move the intents and entities](https://docs.cloud.google.com/dialogflow/es/docs/intents-manage#copy_or_move_intents) from the newly created prebuilt agent to your existing agent.

## Limitations

The following limitations apply:

  * Prebuilt agents are only available for the `global` [region](https://docs.cloud.google.com/dialogflow/es/docs/how/region).
  * Each prebuilt agent supports a subset of all Dialogflow languages. When you are browsing pre-built agents, only the pre-built agents that support the default language of the active agent are shown.



## Import a prebuilt agent

To import a prebuilt agent to your project:

  1. Go to the [Dialogflow ES console](https://dialogflow.cloud.google.com).
  2. Click **Prebuilt agents** in the left sidebar menu.
  3. Hover the mouse over a prebuilt agent.
  4. Click **View details**.
  5. Click **Import**.
  6. Either create a new GCP project or choose an existing one.
  7. Click **Create Agent From Template**.
