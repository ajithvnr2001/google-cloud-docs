#  Data application levels Stay organized with collections  Save and categorize content based on your preferences. 

Dialogflow data is applied at different levels, depending on the type of data. For example, logging settings are applied at the agent version level, so each agent version can have its own logging settings. The following describes the levels:

Level | Data  
---|---  
Agent (applies to all environments and agent versions) | [Knowledge bases](https://docs.cloud.google.com/dialogflow/es/docs/how/knowledge-bases)  
  
[Agent edition](https://docs.cloud.google.com/dialogflow/docs/editions)  
Environment | [Fulfillment and text-to-speech settings established when creating the environment](https://docs.cloud.google.com/dialogflow/es/docs/agents-versions#environment-specific_settings)  
Agent version | All other settings (logging, ML, knowledge base selection, and so on), and all resources (intents, entities, and so on)
