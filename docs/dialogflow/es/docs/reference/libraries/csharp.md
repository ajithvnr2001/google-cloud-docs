### Installation

To install the client library: 

Install the `Google.Cloud.Dialogflow.V2` package from [NuGet](https://docs.microsoft.com/en-us/nuget/). Add it to your project in the normal way (for example by right-clicking on the project in Visual Studio and choosing "Manage NuGet Packages..."). Ensure you enable pre-release packages (for example, in the Visual Studio NuGet user interface, check the "Include prerelease" box). 

Alternatively, you can use the NuGet command line interface: 
    
    
    nuget install Google.Cloud.Dialogflow.V2 -PreRelease
