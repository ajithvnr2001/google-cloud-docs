### Installation

To install the client library: 

  1. Install the preferred dependency manager for PHP, [Composer](https://getcomposer.org/). 
  2. Install the Dialogflow component of Google Cloud Client Libraries: 
         
         composer require google/cloud-dialogflow

  3. This component supports both REST over HTTP/1.1 and gRPC. In order to take advantage of the benefits offered by gRPC (such as streaming methods), follow the instructions in the [gRPC installation guide](https://docs.cloud.google.com/php/docs/reference/help/grpc).
