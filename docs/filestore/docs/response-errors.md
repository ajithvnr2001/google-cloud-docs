The following is a table of common Filestore-related error codes and messages and their corresponding troubleshooting pages.

Error code, message, or unanswered command | Troubleshoot page  
---|---  
`df` and `du`   
(Inconsistent responses when used together) | [Troubleshoot capacity issues](https://docs.cloud.google.com/filestore/docs/capacity-issues#df_and_du_commands_report_different_amounts_of_free_disk_space)  
`error code 13` | [Troubleshoot instance creation](https://docs.cloud.google.com/filestore/docs/create-instance-issues)  
`Error: Output: mount.nfs: access denied by server while mounting x.x.x.x:/file-share-name` | [Troubleshoot file share access from GKE clusters](https://docs.cloud.google.com/filestore/docs/gke-access-issues#error_output_mountnfs_access_denied_by_server_while_mounting_xxxxfile-share-name)  
`FAILED_PRECONDITION` | [Operations concurrency](https://docs.cloud.google.com/filestore/docs/operations-concurrency)  
`Failed to create subnetwork. Couldn't find free blocks in allocated IP ranges.` | [Troubleshoot Filestore API response errors](https://docs.cloud.google.com/filestore/docs/api-issues#failed_to_create_a_subnetwork)  
`mount.nfs: access denied by server while mounting ...` | [Mount issues](https://docs.cloud.google.com/filestore/docs/mount-issues#my_vm_or_gke_pod_cant_access_filestore)  
`mount.nfs: Connection timed out` | [Known issues](https://docs.cloud.google.com/filestore/docs/known-issues#mounting_over_vpn)  
`No space left on device` | [Known issues](https://docs.cloud.google.com/filestore/docs/known-issues)  
[Troubleshoot capacity issues](https://docs.cloud.google.com/filestore/docs/capacity-issues)  
`PERMISSION DENIED` | [Troubleshoot instance creation](https://docs.cloud.google.com/filestore/docs/create-instance-issues)  
`ping`   
(No response) | [Troubleshoot Filestore instance response errors](https://docs.cloud.google.com/filestore/docs/unresponsive)  
`REPAIRING` | [Troubleshoot Filestore instance response errors](https://docs.cloud.google.com/filestore/docs/unresponsive#instance_shows_status_repairing)  
`RESOURCE_EXHAUSTED` | [Operations concurrency](https://docs.cloud.google.com/filestore/docs/operations-concurrency)  
`System limit for internal resources has been reached` | [Troubleshoot instance creation](https://docs.cloud.google.com/filestore/docs/create-instance-issues#system_limit_for_internal_resources_has_been_reached_error_when_creating_an_instance)  
`traceroute`   
(No response) | [Troubleshoot Filestore instance response errors](https://docs.cloud.google.com/filestore/docs/unresponsive)  
`UNAVAILABLE` | [Troubleshoot Filestore instance response errors](https://docs.cloud.google.com/filestore/docs/unresponsive#instance_shows_status_unavailable)
