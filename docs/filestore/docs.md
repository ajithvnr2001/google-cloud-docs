# Filestore documentation

[Read product documentation](https://docs.cloud.google.com/filestore/docs/overview)

Filestore instances are fully managed NFS file servers on Google Cloud for use with applications running on Compute Engine virtual machine (VM) instances, Google Kubernetes Engine clusters, external datastores such as Google Cloud VMware Engine, or your on-premises machines.
