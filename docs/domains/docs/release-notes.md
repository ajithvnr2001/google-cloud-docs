This page contains release notes for features and updates to Cloud Domains. Check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality. 

You can see the latest product updates for all of Google Cloud on the [ Google Cloud](https://docs.cloud.google.com/release-notes) page, browse and filter all release notes in the [Google Cloud console](https://console.cloud.google.com/release-notes), or programmatically access release notes in [BigQuery](https://console.cloud.google.com/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table). 

To get the latest product updates delivered to you, add the URL of this page to your [feed reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the [feed URL](https://docs.cloud.google.com/feeds/domains-release-notes.xml) directly. 

## June 09, 2026

Feature

Organization Policy Service custom constraints are [generally available](https://cloud.google.com/products#product-launch-stages) for Cloud Domains. For more information, see [Use custom organization policies](https://docs.cloud.google.com/domains/docs/custom-constraints).

## June 20, 2024

Feature

You can migrate your Google Domains DNS settings and export your domain and email forwarding configurations if you use Google Domains as your DNS provider. For more information, see [Migrate Google Domains DNS settings](https://docs.cloud.google.com/domains/docs/export-dns-settings).

## June 12, 2024

Feature

If your domain expired within the past 30 days, you can renew it using the Google Cloud CLI or the Cloud Domains API. For more information, see [Renew a recently expired domain](https://docs.cloud.google.com/domains/docs/renew-expired-domain).

Feature

For domains such as `.uk` or `.co.uk` that don't support authorization codes, you can now use the Google Cloud CLI or the Cloud Domains API to initiate a push transfer to another registrar. For more information see, [Transfer a `.uk` or `.co.uk` domain](https://docs.cloud.google.com/domains/docs/transfer-domain-to-another-registrar#initiate-push-transfer).

## January 22, 2024

Announcement

On September 7, 2023, Squarespace acquired all domain registrations and related customer accounts from Google Domains. Consequently, some Cloud Domains features are deprecated and removed. For more information, see [Deprecations and shut down features](https://docs.cloud.google.com/domains/docs/deprecations/feature-deprecations) and [Cloud Domains FAQ](https://docs.cloud.google.com/domains/docs/faq).

## December 06, 2023

Feature

You can now turn off automatic renewal after you've registered your domain. For more information, see [Turn off automatic renewal for a domain name](https://docs.cloud.google.com/domains/docs/edit-registration-settings#turn-off-renew).

## October 20, 2023

Announcement

On September 7, 2023 Squarespace acquired all domain registrations and related customer accounts from Google Domains. For more information about how this change affects Cloud Domains, see [Cloud Domains feature deprecation](https://docs.cloud.google.com/domains/docs/deprecations/feature-deprecations), [Google Domains FAQ](https://support.google.com/domains/answer/13689670), and [Cloud Domains FAQ](https://docs.cloud.google.com/domains/docs/faq).

## April 28, 2023

Feature

[Importing a domain from Google Domains to Cloud Domains](http://cloud.google.com/domains/docs/import-domains-from-gd) is available in [**GA**](https://cloud.google.com/products/#product-launch-stages).

## August 09, 2022

Feature

[Importing a domain from Google Domains to Cloud Domains](http://cloud.google.com/domains/docs/import-domains-from-gd) is available in [**Preview**](https://cloud.google.com/products/#product-launch-stages).

## February 21, 2022

Change

[Cloud Domains](http://cloud.google.com/domains/docs) now supports the following new TLDs:

  * .day
  * .contact
  * .de
  * .nl
  * .autos



The annual price for the following two TLDs has changed to $15:

  * .boats
  * .homes



For details, see [Cloud Domains Pricing](https://cloud.google.com/domains/pricing).

## October 19, 2021

Announcement

[Cloud Domains](http://cloud.google.com/domains/docs) is available in [**GA**](https://cloud.google.com/products/#product-launch-stages). Cloud Domains enables you to search, register, and manage domain names with Google Cloud. Cloud Domains also lets you transfer a domain to or from a third-party provider.

As announced in the MSA sent on September 16, 2021, Cloud Domains has a new [billing model](https://cloud.google.com/domains/pricing#billing-models).

## October 13, 2020

Announcement

[Cloud Domains](http://cloud.google.com/domains/docs) is available in [**Preview**](https://cloud.google.com/products/#product-launch-stages). Cloud Domains enables you to search, register, and manage domain names with Google Cloud.
