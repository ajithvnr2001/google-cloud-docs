# Build, scale, govern, and optimize with Gemini Enterprise Agent Platform

**Gemini Enterprise Agent Platform** is our open and comprehensive platform that empowers businesses to rapidly build, scale, govern, and optimize enterprise-grade agents grounded in your enterprise data. It provides the full-stack foundation and extensive developer choice you need to transform your applications and workflows into powerful, reliable agentic systems at global scale. 

[API quickstart](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start) [Get started in Agent Studio](https://console.cloud.google.com/agent-platform/studio) [Get an API key](https://console.cloud.google.com/agent-platform/studio/settings/api-keys)

![](https://www.gstatic.com/images/branding/productlogos/gemini_2025/v1/192px.svg)

## Everything you need to build  
production-ready agents

### Build

  * Build with Agent Platform  Learn about the different tools and services you can use to build agents with Agent Platform. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build)

  * Agent Development Kit  The Agent Development Kit (ADK) is a modular, model-agnostic framework designed to make building and deploying complex AI agents feel just like standard software development. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/adk)

  * Agent Garden  Explore Google's library of pre-built agents. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/agent-garden)

  * Agent Studio  Low-code canvas for designing complex multi-agent reasoning loops. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/agent-studio)

  * Skill Registry  Skill Registry serves as a secure, private, and low-latency repository for managing and discovering agent skills. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/skill-registry)

  * RAG Engine  RAG Engine helps you securely connect your private data to LLMs, reducing hallucinations and improving answer accuracy by providing the model with relevant, context-rich information. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/rag-engine/rag-overview)

  * Vector Search  Vector Search is an AI-native search engine that combines storage and retrieval into one scalable, auto-tuned platform, simplifying how you store, search, and manage your data for AI applications. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/vector-search/setup)

  * Managed Agents API  A config-driven, REST-first API for building autonomous agents inside a fully managed sandbox. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/build/managed-agents)

## Built for developers,  
designed for enterprise

  * Gemini  Advanced reasoning-first models optimized for complex agentic workflows and coding. Features Gemini 3.1 Pro and Gemini 3 Flash. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/google-models#gemini-models)

  * Veo  High-quality video generation models that create cinematic video from text or image prompts. Features Veo 3.1. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/google-models#veo-models)

  * Lyria  Generate full-length music tracks and audio clips from simple text and image prompts. Features Lyria 3. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/google-models#lyria-models)

  * Partner models  Access curated third-party models offered as managed APIs. Includes Claude, Grok, and Mistral. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/use-partner-models)

  * Open models  Choose from a variety of open weight models and select the best serving option. Includes Llama, DeepSeek, Mistral, and Qwen. [arrow_outward](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/open-models/choose-serving-option)
