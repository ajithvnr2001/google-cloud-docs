#  Install the Ops Agent by using automation tools Stay organized with collections  Save and categorize content based on your preferences. 

In addition to using the Google Cloud CLI or Terraform to create [agent policies](https://docs.cloud.google.com/stackdriver/docs/solutions/agents/ops-agent/agent-policies-overview), you can use other automation tools to manage the Ops Agent across your fleet of Compute Engine VMs:

  * **Ansible** by using the Ansible role, you can install and configure the agent across your fleet of Linux and Windows VMs. For more information, see the following resources: 
    * [Ansible Role for Cloud Ops](https://github.com/GoogleCloudPlatform/google-cloud-ops-agents-ansible#ansible-role-for-cloud-ops) documentation. 
    * [Install the Ops Agent to troubleshoot third-party applications](https://www.youtube.com/watch?v=GQgNygd-XJU&t=7s) walkthrough video for deploying and configuring the Ops Agent. 
  * **Chef** : by using the Chef cookbook, you can install and configure the agent across your fleet of Linux and Windows VMs. For more information, see the [Chef Integration](https://github.com/GoogleCloudPlatform/google-cloud-ops-agents-chef/blob/master/README.md) documentation. 
  * **Puppet** : by using the Puppet module, you can install and configure the agent across your fleet of Linux and Windows VMs. For more information, see the [Puppet Integration](https://github.com/GoogleCloudPlatform/google-cloud-ops-agents-puppet/blob/master/README.md) documentation.
