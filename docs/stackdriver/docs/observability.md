# Google Cloud Observability documentation

[Read product documentation](https://docs.cloud.google.com/stackdriver/docs)

**Google Cloud Observability** includes observability services that help you to understand the behavior, health, and performance of your applications and the systems that they run on. Visibility into how applications and systems behave and how components are connected help you to anticipate, identify, and respond to unexpected changes more quickly and effectively.

**Google Cloud Observability** includes the following services:

  * **Cloud Logging** : A fully managed service that lets you to store, search, analyze, monitor, and alert on logging data and events.
  * **Cloud Monitoring** : A service that collects metric data and provides tools that let you monitor and visualize how your applications and services are performing.
  * **Cloud Trace** : A distributed tracing system for Google Cloud that collects latency data from applications and displays it in near real-time in the Google Cloud console.
  * **Error Reporting** : A service that aggregates and displays errors produced in your running cloud services.
