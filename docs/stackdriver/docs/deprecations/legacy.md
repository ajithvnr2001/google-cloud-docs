#  Legacy Logging and Monitoring deprecation Stay organized with collections  Save and categorize content based on your preferences. 

Legacy Logging and Monitoring support for Google Kubernetes Engine (GKE) was deprecated on **December 12, 2019**. It was replaced by [Cloud Logging and Cloud Monitoring](https://docs.cloud.google.com/monitoring/kubernetes-engine) integration and managed collection of metrics using [Google Cloud Managed Service for Prometheus](https://docs.cloud.google.com/stackdriver/docs/managed-prometheus).

## Shutdown timetable

The following table lists the shutdown schedule for Legacy Logging and Monitoring:

Event | Date  
---|---  
Legacy Logging and Monitoring deprecated | **December 12, 2019**  
Legacy Logging and Monitoring decommissioned | **March 31, 2021**
