#  Configure a MongoDB database for CDC Stay organized with collections  Save and categorize content based on your preferences. 

Datastream lets you stream change data capture (CDC) updates from a MongoDB-compatible database to a [supported destination](https://docs.cloud.google.com/datastream/docs/destinations), such as BigQuery or Cloud Storage. Depending on your deployment type, you prepare your source by configuring change streams, database user privileges, and network connectivity.

## Supported databases

Datastream works with the following types of MongoDB databases:

  * MongoDB Atlas
  * Self-managed MongoDB
  * Amazon DocumentDB (instance-based)
  * Azure DocumentDB (formerly Azure Cosmos DB for MongoDB (vCore-based))
