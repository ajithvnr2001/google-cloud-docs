#  Delete a connection profile Stay organized with collections  Save and categorize content based on your preferences. 

If you no longer need a connection profile, then delete it. 

**Note:** If a connection profile is assigned to any streams, then you can't delete the profile. To delete the connection profile, you must first [delete each stream](https://docs.cloud.google.com/datastream/docs/delete-a-stream) that's associated with the profile. To see which streams are using the connection profile, you can [view detailed information about the profile](https://docs.cloud.google.com/datastream/docs/view-connection-profiles#viewdetailedinformation).

## Delete a connection profile

  1. Go to the **Connection profiles** page in the Google Cloud Console.

[Go to the Connection profiles page](https://console.cloud.google.com/datastream/connection-profiles)

  2. Click the connection profile that you want to delete.

  3. In the **Connection profile details** page, verify that the connection profile isn't being used by any streams. If it is, then [delete the streams](https://docs.cloud.google.com/datastream/docs/delete-a-stream).

  4. Click **DELETE**.

  5. In the dialog, click **DELETE**.
