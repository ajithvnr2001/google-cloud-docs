#  Configure a source MySQL database Stay organized with collections  Save and categorize content based on your preferences. 

You can use Datastream to stream change data capture (CDC) updates from a cloud-hosted or self-managed MySQL database to a [supported destination](https://docs.cloud.google.com/datastream/docs/destinations), such as BigQuery or Cloud Storage. Depending on your MySQL deployment type, you configure row-based binary logging and log retention so that Datastream can read database events.

## Supported databases

Datastream works with the following types of MySQL databases:

  * Amazon RDS for MySQL
  * Amazon Aurora MySQL
  * Cloud SQL for MySQL
  * Self-managed MySQL
