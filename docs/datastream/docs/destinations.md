#  Destinations Stay organized with collections  Save and categorize content based on your preferences. 

This section describes the destinations to which you can stream data using Datastream. Supported destinations are:

  * BigQuery
  * Cloud Storage
  * Apache Iceberg tables.



You learn about the write behavior and known limitations that Datastream has when writing data to each of these destinations. You also find out how to set up your destinations for streaming.

## What's next

  * Learn how to [configure a BigQuery destination](https://docs.cloud.google.com/datastream/docs/destination-bigquery).
  * Learn how to [configure a Cloud Storage destination](https://docs.cloud.google.com/datastream/docs/destination-gcs).
  * Learn how to [configure an Apache Iceberg destination](https://docs.cloud.google.com/datastream/docs/destination-blmt).
