#  Use the Cloud Run Explorer in Cloud Code for IntelliJ Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Code comes with the Cloud Run Explorer; an easy way of monitoring your existing Cloud Run services and revisions, without having to leave your IDE.

## Viewing service status with the Cloud Run Explorer

You can view the status of your Cloud Run services and revisions using the Cloud Run Explorer:

  1. Navigate to the Cloud Run Explorer. It can be accessed from the side panel on the right.

The available general Cloud Run Explorer actions, accessible via their icons in the Explorer, are:

     * Creating a new Cloud Run application from a sample ![New Cloud Run app from a sample icon](https://docs.cloud.google.com/static/code/docs/intellij/images/new-app.png)
     * Refreshing the Explorer ![Refresh explorer icon](https://docs.cloud.google.com/static/code/docs/intellij/images/refresh-explorer.png)
     * Opening the Cloud Code Cloud Run documentation in a web browser ![open docs icon](https://docs.cloud.google.com/static/code/docs/intellij/images/view-docs.png)

![Cloud Run explorer tab highlighted on the right hand-side panel](https://docs.cloud.google.com/static/code/docs/intellij/images/cloud-run-explorer.png)

  2. Click on a service or a revision in the explorer to display its properties.

![Cloud Run explorer open with a service selected and its properties displayed below](https://docs.cloud.google.com/static/code/docs/intellij/images/service-properties.png)

  3. Within a service, active revisions with allocated traffic are displayed next to the revision name. Inactive revisions are grouped separately.

![Cloud Run explorer with active and inactive revisions visible under a service](https://docs.cloud.google.com/static/code/docs/intellij/images/service-active-revision.png)

  4. Additionally, you can right click an active resource within the Cloud Run Explorer and choose to:

     * Open its corresponding URL (for a service)

![Right click a service to open the URL to its corresponding live service](https://docs.cloud.google.com/static/code/docs/intellij/images/open-service-url.png)

     * View logs (for a revision)

![Right-click on a revision to view its logs](https://docs.cloud.google.com/static/code/docs/intellij/images/view-service-logs.png)
