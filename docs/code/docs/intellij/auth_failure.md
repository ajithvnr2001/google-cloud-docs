**Error:** The authentication flow did not complete successfully, and your IDE is **not** authorized to access your account.

## Report issues with logs

Authentication errors occur for a variety of reasons. To report your issues with Cloud Code logs using your IDE's feedback form, perform the following tasks:

  1. Try signing in again. If you're still getting the authentication failure, proceed to the next steps to report the issue to the Cloud Code team.
  2. In your IDE, navigate to **Tools** > **Gemini + Google Cloud Code** > **Help / About** > **Submit feedback or report an issue**.
  3. In the form window, enter detailed information about your issue and provide steps to reproduce the issue.
  4. When you're finished entering the information about the issue, click **Submit Feedback**.



## More information

Try signing in again from your IDE. If you believe that you have received this message in error, report a bug using our [issue tracker](https://github.com/GoogleCloudPlatform/cloud-code-intellij/issues).
