#  Use pre-release features in Cloud Code for IntelliJ Stay organized with collections  Save and categorize content based on your preferences. 

You can try pre-release features, provide valuable feedback, and ask Cloud Code for IntelliJ developers and other users questions by installing pre-release builds and joining the [Cloud Code Insiders group](https://groups.google.com/g/cloud-code-insiders). 

Pre-release builds can include bug fixes and features still in development that can be removed in a future release. Pre-release features are listed on the **Cloud Code - Welcome** page in your IDE. 

## Install Insiders builds

When you turn on notifications for insider builds, you're prompted to update Cloud Code when new insider features are available. 

### Turn on insider build notifications

  1. To open the **Cloud Code - Welcome** page, click **Tools** > **Cloud Code** > **Help/About** > **About Cloud Code**. 
  2. Under the **Cloud Code Insiders** heading on the **Cloud Code - Welcome** page, toggle the **Notify me when new insider builds are available** option to the "on" position. 

Cloud Code prompts you to **Check for Updates** or **Update Later**.

  3. If you click **Check for Updates** , the **Choose Plugins to Install or Enable** dialog appears with the latest insiders build selected. To install the latest insiders build, click **OK**. 

Cloud Code may take a few minutes to complete the installation.

  4. If Cloud Code prompts you to restart your IDE after the installation is complete, click **Restart**.



## Leave the Insiders program

When you turn off notifications for insiders builds, you're no longer prompted when new insider features are available. You can also remove yourself from the [Cloud Code Insiders Group](https://groups.google.com/g/cloud-code-insiders). 

### Turn off pre-release builds

  1. To open the **Cloud Code - Welcome** page, click **Tools** > **Cloud Code** > **Help/About** > **About Cloud Code**. 
  2. Under the **Cloud Code Insiders** heading on the **Cloud Code - Welcome** page, toggle the **Notify me when new insider builds are available** option to the "off" position.
