## Bring the power of cloud to your apps

Cloud Code is a Google-developed plugin that adds support for Google Cloud to your IDE, and integrates with [Gemini Code Assist](https://docs.cloud.google.com/gemini/docs/codeassist/overview), an AI-powered collaborator, to simplify development. To learn more about using Gemini Code Assist in Cloud Code, see [Code with Gemini Code Assist](https://docs.cloud.google.com/gemini/docs/codeassist/write-code-gemini). 

Cloud Code gives you the tools to maximize your cloud development productivity. Context switching is reduced through integrations with Google Cloud services like [Google Kubernetes Engine](https://docs.cloud.google.com/kubernetes-engine), [Cloud Run](https://docs.cloud.google.com/run), and [App Engine](https://docs.cloud.google.com/appengine) which are all available in your IDE to support the full development lifecycle.

You can also [browse APIs in your IDE](https://docs.cloud.google.com/code/docs/intellij/client-libraries) with [Cloud APIs](https://docs.cloud.google.com/apis), [protect sensitive information](https://docs.cloud.google.com/code/docs/intellij/secret-manager) with [Secret Manager](https://docs.cloud.google.com/secret-manager), [set up and share repositories of application samples](https://docs.cloud.google.com/code/docs/intellij/set-up-sample-repo), [manage your virtual machine instances](https://docs.cloud.google.com/code/docs/intellij/manage-vms) with [Compute Engine](https://docs.cloud.google.com/compute), and [connect to a SQL database](https://docs.cloud.google.com/code/docs/intellij/connect-sql-database) with [Cloud SQL](https://docs.cloud.google.com/sql).

To learn more about what Cloud Code for IntelliJ has to offer you, see [Cloud Code for IntelliJ features](https://docs.cloud.google.com/code/docs/intellij/features).
