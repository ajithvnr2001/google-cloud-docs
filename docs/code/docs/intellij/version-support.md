#  IntelliJ version support Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Code for IntelliJ supports the three most recent, major IntelliJ versions: the current release, and the previous two releases.

**Note:** Cloud Code support for the IntelliJ EAP is on a best-effort basis. The EAP sometimes introduces breaking changes, and these may take some time to address.

When a new IntelliJ major version is released, the next Cloud Code release supports the new version and drops support for the earliest, previously supported version.
