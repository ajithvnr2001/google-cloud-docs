## Migrate your app from Cloud Code to a local IDE

To migrate your application, follow these steps:

  1. Set up the Cloud Code extension for your IDE.

Cloud Code is available for installation on [VS Code](https://docs.cloud.google.com/code/docs/vscode/install) and [JetBrains IDEs](https://docs.cloud.google.com/code/docs/intellij/install) (IntelliJ Ultimate/Community, PyCharm Professional/Community, WebStorm, and GoLand).

  2. Download the necessary source code by navigating to **File** > **Download**.

Alternatively, you can [commit your source code to a Git repo](https://docs.cloud.google.com/shell/docs/version-control#committing_changes) using the Source Control: Git view from the Activity bar ![Source Control icon](https://docs.cloud.google.com/static/shell/docs/images/version-control-icon.png) or using Git commands in the Cloud Code terminal ![Open terminal icon available from the Cloud Code top menu bar](https://docs.cloud.google.com/static/shell/docs/images/open-terminal-icon.png).

You can now access your workspace from your local IDE using **File** > **Open Workspace** (VS Code)/**Open** (IntelliJ) if you downloaded your Cloud Code workspace, or your local Source Control: Git view, if you committed your source code to a Git repo.
