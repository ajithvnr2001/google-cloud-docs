## File bugs or feature requests

You can click either **Send feedback** link within the Cloud Code documentation. This will open a feedback form. Your comments will be reviewed by the Cloud Code team.

Alternatively, if you are a Cloud Code for IntelliJ user and encounter any bugs, confusing commands, or unclear documentation, or if you'd like to propose a feature idea, you can [file your feedback through GitHub](https://github.com/GoogleCloudPlatform/cloud-code-intellij/issues/new).

## Get support from the community

### Google Developer Program forums

For community-based support, discussions, and to connect with other users and Google staff, your primary destination is [discuss.google.dev](https://discuss.google.dev/c/google-cloud/14). This is the official forum for:

  * **Asking questions.** Get peer-to-peer support for your technical challenges.
  * **Sharing knowledge.** Contribute your expertise and help other members of the community.
  * **Engaging with Google staff.** Discuss with Google Cloud team members and find best practices and tutorials from Google staff.



### Ask a question on Stack Overflow

Ask a question about Cloud Code on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-code). Use the tag `google-cloud-code` for questions about Cloud Code. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Keep up with Google Cloud

  * Read the [Google Cloud blog](https://cloudplatform.googleblog.com/).
  * Follow [@googlecloud](https://twitter.com/googlecloud) on Twitter.



## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).
