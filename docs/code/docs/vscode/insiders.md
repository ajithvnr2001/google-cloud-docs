#  Use pre-release features in Cloud Code for VS Code Stay organized with collections  Save and categorize content based on your preferences. 

You can try pre-release features, provide valuable feedback, and ask Cloud Code for VS Code developers and other users questions by installing pre-release builds and joining the [Cloud Code Insiders group](https://groups.google.com/g/cloud-code-insiders). 

Pre-release builds can include bug fixes and features still in development that can be removed in a future release. Pre-release features are listed on the **Cloud Code - Welcome** page in your IDE. 

## Install Insiders builds

When you select the Insiders channel, new Insiders builds are installed automatically. 

  1. Click ![Manage Icon](https://docs.cloud.google.com/static/code/docs/vscode/images/manage.png)**Manage** > **Settings**. 
  2. Search for **Cloudcode: Update Channel**. 
  3. In the list, choose **Insiders**. 
  4. When prompted, click **Reload** to use the latest Insiders build of Cloud Code.



## Leave the Insiders program

When you select the Default channel, new Insiders builds are no longer installed. You can also remove yourself from the [Cloud Code Insiders group](https://groups.google.com/g/cloud-code-insiders). 

  1. Click ![Manage Icon](https://docs.cloud.google.com/static/code/docs/vscode/images/manage.png)**Manage** > **Settings**. 
  2. Search for **Cloudcode: Update Channel**. 
  3. In the list, choose **Default**. 
  4. When prompted, click **Reload** to use the latest Default build of Cloud Code.



## Turn off a pre-release feature

While a feature is pre-release, you can return to the default behavior by turning the feature off. If the feature becomes generally available, the option to turn it off can go away. 

  1. Click ![Manage Icon](https://docs.cloud.google.com/static/code/docs/vscode/images/manage.png)**Manage** > **Settings**. 
  2. Search for the setting for the feature you want to turn off. For example, **Cloudcode > Beta: Enable One Activity Bar**. 
  3. Clear the checkbox next to the feature name.
