**Error:** The authentication flow did not complete successfully, and your IDE is **not** authorized to access your account.

## Report exceptions

Authentication errors occur for a variety of reasons. We recommend trying to sign in again. If you're working under a hidden proxy in your IDE, check your [VS Code proxy settings](https://code.visualstudio.com/docs/setup/network#_proxy-server-support). If you're still experiencing authentication errors, report the exception to the product team by filing a bug through the IDE.
