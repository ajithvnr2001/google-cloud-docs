If you have additional need for technical support, you have a number of options listed below.

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about the Cloud Natural Language API on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-nl). Please use the tag `google-cloud-nl` for questions about the Cloud Natural Language API. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

  * [Ask a question](http://stackoverflow.com/questions/ask?tags=google-cloud-nl)
  * [See a list of all questions](http://stackoverflow.com/questions/tagged/google-cloud-nl)



### Discuss Cloud Natural Language API and get updates

Join the [cloud-nl-discuss](https://groups.google.com/forum/#!forum/cloud-nl-discuss) Google group to discuss the Cloud Natural Language API and receive Cloud Natural Language API announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud Natural Language API and other Cloud Natural Language API products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Cloud Natural Language API, join the [`#ai-nlp`](https://googlecloud-community.slack.com/messages/CDRVD8UR2/) channel. 

## File bugs or feature requests

From the Cloud Natural Language API documentation, click "Send feedback" near the top right of the page. This will open a feedback form. Your comments will be reviewed by the Cloud Natural Language API team.
