#  Overview of scoped policies Stay organized with collections  Save and categorize content based on your preferences. 

Scoped policies are [access policies](https://docs.cloud.google.com/access-context-manager/docs/overview#access-policies) that are scoped to specific folders or projects alongside an access policy that you can apply to the entire Google Cloud organization. You can use scoped policies to delegate administration of VPC Service Controls perimeters and access levels to folder-level and project-level administrators.

For more information, see [Scoped policies](https://docs.cloud.google.com/access-context-manager/docs/scoped-policies).

You can use Access Context Manager to define fine-grained and attribute-based access control for projects and resources. For more information, see [Overview of Access Context Manager](https://docs.cloud.google.com/access-context-manager/docs/overview).
