# Anti Money Laundering AI documentation

[Read product documentation](https://docs.cloud.google.com/financial-services/anti-money-laundering/docs/concepts/overview)

Google Cloud's Anti Money Laundering AI (AML AI) product is an API that scores AML risk. Use it to identify more risk, more defensibly, with fewer false positives and reduced time per review. 

The [AML AI product video](https://youtu.be/3yJ6DCVQjWA?si=fe6ohx8u9teiQYwL) describes how our risk scoring method surpasses other rule-based solutions to provide superior protection.
