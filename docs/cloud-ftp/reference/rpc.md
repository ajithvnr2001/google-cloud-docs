#  Cloud FTP API Stay organized with collections  Save and categorize content based on your preferences. 

A managed, cloud-native solution to move data in and out of Google Cloud by using SSH File Transfer Protocol (SFTP).

## Service: ftp.googleapis.com

The Service name `ftp.googleapis.com` is needed to create RPC client stubs.

## `[google.cloud.ftp.v1.CloudFtp](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp)`

Methods  
---  
``[CreateServer](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.CreateServer)`` |  Creates a new Server in a given project and location.  
``[CreateUser](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.CreateUser)`` |  Creates a new User in a given project and location and Server.  
``[DeleteServer](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.DeleteServer)`` |  Deletes a single Server.  
``[DeleteUser](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.DeleteUser)`` |  Deletes a single User.  
``[GetServer](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.GetServer)`` |  Gets details of a single Server.  
``[GetUser](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.GetUser)`` |  Gets details of a single User.  
``[ListServers](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.ListServers)`` |  Lists Servers in a given project and location.  
``[ListUsers](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.ListUsers)`` |  Lists Users in a given project and location.  
``[StartServer](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.StartServer)`` |  Starts a stopping/stopped Server.  
``[StopServer](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.StopServer)`` |  Stops an active Server.  
``[UpdateServer](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.UpdateServer)`` |  Updates the parameters of a single Server.  
``[UpdateUser](https://docs.cloud.google.com/cloud-ftp/reference/rpc/google.cloud.ftp.v1#google.cloud.ftp.v1.CloudFtp.UpdateUser)`` |  Updates the parameters of a single User.
