The following table shows the SFTP clients that are supported by Cloud FTP, and the types of private SSH keys that each client supports. For detailed steps to install and use each client, see the relevant third-party documentation.

Client | Supported versions | SSH key formats  
---|---|---  
Cyberduck | 7.9.0 or later | PEM, PPK  
FileZilla | 3.56.0 or later | PEM, PPK  
OpenSSH (`sftp` commands) | 7.4 or later | PEM  
PuTTY | 0.76 or later | PPK  
WinSCP | 5.19.2 or later | PPK, PEM (WinSCP converts the key to PPK)
