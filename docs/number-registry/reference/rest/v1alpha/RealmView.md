`REALM_VIEW_UNSPECIFIED` | Unspecified view. Defaults to BASIC.  
`BASIC` | Basic view.  
`FULL` | Full view. Includes the same data as the BASIC view.  
`AGGREGATE` | Aggregate includes data about the child resources of the Realm.
