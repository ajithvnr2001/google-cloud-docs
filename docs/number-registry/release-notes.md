## September 16, 2026

Breaking

You must [designate a project to manage Cloud Number Registry](https://docs.cloud.google.com/number-registry/designate-project-cloud-number-registry) before you can [set up Cloud Number Registry](https://docs.cloud.google.com/number-registry/set-up-cloud-number-registry) for an organization.
