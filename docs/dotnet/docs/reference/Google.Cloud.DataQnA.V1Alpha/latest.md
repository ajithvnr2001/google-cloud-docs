# Google.Cloud.DataQnA.V1Alpha

`Google.Cloud.DataQnA.V1Alpha` is a.NET client library for the [Data QnA API](https://cloud.google.com/bigquery/docs/dataqna).

The DataQnA API is officially deprecated.

The Google.Cloud.DataQnA.V1Alpha package is delisted from NuGet, and the source code removed from the google-cloud-dotnet repository. Any projects that depend on the package will still be able to restore that dependency, but the package won't be shown in search results on [nuget.org](https://www.nuget.org/).
