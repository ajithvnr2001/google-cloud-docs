### EffectiveTags
    
    
    public RepeatedField<Tag> EffectiveTags { get; }

The effective tags inherited from the [attached_resource][google.cloud.asset.v1.EffectiveTagDetails.attached_resource]. Note that tags with the same key but different values may attach to resources at a different hierarchy levels. The lower hierarchy tag value will overwrite the higher hierarchy tag value of the same tag key. In this case, the tag value at the higher hierarchy level will be removed. For more information, see [tag inheritance](https://cloud.google.com/resource-manager/docs/tags/tags-overview#inheritance).
