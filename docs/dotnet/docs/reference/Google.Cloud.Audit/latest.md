# Google.Cloud.Audit

`Google.Cloud.Audit` is a.NET client library for the [Google Cloud Audit API](https://cloud.google.com/logging/docs/audit).

Note: This documentation is for version `2.6.0` of the library. Some samples may not work with other versions.

## Installation

Install the `Google.Cloud.Audit` package from NuGet. Add it to your project in the normal way (for example by right-clicking on the project in Visual Studio and choosing "Manage NuGet Packages...").
