## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Managed Airflow on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-composer). Use the tag `google-cloud-composer` for questions about Managed Airflow. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Managed Airflow

Join the [cloud-composer-discuss](https://groups.google.com/forum/#!forum/cloud-composer-discuss) Google group to discuss Managed Airflow and receive Managed Airflow announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Managed Airflow and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Managed Airflow, join the [`#composer`](https://googlecloud-community.slack.com/messages/C7DGV8DGQ/) channel. 

## File bugs or feature requests

To provide feedback to the Managed Service for Apache Airflow team, click the **Send feedback** button on any [Managed Airflow documentation](https://docs.cloud.google.com/composer/docs) page.

To file a bug or a feature request, use the Managed Airflow [Issue Tracker](https://docs.cloud.google.com/support/docs/issue-trackers).
