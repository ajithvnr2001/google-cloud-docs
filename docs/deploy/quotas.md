#  Quotas and limits Stay organized with collections  Save and categorize content based on your preferences. 

This page contains usage quota and limits that apply when using Cloud Deploy.

Cloud Deploy has no quotas on delivery pipelines or other resources. The only quota enforced on Cloud Deploy is the system limit of 18,000 API requests per minute per region.

However, there are quotas for the [related underlying services](https://cloud.google.com/deploy/pricing#underlying) that Cloud Deploy relies on.

You can see quotas for all Google Cloud on the Quotas page in Google Cloud console.

[Go to Quotas](https://console.cloud.google.com/iam-admin/quotas)

For more information, see the [Cloud Quotas documentation](https://docs.cloud.google.com/docs/quotas/overview).
