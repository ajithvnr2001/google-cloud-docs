This page describes how to view [platform logs](https://docs.cloud.google.com/logging/docs/api/platform-logs) generated by Cloud Deploy. Platform logs in Google Cloud are service-specific logs, which you can use to debug and troubleshoot issues, and better understand the Google Cloud services you're using.

Cloud Deploy generates logs for the following events:

  * Release render state changes to in-progress, succeeded, and failed

  * Rollout state changes to in-progress, succeeded, failed, halted, canceling, and canceled

  * Rollout state changes to pending [approval](https://docs.cloud.google.com/deploy/docs/promote-release#manage_approvals_for_a_delivery_pipeline), approved, and rejected

  * [Phase advancement](https://docs.cloud.google.com/deploy/docs/deployment-strategies/manage-rollout#advance_rollout) in rollouts, including phases that have been advanced, and phases that are waiting for advancement

  * Violation or override of a [deploy policy](https://docs.cloud.google.com/deploy/docs/deploy-policy).

  * Failure to send a Pub/Sub notification for a status change, for the following resource types:

    * delivery pipelines
    * targets
    * releases
    * rollouts
    * job runs
    * deploy policies



## Access the platform logs generated by Cloud Deploy

  1. Open the Google Cloud Observability [Logs Explorer page](https://docs.cloud.google.com/logging/docs/view/logs-explorer-interface) in Google Cloud console.

  2. In the [query pane](https://docs.cloud.google.com/logging/docs/view/logs-explorer-interface#query-builder), click the **Log name** drop-down, and enter the **Log ID** of the platform log you want to see.

You can get the Log ID from the [list in the platform logs page](https://docs.cloud.google.com/logging/docs/api/platform-logs#cloud_deploy).

![The log name filter, in the Logs Explorer](https://docs.cloud.google.com/static/deploy/images/logs-explorer-filter.png)

  3. Select that log, and click **Apply**.

Available logs are listed in the **Query results**.

![Query results for Google
Cloud Deploy platform logs](https://docs.cloud.google.com/static/deploy/images/logs-explorer-results.png)

  4. To view the contents of that log, click the arrow next to any log listed in the query results.

![Contents of a
Google Cloud Deploy platform log](https://docs.cloud.google.com/static/deploy/images/release-render-log-contents.png)
