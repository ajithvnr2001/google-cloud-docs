In addition to deploying to any of the supported target types, (Google Kubernetes Engine, Cloud Run, GKE attached clusters), you can use Cloud Deploy to deploy to custom targets.

A custom target is a Cloud Deploy target that deploys to a runtime or an output that is not one of the standard, supported target types.

The article [About custom targets](https://docs.cloud.google.com/deploy/docs/custom-targets) describes custom targets and how you can use them in a Cloud Deploy delivery pipeline.
