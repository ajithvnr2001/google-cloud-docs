# Managed Service for Apache Spark  |  Google Cloud Documentation

> Source: https://docs.cloud.google.com/managed-spark/docs/support/billing-questions/

"Managed Service for Apache Spark" is the new name for the product formerly known as "Dataproc on Compute Engine" (cluster deployment) and "Google Cloud Serverless for Apache Spark" (serverless deployment).

# Billing resources

Use the following resources to get help with billing questions:

  * [Read the Cloud Billing documentation](https://docs.cloud.google.com/billing/docs)
  * [Use the billing concerns troubleshooter](https://support.google.com/cloud/troubleshooter/7279311)
  * [Enable, disable, or change billing for a project](https://docs.cloud.google.com/billing/docs/how-to/modify-project).  If you disable billing for a project, you also disable all product resources in that project.
  * [Get billing support](https://docs.cloud.google.com/support/docs/get-billing-support)
