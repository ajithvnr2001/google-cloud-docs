## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

**To try a Managed Service for Apache Spark[Private Preview](https://cloud.google.com/products#product-launch-stages) feature:** You can contact your Google Cloud Sales representative to have your project(s) added to an allowlist for a specific feature.

## Get support from the community

**Ask a question on Stack Overflow** : Ask a question about Managed Service for Apache Spark on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-dataproc). Use the tag `google-cloud-dataproc` for questions about Managed Service for Apache Spark. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

** Discuss Managed Service for Apache Spark **; Join the [cloud-dataproc-discuss](https://groups.google.com/forum/#!forum/cloud-dataproc-discuss) Google group to discuss Managed Service for Apache Spark and receive Managed Service for Apache Spark announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Managed Service for Apache Spark and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). ## File bugs or feature requests

We welcome your feedback, which you can send to [dataproc-feedback@google.com](mailto:dataproc-feedback@google.com). If you are reporting a bug or error, please include the following information in your message:

  * What happened? What did you expect to happen?
  * How can we reproduce the problem?
  * provide any additional information.



You can also use the Google Cloud [IssueTracker](https://docs.cloud.google.com/support/docs/issue-trackers#search_for_or_create_bugs_and_feature_requests_by_product) to search Managed Service for Apache Spark issues and file a bug or feature request.
