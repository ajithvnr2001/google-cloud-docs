#  Managed Service for Apache Spark templates Stay organized with collections  Save and categorize content based on your preferences. 

To set up and run Managed Service for Apache Spark workloads and jobs, use [Managed Service for Apache Spark templates on GitHub](https://github.com/GoogleCloudPlatform/dataproc-templates)

Templates are provided in the following language and execution environments:

  * [Airflow orchestration templates](https://github.com/GoogleCloudPlatform/dataproc-templates/tree/main/airflow): Run Spark jobs from DAGs in Airflow.
  * [Java templates](https://github.com/GoogleCloudPlatform/dataproc-templates/tree/main/java): Run Spark batch workloads or jobs on Managed Service for Apache Spark or an existing Managed Service for Apache Spark cluster.
  * [Python templates](https://github.com/GoogleCloudPlatform/dataproc-templates/tree/main/python): Run PySpark batch workloads on Managed Service for Apache Spark.
  * [Notebook templates](https://github.com/GoogleCloudPlatform/dataproc-templates/tree/main/notebooks): Run Spark jobs using Vertex AI notebooks.
