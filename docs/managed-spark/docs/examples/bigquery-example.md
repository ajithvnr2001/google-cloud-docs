#  BigQuery connector code samples Stay organized with collections  Save and categorize content based on your preferences. 

All Managed Service for Apache Spark clusters come with the [BigQuery connector for Hadoop](https://github.com/GoogleCloudDataproc/hadoop-connectors) built in. This means you can quickly read and write BigQuery data to and from Managed Service for Apache Spark.

## Use Spark

See [Using the BigQuery Connector with Spark](https://docs.cloud.google.com/managed-spark/docs/tutorials/bigquery-connector-spark-example) for an example on using Spark with the BigQuery connector for Hadoop. This example should work for Managed Service for Apache Spark clusters.

## Use Java MapReduce

See [Writing a MapReduce Job with the BigQuery Connector](https://docs.cloud.google.com/managed-spark/docs/tutorials/bigquery-connector-mapreduce-example) for an example on using Java MapReduce with the BigQuery connector for Hadoop. This example should work for Managed Service for Apache Spark clusters.

## Additional information

See the [BigQuery Hadoop Connector](https://docs.cloud.google.com/managed-spark/docs/connectors/bigquery) documentation.
