In addition to using the [Managed Service for Apache Spark APIs](https://docs.cloud.google.com/managed-spark/docs/reference) or the [Managed Service for Apache Spark in the Google Cloud console](https://console.cloud.google.com/dataproc/overview), you can access Managed Service for Apache Spark using gcloud CLI's `gcloud dataproc` commands.

## Install the gcloud CLI

To use the Google Cloud CLI, install the gcloud CLI by following the instructions at [installation and quick start](https://docs.cloud.google.com/sdk/docs/quickstarts).

## gcloud dataproc reference

Go to the [`gcloud dataproc`](https://docs.cloud.google.com/sdk/gcloud/reference/dataproc) reference page to learn how to use `gcloud dataproc` commands.
