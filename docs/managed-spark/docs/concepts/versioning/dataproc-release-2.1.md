**Notes:**

  1. [`2.1.x-*-arm images`](https://docs.cloud.google.com/managed-spark/docs/concepts/compute/supported-machine-types#arm_machine_types) support only the installed components and the following optional components (the remaining 2.1 optional components and all initialization actions are unsupported): 
     * Apache Hive WebHCat
     * Apache Pig (starting with `2.1.107-ubuntu20-arm`)
     * Docker
     * Zeppelin: Supported only by 2.1.77+-ubuntu20-arm images.
     * Zookeeper (installed in [HA clusters](https://docs.cloud.google.com/managed-spark/docs/concepts/configuring-clusters/high-availability); optional component in non-HA clusters)
  2. Apache Hive installations on Managed Service for Apache Spark clusters include [HCatalog](https://cwiki.apache.org/confluence/display/Hive/HCatalog), but do not include [Hive WebHCat](https://cwiki.apache.org/confluence/display/Hive/WebHCat) (see the [Hive WebHCat Optional Component](https://docs.cloud.google.com/managed-spark/docs/concepts/components/hivewebhcat) to install Hive WebHCat on a cluster).
  3. The [Presto Optional Component](https://docs.cloud.google.com/managed-spark/docs/concepts/components/presto) is available as [Trino Optional Component](https://docs.cloud.google.com/managed-spark/docs/concepts/components/trino) in 2.1 and later image versions.
  4. The HBase and Druid components are not supported in 2.1 and later image versions.
  5. The source code to image 2.1 libraries that are licensed under Reciprocal and Restricted licenses is available at the `/usr/local/share/google/managed-spark/third-party-sources` filepath on Managed Service for Apache Spark cluster VMs.

  6. The `2.1.117`, `2.1.119` and later image versions [do not have preconfigured Conda channels](https://docs.cloud.google.com/managed-spark/docs/release-notes#June_22_2026). Packages can't be installed using Conda unless channels are manually configured during cluster initialization. Also, `2.1` image version clusters that have preconfigured Conda channels, including `2.1.118` and earlier image versions but excluding `2.1.117`, can't be used after August 25, 2026.

     * **You may need to delete and replace existing clusters**. After August 25, 2026, existing clusters that were created with images that have pre-configured Conda channels, even if cluster jobs don't use Conda to install packages, must be deleted and replaced with new clusters [created](https://docs.cloud.google.com/managed-spark/docs/guides/create-cluster#creating_a_cloud_dataproc_cluster) or [recreated](https://docs.cloud.google.com/managed-spark/docs/guides/recreate-cluster#recreate_and_update_a_cluster_2) with images that don't have preconfigured Conda channels.
