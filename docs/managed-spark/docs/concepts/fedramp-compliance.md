Managed Service for Apache Spark is certified to support FedRAMP High and FedRAMP Moderate compliance. This document describes the requirements for using Managed Service for Apache Spark in a FedRAMP-compliant manner.

## About Managed Service for Apache Spark FedRAMP compliance

Managed Service for Apache Spark is certified under FedRAMP High and FedRAMP Moderate. This certification applies to [Managed Service for Apache Spark version 2.3](https://docs.cloud.google.com/managed-spark/docs/concepts/versioning/dataproc-release-2.3) and later.

FedRAMP compliance applies only to [installed components](https://docs.cloud.google.com/managed-spark/docs/concepts/versioning/dataproc-release-2.3). Optional components or components installed through initialization actions aren't covered under FedRAMP compliance.

To use Managed Service for Apache Spark in alignment with FedRAMP Moderate or High levels hosting, you must use Assured Workloads and Assured Support (High only).

**Note:** FedRAMP compliance doesn't apply to any deprecated or [unsupported images](https://docs.cloud.google.com/managed-spark/docs/concepts/versioning/dataproc-version-clusters#unsupported-dataproc-image-versions)

## Maintain Managed Service for Apache Spark FedRAMP compliance

Maintain FedRAMP compliance by updating your clusters to use Managed Service for Apache Spark image version 2.3 or later.
