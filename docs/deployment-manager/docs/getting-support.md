## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Ask a question on Stack Overflow

Ask a question about Deployment Manager on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-deployment-manager). Use the tag `google-deployment-manager` for questions about Deployment Manager. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

## Discuss Deployment Manager

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Deployment Manager and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Deployment Manager, join the [`#deployment-manager`](https://googlecloud-community.slack.com/messages/C48GEKY9Z/) channel. 

## File bugs or feature requests

From the Deployment Manager documentation, click "Send feedback" near the top right of the page. This will open a feedback form. Your comments will be reviewed by the Deployment Manager team.
