#  Manage Cloud Billing support cases Stay organized with collections  Save and categorize content based on your preferences. 

You can track billing inquiries and review correspondence with Cloud Customer Care in the Google Cloud console. This helps you resolve invoicing, payment, and account questions while maintaining a record of communications.

To view and update cases, you must have the [Billing Account Administrator](https://docs.cloud.google.com/billing/docs/how-to/billing-access#overview-of-cloud-billing-roles-in-cloud-iam) role. For more information, see [Get Cloud Billing support](https://docs.cloud.google.com/support/docs/get-billing-support).

  1. In the Google Cloud console, go to the **Billing support cases** page.

[Go to Billing support cases](https://console.cloud.google.com/billing/support/cases)

  2. In the **Billing account** list, select a billing account to go to its support cases page.

  3. You can use the filter_list **Filter** to filter the list of displayed support cases.

  4. To view or update a support case, click the case title.

  5. If the support case is open, you can add comments, upload file attachments, or edit case attributes.

  6. If the support case has been closed less than 15 days, you can reopen it. Otherwise, you can [create a new support case](https://docs.cloud.google.com/support/docs/customer-care-procedures).
