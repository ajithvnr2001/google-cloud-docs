**Note:** Use of this Preview offering of Gemini Cloud Assist is subject to the Google Cloud Agreement, including the Pre-GA Offering Terms of the [Google Cloud Specific Service Terms](https://cloud.google.com/terms/service-terms), as supplemented by the terms for the [Gemini for Google Cloud Trusted Tester Program](https://cloud.google.com/trusted-tester/gemini-for-google-cloud-preview).

[Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/overview) provides AI-powered assistance that can help you troubleshoot an issue or create a support case.

Gemini Cloud Assist investigations can help you understand, diagnose, and resolve issues, providing a root-cause analysis of your infrastructure and applications in Google Cloud. With investigations, you can reduce the time to resolution and improve your overall system availability. For more information, see [Troubleshoot issues with Cloud Assist Investigations](https://docs.cloud.google.com/cloud-assist/investigations).

You can escalate investigations or complex issues by connecting directly with Google Cloud support and providing investigation results as context in a support case. Gemini Cloud Assist streamlines the support experience by summarizing environment states and logs, and will automatically pre-fill support case fields with information from your chat conversation. For more information, see [Get support using Gemini Cloud Assist](https://docs.cloud.google.com/support/docs/get-support-using-cloud-assist).
