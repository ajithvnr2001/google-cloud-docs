This page lists the API references, client libraries, and other developer resources for _borderless Lakehouse_.

**Note:** Google Cloud's _Lakehouse_ is powered by the BigLake API. To maintain backward compatibility for existing workloads, the underlying programmatic surface retains its original naming. When using the Google Cloud CLI, REST APIs, or client libraries, you will continue to use the `biglake` service name, endpoints, and commands.
