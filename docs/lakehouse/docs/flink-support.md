#  Use Apache Flink with the Lakehouse runtime catalog Stay organized with collections  Save and categorize content based on your preferences. 

Apache Flink connects to _borderless Lakehouse_ through the _Lakehouse runtime catalog_. This integration uses the _Apache Iceberg REST catalog_ endpoint to provide a standard interface for discovering and managing tables.

For configuration details, see the official [Apache Iceberg Flink documentation](https://iceberg.apache.org/docs/latest/flink/).
