#  Generate data insights for Lakehouse catalog tables Stay organized with collections  Save and categorize content based on your preferences. 

_Borderless Lakehouse_ supports AI-powered data insights through _Knowledge Catalog_. Data insights help you accelerate data exploration by automatically generating descriptions, relationship graphs, and SQL queries for your Apache Iceberg, Apache Hive, and SAP BDC tables.

For step-by-step instructions on generating insights for Apache Iceberg tables managed by Lakehouse, see [Generate insights for Apache Iceberg tables](https://docs.cloud.google.com/dataplex/docs/use-data-insights-structured-data#insights-iceberg-rest-catalog).
