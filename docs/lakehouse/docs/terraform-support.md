#  Use Terraform with borderless Lakehouse Stay organized with collections  Save and categorize content based on your preferences. 

_Borderless Lakehouse_ supports infrastructure management through Terraform. The Terraform Google Provider provisions resources within the _Lakehouse runtime catalog_ , including the _Apache Iceberg REST catalog_ endpoint.

For configuration details, see the official [Terraform Registry documentation for biglake_iceberg_catalog](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/biglake_iceberg_catalog).
