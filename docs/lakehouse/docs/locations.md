## Multi-regions

The following table lists the multi-regions where Lakehouse is available:

**Multi-region description** | **Multi-region name**  
---|---  
Data centers within [member states of the European Union](https://european-union.europa.eu/principles-countries-history/eu-countries_en) 1 | `EU`  
Data centers in the United States2 | `US`  
**Note:** Selecting a multi-region location doesn't provide cross-region replication or regional redundancy, so there is no increase in dataset availability in the event of a regional outage. Data is stored in a single region within the geographic location.

1 Data located in the `EU` multi-region is only stored in one of the following locations: `europe-west1` (Belgium) or `europe-west4` (Netherlands). The exact location in which the data is stored and processed is determined automatically by Lakehouse.

2 Data located in the `US` multi-region is only stored in one of the following locations: `us-central1` (Iowa) or `us-west1` (Oregon). The exact location in which the data is stored and processed is determined automatically by Lakehouse.
