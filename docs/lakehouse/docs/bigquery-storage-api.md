#  BigQuery Storage Write API (gRPC) Stay organized with collections  Save and categorize content based on your preferences. 

You can use the BigQuery Storage Write API (gRPC) to stream data into borderless Lakehouse. Using the BigQuery Storage Write API (gRPC) for Google Cloud's Lakehouse is only applicable if you are using [Apache Iceberg managed tables (formerly BigLake tables for Apache Iceberg in BigQuery)](https://docs.cloud.google.com/bigquery/docs/biglake-iceberg-tables-in-bigquery).

The BigQuery Storage Write API (gRPC) is a high-performance, unified data ingestion API that provides exactly-once delivery and stream-level transactions. It also supports advanced features like time-unit column partitioning and schema evolution, making it ideal for maintaining organized and efficient storage layouts in your data lake.
