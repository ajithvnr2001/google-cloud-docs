# Looker Block for Salesforce Sales Cloud

This page describes the insights you can get from the Cortex Looker Block for Salesforce Sales Cloud data. Using this Looker Block for Salesforce Sales Cloud, you can gain faster insights into your sales activities, trends, engagement, account management and more, based on the Salesforce data from Cortex Framework Data Foundation.

## Available insights

The Looker block for Salesforce Sales Cloud in Cortex Framework offers the following predefined high-level dashboard samples:

  1. **Leads Capture and Conversion** : Understand leads generated from marketing activities, current status, and how quickly sales are converting to opportunities. From this high-level dashboard, you can drill to the pertinent details in the Leads Capture Conversion Detailed Report.
  2. **Opportunity Trends and Pipeline** : Identify open opportunities and their current stage, which are likely to close and how well sales teams are converting to wins. From this high-level dashboard, you can drill to the pertinent details in the Opportunity Trends and Pipeline Detailed Report.
  3. **Sales Activities and Engagement** : Highlight leads and opportunities which need immediate follow up and understand overall engagement trends across sales. From this high-level dashboard you can drill into pertinent details with these granular reports: 
     * Lead follow ups detailed report.
     * Opportunity activities detailed report.
     * Overdue opportunities detailed report.
  4. **Case Overview and Trends** : Understand overall customer service position across all open cases and case trends.
  5. **Case Management and Resolution** : Get a pulse check on how efficient the service team is at case resolution and highlight any long running open cases for prioritization.
  6. **Accounts with Cases** : Identify which accounts have open cases and which need immediate focus.



## Repository

To access the Cortex Looker Block for Salesforce Sales Cloud, visit its official GitHub repository: [**block-cortex-salesforce**](https://github.com/looker-open-source/block-cortex-salesforce). This repository contains essential LookML files, components, models, views, Explores, and dashboards that enable you to seamlessly integrate Salesforce data into your Looker environment. This repository provides a solid foundation for creating custom reports, visualizations, and dashboards tailored to your specific needs.

For instructions about how to deploy the Looker Block from Cortex Framework for Salesforce Sales Cloud, see [Deploy Looker Blocks for Cortex Framework](https://docs.cloud.google.com/cortex/docs/v6/looker-block-deployment).
