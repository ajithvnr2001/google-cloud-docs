# Demo deployment

This page describes how to quickly get started with a demo instance of the Cortex Framework Data Foundation in Cloud Shell. This demo automatically sets up BigQuery datasets, grants necessary permissions, and includes sample test data.

**Caution:** This demo deployment is not suitable for production environments. For production deployments, see [Cortex Framework Data Foundation prerequisites](https://docs.cloud.google.com/cortex/docs/v6/deployment-prerequisites).

Start your demo with the following instructions:

  1. Click the following button to open Cloud Shell:

[Cloud Shell](https://shell.cloud.google.com/cloudshell/?terminal=true&show=terminal&cloudshell_git_repo=https%3A%2F%2Fgithub.com%2FGoogleCloudPlatform%2Fcortex-data-foundation&cloudshell_tutorial=docs%2Ftutorial.md)

  2. Follow the rest of the steps directly within Cloud Shell.




## What's next?

  * For a technical overview of Cortex Framework Data Foundation, see [Workloads and data sources](https://docs.cloud.google.com/cortex/docs/v6/data-sources-and-workloads).
  * For information about the deployment in production environments, start with the [prerequisites](https://docs.cloud.google.com/cortex/docs/v6/deployment-prerequisites) of the Cortex Framework Data Foundation.
