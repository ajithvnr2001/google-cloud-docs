# Looker Block for YouTube (with DV360)

This page describes the insights you can get from the Cortex Looker Block for YouTube (with DV360). With this Looker Block for YouTube (with DV360), you can get a comprehensive overview of your campaign spend, performance, and audience targeting with actionable insights for paid media campaigns on YouTube purchased using DV360 platform.

Jumpstart your paid media marketing analytics for YouTube by ingesting your campaign data into BigQuery with pre-packaged ingestion pipelines and reporting views provided by Cortex Framework for Marketing.

Install this Looker Model for YouTube to gain insights on cost, impressions, click and view rates, key audience targeting and engagement metrics. Enhance visualizations with more granular metrics like creative (ad level), demographics and YouTube placement.

You can also extend to insights beyond Marketing with other datasets in the Cortex Framework that provide reporting views for enterprise data sources like your enterprise CRM or ERP systems.

## Available insights

The Looker block for YouTube (with DV360) in Cortex Framework offers the following insights.

### Overall campaign performance

Overview of high-level campaign performance and engagement metrics including:

  * Total impressions
  * Total clicks
  * Total TrueView views
  * Click through rate (CTR)
  * TrueView VR (TrueView View Rate)
  * Total Spend
  * Cost per Mille (CPM)
  * Cost per click (CPC)
  * Cost per TrueView (CPV)



### Performance and spend by month

  * **Impressions by month** : Understand detailed performance metrics and cost for YouTube campaigns by line item.
  * **Cumulative monthly spend** : Understand cumulative YouTube campaign spend over a month.



### Campaigns carried out and performance

  * **YouTube line items in chronological view** : See a chronological view of all the YouTube campaigns you ran in a specific period per line item.
  * **Impressions, TrueView views and Clicks by YouTube Line Item** : Understand detailed performance metrics and cost for YouTube campaigns by line item.
  * **Impressions by Device Type and YouTube Line Item** : Understand performance metrics for YouTube campaigns by device type by line item.
  * **Detailed Performance by YouTube Line Item** : Understand detailed performance metrics and cost for YouTube campaigns by line item.



### Performance by audience and ad format

  * **Impressions and TrueView views:** Understand performance and cost by the following parameters: 
    * Age Group and Gender
    * Audience Segment Type
    * YouTube Ad Format

### Other Considerations

For optimizing the performance and functionality of your Looker Block for YouTube (with DV360) consider the following:

  * **Liquid Templating Language** : Some constants, views, Explores and dashboards use liquid templating language. For more information, see Looker's [Liquid Variable Reference](https://docs.cloud.google.com/looker/docs/liquid-variable-reference) documentation.
  * **Unhide additional dimensions and measures** : Many dimensions and measures are hidden for simplicity. If you find anything valuable missing, set field's `hidden` parameter value to `No` in the relevant views.
