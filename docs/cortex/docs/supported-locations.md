# Supported locations for demo deployment

This section outlines the supported geographic locations for BigQuery datasets and Dataform repositories for the **Cortex Framework demo deployment**.

**Note:** For optimal performance and to avoid cross-region data transfer costs, ensure your Dataform region matches the region of your BigQuery datasets.

## Supported BigQuery locations

The following table contains the supported geographic locations for BigQuery datasets within the Cortex Framework demo deployment.

Region group | Location IDs  
---|---  
**Multi-Regional** | `us`, `eu`  
**Americas** |  `us-east5`, `us-south1`, `us-central1`, `us-west4`, `us-west2`, `northamerica-northeast1`, `us-east4`, `us-west1`, `us-west3`, `southamerica-east1`, `southamerica-west1`, `us-east1`, `northamerica-northeast2`, `northamerica-south1`  
**Europe** |  `europe-west1`, `europe-north1`, `europe-north2`, `europe-west3`, `europe-west2`, `europe-southwest1`, `europe-west8`, `europe-west4`, `europe-west9`, `europe-west12`, `europe-central2`, `europe-west6`, `europe-west10`  
**Asia Pacific** |  `asia-south2`, `asia-east2`, `asia-southeast2`, `australia-southeast2`, `asia-south1`, `asia-northeast2`, `asia-northeast3`, `asia-southeast1`, `australia-southeast1`, `asia-east1`, `asia-northeast1`  
**Middle East & Africa** | `me-central1`, `me-west1`, `africa-south1`
