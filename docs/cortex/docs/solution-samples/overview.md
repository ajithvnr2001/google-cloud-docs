# Solution samples overview

Cortex Framework solution samples provide an opinionated approach and sample code to help you get started quickly to address specific business scenarios. Solution sample business logic is built on Cortex Framework [data foundation](https://docs.cloud.google.com/cortex/docs/data-foundation) or [data products](https://docs.cloud.google.com/cortex/docs/data-product). Compared to standard data products, solution samples require additional implementation effort to become production-ready.

## Key characteristics

  * **What they include:** Samples typically feature reference architectures, sample code snippets, or deployable code that extends Cortex Framework data foundation or data products.
  * **Implementation:** Given their highly variable nature across customer production environments, they are intended as a starting point and a reference for customers to adjust based on their specific requirements.



## What's available

The following [consumption data product](https://docs.cloud.google.com/cortex/docs/data-product#key_concepts) samples are available for SAP ERP or SAP BDC sourced data. 

  * [Sales Performance Insights](https://docs.cloud.google.com/cortex/docs/solution-samples/sales-performance-insights)
  * [Supplier Spend Analysis](https://docs.cloud.google.com/cortex/docs/solution-samples/supplier-spend-analysis)
