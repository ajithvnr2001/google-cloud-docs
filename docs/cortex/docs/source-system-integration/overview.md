# Source system integration

Cortex Framework supports flexible integration paths to connect your source data with analytical capabilities. Depending on your [data architecture](https://docs.cloud.google.com/cortex/docs/overview#data_architecture), you can replicate data directly into BigQuery or federate queries to external catalogs with zero data copy.

Select one of the following integration guides to learn more:

  * **[SAP ERP](https://docs.cloud.google.com/cortex/docs/source-system-integration/sap-erp)** : Learn how to prepare and replicate data from SAP ECC or SAP S/4HANA into the BigQuery raw layer.
  * **[SAP Business Data Cloud](https://docs.cloud.google.com/cortex/docs/source-system-integration/sap-bdc)** : Discover how to query data products managed inside SAP BDC directly in BigQuery with zero copy overhead.
