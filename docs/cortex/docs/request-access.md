# Request access

Cortex Framework version 7 is in **public preview**. This page describes the steps to request access to the repository.

  1. **Prerequisites** : Ensure you have a valid GitHub account.
  2. **Submit the request** : Complete and submit the Cortex Framework 7 [Access request form](https://forms.gle/WZQzo3r5GPyy5mHQA).
  3. **Verification process** : The Cortex Framework team will review your request; we aim to provide a response within 24 to 48 business hours.
  4. **Get the invitation** : Monitor your inbox for an invitation from GitHub to access the private repository.

**Note:** If you have not received the invitation within 48 hours, check your spam or junk folder.
