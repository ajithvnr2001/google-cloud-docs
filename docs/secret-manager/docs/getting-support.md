## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Discuss Secret Manager

You can visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Secret Manager and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

## File bugs or feature requests

To file a bug or a feature request, you can use the [Issue Tracker](https://issuetracker.google.com/issues/new?component=784854). Use the component **Public Trackers > Cloud Platform > Identity & Security > Secret Manager** for questions about Secret Manager. Note that this is a **public** component, and other users will be able to see what you have filed. This content will be reviewed by Google engineers, who monitor the component.
