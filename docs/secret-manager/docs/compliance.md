Secret Manager meets the following compliance standards:

  * [CJIS](https://cloud.google.com/security/compliance/cjis)
  * [FedRAMP Moderate and FedRAMP High](https://cloud.google.com/security/compliance/fedramp)
  * [HIPAA](https://cloud.google.com/security/compliance/hipaa-compliance)
  * [HITRUST CSF](https://cloud.google.com/security/compliance/hitrust)
  * [DoD IL2, IL4, and IL5 PAs](https://cloud.google.com/security/compliance/disa)
  * [ITAR](https://cloud.google.com/security/compliance/itar)
  * [IRS 1075](https://cloud.google.com/security/compliance/irs1075)
  * [EU GDPR](https://cloud.google.com/privacy/gdpr)
  * [Privacy Protection Authority (Israel)](https://cloud.google.com/security/compliance/israel-ppa)
  * [Class C license (Kingdom of Saudi Arabia)](https://cloud.google.com/security/compliance/ksa)



You can read more about Google Cloud compliance at the [Compliance resource center](https://cloud.google.com/security/compliance/).
