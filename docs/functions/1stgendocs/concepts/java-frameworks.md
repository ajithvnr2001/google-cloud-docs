# Java Frameworks

In addition to [Functions Framework for Java](https://github.com/GoogleCloudPlatform/functions-framework-java), the [Micronaut framework](https://micronaut-projects.github.io/micronaut-gcp/2.0.x/guide/#simpleFunctions), [Spring Cloud Run function project](https://spring.io/projects/spring-cloud-function), and [Quarkus](https://quarkus.io/guides/gcp-functions) now have out-of-the-box support for Cloud Run functions. You can create both HTTP and event-driven functions using the frameworks' programming models, including capabilities such as dependency injection.

## Spring Cloud Run functions

You can write a function using [Spring Cloud Run functions](https://spring.io/projects/spring-cloud-function#overview), and deploy it to Java using the Cloud Run functions adapter. For details, see the [Spring Cloud documentation](https://docs.spring.io/spring-cloud-function/docs/current/reference/html/spring-cloud-function.html). Also see the [Spring Cloud Run functions sample](https://github.com/spring-cloud/spring-cloud-function/tree/master/spring-cloud-function-samples/function-sample-gcp-http/).

## Micronaut

You can write a function using [Micronaut](https://micronaut-projects.github.io/micronaut-gcp/2.0.x/guide/#introduction), and deploy it to Java using Micronaut's Cloud Run functions support. For details, see the [Micronaut documentation](https://micronaut-projects.github.io/micronaut-gcp/2.0.x/guide/#cloudFunction).

## Quarkus

You can write a function using [Quarkus](https://quarkus.io/), and deploy it to Cloud Run functions using Quarkus Cloud Run functions support. For details, see the [Quarkus documentation](https://quarkus.io/guides/gcp-functions).
