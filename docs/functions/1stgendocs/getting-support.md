## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

Ask a question about Cloud Run functions on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-functions). Use the tag `google-cloud-functions` for questions about Cloud Run functions. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

You can also explore [community tutorials](https://docs.cloud.google.com/community/tutorials?q=%22Cloud%20Functions%22).

## Discuss Cloud Run functions

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud Run functions and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Cloud Run functions, join the [`#functions`](https://googlecloud-community.slack.com/messages/C1D2F6GRF/) channel. 

## File bugs or feature requests

If you believe you have found a legitimate bug, the [Public Issue Tracker](https://issuetracker.google.com/issues?q=status:open%20componentid:187195) is the place to report it. Doing so will alert a member of our support and/or development team to the issue. While the primary purpose of this channel is bug reporting, it is also possible to submit feature requests here as well.

## Beta tester group

The [Cloud Run functions Beta Tester group](https://groups.google.com/forum/#!forum/cloud-functions-beta-testers) is a forum for answering developers' technical questions about Cloud Run functions. It is largely community-driven, with answers provided by other users. Google Support, as well as product and engineering teams, may participate in the conversation when an official answer is needed. Please [join the group](https://groups.google.com/forum/#!forum/cloud-functions-beta-testers) to post a new question and to help out your fellow beta users as they get started with Cloud Run functions.

The Beta Tester group is also where you'll hear about the newest Cloud Run functions features as they're developed. As always, we welcome general feature requests and suggestions via this group, and will relay them directly to our development team.
