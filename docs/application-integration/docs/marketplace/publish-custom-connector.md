# Submit a publish request

This page describes how you can submit a request to publish a custom connector to Google Cloud Marketplace.

## Before you begin

As a partner, ensure that you have completed the following tasks: 

  * Registered as a partner in Marketplace.
  * Created a custom connector that you want to publish to the Marketplace.
  * Submitted the Virtual Machine (VM) image and set the pricing for the Marketplace connector.



## Submit a request to publish the Marketplace connector

  1. Navigate to the **Custom connectors** page in Application Integration or Integration Connectors. 
     * In the [Google Cloud console](https://console.cloud.google.com/), go to the **Integration Connectors > Custom connectors** page, and then select or create a Google Cloud project.

[Go to the Custom connectors page](https://console.cloud.google.com/connectors/custom-connectors)

     * In the [Google Cloud console](https://console.cloud.google.com/), go to the **Application Integration > Marketplace connectors** page, and then select or create a Google Cloud project. 

[Go to the Custom connectors page](https://console.cloud.google.com/integrations/custom-connectors)

  2. Click **Submit for publishing** from the **Custom connectors** tab or from the **Marketplace connectors** tab.
  3. In the confirmation dialog that appears, click **Yes, I am a registered partner** to confirm that you have registered as a partner.
  4. The **Publish a custom connector** page appears. In the **Terms & Conditions** section, do the following: 
     1. Select **Yes, I agree** to agree to the terms of service of Google Cloud Platform and Google Cloud Marketplace.
     2. Select **Yes, I confirm** to confirm that your connector meets all partner connector publishing and onboarding requirements.
     3. Click **Next**.
  5. In the **Connectors details** section, do the following: 
     1. In the **Select a custom connector** list, select the custom connector that you want to publish.
     2. Select the custom connector version to publish. To view the version details of a custom connector, click the information icon corresponding to the connector version.
     3. Specify the following connector details: 
        * **Company name (Partner company name)** : the name of the company that owns the connector.
        * **Marketplace product Google Cloud project ID** : the ID of the VM image project.
        * **Marketplace product ID** : the ID of the VM image.
        * **Marketplace product name** : the name of the VM image.
        * **Target application** : the application to which the connector connects. 
        * **Details of connector use cases** : typical use cases for the connector.
        * **Target customer segment** : the customer segment for which the connector is built.
     4. Click **Next**.
  6. In the **Demo submission** section, specify the following details: 
     * **Demo with a screencast of connector operations** : submit a demo that illustrates key functionalities of the connector and how your connector works in Application Integration.
     * **Template of end-to-end use cases** : submit a template in JSON format that illustrates how to use the connector in an integration.
     * **Additional comments** : mention that this connector is developed for Application Integration.
  7. Click **Next**.
  8. Click **Create** to initiate the publishing request.
  9. A confirmation message appears. Click **Ok** to acknowledge the message. You can view the status of the publishing request on the **Marketplace connectors** tab.



## Edit a publish request

As a partner, you can edit a publish request before the connector is published. To edit a publish request, do the following:

  1. In the [Google Cloud console](https://console.cloud.google.com/), go to the **Integration Connectors > Custom connectors** page, and then select or create a Google Cloud project. 

[Go to the Custom connectors page](https://console.cloud.google.com/connectors/custom-connectors)

  2. From the **Custom connectors** page, click the **Marketplace connectors** tab.
  3. In the **My published connectors** section, select the action menu corresponding to the connector that you want to edit.
  4. Click **Edit**.
  5. Make the required edits.
  6. Click **Create** to initiate the publishing request.



## Delete a publish request

As a partner, you can delete a publish request before the connector is published. To delete a publish request, do the following:

  1. In the [Google Cloud console](https://console.cloud.google.com/), go to the **Integration Connectors > Custom connectors** page, and then select or create a Google Cloud project. 

[Go to the Custom connectors page](https://console.cloud.google.com/connectors/custom-connectors)

  2. From the **Custom connectors** page, click the **Marketplace connectors** tab.
  3. In the **My published connectors** section, select the action menu corresponding to the connector that you want to delete.
  4. Click **Delete**.
