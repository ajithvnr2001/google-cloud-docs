# Application Integration and ADK

[Agent Development Kit](https://google.github.io/adk-docs/#what-is-agent-development-kit) (ADK) is a framework for developing and deploying AI agents. ADK agents can use various tools, including Application Integration workflows, to enhance their functionality. This document describes ADK's integration with Application Integration and federated search.

## Application Integration tools

ADK agents use Application Integration workflows as tools to securely access and interact with enterprise applications such as CRM, ERP, and databases. Integrating ADK with Application Integration transforms standard process automations into agentic workflows. The agent intelligently decides when and how to execute these workflows to achieve specific goals.

For information about using Application Integration workflows as tools for ADK agents, see [Application Integration tools](https://google.github.io/adk-docs/tools/google-cloud-tools/#application-integration-tools).

## Federated search

[Federated search](https://google.github.io/adk-docs/tools/google-cloud-tools/#application-integration-tools) within Application Integration enables ADK agents to query multiple enterprise applications and data sources simultaneously. This provides a single, uniform way to gather comprehensive information, eliminating the need to manually query each siloed system. For example, an agent can simultaneously query a CRM system for a customer's recent support tickets, a loyalty program database for their status, and an e-commerce platform for their order history. This unified view enables powerful automation tasks.
