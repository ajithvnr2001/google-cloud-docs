# GET_INTEGRATION_REGION function

## `GET_INTEGRATION_REGION` function

Function Name | Description | Usage | Input parameter | Return value  
---|---|---|---|---  
`GET_INTEGRATION_REGION` | Returns the region of the current integration. | `GET_INTEGRATION_REGION()` | N/A | A string
