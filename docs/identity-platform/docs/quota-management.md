#  Manage quotas and limits 

You can track and manage quotas for your projects in the Google Cloud console.

Tracking your project's API usage helps you avoid reaching operational limits, helping you maintain availability of your application. Additionally, setting limits for operations based on your application's use case can increase efficiency and keep operational costs low.

To track quotas and limits for your project, do the following:

  1. In the Google Cloud console, go to the **APIs & Services** page.

[ Go to APIs & Services](https://console.cloud.google.com/apis)

  2. Select the API you want to monitor quotas for. For example, **Identity Toolkit API**.

  3. Click **Metrics** to view your project's current API usage.




To configure quota limits, do the following:

  1. In the Google Cloud console, go the **APIs & Services** page.

[ Go to APIs & Services](https://console.cloud.google.com/apis)

  2. Select the API you want to submit a change request for. For example, **Identity Toolkit API**.

  3. Click **Quotas**.

  4. Select the operation you want to edit, then click **Edit quotas**. You can select multiple operations to edit at a time.

  5. Enter a number within the limits set for the operation.

  6. Click **Submit request** to update the operation's quota.
