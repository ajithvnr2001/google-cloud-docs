# Integrating with Google Cloud Platform services and tools  |  Cloud Source Repositories  |  Google Cloud Documentation

> Source: https://docs.cloud.google.com/source-repositories/docs/integration-overview/

Effective June 17, 2024, Cloud Source Repositories isn't available to new customers. For alternative source hosting options, [Secure Source Manager](https://cloud.google.com/secure-source-manager/docs) is a regionally deployed, single tenant, managed source code repository hosted on Google Cloud.

If your organization hasn't previously used Cloud Source Repositories, you can't enable the API or use Cloud Source Repositories. New projects not connected to an organization can't enable the Cloud Source Repositories API. Organizations that have used Cloud Source Repositories prior to June 17, 2024 are not affected by this change.

This page describes other Google Cloud products that integrate with Cloud Source Repositories.

## App Engine

Learn how to deploy your code from Cloud Source Repositories to App Engine.

[How-to](https://docs.cloud.google.com/source-repositories/docs/integrating-with-app-engine)

## Pub/Sub

Build integrations between Cloud Source Repositories and other systems using Pub/Sub.

[How-to](https://docs.cloud.google.com/source-repositories/docs/configuring-notifications)

## Cloud Run functions

Use Cloud Source Repositories to version control the code that contains your function.

[How-to](https://docs.cloud.google.com/source-repositories/docs/deploying-functions-from-source-repositories)

## Cloud Build

Use Cloud Build to automatically deploy an application stored in Cloud Source Repositories to App Engine when there is a new commit.

[How-to](https://docs.cloud.google.com/source-repositories/docs/integrating-with-cloud-build)

## Development Tools

Add extensions to your development tools for fast access to your Cloud Source Repositories buckets and objects within them.

[IntelliJ](https://docs.cloud.google.com/code/docs/intellij/vcs)
