#  Overview Stay organized with collections  Save and categorize content based on your preferences. 

The Gemini Cloud Assist API, in conjunction with the Cloud AI Companion API, provides generative AI-powered assistance to a wide range of Google Cloud users, including developers and data scientists. The Gemini Cloud Assist API provides resources and methods for Gemini Cloud Assist, including for the investigations feature, which offers troubleshooting and support for many Google Cloud products.

API reference documentation for Gemini Cloud Assist can be found at <https://docs.cloud.google.com/cloud-assist/reference/rest>.

If you want to learn more about Gemini Cloud Assist generally, see [Gemini Cloud Assist overview](https://docs.cloud.google.com/cloud-assist/overview).

If you want to explore the Cloud AI Companion API, see the [Cloud AI Companion API reference documentation](https://docs.cloud.google.com/gemini/docs/api/reference/rest).
