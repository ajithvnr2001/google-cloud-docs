#  Configure administrator settings Stay organized with collections  Save and categorize content based on your preferences. 

Administrator settings let you control how Gemini Cloud Assist interacts with your data and resources. Customizing these settings helps you align features like proactive agents with your organization's operational and compliance requirements.

Setting name | Setting default  
---|---  
[Grounding](https://docs.cloud.google.com/cloud-assist/configure-grounding) | Grounding with Google Search  
[Page context sharing](https://docs.cloud.google.com/cloud-assist/chat-panel#page-context-sharing) | Enabled  
[Prompt and response sharing](https://docs.cloud.google.com/cloud-assist/configure-prompt-response-sharing) | Disabled  
[Proactive agents](https://docs.cloud.google.com/cloud-assist/proactive-agents-concepts) | Disabled  
[Custom instructions](https://docs.cloud.google.com/cloud-assist/custom-instructions) | None
