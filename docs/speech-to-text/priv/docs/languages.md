#  On-Prem language support Stay organized with collections  Save and categorize content based on your preferences. 

**Private feature**  
This product is a private feature. The documentation is publicly available but you must [contact Google](https://cloud.google.com/contact) for full access. 

This page lists all languages supported by Cloud Speech-to-Text On-Prem. Language is specified within a recognition request's [`languageCode`](https://docs.cloud.google.com/speech-to-text/priv/docs/reference/rpc/google.cloud.speech.v1p1beta1#google.cloud.speech.v1p1beta1.RecognitionConfig) parameter.

Some language models are supported by one or more additional features, which are indicated in the table below:

  * [Automatic punctuation](https://docs.cloud.google.com/speech-to-text/docs/automatic-punctuation)
  * [Speech adaptation boost (Beta)](https://docs.cloud.google.com/speech-to-text/docs/speech-adaptation#using_boost_adaptation)

---|---|---|---  
English (United States) | en_US | ✔ | ✔
