**Private feature**  
This product is a private feature. The documentation is publicly available but you must [contact Google](https://cloud.google.com/contact) for full access. 

Cloud Speech-to-Text offers the following features that are available to trusted testers only. The documentation is publicly available, but you must [contact Google](https://cloud.google.com/contact) to gain access to the features.

Cloud Speech-to-Text On-Prem integrates Google speech recognition technologies into your on-premises solution. The Cloud STT On-Prem solution gives you control over your infrastructure and protected speech data in order to meet data residency and compliance requirements.   


See the [Cloud Speech-to-Text On-Prem documentation](https://docs.cloud.google.com/speech-to-text/priv/docs).
