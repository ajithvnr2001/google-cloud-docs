Google works continuously to improve its products, including the use of customer data to refine those products where customers have opted in.

By default, Cloud Speech-to-Text does not log customer audio data or transcripts. However, to help Cloud Speech-to-Text better suit your needs, you can opt into the _data logging_ program. This program allows Google to use logged customer data to refine and improve the service quality of Cloud STT — and in exchange, you gain access to discounted [pricing](https://cloud.google.com/speech-to-text/pricing).

## Data privacy and security

When you opt into the _data logging_ program, Google does not log customer data: Google only uses the data sent to Cloud STT on the project with data logging enabled. You can continue to use other Google Cloud projects without data logging enabled. Google only uses the data that you send to those projects as needed to provide the service.

You continue to maintain full ownership of all data that you upload to a project with data logging enabled. However, Google retains ownership of the models trained from that data. For more details about the terms and conditions for data logging, see the [terms for opt-in for data logging](https://docs.cloud.google.com/speech-to-text/docs/v1/data-logging-terms).

Only a limited set of authorized Google employees and contractors have access to customer data collected using data logging, and Google uses this data solely to train and improve Google products and services. Google does not use customer data or any personally identifiable information contained in logged customer data to target products, services, or advertising towards customers or customers' users.

**Note:** Your data collected through data logging enjoys the same level of security as all other Google Cloud services. The Google security model is an end-to-end process, built over 15 years of experience protecting users and customer, and focused on keeping users and customers safe on Google applications like Gmail, Search and other Apps.**Caution** Your logged data is not deleted when you delete your project. Fill out the [deletion request form](https://goo.gl/forms/yneKSdt2QfhCSBbL2) to request to have your data deleted. 

For more information about Google's security policies, see [the Google Cloud security whitepaper](https://cloud.google.com/security/whitepaper).

  * Review the [terms of opting in for data logging](https://docs.cloud.google.com/speech-to-text/docs/v1/data-logging-terms).
