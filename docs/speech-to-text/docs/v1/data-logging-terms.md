Customer should select the Disable Option for a Project if Customer no longer wants data logged from that specific Project (**note** : any Customer Training Data logged from a Project prior to the selection of the Disable Option for that Project will continue to be retained by Google, and logging of Customer Training Data will continue for any other Projects where the data logging option remains enabled).
