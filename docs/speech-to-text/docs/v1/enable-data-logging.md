This page describes how to enable [data logging](https://docs.cloud.google.com/speech-to-text/docs/v1/data-logging) for Cloud Speech-to-Text on a Google Cloud project.

When you enable data logging, you permit Google to collect data from your audio transcription requests. Google then uses this data to improve its machine learning models used for recognizing speech audio.

**Note:** Before enabling data logging you need to certify that you have the proper permissions from the data originator(s), and that you haven't entered into a BAA with Google, for HIPAA purposes as an example. See the complete [terms for opt-in for data logging](https://docs.cloud.google.com/speech-to-text/docs/data-logging-terms) for details.

As a benefit when you enroll in data logging, you can receive discount [pricing](https://docs.cloud.google.com/speech-to-text/pricing).

## Enroll in data logging

To enroll your Google Cloud Platform project in data logging, follow these steps:

  1. Go to your project settings for the Cloud Speech-to-Text in the [Google Cloud Platform Dashboard](https://console.cloud.google.com/apis/api/speech.googleapis.com/).
  2. In the navigation, click **APIs & Services > Dashboard**.
  3. Select **Cloud Speech API** from the list of APIs enabled for the project.
  4. Select the **Data logging** tab in the left-side menu.
  5. Click **Enable data logging**.



## Disable data logging

You can disable data logging for your project at any time. Review the [terms for opt-in](https://docs.cloud.google.com/speech-to-text/docs/data-logging-terms) to read about what happens to your data when you disable data logging for a project.

To discontinue data logging for your Google Cloud Platform project, follow these steps:

  1. Go to your project settings for the Cloud Speech-to-Text in the [Google Cloud Platform Dashboard](https://console.cloud.google.com/apis/api/speech.googleapis.com/).
  2. In the navigation, click **APIs & Services > Dashboard**.
  3. Select **Cloud Speech API** from the list of APIs enabled for the project.
  4. Select the **Data logging** tab in the left-side menu.
  5. Click **Disable data logging**.



## What's next
