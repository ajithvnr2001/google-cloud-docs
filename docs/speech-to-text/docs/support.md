This page offers suggestions on how to get the results you expect from Cloud Speech-to-Text, and what to do if you need support to help you get the answers you need.

## Use the Speech UI to experiment with different configuration options

The Cloud Speech-to-Text API has a powerful [Speech UI](https://console.cloud.google.com/speech) that lets you upload audio files into your own Cloud Storage workspace. You can experiment with different configurations and settings to help improve transcription quality for your specific use cases.

## Ask a question on Stack Overflow

Ask a question about the Cloud Speech-to-Text API on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-speech). Use the tag `google-cloud-speech` for questions about the Cloud Speech-to-Text API. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

  * [Ask a question](http://stackoverflow.com/questions/ask?tags=google-cloud-speech)
  * [See a list of all questions](http://stackoverflow.com/questions/tagged/google-cloud-speech)



## Discuss the Cloud Speech API and get updates

Join the [cloud-speech-discuss](https://groups.google.com/forum/#!forum/cloud-speech-discuss/join) Google group to discuss the Cloud Speech-to-Text API and receive Cloud Speech-to-Text API announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud Speech-to-Text API and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Cloud Speech-to-Text API, join the [`#speech`](https://googlecloud-community.slack.com/messages/C1TK22QTE/) channel. 

## How to get effective support

When asking for support, especially around transcription quality, it is important to provide multiple audio samples so that we can reproduce the issue. Without a small dataset (about 5 audio samples with expected transcriptions) it is difficult to troubleshoot the issues or to generalize a bugfix.

In general, the more information you provide the greater chance that the Cloud Speech-to-Text API team will be able to find issues or configuration options to help you get the best out of Cloud Speech-to-Text API.

## Get a support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Support](https://cloud.google.com/support).

## File bugs or feature requests

To file a bug or a feature request, use [the public issue tracker](https://issuetracker.google.com/issues/new?component=187181&template=0).
