## Japanese Yomigana

Japanese pronunciations must be specified using yomigana, for example:
    
    
    <phoneme alphabet="yomigana" ph="ちゅう">中</phoneme>
    <phoneme alphabet="yomigana" ph="なか">中</phoneme>
    

The pronunciation can also contain pitch accents. The start of a pitch phrase is specified with `^` and the down-pitch position is specified with `!`, for example:
    
    
    <phoneme alphabet="yomigana" ph="^はし">端</phoneme>
    <phoneme alphabet="yomigana" ph="^は!し">箸</phoneme>
    <phoneme alphabet="yomigana" ph="^はし!">橋</phoneme>
    

Vowel elongation is performed automatically, for example `<phoneme alphabet="yomigana" phoneme="じょおう">女王</phoneme>` will be correctly pronounced as じょおー (not じょーう).

Compound words are allowed, and segmentation is performed automatically.

Both katakana and hiragana are allowed.
