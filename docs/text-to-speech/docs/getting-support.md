This page offers suggestions on how to get the results you expect from Cloud Text-to-Speech, and what to do if you need support to help you get the answers you need.

If you have additional need for technical support, you have a number of options listed below.

## Ask a question on Stack Overflow

Ask a question about the Cloud Text-to-Speech API on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-text-to-speech). Please use the tag `google-text-to-speech` for questions about the Cloud Text-to-Speech API. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

  * [Ask a question](http://stackoverflow.com/questions/ask?tags=google-text-to-speech)
  * [See a list of all questions](http://stackoverflow.com/questions/tagged/google-text-to-speech)



## Discuss the Cloud Text-to-Speech API and get updates

Join the [Google Cloud Developers](https://groups.google.com/forum/#!forum/google-cloud-dev) Google group to discuss the Cloud Text-to-Speech API and receive Cloud Text-to-Speech API announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud Text-to-Speech API and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

## Get a support package

Google Cloud Platform offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Platform Support](https://docs.cloud.google.com/support).
