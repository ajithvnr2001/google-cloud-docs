**Warning:** Custom Voice isn't onboarding new customers. Try out [instant custom voice](https://docs.cloud.google.com/text-to-speech/docs/chirp3-instant-custom-voice) instead.

Cloud Text-to-Speech now offers the Custom Voice feature. Custom Voice allows you to train a custom voice model using your own studio-quality audio recordings to create a unique voice. You can use your custom voice to synthesize audio using the Cloud Text-to-Speech API.
