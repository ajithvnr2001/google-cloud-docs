#  Compatible OS versions Stay organized with collections  Save and categorize content based on your preferences. 

This page lists the OS versions that have been tested and verified as compatible with Managed Service for Microsoft Active Directory for different Active Directory features. OS versions other than those listed are also expected to work, but have not been tested. 

## Compatible Windows versions for joining a domain

You can join an instance that's running Windows Server, Windows 10, or Windows 11 to a Managed Microsoft AD domain. The following Windows versions are compatible and have been tested and verified. However, note that this list isn't an exhaustive list of all compatible versions.

  * Windows Server 2016
  * Windows Server 2019
  * Windows Server 2022
  * Windows Server 2025
  * Windows 10 (version 1909 or later)
  * Windows 11



Learn [how to join a Windows VM to a domain](https://docs.cloud.google.com/managed-microsoft-ad/docs/quickstart-domain-join-windows).

## Compatible Linux versions for joining a domain

You can join an instance that is running Linux to a Managed Microsoft AD domain. The following Linux versions are compatible and have been tested and verified. However, note that this list isn't an exhaustive list of all compatible versions.

  * Ubuntu 22.04 LTS or later
  * Red Hat Enterprise Linux (RHEL) 8 or later



Learn [how to join a Linux VM to a domain](https://docs.cloud.google.com/managed-microsoft-ad/docs/quickstart-domain-join-linux).

## Compatible Windows versions for creating a trust

You can create a trust relationship between a Managed Microsoft AD domain and on-premises domains running on Windows operating systems. The following Windows Server versions are compatible and have been tested and verified. However, note that this list isn't an exhaustive list of all compatible versions.

  * Windows Server 2016
  * Windows Server 2019
  * Windows Server 2022
  * Windows Server 2025



Learn [how to create a trust](https://docs.cloud.google.com/managed-microsoft-ad/docs/create-trust).

## Domain and forest functional levels

The domain functional level (DFL) and forest functional level (FFL) of Managed Microsoft AD domains that you create after December 9, 2019 is Windows Server 2012 R2. Learn more about [Windows Server 2012 R2 DFL/FFL](https://learn.microsoft.com/en-us/windows-server/identity/ad-ds/active-directory-functional-levels#windows-server-2012-r2-functional-levels). The DFL and FFL of domains that you created before December 9, 2019 is Windows Server 2012.
