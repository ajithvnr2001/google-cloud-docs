#  View connected Cloud SQL for SQL Server instances Stay organized with collections  Save and categorize content based on your preferences. 

This topic shows you how to view the Cloud SQL for SQL Server instances that are integrated with a Managed Service for Microsoft Active Directory domain. Learn about [using Managed Microsoft AD with Cloud SQL for SQL Server](https://docs.cloud.google.com/sql/docs/sqlserver/configure-ad).

## Viewing integrations

**Note:** Integrations are only visible in the Google Cloud console when one or more integrations exist. If no SQL integrations have been previously configured in your domain, the **Integrations** tab is not visible.

  1. Go to the [Managed Microsoft AD](https://console.cloud.google.com/security/cloud-ad) page in the Google Cloud console.   
[Go to the Managed Microsoft AD page](https://console.cloud.google.com/security/cloud-ad)
  2. On the **Managed Microsoft AD** page, select the domain that you want to view the integrated Cloud SQL for SQL Server instances for.
  3. On **Domain** page, select the **Integrations** tab.
  4. On the **Integrations** tab, the **SQL Integrations** table lists the SQL instances connected to the domain, their project IDs, and the date and time of their integrations.
  5. To visit the **Overview** page for a SQL instance, select its name in the **SQL Integrations** table.
