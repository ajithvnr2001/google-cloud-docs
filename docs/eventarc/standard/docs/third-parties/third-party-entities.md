**Preview — Third-party events in Eventarc**

This feature is subject to the "Pre-GA Offerings Terms" in the General Service Terms section of the [Service Specific Terms](https://docs.cloud.google.com/terms/service-terms#1). Pre-GA features are available "as is" and might have limited support. For more information, see the [launch stage descriptions](https://cloud.google.com/products/#product-launch-stages). 

Eventarc is a platform for sourcing, delivering, and managing events. As a marketplace for events, Eventarc provides you with a catalog of events offered by Google Cloud as well as those offered by third-party vendors.

The following third-party vendors currently offer a source available for use in Eventarc.

**Note:** Eventarc is a fully managed platform for building event-driven systems and supports the ability for approved third-party vendors to generate events. The event sources are offered to you by the third-party vendor.

## Third-party SaaS providers

The following third-party vendors operate SaaS platforms that can send events to Eventarc's publishing API. Access to the customer's project is granted through a setup process that uses a one-time activation code, providing you with a simple and robust integration.

## Third-party self-hosted providers (custom events)

In addition to the preceding Eventarc sources, other third-party providers leverage Eventarc's publishing API to send custom events to the customer project. Authorized access is accomplished using service accounts provided by the customer and setup is handled by the provider service.

**Note:** Google Cloud documentation is provided for convenience only and does not substitute for that of the provider. Custom event integrations are handled by the specific provider and their documentation should be consulted for the most accurate and current details.
