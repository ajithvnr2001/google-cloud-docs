Eventarc lets you build decoupled, event-driven architectures by routing events from cloud services and external systems to downstream consumers. The supported event providers and target destinations depend on whether you use Eventarc Advanced or Eventarc Standard.

## Eventarc Advanced

Events are delivered from an event provider or source to an Eventarc Advanced bus and through an Eventarc Advanced pipeline to a specified event destination. For more information, see [Event providers and destinations](https://docs.cloud.google.com/eventarc/advanced/docs/event-providers-targets).

## Eventarc Standard

Supported events are routed from an event provider (the source) to an event destination (the target), also known as the event consumer or receiver. For more information, see [Event providers and destinations](https://docs.cloud.google.com/eventarc/standard/docs/event-providers-targets).
