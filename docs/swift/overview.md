#  Swift on Google Cloud overview Stay organized with collections  Save and categorize content based on your preferences. 

The Google Cloud Swift SDK lets you build, manage, and scale server-side backend services on Google Cloud using the Swift programming language. Whether you're building microservices on Linux or managing full-stack cloud applications, the Google Cloud Swift client libraries provide idiomatic Swift packages for interacting with Google Cloud services.

## Why Swift on Google Cloud

Features and benefits of the Swift SDK include:

  * **Developer efficiency** : Use a single language across your application architecture and eliminate context-switching between different programming languages.

  * **Full-stack development** : Frontend teams can apply their existing Swift expertise to author, deploy, and support backend services. By pairing the Google Cloud SDK with the Firebase SDK for Apple platforms, you can manage both your mobile frontend and cloud backend with Swift.

  * **Performance and safety** : Swift is a modern, strongly-typed language that offers high performance and memory safety, suitable for performance-critical server-side workloads and secure system programming.

  * **Streamlined package management** : Add Google Cloud client libraries directly to your projects using Swift Package Manager (SPM). Authenticate seamlessly using Application Default Credentials (ADC), Service Account keys, and metadata-server authentication for containerized environments.




## Choose your Swift SDK

Google provides two distinct Swift SDKs to serve different development needs:

Feature | Firebase Apple SDKs | Google Cloud Server-Side Swift SDK  
---|---|---  
Primary use | Client-side mobile and web development. | Backend server-side infrastructure.  
Environment | Apple client ecosystem, such as iOS or watchOS. | Deploy on server environments, such as Linux. Develop on Linux or macOS.  
Authentication | User-based authentication and security rules. | Service accounts, Application Default Credentials (ADC), and Workload Identity Federation.  
Service scope | Mobile-centric tools, such as Analytics or Firestore. | 140+ Google Cloud APIs (such as Cloud Storage, Google Kubernetes Engine (GKE), or Compute Engine).
