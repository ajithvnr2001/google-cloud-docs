#  In-band integration partner providers Stay organized with collections  Save and categorize content based on your preferences. 

The following third-party partners provide virtual network security appliances and solutions that support In-band integration (Packet Intercept) in Network Security Integration.

These partner solutions enable inline threat prevention, Layer 7 deep packet inspection, and advanced firewall security controls for your Virtual Private Cloud (VPC) networks without changing existing routing configurations.

**Partner** | **Description** | **Resources**  
---|---|---  
[![Palo Alto Networks](https://docs.cloud.google.com/static/network-security-integration/images/logos/panw_logo.png)](https://paloaltonetworks.com/) |  Palo Alto Networks VM-Series virtual firewalls support Packet Intercept in Network Security Integration to inspect inline network traffic and protect your Google Cloud workloads against advanced threats without modifying network routes. |  [Deployment guide](https://docs.paloaltonetworks.com/vm-series/deployment/public-cloud/set-up-the-vm-series-firewall-on-google-cloud-platform/configure-gcp-nsi-overlay-support) [Demo video](https://youtu.be/s2MJ5WDk8y8) [Tutorial on GitHub](https://github.com/PaloAltoNetworks/google-cloud-nsi-tutorial)  
[![Fortinet](https://docs.cloud.google.com/static/network-security-integration/images/logos/fortinet_logo.png)](https://www.fortinet.com/) |  Fortinet FortiGate-VM supports Packet Intercept in Network Security Integration to inspect inline network traffic and deliver deep packet inspection, intrusion prevention, and advanced threat protection for your Google Cloud workloads. |  [Deployment guide](https://docs.fortinet.com/document/fortigate-public-cloud/7.6.0/gcp-administration-guide/677907/network-security-integration-inband-with-fortigate-vm) [Demo video](https://www.youtube.com/watch?v=sOBF_Y-VSTA) [Terraform module on GitHub](https://github.com/fortinet/network-security-integration-in-band/blob/pre-prod/README.md)
