#  Feature migrations Stay organized with collections  Save and categorize content based on your preferences. 

The following table lists **current** Google Cloud Marketplace feature migrations. If applicable, the table includes related shutdown schedules:

Migration | Start Date | Details  
---|---|---  
Upgrade Google Cloud Private Marketplace's enforcement capabilities  | March 26, 2025  | Starting March 26, 2025, Google Cloud Private Marketplace can block new API deployments of [supported products](https://docs.cloud.google.com/marketplace/docs/governance/private-marketplace#supported-products) that aren't in a shared collection. After March 26, 2025, if you turn on Google Cloud Private Marketplace for the first time, it blocks these deployments by default. However, if you've previously turned on Google Cloud Private Marketplace at any point, you must upgrade Google Cloud Private Marketplace to ensure that it properly blocks API deployments of unapproved products. For more information, see [Upgrade Google Cloud Private Marketplace's enforcement capabilities](https://docs.cloud.google.com/marketplace/docs/migrations/private-marketplace-api-enforcement).
