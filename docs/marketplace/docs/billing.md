When you get products from Google Cloud Marketplace, you're charged separately for those products and for the Google Cloud resources that you use. For Google Cloud Marketplace products that are free to use, you only pay the standard usage fees for the Google Cloud resources that you run the products on. For information about how you're charged for your usage of Google Cloud, see [Google Cloud pricing](https://cloud.google.com/pricing).

Your charges for Cloud Marketplace products appear as separate items in your [Cloud Billing reports](https://docs.cloud.google.com/billing/docs/reports) and [exported Cloud Billing data from BigQuery](https://docs.cloud.google.com/billing/docs/how-to/export-data-bigquery). Sometimes the charges are linked to one of your Google Cloud projects, and other times they're only linked to your Cloud Billing account.

## How you're charged for software

Vendors offering Cloud Marketplace products choose how they set up their products' pricing plans. Depending on the type of product, you might be charged subscription fees, usage fees, or a combination of the two. For more information about the types of pricing plans available for Cloud Marketplace products, see [Pricing plans by product type](https://docs.cloud.google.com/marketplace/docs/billing/pricing-plans-by-product-type). You can see the available pricing for each Cloud Marketplace product on its listing page.

Vendors can create private offers that let you purchase their products at a discount. When you get a product from a private offer, you see the pricing in the offer before you accept it. For more information about accepting private offers for Cloud Marketplace products, see [Accept a private offer from a vendor](https://docs.cloud.google.com/marketplace/docs/offers/accepting-private-offer).

### Charges for Cloud Monitoring in VM products

Some virtual machine (VM) products from Cloud Marketplace might include Cloud Monitoring, which collects metrics, events, and metadata from your deployment. If you surpass the free usage allotment for Cloud Monitoring, you're charged for using it. For information about Monitoring pricing, see [Monitoring pricing](https://cloud.google.com/stackdriver/pricing).

If you don't want to use Monitoring, you must turn off the Monitoring agent. For instructions, see [Manage logging and monitoring for your deployment](https://docs.cloud.google.com/marketplace/docs/manage-deployments#managing_logging_and_monitoring_for_your_deployment).
