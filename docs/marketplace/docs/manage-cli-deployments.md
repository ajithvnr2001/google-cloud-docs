#  Manage CLI deployments of VM products Stay organized with collections  Save and categorize content based on your preferences. 

Some virtual machine (VM) products on Google Cloud Marketplace support deployment through the command-line interface (CLI) using [Terraform](https://www.terraform.io/), an open-source tool for provisioning and managing infrastructure. For more information on Terraform, visit [Get started with Terraform](https://docs.cloud.google.com/docs/terraform/get-started-with-terraform).

This page describes the steps for managing existing CLI deployments of Cloud Marketplace VM products. For information on deploying Cloud Marketplace VM products through the CLI, visit [Deploy VM products using the CLI](https://docs.cloud.google.com/marketplace/docs/deploy-through-CLI).

## View your current CLI deployments of a VM product

To view your existing CLI deployments of a Cloud Marketplace VM product:

###  Console 

In the Google Cloud console, go to the **VM instances** page:

[Go to VM instances](https://console.cloud.google.com/compute/instances)

The **VM instances** page shows you all of your VM instances, including any instances you deployed through the CLI.

###  Marketplace 

  1. In Google Cloud Marketplace, visit the product listing page for the VM product you deployed.

[Go to Marketplace](https://console.cloud.google.com/marketplace)

  2. [Visit the **Command-line deployment** tab](https://docs.cloud.google.com/marketplace/docs/deploy-through-CLI#visit-tab) for the product.

  3. To view your running instances of the product in Compute Engine, click the link to Compute Engine.

  4. In the window that appears, click **View running instances**. You see all of your Compute Engine instances, including any VM instances you deployed through the CLI.
