#  Create multiple orders of the same product Stay organized with collections  Save and categorize content based on your preferences. 

This document explains how to create multiple orders of the same product for the same Cloud Billing account.

Before you start creating new offers, make sure that you have opted in for the [multiple orders](https://docs.cloud.google.com/marketplace/docs/partners/offers/multiple-offers) feature.

## Create offers for multiple orders of the same product

To create offers for multiple orders of the same product, follow these steps:

  1. [Go to the direct link to the Producer Portal and start creating a private offer.](https://docs.cloud.google.com/marketplace/docs/partners/offers/create-private-offers#create-offer)

  2. [Add customer and sales contact details.](https://docs.cloud.google.com/marketplace/docs/partners/offers/add-offer-details#add_customer_and_sales_contact_details)

  3. [Add the Cloud Billing account and product details.](https://docs.cloud.google.com/marketplace/docs/partners/offers/set-up-pricing-model#enter-account-and-product-details)

When you select the product, the **Offer title** section shows information about the other orders on this product.

  4. Click **View All** to view all the existing orders for the billing account and product.

  5. [Configure pricing and payment details.](https://docs.cloud.google.com/marketplace/docs/partners/offers/set-up-pricing-model#enter-account-and-product-details)

  6. [Specify your end user license agreement (EULA).](https://docs.cloud.google.com/marketplace/docs/partners/offers/select-eula)

  7. [Review and publish your offer.](https://docs.cloud.google.com/marketplace/docs/partners/offers/review-offer)




You can continue to [accept and approve the order](https://docs.cloud.google.com/marketplace/docs/partners/offers/approve-offer) for your customers to start using the product.

## Amend an existing order

If you want to amend an existing order that isn't yet accepted, follow these steps:

  1. Complete the steps 1 through 4 of the Create offers for multiple orders of the same product process.

  2. [Configure pricing and payment details.](https://docs.cloud.google.com/marketplace/docs/partners/offers/set-up-pricing-model#enter-account-and-product-details)

When you select the product for which an existing order exist, an **Amend existing order** dialog is displayed.

  3. Click **Amend** to make the required edits and click **Publish**.




## What's next

After creating offers for multiple orders of the same product, [Monitor your private offers' reports.](https://docs.cloud.google.com/marketplace/docs/partners/offers/manage-private-offers)
