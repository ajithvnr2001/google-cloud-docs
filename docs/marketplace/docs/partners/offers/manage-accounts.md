When a customer purchases a [private offer](https://docs.cloud.google.com/marketplace/docs/partners/offers), Google creates an entitlement and uses Pub/Sub to notify you. You must approve the customer's account resource before the offer becomes active. After you've [turned on account approval](https://docs.cloud.google.com/marketplace/docs/partners/offers/account-approval) for a SaaS product, you can use Producer Portal to approve account resources. You can also approve account resources by using the Partner Procurement API.

## Approve account resources by using Producer Portal

To approve an account resource for a private offer by using Producer Portal, complete the following steps:

  1. In Producer Portal, go to the **Private Offers** page.

  2. Click **Approve Account** more_vert.

**Note:** If you aren't able to approve the account by using Producer Portal, use the Partner Procurement API to verify that you've approved the customer's account.



## Approve account resources by using the Partner Procurement API

To manage account resources for private offers by using the Partner Procurement API, follow the general instructions for [managing user accounts](https://docs.cloud.google.com/marketplace/docs/partners/integrated-saas/manage-user-accounts#create-account).

For additional details on using the Partner Procurement API for private offers, visit the [reference documentation](https://docs.cloud.google.com/marketplace/docs/partners/offers/rest-resources).
