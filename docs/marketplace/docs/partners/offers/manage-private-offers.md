With Cloud Marketplace Private Offers, you can create custom offers for specific customers to purchase your software as a service (SaaS), virtual machine (VM), or Kubernetes products at a discount.

## Manage your customers' private offers

The following documents explain how to manage your customers' private offers:

  * [View the current status](https://docs.cloud.google.com/marketplace/docs/partners/offers/view-offer-status) of your offers.

  * [Approve an accepted offer](https://docs.cloud.google.com/marketplace/docs/partners/offers/approve-offer).

  * [Modify an offer](https://docs.cloud.google.com/marketplace/docs/partners/offers/modify-offer), which can include modifying an existing offer's pricing, contract duration, or acceptance date.

  * [Download an offer](https://docs.cloud.google.com/marketplace/docs/partners/offers/download-offer) as a PDF.

  * [Cancel a published offer](https://docs.cloud.google.com/marketplace/docs/partners/offers/cancel-offer).

  * [Archive an inactive offer](https://docs.cloud.google.com/marketplace/docs/partners/offers/archive-offer).




To create, publish, and send a private offer, see [Create a private offer for a customer](https://docs.cloud.google.com/marketplace/docs/partners/offers/create-private-offers).

For an overview of private offers, see [Discover Private Offers](https://docs.cloud.google.com/marketplace/docs/partners/offers).

To programmatically manage private offers by using the API instead of the Google Cloud console, see [Create and manage private offers using the API](https://docs.cloud.google.com/marketplace/docs/partners/offers/commerce-producer-api).
