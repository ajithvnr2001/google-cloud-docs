This page describes how to create Test Billing Accounts with 100% discounted usage for testing your Cloud Marketplace products.

When you add a Cloud Billing account as a Test Billing Account for your Cloud Marketplace products, you enable it as a Test Billing Account across **all of** your Cloud Marketplace products, and you can continue to use it across all of the products that you offer on Cloud Marketplace.

## Requirements

You can't use a reseller Cloud Billing account as a Test Billing Account.

## Create a Test Billing Account

**Note:** If you follow these steps, you aren't charged for usage of your products when you test them. However, you still incur charges for [your usage of Google Cloud infrastructure](https://docs.cloud.google.com/marketplace/docs/understanding-billing).

To create a Test Billing Account, follow these steps:

  1. If you don't already have a specific Cloud Billing account that you plan to use as your Test Billing Account, create a new Cloud Billing account. For instructions, see [Create a billing account](https://docs.cloud.google.com/billing/docs/how-to/create-billing-account).

  2. On the **Test Billing Accounts** page, in **Configure Test Billing Accounts** , click **Add Test Billing Account** to add your Cloud Billing account as a Test Billing Account.

[Open the Test Billing Account page](https://console.cloud.google.com/producer-portal/test-billing-accounts)

  3. Click **Save** to save your Cloud Billing account as a Test Billing Account.




After you've saved your Cloud Billing account as a Test Billing Account, a status icon appears that notifies you that your Test Billing Account isn't ready for testing usage yet. You don't need to take any action while your Cloud Billing account is automatically prepared for usage as a Test Billing Account.

When your Test Billing Account finishes processing, its status icon changes to indicate that it is now ready to use for testing your products. To check if the status icon has changed, you must reload the page.

**Caution:** If you don't have any Cloud Marketplace products that have already had their Pricing review approved, your Test Billing Account remains in the processing stage until after one of your products completes the Pricing review.
