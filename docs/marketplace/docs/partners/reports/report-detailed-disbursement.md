#  Detailed disbursements reports Stay organized with collections  Save and categorize content based on your preferences. 

The _detailed disbursements report_ details the money that is transferred from Google to you for the month, with a more detailed breakdown when compared to the disbursements report. The charges listed in the detailed disbursements report match the charges from your customer's invoice for the month. To access the detailed disbursements report, visit the destination that you specified or BigQuery table `marketplace_report.detailed_disbursement` when you [set up to receive reports](https://docs.cloud.google.com/marketplace/docs/partners/reports/set-up-reports).

**Note:** As we add features and make improvements to Cloud Marketplace, we add columns as needed to existing reports. If you set up any automated processing of your reports, you should configure it so that it operates based on the names of the columns, and doesn't depend on the order or total number of columns staying the same.

## Report frequency

This report is generated by the tenth business day of every month in the destination that you set up. It includes the details of usage and revenue for the previous month.

In CSV Export, its name uses the following format: `YYYY-MM-DD Detailed Disbursements Report`.

For example, the name `2025-04-01 Detailed Disbursements Report` indicates that the report is for the usage that happened in April 2025.

In BigQuery Export, the data with `_PARTITIONDATE` as `2025-05-01` indicates the usage that happened in April 2025.

## Report fields

This report is organized into rows, based on the values of the `sku_id`, `account_id`, and `private_offer_id` fields and the status of the related payout.

**Note:** All dollar amounts, unless specified otherwise in the field descriptions, are presented in the partner's local currency.

**Note** : You might see different values for usage in the customer insights report and the detailed disbursement report. This difference is because the detailed disbursement report includes usage that was _reported_ by the service during the covered month, while the customer insights report includes usage that _started_ during the month. This can result in different numbers when the usage occurs at the end of a month. 

For example, if a customer starts using your software on March 31 at 10 PM PT, and ends on April 1 at 3 AM, the 5 hours of usage are reported on April 1, and are shown on April's detailed disbursement report. However, because the usage started in March, it's shown in the customer insights report for March.

The difference in calculation ensures that if a usage report from your service or one of Google's services is delayed, you're still paid the correct amount.
