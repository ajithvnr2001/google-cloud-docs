Google Cloud Marketplace lets you deploy functional software packages that run on Google Cloud. Even if you're unfamiliar with services like [Compute Engine](https://docs.cloud.google.com/compute/docs) or [Cloud Storage](https://docs.cloud.google.com/storage/docs), you can start up a familiar software package. You don't have to manually configure the software, virtual machine (VM) instances, storage, or network settings. You can deploy a software package and scale that deployment later when your apps require additional capacity.

## Discover software packages

You can select, purchase, and deploy products from the [Cloud Marketplace page](https://console.cloud.google.com/marketplace) of the Google Cloud console. Cloud Marketplace offers many different products, and in some cases, offers a few variations of the same product; for example, Cloud Marketplace has multiple packages for WordPress. To make sure that a product meets your needs, each product has a details page that describes details, including VM type, operating system, and estimated costs.

Use Cloud Marketplace's AI-powered search features—such as Instant Search, AI Overviews, and conversational AI Mode—to find software packages that meet your business needs. When you launch the deployment, you can use the default configuration for that product, or customize the configuration based on the available options.

## Common tasks

See the following documentation for common tasks that you can perform using Cloud Marketplace:

  * **[Get products](https://docs.cloud.google.com/marketplace/docs/get-products)** : discover, select, and deploy software packages from Cloud Marketplace.
  * **[Use AI-powered features](https://docs.cloud.google.com/marketplace/docs/ai-powered-features)** : discover products using conversational search and use other AI capabilities.
  * **[Manage deployments](https://docs.cloud.google.com/marketplace/docs/manage-deployments)** : view, modify, monitor, and scale your deployed software packages using Google Cloud tools.
  * **[Maintain your deployed products](https://docs.cloud.google.com/marketplace/docs/maintain-deployments)** : update the images of your existing software deployments to fix critical issues and vulnerabilities.
  * **[Manage billing](https://docs.cloud.google.com/marketplace/docs/manage-billing)** : manage, change, or cancel billing and subscriptions for your Cloud Marketplace products.
  * **[Manage access control](https://docs.cloud.google.com/marketplace/docs/access-control)** : define who has access to purchase and manage commercial products using IAM roles and permissions.
  * **[Private Marketplace](https://docs.cloud.google.com/marketplace/docs/access-private-marketplace)** : deploy pre-approved products that meet your organization's internal procurement standards.
  * **[Contact a vendor](https://docs.cloud.google.com/marketplace/docs/contact-vendor)** : contact Cloud Marketplace vendors directly for personalized guidance from their sales team.
  * **[Use the CLI](https://docs.cloud.google.com/marketplace/docs/deploy-through-CLI)** : deploy VM products through the command-line interface using tools like Terraform.
  * **[Get support](https://docs.cloud.google.com/marketplace/docs/get-support)** : find support contacts and get help for your deployed products.
  * **[Troubleshoot deployments](https://docs.cloud.google.com/marketplace/docs/troubleshooting)** : identify and resolve issues when a deployment fails or encounters network and permission problems.
