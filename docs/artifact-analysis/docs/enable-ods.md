#  Enable or disable on-demand scanning Stay organized with collections  Save and categorize content based on your preferences. 

The On-Demand Scanning API lets you scan images stored locally on your computer or in Artifact Registry.

See the [Pricing page](https://cloud.google.com/artifact-analysis/pricing#ods) for pricing information.

[ Enable the On-Demand Scanning API](https://console.cloud.google.com/apis/enableflow?apiid=ondemandscanning.googleapis.com)

## Disable the On-Demand Scanning API

To disable the On-Demand Scanning API follow the instructions to [disable services](https://docs.cloud.google.com/service-usage/docs/enable-disable).
