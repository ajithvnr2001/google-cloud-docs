## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Support](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Artifact Analysis on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-artifact-registry). Use the tag `google-artifact-registry` for questions about Artifact Registry, including Artifact Analysis. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Artifact Analysis

Join the [google-cloud-dev](https://groups.google.com/forum/#!forum/google-cloud-dev) Google group to discuss Google Cloud Platform development tools including Artifact Analysis.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Artifact Analysis and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

## File bugs or feature requests

### Where to file a report

Type of request | Where to file a report  
---|---  
Documentation feedback (incorrect documentation, general feedback, suggestions) |  Rate and review form  
Paid support |  If you are a [paid support](https://cloud.google.com/support/) customer, [ contact Google directly](http://www.google.com/support/enterprise/go/support_info#cloud).   
  
### Bugs and defects

_Example bug or defect: I am unable fetch the vulnerability information for a container image_

Search for existing issues in the Artifact Analysis [issue tracker](https://issuetracker.google.com/issues?q=componentid:187156).

If you cannot find a resolution for your issue, open a new issue and include the following information:

  * What steps will reproduce the problem?
  * What is the expected output? What do you see instead?
  * Any additional information that can help with diagnosing the issue.



### File a feature request

_Example: Artifact Analysis should add feature X_

Search for existing requests for the same feature in the Artifact Analysis [issue tracker](https://issuetracker.google.com/issues?q=componentid:187156). You can add a comment to an existing feature request or add yourself to the **CC** list to track the progress of the request.

If you create a new feature request, include the following information:

  * What is the desired behavior of the feature? (Be specific!)
  * If relevant, why are current approaches or workarounds insufficient?
  * If relevant, what new use cases will this feature enable?



### Documentation feedback

_Example: Documentation for X is out of date_

If you run into issues while using the documentation, have general feedback, or want to make a suggestion, use the documentation feedback mechanism. From any page in the Artifact Analysis documentation, click the _Rate and review_ link next to the page title. This will open a feedback form. Provide the following information (if applicable):

  * What URL are you reporting?
  * What was inaccurate?
  * General comments or suggestions



Your comments will be reviewed by the Artifact Analysis team.
