#  Get started with scanning Stay organized with collections  Save and categorize content based on your preferences. 

Artifact Analysis lets you scan Artifact Registry repositories for vulnerabilities and then view reports of vulnerability occurrences. Two types of scanning are supported:

  * **Container scanning** : Scan the images of a Docker container. For more information, see [Container scanning overview](https://docs.cloud.google.com/artifact-analysis/docs/container-scanning-overview).

  * **Package scanning** : Scan the files of a package. For more information, see [Package scanning overview](https://docs.cloud.google.com/artifact-analysis/docs/package-scanning-overview).
