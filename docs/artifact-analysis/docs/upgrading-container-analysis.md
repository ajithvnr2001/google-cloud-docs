#  Upgrading Artifact Analysis Stay organized with collections  Save and categorize content based on your preferences. 

Artifact Analysis released the generally available version on September 20, 2019. If your workload uses the Artifact Analysis beta version, consider the following to migrate to the newest version:

  * REST API: Use the GA REST API endpoints
        
        https://containeranalysis.googleapis.com/v1
        

instead of
        
        https://containeranalysis.googleapis.com/v1beta1
        

  * Upgrade your client libraries to the latest version. See the [libraries documentation](https://docs.cloud.google.com/artifact-analysis/docs/reference/libraries) for more information.
