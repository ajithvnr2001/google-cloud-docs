## Enable the Container Analysis API

The Artifact Analysis API provides metadata storage for software artifacts on both Container Registry and Artifact Registry.

Enable the Container Analysis API if you are using Artifact Analysis for [managing metadata](https://docs.cloud.google.com/artifact-analysis/docs/metadata-management-overview). You can enable the API for an existing project, or create a new project and then enable the API.

[ Enable the Container Analysis API ](https://console.cloud.google.com/apis/enableflow?apiid=containeranalysis.googleapis.com)

**Note:** This API is automatically enabled by the [Container Scanning](https://docs.cloud.google.com/artifact-analysis/docs/enable-automatic-scanning) API.

Users and service accounts that need to view occurrences must have the **Container Analysis Occurrences Viewer**. See [Configuring access control](https://docs.cloud.google.com/artifact-analysis/docs/access-control) for information about granting permissions.

## Disable the Container Analysis API

When you disable the Container Analysis API, the service is turned off for both Container Registry and Artifact Registry.

To disable the Container Analysis API follow the instructions to [disable services](https://docs.cloud.google.com/service-usage/docs/enable-disable).
