#  Uninstall the Endpoint Verification extension Stay organized with collections  Save and categorize content based on your preferences. 

This document shows how employees of an organization can uninstall the Endpoint Verification extension from their devices.

**Note:** If an administrator automatically installed Endpoint Verification on your device, then you must contact the administrator to uninstall it for you.

To uninstall the Endpoint Verification extension, do the following:

  1. On your device, open Chrome browser.
  2. Click **More more_vert > More Tools > Extensions**.
  3. On the **Endpoint Verification** extension, click **Remove**. You can use the search bar to find the extension.
  4. Click **Remove** to confirm.
  5. Check if your device has the Endpoint Verification helper app installed:

If your device has the Endpoint Verification helper app, you must uninstall the helper app.

To check if your device has the Endpoint Verification helper app and uninstall the helper app, do the following:

### Mac

     1. Open **Finder** and go to **Macintosh HD > Library > Application Support > Google**.
     2. To check if the helper app is installed, look for the **Endpoint Verification** folder.
     3. If you find the **Endpoint Verification** folder, drag the **Endpoint Verification** folder into **Trash**.
     4. Click **Finder > Empty Trash**.

### Windows

     1. Click **Start > Control Panel**.
     2. Click **Programs > Programs and Features**.
     3. To check if the helper app is installed, look for **Google Endpoint Verification**.
     4. If you find **Google Endpoint Verification** , double-click **Google Endpoint Verification** and then click **Uninstall**.

### Linux

     1. Click **Activities** and enter **terminal** to open a terminal.
     2. To check if the helper app is installed, run the following command and look for **endpoint-verification**.

`apt list --installed`

     3. To remove the helper app, run the following command:

`$sudo apt-get remove endpoint-verification`
