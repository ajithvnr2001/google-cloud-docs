Cloud CDN uses Google's globally distributed edge network to cache content close to your users, which reduces latency and the costs of serving from the origin. If you are a network administrator or a developer, you can use Cloud CDN to serve the following:

  * Static web content
  * Download large software
  * Stream videos



Use the following resources to learn about Cloud CDN pricing, release notes, cache locations, and the Service Level Agreement (SLA).

  * ### [Pricing Provides information about Cloud CDN pricing.  ](https://docs.cloud.google.com/cdn/pricing)
  * ### [Release notes Information about features and updates to Cloud CDN.  ](https://docs.cloud.google.com/cdn/docs/release-notes)
  * ### [Billing questions Get answers to common billing questions.  ](https://docs.cloud.google.com/cdn/docs/billing-questions)
  * ### [Cache locations Identifies the locations of Cloud CDN caches.  ](https://docs.cloud.google.com/cdn/docs/locations)
  * ### [Service Level Agreement Describes the terms of the Cloud CDN SLA.  ](https://docs.cloud.google.com/cdn/sla)
