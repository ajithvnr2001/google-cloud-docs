# Colab Enterprise locations

This page describes the available regions for Colab Enterprise. For more information about regions, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions).

The Data Science Agent isn't available in all regions. For more information about the Data Science Agent, see [Use the Data Science Agent](https://docs.cloud.google.com/colab/docs/use-data-science-agent).

## Data residency

When you use the Data Science Agent or other Gemini features, there is no guarantee that requests are processed in the same region as your notebook and runtime. Data processing for generative AI models is specific to the model version, and therefore can change as new model versions are released.

Data stored at rest in your notebook remains at rest in that notebook's location.

For more information about data residency, see [Data residency](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/data-residency).
