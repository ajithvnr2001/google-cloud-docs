### Use streaming AI and ML to power gen AI models in real time

Real-time data empowers AI/ML models with the latest information, enhancing prediction accuracy. [Dataflow ML](https://cloud.google.com/dataflow/docs/machine-learning#dataflow-ml) simplifies deployment and management of complete ML pipelines. We offer [ready-to-use patterns](https://cloud.google.com/dataflow/docs/machine-learning#prediction-and-inference-with-hub-models) for personalized recommendations, fraud detection, threat prevention, and more. Build [streaming AI](https://cloud.google.com/dataflow/docs/machine-learning/gemma) with Gemini platform, Gemini models, and [Gemma models,](https://developers.googleblog.com/en/gemma-for-streaming-ml-with-dataflow/) run remote inference, and streamline data processing with MLTransform. Enhance MLOps and ML job efficiency with [Dataflow GPU](https://cloud.google.com/dataflow/docs/gpu/gpu-support) and [right-fitting](https://cloud.google.com/dataflow/docs/guides/right-fitting) capabilities.

### Enable advanced streaming use cases at enterprise scale 

Dataflow is a fully managed service that uses open source [Apache Beam SDK](https://beam.apache.org/get-started/) to enable advanced streaming use cases at enterprise scale. It offers rich capabilities for [state and time](https://beam.apache.org/get-started/), [transformations](https://beam.apache.org/documentation/programming-guide/#applying-transforms), and [I/O connectors](https://beam.apache.org/documentation/io/connectors/). Dataflow scales to 4K workers per job and routinely processes petabytes of data. It features [autoscaling](https://cloud.google.com/dataflow/docs/horizontal-autoscaling) for optimal resource utilization in both batch and streaming pipelines.

[![What is Apache Beam](https://www.gstatic.com/bricks/image/0-uDMBLojeYzTEm7b3F7jNJ04onvJwNkFOA6xJ0DeAXIoxVMu8H-CzA9JwWR32KJsEFjBGy0G5LD.jpeg)Learn more about Apache Beam and Dataflow5:39](https://www.youtube.com/watch?v=65lmwL7rSy4&list=PLc4EyrNZridc6mllWYgW-VnNpgvZQoZtX&index=16&t=17s)

### Deploy multimodal data processing for gen AI

Dataflow enables parallel ingestion and transformation of [multimodal data](https://cloud.google.com/dataflow/docs/notebooks/run_inference_multi_model) like images, text, and audio. It applies specialized feature extraction for each modality, then fuses these features into a unified representation. This fused data feeds into generative AI models, empowering them to create new content from the diverse inputs. Internal Google teams leverage Dataflow and [FlumeJava](https://research.google/pubs/flumejava-easy-efficient-data-parallel-pipelines/) to organize and compute model predictions for a large pool of available input data with no latency requirements.

### Accelerate time to value with templates and notebooks

Dataflow has tools that make it easy to get started. [Dataflow templates](https://cloud.google.com/dataflow/docs/guides/templates/provided-templates#streaming-templates) are pre-designed blueprints for stream and batch processing and are optimized for efficient CDC and BigQuery data integration. [Iteratively build pipelines](https://cloud.google.com/dataflow/docs/guides/interactive-pipeline-development) with the latest data science frameworks from the ground up with Notebooks in Gemini platform and deploy with the [Dataflow runner](https://cloud.google.com/dataflow/docs/runner-v2). Dataflow [job builder](https://cloud.google.com/dataflow/docs/guides/job-builder) is a visual UI for building and running Dataflow pipelines in the Google Cloud console, without writing code. For a more integrated development experience, you can also leverage the [Data Agent Kit](https://docs.cloud.google.com/data-cloud-extension) to manage data assets, run queries, and deploy data pipelines directly from your preferred IDE.

### Save time with smart diagnostics and monitoring tools

Dataflow offers comprehensive diagnostics and monitoring tools. [Straggler detection](https://cloud.google.com/dataflow/docs/guides/troubleshoot-streaming-stragglers) automatically identifies performance bottlenecks, while [data sampling](https://cloud.google.com/dataflow/docs/guides/data-sampling#:~:text=Data%20sampling%20lets%20you%20observe,a%20running%20or%20completed%20job.) allows observing data at each pipeline step. [Dataflow Insights](https://cloud.google.com/dataflow/docs/guides/using-dataflow-insights) offer recommendations for job improvements. The Dataflow UI provides rich monitoring tools, including [job graphs](https://cloud.google.com/dataflow/docs/guides/job-graph), [execution details](https://cloud.google.com/dataflow/docs/concepts/execution-details), [metrics](https://cloud.google.com/dataflow/docs/guides/using-monitoring-intf), [autoscaling dashboards](https://cloud.google.com/dataflow/docs/guides/autoscaling-metrics), and [logging](https://cloud.google.com/dataflow/docs/guides/logging). Dataflow also features a [job cost monitoring UI](https://cloud.google.com/dataflow/docs/guides/monitoring-overview#cost) for easy cost estimation.

### Built-in governance and security

Dataflow helps you protect your data in a number of ways: encrypting data in use with confidential VM support; customer managed encryption keys (CMEK); VPC Service Controls integration; turning off public IPs. [Dataflow audit logging](https://cloud.google.com/dataflow/docs/audit-logging) gives your organization the visibility into Dataflow usage and helps answer the question “Who did what, where, and when?" for better governance.
