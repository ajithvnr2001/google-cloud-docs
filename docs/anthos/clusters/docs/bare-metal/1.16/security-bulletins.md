Security bulletins are published when Google Distributed Cloud is affected by software or service component flaws that have the potential to compromise the security of your clusters and the information they contain. Security vulnerabilities are usually identified through the [Common Vulnerabilities and Exposures (CVE)](https://cve.mitre.org/) system.

A security bulletin describes the security issue and its impact and provides a mitigation. Security bulletins for Google Distributed Cloud are published on a page shared by the following products:

  * Google Kubernetes Engine (GKE)
  * Google Distributed Cloud
  * GKE on AWS
  * GKE on Azure
  * Google Distributed Cloud



When a security bulletin is published for a vulnerability that affects Google Distributed Cloud, we publish a corresponding Google Distributed Cloud release note with a link to the bulletin.

To leave the Google Distributed Cloud documentation and open the shared security bulletins page, click the following link:

  * [Security bulletins](https://docs.cloud.google.com/anthos/clusters/docs/security-bulletins)
