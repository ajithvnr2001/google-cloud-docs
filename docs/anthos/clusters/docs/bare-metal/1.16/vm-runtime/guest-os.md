This document lists the guest operating systems that have been tested by Google and verified to work with VM Runtime on GDC. Thorough tests validate that these operating systems behave as expected in key areas.

**Note:** This is not an exhaustive list and does not imply that other operating systems work properly with VM Runtime on GDC. Minor releases within a verified OS major version are expected to work without issue. For example, Red Hat Enterprise Linux (RHEL) 8.3 is verified. Therefore, RHEL 8 minor releases such as RHEL 8.2 or RHEL 8.4 might work without issue, even though they aren't verified. Other operating systems might also work without issue.

Verified guest operating systems:

  * CentOS 8.3
  * Red Hat Enterprise Linux (RHEL) 7.9
  * Red Hat Enterprise Linux (RHEL) 8.3
  * Rocky Linux 8.6
  * Ubuntu 18.04
  * Ubuntu 20.04
  * Ubuntu 22.04
  * Windows Server 2016
  * Windows Server 2019
  * Windows Server 2022
  * Windows 10 Professional
