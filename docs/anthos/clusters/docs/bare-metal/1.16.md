Google Distributed Cloud (Distributed Cloud) is software that extends Google Cloud's infrastructure and services into your data center, with Google-provided software running on your own hardware. Distributed Cloud is built on [Google Kubernetes Engine (GKE)](https://docs.cloud.google.com/kubernetes-engine/docs/concepts/kubernetes-engine-overview), with its own _Google Distributed Cloud_ package that extends GKE for use in an on-premises environment. With Google Distributed Cloud, you can create and manage Kubernetes clusters on hardware in your own data center, while using Google Cloud features. 

Distributed Cloud includes VM Runtime on Google Distributed Cloud, which lets you run VMs on top of Kubernetes in the same way that you run containers. With VM Runtime on GDC, you can run existing VM-based workloads as you also develop and run new container-based applications.
