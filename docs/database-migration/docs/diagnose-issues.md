#  Diagnose migration issues Stay organized with collections  Save and categorize content based on your preferences. 

This page helps you diagnose and resolve issues that might occur in Database Migration Service during a migration. Depending on your migration scenario, you can troubleshoot errors, debug connectivity, or use other debugging tools.

## Diagnose homogeneous migration issues

Learn how to diagnose migration issues for the following homogeneous migrations:

### MySQL to Cloud SQL for MySQL

**Troubleshoot errors**

Find examples of issues and learn how they can be solved. For more information, see [ Diagnose issues for MySQL](https://docs.cloud.google.com/database-migration/docs/mysql/diagnose-issues).

**Debug connectivity**

Use standard network debugging tools, such as `ping` and `traceroute`. For more information, see [ Debugging connectivity](https://docs.cloud.google.com/database-migration/docs/mysql/debugging-connectivity).

**Other debugging tools**

Use scripts to diagnose and resolve issues. For more information, see [ Debugging and other tools](https://docs.cloud.google.com/database-migration/docs/mysql/debugging-tools).

### PostgreSQL to Cloud SQL for PostgreSQL

**Troubleshoot errors**

Find examples of issues and learn how they can be solved. For more information, see [ Diagnose issues for homogeneous migrations to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgres/diagnose-issues).

**Debug connectivity**

Use standard network debugging tools, such as `ping` and `traceroute`. For more information, see [ Debugging connectivity](https://docs.cloud.google.com/database-migration/docs/postgres/debugging-connectivity).

**Other debugging tools**

Use scripts to diagnose and resolve issues. For more information, see [ Debugging and other tools](https://docs.cloud.google.com/database-migration/docs/postgres/debugging-tools).

### PostgreSQL to AlloyDB for PostgreSQL

**Troubleshoot errors**

Find examples of issues and learn how they can be solved. For more information, see [ Diagnose issues in PostgreSQL to AlloyDB migrations](https://docs.cloud.google.com/database-migration/docs/postgresql-to-alloydb/diagnose-issues).

**Debug connectivity**

Use standard network debugging tools, such as `ping` and `traceroute`. For more information, see [ Debugging connectivity](https://docs.cloud.google.com/database-migration/docs/postgresql-to-alloydb/debugging-connectivity).

**Other debugging tools**

Use scripts to diagnose and resolve issues. For more information, see [ Debugging and other tools](https://docs.cloud.google.com/database-migration/docs/postgresql-to-alloydb/debugging-tools).

### SQL Server to Cloud SQL for SQL Server

**Troubleshoot errors**

Find examples of issues and learn how they can be solved. For more information, see [ Diagnose issues for SQL Server](https://docs.cloud.google.com/database-migration/docs/sqlserver/diagnose-issues).
