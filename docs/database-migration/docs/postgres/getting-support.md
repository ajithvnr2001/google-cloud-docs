## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

If you have questions about how to use or manage Database Migration Service for PostgreSQL, then try the following:

  * Review the [Known limitations](https://docs.cloud.google.com/database-migration/docs/postgres/known-limitations) page.
  * Review the [Diagnose issues for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgres/diagnose-issues) page.
  * Have a look at the [FAQ](https://docs.cloud.google.com/database-migration/docs/faq).
  * Search existing issues in the [Stack Overflow](https://stackoverflow.com/questions/tagged/google-cloud-database-migration-service) community forums.



If you're still stuck, then take one of the following steps:

  * Ask a question on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-database-migration-service). Use the tag `google-cloud-database-migration-service` for questions about Database Migration Service for PostgreSQL. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.
  * Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Database Migration Service for PostgreSQL and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 



When posting your question, provide:

  * A description of your problem, including any error messages.
  * The operation you attempted, for example, an admin operation or query.
  * The time and date (including timezone) you encountered the problem.
  * The tool or library that you use to interact with Database Migration Service.
  * A code sample, if applicable and possible.



## File bugs or feature requests

From the Database Migration Service for PostgreSQL documentation, click `Send feedback`. This will open a feedback form. Your comments will be reviewed by the Database Migration Service for PostgreSQL team.
