Each migration scenario supported by Database Migration Service is subject to different known limitations. For more information, see the dedicated pages for each scenario.

Known limitations for homogeneous migrations:

  * [ For MySQL to Cloud SQL for MySQL](https://docs.cloud.google.com/database-migration/docs/mysql/known-limitations)
  * [ For PostgreSQL to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgres/known-limitations)
  * [ For SQL Server to Cloud SQL for SQL Server](https://docs.cloud.google.com/database-migration/docs/sqlserver/known-limitations)
  * [ For PostgreSQL to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgresql-to-alloydb/known-limitations)



Known limitations for heterogeneous migrations:

  * [ For Oracle to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/oracle-to-postgresql/known-limitations)
  * [ For Oracle to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/oracle-to-alloydb/known-limitations)
  * [ For SQL Server to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/sqlserver-to-csql-pgsql/known-limitations)
  * [ For SQL Server to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/sqlserver-to-alloydb/known-limitations)
