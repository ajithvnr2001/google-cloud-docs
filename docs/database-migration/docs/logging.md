#  View migration logs Stay organized with collections  Save and categorize content based on your preferences. 

You can use Cloud Logging to monitor and troubleshoot your Database Migration Service migrations. Logs provide insights into the progress and health of your migrations, helping you identify and troubleshoot potential issues.

You can view logs for the following homogeneous migrations:

  * [ From MySQL to Cloud SQL for MySQL](https://docs.cloud.google.com/database-migration/docs/mysql/logging)
  * [ From PostgreSQL to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgres/logging)
  * [ From PostgreSQL to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgresql-to-alloydb/logging)



You can view logs for the following heterogeneous migrations:

  * [ From Oracle to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/oracle-to-postgresql/logging)
  * [ From Oracle to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/oracle-to-alloydb/logging)
  * [ From SQL Server to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/sqlserver-to-csql-pgsql/logging)
  * [ From SQL Server to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/sqlserver-to-alloydb/logging)
