#  Manage migration jobs Stay organized with collections  Save and categorize content based on your preferences. 

Migration jobs represent data movement that Database Migration Service manages. They let you combine source and destination connection profiles, define settings specific to that particular migration process, monitor the progress, and safely finalize the data movement process.

Migration jobs progress differently in different migration scenarios. For more information about migration jobs statuses and actions, see the following documentation relevant for your migration scenario.

Learn how to manage migration jobs for the following homogeneous migrations:

  * [ From MySQL to Cloud SQL for MySQL](https://docs.cloud.google.com/database-migration/docs/mysql/migration-job-actions)
  * [ From PostgreSQL to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgres/migration-job-actions)
  * [ From PostgreSQL to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/postgresql-to-alloydb/migration-job-actions)
  * [ From SQL Server to Cloud SQL for SQL Server](https://docs.cloud.google.com/database-migration/docs/sqlserver/manage-migration-jobs)



Learn how to manage migration jobs for the following heterogeneous migrations:

  * [ From Oracle to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/oracle-to-postgresql/manage-migration-jobs)
  * [ From Oracle to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/oracle-to-alloydb/manage-migration-jobs)
  * [ From SQL Server to Cloud SQL for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/sqlserver-to-csql-pgsql/manage-migration-jobs)
  * [ From SQL Server to AlloyDB for PostgreSQL](https://docs.cloud.google.com/database-migration/docs/sqlserver-to-alloydb/manage-migration-jobs)
