## Overview

Database Migration Service supports PostgreSQL to AlloyDB for PostgreSQL migrations from any of the supported [source versions](https://docs.cloud.google.com/database-migration/docs/postgresql-to-alloydb/migration-src-and-dest#supported-source-databases).
