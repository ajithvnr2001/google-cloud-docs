## Overview

From the list of connection profiles, you can click a specific connection profile to view detailed information about it, modify it, or delete it.

Detailed information that you can view about a connection profile includes:

  * All of the details provided when the connection profile was created, such as the connection profile ID, database engine, hostname or IP address, port, username, region, and SSL/TLS encryption type.
  * The time when the connection profile was created.
  * The time when the connection profile was last modified.
  * A list of migration jobs using the connection profile.



### Modify a connection profile

Information that you can modify for a connection profile includes the display name, hostname or IP address, port, username, password, and encryption type.

  1. Go to the [Connection profiles](https://console.cloud.google.com/dbmigration/connection-profiles) page in the Google Cloud Console.
  2. Click the display name of the connection profile that you want to modify. An overview page appears for the connection profile.
  3. Click **EDIT** at the top of the page.
  4. Make the desired changes to the connection profile.
  5. Click **SAVE**.



### Delete a connection profile

You can delete a connection profile only if no migration jobs are linked to it.

To delete a connection profile that's linked to migration jobs, first, delete all migration jobs that are linked to the connection profile. Then, delete the connection profile.

  1. Go to the [Connection profiles](https://console.cloud.google.com/dbmigration/connection-profiles) page in the Google Cloud Console.
  2. Click the display name of the connection profile that you want to delete. An overview page appears for the connection profile.
  3. Click **DELETE** at the top of the page.
  4. In the dialog box, click **DELETE**.
