# Beta Features  |  Video Intelligence API  |  Google Cloud Documentation

> Source: https://docs.cloud.google.com/video-intelligence/docs/beta/

Starting on September 14, 2026, Video Intelligence API is officially deprecated and will no longer be supported. You can continue using Video Intelligence API until September 14, 2027, when it will be shut down. We recommend migrating to [Gemini family of models](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/google-models).

#  Beta Features Stay organized with collections  Save and categorize content based on your preferences. 

The Video Intelligence API includes the following beta features:

  * **Streaming** \- Video Intelligence can provide streaming video annotation from a file. [Learn more](https://docs.cloud.google.com/video-intelligence/docs/streaming/streaming)

  * **Live streaming** \- Video Intelligence can perform video annotation from a live video feed. [Learn more](https://docs.cloud.google.com/video-intelligence/docs/streaming/live-streaming-overview)




See [Beta Client Libraries](https://docs.cloud.google.com/video-intelligence/docs/beta-libraries) for information on downloading the client libraries for beta features.
