# Getting support  |  Video Intelligence API  |  Google Cloud Documentation

> Source: https://docs.cloud.google.com/video-intelligence/docs/getting-support/

Starting on September 14, 2026, Video Intelligence API is officially deprecated and will no longer be supported. You can continue using Video Intelligence API until September 14, 2027, when it will be shut down. We recommend migrating to [Gemini family of models](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/google-models).

## Ask a question on Stack Overflow

Ask a question about the Google Cloud Video Intelligence API on [Stack Overflow](http://stackoverflow.com/questions/tagged/video-intelligence-api). Please use the tag `video-intelligence-api` for questions about the Cloud Video Intelligence API. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

## Discuss the Video Intelligence API and get updates

Join the [cloud-videointel-discuss](https://groups.google.com/forum/#!forum/cloud-videointel-discuss) Google group to discuss the Cloud Video Intelligence API and receive announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Video Intelligence and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

## Get a support package

Google Cloud Platform offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Platform Support](https://docs.cloud.google.com/support).
