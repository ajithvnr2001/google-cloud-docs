#  Customers API Stay organized with collections  Save and categorize content based on your preferences. 

The Customers API lets you view information about Spectrum Access System (SAS) customers.

A SAS customer is defined by the following parameters:

  * A unique name that is assigned by the server
  * A display name
  * A SAS user ID that is associated with the customer



User IDs must be unique. A given user ID can only be associated with one customer.

The API defines methods to list the customers visible to you or to get information about a specific customer.
