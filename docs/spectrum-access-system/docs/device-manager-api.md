#  Device Manager API Stay organized with collections  Save and categorize content based on your preferences. 

The Device Manager API is a create, read, update, and delete (CRUD) API, and is used to manage devices and their configurations. A _device_ is a resource, and _device configurations_ describe the metadata about the device.

In addition to the standard [`CreateDevice()`](https://docs.cloud.google.com/spectrum-access-system/docs/reference/rest/customers.devices/create), [`GetDevice()`](https://docs.cloud.google.com/spectrum-access-system/docs/reference/rest/customers.devices/get), and [`UpdateDevice()` methods](https://docs.cloud.google.com/spectrum-access-system/docs/reference/rest/customers.devices/patch) to manage devices, Device Manager also offers the [`CreateSignedDevice()` method](https://docs.cloud.google.com/spectrum-access-system/docs/reference/rest/customers.devices/createSigned) to create devices that need to be installed by a Certified Professional Installer (CPI) from a [JSON Web Token](https://jwt.io/)-encoded payload.
