#  Google SAS Portal API Stay organized with collections  Save and categorize content based on your preferences. 

The Google Spectrum Access System (SAS) Portal API provides administrative actions to help manage Citizens Broadband Radio Service (CBRS) resources, such as devices and user IDs that are controlled by Google SAS.

**Important:** The Google SAS Portal API is available by invitation only. Contact [sas-api-support@google.com](mailto:sas-api-support@google.com) to request access.

The SAS Portal API lets you do the following:

  * Assist with the multistep registration of Citizens Broadband Radio Service Devices (CBSDs) that need installation by a Certified Professional Installer (CPI).
  * Manage CBSDs at scale.



All usage of the API is subject to authorization rules based on user roles.

**Note:** The SAS Portal API applies only to Google Spectrum Access System, unlike the [SAS-CBSD API](https://winnf.memberclicks.net/assets/CBRS/WINNF-TS-0016.pdf), which is defined by the [WInnForum](https://www.wirelessinnovation.org/). Make sure that you are familiar with the WInnForum SAS-CBSD API.[ ![SAS overview](https://docs.cloud.google.com/static/spectrum-access-system/docs/images/overview.svg)](https://docs.cloud.google.com/static/spectrum-access-system/docs/images/overview.svg) SAS overview (click to enlarge)

The CBSDs communicate with SAS through the SAS-CBSD API. The SAS Portal API allows SAS customers to manage resources and users at a higher level.
