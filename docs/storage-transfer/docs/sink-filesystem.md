#  Configure access to a sink: file systems Stay organized with collections  Save and categorize content based on your preferences. 

For transfers involving a file system as the sink, you must install agents on a machine with access to your file system. If agents in the same agent pool are installed on different machines, they must all have uniform access to the file system, or the transfer will fail.

See [Manage transfer agents](https://docs.cloud.google.com/storage-transfer/docs/managing-on-prem-agents) for more details.

To limit your agents' access to your file system, see [Restricting agent directory access](https://docs.cloud.google.com/storage-transfer/docs/on-prem-agent-details#restrict-directory-access).
