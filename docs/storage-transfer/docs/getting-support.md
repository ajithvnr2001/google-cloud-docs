## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Provide feedback

To provide feedback to the Storage Transfer Service team, click **Send feedback** at the bottom of the [Storage Transfer Service documentation](https://docs.cloud.google.com/storage-transfer/docs).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Storage Transfer Service on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-data-transfer). Use the tag `google-cloud-data-transfer` for questions about Storage Transfer Service. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Storage Transfer Service

Join the [google-cloud-data-transfer-discuss](https://groups.google.com/forum/#!forum/google-cloud-data-transfer-discuss) Google group to discuss Storage Transfer Service. Google engineers monitor this discussion group and offer unofficial support.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Storage Transfer Service and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Storage Transfer Service, join the [`#cloud-data-transfer`](https://googlecloud-community.slack.com/messages/CSLNCCPK4/) channel. 

## Receive product updates

Join the [google-cloud-data-transfer-announce](https://groups.google.com/forum/#!forum/google-cloud-data-transfer-announce) Google group to receive Storage Transfer Service announcements and updates.

## File bugs or feature requests

To file a bug or a feature request for Google engineers to review, use the [Storage Transfer Service issue tracker](https://issuetracker.google.com/issues/new?component=815827&template=1395449).
