#  Device Streaming API Organizational Controls for Google Device Cloud Stay organized with collections  Save and categorize content based on your preferences. 

Google Device Cloud provides access to Partner Device Labs operated by Google OEM partners, such as Samsung, Xiaomi, OPPO, OnePlus, vivo, Transsion, and others. Your usage of Google Device Cloud is subject to the [Google Device Cloud service-specific terms](https://cloud.google.com/terms/service-terms). 

To enable and disable Google Device Cloud for your project:

  * If your project belongs to an organization, ask your organization administrator to enable labs for the project.
  * If your project does not belong to an organization, you must be a project owner to enable labs.
