The Device Streaming API lets you securely connect to remote physical Android devices hosted in Google's data centers. You can interact with these devices in real time using the Android Debug Bridge (ADB) protocol.

By using the Device Streaming API, you can deploy apps, test their functionality on various physical hardware configurations, and run tests on various Android devices directly from your development environment.

## Key benefits

The Device Streaming API provides the following key benefits:

  * **Access to a wide range of devices** : Connect to a diverse catalog of physical Android devices, including Google Pixel devices and select models from OEM partner device labs.
  * **Secure remote environment** : Every session is isolated. When a session ends, the device is automatically factory reset and wiped of all user data.
  * **Direct helper tool integration** : Connect to remote devices directly using ADB, which enables integration with development tools such as Android Studio.
