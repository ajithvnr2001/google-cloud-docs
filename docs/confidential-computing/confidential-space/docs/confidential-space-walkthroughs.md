This document links out to codelabs that demonstrate building specific Confidential Space environments from beginning to end. You can use them to familiarize yourself with how to set up Confidential Space environments, and adapt them to your own use cases.

  * ### [Confidential LLM inference Communicate with an LLM served in a Trusted Execution Environment by using the Prompt Encryption SDK.  ](https://codelabs.developers.google.com/prompt-encryption-sdk)
  * ### [Use Confidential Space with resources hosted outside Google Cloud Request a self-contained token from Google Cloud Attestation that a relying party can verify offline.  ](https://codelabs.developers.google.com/confidential-space-pki)
  * ### [Transact digital assets with multi-party computation Perform multi-party computed blockchain signing using Confidential Space.  ](https://codelabs.developers.google.com/codelabs/confidential-space-mpc)
  * ### [Share proprietary machine learning models in Confidential Space Run a proprietary model in Confidential Space, which another party can use private data with.  ](https://codelabs.developers.google.com/codelabs/secure-ml-model-confidential-space)
  * ### [Deploy a Confidential Space workload with MIGs using autoscaling, autohealing, and image updates Automate your Confidential Space image lifecycle.  ](https://codelabs.developers.google.com/codelabs/confidential-space-mig)
  * ### [Use container image signatures to validate workloads Sign your container image to avoid changing your attestation policy whenever a workload image updates.  ](https://codelabs.developers.google.com/signed-container-image-codelab)
