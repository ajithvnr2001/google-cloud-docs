This page explains how to edit and delete experiment templates.

Before proceeding, you must have the `roles/faulttesting.operator` role.

## Edit previously created experiment templates

To edit a template:

  1. Select **Experiment templates** from the left-hand navigation.
  2. Select a template.
  3. Select the Edit button, and update the template.
  4. Save the template.



## Delete an experiment template

To delete a template:

  1. Select **Experiment templates** from the left-hand navigation.
  2. Select a template.
  3. Select the Delete button.
