This page explains how to monitor your system using logs when an experiment is running.

Before proceeding, you must have the following:

  * Viewer permissions for the resources affected by the experiment.
  * The `roles/faulttesting.operator` role.



To monitor system behavior during an experiment:

  1. Select **Experiments** at the left-hand navigation.
  2. Select an experiment. You can see the metadata for the experiment such as fault type, targeted resources, current state, who started the experiment, start time, time elapsed, and time needed to complete the experiment.
  3. Select the **Logs** tab. A list of log entries appears.



If you would like to see more log details, select the **View in Log Explorer** button to modify the scope.
