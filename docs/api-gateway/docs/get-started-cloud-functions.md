# Get started with API Gateway and Cloud Functions 

The steps required to set up API Gateway to manage and secure a [Cloud Functions](https://docs.cloud.google.com/functions/docs) backend service are outlined in the API Gateway [Quickstarts](https://docs.cloud.google.com/api-gateway/docs/quickstarts).

See [Quickstart: Use the Google Cloud CLI](https://docs.cloud.google.com/api-gateway/docs/secure-traffic-gcloud) or [Quickstart: Use the Cloud console](https://docs.cloud.google.com/api-gateway/docs/secure-traffic-console) for more information on getting started with API Gateway and Cloud Functions.
