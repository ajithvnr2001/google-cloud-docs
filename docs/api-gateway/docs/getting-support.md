# Get support

This page lists the ways to get support on API Gateway

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Support](https://cloud.google.com/support).

## File a support request

Users with a support package can request assistance through the [Google Cloud Support console](https://console.cloud.google.com/support).

## Get support from the community

### Discuss API Gateway

Use the [API Gateway Users](https://groups.google.com/d/forum/api-gateway-users) Google group to discuss API Gateway and to receive API Gateway announcements and updates.

### Ask a question on Stack Overflow

Ask a question about API Gateway on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-api-gateway). Use the tag `google-cloud-api-gateway` for questions about API Gateway. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

## Provide feedback

### File bugs or feature requests

If you believe you have found a legitimate bug, the [Public Issue Tracker](https://issuetracker.google.com/issues?q=status:open%20componentid:961566) is the place to report it. Doing so will alert a member of our support and/or development team to the issue. While the primary purpose of this channel is bug reporting, it is also possible to submit feature requests here as well.

### Provide documentation feedback

If you run into issues while using the documentation, have general feedback, or want to make a suggestion, use the documentation feedback mechanism. From any page in the API Gateway documentation, click the **Send feedback** link at the top or bottom of the page to open a feedback form. Your comments will be reviewed by the API Gateway team.
