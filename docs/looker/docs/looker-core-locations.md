#  Looker (Google Cloud core) locations Stay organized with collections  Save and categorize content based on your preferences. 

Within a Google Cloud console project, Looker (Google Cloud core) instances can be created in one of many [locations](https://cloud.google.com/about/locations). These represent the geographical regions where a Looker (Google Cloud core) instance is hosted. Select the region that matches the region in the subscription contract, which is where the [quota for your project](https://docs.cloud.google.com/docs/quotas/view-manage) is allocated.

To see a list of the locations that are available for use in Looker (Google Cloud core) for different parts of the world, select one of the following options:
