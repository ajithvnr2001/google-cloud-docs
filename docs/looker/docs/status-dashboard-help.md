Use the Looker Status Dashboard to get real-time updates about product outages or service disruptions for Looker (original). You can view the dashboard at <https://status.cloud.google.com/looker>.

**Note:** This dashboard doesn't report status for customer-hosted Looker instances or for [Looker (Google Cloud core)](https://docs.cloud.google.com/looker/docs/looker-core-overview).

[VIEW THE LOOKER STATUS DASHBOARD](https://status.cloud.google.com/looker)

## Understand the dashboard

All times are shown in Coordinated Universal Time (UTC).

The display provides the following information:

  * The first column on the left shows that the product being reported on is Looker (original).
  * The last column on the right shows the current service status for the product.
  * The dated columns in between contain icons indicating historical statuses for the dates shown. For example, if you see an orange status icon in the column dated May 1, this indicates a service disruption on that date for the product in that row.



The following table shows more information about the status icons:

check_circle | Available | The product is fully available with no known disruptions.  
---|---|---  
info | Service information | The product has a service information update.  
error | Service disruption | Major features in the product are unavailable or affected by a known issue.  
cancel | Service outage | The product is inaccessible to all users.  
  
  * To see related incident details, click a status icon.
  * To see historical incident details, click **View history**.
  * To subscribe to atom feeds, click **RSS Feed** at the bottom of the page.
