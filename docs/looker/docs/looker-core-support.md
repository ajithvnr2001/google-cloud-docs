To resolve issues and get assistance for Looker (Google Cloud core), you can access Google Cloud Support. Support options include 24/7 coverage, phone, and chat. You can contact technical support for your Looker (Google Cloud core) instance, understand available support packages, and submit issues or feature requests directly through the [Google Cloud console support page](https://console.cloud.google.com/support).

## Get support through chat

Chat support for Looker (Google Cloud core) is available through the [Google Cloud console support page](https://console.cloud.google.com/support) and through the **Get Support** option in the Looker **Help** menu in the upper right-hand corner of the Looker (Google Cloud core) application.

## Get Comprehensive Support

Looker (Google Cloud core) customers receive [Comprehensive Support](https://docs.cloud.google.com/support/docs/integrations#comprehensive_support) at no additional cost. Comprehensive Support includes the ability to file issues or feature requests through the Google Cloud console. To access Comprehensive Support, contact Cloud Customer Care at `saas-support-onboarding@google.com`.

**Note:** If you receive a `403` permission error when you attempt to create a support case in the [Google Cloud console](https://console.cloud.google.com/), even if you have been granted the Tech Support Editor (`roles/cloudsupport.techSupportEditor`) IAM role, your instance might not be onboarded to Comprehensive Support. To resolve this issue, verify your Comprehensive Support entitlement on the [Google Cloud console support page](https://console.cloud.google.com/support). If Comprehensive Support isn't listed, your organization administrator (who also requires the Organization Viewer role, `roles/resourcemanager.organizationViewer`) must email `saas-support-onboarding@google.com` with your Google Cloud Organization ID to request onboarding.

## Required role

To configure access control for Cloud Customer Care support in the [Google Cloud console](https://console.cloud.google.com/), visit the [Access control with IAM](https://docs.cloud.google.com/support/docs/access-control) page of the Cloud Customer Care documentation.

## Granting Google employees temporary access to your Looker (Google Cloud core) instance

For public IP instances, Google employees can temporarily access your Looker (Google Cloud core) instance for support purposes through the [**Support Access**](https://docs.cloud.google.com/looker/docs/admin-panel-general-support-access) setting. The **Support Access** setting isn't available for private IP instances.

## Accessing logs

For instructions on viewing Looker (Google Cloud core) logs, see the [**View instance logs for Looker (Google Cloud core)**](https://docs.cloud.google.com/looker/docs/looker-core-logging) documentation page.

## Filing issues or feature requests

From the Looker (Google Cloud core) documentation, click "Send feedback" near the top right of the page. This action will open a feedback form. Your comments will be reviewed by the Looker (Google Cloud core) team.

Looker (Google Cloud core) doesn't provide a public [issue tracker](https://docs.cloud.google.com/support/docs/issue-trackers) for listing known bugs. Known issues and resolved bugs are published exclusively in the [Looker release notes](https://docs.cloud.google.com/looker/docs/release-notes). The public issue tracker is used solely for managing feature requests.
