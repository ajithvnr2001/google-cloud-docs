#  Get ready for development Stay organized with collections  Save and categorize content based on your preferences. 

To unlock the magic of Looker, data experts at each organization describe their data in a lightweight modeling language called _LookML_. LookML tells Looker how to query data so everyone in the organization can create Looks and dashboards without needing to understand the behind-the-scenes details. This page outlines the documentation on preparing to write LookML.

The following documentation pages help you understand the basics of developing in Looker:

  * [How a project works in Looker](https://docs.cloud.google.com/looker/docs/how-project-works) — Understand the basic concepts and structure of a project in Looker.
  * [Development Mode and Production Mode](https://docs.cloud.google.com/looker/docs/dev-mode-prod-mode) — Understand the differences between Development Mode and Production Mode.
  * [LookML project files](https://docs.cloud.google.com/looker/docs/lookml-project-files) — Get an overview of the types of files that may exist in a project in Looker.
  * [Understanding model and view files](https://docs.cloud.google.com/looker/docs/model-and-view-files) — Build model and view files.
  * [Understanding other project files](https://docs.cloud.google.com/looker/docs/other-project-files) — Add dashboard, document, data, project manifest, locale strings, explore, data test, and other files to your project.
  * [Navigating projects with the object browser panel](https://docs.cloud.google.com/looker/docs/object-browser) — Use the object browser in the IDE to view the objects and object hierarchies within your project.



## SQL in Looker

The following documentation pages help you understand how to use SQL with Looker:

  * [How Looker generates SQL](https://docs.cloud.google.com/looker/docs/how-looker-generates-sql) — Learn how Looker generates SQL from LookML.

  * [Using SQL Runner to create queries and Explores](https://docs.cloud.google.com/looker/docs/sql-runner-create-queries-and-explores) — Use SQL Runner to issue and debug SQL queries.
