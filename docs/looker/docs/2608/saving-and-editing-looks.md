#  Saving and editing Looks Stay organized with collections  Save and categorize content based on your preferences. 

While exploring, you can save your work by saving a Look. This saves the Explore query, including the settings for filters, visualizations, fields, and sort order.

Both Looks and dashboards can be organized in [folders](https://docs.cloud.google.com/looker/docs/2608/organizing-spaces) (for example, you can have folders named Marketing, Q4 Sales Review, and so on) and later edited as needed.

This page explains how to save, edit, and make other changes to Looks and Look settings that affect what other users can see. For more information about the components on the Look page and interacting with a Look's data, visit the [Viewing Looks in Looker](https://docs.cloud.google.com/looker/docs/2608/viewing-looks) documentation page.

## Saving Looks from an Explore

**Note:** If you're using Looker's [new Explore experience](https://docs.cloud.google.com/looker/docs/2608/new-explore-experience-overview), see the [Viewing and interacting with Explores in the new Explore experience](https://docs.cloud.google.com/looker/docs/2608/viewing-and-interacting-new-explore-experience#save-or-share-menu) documentation page.

To save a Look from an Explore:

![](https://docs.cloud.google.com/static/looker/docs/images/save-look-from-explore-2314.png)

  1. In the upper right of the Explore, select the **Explore actions** gear menu.
  2. Choose **Save**.
  3. Select **As a Look** to open the **Save Look** menu.

![](https://docs.cloud.google.com/static/looker/docs/images/save-look-from-explore-2-2312.png)

  4. In the **Title** field, enter a new title.

  5. In the **Description** field, you can enter a description of the Look.

  6. In the **Folder** drop-down menu, select a folder where you want to save the Look. You won't be able to select folders to which you don't have access.

  7. You can locate subfolders where you want to save the Look by expanding top-level folders.

  8. You can filter on subfolder titles in the filter field.

  9. Save the Look.

     * To save your Look and return to the Explore page, select **Save**.
     * To save and view your Look, select **Save & View Look**.
     * Alternatively, select the **X** at the top right of the **Save Look** menu to close the menu and return to the Explore without saving the Look.



## Navigating to folders to see your Looks

You can access your company's folders by expanding the list of folders in the [**Folders** section](https://docs.cloud.google.com/looker/docs/2608/finding-content#navigating_to_content_in_folders) of the [left navigation panel](https://docs.cloud.google.com/looker/docs/2608/finding-content).

## Moving and copying Looks

Once you create and save a Look to a folder, you can move and copy it to other folders to which you have access.

Continue reading for details about how to copy or move Looks to other locations within Looker.

### Copying Looks

There are two ways to copy a Look:

  * From the gear menu on a Look's page
  * From a folder



#### Copying Looks from the Look page gear menu

To copy a Look from the Look page:

![](https://docs.cloud.google.com/static/looker/docs/images/copy-look-from-look-page-2320.png)

  1. In the upper right of the Look page, select the [**Explore actions** gear menu](https://docs.cloud.google.com/looker/docs/2608/viewing-looks#the_look_explore_actions_gear_menu).
  2. Choose **Save**.
  3. Select **Save As...** to open the **Save Look** menu.

![](https://docs.cloud.google.com/static/looker/docs/images/save-look-from-explore-2-2312.png)

  4. In the **Title** field, enter a new title.

  5. In the **Description** field, you can change or enter a description of the Look.

  6. In the **Folder** drop-down menu, select a folder where you want to save the Look. You won't be able to select folders to which you don't have access.

  7. You can locate subfolders where you want to save the Look by expanding top-level folders.

  8. You can filter on subfolder titles in the filter field.

  9. Save the Look.

     * To save your Look and remain on the original Look page, select **Save**.
     * To save and view the copied Look, select **Save & View Look**.
     * Alternatively, select the **X** at the top right of the **Save Look** menu to close the menu and return to the original Look without saving the copy.



#### Copying Looks from a folder

Once you create and save a Look or Looks to a folder, you can move and copy one individual Look or more than one Look in bulk to other folders to which you have access. You can view the detailed steps for moving and copying Looks on the [Organizing and managing access to content](https://docs.cloud.google.com/looker/docs/2608/organizing-spaces#copying_and_moving_looks_and_dashboards) documentation page.

### Moving Looks

You can only move Looks from a folder. You can move Looks individually or in bulk to other folders to which you have access. You can view the detailed steps for moving Looks on the [Organizing and managing access to content](https://docs.cloud.google.com/looker/docs/2608/organizing-spaces#copying_and_moving_looks_and_dashboards) documentation page.

## Editing Looks

After creating a Look, you can edit its underlying query, edit its name, and decide if it should automatically run when loaded. If you have permission to do so, you can also give access to the Look through publicly accessible URLs, described in more detail on the [Public sharing, importing, and embedding of Looks](https://docs.cloud.google.com/looker/docs/2608/publishing-looks-with-public-urls) documentation page.

### Editing a Look's source query

You can edit a saved Look, including its fields, filters, visualizations, and sorting by following these steps:

![A Look called Order count by month displays a table chart with a count of Orders grouped by Orders Created Month.](https://docs.cloud.google.com/static/looker/docs/images/explore-edit-looks-2500.png)

  1. Select **Edit** on the saved Look's page to open the **Edit Look** menu.

![Users, a count of users, is added to the Order count by month table visualization from the Edit Look menu.](https://docs.cloud.google.com/static/looker/docs/images/explore-edit-looks-2-2402.png)

  2. On the **Edit Look** menu, make any changes you want to the Look, including fields, filters, and visualization. You can make changes from both the [field picker](https://docs.cloud.google.com/looker/docs/2608/creating-and-editing-explores#field_picker) and the **Filters** panel, as necessary. For example, **Users** , a count of users, was added to the query.

     * For more information regarding making changes to an Explore query, see the [Creating and editing Explores](https://docs.cloud.google.com/looker/docs/2608/creating-and-editing-explores) documentation page.
  3. After you make the changes, select the **Run** button to update the data and preview the changes.

  4. Select **Save** to save the changes and navigate back to the Look page.

     * Alternatively, select the **Cancel** option next to the **Save** button in the **Edit Look** menu header to navigate back to the Look page without saving the changes.



### Renaming a Look

There are two ways to rename an existing Look, including:

  * Renaming a Look from a Look's page
  * Renaming a Look from a folder



#### Renaming a Look from a Look's page

![A Look called Order count by month displays a table chart with a count of Orders grouped by Orders Created Month.](https://docs.cloud.google.com/static/looker/docs/images/explore-edit-looks-2500.png)

  1. Select **Edit** on the saved Look's page to open the **Edit Look** menu.

![The Look title Order count by month is changed to Monthly order count on the Edit Look menu.](https://docs.cloud.google.com/static/looker/docs/images/look-rename-from-look-2402.png)

  2. Input the new name in the title field underneath the header on the **Edit Look** menu. In this example, the Look title "Order count by month" was changed to "Monthly order count".

  3. Select **Save** to save the changes.




#### Renaming a Look from a folder

Whether viewing Looks in a folder with [list view](https://docs.cloud.google.com/looker/docs/2608/finding-content#list_view) or [grid view](https://docs.cloud.google.com/looker/docs/2608/finding-content#grid_view), you can rename an existing Look from a folder in the following way:

![](https://docs.cloud.google.com/static/looker/docs/images/look-rename-from-folder-2420.png)

  1. Select the Look's three-dot menu icon.
  2. Select **Rename** to open the **Rename Look** dialog.

![](https://docs.cloud.google.com/static/looker/docs/images/look-rename-from-folder-2-2206.png)

  3. Change the Look title in the **Name** field.

  4. Select **OK**.

     * Alternatively, select **Cancel** to close the **Rename Look** dialog without saving the changes.



### Turning off automatic Run on Load

You can prevent a Look from automatically loading its data when a user opens it by disabling the **Run on Load** option, which is enabled by default. This can be useful if you want to give the user a chance to select their filters before a Look's query is run.

If you choose to prevent the Look from running automatically, users will see an empty visualization that displays the text **Press "Run" to load this data** when they initially view the Look.

![](https://docs.cloud.google.com/static/looker/docs/images/edit-looks-runonload-result-2204.png)

There are two ways to adjust the **Run on Load** option:

  * From the Look page **Explore actions** gear menu
  * From a folder



#### Disabling automatic Run on Load from the Look page Explore actions gear menu

To disable automatic **Run on Load** from the Look page [**Explore actions** gear menu](https://docs.cloud.google.com/looker/docs/2608/viewing-looks#the_look_explore_actions_gear_menu), perform the following steps:

![](https://docs.cloud.google.com/static/looker/docs/images/disable-look-run-on-load-gear-menu-2314.png)

  1. Select the **Explore actions** gear menu.
  2. Select **Edit Settings** to open the **Look Settings** menu.

![](https://docs.cloud.google.com/static/looker/docs/images/disable-look-run-on-load-gear-menu-2-2216.png)

  3. Select the **Run on Load** switch to disable automatic **Run on Load**.

  4. Select **Save**.




You can also follow the preceding instructions to enable automatic **Run on Load** if it is disabled.

#### Disabling automatic Run on Load from a folder

Whether viewing Looks in a folder with [list view](https://docs.cloud.google.com/looker/docs/2608/finding-content#list_view) or [grid view](https://docs.cloud.google.com/looker/docs/2608/finding-content#grid_view), you can disable a Look's automatic **Run on Load** setting from a folder in the following way:

![](https://docs.cloud.google.com/static/looker/docs/images/disable-look-run-on-load-folder-menu-2312.png)

  1. Select the Look's three-dot menu icon.
  2. Select **Edit Settings** to open the **Look Settings** menu.

![](https://docs.cloud.google.com/static/looker/docs/images/disable-look-run-on-load-gear-menu-2-2216.png)

  3. Select the **Run on Load** switch to disable automatic **Run on Load**.

  4. Select **Save**.




You can also follow the preceding instructions to enable automatic **Run on Load** if it is disabled.

### Editing a Look's description

A Look's description appears under the Look's name in [folders](https://docs.cloud.google.com/looker/docs/2608/organizing-spaces) that are set to [list view](https://docs.cloud.google.com/looker/docs/2608/finding-content#using_list_view_and_grid_view), or when you hold the pointer over the Look's thumbnail in a folder that is set to [grid view](https://docs.cloud.google.com/looker/docs/2608/finding-content#using_list_view_and_grid_view).

If your admin has set your homepage to the [pre-built Looker homepage](https://docs.cloud.google.com/looker/docs/2608/finding-content#pre-built_homepage), the description is also displayed when you hold the pointer over the Look's thumbnail on your homepage.

You can add or edit a Look's description directly from the Look page:

![](https://docs.cloud.google.com/static/looker/docs/images/edit-look-description-2420.png)

  1. [Open the Look page](https://docs.cloud.google.com/looker/docs/2608/finding-content) and select the **Edit** link in the **Description** section of the [**Details** panel](https://docs.cloud.google.com/looker/docs/2608/viewing-looks#the_details_panel) to expand the **Description** field.

![](https://docs.cloud.google.com/static/looker/docs/images/edit-look-description-2-2220.png)

  2. Add or edit the text for the description in the **Description** field.

  3. Select **Save** to save the updated description, or select **Cancel** to close the **Description** field without saving.




## Deleting Looks

You can delete a Look or Looks in one of two ways:

  * Individually or in bulk from folders, as described on the [Organizing and managing access to content](https://docs.cloud.google.com/looker/docs/2608/organizing-spaces#deleting_looks_and_dashboards) documentation page
  * Individually from the Look page [**Explore actions** gear menu](https://docs.cloud.google.com/looker/docs/2608/viewing-looks#the_look_explore_actions_gear_menu)



To delete a Look using the Look page **Explore actions** gear menu, perform the following steps:

  1. Select the **Explore actions** gear icon to open the menu options.
  2. Select **Move to trash**.
  3. Select **OK** in the confirmation dialog to delete the Look.



If you delete a Look that is the source for a [dashboard](https://docs.cloud.google.com/looker/docs/2608/creating-user-defined-dashboards#adding_look-linked_tiles_from_a_look) tile, the dashboard's Look-linked tile returns an **Element not found** error.

**Note:** If you accidentally delete a Look, your Looker admin _might_ be able to recover it for you. Looker stores deleted content in the trash until your Looker admin team empties the [trash](https://docs.cloud.google.com/looker/docs/2608/admin-spaces#trash) as part of their maintenance process.
