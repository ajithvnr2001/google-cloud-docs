# Looker documentation

[Read product documentation](https://docs.cloud.google.com/looker/docs/intro)

Looker is Google Cloud's platform for business intelligence, data applications, and embedded analytics. Looker provides a comprehensive set of tools to explore, analyze, and visualize your data, all while ensuring governance and a single source of truth. Looker lets you empower your entire organization to make data-driven decisions while taking advantage of a unified data model that provides governance for your key metrics.
