#  Get Folder Looks Stay organized with collections  Save and categorize content based on your preferences. 

Version 4.0.26.18 (latest) 

### Get all looks in a folder.

In API 4.0+, all looks in a folder will be returned, excluding looks in the trash.

## Request

GET /folders/{folder_id}/looks
