#  LookML reference overview Stay organized with collections  Save and categorize content based on your preferences. 

The LookML parameter reference is organized by the [major structures of a LookML project](https://docs.cloud.google.com/looker/docs/lookml-terms-and-concepts#major_lookml_structures), from the highest-level structures to the most detailed components of a LookML project:

  * [Project manifest parameters](https://docs.cloud.google.com/looker/docs/reference/param-project-manifest)
  * [Model parameters](https://docs.cloud.google.com/looker/docs/reference/param-model)
  * [Explore parameters](https://docs.cloud.google.com/looker/docs/reference/param-explore)
  * [Join parameters](https://docs.cloud.google.com/looker/docs/reference/param-join)
  * [View parameters](https://docs.cloud.google.com/looker/docs/reference/param-view)
  * [Field parameters](https://docs.cloud.google.com/looker/docs/reference/param-field)
  * [Dimension, filter, and parameter types](https://docs.cloud.google.com/looker/docs/reference/param-dimension-filter-parameter-types)
  * [Measure types](https://docs.cloud.google.com/looker/docs/reference/param-measure-types)

**Note:** [LookML dashboard parameters](https://docs.cloud.google.com/looker/docs/reference/param-lookml-dashboard) are described along with user-defined dashboards in the Looker documentation. See the [LookML dashboard overview](https://docs.cloud.google.com/looker/docs/reference/lookml-dashboard-overview) for information.
