#  Looker's available APIs Stay organized with collections  Save and categorize content based on your preferences. 

Looker makes available several APIs that each perform specific functions.

[ Looker Application API arrow_forward_ios The **Looker Application API** gives developers access to the vast majority of Looker functionality over a convenient JSON-oriented REST API. This API includes a diversity of endpoints, from running of queries to managing users, content, schedules, instance configurations, and more.  ](https://docs.cloud.google.com/looker/docs/reference/looker-api/latest)

[ Looker (Google Cloud core) Admin API arrow_forward_ios The **Looker (Google Cloud core) Admin API** lets developers execute some Looker administrative functions through the Google Cloud console. This API is available only to those customers who use Looker (Google Cloud core) hosting for their Looker instances.  ](https://docs.cloud.google.com/looker/docs/reference/rest)

[ Looker Actions API arrow_forward_ios The **Looker Actions API** lets developers define Actions or custom destinations to which Looker can send query results, dashboard results, or user interactions.  ](https://docs.cloud.google.com/looker/docs/actions-overview)

The endpoint reference for this API is documented [on GitHub](https://github.com/looker-open-source/actions/blob/master/docs/action_api.md) and not the Google Cloud console documentation pages.
