#  Admin settings - Backup Stay organized with collections  Save and categorize content based on your preferences. 

Starting in Looker 7.6, automatic backups of Looker's internal database to an S3 bucket are no longer supported. Looker-hosted instances are still backed up daily through a separate process, but backup files cannot be sent to a custom S3 bucket.
