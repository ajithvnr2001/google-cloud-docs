You can configure a Looker (Google Cloud core) instance to use private services access, which can help you ensure security and meet compliance requirements. This capability establishes secure and private connections between your Looker instance and your data sources.

To create and set up a private connections Looker (Google Cloud core) instance that uses private services access, use the following documentation in the order presented here:

  1. [Looker (Google Cloud core) networking options](https://docs.cloud.google.com/looker/docs/looker-core-networking-options)
  2. [Create an OAuth client and credentials for a Looker (Google Cloud core) instance](https://docs.cloud.google.com/looker/docs/looker-core-create-oauth)
  3. [Create a private connections (PSA) Looker (Google Cloud core) instance](https://docs.cloud.google.com/looker/docs/looker-core-create-private-ip)
  4. [Access a Looker (Google Cloud core) instance using private services access](https://docs.cloud.google.com/looker/docs/looker-core-custom-domain-private-ip)
  5. [Access external services using private services access](https://docs.cloud.google.com/looker/docs/looker-core-private-ip-config)
