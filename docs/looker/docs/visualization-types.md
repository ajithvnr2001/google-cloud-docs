#  Visualization types Stay organized with collections  Save and categorize content based on your preferences. 

**Note:** Ask your admin to enable the new [**KPI Visualization** preview feature](https://docs.cloud.google.com/looker/docs/admin-panel-general-preview-features#kpi-visualization), which lets you do the following: 

  * Add secondary visualizations: Users can add a sparkline or bar chart within a visualization to show trends or distributions that are related to the primary KPI. 
  * Show enhanced comparisons: Users can specify and compare a primary value against any other measure in an Explore query, using data from the first row, second row, last row, or the totals row. 
  * Access improved styling options: Users have more control over the appearance of the visualization, including background color of the tile, and the alignment of the values. 



Learn more about the new [KPI (Single Value) Visualization](https://docs.cloud.google.com/looker/docs/kpi-single-value-options). 

Looker has many visualizations that you can use to make sense of your data. Each type of visualization has different settings that you can use to customize its appearance. The following links provide information about each visualization and its settings.

**Tip:** For information about choosing a visualization type that best fits your data, see the [Selecting an effective data visualization](https://docs.cloud.google.com/looker/docs/visualization-guide) documentation page.

## Chart Config Editor

If you have the [`can_override_vis_config` permission](https://docs.cloud.google.com/looker/docs/admin-panel-users-roles#can_override_vis_config), you can use the [Chart Config Editor](https://docs.cloud.google.com/looker/docs/chart-config-editor) to create the following visualization types:

  * [Bullet](https://docs.cloud.google.com/looker/docs/bullet-chart)
  * [Solid gauge](https://docs.cloud.google.com/looker/docs/solid-gauge)
  * [Streamgraph](https://docs.cloud.google.com/looker/docs/streamgraph)
  * [Treemap](https://docs.cloud.google.com/looker/docs/treemap)
  * [Sankey](https://docs.cloud.google.com/looker/docs/sankey)
  * [Dependency wheel](https://docs.cloud.google.com/looker/docs/dependency-wheel)
  * [Venn diagram](https://docs.cloud.google.com/looker/docs/venn)
  * [Sunburst](https://docs.cloud.google.com/looker/docs/sunburst)
  * [Item](https://docs.cloud.google.com/looker/docs/item)
