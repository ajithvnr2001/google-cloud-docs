#  Set up and administer Looker Stay organized with collections  Save and categorize content based on your preferences. 

Looker customers can [opt to have Looker host their instance or to self-host an on-premises Looker deployment](https://docs.cloud.google.com/looker/docs/choosing-hosting-option). Throughout our documentation, we refer to instances that are hosted by Looker as "Looker-hosted" and to instances that are hosted on-premises as "customer-hosted" or "self-hosted."

This page outlines the documentation on setting up and administering the Looker application.

## Documentation pages that apply only to Looker-hosted instances

The following page describes how to install and configure Looker-hosted instances:

  * [Looker-hosted installation steps](https://docs.cloud.google.com/looker/docs/looker-hosted-installation-steps): View a list of Looker-hosted installation steps and resources for each step.



## Documentation pages that apply only to customer-hosted instances

The following pages describe how to install, configure, and maintain customer-hosted instances:

  * [Customer-hosted installation steps](https://docs.cloud.google.com/looker/docs/customer-hosted-installation-steps): View a list of customer-hosted installation steps and resources for each step.
  * [Managing a customer-hosted deployment](https://docs.cloud.google.com/looker/docs/managing-customer-hosted-deployment): View a list of resources about managing your own Looker instance.
  * [Customer-hosted component infrastructure walkthroughs](https://docs.cloud.google.com/looker/docs/best-practices/customer-hosted-component-walkthroughs): Explore common practices for specific components of customer-hosted Looker architecture and how to configure them within a deployment.
  * [Customer-hosted infrastructure architecture patterns](https://docs.cloud.google.com/looker/docs/best-practices/customer-hosted-patterns-and-practices): Explore the most common architecture patterns for a customer-hosted deployment and describes the best practices for implementing them.
  * [Exporting data from a customer-hosted Looker instance](https://docs.cloud.google.com/looker/docs/customer-hosted-backup): Back up your instance's file system and database schema data in preparation for migrating to a Looker-hosted instance.



## Setting up a database connection

The following pages help you understand how to connect to a database:

  * [Enabling secure database access](https://docs.cloud.google.com/looker/docs/enabling-secure-db-access): Take the first step in connecting a database: Choose an option to secure data between Looker and your database.
  * [Database configuration instructions](https://docs.cloud.google.com/looker/docs/dialects): View links for database-specific instructions for configuring your database to work with Looker.
  * [Connecting Looker to your database](https://docs.cloud.google.com/looker/docs/connecting-to-your-db): Learn how to connect your database and Looker.



## Administrative tutorials

The following pages describe a variety of topics relating to the administration of a Looker instance:

  * [Supported browsers](https://docs.cloud.google.com/looker/docs/supported-browsers): View a list of the browsers that Looker supports.
  * [Configuring sign-in options for users](https://docs.cloud.google.com/looker/docs/getting-started-with-users): Configure sign-in options for your users.
  * [Access control and permission management](https://docs.cloud.google.com/looker/docs/access-control-and-permission-management): Learn how to configure roles, permission sets, and model sets to manage user and group access to your data and to Looker features.
  * [Designing and configuring a system of access levels](https://docs.cloud.google.com/looker/docs/access-levels): Learn about different ways you can configure Looker to manage user and group access to saved Looks and dashboards.
  * [Clustering Looker](https://docs.cloud.google.com/looker/docs/clustering-looker): Learn how to create a clustered Looker configuration.
  * [Creating connections](https://docs.cloud.google.com/looker/docs/creating-connections): Get an overview of the process to connect Looker to your database.
  * [Monitoring Looker usage with System Activity Explores](https://docs.cloud.google.com/looker/docs/usage-reports-with-system-activity-explores): Learn how to use Looker's System Activity Explores to view information and history about your Looker instance.
  * [Making announcements to your users](https://docs.cloud.google.com/looker/docs/making-announcements-to-your-users): Learn how to configure Looker's sidebar to create personalized messages to your users on your homepage.
  * [Managing business user features](https://docs.cloud.google.com/looker/docs/managing-business-user-features): Learn about administrative settings that affect options for viewing, retrieving, and sharing data.
  * [Deleting personal user information](https://docs.cloud.google.com/looker/docs/deleting-personal-user-information): Learn how to remove all of a disabled or deleted user's personal information from their Looker account.
  * [Using time zone settings](https://docs.cloud.google.com/looker/docs/using-time-zone-settings): Learn about Looker's various time zone settings and how they interact to convert time-based data.
  * [Supported user-interface languages](https://docs.cloud.google.com/looker/docs/supported-user-interface-languages): Learn about managing user-interface localization, letting you display data and Looker menus in multiple international languages.
  * [Localizing number formatting](https://docs.cloud.google.com/looker/docs/localizing-number-formatting): Learn about managing localized number formatting in Looker.
  * [Monitor Looker status](https://docs.cloud.google.com/looker/docs/status-dashboard-help): Learn how to use the Looker Status Dashboard to monitor the status of the Looker (original) application.



## Administrative panels

The following pages mirror the pages in the Looker instance **Admin** panel. Each documentation page describes the administration functions that are executed on the corresponding instance page:

  * [General pages](https://docs.cloud.google.com/looker/docs/admin-panel-general-pages): View a list of pages about setting system-wide options, enabling or disabling beta and legacy features, creating a custom help page for your users, setting a default homepage for your instance or for a user or group, and customizing the welcome emails new users receive.
  * [System Activity pages](https://docs.cloud.google.com/looker/docs/system-activity-pages): View information about the System Activity dashboards, which show user activity, content activity, and performance data for your Looker instance.
  * [Users pages](https://docs.cloud.google.com/looker/docs/admin-panel-users-pages): View a list of pages about configuring users, groups, roles, and user attributes; managing user and group access to saved content; and viewing and resetting locked user accounts.
  * [Database pages](https://docs.cloud.google.com/looker/docs/admin-panel-database-pages): View a list of pages about configured database connections, database query history, persistent derived tables, and datagroups.
  * [Alerts & Schedules pages](https://docs.cloud.google.com/looker/docs/admin-panel-alerts-and-schedules-pages): View a list of pages about managing user alerts and schedules, viewing alert and schedule histories, specifying an emailed data policy, and monitoring data sent to external email addresses.
  * [Platform pages](https://docs.cloud.google.com/looker/docs/admin-panel-platform-pages): View a list of pages about setting system-wide options for integrated services, Looker's API, embedded content, email deliveries, and custom visualization types.
  * [Authentication pages](https://docs.cloud.google.com/looker/docs/admin-panel-authentication-pages): View a list of pages about configuring authentication methods — including passwords, two-factor authentication, Google OAuth, LDAP, SAML, and OpenID Connect — and configuring options for user to stay logged in to Looker.
  * [Server pages](https://docs.cloud.google.com/looker/docs/admin-panel-server-pages): View a list of pages about configuring Looker backups, configuring a list of IP addresses that can access your instance, viewing the internal Looker log, and viewing Looker usage information.
