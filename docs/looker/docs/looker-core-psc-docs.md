To create and set up a private connections Looker (Google Cloud core) instance with Private Service Connect enabled, use the following documentation in the order presented here:

  1. [Looker (Google Cloud core) networking options](https://docs.cloud.google.com/looker/docs/looker-core-networking-options)
  2. [Use Private Service Connect with Looker (Google Cloud core)](https://docs.cloud.google.com/looker/docs/looker-core-psc-overview)
  3. [Create an OAuth client and credentials for a Looker (Google Cloud core) instance](https://docs.cloud.google.com/looker/docs/looker-core-create-oauth)
  4. [Create a Looker (Google Cloud core) Private Service Connect instance](https://docs.cloud.google.com/looker/docs/looker-core-create-psc)
  5. Access your instance:

     * [Public inbound access to a Looker (Google Cloud core) instance using Private Service Connect](https://docs.cloud.google.com/looker/docs/looker-core-psc-access-public)
     * [Private inbound access to a Looker (Google Cloud core) instance using Private Service Connect](https://docs.cloud.google.com/looker/docs/looker-core-psc-access)
  6. [Looker (Google Cloud core) outbound access to external services using Private Service Connect](https://docs.cloud.google.com/looker/docs/looker-core-psc-southbound)
