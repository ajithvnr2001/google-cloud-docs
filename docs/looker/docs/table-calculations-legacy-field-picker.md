#  Using table calculations with the legacy field picker Stay organized with collections  Save and categorize content based on your preferences. 

As of Looker 21.16, the [upgraded Explore field picker](https://docs.cloud.google.com/looker/docs/creating-and-editing-explores#field_picker) is the default field picker, and the legacy Explore field picker is no longer available. See the [**Using Table Calculations**](https://docs.cloud.google.com/looker/docs/table-calculations) documentation page to learn how to create ad hoc metrics using the upgraded Explore field picker.
