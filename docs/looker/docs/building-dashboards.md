#  Building Dashboards Stay organized with collections  Save and categorize content based on your preferences. 

Once you understand how to [explore and visualize data](https://docs.cloud.google.com/looker/docs/retrieve-and-chart-data), you can begin to build dashboards. Dashboards allow you to place multiple tables or graphs on one page, so that you can get a quick view of related content. If you like, you can also make dashboards interactive, so that users can filter them down to the specific data they are interested in.

For creating dashboards using the user interface, see [Creating User-Defined Dashboards](https://docs.cloud.google.com/looker/docs/creating-user-defined-dashboards).

For creating a dashboard using a YAML-based file in a project, with version control functionality, see the [Building LookML Dashboards](https://docs.cloud.google.com/looker/docs/building-lookml-dashboards) page. That page also includes links to related features and how to convert between user-defined dashboards and LookML dashboards.
