Looker can be accessed in more ways than directly through the application. If you have the proper permissions, you can also use Looker through the API or embed Looker content in web sites, both publicly and privately. This page outlines the documentation on the Looker API and embedding. 

## Looker API

The following pages help you understand how to interact with the Looker API:

  * [Getting started with the Looker API](https://docs.cloud.google.com/looker/docs/api-getting-started) — Learn the basics of Looker's API.
  * [Looker API authentication](https://docs.cloud.google.com/looker/docs/api-auth) — Understand the details of authenticating to the Looker API.
  * [Looker API 4.0 (current) reference](https://docs.cloud.google.com/looker/docs/reference/looker-api/latest) — View a list of Looker API 4.0 endpoint references.
  * [Looker API SDKs](https://docs.cloud.google.com/looker/docs/api-sdk) — Use Looker's Ruby, Python, or TypeScript/JavaScript SDK for the Looker API, or generate your own SDK.
  * [Looker API troubleshooting](https://docs.cloud.google.com/looker/docs/api-troubleshooting) — Troubleshoot common API problems.



## Embedding

The following pages help you learn how to embed Looker content on to web pages:

  * [Security best practices for embedded analytics](https://docs.cloud.google.com/looker/docs/security-best-practices-embedded-analytics) — Consider these best practices when creating embedded content.
  * [Private embedding](https://docs.cloud.google.com/looker/docs/private-embedding) — Learn how to require a Looker login for embedded Looks, Explores, or dashboards.
  * [Signed embedding](https://docs.cloud.google.com/looker/docs/single-sign-on-embedding) — Create Looker embeds that let you authenticate users with your own application.
  * [Viewing embedded Looks, Explores, and dashboards](https://docs.cloud.google.com/looker/docs/viewing-embedded-items) — Learn how users can access, save, download, and schedule embedded content.
  * [Embedded Javascript events](https://docs.cloud.google.com/looker/docs/embedded-javascript-events) — Interact with Looker embeds through JavaScript events.
  * [Signed embedding time zone reference](https://docs.cloud.google.com/looker/docs/sso-embedding-time-zone-reference) — View a list of time zones for use in the `user_timezone` parameter of signed embeds.
  * [Custom themes](https://docs.cloud.google.com/looker/docs/themes-for-embedded-dashboards-and-explores) — Customize the appearance of your embedded Looker dashboards and Explores.
  * [Embed SDK](https://docs.cloud.google.com/looker/docs/embed-sdk) — View a list of documentation pages for the Looker Embed SDK.
