#  The Looker Developer Portal has been deprecated Stay organized with collections  Save and categorize content based on your preferences. 

The Looker Developer Portal, formerly located at developers.looker.com, has been deprecated.

  * To view Looker application API reference documentation, see the [Looker API Reference home page](https://docs.cloud.google.com/looker/docs/reference/looker-api/latest).

  * To use the interactive API Explorer, you can access the API Explorer application installed on your Looker instance. For more information, see the [Using the API Explorer](https://docs.cloud.google.com/looker/docs/api-explorer) documentation page.

  * To view additional documentation about the Looker API and about embedding Looker, see the [Use embedding and the API](https://docs.cloud.google.com/looker/docs/use-embedding-and-api) documentation page.
