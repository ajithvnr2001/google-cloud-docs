As a Looker (Google Cloud core) admin, you can manage and configure your instance directly from the Google Cloud console. This capability helps you perform essential tasks like user management, security settings, and backup procedures. By using the settings in the console, you ensure that your Looker environment meets your operational and compliance needs.
