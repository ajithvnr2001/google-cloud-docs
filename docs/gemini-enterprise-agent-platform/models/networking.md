For network administrators (or anyone else who needs to dive deeper into Gemini Enterprise Agent Platform and generative AI networking), [Gemini Enterprise Agent Platform networking documentation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/general/netsec-overview) shows you how to configure and work with networking and traffic management features for your generative AI models and data, including the following topics:

Guide 

###  [ Accessing the Agent Platform API ](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/general/googleapi-access-methods)

Learn about the different ways to access the Agent Platform API, such as available deployment endpoints, when to use a Shared VPC, and more. 

Overview 

###  [ Network access with Agent Platform ](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/general/netsec-overview)

Information on the ways that you can use enterprise networking options to access Agent Platform. 

Overview 

###  [ Accessing Agent Platform services through PSC endpoints ](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/general/psc-endpoints)

Information on how to access Agent Platform services through Private Service Connect endpoints. 

Guide 

###  [ Set up a PSC interface for Agent Platform resources ](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/general/vpc-psc-i-setup)

Learn how to set up a Private Service Connect interface for Agent Platform resources. 

Guide 

###  [ VPC Service Controls with Agent Platform ](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/general/vpc-service-controls)

Learn how to mitigate the risk of data exfiltration by creating a service perimeter around your models, training data, and other critical resources. 

Tutorial 

###  [ Use Private Service Connect to access Agent Platform from on-premises ](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/general/vertex-psc-gen-ai)

Learn to use High-Availability VPN (HA VPN) to access Agent Platform both publicly, through Cloud NAT; and privately, between two Virtual Private Cloud (VPC) networks that can serve as a basis for multi-cloud and on-premises private connectivity.
