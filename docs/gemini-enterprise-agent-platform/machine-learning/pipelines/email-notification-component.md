The email notification component lets you configure email notifications from a pipeline. For more information, see [Configuring email notifications](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/pipelines/email-notifications).

The Google Cloud SDK includes the following operator related to email notifications in Gemini Enterprise Agent Platform Pipelines:
