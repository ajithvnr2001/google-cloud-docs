# Cloud FTP documentation

[Read product documentation](https://docs.cloud.google.com/cloud-ftp/overview)

Cloud FTP provides a managed, cloud-based solution to securely move data in and out of Cloud Storage by using SSH File Transfer Protocol (SFTP).
