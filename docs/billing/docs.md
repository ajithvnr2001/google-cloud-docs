# Cloud Billing documentation

[Read product documentation](https://docs.cloud.google.com/billing/docs/concepts)

Cloud Billing is a [collection of tools](https://docs.cloud.google.com/billing/docs/concepts) that help you track and understand your Google Cloud spending, pay your bill, and optimize your costs. 

A [Cloud Billing account](https://docs.cloud.google.com/billing/docs/how-to/manage-billing-account) defines who pays for a given set of Google Cloud resources. To use Google Cloud services, you must have a valid Cloud Billing account, and must link it to your Google Cloud projects. Your project's Google Cloud usage is charged to the linked Cloud Billing account. 

You must have a valid Cloud Billing account even if you are in your [free trial period](https://docs.cloud.google.com/free/docs/gcp-free-tier#free-trial) or if you only use Google Cloud resources that are covered by the [Google Cloud Free Tier](https://docs.cloud.google.com/free/docs/gcp-free-tier#free-tier). 

You also need a Cloud Billing account to pay for your use of the [Google Maps Platform APIs](https://developers.google.com/maps/billing/gmp-billing).
