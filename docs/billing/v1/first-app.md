To create a small but functional basic client application using the Cloud Billing API, follow the steps in this tutorial.

[Prerequisites](https://docs.cloud.google.com/billing/v1/prereqs)
    Get an account, learn about the product, and create a Google Cloud project.
[Set up your application](https://docs.cloud.google.com/billing/v1/configure)
    Download a client library for your programming language, set up authorization, provide your client ID and secret, and create a `Service` object.
[Send requests](https://docs.cloud.google.com/billing/v1/requests)
    Send a few sample requests to the Cloud Billing API.
