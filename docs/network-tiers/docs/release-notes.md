## October 05, 2026

Feature

External IPv6 addresses are now supported for [Standard Tier](https://docs.cloud.google.com/network-tiers/docs/overview#standard_tier) in **Preview**. For more information, see [IPv6 subnet ranges](https://docs.cloud.google.com/vpc/docs/subnets#ipv6-ranges).

## June 18, 2019

Change

[Cloud Armor is now supported with Standard Tier.](https://docs.cloud.google.com/armor/docs)

## March 28, 2019

Feature

[Network Service Tiers](https://docs.cloud.google.com/network-tiers/docs) is available in **General Availability**.

## May 07, 2018

Feature

## August 22, 2017

Feature
