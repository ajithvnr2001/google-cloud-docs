#  Building artifacts Stay organized with collections  Save and categorize content based on your preferences. 

You can build your artifacts with:

  * [Cloud Build](https://docs.cloud.google.com/artifact-registry/docs/configure-cloud-build), which tightly integrates with Artifact Registry.
  * Format-specific tools such as Maven for Java packages or Docker for container images.
  * General build or continuous integration tools such as [Jenkins](https://docs.cloud.google.com/artifact-registry/docs/configure-jenkins%0A) or [Tekton](https://tekton.dev/).



The approach that you take to building artifacts can impact the speed of builds and deployments, the effort required to maintain artifacts, and the security of your applications. Use the following resources as a starting point to learn more:

  * Learn about [DevOps capabilities](https://dora.dev/devops-capabilities/) that drive higher software delivery and organizational performance. These capabilities were identified by the DevOps Research and Assessment [research program](https://dora.dev/).

  * Learn [Docker best practices](https://docs.docker.com/build/building/best-practices/) for building container images.
