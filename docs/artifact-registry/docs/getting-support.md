## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Artifact Registry on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-artifact-registry). Use the tag `google-artifact-registry` for questions about Artifact Registry. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Google Developer Tools community forum

Get answers from the user community for Google Cloud developer tools, including [Artifact Registry](https://www.googlecloudcommunity.com/gc/forums/filteredbylabelpage/board-id/cloud-developer-tools/label-name/artifact%20registry).

## File bugs or feature requests

### Where to file a report

Type of request | Where to file a report  
---|---  
Bugs, defects, or feature requests |  [Issue tracker](https://issuetracker.google.com/issues?q=componentid:187156)  
Documentation feedback (incorrect documentation, general feedback, suggestions) |  Documentation feedback form  
Paid support |  If you are a [paid support](https://cloud.google.com/support/) customer, [ contact Google directly](http://www.google.com/support/enterprise/go/support_info#cloud).   
  
### Bugs and defects

_Example bug or defect: I am unable to push a container image_

Check existing resources to address your issue. Search for existing Artifact Registry issues in the [issue tracker](https://issuetracker.google.com/issues?q=componentid:187156).

If you cannot find a resolution for your issue, open a new issue and include the following information:

  * What steps will reproduce the problem?
  * What is the expected output? What do you see instead?
  * What version of Docker are you using? On what operating system?
  * Any additional information that can help with diagnosing the issue.



### File a feature request

_Example: Artifact Registry should add feature X_

Search for existing requests for the same Artifact Registry feature in the [issue tracker](https://issuetracker.google.com/issues?q=componentid:187156). You can add a comment to an existing feature request or add yourself to the **CC** list to track the progress of the request.

If you create a new feature request, include the following information:

  * What is the desired behavior of the feature? (Be specific!)
  * If relevant, why are current approaches or workarounds insufficient?
  * If relevant, what new use cases will this feature enable?



### Documentation feedback

_Example: Documentation for X is out of date_

If you run into issues while using the documentation, have general feedback, or want to make a suggestion, use the documentation feedback mechanism. From any page in the Artifact Registry documentation, click the _Send feedback_ link next to the page title. This will open a feedback form. Provide the following information (if applicable):

  * What URL are you reporting?
  * What was inaccurate?
  * General comments or suggestions



Your comments will be reviewed by the Artifact Registry team.

### Production issues

_Example: I cannot deploy images to a repository_

If you have a paid support contract, [contact Google directly](http://www.google.com/support/enterprise/go/support_info#cloud).

You can file a [production issue report](mailto:gc-team@google.com) for your application. Google reads these reports but cannot reply individually. Operational support for individual applications is not provided via the issue tracker.
