## Overview

Using Artifact Registry with Ruby consists of the following steps:

  1. [Create a standard repository](https://docs.cloud.google.com/artifact-registry/docs/repositories/create-repos) for your gems.
  2. Learn how to create [remote](https://docs.cloud.google.com/artifact-registry/docs/repositories/remote-repo) repositories.
  3. Read about how remote and virtual repositories can be used in this [repository usage example](https://docs.cloud.google.com/artifact-registry/docs/repositories#repository_usage_example).
  4. [Grant permissions](https://docs.cloud.google.com/artifact-registry/docs/access-control) to the account that will connect with the repository. Service accounts for common integrations with Artifact Registry have default [permissions](https://docs.cloud.google.com/artifact-registry/docs/access-control#gcp) for repositories in the same project.
  5. Configure your tools: 
     * [Configure authentication](https://docs.cloud.google.com/artifact-registry/docs/ruby/authentication) for Ruby clients that interact with the repository.
     * [Configure Cloud Build](https://docs.cloud.google.com/artifact-registry/docs/configure-cloud-build) to store gems and other packages in an Artifact Registry repository.
     * Learn about [deploying](https://docs.cloud.google.com/artifact-registry/docs/deploy) to Google Cloud runtime environments.
  6. [Learn about managing packages](https://docs.cloud.google.com/artifact-registry/docs/ruby/manage-packages).
