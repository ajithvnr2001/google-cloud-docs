#  Common test scenarios Stay organized with collections  Save and categorize content based on your preferences. 

Connectivity Tests evaluates whether traffic can travel successfully between endpoints within your network. It assesses reachability by analyzing your network configuration and, in certain use cases, by sending probe packets.

The following documentation describes several common use cases for Connectivity Tests:

  * [Test connectivity within Virtual Private Cloud (VPC) networks](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/test-within-vpc-networks), including networks that use Shared VPC and VPC Network Peering. This use case describes a full end-to-end testing scenario, including the test results provided in the Google Cloud console.

  * [Test connectivity to and from Google-managed services](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/test-google-managed-services)

  * [Test connectivity from a VPC network to a non-Google Cloud network](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/test-between-networks), such as an on-premises data center

  * [Test connectivity from a non-Google Cloud network to a VPC network](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/test-between-networks#non-gcp2vpc)

  * [Test connectivity between two non-Google Cloud networks](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/test-between-networks#non-gcp2non-gcp)

  * [Test connectivity from VM to VM through a NCC hub](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/test-through-ncc-hub)

  * [Test connectivity to Google Cloud load balancers](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/test-load-balancers)




To troubleshoot these scenarios, see [Detect invalid or inconsistent configurations](https://docs.cloud.google.com/network-intelligence-center/docs/connectivity-tests/concepts/detecting-configs).
