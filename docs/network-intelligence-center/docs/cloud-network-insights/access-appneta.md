#  Access AppNeta Stay organized with collections  Save and categorize content based on your preferences. 

Some configuration tasks can only be performed on the AppNeta instance created when you enable Cloud Network Insights. You don't need separate login credential; access is handled through Google Single Sign On (SSO).

If you want to configure access to the AppNeta API, see [Access the AppNeta API](https://docs.cloud.google.com/network-intelligence-center/docs/cloud-network-insights/access-appneta-api).

## Before you begin

You can only access your AppNeta instance after you have [deployed a Monitoring Point](https://docs.cloud.google.com/network-intelligence-center/docs/cloud-network-insights/add-monitoring-points).

## Authenticate using Google SSO

To perform tasks located in AppNeta, you must authenticate through the Google Cloud console.

  1. In the Google Cloud console, navigate to **Network Intelligence** > **Cloud Network Insights** > **Monitoring Points**.

[Go to Cloud Network Insights](https://console.cloud.google.com/net-intelligence/cloud-network-insights)

  2. Open the _more_vert_ **Actions** menu on any active Monitoring Point.

  3. Select **Open in AppNeta**.

  4. Sign in to AppNeta using Google SSO. You might be prompted to authorize AppNeta to read Google Cloud data.
