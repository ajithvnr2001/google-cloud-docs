Cloud Network Insights is possible with a close partnership with Broadcom AppNeta. As such, both Google Cloud API methods and Broadcom AppNeta API methods can be used to perform actions with Cloud Network Insights resources.

## Network Management API

Cloud Network Insights API methods are available through the Network Management API.

  * ### [Network Management v1 reference  Reference documentation for the v1 Network Management API.  ](https://docs.cloud.google.com/network-intelligence-center/docs/reference/networkmanagement/rest)
  * ### [Network Management v1alpha1 reference  Reference documentation for the v1alpha1 Network Management API.  ](https://docs.cloud.google.com/network-intelligence-center/docs/reference/networkmanagement/rest)



## AppNeta API

Broadcom's AppNeta API makes data collected and generated by AppNeta available for analysis, reporting, and presentation in third-party systems. In addition to collecting system data, the API also provides the ability to configure and control monitoring performed by AppNeta.

  * ### [Access the AppNeta API Generate an access token to use with the AppNeta API.  ](https://docs.cloud.google.com/network-intelligence-center/docs/cloud-network-insights/access-appneta-api)
  * ### [AppNeta API reference Reference documentation for the AppNeta API.  ](https://techdocs.broadcom.com/us/en/ca-enterprise-software/it-operations-management/appneta-for-google-cloud-network-insights/GA/api.html)
