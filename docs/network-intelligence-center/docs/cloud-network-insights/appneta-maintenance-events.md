This page describes how you can be notified about AppNeta's planned maintenance events.

## Understand AppNeta planned maintenance events

AppNeta planned maintenance events are times that Broadcom performs maintenance that might result in service degradation or unavailability for Cloud Network Insights users.

We provide advance notification, when possible, so that you can plan for the AppNeta maintenance event.

## Receive event notifications

You can receive notifications for planned maintenance events, product updates, event information, news, and special offers by filling out a [form](https://forms.gle/VLPC6GGZyRw3Zf7k9) to join the `cni-announcements-external@google.com` mailing list.

Notifications for planned maintenance events are sent at least seven calendar days before the scheduled event. In rare cases, a notification for an emergency maintenance event can be sent with shorter notice.

Scheduled maintenance is subject to change and an updated event notification is sent if a maintenance event is rescheduled or canceled.

Notifications don't appear in Google Cloud console for Cloud Network Insights users.

## Stop receiving event notifications

If you want to stop receiving notifications, send an email to [cni-announcements-external+unsubscribe@google.com](mailto:cni-announcements-external+unsubscribe@google.com). This action removes your email from the mailing list.
