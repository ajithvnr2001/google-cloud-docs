Network Services Monitoring provides observability for Google Kubernetes Engine services and workloads that run in environments with ambient networking.

By visualizing network-level metrics, Network Services Monitoring lets you monitor your service communication paths, identify high-throughput services, and analyze connection health.

## Why use Network Services Monitoring

  * **Analyze service communication:** visualize inbound and outbound connections.
  * **Identify high-throughput services and connections:** monitor throughput to identify the services that are handling the most traffic.
  * **Troubleshoot connection failures:** monitor connection timeouts, resets, and TLS handshake failures to detect performance anomalies.
  * **Correlate application and network health:** access Application Monitoring, App Hub, Access logs, VPC Flow Logs, and Flow Analyzer.



## What Network Services Monitoring provides

Network Services Monitoring provides the following capabilities:

  * **Service visibility and Layer 4 telemetry visualization:** view service communication paths and metrics in the Google Cloud console.
  * **Time-series charts:** view time-series data to monitor performance trends or correlate metric spikes.
  * **App Hub integration:** enrich analysis with application metadata for services and workloads that are registered in App Hub.
  * **Flow Analyzer integration:** use pre-populated Flow Analyzer queries to analyze traffic flows.
