#  Using the gcloud CLI for Firewall Insights Stay organized with collections  Save and categorize content based on your preferences. 

`gcloud` is a unified command-line tool that is part of the [Google Cloud CLI](https://docs.cloud.google.com/sdk/docs). When you run `gcloud` commands for Firewall Insights, you perform operations on the `Insight` resource that is part of Firewall Insights.

For more information about Firewall Insights, see the [API reference](https://docs.cloud.google.com/network-intelligence-center/docs/firewall-insights/apis).

## `gcloud` commands

You can use the Google Cloud CLI to run the following commands for Firewall Insights. For more information, see [the SDK overview for Firewall Insights](https://docs.cloud.google.com/sdk/gcloud/reference/recommender/insights).

Command | Task  
---|---  
[`gcloud recommender insights list`](https://docs.cloud.google.com/sdk/gcloud/reference/recommender/insights/list) | List insights for a project.  
[`gcloud recommender insights describe`](https://docs.cloud.google.com/sdk/gcloud/reference/recommender/insights/describe) | Describe (list details for) an insight.  
[`gcloud recommender insights mark-accepted`](https://docs.cloud.google.com/sdk/gcloud/reference/recommender/insights/mark-accepted) | Mark an insight as `ACCEPTED`.  
  
For command-line examples, see [Using Firewall Insights](https://docs.cloud.google.com/network-intelligence-center/docs/firewall-insights/how-to/using-firewall-insights).
