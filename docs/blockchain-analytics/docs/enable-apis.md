Blockchain Analytics offers indexed blockchain data made available through [BigQuery](https://cloud.google.com/bigquery/docs); therefore, you must enable the BigQuery API.

Projects created in Google Cloud should already have the BigQuery API enabled.

To verify that the BigQuery API is enabled in the Google Cloud console:

  1. In the Google Cloud console, go to the **BigQuery** API page.

[Enable the API](https://console.cloud.google.com/apis/library/bigquery.googleapis.com)

If the BigQuery API is enabled, you see a button labeled **Manage**. Otherwise, you see a button labeled **Enable**.

  2. If necessary, click **Enable**. It can take a couple of minutes for this command to complete.
