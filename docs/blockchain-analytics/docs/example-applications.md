## Create a Looker dashboard

See the [Data Studio documentation](https://docs.cloud.google.com/looker-studio) for instructions on using Data Studio.

Use Blockchain Analytics to power beautiful and interactive dashboards. The following dashboard gives an overview of activity on the Ethereum network, powered by the [`blocks`](https://console.cloud.google.com/bigquery?ws=!1m5!1m4!4m3!1sbigquery-public-data!2sgoog_blockchain_ethereum_mainnet_us!3sblocks) and [`transactions`](https://console.cloud.google.com/bigquery?ws=!1m5!1m4!4m3!1sbigquery-public-data!2s2sgoog_blockchain_ethereum_mainnet_us!3stransactions) tables.
