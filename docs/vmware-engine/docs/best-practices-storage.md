# Storage best practices

This page presents information about storage best practices for Google Cloud VMware Engine.

VMware Engine supports three storage backends: vSAN, Filestore, and Google Cloud NetApp Volumes. Each of these have their own sets of best practices and fine-tuning recommendations.

  * For vSAN storage best practices, see [Storage Design Considerations](https://core.vmware.com/resource/vmware-vsan-design-guide#section5) in the vSAN Design Guide.

  * For best practices pertaining to Filestore, a Google-native file-sharing product, see [Optimize and test instance performance](https://docs.cloud.google.com/filestore/docs/performance).

  * For best practices pertaining to Google Cloud NetApp Volumes, a first-party Google offering for NetApp storage in the cloud, see [Performance considerations](https://docs.cloud.google.com/netapp/volumes/docs/performance/performance-considerations).
