# Accessing the Google Cloud console

You can sign in to the Google Cloud console with single sign-on by using your Google Cloud credentials. To do so, begin in the Google Cloud console:

  1. In the Google Cloud console, click the menu navigation menu.

[Go to the Google Cloud console](https://console.cloud.google.com/)

  2. In the **Compute** section, click **VMware Engine** to open VMware Engine.
