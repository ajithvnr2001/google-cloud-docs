#  NodeTypeConfig Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Information about the type and number of nodes associated with the cluster.

JSON representation  
---  
      
    
    {
      "nodeCount": integer,
      "customCoreCount": integer
    }  
  
Fields  
---  
`nodeCount` |  `integer` Required. The number of nodes of this type in the cluster  
`customCoreCount` |  `integer` Optional. Customized number of cores available to each node of the type. This number must always be one of `nodeType.availableCustomCoreCounts`. If zero is provided max value from `nodeType.availableCustomCoreCounts` will be used.
