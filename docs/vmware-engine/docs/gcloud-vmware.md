# gcloud vmware

The Google Cloud CLI command-line tool lets you manage your VMware Engine resources, using the `gcloud vmware` command group.

The gcloud CLI is part of the [Google Cloud CLI](https://docs.cloud.google.com/sdk) and is a unified command-line tool that includes features like statement autocompletion, in-place updating, command-line help, human-readable and machine-parsable output formats, and integration with Google Cloud CLI.

**Note:** Looking for reference pages for `gcloud vmware` commands? Try the command-line `--help` function. For example, to get help about private cloud creation, use `gcloud vmware private-clouds create --help`. You can see all command-line documentation in the [Google Cloud CLI reference](https://docs.cloud.google.com/sdk/gcloud/reference/vmware).

## Before you begin

If you want to run `gcloud vmware` in a command prompt, [install, update, and initialize the Google Cloud CLI](https://docs.cloud.google.com/sdk/docs/install-sdk). If you don't have a command prompt readily available, try using the gcloud CLI in [Cloud Shell](https://docs.cloud.google.com/shell/docs). Cloud Shell is automatically installed, updated, and initialized with the latest gcloud CLI.
