# Support for Oracle workloads in Google Cloud VMware Engine

Google Cloud VMware Engine provides a fully managed VMware platform with VMware vSphere, vCenter, vSAN, and NSX, running on Google-provided enterprise-grade hardware infrastructure. Oracle [supports Oracle products on VMware virtualized environments](https://support.oracle.com/oip/faces/secure/km/DocumentDisplay.jspx?id=249212.1).

[My Oracle support portal](https://support.oracle.com/portal/) note 249212.1 states that _Oracle customers with an active support contract and running supported versions of Oracle products will receive assistance from Oracle when running those products on VMware virtualized environments._

The compatibility matrix on the [Oracle support portal](https://support.oracle.com/portal/) shows Oracle products certified by Oracle by using operating system support. Oracle also [certifies](https://linux.oracle.com/pls/apex/f?p=117:2:::NO:RP:P2_CERT_ID,P2_VIRTUAL_FLAG,P2_PRODUCT_ID:17694,2,822) its own operating systems for the VMware ESXi hypervisor used in Google Cloud VMware Engine.

The VMware vSphere platform is fully compatible with Oracle Linux, SUSE Linux, Red Hat Linux, Windows Server, and other operating systems certified for Oracle products. For more information, see the [VMware Compatibility Guide for Guest OS](https://www.vmware.com/resources/compatibility/search.php?deviceCategory=software&details=1&productNames=15&page=1&display_interval=10&sortColumn=Partner&sortOrder=Asc&testConfig=16).

VMware provides support for Oracle database technical issues on VMware vSphere platforms. For information about the support and subscription contract, see the [VMware Oracle Support Policy](https://www.vmware.com/support/policies/oracle-support.html).

Google Cloud support extends the support described above to VMware Engine customers. Google is committed to working with VMware and Oracle to support Oracle workloads running in VMware Engine.

You are fully responsible for ensuring that you comply with Oracle licensing and technical support on Google Cloud VMware Engine.
