# Glossary

#### Catalog

A single enterprise can create multiple catalogs in Service Catalog. Each catalog has a unique name, a description, and a collection of solutions.

#### Form Schema

Form Schema builds on [JSON schema form](https://json-schema.org/learn/getting-started-step-by-step) which is an open source schema written in JSON for specifying and validating a set of parameters. Cloud admins can use Form Schema to create forms that allow users to customize Deployment Manager (DM) template-based solutions before launching the solutions.

#### Solutions

A solution is an entry in a catalog.

A solution can be one of the following:

  * Reference link
  * Cloud Deployment Manager (DM) template
  * Terraform configuration
  * Google Cloud Marketplace product



##### Reference link

A reference link is a Service Catalog solution that has a landing page and a web link. The web link can point anywhere.

##### Cloud Deployment Manager template

A configuration file that defines cloud resources to be created using a [Deployment Manager template](https://docs.cloud.google.com/deployment-manager/docs/step-by-step-guide/create-a-template).

##### Terraform configuration

A configuration file that defines cloud resources to be created using [Terraform](https://docs.cloud.google.com/docs/terraform).

##### Google Cloud Marketplace product

A product from [Google Cloud Marketplace](https://docs.cloud.google.com/marketplace/docs), such as a software as a service (SaaS) product, virtual machine (VM), or Kubernetes app.

#### User

A user is an enterprise user who has access to Service Catalog solutions.

#### Cloud admin

A cloud admin is an administrative enterprise user who has access to create, curate, and share catalogs.
