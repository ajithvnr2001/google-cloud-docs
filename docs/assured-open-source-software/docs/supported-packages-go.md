The Assured Open Source Software free tier includes a total of 2,911 curated binaries, including 1,021 Java, 1,474 Python, and 416 Go primary packages. For a list of Go packages that are curated for the Assured Open Source Software premium tier, see [List of supported Go packages for the Assured Open Source Software premium tier](https://docs.cloud.google.com/security-command-center/docs/aoss-supported-packages-go-premium).
