This page documents production updates to Assured OSS. You can periodically check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality.

You can see the latest product updates for all of Google Cloud on the [ Google Cloud](https://docs.cloud.google.com/release-notes) page, browse and filter all release notes in the [Google Cloud console](https://console.cloud.google.com/release-notes), or programmatically access release notes in [BigQuery](https://console.cloud.google.com/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table). 

To get the latest product updates delivered to you, add the URL of this page to your [feed reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the [feed URL](https://docs.cloud.google.com/feeds/assured-open-source-software-release-notes.xml) directly. 

## August 03, 2026

Feature

The Assured Open Source Software Premium tier supports JavaScript (NPM) packages for Node.js environments.

For more information, see [Download NPM packages using direct repository access](https://docs.cloud.google.com/security-command-center/docs/aoss-download-npm-packages) and [List of supported NPM packages for the Assured Open Source Software premium tier](https://docs.cloud.google.com/security-command-center/docs/aoss-supported-packages-npm-premium).

## June 25, 2026

Change

The Assured Open Source Software free tier includes an updated list of curated binaries for the Go, Java, and Python languages.

For more information, see [List of supported Java and Python packages for the Assured OSS free tier](https://docs.cloud.google.com/assured-open-source-software/docs/supported-packages) and [List of supported Go packages for the Assured OSS free tier](https://docs.cloud.google.com/assured-open-source-software/docs/supported-packages-go).

## September 11, 2025

Feature

Assured Open Source Software (Assured OSS) now supports Go packages. For more information, see [Download Go packages using direct repository access for the free tier](https://docs.cloud.google.com/assured-open-source-software/docs/download-go-packages).

## June 30, 2025

Feature

You can now verify the signatures on Assured OSS artifacts using checksums.

## April 02, 2024

Feature

Assured OSS premium tier is available as part of Security Command Center Enterprise. The premium tier includes an expanded package list, a secure proxy server for Java, Python, and Javascript packages, and enriched metadata support. For more information, see [Overview of Assured Open Source Software](https://docs.cloud.google.com/assured-open-source-software/docs/overview) and [Integrate with Assured OSS for code security](https://docs.cloud.google.com/security-command-center/docs/integrate-aoss-with-scc).

## April 12, 2023

Announcement

Assured Open Source Software is generally available. For information about the product, see [Overview of Assured Open Source Software](https://docs.cloud.google.com/assured-open-source-software/docs/overview).
