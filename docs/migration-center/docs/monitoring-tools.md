#  Monitoring tools Stay organized with collections  Save and categorize content based on your preferences. 

One of the critical priorities of customers in a cloud migration initiative is to ensure minimal or no impact on performance and availability of workloads being migrated. It is essential to build a holistic monitoring framework to capture metrics on the health of infrastructure components, network, services, databases, applications, and end-user experience.

## Google Cloud tools

[Google Cloud Observability](https://cloud.google.com/products/operations) provides an integrated monitoring, logging, and trace managed services for applications and systems running on Google Cloud and beyond. Google Cloud Observability includes the following components:

  * [Cloud Logging](https://docs.cloud.google.com/logging)
  * [Observability Analytics](https://docs.cloud.google.com/logging/docs/log-analytics)
  * [Cloud Monitoring](https://docs.cloud.google.com/monitoring)
  * [Managed Service for Prometheus](https://cloud.google.com/managed-prometheus)
  * [Cloud Trace](https://docs.cloud.google.com/trace)
  * [Cloud Profiler](https://docs.cloud.google.com/profiler/docs)



For day 2 optimizations, Google's [Active Assist](https://docs.cloud.google.com/solutions/active-assist) portfolio of intelligent tools helps you optimize your cloud operations with recommendations to reduce costs, increase performance, improve security, and even help you make more sustainable decisions. For more details, view an [interactive demo](https://showcase.withgoogle.com/active-assist?utm_source=N20&utm_campaign=active-assist&utm_medium=web).

## Third-party tools

Examples of other commonly used monitoring tools include the following:

  * [Splunk](https://www.splunk.com)
  * [Dynatrace](https://www.dynatrace.com)
  * [AppDynamics](https://www.appdynamics.com/)
  * [NewRelic](https://www.appdynamics.com/)
