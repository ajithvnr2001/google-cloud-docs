Migration Center detects software workloads in your infrastructure using predefined rules. It also provides AI-powered software suggestions. For both detected and suggested workloads, Migration Center offers insights into their technical transformation fit. For more information, see [View and understand insights](https://docs.cloud.google.com/migration-center/docs/view-and-understand-insights).
