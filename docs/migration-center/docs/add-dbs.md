#  Add database assets Stay organized with collections  Save and categorize content based on your preferences. 

The discovery client doesn't support database asset discovery and collection.

To discover and import database assets into Migration Center, use one of the following methods:

  * To import your database data by using database collection scripts, see [Discover and import databases](https://docs.cloud.google.com/migration-center/docs/discover-and-import-databases).
  * For on-premises environments, discover and collect database asset information by using [guest discovery](https://docs.cloud.google.com/migration-center/docs/run-guest-discovery) or an [IP range scan](https://docs.cloud.google.com/migration-center/docs/run-ip-range-scan).
  * To discover and collect Amazon Relational Database Service (RDS) databases, use the Migration Center discovery client CLI.



After collecting your database information for on-premises and AWS environments, you can [export data to Migration Center](https://docs.cloud.google.com/migration-center/docs/export-collected-data).
