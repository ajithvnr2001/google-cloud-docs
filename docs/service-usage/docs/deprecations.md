# Feature deprecations

The [Google Cloud Platform Terms of Service (section "Discontinuation of Services")](https://docs.cloud.google.com/terms) defines the deprecation policy that applies to Service Usage. The [deprecation policy](https://docs.cloud.google.com/terms/deprecation) only applies to the services, features, or products listed therein. 

After a service, feature, or product is officially deprecated, it continues to be available for at least the period of time defined in the Terms of Service. After this period of time, the service is scheduled for shutdown. 

Feature | Deprecated date | Shutdown date | Details  
---|---|---|---  
MCP enablement and policy management | June 3, 2026 | July 30, 2026 | Support for managing Model Context Protocol (MCP) server enablement and consumer policies using the Service Usage v2beta API is deprecated. MCP server enablement is no longer required; enabling the underlying service is now sufficient. Corresponding Identity and Access Management permissions for these methods are also deprecated. For more information, see [Manage MCP servers](https://docs.cloud.google.com/mcp/manage-mcp-servers).
