# Service Usage overview

Service Usage is an infrastructure service of Google Cloud that lets you list and manage APIs and services in your Google Cloud projects.

You can list and manage APIs and services provided by Google, Google Cloud, and third-party producers. 

Before you can use most Google APIs you must first enable them in a Google Cloud project. You can use Service Usage to perform the following tasks:

  * [List enabled services in an organization or project](https://docs.cloud.google.com/service-usage/docs/list-services)
  * [Enable or disable services for a Google Cloud project](https://docs.cloud.google.com/service-usage/docs/enable-disable)
  * [Enable or disable services at different levels of the resource hierarchy](https://docs.cloud.google.com/service-usage/docs/hierarchical-service-activation/overview) (Preview)



Some APIs and services are enabled by default when you create a Google Cloud project, while others are automatically enabled when you use them in the Google Cloud console. For more information, see [Enabled services](https://docs.cloud.google.com/service-usage/docs/enabled-service).

You can use Service Usage through the [Google Cloud console](https://console.cloud.google.com/), from the [Google Cloud CLI](https://docs.cloud.google.com/sdk/gcloud/reference/services), or programmatically using the [Service Usage API](https://docs.cloud.google.com/service-usage/docs/reference/rest) from one of the [Google API Client Libraries](https://docs.cloud.google.com/service-usage/docs/libraries).
