#  App Hub locations Stay organized with collections  Save and categorize content based on your preferences. 

In App Hub, you define applications as either _global_ or _regional_. This location setting determines the services and workloads you can register to the application. To learn more about the differences between global and regional applications, see [Global and regional applications](https://docs.cloud.google.com/app-hub/docs/global-regional-applications).

App Hub is available in the following global and regional locations. For more information about regions and zones, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions).

## Global and multiregional

You must register [App Hub supported resources](https://docs.cloud.google.com/app-hub/docs/supported-resources) that are either global or located in [multiregions](https://docs.cloud.google.com/docs/geography-and-regions#multiregional_resources) as _global applications_ , with no dependence on location. To define global applications or register global components to them, set their location as `global`.

A _regional application_ can only contain components from the same region as the one in which the application resides. The following sections of this page list the available regions for regional applications.
