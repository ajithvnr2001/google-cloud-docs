#  Collect on-premises and hybrid-cloud logs with Bindplane Stay organized with collections  Save and categorize content based on your preferences. 

[Bindplane](https://bindplane.com/google) is an OpenTelemetry-native telemetry pipeline that streamlines log collection from over 150 standard application components, on-premises, and hybrid cloud systems. Using Bindplane, you can collect, process, and send logs to Google Cloud Observability, as well as Google Security Operations, so you can view those log events within the same dashboards as your other monitored systems. For more information, see [About Bindplane](https://docs.cloud.google.com/stackdriver/bindplane).

![Bindplane lets you collect telemetry from a variety of sources and export
that data to Cloud Monitoring and Cloud Logging.](https://docs.cloud.google.com/static/stackdriver/images/bindplane-capabilities.png)

This architecture has the following advantages: 

  * Google Cloud Observability customers can deploy and use Bindplane at no additional cost. For information about the features available, see the [Bindplane (Google Edition) page](https://bindplane.com/google). 
  * For more information about implementing this pattern, see [ Logging and monitoring on-premises resources with Bindplane](https://docs.cloud.google.com/architecture/logging-and-monitoring-on-premises-resources-with-bindplane).
