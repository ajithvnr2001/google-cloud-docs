This page documents production updates to Advisory Notifications. Check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality. 

You can see the latest product updates for all of Google Cloud on the [ Google Cloud](https://docs.cloud.google.com/release-notes) page, browse and filter all release notes in the [Google Cloud console](https://console.cloud.google.com/release-notes), or programmatically access release notes in [BigQuery](https://console.cloud.google.com/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table). 

To get the latest product updates delivered to you, add the URL of this page to your [feed reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the [feed URL](https://docs.cloud.google.com/feeds/advisory-notifications-release-notes.xml) directly. 

## April 05, 2024

Announcement

Advisory Notifications for users using Google Cloud without an organization is now in [General Availability](https://cloud.google.com/products/#product-launch-stages). Advisory Notifications now lets users [opt in to or out of optional notification types](https://docs.cloud.google.com/advisory-notifications/docs/opt-in-out-notifications).

## December 04, 2023

Feature

Advisory Notifications now sends mandatory security and privacy notifications for users using Google Cloud without an organization. This feature is available in [Preview](https://cloud.google.com/products/#product-launch-stages). For a list of notification types, see [Types of notifications](https://docs.cloud.google.com/advisory-notifications/docs/overview#types).

## September 25, 2023

Feature

Advisory Notifications lets you opt in to or out of optional notification types. For more information, see [Opt in to or out of notifications](https://docs.cloud.google.com/advisory-notifications/docs/opt-in-out-notifications).

## November 17, 2022

Announcement

Advisory Notifications is now [generally available](https://cloud.google.com/products/#product-launch-stages). For information about getting started with Advisory Notifications, see [Viewing notifications](https://docs.cloud.google.com/advisory-notifications/docs/quickstart).

## June 09, 2022

Announcement

Advisory Notifications is available in the [Preview](https://cloud.google.com/products/#product-launch-stages) stage. For information about the product, see [Overview of Advisory Notifications](https://docs.cloud.google.com/advisory-notifications/docs/overview).
