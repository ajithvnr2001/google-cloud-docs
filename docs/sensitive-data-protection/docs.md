# Sensitive Data Protection documentation

[Read product documentation](https://docs.cloud.google.com/sensitive-data-protection/docs/sensitive-data-protection-overview)

Sensitive Data Protection provides access to a powerful sensitive data inspection, classification, and de-identification platform. Sensitive Data Protection includes:

  * Over 200 built-in [information type (or "infoType") detectors](https://docs.cloud.google.com/sensitive-data-protection/docs/infotypes-reference). 
  * The ability to [define custom infoType detectors](https://docs.cloud.google.com/sensitive-data-protection/docs/concepts-infotypes) using dictionaries, regular expressions, and contextual elements. 
  * [De-identification techniques](https://docs.cloud.google.com/sensitive-data-protection/docs/deidentify-sensitive-data) including redaction, masking, format-preserving encryption, date-shifting, and more.
  * The ability to detect sensitive data within [streams of data](https://docs.cloud.google.com/sensitive-data-protection/docs/inspecting-text), [structured text](https://docs.cloud.google.com/sensitive-data-protection/docs/inspecting-structured-text), [files in storage repositories such as Cloud Storage and BigQuery](https://docs.cloud.google.com/sensitive-data-protection/docs/inspecting-storage), and even within [images](https://docs.cloud.google.com/sensitive-data-protection/docs/inspecting-images). 
  * [Analysis of structured data](https://docs.cloud.google.com/sensitive-data-protection/docs/concepts-risk-analysis) to help understand its risk of being re-identified, including computation of metrics like _k_ -anonymity, _l_ -diversity, and more. 
  * The ability to automatically [discover unencrypted secrets](https://docs.cloud.google.com/sensitive-data-protection/docs/secrets-discovery) and [profile data](https://docs.cloud.google.com/sensitive-data-protection/docs/data-profiles) across an organization, folder, or project to identify data assets where high-risk and sensitive data reside.
