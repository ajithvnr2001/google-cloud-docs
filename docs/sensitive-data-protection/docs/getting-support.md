## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Sensitive Data Protection on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-dlp). Use the tag `google-cloud-dlp` for questions about Sensitive Data Protection. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Sensitive Data Protection

Join the [dlp-api-feedback](https://groups.google.com/forum/#!forum/dlp-api-feedback) Google group to discuss Sensitive Data Protection and receive Sensitive Data Protection announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Sensitive Data Protection and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA).
