#  CloudStoragePath Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Message representing a single file or path in Cloud Storage.

JSON representation  
---  
      
    
    {
      "path": string
    }  
  
Fields  
---  
`path` |  `string` A URL representing a file or path (no wildcards) in Cloud Storage. Example: `gs://[BUCKET_NAME]/dictionary.txt`
