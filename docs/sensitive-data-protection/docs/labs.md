#  Google Cloud Skills Boost for Sensitive Data Protection Stay organized with collections  Save and categorize content based on your preferences. 

This document lists select Google Cloud Skills Boost labs that you can complete to learn how to use Sensitive Data Protection and demonstrate your skills. To view more labs and courses related to Sensitive Data Protection, see the [Google Cloud Skills Boost catalog](https://www.cloudskillsboost.google/catalog?keywords=sensitive+data+protection).

[Lab: Redact sensitive data with Sensitive Data Protection](https://www.cloudskillsboost.google/focuses/46234?parent=catalog)
    Learn the basic capabilities of the Cloud Data Loss Prevention API and try various ways to use the API to help protect data.
[Lab: Create a de-identified copy of data in Cloud Storage](https://www.cloudskillsboost.google/focuses/47127?parent=catalog)
    Scan a Cloud Storage bucket for sensitive data and create a de-identified copy of the data in a separate bucket.
[Skill badge: Discover and Protect Sensitive Data Across Your Ecosystem](https://www.cloudskillsboost.google/course_templates/1177)
    Complete a course consisting of four labs to demonstrate your skills in using Sensitive Data Protection services. When you complete this course, you receive a digital badge that you can share with your network.
