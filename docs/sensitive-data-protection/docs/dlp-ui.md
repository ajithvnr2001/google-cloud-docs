Sensitive Data Protection has a user interface (UI) that is available in the Google Cloud console. The Sensitive Data Protection UI contains a subset of the functionality available in the DLP API, as detailed on this page.

**Note:** We plan to update the Sensitive Data Protection UI to enable new Sensitive Data Protection features on an ongoing basis.

This topic provides instructions on how to access the Sensitive Data Protection UI and lists the features available in the Sensitive Data Protection UI.

## Access the Sensitive Data Protection UI

To access Sensitive Data Protection in the Google Cloud console:

[Go to Sensitive Data Protection UI](https://console.cloud.google.com/security/sensitive-data-protection;source=7)

The Sensitive Data Protection UI appears.

## Available features

The Sensitive Data Protection UI supports the following existing Sensitive Data Protection features:

  * [Inspection jobs for inspecting Cloud Storage, BigQuery, and Datastore storage repositories](https://docs.cloud.google.com/sensitive-data-protection/docs/creating-job-triggers): Creating, listing, deleting, viewing detail, and triggering (with a job trigger).
  * [Inspection job triggers](https://docs.cloud.google.com/sensitive-data-protection/docs/creating-job-triggers): Creating/scheduling, listing, deleting, updating, and viewing detail.
  * [Inspection templates](https://docs.cloud.google.com/sensitive-data-protection/docs/creating-templates-inspect): Creating, listing, deleting, updating, and viewing detail.
  * [Stored custom dictionary infoTypes](https://docs.cloud.google.com/sensitive-data-protection/docs/creating-stored-infotypes): Creating, listing, deleting, updating, and viewing detail.
