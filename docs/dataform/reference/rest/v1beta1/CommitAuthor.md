Represents the author of a Git commit.

JSON representation  
---  
      
    
    {
      "name": string,
      "emailAddress": string
    }  
  
Fields  
---  
`name` |  `string` Required. The commit author's name.  
`emailAddress` |  `string` Required. The commit author's email address.
