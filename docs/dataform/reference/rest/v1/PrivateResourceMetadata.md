#  PrivateResourceMetadata Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Metadata used to identify if a resource is user scoped.

JSON representation  
---  
      
    
    {
      "userScoped": boolean
    }  
  
Fields  
---  
`userScoped` |  `boolean` Output only. If true, this resource is user-scoped, meaning it is either a workspace or sourced from a workspace.
