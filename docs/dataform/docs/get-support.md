## File bugs or feature requests

To file a bug or a feature request, use the [Dataform Issue Tracker](https://cloud.google.com/support/docs/issue-trackers).

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Dataform on [Stack Overflow](https://stackoverflow.com/questions/tagged/#google-dataform). Use the tag `#google-dataform` for questions about Dataform. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and answer questions.

### Discuss Dataform

Fill in [this form](https://forms.gle/rACSD5ojYJBZmEk66) to join the [`dataform-discuss-external`](https://groups.google.com/forum/#!forum/dataform-discuss-external) Google group to receive Dataform announcements and updates.

You can also start a conversation on the [Google Cloud Community forum](https://www.googlecloudcommunity.com/gc/Data-Analytics/bd-p/cloud-data-analytics). Make sure to add the `Dataform` label.
