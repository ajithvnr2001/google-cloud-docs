#  Transition from Dataplex Universal Catalog to Knowledge Catalog Stay organized with collections  Save and categorize content based on your preferences. 

To unify data governance with generative AI capabilities, Dataplex Universal Catalog has transitioned to Knowledge Catalog. This evolution shifts the product focus from a passive metadata registry to an active, AI-powered context graph within Google's [Agentic Data Cloud](https://cloud.google.com/data-cloud). The Agentic Data Cloud is a framework that unifies databases, data warehouses, and AI tools. It builds a semantic context engine that lets AI agents take autonomous actions.

Existing Dataplex Universal Catalog configurations, APIs, and deployments remain operational. Core features like data discovery, data lineage, data quality scans, and business glossaries are unchanged and supported. Existing metadata, aspects, and configurations transition to the Knowledge Catalog experience without manual migration, data movement, or downtime.

## API and client library compatibility

The update to Knowledge Catalog preserves all existing API endpoints, client libraries, and Google Cloud CLI commands:

  * **REST API**. See the [Knowledge Catalog REST API documentation](https://docs.cloud.google.com/knowledge-catalog/docs/reference/rest).
  * **RPC API**. See the [Knowledge Catalog RPC API documentation](https://docs.cloud.google.com/knowledge-catalog/docs/reference/rpc).
  * **Client libraries**. See the language-specific [Knowledge Catalog client libraries](https://docs.cloud.google.com/knowledge-catalog/docs/reference/libraries).
  * **gcloud CLI commands**. Manage resources using the `gcloud dataplex` commands. See the [gcloud Dataplex command reference](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex).



## Key differences with conventional data catalogs

Because organizations accelerate generative AI adoption, AI agents require deep business context to prevent failures and errors. Knowledge Catalog bridges the gap between enterprise data governance and AI agent workflows. It provides the contextual framework that agents need to retrieve accurate, grounded responses.

Unlike conventional passive catalogs, Knowledge Catalog automatically curates metadata, business relationships, and operational rules into a unified context graph. It introduces active, AI-centric features, including verified example queries, and Model Context Protocol (MCP) integrations.
