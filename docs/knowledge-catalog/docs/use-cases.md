##  Knowledge Catalog use cases 

![](https://docs.cloud.google.com/static/knowledge-catalog/images/knowledge-catalog-concept.png)

Knowledge Catalog (formerly Dataplex Universal Catalog) lets you ingest and enrich metadata, enforce data governance, and track data lineage across your data assets. Through these tutorials and reference architectures, you can ground AI agents and analytics workflows with enterprise data context.
