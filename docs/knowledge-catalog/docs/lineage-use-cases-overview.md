#  About lineage use cases Stay organized with collections  Save and categorize content based on your preferences. 

Data lineage in Knowledge Catalog lets you track how data moves through your systems. To explore how you can use data lineage to solve common data management challenges, see the following use cases:

  * **[Analyze the impact of data changes on workflows](https://docs.cloud.google.com/knowledge-catalog/docs/lineage-use-cases-impact-analysis)** to identify how data transformations affect downstream resources and data integrity.
  * **[Analyze causes of Personally Identifiable Information (PII) leak](https://docs.cloud.google.com/knowledge-catalog/docs/lineage-use-cases-pii-leakage)** to trace the flow of sensitive data back to the process that moves it from a trusted to an untrusted location.
  * **[Optimize costs](https://docs.cloud.google.com/knowledge-catalog/docs/lineage-use-cases-cost-optimization)** to reduce storage costs by identifying assets that are not actively used as sources for other processes.
