TensorFlow Enterprise provides a seamless, scalable and supported TensorFlow development experience across a variety of Google Cloud AI products. All TensorFlow Enterprise versions provide users with a Google Cloud optimized distribution of TensorFlow.

## TensorFlow Enterprise distribution

The TensorFlow Enterprise distribution contains custom built TensorFlow binaries and related packages. Each version of the TensorFlow Enterprise distribution is anchored on a particular version of TensorFlow, and all packages included are available in open source.

TensorFlow Enterprise is available to use in the following products:

  * Vertex AI
  * Deep Learning VM Images
  * Deep Learning Containers
  * AI Platform Training



## One year of support

Starting with TensorFlow Enterprise 2.9, each [minor release](https://www.tensorflow.org/guide/versions#semantic_versioning_20) of TensorFlow Enterprise, when used on Google Cloud, is supported with security updates and selected bug fixes for one year.

Previous TensorFlow Enterprise releases that included Long Term Version Support (three years) are still supported for the three-year time period.

The TensorFlow Enterprise distribution is not a fork of TensorFlow. While it is available in Google Cloud products, patches and bug fixes included in the TensorFlow Enterprise distribution are reflected in the mainline TensorFlow code repository.

## What's included in TensorFlow Enterprise

The following packages are included in TensorFlow Enterprise. These packages are updated with non-API breaking changes as they become available and are fully tested.

  * [TensorFlow-io](https://www.tensorflow.org/api_docs/python/tf/io)
  * [TensorFlow-estimator](https://www.tensorflow.org/guide/estimator)
  * [TensorFlow-probability](https://www.tensorflow.org/probability)
  * [TensorFlow-datasets](https://www.tensorflow.org/datasets)
  * [TensorFlow-hub](https://www.tensorflow.org/hub)
  * [fairness-indicators](https://www.tensorflow.org/responsible_ai/fairness_indicators/guide) included with TensorFlow 2.3
  * many more

**Note:** TensorFlow Enterprise does not provide any support for code found within TensorFlow Contrib (`tf.contrib`).
