## Overview

[Google Cloud Observability](https://docs.cloud.google.com/stackdriver) provides powerful monitoring, logging, and diagnostics for Ruby applications.

Ruby libraries are available for the following Google Cloud Observability services:

  * Error Reporting
  * Logging
  * Monitoring
  * Trace



## Error Reporting

[Error Reporting](https://docs.cloud.google.com/error-reporting/docs) for Ruby aggregates and displays errors produced in your running Ruby applications. To get started with Error Reporting, see [Setting Up Error Reporting for Ruby applications](https://docs.cloud.google.com/error-reporting/docs/setup/ruby).

## Logging

[Cloud Logging](https://docs.cloud.google.com/logging/docs) for Ruby allows you to store, search, analyze, monitor, and alert on log data and events in Ruby applications. We provide Bunyan and Winston plugins, as well as a Stackdriver Logging API client library. To get started with Cloud Logging, see [Setting Up Cloud Logging for Ruby applications](https://docs.cloud.google.com/logging/docs/setup/ruby).

## Monitoring

[Cloud Monitoring](https://docs.cloud.google.com/monitoring/docs) for Ruby collects metrics, events, and metadata from Ruby applications. Stackdriver ingests that data and generates insights via dashboards, charts, and alerts.

Links:

  * [Cloud Client Libraries for the Cloud Monitoring API](https://docs.cloud.google.com/monitoring/docs/reference/libraries)
  * [Creating Custom Metrics](https://docs.cloud.google.com/monitoring/custom-metrics/creating-metrics)
  * [Reading Metrics](https://docs.cloud.google.com/monitoring/custom-metrics/reading-metrics)
  * [Browsing Metrics](https://docs.cloud.google.com/monitoring/custom-metrics/browsing-metrics)
  * [Cloud Monitoring for Ruby on GitHub](https://github.com/GoogleCloudPlatform/google-cloud-ruby/tree/master/google-cloud-monitoring)



## Trace

[Cloud Trace](https://docs.cloud.google.com/trace/docs) is a distributed tracing system for Google Cloud that collects latency data from Ruby applications and displays it in near real time in the Google Cloud console. To get started with Cloud Trace, see [Setting Up Cloud Trace for Ruby applications](https://docs.cloud.google.com/trace/docs/setup/ruby).
