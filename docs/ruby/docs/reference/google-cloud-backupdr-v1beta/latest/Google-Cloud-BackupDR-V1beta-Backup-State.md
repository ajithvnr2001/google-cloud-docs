#  Backup and DR Service V1BETA API - Module Google::Cloud::BackupDR::V1beta::Backup::State (v0.1.0) Stay organized with collections  Save and categorize content based on your preferences. 

Reference documentation and code samples for the Backup and DR Service V1BETA API module Google::Cloud::BackupDR::V1beta::Backup::State.

Holds the state of the backup resource.

## Constants 

### STATE_UNSPECIFIED

**value:** 0  
State not set.

### CREATING

**value:** 1  
The backup is being created.

### ACTIVE

**value:** 2  
The backup has been created and is fully usable.

### DELETING

**value:** 3  
The backup is being deleted.

### ERROR

**value:** 4  
The backup is experiencing an issue and might be unusable.

### UPLOADING

**value:** 5  
The backup is being uploaded.
