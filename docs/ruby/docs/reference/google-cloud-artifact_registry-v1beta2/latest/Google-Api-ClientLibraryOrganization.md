Reference documentation and code samples for the Artifact Registry V1beta2 API module Google::Api::ClientLibraryOrganization.

The organization for which the client libraries are being published. Affects the url where generated docs are published, etc.

## Constants 

### CLIENT_LIBRARY_ORGANIZATION_UNSPECIFIED

**value:** 0  
Not useful.

### CLOUD

**value:** 1  
Google Cloud Platform Org.

### ADS

**value:** 2  
Ads (Advertising) Org.

**value:** 3  
Photos Org.

**value:** 4  
Street View Org.

### SHOPPING

**value:** 5

### GEO

**value:** 6
