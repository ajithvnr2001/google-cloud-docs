Reference documentation and code samples for the BigQuery Migration V2 API module Google::Api::MetricDescriptor::ValueType.

The value type of a metric.

## Constants 

### VALUE_TYPE_UNSPECIFIED

**value:** 0  
Do not use this default value.

### BOOL

**value:** 1  
The value is a boolean. This value type can be used only if the metric kind is `GAUGE`.

### INT64

**value:** 2  
The value is a signed 64-bit integer.

### DOUBLE

**value:** 3  
The value is a double precision floating point number.

### STRING

**value:** 4  
The value is a text string. This value type can be used only if the metric kind is `GAUGE`.

### DISTRIBUTION

**value:** 5  
The value is a [`Distribution`](https://docs.cloud.google.com/ruby/docs/reference/google-cloud-bigquery-migration-v2/latest/Google-Api-Distribution "Google::Api::Distribution \(class\)").

### MONEY

**value:** 6  
The value is money.
