Reference documentation and code samples for the Workflows Executions V1beta API module Google::Api::FlowControlLimitExceededBehaviorProto.

The behavior to take when the flow control limit is exceeded.

## Constants 

### UNSET_BEHAVIOR

**value:** 0  
Default behavior, system-defined.

### THROW_EXCEPTION

**value:** 1  
Stop operation, raise error.

### BLOCK

**value:** 2  
Pause operation until limit clears.

### IGNORE

**value:** 3  
Continue operation, disregard limit.
