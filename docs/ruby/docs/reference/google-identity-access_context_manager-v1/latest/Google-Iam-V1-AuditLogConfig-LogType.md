Reference documentation and code samples for the Access Context Manager V1 API module Google::Iam::V1::AuditLogConfig::LogType.

The list of valid permission types for which logging can be configured. Admin writes are always logged, and are not configurable.

## Constants 

### LOG_TYPE_UNSPECIFIED

**value:** 0  
Default case. Should never be this.

### ADMIN_READ

**value:** 1  
Admin reads. Example: CloudIAM getIamPolicy

### DATA_WRITE

**value:** 2  
Data writes. Example: CloudSQL Users create

### DATA_READ

**value:** 3  
Data reads. Example: CloudSQL Users list
