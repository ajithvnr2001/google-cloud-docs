Reference documentation and code samples for the Developer Connect V1 API module Google::Cloud::DeveloperConnect::V1::InstallationState::Stage.

Stage of the installation process.

## Constants 

### STAGE_UNSPECIFIED

**value:** 0  
No stage specified.

### PENDING_CREATE_APP

**value:** 1  
Only for GitHub Enterprise. An App creation has been requested. The user needs to confirm the creation in their GitHub enterprise host.

### PENDING_USER_OAUTH

**value:** 2  
User needs to authorize the GitHub (or Enterprise) App via OAuth.

### PENDING_INSTALL_APP

**value:** 3  
User needs to follow the link to install the GitHub (or Enterprise) App.

### COMPLETE

**value:** 10  
Installation process has been completed.
