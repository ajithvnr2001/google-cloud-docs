Reference documentation and code samples for the Migrate for Compute Engine V1 API module Google::Cloud::VMMigration::V1::AppliedLicense::Type.

License types used in OS adaptation.

## Constants 

### TYPE_UNSPECIFIED

**value:** 0  
Unspecified license for the OS.

### NONE

**value:** 1  
No license available for the OS.

### PAYG

**value:** 2  
The license type is Pay As You Go license type.

### BYOL

**value:** 3  
The license type is Bring Your Own License type.
