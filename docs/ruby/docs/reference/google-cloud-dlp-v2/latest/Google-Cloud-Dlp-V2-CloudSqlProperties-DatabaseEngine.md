Reference documentation and code samples for the Cloud Data Loss Prevention (DLP) V2 API module Google::Cloud::Dlp::V2::CloudSqlProperties::DatabaseEngine.

Database engine of a Cloud SQL instance. New values may be added over time.

## Constants 

### DATABASE_ENGINE_UNKNOWN

**value:** 0  
An engine that is not currently supported by Sensitive Data Protection.

### DATABASE_ENGINE_MYSQL

**value:** 1  
Cloud SQL for MySQL instance.

### DATABASE_ENGINE_POSTGRES

**value:** 2  
Cloud SQL for PostgreSQL instance.
