# Google Cloud Fraud Defense documentation

[Read product documentation](https://docs.cloud.google.com/recaptcha/docs/overview)

Google Cloud Fraud Defense is a unified platform for preventing fraud and abuse, including bot, account, and transaction protection across the agentic web. reCAPTCHA, an offering within Fraud Defense, provides core bot defense capabilities.
