#  Setup overview for Google Cloud Armor Stay organized with collections  Save and categorize content based on your preferences. 

This document provides a high-level overview of setting up Google Cloud Fraud Defense with Google Cloud Armor.

Setting up Fraud Defense with Google Cloud Armor involves the following steps:

  1. [Choose the features for your integration](https://docs.cloud.google.com/recaptcha/docs/features-ca).
  2. Create a reCAPTCHA key for each selected feature.
  3. Configure the Fraud Defense frontend integration.

     * [Integrate with Google Cloud Armor for websites](https://docs.cloud.google.com/recaptcha/docs/implement-waf-ca).
     * [Integrate with Google Cloud Armor for mobile applications](https://docs.cloud.google.com/recaptcha/docs/implement-waf-ca-mobile).
  4. Create security policies to enable protections on selected web pages and paths.

     * Use [reCAPTCHA token attributes](https://docs.cloud.google.com/recaptcha/docs/token-attr-ca) in [Google Cloud Armor security policies](https://docs.cloud.google.com/armor/docs/security-policy-overview).
