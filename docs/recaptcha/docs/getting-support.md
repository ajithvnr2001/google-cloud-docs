## Get a Google Cloud support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical account manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

Google Cloud support packages provide support only for questions regarding Fraud Defense. Google Cloud support redirects questions related to the free version of Fraud Defense to the community support options, such as the Google Cloud Security Community.

## Ask questions in the Google Cloud Security Community forum

You can ask questions about Fraud Defense in the [Google Cloud Security Community forum](https://www.googlecloudcommunity.com/gc/reCAPTCHA-Enterprise/bd-p/recaptcha-forum).

This forum not only receives responses from the Fraud Defense community, but also from Google engineers, who monitor the forum and offer unofficial support.

## File bugs or feature requests

From the Fraud Defense documentation, click **Send feedback** near the top right of the page. This will open a feedback form. Your comments will be reviewed by the Fraud Defense team.
