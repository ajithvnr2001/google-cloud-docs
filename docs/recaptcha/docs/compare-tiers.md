#  Compare features between Google Cloud Fraud Defense tiers Stay organized with collections  Save and categorize content based on your preferences. 

This page lists Fraud Defense features across the Essentials, Premium, and Enterprise tiers. Learn more about [how billing works](https://docs.cloud.google.com/recaptcha/docs/billing-information#how-it-works).

For more information about the tiers, contact your account representative or [Google Cloud sales](https://cloud.google.com/contact).

Feature | Essentials | Premium | Enterprise  
---|---|---|---  
| Provides free, foundational bot protection, with enterprise logging, dashboards, and global fraud reports. | Provides enhanced bot, account, and transaction protection. | Provides comprehensive protection with advanced features tailored for security and fraud analysts, including custom policies, advanced analytics, extended risk scoring, and account manager support.  
**Monthly assessment cost** | 

  * Free up to 10,000 assessments per calendar month*

| 

  * Requires a valid [billing instrument](https://cloud.google.com/billing/docs/concepts) in Google Cloud
  * 0–10,000 assessments per calendar month: Free*
  * 10,001–100,000 assessments per month: $8.00 flat fee
  * More than 100,000 assessments per month: $1.00 per 1,000 assessments

| Fixed monthly volume commitment at $1 per 1,000 assessments.  
**Commitment** | None | Monthly + Pay-As-You-Go | Subscription (Minimum 12 months)  
Bot Protection  
Network bot defense | Yes | Yes | Yes  
Enterprise bot defense | Yes ([4 levels](https://docs.cloud.google.com/recaptcha/docs/interpret-assessment#interpret_scores)) | Yes ([11 levels](https://docs.cloud.google.com/recaptcha/docs/interpret-assessment#interpret_scores)) | Yes ([11 levels](https://docs.cloud.google.com/recaptcha/docs/interpret-assessment#interpret_scores))  
[Visual bot challenges](https://docs.cloud.google.com/recaptcha/docs/choose-key-type#differences-keys) | Yes | Yes | Yes  
[ Explainability reasons ](https://docs.cloud.google.com/recaptcha/docs/interpret-assessment#understand_reason_codes) | No | Basic | Advanced  
Policy-based challenge | No | Yes | Yes  
[ Policy Engine ](https://docs.cloud.google.com/recaptcha/docs/policy-engine) | No | Yes (limited to 3 rules) | Yes  
Mobile Protection  
[iOS SDK](https://docs.cloud.google.com/recaptcha/docs/instrument-ios-apps) | Yes | Yes | Yes  
[Android SDK](https://docs.cloud.google.com/recaptcha/docs/instrument-android-apps) | Yes | Yes | Yes  
Account Protection  
[Account defense](https://docs.cloud.google.com/recaptcha/docs/account-defender) | N/A | Basic explainability reasons | Account takeover risk score, and advanced explainability reasons  
[Password defense](https://docs.cloud.google.com/recaptcha/docs/check-passwords) | No | Yes** | Yes**  
[ SMS defense ](https://docs.cloud.google.com/recaptcha/docs/sms-fraud-detection) | No | Yes** | Yes**  
[Annotation API](https://docs.cloud.google.com/recaptcha/docs/annotate-assessment) | No | Yes | Yes  
[Related accounts API](https://docs.cloud.google.com/recaptcha/docs/account-query-apis) | No | No | Yes  
Transaction Protection  
[ Carding detection ](https://docs.cloud.google.com/recaptcha/docs/fraud-prevention) | No | Yes** | Yes**  
[ Chargeback detection ](https://docs.cloud.google.com/recaptcha/docs/fraud-prevention) | No | Yes** | Yes**  
[ Explainability reasons ](https://docs.cloud.google.com/recaptcha/docs/fraud-prevention#interpret) | No | Yes | Yes  
[Annotation API](https://docs.cloud.google.com/recaptcha/docs/annotate-assessment) | No | Yes | Yes  
[API-only transaction defense](https://docs.cloud.google.com/recaptcha/docs/fraud-prevention#assessment-api) | No | No | Yes  
Enterprise Analytics  
Global fraud report | Yes | Yes | Yes  
Enterprise dashboard | Yes | Yes | Yes  
Platform logging | Yes | Yes | Yes  
Customer-specific fraud report | No | No | Yes  
Attack investigation | No | No | Yes  
Support  
[Community forum](https://docs.cloud.google.com/support/docs/community-support) | Yes | Yes | Yes  
Customer support | Available from Google Cloud | Available from Google Cloud | Available from Google Cloud  
Dedicated account management | No | No | Yes  
  
* The free 10,000 assessments are per organization. The limit aggregates use across all accounts and all sites.
