#  User accounts protection features Stay organized with collections  Save and categorize content based on your preferences. 

This page lists the user account protection features offered by reCAPTCHA for several use cases.

To protect your end user accounts, you can do the following:

  * [Verify an end user's identity with multi-factor authentication (MFA)](https://docs.cloud.google.com/recaptcha/docs/integrate-account-verification).

  * [Detect stolen passwords with Password defense](https://docs.cloud.google.com/recaptcha/docs/check-passwords).

  * [Detect suspicious account activity on websites with Account defense](https://docs.cloud.google.com/recaptcha/docs/account-defender).

  * [Detect suspicious account activity on mobile applications with Account defense](https://docs.cloud.google.com/recaptcha/docs/account-defender-mobile).

  * [Detect and prevent ATOs by using score-based and checkbox challenges](https://docs.cloud.google.com/recaptcha/docs/account-takeovers).

  * [Protect from automated threats by implementing fraud mitigation strategies](https://docs.cloud.google.com/recaptcha/docs/best-practices-oat).
