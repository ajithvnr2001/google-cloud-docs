### MakeImageAnnotatorConnection(Options)

A factory function to construct an object of type [`ImageAnnotatorConnection`](https://docs.cloud.google.com/cpp/docs/reference/vision/latest/classgoogle_1_1cloud_1_1vision__v1_1_1ImageAnnotatorConnection). 

The returned connection object should not be used directly; instead it should be passed as an argument to the constructor of [ImageAnnotatorClient](https://docs.cloud.google.com/cpp/docs/reference/vision/latest/classgoogle_1_1cloud_1_1vision__v1_1_1ImageAnnotatorClient).

The optional `options` argument may be used to configure aspects of the returned [`ImageAnnotatorConnection`](https://docs.cloud.google.com/cpp/docs/reference/vision/latest/classgoogle_1_1cloud_1_1vision__v1_1_1ImageAnnotatorConnection). Expected options are any of the types in the following option lists:

  * [`google::cloud::CommonOptionList`](https://docs.cloud.google.com/cpp/docs/reference/common/latest/namespacegoogle_1_1cloud.html)
  * [`google::cloud::GrpcOptionList`](https://docs.cloud.google.com/cpp/docs/reference/common/latest/namespacegoogle_1_1cloud.html)
  * [`google::cloud::UnifiedCredentialsOptionList`](https://docs.cloud.google.com/cpp/docs/reference/common/latest/namespacegoogle_1_1cloud.html)
  * [`google::cloud::vision_v1::ImageAnnotatorPolicyOptionList`](about:invalid#zCSafez)

**Note:** Unexpected options will be ignored. To log unexpected options instead, set `GOOGLE_CLOUD_CPP_ENABLE_CLOG=yes` in the environment.
