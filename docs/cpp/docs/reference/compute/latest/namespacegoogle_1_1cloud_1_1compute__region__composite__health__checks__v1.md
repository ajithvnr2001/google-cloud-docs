### MakeRegionCompositeHealthChecksConnectionRest(Options)

A factory function to construct an object of type [`RegionCompositeHealthChecksConnection`](https://docs.cloud.google.com/cpp/docs/reference/compute/latest/classgoogle_1_1cloud_1_1compute__region__composite__health__checks__v1_1_1RegionCompositeHealthChecksConnection) that uses REST over HTTP as transport in lieu of gRPC. 

REST transport should only be used for services that do not support gRPC or if the existing network configuration precludes using gRPC.

The returned connection object should not be used directly; instead it should be passed as an argument to the constructor of [RegionCompositeHealthChecksClient](https://docs.cloud.google.com/cpp/docs/reference/compute/latest/classgoogle_1_1cloud_1_1compute__region__composite__health__checks__v1_1_1RegionCompositeHealthChecksClient).

The optional `options` argument may be used to configure aspects of the returned [`RegionCompositeHealthChecksConnection`](https://docs.cloud.google.com/cpp/docs/reference/compute/latest/classgoogle_1_1cloud_1_1compute__region__composite__health__checks__v1_1_1RegionCompositeHealthChecksConnection). Expected options are any of the types in the following option lists:

  * [`google::cloud::CommonOptionList`](https://docs.cloud.google.com/cpp/docs/reference/common/latest/namespacegoogle_1_1cloud.html)
  * [`google::cloud::RestOptionList`](https://docs.cloud.google.com/cpp/docs/reference/common/latest/namespacegoogle_1_1cloud.html)
  * [`google::cloud::UnifiedCredentialsOptionList`](https://docs.cloud.google.com/cpp/docs/reference/common/latest/namespacegoogle_1_1cloud.html)
  * [`google::cloud::compute_region_composite_health_checks_v1::RegionCompositeHealthChecksPolicyOptionList`](about:invalid#zCSafez)
