# Universal Ledger documentation

[Read product documentation](https://docs.cloud.google.com/universal-ledger/overview)

The Universal Ledger API provides financial institutions and intermediaries access to a managed, distributed ledger network. Use this API to build innovative payment services, create financial market products, simplify the management of commercial bank money accounts, and facilitate secure transfers. Universal Ledger empowers these organizations to meet evolving client demands and enhance their competitive edge. [Learn more](https://docs.cloud.google.com/universal-ledger/overview).
