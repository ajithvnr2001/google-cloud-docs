# Deep Learning VM Images pricing

## Pricing overview

Deep Learning VM Images instances are free to use. Because Deep Learning VM runs on Compute Engine, pricing for resource usage is provided in [Compute Engine Pricing](https://docs.cloud.google.com/compute/pricing).
