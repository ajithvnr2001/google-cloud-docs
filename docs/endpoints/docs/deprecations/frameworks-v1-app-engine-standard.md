#  Cloud Endpoints Framework v1 for App Engine standard environment deprecation Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Endpoints Frameworks v1 for the App Engine standard environment was deprecated on August 2, 2017. The service is scheduled to be shutdown on September 3, 2018, and the documentation will be removed. To avoid an outage, you must migrate your v1 application. For information on migrating your application to Endpoints Frameworks v2, see the following:

  * [Java: Migration Guide](https://docs.cloud.google.com/endpoints/docs/frameworks/java/migrating)
  * [Java: Migrating Android Projects](https://docs.cloud.google.com/endpoints/docs/frameworks/java/migrating-android)
  * [Python: Migration Guide](https://docs.cloud.google.com/endpoints/docs/frameworks/python/migrating)



## Shutdown schedule

The following table lists the shutdown schedule for Cloud Endpoints Portal.

Date | Event  
---|---  
**August 2, 2017** | Cloud Endpoints Frameworks v1 for the App Engine standard environment deprecated  
**September 3, 2018** | Cloud Endpoints Frameworks v1 for the App Engine standard environment shut down
