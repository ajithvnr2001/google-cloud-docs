#  Cloud Endpoints Portal deprecation Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Endpoints Portal was used to create a developer portal, a website that users of your Cloud Endpoints API can access to explore and test your APIs. Cloud Endpoints Portal was deprecated as an API documentation tool for Cloud Endpoints on March 21, 2022.

API traffic managed by Cloud Endpoints is not affected by this change.

We encourage you to back up any data that is important to you before March 21, 2023. Please be aware that as part of the deprecation process, we will disable creation of new Cloud Endpoints Portals on April 21, 2022.

## Shutdown schedule

The following table lists the shutdown schedule for Cloud Endpoints Portal.

Date | Event  
---|---  
**March 21, 2022** | Cloud Endpoints Portal deprecated  
**April 21, 2022** | Creation of new Cloud Endpoints Portals disabled  
**March 21, 2023** | Cloud Endpoints Portal shut down
