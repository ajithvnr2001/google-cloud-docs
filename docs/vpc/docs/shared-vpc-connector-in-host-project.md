# Configure Shared VPC with connectors in host project

If your organization uses Shared VPC, you can set up [Serverless VPC Access](https://docs.cloud.google.com/vpc/docs/serverless-vpc-access) connectors in either the [service project or the host project](https://docs.cloud.google.com/vpc/docs/shared-vpc#shared_vpc_host_project_and_service_project_associations).

## Advantages

To learn about the advantages of configuring Shared VPC with connectors in the host project, see the comparison of configuration methods for your product:

  * [Cloud Run](https://docs.cloud.google.com/run/docs/configuring/connecting-shared-vpc#host-project)
  * [Cloud Run functions](https://docs.cloud.google.com/functions/docs/networking/connecting-shared-vpc#host-project)
  * [App Engine standard environment](https://docs.cloud.google.com/appengine/docs/standard/python3/connecting-shared-vpc#host-project)



## Configuration

For instructions on how to configure Shared VPC with connectors in the host project, see the configuration page for your product:

  * [Cloud Run](https://docs.cloud.google.com/run/docs/configuring/shared-vpc-host-project)
  * [Cloud Run functions](https://docs.cloud.google.com/functions/docs/networking/shared-vpc-host-project)
  * [App Engine standard environment](https://docs.cloud.google.com/appengine/docs/standard/python3/shared-vpc-host-project)
