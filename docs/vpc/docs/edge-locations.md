# Network edge locations

Google Cloud offers connections to Google Cloud services from over 200 locations across the following metropolitan areas.

These locations offer connectivity through one or more of the following methods:

  * [Cloud Interconnect](https://docs.cloud.google.com/network-connectivity/docs/interconnect)

For a list of Cloud Interconnect facilities, see [All colocation facilities](https://docs.cloud.google.com/network-connectivity/docs/interconnect/concepts/choosing-colocation-facilities).

  * [Verified Peering Provider](https://docs.cloud.google.com/network-connectivity/docs/verified-peering-provider)

For a list of Verified Peering Providers, see [Verified Peering Providers](https://peering.google.com/#/options/verified-peering-provider).

  * [Direct Peering](https://docs.cloud.google.com/network-connectivity/docs/direct-peering)

For list of Direct Peering facilities, see [PeeringDB](https://www.peeringdb.com/asn/15169).
