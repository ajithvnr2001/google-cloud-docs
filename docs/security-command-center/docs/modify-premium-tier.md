#  Modify Security Command Center Premium tier configuration Stay organized with collections  Save and categorize content based on your preferences. 

Premium [service tier](https://docs.cloud.google.com/security-command-center/docs/service-tiers)

This document describes how to modify an existing Security Command Center Premium tier activation for the following use cases:

  * Change Premium tier activation from project-level to organization-level

  * Switch to pay-as-you-go pricing as an organization using an expiring Premium tier subscription

  * Downgrade from Premium tier to Standard tier

  * Deactivate Security Command Center




Tier changes might affect the availability and behavior of services. For more details, see Effects of tier changes on services.

Any of these changes might affect pricing. For more details, see [Security Command Center pricing](https://cloud.google.com/security-command-center/pricing).

## Change to organization-level activation of the Premium tier

To change from a project-level activation to an organization-level activation, you must first review and complete all of the items in the [Before you begin](https://docs.cloud.google.com/security-command-center/docs/activate-premium-tier#before-you-begin) section of the Security Command Center Premium tier activation documentation. Then, follow the instructions in [Activate Security Command Center Premium at the organization level](https://docs.cloud.google.com/security-command-center/docs/activate-premium-tier#activate-premium).

**Note:** If you change to an organization-level activation, don't revoke the roles granted to any service agents that were created when you activated Security Command Center at the project level. If you revoke roles from the service agents, then some detectors might not work correctly.

### Switch to the Premium tier pay-as-you-go option

If your organization uses a Security Command Center Premium tier subscription, you can enroll in pay-as-you-go pricing before your subscription expires to provide uninterrupted access to Security Command Center Premium.

To enroll in pay-as-you-go pricing, complete the following steps:

  1. In the Google Cloud console, go to the **Tier details** page.

[Go to Tier details](https://console.cloud.google.com/projectselector2/security/command-center/config/tier-detail?supportedpurview=organizationId)

  2. Select the organization that you want to switch the pricing option for, and then click **Select**.

  3. Click **Manage tier**.

  4. In the **Manage tier** pane, verify that **Premium** is selected and click **Update**.




Once you have completed these steps and your subscription expires, the pay-as-you-go pricing takes effect.

### Downgrade from the Premium tier to the Standard tier

Complete the following steps to change from the pay-as-you-go payment option for the Security Command Center Premium tier to the Security Command Center Standard tier. By default, if you have a subscription, you are automatically downgraded to the Standard tier when the subscription expires.

When you downgrade to the Security Command Center Standard tier:

  * You lose access to Premium tier services and features. Verify that your organization's security risk profile isn't negatively affected before you make this change.

  * For active findings, the state that is generated by detectors that are only supported in the Premium tier but not in the Standard tier is set to `INACTIVE`. For details about how long your findings and configurations are retained after a tier downgrade, see [Data retention for findings](https://docs.cloud.google.com/security-command-center/docs/concepts-data-security-overview#data_retention).




Even though the Security Command Center Standard tier is free, you might still experience indirect charges. For more information, see [Possible indirect charges associated with Security Command Center](https://cloud.google.com/security-command-center/pricing#possible-indirect-charges-associated-with-security-command-center).

  1. In the Google Cloud console, go to the **Tier details** page.

[Go to Tier details](https://console.cloud.google.com/projectselector2/security/command-center/config/tier-detail?supportedpurview=organizationId)

  2. Select the organization that you want to downgrade the Security Command Center tier for, and then click **Select**.

  3. Click **Manage tier**.

  4. In the **Manage tier** pane, click **Select** for the Standard tier and click **Update**.




## Effects of tier changes on services

Service availability and behavior can change when you switch tiers. If you use any of the following services, before you upgrade or downgrade, review this documentation to understand how tier changes affect the services:

  * [Compliance Manager](https://docs.cloud.google.com/security-command-center/docs/compliance-manager-enable#manage-service-tiers)

  * [Data Security Posture Management (DSPM)](https://docs.cloud.google.com/security-command-center/docs/dspm-use-data-security#downgrade-tiers)

  * [Security Health Analytics](https://docs.cloud.google.com/security-command-center/docs/concepts-security-health-analytics#switching-tiers)

  * [Vulnerability Assessment for Google Cloud](https://docs.cloud.google.com/security-command-center/docs/vulnerability-assessment-google-cloud#upgrade-downgrade)




## Deactivate Security Command Center

To deactivate Security Command Center, contact [Cloud Customer Care](https://docs.cloud.google.com/support).
