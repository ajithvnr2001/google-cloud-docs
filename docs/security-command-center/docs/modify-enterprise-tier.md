Enterprise (Deprecated) [service tier](https://docs.cloud.google.com/security-command-center/docs/service-tiers) The Security Command Center Enterprise service tier will shut down on May 21, 2027. If your organization uses the Enterprise service tier, then the organization will automatically move to the Premium service tier on or after May 21, 2027. Contact your account representative or a [Google Cloud sales specialist](https://cloud.google.com/contact) if you have questions. 

This document describes how to modify an existing Security Command Center Enterprise tier activation for the following use cases:

  * Set your organization to downgrade to the Premium tier or Standard tier when your Enterprise subscription ends

  * Deactivate Security Command Center




### Downgrade when your Enterprise tier subscription ends

By default, if you have a subscription, you are automatically downgraded to the Standard tier when the subscription expires. Before your Security Command Center Enterprise subscription ends, you can select which other Security Command Center tier you want to downgrade to when your subscription ends.

When your Security Command Center Enterprise subscription ends:

  * You lose access to [Enterprise tier services and features](https://docs.cloud.google.com/security-command-center/docs/service-tiers). Verify that your organization's security risk profile isn't negatively affected before you make this change.

  * For active findings, the state that is generated by detectors that are only supported on the Enterprise tier is set to `INACTIVE`. For details about how long your findings and configurations are retained after a tier downgrade, see [Data retention for findings](https://docs.cloud.google.com/security-command-center/docs/concepts-data-security-overview#data_retention).

  * All [Google Cloud-native log ingestion to Google SecOps](https://docs.cloud.google.com/chronicle/docs/ingestion/default-parsers/ingest-gcp-logs) is disabled, including Security Command Center finding ingestion. If you maintain a Google SecOps license, you can [re-enable log ingestion](https://docs.cloud.google.com/chronicle/docs/ingestion/default-parsers/ingest-gcp-logs#enable-direct-ingestion).




Even though the Security Command Center Standard tier is free, you might still experience indirect charges. For more information, see [Possible indirect charges associated with Security Command Center](https://cloud.google.com/security-command-center/pricing#possible-indirect-charges-associated-with-security-command-center).

Complete the following steps to select which Security Command Center tier, Premium or Standard, you want to downgrade to when your Security Command Center Enterprise subscription ends.

**Note:** If you select Security Command Center Premium, you begin to incur [pay-as-you-go charges](https://cloud.google.com/security-command-center/pricing#premium-tier-pay-as-you-go-pricing) once your Security Command Center Enterprise subscription ends.

  1. In the Google Cloud console, go to the **Tier details** page.

[Go to Tier details](https://console.cloud.google.com/projectselector2/security/command-center/config/tier-detail?supportedpurview=organizationId)

  2. Select the organization that you want to downgrade the Security Command Center tier for, and then click **Select**.

  3. Click **Manage tier**.

  4. In the **Manage tier** pane, click **Select** for the Premium or Standard tier and click **Update**.




Once you have completed these steps and your subscription expires, your new tier takes effect.

## Deactivate Security Command Center

To deactivate Security Command Center, contact [Cloud Customer Care](https://docs.cloud.google.com/support).
