Enterprise (Deprecated) [service tier](https://docs.cloud.google.com/security-command-center/docs/service-tiers) The Security Command Center Enterprise service tier will shut down on May 21, 2027. If your organization uses the Enterprise service tier, then the organization will automatically move to the Premium service tier on or after May 21, 2027. Contact your account representative or a [Google Cloud sales specialist](https://cloud.google.com/contact) if you have questions. 

You can connect Security Command Center Enterprise to other cloud platforms so that you can detect, investigate, and respond to threats and vulnerabilities from a single place. A connection to another cloud also lets you use Security Command Center to monitor compliance for your other cloud deployments.

During the [activation process for the Security Command Center Enterprise tier](https://docs.cloud.google.com/security-command-center/docs/activate-enterprise-tier), you can set up connections with the following cloud providers:

  * Amazon Web Services (AWS):

    * To change the AWS connector settings, see [Update AWS connection settings](https://docs.cloud.google.com/security-command-center/docs/update-aws-settings).
  * To change the connection settings for log data ingestion, see [Ingest AWS logs into Security Operations console](https://docs.cloud.google.com/chronicle/docs/ingestion/ingest-aws-logs-into-chronicle).

  * Microsoft Azure:

    * To collect data for vulnerability detection and risk assessment, see [Connect to Microsoft Azure for vulnerability detection and risk assessment](https://docs.cloud.google.com/security-command-center/docs/connect-scc-to-azure).

    * To collect data for threat detection, see [Connect to Microsoft Azure for log ingestion](https://docs.cloud.google.com/security-command-center/docs/connect-secops-azure).
