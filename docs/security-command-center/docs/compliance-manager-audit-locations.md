#  Audit locations for Compliance Manager Stay organized with collections  Save and categorize content based on your preferences. 

Premium and Enterprise (Deprecated) [service tiers](https://docs.cloud.google.com/security-command-center/docs/service-tiers)

This document describes the regions and multi-regions where the audits that you can complete with Compliance Manager are processed. For more information about supported Google Cloud regions, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions). For instructions on how to complete an audit, see [Audit your environment with Compliance Manager](https://docs.cloud.google.com/security-command-center/docs/compliance-manager-audit).

**Note:** This page applies to the audit feature within Compliance Manager only. This page doesn't apply to other features such as creating, applying, and monitoring frameworks and cloud controls.
