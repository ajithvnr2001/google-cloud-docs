## Overview

An attempt was made to modify the `ld.so.preload` file. Changes to `ld.so.preload` can be used by attackers to preload malicious shared libraries into a system's library set. An attacker could use this to hijack the execution flow by loading their own libraries during program execution, potentially leading to privilege escalation or evasion of defense mechanisms. This is a file monitoring detector and has [ specific GKE version requirements](https://docs.cloud.google.com/security-command-center/docs/how-to-use-container-threat-detection#gke-version). This detector is disabled by default. For instructions on how to enable it, see [ Testing Container Threat Detection](https://docs.cloud.google.com/security-command-center/docs/how-to-test-container-threat-detection).

[Container Threat Detection](https://docs.cloud.google.com/security-command-center/docs/concepts-container-threat-detection-overview) is the source of this finding.
