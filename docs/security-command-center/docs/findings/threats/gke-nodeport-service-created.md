## Overview

Someone created a NodePort service. NodePort services expose Pods directly on a node's IP address and static port, which makes the Pods accessible from outside the cluster. This can introduce a significant security risk because it could allow an attacker to exploit vulnerabilities in the exposed service to gain access to the cluster or sensitive data.

[Event Threat Detection](https://docs.cloud.google.com/security-command-center/docs/concepts-event-threat-detection-overview) is the source of this finding.

## How to respond

The following response plan might be appropriate for this finding, but might also impact operations. Carefully evaluate the information you gather in your investigation to determine the best way to resolve findings. 

To respond to this finding, do the following:

  1. Review the service's configuration to determine its purpose.
  2. Consider restricting network policies to secure the service.
