Enterprise (Deprecated) [service tier](https://docs.cloud.google.com/security-command-center/docs/service-tiers) The Security Command Center Enterprise service tier will shut down on May 21, 2027. If your organization uses the Enterprise service tier, then the organization will automatically move to the Premium service tier on or after May 21, 2027. Contact your account representative or a [Google Cloud sales specialist](https://cloud.google.com/contact) if you have questions. 

Advanced configuration for threat management helps you obtain as much information about threats as possible, by integrating Security Command Center with other optional products and services using its security orchestration, automation, and response (SOAR) features.

To identify, enrich, and triage threats, certain integrations provided in the Enterprise tier of Security Command Center require you to manually configure them.

To configure optional integrations for advanced threat management, refer to the following pages in the Google SecOps documentation:

  1. [AWS Elastic Compute Cloud (EC2)](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/aws-elastic-compute-cloud-ec2)
  2. [AWS Identity and Access Management (IAM)](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/aws-iam)
  3. [Email V2](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/email-v2)
  4. [Mandiant Threat Intelligence](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/mandiant-threat-intelligence)
  5. [VirusTotalV3](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/virustotal-v3)
