Standard-legacy and Standard [service tiers](https://docs.cloud.google.com/security-command-center/docs/service-tiers) (requires [organization-level activation](https://docs.cloud.google.com/security-command-center/docs/activate-scc-overview#overview_of_organization-level_activation))

This document describes how to modify an existing Security Command Center Standard tier activation for the following use cases:

  * Upgrade from Standard tier to Premium tier

  * Deactivate Security Command Center




### Upgrade from the Standard tier to the Premium tier

Upgrading affects your pricing. For more details, see [Security Command Center pricing](https://cloud.google.com/security-command-center/pricing).

Before you upgrade, you must review and complete all of the items in the [Before you begin](https://docs.cloud.google.com/security-command-center/docs/activate-premium-tier#before-you-begin) section of the Security Command Center Premium tier activation documentation.

Then, complete the following steps to upgrade from the Security Command Center Standard tier to the Security Command Center Premium tier.

  1. In the Google Cloud console, go to the **Tier details** page.

[Go to Tier details](https://console.cloud.google.com/projectselector2/security/command-center/config/tier-detail?supportedpurview=organizationId)

  2. Select the organization that you want to upgrade the Security Command Center tier for, and then click **Select**.

  3. Click **Upgrade to Premium**.

  4. In the **Manage tier** pane, click **Update**.




## Deactivate Security Command Center

To deactivate Security Command Center, contact [Cloud Customer Care](https://docs.cloud.google.com/support).
