#  Compute Engine threat findings Stay organized with collections  Save and categorize content based on your preferences. 

Security Command Center performs agentless and log-based monitoring of Compute Engine resources. For recommended responses to these threats, see [Respond to Compute Engine threat findings](https://docs.cloud.google.com/security-command-center/docs/respond-compute-engine-threats).

## Agentless monitoring finding types

The following agentless monitoring detections are available with [Virtual Machine Threat Detection](https://docs.cloud.google.com/security-command-center/docs/concepts-vm-threat-detection-overview):

  * [ `Defense Evasion: Rootkit`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-rootkit)
  * [ `Defense Evasion: Unexpected ftrace handler`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-unexpected-ftrace-handler)
  * [ `Defense Evasion: Unexpected interrupt handler`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-unexpected-interrupt-handler)
  * [ `Defense Evasion: Unexpected kernel modules`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-unexpected-kernel-modules)
  * [ `Defense Evasion: Unexpected kernel read-only data modification`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-unexpected-kernel-read-only-data-modification)
  * [ `Defense Evasion: Unexpected kprobe handler`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-unexpected-kprobe-handler)
  * [ `Defense Evasion: Unexpected processes in runqueue`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-unexpected-processes-in-runqueue)
  * [ `Defense Evasion: Unexpected system call handler`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/defense-evasion-unexpected-system-call-handler)
  * [ `Execution: cryptocurrency mining combined detection`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/execution-cryptocurrency-mining-combined-detection)
  * [ `Execution: Cryptocurrency Mining Hash Match`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/execution-cryptocurrency-mining-hash-match)
  * [ `Execution: Cryptocurrency Mining YARA Rule`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/execution-cryptocurrency-mining-yara-rule)
  * [ `Malware: Malicious file on disk`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/malware-malicious-file-on-disk)
  * [ `Malware: Malicious file on disk (YARA)`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/malware-malicious-file-on-disk-yara)



## Log-based finding types

The following log-based detections are available with [Event Threat Detection](https://docs.cloud.google.com/security-command-center/docs/concepts-event-threat-detection-overview):

  * [ `Brute force SSH`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/ssh-brute-force)
  * [ `Impact: Managed Instance Group Autoscaling Set To Maximum`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/yl2-mig-autoscaling-set-to-max)
  * [ `Lateral Movement: Modified Boot Disk Attached to Instance`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/modify-boot-disk-attach-to-instance)
  * [ `Lateral Movement: OS Patch Execution From Service Account`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/yl2-os-patch-execution-from-service-account)
  * [ `Persistence: GCE Admin Added SSH Key`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/gce-admin-add-ssh-key)
  * [ `Persistence: GCE Admin Added Startup Script`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/gce-admin-add-startup-script)
  * [ `Persistence: Global Startup Script Added`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/yl2-global-startup-script-added)
  * [ `Privilege Escalation: Global Shutdown Script Added`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/yl2-global-shutdown-script-added)



The following log-based detections are available with [Sensitive Actions Service](https://docs.cloud.google.com/security-command-center/docs/concepts-sensitive-actions-overview):

  * [ `Impact: GPU Instance Created`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/sensitive-action-gpu-instance-created)
  * [ `Impact: Many Instances Created`](https://docs.cloud.google.com/security-command-center/docs/findings/threats/sensitive-action-many-instances-created)
