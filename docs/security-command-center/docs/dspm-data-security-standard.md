Data Security Posture Management (DSPM) in the Security Command Center Standard tier offers baseline data security features at the organization level through the Security Essentials framework, which includes foundational data security controls.

DSPM lets you complete the following data security tasks:

  * **Basic posture management:** Understand your data security posture against essential best practices.
  * **Risk awareness:** Identify potential issues through findings from the included controls.



## DSPM in the Security Command Center Standard tier

The Standard tier includes the Security Essentials framework which provides baseline controls for data security and compliance. Findings are generated for deviations from these controls.

DSPM provides the following essential insights:

  * **Learning resources:** Current information on DSPM features and their value.
  * **Top findings:** A summary of top data security findings from the Security Essentials framework.
  * **Data map:** A visual representation of a sample of assets with findings. The Standard tier version provides a limited experience compared to the Premium and Enterprise tiers.
  * **Resources table:** A list of resources that you can filter by display name, location, resource type, and associated project. From the table, you can navigate to the **Assets** and **Findings** pages to view detailed asset and finding information for a resource.



## Limitations in the Standard tier

The following DSPM functionalities aren't available in the Security Command Center Standard tier:

  * Advanced data governance and security cloud controls, such as Data Access Governance and Data Flow Governance.
  * Advanced risk analysis features.
  * Custom data security frameworks.
  * The full, unrestricted DSPM dashboard.
