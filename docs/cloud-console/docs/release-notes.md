## May 26, 2026

Deprecated

The [Dashboard](https://console.cloud.google.com/home/dashboard) is deprecated and will be removed in May 2027. Use [Cloud Hub](https://docs.cloud.google.com/hub/docs) to get a more comprehensive view of your applications and resources.

  * Access project overview, news, and getting started information on the [Home](https://docs.cloud.google.com/hub/docs/home) page.
  * Review Google Cloud incidents, open alerts, metrics, logs, and other observability data on the [Health & troubleshooting](https://docs.cloud.google.com/hub/docs/health) page.
  * View quotas with over 90% usage on the [Quotas & reservations](https://docs.cloud.google.com/hub/docs/quotas-reservations) page or monitor usage on the [API Dashboard](https://docs.cloud.google.com/apis/docs/monitoring).
  * View cost data, cost optimization recommendations, and Gemini Cloud Assist insights on the [Optimization](https://docs.cloud.google.com/hub/docs/optimize) page. If you manage your project's billing account, [FinOps hub](https://docs.cloud.google.com/billing/docs/how-to/finops-hub) provides additional billing data as well as cost optimization recommendations.



## December 16, 2022

Change

You can now enable a keyboard shortcuts helper. This overlay displays contextual shortcuts based on what's on the screen, or which UI element is focused such as code editors, tables, and menu bars.

For more information, see [Keyboard shortcuts](https://docs.cloud.google.com/docs/shortcuts#view_contextual_keyboard_shortcuts).

## September 03, 2021

Change

Keyboard shortcuts are now [WCAG 2.1](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-21/#guideline-21-keyboard-accessible) compliant:

  * You can turn off a shortcut.
  * You can remap a shortcut to include one or more non-printable keyboard keys.



For more information, see [Keyboard shortcuts](https://docs.cloud.google.com/docs/shortcuts).
