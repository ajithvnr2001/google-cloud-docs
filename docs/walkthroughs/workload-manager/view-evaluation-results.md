### Before you begin

Before viewing evaluation results, first make sure you've created an evaluation. 

### View evaluation results

After your evaluation completes, the results are available for you to view in the Workload Manager results page. The results page contains metadata for your evaluation, including evaluation name, description, and last evaluation time, along with the results for your evaluation. 

To view evaluation results, follow these steps:

  1. Click the evaluation name.
  2. On the **Evaluation information** page, click **Results**.
  3. For each **Evaluation rule** , do the following: 
     1. Click the **Best practice name**.
     2. Note the **Severity**.
     3. Read the **Message** to learn why the resource is not adhering to the best practice and for information about how to modify the resource.
     4. To go to resource's Google Cloud console page to modify the resource, in **Resource** , click the resource name.



### View evaluation history

To view evaluation history, follow these steps:

  1. Click the evaluation name to view the **Evaluation information** page.
  2. In the **Execution history** section, select the timestamp of the evaluation to view the results.
