This page describes how to enable the Blockchain Node Engine API using the console.

To enable the Blockchain Node Engine API in the Google Cloud console:

  1. In the Google Cloud console, go to the **Blockchain Node Engine** API page.

[Enable the API](https://console.cloud.google.com/apis/library/blockchainnodeengine.googleapis.com)

If the Blockchain Node Engine API is not yet enabled, you see a button labeled **Enable**. Otherwise, you see a button labeled **Manage**.

  2. Click **Enable**. It can take a couple of minutes for this command to complete.
