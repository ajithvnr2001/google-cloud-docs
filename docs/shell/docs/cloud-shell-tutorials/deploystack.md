##  DeployStack 

**One click solutions focused on making developers successful**

DeployStack is a series of applications that are prebuilt and architected to demonstrate common application architectures and share projects that can be repurposed to support your needs. Each one requires just one command to run, and when the process is done, a fully functional version of the app is available and running, ready to use or modify.

[ ![](https://docs.cloud.google.com/static/shell/docs/cloud-shell-tutorials/deploystack/images/arch-costsentry.svg)](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/cost-sentry)

###  [ Cost Sentry ](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/cost-sentry)

Cost Sentry is a simple set of scripts and configurations that allow you to shut down resources when Google Cloud Billing Budgets are exceeded. 

[ ![](https://docs.cloud.google.com/static/shell/docs/cloud-shell-tutorials/deploystack/images/arch-batchetl.svg)](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/etl-pipeline)

###  [ ETL Pipeline ](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/etl-pipeline)

ETL Pipeline is an architecture for running batch data processing pipelines using the extract, transform, load method. 

[ ![](https://docs.cloud.google.com/static/shell/docs/cloud-shell-tutorials/deploystack/images/arch-basiclb.svg)](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/load-balanced-vms)

###  [ Load Balanced VMs ](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/load-balanced-vms)

Load Balanced VMs is a simple infrastructure building script that sets up a cluster of VMs and puts a Load Balancer in front of them to expose publically. 

[ ![](https://docs.cloud.google.com/static/shell/docs/cloud-shell-tutorials/deploystack/images/arch-nosql-client-server.svg)](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/nosql-client-server)

###  [ NoSQL Client Server ](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/nosql-client-server)

NoSQL Client Server configures and creates two Compute Engine instances to work with MongoDB. 

[ ![](https://docs.cloud.google.com/static/shell/docs/cloud-shell-tutorials/deploystack/images/arch-ops-agent.svg)](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/ops-agent)

###  [ Ops Agent ](https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/deploystack/ops-agent)

Ops Agent creates a virtual machine and installs the Ops Agent for integrating with Monitoring and Logging services.

Serverless End-To-End Photo Sharing Application creates a scalable end-to-end photo-sharing application with 11 Google Cloud products, Terraform, and Django.
