## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Ask a question on Stack Overflow

Ask a question about Cloud Shell on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-shell). Use the tag `google-cloud-shell` for questions about Cloud Shell. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

## Discuss Cloud Shell

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud Shell and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Cloud Shell, join the [`#cloud-shell`](https://googlecloud-community.slack.com/messages/C6D623AMN/) channel. 

## File bugs or feature requests

From the Cloud Shell documentation, click either **Send feedback** link on the page. This will open a feedback form. Your comments will be reviewed by the Cloud Shell team.
