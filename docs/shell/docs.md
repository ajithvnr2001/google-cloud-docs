# Cloud Shell documentation

[Read product documentation](https://docs.cloud.google.com/shell/docs/how-cloud-shell-works)

Cloud Shell is an interactive shell environment for Google Cloud that lets you learn and experiment with Google Cloud and manage your projects and resources from your web browser. 

With Cloud Shell, the [Google Cloud CLI](https://docs.cloud.google.com/sdk/gcloud) and other utilities you need are pre-installed, fully authenticated, up-to-date, and always available when you need them. Cloud Shell comes with a built-in code editor with an integrated Cloud Code experience, allowing you to develop, build, debug, and deploy your cloud-based apps entirely in the cloud. You can also launch interactive tutorials, open cloned repositories, and preview web apps on a Cloud Shell virtual machine instance.
