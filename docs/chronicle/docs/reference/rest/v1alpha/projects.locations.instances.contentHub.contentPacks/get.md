**Full name** : projects.locations.instances.contentHub.contentPacks.get

Gets a single `ContentPack` by its resource name. Use this method to retrieve the full manifest and metadata of a content package.

### HTTP request

`GET https://{endpoint}/v1alpha/{name}`

Where `{endpoint}` is one of the [supported service endpoints](https://docs.cloud.google.com/chronicle/docs/reference/rest#rest_endpoints).

### Path parameters

Parameters  
---  
`name` |  `string` Required. The resource name of the ContentPack to retrieve. Format: projects/{project}/locations/{location}/instances/{instance}/contentHub/contentPacks/{contentPack}  
  
### Query parameters

Parameters  
---  
`expand` |  `string` Optional. Expand the response with the full content pack details.  
  
### Request body

The request body must be empty.

### Response body

If successful, the response body contains an instance of `[ContentPack](https://docs.cloud.google.com/chronicle/docs/reference/rest/v1alpha/projects.locations.instances.contentHub.contentPacks#ContentPack)`.

### Authorization scopes

Requires one of the following OAuth scopes:

  * `https://www.googleapis.com/auth/cloud-platform`
  * ` https://www.googleapis.com/auth/chronicle`



For more information, see the [Authentication Overview](https://docs.cloud.google.com/docs/authentication#authorization-gcp).

### IAM Permissions

Requires the following [IAM](https://cloud.google.com/iam/docs) permission on the `name` resource:

  * `chronicle.contentPacks.get`



For more information, see the [IAM documentation](https://cloud.google.com/iam/docs).
