#  ParserView Stay organized with collections  Save and categorize content based on your preferences. 

Specifies the amount of detail to return for a parser.

Enums  
---  
`PARSER_VIEW_UNSPECIFIED` | The default / unset value. The API will default to the FULL view for backward compatibility.  
`BASIC_VIEW` | Include basic metadata about the parser (including high-level AI generation state metadata `aiParserGenerationMetadata.generation_job_id`) and `generationStage`, but not the full contents like config.  
`FULL_VIEW` | Include everything.
