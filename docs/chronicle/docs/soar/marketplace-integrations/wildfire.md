# WildFire

This document provides guidance on how to integrate WildFire with Google SecOps.

## ‌Configure WildFire to work with Google Security Operations

To obtain the API Key for your WildFire public cloud, please complete following steps:

  1. Log in to the [WildFire portal](https://wildfire.paloaltonetworks.com/).
  2. Select **Account** on the navigation bar at the top of the page.
  3. Your API key(s) is under **My WildFire API Keys**.



## Configure WildFire integration in Google SecOps

For detailed instructions on how to configure an integration in Google SecOps, see [Configure integrations](https://docs.cloud.google.com/chronicle/docs/soar/respond/integrations-setup/configure-integrations).
