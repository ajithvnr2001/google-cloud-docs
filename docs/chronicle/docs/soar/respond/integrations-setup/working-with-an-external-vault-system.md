# Manage secrets with secret managers

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

This document explains how to manage secrets (such as passwords, API keys, or certificates) in Google Security Operations using secret managers. 

To manage secrets through secret managers, configure a specialized sync job within supported integrations. This sync job automatically manages configurations across integrations, connectors, and jobs. 

## Supported integrations

For detailed configuration instructions and product-specific nuances, refer to the documentation for each supported integration in the Content Hub: 

  * **CyberArk PAM** : See the [ Sync Integration Credentials Job](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/cyberark-pam#sync-integration-credentials). 
  * **CyberArk Credential Provider** : See the [Sync Integration Credentials Job](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/cyberark-credential-provider#sync_integration_credentials_job). 
  * **Secret Manager** : See the configuration job details in the [Secret Manager documentation](https://docs.cloud.google.com/chronicle/docs/soar/marketplace-integrations/secret-manager).
