# Create an agent using Docker 

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

This document outlines the procedure to deploy a Remote Agent using the platform's Docker installation wizard. This method automates the container setup process on the host machine.

  1. In the Google Security Operations platform, go to **SOAR Settings** > **Advanced** > **Remote Agents**. 
  2. On the **Remote Agents** page, click add**Add** > **Docker installation**.
  3. In the **Name** field, enter an agent name.
  4. Select an environment for the agent.
  5. Follow all steps in the wizard to complete the deployment.
  6. Click **Next** to perform a connectivity check with your new agent. If the check is successful, the agent is added. If the check fails, a prompt appears with helpful links on how to troubleshoot the issue.
  7. Click **Done**. The agent is now added.

**Note:** At this stage, you can't update the Docker image. For details on how to update an existing Remote Agent using its Docker image, see [Perform a major upgrade of a Docker image](https://docs.cloud.google.com/chronicle/docs/soar/working-with-remote-agents/upgrade-agent-docker-image).
