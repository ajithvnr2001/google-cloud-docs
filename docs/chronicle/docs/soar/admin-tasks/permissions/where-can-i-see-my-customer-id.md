# Locate your customer ID

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

Finding your Google Security Operations customer ID is essential for performing administrative tasks and managing permissions within your Google Security Operations SOAR account.

To find your customer ID, go to **SOAR Settings > Organization > License Management**.
