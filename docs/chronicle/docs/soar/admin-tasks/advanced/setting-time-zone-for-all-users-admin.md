# Set time zone

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

In the **Localization** settings, administrators can set the default time zone and date/time format for all platform users. These changes take effect immediately after saving. 

While administrators can set the default time zone, individual users can customize these settings to match their own preferences. For more information, see [Configure user preferences](https://docs.cloud.google.com/chronicle/docs/soar/admin-tasks/permissions/set-your-time-zone).

To customize these settings, follow these steps: 

  1. Go to **Settings** > **Advanced** > **Localization**.
  2. Select the time zone.
  3. Select **Date Format** and **Time Format** to configure the date and time formats. **Note:** These settings only apply to SOAR pages, including **Cases** , **Playbooks** , and **SOAR Dashboards**. 
  4. Click **Save**.
