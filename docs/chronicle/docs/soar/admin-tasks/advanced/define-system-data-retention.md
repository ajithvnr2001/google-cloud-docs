# Configure SOAR data retention

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

You can define the retention period for information about closed cases. You can set the period either for all environments or individually. The retention time period starts when the case or cases were closed.

**Note:** If you select the **Allow Data Retention Period per Environment** checkbox, go to **SOAR Settings** > **Organization** > **Environments** , select the environment you want to edit, click **Edit** , and then select the new timeframe. 

Your customer license defines the maximum retention timeframe. To extend it, contact [Google SecOps Support](https://docs.cloud.google.com/chronicle/docs/getting-support).

To configure data retention, follow these steps:

  1. Go to **SOAR Settings** > **Advanced** > **General**.
  2. Select the time period. The default period is 12 months.
  3. Optional: Select **Allow Data Retention Period per Environment**.
  4. Click **Save**.
