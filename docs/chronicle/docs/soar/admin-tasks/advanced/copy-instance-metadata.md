# Troubleshoot SOAR functionality

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

You can authorize Google Support to replicate your instance's runtime configuration to troubleshoot SOAR functionality issues without requiring a live screen-share session.

To provide the necessary instance data, do the following:

  1. Go to the question mark icon at the top of the platform.

  2. Select **Copy Instance Metadata**.

  3. Send the resulting JSON file to your Support representative.


**Note:** No data or Personal Identifying Information (PII) is included in the instance metadata.
