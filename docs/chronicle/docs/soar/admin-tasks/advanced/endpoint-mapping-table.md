# SOAR API mapping table

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

**Caution:** Legacy APIs can have a performance impact.  
  
Legacy Google SecOps SOAR APIs are deprecated and will be fully non-functional by **March 31, 2027**. Continued use of these APIs can lead to performance issues or unexpected behavior within the platform.  
  
You must migrate all legacy API calls to the new, more efficient Chronicle APIs immediately to ensure platform stability and performance. For more information, see the [API migration guide](https://docs.cloud.google.com/chronicle/docs/soar/admin-tasks/advanced/api-migration-guide).

Legacy endpoints are exact replicas of the previous API structure and will be deprecated and eventually removed. They're now available in the new v1beta or v1 releases, which instead use resource-oriented endpoints. We recommend that you migrate to the new resource endpoints immediately.
