# Manage password policy

Supported in:

[ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

**Note:** This document applies only to the standalone Google SecOps SOAR platform. 

**Note:** This section only applies if you have not yet completed Stage 1 of [SOAR Migration to Google Cloud](https://docs.cloud.google.com/chronicle/docs/soar/admin-tasks/advanced/migrate-to-gcp). After the completion of Stage 1, refer to [Access Google Secops instance](https://docs.cloud.google.com/chronicle/docs/onboard/log-in-to-new-instance).

This document explains how to create Google Security Operations SOAR passwords and manage their settings. For security, we recommend using a strong password that meets the following requirements:

  * A minimum of 10 characters
  * At least one capital letter
  * At least one special character



## Change your password

To change your password, follow these steps:

  1. Click your user avatar.
  2. In the menu, select **Change Password**.



## Enforce mandatory password changes

**Note:** The password policy applies to all standard users but doesn't affect Google SecOps SOAR administrators. 

To safeguard your data, password changes are required every 90 days. The following protocol is in place:

  * Passwords expire after 90 days.
  * Users receive the following notifications when their password is nearing expiration: 
    * 14 days before password expiry
    * 7 days before password expiry
    * 2 days before password expiry
    * 1 day before password expiry
  * An account locks if a password expires or if a user attempts multiple incorrect logins.
  * Administrators can re-enable locked user accounts, and the password is then valid for another 90 days.
