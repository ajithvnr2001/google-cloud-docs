# Invite users to the platform

Supported in:

[ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

**Note:** This document applies only to the standalone Google SecOps SOAR platform. 

**Note:** This section only applies if you have not yet completed Stage 1 of [SOAR Migration to Google Cloud](https://docs.cloud.google.com/chronicle/docs/soar/admin-tasks/advanced/migrate-to-gcp). After the completion of Stage 1, refer to [Access Google Secops instance](https://docs.cloud.google.com/chronicle/docs/onboard/log-in-to-new-instance).

This document details how the email invitation system for new internal users is configured in the Google Security Operations SOAR platform. After an administrator creates a new internal user, an email invitation is automatically sent to them. You must choose to configure this system using either the Siemplify SMTP service (default) or a customer-specific SMTP configuration.

## Configure a Gmail account {#configure-gmail-acct}

To configure a Gmail account, follow these steps:

  1. Go to **Google Admin Panel > Security > Settings**.
  2. Select **Allow users to manage their access to less secure apps**.
  3. Click **Save**. **Note:** You can configure email settings for other email service providers, such as Microsoft Exchange or SMTP server.**Important:** This option requires explicit permission and is not available by default to all users.
  4. Go to **Gmail Account > Security**.
  5. Click the **Less secure app access** toggle to the on position.



Once these settings are applied, an email invitation to the Google SecOps SOAR platform is automatically sent to the user. The user then receives the invitation to join.
