# Create custom lists

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

You can create custom lists of special interest, for example, hosts holding confidential information, or users who have come under suspicion. These custom lists can be selected as triggers for playbooks. 

To create a custom list, you have two options:

  * Manually create a new list and add your items.
  * Download a template with sample data, add your information using the provided format, and then import it. This is especially useful for new customers who want to upload existing data to the platform.

**Note:** You can define identifiers for multiple environments by separating them with a vertical line (pipe symbol), for example: `Default Environment|customer_123`. Enter the ***** asterisk sign to define the identifier for all environments. 

To add a new custom list, do the following:

  1. Go to **SOAR Settings > Environments > Custom Lists.**
  2. Click add**Add**.
  3. Enter the relevant information into the **Add Custom List** dialog and click **Add**.
