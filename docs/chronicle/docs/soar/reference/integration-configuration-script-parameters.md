# Integration configuration and script parameters 

###  Integration configuration 

Usually, each integration will have several configurations that need to be set by the user, and used by the code.  
To set the configuration via the Google Security Operations Marketplace, click settings **Configuration** on each installed integration card. 

**Note:** Related Methods: [Siemplify.extract_configuration_param,](https://docs.cloud.google.com/chronicle/docs/soar/reference/siemplify-module#extract-config-params-siemplify)  
[SiemplifyAction.get_configuration](https://docs.cloud.google.com/chronicle/docs/soar/reference/siemplify-job-module#get-config-siemplify-job) **Note:** Google recommends using the `extract_configuration_param` params, and **not** the raw `get_configuration` method. 

###  Script parameters 

Usually, each Action/Job/Connector script will require additional parameters, configured per Instance.  
This can be configured by the Connectors screen, Jobs Screen, Playbook Screen, IDE Screen, or Manual Action Screen. 

**Note:** Related methods: [SiemplifyJob.extract_job_param](https://docs.cloud.google.com/chronicle/docs/soar/reference/siemplify-job-module#extract-job-params),  
[SiemplifyAction.extract_action_param](https://docs.cloud.google.com/chronicle/docs/soar/reference/siemplify-action-module#extract-action-params),  
[SiemplifyConnectorExecution.extract_connector_param](https://docs.cloud.google.com/chronicle/docs/soar/reference/siemplify-connectors-module)
