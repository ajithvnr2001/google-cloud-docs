# Release plan for Google SecOps

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

**Note:** This document details the regional release plan for the SOAR functionality, applicable to both customers using Google SecOps SOAR as a standalone platform and those using the SOAR component within Google SecOps. 

This document explains how Google SecOps SOAR releases are deployed across regions.

Releases typically follow a two-stage rollout, with updates occurring during the maintenance window (every Sunday between 13:00 - 17:00 GMT+2). The second-stage regions are upgraded one week after the first-stage regions.

### First-stage regions

  * Japan
  * India
  * Australia
  * Canada
  * Germany
  * Switzerland



### Second-stage regions

  * Singapore
  * Qatar
  * Saudi Arabia
  * Israel
  * UK (London)
  * Italy
  * EU (multi-region)
  * US (multi-region)



If you're unsure of your assigned region, contact your Google SecOps representative.
