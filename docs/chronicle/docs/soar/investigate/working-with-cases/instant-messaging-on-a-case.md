# Collaborate using case chat

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

This document explains how to use the **Case Chat** feature in Google Security Operations to collaborate in real time. Case Chat provides a secure and convenient, built-in messaging experience that lets you and other team members (with access to a case) communicate directly within the platform.

Available features include:

  * Mention specific users or SOC roles to trigger email notifications. When you mention a role, all users assigned to that role are notified.
  * Pin important messages to the Case Wall, to make them easier to find and reference.



## Send a message in Case Chat

To chat with other members within a case, follow these steps:

  1. Click ![chaticon](https://docs.cloud.google.com/static/chronicle/images/soar/chaticon.png)**Chat** to open the side drawer.
  2. To mention someone, enter  alternate_email **alternate_email** and the user's name or role.
  3. Optional: Attach one or more files.
  4. Click ![sendicon](https://docs.cloud.google.com/static/chronicle/images/soar/sendicon.png)**Send**.
  5. Optional: To pin your message to the **Case Wall** , hold the pointer over the message and click ![pinicon](https://docs.cloud.google.com/static/chronicle/images/soar/pinicon.png)**Pin to Case Wall**.
