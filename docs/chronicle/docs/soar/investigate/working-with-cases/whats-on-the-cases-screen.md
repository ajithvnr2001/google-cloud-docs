# Explore the cases page

Supported in:

Google SecOps  [ SOAR ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-soar-toc)

**Note:** This document applies both to SOAR standalone customers and Google SecOps unified customers using the legacy cases experience. 

This document describes the layout and interactive elements available on the **Cases** page in Google Security Operations.

##  Case top bar - left side 

[ ![workingwithcases2](https://docs.cloud.google.com/static/chronicle/images/soar/workingwithcases2.png)](https://docs.cloud.google.com/static/chronicle/images/soar/workingwithcases2.png)

The left side of the case top bar displays the following details:

## Additional actions on the cases page

In addition to the standard options, the **Manual Action** , **Case Task** , and **Alert Options** menus are available under the case header. These menus provide quick access to these commonly used actions.

[ ![workingwithcases7](https://docs.cloud.google.com/static/chronicle/images/soar/workingwithcases7.png)](https://docs.cloud.google.com/static/chronicle/images/soar/workingwithcases7.png)

  * **Alerts List** : The **Alerts List** icon appears only when a case contains more than two alerts. You can use the menu to select a specific alert and go directly to it.
  * **Manual Action** : While reviewing case information, you can initiate a manual action without leaving the **Cases** page. For more information, see [Perform a manual action](https://docs.cloud.google.com/chronicle/docs/soar/investigate/working-with-cases/perform-a-manual-action).
  * **Case Task** : You can add a case-specific task and assign it to a user or role, including yourself. For more information, see [Manage tasks from the Cases page](https://docs.cloud.google.com/chronicle/docs/soar/investigate/working-with-cases/manage-tasks-from-the-cases-screen). 
  * **Alert Options** : For details about available options when working with alerts, see [Alert Options menu in the Cases page](https://docs.cloud.google.com/chronicle/docs/soar/investigate/working-with-cases/what-actions-can-you-take-on-a-case#manage-alert-within-case).
