# Change log for WINDOWS_DHCP

Date | Changes  
---|---  
2026-08-21 |  Added support for `11003`, `11004`, and `11008` of DHCPv6 CSV logs.   
2025-06-10 |  `JSON`: Added support for Bindplane updated `JSON` format.   
2025-02-20 |  Added support for a resource detection logs forwarded by the Bindplane agent.   
2024-12-16 |  Added support for a new JSON schema of logs forwarded by the Bindplane agent.   
2024-08-23 |  Added support for non mandatory raw log fields as optional fields.   
2023-11-29 |  Aligned `principal/target.hostname` and `principal/target.asset.hostname` mapping.   
2022-05-23 |  Extended WINDOWS_DHCP parser to support CEF format.   
2022-04-13 |  Formal launch of Chronicle's Windows DHCP Parser.  
This represents a comprehensive refresh to Windows DHCP parsing, and is built from the ground up for improved stability, coverage, and efficacy.  
Added support for JSON+CSV format.  
Extracted the CSV `Message` field from the JSON log for DHCP service logs.
