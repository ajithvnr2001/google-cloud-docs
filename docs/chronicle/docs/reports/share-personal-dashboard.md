# Share a personal dashboard

Supported in:

Google SecOps  [ SIEM ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-siem-toc)

This document explains how to share a personal dashboard with other members of your team.

**Personal Dashboards** are visible only to you. **Shared Dashboards** are visible to all members of the team who can view dashboards in Google Security Operations SIEM.

  1. Go to **Personal Dashboards** in the left navigation.
  2. Select the dashboard you want to share, and then click the  more_vert menu next to the dashboard name.
  3. Select **Copy to Shared**. A copy of the dashboard is created under the **Shared Dashboards** section in the left navigation.
