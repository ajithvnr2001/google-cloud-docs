# Google Security Operations documentation

Google SecOps SOAR (Security Orchestration, Automation and Response) enables security teams to automate response to threats. Google SecOps SOAR does this by ingesting, grouping, and prioritizing alerts from all your detection tools to automatically execute playbooks and coordinate a hands-on response.
