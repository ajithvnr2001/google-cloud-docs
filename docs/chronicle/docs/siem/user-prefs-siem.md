# Configure user preferences for SIEM standalone

Supported in:

[ SIEM ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-siem-toc)

The **User Preferences** dialog is where you manage your user-related configurations, such as localization and accessibility.

To configure user preferences for SIEM, do the following:

  1. Click your user avatar.
  2. Select **User preferences** from the menu.
  3. In the **User preferences** dialog, access the following options:
     * **Localization** :
       * **Time Zone** : configure your time zone.
     * **Accessibility** :
       * Set the duration for how long feedback messages, such as confirmation or error messages, remain visible before they disappear from the platform.
