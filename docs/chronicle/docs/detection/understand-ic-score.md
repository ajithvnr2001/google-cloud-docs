# GTI score overview

Supported in:

Google SecOps  [ SIEM ](https://docs.cloud.google.com/chronicle/docs/secops/google-secops-siem-toc)

The Google Threat Intelligence scoring system helps Google Security Operations prioritize and address the most significant security threats. Google Threat Intelligence scores calculate threat levels for various indicators, including domains, IP addresses, file hashes, and URLs.

The Google Threat Intelligence score is a numeric representation (from 0-100) of an indicator's potential impact if detected in an environment. The scoring system combines Google Threat Intelligence data with analyst expertise to determine the score and the resulting verdict.

For more details about Google Threat Intelligence scoring, see [Google Threat Intelligence Indicator Score](https://gtidocs.virustotal.com/docs/google-threat-intelligence-indicator-score).
