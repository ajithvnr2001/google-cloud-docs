#  Job search API Basics (v3) Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Talent Solution (CTS) Job search is designed to transform the recruiting and talent acquisition industry by powering your job search and candidate matching solutions with built-in Machine Learning (ML) algorithms. The Job search API is designed to be integrated with your existing job search site. Your site may belong to any of four basic use cases:

  1. **Job boards** (returns a list of jobs to job seekers)
  2. **Career site providers** (provides career site services to client companies)
  3. **Staffing agencies** (provides short- or long-term employees to clients)
  4. **Applicant tracking systems** (tracks applicants throughout the hiring process)



Business goals and metrics vary significantly between companies. The CTS Job search API is designed to be customizable, so you can modify the API's performance based on your needs. The [best practices](https://docs.cloud.google.com/talent-solution/job-search/v3/docs/best-practices), [implementation guide](https://docs.cloud.google.com/talent-solution/job-search/v3/docs/implementation), and [launch checklist](https://docs.cloud.google.com/talent-solution/job-search/v3/docs/best-practices) documents are intended to guide you through factors that you need to consider when setting up the API to meet your specific goals.

![](https://docs.cloud.google.com/static/talent-solution/job-search/v3/docs/images/overview-image.png)

## How the API works

The CTS Job search API enables you to leverage Machine Learning (ML) technology within your own website. You send a list of jobs and companies to the API, which stores them and indexes them into a searchable form. It uses a pre-trained ML model with your provided data to return relevant search results. You can then render the API output to your company site as viewable results. As soon as the Job search API is integrated with your system your users will begin seeing high quality search results immediately.

## Implementing the Job search API

For more information on implementing Job search in your UI, see our [implementation guide](https://docs.cloud.google.com/talent-solution/job-search/v3/docs/implementation).
