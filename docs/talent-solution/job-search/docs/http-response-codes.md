#  HTTP Response Codes Stay organized with collections  Save and categorize content based on your preferences. 

You might see the following response codes while using the service:

Error Code | Description  
---|---  
200 | OK.  
400 | Invalid argument or bad request.  
401 | Unauthorized access.  
403 | Access forbidden. Please check the cloud console and credentials file to ensure that the service has been correctly enabled.  
404 | Resource not found.  
409 | Attempted to create a resource that already exists, or aborted.  
429 | Too many requests. The client has exceeded the allocated quota restrictions. Please see [quotas and limits](https://docs.cloud.google.com/talent-solution/quotas) for details on your quota.  
499 | The operation was canceled.  
500 | Internal server error.  
501 | The operation is not implemented or is not supported/enabled.  
503 | Service unavailable. Try again later.  
504 | Gateway request timeout.
