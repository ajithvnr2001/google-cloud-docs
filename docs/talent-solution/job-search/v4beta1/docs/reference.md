## Introduction

Cloud Talent Solution provides hiring companies and job distributors with the capability to create and manage job postings and organizational information, and perform job search using field based queries. This site contains all of the information you need to integrate Cloud Talent Solution, create company entities that represent employers with intended access control, post and manage jobs on Garage Jobs on behalf of employers, and search jobs where access control permits. For a full list of supported API methods, refer to the [Reference](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/reference/rest) section.
