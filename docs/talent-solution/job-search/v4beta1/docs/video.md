## Get started

The [get started](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-started) series provides a brief introduction of the Cloud Talent Solution Job Search API by focusing on what the API does, Job Search use cases, and the steps required to implement the API.

  * [Introduction to Cloud Talent Solution](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-started#introduction_to_cloud_talent_solution)
  * [Implementing the Job Search API](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-started#implementing_the_job_search_api)



## Get technical

The [get technical](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-technical) series is geared toward technical viewers looking for hands-on experience and more specific instruction. It includes creating companies and jobs, searching for jobs, and improving search relevance. Step by step [codelab](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-technical#codelabs) instruction is also included in this section.

  * [Start using the Job Search API](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-technical#start_using_the_job_search_api)
  * [Working with companies](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-technical#working_with_companies)
  * [Working with jobs](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-technical#working_with_jobs)
  * [Searching for jobs](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-technical#searching_for_jobs)
  * [Search relevance](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/get-technical#search_relevance)



## Configuration & best practices

The [best practices](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/configuration) series includes Job Search configuration tips and best practices information. Learn how to configure search requests/results and how to handle relevance-related issues.

  * [Search results best practices](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/configuration#search_results_best_practices)
  * [Customize your returned search results](https://docs.cloud.google.com/talent-solution/job-search/v4beta1/docs/configuration#customize_your_returned_search_results)
