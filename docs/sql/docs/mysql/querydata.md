QueryData lets you interact with the data in your database using conversational language and build data agents. You provide database-specific information in the form of context sets to improve generator accuracy.

## Context sets

A context set is a collection of database-specific information that enables QueryData to generate queries with high accuracy. 

To learn more, see:

  * [Context sets overview](https://docs.cloud.google.com/gemini/data-agents/querydata/sql-mysql/context-sets-overview)
  * [Build context sets using the context engineering agent](https://docs.cloud.google.com/gemini/data-agents/querydata/sql-mysql/build-context-gemini-cli)
  * [Manage context sets in Cloud SQL Studio](https://docs.cloud.google.com/gemini/data-agents/querydata/sql-mysql/manage-data-agents)



## QueryData

QueryData writes queries for your database using context sets, translating natural language questions into accurate SQL queries. 

To learn more, see the following resources:

  * [QueryData overview](https://docs.cloud.google.com/gemini/data-agents/querydata/sql-mysql/data-agent-overview)
  * [Test QueryData in Cloud SQL Studio](https://docs.cloud.google.com/gemini/data-agents/querydata/sql-mysql/inspect-data-agent)
  * [Integrate QueryData with an application](https://docs.cloud.google.com/gemini/data-agents/querydata/sql-mysql/integrate-applications-data-agent)
