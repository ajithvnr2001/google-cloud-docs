#  Cloud SQL for MySQL First Generation shutdown Stay organized with collections  Save and categorize content based on your preferences. 

This page has the timetable for the shutdown of First Generation instances and points to resources for migrating First Generation instances to Second Generation.

In 2016, we started offering Second Generation instances to Cloud SQL customers. Second Generation instances offer improved performance, availability, and storage capacity. In October, 2018, we released a tool for upgrading First Generation instances to Second Generation. On January 29, 2019, we deprecated First Generation instances in favor of Second Generation.

On March 25th, 2020, we fully decommissioned First Generation and no longer support it.

## Where to get help

If you have a Platinum, Gold, or Silver support package, contact our support team. Otherwise, contact us at any time using [this form](https://support.google.com/cloud/contact/free_trial_support).

## Shutdown timetable

With any deprecation, there is a follow-up decommission where the API or service is formally removed. The following table lists the First Generation shutdown schedule:

Date | Event  
---|---  
October 30, 2018 | General release of Second Generation upgrade tool  
January 22, 2019 | Announcement of deprecation for First Generation customers  
January 29, 2019 | Official deprecation for First Generation customers  
February 5, 2020 | No new First Generation instances can be created  
March 4, 2020 | Auto-upgrade of remaining First Generation instances  
March 25, 2020 | Decommission of Cloud SQL First Generation
