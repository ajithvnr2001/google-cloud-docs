## Methods  
  
---  
  
### `[generateEphemeralCert](https://docs.cloud.google.com/sql/docs/mysql/admin-api/rest/v1beta4/connect/generateEphemeralCert)`

|  Generates a short-lived X509 certificate containing the provided public key and signed by a private key specific to the target instance.  
  
### `[get](https://docs.cloud.google.com/sql/docs/mysql/admin-api/rest/v1beta4/connect/get)`

|  Retrieves connect settings about a Cloud SQL instance.  
  
### `[resolve](https://docs.cloud.google.com/sql/docs/mysql/admin-api/rest/v1beta4/connect/resolve)`

|  Retrieves connect settings about a Cloud SQL instance using the instance DNS name.
