This page describes integrations between Cloud SQL for MySQL and other products and services.

## Google Cloud services

This section describes the Google Cloud services that Cloud SQL integrates with.

### Looker

Looker is an enterprise platform for business intelligence, data applications, and embedded analytics. Looker helps you explore, share, and visualize your company's data so that you can make better business decisions.

To get started, see [Use Looker with Cloud SQL](https://docs.cloud.google.com/sql/docs/mysql/looker).

### BigQuery

[BigQuery](https://docs.cloud.google.com/bigquery) is Google's fully managed, petabyte-scale, low-cost analytics data warehouse. You can use BigQuery to query data stored in Cloud SQL.

To get started, see [Querying Cloud SQL Data](https://docs.cloud.google.com/bigquery/docs/cloud-sql-federated-queries#api).

### Cloud Run functions

[Cloud Run functions](https://docs.cloud.google.com/functions) is an event-driven serverless compute platform that integrates with Cloud SQL.

### Cloud Run

[Cloud Run](https://docs.cloud.google.com/run/docs) is a managed compute platform that lets you run containers. You can invoke the containers by requests or events and integrate them with Cloud SQL.

The [Connecting from Cloud Run to Cloud SQL](https://docs.cloud.google.com/sql/docs/mysql/connect-run) page demonstrates how to configure and connect to Cloud SQL in several programming languages.

### App Engine standard environment

The [App Engine standard environment](https://docs.cloud.google.com/appengine/docs/standard) is based on container instances running on Google's infrastructure. Containers are preconfigured with one of several available runtimes.

The [Connecting from App Engine standard environment to Cloud SQL](https://docs.cloud.google.com/sql/docs/mysql/connect-app-engine-standard) page demonstrates how to configure and connect to Cloud SQL in several programming languages.

### App Engine flexible environment

The [App Engine flexible environment](https://docs.cloud.google.com/appengine/docs/flexible) automatically scales your app up and down while also balancing the load.

The [Connecting from App Engine flexible environment to Cloud SQL](https://docs.cloud.google.com/sql/docs/mysql/connect-app-engine-flexible) page demonstrates how to configure and connect to Cloud SQL in several programming languages.

### Google Kubernetes Engine

[Google Kubernetes Engine](https://docs.cloud.google.com/kubernetes-engine/docs) helps you deploy, manage, and scale containerized applications on Kubernetes, powered by Google Cloud.

The [Connecting from Google Kubernetes Engine](https://docs.cloud.google.com/sql/docs/mysql/connect-kubernetes-engine) page demonstrates how to configure and connect to Cloud SQL.

## Data management

This section describes data management tools that Cloud SQL integrates with.

### Knowledge Catalog

Knowledge Catalog is a metadata management and governance platform. You can use Knowledge Catalog to organize and enrich the metadata of Cloud SQL resources.

## Infrastructure management

This section describes infrastructure management tools that Cloud SQL integrates with.

### Apps Script

[Apps Script](https://developers.google.com/apps-script/guides/jdbc) can connect to external databases through the JDBC service, a wrapper around the standard Java Database Connectivity technology. The JDBC service supports Cloud SQL.

### Terraform

Terraform is an open source tool that codifies APIs into declarative configuration files. These files can be shared among team members, treated as code, edited, reviewed, and versioned.

For more information about using Cloud SQL with Terraform, see [Cloud SQL Database Instance](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/sql_database_instance) in the Terraform documentation.
