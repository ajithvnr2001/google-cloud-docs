# Cloud SQL for SQL Server documentation

[Read product documentation](https://docs.cloud.google.com/sql/docs/sqlserver/features)

Cloud SQL for SQL Server is a managed database service that helps you set up, maintain, manage, and administer your SQL Server databases on Google Cloud. For information specific to Microsoft SQL Server, see the [SQL Server documentation](https://docs.microsoft.com/sql/sql-server/sql-server-technical-documentation?view=sql-server-2017).
