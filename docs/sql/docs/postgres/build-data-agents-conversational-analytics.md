Conversational analytics in Cloud SQL for PostgreSQL lets you interact with your database data using natural language. You can ask questions in plain language and receive answers without writing SQL queries. This feature uses data agents that you configure to understand your data.

For more information, see [Conversational analytics for Cloud SQL for PostgreSQL overview](https://docs.cloud.google.com/gemini/data-agents/conversational-analytics/sql-postgres).
