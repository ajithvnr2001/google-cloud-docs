## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

### Prepare for Google support

Before contacting technical support, see if your question or problem has already been addressed in one of the following places: 

  * [Known issues](https://docs.cloud.google.com/sql/docs/mysql/known-issues)
  * [Troubleshooting](https://docs.cloud.google.com/sql/docs/mysql/troubleshooting)
  * [FAQ](https://docs.cloud.google.com/sql/faq)
  * [Error messages](https://docs.cloud.google.com/sql/docs/mysql/error-messages)
  * [Diagnose issues](https://docs.cloud.google.com/sql/docs/mysql/diagnose-issues)



When you contact technical support, we recommend that you have the following types of information ready:

  * Your project ID and Cloud SQL instance name.
  * If your issue involves an error of any kind, [check the Cloud SQL logs](https://docs.cloud.google.com/sql/docs/mysql/logging#viewing_logs).Copy and save any resulting log entries that appear to be relevant to the time the problem occurred. 

Read the entries carefully. Error logs can be full of information, and often the root cause of the problem is hidden somewhere in the text. 




## Get support through the Google Cloud console

You can contact technical support through phone or chat, and find other support options on the [Google Cloud console support page](https://console.cloud.google.com/support).

## Get support from the community

  * Search existing issues in the community forums [Stack Overflow](https://stackoverflow.com/questions/tagged/google-cloud-sql) and [google-cloud-sql-discuss](https://groups.google.com/forum/#!forum/google-cloud-sql-discuss).
  * Check the [public issue tracker for Cloud SQL](https://issuetracker.google.com/savedsearches/559773).



If you are still stuck, take one of the following steps:

  * Ask a question on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-sql). Use the tag `google-cloud-sql` for questions about Cloud SQL. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.
  * Join the [google-cloud-sql-discuss](https://groups.google.com/forum/#!forum/google-cloud-sql-discuss) Google group to discuss Cloud SQL issues.
  * Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud SQL and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 



When posting your question, provide:

  * A description of your problem, including any error messages.
  * The operation you attempted, for example, an admin operation or query.
  * The time and date (including timezone) you encountered the problem.
  * The tool or library that you use to interact with Cloud SQL.
  * A code sample, if applicable and possible.



To be notified of product updates and new features for MySQL, you can also subscribe to the [release notes](https://docs.cloud.google.com/sql/docs/mysql/release-notes) by adding that page's URL to your feed reader, or by adding its [feed URL](https://docs.cloud.google.com/static/feeds/cloud-sql-mysql-release-notes.xml) directly.

## File bugs or feature requests

From the Cloud SQL documentation click "Send feedback" near the top right of the page. This will open a feedback form. Your comments will be reviewed by the Cloud SQL team.
