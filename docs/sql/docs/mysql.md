# Cloud SQL for MySQL documentation

[Read product documentation](https://docs.cloud.google.com/sql/docs/mysql/features)

Cloud SQL for MySQL is a fully-managed database service that helps you set up, maintain, manage, and administer your MySQL relational databases on Google Cloud. For information specific to MySQL, see the [MySQL documentation](https://dev.mysql.com/doc/refman/5.7/en/) or [learn more about Cloud SQL for MySQL](https://docs.cloud.google.com/sql/docs/mysql/features).
