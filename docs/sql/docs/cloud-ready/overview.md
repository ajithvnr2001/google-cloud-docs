Google Cloud Ready - Cloud SQL recognizes partner solutions that have met a core set of requirements to ensure the best possible integration between the partner product and Cloud SQL. Validated partner products enable existing and prospective customers to discover and use proven partner products. Now Cloud SQL customers can save time on evaluating new tools, and focus on building solutions using partner products that have been proven through a rigorous validation process to work optimally with Cloud SQL.

## How does Google Cloud Ready - Cloud SQL work?

Our Cloud SQL validation initiative lets partners work with Google Cloud Engineering teams and validate their integrations with Cloud SQL to ensure the best possible customer experience. Our Cloud SQL initiative has three phases:

  1. **Evaluate** : Google Cloud Engineering teams work with partners to run a series of data integration tests in a sandbox and production environment and compare results against best practices and performance benchmarks.

  2. **Enhance** : We take the results of the Evaluate phase and work with our partners to fill in the gaps, if any.

  3. **Enable** : Together with our partners, we refine existing documentation to make sure our mutual customers have everything they need to successfully implement a solution using our integrated products.




## Scope of the initiative and partner benefits

When partners sign up for this initiative, Google Cloud Engineering teams work with partners to validate the quality of their Cloud SQL integration. Partners can then work on addressing any identified gaps or areas for improvement. After the partner integration is validated, we recognize the partner with the designation **_Google Cloud Ready - Cloud SQL_**.

The initiative benefits partners by providing a comprehensive review of their software to ensure they follow best practices and identify areas for improvement. The following is a list of the benefits offered to participating independent software vendors (ISVs):

  * Increased customer confidence in partner solutions validated to work with Cloud SQL.

  * Partner badging and **_Google Cloud Ready - Cloud SQL_** designation.

  * Priority placement and recognition on the Google Cloud [Cloud SQL Partner page](https://cloud.google.com/sql#section-1).

  * Access to Google Cloud Partner Engineering and Cloud SQL product teams for joint roadmap development and exclusive feature release previews.

  * Support for GTM activities in addition to those offered through the standard Google Cloud Google Cloud Partner Network program. These additional benefits include support for joint partner led activities such as blogs, workshops, webinars, social media, and more.

  * Early access to Cloud SQL material and support for creating best practice guides, solution briefs, and joint reference architecture.




## How are partners selected for validation?

Partners that are interested in initiative participation need to meet the following minimum criteria:

  * Partner products should include a production-quality Cloud SQL integration or be willing to work with us to build one.

  * Partners should be a registered Google Cloud partner at **Partner Tier**. If not already a Google Cloud partner, [sign up](https://partners.cloud.google.com/enrollment/email) before applying.

  * Partners should be willing to work with the Google Cloud Engineering team to test and validate the connector or build one following the best practices.




Partners can apply through the [Google Cloud Ready - Cloud SQL Interest Form](https://forms.gle/HqVnhU6qAZmhZfuD9) for validating their product and once an application is submitted, the cloud partner engineering team will coordinate their validation. If you don't have an existing integration and are willing to work with us on it, you can still apply.

## Becoming a Google Cloud Ready - Cloud SQL partner

Eligible Google Cloud partners can participate in Google Cloud Ready - Cloud SQL to qualify and promote their solutions by meeting the requirements based on how the partner product is categorized. Categories include the following:

  * Business Intelligence, Machine Learning and Advanced Analytics
  * Data Integration and Migration
  * Data Quality and Observability
  * Data Security, Caching and Proxy Services



Each category requires successful completion of category-specific integration and interoperability testing. If you are already a Google Cloud partner and are interested in participating, contact your Partner Manager, apply directly from the [Partner Network Hub](https://partners.cloud.google.com) or by filling out the [Google Cloud Ready - Cloud SQL Interest Form](https://forms.gle/HqVnhU6qAZmhZfuD9). If you are not already a Google Cloud Partner, you can start the application process by completing our [enrollment form](https://partners.cloud.google.com/enrollment/email). If you have questions related to the initiative, [send an email to us](mailto:cloudsql_partnerships@google.com).
