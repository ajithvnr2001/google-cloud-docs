## June 5, 2020

Description | Severity | Notes  
---|---|---  
MySQL 5.6 minor version is upgraded to 5.6.42. MySQL 5.7 minor version is upgraded to 5.7.25.

#### Cloud SQL impact

Cloud SQL for MySQL instances were automatically updated as part of the maintenance update.

#### What should I do?

No action is required by you. |  |   
PostgreSQL 9.6 minor version is upgraded to 9.6.16. PostgreSQL 10 minor version is upgraded to 10.11. PostgreSQL 11 minor version is upgraded to 11.6. PostgreSQL 12 minor version is upgraded to 12.1. Refer to the PostgreSQL [Security Information](https://www.postgresql.org/support/security/) for information about specific vulnerabilities addressed in the update.

#### Cloud SQL impact

Cloud SQL for PostgreSQL instances were automatically updated as part of the maintenance update.

#### What should I do?

No action is required by you. |  |
