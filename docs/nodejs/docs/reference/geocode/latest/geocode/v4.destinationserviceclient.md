#  Class v4.DestinationServiceClient (0.2.1) Stay organized with collections  Save and categorize content based on your preferences. 

A service for retrieving destinations.

A destination provides hierarchical context about a place, which allows you to, for example, find apartment buildings within a larger apartment complex and vice versa. It also provides navigation points suitable for use cases such as ridesharing or delivery. v4
