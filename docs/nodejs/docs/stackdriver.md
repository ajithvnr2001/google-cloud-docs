## Overview

[Google Cloud Observability](https://docs.cloud.google.com/stackdriver) provides powerful monitoring, logging, and diagnostics for Node.js applications.

Node.js libraries are available for the following Google Cloud Observability services:

  * Error Reporting
  * Cloud Logging
  * Cloud Monitoring
  * Cloud Trace



## Error Reporting

[Error Reporting](https://docs.cloud.google.com/error-reporting/docs) for Node.js aggregates and displays errors produced in your running Node.js applications. To get started with Error Reporting, see [Setting Up Error Reporting for Node.js applications](https://docs.cloud.google.com/error-reporting/docs/setup/nodejs).

## Cloud Logging

[Cloud Logging](https://docs.cloud.google.com/logging/docs) for Node.js lets you store, search, analyze, monitor, and alert on log data and events in Node.js applications. We provide Bunyan and Winston plugins, as well as a Stackdriver Logging API client library. To get started with Cloud Logging, see [Setting Up Cloud Logging for Node.js applications](https://docs.cloud.google.com/logging/docs/setup/nodejs).

## Cloud Monitoring

[Cloud Monitoring](https://docs.cloud.google.com/monitoring/docs) for Node.js collects metrics, events, and metadata from Node.js applications. Stackdriver ingests that data and generates insights by using dashboards, charts, and alerts.

Links:

  * [Cloud Client Libraries for the Cloud Monitoring API](https://docs.cloud.google.com/monitoring/docs/reference/libraries)
  * [Creating Custom Metrics](https://docs.cloud.google.com/monitoring/custom-metrics/creating-metrics)
  * [Reading Metrics](https://docs.cloud.google.com/monitoring/custom-metrics/reading-metrics)
  * [Browsing Metrics](https://docs.cloud.google.com/monitoring/custom-metrics/browsing-metrics)
  * [Cloud Monitoring for Node.js on GitHub](https://github.com/googleapis/google-cloud-node/tree/main/packages/google-cloud-monitoring)



## Cloud Trace

[Cloud Trace](https://docs.cloud.google.com/trace/docs) is a distributed tracing system for Google Cloud that collects latency data from Node.js applications and displays it in near real time in the Google Cloud console. To get started with Cloud Trace, see [Setting Up Cloud Trace for Node.js applications](https://docs.cloud.google.com/trace/docs/setup/nodejs-ot).
