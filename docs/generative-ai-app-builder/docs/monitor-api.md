#  Monitor API methods Stay organized with collections  Save and categorize content based on your preferences. 

You can monitor information about API method activity across all apps in your project using the console.

On the **Monitoring** page, you can see metrics for traffic, error rates, and latency by API method. This page also displays document service, recommendation service, and user event service errors.

## View API method metrics

  1. In the console, go to the **AI Applications** page.

[AI Applications](https://console.cloud.google.com/gen-app-builder/start)

  2. Go to the **Monitoring** page.

  3. Select or specify the time period from which to view your metrics.

  4. To filter metrics in a graph:

     * Select any API method name to show that method's metrics
     * Drag to zoom in on a time period
  5. For more metrics and filters, click **View API metrics** to go to the **APIs & Services** page.




## View API method errors

  1. In the Google Cloud console, go to the **AI Applications** page.

[AI Applications](https://console.cloud.google.com/gen-app-builder/start)

  2. Go to the **Monitoring** page.

  3. Select or specify the time period from which to view errors.

  4. Click the **Document service** , **Recommendation service** , or **User event service** tabs to see errors for that service.

  5. To see more details about an error, click the error name to view it in Error Reporting.
