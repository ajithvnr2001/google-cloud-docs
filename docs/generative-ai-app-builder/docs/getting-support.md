## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Agent Search on [Stack Overflow](http://stackoverflow.com/questions/tagged/vertex-ai-search). Use the tag `vertex-ai-search` for questions about Agent Search. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Agent Search

Join the [Google Cloud Developers](https://groups.google.com/forum/#!forum/google-cloud-dev) Google group to discuss Agent Search and receive announcements and updates.

You can also visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Agent Search and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

## Documentation issues

From any Agent Search documentation page, click **Send feedback** near the top right or bottom of the page. This opens a feedback form specific to the page you are viewing. Your comments will be reviewed by the Agent Search documentation team.
