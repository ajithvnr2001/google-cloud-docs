  * JSON representation



Parameters for Agentspace.

JSON representation  
---  
      
    
    {
      "acceptBizQos": boolean,
      "isBiz": boolean
    }  
  
Fields  
---  
`acceptBizQos` |  `boolean` Optional. Set to `true` to specify that caller has read and would like to give consent to the [Terms for Agent Space quality of service].  
`isBiz` |  `boolean` Optional. Indicates if the current request is for Biz edition (= true) or not (= false).
