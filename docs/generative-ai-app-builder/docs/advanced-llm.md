#  Turn generative responses on or off Stay organized with collections  Save and categorize content based on your preferences. 

For structured, unstructured, and advanced website search, generative responses include the following advanced LLM features:

  * Search summaries using the [search](https://docs.cloud.google.com/generative-ai-app-builder/docs/get-search-summaries) method

  * Search answers using the [answer](https://docs.cloud.google.com/generative-ai-app-builder/docs/answer) method

  * Search with follow-ups using the [answer](https://docs.cloud.google.com/generative-ai-app-builder/docs/answer) or the [converse](https://docs.cloud.google.com/generative-ai-app-builder/docs/multi-turn-search) method




This page describes how to turn [generative responses](https://docs.cloud.google.com/generative-ai-app-builder/docs/about-advanced-features#generative-response-features) on or off for an app.

## Before you begin

If you're turning on generative responses, be aware of additional costs that this can incur. See [Pricing](https://docs.cloud.google.com/generative-ai-app-builder/pricing).

When you're turning off generative responses for an app, make sure the app doesn't require these features. For example, if you have deployed a search widget that uses search with follow-ups, Google recommends that you change the search type to "single-turn without summarization" before turning off generative responses. After turning generative responses off, all features that require advanced LLM features stop working in your app within a few minutes.

**Key Terms:** _answer_ versus _summary_ : _Answers_ and _summaries_ are indistinguishable. However, _answers_ are generated by the [`answer`](https://docs.cloud.google.com/generative-ai-app-builder/docs/answer) method and _summaries_ are generated by the [`search`](https://docs.cloud.google.com/generative-ai-app-builder/docs/get-search-summaries) method. 

## Turn generative responses on or off

To turn generative responses on or off, follow these steps:

  1. In the Google Cloud console, go to the **AI Applications** page.

[AI Applications](https://console.cloud.google.com/gen-app-builder/engines)

  2. Click the app from the **Name** field.

  3. In the navigation menu, click **Configurations**.

![Navigation menu in the console with the Configurations item selected](https://docs.cloud.google.com/static/generative-ai-app-builder/docs/images/configurations-menu-option.png)

  4. Click the **Response Settings** tab.

  5. In the **Generative Responses** pane, click the toggle on or off.

  6. Click **Save**. Your changes take place within a few minutes.
