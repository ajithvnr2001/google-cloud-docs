#  Quotas and system limits Stay organized with collections  Save and categorize content based on your preferences. 

This document lists the quotas and system limits that apply to Audit Manager.

  * _Quotas_ have default values, but you can typically request adjustments.
  * _System limits_ are fixed values that can't be changed.



## Rate quotas

Rate quotas restrict the rate at which you can consume a resource. The following table lists the rate quotas that apply to Audit Manager and the default value for each quota.

Quota | Value  
---|---  
API requests per minute | 1,200  
  
## System limits

The following table lists the system limits that apply to Audit Manager and the value for each system limit.

System limit | Value  
---|---  
Maximum number of resources in an audit | 12 million
