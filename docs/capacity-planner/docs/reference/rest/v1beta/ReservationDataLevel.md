#  ReservationDataLevel Stay organized with collections  Save and categorize content based on your preferences. 

The form in which data of reservations should be returned. In case of AGGREGATED, timeseries for selected reservations is returned. If unspecified, all levels are included.

Enums  
---  
`RESERVATION_DATA_LEVEL_UNSPECIFIED` | No reservation data level specified.  
`RESERVATION_DATA_LEVEL_AGGREGATED` | aggregated reservations data in a timeseries or aggregation over timeseries.  
`RESERVATION_DATA_LEVEL_PER_RESERVATION` | per reservation detail which is equivalent of Arcus Future Reservation or Allocation with only limited fields which are useful for Capacity Planning.
