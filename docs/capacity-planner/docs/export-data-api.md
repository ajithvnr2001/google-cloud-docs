This document explains how to export usage and forecast data of the resources in your project, folder, or organization to a Cloud Storage bucket or BigQuery table. To export this data as a CSV file to your local workstation, see instead [Export data to your local workstation](https://docs.cloud.google.com/capacity-planner/docs/export-data-api).

You can use the Capacity Planner API to export data from Capacity Planner to a Cloud Storage bucket or a BigQuery table for the following resources:

  * Compute Engine instances

  * Persistent Disk and Hyperdisk volumes

  * GPUs

  * TPUs

  * Reservations

  * Cloud Storage buckets




To learn more about the data that's available from Capacity Planner, data limitations, and how you can use this data, see [View usage and forecast data](https://docs.cloud.google.com/capacity-planner/docs/view-data).
