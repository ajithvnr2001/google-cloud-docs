# Supported services

The page lists the Google Cloud services that support Access Approval.

_GA_ indicates that approval requests are generally available for a service. _Preview_ indicates that approval requests are supported, but might be changed in backward-incompatible ways and are not subject to any SLA or deprecation policy.
