## December 13, 2021

v1

Feature

Access Approval provides a [preview](https://cloud.google.com/products#product-launch-stages) feature that uses a cryptographic key to sign an access request. Access Approval uses this signature to verify the integrity of the approval.

You can either use the default Google-managed signing key or bring your own signing key. To bring your own signing key, you must meet certain [requirements](https://docs.cloud.google.com/cloud-provider-access-management/access-approval/docs/overview#requirement-signing-key). Using the default Google-managed signing key doesn't require any additional configuration.

For more information about how signing of an access request works, see [Overview of Access Approval](https://docs.cloud.google.com/cloud-provider-access-management/access-approval/docs/overview).

## March 24, 2021

v1

Feature

Access Transparency logs contain a new field called `accessApprovals`. This field lists the approvals that granted access to a resource that is enrolled in [Access Approval](https://docs.cloud.google.com/access-approval/docs). Access Transparency logs published before March 24, 2021 will not have this field populated. This feature is subject to [Access Approval exclusions](https://docs.cloud.google.com/access-approval/docs/overview#exclusions) and only available for the [services supported by Access Approval](https://docs.cloud.google.com/access-approval/docs/supported-services).
