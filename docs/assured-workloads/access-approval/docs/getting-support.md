# Getting support

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## File bugs or feature requests

You can suggest product features, provide product and documentation feedback, and report issues on our [public issue tracker](https://issuetracker.google.com/issues/new?component=1132217). Before filing an issue, [review the open issues](https://issuetracker.google.com/savedsearches/6133833) to see if someone has already reported that issue or request. If a similar open issue already exists, subscribe to the thread to keep updated.

Google engineers review the issues filed using this issue tracker.

## Provide feedback for documentation

If you run into issues while using the documentation, have general feedback, or want to suggest new content, use the documentation feedback mechanism. To provide feedback, click either of the **Send feedback** buttons in any Access Approval documentation page. In the modal that opens, provide the following information:

  * The URL of the document you are reporting.
  * The inaccuracy or missing information in the document.
  * Any other comments or suggestions.



The Access Approval team reviews your feedback.

## Keep up with Google Cloud

  * Read the [Google Cloud blog](https://cloud.google.com/blog/products/gcp).
  * Follow [@googlecloud](https://twitter.com/googlecloud) and [@GoogleCloudTech](https://twitter.com/GoogleCloudTech) on Twitter.
  * Watch technical tutorials on [Google Cloud's channel](https://www.youtube.com/user/googlecloudplatform) on YouTube.
