# Introduction to Assured Workloads

Assured Workloads lets you confidently secure and configure your workloads to support various compliance requirements. Assured Workloads regulates the Google personnel that can be granted access. It also ensures that all authorization requests are recorded in audit logs. For more information, see [Overview of Assured Workloads](https://docs.cloud.google.com/assured-workloads/docs/concept-overview).

Assured Workloads enables regulatory compliance by focusing on [data residency](https://docs.cloud.google.com/assured-workloads/docs/concept-data-residency), [data encryption](https://docs.cloud.google.com/assured-workloads/docs/concept-encryption-keys), [encryption key management](https://docs.cloud.google.com/assured-workloads/docs/concept-key-management), and [platform controls](https://docs.cloud.google.com/assured-workloads/docs/concept-platform-controls).

## Get started with using Assured Workloads

To learn how you can get started with Assured Workloads, see [Deploy a resource with Assured Workloads](https://docs.cloud.google.com/assured-workloads/docs/deploy-resource).

To learn how you can be compliant with IL4 and CJIS compliance regimes, see [Create a new folder in a workload environment for IL4 and CJIS)](https://docs.cloud.google.com/assured-workloads/docs/create-new-project-il4-cjis).

To learn how you can be compliant with FedRAMP Moderate, FedRAMP High, and US Regions and Support compliance regimes, see [Create a new folder in a workload environment for FedRAMP and US Regions and Support](https://docs.cloud.google.com/assured-workloads/docs/create-new-project-fedramp-us-regions).

To learn about the controls that Google Cloud provides to prevent unauthorized administrative access, see [Overview of administrative access controls](https://docs.cloud.google.com/assured-workloads/cloud-provider-access-management/docs/administrative-access).
