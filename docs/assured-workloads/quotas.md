# Quotas and limits

This page lists the quotas and limits that apply to Assured Workloads.

## Workload environment limits

Assured Workloads enforces the following usage limits:

Limit | Value  
---|---  
Create/update/delete workload environment | 0.5 write per second per organization per region  
Reading/listing workload environments | 5 reads per second per organization per region
