# Google Cloud Documentation

> Source: https://docs.cloud.google.com/transfer-appliance/docs/edge/overview/

Distributed Cloud Edge Appliance has been discontinued. The following Google Distributed Cloud products offer similar functionality:

  * [Google Distributed Cloud connected servers](https://docs.cloud.google.com/distributed-cloud/edge/latest/docs/requirements#hardware) provides a hybrid hardware and software solution with similar functionality.
  * [Google Distributed Cloud (software only)](https://docs.cloud.google.com/kubernetes-engine/distributed-cloud/bare-metal/docs/concepts/about-bare-metal) provides a software solution with similar functionality that you can deploy on your own hardware.
