This page lists specifications for Transfer Appliance models, including usable space capacities, dimensions, power requirements, and packing lists.

## Transfer Appliance common specifications

Specification | All models  
---|---  
Model description | Rugged, tamper-resistant appliance, using SSD technology.  
Packaging description | Rugged shipping case with rolling wheels and collapsible handle.  
Power requirements | 100-240 V, 50-60 Hz, 700 W  
Network connectivity |  Data ports: 

  * RJ45 (10 Gbps)
  * QSFP28 (100 Gbps) - TA300 V2 and TA40 V2 only

Configuration port: RJ45 (10 Gbps)   
Delivery time | Overnight (US)  
End-to-end cycle time | Approximately 3 weeks  
Security and encryption | 

  * Customer-Managed Encryption Key (CMEK)
  * Remote attestation with Secure Boot
  * Unique PIN

  
Transfer modes | 

  * NFS share
  * SMB share
  * SSH or SCP transfer

**Note:** Only one of these file transfer protocols can be enabled per Transfer Appliance.  
On-device interface | Command-line interface  
Ease-of-use | Automated ingest
