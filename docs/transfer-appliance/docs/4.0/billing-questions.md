## Calculation of use fees or late days

Only weekdays count towards usage. The usage period starts the day after you receive Transfer Appliance. The usage period ends the day before you have Transfer Appliance picked up for return shipment. For more information, see [Pricing](https://cloud.google.com/transfer-appliance/pricing).
