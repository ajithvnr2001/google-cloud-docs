Remote Model Context Protocol (MCP) servers let your MCP clients access Google and Google Cloud products and services through HTTP endpoints running on Google infrastructure.

For a list of Google-maintained local MCP servers, see the [MCP GitHub repository](https://github.com/Google/mcp).
