#  LogicalProduct Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Represents a Product Main logical product.

JSON representation  
---  
      
    
    {
      "name": string,
      "title": string,
      "shortDescription": string
    }  
  
Fields  
---  
`name` |  `string` Output only. The resource name of the logical product. Format: logicalProducts/{logical_product}  
`title` |  `string` Output only. The display name of the logical product.  
`shortDescription` |  `string` Output only. A short description of the logical product.
