#  TemplateType Stay organized with collections  Save and categorize content based on your preferences. 

Assembly template types.

Enums  
---  
`TEMPLATE_TYPE_UNSPECIFIED` | Default.  
`SERVICE` | A service template is an App Hub service.  
`WORKLOAD` | A workload template is an App Hub workload.  
`ASSET` | An asset template can be used to provision resources that are not services or workloads.  
`APPLICATION` | An application template is a composition of workload/service/asset templates.This item is deprecated!  
`JSS_SOLUTION` | A Jumpstart Solution template.This item is deprecated!  
`SERVICE_DATA_SOURCE` | A service data source template.This item is deprecated!  
`HELM_APPLICATION` | A helm chart based template.This item is deprecated!  
`STANDARD_APPLICATION_TEMPLATE` | A standard application template.  
`COMPOSITE_APPLICATION_TEMPLATE` | A composite application template.  
`HELM_CHART` | A helm chart based template.
