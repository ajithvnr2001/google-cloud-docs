This page documents production updates to Application Design Center. Check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality. 

You can see the latest product updates for all of Google Cloud on the [ Google Cloud](https://docs.cloud.google.com/release-notes) page, browse and filter all release notes in the [Google Cloud console](https://console.cloud.google.com/release-notes), or programmatically access release notes in [BigQuery](https://console.cloud.google.com/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table). 

To get the latest product updates delivered to you, add the URL of this page to your [feed reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the [feed URL](https://docs.cloud.google.com/feeds/applicationdesigncenter-release-notes.xml) directly. 

## October 13, 2026

Feature

You can import existing multi-product Google Cloud Terraform configurations into an Application Design Center application template as is, without splitting them into components or publishing them to a catalog first. From a template revision, you can create, assess, and deploy applications directly, or publish the revision to your catalog to reuse it in other templates ([Preview](https://cloud.google.com/products#product-launch-stages)). For more information, see [Import existing Terraform](https://docs.cloud.google.com/application-design-center/docs/import-terraform).

## October 05, 2026

Feature

Use the [`recommendeIAMroles`](https://docs.cloud.google.com/application-design-center/docs/reference/rest/v1/projects.locations.spaces.applications/recommendIAMRoles) API to identify a list of required APIs and Identity and Access Management (IAM) roles that you must configure before you deploy your application.

## July 21, 2025

Change

When you create a new application, the **Application scope** is set to `Global` by default. For more information, see [Create an application draft](https://docs.cloud.google.com/application-design-center/docs/manage-applications).

Change

If your deployment fails, error messages are displayed in the **Application details** panel. For more information, see [View application details](https://docs.cloud.google.com/application-design-center/docs/deploy-from-console#view-application-details).

Change

When you create a Cloud SQL component, you can select from a list of **Machine** series and types. For more information, see [Configure Cloud SQL (MySQL)](https://docs.cloud.google.com/application-design-center/docs/configure-cloud-sql-mysql) and [Configure Cloud SQL (PostgreSQL)](https://docs.cloud.google.com/application-design-center/docs/configure-cloud-sql-postgresql).

Change

When you create a template, the following field names have been changed:

Template name is **Template ID**.

Display name is now **Template name**.

For more information, see [Specify template details](https://docs.cloud.google.com/application-design-center/docs/design-application-templates#specify_template_details).
