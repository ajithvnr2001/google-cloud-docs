# Cloud Run documentation

[Read product documentation](https://docs.cloud.google.com/run/docs/overview/what-is-cloud-run)

Cloud Run is a fully managed application platform that lets you run containers as services, jobs, worker pools, or instances. Cloud Run is serverless: it abstracts away all infrastructure management, so you can focus on what matters most—building great applications.
