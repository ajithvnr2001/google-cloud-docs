Each Cloud Run resource resides in a [region](https://docs.cloud.google.com/docs/geography-and-regions#regions_and_zones). Customer data associated with the Cloud Run resource is [stored in the selected region](https://cloud.google.com/terms/service-terms#1). You can serve traffic from multiple regions by [configuring external HTTP(S) Load Balancing](https://docs.cloud.google.com/run/docs/multiple-regions). To learn about all Google Cloud locations and to find the region picker tool, see the [Cloud locations](https://cloud.google.com/about/locations) page.

## Domain mappings locations

The domain mapping feature of Cloud Run is available in the following regions:

  * `asia-east1`
  * `asia-northeast1`
  * `asia-southeast1`
  * `europe-north1`
  * `europe-west1`
  * `europe-west4`
  * `us-central1`
  * `us-east1`
  * `us-east4`
  * `us-west1`



To map custom domains in other regions, you must use one of the [other options](https://docs.cloud.google.com/run/docs/mapping-custom-domains).

## Serverless VPC Access connectors

Serverless VPC Access connectors are not supported in the `asia-southeast3` region.

## Cloud Run instances locations

Cloud Run instances can be created in any of the [supported regions](https://docs.cloud.google.com/run/docs/locations), **except for the following regions** :

  * `europe-west1`
  * `us-central1`
  * `us-east1`
