#  Understand zonal redundancy Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Run is a regional offering. Data and traffic are automatically load balanced across zones within a region. In the event of a zonal failure, API operations are not affected and traffic will be routed to other zones. If you use [Cloud Run GPUs](https://docs.cloud.google.com/run/docs/configuring/services/gpu), you can turn off zonal redundancy for the service. For details, see [GPU zonal redundancy options](https://docs.cloud.google.com/run/docs/configuring/services/gpu#zonal-redundancy).

Learn more about planning for [zonal and regional failures](https://docs.cloud.google.com/architecture/disaster-recovery#cloud_run).
