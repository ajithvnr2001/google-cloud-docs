#  Run batch inference using GPUs on Cloud Run jobs Stay organized with collections  Save and categorize content based on your preferences. 

You can run batch inference with [Meta's Llama 3.2-1b LLM](https://huggingface.co/meta-llama/Llama-3.2-1B) and [vLLM](https://github.com/vllm-project/vllm) on a Cloud Run job, then write the results directly to Cloud Storage using Cloud Run volume mounts.

See a step-by-step instructional codelab at [How to run batch inference on Cloud Run jobs](https://codelabs.developers.google.com/codelabs/cloud-run/how-to-batch-inference-cloud-run-jobs).
