#  Invoke jobs using Workflows Stay organized with collections  Save and categorize content based on your preferences. 

To execute Cloud Run jobs from a workflow, use the [Cloud Run Admin API connector](https://docs.cloud.google.com/workflows/docs/reference/googleapis/run/Overview).

For an end-to-end example of executing a Cloud Run job that processes data passed as environment variables to the job, see [Execute a Cloud Run job using Workflows](https://docs.cloud.google.com/workflows/docs/tutorials/execute-cloud-run-jobs).

For an end-to-end example of executing a Cloud Run job that processes data stored in a Cloud Storage bucket allowing you to encrypt the data using customer-managed encryption keys (CMEK), see [Execute a Cloud Run job that processes event data saved in Cloud Storage](https://docs.cloud.google.com/workflows/docs/tutorials/execute-cloud-run-jobs-stored-events).
