#  Upgrade a 1st gen Cloud Run function to Cloud Run Stay organized with collections  Save and categorize content based on your preferences. 

Transitioning your 1st gen functions to Cloud Run functions lets you take advantage of features like request concurrency, longer processing timeouts, and updated language runtimes. Deploying workloads through the Cloud Run Admin API replaces the legacy Cloud Functions v1 API and provides consistent configuration across your services.

Before you begin, review how 1st gen functions [differ](https://docs.cloud.google.com/run/docs/functions/comparison#comparison) from Cloud Run functions. When you are ready to move your workloads, follow the steps to [upgrade](https://docs.cloud.google.com/functions/1stgendocs/migrating/upgrade-gen1-functions) your existing deployments.

  * Understand how 1st gen functions [differ](https://docs.cloud.google.com/run/docs/functions/comparison#comparison) from Cloud Run functions running on Cloud Run.

  * Learn how to [upgrade](https://docs.cloud.google.com/functions/1stgendocs/migrating/upgrade-gen1-functions) a 1st gen Cloud Run function to Cloud Run.
