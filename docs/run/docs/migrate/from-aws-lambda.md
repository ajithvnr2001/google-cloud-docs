#  Migrate from AWS Lambda Stay organized with collections  Save and categorize content based on your preferences. 

Cloud Run is one of several serverless migration options that are available when you migrate from Amazon Web Services (AWS) Lambda to Google Cloud. Many users migrate to Cloud Run from AWS Lambda because both products share similarities such as automatic resource provisioning, scaling by the cloud provider, and a pay-per-use pricing model.

Learn more about how to [migrate from AWS Lambda to Cloud Run](https://docs.cloud.google.com/architecture/migrate-aws-lambda-to-cloudrun).
