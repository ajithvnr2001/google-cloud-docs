#  Migrate from on-premise Stay organized with collections  Save and categorize content based on your preferences. 

Migrate to Containers is used for modernizing traditional applications away from virtual machine (VM) instances and into native containers that run on Google Kubernetes Engine (GKE), GKE clusters, or Cloud Run. You can migrate workloads from VMs that run on VMware or Compute Engine, giving you the flexibility to containerize your existing workloads with ease and helping you plan for disaster recovery and resilience through designing for strengthening your service in case of [zonal and regional failures](https://docs.cloud.google.com/architecture/disaster-recovery#cloud-run).

Learn more about how to [migrate from a VM using Migrate to Containers](https://docs.cloud.google.com/migrate/containers/docs/autopilot-overview).
