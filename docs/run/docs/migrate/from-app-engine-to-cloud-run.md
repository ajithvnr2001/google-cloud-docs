App Engine and Cloud Run are Google Cloud platforms for hosting apps and services. Cloud Run is the latest Google Cloud serverless product.

To migrate from App Engine to Cloud Run:

  * Understand [the similarities and differences](https://docs.cloud.google.com/appengine/migration-center/run/compare-gae-with-run) between App Engine and Cloud Run.
  * Learn how to migrate from the App Engine [standard environment](https://docs.cloud.google.com/appengine/migration-center/run/migrate-app-engine-standard-to-run) and [flexible environment](https://docs.cloud.google.com/appengine/migration-center/run/migrate-app-engine-flexible-to-run).
  * For custom domains, see [how to migrate to Cloud Load Balancing](https://docs.cloud.google.com/appengine/migration-center/run/custom-domain-to-cloud-load-balancing).
