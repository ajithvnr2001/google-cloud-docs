#  Monitoring and logging overview Stay organized with collections  Save and categorize content based on your preferences. 

[Google Cloud Observability](https://docs.cloud.google.com/stackdriver/docs) provides logging and monitoring tools that help you understand what is happening in your Cloud Run resource.

## Writing and viewing logs

Cloud Logging captures, stores, and analyzes Cloud Run logs.

Read more about [writing and viewing logs](https://docs.cloud.google.com/run/docs/logging).

## Reporting errors

Error Reporting captures specially formatted error logs and displays them in the [Error Reporting dashboard](https://console.cloud.google.com/errors).

Read more about [reporting errors](https://docs.cloud.google.com/run/docs/error-reporting).

## Viewing monitored metrics

Cloud Monitoring records metrics regarding the execution of Cloud Run.

Read more about [viewing recorded metrics](https://docs.cloud.google.com/run/docs/monitoring).

## Using distributed tracing

Use traces to identify sources of any latency issues in your implementation.

Read more about [distributed tracing](https://docs.cloud.google.com/run/docs/trace).

## Audit logging

Google Cloud services generate audit logs that record administrative and access activities within your Google Cloud resources. Read more about [audit logging](https://docs.cloud.google.com/run/docs/audit-logging).

If you created Cloud Run functions using the [Cloud Functions v2 API](https://docs.cloud.google.com/functions/docs/apis), see [Functions audit logging](https://docs.cloud.google.com/functions/docs/monitoring/audit-logging).
