## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://cloud.google.com/support).

## Get support from the community

## Billing questions

Use the following resources to get help with billing questions:

  * To learn more about billing, read the [Google Cloud billing documentation](https://docs.cloud.google.com/billing/docs).
  * Resolve billing concerns by using the [Google Cloud Billing Troubleshooter](https://support.google.com/cloud/troubleshooter/7279311).
  * Request help with billing questions by contacting [Cloud Billing Support](https://docs.cloud.google.com/support/docs/get-billing-support).
  * To change or disable billing on a project, go to the **Billing** page in the Google Cloud console. For more information, see [Enable, disable, or change billing for a project](https://docs.cloud.google.com/billing/docs/how-to/modify-project) in the Cloud Billing Help.

**Caution:** When you disable billing for a project, you also disable all product resources in that project.
