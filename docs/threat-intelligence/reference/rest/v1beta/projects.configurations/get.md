Get a configuration by name.

### HTTP request

`GET https://threatintelligence.googleapis.com/v1beta/{name=projects/*/configurations/*}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`name` |  `string` Required. Name of the configuration to get. Format: vaults/{vault}/configurations/{configuration}  
  
### Request body

The request body must be empty.

### Response body

If successful, the response body contains an instance of `[Configuration](https://docs.cloud.google.com/threat-intelligence/reference/rest/v1beta/projects.configurations#Configuration)`.

### Authorization scopes

Requires the following OAuth scope:

  * `https://www.googleapis.com/auth/cloud-platform`



For more information, see the [Authentication Overview](https://docs.cloud.google.com/docs/authentication#authorization-gcp).

### IAM Permissions

Requires the following [IAM](https://cloud.google.com/iam/docs) permission on the `name` resource:

  * `threatintelligence.configurations.get`



For more information, see the [IAM documentation](https://cloud.google.com/iam/docs).
