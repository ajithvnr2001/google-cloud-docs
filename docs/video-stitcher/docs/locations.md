The Video Stitcher API is available in the following regions. For more information about regions, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions).

## Regions

The following table lists the regions in the Americas where the Video Stitcher API is available.

Region description | Region name  
---|---  
Iowa, USA | `us-central1`  
Oregon, USA | `us-west1`  
South Carolina, USA | `us-east1`  
São Paulo, Brazil | `southamerica-east1`  
  
The following table lists the regions in Asia Pacific where the Video Stitcher API is available.

Region description | Region name  
---|---  
Taiwan | `asia-east1`  
Mumbai | `asia-south1`  
Singapore | `asia-southeast1`  
  
The following table lists the regions in Europe where the Video Stitcher API is available.

Region description | Region name  
---|---  
Belgium | `europe-west1`  
  
## Location considerations

When you create a live or VOD session, you can specify a location to process it with the Video Stitcher API. After you create a session, you can't change its location.
