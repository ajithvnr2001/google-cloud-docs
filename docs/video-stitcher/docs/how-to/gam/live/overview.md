#  Integrate Google Ad Manager (GAM) with livestreams Stay organized with collections  Save and categorize content based on your preferences. 

This guide shows you how to insert ads served by Google Ad Manager (GAM) into a livestream using the Video Stitcher API. A test livestream generated by the Live Stream API is used in this guide, but you can also use your own livestream. 

## Limitations

The following limitations apply to this feature during the preview period:

  * An [Ad Manager account](https://admanager.google.com/home/capabilities/video/) will be needed. You must have administrator access to the Ad Manager account.
  * This feature is available through HTTP requests.
  * This feature is available in [select regions](https://docs.cloud.google.com/video-stitcher/docs/locations).
