#  Integrate Google Ad Manager (GAM) with VOD assets Stay organized with collections  Save and categorize content based on your preferences. 

This guide shows you how to insert ads served by Google Ad Manager (GAM) into a VOD asset using the Video Stitcher API. This guide assumes you have a VOD asset. If you don't, this guide will direct you on how to create one in Cloud Storage. You also need a valid Ad Manager [ad tag](https://support.google.com/admanager/answer/1181016). 

## Limitations

The following limitations apply to this feature during the preview period:

  * An [Ad Manager account](https://admanager.google.com/home/capabilities/video/) will be needed. You must have administrator access to the Ad Manager account.
  * This feature is available through HTTP requests.
  * This feature is available in [select regions](https://docs.cloud.google.com/video-stitcher/docs/locations).
