# Knowledge Catalog documentation

[Read product documentation](https://docs.cloud.google.com/knowledge-catalog/docs/introduction)

Knowledge Catalog (formerly Dataplex Universal Catalog) is an AI-powered data catalog that provides business context and governance for your entire data estate. By automatically extracting semantics from structured and unstructured data, it builds a dynamic context graph that grounds AI agents in enterprise truth and reduces hallucinations. Data teams and AI developers use Knowledge Catalog to discover data, enforce policies, and retrieve rich context for both traditional data analytics and autonomous agentic applications. [Learn more](https://docs.cloud.google.com/knowledge-catalog/docs/introduction).
