#  Function: uuid.generate Stay organized with collections  Save and categorize content based on your preferences. 

Returns a random universally unique identifier (UUID).

## Returns

A random 128-bit UUID in string form.

## Examples
    
    
    # Return a random 128-bit UUID in string form
    # For example, returns "747760c7-0fcf-49fe-a204-28c3fc0ffabc"
    - returnStep:
        return: ${uuid.generate()}
