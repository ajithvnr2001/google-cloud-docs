## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Join Workflows Insiders

Join the [Workflows Insiders email list](https://docs.google.com/forms/d/e/1FAIpQLSfSWZyExf1QGcxIuiHVxVzcoP9PWOABvhkLjDpSIIngT06mTA/viewform?resourcekey=0-Hxd53Di_BDNIpyEZ1bcAmg) to receive Workflows announcements, community support, and early access to preview releases.

## Get support from the community

### Ask a question on Stack Overflow

Use the tag `google-workflows` to ask a question about Workflows on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-workflows). This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Workflows

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Workflows and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Workflows, join the [`#workflows`](https://googlecloud-community.slack.com/messages/C01A9P72SKB/) channel. 

## File bugs or feature requests

To file a bug or a feature request, use the Workflows [issue tracker](https://issuetracker.google.com/issues/new?component=976157).

To file a bug or a feature request about the documentation, click the thumbs up or thumbs down button on the documentation page and select **Need to tell us more?** after answering the brief survey.

### Request a Workflows connector

To request a new [connector](https://docs.cloud.google.com/workflows/docs/reference/googleapis#list_of_supported_connectors), submit this [form](https://docs.google.com/forms/d/e/1FAIpQLScdDRwFHcFuy28hvjGq0XCBMyiVuhHGq2c-7Gy_no1ZuqKAOg/viewform).

### Request support for a region

To request Workflows support for a [region](https://docs.cloud.google.com/workflows/docs/locations), submit this [form](https://docs.google.com/forms/d/e/1FAIpQLSeYws9NlyYBKdJpBJZaptCSAaX6HHxpkPbnrblLtIBdLdMyZw/viewform).
