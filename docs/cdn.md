Features

### Cloud CDN and Media CDN

[Cloud CDN](https://cloud.google.com/cdn/docs/overview) accelerates web applications using Google's global edge network.

[Media CDN](https://cloud.google.com/media-cdn/docs/overview) uses YouTube's infrastructure to bring video streams (VoD and live) and large file downloads closer to users for fast and reliable delivery.

[![Getting started with Cloud CDN](https://www.gstatic.com/bricks/image/n1UGV-v4fy5T19oOhpwzHKbiFAGsNtV9OUDfOLWwznDDkWu6fbcQm0Ds4TJ1OTPU9CLR8cZfw_k.png)VIDEOGetting started with Cloud CDN3:13](https://youtu.be/ftocllBHpe0)

### Universal support for any origin and back end

Pull content from any HTTP-capable origin, including [Compute Engine](https://cloud.google.com/compute), [Cloud Storage](https://cloud.google.com/storage), and [Google Kubernetes Engine](https://cloud.google.com/kubernetes-engine) back ends and origins outside of Google Cloud, such as storage buckets in other clouds.

[![google cloud logo with text media CDN](https://www.gstatic.com/bricks/image/gMFBJBwAXq-_606E1C27JpgsVxuCNelyqL1BYfEWG3RKPUKkpwSbBRsiOdflW0AJ56A9rCmcXbo.png)VIDEO Introducing Media CDN1:41](https://youtu.be/N_TBfQU7eJE)

### Security in-depth

Cloud CDN and Media CDN integrate with [Cloud Armor](https://cloud.google.com/armor). Protect content at the edge with Cloud Armor that has protected companies from some of the largest DDoS attacks. 

### Fine-grain cache controls

Configure caching behavior by origin that allows you to have [fine-grained control](https://cloud.google.com/cdn/docs/caching) over cache keys, TTLs, and other caching features based on the content type being served. 

[![AI generated yellow pattern](https://www.gstatic.com/bricks/image/6af49441-81e4-4987-ab69-44bd8d569f00.png)Media CDN origin offload for a higher cache hit rate](https://cloud.google.com/blog/products/networking/media-cdn-origin-offload-does-trick-for-warner-bros-discovery)

### Route matching and origin selection

[Cloud CDN](https://cloud.google.com/cdn/docs) and [Media CDN](https://cloud.google.com/media-cdn/docs) provide advanced HTTP routing capabilities that allow you to map traffic to specific edge configurations and origins at a fine-grained level.

### Real-time logging and metrics

Understand how traffic is being served by [Cloud CDN](https://cloud.google.com/cdn/docs/logging) and [Media CDN](https://cloud.google.com/media-cdn/docs/logging) with Cloud Logging and [Cloud Monitoring](https://cloud.google.com/monitoring).

### Modern protocols for better user experience

Protocols such as [TLS version 1.3](https://cloud.google.com/media-cdn/docs/ssl-certificates), QUIC, Global Anycast directly benefit the user experience by delivering render-blocking web content more quickly and reducing playback start time and rebuffering when serving video.
