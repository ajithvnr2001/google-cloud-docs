## Volume backup workflow

Creating a reliable backup strategy, by setting up volume backups, helps you protect and access your data.

You must complete the following steps to successfully set up volume backups for NetApp Volumes:

  1. [Create a backup vault](https://docs.cloud.google.com/netapp/volumes/docs/protect-data/create-backup-vault) to hold your backups.

  2. For scheduled backups, [create a backup schedule](https://docs.cloud.google.com/netapp/volumes/docs/protect-data/create-backup-policy).

  3. [Assign a volume to a backup vault](https://docs.cloud.google.com/netapp/volumes/docs/protect-data/manage-backup-vault#assign_a_volume_to_your_backup_vault). If you want to schedule backups, [attach a backup policy](https://docs.cloud.google.com/netapp/volumes/docs/protect-data/manage-backup-policy#assign_a_backup_policy_for_a_new_volume).
