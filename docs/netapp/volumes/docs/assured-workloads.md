## About Assured Workloads

Assured Workloads lets you apply controls to a folder to meet regional requirements. It offers features like data residency and customer-managed encryption keys (CMEK) to maintain compliance with various regulatory and administrative policies.

NetApp Volumes supports Assured Workloads for [regional controls](https://docs.cloud.google.com/assured-workloads/docs/control-packages#regional-controls) across its Flex (File type), Standard, Premium, and Extreme service levels in all [regions](https://docs.cloud.google.com/assured-workloads/docs/locations) that support these service levels.

**Note:** The Flex service level of the **File** type supports Assured Workloads in all Flex regions, with the exception of the Kingdom of Saudi Arabia (KSA).**Note:** Assured Workloads isn't supported by the Flex service level of the **Unified** type because it doesn't meet the same regulatory control requirements as the Flex service level of the **File** type.

You can deploy NetApp Volumes in a protected and controlled environment that meets compliance requirements for highly regulated sectors such as government, healthcare, and financial services.

For more information about using Assured Workloads, see [Assured Workloads documentation](https://docs.cloud.google.com/assured-workloads/docs/overview).

## Key features and benefits

Assured Workloads offers strict controls and enhanced visibility into data locality, personnel access, and auditing of data stored in NetApp Volumes.

  * **Data locality** : provides precise control over data location, which lets you specify where NetApp Volumes data is stored and processed.

  * **Personnel access** : defines which Google Cloud users can access your data and under what circumstances, adding an extra layer of security and control.

  * **Audit logging** : provides comprehensive audit logs which offer detailed visibility into activities and events in your environment. These logs help you with monitoring, troubleshooting, and compliance audits.

  * **Cryptographic control over data access** : all data stored in NetApp Volumes is encrypted by default. For more control over data encryption, you can use Cloud Key Management Service (Cloud KMS) to manage your own encryption keys. Assured Workloads supports appropriate encryption standards based on your specific compliance needs.
