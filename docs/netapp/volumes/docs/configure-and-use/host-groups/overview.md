This page provides an overview of the host groups feature of Google Cloud NetApp Volumes.

## About host groups

A host group manages access to NetApp Volumes for multiple iSCSI initiators (host IQNs). By grouping these initiators, you can control which hosts can connect to and use specific volumes. Host groups also manage permissions and streamline storage provisioning across multiple hosts.
