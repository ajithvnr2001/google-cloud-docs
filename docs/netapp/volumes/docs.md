# Google Cloud NetApp Volumes documentation

[Read product documentation](https://docs.cloud.google.com/netapp/volumes/docs/discover/overview)

Google Cloud NetApp Volumes is a fully managed, cloud-based data storage service that provides advanced data management capabilities and highly scalable performance. You can use Google Cloud NetApp Volumes to accelerate deployment times, manage your workloads and applications, and migrate workloads to the cloud while keeping the performance and features of on-premises storage.
