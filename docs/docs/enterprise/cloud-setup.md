Before you run workloads on Google Cloud, we recommend that administrators configure a foundation using Google Cloud Setup. A foundation includes fundamental settings that help you organize, manage, and maintain Google Cloud resources, including the following:

  * A [folder configured for application management](https://docs.cloud.google.com/resource-manager/docs/manage-applications) where you can define and manage applications.
  * A [management project](https://docs.cloud.google.com/resource-manager/docs/manage-applications#management-project) which helps you manage access, billing, observability, and other administrative functions for your applications.
  * A standard [project](https://docs.cloud.google.com/resource-manager/docs/cloud-platform-resource-hierarchy#projects) where you can deploy resources.
  * Administrator groups required to configure each foundation option.
  * Recommended organization policies.



Using the interactive guide in Google Cloud Setup, you can quickly deploy a default configuration or make adjustments to align with your business needs:

[Go to Google Cloud Setup](https://console.cloud.google.com/cloud-setup/overview)

## Select a Google Cloud Setup foundation option

To get started with Google Cloud Setup, select one of the following foundation options based on your organization's needs:

  * [Proof of concept](https://docs.cloud.google.com/docs/enterprise/proof-of-concept): Support proof-of-concept workloads with basic security in mind. This option guides you through the Organization, Billing, and Resource Hierarchy tasks. Use this option to experiment with Google Cloud before making a larger commitment.

  * [Production](https://docs.cloud.google.com/docs/enterprise/production): Support production-ready workloads with security and scalability in mind. This option includes all tasks in the _Proof of concept_ foundation, as well as logging, monitoring, and Security Command Center settings. Use this option to configure a secure and scalable foundation for your organization.

  * [Advanced production](https://docs.cloud.google.com/docs/enterprise/advanced-production): Support highly secure or complex workloads. This option includes all tasks in the _Production_ foundation, as well as networking settings, and Cloud KMS with Autokey configuration. Select this option if you have strict security requirements or want to apply networking configurations.




### Start a foundation option

To select a foundation option, do the following:

  1. Go to **Google Cloud Setup: Foundations**.

[Go to Foundations](https://console.cloud.google.com/cloud-setup/foundations)

  2. Click **Start** under one of the following options:

     * **Proof of concept**.
     * **Production**.
     * **Advanced production**.



## What's next

Complete the steps in one of the following pages:

  * If you selected the **Proof of concept** option, see [Create a proof of concept foundation](https://docs.cloud.google.com/docs/enterprise/proof-of-concept).

  * If you selected the **Production** option, see [Create a production foundation](https://docs.cloud.google.com/docs/enterprise/production).

  * If you selected the **Advanced production** option, see [Create an advanced production foundation](https://docs.cloud.google.com/docs/enterprise/advanced-production).
