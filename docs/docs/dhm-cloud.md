## Distributed, hybrid, and multicloud products by use case

Expand sections or use the filter to find products and guides for typical use cases.

### Distributed cloud

Extend Google Cloud infrastructure and services to the edge and into your data centers. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/products/distributed-cloud-color.svg)

####  [ Google Distributed Cloud air-gapped ](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch)

A private cloud that enables public sector organizations and regulated enterprises to address strict data residency and security requirements. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/products/distributed-cloud-color.svg)

####  [ Google Distributed Cloud connected ](https://docs.cloud.google.com/distributed-cloud/connected/latest/docs)

Run GKE clusters on dedicated hardware provided and maintained by Google that is separate from the Google Cloud data center. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/products/distributed-cloud-color.svg)

####  [ Google Distributed Cloud software only for bare metal ](https://docs.cloud.google.com/kubernetes-engine/distributed-cloud/bare-metal/docs)

Create, manage, and upgrade GKE clusters on premises while using Google Cloud features. Your clusters and workloads run directly on your on-premises hardware. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/products/distributed-cloud-color.svg)

####  [ Google Distributed Cloud software only for VMware ](https://docs.cloud.google.com/kubernetes-engine/distributed-cloud/vmware/docs)

Create, manage, and upgrade GKE clusters on premises while using Google Cloud features. Your clusters and workloads run in a VMware vSphere environment on your on-premises hardware. 

### Multicloud

Identify where to deploy resources across cloud providers, and create and manage Kubernetes clusters from Google Cloud in both AWS and Azure cloud environments. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/categories/hybrid-multicloud-color.svg)

####  [ GKE Multi-Cloud ](https://docs.cloud.google.com/kubernetes-engine/enterprise/clusters/docs)

Provides a unified way to work with Kubernetes clusters, extending GKE to work in multiple environments. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/categories/hybrid-multicloud-color.svg)

####  [ GKE attached clusters ](https://docs.cloud.google.com/anthos/clusters/docs/multi-cloud/attached)

Manage any standard, CNCF-compliant Kubernetes installation, including clusters in production. Add features to standardize and secure your clusters across multiple cloud environments and Kubernetes vendors. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/categories/hybrid-multicloud-color.svg)

####  [ GKE on AWS ](https://docs.cloud.google.com/anthos/clusters/docs/multi-cloud/aws)

Manage GKE clusters running on AWS infrastructure. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/categories/hybrid-multicloud-color.svg)

####  [ GKE on Azure ](https://docs.cloud.google.com/anthos/clusters/docs/multi-cloud/azure)

Manage GKE clusters running on Azure infrastructure. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/categories/compute-color.svg)

####  [ Knative serving ](https://docs.cloud.google.com/anthos/run/docs)

Abstracts away the complexity of Kubernetes, making it easy to build and deploy your serverless workloads across hybrid and multicloud environments. 

![](https://docs.cloud.google.com/_static/clouddocs/images/icons/categories/operations-color.svg)

####  [ Cloud Location Finder ](https://docs.cloud.google.com/location-finder/docs)

Find cloud locations across cloud providers based on proximity, jurisdiction, and carbon footprint. 

### Fleet management

Simplify managing multi-cluster deployments, including clusters outside Google Cloud. 

description 

####  [ GKE fleet management ](https://docs.cloud.google.com/kubernetes-engine/fleet-management/docs)

Manage clusters, infrastructure, and workloads together as a fleet of Kubernetes clusters and other resources.
