## September 20, 2024

Announcement

Gitlab on Google cloud is [Generally Available](https://cloud.google.com/products#product-launch-stages). 

The integration enables customers to deploy source from GitLab to Google Cloud run-time environments. The integration simplifies authentication and authorization to Google for GitLab piplines, and uses GitLab and Google CI/CD components. 

To get started, try the [GitLab end-to-end tutorial](https://docs.gitlab.com/ee/tutorials/set_up_gitlab_google_integration/).

## April 09, 2024

Announcement

GitLab on Google Cloud is in [Preview](https://cloud.google.com/products#product-launch-stages). The integration enables customers to deploy source from GitLab to Google Cloud run-time environments. The integration simplifies authentication and authorization to Google for GitLab piplines, and uses GitLab and Google CI/CD components. To get started, try the [GitLab end-to-end tutorial](https://docs.gitlab.com/ee/tutorials/set_up_gitlab_google_integration/).
