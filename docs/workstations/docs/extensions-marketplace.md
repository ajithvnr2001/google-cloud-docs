Code OSS for Cloud Workstations is based on the open source project [Code-OSS](https://github.com/microsoft/vscode). You can debug code, run scripts, view code with syntax highlighting, and use version control through the editor interface. The editor provides basic support for the most common programming languages and you can add additional languages and features with extensions or customize your environment with [containers](https://docs.cloud.google.com/workstations/docs/custom-container-images).

## Browse extensions

You can find and install extensions from the [Open VSX Registry](https://open-vsx.org/) through the Cloud Workstations interface.

To access extensions from within Cloud Workstations, follow these steps:

  1. Launch your workstation.

To learn how to launch a workstation, and create one first if necessary, see [Create and launch a workstation](https://docs.cloud.google.com/workstations/docs/create-workstation).

  2. Navigate to the Activity Bar and click ![](https://docs.cloud.google.com/static/workstations/images/extensions-icon.svg)**Extensions**. The primary sidebar opens and displays a list of extensions.

  3. Enter text in the search field to browse the catalog and find extensions to add additional features to your IDE. For example, enter `python` to find extensions for the Python programming language.




## Install an extension

**Note:** Google does not operate open-vsx.org nor validate the extensions hosted there. Before installing an extension, make sure that you validate and trust the provenance of the extension. For added protection, we recommend using a custom container and [installing extensions from a known source](https://docs.cloud.google.com/workstations/docs/customize-container-images#container-image-that-pre-installs-ide-extensions-in-code-oss-for-cloud-workstations-for-java-development) at container build time.

After you browse and find an extension you want to try, install it with these steps:

  1. In the primary sidebar, select the extension that you want to install.

  2. The Editor area displays additional information about the extension. To install the extension, click **Install** from the entry in the catalog.

![Extensions marketplace](https://docs.cloud.google.com/static/workstations/images/extensions-marketplace-install.png)

  3. During installation, the **Install** button in the primary sidebar changes to **Installing**. After the installation finishes, the button changes to ![](https://docs.cloud.google.com/static/workstations/images/settings-gear.svg)**Manage**.
