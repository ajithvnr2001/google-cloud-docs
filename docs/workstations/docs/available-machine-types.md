#  Available machine types Stay organized with collections  Save and categorize content based on your preferences. 

This page lists available machine types for Cloud Workstations. To compare available machine series types, see the Compute Engine [machine types comparison table](https://docs.cloud.google.com/compute/docs/machine-types#machine_type_comparison). For a detailed list of Compute Engine supported machine types per region, see [available regions and zones](https://docs.cloud.google.com/compute/docs/regions-zones#available).

GPUs are optional for Cloud Workstations. For more information, see the list of [GPUs available in Cloud Workstations](https://docs.cloud.google.com/workstations/docs/available-gpus) and Compute Engine [GPU platforms](https://docs.cloud.google.com/compute/docs/gpus).
