## Authorization

RBAC policy that will be applied and managed by GEC.

Fields  
---  
`admin_users` |  ``[ClusterUser](https://docs.cloud.google.com/distributed-cloud/connected/1.6.0/docs/reference/container/rpc/google.cloud.edgecontainer.v1#google.cloud.edgecontainer.v1.ClusterUser)`` Required. User that will be granted the cluster-admin role on the cluster, providing full access to the cluster. Currently, this is a singular field, but will be expanded to allow multiple admins in the future.  
  
## Cluster

A Google Distributed Cloud Edge Kubernetes cluster.

Fields  
---  
`name` |  `string` Required. The resource name of the cluster.  
`create_time` |  ``[Timestamp](https://developers.google.com/protocol-buffers/docs/reference/google.protobuf#google.protobuf.Timestamp)`` Output only. The time when the cluster was created.  
`update_time` |  ``[Timestamp](https://developers.google.com/protocol-buffers/docs/reference/google.protobuf#google.protobuf.Timestamp)`` Output only. The time when the cluster was last updated.
