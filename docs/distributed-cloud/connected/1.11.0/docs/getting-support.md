To get support for Google Distributed Cloud connected, version 1.11.0, see the following resources.

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Customer Care support](https://docs.cloud.google.com/support).

## Get support from the community

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Distributed Cloud connected and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Distributed Cloud connected, join the [`#networking`](https://googlecloud-community.slack.com/messages/C2Q13BM0T/) channel. 

## File bugs or feature requests

From the Distributed Cloud connected documentation, click **Send feedback** at the top or bottom of the page. This opens a feedback form. Your comments are reviewed by the Distributed Cloud connected team.
