# Google Distributed Cloud connected, version 1.11.0 documentation

[Read product documentation](https://docs.cloud.google.com/distributed-cloud/connected/1.11.0/docs/overview)

Google Distributed Cloud connected, version 1.11.0 allows you to run Kubernetes clusters on dedicated hardware provided and maintained by Google that is separate from the Google Cloud data center.
