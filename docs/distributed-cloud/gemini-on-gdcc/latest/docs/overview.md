This feature is subject to the "Pre-GA Offerings Terms" in the General Service Terms section of the [Service Specific Terms](https://docs.cloud.google.com/terms/service-terms#1). Pre-GA features are available "as is" and might have limited support. For more information, see the [launch stage descriptions](https://cloud.google.com/products/#product-launch-stages). 

**Warning:** During the Preview period, you may only use Gemini on GDC connected API for evaluation and testing purposes. You may not use the Preview release of Gemini on GDC connected API for commercial or production purposes, or disclose generated output to a third party.

Gemini on Google Distributed Cloud connected API is a turnkey software solution that lets you deploy Gemini models on your own hardware connected to your local network. This lets you retain all of your data on your premises and within your local network.

Gemini on GDC connected API hosts models within Confidential Virtual Machines (CVMs) deployed on [Distributed Cloud connected](https://docs.cloud.google.com/distributed-cloud/edge/latest/docs/overview) clusters. The CVMs expose local endpoints that you can use to interact with the deployed models using the `ChatCompletions` API and the `ListAvailableModels` API.

Gemini on GDC connected API runs on a specific hardware configuration established and certified by Google. Gemini on GDC connected API connected does not run on non-certified hardware configurations.

Google supplies, deploys, and manages the Gemini on GDC connected API and Distributed Cloud connected software. You are responsible for procuring, deploying, and maintaining your Google-certified hardware.
