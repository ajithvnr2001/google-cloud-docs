This page lists the permissions required by Gemini on Google Distributed Cloud connected API and the [Identity and Access Management (IAM) roles](https://docs.cloud.google.com/iam/docs/understanding-roles) that encapsulate them.

## Distributed Cloud Edge Container API roles and permissions

Distributed Cloud Edge Container API roles and permissions required on the Google Cloud organization that hosts your Gemini on GDC connected API Google Cloud project. Assign them to IT Administrator and Organization Administrator accounts that interact with Gemini on GDC connected API endpoints.

  * [Edge Container Zone Viewer](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.zoneViewer)
  * [Edge Container Zonal Project Admin](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.zonalProjectAdmin)
  * [Edge Container Zonal Project Viewer](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.zonalProjectViewer)



The following Distributed Cloud Edge Container API roles and permissions are required on the Google Cloud project that hosts your Gemini on GDC connected API deployment. Assign them to accounts that interact with Gemini on GDC connected API endpoints.

  * [Service Usage Admin](https://docs.cloud.google.com/iam/docs/roles-permissions/serviceusage#serviceusage.serviceUsageAdmin)
  * [Edge Container Zonal Service Admin](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.zonalServiceAdmin)
  * [Edge Container Zonal Service Viewer](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.zonalServiceViewer)
  * [Edge Container Service Account Admin](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.serviceAccountAdmin)
  * [Edge Container Service Account Viewer](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.serviceAccountViewer)
  * [Edge Container Service Account Key Admin](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.serviceAccountKeyAdmin)
  * [Edge Container Zone Iam Policy Admin](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.zoneIamAdmin)
  * [Edge Container Zone Iam Policy Viewer](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.zoneIamViewer)
  * [Edge Container Machine User](https://docs.cloud.google.com/iam/docs/roles-permissions/edgecontainer#edgecontainer.machineUser)



## Vertex AI API roles and permissions

Vertex AI API roles and permissions required on the Google Cloud project that hosts your Gemini on GDC connected API deployment:

  * [Vertex AI User](https://docs.cloud.google.com/iam/docs/roles-permissions/aiplatform#aiplatform.user)
  * [Vertex AI Administrator](https://docs.cloud.google.com/iam/docs/roles-permissions/aiplatform#aiplatform.admin)



## Gemini on GDC connected API roles and permissions

The following Gemini on GDC connected API roles and permissions are required on the Google Cloud project that hosts your Gemini on GDC connected API deployment. Assign them to service accounts that interact with Gemini on GDC connected API endpoints. You must use the steps described in [Deploy an endpoint](https://docs.cloud.google.com/distributed-cloud/gemini-on-gdcc/latest/docs/endpoints#deploy-endpoint) to assign the roles listed in this section.

  * AI Platform Gemini Developer (`roles/aiplatform.geminiDeveloper`)
