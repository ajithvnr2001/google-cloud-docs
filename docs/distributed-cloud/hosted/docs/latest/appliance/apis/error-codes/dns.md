#  DNS error reference Stay organized with collections  Save and categorize content based on your preferences. 

Domain Name System (DNS) error messages consist of an error ID in the format `DNS1234` where `1234` is a unique number, followed by a description of the problem and a suggestion for how to fix it. This topic documents each of those error messages.

## DNS1000: FrequentDNSPanics

DNS service has experienced more than 5 panics over a recent period of 10 minutes. Please check for error logs (if any) in the DNS service. If the error logs do not point to an explicit issue, restart the DNS deployment.
