#  View the virtual network Stay organized with collections  Save and categorize content based on your preferences. 

There is a single isolated virtual network in GDC, consisting of two ranges: and internal range and an external range. To view these IP ranges in the GDC console, follow these steps:

  1. Sign in to the GDC console.
  2. Click _menu_ **Menu**.
  3. In the **Networking** section, click **Virtual Network**.
  4. View the table to see the internal and external IP ranges for the default virtual network.
