#  Supported languages for Vertex AI Translation Stay organized with collections  Save and categorize content based on your preferences. 

Vertex AI Translation lets you translate text written in a given language into English, the language code of which is `en`.

This page contains the list of supported languages that translate to English.

To use the `getSupportedLanguages` method to return the list of languages that the Vertex AI Translation API supports, see [Get supported languages](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/application/ao-user/quickstart-translation#get-supported-lang).

## Supported languages to translate to English

The following languages translate to English (`en`):

Language | Language code  
---|---  
Arabic | `ar`  
Bulgarian | `bg`  
Chinese (Simplified) | `zh`  
French | `fr`  
German | `de`  
Japanese | `ja`  
Korean | `ko`  
Pashto | `ps`  
Persian | `fa`  
Russian | `ru`  
Slovak | `sk`  
Ukrainian | `uk`
