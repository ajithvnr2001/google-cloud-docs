#  Return the device Stay organized with collections  Save and categorize content based on your preferences. 

Return your Google Distributed Cloud (GDC) air-gapped appliance to Google when it's no longer needed or if requesting a replacement of a non-functional device. Contact your Google representative to make arrangements for returning the device.

Before returning the device to Google, remove the YubiKeys from the server and destroy the YubiKeys.
