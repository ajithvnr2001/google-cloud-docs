#  Dashboards overview Stay organized with collections  Save and categorize content based on your preferences. 

Grafana dashboards let you visualize metrics and logs of operable components on Google Distributed Cloud (GDC) air-gapped appliance. These dashboards provide graphical information and visualization panels for viewing component-specific data from your project.

This section contains an overview of the available dashboards from operable components on GDC and the type of information that the available graphs and visualization panels provide.

To obtain more information about monitoring and visualizing processes, such as how to obtain authorization to access dashboards, review the following pages:

  * [Collect and query metrics](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/admin/monitoring-overview): Detailed information about collecting metrics, viewing metrics, and managing your dashboards
  * [Collect and query logs](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/admin/logging-overview): The logging processes available in GDC
  * [Create and manage alerts](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/admin/alerting-overview): Information about alerts and notification channels
