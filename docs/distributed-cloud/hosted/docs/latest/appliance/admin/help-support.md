This page describes the available resources and support options for Google Distributed Cloud (GDC) air-gapped appliance.

## Google Cloud support

GDC technical support services are only available for customers who have purchased Enhanced or Premium support. Use the [Google Cloud Support Portal](https://support.cloud.google.com/portal/) to file and manage support cases for your organization. For more information on Google Cloud support, refer to [Create a support case](https://cloud.google.com/support/docs/customer-care-procedures#create_a_support_case) and visit the [Support Hub](https://cloud.google.com/support-hub).
