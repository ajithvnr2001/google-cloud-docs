## NAME

gdcloud storage - Create and manage GDC air-gapped storage resources, such as buckets and objects.

## SYNOPSIS
    
    
    gdcloud storage GROUP | COMMAND [flags]
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/resources/gdcloud-reference/gdcloud) page.

### GROUPS

`GROUP` is one of the following:
    
    
    buckets
        Manage GDC air-gapped object storage buckets.
    objects
        Manage object storage objects.
    

### COMMANDS

`COMMAND` is one of the following:
    
    
    cat
        Output the contents of one or more URLs to stdout.
    cp
        Upload, download, and copy objects.
    ls
        List storage buckets and objects
    mv
        Move or rename objects.
    rm
        Delete objects and buckets.
