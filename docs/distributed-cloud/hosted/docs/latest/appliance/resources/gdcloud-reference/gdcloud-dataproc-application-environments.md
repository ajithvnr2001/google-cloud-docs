## NAME

gdcloud dataproc application-environments - Manage Dataproc application environments.

## SYNOPSIS
    
    
    gdcloud dataproc application-environments COMMAND [flags]
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/resources/gdcloud-reference/gdcloud) page.

### COMMANDS

`COMMAND` is one of the following:
    
    
    create
        Create a new Dataproc application environment.
    delete
        Delete a Dataproc application environment.
    list
        List all Dataproc application environments.
