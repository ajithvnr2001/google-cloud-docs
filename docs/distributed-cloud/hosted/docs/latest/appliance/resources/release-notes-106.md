## July 13, 2026

* * *

Announcement

Google Distributed Cloud (GDC) air-gapped appliance 1.0.6 is generally available.  
See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/overview) to learn about the features of GDC air-gapped appliance. 

* * *

Feature

The following new features are available: 

**Virtual machines**

  * Added Secure Boot certificate renewal support for VMs with expiring certificates. For more information, see [Update Secure Boot certificates](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/application/ao-user/vms/manage-vms/secure-vms/secure-boot-cert-update).
