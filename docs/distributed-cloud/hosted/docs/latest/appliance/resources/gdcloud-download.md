#  Download the gdcloud CLI Stay organized with collections  Save and categorize content based on your preferences. 

This page details how to download the gdcloud CLI. You have two options for this download:

  1. Download the latest version.
  2. Download an archived version.



## Download the latest gdcloud CLI

**Important:** All gdcloud CLI commands in the Google Distributed Cloud (GDC) air-gapped appliance documentation use gdcloud CLI and require a Linux environment.

Download the gdcloud CLI bundle to your system from the user interface (UI).

To download the gdcloud CLI through the UI:

  1. Sign in and access the Google Distributed Cloud air-gapped appliance **Welcome** page.
  2. Navigate to the **Connect with CLI** section.
  3. Click **Download CLI bundle**.



![Download the CLI bundle.](https://docs.cloud.google.com/static/distributed-cloud/hosted/docs/latest/appliance/resources/images/download-button.png)

## Download an archived version of the gdcloud CLI

To download a different version of the gdcloud CLI, complete the following steps:

  1. Go to the Google Distributed Cloud air-gapped appliance **Welcome** page.
  2. In the **Connect with CLI** section, click **Download CLI bundle**.
  3. Choose the supported version of interest.



![Download the CLI bundle](https://docs.cloud.google.com/static/distributed-cloud/hosted/docs/latest/appliance/resources/images/download-cli-bundle.png)

## Extract the gdcloud CLI bundle

Extract the contents of the downloaded gdcloud CLI bundle to any location on your file system.

To replace an existing installation, remove the existing `google-distributed-cloud-hosted-cli` directory and extract the archive to the same location.

  * Extract the bundle:
        
        tar -xf BUNDLE_PATH/gdcloud_cli.tar.gz
        

Replace `BUNDLE_PATH` with the path of the gdcloud CLI bundle. The default path is `~/Downloads`, unless the bundle download path was intentionally changed.
