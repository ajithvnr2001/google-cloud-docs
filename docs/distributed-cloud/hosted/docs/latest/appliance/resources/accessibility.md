#  Google Distributed Cloud air-gapped appliance accessibility Stay organized with collections  Save and categorize content based on your preferences. 

Accessibility features in Google Distributed Cloud (GDC) air-gapped appliance let you operate the platform with screen readers and assistive gdcloud CLI settings. You can also check supported browser pairings and review Voluntary Product Accessibility Template (VPAT) reports for US Section 508 and EN 301 549 compliance.

**Important:** To access the URLs on this page, you must connect to the internet. The URLs are provided for use when you have such access.

## Recommended browsers and screen readers

Based on your operating system, use the following screen readers with these recommended browsers:

Operating system  | Screen reader  | Browser   
---|---|---  
Microsoft Windows  | NVDA or JAWS  | Mozilla Firefox  Chrome Browser  
macOS  | VoiceOver  | Chrome Browser   
ChromeOS  | ChromeVox  | Chrome Browser   
iOS  | VoiceOver  | Not applicable (mobile app)   
Android  | TalkBack  | Not applicable (mobile app)   
  
## Use accessibility features

To use assistive technology with GDC, see the following resources:

  * [Enabling accessibility features for the gdcloud CLI](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/appliance/resources/gdcloud-accessibility)



## GDC air-gapped appliance accessibility report

A Voluntary Product Accessibility Template (VPAT) explains how information and communication technology meet the _US Section 508_ and _EN 301 549_ standards for accessibility.

See the [VPAT](https://docs.cloud.google.com/static/distributed-cloud/hosted/docs/latest/appliance/resources/vpats/GDCH_Appliance_VPAT_22_December_2023.pdf) for GDC air-gapped appliance.

For more information about the GDC Voluntary Product Accessibility Templates (VPAT), contact [gdch-a11y@google.com](mailto:gdch-a11y@google.com).

### Resources

For more information on the US Section 508 and EN 301 549 standards, see the following:

  * US Section 508: <https://www.section508.gov/manage/laws-and-policies/#508-policy>
  * EN 301 549: <https://www.etsi.org/deliver/etsi_en/301500_301599/301549/02.01.02_60/en_301549v020102p.pdf>
