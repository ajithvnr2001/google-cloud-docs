#  Supported GDC services for multi-zone Stay organized with collections  Save and categorize content based on your preferences. 

Google Distributed Cloud (GDC) air-gapped offers the following multi-zone services for audiences part of the [platform administrator](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/audiences#pa) group and [application operator](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/audiences#ao) group:

Service | Data plane configuration  
---|---  
[Asynchronous storage buckets](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/ha-apps/deploy-ha-vm-app#async-obj-storage) | Dual zone  
[Asynchronous storage volumes](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/async-block-replication) | Dual zone  
[Cloud DNS](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/dns/dns-overview) | All zones in an organization  
[GDC console](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/multi-zone/api-servers#console) | All zones in an organization  
[Global API](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/multi-zone/api-servers) | All zones in an organization  
[IAM](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/iam/connect-identity) | All zones in an organization  
[L4 load balancer](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/expose-services) | All zones in an organization  
[Resource Manager](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/project-management) | All zones in an organization  
  
For more information on multi-zone and how you can configure your services for high availability, see [Multi-zone overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/multi-zone/mz-overview).
