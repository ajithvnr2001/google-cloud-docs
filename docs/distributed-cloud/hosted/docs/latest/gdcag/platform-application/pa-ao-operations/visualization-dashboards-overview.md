#  Dashboards overview Stay organized with collections  Save and categorize content based on your preferences. 

Google Distributed Cloud (GDC) air-gapped provides comprehensive dashboards within your project to help you visualize data and monitor the health and performance of your deployments. These dashboards offer graphical insights into key metrics and logs for various GDC components, letting you assess and understand your system's behavior.

This section provides a description of the available dashboards and the information they present.

For more information about monitoring and visualization, including how to access dashboards and configure alerts, see the following resources:

  * [Collect and query metrics](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/monitoring-overview): Learn how to gather, view, and manage metrics and dashboards.
  * [Collect and query logs](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/logging-overview): Understand the logging processes available in GDC.
  * [Create and manage alerts](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/alerting-overview): Discover how to set up alerts and configure notification channels for proactive monitoring.
