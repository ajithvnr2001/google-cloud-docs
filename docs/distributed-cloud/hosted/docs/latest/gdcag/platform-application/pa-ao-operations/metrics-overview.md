#  Metrics overview Stay organized with collections  Save and categorize content based on your preferences. 

Metrics are quantitative measurements taken from workloads deployed in your Google Distributed Cloud (GDC) air-gapped project that help you monitor resources.

This section provides information about metrics collected in your GDC environment, including information on type, duration, and labels for each component metric. Use this information to construct [PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/) (Prometheus Query Language) expressions for querying metrics. For more information, see [Query and view metrics](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/query-and-view-metrics).

Review information about metrics for the following GDC components:

  * [AddOn Manager (ADD)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-add)
  * [Backup and Restore (BACK)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-back)
  * [Cloud DNS (DNS)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-dns)
  * [Database Service (DBS)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-dbs)
  * [Kubernetes cluster (KUB)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-kub)
  * [Managed Harbor Service (MHS)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-mhs)
  * [Object Storage (OBJ)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-obj)
  * [Upgrade Orchestrator (UPG)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-upg)
  * [Agent Search (VAIS)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-vais)
  * [Virtual Machine Management (VMM)](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform-application/pa-ao-operations/metrics-vmm)
