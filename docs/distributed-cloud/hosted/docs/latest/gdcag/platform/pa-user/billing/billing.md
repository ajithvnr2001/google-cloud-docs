Google Distributed Cloud (GDC) air-gapped provides a view of usage and costs for running your Distributed Cloud installation using dashboards.

## Billing reports

View the costs in your organization and project through the **Billing reports** page in the GDC console.

**Note:** Before accessing the **Billing reports** page you must ask your Organization IAM Admin to:  


  * In case of Organization, grant you the Organization Grafana Viewer (`organization-grafana-viewer`) role.
  * In case of Project, grant you Project Grafana Viewer (`project-grafana-viewer`) role for your project.



The **Billing reports** page provides the links to view your costs and resource metrics through the following dashboards:

  * [**Invoices**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/billing/view-invoices)
  * [**Cost projection**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/billing/estimate-projected-costs)
  * [**Real Time Cost**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/billing/monitor-real-time-costs)
  * [**Services usage**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/billing/track-resource-consumption)
  * [**Storage and Compute allocation dashboards**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/platform/pa-user/billing/track-resource-consumption)



The GDC console defaults the **Billing reports** page at the organization level. To access the **Billing reports** page, do the following:

  1. Sign in to the GDC console.
  2. In the navigation menu, select **Billing > Reports**.
