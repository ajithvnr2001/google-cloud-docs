#  View NAT settings Stay organized with collections  Save and categorize content based on your preferences. 

Network Address Translation (NAT) settings refer to configurations that control how instances with private IP addresses can communicate with the internet or other networks. Google Distributed Cloud (GDC) air-gapped provides egress NAT configurations to both virtual machine and containerized workloads when accessing external networks. The GDC console shows all NAT settings across container deployments for a particular project.

## Before you begin

To get the permissions that you need to view NAT configurations, ask your Organization IAM Admin to grant you the NAT Viewer (`nat-viewer`) role.

## View NAT settings

To view NAT settings in the GDC console, follow these steps:

  1. Sign in to the GDC console.
  2. Click _menu_ **Menu**.
  3. In the Networking section, click **NAT**.
  4. Use the project drop-down menu to select a project.
  5. All NAT settings across container deployments are shown for the selected project.
