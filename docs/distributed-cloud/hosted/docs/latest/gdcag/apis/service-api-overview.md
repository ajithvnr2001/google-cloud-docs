#  Service APIs overview Stay organized with collections  Save and categorize content based on your preferences. 

Google Distributed Cloud (GDC) air-gapped application programming interfaces (APIs) are programmatic interfaces to the GDC platform services. They are a key part of the GDC platform. Use them to add additional computing, networking, storage, and machine-learning-based data analysis functionality to your applications.

### GDC Service APIs, System APIs, and Kubernetes APIs.

Some APIs are used by the underlying GDC system and are discoverable in Kubernetes. To discover such System APIs, use `kubectl` and other open source tools. Access to these APIs is restricted to the relevant Infrastructure Operators.
