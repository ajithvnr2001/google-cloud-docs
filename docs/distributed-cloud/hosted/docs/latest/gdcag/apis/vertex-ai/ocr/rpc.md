#  Vertex AI Optical Character Recognition API Stay organized with collections  Save and categorize content based on your preferences. 

This is the gRPC API reference for the Optical Character Recognition pre-trained API that is included with Vertex AI on Google Distributed Cloud (GDC) air-gapped. Use this guide to programmatically detect text in files and images.

## Service: Optical Character Recognition (OCR)

The Service name `OCR_ENDPOINT` is required to create RPC client stubs. For more information, see [View Vertex AI service statuses and endpoints](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-api-status)
