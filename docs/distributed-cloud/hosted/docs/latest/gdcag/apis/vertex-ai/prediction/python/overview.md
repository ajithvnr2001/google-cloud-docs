This is the Python Client Library (SDK) reference for the Online Predictions pre-trained API that is included with Vertex AI on Google Distributed Cloud (GDC) air-gapped. Use the API to get online predictions using your custom-trained models.

For information about this API, see [Send an online prediction request](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/quickstart-op#send-an-online-prediction-request).
