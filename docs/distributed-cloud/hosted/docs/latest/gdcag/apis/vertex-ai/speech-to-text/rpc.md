#  Vertex AI Speech-to-Text API Stay organized with collections  Save and categorize content based on your preferences. 

Converts audio to text by applying powerful neural network models.

## Service: speech.googleapis.com

The Service name `speech.googleapis.com` is needed to create RPC client stubs.

## `[google.cloud.speech.v1.Speech](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/apis/vertex-ai/speech-to-text/rpc/google.cloud.speech.v1#speech)`

Methods  
---  
``[Recognize](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/apis/vertex-ai/speech-to-text/rpc/google.cloud.speech.v1#recognizerequest)`` |  Performs synchronous speech recognition. `Recognize` receives results after all audio has been sent and processed. The request times out in 60 minutes.  
``[StreamingRecognize](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/apis/vertex-ai/speech-to-text/rpc/google.cloud.speech.v1#streamingrecognizerequest)`` |  Performs bidirectional streaming speech recognition. `StreamingRecognize` receives results while sending audio. The request times out in 60 minutes.
