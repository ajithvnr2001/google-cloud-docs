## August 2, 2023 [GDC 1.9.5]

* * *

Announcement

Google Distributed Cloud air-gapped 1.9.5 is now released.

See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Google Distributed Cloud air-gapped.

* * *

Change

In the Google Distributed Cloud air-gapped 1.9.5 Addon Manager (ADD) component, the Google Distributed Cloud version is updated to 1.14.6 to apply the latest security patches and important updates. 

See [Google Distributed Cloud 1.14.6 release notes](https://cloud.google.com/anthos/clusters/docs/bare-metal/1.14/release-notes-ver#release_1146) for details.

* * *

Fixed

In the Google Distributed Cloud air-gapped 1.9.5 AddOn component, the issue on clamav runner handling SIGTERM signal is resolved.

* * *

Fixed

In Google Distributed Cloud air-gapped versions 1.9.0 through 1.9.4, if a Project was created with a name longer than 20 characters, the Monitoring stack would fail to start due to a volume name being generated that exceeded Kubernetes' limit. The volume name is no longer generated in this way and the Monitoring stack supports the full 30-character Project name limit. 

* * *

Fixed

This release fixes an issue with disaster recovery execution of HSM backups.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.5 has a known issue where role-based access control (RBAC) and schema settings in the VM manager is stopping users from starting VM backup and restore processes. 

* * *

Issue

Google Distributed Cloud air-gapped 1.9.5 has a known issue where the `harbor-cert-secret` has a different certificate authority (CA) from the client side CA.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.5 has a known issue where a user cluster with three `n2-standard-4` worker nodes has insufficient CPU resources for upgrade.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.5 has a known issue where upgrade fails when a pod is terminated.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.5 has a known issue where the `kube-state-metrics` deployment crash loops.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.5 has a known issue where a user cluster does not become ready in time to restart the `coredns` deployment.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.5 has a known issue where alerts in organization system clusters don't reach the ticketing system.
