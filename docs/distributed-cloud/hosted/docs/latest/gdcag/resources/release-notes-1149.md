* * *

Announcement

Google Distributed Cloud (GDC) air-gapped 1.14.9 is available.  
See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Distributed Cloud.

Issue

The following issues are identified: 

**Monitoring**

  * There is no cost projection data visible within the **Dashboards > Billing > Projected Cost** section. 



**Networking**

  * Pods fail to start due to `Stray endpoint` warning and missing CiliumEndpoint. 



**Platform authentication**

  * Errors can occur when using a wildcard certificate for the infra web PKI while in BYO Cert mode. 



**Storage** :

  * `BucketLocationConfig` never becomes ready in organizations with membership asymmetry. 



**Ticketing system** :

  * An RBAC error from customer networks might deny access to ServiceNow. 



* * *

Fixed

The following issues are fixed: 

**DNS** :

  * A false DNS alert is fired suggesting `GlobalCustomerRootDNSServerNotReachable`.
