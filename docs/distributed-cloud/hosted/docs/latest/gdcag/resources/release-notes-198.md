## December 8, 2023 [GDC 1.9.8]

* * *

Announcement

Google Distributed Cloud air-gapped 1.9.8 is now released.

See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Google Distributed Cloud air-gapped.

* * *

Change

**Add-on Manager** :

The Google Distributed Cloud version is updated to 1.14.11 to apply the latest security patches and important updates. 

See [Google Distributed Cloud 1.14.11 release notes](https://cloud.google.com/anthos/clusters/docs/bare-metal/1.14/release-notes-ver#release_11411) for details.

* * *

Change

**Version update** :

The Debian-based image version is updated to bullseye-v1.4.3-gke.10.

* * *

Security

Updated Canonical Ubuntu OS image version to 20231116 to apply the latest security patches and important updates. To take advantage of the bug and security vulnerability fixes, you must upgrade all nodes with each release. The following security vulnerabilities are fixed:

  * [CVE-2022-33065](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2022-33065)
  * [CVE-2023-4016](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2023-4016)

  * [CVE-2023-43804](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2023-43804)
  * [CVE-2023-45803](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2023-45803)

* * *

Fixed

Google Distributed Cloud air-gapped 1.9.8 fixes an issue with the upgrade where `NodeUpgrade` firmware upgrade task gets stuck in the `in process` status.

* * *

Fixed

Google Distributed Cloud air-gapped 1.9.8 fixes an issue where the server BMC certificate state might get stuck in the `Generating` or `Verifying` states, blocking upgrade or server credential rotation.

* * *

Fixed

Google Distributed Cloud air-gapped 1.9.8 has a known issue where a user cluster with three `n2-standard-4` worker nodes has insufficient CPU resources for upgrade.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.8 has a known issue where role-based access control (RBAC) and schema settings in the VM manager is stopping users from starting VM backup and restore processes. 

* * *

Issue

Google Distributed Cloud air-gapped 1.9.8 has a known issue where the node draining is blocked due to pod stuck in the terminating state.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.8 has a known issue where the artifact distribution fails after attaching signatures.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.8 has a known issue where alerts in organization system clusters don't reach the ticketing system.
