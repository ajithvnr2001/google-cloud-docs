## March 27, 2025

* * *

Announcement

Google Distributed Cloud (GDC) air-gapped 1.13.9 is available.  
See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Distributed Cloud. 

* * *

Security

Updated the Rocky OS image version to 20250219 to apply the latest security patches and important updates. 

The following security vulnerabilities are fixed:

  * [CVE-2022-40303](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2022-40303)

Change

The following changes are identified: 

**Version updates** :

  * The Google Distributed Cloud for bare metal version is updated to 1.29.1100-gke.84 to apply the latest security patches and important updates.   
  
See the [Google Distributed Cloud for bare metal 1.29.1000 release notes](https://cloud.google.com/kubernetes-engine/distributed-cloud/bare-metal/docs/release-notes-ver-2#release_1291100-gke84) for details.



* * *

Issue

The following issues are identified: 

**Logging:**

  * Audit logs from the platform namespace are visible to the Infrastructure Operator (IO) instead of the Platform Administrator (PA). 



**Vertex AI:**

  * The Vertex AI pre-trained services are unavailable.
