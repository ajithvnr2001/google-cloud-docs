## December 9, 2024

* * *

Announcement

Google Distributed Cloud air-gapped 1.9.20 is released.

See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Google Distributed Cloud air-gapped.

* * *

Security

Updated the Ubuntu OS image version to 20241021 to apply the latest security patches and important updates. 

The following security vulnerabilities are fixed:

  * [CVE-2021-38578](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2021-38578)
  * [CVE-2023-31315](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2023-31315)
  * [CVE-2024-26960](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2024-26960)
  * [CVE-2024-27397](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2024-27397)
  * [CVE-2024-38630](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2024-38630)
  * [CVE-2024-45016](https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2024-45016)
