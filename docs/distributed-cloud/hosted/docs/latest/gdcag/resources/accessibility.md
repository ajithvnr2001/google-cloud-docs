#  Google Distributed Cloud air-gapped accessibility Stay organized with collections  Save and categorize content based on your preferences. 

Part of Google's mission is to make products and services universally accessible to users, including one billion people in the world who have a disability. This page outlines Google Distributed Cloud (GDC) air-gapped accessibility resources.

**Important:** To access the URLs listed on this page, you must connect to the internet. The URLs are provided to access outside of your air-gapped environment.

## Recommended browsers and screen readers

Based on your operating system, use the following screen readers with these recommended browsers:

Operating system  | Screen reader  | Browser   
---|---|---  
Microsoft Windows  | NVDA or JAWS  | Mozilla Firefox  Chrome Browser   
macOS  | VoiceOver  | Chrome Browser   
Chrome OS  | ChromeVox  | Chrome Browser   
iOS  | VoiceOver  | N/A (mobile app)   
Android  | TalkBack  | N/A (mobile app)   
  
## Use accessibility features

To use assistive technology with GDC, see the following resources:

  * [Enabling accessibility features for the gdcloud CLI](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-accessibility)



## Request a GDC accessibility report

A Voluntary Product Accessibility Template (VPAT) explains how information and communication technology meet the _U.S. Section 508_ and _EN 301 549_ standards for accessibility.

View the [VPAT](https://docs.cloud.google.com/static/distributed-cloud/hosted/docs/latest/gdcag/resources/vpat/gdch_vpat_12_2023.pdf) for Google Distributed Cloud air-gapped.

For more information about GDC Voluntary Product Accessibility Templates, contact [gdch-a11y@google.com](mailto:gdch-a11y@google.com).

## Get support

For general accessibility help and information, see the following:
