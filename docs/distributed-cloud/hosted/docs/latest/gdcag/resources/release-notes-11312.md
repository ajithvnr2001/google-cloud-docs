## August 19, 2025

* * *

Announcement

Google Distributed Cloud (GDC) air-gapped 1.13.12 is available.  
See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Distributed Cloud. 

* * *

Security

Updated the Ubuntu OS image version to 20250604 to apply the latest security patches and important updates. 

* * *

Issue

The following issues are identified: 

**Object storage:**

  * StorageGRID load balancer endpoint certificate expired. 



**Operating System:**

  * Baremetal nodes fail to boot from latest OS image due to secure boot not recognizing the OS signature .
