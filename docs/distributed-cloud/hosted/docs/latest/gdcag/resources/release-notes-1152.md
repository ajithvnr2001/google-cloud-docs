## January 26, 2026

* * *

Announcement

Google Distributed Cloud (GDC) air-gapped 1.15.2 is available.  
See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Distributed Cloud.

Issue

The following issues are identified: 

**Database Service** :

  * Cloning an AlloyDB Omni database cluster might fail. 



**Monitoring**

  * Metric data displays a temporary step-change value dip and refresh instability (toggling). 



**Resource Manager**

  * Global org creation in `ACCREDITED` environments default to V1 org. 



* * *

Change

The following changes are identified: 

**Version updates** :

  * The Google Distributed Cloud for bare metal version is updated to 1.30.1500-gke.40 to apply the latest security patches and important updates.
