## January 08, 2024 [GDC 1.9.9]

* * *

Announcement

Google Distributed Cloud air-gapped 1.9.9 is now released.

See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Google Distributed Cloud air-gapped.

* * *

Fixed

Google Distributed Cloud air-gapped 1.9.9 fixes an issue where API server access on the data plane network is blocked.

* * *

Fixed

Google Distributed Cloud air-gapped 1.9.9 fixes an issue where system cluster does not become ready in time when creating an Oracle database.

* * *

Issue

**VM Backup and Restore** :

  * Role-based access control (RBAC) and schema settings in the VM manager is stopping users from starting VM backup and restore processes. 



* * *

Issue

**Hardware security module (HSM)** : 

  * A server reports that an HSM tenant is unhealthy. 



* * *

Issue

**Node and operating system** : 

  * The `NodeUpgradeTask` might have the `failed to monitor failover registry recreation: failed to monitor job: job not complete` condition that blocks the completion of the task. 



* * *

Issue

**Google Distributed Cloud** : 

  * Organization creation might get stuck because the control plane node pool doesn't become ready in time. 



* * *

Issue

**Monitoring** : 

  * Alerts in organization system clusters don't reach the ticketing system.
