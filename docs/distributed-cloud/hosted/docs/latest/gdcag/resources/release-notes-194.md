## June 16, 2023 [GDC 1.9.4]

* * *

Announcement

Google Distributed Cloud air-gapped 1.9.4 is now released.

See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Google Distributed Cloud air-gapped.

* * *

Change

In the Google Distributed Cloud air-gapped 1.9.4 Addon Manager (ADD) component, the Google Distributed Cloud version is updated to 1.14.5-gke.1 to apply the latest security patches and important updates. 

See [Google Distributed Cloud 1.14.5 release notes](https://cloud.google.com/anthos/clusters/docs/bare-metal/1.14/release-notes-ver#release_1145) for details.

* * *
