## NAME

gdcloud config configurations - Manage the set of Google Distributed Cloud Hosted CLI named configurations.

## SYNOPSIS
    
    
    gdcloud config configurations COMMAND [flags]
    

## DESCRIPTION

Manage the set of Google Distributed Cloud Hosted CLI named configurations. You can activate, create, delete, describe, rename, and list named configurations.

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.

### COMMANDS

`COMMAND` is one of the following:
    
    
    activate
        Activate an existing gdcloud CLI named configuration.
    create
        Create a new gdcloud CLI named configuration.
    delete
        Delete one or more gdcloud CLI named configurations.
    describe
        Describe a gdcloud CLI named configuration.
    list
        List all existing Google Distributed Cloud Hosted CLI named configurations.
    rename
        Rename a gdcloud CLI named configuration.
