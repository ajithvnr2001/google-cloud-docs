## NAME

gdcloud logging siem-org-forwarders - Manage log export to an external organization Security Information and Event Management (SIEM) system.

## SYNOPSIS
    
    
    gdcloud logging siem-org-forwarders COMMAND [flags]
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.

### COMMANDS

`COMMAND` is one of the following:
    
    
    create
        Create an organization Security Information and Event Management (SIEM) log export.
    delete
        Delete an organization Security Information and Event Management (SIEM) log export.
    describe
        Display information for the organization Security Information and Event Management (SIEM) log export.
    list
        List all the organization Security Information and Event Management (SIEM) log exports.
    update
        Update an organization Security Information and Event Management (SIEM) log export.
