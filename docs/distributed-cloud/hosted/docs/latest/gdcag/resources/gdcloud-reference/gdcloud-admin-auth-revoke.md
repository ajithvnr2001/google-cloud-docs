## NAME

gdcloud admin auth revoke - Admin initiated user session revocation

## SYNOPSIS
    
    
    gdcloud admin auth revoke [flags]
    

### REQUIRED FLAGS
    
    
          --accounts string   User account to be revoked

These flags are available to all commands: `--configuration`, `--format`, `--help`, `--project`, `--quiet`.
