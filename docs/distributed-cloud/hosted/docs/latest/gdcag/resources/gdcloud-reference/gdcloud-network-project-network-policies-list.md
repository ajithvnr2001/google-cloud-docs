## NAME

gdcloud network project-network-policies list - List project network policies.

## SYNOPSIS
    
    
    gdcloud network project-network-policies list [flags]
    

### EXAMPLES
    
    
    To list all project network policies in the current project, run:
        gdcloud network project-network-policies list
    
    To list all project network policies in project 'project-1', run:
        gdcloud network project-network-policies list --project=project-1
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--configuration`, `--format`, `--help`, `--project`, `--quiet`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.
