## NAME

gdcloud compute instances - Read and manipulate GDC air-gapped virtual machine instances.

## SYNOPSIS
    
    
    gdcloud compute instances COMMAND [flags]
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.

### COMMANDS

`COMMAND` is one of the following:
    
    
    add-metadata
        Add metadata for a virtual machine instance.
    create
        Create virtual machine instances.
    delete
        Delete virtual machine instances.
    describe
        Describe a virtual machine instance.
    list
        List virtual machine instances.
    remove-metadata
        Remove metadata for a virtual machine instance.
    reset
        Reset a virtual machine instance.
    start
        Start a stopped virtual machine instance.
    stop
        Stop a virtual machine instance.
