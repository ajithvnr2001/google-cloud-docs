## NAME

gdcloud harbor backup-repositories - Operate GDC Managed Harbor Service (MHS) backup repositories in an air-gapped configuration.

## SYNOPSIS
    
    
    gdcloud harbor backup-repositories COMMAND [flags]
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.

### COMMANDS

`COMMAND` is one of the following:
    
    
    create
        Create a new harbor backup repository.
    delete
        Delete a harbor backup repository.
    describe
        Describe a harbor backup repository.
    list
        List harbor backup repositories.
    update
        Update a harbor backup repository.
