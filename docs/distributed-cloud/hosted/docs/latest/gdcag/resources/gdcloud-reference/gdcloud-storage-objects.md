#  gdcloud storage objects Stay organized with collections  Save and categorize content based on your preferences. 

## NAME

gdcloud storage objects - Manage object storage objects.

## SYNOPSIS
    
    
    gdcloud storage objects COMMAND [flags]
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.

### COMMANDS

`COMMAND` is one of the following:
    
    
    describe
        Describe a storage object.
    list
        List storage objects.
    update
        Update object storage objects.
