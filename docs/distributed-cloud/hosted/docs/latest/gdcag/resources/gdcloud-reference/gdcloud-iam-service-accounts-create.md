## NAME

gdcloud iam service-accounts create - Create a new service account for a project.

## SYNOPSIS
    
    
    gdcloud iam service-accounts create SERVICE_ACCOUNT_NAME [flags]
    

## DESCRIPTION

Create a new service account for a project. A service account name must be provided.

### EXAMPLES
    
    
      To create a service account of name "psa-test" for project "iam-test", run:
    
        gdcloud iam service-accounts create psa-test --project=iam-test
