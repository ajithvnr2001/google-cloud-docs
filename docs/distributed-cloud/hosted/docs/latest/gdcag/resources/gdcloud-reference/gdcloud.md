## NAME

gdcloud - CLI for Google Distributed Cloud (GDC).

**Note:** Some command groups, commands, and flags might not be available as they may not be accredited for use in your deployment. You can access them when they are approved. For more information, see https://cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/feature-stages.

## SYNOPSIS
    
    
    gdcloud GROUP | COMMAND [flags]
    

### GDCLOUD WIDE FLAGS

These flags are available to all commands: `--help`.

For more information, see the [gdcloud CLI reference overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/gdcloud-reference/gdcloud) page.

### GROUPS

`GROUP` is one of the following:
    
    
    admin
        Command group to perform administrative tasks
    artifacts
        Create and manage artifacts in a GDC air-gapped environment.
    auth
        Configure authentication settings.
    backup
        Create and manage backup resources.
    billing
        Manage cloud billing within GDC universe.
    clusters
        Manage Kubernetes clusters in a GDC air-gapped zone.
    components
        Manage gdcloud CLI components.
    compute
        Read and manipulate GDC air-gapped compute resources.
    config
        View and edit gdcloud CLI properties.
    container
        Deploy and manage user clusters and containers in a GDC air-gapped instance.
    database
        Command group for managing db resources
    disaster-recovery
        Manage Disaster Recovery (DR) configurations.
    dns
        Manage DNS operations
    harbor
        Operate GDC Managed Harbor Service (MHS) resources, such as instances and Harbor projects, in an air-gapped configuration.
    iam
        Manage service identities, identity providers, keys and custom roles.
    kms
        Manage and use cryptographic keys with the Key Management Service (KMS).
    logging
        Manage cloud logging resources within GDC universe.
    maintenance
        Manage maintenance resources.
    marketplace
        Manage Marketplace services.
    network
        Create and manage all GDC network resources.
    observability
        Manage the observability stack.
    organizations
        Create and manage GDC air-gapped organizations.
    projects
        Create and manage GDC air-gapped projects.
    resource-support
        View resource support information in a GDC air-gapped deployment.
    storage
        Create and manage GDC air-gapped storage resources, such as buckets and objects.
    topic
        View gdcloud CLI supplementary help.
    zones
        Interact with the zones in a GDC air-gapped deployment.
    

### COMMANDS

`COMMAND` is one of the following:
    
    
    completion
        Generate autocompletion code for Bash, Zsh, or Fish shells.
    init
        Initialize the default gdcloud CLI configuration file.
    version
        Print version information for the gdcloud CLI.
