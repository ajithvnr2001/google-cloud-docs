## NAME

gdcloud harbor backup-repositories list - List harbor backup repositories.

## SYNOPSIS
    
    
    gdcloud harbor backup-repositories list [flags]
    

### EXAMPLES
    
    
    To list all harbor backup repositories, run:
    
      gdcloud harbor backup-repositories list
    
    To list harbor backup repositories in the S3 bucket region 'us-central1', run:
    
      gdcloud harbor backup-repositories list --bucket-region=us-central1
    

### OPTIONAL FLAGS
    
    
          --bucket-region string   Region of the S3 bucket.
