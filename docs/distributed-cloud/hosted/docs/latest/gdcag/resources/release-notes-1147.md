## August 22, 2025

* * *

Announcement

Google Distributed Cloud (GDC) air-gapped 1.14.7 is available.  
See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Distributed Cloud. 

* * *

Issue

The following issues are identified: 

**Backup and restore**

  * User clusters get stuck in a deleting state. 



**Storage:**

  * Buckets created with the `gdcloud config set zone` command fail to delete. 



**Ticketing system** :

  * An RBAC error from customer networks might deny access to ServiceNow. 



* * *

Fixed

The following issues are fixed: 

**Multi-tenancy** :

  * GDC console does not indicate node pool creation failures 



**Upgrade**

  * The org admin node upgrade is stuck. 

  * The add-on upgrade is stuck. 

  * The support report fails.
