## January 27, 2023 [GDC 1.9.0]

* * *

Announcement

Google Distributed Cloud air-gapped 1.9.0 is now available.

See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Google Distributed Cloud air-gapped.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue where role-based access control (RBAC) and schema settings in the VM manager is stopping users from starting VM backup and restore processes. 

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue where remote server management software is occasionally unable to retrieve the key from HSM.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue where using the `standard-block` storage class might prevent virtual machines (VMs) from starting or restarting.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue where a server is stuck the `available` state and its encryption configuration job keeps failing due to an SSH key error.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue in the UI that lets you select an incompatible coupling of GPU to VM type.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue where VMs with memory greater than 32 GB require a memory override due to an incorrect QEMU overhead calculation.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue where upgrading an organization to 1.10.x from 1.9.1 or earlier might cause `kube-apiserver` pods to not come up during an upgrade.

* * *

Issue

Google Distributed Cloud air-gapped 1.9.0 has a known issue where alerts in organization system clusters don't reach the ticketing system.
