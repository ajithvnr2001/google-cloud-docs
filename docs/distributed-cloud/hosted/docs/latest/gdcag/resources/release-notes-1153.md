## March 19, 2026

* * *

Announcement

Google Distributed Cloud (GDC) air-gapped 1.15.3 is available.  
See the [product overview](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/overview) to learn about the features of Distributed Cloud.  
  
Before upgrading to version 1.15.3, read the specific instructions for [applying 1.15.3 hotfixes](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/hotfix/1153#instructions).

* * *

Issue

The following issues are identified: 

**Cluster management**

  * Cluster deletion might fail to complete due to dangling finalizer. 



**Logging**

  * Loki write instances become unstable and unhealthy in Root and `gdchservices` org. 



**Networking**

  * Enabling Cloud NAT on a VM prevents SSH connections using the GDC console UI. 

  * Preflight validation might report false connection failures between the management switches and the firewall management ports. 




* * *

Fixed

The following issues are fixed: 

**Inventory** :

  * The `system assets create` command doesn't accept correct ports for firewall devices. 



**Key management system** :

  * KMS servers might experience performance issues and `OOMKilling` under heavy workloads. 



**Network Time Protocol (NTP)**

  * The SyncServer credential rotation process NTP-P0004 contains errors in encoding and shell syntax. 



**Resource manager** :

  * A v1 organization uses incompatible IP address plans and can't be upgraded to a v2 organization. 



**Ticketing system** :

  * ServiceNow can't reach the customer OIDC IDP. 



* * *

Change

The following changes are identified: 

**Version updates** :

  * The Google Distributed Cloud for bare metal version is updated to 1.30.1700-gke.32 to apply the latest security patches and important updates.
