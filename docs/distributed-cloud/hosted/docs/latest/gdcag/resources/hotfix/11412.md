## Hotfix 1

Fixed

The 1.14.12-gdch.686-1 hotfix is available. This hotfix fixes the following issues: 

**Billing** :

  * Introduces a new billing SKU required for Gemini 2.5 Flash.



**Monitoring** :

  * Introduces a new billing SKU related to metering required for Gemini 2.5 Flash.



**Operating system** :

  * Fixes an upgrade issue where the Linux Unified Key Setup (LUKS) passphrase used to unlock the LUKS-encrypted partition containing the operating system (OS) is lost during a bare metal node upgrade. This issue causes nodes with LUKS enabled to not reboot, and must be reprovisioned manually.
