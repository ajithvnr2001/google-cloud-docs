#  Google Distributed Cloud air-gapped 1.15.2 hotfixes Stay organized with collections  Save and categorize content based on your preferences. 

**Important:** Hotfix 1 and hotfix 2 were released and later combined into hotfix 3. Therefore, hotfix 3 is the first hotfix publicly available for upgrades in GDC 1.15.2.

## Hotfix 4

Fixed

The 1.15.2-gdch.8771-4 hotfix is available. This hotfix fixes the following issue: 

**Virtual machines**

  * Added [Secure Boot certificate renewal](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vms/manage-vms/secure-vms/secure-boot-cert-update) support for VMs with expiring certificates.



## Hotfix 3

Fixed

The 1.15.2-gdch.8771-3 hotfix is available. This hotfix fixes the following issues: 

**Cloud Service Mesh** :

  * The control plane for Cloud Service Mesh is reporting reconciliation errors in all zones.



**Networking** :

  * There are north-south network traffic issues caused by an upgrade.

  * A project network policy is marked `Unready` because it can't propagate to a deleted shadow project.

  * Updated the reconciler to handle the deletion of propagated project network policies during partial syncs with services.

  * There are permissions issues during the bootstrap request process.




**Storage** :

  * Improved system reliability by consolidating storage error data (`trident_errors_total`), reducing the risk of memory-related crashes in the monitoring stack.
