## Hotfix 1

Fixed

The 1.14.9-gdch.312-1 hotfix is available. This hotfix fixes the following issues: 

**AI central services** :

  * Fixes a critical Gemini authentication failure when using group role-based access control (RBAC) to access Gemini.



**Key and secret management** :

  * Fixes an authentication failure when using group RBAC to access the Key Management Service (KMS).
