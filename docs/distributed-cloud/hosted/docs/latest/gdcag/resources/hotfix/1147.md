## Hotfix 2

Fixed

The 1.14.7-gdch.278-2 hotfix is available. This hotfix fixes the following issues: 

**File storage** :

  * Fixes an issue where ONTAP might upgrade prematurely, such as the file storage upgrade starting after the `load-oci` step, and block the upgrade.



**Networking** :

  * Fixes the CRD conflicts between physical networking and DNS, to avoid a loss of north-south traffic.



## Hotfix 1

Fixed

The 1.14.7-gdch.278-1 hotfix is available. This hotfix fixes the following issue: 

**SIEM** :

  * Fixes issues with Splunk deployment (for partner operated mode) introduced in 1.14.7.
