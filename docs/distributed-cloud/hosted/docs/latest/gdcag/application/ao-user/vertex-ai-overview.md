This page provides an overview of Vertex AI on Google Distributed Cloud (GDC) air-gapped, covering the available features and key benefits to help you understand how its machine learning features can innovate your air-gapped applications.

This page is for application developers working within application operator groups who are looking to incorporate AI features into their air-gapped applications and workflows. For more information, see [Audiences for GDC air-gapped documentation](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/resources/audiences).

## Vertex AI for secure on-premise environments

Vertex AI on Distributed Cloud brings the power of a machine learning platform and generative AI models to your secure on-premises environments. This solution is designed for organizations with strict data sovereignty, security, and privacy requirements. Vertex AI services let you innovate with AI features while maintaining complete control in the same air-gapped infrastructure.

## Key features

Vertex AI on Distributed Cloud offers you the following features:

  * **Air-gapped deployment** : Run Vertex AI services entirely within your data center, ensuring data sovereignty and compliance.
  * **Familiar Vertex AI experience** : Take advantage of the same tools, APIs, and models from Vertex AI on Google Cloud, simplifying development and management.
  * **Pre-built models and algorithms** : Access a range of state-of-the-art models for common machine learning and AI tasks, accelerating your time to value.
  * **Custom model training** : Train your AI and machine learning models using your own data, tailoring solutions to your specific needs.
  * **MLOps capabilities** : Streamline your machine learning workflows with tools for model deployment, monitoring, and management.



## Available services

Vertex AI on Distributed Cloud offers the following services:

  * [**Generative AI**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/genai/genai-overview): Build applications that are powered by state-of-the-art generative AI models to create data.
  * [**Online Prediction**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-online-predictions): (_Preview_) Deploy and make requests to your prediction models.
  * [**Optical Character Recognition (OCR)**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-ocr): Extract text from images and documents.
  * [**Speech-to-Text**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-stt): Convert spoken language into written text.
  * [**Vertex AI Translation**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-translation): Translate text between multiple languages.
  * [**Vertex AI Workbench**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-workbench-intro): Create a managed JupyterLab notebook environment for machine learning development.



## Benefits

Vertex AI on Distributed Cloud offers the following benefits:

  * **Seamless development experience** : Use the same tools, APIs, models, and workflows of Vertex AI on Google Cloud, making development and management intuitive and efficient.
  * **Enhanced security and privacy** : Maintain complete control over your data and comply with regulatory requirements.
  * **Increased agility** : Develop and deploy AI and machine learning models in your air-gapped environment.
  * **Accelerated time to value** : Utilize pre-trained models for common machine learning tasks, or train your custom models using your unique datasets.
  * **Streamlined MLOps** : Benefit from robust machine learning operation capabilities for seamless model deployment, monitoring, and management within your air-gapped environment.



## Get started

To get started with Vertex AI on Distributed Cloud, do the following:

  * [Learn about essential roles and permissions for available services](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-ao-permissions).
  * [Set up a project for your AI and machine learning workflows](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-set-up-project).
  * [Provision GPUs and enable the Vertex AI services](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-enable-pre-trained-apis).
  * [Install the Vertex AI client libraries](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-install-libraries).



Then, you can start building and deploying your AI and machine learning models.
