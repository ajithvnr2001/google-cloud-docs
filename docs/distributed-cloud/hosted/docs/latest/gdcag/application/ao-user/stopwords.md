#  Identify glossary stopwords Stay organized with collections  Save and categorize content based on your preferences. 

This page contains the words that Vertex AI Translation ignores when you [use a glossary](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/vertex-ai-glossary) for translation in a particular language. Ignored words are called _stopwords_.

Vertex AI Translation ignores a glossary entry only if the entry exactly matches a stopword. For example, the service ignores the `when` glossary entry but not the `when and what` entry.
