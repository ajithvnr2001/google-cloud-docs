Google Distributed Cloud (GDC) air-gapped provides a view of usage and costs for running your GDC installation using monitoring dashboards.

## Billing reports

The GDC console lets you view the resource usage for your project through the **Billing reports** page.

The **Billing reports** page provides the links to view your resource metrics through the following monitoring dashboards:

  * [**Storage allocation**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/billing/review-resource-consumption)
  * [**Compute allocation**](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdcag/application/ao-user/billing/review-resource-consumption)



The GDC console defaults the **Billing reports** page at the project level. To access the **Billing reports** page, do the following:

  1. Sign in to the GDC console.
  2. In the navigation menu, select **Billing > Reports**. The **Billing reports** page opens.



To select a new project, do the following:

  1. In the menu bar, click **Select Project**.
  2. Select the name of the project you want to view.
  3. Click **Open**.
