#  Monitor and log metrics Stay organized with collections  Save and categorize content based on your preferences. 

GDC Sandbox provides you the following Google Distributed Cloud air-gapped monitoring and logging features:

  * Metrics and log collection
  * Alert management
  * Data visualization with dashboards



To collect metrics from your project, see [Collect metrics](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/collect-metrics). For metric query and data visualization through dashboards, refer to [Query and view metrics](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/query-and-view-metrics).

To collect logs from your project, see [Collect operational logs](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/collect-logs). For log query and data visualization through dashboards, refer to [Query and view logs](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/query-and-view-logs).

To create and manage alerts, see [Create alert rules](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/application/ao-user/create-alert-rules).
