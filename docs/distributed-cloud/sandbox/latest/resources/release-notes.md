## GDC Sandbox 1.2.0.

  * This release of GDC Sandbox is built upon Google Distributed Cloud air-gapped version 1.14.6. For comprehensive release notes regarding the overall product, refer to the [Google Distributed Cloud air-gapped 1.14.6 release notes](https://docs.cloud.google.com/distributed-cloud/hosted/docs/latest/gdch/resources/release-notes-1146).

  * A new AI Optimized SKU `GDCSandboxAIOptimizedH100` has been added, which includes H100 GPUs. The original AI Optimized SKU `GDCSandboxAIOptimized`, which included A100 GPUs, has been deprecated.
