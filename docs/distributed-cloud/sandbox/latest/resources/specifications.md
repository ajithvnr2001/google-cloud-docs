GDC Sandbox is available in two SKUs: 

  * **Basic** : a complete Google Distributed Cloud air-gapped experience in a virtual environment
  * **AI Optimized** : adds GPUs for AI workloads

Resources | Basic | AI Optimized  
---|---|---  
CPU (Clusters) | 60 vCPUs | 60 vCPUs  
Memory (Clusters) | 192 GB | 192 GB  
CPU (VMs + Services) | 64 vCPUs | 64 vCPUs  
Memory (VMs + Services) | 240 GB | 240 GB  
Block Storage | 2 TB | 2 TB  
Object Storage | 20 TB | 20 TB  
GPUs | NA | 8 GPUs
