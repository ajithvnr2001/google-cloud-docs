#  Chrome Enterprise Premium and Tanium integration shutdown Stay organized with collections  Save and categorize content based on your preferences. 

On January 3, 2024, Chrome Enterprise Premium and Tanium integration was officially shut down because Tanium has deprecated the APIs on which this integration was built.

This shutdown has no effect on customers because there were no customers using this integration in their production environment.
