`↳ specified_amount` |  `[Google\Type\Money](https://docs.cloud.google.com/php/docs/reference/common-protos/latest/Type.Money.html)`   
A specified amount to use as the budget. `currency_code` is optional. If specified when creating a budget, it must match the currency of the billing account. If specified when updating a budget, it must match the currency_code of the existing budget. The `currency_code` is provided on output.  
`↳ last_period_amount` |  `[LastPeriodAmount](https://docs.cloud.google.com/php/docs/reference/cloud-billing-budgets/latest/V1.LastPeriodAmount)`   
Use the last period's actual spend as the budget for the present period. LastPeriodAmount can only be set when the budget's time period is a [Filter.calendar_period](https://docs.cloud.google.com/php/docs/reference/cloud-billing-budgets/latest/V1.Filter#_Google_Cloud_Billing_Budgets_V1_Filter__getCalendarPeriod__). It cannot be set in combination with [Filter.custom_period](https://docs.cloud.google.com/php/docs/reference/cloud-billing-budgets/latest/V1.Filter#_Google_Cloud_Billing_Budgets_V1_Filter__getCustomPeriod__).
