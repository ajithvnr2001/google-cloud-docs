Reference documentation and code samples for the Google Cloud Sql Admin V1 Client class SqlRegionsServiceClient.

Service Description: Service that exposes Cloud SQL region information. This service is only used internally and does not follow the same patterns as the other v1 RPCs.

This class provides the ability to make remote calls to the backing service through method calls that map to API methods.
