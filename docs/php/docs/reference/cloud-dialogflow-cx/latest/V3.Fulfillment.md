Reference documentation and code samples for the Google Cloud Dialogflow Cx V3 Client class Fulfillment.

A fulfillment can do one or more of the following actions at the same time:

  * Generate rich message responses.


  * Set parameter values.
    * Call the webhook. Fulfillments can be called at various stages in the [Page](https://docs.cloud.google.com/php/docs/reference/cloud-dialogflow-cx/latest/V3.Page) or [Form](https://docs.cloud.google.com/php/docs/reference/cloud-dialogflow-cx/latest/V3.Form) lifecycle. For example, when a [DetectIntentRequest](https://docs.cloud.google.com/php/docs/reference/cloud-dialogflow-cx/latest/V3.DetectIntentRequest) drives a session to enter a new page, the page's entry fulfillment can add a static response to the [QueryResult](https://docs.cloud.google.com/php/docs/reference/cloud-dialogflow-cx/latest/V3.QueryResult) in the returning [DetectIntentResponse](https://docs.cloud.google.com/php/docs/reference/cloud-dialogflow-cx/latest/V3.DetectIntentResponse), call the webhook (for example, to load user data from a database), or both.
