`↳ rating_histogram` |  `int[]`   
List of rating counts per rating value (index = rating - 1). The list is empty if there is no rating. If the list is non-empty, its size is always 5. Otherwise, an INVALID_ARGUMENT error is returned. It means that the [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product) got 41 ratings with 1 star, 14 ratings with 2 star, and so on.
