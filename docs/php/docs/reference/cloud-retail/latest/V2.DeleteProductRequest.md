### getName

Required. Full resource name of [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product), such as `projects/*/locations/global/catalogs/default_catalog/branches/default_branch/products/some_product_id`.

If the caller does not have permission to delete the [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product), regardless of whether or not it exists, a PERMISSION_DENIED error is returned. If the [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product) to delete does not exist, a NOT_FOUND error is returned. The [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product) to delete can neither be a [Product.Type.COLLECTION](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product.Type#_Google_Cloud_Retail_V2_Product_Type__COLLECTION) [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product) member nor a [Product.Type.PRIMARY](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product.Type#_Google_Cloud_Retail_V2_Product_Type__PRIMARY) [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product) with more than one [variants](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product.Type#_Google_Cloud_Retail_V2_Product_Type__VARIANT). Otherwise, an INVALID_ARGUMENT error is returned. All inventory information for the named [Product](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Product) will be deleted.
