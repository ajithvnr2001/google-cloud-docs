### getPriceRerankingLevel

How much price ranking we want in serving results.

Price reranking causes product items with a similar recommendation probability to be ordered by price, with the highest-priced items first. This setting could result in a decrease in click-through and conversion rates. Allowed values are:

  * `no-price-reranking`
  * `low-price-reranking`
  * `medium-price-reranking`
  * `high-price-reranking` If not specified, we choose default based on model type. Default value: `no-price-reranking`. Can only be set if [solution_types](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.ServingConfig#_Google_Cloud_Retail_V2_ServingConfig__getSolutionTypes__) is [SOLUTION_TYPE_RECOMMENDATION](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.SolutionType#_Google_Cloud_Retail_V2_SolutionType__SOLUTION_TYPE_RECOMMENDATION).

### getFacetControlIds

Facet specifications for faceted search. If empty, no facets are returned.

The ids refer to the ids of [Control](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.Control) resources with only the Facet control set. ### getBoostControlIds

Condition boost specifications. If a product matches multiple conditions in the specifications, boost scores from these specifications are all applied and combined in a non-linear way. Maximum number of specifications is 100.

Notice that if both [ServingConfig.boost_control_ids](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.ServingConfig#_Google_Cloud_Retail_V2_ServingConfig__getBoostControlIds__) and [SearchRequest.boost_spec](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.SearchRequest#_Google_Cloud_Retail_V2_SearchRequest__getBoostSpec__) are set, the boost conditions from both places are evaluated. If a search request matches multiple boost conditions, the final boost score is equal to the sum of the boost scores from all matched boost conditions. Can only be set if [solution_types](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.ServingConfig#_Google_Cloud_Retail_V2_ServingConfig__getSolutionTypes__) is [SOLUTION_TYPE_SEARCH](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.SolutionType#_Google_Cloud_Retail_V2_SolutionType__SOLUTION_TYPE_SEARCH).

### getEnableCategoryFilterLevel

Whether to add additional category filters on the `similar-items` model.

If not specified, we enable it by default. Allowed values are:

  * `no-category-match`: No additional filtering of original results from the model and the customer's filters.
  * `relaxed-category-match`: Only keep results with categories that match at least one item categories in the PredictRequests's context item.
    * If customer also sends filters in the PredictRequest, then the results will satisfy both conditions (user given and category match). Can only be set if [solution_types](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.ServingConfig#_Google_Cloud_Retail_V2_ServingConfig__getSolutionTypes__) is [SOLUTION_TYPE_RECOMMENDATION](https://docs.cloud.google.com/php/docs/reference/cloud-retail/latest/V2.SolutionType#_Google_Cloud_Retail_V2_SolutionType__SOLUTION_TYPE_RECOMMENDATION).
