### bidiRunSession

Establishes a bidirectional streaming connection with the CES agent.

The agent processes continuous multimodal inputs (e.g., text, audio) and generates real-time multimodal output streams.

\--- Client Request Stream --- The client streams requests in the following order:

  1. Initialization: The first message must contain [SessionConfig](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionClientMessage#_Google_Cloud_Ces_V1_BidiSessionClientMessage__getConfig__). For audio sessions, this should also include [InputAudioConfig](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.SessionConfig#_Google_Cloud_Ces_V1_SessionConfig__getInputAudioConfig__) and [OutputAudioConfig](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.SessionConfig#_Google_Cloud_Ces_V1_SessionConfig__getOutputAudioConfig__) to define audio processing and synthesis parameters.

  2. Interaction: Subsequent messages stream [SessionInput](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionClientMessage#_Google_Cloud_Ces_V1_BidiSessionClientMessage__getRealtimeInput__) containing real-time user input data.

  3. Termination: The client should half-close the stream when there is no more user input. It should also half-close upon receiving [EndSession](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionServerMessage#_Google_Cloud_Ces_V1_BidiSessionServerMessage__getEndSession__) or [GoAway](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionServerMessage#_Google_Cloud_Ces_V1_BidiSessionServerMessage__getGoAway__) from the agent.




\--- Server Response Stream --- For each interaction turn, the agent streams messages in the following sequence:

  1. Speech Recognition (First N messages): Contains [RecognitionResult](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionServerMessage#_Google_Cloud_Ces_V1_BidiSessionServerMessage__getRecognitionResult__) representing the concatenated user speech segments captured so far. This is only populated for audio sessions.

  2. Response (Next M messages): Contains [SessionOutput](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionServerMessage#_Google_Cloud_Ces_V1_BidiSessionServerMessage__getSessionOutput__) delivering the agent's response in various modalities (e.g., text, audio).

  3. Turn Completion (Final message of the turn): Contains [SessionOutput](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionServerMessage#_Google_Cloud_Ces_V1_BidiSessionServerMessage__getSessionOutput__) with [turn_completed](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.SessionOutput#_Google_Cloud_Ces_V1_SessionOutput__getTurnCompleted__) set to true. This signals the end of the current turn and includes [DiagnosticInfo](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.SessionOutput#_Google_Cloud_Ces_V1_SessionOutput__getDiagnosticInfo__) with execution details.




\--- Audio Best Practices ---

  1. Streaming: Stream [audio data](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.SessionInput#_Google_Cloud_Ces_V1_SessionInput__getAudio__) **CONTINUOUSLY** , even during silence. Recommended chunk size: 40-120ms (balances latency vs. efficiency).

  2. Playback & Interruption: Play [audio responses](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.SessionOutput#_Google_Cloud_Ces_V1_SessionOutput__getAudio__) upon receipt. Stop playback immediately if an [InterruptionSignal](https://docs.cloud.google.com/php/docs/reference/cloud-ces/latest/V1.BidiSessionServerMessage#_Google_Cloud_Ces_V1_BidiSessionServerMessage__getInterruptionSignal__) is received (e.g., user barge-in or new agent response).

### static::parseName

Parses a formatted name string and returns an associative array of the components in the name.

The following name formats are supported: Template: Pattern

  * agent: projects/{project}/locations/{location}/apps/{app}/agents/{agent}
  * session: projects/{project}/locations/{location}/apps/{app}/sessions/{session}
  * tool: projects/{project}/locations/{location}/apps/{app}/tools/{tool}
  * toolset: projects/{project}/locations/{location}/apps/{app}/toolsets/{toolset}



The optional $template argument can be supplied to specify a particular pattern, and must match one of the templates listed above. If no $template argument is provided, or if the $template argument does not match one of the templates listed, then parseName will check each of the supported templates, and return the first match.

**Parameters**  
---  
**Name** | **Description**  
`formattedName` |  `string`   
The formatted name string  
`template` |  `?string`   
Optional name of template to match  
**Returns**  
---  
**Type** | **Description**  
`array` | An associative array from name component IDs to component values.
