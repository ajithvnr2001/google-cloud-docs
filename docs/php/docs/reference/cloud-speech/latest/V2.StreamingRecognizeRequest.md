Reference documentation and code samples for the Cloud Speech V2 Client class StreamingRecognizeRequest.

Request message for the [StreamingRecognize](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.Client.SpeechClient#_Google_Cloud_Speech_V2_Client_SpeechClient__streamingRecognize__) method. Multiple [StreamingRecognizeRequest](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.StreamingRecognizeRequest) messages are sent in one call.

If the [Recognizer](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.Recognizer) referenced by [recognizer](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.StreamingRecognizeRequest#_Google_Cloud_Speech_V2_StreamingRecognizeRequest__getRecognizer__) contains a fully specified request configuration then the stream may only contain messages with only [audio](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.StreamingRecognizeRequest#_Google_Cloud_Speech_V2_StreamingRecognizeRequest__getAudio__) set. Otherwise the first message must contain a [recognizer](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.StreamingRecognizeRequest#_Google_Cloud_Speech_V2_StreamingRecognizeRequest__getRecognizer__) and a [streaming_config](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.StreamingRecognizeRequest#_Google_Cloud_Speech_V2_StreamingRecognizeRequest__getStreamingConfig__) message that together fully specify the request configuration and must not contain [audio](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.StreamingRecognizeRequest#_Google_Cloud_Speech_V2_StreamingRecognizeRequest__getAudio__). All subsequent messages must only have [audio](https://docs.cloud.google.com/php/docs/reference/cloud-speech/latest/V2.StreamingRecognizeRequest#_Google_Cloud_Speech_V2_StreamingRecognizeRequest__getAudio__) set.
