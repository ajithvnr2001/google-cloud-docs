Reference documentation and code samples for the Compute V1 Client class Address.

Represents an IP Address resource.

Google Compute Engine has two IP Address resources:

  * [Global (external and internal)](https://cloud.google.com/compute/docs/reference/rest/v1/globalAddresses)
  * [Regional (external and internal)](https://cloud.google.com/compute/docs/reference/rest/v1/addresses) For more information, see Reserving a static external IP address.
