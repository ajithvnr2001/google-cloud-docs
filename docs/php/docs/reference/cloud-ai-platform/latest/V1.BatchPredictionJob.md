Reference documentation and code samples for the Google Cloud Ai Platform V1 Client class BatchPredictionJob.

A job that uses a [Model](https://docs.cloud.google.com/php/docs/reference/cloud-ai-platform/latest/V1.BatchPredictionJob#_Google_Cloud_AIPlatform_V1_BatchPredictionJob__getModel__) to produce predictions on multiple [input instances](https://docs.cloud.google.com/php/docs/reference/cloud-ai-platform/latest/V1.BatchPredictionJob#_Google_Cloud_AIPlatform_V1_BatchPredictionJob__getInputConfig__). If predictions for significant portion of the instances fail, the job may finish without attempting predictions for all remaining instances.
