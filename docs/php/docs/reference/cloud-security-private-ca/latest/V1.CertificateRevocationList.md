Reference documentation and code samples for the Google Certificate Authority Service V1 Client class CertificateRevocationList.

A [CertificateRevocationList](https://docs.cloud.google.com/php/docs/reference/cloud-security-private-ca/latest/V1.CertificateRevocationList) corresponds to a signed X.509 certificate Revocation List (CRL). A CRL contains the serial numbers of certificates that should no longer be trusted.
