## Constants 

### ROUTING_PREFERENCE_UNSPECIFIED
    
    
    Value: 0

No routing preference specified. The server will use its default, which is TRAFFIC_UNAWARE.

Generated from protobuf enum `ROUTING_PREFERENCE_UNSPECIFIED = 0;`

### TRAFFIC_UNAWARE
    
    
    Value: 1

The calculation will not take traffic conditions into consideration.

The isochrone will be based on the road network and static travel times. This is suitable for planning purposes where traffic is not a factor.

Generated from protobuf enum `TRAFFIC_UNAWARE = 1;`

### TRAFFIC_AWARE
    
    
    Value: 2

The calculation will factor in live traffic conditions.

Generated from protobuf enum `TRAFFIC_AWARE = 2;`
