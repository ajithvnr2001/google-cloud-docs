Reference documentation and code samples for the Cloud Datastore V1 Client class TransactionOptions.

Options for beginning a new transaction.

Transactions can be created explicitly with calls to [Datastore.BeginTransaction](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.Client.DatastoreClient#_Google_Cloud_Datastore_V1_Client_DatastoreClient__beginTransaction__) or implicitly by setting [ReadOptions.new_transaction](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.ReadOptions#_Google_Cloud_Datastore_V1_ReadOptions__getNewTransaction__) in read requests.
