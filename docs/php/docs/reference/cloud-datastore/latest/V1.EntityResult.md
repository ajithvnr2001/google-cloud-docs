`↳ version` |  `int|string`   
The version of the entity, a strictly positive number that monotonically increases with changes to the entity. This field is set for [`FULL`](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.EntityResult.ResultType#_Google_Cloud_Datastore_V1_EntityResult_ResultType__FULL) entity results. For [missing](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.LookupResponse#_Google_Cloud_Datastore_V1_LookupResponse__getMissing__) entities in `LookupResponse`, this is the version of the snapshot that was used to look up the entity, and it is always set except for eventually consistent reads.  
`↳ create_time` |  `Google\Protobuf\Timestamp`   
The time at which the entity was created. This field is set for [`FULL`](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.EntityResult.ResultType#_Google_Cloud_Datastore_V1_EntityResult_ResultType__FULL) entity results. If this entity is missing, this field will not be set.  
`↳ update_time` |  `Google\Protobuf\Timestamp`   
The time at which the entity was last changed. This field is set for [`FULL`](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.EntityResult.ResultType#_Google_Cloud_Datastore_V1_EntityResult_ResultType__FULL) entity results. If this entity is missing, this field will not be set.  
`↳ cursor` |  `string`   
A cursor that points to the position after the result entity. Set only when the `EntityResult` is part of a `QueryResultBatch` message.
