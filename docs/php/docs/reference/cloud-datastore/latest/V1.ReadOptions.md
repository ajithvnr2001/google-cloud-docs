The non-transactional read consistency to use.  
`↳ transaction` |  `string`   
The identifier of the transaction in which to read. A transaction identifier is returned by a call to [Datastore.BeginTransaction](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.Client.DatastoreClient#_Google_Cloud_Datastore_V1_Client_DatastoreClient__beginTransaction__).

Options for beginning a new transaction for this request. The new transaction identifier will be returned in the corresponding response as either [LookupResponse.transaction](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.LookupResponse#_Google_Cloud_Datastore_V1_LookupResponse__getTransaction__) or [RunQueryResponse.transaction](https://docs.cloud.google.com/php/docs/reference/cloud-datastore/latest/V1.RunQueryResponse#_Google_Cloud_Datastore_V1_RunQueryResponse__getTransaction__).  
`↳ read_time` |  `Google\Protobuf\Timestamp`   
Reads entities as they were at the given time. This value is only supported for Cloud Firestore in Datastore mode. This must be a microsecond precision timestamp within the past one hour, or if Point-in-Time Recovery is enabled, can additionally be a whole minute timestamp within the past 7 days.
