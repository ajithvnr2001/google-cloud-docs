Reference documentation and code samples for the Cloud KMS V1 Client class ImportJob.

An [ImportJob](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob) can be used to create [CryptoKeys](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey) and [CryptoKeyVersions](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersion) using pre-existing key material, generated outside of Cloud KMS.

When an [ImportJob](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob) is created, Cloud KMS will generate a "wrapping key", which is a public/private key pair. You use the wrapping key to encrypt (also known as wrap) the pre-existing key material to protect it during the import process. The nature of the wrapping key depends on the choice of [import_method](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob#_Google_Cloud_Kms_V1_ImportJob__getImportMethod__). When the wrapping key generation is complete, the [state](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob#_Google_Cloud_Kms_V1_ImportJob__getState__) will be set to [ACTIVE](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob.ImportJobState#_Google_Cloud_Kms_V1_ImportJob_ImportJobState__ACTIVE) and the [public_key](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob#_Google_Cloud_Kms_V1_ImportJob__getPublicKey__) can be fetched. The fetched public key can then be used to wrap your pre-existing key material. Once the key material is wrapped, it can be imported into a new [CryptoKeyVersion](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersion) in an existing [CryptoKey](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey) by calling [ImportCryptoKeyVersion](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.Client.KeyManagementServiceClient#_Google_Cloud_Kms_V1_Client_KeyManagementServiceClient__importCryptoKeyVersion__). Multiple [CryptoKeyVersions](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersion) can be imported with a single [ImportJob](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob). Cloud KMS uses the private key portion of the wrapping key to unwrap the key material. Only Cloud KMS has access to the private key. An [ImportJob](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob) expires 3 days after it is created. Once expired, Cloud KMS will no longer be able to import or unwrap any key material that was wrapped with the [ImportJob](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ImportJob)'s public key. For more information, see [Importing a key](https://cloud.google.com/kms/docs/importing-a-key).
