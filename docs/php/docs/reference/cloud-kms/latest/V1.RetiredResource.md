Reference documentation and code samples for the Cloud KMS V1 Client class RetiredResource.

A RetiredResource resource represents the record of a deleted [CryptoKey](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey). Its purpose is to provide visibility into retained user data and to prevent reuse of these names for new [CryptoKeys](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey).
