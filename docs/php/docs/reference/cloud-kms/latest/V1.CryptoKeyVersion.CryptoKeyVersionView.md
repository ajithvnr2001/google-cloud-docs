Reference documentation and code samples for the Cloud KMS V1 Client class CryptoKeyVersionView.

A view for [CryptoKeyVersion](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersion)s.

Controls the level of detail returned for [CryptoKeyVersions](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersion) in [KeyManagementService.ListCryptoKeyVersions](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.Client.KeyManagementServiceClient#_Google_Cloud_Kms_V1_Client_KeyManagementServiceClient__listCryptoKeyVersions__) and [KeyManagementService.ListCryptoKeys](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.Client.KeyManagementServiceClient#_Google_Cloud_Kms_V1_Client_KeyManagementServiceClient__listCryptoKeys__).
