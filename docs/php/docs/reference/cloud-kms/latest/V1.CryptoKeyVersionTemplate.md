Reference documentation and code samples for the Cloud KMS V1 Client class CryptoKeyVersionTemplate.

A [CryptoKeyVersionTemplate](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersionTemplate) specifies the properties to use when creating a new [CryptoKeyVersion](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersion), either manually with [CreateCryptoKeyVersion](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.Client.KeyManagementServiceClient#_Google_Cloud_Kms_V1_Client_KeyManagementServiceClient__createCryptoKeyVersion__) or automatically as a result of auto-rotation.
