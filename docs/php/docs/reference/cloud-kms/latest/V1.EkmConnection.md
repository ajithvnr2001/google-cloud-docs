Reference documentation and code samples for the Cloud KMS V1 Client class EkmConnection.

An [EkmConnection](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.EkmConnection) represents an individual EKM connection. It can be used for creating [CryptoKeys](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey) and [CryptoKeyVersions](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKeyVersion) with a [ProtectionLevel](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ProtectionLevel) of [EXTERNAL_VPC](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.ProtectionLevel#_Google_Cloud_Kms_V1_ProtectionLevel__EXTERNAL_VPC), as well as performing cryptographic operations using keys created within the [EkmConnection](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.EkmConnection).
