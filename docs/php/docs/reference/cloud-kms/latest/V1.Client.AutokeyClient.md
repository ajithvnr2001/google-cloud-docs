Reference documentation and code samples for the Cloud KMS V1 Client class AutokeyClient.

Service Description: Provides interfaces for using [Cloud KMS Autokey](https://cloud.google.com/kms/help/autokey) to provision new [CryptoKeys](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey), ready for Customer Managed Encryption Key (CMEK) use, on-demand. To support certain client tooling, this feature is modeled around a [KeyHandle](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.KeyHandle) resource: creating a [KeyHandle](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.KeyHandle) in a resource project and given location triggers Cloud KMS Autokey to provision a [CryptoKey](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey) in the configured key project and the same location.

Prior to use in a given resource project, [UpdateAutokeyConfig](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.Client.AutokeyAdminClient#_Google_Cloud_Kms_V1_Client_AutokeyAdminClient__updateAutokeyConfig__) should have been called on an ancestor folder, setting the key project where Cloud KMS Autokey should create new [CryptoKeys](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.CryptoKey). See documentation for additional prerequisites. To check what key project, if any, is currently configured on a resource project's ancestor folder, see [ShowEffectiveAutokeyConfig](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.Client.AutokeyAdminClient#_Google_Cloud_Kms_V1_Client_AutokeyAdminClient__showEffectiveAutokeyConfig__).

This class provides the ability to make remote calls to the backing service through method calls that map to API methods.

Many parameters require resource names to be formatted in a particular way. To assist with these names, this class includes a format method for each type of name, and additionally a parseName method to extract the individual identifiers contained within formatted names that are returned by the API.

The optional $template argument can be supplied to specify a particular pattern, and must match one of the templates listed above.
