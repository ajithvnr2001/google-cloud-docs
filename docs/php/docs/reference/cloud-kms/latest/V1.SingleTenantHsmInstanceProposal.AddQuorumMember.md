Reference documentation and code samples for the Cloud KMS V1 Client class AddQuorumMember.

Add a quorum member to the [SingleTenantHsmInstance](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.SingleTenantHsmInstance).

This will increase the [total_approver_count](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.SingleTenantHsmInstance.QuorumAuth#_Google_Cloud_Kms_V1_SingleTenantHsmInstance_QuorumAuth__getTotalApproverCount__) by 1. The [SingleTenantHsmInstance](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.SingleTenantHsmInstance) must be in the [ACTIVE](https://docs.cloud.google.com/php/docs/reference/cloud-kms/latest/V1.SingleTenantHsmInstance.State#_Google_Cloud_Kms_V1_SingleTenantHsmInstance_State__ACTIVE) state to perform this operation.
