Reference documentation and code samples for the Cloud Spanner V1 Client class Mutation.

A modification to one or more Cloud Spanner rows. Mutations can be applied to a Cloud Spanner database by sending them in a [Commit](https://docs.cloud.google.com/php/docs/reference/cloud-spanner/latest/V1.Client.SpannerClient#_Google_Cloud_Spanner_V1_Client_SpannerClient__commit__) call.
