Reference documentation and code samples for the Google Maps Route Optimization V1 Client class VehicleFullness.

[VehicleFullness](https://docs.cloud.google.com/php/docs/reference/maps-routeoptimization/latest/V1.VehicleFullness) is a metric which computes how full a vehicle is. Each [VehicleFullness](https://docs.cloud.google.com/php/docs/reference/maps-routeoptimization/latest/V1.VehicleFullness) field is between 0 and 1, computed as the ratio between a capped metric field (e.g.

[AggregatedMetrics.travel_distance_meters](https://docs.cloud.google.com/php/docs/reference/maps-routeoptimization/latest/V1.AggregatedMetrics#_Google_Maps_RouteOptimization_V1_AggregatedMetrics__getTravelDistanceMeters__)) and its related vehicle limit (e.g. [Vehicle.route_distance_limit](https://docs.cloud.google.com/php/docs/reference/maps-routeoptimization/latest/V1.Vehicle#_Google_Maps_RouteOptimization_V1_Vehicle__getRouteDistanceLimit__)), if it exists. Otherwise the fullness ratio stays unset. If the limit is 0, the field is set to 1. Note: when a route is subject to traffic infeasibilities, some raw fullness ratios might exceed 1.0, e.g. the vehicle might exceed its distance limit. In these cases, we cap the fullness values at 1.0.
