Reference documentation and code samples for the Google Cloud Document Ai V1 Client class CreateProcessorRequest.

Request message for the [CreateProcessor](https://docs.cloud.google.com/php/docs/reference/cloud-document-ai/latest/V1.Client.DocumentProcessorServiceClient#_Google_Cloud_DocumentAI_V1_Client_DocumentProcessorServiceClient__createProcessor__) method. Notice this request is sent to a regionalized backend service. If the [ProcessorType](https://docs.cloud.google.com/php/docs/reference/cloud-document-ai/latest/V1.ProcessorType) isn't available in that region, the creation fails.
