Many parameters require resource names to be formatted in a particular way. ### pauseJob

Pauses a job.

If a job is paused then the system will stop executing the job until it is re-enabled via [ResumeJob](https://docs.cloud.google.com/php/docs/reference/cloud-scheduler/latest/V1.Client.CloudSchedulerClient#_Google_Cloud_Scheduler_V1_Client_CloudSchedulerClient__resumeJob__). The state of the job is stored in [state](https://docs.cloud.google.com/php/docs/reference/cloud-scheduler/latest/V1.Job#_Google_Cloud_Scheduler_V1_Job__getState__); if paused it will be set to [Job.State.PAUSED](https://docs.cloud.google.com/php/docs/reference/cloud-scheduler/latest/V1.Job.State#_Google_Cloud_Scheduler_V1_Job_State__PAUSED).
