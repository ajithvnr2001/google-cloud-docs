**NOTE:** This repository is part of [Google Cloud PHP](https://github.com/googleapis/google-cloud-php). Any support requests, bug reports, or development contributions should be directed to that project.

This repository is a home for the [protocol buffer](https://developers.google.com/protocol-buffers/) types which are shared by multiple Google Cloud APIs, generated for PHP. The protobuf definitions for these generated PHP classes are provided in the [Googleapis](https://github.com/googleapis/googleapis/) repository.

## Using these generated classes

These classes are made available under an Apache license (see `LICENSE`) and you are free to depend on them within your applications. They are considered stable and will not change in backwards-incompaible ways.

They are distributed as the [google/cloud-common-protos](https://packagist.org/packages/google/cloud-common-protos/) composer package, available on [Packagist](https://packagist.org/).

In order to depend on these classes, add the following line to your composer.json file in the `requires` section:
    
    
      "google/cloud-common-protos": "^1.0"
    

Or else use composer from the command line:
    
    
    composer require google/cloud-common-protos
