The Cloud Monitoring API, client libraries, metric and resource type references, and MCP tools let you programmatically access and manage Cloud Monitoring. 

  * ### [Enable the Cloud Monitoring API Enable the Monitoring API to run code that uses it.  ](https://docs.cloud.google.com/monitoring/api/enable-api)
  * ### [APIs Explorer Use the APIs Explorer to make API calls on Cloud Monitoring without writing code.  ](https://docs.cloud.google.com/monitoring/api/apis-explorer)
  * ### [Cloud Monitoring API client libraries Get started with Cloud Monitoring in your language of choice.  ](https://docs.cloud.google.com/monitoring/docs/reference/libraries)
  * ### [Cloud Monitoring API v3 Access all the features of Monitoring, including alerting policies, custom dashboards, and metrics scopes.  ](https://docs.cloud.google.com/monitoring/api/v3)
  * ### [Metrics list View the available metric types in Cloud Monitoring, Amazon Web Services, and third-party applications.  ](https://docs.cloud.google.com/monitoring/api/metrics)
  * ### [Monitored resource list View the available monitored resource types in Cloud Monitoring.  ](https://docs.cloud.google.com/monitoring/api/resources)
  * ### [Monitoring Query Language reference Review the reference guide for the Monitoring Query Language (MQL).  ](https://docs.cloud.google.com/monitoring/mql/reference)
  * ### [MCP reference View the MCP reference for the Cloud Monitoring API.  ](https://docs.cloud.google.com/monitoring/api/ref_v3_mcp/mcp)
