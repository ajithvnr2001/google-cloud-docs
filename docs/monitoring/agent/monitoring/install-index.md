**Caution:** As of September 28, 2026, the legacy Monitoring agent has reached its end of support. Standard maintenance and bug fixes are no longer provided. We strongly recommend migrating to one of the [supported alternatives](https://docs.cloud.google.com/monitoring/agent/). For more information about this deprecation, see [Legacy Monitoring and Logging agents end of support](https://docs.cloud.google.com/stackdriver/docs/deprecations/legacy-agents). 

## Select an installation method

  * ### [Install the Monitoring agent on a fleet of VMs by using agent policies Use the Google Cloud CLI or Terraform to create an agent policy that installs and manages agents on your fleet of VMs.  ](https://docs.cloud.google.com/monitoring/agent/monitoring/managing-agent-policies)
  * ### [Install the Monitoring agent on a fleet of VMs using automation tools Use Ansible, Chef, or Puppet to install and manage agents on your fleet of VMs.  ](https://docs.cloud.google.com/monitoring/agent/monitoring/fleet-installation)
