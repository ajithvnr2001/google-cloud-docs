#  Summary of example alerting policies Stay organized with collections  Save and categorize content based on your preferences. 

This document provides links to different types of alerting policies. The linked content might help you create the alerting policies that you need to monitor your services.

If you use the Cloud Monitoring API, we recommend that you use the Google Cloud CLI or client libraries to create your alerting policies. If you use the Google Cloud CLI, you pass to it a JSON file that contains the policy definition. For more information, see [Create alerting policies by using the API](https://docs.cloud.google.com/monitoring/alerts/policies-in-api).

Each entry in the following list contains a brief description and two links. If you use the Cloud Monitoring API and want more information, then click on `JSON`. If you use the Google Cloud console, then click on `console`:

  * Compare value of a metric to a threshold: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-metric-threshold), [console](https://docs.cloud.google.com/monitoring/alerts/using-alerting-ui)
  * Compare rate of change of metric's value to a threshold: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-rate-of-change), [console](https://docs.cloud.google.com/monitoring/alerts/using-alerting-ui#rate-of-change)
  * Create alert on metric absence: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-metric-absence), [console](https://docs.cloud.google.com/monitoring/alerts/metric-absence)
  * Compare value of forecasted metric value to a threshold: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-forecast), [console](https://docs.cloud.google.com/monitoring/alerts/metric-forecast)
  * Monitor a dynamic group of resources: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-group-aggr), [console](https://docs.cloud.google.com/monitoring/alerts/monitor-resource-group)
  * Create alert for an uptime check: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-uptime), [console](https://docs.cloud.google.com/monitoring/uptime-checks/uptime-alerting-policies)
  * Monitor count of VM processes: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-process-health), [console](https://docs.cloud.google.com/monitoring/alerts/monitor-process-count)
  * Compare a ratio of metrics to a threshold: [JSON](https://docs.cloud.google.com/monitoring/alerts/policies-in-json#json-ratio), [console](https://docs.cloud.google.com/monitoring/mql/examples#qlx-ratios)
  * Monitor quota metrics: [JSON](https://docs.cloud.google.com/monitoring/alerts/using-quota-metrics) , [console](https://docs.cloud.google.com/monitoring/alerts/using-quota-metrics)
