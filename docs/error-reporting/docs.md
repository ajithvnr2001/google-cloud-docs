# Error Reporting documentation

[Read product documentation](https://docs.cloud.google.com/error-reporting/docs/grouping-errors)

**Error Reporting** aggregates and displays errors produced in your running cloud services. Using the centralized error management interface, you can find your application's top or new errors so that you can fix the root causes faster.

You can report errors from your application by sending them directly to Cloud Logging with [proper formatting](https://docs.cloud.google.com/error-reporting/docs/formatting-error-messages) or by calling an [Error Reporting API](https://docs.cloud.google.com/error-reporting/reference) endpoint that sends them for you. The setup process depends on your platform; for instructions, see [Setup guides](https://docs.cloud.google.com/error-reporting/docs/setup).

To report errors from Android and iOS client applications, we recommend setting up [Firebase Crashlytics](https://firebase.google.com/docs/crashlytics).
