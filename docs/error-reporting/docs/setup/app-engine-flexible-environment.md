#  Setting up on App Engine flexible environment Stay organized with collections  Save and categorize content based on your preferences. 

Error Reporting lets you monitor application crashes and unhandled exceptions in the App Engine flexible environment, where Error Reporting is automatically enabled. The service automatically analyzes messages written to `stderr` and displays detected issues in the Google Cloud console. To manually report events or inspect application data, see [Formatting errors in Cloud Logging](https://docs.cloud.google.com/error-reporting/docs/formatting-error-messages) and [Viewing errors](https://docs.cloud.google.com/error-reporting/docs/viewing-errors).

**Note** : If you see the message "Set up Error Reporting" on the **Error Reporting** page, then your Google Cloud project has no error groups to display.

## Examples using the instrumentation libraries
