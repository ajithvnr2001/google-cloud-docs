#  Setting up on Apps Script Stay organized with collections  Save and categorize content based on your preferences. 

When you enable exception logging in Google Apps Script, Error Reporting automatically groups exceptions from your Apps Script logs. For integration details, see the [Apps Script documentation](https://developers.google.com/apps-script/guides/logging#stackdriver_error_reporting). To inspect data in the Google Cloud console, see [Viewing errors](https://docs.cloud.google.com/error-reporting/docs/viewing-errors).

**Note** : If you see the message "Set up Error Reporting" on the **Error Reporting** page, then your Google Cloud project has no error groups to display.
