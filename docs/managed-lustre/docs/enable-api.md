#  Enable the Google Cloud Managed Lustre API Stay organized with collections  Save and categorize content based on your preferences. 

Before following any of the instructions in this guide, you must enable the Google Cloud Managed Lustre API.

###  gcloud 

Use `gcloud services enable` as follows:
    
    
    gcloud services enable lustre.googleapis.com --project=PROJECT_ID
    

###  Google Cloud console 

  1. Go to the **Google Cloud Managed Lustre API** page in the Google Cloud console.

[Go to Google Cloud Managed Lustre API](https://console.cloud.google.com/marketplace/product/google/lustre.googleapis.com)

  2. Click **Enable API**. The API is enabled for your project and the Google Cloud Managed Lustre **Instances** page is displayed.
