This document describes your support options.

## Google Cloud Support

If you have a paid [Google Cloud support plan](https://docs.cloud.google.com/support#support-plans) always open support cases through the support console, as described in the [Create a support case documentation](https://docs.cloud.google.com/support/docs/customer-care-procedures#create_a_support_case)

Before submitting your request, check if the [Release Notes](https://docs.cloud.google.com/gemini-enterprise-cx/cx-agent-studio/resources/release-notes) have answers to your questions.

When opening a case, use the CX Agent Studio component.

The Google Cloud Support team offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Getting Google Cloud support](https://docs.cloud.google.com/support/docs).

## Community Support

### File product issues or feature requests

You can report issues or file feature requests via Issue Trackers. See the [general guidelines](https://docs.cloud.google.com/support/docs/issue-trackers).

  * CX Agent Studio

    * Search the [existing list](https://issuetracker.google.com/issues?q=componentid:2117018%20status:open) for a similar issue before filing a new one.
    * If you do not find a similar issue and would like to report it, you can [create a new issue](https://issuetracker.google.com/issues/new?component=2117018).



## Documentation issues

From any CX Agent Studio documentation page, click **Send feedback** near the top right or bottom of the page. This will open a feedback form specific to the page you are viewing. Your comments will be reviewed by the documentation team.
