Enums  
---  
`SCENARIO_EXECUTION_MODE_UNSPECIFIED` | Unspecified execution mode. Defaults to QUALITY_OPTIMIZED.  
`QUALITY_OPTIMIZED` | Quality optimized mode.  
`SPEED_OPTIMIZED` | Speed optimized mode.
