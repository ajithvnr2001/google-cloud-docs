#  Languages Stay organized with collections  Save and categorize content based on your preferences. 

You should design your agents using English, but agents can automatically detect the language of end-user input, and they will automatically respond using the same language.

## Chat interactions

For chat interactions (text only), you can use any [language supported by Vertex AI Gemini models](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/models#language_support).
