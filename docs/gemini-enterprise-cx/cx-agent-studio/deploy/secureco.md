#  SecureCo Stay organized with collections  Save and categorize content based on your preferences. 

Connect your agent to the [SecureCo](https://www.secureco.co/) Intelligent Voice Platform (IVP) by creating and configuring a Voice Gateway service in the IVP Portal.

  1. Create a Voice Gateway service in the [IVP Portal](https://portal.ivp.secureco.co/dashboard).
  2. Configure the CX Agent Studio integration using your agent and deployment details.
  3. Assign IVP phone number(s) to the service.
  4. Allocate voice ports and create the service.
