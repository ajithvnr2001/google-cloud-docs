You can integrate your CX Agent Studio agent application with your [WhatsApp](https://www.whatsapp.com/) or [Instagram](https://www.instagram.com) conversations by connecting to the WhatsApp or Instagram deployment platform.

## Configuration

**Note:** When configuring WhatsApp or Instagram deployment for an agent application, only owners of the associated project have permissions to create the deployment.

To configure this platform:

  1. Click the **Deploy** button at the top of the agent builder.
  2. Select **Connect to a platform**.
  3. Provide a channel name.
  4. Select "WhatsApp" or "Instagram" as the platform type.
  5. Provide an agent version.
  6. Click **Authenticate to Meta**.
  7. When configuring WhatsApp, Meta requires a two-step verification PIN to proceed. Enter your existing PIN, or enter a new PIN to create one. Store this PIN in a safe place for future reference.
  8. Click **Sign in to Meta**.
  9. Follow the steps on the Meta dialog and select the business assets you want to share with CX Agent Studio.
  10. Once completed, CX Agent Studio will make the connection.
