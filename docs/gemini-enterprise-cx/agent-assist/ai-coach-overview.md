#  AI coach overview Stay organized with collections  Save and categorize content based on your preferences. 

Use a large language model (LLM) to make suggestions for how a contact center agent should respond during customer service conversations. AI coach provides useful suggestions to your agents for the following customer service situations:

  * Up sell and cross sell.
  * Retain customers.
  * Automate operations.



AI coach can also improve other business products. For example, recommendation engines predict user preferences and suggest products using data analysis and machine learning algorithms. AI coach can help recommendation engines provide relevant recommendations, but it doesn't replace them.

AI coach is available in all Google Cloud [languages](https://docs.cloud.google.com/gemini-enterprise-cx/agent-assist/languages) and [regions](https://docs.cloud.google.com/gemini-enterprise-cx/agent-assist/regionalization).
