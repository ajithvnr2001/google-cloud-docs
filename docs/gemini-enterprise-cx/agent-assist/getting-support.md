## Google groups

Join the [Agent Assist users Google Group](https://groups.google.com/g/agent-assist-discuss) for general product discussion.

This group is monitored by Google on a best-effort basis.

## File product issues or feature requests

You can report issues or file feature requests using the Issue Tracker. See the [general guidelines](https://docs.cloud.google.com/support/docs/issue-trackers). You can search the [existing list](https://issuetracker.google.com/savedsearches/5969415) for a similar issue before filing a new one. If you don't find a similar issue and would like to report it, you can [create an issue](https://issuetracker.google.com/issues/new?component=1028559). So the feedback is best understood, add a screenshot.
