#  All BigQuery schemas Stay organized with collections  Save and categorize content based on your preferences. 

The latest schema version is used when you export CX Insights data to BigQuery. The command `EXPORT_VERSION_LATEST_AVAILABLE` provides the latest default schema, which serves as the established General Availability (GA) baseline.

Older schema versions are listed here as references. Contact Cloud support if you'd like to use an older schema version.
