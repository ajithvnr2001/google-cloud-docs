Publish an Assessment.

### HTTP request

`POST https://{endpoint}/v1alpha1/{name=projects/*/locations/*/conversations/*/assessments/*}:publish`

Where `{endpoint}` is one of the [supported service endpoints](https://docs.cloud.google.com/gemini-enterprise-cx/insights/reference/rest#rest_endpoints).

The URLs use [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`name` |  `string` Required. The name of the assessment to publish.  
  
### Request body

The request body must be empty.

### Response body

If successful, the response body contains an instance of `[Assessment](https://docs.cloud.google.com/gemini-enterprise-cx/insights/reference/rest/v1alpha1/projects.locations.authorizedViewSets.authorizedViews.conversations.assessments#Assessment)`.

### Authorization scopes

Requires the following OAuth scope:

  * `https://www.googleapis.com/auth/cloud-platform`



For more information, see the [Authentication Overview](https://docs.cloud.google.com/docs/authentication#authorization-gcp).

### IAM Permissions

Requires the following [IAM](https://cloud.google.com/iam/docs) permission on the `name` resource:

  * `contactcenterinsights.assessments.publish`



For more information, see the [IAM documentation](https://cloud.google.com/iam/docs).
