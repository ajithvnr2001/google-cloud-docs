#  SheetsSource Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Google Sheets document details to get the feedback label file from.

JSON representation  
---  
      
    
    {
      "spreadsheetUri": string
    }  
  
Fields  
---  
`spreadsheetUri` |  `string` Required. The Google Sheets document to write the feedback labels to. Retrieved from Google Sheets URI. E.g. `https://docs.google.com/spreadsheets/d/1234567890` The spreadsheet must be shared with the Insights P4SA.
