##  Get a Google support package 

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Google Cloud Support](https://docs.cloud.google.com/support). 

##  Get support from the community 

Community resources are available for recommendations. 

###  Ask a question on Stack Overflow 

Ask a question about recommendations on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-recommendations). Use the tag `google-cloud-recommendations` for questions about recommendations. 

###  Discuss AI Commerce Search 

Join the [cloud-recommendations-users](https://groups.google.com/forum/#!forum/cloud-recommendations-users) Google group to discuss recommendations and receive recommendations announcements and updates. 

You can visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss recommendations and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

##  File bugs or feature requests 

To file a bug or a feature request, file a support ticket. To set your ticket to the correct component, select the following fields. 

For recommendations: 

  * **Category** : Machine Learning
  * **Component** : AI Commerce Search: recommendations
  * **Subcomponent** : Choose the subcomponent you are experiencing the issue with 
    * Access & Permissions
    * Account Administration & Billing
    * API, SDK & Client Libraries
    * Outage & latency
    * Migration
    * Placement
    * Quality of Results
    * Feature Request
    * Quotas
    * Other



For search: 

  * **Category** : Machine Learning
  * **Component** : AI Commerce Search: search & browse
  * **Subcomponent** : Choose the subcomponent you are experiencing the issue with 
    * Access & Permissions
    * Account Administration & Billing
    * API, SDK & Client Libraries
    * Autocomplete
    * Indexes
    * Indexing & serving
    * Dynamic Facets
    * Events Ingestion
    * Facets/Browsing
    * merchant center integration
    * Outage & latency
    * Product Data
    * Product Ingestion
    * Quality/Modeling
    * Feature Request
    * Quotas
    * Other



For more information on creating a support ticket, see [Getting support](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/getting-support).
