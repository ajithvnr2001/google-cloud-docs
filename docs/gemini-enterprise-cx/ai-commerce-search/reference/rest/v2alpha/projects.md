## Resource

## Methods  
  
---  
  
### `[enrollSolution](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/projects/enrollSolution)`

|  The method enrolls a solution of type `[Retail Search](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/SolutionType#ENUM_VALUES.SOLUTION_TYPE_SEARCH)` into a project.  
  
### `[getAlertConfig](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/projects/getAlertConfig)`

|  Get the `[AlertConfig](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/AlertConfig)` of the requested project.  
  
### `[getLoggingConfig](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/projects/getLoggingConfig)`

|  Gets the `[LoggingConfig](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/LoggingConfig)` of the requested project.  
  
### `[getRetailProject](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/projects/getRetailProject)`

|  Gets the project.  
  
### `[listEnrolledSolutions](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/projects/listEnrolledSolutions)`

|  Lists all the retail API solutions the project has enrolled.  
  
### `[updateAlertConfig](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/projects/updateAlertConfig)`

|  Update the alert config of the requested project.  
  
### `[updateLoggingConfig](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/projects/updateLoggingConfig)`

|  Updates the `[LoggingConfig](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/LoggingConfig)` of the requested project.
