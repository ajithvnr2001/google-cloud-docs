Gets the project.

Throws `NOT_FOUND` if the project wasn't initialized for the Retail API service.

### HTTP request

`GET https://retail.googleapis.com/v2alpha/{name=projects/*/retailProject}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`name` |  `string` Required. Full resource name of the project. Format: `projects/{project_number_or_id}/retailProject`  
  
### Request body

The request body must be empty.

### Response body

If successful, the response body contains an instance of `[Project](https://docs.cloud.google.com/gemini-enterprise-cx/ai-commerce-search/reference/rest/v2alpha/Project)`.

### Authorization scopes

Requires the following OAuth scope:

  * `https://www.googleapis.com/auth/cloud-platform`



For more information, see the [Authentication Overview](https://docs.cloud.google.com/docs/authentication#authorization-gcp).

### IAM Permissions

Requires the following [IAM](https://cloud.google.com/iam/docs) permission on the `name` resource:

  * `retail.retailProjects.get`



For more information, see the [IAM documentation](https://cloud.google.com/iam/docs).
