Database Center provides a centralized view across your fleet of Google Cloud databases. Database Center also displays health issues and recommendations for self-managed databases that you run on Compute Engine virtual machines (VMs). Database Center supports the following databases on Compute Engine VMs:

  * MySQL
  * PostgreSQL
  * Microsoft SQL Server



## Health issues for databases on Compute Engine VMs

The following health issues are supported for databases on a Compute Engine VM:

Health issue | MySQL | PostgreSQL | SQL Server  
---|---|---|---  
Outdated minor version for patch | ✔ | ✔ | ✔  
Exposed to broad access | ✔ | ✔ | ✔  
Unencrypted connections | ✔ | ✔ | ✔  
Auditing not enabled | ✔ | ✔ | ✔  
No root password | ✔ | ✔ |
