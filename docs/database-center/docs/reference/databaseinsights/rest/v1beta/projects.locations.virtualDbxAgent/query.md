#  Method: projects.locations.virtualDbxAgent.query Stay organized with collections  Save and categorize content based on your preferences. 

virtualDbxAgent.query runs the agent.

### HTTP request

`POST https://databaseinsights.googleapis.com/v1beta/{parent=projects/*/locations/*}/virtualDbxAgent:query`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`parent` |  `string`  
  
### Request body

The request body contains data with the following structure:

JSON representation  
---  
      
    
    {
      "userQuery": string,
      "sessionId": string,
      "projectId": string,
      "productType": string,
      "engineType": string,
      "location": string,
      "databaseChatContext": {
        object ([DatabaseChatContext](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#DatabaseChatContext))
      },
      "additionalContext": {
        string: string,
        ...
      },
      "agentOptions": {
        object ([AgentOptions](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#AgentOptions))
      }
    }  
  
Fields  
---  
`userQuery` |  `string` Required. The user query to be used for the agent.  
`sessionId` |  `string` Required. The session id of the user query. This is used to identify the user query and the agent response.  
`projectId` |  `string` Optional. The project id of the database.  
`productType` |  `string` Optional. The product type of the database. This is a string representation of the product type  
`engineType` |  `string` Optional. The engine type of the database. This is a string representation of the engine type.  
`location` |  `string` Optional. The location of the database resource  
`databaseChatContext` |  `object (`[DatabaseChatContext](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#DatabaseChatContext)`)` Optional. The database chat context to be used for database chat tools.  
`additionalContext` |  `map (key: string, value: string)` Optional. The additional context to be used for the agent.An object containing a list of `"key": value` pairs. Example: `{ "name": "wrench", "mass": "1.3kg", "count": "3" }`.  
`agentOptions` |  `object (`[AgentOptions](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#AgentOptions)`)` Optional. The options for processing the request on the agent.  
  
### Response body

If successful, the response body contains data with the following structure:

JSON representation  
---  
      
    
    {
      "response": string,
      "visualizations": [
        {
          object ([Visualization](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#Visualization))
        }
      ],
      "sduiRequests": [
        {
          object ([SduiRequest](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#SduiRequest))
        }
      ]
    }  
  
Fields  
---  
`response` |  `string` The agent's response to the user query.  
`visualizations[]` |  `object (`[Visualization](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#Visualization)`)` A list of visualizations generated by the agent.  
`sduiRequests[]` |  `object (`[SduiRequest](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest/v1beta/projects.locations.virtualDbxAgent/query#SduiRequest)`)` Output only. The SDUI requests for UI widgets. The number of elements is limited to 100.
