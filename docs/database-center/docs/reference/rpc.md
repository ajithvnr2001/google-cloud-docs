#  Database Center API Stay organized with collections  Save and categorize content based on your preferences. 

Database Center offers a comprehensive, organization-wide platform for monitoring database fleet health across various products. It simplifies management and reduces risk by automatically aggregating and summarizing key health signals, removing the need for custom dashboards. The platform provides a unified view through its dashboard and API, enabling teams focused on reliability, compliance, security, cost, and administration to quickly identify and address relevant issues within their database fleets.

## Service: databasecenter.googleapis.com

The Service name `databasecenter.googleapis.com` is needed to create RPC client stubs.

## `[google.cloud.databasecenter.v1beta.DatabaseCenter](https://docs.cloud.google.com/database-center/docs/reference/rpc/google.cloud.databasecenter.v1beta#google.cloud.databasecenter.v1beta.DatabaseCenter)`

Methods  
---  
``[AggregateFleet](https://docs.cloud.google.com/database-center/docs/reference/rpc/google.cloud.databasecenter.v1beta#google.cloud.databasecenter.v1beta.DatabaseCenter.AggregateFleet)`` |  AggregateFleet provides statistics about the fleet grouped by various fields.  
``[AggregateIssueStats](https://docs.cloud.google.com/database-center/docs/reference/rpc/google.cloud.databasecenter.v1beta#google.cloud.databasecenter.v1beta.DatabaseCenter.AggregateIssueStats)`` |  AggregateIssueStats provides database resource issues statistics.  
``[QueryDatabaseResourceGroups](https://docs.cloud.google.com/database-center/docs/reference/rpc/google.cloud.databasecenter.v1beta#google.cloud.databasecenter.v1beta.DatabaseCenter.QueryDatabaseResourceGroups)`` |  QueryDatabaseResourceGroups returns paginated results of database groups.  
``[QueryIssues](https://docs.cloud.google.com/database-center/docs/reference/rpc/google.cloud.databasecenter.v1beta#google.cloud.databasecenter.v1beta.DatabaseCenter.QueryIssues)`` |  QueryIssues provides a list of issues and recommendations that a user has access to and that are within the requested scope.  
``[QueryProducts](https://docs.cloud.google.com/database-center/docs/reference/rpc/google.cloud.databasecenter.v1beta#google.cloud.databasecenter.v1beta.DatabaseCenter.QueryProducts)`` |  QueryProducts provides a list of all possible products which can be used to filter database resources.
