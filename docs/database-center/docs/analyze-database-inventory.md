#  Analyze your database inventory Stay organized with collections  Save and categorize content based on your preferences. 

This document describes how to analyze your database inventory by grouping and sorting database fleet health information that you're interested in.

Database Center lets you customize and share the data that appears on your dashboard. Database Center displays all of the database information for your organization. Any customizations that you make only apply to your view of the dashboard.

**Note:** Database Center updates data approximately every 24 hours.

The **Fleet inventory** section of the Database Center dashboard gives you a visual overview of the database groups and database resources in your database fleet. The section contains two _segments_ that you configure: Segment 1 and Segment 2.

Segments are useful when you want to learn specific information about your database fleet inventory. For example, you can use segments to determine the following:

  * Where are my PostgreSQL 14 instances hosted?
  * Which Google Cloud projects have database resources deployed in Asia and America?
  * Which are my largest regions, and which engines do I use the most in those regions?



Segment 1 groups the database resources on the top level by the selected segment, while Segment 2 groups the expanded row by the selected segment. For each segment, you can choose one of the following options:

  * **Project** : Your Google Cloud project.
  * **Region** : The geographic location where your data resides.
  * **Product & version**: The version of the database that you're interested in.
  * **Resource type** : The name assigned to provisioned computing resources in different Google Cloud database products.

## Group and sort database fleet health information

  1. In the Google Cloud console, go to the **Database Center Overview** page.

[Database Center](https://console.cloud.google.com/database-center)

  2. Use filters to view health issues on the database resources you want to analyze. For more information, see [Filter database resources](https://docs.cloud.google.com/database-center/docs/filter-resources-export-fleet-inventory-information#filter-database-resources).
