Welcome to the Database Center Reference Documentation. Here you can find reference documentation for both Database Center and Database Insights APIs.

## Database Center API

The Database Center API provides access to an organization-wide, cross-product database fleet health platform. It aggregates health, security, and compliance signals from various Google Cloud databases, offering a single pane of glass to identify and manage issues.

  * [REST Reference](https://docs.cloud.google.com/database-center/docs/reference/rest)
  * [RPC Reference](https://docs.cloud.google.com/database-center/docs/reference/rpc)
  * [MCP Reference](https://docs.cloud.google.com/database-center/docs/reference/mcp)



## Database Insights API

Database Insights API is a regional service that provides deep performance diagnostics and monitoring for cloud databases. It exposes tools like Query Insights, which helps you detect, diagnose, and prevent query performance problems, and System Insights, which provides comprehensive telemetry and monitoring for system-level instance metrics.

  * [REST Reference](https://docs.cloud.google.com/database-center/docs/reference/databaseinsights/rest)
