Database Center reporting allows you to monitor your fleet inventory and health by configuring daily, weekly, and monthly reports for your [customized dashboard views](https://docs.cloud.google.com/database-center/docs/dashboard-views). These reports summarize key metrics and status information for your database resources.

## Manage views and reports

The **Views and reports** page is the central location for managing your dashboard views and reports.

To access this page:

  1. In the Google Cloud console, open **Database Center**.

[Database Center](https://console.cloud.google.com/database-center/views)

  2. In the navigation pane, click **Views and Reports**.




The **Views and reports** page provides the following information:

  * The name of the dashboard view and any reports associated with each view. You can expand a view entry to see the reports associated with it.

  * The frequency of the report or the number of reports associated with a view.

  * The recipients who receive the automated reports.

  * The timestamp when the report or view was last modified.

  * For views, who has permission to access the view.

  * The user who created the view or report.

  * Access to actions, such as editing or deleting a report or view. Available actions might vary for each report depending on who can update the report.




## Create a report

To schedule a new automated report for a view:

  1. In the Google Cloud console, open **Database Center**.

[Database Center](https://console.cloud.google.com/database-center/views)

  2. In the navigation pane, click **Views and Reports**.

  3. Click **Create new report**.

  4. In the **Schedule a report** dialog, provide the following:

     * **Report name** : Enter a name for the report.

     * **Report frequency** : Select how often the report should be sent (for example, **Weekly (Monday)**).

     * **View** : Select the dashboard view that the report is for.

  5. In the **Recipients** section, select one or more **Notification Channels** to receive the report.

     * To add a new recipient, click **Manage Notification Channels**.
  6. Click **Submit**.
