#  Work with Contact Center data Stay organized with collections  Save and categorize content based on your preferences. 

The CX Insights Accelerator lets you work with Contact Center data in your Cloud Data Fusion instance. It's an out-of-the-box approach to importing and exporting large amounts of data in Customer Experience Insights with a Cloud Data Fusion pipeline.

The Accelerator is useful in the following use cases:

  * Importing a large volume of historical data into CX Insights for analysis.
  * Scheduling frequent data exports out of CX Insights and into BigQuery for real-time updates.
  * Scheduling frequent data imports for conversation data that must be loaded into CX Insights.
