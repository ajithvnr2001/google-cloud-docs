This page describes the available version upgrades for Cloud Data Fusion instances and pipelines.

For more information, see [Versioning in Cloud Data Fusion](https://docs.cloud.google.com/data-fusion/docs/concepts/versioning).

## Available version upgrades for instances and pipelines

When upgrading, use the latest version of Cloud Data Fusion so that your instances run in a supported environment as long as possible. For more information, see the [version support policy](https://docs.cloud.google.com/data-fusion/docs/support/version-support-policy). Depending on the original version, upgrades to some versions might not be available. In those cases, upgrade to a version that supports upgrades to the version you want.

## Available patch revisions

When you upgrade an instance, use the latest revision of Cloud Data Fusion version, so that your instances have the necessary fixes. For more information, see the [Version support policy](https://docs.cloud.google.com/data-fusion/docs/support/version-support-policy). Use a patch revision that supports the version you want.

Cloud Data Fusion supports the following patch revisions:

Your Cloud Data Fusion version | Latest patch revision  
---|---  
6.11.1 | 6.11.1.2  
6.10.1 | 6.10.1.2  
6.9.2 | 6.9.2.4  
6.8.3 | 6.8.3.1  
6.7.3 | 6.7.3.1
