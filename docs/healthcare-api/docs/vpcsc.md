#  Protecting data with service perimeters Stay organized with collections  Save and categorize content based on your preferences. 

[VPC Service Controls](https://docs.cloud.google.com/vpc-service-controls) provide additional security for your data in the Cloud Healthcare API to help mitigate the risk of data exfiltration. Using VPC Service Controls, you can add projects to service perimeters that protect resources and services from requests that originate outside the perimeter.

For information about configuring service perimeters, see [Service perimeter configuration](https://docs.cloud.google.com/vpc-service-controls/docs/service-perimeters).
