## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Provide product or documentation feedback

You can provide feedback about Cloud Healthcare API or its documentation without having a support package. To submit feedback, click the **Send Feedback** button on any page of the documentation.

## Get support from the community

### Discuss the Cloud Healthcare API

Join the [gcp-healthcare-discuss](https://groups.google.com/forum/#!forum/gcp-healthcare-discuss) Google group to discuss the Cloud Healthcare API.

### Receive announcements and updates

Join the [gcp-hcls-announce](https://groups.google.com/forum/#!forum/gcp-hcls-announce/join) Google group to receive industry updates and the latest launch announcements for the Cloud Healthcare API and [Cloud Life Sciences](https://docs.cloud.google.com/life-sciences).
