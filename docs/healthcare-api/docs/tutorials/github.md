This page contains tutorials and codelabs hosted on [GitHub](https://github.com) that demonstrate how to create applications with the Cloud Healthcare API.

## Getting the tutorials

The latest Cloud Healthcare API tutorials are available in the [GoogleCloudPlatform/healthcare](https://github.com/GoogleCloudPlatform/healthcare) GitHub repository.

## Understanding the tutorials

The provided tutorials give concrete examples of how the Cloud Healthcare API is used.

Several of the tutorials use [public datasets](https://docs.cloud.google.com/healthcare-api/docs/resources/public-datasets) that are provided by the Cloud Healthcare API for use with your applications.
