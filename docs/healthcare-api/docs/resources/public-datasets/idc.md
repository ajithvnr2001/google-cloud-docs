#  Imaging Data Commons (IDC) datasets Stay organized with collections  Save and categorize content based on your preferences. 

The [Imaging Data Commons (IDC)](https://portal.imaging.datacommons.cancer.gov/collections/) hosts collections of de-identified medical images, primarily in DICOM format.

You can access this data from Google Cloud in the following ways:

  * In a **NCI Imaging Data Commons** BigQuery dataset from the Google Cloud Marketplace:

[Go to the IDC datasets in the Google Cloud Marketplace](https://console.cloud.google.com/marketplace/product/bigquery-public-data/nci-idc-data)

  * In a DICOM store in the Cloud Healthcare API. The DICOM store is named `idc-store`, and is in a Cloud Healthcare API dataset named `idc` in the `nci-idc-data` Google Cloud project. To request access to the IDC datasets, complete the [NCI Imaging Data Commons Access Form](https://forms.gle/QkpNeWqgsDfJs6W79).

[Go to the IDC datasets in the Cloud Healthcare API DICOM Studio](https://console.cloud.google.com/healthcare/dicom-studio/workbench?project=nci-idc-data)

For information about the structure of the data, see the [DICOM overview](https://docs.cloud.google.com/healthcare-api/docs/concepts/dicom) and [Using the DICOMweb standard](https://docs.cloud.google.com/healthcare-api/docs/how-tos/dicomweb).
