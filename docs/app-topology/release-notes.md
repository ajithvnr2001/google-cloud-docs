## September 24, 2026

Announcement

[App Topology](https://docs.cloud.google.com/app-topology/overview) is [generally available](https://cloud.google.com/products#product-launch-stages).

App Topology lets you query data about your resources and applications from multiple sources, and then view the correlated data as a topology graph. For example, you can view all agents that have a specific vulnerability.

By bringing together data across multiple sources, App Topology provides a single place to view resource relationships and dependencies.
