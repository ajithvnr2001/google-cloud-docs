When you create a Dataproc Metastore service, you can choose to use a _Dataproc Metastore 2 service_ or a _Dataproc Metastore 1 service_.

This document explains how to control resource consumption for Dataproc Metastore 1.

## Types of service tiers

Dataproc Metastore uses service tiers to manage stability and workloads. You can select a tier when you create a Dataproc Metastore service or change it for an existing service.

There are two types of service tiers:

  * **Developer** : The `Developer` tier is typically used for low-cost proof-of-concept projects. This tier provides limited scalability and no fault tolerance.

  * **Enterprise** : The `Enterprise` tier is typically used for production projects. This tier provides flexible scalability, fault tolerance, and multi-zone high availability. It can handle heavy Dataproc Metastore workloads.




By default, new Dataproc Metastore services are created with the `Developer` tier.
