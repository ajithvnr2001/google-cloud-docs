Cloud API Registry lets you discover, govern, use, and monitor APIs provided by Google, or by your organization through Apigee API hub. The registry serves as a centralized catalog for API discovery, and provides a single endpoint through which you can find and access metadata about various APIs available to a Google Cloud user or organization.

Apigee API hub is a platform that helps you manage your organization's APIs. It serves as a central repository for API information. Cloud API Registry imports metadata from Apigee API hub, making API resources easier for you to discover and use. [Learn more about Apigee API hub](https://docs.cloud.google.com/apigee/docs/apihub/what-is-api-hub).

Service Usage is a service that lets you control enabling and disabling APIs across your organization's resource hierarchy: projects, folders, and organizations. Permissions through a Service Usage role are required to enable and disable APIs. [Learn more about Service Usage](https://docs.cloud.google.com/service-usage/docs/overview).
