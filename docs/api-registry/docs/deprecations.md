**Preview**

This product is subject to the "Pre-GA Offerings Terms" in the General Service Terms section of the [Service Specific Terms](https://docs.cloud.google.com/terms/service-terms#1). Pre-GA products are available "as is" and might have limited support. For more information, see the [launch stage descriptions](https://cloud.google.com/products/#product-launch-stages). 

The [Google Cloud Platform Terms of Service (section "Discontinuation of Services")](https://docs.cloud.google.com/terms) defines the deprecation policy that applies to Cloud API Registry. The [deprecation policy](https://docs.cloud.google.com/terms/deprecation) only applies to the services, features, or products listed therein. 

After a service, feature, or product is officially deprecated, it continues to be available for at least the period of time defined in the Terms of Service. After this period of time, the service is scheduled for shutdown. 

Feature | Deprecated date | Shutdown date | Details  
---|---|---|---  
Support for Model Context Protocol (MCP) servers and tools | April 30, 2026 | July 30, 2026 | Support for retrieving, listing, enabling, and disabling MCP servers and tools using the Cloud API Registry API is deprecated. Corresponding Google Cloud CLI commands and associated Identity and Access Management permissions are also deprecated. Alternatively, you can use [Agent Registry](https://docs.cloud.google.com/agent-registry/overview), a centralized catalog, to store, discover, and govern MCP servers, tools, and AI agents within Google Cloud.
