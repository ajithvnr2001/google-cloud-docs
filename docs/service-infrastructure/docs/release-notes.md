## April 01, 2019

Feature

  * [`services.tenancyUnits.undeleteProject`](https://docs.cloud.google.com/service-infrastructure/docs/service-consumer-management/reference/rest/v1/services.tenancyUnits/undeleteProject) attempts to undelete a previously deleted tenant project.



Feature

  * [`services.tenancyUnits.attachProject`](https://docs.cloud.google.com/service-infrastructure/docs/service-consumer-management/reference/rest/v1/services.tenancyUnits/attachProject) attaches an existing project to a tenancy unit as a new tenant resource.



Feature

  * [`services.tenancyUnits.applyProjectConfig`](https://docs.cloud.google.com/service-infrastructure/docs/service-consumer-management/reference/rest/v1/services.tenancyUnits/applyProjectConfig) applies a configuration to an existing tenant project.



Feature

  * [`services.tenancyUnits.deleteProject`](https://docs.cloud.google.com/service-infrastructure/docs/service-consumer-management/reference/rest/v1/services.tenancyUnits/deleteProject) deletes the specified project resource identified by a tenant resource tag.



Feature

  * [`TenantProjectConfig`](https://docs.cloud.google.com/service-infrastructure/docs/service-consumer-management/reference/rest/v1/TenantProjectConfig) defines a tenant project to be added to the specified tenancy unit as well as its initial configuration and properties.
