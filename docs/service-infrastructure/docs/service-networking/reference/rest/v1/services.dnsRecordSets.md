## Resource

## Methods  
  
---  
  
### `[add](https://docs.cloud.google.com/service-infrastructure/docs/service-networking/reference/rest/v1/services.dnsRecordSets/add)`

|  Service producers can use this method to add DNS record sets to private DNS zones in the shared producer host project.  
  
### `[get](https://docs.cloud.google.com/service-infrastructure/docs/service-networking/reference/rest/v1/services.dnsRecordSets/get)`

|  Service producers can use this method to get a DNS record set from a private DNS zone in the shared producer host project.  
  
### `[list](https://docs.cloud.google.com/service-infrastructure/docs/service-networking/reference/rest/v1/services.dnsRecordSets/list)`

|  Service producers can use this method to list DNS record sets in private DNS zones in the shared producer host project.  
  
### `[remove](https://docs.cloud.google.com/service-infrastructure/docs/service-networking/reference/rest/v1/services.dnsRecordSets/remove)`

|  Service producers can use this method to remove DNS record sets from private DNS zones in the shared producer host project.  
  
### `[update](https://docs.cloud.google.com/service-infrastructure/docs/service-networking/reference/rest/v1/services.dnsRecordSets/update)`

|  Service producers can use this method to update DNS record sets from private DNS zones in the shared producer host project.
