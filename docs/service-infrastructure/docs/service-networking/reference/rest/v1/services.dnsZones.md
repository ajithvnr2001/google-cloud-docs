## Methods  
  
---  
  
### `[add](https://docs.cloud.google.com/service-infrastructure/docs/service-networking/reference/rest/v1/services.dnsZones/add)`

|  Service producers can use this method to add private DNS zones in the shared producer host project and matching peering zones in the consumer project.  
  
### `[remove](https://docs.cloud.google.com/service-infrastructure/docs/service-networking/reference/rest/v1/services.dnsZones/remove)`

|  Service producers can use this method to remove private DNS zones in the shared producer host project and matching peering zones in the consumer project.
