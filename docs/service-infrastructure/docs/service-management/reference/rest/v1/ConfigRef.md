#  ConfigRef Stay organized with collections  Save and categorize content based on your preferences. 

  * JSON representation



Represents a service configuration with its name and id.

JSON representation  
---  
      
    
    {
      "name": string
    }  
  
Fields  
---  
`name` |  `string` Resource name of a service config. It must have the following format: "services/{service name}/configs/{config id}".
