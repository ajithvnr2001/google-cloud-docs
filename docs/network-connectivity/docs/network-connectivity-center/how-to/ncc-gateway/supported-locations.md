#  Locations supported for NCC Gateway Stay organized with collections  Save and categorize content based on your preferences. 

If you want to use NCC Gateway, you must create the spokes in regions that support NCC Gateway. If you create spokes in additional regions for redundancy, these regions must also support this feature.

## Limitations

NCC Gateway capabilities can vary across regions. To minimize the risk of issues occurring, when you plan your deployment, check which capabilities are available in your region of choice. NCC Gateway capabilities are not uniform across all regions.

**Bandwidth**

The available provisioned bandwidth (1 Gbps, 10 Gbps, or 100 Gbps) might be limited based on the region or the specific security partner that you use, such as Palo Alto Prisma Access. For example, some regions or partners might not support 100 Gbps.

**Security partner availability**

Third-party SSE partners (Palo Alto Prisma Access and Symantec Cloud SWG) might only be available in a subset of the supported NCC Gateway regions.
