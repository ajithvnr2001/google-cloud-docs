To get help or submit feedback for Network Connectivity, you can use Google Cloud and community support channels. This document lists the available support options and feedback methods.

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## Get support from the community

You can also ask for help in our Stack Overflow and Slack communities.

### Ask a question on Stack Overflow

Ask a question about Network Connectivity on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-networking). Use the tag `google-cloud-networking` for questions about Network Connectivity. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Network Connectivity

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Network Connectivity and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Network Connectivity, join the [`#networking`](https://googlecloud-community.slack.com/messages/C2Q13BM0T/) channel. 

## File bugs or feature requests

From the Network Connectivity documentation, click **Send feedback** near the top right of the page or at the bottom of the page. This opens a feedback form. Your comments are reviewed by the Network Connectivity team.
