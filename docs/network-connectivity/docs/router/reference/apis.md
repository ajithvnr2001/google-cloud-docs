# APIs and reference

To work with Cloud Router by using APIs or Google Cloud CLI commands, you use the `Router` resource type. The relevant APIs and commands are part of Compute Engine.

For more information, see the following:

  * [API `Router` resource](https://docs.cloud.google.com/compute/docs/reference/latest/routers)

  * [`gcloud compute routers`](https://docs.cloud.google.com/sdk/gcloud/reference/compute/routers)




## What's next
