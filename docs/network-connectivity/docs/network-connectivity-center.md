# Network Connectivity Center documentation

[Read product documentation](https://docs.cloud.google.com/network-connectivity/docs/network-connectivity-center/concepts/overview)

Network Connectivity Center lets you use a hub-and-spoke architecture for network connectivity management. With this architecture, you can conduct data transfer between your sites. NCC lets you create VPC spokes to connect VPC networks together using various topologies. You can use NCC Gateway spokes to enable security functions such as third-party Security Service Edge (SSE). NCC also includes the Router appliance feature, which lets you use a third-party network virtual appliance to establish site-to-site or site-to-cloud connectivity.
