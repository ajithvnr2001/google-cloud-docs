#  APIs and reference Stay organized with collections  Save and categorize content based on your preferences. 

The Cloud Interconnect API and `gcloud` commands are part of Compute Engine.

Cloud Interconnect provides the following API resource types and their methods in the Compute Engine documentation:

  * [`interconnects`](https://docs.cloud.google.com/compute/docs/reference/latest/interconnects)
  * [`interconnectAttachments`](https://docs.cloud.google.com/compute/docs/reference/latest/interconnectAttachments)
  * [`interconnectLocations`](https://docs.cloud.google.com/compute/docs/reference/latest/interconnectLocations)
  * [`crossSiteNetworks`](https://docs.cloud.google.com/compute/docs/reference/rest/beta/crossSiteNetworks)
  * [`wireGroups`](https://docs.cloud.google.com/compute/docs/reference/rest/beta/wireGroups)



For more information about the `gcloud` commands, see [`gcloud compute interconnects`](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects) in the Google Cloud CLI documentation.
