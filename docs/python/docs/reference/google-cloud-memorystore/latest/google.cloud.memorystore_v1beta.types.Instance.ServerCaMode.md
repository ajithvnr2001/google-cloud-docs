## Enums  
  
---  
**Name** | **Description**  
`SERVER_CA_MODE_UNSPECIFIED` | Server CA mode not specified.  
`GOOGLE_MANAGED_PER_INSTANCE_CA` | Each instance has its own Google-managed CA.
