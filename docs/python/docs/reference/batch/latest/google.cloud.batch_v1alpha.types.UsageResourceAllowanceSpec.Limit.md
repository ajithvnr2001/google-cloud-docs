**Name** | **Description**  
`calendar_period` |  `[google.cloud.batch_v1alpha.types.CalendarPeriod](https://docs.cloud.google.com/python/docs/reference/batch/latest/google.cloud.batch_v1alpha.types.CalendarPeriod)`   
Optional. A CalendarPeriod represents the abstract concept of a time period that has a canonical start. This field is a member of `oneof`_ `duration`.   
`limit` |  `float`   
Required. Limit value of a UsageResourceAllowance within its one duration. Limit cannot be a negative value. Default is 0. For example, you can set `limit` as 10000.0 with duration of the current month by setting `calendar_period` field as monthly. That means in your current month, 10000.0 is the core hour limitation that your resources are allowed to consume. This field is a member of `oneof`_ `_limit`.
