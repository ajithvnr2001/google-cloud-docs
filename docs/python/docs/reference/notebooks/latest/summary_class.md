This class thinly wraps an initial [ListInstancesResponse](https://docs.cloud.google.com/python/docs/reference/notebooks/latest/google.cloud.notebooks_v2.types.ListInstancesResponse) object, and provides an `__aiter__` method to iterate through its `instances` field.

All the usual [ListInstancesResponse](https://docs.cloud.google.com/python/docs/reference/notebooks/latest/google.cloud.notebooks_v2.types.ListInstancesResponse) attributes are available on the pager. If multiple requests are made, only the most recent response is retained, and thus used for attribute lookup.
