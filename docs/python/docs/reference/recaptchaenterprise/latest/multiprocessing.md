**NOTE** : Because this client uses [`grpc`](https://grpc.github.io/grpc/python/grpc.html#module-grpc) library, it is safe to share instances across threads. In multiprocessing scenarios, the best practice is to create client instances _after_ the invocation of [`os.fork()`](https://docs.python.org/3/library/os.html#os.fork) by [`multiprocessing.pool.Pool`](https://docs.python.org/3/library/multiprocessing.html#multiprocessing.pool.Pool) or [`multiprocessing.Process`](https://docs.python.org/3/library/multiprocessing.html#multiprocessing.Process).
