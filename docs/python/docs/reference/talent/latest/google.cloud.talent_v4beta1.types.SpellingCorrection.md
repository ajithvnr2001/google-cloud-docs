## Attributes  
  
---  
**Name** | **Description**  
`corrected` |  `bool`   
Indicates if the query was corrected by the spell checker.   
`corrected_text` |  `str`   
Correction output consisting of the corrected keyword string.   
`corrected_html` |  `str`   
Corrected output with html tags to highlight the corrected words. Corrected words are called out with the "**_..._** " html tags. For example, the user input query is "software enginear", where the second word, "enginear," is incorrect. It should be "engineer". When spelling correction is enabled, this value is "software **_engineer_** ".
