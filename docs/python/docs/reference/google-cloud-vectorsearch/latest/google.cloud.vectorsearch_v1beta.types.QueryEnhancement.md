Query enhancement settings. When enabled, expands the search terms with stemming, synonyms, and spelling corrections, and removes stop words.

## Attributes  
  
---  
**Name** | **Description**  
`enabled` |  `bool`   
Optional. Whether query enhancement is enabled.   
`language_code` |  `str`   
Optional. The IETF BCP 47 language tag, such as "en-US", for query enhancement. If unset, the language is detected automatically. See https://en.wikipedia.org/wiki/IETF_language_tag.
