Retrieve a single unit kind.

### HTTP request

`GET https://saasservicemgmt.googleapis.com/v1/{name=projects/*/locations/*/unitKinds/*}`

The URL uses [gRPC Transcoding](https://google.aip.dev/127) syntax.

### Path parameters

Parameters  
---  
`name` |  `string` Required. The resource name of the resource within a service.  
  
### Request body

The request body must be empty.

### Response body

If successful, the response body contains an instance of `[UnitKind](https://docs.cloud.google.com/app-lifecycle-manager/reference/rest/v1/projects.locations.unitKinds#UnitKind)`.

### Authorization scopes

Requires the following OAuth scope:

  * `https://www.googleapis.com/auth/cloud-platform`



For more information, see the [Authentication Overview](https://docs.cloud.google.com/docs/authentication#authorization-gcp).

### IAM Permissions

Requires the following [IAM](https://cloud.google.com/iam/docs) permission on the `name` resource:

  * `saasservicemgmt.unitKinds.get`



For more information, see the [IAM documentation](https://cloud.google.com/iam/docs).
