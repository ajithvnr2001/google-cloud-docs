## April 22, 2026

Announcement

SaaS Runtime is now App Lifecycle Manager. You can use Application Design Center to model your App offering, and App Lifecycle Manager to manage and provision your applications.

For more information, see [App Lifecycle Manager overview](https://docs.cloud.google.com/saas-runtime/docs/overview).

Feature

You can use the [App Lifecycle Manager remote Model Context Protocol (MCP)](https://docs.cloud.google.com/saas-runtime/docs/use-app-lifecycle-manager-mcp) server to connect with AI applications including Gemini, ChatGPT, Claude, and custom applications.

## March 10, 2026

Feature

See [Quotas and limits](https://docs.cloud.google.com/saas-runtime/docs/quotas) for SaaS Runtime.

Feature

Use [SaaS Runtime feature flags](https://docs.cloud.google.com/saas-runtime/docs/flags/flags-overview) to control the availability and behavior of features within your applications, without requiring new code deployments or infrastructure changes.

## March 01, 2026

Feature

SaaS Runtime supports [rollout strategies](https://docs.cloud.google.com/saas-runtime/docs/update-saas-offering) to manage how units in your App offering are updated. Strategies include:

  * One location at a time (simple)
  * All at once (simple)
  * Progressive (gradual)
  * Progressive (single location)



## February 01, 2026

Feature

Delete your SaaS Runtime resources using Google Cloud Console. For more information, see [Delete a SaaS Runtime resource](https://docs.cloud.google.com/saas-runtime/docs/delete-resources).

## January 26, 2026

Feature

SaaS Runtime supports VPCSC, providing additional security for your resources.

## April 09, 2025

Announcement

[SaaS Runtime](https://docs.cloud.google.com/app-lifecycle-manager) is available in [Preview](https://cloud.google.com/products#product-launch-stages).

SaaS Runtime lets you store, host, manage, and monitor software as a service (SaaS) applications on Google Cloud. 

To get started with SaaS Runtime: 

  * [Familiarize yourself](https://docs.cloud.google.com/app-lifecycle-manager/overview) with the SaaS Runtime ecosystem.
  * [Create an App offering](https://docs.cloud.google.com/app-lifecycle-manager/create-saas-offering).
  * [Try the quickstart](https://docs.cloud.google.com/app-lifecycle-manager/deploy-sql) to learn how to deploy a service instance using SaaS Runtime.
