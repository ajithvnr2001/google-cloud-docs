# Feature deprecations

Google Cloud's [terms of service (section 7)](https://cloud.google.com/terms/) define the deprecation policy that applies to Bigtable. The deprecation policy only applies to the features or services on the list of [services subject to the deprecation policy](https://cloud.google.com/terms/deprecation).

Once a Bigtable feature has been officially deprecated, the feature continues to be available for at least the period of time defined in the [terms of service](https://cloud.google.com/terms/). After this period of time, the feature or service will be scheduled for shutdown.

The following table lists Bigtable features that were deprecated and have been shut down.

Feature (status) | Deprecated | Shutdown Date | Details  
---|---|---|---  
v1 API | January 31, 2020 | January 31, 2021 | [ Service shutdown complete](https://docs.cloud.google.com/bigtable/docs/deprecations/v1-api-shutdown).   
The v1 API was replaced by the [ v2 data and admin API.](https://docs.cloud.google.com/bigtable/docs/reference/service-apis-overview)
