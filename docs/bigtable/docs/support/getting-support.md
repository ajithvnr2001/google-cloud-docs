# Get support

Use the following resources to request support for Bigtable.

## Ask a development question

We support developers using Bigtable on Stack Overflow. Google engineers monitor and answer questions with the tag `google-cloud-bigtable`. Use this tag when asking questions. We try to answer all questions within a reasonable amount of time.

  * [Ask a question](http://stackoverflow.com/questions/ask?tags=google-cloud-bigtable)
  * [View all questions](http://stackoverflow.com/questions/tagged/google-cloud-bigtable)



## Download code samples

We've created a variety of code samples to help you get started with Bigtable. Code samples for Bigtable are available in the following GitHub repositories:

  * C#: [GoogleCloudPlatform/dotnet-docs-samples](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/tree/master/bigtable/api)
  * C++: [googleapis/google-cloud-cpp](https://github.com/googleapis/google-cloud-cpp/tree/49df3b020dc714ee41aaea19b4d7dc5c677fe600/google/cloud/bigtable/examples)
  * Go: [GoogleCloudPlatform/golang-samples](https://github.com/GoogleCloudPlatform/golang-samples/tree/master/bigtable)
  * HBase client for Java and Dataflow connector:

    * [GoogleCloudPlatform/cloud-bigtable-examples](https://github.com/GoogleCloudPlatform/cloud-bigtable-examples//tree/master/java)
    * [GoogleCloudPlatform/java-docs-samples](https://github.com/GoogleCloudPlatform/java-docs-samples/tree/master/appengine-java8/bigtable)
  * Java: [googleapis/google-cloud-java](https://github.com/googleapis/google-cloud-java/tree/main/java-bigtable/samples/snippets/src/main/java/com/example/bigtable)
  * Node.js: [googleapis/nodejs-bigtable](https://github.com/googleapis/nodejs-bigtable/blob/master/samples)
  * PHP: [GoogleCloudPlatform/php-docs-samples](https://github.com/GoogleCloudPlatform/php-docs-samples/tree/8721645c69fa2d390579ff251f73198334ca5f01/bigtable)
  * Python: [googleapis/python-bigtable](https://github.com/googleapis/python-bigtable/tree/master/samples)
  * Ruby: [googleapis/google-cloud-ruby](https://github.com/googleapis/google-cloud-ruby/tree/main/google-cloud-bigtable/samples)



## Get a support package

Google Cloud offers various levels of support packages depending on your needs. Support packages include features such as 24/7 coverage, phone support, and access to a technical account manager. For more information, see [Google Cloud Support](https://docs.cloud.google.com/support).

## Receive announcements and notifications

  * Bigtable feature announcements and service disruption notifications: [google-cloud-bigtable-announce](https://groups.google.com/forum/#!forum/google-cloud-bigtable-announce)
  * Bigtable general discussion: [google-cloud-bigtable-discuss](https://groups.google.com/forum/#!forum/google-cloud-bigtable-discuss)



## Discuss Bigtable

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Bigtable and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). For Bigtable, join the [`#cloud-bigtable`](https://googlecloud-community.slack.com/messages/C0DFMMX8X/) channel.

## File feature requests and bug reports

File new feature requests and bug reports in the following GitHub repositories:

  * C# client library: [googleapis/google-cloud-dotnet](https://github.com/googleapis/google-cloud-dotnet/issues)
  * C++ client library: [googleapis/google-cloud-cpp](https://github.com/googleapis/google-cloud-cpp/issues)
  * Go client library: [GoogleCloudPlatform/google-cloud-go](https://github.com/GoogleCloudPlatform/google-cloud-go/issues)
  * HBase client for Java and the Bigtable HBase Beam connector: [googleapis/java-bigtable-hbase](https://github.com/googleapis/java-bigtable-hbase/issues)
  * Java (Bigtable client library for Java): [googleapis/google-cloud-java](https://github.com/googleapis/google-cloud-java/issues)
  * Node.js client library: [googleapis/nodejs-bigtable](https://github.com/googleapis/google-cloud-node/issues)
  * PHP client library: [googleapis/google-cloud-php](https://github.com/googleapis/google-cloud-php/issues)
  * Python and HappyBase client libraries: [GoogleCloudPlatform/google-cloud-python](https://github.com/googleapis/google-cloud-python/issues)
  * Ruby client library: [googleapis/google-cloud-ruby](https://github.com/googleapis/google-cloud-ruby/issues)



You can also file new feature requests and bug reports using the [Bigtable issue tracker](https://issuetracker.google.com/issues/new?component=187206&template=0).
