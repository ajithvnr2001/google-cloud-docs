#  Google Cloud infrastructure reliability: What's next Stay organized with collections  Save and categorize content based on your preferences. 

Last reviewed 2026-09-23 UTC

This page provides links to reliability-focused documentation that supplements the architectural guidance in the [Google Cloud infrastructure reliability guide](https://docs.cloud.google.com/architecture/infra-reliability-guide).

  * [Design scalable and resilient applications](https://docs.cloud.google.com/architecture/scalable-and-resilient-apps).

Patterns and best practices for building cloud applications that are resilient and scalable.

  * [Mitigate ransomware attacks using Google Cloud](https://docs.cloud.google.com/docs/security/mitigating-ransomware-attacks).

Best practices to help you identify, prevent, detect, and respond to ransomware attacks.

  * [Plan for disaster recovery (DR)](https://docs.cloud.google.com/architecture/dr-scenarios-planning-guide).

A series of documents that focus on designing for DR in the cloud.

  * [Google Cloud Well-Architected Framework: Reliability pillar](https://docs.cloud.google.com/architecture/framework/reliability).

Principles and recommendations to help you build, deploy, and operate reliable and resilient workloads on Google Cloud.

  * [Learn about Google Cloud deployment archetypes](https://docs.cloud.google.com/architecture/deployment-archetypes).

Describes the following six deployment archetypes: zonal, regional, multi-regional, global, hybrid, and multicloud. It also presents Google Cloud-specific design considerations for each deployment archetype.

  * [Learn how Google Cloud manages changes](https://docs.cloud.google.com/docs/cloud-approach-to-change).

Explains how Google Cloud teams apply reliability best practices and engineering standards to develop and release changes to our platform and services.
