Last reviewed 2025-11-25 UTC

This document provides an overview of architecture guides to design, build, and deploy AI and ML applications.

To help you find the right guidance that's relevant to your persona and needs, we provide the following types of architecture guides:

  * **Design guides** : Prescriptive, cross-product guidance to help you plan and design your cloud architecture.
  * **Reference architectures** : Detailed architecture examples and design recommendations for specific workloads.
  * **Use cases** : High-level architecture examples to solve specific business problems.
  * **Deployment guides** : Step-by-step instructions or code to deploy a specific architecture.



## Agentic AI

[Agentic AI applications](https://cloud.google.com/discover/what-is-agentic-ai) solve open-ended problems through autonomous planning and multi-step workflows.

To build agentic AI applications on Google Cloud, start with the following guides:

  * Design guide: [Choose your agentic AI architecture components](https://docs.cloud.google.com/architecture/choose-agentic-ai-architecture-components)
  * Design guide: [Choose a design pattern for your agentic AI system](https://docs.cloud.google.com/architecture/choose-design-pattern-agentic-ai-system)
  * Reference architecture: [Multi-agent AI system in Google Cloud](https://docs.cloud.google.com/architecture/multiagent-ai-system)
  * Reference architecture: [Single-agent AI system using ADK and Cloud Run](https://docs.cloud.google.com/architecture/single-agent-ai-system-adk-cloud-run)



Explore more [agentic AI architecture guides](https://docs.cloud.google.com/architecture/agentic-ai-overview).

## Generative AI

[Generative AI](https://docs.cloud.google.com/docs/generative-ai) applications let use AI to create summaries, uncover complex hidden correlations, or generate new content.

To build generative AI applications on Google Cloud, start with the following guides:

  * Design guide: [Deploy and operate generative AI applications](https://docs.cloud.google.com/architecture/deploy-operate-generative-ai-applications)
  * Design guide: [Choose models and infrastructure for your generative AI application](https://docs.cloud.google.com/docs/generative-ai/choose-models-infra-for-ai)
  * Reference architectures: [Generative AI with RAG](https://docs.cloud.google.com/architecture/rag-reference-architectures)



Explore more [generative AI architecture guides](https://docs.cloud.google.com/architecture/genai-overview).

## ML applications and operations

Robust machine learning operations (MLOps) is the foundation for every AI initiative, from classification and regression models to complex generative AI and agentic AI systems.

To build and operate ML applications on Google Cloud, start with the following guides:

  * Design guide: [Best practices for implementing machine learning on Google Cloud](https://docs.cloud.google.com/architecture/ml-on-gcp-best-practices)
  * Blueprint: [Build and deploy generative AI and machine learning models in an enterprise](https://docs.cloud.google.com/architecture/blueprints/genai-mlops-blueprint#whats_next)
  * Reference architecture: [Build an ML vision analytics solution with Dataflow and Cloud Vision API](https://docs.cloud.google.com/architecture/building-a-vision-analytics-solution)
  * Reference architecture: [Cross-silo and cross-device federated learning on Google Cloud](https://docs.cloud.google.com/architecture/cross-silo-cross-device-federated-learning-google-cloud)



Explore more [ML applications and operations architecture guides](https://docs.cloud.google.com/architecture/ai-ml/ml-application-operations-architecture-guides).

## AI and ML infrastructure

The performance, cost, and scalability of your AI and ML applications depend directly on the underlying infrastructure. Each stage of the ML lifecycle has unique requirements for compute, storage, and networking.

The following resources help you design and select an appropriate infrastructure for your AI and ML workloads:

  * Design guide: [Design storage for AI and ML workloads in Google Cloud](https://docs.cloud.google.com/architecture/ai-ml/storage-for-ai-ml)
  * Reference architecture: [Optimize AI and ML workloads with Cloud Storage FUSE](https://docs.cloud.google.com/architecture/optimize-ai-ml-workloads-cloud-storage-fuse)
  * Reference architecture: [Optimize AI and ML workloads with Google Cloud Managed Lustre](https://docs.cloud.google.com/architecture/optimize-ai-ml-workloads-managed-lustre)
