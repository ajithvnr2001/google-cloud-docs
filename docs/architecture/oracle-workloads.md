This page in the Architecture Center lists reference architectures to deploy Oracle and other enterprise applications with Oracle databases in Google Cloud.

**Select the application and database that you want to deploy** : 

Select an applicationOracle E-Business SuiteOracle PeopleSoftOther enterprise applicationsSelect a databaseOracle Database on Compute EngineOracle ExadataApplication | Database | Reference architecture  
---|---|---  
Oracle E-Business Suite | Oracle Database on Compute Engine | [Oracle E-Business Suite with Oracle Database on Compute Engine](https://docs.cloud.google.com/architecture/oracle-ebs-on-compute-engine-vm) Build infrastructure to run Oracle E-Business Suite applications with Oracle Database on Compute Engine VMs in Google Cloud.  
Oracle E-Business Suite | Oracle Exadata | [Oracle E-Business Suite on Compute Engine with Oracle Exadata](https://docs.cloud.google.com/architecture/oracle-ebs-with-oci-exadata) Build infrastructure to run Oracle E-Business Suite applications on Compute Engine VMs with low-latency connectivity to OCI Exadata databases that run within Google Cloud.  
Oracle PeopleSoft | Oracle Exadata | [Oracle PeopleSoft on Compute Engine with Oracle Exadata](https://docs.cloud.google.com/architecture/oracle-peoplesoft-with-oci-exadata) Build infrastructure to run PeopleSoft applications on Compute Engine VMs with low-latency connectivity to OCI Exadata databases that run within Google Cloud.  
Other enterprise applications | Oracle Database on Compute Engine | [Enterprise application with Oracle Database on Compute Engine](https://docs.cloud.google.com/architecture/enterprise-app-oracle-database-compute-engine) Build infrastructure to host a highly available enterprise application that uses an Oracle database, with the entire stack deployed on Compute Engine VMs.  
Other enterprise applications | Oracle Exadata | [Enterprise application on Compute Engine with Oracle Exadata](https://docs.cloud.google.com/architecture/enterprise-app-oracle-exadata-database-compute-engine) Build infrastructure to host a highly available enterprise application that runs on Compute Engine VMs with low-latency connectivity to OCI Exadata databases that run within Google Cloud.
