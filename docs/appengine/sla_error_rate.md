# App Engine error rates

The Error Rate for the SLA is defined in the following table. Capitalized terms not defined herein have the meaning set forth in the Agreement. New components may be added to this page with their respective errors. Any changes will be made in accordance with the Agreement.

Component | Error | Total calls | Date added  
---|---|---|---  
Serving Infrastructure | HTTP Request sent to App Engine that results in an INTERNAL_SERVING_ERROR | The total number of HTTP requests sent to App Engine | Oct 10, 2011  
Search | Search API search call returning one of the following errors: TRANSIENT_ERROR, INTERNAL_ERROR | The total number of Search API calls | Aug 27, 2013  
  
To diagnose and resolve SLA error rate issues, see Troubleshooting [App Engine standard environment](https://docs.cloud.google.com/appengine/docs/standard/troubleshooting) or [App Engine flexible environment](https://docs.cloud.google.com/appengine/docs/flexible/troubleshooting) errors.
