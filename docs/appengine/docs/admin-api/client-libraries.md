You can build client libraries to interact with the Admin API or use the pre-built libraries for any of the available programming languages.

## Building client libraries

Use both the Google API Discovery Service and the discovery document of the App Engine Admin API to build a client library. See [Google API Discovery Service](https://developers.google.com/discovery/v1/using#build) for information about using the [discovery document of the Admin API](https://www.googleapis.com/discovery/v1/apis/appengine/v1/rest) to build the client library.

## Client libraries for Google APIs

See [Google API Client Libraries](https://developers.google.com/api-client-library/) for information about the pre-built client libraries and all the available programming languages.

You can use any of the Google API Client Libraries to interact with the App Engine Admin API but the following languages have Admin API specific pages or instructions to help you get up and running with the client library:

  * [C++](https://docs.cloud.google.com/cpp/docs/reference/appengine/latest)
  * [Java](https://docs.cloud.google.com/api-client-library/java/apis/appengine/v1)
  * [.NET](https://docs.cloud.google.com/api-client-library/dotnet/apis/appengine/v1)
  * [PHP](https://docs.cloud.google.com/api-client-library/php/start/get_started#google-app-engine-support)
  * [Python](https://docs.cloud.google.com/api-client-library/python/apis/appengine/v1)
  * [Ruby](https://docs.cloud.google.com/api-client-library/ruby/apis/appengine/v1)
