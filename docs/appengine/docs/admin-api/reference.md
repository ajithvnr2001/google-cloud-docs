## Google App Engine Admin API

### Overview

The Google App Engine Admin API is a RESTful API for managing App Engine applications. The Admin API provides programmatic access to several of the App Engine administrative operations that are found in the [Google Cloud Platform Console](https://console.cloud.google.com/appengine).
