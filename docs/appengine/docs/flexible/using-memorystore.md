#  Caching data with Memorystore Stay organized with collections  Save and categorize content based on your preferences. 

High performance scalable web applications often use a distributed in-memory data cache in front of or in place of robust persistent storage for some tasks. We recommend using Memorystore for Redis as your caching service. Note that **Memorystore for Redis does not provide a free tier**.

For more information, see the following pages:

  * [Overview of Cloud Memorystore for Redis](https://docs.cloud.google.com/memorystore/docs/redis/redis-overview)

  * [Connecting to a Redis instance from an App Engine flexible environment application](https://docs.cloud.google.com/memorystore/docs/redis/connect-redis-instance-flex)

  * [Memorystore Pricing](https://cloud.google.com/memorystore/pricing)
