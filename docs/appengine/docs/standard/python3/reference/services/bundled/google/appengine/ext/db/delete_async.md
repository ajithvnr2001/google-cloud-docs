    google.appengine.ext.db.delete_async(

Asynchronous version of delete one or more `Model` instances. Identical to [`db.delete()`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/ext/db/delete) except returns an asynchronous object. Call `get_result()` on the return value to block on the call.
