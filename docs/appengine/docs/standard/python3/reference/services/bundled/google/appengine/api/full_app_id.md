Not to be confused with [`google.appengine.api.app_identity.get_application_id()`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/app_identity/get_application_id) which gets a "display" app ID.

## Functions

[`clear(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/full_app_id/clear): Unset the application ID in the environment. [`get(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/full_app_id/get): Get the application ID from the environment. [`normalize(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/full_app_id/normalize): Normalize the environment variables which set the app ID. [`parse(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/full_app_id/parse): Parses a full app ID into `partition`, `domain_name`, and `display_app_id`. [`project_id(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/full_app_id/project_id): Parses the domain prefixed project ID from the app_id. [`put(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/full_app_id/put): Set the application ID in the environment.
