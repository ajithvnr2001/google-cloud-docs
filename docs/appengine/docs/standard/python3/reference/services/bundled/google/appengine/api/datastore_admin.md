## Functions

[`CreateIndex(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_admin/CreateIndex): Creates a new composite index in the datastore for this app. [`DeleteIndex(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_admin/DeleteIndex): Deletes an index. The entire index definition must be present. [`GetIndices(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_admin/GetIndices): Fetches all composite indices in the datastore for this app. [`UpdateIndex(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_admin/UpdateIndex): Updates an index's status. The entire index definition must be present.
