## Classes

[`class BadArgumentError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/BadArgumentError): Raised by [`Query.Order()`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore/Query#Order), `Iterator.Next()`, and others when they're passed an invalid argument. [`class BadFilterError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/BadFilterError): Raised by `Query.__setitem__()` and [`Query.Run()`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore/Query#Run) when a filter string is invalid. [`class BadKeyError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/BadKeyError): Raised by `Key.__str__` when the key is invalid. [`class BadPropertyError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/BadPropertyError): Raised by `Entity.__setitem__()` when a property name isn't a string. [`class BadQueryError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/BadQueryError): Raised by `Query` when a query or query string is invalid. [`class BadValueError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/BadValueError): Raised by `Entity.__setitem__()`, `Query.__setitem__()`, `Get()`, and others. [`class CommittedButStillApplying`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/CommittedButStillApplying): The write or transaction was committed, but some entities or index rows may not have been fully updated. [`class EntityNotFoundError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/EntityNotFoundError): DEPRECATED: Raised by `Get()` when the requested entity is not found. [`class Error`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/Error): Base datastore error type. [`class InternalError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/InternalError): An internal datastore error. Please report this to Google. [`class NeedIndexError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/NeedIndexError): No matching index was found for a query that requires an index. [`class QueryNotFoundError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/QueryNotFoundError): DEPRECATED: Raised by Iterator methods when the Iterator is invalid. [`class ReferencePropertyResolveError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/ReferencePropertyResolveError): An error occurred while trying to resolve a `ReferenceProperty`. [`class Rollback`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/Rollback): May be raised by transaction functions when they want to roll back instead of committing. [`class SnapshotVersionTooOldError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/SnapshotVersionTooOldError): Raised by `Query` when a snapshot is too old and no longer exists. [`class Timeout`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/Timeout): The datastore operation timed out, or the data was temporarily unavailable. [`class TransactionFailedError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/TransactionFailedError): Raised by `RunInTransaction` methods when the transaction could not be committed, even after retrying. [`class TransactionNotFoundError`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/datastore_errors/TransactionNotFoundError): DEPRECATED: Raised by `RunInTransaction`.
