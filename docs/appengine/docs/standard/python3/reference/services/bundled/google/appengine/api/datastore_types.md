#### View aliases

**Main aliases** `google.appengine.api.datastore.datastore_types` These types are expected to be set as attributes of `Entities`. Most of these types are based on XML elements from Atom and GData elements from the `atom` and `gd` namespaces. For more information, see:

  * http://www.atomenabled.org/developers/syndication/
  * https://developers.google.com/gdata/docs/1.0/elements

The namespace schemas are:

  * http://www.w3.org/2005/Atom
  * http://schemas.google.com/g/2005
