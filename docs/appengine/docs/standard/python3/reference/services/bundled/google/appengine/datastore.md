[`datastore_pbs`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/datastore/datastore_pbs) module: Utilities for converting between v3 and v1 datastore protocol buffers. [`datastore_query`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/datastore/datastore_query) module: A thin wrapper around datastore query RPC calls. [`datastore_stub_util`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/datastore/datastore_stub_util) module: Utility functions shared between the file and sqlite datastore stubs. [`datastore_v4_stub`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/datastore/datastore_v4_stub) module: Implementation of the datastore_v4 API that forwards to the v3 service. [`datastore_v4_validator`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/datastore/datastore_v4_validator) module: Validators for v4 datastore protocol buffers. [`sortable_pb_encoder`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/datastore/sortable_pb_encoder) module: An Encoder class for protocol buffers (PB) that preserves sorting characteristics.
