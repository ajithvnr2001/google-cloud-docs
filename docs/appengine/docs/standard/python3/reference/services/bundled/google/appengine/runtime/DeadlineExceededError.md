Inherits From: [`expected_type`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/validation/Validator/expected_type) This exception will be thrown by the original thread handling the request, shortly after the request reaches its deadline. Since the exception is asynchronously set on the thread by the App Engine runtime, it can appear to originate from any line of code that happens to be executing at that time. If the application catches this exception and does not generate a response very quickly afterwards, an error will be returned to the user and the application instance may be terminated. Not to be confused with runtime.apiproxy_errors.DeadlineExceededError. That one is raised when individual API calls take too long.
