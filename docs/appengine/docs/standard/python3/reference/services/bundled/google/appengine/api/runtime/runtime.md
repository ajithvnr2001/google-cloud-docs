## Functions

[`cpu_usage(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/runtime/cpu_usage): Returns a SystemStat describing cpu usage, expressed in mcycles. [`is_shutting_down(...)`](https://docs.cloud.google.com/appengine/docs/standard/python3/reference/services/bundled/google/appengine/api/runtime/is_shutting_down): Returns true if the server is shutting down.
