View when previous App Engine features were shut down.

See the list of [App Engine features that are scheduled for deprecation](https://docs.cloud.google.com/appengine/docs/standard/deprecations).

Feature | Deprecated | Shutdown date | Details  
---|---|---|---  
Spending limits | July 24, 2020 | July 1, 2023 | Service shutdown complete. For information about other mechanisms to manage costs, see [Manage App Engine costs](https://docs.cloud.google.com/appengine/docs/standard/managing-costs).  
DoS Protection Service | October 11, 2017 | Apr 29, 2022 | DoS rules have been auto-migrated to [App Engine Firewall](https://docs.cloud.google.com/appengine/docs/standard/creating-firewalls).  
The standalone legacy SDK and `appcfg` tooling | July 30, 2019 | August 30, 2020 | Service shutdown complete; Migrate to Google Cloud CLI ([Java](https://docs.cloud.google.com/appengine/docs/legacy/standard/java/sdk-gcloud-migration) | [Go](https://docs.cloud.google.com/appengine/docs/legacy/standard/go111/sdk-gcloud-migration) | [Python](https://docs.cloud.google.com/appengine/docs/legacy/standard/python/sdk-gcloud-migration) | [PHP](https://docs.cloud.google.com/appengine/docs/legacy/standard/php/sdk-gcloud-migration))  
Go 1.9 (GA) | June 27, 2019 | June 30, 2020 | On June 30, 2020, applications still running on unsupported versions of Go will be shut down. Legacy health checks for the App Engine flexible environment (GA) | September 18, 2017 | September 30, 2018 | [Legacy health checks](https://docs.cloud.google.com/appengine/docs/flexible/reference/app-yaml#legacy_health_checks)  
Cloud Endpoints Frameworks v1 | August 2, 2017 | September 13, 2018 | Service shutdown complete
