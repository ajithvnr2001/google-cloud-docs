You can use the Cloud Tasks client library to run tasks in App Engine. For a more detailed overview, see [Understand Cloud Tasks](https://docs.cloud.google.com/tasks/docs/dual-overview) in the Cloud Tasks documentation.

To run asynchronous tasks, you can:

  * Create Cloud Tasks queues, see [Create Cloud Tasks queues](https://docs.cloud.google.com/tasks/docs/creating-queues).

  * Create App Engine tasks in the form of an HTTP request and then place them in Cloud Tasks queues, see [Create App Engine tasks](https://docs.cloud.google.com/tasks/docs/creating-appengine-tasks).
