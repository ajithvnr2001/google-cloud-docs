Use the following steps to set up your local environment for developing and deploying your App Engine services:

  1. Install the latest release of Python 3.

See [Python 3 runtime environment](https://docs.cloud.google.com/appengine/docs/standard/python3/runtime) for a list of the supported versions.

  2. Install and initialize the [gcloud CLI](https://docs.cloud.google.com/sdk/docs/install) for deploying and managing your apps. If you already have the gcloud CLI installed and initialized, run the [`gcloud components update`](https://docs.cloud.google.com/sdk/gcloud/reference/components/update) command to update to the latest release. By downloading, you agree to be bound by the [Terms](https://cloud.google.com/terms) that govern use of the gcloud CLI for App Engine.




**Optional tools** :

  * [Install Git](https://git-scm.com/download/) for access to code, samples, libraries, and tools in the [Google Cloud GitHub](https://github.com/GoogleCloudPlatform) repository. 

  * Install your preferred tooling or framework, for example you can use any of the following frameworks to develop your Python 3 app: 
    * [Flask](http://flask.pocoo.org/)
    * [Django](https://www.djangoproject.com)
    * [Pyramid](http://www.pylonsproject.org/)
    * [Bottle](http://bottlepy.org/)
    * [web.py](http://webpy.org/)
    * [Tornado](http://www.tornadoweb.org/)
