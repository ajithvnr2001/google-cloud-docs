The flexible environment runs your applications within Docker containers on Compute Engine virtual machines (VM). Your application code can be written in a version of any of the supported programming languages.

[Learn more in the overview of the flexible environment documentation](https://docs.cloud.google.com/appengine/docs/flexible).
