# Control Dataflow logging

Depending on how you use Manufacturing Data Engine (MDE) there can be a lot of logs generated by the Dataflow jobs. You can control the volume of Dataflow logs ingested by Cloud Logging by following the [Filter logs documentation](https://docs.cloud.google.com/dataflow/docs/guides/filter-logs).
