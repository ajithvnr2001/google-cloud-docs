# Upload configuration package

This guide introduces the upload configuration package.

Starting on v1.5.0 Manufacturing Data Engine (MDE) allows uploading a whole configuration, including all the MDE entities to an existing deployment.

If you have a backup configuration, an integration partner has created a configuration for you, or if you are migrating to a new MDE deployment, you can use this configuration package to upload the configuration.

For information, see [Configuration packages](https://docs.cloud.google.com/manufacturing-data-engine/docs/guides/configuration/format).
