The Device Streaming API lets you securely connect to remote physical Android devices hosted in Google's secure data centers. It allows you to test your app against some of the latest Android devices on demand. ​​You can interact with your app on a real remote device as if it is connected to your local machine. 

To get started, [use the Device Streaming API in Android Studio](https://developer.android.com/studio/run/android-device-streaming) and the coding agent of your choice with the [DDP Agent Skill](https://docs.cloud.google.com/developer-device-platform/agent-skill).
