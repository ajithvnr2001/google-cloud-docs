The Developer Device Platform is a next-generation, commercial-grade platform for remote device orchestration. It provides a managed device farm for developers to build and test applications using remote infrastructure, natively integrating with Google Cloud.

The **Device Streaming API** provides real-time, interactive access to remote physical Android devices for live debugging, testing, and streaming across physical device catalogs.

#### Key Features

  * **Physical Device Access** : Securely access real physical Android devices—including Google Pixel models and partner devices from Samsung, Xiaomi, OPPO, OnePlus, vivo, and Transsion—to deploy and test applications remotely.
  * **Direct ADB over SSL** : Establish direct ADB over SSL connections for real-time device interaction (screen manipulation, rotation, unfolding) and native integration with developer tooling, Debugger, Profiler, Logcat, and Device Explorer.
  * **Automated Security & Privacy**: Automatic data wiping and factory resets are performed after every session to protect developer data and maintain device security.
  * **Google Cloud Integration** : Fully integrated with Cloud Logging, Cloud IAM, and Google Cloud billing.



For more details, see the [Developer Device Platform documentation](https://docs.cloud.google.com/developer-device-platform).
