# Memorystore for Memcached maintenance changelogs  |  Google Cloud Documentation

> Source: https://docs.cloud.google.com/memorystore/docs/memcached/maintenance-changelog/

Memorystore for Memcached is being deprecated and will be shut down on January 31, 2029. After February 1, 2027, you can't create Memorystore for Memcached instances in new projects unless these instances already exist in these projects. We recommend that you migrate your workloads to [Memorystore for Valkey](https://docs.cloud.google.com/memorystore/docs/valkey), which offers superior performance and features.

#  Memorystore for Memcached maintenance changelogs Stay organized with collections  Save and categorize content based on your preferences. 

This page contains a log of maintenance changes. Memorystore for Memcached releases maintenance updates for new features, security patches, bug fixes, and performance improvements.

You can perform maintenance updates by using [self-service maintenance](https://docs.cloud.google.com/memorystore/docs/memcached/self-service-maintenance). Memorystore for Memcached also performs scheduled maintenance updates once every few months. You can set windows for when maintenance updates occur. For more information, see [Find and set maintenance windows](https://docs.cloud.google.com/memorystore/docs/memcached/find-and-set-maintenance-windows).

To view the maintenance version, use the [`gcloud memcache instances describe`](https://docs.cloud.google.com/sdk/gcloud/reference/memcache/instances/describe) command. The maintenance version appears next to the `effectiveMaintenanceVersion` parameter. For more information, see [View instance information](https://docs.cloud.google.com/memorystore/docs/memcached/create-manage-instances#viewing_instance_information). Also, to learn more about maintenance updates, see [About maintenance](https://docs.cloud.google.com/memorystore/docs/memcached/about-maintenance).

To get the latest maintenance changes, add the URL for the [XML file](https://docs.cloud.google.com/static/feeds/memorystore-for-memcached-maintenance-changelog.xml) of the maintenance changelog for Memorystore for Memcached to your feed reader.
