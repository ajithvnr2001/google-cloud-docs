# Memorystore for Redis documentation

[Read product documentation](https://docs.cloud.google.com/memorystore/docs/redis/redis-overview)

Memorystore for Redis is a fully managed Redis service for Google Cloud. Applications running on Google Cloud can achieve extreme performance by leveraging the highly scalable, available, secure Redis service without the burden of managing complex Redis deployments.

Memorystore for Redis is based on and is compatible with open-source Redis versions 7.2 and earlier and supports a subset of the total Redis command library.
