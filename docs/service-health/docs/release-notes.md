This page documents production updates to Personalized Service Health. Check this page for announcements about new or updated features, bug fixes, known issues, and deprecated functionality.

You can see the latest product updates for all of Google Cloud on the [ Google Cloud](https://docs.cloud.google.com/release-notes) page, browse and filter all release notes in the [Google Cloud console](https://console.cloud.google.com/release-notes), or programmatically access release notes in [BigQuery](https://console.cloud.google.com/bigquery?p=bigquery-public-data&d=google_cloud_release_notes&t=release_notes&page=table). 

To get the latest product updates delivered to you, add the URL of this page to your [feed reader](https://wikipedia.org/wiki/Comparison_of_feed_aggregators), or add the [feed URL](https://docs.cloud.google.com/feeds/service-health-release-notes.xml) directly. 

## August 21, 2026

Feature

The Personalized Service Health remote MCP server provides a secure environment that lets you send natural language prompts to your AI application so that it can retrieve incident information, audit incidents, and automate debugging on your behalf.

For more information, see [Use the Personal Service Health remote MCP server](https://docs.cloud.google.com/service-health/docs/use-service-health-mcp).

## April 08, 2025

Feature

  * You can [ask Gemini Cloud Assist about active incidents, their impact, and updates](https://docs.cloud.google.com/gemini/docs/cloud-assist/analyze-and-optimize-cloud-resources#incident-check)
  * You can [view incidents related to your App Hub applications in Cloud Hub](https://docs.cloud.google.com/hub/docs/support#events). See [instructions for displaying incidents in Cloud Hub](https://docs.cloud.google.com/service-health/docs/overview#incidents-cloud-hub).



## January 27, 2025

Announcement

Personalized Service Health supports Agent Assist, Backup for GKE, Batch prediction, Cloud Contact Center, Cloud Customer Care, Cloud Vision, Identity Platform, Memorystore for Redis Cluster, Online prediction, Retail API, Talent Solution, Text-to-Speech, Vertex AI Model Monitoring, Vertex AI Model Registry, and Vertex AI Pipelines. See the [updated list](https://docs.cloud.google.com/service-health/docs/supported-products-locations).

## January 24, 2025

Change

[Incident reports](https://docs.cloud.google.com/service-health/docs/overview#incident) are available in Personalized Service Health.

## January 07, 2025

Change

Added [stable product IDs](https://docs.cloud.google.com/service-health/docs/supported-products-locations) for Google Cloud products to use in API calls and alerting policies.

## December 12, 2024

Announcement

Personalized Service Health supports Backup and DR Service, Batch, Cloud Billing, Colab Enterprise, Document AI, Google Cloud VMware Engine, Hub, Migrate to Virtual Machines, Vertex AI Search, and Web Risk. See the [updated list](https://docs.cloud.google.com/service-health/docs/supported-products-locations).

## December 09, 2024

Announcement

Personalized Service Health supports Application Integration, BigQuery Data Transfer Service, Cloud Tasks, Cloud Workstations, Google Cloud NetApp Volumes, Dataform, and Integration Connectors. See the [updated list](https://docs.cloud.google.com/service-health/docs/supported-products-locations).

## May 31, 2024

Announcement

Personalized Service Health supports Bare Metal Solution, Cloud Build, Cloud Service Mesh, Cloud Data Loss Prevention, Cloud Scheduler, Cloud Source Repositories, and Vertex AI Workbench. See the [updated list](https://docs.cloud.google.com/service-health/docs/supported-products-locations).

## March 04, 2024

Feature

## January 24, 2024

Announcement
