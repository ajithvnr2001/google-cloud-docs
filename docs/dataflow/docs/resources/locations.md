This page describes the regions and zones where you can use Dataflow. For more information about regions and zones, see [Geography and regions](https://docs.cloud.google.com/docs/geography-and-regions).

## Regional availability

You can use Dataflow workers, endpoints, Streaming Engine, Shuffle, and FlexRS in supported regions. This section lists the available regions. For information about GPUs, see GPU availability.

**Note:** The [Dataflow Data Pipelines](https://docs.cloud.google.com/dataflow/docs/guides/data-pipelines) feature is available in the [ Cloud Scheduler regions](https://cloud.google.com/about/locations#region).

## GPU availability

Dataflow supports a variety of GPU types. For more information about GPUs that are supported with Dataflow, see [Dataflow support for GPUs](https://docs.cloud.google.com/dataflow/docs/gpu/gpu-support).

For information about available regions and zones for GPUs, see [GPU regions and zones availability](https://docs.cloud.google.com/compute/docs/gpus/gpu-regions-zones) in the Compute Engine documentation.

For information about pricing for GPUs on Compute Engine, see [GPU pricing](https://cloud.google.com/compute/gpus-pricing).

**Note:** For a more detailed description of zones, see [Regions and zones](https://docs.cloud.google.com/compute/docs/regions-zones). 

## TPU availability

Dataflow supports a variety of TPU types. For more information about TPUs that are supported with Dataflow, see [Dataflow support for TPUs](https://docs.cloud.google.com/dataflow/docs/tpu/tpu-support).

For information about available regions and zones for TPUs, see [TPU regions and zones](https://docs.cloud.google.com/tpu/docs/regions-zones) in the Cloud TPU documentation.

For information about pricing for TPUs, see [Dataflow pricing](https://cloud.google.com/dataflow/pricing).
