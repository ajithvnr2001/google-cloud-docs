The open source Apache Beam project provides SDKs for creating pipelines that you can run on Dataflow. To learn about the latest Apache Beam releases, see the following links:

  * [Apache Beam releases](https://github.com/apache/beam/releases)

  * [Apache Beam blog](https://beam.apache.org/blog/)
