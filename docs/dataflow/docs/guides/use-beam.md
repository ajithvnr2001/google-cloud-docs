#  Use Apache Beam to build pipelines Stay organized with collections  Save and categorize content based on your preferences. 

Dataflow is built on the open source [Apache Beam](https://beam.apache.org/) project. You can use the Apache Beam SDK to build pipelines for Dataflow. This document lists some resources for getting started with Apache Beam programming.

## Get started

  * [Install or update the Apache Beam SDK](https://docs.cloud.google.com/dataflow/docs/guides/installing-beam-sdk): Shows how to install or update the Apache Beam SDK so that you can run your pipelines in Dataflow.

  * [Create a Java pipeline](https://docs.cloud.google.com/dataflow/docs/guides/create-pipeline-java): Shows how to create a pipeline with the Apache Beam Java SDK and run the pipeline in Dataflow.

  * [Create a Python pipeline](https://docs.cloud.google.com/dataflow/docs/guides/create-pipeline-python): Shows how to create a pipeline with the Apache Beam Python SDK and run the pipeline in Dataflow.

  * [Create a Go pipeline](https://docs.cloud.google.com/dataflow/docs/guides/create-pipeline-go): Shows how to create a pipeline with the Apache Beam Go SDK and run the pipeline in Dataflow.




## Learn Apache Beam

You can use the following pages on the Apache Beam website to learn about Apache Beam programming.

  * [Apache Beam programming guide](https://beam.apache.org/documentation/programming-guide/): Provides guidance for using the Apache Beam SDK classes to build and test your pipeline.

  * [Tour of Apache Beam](https://tour.beam.apache.org/): A learning guide you can use to familiarize yourself with Apache Beam. Learning units are accompanied by code examples that you can run and modify. 

  * [Apache Beam playground](https://play.beam.apache.org/): An interactive environment to try out Apache Beam transforms and examples without having to install Apache Beam in your environment.

  * [Create your pipeline](https://beam.apache.org/documentation/pipelines/create-your-pipeline/): Explains the mechanics of using the classes in the Apache Beam SDKs and the necessary steps needed to build a pipeline.




## Develop pipelines

  * [Plan your pipeline](https://docs.cloud.google.com/dataflow/docs/guides/plan-pipelines): Learn how to plan your pipeline before you begin code development.

  * [Develop and test pipelines](https://docs.cloud.google.com/dataflow/docs/guides/plan-pipelines): Learn best practices for developing and testing your Dataflow pipeline.

  * [Streaming pipelines](https://docs.cloud.google.com/dataflow/docs/concepts/streaming-pipelines): Learn about important design considerations for streaming pipelines, including windows, triggers, and watermarks.




## Code examples

You can use the following examples from the Apache Beam GitHub to start building a streaming pipeline:

  * [Streaming word extraction](https://github.com/apache/beam/blob/master/examples/java/src/main/java/org/apache/beam/examples/complete/StreamingWordExtract.java) (Java)
  * [Streaming word count](https://github.com/apache/beam/blob/master/sdks/python/apache_beam/examples/streaming_wordcount.py) (Python), and
  * [`streaming_wordcap`](https://github.com/apache/beam/blob/master/sdks/go/examples/streaming_wordcap/wordcap.go) (Go).
