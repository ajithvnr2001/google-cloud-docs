## API enablement

To use Cloud Key Management Service, you need to enable the Cloud Key Management Service API. This can be done in the Google Cloud console. 

[Enable the API](https://console.cloud.google.com/apis/enableflow?apiid=cloudkms.googleapis.com)

## Billing account

To use Cloud KMS, you need to use it in a project with a billing account enabled. 

[Enable billing](https://support.google.com/cloud/answer/6293499#enable_billing_for_a_project)

[Cloud KMS pricing](https://cloud.google.com/kms/pricing) is based on usage.

## Supported countries

You can use Cloud KMS in any country where Google Cloud services are supported.
