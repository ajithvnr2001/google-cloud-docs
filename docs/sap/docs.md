# SAP on Google Cloud documentation

Google Cloud provides best-in-class infrastructure, databases, and advanced AI/ML tools to run, operate, and modernize your SAP workloads. Whether deploying SAP HANA or SAP NetWeaver, automating day-to-day operations, or building generative AI applications with the ABAP SDK for Google Cloud, Google Cloud delivers SAP-certified infrastructure alongside high availability and enterprise security.

Use these resources to explore, deploy, and manage your SAP workloads:

  * **Get started, plan, and secure:** explore architecture checklists, RISE with SAP connectivity, Identity and Access Management (IAM), sovereign controls, and certifications.
  * **Deploy and operate core systems:** run SAP HANA, SAP NetWeaver, and certified databases (IBM Db2, SAP ASE, MaxDB, Oracle) with automated Terraform deployments, high availability filers, and comprehensive troubleshooting guides.
  * **Build apps with data and AI:** replicate enterprise SAP data in real time to BigQuery, invoke Vertex AI and Gemini models from ABAP environments, and explore developer SDKs, API references, and code samples.
