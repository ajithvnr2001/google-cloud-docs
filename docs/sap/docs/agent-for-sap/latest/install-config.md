#  Choose your Google Cloud's Agent for SAP installation and configuration guide Stay organized with collections  Save and categorize content based on your preferences. 

How you install and configure **version 3.15 (latest)** of Google Cloud's Agent for SAP, differs depending on whether you are installing the agent on a Compute Engine instance or on a Bare Metal Solution server.

To install and configure version 3.15 (latest) of the agent, see the guide for your deployment scenario:

  * [Install and configure Google Cloud's Agent for SAP on a Compute Engine instance](https://docs.cloud.google.com/sap/docs/agent-for-sap/latest/install-config-on-vm)
  * [Install and manage Google Cloud's Agent for SAP on a fleet of VMs](https://docs.cloud.google.com/sap/docs/agent-for-sap/latest/install-manage-on-vm-fleet)
  * [Install and configure Google Cloud's Agent for SAP on a Bare Metal Solution server](https://docs.cloud.google.com/sap/docs/agent-for-sap/latest/install-config-on-bms)
