#  Overview of automating SAP deployments on Google Cloud Stay organized with collections  Save and categorize content based on your preferences. 

Google Cloud provides tools that can help you accelerate the deployment of SAP solutions and the underlying infrastructure such as Compute Engine instances, Hyperdisk or Persistent Disk volumes. This guide provides an overview about these tools.

This guide is intended for cloud architects and platform administrators who help you design the deployment strategy for SAP solutions that you want to run on Google Cloud.

## Automation options

You can automate SAP deployments on Google Cloud by using the following options:

  * **Terraform** (Recommended): provides declarative configuration files to provision resources. For more information, see [Automating SAP deployments on Google Cloud with Terraform](https://docs.cloud.google.com/sap/docs/tf-for-sap).
  * **Workload Manager - Guided Deployment Automation** : lets you configure and deploy SAP systems on Google Cloud. Post deployment, this tool lets you generate Terraform and Ansible files that you can export for further customization or use in an existing deployment pipeline. For more information, see [About Guided Deployment Automation](https://docs.cloud.google.com/workload-manager/docs/deploy/about-wlm-deployment).
