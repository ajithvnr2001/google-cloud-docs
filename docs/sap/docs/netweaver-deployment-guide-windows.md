#  Overview of Windows deployment for SAP NetWeaver Stay organized with collections  Save and categorize content based on your preferences. 

This guide shows you how to deploy and configure the Google Cloud resources that SAP NetWeaver needs in order to run on Google Cloud, including the Compute Engine virtual machine (VM), the operating system, persistent storage, and more.

Use this guide if you are running SAP NetWeaver on the Windows Server operating system. If you need to run SAP NetWeaver on Linux, then see the [Terraform: Automated VM deployment for SAP NetWeaver on Linux](https://docs.cloud.google.com/sap/docs/netweaver-deployment-linux-tf). 

After the Google Cloud resources are deployed and configured, you install SAP NetWeaver on Google Cloud by following the SAP documentation that is applicable to your version of SAP NetWeaver and your database server. For more information, see SAP NetWeaver in the [SAP Help Portal](https://help.sap.com/viewer/p/SAP_NETWEAVER).

## Deployment methods

To deploy the Google Cloud resources for an SAP NetWeaver system, see [Manual VM deployment for SAP NetWeaver on Windows Server](https://docs.cloud.google.com/sap/docs/netweaver-deployment-windows-manual)

To use these deployment methods, you must have: 

  * A Google account with the necessary administrative permissions to create, modify, and delete Compute Engine resources in a Google Cloud project. For information about roles and permissions, see [Compute Engine roles](https://docs.cloud.google.com/iam/docs/roles-permissions/compute)
  * A Google Cloud project
  * A network and subnetwork defined in Google Cloud
