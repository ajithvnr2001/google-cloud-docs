#  Deployment Manager templates for SAP diagnostic information Stay organized with collections  Save and categorize content based on your preferences. 

**Note:** Cloud Deployment Manager reaches end of support on March 31, 2026. For more information, see [Cloud Deployment Manager deprecation](https://docs.cloud.google.com/deployment-manager/docs/deprecations). 

To automate the deployment of SAP solutions on Google Cloud, we recommend that you use Terraform or Workload Manager. For more information, see [Overview of automating SAP deployments on Google Cloud](https://docs.cloud.google.com/sap/docs/automation-for-sap).

For problems that are related to the Deployment Manager templates for SAP, provide the following information to Cloud Customer Care as soon as you can:

  * A complete and detailed description of the problem or error, including:

    * The current application or system state.
  * The URL of the Google Cloud deployment guide that corresponds to the Deployment Manager template that you are using. You can find all of the guides at [Support SAP solutions](https://docs.cloud.google.com/sap/docs/dm-templates-for-sap#supported_sap_solutions).

  * The name of the deployment as listed on the [**Deployments** page](https://console.cloud.google.com/dm/deployments) in the Google Cloud console.

  * The date and time that the deployment was created. You can find the date and time in the Google Cloud console on the details page for your deployment under **Deployment properties**.

  * After removing passwords, the YAML configuration file that you used for the deployment.

  * If the deployed VM is available, then provide the `/var/log/messages` file.
