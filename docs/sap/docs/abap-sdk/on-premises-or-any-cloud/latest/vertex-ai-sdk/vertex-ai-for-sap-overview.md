With the Agent Platform SDK for ABAP, you can build production-ready SAP applications that are powered by state-of-the-art generative AI models hosted on Google's advanced, global infrastructure.

Access the following capabilities from the Gemini model family and turn your ideas into real apps that scale:

  * **Invoke the Gemini models** : Process multiple types of input media at the same time, such as text, image, video, audio, and documents by using the Gemini text and multimodal models. For more information, see [Invoke the Gemini models](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/vertex-ai-sdk/invoke-gemini-models).

  * **Invoke the Gemma models** : Process multiple types of input media at the same time, such as text, image, video, audio, and documents by using the Gemma models. For more information, see [Invoke the Gemma models](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/vertex-ai-sdk/invoke-gemma-models).

  * **Invoke the Anthropic Claude models** : Process multiple types of input media at the same time, such as text, image, and documents by using the Anthropic Claude text and multimodal models. For more information, see [Invoke the Anthropic Claude models](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/vertex-ai-sdk/invoke-claude-models).

  * **Generate embeddings** : Generate text and multimodal embeddings to perform tasks such as search, classification, clustering, and outlier detection. For more information, see [Generate embeddings](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/vertex-ai-sdk/generate-embeddings).

  * **Use Agent Platform Vector Search** : Find information based on meaning, not just keywords, by using AI to understand the relationships between words and concepts. For more information, see [Use Agent Platform Vector Search](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/vertex-ai-sdk/use-vector-search).

  * **Use Agent Platform Feature Store** : Sync your online store with the feature data source in BigQuery, serve features from an online store, and search an online store using an entity or embedding. For more information, see [Use Agent Platform Feature Store](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/vertex-ai-sdk/use-feature-store).

  * **Use SAP function calling with Agent Platform hosted models** : Define custom functions and provide them to the Gemini and Claude models by using the [Function Calling](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/multimodal/function-calling) feature. For more information, see [Use SAP function calling with Agent Platform hosted models](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/vertex-ai-sdk/use-function-calling).
