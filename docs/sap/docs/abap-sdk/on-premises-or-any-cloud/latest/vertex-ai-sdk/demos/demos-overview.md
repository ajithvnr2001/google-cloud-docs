The Agent Platform SDK for ABAP comes with demo programs that let you practice and learn how to use Google's generative AI services. You can also use reference code from the demo programs as a starting point for your own projects. Explore these demos to see how Google's generative AI models can address your unique needs for SAP use cases from your ABAP environment.

**Note:** Demo programs are available only with the on-premises or any cloud edition of ABAP SDK for Google Cloud. They are not available with the SAP BTP edition of ABAP SDK for Google Cloud. 

Before you try these demos, make sure to complete the necessary [configurations for the Agent Platform SDK for ABAP](https://docs.cloud.google.com/sap/docs/abap-sdk/vertex-ai-sdk/latest/install-configure-vertex-ai-sdk-abap).

The demos cover a variety of generative AI services, such as:

  * Invoke Gemini models to generate text and multimodal content. Try the following:

    * [Demo: Generate text content](https://docs.cloud.google.com/sap/docs/abap-sdk/vertex-ai-sdk/latest/demos/generate-text-content)
    * [Demo: Generate multimodal content](https://docs.cloud.google.com/sap/docs/abap-sdk/vertex-ai-sdk/latest/demos/generate-multimodal-content)
  * Generate embeddings to represent complex data as numerical vectors, capturing semantic meaning and relationships between the data points. Try the following:

    * [Demo: Generate text embeddings](https://docs.cloud.google.com/sap/docs/abap-sdk/vertex-ai-sdk/latest/demos/generate-text-embeddings)
    * [Demo: Generate multimodal embeddings](https://docs.cloud.google.com/sap/docs/abap-sdk/vertex-ai-sdk/latest/demos/generate-multimodal-embeddings)



Additionally, you can also try the Vector Search and Agent Platform Feature Store demos within the Agent Platform SDK for ABAP.
