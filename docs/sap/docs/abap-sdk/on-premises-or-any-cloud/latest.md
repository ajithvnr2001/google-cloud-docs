On-premises or any cloud edition v1.14keyboard_arrow_down

  * [ SAP BTP edition v1.1 ](https://docs.cloud.google.com/sap/docs/abap-sdk/btp/latest/)
  * [ On-premises or any cloud edition v1.14 ](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/)



Integrate your on-premises or external cloud SAP systems directly with Google Cloud services using the ABAP SDK for Google Cloud. You can establish secure connectivity, develop applications using client stubs, and embed AI and analytics capabilities like Gemini models and BigQuery ML natively within your ABAP codebase.

##  Solutions and accelerators 

Build generative AI capabilities, automate enterprise data replication, and implement event-driven architectures using specialized toolkits and SDKs. 

###  [ Vertex AI SDK for ABAP ](https://docs.cloud.google.com/sap/docs/abap-sdk/vertex-ai-sdk-overview)

Build generative AI applications and call foundational Gemini models directly within your ABAP codebase. 

###  [ BigQuery AI and ML SDK ](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/bq-ai-ml-sdk/overview)

Harmonize SAP enterprise data with Google Cloud analytics to generate predictive insights using BigQuery ML. 

###  [ BigQuery Toolkit for SAP ](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/bq-toolkit-for-sap-overview)

Replicate SAP data directly into BigQuery without requiring external integration middleware. 

###  [ Business Eventing Toolkit for SAP ](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/eventing-toolkit-for-sap-overview)

Publish SAP business events to Google Cloud services like Pub/Sub and Eventarc to build event-driven architectures. 

###  [ Implement Cloud Storage as a content repository for SAP ](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/implement-gcs-sap-content-repository)

Implement Cloud Storage as a scalable, cost-effective content repository for storing SAP attachments and archive files.
