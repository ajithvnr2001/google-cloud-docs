This page provides a curated list of quickstarts. If you are new to the SAP BTP edition of ABAP SDK for Google Cloud and would like to try it out, you can work through a quickstart to get a basic understanding of the fundamentals that you would use at scale in a development environment.

To find quickstarts for various use cases with the SAP BTP edition of ABAP SDK for Google Cloud, see the [quickstarts repository on GitHub](https://github.com/GoogleCloudPlatform/abapsdk-btp-samples/tree/main/src/zgoog_sdk_btp_quickstart).

**Messaging and data analytics**
