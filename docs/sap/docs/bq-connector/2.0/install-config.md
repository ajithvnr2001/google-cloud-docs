#  Version 2.0: Choose your BigQuery Connector for SAP installation and configuration guide Stay organized with collections  Save and categorize content based on your preferences. 

How you install and configure **version 2.0 or 2.1** of the BigQuery Connector for SAP differs depending on whether SAP LT Replication Server is running on a Compute Engine virtual machine on Google Cloud or on a host that is outside of Google Cloud, such as a host on premises or a host on another cloud platform.

To install and configure version 2.0 or 2.1 of the BigQuery Connector for SAP, select the guide for your SAP LT Replication Server host:

  * [Install and configure BigQuery Connector for SAP on a Compute Engine VM](https://docs.cloud.google.com/sap/docs/bq-connector/2.0/install-config-on-gc)
  * [Install and configure BigQuery Connector for SAP on a host outside of Google Cloud](https://docs.cloud.google.com/sap/docs/bq-connector/2.0/install-config-off-gc)
