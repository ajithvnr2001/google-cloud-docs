# AI and data integrations for SAP on Google Cloud  documentation

Google Cloud provides data integration services and AI/ML tools that you can implement natively in your SAP applications. By connecting your SAP systems to Google Cloud across several SAP environments—including on-premises, other cloud providers, SAP BTP, and SAP RISE—you can stream business data and telemetry from SAP to Google Cloud for real-time insights and uncover operational efficiencies with advanced analytics. You can also accelerate business processes by building generative AI applications natively within your ABAP environment.

Use these resources to do the following:

  * **Integrate enterprise data:** replicate SAP tables in near-real-time to BigQuery. By connecting your SAP workloads to over 290 Google Cloud APIs, you can automate pipelines without complex middleware.
  * **Build generative AI applications:** invoke Gemini models, orchestrate agentic database workflows, and index vector search databases natively. Use the ABAP Code Wizard to auto-generate boilerplate code.
