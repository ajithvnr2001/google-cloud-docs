#  SAP certifications for Google Cloud Stay organized with collections  Save and categorize content based on your preferences. 

This page provides consolidated information about the certifications that SAP has published to run SAP solutions on Google Cloud. These certifications include the Compute Engine machine types and supported block storage.

## Certified solutions and machine types

The following table lists the Compute Engine machine types that SAP has certified to run specific SAP solutions. To view, filter, and interpret the information displayed by the table, use the following guidance:

  * You can filter the machine types by selecting an SAP solution, a vCPU range, a memory range, or all of these.
  * Click a row in the table to open its detail view, which shows additional information about the SAP certifications for that machine type.
  * In the **Certified SAP solution** field, selecting the value **All** shows all the Compute Engine machine types that SAP has certified.
  * In the **Certified SAP solution** field, the value **SAP NetWeaver** represents the components of the ABAP Platform, which include the following: SAP NetWeaver application server, SAP S/4HANA (3-tier configuration), SAP BW/4HANA (3-tier configuration), SAP ECC, SAP Business Suite, SAP NetWeaver Business Warehouse, SAP Landscape Transformation Replication Server (SLT), and SAP Solution Manager.

  * Although SAP also certifies SAP BusinessObjects BI Suite and SAP Financial Consolidation for Google Cloud, this table omits them because you can run these solutions on any Compute Engine machine type.

  * Compute Engine calculates disk size, machine type memory, and network usage in JEDEC binary gigabytes (GB), also known as gibibytes (GiB), where 1 GiB is 230 bytes. Similarly, 1 TiB is 240 bytes, or 1024 JEDEC GBs.




For more information about a specific machine type, see [Machine families resource and comparison guide](https://docs.cloud.google.com/compute/docs/machine-resource). For information about the availability of machine types in specific regions and zones, see [Available regions and zones](https://docs.cloud.google.com/compute/docs/regions-zones#available).

## Relevant SAP resources

For information from SAP about the certifications issued for Google Cloud, see the following resources:

  * [ SAP Note 2456432 - SAP Applications on Google Cloud: Supported Products and Google Cloud machine types](https://launchpad.support.sap.com/#/notes/2456432)
  * [ SAP Note 2456406 - SAP on Google Cloud Platform: Support Prerequisites](https://launchpad.support.sap.com/#/notes/2456406)
