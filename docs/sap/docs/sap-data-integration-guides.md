#  Data integration guides for SAP on Google Cloud Stay organized with collections  Save and categorize content based on your preferences. 

Explore integration options to replicate, export, and ingest enterprise SAP data into Google Cloud using Google-built solutions or existing SAP data platforms.

## Integration through Google Cloud solutions

Use Google-built connectors, ABAP client libraries, and data extraction plugins to replicate SAP tables directly into BigQuery and Google Cloud storage layers.

###  [ Replicate SAP data using BigQuery Connector for SAP ](https://docs.cloud.google.com/sap/docs/bq-connector-for-sap-guides)

Explains how to replicate data from your SAP systems directly into BigQuery using real-time Change Data Capture (CDC) or scheduled file transfers. 

###  [ Replicate data from an SAP ABAP environment using BigQuery Toolkit for SAP ](https://docs.cloud.google.com/sap/docs/abap-sdk/on-premises-or-any-cloud/latest/bq-toolkit-for-sap-overview)

Explains how to transfer tables from inside your SAP applications directly into BigQuery using custom ABAP logic, without requiring an SLT server. 

###  [ Extract and ingest data using Cloud Data Fusion ](https://docs.cloud.google.com/sap/docs/cdf-plugin-for-sap)

Explains how to extract tables from SAP ERP and BW systems into Google Cloud using code-free visual batch ingestion pipelines inside Cloud Data Fusion. 

## Integration through SAP data platforms

Use existing SAP data platforms, such as SDS, SLT, and Datasphere, to replicate and export tables into BigQuery.

###  [ Export to BigQuery using SAP Data Services ](https://docs.cloud.google.com/sap/docs/bigquery-sap-export-using-sds)

Explains how to export data from an SAP application or database directly into BigQuery configured targets inside SAP Data Services (SDS). 

###  [ Replicate using SAP Data Services and SLT ](https://docs.cloud.google.com/sap/docs/bigquery-replication-from-sap-apps)

Explains how to set up near-real-time data replication from SAP S/4HANA or SAP Business Suite to BigQuery by combining SLT with SDS. 

###  [ Replicate from SAP S/4HANA through SAP Datasphere ](https://docs.cloud.google.com/sap/docs/sap-datasphere-replication-bigquery-overview)

Explains how to replicate data flows from SAP S/4HANA to BigQuery in near-real time or scheduled batch mode using SAP Datasphere. 

###  [ Set up cross-cloud connection for SAP Business Data Cloud ](https://docs.cloud.google.com/lakehouse/docs/set-up-cross-cloud-connection-sap-bdc)

Explains how to set up and use cross-cloud connection to query remote data in SAP Business Data Cloud (BDC) directly within Google Cloud.
