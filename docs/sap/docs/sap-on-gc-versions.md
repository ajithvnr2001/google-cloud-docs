## Versioning scheme

The tools and SDKs that Google Cloud provides for SAP solutions use the following versioning scheme:

  * Major version: This version introduces new functionalities and might introduce backward incompatible changes.
  * Minor version: This version generally includes bug fixes and might introduce new functionalities.
