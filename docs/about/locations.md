#### Regions*

Deliver high performance applications with low latency, while ensuring that valuable data remains securely resident within country borders.

*Regions consist of three or more zones housed in three or more physical data centers.  
The regions Stockholm, Osaka, and Montreal have three zones within one or two physical data centers and are in the process of expanding to at least three physical data centers. For more information, please see the 'Global geography and regions' section below.

Google global network

The [Google global network](https://cloud.google.com/resources/google-global-network) connects over 200 countries via 10 million kilometers of fiber. This infrastructure minimizes latency and security risks for enterprise apps and AI training. Our multi-shard design allowed a 7x WAN bandwidth increase from 2020 to 2025, ensuring a fast, consistent global experience.

We manage this network with agentic AI and digital twins to predict and prevent outages. This autonomous approach reduces outage durations by up to 93%—shortening mitigation times from hours to minutes—and shifts operations from reactive to predictive. With regional isolation and protective rerouting, we provide deterministic performance and high-level resilience.

At a minimum, all regions will offer the following products at launch: Compute Engine, Google Kubernetes Engine, Cloud Storage, Persistent Disk, Cloud SQL, Virtual Private Cloud, Cloud VPN, Key Management Service, Cloud Identity and Secret Manager.

Additional products will be available within 6 months of a new region launch, including: Cloud Run, Bigtable, Cloud MemCache, Apigee, Cloud Redis, Spanner, Extreme PD, BigQuery, Cloud Dataflow, Managed Service for Apache Spark (Cloud Dataproc), Pub/Sub.

Available products in the region will continue to evolve based on customer demand.

Some services differentiate between regions using uppercase (e.g., "US") and lowercase (e.g., "us") letters. Please refer to the service's documentation for the precise multi-region format.

## Cloud Location Finder

For programmatic access to location data across clouds, consider using [Cloud Location Finder](https://docs.cloud.google.com/location-finder/docs) (CLF), an API which provides up-to-date location data across Google Cloud, Amazon Web Services (AWS), Azure, and Oracle Cloud Infrastructure (OCI). You can easily find locations, get specific location details, find nearby locations, and filter these based on criteria such as cloud provider, location type, territory, or carbon footprint. 

[ Documentation ](https://docs.cloud.google.com/location-finder/docs)
