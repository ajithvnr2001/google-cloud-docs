#  Smart reply Stay organized with collections  Save and categorize content based on your preferences. 

This page contains the API documentation for the [Smart Reply](https://docs.cloud.google.com/gemini-enterprise-cx/agent-assist/smart-reply) UI module. This module is used to display Smart Reply suggestions to agents during the course of a conversation. Smart Reply only integrates with chat conversations.

## Usage

Import the module in your HTML page using the following code:
    
    
    <script src="https://www.gstatic.com/agent-assist-ui-modules/v1/smart_reply.js"></script>
    

Embed the module using the following tag:
    
    
    <agent-assist-smart-reply>
