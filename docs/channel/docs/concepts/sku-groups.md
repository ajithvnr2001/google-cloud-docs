#  Google Cloud SKU groups Stay organized with collections  Save and categorize content based on your preferences. 

This page provides a summary of the stock keeping unit (SKU) groups available to you as a reseller. **Note:** This page does not cover Google Workspace products and SKUs. Visit our [Google Workspace products, SKUs, and plans](https://docs.cloud.google.com/channel/docs/concepts/workspace/products-skus) page for those details.

## Channel Services SKU groups

All [public SKU groups](https://docs.cloud.google.com/skus/sku-groups) in addition to the following SKU groups are available for use when you create and manage custom repricing configurations:

  * Third Party Marketplace (Id: 31f47c09-96ff-43dc-912b-bb3808148be2)
  * Google Maps Platform (Id: d56c1f4c-d3bb-4a7b-acb0-8376793b4105)
  * GCP Reseller (Id: 3d50fd57-3157-4577-a5a9-a219b8490041)

### Third party Marketplace SKU group

This group includes product SKUs from third-party software providers. This represents the complete collection of all 3p SKUs. We do not provide partner program discount on the full list. But there might be individual ISV-level margins available to you via overrides on ISV SKU groups above.

As an example, the [MongoDB](https://docs.cloud.google.com/mongodb) and [MariaDB](https://mariadb.com/products/skysql/google-cloud-platform/) SKUs are a part of this group.

### Google Maps Platform SKU group

This group includes SKUs for products available on the Google Maps Platform. You can visit the Google Maps Platform documentation for information on how to [get started with the platform](https://developers.google.com/maps/get-started).

As an example, the Directions API and Places API SKUs are a part of this group.

### GCP Reseller SKU group

This group includes Google Cloud SKUs that we provide with partner program discounts. Most Google Cloud SKUs are a part of this group. To view the SKUs this might include, you can [export this SKU group](https://docs.cloud.google.com/channel/docs/rebilling/manage-repricing-configurations#export-sku-groups) to a file and view the full list of available SKUs.

For more information on the SKUs included in this group, visit the [Google Cloud SKU Groups article](https://docs.cloud.google.com/skus/sku-groups).
