#  gcloud CLI commands for Data Transfer Essentials Stay organized with collections  Save and categorize content based on your preferences. 

Google Cloud CLI commands for Network Connectivity enable connectivity with Google Cloud resources.

When you run gcloud CLI commands, you perform operations on resources that are part of the Network Connectivity API. For more information about the API, see the [Network Connectivity API reference](https://docs.cloud.google.com/network-connectivity/docs/apis).

## Commands for supported services

Use the following commands to list and view the details of [supported services](https://docs.cloud.google.com/data-transfer-essentials/docs/services).

Command | Task  
---|---  
[`gcloud network-connectivity multicloud-data-transfer-supported-services list`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-supported-services/list) | Lists the supported services in your project  
[`gcloud network-connectivity multicloud-data-transfer-supported-services describe`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-supported-services/describe) | Describes a specified service in your project  
  
## Commands to work with configurations

Use the following commands when working with Data Transfer Essentials configurations.

Command | Task  
---|---  
[`gcloud network-connectivity multicloud-data-transfer-configs create`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/create) | Creates a configuration  
[`gcloud network-connectivity multicloud-data-transfer-configs list`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/list) | Lists all configurations in your project  
[`gcloud network-connectivity multicloud-data-transfer-configs describe`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/describe) | Describes a configuration  
[`gcloud network-connectivity multicloud-data-transfer-configs update`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/update) | Updates a configuration  
[`gcloud network-connectivity multicloud-data-transfer-configs delete`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/delete) | Deletes a configuration  
  
## Commands to work with destinations

Use the following commands when working with Data Transfer Essentials destinations.

Command | Task  
---|---  
[`gcloud network-connectivity multicloud-data-transfer-configs destinations create`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/destinations/create) | Creates a destination  
[`gcloud network-connectivity multicloud-data-transfer-configs destinations list`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/destinations/list) | Lists all destinations in your project  
[`gcloud network-connectivity multicloud-data-transfer-configs destinations describe`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/destinations/describe) | Describes a destination  
[`gcloud network-connectivity multicloud-data-transfer-configs destinations update`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/destinations/update) | Updates a destination  
[`gcloud network-connectivity multicloud-data-transfer-configs destinations delete`](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/multicloud-data-transfer-configs/destinations/delete) | Deletes a destination
