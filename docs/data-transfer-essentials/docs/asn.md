#  Recognized ASNs Stay organized with collections  Save and categorize content based on your preferences. 

Data Transfer Essentials recognizes only the following autonomous system numbers (ASNs). When you [create Data Transfer Essentials destinations](https://docs.cloud.google.com/data-transfer-essentials/docs/create-resources), use the ASN number.

Cloud service provider | ASN  
---|---  
ALIBABA-CN-NET | `45102`  
AMAZON-02 | `16509`  
AMAZON-AES | `14618`  
MICROSOFT-CORP-MSN-AS-BLOCK | `8075`  
ORACLE-BMC-31898 | `31898`  
RACKSPACE | `27357`  
DigitalOcean | `14061`  
IBM | `64999`  
OVHcloud | `16276`
