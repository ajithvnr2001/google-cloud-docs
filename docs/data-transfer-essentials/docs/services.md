#  Supported services and regions Stay organized with collections  Save and categorize content based on your preferences. 

Data Transfer Essentials supports the following services at the specified [Network Service Tiers](https://docs.cloud.google.com/network-tiers/docs/overview) tier or regional endpoint. A service that is already enrolled for the [free data transfer exit program](https://cloud.google.com/exit-cloud) isn't eligible for Data Transfer Essentials support.

When you [create a Data Transfer Essentials configuration](https://docs.cloud.google.com/data-transfer-essentials/docs/create-resources), use the service string mentioned against each service.
