#  REST API methods for Data Transfer Essentials Stay organized with collections  Save and categorize content based on your preferences. 

This page describes how to create and manage Data Transfer Essentials by using the Network Connectivity API. For more information about the API, see the [Network Connectivity API reference](https://docs.cloud.google.com/network-connectivity/docs/apis).

## Methods for supported services

Use the following methods to list and view the details of [supported services](https://docs.cloud.google.com/data-transfer-essentials/docs/services) or [`multicloudDataTransferSupportedServices` resources](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferSupportedServices).

Method | Task  
---|---  
`[get](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferSupportedServices/get)` | Describes a specified service in your project  
`[list](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferSupportedServices/list)` | Lists the supported services in your project  
  
## Methods to work with configurations

Use the following methods when working with Data Transfer Essentials configurations or [`multicloudDataTransferConfigs` resources](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs).

Method | Task  
---|---  
`[create](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs/create)` | Creates a configuration  
`[delete](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs/delete)` | Deletes a configuration  
`[get](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs/get)` | Describes a configuration  
`[list](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs/list)` | Lists all configurations in your project  
`[patch](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs/patch)` | Updates a configuration  
  
## Methods to work with destinations

Use the following methods when working with Data Transfer Essentials destinations or [`multicloudDataTransferConfigs.destinations` resources](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs.destinations).

Method | Task  
---|---  
`[create](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs.destinations/create)` | Creates a destination  
`[delete](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs.destinations/delete)` | Deletes a destination  
`[get](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs.destinations/get)` | Describes a destination  
`[list](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs.destinations/list)` | Lists all destinations in your project  
`[patch](https://docs.cloud.google.com/network-connectivity/docs/reference/networkconnectivity/rest/v1/projects.locations.multicloudDataTransferConfigs.destinations/patch)` | Updates a destination
