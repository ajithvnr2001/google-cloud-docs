#  Validated partner solutions Stay organized with collections  Save and categorize content based on your preferences. 

This page provides information about the partner solutions that are validated with organization restrictions.

If you use other egress proxy or firewall solutions, make sure that the solutions adhere to the [organization restrictions prerequisites](https://docs.cloud.google.com/resource-manager/docs/organization-restrictions/configure-organization-restrictions#before-you-begin).

The following table lists the validated partner solutions and their corresponding integration guides:

Partner | Feature | Integration guide  
---|---|---  
F5 | F5 BIG-IP SSL Orchestrator | [ SSL Orchestrator integration guide](https://community.f5.com/t5/technical-articles/ssl-orchestrator-advanced-use-cases-enabling-gcloud-organization/ta-p/313600)  
Fortinet | FortiGate | [ FortiGate integration guide](https://docs.fortinet.com/document/fortigate-public-cloud/7.2.0/gcp-administration-guide/666440)  
Palo Alto Networks | Palo Alto Networks URL Filtering | [ Palo Alto Networks URL Filtering integration guide](https://live.paloaltonetworks.com/t5/general-articles/implement-google-cloud-organization-restrictions/ta-p/537284)  
Zscaler | Secure Internet and SaaS Access (ZIA) | [ ZIA configuration guide](https://help.zscaler.com/zia/adding-tenant-profiles#google-cloud-platform)
