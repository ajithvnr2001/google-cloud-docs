## Services that support labels

The following Google Cloud services support labels:

  * API Gateway
  * AI Platform
  * App Engine (both Flexible and Standard environments)
  * Artifact Registry
  * Batch (Labels are supported for batch jobs and VMs)
  * BigQuery
  * Bigtable
  * Certificate Authority Service
  * Certificate Manager
  * Cloud DNS (managed zones)
  * Managed Service for Apache Airflow
  * Compute Engine
  * Dataflow
  * Managed Service for Apache Spark
  * Cloud Deployment Manager
  * Eventarc
  * Filestore
  * Cloud Run functions
  * Cloud Healthcare API
  * Cloud Key Management Service
  * Memorystore
  * Networking (NAT gateway doesn't support labels)
  * Pub/Sub
  * reCAPTCHA
  * Resource Manager (projects only)
  * Cloud Run
  * Secret Manager
  * Spanner
  * Cloud SQL
  * Cloud Storage
  * Google Kubernetes Engine
  * Transcoder API
  * Cloud Translation
  * Vertex AI
  * Workflows
