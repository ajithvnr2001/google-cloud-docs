#  REST Resource: folders Stay organized with collections  Save and categorize content based on your preferences. 

  * Resource
  * Methods



## Resource

There is no persistent data associated with this resource.

## Methods  
  
---  
  
### `[clearOrgPolicy](https://docs.cloud.google.com/resource-manager/reference/rest/v1/folders/clearOrgPolicy)`

|  Clears a `Policy` from a resource.  
  
### `[getEffectiveOrgPolicy](https://docs.cloud.google.com/resource-manager/reference/rest/v1/folders/getEffectiveOrgPolicy)`

|  Gets the effective `Policy` on a resource.  
  
### `[getOrgPolicy](https://docs.cloud.google.com/resource-manager/reference/rest/v1/folders/getOrgPolicy)`

|  Gets a `Policy` on a resource.  
  
### `[listAvailableOrgPolicyConstraints](https://docs.cloud.google.com/resource-manager/reference/rest/v1/folders/listAvailableOrgPolicyConstraints)`

|  Lists `Constraints` that could be applied on the specified resource.  
  
### `[listOrgPolicies](https://docs.cloud.google.com/resource-manager/reference/rest/v1/folders/listOrgPolicies)`

|  Lists all the `Policies` set for a particular resource.  
  
### `[setOrgPolicy](https://docs.cloud.google.com/resource-manager/reference/rest/v1/folders/setOrgPolicy)`

|  Updates the specified `Policy` on the resource.
