# Migrate to Containers documentation

[Read product documentation](https://docs.cloud.google.com/migrate/containers/docs/getting-started)

Use Migrate to Containers to convert VM-based workloads into containers in [ Google Kubernetes Engine (GKE)](https://docs.cloud.google.com/kubernetes-engine). Workloads can be migrated from VMs running on either VMware on-premises or Compute Engine, giving you the flexibility to containerize your existing workloads with ease. 

[Go to the Migrate to Containers product page for more.](https://cloud.google.com/products/cloud-migration/containers)
