#  Migrate to Containers Open Source Disclosure Information

Migrate to Containers values the open source community as an essential resource and partner in innovation. For this reason, we provide a list of licenses for the open source projects used in Migrate to Containers products.

  * For the latest version of Migrate to Containers CLI, run the following command:
        
        curl -O "https://m2c-cli-release.storage.googleapis.com/$(curl -s https://m2c-cli-release.storage.googleapis.com/latest)/notices.tar.gz"
        

  * For the latest version of Migrate to Containers CLI plugins, run the following command:
        
        curl -O "https://storage.googleapis.com/modernize-plugins-prod/$(curl -s https://modernize-plugins-prod.storage.googleapis.com/latest)/notices.tar.gz"
