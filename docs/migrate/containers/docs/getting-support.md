# Getting support

## Get a Google support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. Read more about support options at [Getting support with Cloud Customer Care](https://docs.cloud.google.com/support).

You can also find live support, developer communities, and self-service help for Google Cloud, Google Workspace, and other Google Cloud products at the [support hub](https://cloud.google.com/support-hub).

## Support for Migrate to Containers

If you have any questions about Migrate to Containers or require additional support, then you can reach out to [m2c-external-feedback@google.com](mailto:m2c-external-feedback@google.com).

## Support for GKE Enterprise attached clusters

Your Google Cloud support includes support for any GKE Enterprise components deployed on GKE Enterprise [attached clusters](https://docs.cloud.google.com/anthos/docs/setup/attach-kubernetes-clusters), though not for the clusters themselves.

## Version Support Policy

Starting with GKE Enterprise version 1.14, Google supports each Migrate to Containers minor version for the later of:

  * 12 months after the initial release of the minor version.
  * The release of the third subsequent minor version.



We encourage you to maintain your Migrate to Containers environment with the product's latest major or minor release. You can find out about the latest supported versions and how to upgrade in the [Release Notes](https://docs.cloud.google.com/migrate/containers/docs/release-notes).
