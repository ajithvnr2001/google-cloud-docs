#  Overview Stay organized with collections  Save and categorize content based on your preferences. 

Migrate to Virtual Machines lets you migrate your virtual machines (VMs) running on an on-premises vSphere data center or on Google Cloud VMware Engine to VM instances running on Google Cloud.

  * To migrate a VM from an on-premises vSphere data center, see [Migrate to Virtual Machines from a VMware source](https://docs.cloud.google.com/migrate/virtual-machines/docs/5.0/migrate/create-a-vmware-source).

  * To migrate a VM from Google Cloud VMware Engine, see [Migrate to Virtual Machines from a Google Cloud VMware Engine source](https://docs.cloud.google.com/migrate/virtual-machines/docs/5.0/migrate/create-a-gcve-source).




The following diagram shows the architecture for migrating VMs from on-premises vSphere data center or from Google Cloud VMware Engine to Google Cloud:
