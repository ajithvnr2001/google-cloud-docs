# Migrate to Virtual Machines documentation

[Read product documentation](https://docs.cloud.google.com/migrate/virtual-machines/docs/5.0/discover/lifecycle)

Migrate to Virtual Machines lets you migrate virtual machine (VM) instances and disks of VMs from different migration sources such as vSphere on-premises data center, AWS cloud computing services, Azure cloud computing services, and Google Cloud VMware Engine to VM instances or Persistent Disk volumes on Google Cloud. 

[Go to the Migrate to Virtual Machines product page for more.](https://cloud.google.com/products/cloud-migration/virtual-machines)
