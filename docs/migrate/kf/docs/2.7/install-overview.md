#  Install Kf Stay organized with collections  Save and categorize content based on your preferences. 

You can install Kf on [Google Kubernetes Engine (GKE)](https://docs.cloud.google.com/kubernetes-engine) clusters running in Google Cloud and on [Google Distributed Cloud](https://docs.cloud.google.com/anthos/clusters/docs/on-prem/1.9/overview) or [Google Distributed Cloud](https://docs.cloud.google.com/anthos/clusters/docs/bare-metal/latest/concepts/about-bare-metal) on-premises clusters running outside Google Cloud.

Each installation option has its own unique requirements that are documented along with the installation instructions for the environment. Ensure that you review the requirements before you start the installation process.

For more information, see:

  * [Install Kf on Google Cloud](https://docs.cloud.google.com/migrate/kf/docs/2.7/install)

  * [Install Kf outside Google Cloud](https://docs.cloud.google.com/migrate/kf/docs/2.7/outside-gcp-install)
