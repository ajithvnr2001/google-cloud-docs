#  Get started with Kf Stay organized with collections  Save and categorize content based on your preferences. 

With Kf, you can migrate your Cloud Foundry apps to [Google Kubernetes Engine (GKE)](https://docs.cloud.google.com/kubernetes-engine) or [GKE Enterprise](https://docs.cloud.google.com/anthos) without changing your developer workflows. 

Use the following sections to get started deploying Cloud Foundry apps to GKE by using Kf.

## Get started with a quickstart

Use the [quickstart](https://docs.cloud.google.com/migrate/kf/docs/2.7/quickstart) to install Kf and deploy a simple test Cloud Foundry app. This introduces you to the basic steps you'd perform for most app deployments.

## Get an introduction to key concepts

For an introduction to the value of Kf, as well as high-level overviews of the technology, see the following documents:

  * To learn more about how Kf works, see [Kf dependencies and architecture](https://docs.cloud.google.com/migrate/kf/docs/2.7/concepts/kf-dependencies).
  * For a side-by-side comparison of Cloud Foundry and Kf components, see [Compare Cloud Foundry and Kf services](https://docs.cloud.google.com/migrate/kf/docs/2.7/concepts/compare-services).
  * To learn how to use service brokers with Kf, see [Service brokers](https://docs.cloud.google.com/migrate/kf/docs/2.7/concepts/about-service-brokers).
  * For more information about Kf security design, see the [Security overview](https://docs.cloud.google.com/migrate/kf/docs/2.7/concepts/security-overview).



## Migrate an existing Cloud Foundry Foundation to Kf

Kf provides tools that you can use to perform a _readiness assessment_ of your existing Cloud Foundry Foundation in preparation for migration to Kf. You can then migrate the Cloud Foundry Foundation, Organization, Space, or App to Kf.

For details about using the assessment and migration tools, see [Assessment and migration](https://docs.cloud.google.com/migrate/kf/docs/2.7/how-to/migrate-cf).
