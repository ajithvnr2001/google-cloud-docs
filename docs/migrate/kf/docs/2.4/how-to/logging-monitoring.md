#  Logging and Monitoring Stay organized with collections  Save and categorize content based on your preferences. 

Kf can use GKE's GCP integrations to send a log of events to your Cloud Monitoring and Cloud Logging project for observability. See [Overview of Google Cloud's operations suite for GKE](https://docs.cloud.google.com/monitoring/kubernetes-engine) for more information.

Kf deploys two server side components:

  1. Controller
  2. Webhook



To view the logs for these components, use the following Cloud Logging query:
    
    
    resource.type="k8s_container"
    resource.labels.project_id=<PROJECT ID>
    resource.labels.location=<GCP ZONE>
    resource.labels.cluster_name=<CLUSTER NAME>
    resource.labels.namespace_name="kf"
    labels.k8s-pod/app=<controller OR webhook>
    

**Note:** Replace the values inside the <> with the correct values.
