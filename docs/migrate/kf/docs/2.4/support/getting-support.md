#  Getting support Stay organized with collections  Save and categorize content based on your preferences. 

**Note:** Set the support category to `Compute` and select Kf as the component when filing a new support case.

## Before contacting support

To troubleshoot and resolve certain Kf problems yourself, see [Troubleshooting Kf](https://docs.cloud.google.com/migrate/kf/docs/2.4/support/troubleshooting). If other troubleshooting steps fail to resolve the problem, you can contact Google Cloud Support to help you.

To get support, you must install supported versions of Kf using the steps as described in the [installation guide](https://docs.cloud.google.com/migrate/kf/docs/2.4/install), on supported versions of Google Kubernetes Engine (GKE).

## Support options

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. Read more about support options at [Getting support with Cloud Customer Care](https://docs.cloud.google.com/support).

You can also find live support, developer communities, and self-service help for Google Cloud, Google Workspace, and other Google Cloud products at the [support hub](https://cloud.google.com/support-hub).

All Google Cloud Support packages include support for Kf for customers who have purchased GKE Enterprise licenses. If you have an existing GKE Enterprise license, you already have support for Kf.

## Version support policy

The objective of this Version Support Policy is to provide you the flexibility to schedule upgrades when it meets your business needs, while balancing the rapid evolution of Istio, Kubernetes, Google Distributed Cloud, GKE, and Kf.

Google supports the current and previous two (n-2) minor versions of Kf. The following table shows the supported versions of Kf and the unsupported end-of-life (EOL) versions.
