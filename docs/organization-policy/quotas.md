#  Quotas and system limits Stay organized with collections  Save and categorize content based on your preferences. 

This document lists the quotas and system limits that apply to Organization Policy Service.

  * _Quotas_ have default values, but you can typically request adjustments.
  * _System limits_ are fixed values that can't be changed.



## System limits

The following table lists the system limits that apply to Organization Policy and the value for each system limit.

System limit | Value  
---|---  
Organization policy size | 32 KB  
List rule parameters in a legacy managed constraint | 500  
Custom constraints per resource | 20
