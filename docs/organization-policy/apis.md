## v1 Resource Manager API

Resources and methods for managing the Organization Policy Service can be found in the v1 [Resource Manager API](https://docs.cloud.google.com/resource-manager/docs).

  * Resource Manager resources with Organization Policy Service-related methods: 
    * [`Policy`](https://docs.cloud.google.com/resource-manager/reference/rest/v1/Policy)
    * [`Organization`](https://docs.cloud.google.com/resource-manager/reference/rest/v1/organizations)
    * [`Folder`](https://docs.cloud.google.com/resource-manager/reference/rest/v1/folders)
    * [`Project`](https://docs.cloud.google.com/resource-manager/reference/rest/v1/projects)
  * [Resource Manager SDK reference](https://docs.cloud.google.com/sdk/gcloud/reference/resource-manager/org-policies)
