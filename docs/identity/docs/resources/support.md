# Getting support

## Get a Google support package

Google Workspace offers different support packages to meet different needs. For more information, see [Google Workspace Support](https://gsuite.google.com/support/).

## Get support from the community

### Ask a question on Stack Overflow

Ask a question about Cloud Identity on [Stack Overflow](http://stackoverflow.com/questions/tagged/google-cloud-identity). Use the tag `google-cloud-identity` for questions about Cloud Identity. This tag not only receives responses from the Stack Overflow community, but also from Google engineers, who monitor the tag and offer unofficial support.

### Discuss Cloud Identity

Visit the Google Cloud [Slack community](https://googlecloud-community.slack.com/) to discuss Cloud Identity and other Google Cloud products. If you haven't already joined, [use this form to sign up](https://join.slack.com/t/googlecloud-community/shared_invite/zt-3icuwfdvq-eq_58LqmOoCNc16mpZcaNA). 

## File bugs or feature requests

To file a bug or a feature request, use the Google Workspace [bug tracking system](https://issuetracker.google.com/issues/new?component=522910&template=1192013).
