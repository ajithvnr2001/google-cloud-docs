# Manage file sharing and syncing for Cloud Identity

Users with Cloud Identity licenses can access and share files in Google Drive. Users with Cloud Identity Premium can also create files.

**The following links go to Google Workspace help for administrators.** That's because you manage Drive file sharing for Cloud Identity the same as you do for Google Workspace.

![](https://docs.cloud.google.com/static/identity/docs/images/migrated/image-14859158.svg) | 

### Manage file sharing

You can use file sharing settings to prevent over-sharing and control sharing with users outside your work or school. For details: [Manage file sharing](https://support.google.com/a/topic/6097537).

### Set up Drive for desktop for Cloud Identity

Google Drive for desktop can help users get started with cloud-based files and collaboration. It lets them sync files between Google Drive and their computer. For details: [Deploy Drive for desktop](https://support.google.com/a/topic/7455083).

![](https://docs.cloud.google.com/static/identity/docs/images/migrated/image-14861668.svg) | 

### Turn Drive features and access on or off

You can control which Drive features and integrations your Cloud Identity users have available to them. For details:

  * [Integrate Drive with third-party apps](https://support.google.com/a/topic/9140737)
  * [Manage shared drives](https://support.google.com/a/topic/7337266) (Cloud Identity users can be "Viewer" members)
  * [Turn Drive or Drive features on or off](https://support.google.com/a/topic/13071240)
