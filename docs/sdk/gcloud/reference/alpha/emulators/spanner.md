NAME
    

gcloud alpha emulators spanner - manage your local Spanner emulator 
SYNOPSIS
    

`gcloud alpha emulators spanner` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` This set of commands allows you to start and use a local Spanner emulator. 
EXAMPLES
     To start a local Cloud Spanner emulator, run: 
    
    
    [gcloud alpha emulators spanner start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/emulators/spanner/start)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[env-init](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/emulators/spanner/env-init)`
     `(ALPHA)` Print the commands required to export Spanner emulator's env variables. 
`[notices](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/emulators/spanner/notices)`
     `(ALPHA)` Print third-party notices for the local Cloud Spanner emulator. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/emulators/spanner/start)`
     `(ALPHA)` Start a local Cloud Spanner emulator. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud emulators spanner](https://docs.cloud.google.com/sdk/gcloud/reference/emulators/spanner)
    
    
    [gcloud beta emulators spanner](https://docs.cloud.google.com/sdk/gcloud/reference/beta/emulators/spanner)
