NAME
    

gcloud alpha software-delivery-trust - manage Software Delivery Trust security policies and evidence 
SYNOPSIS
    

`gcloud alpha software-delivery-trust` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Software Delivery Trust (SD Trust) provides centralized software supply chain security policy management and cryptographic evidence verification for Google Cloud workloads. 

With Software Delivery Trust, you can define declarative CEL policies, bind them to target deployment resources (such as GKE clusters or Cloud Run services), and verify verifiable supply chain evidence (in-toto attestations and SLSA provenance). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[attestations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/attestations)`
     `(ALPHA)` Inspect Software Delivery Trust cryptographic attestations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/operations)`
     `(ALPHA)` Manage Operation resources. 
`[policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/policies)`
     `(ALPHA)` Manage Software Delivery Trust policy resources. 
`[policy-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/software-delivery-trust/policy-bindings)`
     `(ALPHA)` Manage Software Delivery Trust policy binding resources. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
