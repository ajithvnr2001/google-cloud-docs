NAME
    

gcloud alpha biglake iceberg namespaces list - list BigLake Iceberg REST namespaces 
SYNOPSIS
    

`gcloud alpha biglake iceberg namespaces list` `--catalog`=`CATALOG` [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List BigLake Iceberg REST namespaces. 
EXAMPLES
     To list namespaces in parent catalog `my-catalog`, run:
    
    
    gcloud alpha biglake iceberg namespaces list --catalog=my-catalog

REQUIRED FLAGS
    

Catalog resource - The Iceberg Catalog to list. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--catalog` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`--catalog`=`CATALOG`
     ID of the catalog or fully qualified identifier for the catalog. 

To set the `catalog` attribute: 

  * provide the argument `--catalog` on the command line.
