NAME
    

gcloud alpha biglake iceberg tables - manage BigLake Iceberg REST catalog tables 
SYNOPSIS
    

`gcloud alpha biglake iceberg tables` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage BigLake Iceberg REST catalog tables. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/create)`
     `(ALPHA)` Create a BigLake Iceberg table. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/delete)`
     `(ALPHA)` Delete a BigLake Iceberg table. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/describe)`
     `(ALPHA)` Describe a BigLake Iceberg table. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a BigLake Iceberg REST catalog table. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/list)`
     `(ALPHA)` List BigLake Iceberg REST tables. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/register)`
     `(ALPHA)` Register a BigLake Iceberg table. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a BigLake Iceberg REST catalog table. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/tables/update)`
     `(ALPHA)` Update a BigLake Iceberg table. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud biglake iceberg tables](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/tables)
