NAME
    

gcloud alpha biglake hive tables - manage BigLake Hive catalog tables 
SYNOPSIS
    

`gcloud alpha biglake hive tables` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage BigLake Hive catalog tables. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables/create)`
     `(ALPHA)` Create a BigLake Hive table. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables/delete)`
     `(ALPHA)` Deletes a BigLake Hive table. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables/describe)`
     `(ALPHA)` Describes a BigLake Hive table. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a BigLake Hive catalog table. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables/list)`
     `(ALPHA)` List BigLake Hive tables in a database. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a BigLake Hive catalog table. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables/update)`
     `(ALPHA)` Update a BigLake Hive table. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud biglake hive tables](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/hive/tables)
