NAME
    

gcloud alpha biglake hive - biglake Hive Catalogs 
SYNOPSIS
    

`gcloud alpha biglake hive` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Biglake Hive Catalogs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[catalogs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/catalogs)`
     `(ALPHA)` Manage BigLake Hive catalogs. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/databases)`
     `(ALPHA)` Manage BigLake Hive databases. 
`[tables](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/hive/tables)`
     `(ALPHA)` Manage BigLake Hive catalog tables. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud biglake hive](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/hive)
    
    
    [gcloud beta biglake hive](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/hive)
