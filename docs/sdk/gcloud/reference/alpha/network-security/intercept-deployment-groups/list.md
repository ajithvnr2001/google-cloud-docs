NAME
    

gcloud alpha network-security intercept-deployment-groups list - list Intercept Deployment Groups 
SYNOPSIS
    

`gcloud alpha network-security intercept-deployment-groups list` [`--location`=`LOCATION`] [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List intercept deployment groups. 

For more examples, refer to the EXAMPLES section below. 

EXAMPLES
     To list intercept deployment groups in project ID `my-project`, run: 
    
    
    gcloud alpha network-security intercept-deployment-groups list --location=global --project=my-project

OR 
    
    
    gcloud alpha network-security intercept-deployment-groups list --location=global
