NAME
    

gcloud alpha network-security security-profiles wildfire-analysis - manage Security Profiles - WildFire Analysis Profile 
SYNOPSIS
    

`gcloud alpha network-security security-profiles wildfire-analysis` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Security Profiles - WildFire Analysis Profile. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-inline-cloud-analysis-rule](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/add-inline-cloud-analysis-rule)`
     `(ALPHA)` Add a WildFire inline cloud analysis rule to a WildFire Analysis Profile. 
`[add-inline-ml-exception](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/add-inline-ml-exception)`
     `(ALPHA)` Add a WildFire inline machine learning exception to a WildFire Analysis Profile. 
`[add-override](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/add-override)`
     `(ALPHA)` Add an override to a WildFire Analysis Profile. 
`[add-submission-rule](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/add-submission-rule)`
     `(ALPHA)` Add a WildFire submission rule to a WildFire Analysis Profile. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/create)`
     `(ALPHA)` Create a new WildFire Analysis Profile. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/delete)`
     `(ALPHA)` Delete a WildFire Analysis Profile. 
`[delete-inline-cloud-analysis-rule](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/delete-inline-cloud-analysis-rule)`
     `(ALPHA)` Delete a WildFire inline cloud analysis rule from a WildFire Analysis Profile. 
`[delete-inline-ml-exception](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/delete-inline-ml-exception)`
     `(ALPHA)` Delete a WildFire inline machine learning exception from a WildFire Analysis Profile. 
`[delete-override](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/delete-override)`
     `(ALPHA)` Delete an override from a WildFire Analysis Profile. 
`[delete-submission-rule](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/delete-submission-rule)`
     `(ALPHA)` Delete a WildFire submission rule from a WildFire Analysis Profile. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/describe)`
     `(ALPHA)` Describe a WildFire Analysis Security Profile. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/list)`
     `(ALPHA)` List WildFire Analysis Security Profiles. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/update)`
     `(ALPHA)` Update a WildFire Analysis Security Profile. 
`[update-override](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/security-profiles/wildfire-analysis/update-override)`
     `(ALPHA)` Update an override in a WildFire Analysis Profile.
