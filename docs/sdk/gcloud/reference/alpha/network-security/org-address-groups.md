NAME
    

gcloud alpha network-security org-address-groups - manage Network Security AddressGroups 
SYNOPSIS
    

`gcloud alpha network-security org-address-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Security AddressGroups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-items](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/add-items)`
     `(ALPHA)` Add items to an address group of organization. 
`[clone-items](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/clone-items)`
     `(ALPHA)` Clone items from source address group of organization. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/create)`
     `(ALPHA)` Create an address group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/delete)`
     `(ALPHA)` Delete address group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/describe)`
     `(ALPHA)` Describe an address group. 
`[force-start-progressive-rollout](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/force-start-progressive-rollout)`
     `(ALPHA)` Force start progressive rollout of an Organization Address Group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/list)`
     `(ALPHA)` List address groups. 
`[list-references](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/list-references)`
     `(ALPHA)` Lists References of an Organization Address Group. 
`[remove-items](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/remove-items)`
     `(ALPHA)` Remove items from an address group of organization. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups/update)`
     `(ALPHA)` Update an address group. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-security org-address-groups](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/org-address-groups)
    
    
    [gcloud beta network-security org-address-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups)
