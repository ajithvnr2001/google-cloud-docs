NAME
    

gcloud alpha network-security backend-authentication-configs - manage Network Security BackendAuthenticationConfigs 
SYNOPSIS
    

`gcloud alpha network-security backend-authentication-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Security BackendAuthenticationConfigs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/backend-authentication-configs/create)`
     `(ALPHA)` Create a BackendAuthenticationConfig. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/backend-authentication-configs/delete)`
     `(ALPHA)` Delete BackendAuthenticationConfig. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/backend-authentication-configs/describe)`
     `(ALPHA)` Describe BackendAuthenticationConfig. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/backend-authentication-configs/export)`
     `(ALPHA)` Export BackendAuthenticationConfig. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/backend-authentication-configs/import)`
     `(ALPHA)` Import BackendAuthenticationConfigs. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/backend-authentication-configs/list)`
     `(ALPHA)` List BackendAuthenticationConfigs. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
