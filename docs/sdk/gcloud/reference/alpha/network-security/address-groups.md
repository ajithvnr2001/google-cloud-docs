NAME
    

gcloud alpha network-security address-groups - manage Network Security AddressGroups 
SYNOPSIS
    

`gcloud alpha network-security address-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Security AddressGroups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-items](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/add-items)`
     `(ALPHA)` Add items to an address group. 
`[clone-items](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/clone-items)`
     `(ALPHA)` Clone items from source address group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/create)`
     `(ALPHA)` Create an address group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/delete)`
     `(ALPHA)` Delete address group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/describe)`
     `(ALPHA)` Describe an address group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/list)`
     `(ALPHA)` List address groups. 
`[list-references](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/list-references)`
     `(ALPHA)` Lists References of an Address Group. 
`[remove-items](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/remove-items)`
     `(ALPHA)` Remove items from an address group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/address-groups/update)`
     `(ALPHA)` Update an address group. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-security address-groups](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/address-groups)
    
    
    [gcloud beta network-security address-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/address-groups)
