NAME
    

gcloud alpha network-security mirroring-deployments - manage Mirroring Deployment resources 
SYNOPSIS
    

`gcloud alpha network-security mirroring-deployments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` This class provides commands for managing Mirroring Deployments. 

Attributes: category (str): The category under which this command group falls. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/mirroring-deployments/create)`
     `(ALPHA)` Create a Mirroring Deployment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/mirroring-deployments/delete)`
     `(ALPHA)` Delete a Mirroring Deployment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/mirroring-deployments/describe)`
     `(ALPHA)` Describe a Mirroring Deployment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/mirroring-deployments/list)`
     `(ALPHA)` List Mirroring Deployments. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/mirroring-deployments/update)`
     `(ALPHA)` Update a Mirroring Deployment. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-security mirroring-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/mirroring-deployments)
    
    
    [gcloud beta network-security mirroring-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/mirroring-deployments)
