NAME
    

gcloud alpha network-security operations - manage Network Security Operations 
SYNOPSIS
    

`gcloud alpha network-security operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Security Operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/operations/cancel)`
     `(ALPHA)` Cancel a Network Security long running operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/operations/describe)`
     `(ALPHA)` Show details of a Network Security long running operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/operations/list)`
     `(ALPHA)` List all Network Security long running operations. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/operations/wait)`
     `(ALPHA)` Poll a Network Security long running operation. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-security operations](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/operations)
    
    
    [gcloud beta network-security operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/operations)
