NAME
    

gcloud alpha network-security firewall-endpoints - create and manage Firewall Plus endpoints 
SYNOPSIS
    

`gcloud alpha network-security firewall-endpoints` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Firewall Plus endpoints. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[wildfire-verdict-change-requests](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/firewall-endpoints/wildfire-verdict-change-requests)`
     `(ALPHA)` Manage WildFire Verdict Change Requests. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/firewall-endpoints/create)`
     `(ALPHA)` Create a Firewall Plus endpoint. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/firewall-endpoints/delete)`
     `(ALPHA)` Delete a Firewall Plus endpoint. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/firewall-endpoints/describe)`
     `(ALPHA)` Describe a Firewall Plus endpoint. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/firewall-endpoints/list)`
     `(ALPHA)` List Firewall Plus endpoints. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/firewall-endpoints/update)`
     `(ALPHA)` Update a Firewall Plus endpoint. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-security firewall-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/firewall-endpoints)
    
    
    [gcloud beta network-security firewall-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/firewall-endpoints)
