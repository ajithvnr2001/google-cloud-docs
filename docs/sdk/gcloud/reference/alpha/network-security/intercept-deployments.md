NAME
    

gcloud alpha network-security intercept-deployments - manage Intercept Deployment resources 
SYNOPSIS
    

`gcloud alpha network-security intercept-deployments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud intercept-deployments command group lets you manage zonal deployments for your Intercept Deployment Group. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/intercept-deployments/create)`
     `(ALPHA)` Create an Intercept Deployment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/intercept-deployments/delete)`
     `(ALPHA)` Delete an Intercept Deployment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/intercept-deployments/describe)`
     `(ALPHA)` Describe an Intercept Deployment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/intercept-deployments/list)`
     `(ALPHA)` List Intercept Deployments. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/intercept-deployments/update)`
     `(ALPHA)` Update an Intercept Deployment. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-security intercept-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/intercept-deployments)
    
    
    [gcloud beta network-security intercept-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/intercept-deployments)
