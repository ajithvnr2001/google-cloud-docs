NAME
    

gcloud alpha network-connectivity hubs - manage Network Connectivity Center hubs 
SYNOPSIS
    

`gcloud alpha network-connectivity hubs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Connectivity Center hubs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/hubs/create)`
     `(ALPHA)` Create a new hub. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/hubs/delete)`
     `(ALPHA)` Delete a hub. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/hubs/describe)`
     `(ALPHA)` Describe a hub. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/hubs/list)`
     `(ALPHA)` List hubs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/hubs/update)`
     `(ALPHA)` Update a hub. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-connectivity hubs](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/hubs)
    
    
    [gcloud beta network-connectivity hubs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs)
