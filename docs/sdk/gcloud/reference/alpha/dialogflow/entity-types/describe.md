NAME
    

gcloud alpha dialogflow entity-types describe - describe a Dialogflow entity type 
SYNOPSIS
    

`gcloud alpha dialogflow entity-types describe` `ENTITY_TYPE` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Describe a Dialogflow entity type. 
EXAMPLES
     To delete an entity type: 
    
    
    gcloud alpha dialogflow entity-types describe 12345678-1234-1234-1234-1234567890ab

POSITIONAL ARGUMENTS
    

EntityType resource - Entity type to describe. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `entity_type` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`ENTITY_TYPE`
     ID of the entityType or fully qualified identifier for the entityType. 

To set the `entity_type` attribute: 

  * provide the argument `entity_type` on the command line.
