NAME
    

gcloud alpha spanner backups - manage Cloud Spanner backups 
SYNOPSIS
    

`gcloud alpha spanner backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Spanner backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Cloud Spanner backup. 
`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/copy)`
     `(ALPHA)` Copies a backup of a Cloud Spanner database. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/create)`
     `(ALPHA)` Creates a backup of a Cloud Spanner database. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/delete)`
     `(ALPHA)` Delete an existing backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/describe)`
     `(ALPHA)` Retrieves information about a backup. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Cloud Spanner backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/list)`
     `(ALPHA)` List existing Cloud Spanner Cloud Spanner backups. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Cloud Spanner backup. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Spanner backup. 
`[update-metadata](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups/update-metadata)`
     `(ALPHA)` Updates the metadata of a Cloud Spanner a backup. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud spanner backups](https://docs.cloud.google.com/sdk/gcloud/reference/spanner/backups)
    
    
    [gcloud beta spanner backups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups)
