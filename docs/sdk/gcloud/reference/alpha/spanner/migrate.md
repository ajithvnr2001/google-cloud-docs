NAME
    

gcloud alpha spanner migrate - migrate external databases to Cloud Spanner 
SYNOPSIS
    

`gcloud alpha spanner migrate` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Migrate external databases to Cloud Spanner. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cleanup](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/migrate/cleanup)`
     `(ALPHA)` Cleanup migration resources given a data migration job id. 
`[data](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/migrate/data)`
     `(ALPHA)` Migrate data from a source database to Cloud Spanner given a schema. 
`[schema](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/migrate/schema)`
     `(ALPHA)` Migrate schema from a source database to Cloud Spanner. 
`[schema-and-data](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/migrate/schema-and-data)`
     `(ALPHA)` Migrate data from a source database to Cloud Spanner given a schema. 
`[web](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/migrate/web)`
     `(ALPHA)` Run the web UI assistant for schema migrations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
