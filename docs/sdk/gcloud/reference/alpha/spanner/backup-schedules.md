NAME
    

gcloud alpha spanner backup-schedules - manage Cloud Spanner backup schedules 
SYNOPSIS
    

`gcloud alpha spanner backup-schedules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Spanner backup schedules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Cloud Spanner backup schedule. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/create)`
     `(ALPHA)` Create a Cloud Spanner backup schedule. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/delete)`
     `(ALPHA)` Delete a Cloud Spanner backup schedule. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/describe)`
     `(ALPHA)` Describe a Cloud Spanner backup schedule. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Cloud Spanner backup schedule. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/list)`
     `(ALPHA)` List Cloud Spanner backup schedules. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Cloud Spanner backup schedule. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Spanner backup schedule. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules/update)`
     `(ALPHA)` Update a Cloud Spanner backup schedule. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud spanner backup-schedules](https://docs.cloud.google.com/sdk/gcloud/reference/spanner/backup-schedules)
    
    
    [gcloud beta spanner backup-schedules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backup-schedules)
