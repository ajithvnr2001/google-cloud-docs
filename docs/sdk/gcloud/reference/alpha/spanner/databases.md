NAME
    

gcloud alpha spanner databases - manage Cloud Spanner databases 
SYNOPSIS
    

`gcloud alpha spanner databases` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Spanner databases. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/config)`
     `(ALPHA)` Manage Spanner database configurations. 
`[ddl](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/ddl)`
     `(ALPHA)` Manage the DDL for Cloud Spanner databases. 
`[roles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/roles)`
     `(ALPHA)` Manage Cloud Spanner database roles. 
`[sessions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/sessions)`
     `(ALPHA)` Manage the sessions for Cloud Spanner databases. 
`[splits](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/splits)`
     `(ALPHA)` Manage the split points for Spanner databases. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Cloud Spanner database. 
`[change-quorum](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/change-quorum)`
     `(ALPHA)` Change quorum of a Cloud Spanner database. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/create)`
     `(ALPHA)` Create a Cloud Spanner database. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/delete)`
     `(ALPHA)` Delete a Cloud Spanner database. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/describe)`
     `(ALPHA)` Describe a Cloud Spanner database. 
`[execute-sql](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/execute-sql)`
     `(ALPHA)` Executes a SQL query against a Cloud Spanner database. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Cloud Spanner database. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/import)`
     `(ALPHA)` Import data from various source files to Cloud Spanner. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/list)`
     `(ALPHA)` List the Cloud Spanner databases contained within the given instance. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Cloud Spanner database. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/restore)`
     `(ALPHA)` Restore a Cloud Spanner database. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Spanner database. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/update)`
     `(ALPHA)` Update a Cloud Spanner database. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud spanner databases](https://docs.cloud.google.com/sdk/gcloud/reference/spanner/databases)
    
    
    [gcloud beta spanner databases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/databases)
