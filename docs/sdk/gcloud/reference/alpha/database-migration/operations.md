NAME
    

gcloud alpha database-migration operations - manage Database Migration Service operations 
SYNOPSIS
    

`gcloud alpha database-migration operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Database Migration Service operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/operations/delete)`
     `(ALPHA)` Delete a Database Migration Service operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/operations/describe)`
     `(ALPHA)` Show details about a operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/operations/list)`
     `(ALPHA)` List operations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud database-migration operations](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/operations)
