NAME
    

gcloud alpha database-migration migration-jobs - manage Database Migration Service migration jobs 
SYNOPSIS
    

`gcloud alpha database-migration migration-jobs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Database Migration Service migration jobs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/create)`
     `(ALPHA)` Create a Database Migration Service migration job. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/delete)`
     `(ALPHA)` Delete a Database Migration Service migration job. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/describe)`
     `(ALPHA)` Show details about a Database Migration Service migration job. 
`[generate-ssh-script](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/generate-ssh-script)`
     `(ALPHA)` Generate a SSH script for a Database Migration Service migration job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/list)`
     `(ALPHA)` List Database Migration Service migration jobs. 
`[promote](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/promote)`
     `(ALPHA)` Promote a Database Migration Service migration job. 
`[restart](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/restart)`
     `(ALPHA)` Restart a Database Migration Service migration job. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/resume)`
     `(ALPHA)` Resume a Database Migration Service migration job. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/start)`
     `(ALPHA)` Start a Database Migration Service migration job. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/stop)`
     `(ALPHA)` Stop a Database Migration Service migration job. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/update)`
     `(ALPHA)` Update a Database Migration Service migration job. 
`[verify](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/migration-jobs/verify)`
     `(ALPHA)` Verify a Database Migration Service migration job. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud database-migration migration-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/migration-jobs)
