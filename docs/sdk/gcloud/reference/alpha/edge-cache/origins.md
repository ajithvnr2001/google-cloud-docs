NAME
    

gcloud alpha edge-cache origins - interact with and manage EdgeCacheOrigin resources 
SYNOPSIS
    

`gcloud alpha edge-cache origins` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Interact with and manage EdgeCacheOrigin resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins/create)`
     `(ALPHA)` Create an EdgeCacheOrigin resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins/delete)`
     `(ALPHA)` Delete an EdgeCacheOrigin resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins/describe)`
     `(ALPHA)` Show details about an EdgeCacheOrigin resource. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins/export)`
     `(ALPHA)` Export an EdgeCacheOrigin resource. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins/import)`
     `(ALPHA)` Import an EdgeCacheOrigin resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins/list)`
     `(ALPHA)` List all EdgeCacheOrigin resources in a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins/update)`
     `(ALPHA)` Update an EdgeCacheOrigin resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cache origins](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins)
