#  gcloud alpha agent-identity auth-providers Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha agent-identity auth-providers - manage Auth Provider resources 
SYNOPSIS
    

`gcloud alpha agent-identity auth-providers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Auth Provider resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations)`
     `(ALPHA)` Manage Authorization resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to an Agent Identity authProvider. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/create)`
     `(ALPHA)` Create an auth provider. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/delete)`
     `(ALPHA)` Delete an auth provider. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/describe)`
     `(ALPHA)` Describe an auth provider. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/disable)`
     `(ALPHA)` Disable an auth provider. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/enable)`
     `(ALPHA)` Enable an auth provider. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for an Agent Identity authProvider. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/list)`
     `(ALPHA)` List auth providers. 
`[query](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/query)`
     `(ALPHA)` Query auth providers used by a workload. 
`[query-workloads](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/query-workloads)`
     `(ALPHA)` Query workloads using an auth provider. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from an Agent Identity authProvider. 
`[resolve-authorization](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/resolve-authorization)`
     `(ALPHA)` Resolve authorization for a user on an auth provider. 
`[revoke-authorization](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/revoke-authorization)`
     `(ALPHA)` Revoke authorization for a user on an auth provider. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for an Agent Identity authProvider. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for an Agent Identity authProvider. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/undelete)`
     `(ALPHA)` Undelete an auth provider. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/update)`
     `(ALPHA)` Update an auth provider. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
