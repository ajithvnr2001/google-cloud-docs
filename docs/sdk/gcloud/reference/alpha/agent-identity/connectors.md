NAME
    

gcloud alpha agent-identity connectors - manage Connector resources 
SYNOPSIS
    

`gcloud alpha agent-identity connectors` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Connector resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/authorizations)`
     `(ALPHA)` Manage Authorization resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to an Agent Identity connector. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/create)`
     `(ALPHA)` Create connectors. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/delete)`
     `(ALPHA)` Delete connectors. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/describe)`
     `(ALPHA)` Describe connectors. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for an Agent Identity connector. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/list)`
     `(ALPHA)` List connectors. 
`[query](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/query)`
     `(ALPHA)` query connectors. 
`[query-workloads](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/query-workloads)`
     `(ALPHA)` query connectors. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from an Agent Identity connector. 
`[revoke-authorization](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/revoke-authorization)`
     `(ALPHA)` revoke connectors. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for an Agent Identity connector. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for an Agent Identity connector. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/undelete)`
     `(ALPHA)` undelete connectors. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors/update)`
     `(ALPHA)` Update connectors. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
