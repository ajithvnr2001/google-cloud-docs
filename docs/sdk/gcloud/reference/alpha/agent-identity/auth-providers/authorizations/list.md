NAME
    

gcloud alpha agent-identity auth-providers authorizations list - list authorizations 
SYNOPSIS
    

`gcloud alpha agent-identity auth-providers authorizations list` (`--auth-provider`=`AUTH_PROVIDER` : `--location`=`LOCATION`) [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List authorizations for a given auth provider in a project and location. 
EXAMPLES
     To list authorizations for auth provider 'my-auth-provider' in location 'us-central1' and project 'my-project', run: 
    
    
    gcloud alpha agent-identity auth-providers authorizations list --auth-provider=my-auth-provider --location=us-central1 --project=my-project

REQUIRED FLAGS
    

AuthProvider resource - The parent resource where the search is performed. Format: projects/{project}/locations/{location}/authProviders/{auth_provider} The arguments in this group can be used to specify the attributes of this resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--auth-provider` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`--auth-provider`=`AUTH_PROVIDER`
     ID of the authProvider or fully qualified identifier for the authProvider. 

To set the `auth-provider` attribute: 

  * provide the argument `--auth-provider` on the command line. 



This flag argument must be specified if any of the other arguments in this group are specified. 

`--location`=`LOCATION`
     The location id of the authProvider resource. 

To set the `location` attribute: 

  * provide the argument `--auth-provider` on the command line with a fully specified name; 
  * provide the argument `--location` on the command line.
