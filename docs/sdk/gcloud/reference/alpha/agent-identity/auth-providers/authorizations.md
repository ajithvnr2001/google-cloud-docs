NAME
    

gcloud alpha agent-identity auth-providers authorizations - manage Authorization resources 
SYNOPSIS
    

`gcloud alpha agent-identity auth-providers authorizations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Authorization resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to an Agent Identity authorization. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/delete)`
     `(ALPHA)` Delete an authorization. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/describe)`
     `(ALPHA)` Describe an authorization. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for an Agent Identity authorization. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/list)`
     `(ALPHA)` List authorizations. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from an Agent Identity authorization. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for an Agent Identity authorization. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for an Agent Identity authorization. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud agent-identity auth-providers authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/agent-identity/auth-providers/authorizations)
    
    
    [gcloud beta agent-identity auth-providers authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations)
