NAME
    

gcloud alpha number-registry - manage Cloud Number Registry resources 
SYNOPSIS
    

`gcloud alpha number-registry` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Number Registry resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[custom-ranges](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/custom-ranges)`
     `(ALPHA)` Manage custom range resources. 
`[discovered-ranges](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/discovered-ranges)`
     `(ALPHA)` Manage discovered range resources. 
`[ipam-admin-scopes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes)`
     `(ALPHA)` Manage IPAM admin scopes. This is the scope of which resources CNR can discover. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/operations)`
     `(ALPHA)` Manage Operation resources. 
`[org-number-registries](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/org-number-registries)`
     `(ALPHA)` Manage org number registry resources. 
`[realms](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/realms)`
     `(ALPHA)` Manage discovered and custom realm resources. 
`[registry-books](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/registry-books)`
     `(ALPHA)` Manage registry book resources. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
