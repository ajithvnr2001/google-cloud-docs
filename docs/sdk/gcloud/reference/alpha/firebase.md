NAME
    

gcloud alpha firebase - work with Google Firebase 
SYNOPSIS
    

`gcloud alpha firebase` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` To view all options available for using Firebase Test Lab, run: 
    
    
    [gcloud alpha firebase test](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test) --help

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[apps](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/apps)`
     `(ALPHA)` Manage Firebase applications. 
`[auth](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/auth)`
     `(ALPHA)` Manage Firebase Authentication. 
`[projects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/projects)`
     `(ALPHA)` Manage and provision Firebase projects. 
`[security-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/security-rules)`
     `(ALPHA)` Manage Firebase Security Rules releases and rulesets. 
`[test](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test)`
     `(ALPHA)` Interact with Firebase Test Lab. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud firebase](https://docs.cloud.google.com/sdk/gcloud/reference/firebase)
    
    
    [gcloud beta firebase](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase)
