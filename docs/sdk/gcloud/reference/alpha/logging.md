NAME
    

gcloud alpha logging - manage Cloud Logging 
SYNOPSIS
    

`gcloud alpha logging` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Logging. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[buckets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/buckets)`
     `(ALPHA)` Manage Cloud Logging buckets. 
`[links](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/links)`
     `(ALPHA)` Manage linked datasets. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/locations)`
     `(ALPHA)` Query Cloud Logging locations. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/logs)`
     `(ALPHA)` Manages your project's logs. 
`[metrics](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/metrics)`
     `(ALPHA)` Manages logs-based metrics. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/operations)`
     `(ALPHA)` Manage long running operations. 
`[resource-descriptors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/resource-descriptors)`
     `(ALPHA)` Get information about resource descriptors. 
`[settings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/settings)`
     `(ALPHA)` Manages the org settings for the Cloud Logging Logs Router. 
`[sinks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/sinks)`
     `(ALPHA)` Manages sinks used to route logs to storage or export destinations. 
`[views](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/views)`
     `(ALPHA)` Manage log views. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/copy)`
     `(ALPHA)` Copy log entries. 
`[read](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/read)`
     `(ALPHA)` Read log entries. 
`[tail](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/tail)`
     `(ALPHA)` Tail log entries. 
`[write](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/write)`
     `(ALPHA)` Write a log entry. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud logging](https://docs.cloud.google.com/sdk/gcloud/reference/logging)
    
    
    [gcloud beta logging](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging)
