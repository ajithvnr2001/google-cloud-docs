NAME
    

gcloud alpha notebooks - notebooks Command Group 
SYNOPSIS
    

`gcloud alpha notebooks` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Notebooks Command Group. 

This command is deprecated. Please use `[gcloud notebooks](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[environments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/notebooks/environments)`
     `(ALPHA)` `(DEPRECATED)` Notebooks Environments Command Group. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/notebooks/instances)`
     `(ALPHA)` `(DEPRECATED)` Notebooks Instances command group. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/notebooks/locations)`
     `(ALPHA)` `(DEPRECATED)` View locations available for a project. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud notebooks](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks)
    
    
    [gcloud beta notebooks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/notebooks)
