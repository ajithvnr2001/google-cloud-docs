NAME
    

gcloud alpha edge-cloud zones - manage zone operations for Google Distributed Cloud 
SYNOPSIS
    

`gcloud alpha edge-cloud zones` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage zone operations for Google Distributed Cloud. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[roles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/zones/roles)`
     `(ALPHA)` Manage roles for Google Distributed Cloud Zones. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/zones/describe)`
     `(ALPHA)` Describe a Google Distributed Cloud zone. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/zones/get-iam-policy)`
     `(ALPHA)` Get IAM policy for a project on the Google Distributed Cloud zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/zones/list)`
     `(ALPHA)` List Google Distributed Cloud zones. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/zones/set-iam-policy)`
     `(ALPHA)` Set IAM policy for a project on the Google Distributed Cloud zone. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud zones](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/zones)
