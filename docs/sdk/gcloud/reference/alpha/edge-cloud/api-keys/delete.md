NAME
    

gcloud alpha edge-cloud api-keys delete - delete a Google Distributed Cloud API key 
SYNOPSIS
    

`gcloud alpha edge-cloud api-keys delete` (`API_KEY` : `--location`=`LOCATION`) [`--async`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Deletes the specified Google Distributed Cloud API key. 
EXAMPLES
     To delete an API key called `test-api-key` in project `test-project` and location `us-central1`, run: 
    
    
    gcloud alpha edge-cloud api-keys delete test-api-key --location=us-central1 --project=test-project

POSITIONAL ARGUMENTS
    

ApiKey resource - The Google Distributed Cloud API key to delete. The arguments in this group can be used to specify the attributes of this resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `api_key` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`API_KEY`
     ID of the apiKey or fully qualified identifier for the apiKey. 

To set the `api_key` attribute: 

  * provide the argument `api_key` on the command line. 



This positional argument must be specified if any of the other arguments in this group are specified. 

`--location`=`LOCATION`
     The location name. 

To set the `location` attribute: 

  * provide the argument `api_key` on the command line with a fully specified name; 
  * provide the argument `--location` on the command line. 


FLAGS
    

`--async`
     Return immediately, without waiting for the operation in progress to complete.
