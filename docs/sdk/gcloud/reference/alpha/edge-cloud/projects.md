NAME
    

gcloud alpha edge-cloud projects - google Distributed Cloud Connected Project gcloud commands 
SYNOPSIS
    

`gcloud alpha edge-cloud projects` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Google Distributed Cloud Connected Project gcloud commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/projects/describe)`
     `(ALPHA)` Describe a Google Cloud Platform project enabled on Google Distributed Cloud zone. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/projects/disable)`
     `(ALPHA)` Disables a Google Cloud Platform project on Google Distributed Cloud zone. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/projects/enable)`
     `(ALPHA)` Enables a Google Cloud Platform project on Google Distributed Cloud zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/projects/list)`
     `(ALPHA)` List the Google Cloud Platform projects enabled on Google Distributed Cloud zone. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud projects](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/projects)
