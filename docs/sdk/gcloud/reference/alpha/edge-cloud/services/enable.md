NAME
    

gcloud alpha edge-cloud services enable - enables a Google Cloud Platform service on a Google Distributed Cloud zone 
SYNOPSIS
    

`gcloud alpha edge-cloud services enable` `SERVICE_NAME` `--location`=`LOCATION` `--zone`=`ZONE` [`--async`] [`--id`=`ID`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Enables a Google Cloud Platform service on a Google Distributed Cloud zone. 
EXAMPLES
     To enable `sample-service` service in location `us-central1` in `sample-project` project and `sample-zone` zone, run: 
    
    
    gcloud alpha edge-cloud services enable sample-service --location=us-central1 --project=sample-project --zone=sample-zone

POSITIONAL ARGUMENTS
    

`SERVICE_NAME`
     Google Cloud Platform service name. 
REQUIRED FLAGS
    

Location resource - Google Cloud Platform region This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--location` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`--location`=`LOCATION`
     ID of the location or fully qualified identifier for the location. 

To set the `location` attribute: 

  * provide the argument `--location` on the command line. 


`--zone`=`ZONE`
     Google Distributed Cloud zone. 
OPTIONAL FLAGS
    

`--async`
     Return immediately, without waiting for the operation in progress to complete. 
`--id`=`ID`
     Service ID.
