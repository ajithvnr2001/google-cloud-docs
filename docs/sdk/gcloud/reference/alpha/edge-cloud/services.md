NAME
    

gcloud alpha edge-cloud services - GDC Connected Service gcloud commands 
SYNOPSIS
    

`gcloud alpha edge-cloud services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` GDC Connected Service gcloud commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/services/describe)`
     `(ALPHA)` Describe a Google Cloud Platform service enabled on a Google Distributed Cloud zone. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/services/disable)`
     `(ALPHA)` Disables a Google Cloud Platform service on a Google Distributed Cloud zone. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/services/enable)`
     `(ALPHA)` Enables a Google Cloud Platform service on a Google Distributed Cloud zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/services/list)`
     `(ALPHA)` List Google Cloud Platform services enabled on a Google Distributed Cloud zone. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud services](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/services)
