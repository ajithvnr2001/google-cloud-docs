NAME
    

gcloud alpha edge-cloud auth - google Distributed Cloud Authentication commands group 
SYNOPSIS
    

`gcloud alpha edge-cloud auth` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` This group contains commands for authentication with GDC services. These commands generate tokens that can be used to authenticate with GDC services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[print-identity-token](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/auth/print-identity-token)`
     `(ALPHA)` Print an identity token for a specified audience. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
