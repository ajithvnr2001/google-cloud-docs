NAME
    

gcloud alpha edge-cloud service-accounts keys - google Distributed Cloud Service Account Keys gcloud commands 
SYNOPSIS
    

`gcloud alpha edge-cloud service-accounts keys` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Google Distributed Cloud Service Account Keys gcloud commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/keys/create)`
     `(ALPHA)` Create service account key for a service account on a Google Distributed Cloud zone. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/keys/describe)`
     `(ALPHA)` Describe a service account key for a service account on a Google Distributed Cloud zone. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/keys/disable)`
     `(ALPHA)` Disable a service account key for a service account on a Google Distributed Cloud zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/keys/list)`
     `(ALPHA)` List service account keys for a service account on a Google Distributed Cloud zone. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud service-accounts keys](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/service-accounts/keys)
