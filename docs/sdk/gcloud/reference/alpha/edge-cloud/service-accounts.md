NAME
    

gcloud alpha edge-cloud service-accounts - google Distributed Cloud Service Account gcloud commands 
SYNOPSIS
    

`gcloud alpha edge-cloud service-accounts` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Google Distributed Cloud Service Account gcloud commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/keys)`
     `(ALPHA)` Google Distributed Cloud Service Account Keys gcloud commands. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/create)`
     `(ALPHA)` Creates a Service Account on a Google Distributed Cloud zone. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/delete)`
     `(ALPHA)` Deletes a Service Account on a Google Distributed Cloud zone. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/describe)`
     `(ALPHA)` Describes a Service Account on a Google Distributed Cloud zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/list)`
     `(ALPHA)` List Service Accounts in a given project and location on a Google Distributed Cloud zone. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud service-accounts](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/service-accounts)
