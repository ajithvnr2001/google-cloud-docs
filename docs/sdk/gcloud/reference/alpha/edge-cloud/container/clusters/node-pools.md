NAME
    

gcloud alpha edge-cloud container clusters node-pools - manage Kubernetes Edge node pools 
SYNOPSIS
    

`gcloud alpha edge-cloud container clusters node-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Kubernetes Edge node pools. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/node-pools/create)`
     `(ALPHA)` Create an Edge Container node pool. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/node-pools/delete)`
     `(ALPHA)` Delete an Edge Container nodePool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/node-pools/describe)`
     `(ALPHA)` Show details about the nodePool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/node-pools/list)`
     `(ALPHA)` List Edge Container nodePools. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/node-pools/update)`
     `(ALPHA)` Updates an Edge Container node pool. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud container clusters node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/container/clusters/node-pools)
