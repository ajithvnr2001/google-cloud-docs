NAME
    

gcloud alpha edge-cloud container clusters - manage Kubernetes Edge clusters 
SYNOPSIS
    

`gcloud alpha edge-cloud container clusters` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Kubernetes Edge clusters. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/node-pools)`
     `(ALPHA)` Manage Kubernetes Edge node pools. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/create)`
     `(ALPHA)` Create an Edge Container cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/delete)`
     `(ALPHA)` Delete an Edge Container cluster. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/describe)`
     `(ALPHA)` Show details about the cluster. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/get-credentials)`
     `(ALPHA)` Get credentials of an edge-container cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/list)`
     `(ALPHA)` List Edge Container clusters. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/update)`
     `(ALPHA)` Update an Edge Container cluster. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container/clusters/upgrade)`
     `(ALPHA)` Upgrade an Edge Container cluster. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud container clusters](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/container/clusters)
