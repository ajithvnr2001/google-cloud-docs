NAME
    

gcloud alpha backup-dr - manage Backup and DR resources 
SYNOPSIS
    

`gcloud alpha backup-dr` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Backup and DR resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[applied-auto-protection-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/applied-auto-protection-policies)`
     `(ALPHA)` Manage Backup and DR AppliedAutoProtectionPolicies. 
`[auto-protection-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/auto-protection-bindings)`
     `(ALPHA)` Manage Backup and DR auto protection bindings. 
`[auto-protection-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/auto-protection-policies)`
     `(ALPHA)` Manage Backup and DR AutoProtectionPolicies. 
`[backup-plan-associations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/backup-plan-associations)`
     `(ALPHA)` Manage Backup and DR backup plan associations. 
`[backup-plan-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/backup-plan-revisions)`
     `(ALPHA)` View Backup and DR backup plan revisions. 
`[backup-plans](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/backup-plans)`
     `(ALPHA)` Manage Backup and DR backup plans. 
`[backup-vaults](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/backup-vaults)`
     `(ALPHA)` Manage Backup and DR backup vaults. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/backups)`
     `(ALPHA)` Manage Backup and DR backups. 
`[binding-matching-resources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/binding-matching-resources)`
     `(ALPHA)` Manage Backup and DR binding matching resources. 
`[data-source-references](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/data-source-references)`
     `(ALPHA)` Command group for Backup and DR Data Source References. 
`[data-sources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/data-sources)`
     `(ALPHA)` View Backup and DR data sources. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/locations)`
     `(ALPHA)` Manage Backup and DR locations. 
`[management-servers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/management-servers)`
     `(ALPHA)` Manage Backup and DR management server. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/operations)`
     `(ALPHA)` Manage Backup and DR operations. 
`[resource-backup-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/resource-backup-config)`
     `(ALPHA)` Show protection summary for resources in a particular location and project. 
`[service-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/service-config)`
     `(ALPHA)` Manage Backup and DR Service configuration.

     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
