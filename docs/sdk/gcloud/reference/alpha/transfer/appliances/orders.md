NAME
    

gcloud alpha transfer appliances orders - manage Transfer Appliance Orders 
SYNOPSIS
    

`gcloud alpha transfer appliances orders` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Transfer Appliances are high-capacity storage devices that enable the transfer and secure shipment of data to a Google upload facility, where data is uploaded to Cloud Storage. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/appliances/orders/create)`
     `(ALPHA)` Create an order for a transfer appliance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/appliances/orders/delete)`
     `(ALPHA)` Delete transfer appliance orders. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/appliances/orders/describe)`
     `(ALPHA)` Get information about Transfer Appliance orders. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/appliances/orders/list)`
     `(ALPHA)` List Transfer Appliance orders. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/appliances/orders/update)`
     `(ALPHA)` Update an order for a transfer appliance. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
