NAME
    

gcloud alpha transfer operations - manage transfer operations 
SYNOPSIS
    

`gcloud alpha transfer operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage transfer operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/operations/cancel)`
     `(ALPHA)` Cancel a transfer operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/operations/describe)`
     `(ALPHA)` Get configuration and latest transfer operation details. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/operations/list)`
     `(ALPHA)` List Transfer Service transfer operations. 
`[monitor](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/operations/monitor)`
     `(ALPHA)` Track progress in real time for a transfer operation. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/operations/pause)`
     `(ALPHA)` Pause a currently running transfer operation. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/operations/resume)`
     `(ALPHA)` Resume a currently paused transfer operation. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud transfer operations](https://docs.cloud.google.com/sdk/gcloud/reference/transfer/operations)
