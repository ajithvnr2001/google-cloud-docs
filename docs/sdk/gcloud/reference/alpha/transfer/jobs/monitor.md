NAME
    

gcloud alpha transfer jobs monitor - track progress in real time for a transfer job's latest operation 
SYNOPSIS
    

`gcloud alpha transfer jobs monitor` `NAME` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Track progress in real time for a transfer job's latest operation. 
EXAMPLES
     To monitor a job, run: 
    
    
    gcloud alpha transfer jobs monitor JOB-NAME

If you're looking for recent error details, use the "Operation name" returned by this command as input to the "operations describe" command: 
    
    
    gcloud alpha transfer jobs monitor JOB-NAME
    
    
    [gcloud alpha transfer operations describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/transfer/operations/describe) OPERATION-NAME

POSITIONAL ARGUMENTS
    

`NAME`
     The name of the job you want to monitor (you'll see details for the job's latest operation).
