NAME
    

gcloud alpha bigtable - manage your Cloud Bigtable storage 
SYNOPSIS
    

`gcloud alpha bigtable` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage your Cloud Bigtable storage. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[app-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/app-profiles)`
     `(ALPHA)` Manage Cloud Bigtable app profiles. 
`[authorized-views](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/authorized-views)`
     `(ALPHA)` Manage Cloud Bigtable Authorized Views. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/backups)`
     `(ALPHA)` Manage Cloud Bigtable backups. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/clusters)`
     `(ALPHA)` Manage Cloud Bigtable clusters. 
`[hot-tablets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/hot-tablets)`
     `(ALPHA)` Manage Cloud Bigtable hot tablets. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/instances)`
     `(ALPHA)` Manage Cloud Bigtable instances. 
`[logical-views](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/logical-views)`
     `(ALPHA)` Manage Bigtable logical views. 
`[materialized-views](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/materialized-views)`
     `(ALPHA)` Manage Bigtable materialized views. 
`[memory-layers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/memory-layers)`
     `(ALPHA)` Manage Cloud Bigtable memory layers. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/operations)`
     `(ALPHA)` Manage Cloud Bigtable operations. 
`[schema-bundles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/schema-bundles)`
     `(ALPHA)` Manage Bigtable schema bundles. 
`[tables](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/tables)`
     `(ALPHA)` Query Cloud Bigtable tables. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud bigtable](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable)
    
    
    [gcloud beta bigtable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable)
