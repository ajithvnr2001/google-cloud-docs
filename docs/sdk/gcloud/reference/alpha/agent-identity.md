NAME
    

gcloud alpha agent-identity - manage Agent Identity resources 
SYNOPSIS
    

`gcloud alpha agent-identity` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Agent Identity resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[access-events](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/access-events)`
     `(ALPHA)` Manage Access Event resources. 
`[access-summaries](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/access-summaries)`
     `(ALPHA)` Manage Access Summary resources. 
`[auth-providers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers)`
     `(ALPHA)` Manage Auth Provider resources. 
`[connectors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/connectors)`
     `(ALPHA)` Manage Connector resources. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud agent-identity](https://docs.cloud.google.com/sdk/gcloud/reference/agent-identity)
    
    
    [gcloud beta agent-identity](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity)
