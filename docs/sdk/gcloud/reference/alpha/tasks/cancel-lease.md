NAME
    

gcloud alpha tasks cancel-lease - cancel the lease on a task in a pull queue 
SYNOPSIS
    

`gcloud alpha tasks cancel-lease` `TASK` `--schedule-time`=`SCHEDULE_TIME` [`--location`=`LOCATION`] [`--queue`=`QUEUE`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Cancel the lease on a task in a pull queue. 
POSITIONAL ARGUMENTS
    

`TASK`
     The task to cancel the lease of. 
REQUIRED FLAGS
    

`--schedule-time`=`SCHEDULE_TIME`
     The task's current schedule time. This restriction is to check that the caller is canceling the correct task. 
OPTIONAL FLAGS
    

`--location`=`LOCATION`
     The location where we want to manage the queue or task. If not specified, uses the location of the current project's App Engine app if there is an associated app. 
`--queue`=`QUEUE`
     The queue the task belongs to.
