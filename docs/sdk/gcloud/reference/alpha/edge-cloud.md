NAME
    

gcloud alpha edge-cloud - manage edge-cloud resources 
SYNOPSIS
    

`gcloud alpha edge-cloud` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage edge-cloud resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/api-keys)`
     `(ALPHA)` Read and manipulate API keys for Google Distributed Cloud. 
`[auth](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/auth)`
     `(ALPHA)` Google Distributed Cloud Authentication commands group. 
`[container](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/container)`
     `(ALPHA)` Manage Edge Container resources. 
`[identity-providers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/identity-providers)`
     `(ALPHA)` The Google Distributed Cloud Identity Provider gcloud commands. 
`[networking](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/networking)`
     `(ALPHA)` Manage Distributed Cloud Edge Network resources. 
`[projects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/projects)`
     `(ALPHA)` Google Distributed Cloud Connected Project gcloud commands. 
`[service-accounts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts)`
     `(ALPHA)` Google Distributed Cloud Service Account gcloud commands. 
`[services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/services)`
     `(ALPHA)` GDC Connected Service gcloud commands. 
`[zones](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/zones)`
     `(ALPHA)` Manage zone operations for Google Distributed Cloud. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud edge-cloud](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud)
