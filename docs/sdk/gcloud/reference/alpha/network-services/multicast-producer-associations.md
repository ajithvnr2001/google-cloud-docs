NAME
    

gcloud alpha network-services multicast-producer-associations - manage Network Services MulticastProducerAssociations 
SYNOPSIS
    

`gcloud alpha network-services multicast-producer-associations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Services MulticastProducerAssociations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/multicast-producer-associations/create)`
     `(ALPHA)` Create a multicast producer association. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/multicast-producer-associations/delete)`
     `(ALPHA)` Delete a multicast producer association. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/multicast-producer-associations/describe)`
     `(ALPHA)` Describe a multicast producer associations. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/multicast-producer-associations/list)`
     `(ALPHA)` List multicast producer associations. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/multicast-producer-associations/update)`
     `(ALPHA)` Update a multicast producer association. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
