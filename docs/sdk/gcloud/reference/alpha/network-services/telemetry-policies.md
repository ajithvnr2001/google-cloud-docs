NAME
    

gcloud alpha network-services telemetry-policies - manage Network Services Telemetry Policies 
SYNOPSIS
    

`gcloud alpha network-services telemetry-policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Services Telemetry Policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/telemetry-policies/delete)`
     `(ALPHA)` Delete a TelemetryPolicy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/telemetry-policies/describe)`
     `(ALPHA)` Describe a TelemetryPolicy. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/telemetry-policies/export)`
     `(ALPHA)` Export a TelemetryPolicy. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/telemetry-policies/import)`
     `(ALPHA)` Import a TelemetryPolicy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/telemetry-policies/list)`
     `(ALPHA)` List TelemetryPolicies. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta network-services telemetry-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/telemetry-policies)
