NAME
    

gcloud alpha network-services gateways - manage Network Services Gateways 
SYNOPSIS
    

`gcloud alpha network-services gateways` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Services Gateways. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/gateways/delete)`
     `(ALPHA)` Delete a gateway. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/gateways/describe)`
     `(ALPHA)` Describe a gateway. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/gateways/export)`
     `(ALPHA)` Export the configuration for a gateway. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/gateways/import)`
     `(ALPHA)` Import the configuration for a gateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/gateways/list)`
     `(ALPHA)` List gateways. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud network-services gateways](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/gateways)
