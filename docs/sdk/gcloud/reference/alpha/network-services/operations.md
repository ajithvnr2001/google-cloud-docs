NAME
    

gcloud alpha network-services operations - manage Network Services Operations 
SYNOPSIS
    

`gcloud alpha network-services operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Services Operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/operations/cancel)`
     `(ALPHA)` Cancel a Network Services long running operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/operations/describe)`
     `(ALPHA)` Show details of a Network Services long running operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/operations/list)`
     `(ALPHA)` List all Network Services long running operations. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/operations/wait)`
     `(ALPHA)` Poll a Network Services long running operation. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-services operations](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/operations)
    
    
    [gcloud beta network-services operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/operations)
