NAME
    

gcloud alpha active-directory domains sql-integrations - discover Cloud SQL integrations with Managed Microsoft AD domains 
SYNOPSIS
    

`gcloud alpha active-directory domains sql-integrations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Discover Cloud SQL integrations with Managed Microsoft AD domains. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/active-directory/domains/sql-integrations/describe)`
     `(ALPHA)` Describe a Cloud SQL integration against a Managed Microsoft AD domain. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/active-directory/domains/sql-integrations/list)`
     `(ALPHA)` List Cloud SQL Integrations for a Managed Microsoft AD domain. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta active-directory domains sql-integrations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/active-directory/domains/sql-integrations)
