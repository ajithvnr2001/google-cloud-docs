NAME
    

gcloud alpha essential-contacts - manage Essential Contacts 
SYNOPSIS
    

`gcloud alpha essential-contacts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Essential Contacts can be set on a Cloud resource to receive communications from Google Cloud regarding that resource. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[compute](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/essential-contacts/compute)`
     `(ALPHA)` Compute the essential contacts that are subscribed to the specified notification categories for a resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/essential-contacts/create)`
     `(ALPHA)` Create an essential contact. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/essential-contacts/delete)`
     `(ALPHA)` Delete an essential contact. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/essential-contacts/describe)`
     `(ALPHA)` Describe an essential contact. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/essential-contacts/list)`
     `(ALPHA)` List essential contacts for a resource. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/essential-contacts/update)`
     `(ALPHA)` Update an essential contact. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud essential-contacts](https://docs.cloud.google.com/sdk/gcloud/reference/essential-contacts)
    
    
    [gcloud beta essential-contacts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/essential-contacts)
