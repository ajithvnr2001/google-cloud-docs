NAME
    

gcloud alpha ai persistent-resources - create and manage Vertex AI rersistent resources 
SYNOPSIS
    

`gcloud alpha ai persistent-resources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Vertex AI rersistent resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/persistent-resources/create)`
     `(ALPHA)` Create a new persistent resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/persistent-resources/delete)`
     `(ALPHA)` Delete an active Persistent Resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/persistent-resources/describe)`
     `(ALPHA)` Get detailed information about a PersistentResource with a given id. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/persistent-resources/list)`
     `(ALPHA)` Lists the active persistent resources. 
`[reboot](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/persistent-resources/reboot)`
     `(ALPHA)` Reboot an active Persistent Resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud ai persistent-resources](https://docs.cloud.google.com/sdk/gcloud/reference/ai/persistent-resources)
    
    
    [gcloud beta ai persistent-resources](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/persistent-resources)
