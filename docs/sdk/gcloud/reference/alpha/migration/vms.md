NAME
    

gcloud alpha migration vms - provides Migrate to Virtual Machines (VM migration) service functionality 
SYNOPSIS
    

`gcloud alpha migration vms` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud alpha migration vms command group provides the CLI for the Migrate to Virtual Machines API. Google Cloud Migrate to Virtual Machines migrates VMs from on-premises data center and other cloud providers to Google Compute Engine virtual machine (VM) instances. VM Migration API must be enabled in your project. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[disk-migrations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/migration/vms/disk-migrations)`
     `(ALPHA)` Migrates disks to Compute Engine. 
`[image-imports](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/migration/vms/image-imports)`
     `(ALPHA)` Imports images to Google Compute Engine from Google Cloud Storage. 
`[machine-image-imports](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/migration/vms/machine-image-imports)`
     `(ALPHA)` Imports machine images to Google Compute Engine from Google Cloud Storage. 
`[target-projects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/migration/vms/target-projects)`
     `(ALPHA)` Manage Target Projects. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud migration vms](https://docs.cloud.google.com/sdk/gcloud/reference/migration/vms)
