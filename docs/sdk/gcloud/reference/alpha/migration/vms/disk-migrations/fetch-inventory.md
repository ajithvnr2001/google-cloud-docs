NAME
    

gcloud alpha migration vms disk-migrations fetch-inventory - lists source environment volume inventory 
SYNOPSIS
    

`gcloud alpha migration vms disk-migrations fetch-inventory` (`SOURCE` : `--location`=`LOCATION`) [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` gcloud alpha migration vms disk-migrations fetch-inventory prints a detailed list of the source environment volume inventory. To use this command, you must enable VM Migration API in your project. 
EXAMPLES
     To list the source environment volume resources in us-central1 in the AWS source my-aws-source in the default project, run: 
    
    
    gcloud alpha migration vms disk-migrations fetch-inventory my-aws-source --location=us-central1

POSITIONAL ARGUMENTS

The arguments in this group can be used to specify the attributes of this resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways.

  * set the property `core/project`. 



This must be specified.

     ID of the source or fully qualified identifier for the source.
