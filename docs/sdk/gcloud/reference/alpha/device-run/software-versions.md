NAME
    

gcloud alpha device-run software-versions - manage Device Run software versions 
SYNOPSIS
    

`gcloud alpha device-run software-versions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Device Run software versions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/software-versions/describe)`
     `(ALPHA)` Describe a Device Run software version. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/software-versions/list)`
     `(ALPHA)` List available Device Run software versions. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta device-run software-versions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/software-versions)
