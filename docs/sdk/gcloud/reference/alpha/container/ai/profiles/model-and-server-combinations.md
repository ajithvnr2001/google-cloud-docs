NAME
    

gcloud alpha container ai profiles model-and-server-combinations - manage supported model and model servers for GKE Inference Quickstart 
SYNOPSIS
    

`gcloud alpha container ai profiles model-and-server-combinations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage supported model and model servers for GKE Inference Quickstart. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/ai/profiles/model-and-server-combinations/list)`
     `(ALPHA)` List supported model and server combinations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
