NAME
    

gcloud alpha container hub multi-cluster-services - manage Multi-cluster Services Feature 
SYNOPSIS
    

`gcloud alpha container hub multi-cluster-services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Multi-cluster Services Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/multi-cluster-services/describe)`
     `(ALPHA)` Describe the status of the Multi-cluster Services Feature resource. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/multi-cluster-services/disable)`
     `(ALPHA)` Disable the Multi-cluster Services Feature. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/multi-cluster-services/enable)`
     `(ALPHA)` Enable the Multi-cluster Services Feature. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container hub multi-cluster-services](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/multi-cluster-services)
    
    
    [gcloud beta container hub multi-cluster-services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/multi-cluster-services)
