NAME
    

gcloud alpha container hub mesh - manage Service Mesh Feature 
SYNOPSIS
    

`gcloud alpha container hub mesh` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Service Mesh Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[debug](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/mesh/debug)`
     `(ALPHA)` Debug Service Mesh memberships. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/mesh/describe)`
     `(ALPHA)` Describe the status of Service Mesh Feature resource. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/mesh/disable)`
     `(ALPHA)` Disable Service Mesh Feature. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/mesh/enable)`
     `(ALPHA)` Enable Service Mesh Feature. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/mesh/update)`
     `(ALPHA)` Update the configuration of the Service Mesh Feature. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container hub mesh](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/mesh)
    
    
    [gcloud beta container hub mesh](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/mesh)
