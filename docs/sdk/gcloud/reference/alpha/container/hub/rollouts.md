NAME
    

gcloud alpha container hub rollouts - manage rollouts 
SYNOPSIS
    

`gcloud alpha container hub rollouts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage rollouts. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/rollouts/cancel)`
     `(ALPHA)` Cancel a rollout. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/rollouts/delete)`
     `(ALPHA)` Delete a rollout resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/rollouts/describe)`
     `(ALPHA)` Describe a fleet rollout. 
`[force-complete-stage](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/rollouts/force-complete-stage)`
     `(ALPHA)` Force-complete a rollout stage. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/rollouts/list)`
     `(ALPHA)` List all fleet rollouts. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/rollouts/pause)`
     `(ALPHA)` Pause a rollout resource. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/rollouts/resume)`
     `(ALPHA)` Resume a rollout resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container hub rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/rollouts)
    
    
    [gcloud beta container hub rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/rollouts)
