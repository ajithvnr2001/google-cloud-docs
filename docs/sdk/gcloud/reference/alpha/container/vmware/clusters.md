NAME
    

gcloud alpha container vmware clusters - create and manage Anthos clusters on VMware 
SYNOPSIS
    

`gcloud alpha container vmware clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Anthos clusters on VMware. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/create)`
     `(ALPHA)` Create an Anthos cluster on VMware. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/delete)`
     `(ALPHA)` Delete an Anthos cluster on VMware. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/describe)`
     `(ALPHA)` Describe an Anthos cluster on VMware. 
`[enroll](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/enroll)`
     `(ALPHA)` Enroll an Anthos cluster on VMware. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/list)`
     `(ALPHA)` List Anthos clusters on VMware. 
`[query-version-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/query-version-config)`
     `(ALPHA)` Query versions for creating or upgrading an Anthos on VMware user cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/update)`
     `(ALPHA)` Update an Anthos cluster on VMware. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/clusters/upgrade)`
     `(ALPHA)` Centrally upgrade an Anthos cluster on VMware. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container vmware clusters](https://docs.cloud.google.com/sdk/gcloud/reference/container/vmware/clusters)
    
    
    [gcloud beta container vmware clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/clusters)
