NAME
    

gcloud alpha container vmware admin-clusters - create and manage admin clusters in Anthos on VMware 
SYNOPSIS
    

`gcloud alpha container vmware admin-clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage admin clusters in Anthos on VMware. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/admin-clusters/describe)`
     `(ALPHA)` Describe an Anthos on VMware admin cluster. 
`[enroll](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/admin-clusters/enroll)`
     `(ALPHA)` Enroll an Anthos on VMware admin cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/admin-clusters/list)`
     `(ALPHA)` List Anthos on VMware admin clusters. 
`[unenroll](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/admin-clusters/unenroll)`
     `(ALPHA)` Unenroll an Anthos on VMware admin cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/admin-clusters/update)`
     `(ALPHA)` Update an Anthos on VMware admin cluster. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container vmware admin-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/container/vmware/admin-clusters)
    
    
    [gcloud beta container vmware admin-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/admin-clusters)
