NAME
    

gcloud alpha container azure clusters - create and manage Anthos clusters on Azure 
SYNOPSIS
    

`gcloud alpha container azure clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Create and manage Anthos clusters on Azure. 

This command is deprecated. See <https://cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/deprecations/deprecation-announcement> for more details. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clusters/create)`
     `(ALPHA)` `(DEPRECATED)` Create an Anthos cluster on Azure. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clusters/delete)`
     `(ALPHA)` `(DEPRECATED)` Delete an Anthos cluster on Azure. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clusters/describe)`
     `(ALPHA)` `(DEPRECATED)` Describe an Anthos cluster on Azure. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clusters/get-credentials)`
     `(ALPHA)` `(DEPRECATED)` Get credentials of an Anthos cluster on Azure. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clusters/list)`
     `(ALPHA)` `(DEPRECATED)` List Anthos clusters on Azure. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clusters/update)`
     `(ALPHA)` `(DEPRECATED)` Update an Anthos cluster on Azure. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud container azure clusters](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/clusters)
