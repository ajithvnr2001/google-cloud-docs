NAME
    

gcloud alpha container binauthz policy - create and manage Google Binary Authorization policies 
SYNOPSIS
    

`gcloud alpha container binauthz policy` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Google Binary Authorization policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Binary Authorization policy. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/create)`
     `(ALPHA)` Create a Binary Authorization platform policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/delete)`
     `(ALPHA)` Delete a Binary Authorization platform policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/describe)`
     `(ALPHA)` Describe a Binary Authorization platform policy. 
`[evaluate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/evaluate)`
     `(ALPHA)` Evaluate a Binary Authorization platform policy. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/export)`
     `(ALPHA)` Export the Binary Authorization policy for the current project. 
`[export-system-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/export-system-policy)`
     `(ALPHA)` Export the Binary Authorization system policy. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Binary Authorization policy. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/import)`
     `(ALPHA)` Import a Binary Authorization policy to the current project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/list)`
     `(ALPHA)` List Binary Authorization platform policies. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Binary Authorization policy. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Binary Authorization policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz/policy/update)`
     `(ALPHA)` Update a Binary Authorization platform policy. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
