NAME
    

gcloud alpha container aws - deploy and manage clusters of machines on AWS for running containers 
SYNOPSIS
    

`gcloud alpha container aws` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Deploy and manage clusters of machines on AWS for running containers. 

This command is deprecated. See <https://cloud.google.com/kubernetes-engine/multi-cloud/docs/aws/deprecations/deprecation-announcement> for more details. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/aws/clusters)`
     `(ALPHA)` `(DEPRECATED)` Create and manage Anthos clusters on AWS. 
`[node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/aws/node-pools)`
     `(ALPHA)` `(DEPRECATED)` Create and manage node pools in an Anthos cluster on AWS. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/aws/operations)`
     `(ALPHA)` `(DEPRECATED)` Manage Anthos Multi-Cloud long running operations for AWS. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[get-server-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/aws/get-server-config)`
     `(ALPHA)` `(DEPRECATED)` Get Anthos Multi-Cloud server configuration for AWS. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud container aws](https://docs.cloud.google.com/sdk/gcloud/reference/container/aws)
