NAME
    

gcloud alpha container fleet scopes - manage scopes of all your GKE fleets 
SYNOPSIS
    

`gcloud alpha container fleet scopes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage scopes of all your GKE fleets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[namespaces](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/namespaces)`
     `(ALPHA)` Fleet namespaces are the fleet equivalent of k8s cluster namespaces. 
`[rbacrolebindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/rbacrolebindings)`
     `(ALPHA)` Fleet scope RBAC RoleBindings for permissions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-app-operator-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/add-app-operator-binding)`
     `(ALPHA)` Add project-level and fleet scope-level IAM bindings and create a fleet scope RBAC role binding for an app operator principal. 
`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Fleet Scope. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/create)`
     `(ALPHA)` Create a new fleet scope. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/delete)`
     `(ALPHA)` Delete a fleet scope. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/describe)`
     `(ALPHA)` Describe a fleet scope. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Fleet Scope. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/list)`
     `(ALPHA)` List fleet scopes in a project permitted to be viewed by the caller. 
`[list-app-operator-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/list-app-operator-bindings)`
     `(ALPHA)` List app operator principals corresponding to a fleet scope and their roles based on project-level IAM bindings, fleet scope-level IAM bindings, and fleet scope RBAC role bindings. 
`[list-memberships](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/list-memberships)`
     `(ALPHA)` List memberships bound to a fleet scope. 
`[remove-app-operator-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/remove-app-operator-binding)`
     `(ALPHA)` Remove project-level and fleet scope-level IAM bindings and delete a fleet scope RBAC role binding for an app operator principal. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Fleet Scope. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/scopes/update)`
     `(ALPHA)` Update a scope. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
