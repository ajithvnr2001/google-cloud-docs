NAME
    

gcloud alpha container fleet policycontroller - manage Policy Controller Feature 
SYNOPSIS
    

`gcloud alpha container fleet policycontroller` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Policy Controller Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[content](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/content)`
     `(ALPHA)` Manage Policy Controller content. 
`[deployment](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/deployment)`
     `(ALPHA)` Configure Policy Controller component deployments. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/describe)`
     `(ALPHA)` Describe Policy Controller feature. 
`[detach](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/detach)`
     `(ALPHA)` Detach Policy Controller Feature. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/disable)`
     `(ALPHA)` Disable (Uninstall) Policy Controller. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/enable)`
     `(ALPHA)` Enable Policy Controller Feature. 
`[suspend](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/suspend)`
     `(ALPHA)` Suspend Policy Controller Feature. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller/update)`
     `(ALPHA)` Updates the configuration of Policy Controller Feature. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container fleet policycontroller](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/policycontroller)
    
    
    [gcloud beta container fleet policycontroller](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller)
