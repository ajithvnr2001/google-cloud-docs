NAME
    

gcloud alpha container fleet identity-service - manage Identity Service Feature 
SYNOPSIS
    

`gcloud alpha container fleet identity-service` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Identity Service Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[apply](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/identity-service/apply)`
     `(ALPHA)` Update the Identity Service Feature. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/identity-service/delete)`
     `(ALPHA)` Delete a resource from the Identity Service Feature. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/identity-service/describe)`
     `(ALPHA)` Prints the status of all clusters with Identity Service installed. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/identity-service/disable)`
     `(ALPHA)` Disable Identity Service Feature. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/identity-service/enable)`
     `(ALPHA)` Enable the Identity Service Feature. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container fleet identity-service](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/identity-service)
    
    
    [gcloud beta container fleet identity-service](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/identity-service)
