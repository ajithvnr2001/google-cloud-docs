#  gcloud alpha container fleet memberships Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha container fleet memberships - manage memberships of all your GKE and other Kubernetes clusters with fleets 
SYNOPSIS
    

`gcloud alpha container fleet memberships` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage memberships of all your GKE and other Kubernetes clusters with fleets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/bindings)`
     `(ALPHA)` Membership Bindings for permissions. 
`[support-access](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/support-access)`
     `(ALPHA)` Membership used for support access. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/delete)`
     `(ALPHA)` Delete a membership. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/describe)`
     `(ALPHA)` Describe a membership. 
`[generate-gateway-rbac](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/generate-gateway-rbac)`
     `(ALPHA)` Generate RBAC policy files for connected clusters by the user. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/get-credentials)`
     `(ALPHA)` Fetch credentials for a fleet-registered cluster to be used in Connect Gateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/list)`
     `(ALPHA)` List memberships. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/register)`
     `(ALPHA)` Register a cluster with a fleet. 
`[unregister](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/unregister)`
     `(ALPHA)` Unregister a cluster from a fleet. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships/update)`
     `(ALPHA)` Update a membership. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container fleet memberships](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/memberships)
    
    
    [gcloud beta container fleet memberships](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships)
