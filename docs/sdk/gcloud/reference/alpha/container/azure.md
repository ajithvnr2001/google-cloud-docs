NAME
    

gcloud alpha container azure - deploy and manage clusters of machines on Azure for running containers 
SYNOPSIS
    

`gcloud alpha container azure` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Deploy and manage clusters of machines on Azure for running containers. 

This command is deprecated. See <https://cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/deprecations/deprecation-announcement> for more details. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[clients](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clients)`
     `(ALPHA)` `(DEPRECATED)` Create and manage Azure clients. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/clusters)`
     `(ALPHA)` `(DEPRECATED)` Create and manage Anthos clusters on Azure. 
`[node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/node-pools)`
     `(ALPHA)` `(DEPRECATED)` Create and manage node pools in an Anthos cluster on Azure. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/operations)`
     `(ALPHA)` `(DEPRECATED)` Manage Anthos Multi-Cloud long running operations for Azure. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[get-server-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure/get-server-config)`
     `(ALPHA)` `(DEPRECATED)` Get Anthos Multi-Cloud server configuration for Azure. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud container azure](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure)
