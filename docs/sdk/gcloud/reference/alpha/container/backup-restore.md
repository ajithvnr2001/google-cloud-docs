NAME
    

gcloud alpha container backup-restore - backup for GKE Services 
SYNOPSIS
    

`gcloud alpha container backup-restore` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Backup for GKE Services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backup-channels](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backup-channels)`
     `(ALPHA)` Backup for GKE Backup Channels. 
`[backup-plan-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backup-plan-bindings)`
     `(ALPHA)` Backup for GKE Backup Plan Bindings. 
`[backup-plans](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backup-plans)`
     `(ALPHA)` Backup for GKE Backup Plans. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups)`
     `(ALPHA)` Backup for GKE Backups. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/locations)`
     `(ALPHA)` Backup for GKE Locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/operations)`
     `(ALPHA)` Backup for GKE Operations. 
`[restore-channels](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/restore-channels)`
     `(ALPHA)` Backup for GKE Restore Channels. 
`[restore-plan-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/restore-plan-bindings)`
     `(ALPHA)` Backup for GKE Restore Plan Bindings. 
`[restore-plans](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/restore-plans)`
     `(ALPHA)` Backup for GKE Restore Plans. 
`[restores](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/restores)`
     `(ALPHA)` Backup for GKE Restores. 
`[volume-backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/volume-backups)`
     `(ALPHA)` Backup for GKE Volume Backups. 
`[volume-restores](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/volume-restores)`
     `(ALPHA)` Backup for GKE Volume Restores. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta container backup-restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore)
