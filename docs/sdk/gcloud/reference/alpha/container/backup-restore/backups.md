NAME
    

gcloud alpha container backup-restore backups - backup for GKE Backups 
SYNOPSIS
    

`gcloud alpha container backup-restore backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Backup for GKE Backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/create)`
     `(ALPHA)` Creates a backup. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/delete)`
     `(ALPHA)` Delete a backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/describe)`
     `(ALPHA)` Describe a backup. 
`[get-backup-index-download-url](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/get-backup-index-download-url)`
     `(ALPHA)` Get a backup index download URL. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/list)`
     `(ALPHA)` List backups. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a backup. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups/update)`
     `(ALPHA)` Update a backup. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta container backup-restore backups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups)
