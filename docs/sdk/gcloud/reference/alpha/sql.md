NAME
    

gcloud alpha sql - create and manage Google Cloud SQL databases 
SYNOPSIS
    

`gcloud alpha sql` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud sql command group lets you create and manage Google Cloud SQL databases. 

Cloud SQL is a fully-managed database service that makes it easy to set up, maintain, manage, and administer your relational databases in the cloud. 

More information on Cloud SQL can be found here: <https://cloud.google.com/sql> and detailed documentation can be found here: <https://cloud.google.com/sql/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/backups)`
     `(ALPHA)` Provide commands for working with backups of Cloud SQL instances. 
`[blue-green-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/blue-green-deployments)`
     `(ALPHA)` Provide commands for managing Cloud SQL blue-green deployments. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases)`
     `(ALPHA)` Provide commands for managing databases of Cloud SQL instances. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/export)`
     `(ALPHA)` Provide commands to export Cloud SQL instances. 
`[flags](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/flags)`
     `(ALPHA)` Provide a command to list flags. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/import)`
     `(ALPHA)` Provides commands to import Cloud SQL instances. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/instances)`
     `(ALPHA)` Provide commands for managing Cloud SQL instances. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/operations)`
     `(ALPHA)` Provide commands for working with Cloud SQL instance operations. 
`[ssl](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/ssl)`
     `(ALPHA)` Provide commands for managing SSL certificates of Cloud SQL instances. 
`[ssl-certs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/ssl-certs)`
     `(ALPHA)` `(DEPRECATED)` Provide commands for managing SSL certificates of Cloud SQL instances. 
`[tiers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/tiers)`
     `(ALPHA)` Provide a command to list tiers. 
`[users](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/users)`
     `(ALPHA)` Provide commands for managing Cloud SQL users. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[connect](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/connect)`
     `(ALPHA)` Connects to a Cloud SQL instance. 
`[generate-login-token](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/generate-login-token)`
     `(ALPHA)` Generate an IAM login token for Cloud SQL. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/reschedule-maintenance)`
     `(ALPHA)` Reschedule a Cloud SQL instance's maintenance. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud sql](https://docs.cloud.google.com/sdk/gcloud/reference/sql)
    
    
    [gcloud beta sql](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql)
