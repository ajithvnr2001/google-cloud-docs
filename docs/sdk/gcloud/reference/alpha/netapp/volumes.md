NAME
    

gcloud alpha netapp volumes - create and manage Cloud NetApp Volumes 
SYNOPSIS
    

`gcloud alpha netapp volumes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Cloud NetApp Volumes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[replications](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications)`
     `(ALPHA)` Create and manage Cloud NetApp Volume Replications. 
`[snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/snapshots)`
     `(ALPHA)` Create and manage Cloud NetApp Volume Snapshots. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/create)`
     `(ALPHA)` Create a Cloud NetApp Volume. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/delete)`
     `(ALPHA)` Delete a Cloud NetApp Volume. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/describe)`
     `(ALPHA)` Show metadata for a Cloud NetApp Volume. 
`[establish-peering](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/establish-peering)`
     `(ALPHA)` Establish peering for Cache Volumes. 
`[get-split-status](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/get-split-status)`
     `(ALPHA)` Retrieves the split status of a Cloud NetApp clone volume. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/list)`
     `(ALPHA)` List Cloud NetApp Volumes. 
`[restore-backup-files](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/restore-backup-files)`
     `(ALPHA)` Restore specific files from a backup to a Volume. 
`[revert](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/revert)`
     `(ALPHA)` Revert a Cloud NetApp Volume back to a specified Snapshot. 
`[start-split](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/start-split)`
     `(ALPHA)` Starts splitting a Cloud NetApp clone volume from its source volume. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/update)`
     `(ALPHA)` Update a Cloud NetApp Volume. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud netapp volumes](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes)
    
    
    [gcloud beta netapp volumes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/volumes)
