NAME
    

gcloud alpha netapp volumes replications - create and manage Cloud NetApp Volume Replications 
SYNOPSIS
    

`gcloud alpha netapp volumes replications` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Cloud NetApp Volume Replications. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/create)`
     `(ALPHA)` Create a Cloud NetApp Volume Replication. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/delete)`
     `(ALPHA)` Delete a Cloud NetApp Storage Pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/describe)`
     `(ALPHA)` Describe a Cloud NetApp Volume Replication. 
`[establish-peering](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/establish-peering)`
     `(ALPHA)` Establish peering for Hybrid replication. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/list)`
     `(ALPHA)` List Cloud NetApp Volume Replications. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/resume)`
     `(ALPHA)` Resume a Cloud NetApp Volume Replication. 
`[reverse](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/reverse)`
     `(ALPHA)` Reverse a Cloud NetApp Volume Replication's direction. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/stop)`
     `(ALPHA)` Stop a Cloud NetApp Volume Replication. 
`[sync](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/sync)`
     `(ALPHA)` Sync a Cloud NetApp Volume Replication. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/replications/update)`
     `(ALPHA)` Update a Cloud NetApp Volume Replication. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
