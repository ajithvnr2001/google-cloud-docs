NAME
    

gcloud alpha netapp volumes snapshots - create and manage Cloud NetApp Volume Snapshots 
SYNOPSIS
    

`gcloud alpha netapp volumes snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Cloud NetApp Volume Snapshots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/snapshots/create)`
     `(ALPHA)` Creates a Cloud NetApp Volume Snapshot. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/snapshots/delete)`
     `(ALPHA)` Delete a Cloud NetApp Volume Snapshot. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/snapshots/describe)`
     `(ALPHA)` Describe a Cloud NetApp Volume Snapshot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/snapshots/list)`
     `(ALPHA)` List Cloud NetApp Volume Snapshots. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes/snapshots/update)`
     `(ALPHA)` Update a Cloud NetApp Volume Snapshot. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud netapp volumes snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/snapshots)
    
    
    [gcloud beta netapp volumes snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/volumes/snapshots)
