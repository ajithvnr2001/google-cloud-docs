NAME
    

gcloud alpha netapp storage-pools - create and manage Cloud NetApp Storage Pools 
SYNOPSIS
    

`gcloud alpha netapp storage-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage Cloud NetApp Storage Pools. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/create)`
     `(ALPHA)` Create a Cloud NetApp Storage Pool. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/delete)`
     `(ALPHA)` Delete a Cloud NetApp Storage Pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/describe)`
     `(ALPHA)` Show metadata for a Cloud NetApp Storage Pool. 
`[execute](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/execute)`
     `(ALPHA)` Execute an ONTAP CLI command. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/list)`
     `(ALPHA)` List Cloud NetApp Storage Pools. 
`[list-backup-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/list-backup-configs)`
     `(ALPHA)` List backup configurations for all volumes in an ONTAP-mode Storage Pool. 
`[restore-volume](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/restore-volume)`
     `(ALPHA)` Restore a backup to a volume in a specified ONTAP-mode Storage Pool. 
`[switch](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/switch)`
     `(ALPHA)` Switch a Regional Cloud NetApp Flex Storage Pool zone. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/update)`
     `(ALPHA)` Update a Cloud NetApp Storage Pool. 
`[update-backup-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/storage-pools/update-backup-config)`
     `(ALPHA)` Update backup config of a volume in an ONTAP-mode Storage Pool. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud netapp storage-pools](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools)
    
    
    [gcloud beta netapp storage-pools](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/storage-pools)
