NAME
    

gcloud alpha filestore locations - list locations where Filestore is available 
SYNOPSIS
    

`gcloud alpha filestore locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List locations where Filestore is available. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/filestore/locations/describe)`
     `(ALPHA)` Describe a Filestore location. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/filestore/locations/list)`
     `(ALPHA)` List all Filestore locations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud filestore locations](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/locations)
    
    
    [gcloud beta filestore locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/filestore/locations)
