NAME
    

gcloud alpha beyondcorp app - manages application connectors and connections 
SYNOPSIS
    

`gcloud alpha beyondcorp app` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Manages application connectors and connections. 

BeyondCorp App Connector is deprecated and will be removed in a future release. 

The gcloud beyondcorp command group lets you secure non-gcp application by managing connectors and connections. 

BeyondCorp Enterprise offers a zero trust solution that enables secure access with integrated threat and data protection.The solution enables secure access to both Google Cloud Platform and on-prem hosted apps. For remote apps that are not deployed in Google Cloud Platform, BeyondCorp Enterprise's App connector provides simplified connectivity and app publishing experience. More information on Beyondcorp can be found here: <https://cloud.google.com/beyondcorp>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[connections](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/beyondcorp/app/connections)`
     `(ALPHA)` `(DEPRECATED)` Create and manipulate beyondcorp connections. 
`[connectors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/beyondcorp/app/connectors)`
     `(ALPHA)` `(DEPRECATED)` Create and manipulate beyondcorp connectors. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/beyondcorp/app/operations)`
     `(ALPHA)` `(DEPRECATED)` List and Describe beyondcorp appconnector operations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta beyondcorp app](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/app)
