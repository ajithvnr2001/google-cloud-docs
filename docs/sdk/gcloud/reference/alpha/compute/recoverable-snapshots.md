NAME
    

gcloud alpha compute recoverable-snapshots - recover, list, describe and delete Compute Engine recoverable snapshots 
SYNOPSIS
    

`gcloud alpha compute recoverable-snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Recover, list, describe and delete Compute Engine recoverable snapshots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/recoverable-snapshots/delete)`
     `(ALPHA)` Delete Compute Engine recoverable snapshots. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/recoverable-snapshots/describe)`
     `(ALPHA)` Describe a Compute Engine recoverable snapshot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/recoverable-snapshots/list)`
     `(ALPHA)` List Google Compute Engine recoverable snapshots. 
`[recover](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/recoverable-snapshots/recover)`
     `(ALPHA)` Recovers a Compute Engine recoverable snapshot. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/recoverable-snapshots/set-iam-policy)`
     `(ALPHA)` Set the IAM policy binding for a Compute Engine recoverable snapshot. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/recoverable-snapshots/test-iam-permissions)`
     `(ALPHA)` Test the IAM permissions for a Compute Engine recoverable snapshot. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta compute recoverable-snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/recoverable-snapshots)
