NAME
    

gcloud alpha compute routers - list, create, and delete Compute Engine routers 
SYNOPSIS
    

`gcloud alpha compute routers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List, create, and delete Cloud Routers. 

For more information about Cloud Routers, see the [Cloud Router documentation](https://cloud.google.com//network-connectivity/docs/router/concepts/overview). 

See also: [Routers API](https://cloud.google.com/compute/docs/reference/rest/v1/routers). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[nats](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/routers/nats)`
     `(ALPHA)` List, create, describe, and delete Cloud NAT. 
COMMANDS

`[add-bgp-peer](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/routers/add-bgp-peer)`
     `(ALPHA)` Add a BGP peer to a Compute Engine router.

     `(ALPHA)` Add an empty route policy to a Compute Engine router.

     `(ALPHA)` Adds a new term to an existing route policy of a Comute Engine router.
