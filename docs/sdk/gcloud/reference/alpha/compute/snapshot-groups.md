NAME
    

gcloud alpha compute snapshot-groups - create, list, describe and delete Compute Engine snapshot groups 
SYNOPSIS
    

`gcloud alpha compute snapshot-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create, list, describe and delete Compute Engine snapshot groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/snapshot-groups/create)`
     `(ALPHA)` Create a Compute Engine snapshot group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/snapshot-groups/delete)`
     `(ALPHA)` Delete Compute Engine snapshot groups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/snapshot-groups/describe)`
     `(ALPHA)` Describe a Compute Engine snapshot group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/snapshot-groups/list)`
     `(ALPHA)` List Google Compute Engine snapshot groups. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/snapshot-groups/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Compute Engine snapshot group. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/snapshot-groups/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Compute Engine snapshot group. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
