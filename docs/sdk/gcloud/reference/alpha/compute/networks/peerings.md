NAME
    

gcloud alpha compute networks peerings - list, create, delete, and update VPC Network Peering 
SYNOPSIS
    

`gcloud alpha compute networks peerings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List, create, delete, and update VPC Network Peering. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel-request-delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings/cancel-request-delete)`
     `(ALPHA)` Cancel deletion request of a Compute Engine network peering. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings/create)`
     `(ALPHA)` Create a Compute Engine network peering. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings/delete)`
     `(ALPHA)` Delete a Compute Engine network peering. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings/list)`
     `(ALPHA)` List Google Compute Engine peerings. 
`[list-routes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings/list-routes)`
     `(ALPHA)` List received or advertised routes for a VPC network peering. 
`[request-delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings/request-delete)`
     `(ALPHA)` Request deletion of a Compute Engine network peering. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings/update)`
     `(ALPHA)` Update a Compute Engine network peering. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
