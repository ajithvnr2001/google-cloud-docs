NAME
    

gcloud alpha compute network-firewall-policies - manage Compute Engine network firewall policies 
SYNOPSIS
    

`gcloud alpha compute network-firewall-policies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Compute Engine network firewall policies. Network firewall policies are used to control incoming/outgoing traffic. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[associations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/associations)`
     `(ALPHA)` Read and manipulate Compute Engine network firewall policy associations. 
`[mirroring-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/mirroring-rules)`
     `(ALPHA)` Read and manipulate Compute Engine packet mirroring rules in network firewall policy. 
`[rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/rules)`
     `(ALPHA)` Read and manipulate Compute Engine network firewall policy rules. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[clone-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/clone-rules)`
     `(ALPHA)` Replace the rules of a Compute Engine network firewall policy with rules from another policy. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/create)`
     `(ALPHA)` Create a Compute Engine Network firewall policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/delete)`
     `(ALPHA)` Delete a Compute Engine network firewall policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/describe)`
     `(ALPHA)` Describe a Compute Engine network firewall policy. 
`[export-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/export-rules)`
     `(ALPHA)` Export Compute Engine network firewall policy rules. 
`[get-effective-firewalls](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/get-effective-firewalls)`
     `(ALPHA)` Get the effective firewalls for a network. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Compute Engine network firewall policy. 
`[import-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/import-rules)`
     `(ALPHA)` Import a Compute Engine network firewall policy rules. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/list)`
     `(ALPHA)` List Compute Engine network firewall policies. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/set-iam-policy)`
     `(ALPHA)` Set the IAM policy binding for a Compute Engine network firewall policy. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Compute Engine network firewall policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-firewall-policies/update)`
     `(ALPHA)` Update a Compute Engine network firewall policy. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
