NAME
    

gcloud alpha compute composite-health-checks - manage composite health checks 
SYNOPSIS
    

`gcloud alpha compute composite-health-checks` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage composite health checks. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/composite-health-checks/create)`
     `(ALPHA)` Create a composite health check. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/composite-health-checks/delete)`
     `(ALPHA)` Delete a composite health check. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/composite-health-checks/describe)`
     `(ALPHA)` Describe a composite health check. 
`[get-health](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/composite-health-checks/get-health)`
     `(ALPHA)` Get health status of a composite health check. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/composite-health-checks/list)`
     `(ALPHA)` List composite health checks. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/composite-health-checks/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Compute Engine composite health check. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/composite-health-checks/update)`
     `(ALPHA)` Update a composite health check. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud compute composite-health-checks](https://docs.cloud.google.com/sdk/gcloud/reference/compute/composite-health-checks)
    
    
    [gcloud beta compute composite-health-checks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/composite-health-checks)
