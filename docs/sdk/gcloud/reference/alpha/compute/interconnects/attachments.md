NAME
    

gcloud alpha compute interconnects attachments - read and manipulate Compute Engine interconnect attachments 
SYNOPSIS
    

`gcloud alpha compute interconnects attachments` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Read and manipulate Compute Engine interconnect attachments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[dedicated](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/dedicated)`
     `(ALPHA)` Create or manipulate dedicated interconnect attachments. 
`[groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/groups)`
     `(ALPHA)` Create or manipulate interconnect attachment groups. 
`[l2-forwarding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/l2-forwarding)`
     `(ALPHA)` Create or manipulate dedicated interconnect attachments. 
`[partner](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/partner)`
     `(ALPHA)` Create or manipulate partner interconnect attachments. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/delete)`
     `(ALPHA)` Delete Compute Engine interconnect attachments. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/describe)`
     `(ALPHA)` Describe a Compute Engine interconnect attachment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/list)`
     `(ALPHA)` List Google Compute Engine interconnect attachments. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Compute Engine interconnect attachment. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/attachments/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Compute Engine interconnect attachment. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
