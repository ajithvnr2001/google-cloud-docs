NAME
    

gcloud alpha compute interconnects attachments groups delete - delete Compute Engine interconnect attachment groups 
SYNOPSIS
    

`gcloud alpha compute interconnects attachments groups delete` `NAME` [`NAME` …] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `gcloud alpha compute interconnects attachments groups delete` is used to delete interconnect attachment groups. 

For an example, refer to the `EXAMPLES` section below. 

EXAMPLES
     To delete an interconnect attachment group, run: 
    
    
    gcloud alpha compute interconnects attachments groups delete example-attachment-group"

Although not shown in this example, you can delete multiple interconnect attachment groups in a single command. 

POSITIONAL ARGUMENTS
    

`NAME` [`NAME` …]
     Names of the interconnect attachment groups to delete.
