NAME
    

gcloud alpha compute networks - list, create, and delete Compute Engine networks 
SYNOPSIS
    

`gcloud alpha compute networks` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Read and manipulate VPC networks. 

For more information about networks, see the [networks documentation](https://cloud.google.com/vpc/docs/vpc). 

See also: [Networks API](https://cloud.google.com/compute/docs/reference/rest/v1/networks). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[peerings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/peerings)`
     `(ALPHA)` List, create, delete, and update VPC Network Peering. 
`[subnets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/subnets)`
     `(ALPHA)` List, describe, and delete, and update Compute Engine subnetworks. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/create)`
     `(ALPHA)` Create a Compute Engine network. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/delete)`
     `(ALPHA)` Delete Compute Engine networks. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/describe)`
     `(ALPHA)` Describe a Compute Engine network. 
`[get-effective-firewalls](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/get-effective-firewalls)`
     `(ALPHA)` Get the effective firewalls of a Compute Engine network. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/list)`
     `(ALPHA)` List Google Compute Engine networks. 
`[list-ip-addresses](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/list-ip-addresses)`
     `(ALPHA)` List internal IP addresses in a network. 
`[list-ip-owners](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/list-ip-owners)`
     `(ALPHA)` List IP owners in a network. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Compute Engine network. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/networks/update)`
     `(ALPHA)` Update a Compute Engine network. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
