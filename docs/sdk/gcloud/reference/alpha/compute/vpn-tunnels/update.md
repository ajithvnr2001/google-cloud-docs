NAME
    

gcloud alpha compute vpn-tunnels update - update a Compute Engine VPN tunnel 
SYNOPSIS
    

`gcloud alpha compute vpn-tunnels update` `NAME` [`--region`=`REGION`] [`--update-labels`=[`KEY`=`VALUE`,…]] [`--clear-labels` | `--remove-labels`=[`KEY`,…]] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `gcloud alpha compute vpn-tunnels update` updates labels for a Compute Engine VPN tunnel. For example: 
    
    
    gcloud alpha compute vpn-tunnels update example-tunnel --region us-central1 --update-labels=k0=value1,k1=value2 --remove-labels=k3

will add/update labels ``k0`` and ``k1`` and remove labels with key ``k3``. 

Labels can be used to identify the VPN tunnel and to filter them as in 
    
    
    [gcloud alpha compute vpn-tunnels list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/list) --filter='labels.k1:value2'

To list existing labels 
    
    
    [gcloud alpha compute vpn-tunnels describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/describe) example-tunnel --format="default(labels)"

POSITIONAL ARGUMENTS
    

`NAME`
     Name of the VPN Tunnel to update. 
FLAGS
    

`--region`=`REGION`
     Region of the VPN Tunnel to update. If not specified, you might be prompted to select a region (interactive mode only). 

To avoid prompting when this flag is omitted, you can set the ``compute/region`` property: 
    
    
    [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) compute/region REGION

A list of regions can be fetched by running: 
    
    
    [gcloud compute regions list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/regions/list)

To unset the property, run: 
    
    
    [gcloud config unset](https://docs.cloud.google.com/sdk/gcloud/reference/config/unset) compute/region

Alternatively, the region can be stored in the environment variable ``CLOUDSDK_COMPUTE_REGION``. 

`--update-labels`=[`KEY`=`VALUE`,…]
     List of label KEY=VALUE pairs to update. If a label exists, its value is modified. Otherwise, a new label is created. 

Keys must start with a lowercase character and contain only hyphens (`-`), underscores (`_`), lowercase characters, and numbers. Values must contain only hyphens (`-`), underscores (`_`), lowercase characters, and numbers. 

At most one of these can be specified: 

`--clear-labels`
     Remove all labels. If `--update-labels` is also specified then `--clear-labels` is applied first. 

For example, to remove all labels: 
    
    
    gcloud alpha compute vpn-tunnels update --clear-labels

To remove all existing labels and create two new labels, ``foo`` and ``baz``: 
    
    
    gcloud alpha compute vpn-tunnels update --clear-labels --update-labels foo=bar,baz=qux

`--remove-labels`=[`KEY`,…]
     List of label keys to remove. If a label does not exist it is silently ignored. If `--update-labels` is also specified then `--update-labels` is applied first.
