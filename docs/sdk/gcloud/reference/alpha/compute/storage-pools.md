NAME
    

gcloud alpha compute storage-pools - read and manipulate storage pools 
SYNOPSIS
    

`gcloud alpha compute storage-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Read and manipulate Compute Engine storage pools. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/create)`
     `(ALPHA)` Create a storage pool. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/delete)`
     `(ALPHA)` Delete a storage pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/describe)`
     `(ALPHA)` Describe a storage pool. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/get-iam-policy)`
     `(ALPHA)` Get the IAM policy of a storage pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/list)`
     `(ALPHA)` View storage pools. 
`[list-disks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/list-disks)`
     `(ALPHA)` View the disks that are in a storage pool. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/set-iam-policy)`
     `(ALPHA)` Set the IAM policy of the given storage pool. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a storage pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/storage-pools/update)`
     `(ALPHA)` Update a storage pool. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud compute storage-pools](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools)
    
    
    [gcloud beta compute storage-pools](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/storage-pools)
    
    
    [gcloud preview compute storage-pools](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/storage-pools)
