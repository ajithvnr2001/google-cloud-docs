NAME
    

gcloud alpha compute vpn-tunnels - read and manipulate Compute Engine VPN tunnels 
SYNOPSIS
    

`gcloud alpha compute vpn-tunnels` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Read and manipulate Cloud VPN tunnels. 

For more information about Cloud VPN tunnels, see the [Cloud VPN tunnels documentation](https://cloud.google.com//network-connectivity/docs/vpn/concepts/overview). 

See also: [VPN tunnels API](https://cloud.google.com/compute/docs/reference/rest/v1/vpnTunnels). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/config)`
     `(ALPHA)` Manage Compute Engine vpn tunnel configurations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/create)`
     `(ALPHA)` Create a VPN tunnel. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/delete)`
     `(ALPHA)` Delete VPN tunnels. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/describe)`
     `(ALPHA)` Describe a Compute Engine VPN tunnel. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/list)`
     `(ALPHA)` List Google Compute Engine VPN tunnels. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Compute Engine VPN tunnel. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/vpn-tunnels/update)`
     `(ALPHA)` Update a Compute Engine VPN tunnel. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud compute vpn-tunnels](https://docs.cloud.google.com/sdk/gcloud/reference/compute/vpn-tunnels)
    
    
    [gcloud beta compute vpn-tunnels](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-tunnels)
