NAME
    

gcloud alpha compute advice - provides recommendation on optimal allocation of resources according to a flexible specifications 
SYNOPSIS
    

`gcloud alpha compute advice` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Provides recommendation on optimal allocation of resources according to a flexible specifications. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[calendar-mode](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/advice/calendar-mode)`
     `(ALPHA)` Recommends the optimal time window and zone for Future Reservations. 
`[capacity](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/advice/capacity)`
     `(ALPHA)` Get capacity advice for Compute Engine resources. 
`[capacity-history](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/advice/capacity-history)`
     `(ALPHA)` Show historical data on Spot VMs preemption and price. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud compute advice](https://docs.cloud.google.com/sdk/gcloud/reference/compute/advice)
    
    
    [gcloud beta compute advice](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/advice)
