NAME
    

gcloud alpha compute reservations hosts - read Compute Engine reservation hosts 
SYNOPSIS
    

`gcloud alpha compute reservations hosts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Read Compute Engine reservation hosts. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/hosts/describe)`
     `(ALPHA)` Describe a Google Compute Engine host in a reservation. 
`[get-version](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/hosts/get-version)`
     `(ALPHA)` Get software versions for a Compute Engine host in a reservation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/hosts/list)`
     `(ALPHA)` List Google Compute Engine hosts for a reservation. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud compute reservations hosts](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/hosts)
    
    
    [gcloud beta compute reservations hosts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/hosts)
