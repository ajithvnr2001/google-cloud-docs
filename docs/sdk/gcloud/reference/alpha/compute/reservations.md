NAME
    

gcloud alpha compute reservations - manage Compute Engine reservations 
SYNOPSIS
    

`gcloud alpha compute reservations` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Compute Engine reservations. 

For more information about reservations, see the [reservations documentation](https://cloud.google.com/compute/docs/instances/reserving-zonal-resources). 

See also: [Reservations API](https://cloud.google.com/compute/docs/reference/rest/v1/reservations). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[blocks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/blocks)`
     `(ALPHA)` Manage Compute Engine reservation blocks. 
`[consumed-instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/consumed-instances)`
     `(ALPHA)` Manage Compute Engine reservation consumed instances. 
`[hosts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/hosts)`
     `(ALPHA)` Read Compute Engine reservation hosts. 
`[slots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/slots)`
     `(ALPHA)` Manage Compute Engine reservation slots. 
`[sub-blocks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/sub-blocks)`
     `(ALPHA)` Manage Compute Engine reservation sub blocks. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Compute Engine reservation. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/create)`
     `(ALPHA)` Create a Compute Engine reservation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/delete)`
     `(ALPHA)` Delete a Compute Engine reservation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/describe)`
     `(ALPHA)` Show details about a Compute Engine reservation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Compute Engine reservation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/list)`
     `(ALPHA)` List Compute Engine reservations. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/perform-maintenance)`
     `(ALPHA)` Perform maintenance on a reservation, only applicable to reservations with reservation blocks. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from a Compute Engine reservation. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Compute Engine reservation. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Compute Engine reservation. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/update)`
     `(ALPHA)` Update Compute Engine reservations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
