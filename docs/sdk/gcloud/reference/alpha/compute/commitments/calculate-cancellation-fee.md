NAME
    

gcloud alpha compute commitments calculate-cancellation-fee - calculate the cancellation fee for a Compute Engine commitment 
SYNOPSIS
    

`gcloud alpha compute commitments calculate-cancellation-fee` `COMMITMENT` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Calculate the cancellation fee for a Compute Engine commitment. 
EXAMPLES
     To calculate the cancellation fee for the commitment called ``commitment-1`` in the ``us-central1`` region, run: 
    
    
    gcloud alpha compute commitments calculate-cancellation-fee commitment-1 --region=us-central1

POSITIONAL ARGUMENTS
    

`COMMITMENT`
     Name of the commitment to calculate cancellation fee. 
FLAGS
    

`--region`=`REGION`
     Region of the commitment to calculate cancellation fee. If not specified, you might be prompted to select a region (interactive mode only). 

To avoid prompting when this flag is omitted, you can set the ``compute/region`` property: 
    
    
    [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) compute/region REGION

A list of regions can be fetched by running: 
    
    
    [gcloud compute regions list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/regions/list)

To unset the property, run: 
    
    
    [gcloud config unset](https://docs.cloud.google.com/sdk/gcloud/reference/config/unset) compute/region

Alternatively, the region can be stored in the environment variable ``CLOUDSDK_COMPUTE_REGION``.
