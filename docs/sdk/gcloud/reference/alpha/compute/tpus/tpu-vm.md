NAME
    

gcloud alpha compute tpus tpu-vm - list, create, and manage Cloud TPU VM nodes 
SYNOPSIS
    

`gcloud alpha compute tpus tpu-vm` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List, create, and manage Cloud TPU VM nodes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[accelerator-types](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/accelerator-types)`
     `(ALPHA)` List or Describe Available Cloud TPU VM node accelerator types. 
`[service-identity](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/service-identity)`
     `(ALPHA)` Commands for Cloud TPU VM service identity. 
`[versions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/versions)`
     `(ALPHA)` Explore available runtime versions for Cloud TPU VM nodes. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[attach-disk](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/attach-disk)`
     `(ALPHA)` Attach disk to TPU VM. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/create)`
     `(ALPHA)` Create a new Cloud TPU VM node. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/delete)`
     `(ALPHA)` Delete a Cloud TPU VM node. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/describe)`
     `(ALPHA)` Describe a Cloud TPU VM node. 
`[detach-disk](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/detach-disk)`
     `(ALPHA)` Detach a disk from an instance. 
`[get-guest-attributes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/get-guest-attributes)`
     `(ALPHA)` Retrieve the Guest Attributes for a Cloud TPU VM. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/list)`
     `(ALPHA)` List Cloud TPU VM nodes. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/perform-maintenance)`
     `(ALPHA)` perform maintenance on a Cloud TPU VM. 
`[scp](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/scp)`
     `(ALPHA)` Copy files to and from a Cloud TPU VM via SCP. 
`[simulate-maintenance-event](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/simulate-maintenance-event)`
     `(ALPHA)` Simulates a maintenance event on a Cloud TPU VM. 
`[ssh](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/ssh)`
     `(ALPHA)` SSH into a Cloud TPU VM. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/start)`
     `(ALPHA)` Start a Cloud TPU VM node. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/stop)`
     `(ALPHA)` Stop a Cloud TPU VM node. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm/update)`
     `(ALPHA)` Update a Cloud TPU VM node. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud compute tpus tpu-vm](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm)
