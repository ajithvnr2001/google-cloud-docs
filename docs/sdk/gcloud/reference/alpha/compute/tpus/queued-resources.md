NAME
    

gcloud alpha compute tpus queued-resources - list, create, delete, and manage Queued Resources 
SYNOPSIS
    

`gcloud alpha compute tpus queued-resources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List, create, delete, and manage Queued Resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/create)`
     `(ALPHA)` Create a Queued Resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/delete)`
     `(ALPHA)` Delete a Queued Resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/describe)`
     `(ALPHA)` Describe a Queued Resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/list)`
     `(ALPHA)` List Queued Resources. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/perform-maintenance)`
     `(ALPHA)` Performs maintenance on a Cloud TPU Queued Resource. 
`[reset](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/reset)`
     `(ALPHA)` Reset a Queued Resource. 
`[scp](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/scp)`
     `(ALPHA)` Copy files to and from a Cloud TPU Queued Resource via SCP. 
`[ssh](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/queued-resources/ssh)`
     `(ALPHA)` SSH into a Cloud TPU Queued Resource's node(s). 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud compute tpus queued-resources](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/queued-resources)
