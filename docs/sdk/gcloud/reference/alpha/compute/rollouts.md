NAME
    

gcloud alpha compute rollouts - read and manipulate Compute Engine Rollouts 
SYNOPSIS
    

`gcloud alpha compute rollouts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Read and manipulate Compute Engine Rollouts. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[advance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/rollouts/advance)`
     `(ALPHA)` Advance a Google Compute Engine rollout. 
`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/rollouts/cancel)`
     `(ALPHA)` Cancel a Google Compute Engine rollout. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/rollouts/delete)`
     `(ALPHA)` Delete a Google Compute Engine rollout. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/rollouts/describe)`
     `(ALPHA)` Describe a rollout. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/rollouts/list)`
     `(ALPHA)` List Google Compute Engine Rollouts. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud compute rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/compute/rollouts)
    
    
    [gcloud beta compute rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/rollouts)
