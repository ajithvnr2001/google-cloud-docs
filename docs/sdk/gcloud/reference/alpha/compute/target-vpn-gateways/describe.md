NAME
    

gcloud alpha compute target-vpn-gateways describe - describe a Compute Engine Cloud VPN Classic Target VPN Gateway 
SYNOPSIS
    

`gcloud alpha compute target-vpn-gateways describe` `NAME` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `gcloud alpha compute target-vpn-gateways describe` displays all data associated with a Compute Engine Cloud VPN Target VPN Gateway in a project. 
POSITIONAL ARGUMENTS
    

`NAME`
     Name of the Target VPN Gateway to describe. 
FLAGS
    

`--region`=`REGION`
     Region of the Target VPN Gateway to describe. If not specified, you might be prompted to select a region (interactive mode only). 

To avoid prompting when this flag is omitted, you can set the ``compute/region`` property: 
    
    
    [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) compute/region REGION

A list of regions can be fetched by running: 
    
    
    [gcloud compute regions list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/regions/list)

To unset the property, run: 
    
    
    [gcloud config unset](https://docs.cloud.google.com/sdk/gcloud/reference/config/unset) compute/region

Alternatively, the region can be stored in the environment variable ``CLOUDSDK_COMPUTE_REGION``.
