NAME
    

gcloud alpha compute org-security-policies - manage Compute Engine organization security policies 
SYNOPSIS
    

`gcloud alpha compute org-security-policies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Compute Engine organization security policies. Organization security policies are used to control incoming/outgoing traffic. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[associations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/associations)`
     `(ALPHA)` Read and manipulate Compute Engine organization security policy associations. 
`[rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/rules)`
     `(ALPHA)` Read and manipulate Compute Engine organization security policy rules. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[copy-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/copy-rules)`
     `(ALPHA)` Replace the rules of a Compute Engine organization security policy with rules from another policy. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/create)`
     `(ALPHA)` Create a Compute Engine organization security policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/delete)`
     `(ALPHA)` Delete a Compute Engine organization security policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/describe)`
     `(ALPHA)` Describe a Compute Engine organization security policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/list)`
     `(ALPHA)` List Compute Engine organization security policies. 
`[list-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/list-rules)`
     `(ALPHA)` List the rules of a Compute Engine organization security policy. 
`[move](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/move)`
     `(ALPHA)` Move a Compute Engine organization security policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-security-policies/update)`
     `(ALPHA)` Update a Compute Engine organization security policy. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
