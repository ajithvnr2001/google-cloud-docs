NAME
    

gcloud alpha compute os-config os-policy-assignments - manage OS policy assignments 
SYNOPSIS
    

`gcloud alpha compute os-config os-policy-assignments` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage OS policy assignments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/os-policy-assignments/operations)`
     `(ALPHA)` Manage long-running operations generated from creating or editing OS policy assignments. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/os-policy-assignments/create)`
     `(ALPHA)` Create an OS policy assignment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/os-policy-assignments/delete)`
     `(ALPHA)` Delete an OS policy assignment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/os-policy-assignments/describe)`
     `(ALPHA)` Describe an OS policy assignment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/os-policy-assignments/list)`
     `(ALPHA)` List OS policy assignments for a specified location. 
`[list-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/os-policy-assignments/list-revisions)`
     `(ALPHA)` List the revisions of an OS policy assignment. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/os-policy-assignments/update)`
     `(ALPHA)` Update an OS policy assignment. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud compute os-config os-policy-assignments](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config/os-policy-assignments)
