NAME
    

gcloud alpha compute os-config inventories - display inventory of a Compute Engine VM 
SYNOPSIS
    

`gcloud alpha compute os-config inventories` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Display inventory of a Compute Engine VM. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/inventories/describe)`
     `(ALPHA)` Describe the inventory data for a Compute Engine VM instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/inventories/list)`
     `(ALPHA)` List inventory data for all Compute Engine VM instances in a specified location. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud compute os-config inventories](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config/inventories)
