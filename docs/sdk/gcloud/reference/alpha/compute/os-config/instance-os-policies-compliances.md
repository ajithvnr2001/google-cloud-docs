NAME
    

gcloud alpha compute os-config instance-os-policies-compliances - report compliance states for OS policies applied to a Compute Engine VM 
SYNOPSIS
    

`gcloud alpha compute os-config instance-os-policies-compliances` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Report compliance states for OS policies applied to a Compute Engine VM. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/instance-os-policies-compliances/describe)`
     `(ALPHA)` Describe the compliance states for OS policies that are applied to a VM. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/instance-os-policies-compliances/list)`
     `(ALPHA)` List compliance states for OS policies that are applied to VMs. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
