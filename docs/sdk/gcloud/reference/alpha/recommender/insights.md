#  gcloud alpha recommender insights Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha recommender insights - manage Cloud resource insights 
SYNOPSIS
    

`gcloud alpha recommender insights` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud resource insights. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/insights/describe)`
     `(ALPHA)` Describe an insight. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/insights/list)`
     `(ALPHA)` List insights for Google Cloud resources. 
`[mark-accepted](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/insights/mark-accepted)`
     `(ALPHA)` Mark an insight's state as ACCEPTED. 
`[mark-active](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/insights/mark-active)`
     `(ALPHA)` Mark an insight's state as ACTIVE. 
`[mark-dismissed](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/insights/mark-dismissed)`
     `(ALPHA)` Mark an insight's state as DISMISSED. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud recommender insights](https://docs.cloud.google.com/sdk/gcloud/reference/recommender/insights)
    
    
    [gcloud beta recommender insights](https://docs.cloud.google.com/sdk/gcloud/reference/beta/recommender/insights)
