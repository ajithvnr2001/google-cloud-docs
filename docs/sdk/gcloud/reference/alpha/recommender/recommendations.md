#  gcloud alpha recommender recommendations Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha recommender recommendations - manage Cloud resource recommendations 
SYNOPSIS
    

`gcloud alpha recommender recommendations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud resource recommendations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/recommendations/describe)`
     `(ALPHA)` Describe a recommendation for a Cloud project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/recommendations/list)`
     `(ALPHA)` List recommendations for Google Cloud resources. 
`[mark-active](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/recommendations/mark-active)`
     `(ALPHA)` Mark Active operations for a recommendation. 
`[mark-claimed](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/recommendations/mark-claimed)`
     `(ALPHA)` Mark a recommendation's state as CLAIMED. 
`[mark-dismissed](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/recommendations/mark-dismissed)`
     `(ALPHA)` Mark recommendation's state as DISMISSED. 
`[mark-failed](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/recommendations/mark-failed)`
     `(ALPHA)` Mark a recommendation's state as FAILED. 
`[mark-succeeded](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recommender/recommendations/mark-succeeded)`
     `(ALPHA)` Mark a recommendation's state as SUCCEEDED. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud recommender recommendations](https://docs.cloud.google.com/sdk/gcloud/reference/recommender/recommendations)
    
    
    [gcloud beta recommender recommendations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/recommender/recommendations)
