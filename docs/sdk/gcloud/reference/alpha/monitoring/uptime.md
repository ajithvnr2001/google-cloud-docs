NAME
    

gcloud alpha monitoring uptime - manage Cloud Monitoring uptime checks and synthetic monitors 
SYNOPSIS
    

`gcloud alpha monitoring uptime` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Monitoring uptime checks and synthetic monitors. 

More information can be found here: <https://cloud.google.com/monitoring/api/v3/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/uptime/create)`
     `(ALPHA)` Create a new uptime check or synthetic monitor. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/uptime/delete)`
     `(ALPHA)` Delete an uptime check or synthetic monitor. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/uptime/describe)`
     `(ALPHA)` Describe an uptime check or synthetic monitor. 
`[list-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/uptime/list-configs)`
     `(ALPHA)` List uptime checks and synthetic monitors. 
`[list-ips](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/uptime/list-ips)`
     `(ALPHA)` List uptime check server ips. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/uptime/update)`
     `(ALPHA)` Update an existing uptime check or synthetic monitor. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud monitoring uptime](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/uptime)
    
    
    [gcloud beta monitoring uptime](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime)
