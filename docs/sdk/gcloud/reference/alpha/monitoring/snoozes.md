NAME
    

gcloud alpha monitoring snoozes - manage Cloud Monitoring snoozes 
SYNOPSIS
    

`gcloud alpha monitoring snoozes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Monitoring snoozes. 

More information can be found here: <https://cloud.google.com/monitoring/api/v3/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/snoozes/cancel)`
     `(ALPHA)` Cancels a snooze. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/snoozes/create)`
     `(ALPHA)` Create a new snooze. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/snoozes/describe)`
     `(ALPHA)` Describe a snooze. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/snoozes/list)`
     `(ALPHA)` List snoozes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/snoozes/update)`
     `(ALPHA)` Updates a snooze. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud monitoring snoozes](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/snoozes)
    
    
    [gcloud beta monitoring snoozes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/snoozes)
