NAME
    

gcloud alpha monitoring channel-descriptors - read Cloud Monitoring notification channel descriptors 
SYNOPSIS
    

`gcloud alpha monitoring channel-descriptors` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Monitoring notification channel descriptors. 

More information can be found here: <https://cloud.google.com/monitoring/api/v3/> <https://cloud.google.com/monitoring/api/ref_v3/rest/v3/projects.notificationChannelDescriptors> <https://cloud.google.com/monitoring/alerts/using-channels-api>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/channel-descriptors/describe)`
     `(ALPHA)` Describe a notification channel descriptor. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/channel-descriptors/list)`
     `(ALPHA)` List notification channel descriptors. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta monitoring channel-descriptors](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/channel-descriptors)
