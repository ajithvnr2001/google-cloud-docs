NAME
    

gcloud alpha monitoring policies - manage Cloud Monitoring alerting policies 
SYNOPSIS
    

`gcloud alpha monitoring policies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Monitoring alerting policies. 

More information can be found here: <https://cloud.google.com/monitoring/api/v3/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[conditions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/conditions)`
     `(ALPHA)` Manage Cloud Monitoring alerting policy conditions. 
`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/config)`
     `(ALPHA)` Manage Monitoring alert policy configurations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/create)`
     `(ALPHA)` Create a new alerting policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/delete)`
     `(ALPHA)` Delete a Cloud Monitoring alerting policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/describe)`
     `(ALPHA)` Describe an alerting policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/list)`
     `(ALPHA)` List alerting policies. 
`[migrate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/migrate)`
     `(ALPHA)` Migrate a Prometheus configuration file to Cloud Monitoring. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies/update)`
     `(ALPHA)` Updates an alerting policy. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud monitoring policies](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/policies)
    
    
    [gcloud beta monitoring policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies)
