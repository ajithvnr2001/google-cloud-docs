NAME
    

gcloud alpha apphub applications workloads - manage App Hub Application Workloads 
SYNOPSIS
    

`gcloud alpha apphub applications workloads` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing App Hub Application Workloads. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apphub/applications/workloads/create)`
     `(ALPHA)` Create an Apphub application workload. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apphub/applications/workloads/delete)`
     `(ALPHA)` Delete an Apphub application workload. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apphub/applications/workloads/describe)`
     `(ALPHA)` Describe an Apphub application workload. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apphub/applications/workloads/list)`
     `(ALPHA)` List Apphub application workloads. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apphub/applications/workloads/update)`
     `(ALPHA)` Update an Apphub application workload. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apphub applications workloads](https://docs.cloud.google.com/sdk/gcloud/reference/apphub/applications/workloads)
