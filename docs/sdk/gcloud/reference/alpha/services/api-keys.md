NAME
    

gcloud alpha services api-keys - manage API keys 
SYNOPSIS
    

`gcloud alpha services api-keys` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage API keys. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/create)`
     `(ALPHA)` Create an API key. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/delete)`
     `(ALPHA)` Delete an API key. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/describe)`
     `(ALPHA)` Describe an API key's metadata. 
`[get-key-string](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/get-key-string)`
     `(ALPHA)` Get the key string of an API key. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/list)`
     `(ALPHA)` Lists API keys. 
`[lookup](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/lookup)`
     `(ALPHA)` Look up resource name of a key string. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/undelete)`
     `(ALPHA)` Undelete an API key. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys/update)`
     `(ALPHA)` Update an API key's metadata. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud services api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys)
    
    
    [gcloud beta services api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/api-keys)
