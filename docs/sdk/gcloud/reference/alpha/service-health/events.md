NAME
    

gcloud alpha service-health events - represents events that may affect Google Cloud products 
SYNOPSIS
    

`gcloud alpha service-health events` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Represents events that may affect Google Cloud products. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-health/events/describe)`
     `(ALPHA)` Get details of an event affecting a project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-health/events/list)`
     `(ALPHA)` List events under a given project and location. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud service-health events](https://docs.cloud.google.com/sdk/gcloud/reference/service-health/events)
    
    
    [gcloud beta service-health events](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/events)
