NAME
    

gcloud alpha dataflow - manage Google Cloud Dataflow resources 
SYNOPSIS
    

`gcloud alpha dataflow` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud dataflow command group lets you manage Google Cloud Dataflow resources. 

Cloud Dataflow is a unified programming model and a managed service for developing and executing a wide range of data processing patterns including ETL, batch computation, and continuous computation. 

More information on Cloud Dataflow can be found here: <https://cloud.google.com/dataflow> and detailed documentation can be found here: <https://cloud.google.com/dataflow/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config-store-settings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataflow/config-store-settings)`
     `(ALPHA)` Manage Dataflow ConfigStore settings. 
`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataflow/jobs)`
     `(ALPHA)` A group of subcommands for working with Dataflow jobs. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataflow/logs)`
     `(ALPHA)` A group of subcommands for working with Dataflow logs. 
`[metrics](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataflow/metrics)`
     `(ALPHA)` A group of subcommands for working with Dataflow metrics. 
`[snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataflow/snapshots)`
     `(ALPHA)` A group of subcommands for working with Cloud Dataflow snapshots. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud dataflow](https://docs.cloud.google.com/sdk/gcloud/reference/dataflow)
    
    
    [gcloud beta dataflow](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow)
