NAME
    

gcloud alpha service-directory services - manage Service Directory services 
SYNOPSIS
    

`gcloud alpha service-directory services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Service Directory services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/add-iam-policy-binding)`
     `(ALPHA)` Adds IAM policy binding to a service. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/create)`
     `(ALPHA)` Creates a service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/delete)`
     `(ALPHA)` Deletes a service. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/describe)`
     `(ALPHA)` Describes a service. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/get-iam-policy)`
     `(ALPHA)` Gets IAM policy for a service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/list)`
     `(ALPHA)` Lists services. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/remove-iam-policy-binding)`
     `(ALPHA)` Removes IAM policy binding from a service. 
`[resolve](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/resolve)`
     `(ALPHA)` Resolves a service. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/set-iam-policy)`
     `(ALPHA)` Sets IAM policy for a service. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services/update)`
     `(ALPHA)` Updates a service. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud service-directory services](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/services)
    
    
    [gcloud beta service-directory services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services)
