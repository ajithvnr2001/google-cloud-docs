NAME
    

gcloud alpha source project-configs - manage Cloud Source Repositories configuration of a project 
SYNOPSIS
    

`gcloud alpha source project-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Source Repositories configuration of a project. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source/project-configs/describe)`
     `(ALPHA)` Show details about the configuration of a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source/project-configs/update)`
     `(ALPHA)` Update the Cloud Source Repositories configuration of the current project. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud source project-configs](https://docs.cloud.google.com/sdk/gcloud/reference/source/project-configs)
    
    
    [gcloud beta source project-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/project-configs)
