NAME
    

gcloud alpha iap - manage IAP policies 
SYNOPSIS
    

`gcloud alpha iap` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Cloud Identity-Aware Proxy (Cloud IAP) controls access to your cloud applications running on Google Cloud Platform. Cloud IAP works by verifying user identity and context of the request to determine if a user should be allowed to access the application. 

More information on Cloud IAP can be found here: <https://cloud.google.com/iap> and detailed documentation can be found here: <https://cloud.google.com/iap/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[oauth-brands](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/oauth-brands)`
     `(ALPHA)` `(DEPRECATED)` Manage IAP OAuth brands. 
`[oauth-clients](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/oauth-clients)`
     `(ALPHA)` `(DEPRECATED)` Manage IAP OAuth clients. 
`[settings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/settings)`
     `(ALPHA)` Manage IAP settings. 
`[tcp](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/tcp)`
     `(ALPHA)` Manage IAP TCP resources. 
`[web](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/web)`
     `(ALPHA)` Manage IAP web policies. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud iap](https://docs.cloud.google.com/sdk/gcloud/reference/iap)
    
    
    [gcloud beta iap](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap)
