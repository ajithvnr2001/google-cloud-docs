NAME
    

gcloud alpha managed-kafka - administer Managed Service for Apache Kafka clusters, topics, and consumer groups 
SYNOPSIS
    

`gcloud alpha managed-kafka` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Administer Managed Service for Apache Kafka clusters, topics, and consumer groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[acls](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls)`
     `(ALPHA)` Administer Managed Service for Apache Kafka acls. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/clusters)`
     `(ALPHA)` Administer Managed Service for Apache Kafka clusters. 
`[connect-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connect-clusters)`
     `(ALPHA)` Administer Managed Service for Apache Kafka connect-clusters. 
`[connectors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors)`
     `(ALPHA)` Administer Managed Service for Apache Kafka connectors. 
`[consumer-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/consumer-groups)`
     `(ALPHA)` Administer Managed Service for Apache Kafka consumer groups. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/operations)`
     `(ALPHA)` View Managed Service for Apache Kafka operations. 
`[schema-registries](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/schema-registries)`
     `(ALPHA)` Administer Managed Service for Apache Kafka schema-registries. 
`[topics](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/topics)`
     `(ALPHA)` Administer Managed Service for Apache Kafka topics. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud managed-kafka](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka)
    
    
    [gcloud beta managed-kafka](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka)
