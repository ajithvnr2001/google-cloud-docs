#  gcloud alpha healthcare datasets Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha healthcare datasets - manage Cloud Healthcare API datasets 
SYNOPSIS
    

`gcloud alpha healthcare datasets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Healthcare API datasets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a Cloud Healthcare API dataset. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/create)`
     `(ALPHA)` Create a Cloud Healthcare API dataset. 
`[deidentify](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/deidentify)`
     `(ALPHA)` Create a new Cloud Healthcare API dataset containing de-identified data from the source dataset. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/delete)`
     `(ALPHA)` Delete a Cloud Healthcare API dataset. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/describe)`
     `(ALPHA)` Describe a Cloud Healthcare API dataset. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/get-iam-policy)`
     `(ALPHA)` Retrieve the IAM policy for a Cloud Healthcare API dataset. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/list)`
     `(ALPHA)` List Cloud Healthcare API datasets. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding to a Cloud Healthcare API dataset. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Healthcare API dataset. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets/update)`
     `(ALPHA)` Update a Cloud Healthcare API dataset. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud healthcare datasets](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets)
    
    
    [gcloud beta healthcare datasets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/datasets)
