NAME
    

gcloud alpha healthcare dicom-stores - manage Cloud Healthcare API DICOM stores 
SYNOPSIS
    

`gcloud alpha healthcare dicom-stores` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Google Cloud Healthcare API DICOM stores. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/export)`
     `(ALPHA)` Manage Cloud Healthcare API DICOM store exports. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/import)`
     `(ALPHA)` Manage Cloud Healthcare API DICOM store imports. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a Cloud Healthcare API DICOM store. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/create)`
     `(ALPHA)` Create a Cloud Healthcare API DICOM store. 
`[deidentify](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/deidentify)`
     `(ALPHA)` De-identify data from the source store and write it to the destination store. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/delete)`
     `(ALPHA)` Delete a Cloud Healthcare API DICOM store. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/describe)`
     `(ALPHA)` Describe a Cloud Healthcare API DICOM store. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/get-iam-policy)`
     `(ALPHA)` Retrieve the IAM policy for a Cloud Healthcare API DICOM store. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/list)`
     `(ALPHA)` List Cloud Healthcare API DICOM stores. 
`[metrics](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/metrics)`
     `(ALPHA)` Get the metrics for a Cloud Healthcare API DICOM store. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding from a Cloud Healthcare API DICOM store. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Healthcare API DICOM store. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/update)`
     `(ALPHA)` Update a Cloud Healthcare API DICOM store. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud healthcare dicom-stores](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/dicom-stores)
    
    
    [gcloud beta healthcare dicom-stores](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/dicom-stores)
