NAME
    

gcloud alpha healthcare dicom-stores export - manage Cloud Healthcare API DICOM store exports 
SYNOPSIS
    

`gcloud alpha healthcare dicom-stores export` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for exporting Google Cloud Healthcare API DICOM stores. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[bq](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/export/bq)`
     `(ALPHA)` Export a Cloud Healthcare API API DICOM store to BigQuery. 
`[gcs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores/export/gcs)`
     `(ALPHA)` Export a Cloud Healthcare API DICOM store to Google Cloud Storage. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud healthcare dicom-stores export](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/dicom-stores/export)
    
    
    [gcloud beta healthcare dicom-stores export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/dicom-stores/export)
