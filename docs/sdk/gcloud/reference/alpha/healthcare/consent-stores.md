#  gcloud alpha healthcare consent-stores Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha healthcare consent-stores - manage Cloud Healthcare API consent stores 
SYNOPSIS
    

`gcloud alpha healthcare consent-stores` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Healthcare API consent stores. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a Cloud Healthcare API consent store. 
`[check-data-access](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/check-data-access)`
     `(ALPHA)` Check the consent for a particular data ID. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/create)`
     `(ALPHA)` Create a Cloud Healthcare API consent store. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/delete)`
     `(ALPHA)` Delete a Cloud Healthcare API consent store. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/describe)`
     `(ALPHA)` Describe a Cloud Healthcare API consent store. 
`[evaluate-user-consents](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/evaluate-user-consents)`
     `(ALPHA)` Check the consents for a particular user's data. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/get-iam-policy)`
     `(ALPHA)` Retrieve the IAM policy for a Cloud Healthcare API consent store. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/list)`
     `(ALPHA)` List Cloud Healthcare API consent stores. 
`[query-accessible-data](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/query-accessible-data)`
     `(ALPHA)` Queries all accessible data IDs. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding from a Cloud Healthcare API consent store. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Healthcare API consent store. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores/update)`
     `(ALPHA)` Update a Cloud Healthcare API consent store. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud healthcare consent-stores](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/consent-stores)
    
    
    [gcloud beta healthcare consent-stores](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/consent-stores)
