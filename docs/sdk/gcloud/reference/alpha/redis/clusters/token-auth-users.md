NAME
    

gcloud alpha redis clusters token-auth-users - manage token auth users of Memorystore for Redis Cluster instances 
SYNOPSIS
    

`gcloud alpha redis clusters token-auth-users` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage token auth users of Memorystore for Redis Cluster instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[auth-tokens](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/token-auth-users/auth-tokens)`
     `(ALPHA)` Manage auth tokens of Memorystore for Redis Cluster instances. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create-auth-token](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/token-auth-users/create-auth-token)`
     `(ALPHA)` Create an auth token for a token auth user of a Redis cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/token-auth-users/delete)`
     `(ALPHA)` Delete a Memorystore for Redis Cluster token auth user. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/token-auth-users/describe)`
     `(ALPHA)` Show metadata for a Memorystore for Redis Cluster token auth user. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/token-auth-users/list)`
     `(ALPHA)` List token auth users of a Redis cluster in a region. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta redis clusters token-auth-users](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/token-auth-users)
