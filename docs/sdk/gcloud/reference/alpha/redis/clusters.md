NAME
    

gcloud alpha redis clusters - manage Memorystore for Redis Cluster instances 
SYNOPSIS
    

`gcloud alpha redis clusters` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Memorystore for Redis Cluster instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backup-collections](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/backup-collections)`
     `(ALPHA)` Manage backup collections of Memorystore for Redis Cluster instances. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/backups)`
     `(ALPHA)` Manage backups of Memorystore for Redis Cluster instances. 
`[token-auth-users](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/token-auth-users)`
     `(ALPHA)` Manage token auth users of Memorystore for Redis Cluster instances. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-cluster-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/add-cluster-endpoints)`
     `(ALPHA)` Add more cluster endpoints. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/create)`
     `(ALPHA)` Create a new Memorystore for Redis Cluster instance. 
`[create-backup](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/create-backup)`
     `(ALPHA)` Create a backup of a Redis cluster. 
`[create-token-auth-user](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/create-token-auth-user)`
     `(ALPHA)` Create a token auth user for a Redis cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/delete)`
     `(ALPHA)` Delete a Memorystore for Redis Cluster instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/describe)`
     `(ALPHA)` Show metadata for a Memorystore for Redis Cluster instance. 
`[detach](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/detach)`
     `(ALPHA)` Detach a secondary cluster. 
`[detach-secondaries](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/detach-secondaries)`
     `(ALPHA)` Detach one or more secondary clusters from the primary cluster. 
`[get-cluster-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/get-cluster-certificate-authority)`
     `(ALPHA)` Get the certificate authority information for a Memorystore for Redis Cluster instance. 
`[get-shared-regional-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/get-shared-regional-certificate-authority)`
     `(ALPHA)` Get the shared regional certificate authority certificates for Memorystore for Redis Cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/list)`
     `(ALPHA)` List Memorystore for Redis Cluster instances. 
`[remove-cluster-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/remove-cluster-endpoints)`
     `(ALPHA)` Remove existing Memorystore cluster endpoints. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/reschedule-maintenance)`
     `(ALPHA)` Reschedule maintenance window for a Memorystore for Redis Cluster instance. 
`[switchover](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/switchover)`
     `(ALPHA)` Switchover to a secondary cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/update)`
     `(ALPHA)` Update Memorystore Cluster for Redis instance. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud redis clusters](https://docs.cloud.google.com/sdk/gcloud/reference/redis/clusters)
    
    
    [gcloud beta redis clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters)
