NAME
    

gcloud alpha apihub plugins - manage Plugin resources 
SYNOPSIS
    

`gcloud alpha apihub plugins` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Plugin resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/instances)`
     `(ALPHA)` Manage Plugin Instance resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/create)`
     `(ALPHA)` Create a Plugin. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/delete)`
     `(ALPHA)` Delete a Plugin. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/describe)`
     `(ALPHA)` Describe a Plugin. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/disable)`
     `(ALPHA)` Disable a Plugin. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/enable)`
     `(ALPHA)` Enable a Plugin. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/list)`
     `(ALPHA)` List Plugins. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apihub plugins](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins)
