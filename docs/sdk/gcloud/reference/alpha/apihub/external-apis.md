NAME
    

gcloud alpha apihub external-apis - manage External Api resources 
SYNOPSIS
    

`gcloud alpha apihub external-apis` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage External Api resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/external-apis/create)`
     `(ALPHA)` Create an External Api. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/external-apis/delete)`
     `(ALPHA)` Delete an External Api. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/external-apis/describe)`
     `(ALPHA)` Describe an External Api. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/external-apis/list)`
     `(ALPHA)` List External Apis. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/external-apis/update)`
     `(ALPHA)` Update an External Api. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apihub external-apis](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/external-apis)
