NAME
    

gcloud alpha apihub deployments - manage Deployment resources 
SYNOPSIS
    

`gcloud alpha apihub deployments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Deployment resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/deployments/create)`
     `(ALPHA)` Create a Deployment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/deployments/delete)`
     `(ALPHA)` Delete a Deployment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/deployments/describe)`
     `(ALPHA)` Describe a Deployment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/deployments/list)`
     `(ALPHA)` List Deployments. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/deployments/update)`
     `(ALPHA)` Update deployments. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apihub deployments](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/deployments)
