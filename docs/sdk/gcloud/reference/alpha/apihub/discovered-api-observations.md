NAME
    

gcloud alpha apihub discovered-api-observations - manage Discovered Api Observation resources 
SYNOPSIS
    

`gcloud alpha apihub discovered-api-observations` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Discovered Api Observation resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[discovered-api-operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/discovered-api-observations/discovered-api-operations)`
     `(ALPHA)` Manage Discovered Api Operation resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/discovered-api-observations/describe)`
     `(ALPHA)` Describe a Discovered Api Observation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/discovered-api-observations/list)`
     `(ALPHA)` List Discovered Api Observations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apihub discovered-api-observations](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/discovered-api-observations)
