NAME
    

gcloud alpha apihub apis versions - manage Version resources 
SYNOPSIS
    

`gcloud alpha apihub apis versions` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Version resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/operations)`
     `(ALPHA)` Manage Api Operation resources. 
`[specs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs)`
     `(ALPHA)` Manage Spec resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/create)`
     `(ALPHA)` Create a Version. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/delete)`
     `(ALPHA)` Delete a Version. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/describe)`
     `(ALPHA)` Describe a Version. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/list)`
     `(ALPHA)` List Versions. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/update)`
     `(ALPHA)` Update versions. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apihub apis versions](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions)
