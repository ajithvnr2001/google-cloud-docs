NAME
    

gcloud alpha apihub apis versions specs - manage Spec resources 
SYNOPSIS
    

`gcloud alpha apihub apis versions specs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Spec resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs/create)`
     `(ALPHA)` Create a Spec. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs/delete)`
     `(ALPHA)` Delete a Spec. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs/describe)`
     `(ALPHA)` Describe a Spec. 
`[get-contents](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs/get-contents)`
     `(ALPHA)` Get the contents of a spec. 
`[lint](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs/lint)`
     `(ALPHA)` Lint a Spec. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs/list)`
     `(ALPHA)` List Specs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions/specs/update)`
     `(ALPHA)` Update specs. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apihub apis versions specs](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/specs)
