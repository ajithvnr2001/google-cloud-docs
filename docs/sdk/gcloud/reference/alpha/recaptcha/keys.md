NAME
    

gcloud alpha recaptcha keys - managed reCAPTCHA Keys 
SYNOPSIS
    

`gcloud alpha recaptcha keys` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Managed reCAPTCHA Keys. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-ip-override](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/add-ip-override)`
     `(ALPHA)` Add an IP override to a key. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/create)`
     `(ALPHA)` Create a Key. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/delete)`
     `(ALPHA)` Delete one or more reCAPTCHA Keys. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/describe)`
     `(ALPHA)` Describe reCAPTCHA Key. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/list)`
     `(ALPHA)` List reCAPTCHA Keys. 
`[list-ip-overrides](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/list-ip-overrides)`
     `(ALPHA)` List IP overrides for a key. 
`[migrate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/migrate)`
     `(ALPHA)` Migrate a key to reCAPTCHA Enterprise. 
`[remove-ip-override](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/remove-ip-override)`
     `(ALPHA)` Remove an IP override from a key. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/recaptcha/keys/update)`
     `(ALPHA)` Update a Key. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud recaptcha keys](https://docs.cloud.google.com/sdk/gcloud/reference/recaptcha/keys)
