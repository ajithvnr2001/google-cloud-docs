NAME
    

gcloud alpha backup-dr auto-protection-bindings - manage Backup and DR auto protection bindings 
SYNOPSIS
    

`gcloud alpha backup-dr auto-protection-bindings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Backup and DR auto protection bindings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/auto-protection-bindings/create)`
     `(ALPHA)` Create a Backup and DR auto-protection binding. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/auto-protection-bindings/delete)`
     `(ALPHA)` Delete a Backup and DR auto-protection binding. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/auto-protection-bindings/describe)`
     `(ALPHA)` Describe a Backup and DR auto-protection binding. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/auto-protection-bindings/list)`
     `(ALPHA)` List Backup and DR auto-protection bindings. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta backup-dr auto-protection-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/auto-protection-bindings)
