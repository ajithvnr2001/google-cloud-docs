NAME
    

gcloud alpha backup-dr data-source-references - command group for Backup and DR Data Source References 
SYNOPSIS
    

`gcloud alpha backup-dr data-source-references` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Command group for Backup and DR Data Source References. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/data-source-references/describe)`
     `(ALPHA)` Show details of the data source reference. 
`[fetch-for-resource-type](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/data-source-references/fetch-for-resource-type)`
     `(ALPHA)` Fetch Data Source References for a given resource type and location. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/data-source-references/list)`
     `(ALPHA)` List Backup and DR data source references. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud backup-dr data-source-references](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/data-source-references)
    
    
    [gcloud beta backup-dr data-source-references](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/data-source-references)
