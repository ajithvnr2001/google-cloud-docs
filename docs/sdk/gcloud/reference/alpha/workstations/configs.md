NAME
    

gcloud alpha workstations configs - manage Cloud Workstations configuration resources 
SYNOPSIS
    

`gcloud alpha workstations configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Workstations configuration resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs/create)`
     `(ALPHA)` Create a workstation configuration. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs/delete)`
     `(ALPHA)` Delete a workstation configuration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs/describe)`
     `(ALPHA)` Describe a config. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a configuration.. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs/list)`
     `(ALPHA)` List workstation configurations. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a configuration. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs/update)`
     `(ALPHA)` Updates a workstation configuration. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud workstations configs](https://docs.cloud.google.com/sdk/gcloud/reference/workstations/configs)
    
    
    [gcloud beta workstations configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs)
