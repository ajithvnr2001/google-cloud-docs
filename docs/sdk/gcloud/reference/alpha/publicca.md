NAME
    

gcloud alpha publicca - manage accounts for Google Trust Services' Certificate Authority 
SYNOPSIS
    

`gcloud alpha publicca` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Publicca command group lets you create an external account key used for binding to an Automatic Certificate Management Environment (ACME) account. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[external-account-keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/publicca/external-account-keys)`
     `(ALPHA)` Create ACME external account binding keys. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud publicca](https://docs.cloud.google.com/sdk/gcloud/reference/publicca)
    
    
    [gcloud beta publicca](https://docs.cloud.google.com/sdk/gcloud/reference/beta/publicca)
