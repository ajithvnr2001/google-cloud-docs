NAME
    

gcloud alpha number-registry operations - manage Operation resources 
SYNOPSIS
    

`gcloud alpha number-registry operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Operation resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/operations/cancel)`
     `(ALPHA)` Cancel operations. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/operations/delete)`
     `(ALPHA)` Delete operations. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/operations/describe)`
     `(ALPHA)` Describe operations. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/operations/list)`
     `(ALPHA)` List operations. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/operations/wait)`
     `(ALPHA)` Wait operations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
