NAME
    

gcloud alpha number-registry discovered-ranges - manage discovered range resources 
SYNOPSIS
    

`gcloud alpha number-registry discovered-ranges` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage discovered range resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/discovered-ranges/describe)`
     `(ALPHA)` Gets details of a single discovered range resource. 
`[find-free-ip-ranges](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/discovered-ranges/find-free-ip-ranges)`
     `(ALPHA)` Find free IP ranges in a discovered range. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/discovered-ranges/list)`
     `(ALPHA)` List discovered range resources. 
`[show-utilization](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/discovered-ranges/show-utilization)`
     `(ALPHA)` Show utilization of a discovered range. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
