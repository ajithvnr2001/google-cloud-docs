NAME
    

gcloud alpha number-registry ipam-admin-scopes - manage IPAM admin scopes. This is the scope of which resources CNR can discover 
SYNOPSIS
    

`gcloud alpha number-registry ipam-admin-scopes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage IPAM admin scopes. This is the scope of which resources CNR can discover. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[check-availability](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/check-availability)`
     `(ALPHA)` Check the availability of IPAM admin scopes. 
`[cleanup](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/cleanup)`
     `(ALPHA)` Clean up a single IPAM admin scope resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/create)`
     `(ALPHA)` Create an IPAM admin scope resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/delete)`
     `(ALPHA)` Delete a single IPAM admin scope resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/describe)`
     `(ALPHA)` Gets details of a single IPAM admin scope resource. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/disable)`
     `(ALPHA)` Disable a single IPAM admin scope resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/list)`
     `(ALPHA)` List IPAM admin scope resources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/number-registry/ipam-admin-scopes/update)`
     `(ALPHA)` Update the parameters of a single IPAM admin scope resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
