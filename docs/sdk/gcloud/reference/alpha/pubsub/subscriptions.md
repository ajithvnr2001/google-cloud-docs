NAME
    

gcloud alpha pubsub subscriptions - manage Cloud Pub/Sub subscriptions 
SYNOPSIS
    

`gcloud alpha pubsub subscriptions` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Pub/Sub subscriptions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/config)`
     `(ALPHA)` Manage Pub/Sub subscription configurations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[ack](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/ack)`
     `(ALPHA)` Acknowledges one or more messages on the specified subscription. 
`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a subscription. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/create)`
     `(ALPHA)` Creates one or more Cloud Pub/Sub subscriptions. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/delete)`
     `(ALPHA)` Deletes one or more Cloud Pub/Sub subscriptions. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/describe)`
     `(ALPHA)` Describes a Cloud Pub/Sub subscription. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a subscription. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/list)`
     `(ALPHA)` Lists Cloud Pub/Sub subscriptions. 
`[modify-ack-deadline](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/modify-ack-deadline)`
     `(ALPHA)` `(DEPRECATED)` Modifies the ACK deadline for a specific Cloud Pub/Sub message. 
`[modify-message-ack-deadline](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/modify-message-ack-deadline)`
     `(ALPHA)` Modifies the ACK deadline for a specific Cloud Pub/Sub message. 
`[modify-push-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/modify-push-config)`
     `(ALPHA)` Modifies the push configuration of a Cloud Pub/Sub subscription. 
`[pull](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/pull)`
     `(ALPHA)` Pulls one or more Cloud Pub/Sub messages from a subscription. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a subscription. 
`[seek](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/seek)`
     `(ALPHA)` Resets a subscription's backlog to a point in time or to a given snapshot. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Pub/Sub Subscription. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions/update)`
     `(ALPHA)` Updates an existing Cloud Pub/Sub subscription. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud pubsub subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/subscriptions)
    
    
    [gcloud beta pubsub subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions)
