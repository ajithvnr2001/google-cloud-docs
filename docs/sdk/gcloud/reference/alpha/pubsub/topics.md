NAME
    

gcloud alpha pubsub topics - manage Cloud Pub/Sub topics 
SYNOPSIS
    

`gcloud alpha pubsub topics` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Pub/Sub topics. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/config)`
     `(ALPHA)` Manage Pub/Sub topic configurations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a topic. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/create)`
     `(ALPHA)` Creates one or more Cloud Pub/Sub topics. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/delete)`
     `(ALPHA)` Deletes one or more Cloud Pub/Sub topics. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/describe)`
     `(ALPHA)` Describes a Cloud Pub/Sub topic. 
`[detach-subscription](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/detach-subscription)`
     `(ALPHA)` Detaches one or more Cloud Pub/Sub subscriptions. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a topic. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/list)`
     `(ALPHA)` Lists Cloud Pub/Sub topics within a project. 
`[list-snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/list-snapshots)`
     `(ALPHA)` Lists Cloud Pub/Sub snapshots from a given topic. 
`[list-subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/list-subscriptions)`
     `(ALPHA)` Lists Cloud Pub/Sub subscriptions from a given topic. 
`[publish](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/publish)`
     `(ALPHA)` Publishes a message to the specified topic. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a topic. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Cloud Pub/Sub Topic. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/topics/update)`
     `(ALPHA)` Updates an existing Cloud Pub/Sub topic. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud pubsub topics](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics)
    
    
    [gcloud beta pubsub topics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/topics)
