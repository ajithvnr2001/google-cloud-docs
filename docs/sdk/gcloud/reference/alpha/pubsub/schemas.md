NAME
    

gcloud alpha pubsub schemas - manage Pub/Sub schemas 
SYNOPSIS
    

`gcloud alpha pubsub schemas` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud alpha pubsub schemas group lets you create and manage Pub/Sub schemas. These schemas can be attached to topics to enable validation of published messages. Commands to validate schemas and messages against schemas are also available. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[commit](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/commit)`
     `(ALPHA)` Commit a Pub/Sub schema revision. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/create)`
     `(ALPHA)` Create a Pub/Sub schema. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/delete)`
     `(ALPHA)` Delete a Pub/Sub schema. 
`[delete-revision](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/delete-revision)`
     `(ALPHA)` Delete a Pub/Sub schema revision. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/describe)`
     `(ALPHA)` Show details of a Pub/Sub schema. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/list)`
     `(ALPHA)` List Pub/Sub schemas. 
`[list-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/list-revisions)`
     `(ALPHA)` List revisions of a Pub/Sub schema. 
`[rollback](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/rollback)`
     `(ALPHA)` Roll back a Pub/Sub schema to a specified revision. 
`[validate-message](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/validate-message)`
     `(ALPHA)` Validate a message against a Pub/Sub schema. 
`[validate-schema](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas/validate-schema)`
     `(ALPHA)` Validate a Pub/Sub schema. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
