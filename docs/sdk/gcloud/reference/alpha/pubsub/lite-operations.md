NAME
    

gcloud alpha pubsub lite-operations - manage Pub/Sub Lite operations 
SYNOPSIS
    

`gcloud alpha pubsub lite-operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Pub/Sub Lite operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/lite-operations/describe)`
     `(ALPHA)` Describe a Pub/Sub Lite operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/lite-operations/list)`
     `(ALPHA)` List Pub/Sub Lite operations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud pubsub lite-operations](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-operations)
    
    
    [gcloud beta pubsub lite-operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-operations)
