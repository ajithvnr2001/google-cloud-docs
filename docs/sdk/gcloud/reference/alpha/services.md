NAME
    

gcloud alpha services - list, enable and disable APIs and services 
SYNOPSIS
    

`gcloud alpha services` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud services command group lets you manage your project's access to services provided by Google and third parties. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys)`
     `(ALPHA)` Manage API keys. 
`[groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/groups)`
     `(ALPHA)` View service group information. 
`[identity](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/identity)`
     `(ALPHA)` Manage service identity. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/operations)`
     `(ALPHA)` Manage Operation for various services. 
`[peered-dns-domains](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/peered-dns-domains)`
     `(ALPHA)` Peered DNS domains for various private service connections. 
`[policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/policies)`
     `(ALPHA)` Get/update consumer policies and get the effective policy. 
`[quota](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/quota)`
     `(ALPHA)` Manage service consumer quota. 
`[vpc-peerings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/vpc-peerings)`
     `(ALPHA)` VPC Peerings to various services. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/disable)`
     `(ALPHA)` Disable a service for consumption for a project, folder or organization. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/enable)`
     `(ALPHA)` Enables a service for consumption for a project, folder or organization. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/list)`
     `(ALPHA)` List services for a project, folder or organization. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud services](https://docs.cloud.google.com/sdk/gcloud/reference/services)
    
    
    [gcloud beta services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services)
