NAME
    

gcloud alpha observability scopes - manage Scope resources 
SYNOPSIS
    

`gcloud alpha observability scopes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Scope resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/observability/scopes/describe)`
     `(ALPHA)` Describe scopes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/observability/scopes/update)`
     `(ALPHA)` Update scopes. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud observability scopes](https://docs.cloud.google.com/sdk/gcloud/reference/observability/scopes)
