NAME
    

gcloud alpha dataproc operations - view and manage Dataproc operations 
SYNOPSIS
    

`gcloud alpha dataproc operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` View and manage Dataproc operations. 
EXAMPLES
     To cancel an active operation, run: 
    
    
    [gcloud alpha dataproc operations cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/cancel) operation_id

To view the details of an operation, run: 
    
    
    [gcloud alpha dataproc operations describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/describe) operation_id

To see the list of all operations, run: 
    
    
    [gcloud alpha dataproc operations list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/list)

To delete the record of an inactive operation, run: 
    
    
    [gcloud alpha dataproc operations delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/delete) operation_id

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/cancel)`
     `(ALPHA)` Cancel an active operation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/delete)`
     `(ALPHA)` Delete the record of an inactive operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/describe)`
     `(ALPHA)` View the details of an operation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/get-iam-policy)`
     `(ALPHA)` Get IAM policy for an operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/list)`
     `(ALPHA)` View the list of all operations. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations/set-iam-policy)`
     `(ALPHA)` Set IAM policy for an operation. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud dataproc operations](https://docs.cloud.google.com/sdk/gcloud/reference/dataproc/operations)
    
    
    [gcloud beta dataproc operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations)
