NAME
    

gcloud alpha service-extensions extension-bindings - manage Extension Binding resources 
SYNOPSIS
    

`gcloud alpha service-extensions extension-bindings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Extension Binding resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings/create)`
     `(ALPHA)` Create extensionBindings. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings/delete)`
     `(ALPHA)` Delete extensionBindings. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings/describe)`
     `(ALPHA)` Describe extensionBindings. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings/import)`
     `(ALPHA)` Import (create or update) extensionBinding from a file. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings/list)`
     `(ALPHA)` List extensionBindings. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings/update)`
     `(ALPHA)` Update extensionBindings. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta service-extensions extension-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings)
