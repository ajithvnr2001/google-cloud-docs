NAME
    

gcloud alpha service-extensions cdn-edge-extensions - manage Service Extensions `CdnEdgeExtension` resources 
SYNOPSIS
    

`gcloud alpha service-extensions cdn-edge-extensions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Service Extensions `CdnEdgeExtension` resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/cdn-edge-extensions/delete)`
     `(ALPHA)` Delete a `CdnEdgeExtension` resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/cdn-edge-extensions/describe)`
     `(ALPHA)` Describe a `CdnEdgeExtension` resource. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/cdn-edge-extensions/import)`
     `(ALPHA)` Import a `CdnEdgeExtension` resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/cdn-edge-extensions/list)`
     `(ALPHA)` List `CdnEdgeExtension` resources. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta service-extensions cdn-edge-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/cdn-edge-extensions)
