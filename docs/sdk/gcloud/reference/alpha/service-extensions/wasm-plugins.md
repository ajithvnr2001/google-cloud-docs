NAME
    

gcloud alpha service-extensions wasm-plugins - interact with and manage Service Extensions `WasmPlugins`
SYNOPSIS
    

`gcloud alpha service-extensions wasm-plugins` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Interact with and manage Service Extensions `WasmPlugins`. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-plugins/create)`
     `(ALPHA)` Create a `WasmPlugin` resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-plugins/delete)`
     `(ALPHA)` Delete a `WasmPlugin` resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-plugins/describe)`
     `(ALPHA)` Show details about a `WasmPlugin` resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-plugins/list)`
     `(ALPHA)` List all `WasmPlugin` resources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-plugins/update)`
     `(ALPHA)` Update a `WasmPlugin` resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud service-extensions wasm-plugins](https://docs.cloud.google.com/sdk/gcloud/reference/service-extensions/wasm-plugins)
    
    
    [gcloud beta service-extensions wasm-plugins](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/wasm-plugins)
