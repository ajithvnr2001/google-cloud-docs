NAME
    

gcloud alpha container - deploy and manage clusters of machines for running containers 
SYNOPSIS
    

`gcloud alpha container` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Deploy and manage clusters of machines for running containers. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[ai](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/ai)`
     `(ALPHA)` Manage AI related workloads for GKE. 
`[attached](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/attached)`
     `(ALPHA)` Manage Attached clusters for running containers. 
`[aws](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/aws)`
     `(ALPHA)` `(DEPRECATED)` Deploy and manage clusters of machines on AWS for running containers. 
`[azure](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/azure)`
     `(ALPHA)` `(DEPRECATED)` Deploy and manage clusters of machines on Azure for running containers. 
`[backup-restore](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore)`
     `(ALPHA)` Backup for GKE Services. 
`[bare-metal](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/bare-metal)`
     `(ALPHA)` Deploy and manage Anthos clusters on bare metal for running containers. 
`[binauthz](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/binauthz)`
     `(ALPHA)` Manage attestations for Binary Authorization on Google Cloud Platform. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/clusters)`
     `(ALPHA)` Deploy and teardown Google Kubernetes Engine clusters. 
`[fleet](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet)`
     `(ALPHA)` Centrally manage features and services on all your Kubernetes clusters with fleet. 
`[hub](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub)`
     `(ALPHA)` Centrally manage features and services on all your Kubernetes clusters with fleet. 
`[images](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/images)`
     `(ALPHA)` List and manipulate Google Container Registry images. 
`[node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/node-pools)`
     `(ALPHA)` Create and delete operations for Google Kubernetes Engine node pools. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/operations)`
     `(ALPHA)` Get and list operations for Google Kubernetes Engine clusters. 
`[subnets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/subnets)`
     `(ALPHA)` Manage subnets to be used by Google Kubernetes Engine clusters. 
`[vmware](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware)`
     `(ALPHA)` Deploy and manage Anthos clusters on VMware for running containers. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[get-server-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/get-server-config)`
     `(ALPHA)` Get Kubernetes Engine server config. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud container](https://docs.cloud.google.com/sdk/gcloud/reference/container)
    
    
    [gcloud beta container](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container)
