NAME
    

gcloud alpha device-run - manage automation sessions and jobs on devices 
SYNOPSIS
    

`gcloud alpha device-run` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage automation sessions and jobs on devices. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[devices](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/devices)`
     `(ALPHA)` Manage Device Run devices. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/locations)`
     `(ALPHA)` Get information about Device Run locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/operations)`
     `(ALPHA)` Manage long-running operations of Device Run. 
`[sessions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/sessions)`
     `(ALPHA)` Manage Device Run sessions. 
`[software-versions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/software-versions)`
     `(ALPHA)` Manage Device Run software versions. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta device-run](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run)
