NAME
    

gcloud alpha scc - manage Cloud SCC resources 
SYNOPSIS
    

`gcloud alpha scc` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Google Cloud SCC (Security Command Center) resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[artifact-guard](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard)`
     `(ALPHA)` Manage Cloud Security Command Center (SCC) artifact guard. 
`[assets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/assets)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) assets. 
`[custom-modules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) custom modules. 
`[findings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) findings. 
`[iac-validation-reports](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/iac-validation-reports)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) iac-validation-reports. 
`[manage](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) settings. 
`[muteconfigs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/muteconfigs)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) mute configs. 
`[notifications](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/notifications)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) notifications. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/operations)`
     `(ALPHA)` Manage Cloud SCC (Security Command Center) operations. 
`[posture-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/posture-deployments)`
     `(ALPHA)` Manage Cloud Security Command Center (SCC) posture deployments. 
`[posture-operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/posture-operations)`
     `(ALPHA)` Manage Cloud Security Command Center (SCC) posture operations.
