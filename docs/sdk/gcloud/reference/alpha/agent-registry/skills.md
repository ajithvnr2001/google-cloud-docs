#  gcloud alpha agent-registry skills Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha agent-registry skills - manage Skill resources 
SYNOPSIS
    

`gcloud alpha agent-registry skills` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Skill resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/revisions)`
     `(ALPHA)` Manage Skill Revision resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding for a skill. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/create)`
     `(ALPHA)` Create skills. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/delete)`
     `(ALPHA)` Delete skills. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/describe)`
     `(ALPHA)` Describe skills. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a skill. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/list)`
     `(ALPHA)` List skills. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from a skill. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/search)`
     `(ALPHA)` search skills. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a skill. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/skills/update)`
     `(ALPHA)` Update skills. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
