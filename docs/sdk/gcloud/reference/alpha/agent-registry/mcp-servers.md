NAME
    

gcloud alpha agent-registry mcp-servers - manage Mcp Server resources 
SYNOPSIS
    

`gcloud alpha agent-registry mcp-servers` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Mcp Server resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/mcp-servers/describe)`
     `(ALPHA)` Get details of an MCP server. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/mcp-servers/list)`
     `(ALPHA)` List MCP servers. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/mcp-servers/search)`
     `(ALPHA)` Search MCP servers matching criteria. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud agent-registry mcp-servers](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/mcp-servers)
