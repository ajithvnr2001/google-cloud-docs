NAME
    

gcloud alpha scc settings - manage Cloud SCC (Security Command Center) settings 
SYNOPSIS
    

`gcloud alpha scc settings` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud SCC (Security Command Center) settings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/services)`
     `(ALPHA)` Manage Cloud SCC services settings. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe-explicit](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/describe-explicit)`
     `(ALPHA)` Display settings of Security Command Center(SCC). 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
