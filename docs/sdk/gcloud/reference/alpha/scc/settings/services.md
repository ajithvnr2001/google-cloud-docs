NAME
    

gcloud alpha scc settings services - manage Cloud SCC services settings 
SYNOPSIS
    

`gcloud alpha scc settings services` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud SCC services settings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[modules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/services/modules)`
     `(ALPHA)` Manage Cloud SCC modules settings. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/services/describe)`
     `(ALPHA)` Display effective service settings of Security Command Center(SCC). 
`[describe-explicit](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/services/describe-explicit)`
     `(ALPHA)` Display component settings of Security Command Center(SCC). 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/services/disable)`
     `(ALPHA)` Disable a service in Security Command Center(SCC). 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/services/enable)`
     `(ALPHA)` Enable a service in Security Command Center(SCC). 
`[inherit](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/settings/services/inherit)`
     `(ALPHA)` Set service enablement state to "inherited" in Security Command Center(SCC). 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
