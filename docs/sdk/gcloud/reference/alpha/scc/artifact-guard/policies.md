NAME
    

gcloud alpha scc artifact-guard policies - manage Cloud Security Command Center artifact guard policies 
SYNOPSIS
    

`gcloud alpha scc artifact-guard policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Security Command Center (SCC) artifact guard policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/policies/create)`
     `(ALPHA)` Create a new artifact guard policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/policies/delete)`
     `(ALPHA)` Delete an artifact guard policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/policies/describe)`
     `(ALPHA)` Describe an artifact guard policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/policies/list)`
     `(ALPHA)` List artifact guard policies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/policies/update)`
     `(ALPHA)` Update an existing artifact guard policy. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
