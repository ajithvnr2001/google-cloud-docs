NAME
    

gcloud alpha scc custom-modules etd - manage custom modules 
SYNOPSIS
    

`gcloud alpha scc custom-modules etd` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage custom modules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/create)`
     `(ALPHA)` Create an Event Threat Detection custom module. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/delete)`
     `(ALPHA)` Delete an Event Threat Detection custom module. 
`[get](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/get)`
     `(ALPHA)` Get the details of an Event Threat Detection custom module. 
`[get-effective](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/get-effective)`
     `(ALPHA)` Get the details of a Event Threat Detection custom module with effective enablement state. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/list)`
     `(ALPHA)` List the details of Event Threat Detection custom modules. 
`[list-descendant](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/list-descendant)`
     `(ALPHA)` List the details of resident and descendant Event Threat Detection custom modules. 
`[list-effective](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/list-effective)`
     `(ALPHA)` List the details of Event Threat Detection custom modules with effective enablement states. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/etd/update)`
     `(ALPHA)` Update an Event Threat Detection custom module. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
