NAME
    

gcloud alpha scc custom-modules sha - manage Security Health Analytics custom modules 
SYNOPSIS
    

`gcloud alpha scc custom-modules sha` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Security Health Analytics custom modules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/create)`
     `(ALPHA)` Create a Security Health Analytics custom module. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/delete)`
     `(ALPHA)` Delete a Security Health Analytics custom module. 
`[get](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/get)`
     `(ALPHA)` Get the details of a Security Health Analytics custom module. 
`[get-effective](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/get-effective)`
     `(ALPHA)` Get the details of a Security Health Analytics custom module with effective enablement state. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/list)`
     `(ALPHA)` List the details of Security Health Analytics custom modules. 
`[list-descendant](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/list-descendant)`
     `(ALPHA)` List the details of the resident and descendant Security Health Analytics custom modules. 
`[list-effective](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/list-effective)`
     `(ALPHA)` List the details of Security Health Analytics custom modules with effective enablement states. 
`[simulate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/simulate)`
     `(ALPHA)` Validates a Security Health Analytics custom module. 
`[test](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/test)`
     `(ALPHA)` Test a Security Health Analytics custom module. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/custom-modules/sha/update)`
     `(ALPHA)` Update a Security Health Analytics custom module. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud scc custom-modules sha](https://docs.cloud.google.com/sdk/gcloud/reference/scc/custom-modules/sha)
