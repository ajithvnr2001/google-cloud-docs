NAME
    

gcloud alpha scc manage custom-modules etd - manage custom modules 
SYNOPSIS
    

`gcloud alpha scc manage custom-modules etd` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage custom modules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/create)`
     `(ALPHA)` Create an Event Threat Detection custom module. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/delete)`
     `(ALPHA)` Delete an Event Threat Detection custom module. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/describe)`
     `(ALPHA)` Get the details of a Event Threat Detection custom module. 
`[describe-effective](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/describe-effective)`
     `(ALPHA)` Get the effective details of a Event Threat Detection effective custom module. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/list)`
     `(ALPHA)` List details of resident and inherited Event Threat Detection Custom Modules. 
`[list-descendant](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/list-descendant)`
     `(ALPHA)` List the details of the resident and descendant Event Threat Detection custom modules. 
`[list-effective](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/list-effective)`
     `(ALPHA)` List the details of an Event Threat Detection effective custom module. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/update)`
     `(ALPHA)` Update an Event Threat Detection custom module. 
`[validate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/custom-modules/etd/validate)`
     `(ALPHA)` Command to validate an ETD custom module. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud scc manage custom-modules etd](https://docs.cloud.google.com/sdk/gcloud/reference/scc/manage/custom-modules/etd)
