NAME
    

gcloud alpha scc manage services - manage Cloud SCC (Security Command Center) services 
SYNOPSIS
    

`gcloud alpha scc manage services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud SCC (Security Command Center) services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/services/describe)`
     `(ALPHA)` Get the details of a Security Command Center service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/services/list)`
     `(ALPHA)` List the details of Security Command Center services. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/manage/services/update)`
     `(ALPHA)` Update a Security Command Center service. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud scc manage services](https://docs.cloud.google.com/sdk/gcloud/reference/scc/manage/services)
