NAME
    

gcloud alpha scc muteconfigs - manage Cloud SCC (Security Command Center) mute configs 
SYNOPSIS
    

`gcloud alpha scc muteconfigs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud SCC (Security Command Center) mute configs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/muteconfigs/create)`
     `(ALPHA)` Create a Security Command Center mute config. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/muteconfigs/delete)`
     `(ALPHA)` Delete a Security Command Center mute config. 
`[get](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/muteconfigs/get)`
     `(ALPHA)` Get a Security Command Center mute config. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/muteconfigs/list)`
     `(ALPHA)` ListSecurity Command Center mute configs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/muteconfigs/update)`
     `(ALPHA)` Update a Security Command Center mute config. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud scc muteconfigs](https://docs.cloud.google.com/sdk/gcloud/reference/scc/muteconfigs)
