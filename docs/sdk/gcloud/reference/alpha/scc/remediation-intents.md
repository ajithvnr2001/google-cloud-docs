NAME
    

gcloud alpha scc remediation-intents - manages Cloud Security Command Center RemediationIntent resource 
SYNOPSIS
    

`gcloud alpha scc remediation-intents` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manages Cloud Security Command Center (SCC) RemediationIntent resource. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[auto-remediate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/remediation-intents/auto-remediate)`
     `(ALPHA)` Command for semi-automatic remediation of SCC findings. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/remediation-intents/create)`
     `(ALPHA)` Creates a remediation intent resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/remediation-intents/delete)`
     `(ALPHA)` Deletes a remediation intent resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/remediation-intents/describe)`
     `(ALPHA)` Describes a remediation intent resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/remediation-intents/list)`
     `(ALPHA)` Lists the remediation intent resources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/remediation-intents/update)`
     `(ALPHA)` Updates a remediation intent resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
