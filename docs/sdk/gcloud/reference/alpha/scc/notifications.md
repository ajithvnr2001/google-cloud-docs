NAME
    

gcloud alpha scc notifications - manage Cloud SCC (Security Command Center) notifications 
SYNOPSIS
    

`gcloud alpha scc notifications` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud SCC (Security Command Center) notifications. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/notifications/create)`
     `(ALPHA)` Create a Security Command Center notification config. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/notifications/delete)`
     `(ALPHA)` Delete a Security Command Center notification config. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/notifications/describe)`
     `(ALPHA)` Describe a Security Command Center notification config. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/notifications/list)`
     `(ALPHA)` List Security Command Center notification configs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/notifications/update)`
     `(ALPHA)` Update a Security Command Center notification config. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud scc notifications](https://docs.cloud.google.com/sdk/gcloud/reference/scc/notifications)
    
    
    [gcloud beta scc notifications](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/notifications)
