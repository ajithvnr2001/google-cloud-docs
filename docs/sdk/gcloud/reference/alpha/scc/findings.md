NAME
    

gcloud alpha scc findings - manage Cloud SCC (Security Command Center) findings 
SYNOPSIS
    

`gcloud alpha scc findings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud SCC (Security Command Center) findings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[bulk-mute](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/bulk-mute)`
     `(ALPHA)` Bulk mute Security Command Center findings based on a filter. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/create)`
     `(ALPHA)` Create a Security Command Center finding. 
`[export-to-bigquery](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/export-to-bigquery)`
     `(ALPHA)` Export Security Command Center findings to bigquery. 
`[group](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/group)`
     `(ALPHA)` Filter an organization or source's findings and groups them by their specified properties. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/list)`
     `(ALPHA)` List an organization or source's findings. 
`[list-marks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/list-marks)`
     `(ALPHA)` List a finding's security marks. 
`[set-mute](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/set-mute)`
     `(ALPHA)` Update a Security Command Center finding's mute state. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/update)`
     `(ALPHA)` Update a Security Command Center finding. 
`[update-marks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/findings/update-marks)`
     `(ALPHA)` Update Security Command Center finding's security marks. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
