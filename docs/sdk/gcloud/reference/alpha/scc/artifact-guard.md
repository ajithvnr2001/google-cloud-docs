NAME
    

gcloud alpha scc artifact-guard - manage Cloud Security Command Center artifact guard 
SYNOPSIS
    

`gcloud alpha scc artifact-guard` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Security Command Center (SCC) artifact guard. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[connectors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/connectors)`
     `(ALPHA)` Manage Cloud Security Command Center (SCC) artifact guard connectors. 
`[images](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/images)`
     `(ALPHA)` Manage Artifact Guard image scanning. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/operations)`
     `(ALPHA)` Manage Cloud Security Command Center (SCC) artifact guard operations. 
`[policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/artifact-guard/policies)`
     `(ALPHA)` Manage Cloud Security Command Center (SCC) artifact guard policies. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
