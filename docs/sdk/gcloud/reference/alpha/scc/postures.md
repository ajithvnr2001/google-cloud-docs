NAME
    

gcloud alpha scc postures - manage Cloud Security Command Center postures 
SYNOPSIS
    

`gcloud alpha scc postures` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Security Command Center (SCC) postures. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/postures/create)`
     `(ALPHA)` Create a Cloud Security Command Center (SCC) posture. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/postures/delete)`
     `(ALPHA)` Delete a Cloud Security Command Center (SCC) posture. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/postures/describe)`
     `(ALPHA)` Describe a Cloud Security Command Center (SCC) posture. 
`[extract](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/postures/extract)`
     `(ALPHA)` Extract a Cloud Security Command Center (SCC) posture from a workload. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/postures/list)`
     `(ALPHA)` Lists all the Cloud Security Command Center postures for an organization. 
`[list-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/postures/list-revisions)`
     `(ALPHA)` List the revisions of a Cloud Security Command Center (SCC) posture. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/postures/update)`
     `(ALPHA)` Update the given Cloud Security Command Center (SCC) posture. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud scc postures](https://docs.cloud.google.com/sdk/gcloud/reference/scc/postures)
