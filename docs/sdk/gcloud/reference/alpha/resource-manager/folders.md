#  gcloud alpha resource-manager folders Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha resource-manager folders - manage Cloud Folders 
SYNOPSIS
    

`gcloud alpha resource-manager folders` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands to query and update your Cloud Folders. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding for a folder. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/create)`
     `(ALPHA)` Create a new folder. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/delete)`
     `(ALPHA)` Delete a folder. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/describe)`
     `(ALPHA)` Show metadata for a folder. 
`[get-ancestors-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/get-ancestors-iam-policy)`
     `(ALPHA)` Get IAM policies for a folder and its ancestors. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a folder. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/list)`
     `(ALPHA)` List folders accessible by the active account. 
`[move](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/move)`
     `(ALPHA)` Move a folder to a new position within the same organization. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding for a folder. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/search)`
     `(ALPHA)` Search folders matching the specified query. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/set-iam-policy)`
     `(ALPHA)` Set IAM policy for a folder. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/undelete)`
     `(ALPHA)` Undelete a folder. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/folders/update)`
     `(ALPHA)` Update the display name of a folder. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud resource-manager folders](https://docs.cloud.google.com/sdk/gcloud/reference/resource-manager/folders)
    
    
    [gcloud beta resource-manager folders](https://docs.cloud.google.com/sdk/gcloud/reference/beta/resource-manager/folders)
