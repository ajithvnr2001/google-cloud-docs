NAME
    

gcloud alpha developer-connect connections git-repository-links - manage git repository link resources 
SYNOPSIS
    

`gcloud alpha developer-connect connections git-repository-links` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage git repository link resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links/create)`
     `(ALPHA)` Create a git repository link. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links/delete)`
     `(ALPHA)` Delete a single git repository link. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links/describe)`
     `(ALPHA)` Get details of a single git repository link. 
`[fetch-read-token](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links/fetch-read-token)`
     `(ALPHA)` Fetch the read token of a given gitRepositoryLink. 
`[fetch-read-write-token](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links/fetch-read-write-token)`
     `(ALPHA)` Fetch the read/write token of a given gitRepositoryLink. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links/list)`
     `(ALPHA)` List all git repository links in a connection. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links/update)`
     `(ALPHA)` Update a git repository link to enable metrics collection. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud developer-connect connections git-repository-links](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/connections/git-repository-links)
    
    
    [gcloud beta developer-connect connections git-repository-links](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links)
