NAME
    

gcloud alpha deployment-manager operations - commands for Deployment Manager operations 
SYNOPSIS
    

`gcloud alpha deployment-manager operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands to list, examine, and wait for long-running operations. 
EXAMPLES
     To view the details of an operation, run: 
    
    
    [gcloud alpha deployment-manager operations describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/operations/describe) operation-name

To see the list of all operations, run: 
    
    
    [gcloud alpha deployment-manager operations list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/operations/list)

To wait for an operation to complete, run: 
    
    
    [gcloud alpha deployment-manager operations wait](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/operations/wait) operation-name

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/operations/describe)`
     `(ALPHA)` Provide information about an operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/operations/list)`
     `(ALPHA)` List operations in a project. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/operations/wait)`
     `(ALPHA)` Wait for all operations specified to complete before returning. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud deployment-manager operations](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/operations)
    
    
    [gcloud beta deployment-manager operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/operations)
