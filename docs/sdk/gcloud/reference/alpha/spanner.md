NAME
    

gcloud alpha spanner - command groups for Cloud Spanner 
SYNOPSIS
    

`gcloud alpha spanner` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Command groups for Cloud Spanner. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backup-schedules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backup-schedules)`
     `(ALPHA)` Manage Cloud Spanner backup schedules. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups)`
     `(ALPHA)` Manage Cloud Spanner backups. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases)`
     `(ALPHA)` Manage Cloud Spanner databases. 
`[instance-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/instance-configs)`
     `(ALPHA)` Manage Cloud Spanner instance configs. 
`[instance-partitions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/instance-partitions)`
     `(ALPHA)` Manage Spanner instance partitions. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/instances)`
     `(ALPHA)` Manage Cloud Spanner instances. 
`[migrate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/migrate)`
     `(ALPHA)` Migrate external databases to Cloud Spanner. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/operations)`
     `(ALPHA)` Manage Cloud Spanner operations. 
`[rows](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/rows)`
     `(ALPHA)` Manage the rows in Cloud Spanner databases. 
`[samples](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/samples)`
     `(ALPHA)` Cloud Spanner sample apps. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[cli](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/cli)`
     `(ALPHA)` An interactive shell for Spanner. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud spanner](https://docs.cloud.google.com/sdk/gcloud/reference/spanner)
    
    
    [gcloud beta spanner](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner)
