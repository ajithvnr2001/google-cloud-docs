NAME
    

gcloud alpha tasks - manage Cloud Tasks queues and tasks 
SYNOPSIS
    

`gcloud alpha tasks` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Tasks queues and tasks. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[cmek-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/cmek-config)`
     `(ALPHA)` Get or change CMEK configuration for Cloud Tasks. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/locations)`
     `(ALPHA)` Get information about Cloud Tasks locations. 
`[queues](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/queues)`
     `(ALPHA)` Manage Cloud Tasks queues. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[acknowledge](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/acknowledge)`
     `(ALPHA)` Acknowledge the lease on a task in a pull queue. 
`[batch-create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/batch-create)`
     `(ALPHA)` Create multiple tasks from a file in a single batch operation. 
`[buffer](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/buffer)`
     `(ALPHA)` Buffers a task into a queue. 
`[cancel-lease](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/cancel-lease)`
     `(ALPHA)` Cancel the lease on a task in a pull queue. 
`[create-app-engine-task](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/create-app-engine-task)`
     `(ALPHA)` Create and add a task that targets App Engine. 
`[create-http-task](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/create-http-task)`
     `(ALPHA)` Create and add a task that targets a HTTP endpoint. 
`[create-pull-task](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/create-pull-task)`
     `(ALPHA)` Create and add a task to a pull queue. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/delete)`
     `(ALPHA)` Delete a task or multiple tasks from a queue. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/describe)`
     `(ALPHA)` Show details about a task. 
`[lease](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/lease)`
     `(ALPHA)` Leases a list of tasks and displays them. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/list)`
     `(ALPHA)` List tasks. 
`[renew-lease](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/renew-lease)`
     `(ALPHA)` Renew the lease on a task in a pull queue. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/run)`
     `(ALPHA)` Force a task to run now. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud tasks](https://docs.cloud.google.com/sdk/gcloud/reference/tasks)
    
    
    [gcloud beta tasks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/tasks)
