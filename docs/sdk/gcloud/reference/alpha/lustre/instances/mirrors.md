NAME
    

gcloud alpha lustre instances mirrors - manage Lustre mirror resources 
SYNOPSIS
    

`gcloud alpha lustre instances mirrors` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Lustre mirror resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/mirrors/create)`
     `(ALPHA)` Creates a Managed Lustre mirror. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/mirrors/delete)`
     `(ALPHA)` Deletes a Managed Lustre mirror. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/mirrors/describe)`
     `(ALPHA)` Gets details of a single Managed Lustre mirror. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/mirrors/list)`
     `(ALPHA)` List Lustre mirrors. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/mirrors/update)`
     `(ALPHA)` Updates the parameters of a single Managed Lustre mirror. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
