NAME
    

gcloud alpha lustre instances - manage Lustre instance resources 
SYNOPSIS
    

`gcloud alpha lustre instances` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Lustre instance resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[directory-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/directory-policies)`
     `(ALPHA)` Manage Directory Policy resources. 
`[mirrors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/mirrors)`
     `(ALPHA)` Manage Lustre mirror resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/create)`
     `(ALPHA)` Creates a Managed Lustre instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/delete)`
     `(ALPHA)` Deletes a Managed Lustre instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/describe)`
     `(ALPHA)` Gets details of a single Managed Lustre instance. 
`[export-data](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/export-data)`
     `(ALPHA)` Exports data from a Managed Lustre instance to Cloud Storage. 
`[import-data](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/import-data)`
     `(ALPHA)` Imports data from Cloud Storage to a Managed Lustre instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/list)`
     `(ALPHA)` Lists Managed Lustre instances. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/reschedule-maintenance)`
     `(ALPHA)` Reschedules a planned maintenance window for a Managed Lustre instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/lustre/instances/update)`
     `(ALPHA)` Updates the parameters of a single Managed Lustre instance. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud lustre instances](https://docs.cloud.google.com/sdk/gcloud/reference/lustre/instances)
