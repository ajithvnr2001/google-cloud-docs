NAME
    

gcloud alpha zone-management - zone Management gcloud commands 
SYNOPSIS
    

`gcloud alpha zone-management` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Zone Management gcloud commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[auth](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/zone-management/auth)`
     `(ALPHA)` Zone Management Auth gcloud commands. 
`[identity-providers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/zone-management/identity-providers)`
     `(ALPHA)` Zone Management Service Identity Provider gcloud commands. 
`[projects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/zone-management/projects)`
     `(ALPHA)` Zone Management Project gcloud commands. 
`[service-accounts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/zone-management/service-accounts)`
     `(ALPHA)` Zone Management Service Account gcloud commands. 
`[services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/zone-management/services)`
     `(ALPHA)` Zone Management Service gcloud commands. 
`[zones](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/zone-management/zones)`
     `(ALPHA)` Zone Management Zone gcloud commands. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
