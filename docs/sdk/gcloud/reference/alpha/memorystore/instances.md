NAME
    

gcloud alpha memorystore instances - manage Instance resources 
SYNOPSIS
    

`gcloud alpha memorystore instances` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Instance resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[token-auth-users](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/token-auth-users)`
     `(ALPHA)` Manage Token Auth User resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[backup](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/backup)`
     `(ALPHA)` backup instances. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/create)`
     `(ALPHA)` Create a Memorystore instance. 
`[create-token-auth-user](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/create-token-auth-user)`
     `(ALPHA)` create token auth user for a Memorystore instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/delete)`
     `(ALPHA)` Delete a Memorystore instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/describe)`
     `(ALPHA)` Get details of a Memorystore instance. 
`[finish-migration](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/finish-migration)`
     `(ALPHA)` Finish migration for a Memorystore instance. 
`[get-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/get-certificate-authority)`
     `(ALPHA)` Get certificate authority details of a Memorystore instance. 
`[get-shared-regional-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/get-shared-regional-certificate-authority)`
     `(ALPHA)` Get the shared regional CA certificate bundle for Memorystore. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/list)`
     `(ALPHA)` List all Memorystore instances in a specified project and location. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/reschedule-maintenance)`
     `(ALPHA)` Reschedule maintenance window for an instance. 
`[start-migration](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/start-migration)`
     `(ALPHA)` Start migration for a Memorystore instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/update)`
     `(ALPHA)` Update the configuration of a Memorystore instance. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud memorystore instances](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances)
    
    
    [gcloud beta memorystore instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances)
