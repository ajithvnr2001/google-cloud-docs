NAME
    

gcloud alpha storage hmac - manage Cloud Storage service account HMAC keys 
SYNOPSIS
    

`gcloud alpha storage hmac` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Storage service account HMAC keys. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/hmac/create)`
     `(ALPHA)` Add a service account HMAC. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/hmac/delete)`
     `(ALPHA)` Remove a service account HMAC. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/hmac/describe)`
     `(ALPHA)` Describes a service account HMAC key. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/hmac/list)`
     `(ALPHA)` List service account HMAC keys. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/hmac/update)`
     `(ALPHA)` Change the status of a service account HMAC. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud storage hmac](https://docs.cloud.google.com/sdk/gcloud/reference/storage/hmac)
