NAME
    

gcloud alpha storage buckets get-iam-policy - get the IAM policy for a bucket 
SYNOPSIS
    

`gcloud alpha storage buckets get-iam-policy` `URL` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Get the IAM policy for a bucket. For more information, see [Cloud Identity and Access Management](https://cloud.google.com/storage/docs/access-control/iam). 
EXAMPLES
     To get the IAM policy for BUCKET: 
    
    
    gcloud alpha storage buckets get-iam-policy gs://BUCKET

To output the IAM policy for BUCKET to a file: 
    
    
    gcloud alpha storage buckets get-iam-policy gs://BUCKET > policy.txt

POSITIONAL ARGUMENTS
    

`URL`
     Request IAM policy for this bucket.
