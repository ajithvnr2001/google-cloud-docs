NAME
    

gcloud alpha storage hmac describe - describes a service account HMAC key 
SYNOPSIS
    

`gcloud alpha storage hmac describe` `ACCESS_ID` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `gcloud alpha storage hmac describe` retrieves the specified HMAC key's metadata. Note that there is no option to retrieve a key's secret material after it has been created. 
EXAMPLES
     The following command retrieves the HMAC key's metadata: 
    
    
    gcloud alpha storage hmac describe GOOG56JBMFZX6PMPTQ62VD2

Note `GOOG56JBMFZX6PMPTQ62VD2` is the `ACCESS_ID` of the HMAC key. 

POSITIONAL ARGUMENTS
    

`ACCESS_ID`
     The [Access ID](https://cloud.google.com/storage/docs/authentication/hmackeys#overview) of the HMAC key
