NAME
    

gcloud alpha storage hmac create - add a service account HMAC 
SYNOPSIS
    

`gcloud alpha storage hmac create` `SERVICE_ACCOUNT` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `gcloud alpha storage hmac create` command creates an HMAC key for the specified service account. The secret key material is only available upon creation, so be sure to store the returned secret along with the access_id. 
EXAMPLES
     To create an HMAC key for ``test.service.account@test_project.iam.gserviceaccount.com``: 
    
    
    gcloud alpha storage hmac create test.service.account@test_project.iam.gserviceaccount.com

POSITIONAL ARGUMENTS
    

`SERVICE_ACCOUNT`
     The service account email.
