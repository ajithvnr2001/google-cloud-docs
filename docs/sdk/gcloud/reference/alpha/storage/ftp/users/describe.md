NAME
    

gcloud alpha storage ftp users describe - describe an existing Cloud FTP user 
SYNOPSIS
    

`gcloud alpha storage ftp users describe` `USER_ID` `--location`=`LOCATION` `--server`=`SERVER` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Describe an existing Cloud FTP user. 
EXAMPLES
     To describe user `my-user` for server `my-server` in `us-west1`, run: 
    
    
    gcloud alpha storage ftp users describe my-user --server=my-server --location=us-west1

POSITIONAL ARGUMENTS
    

`USER_ID`
     The ID of the user to describe. 
REQUIRED FLAGS
    

`--location`=`LOCATION`
     The region of the server. 
`--server`=`SERVER`
     The ID of the server.
