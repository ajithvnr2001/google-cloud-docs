NAME
    

gcloud alpha storage ftp users - manage Cloud FTP user resources 
SYNOPSIS
    

`gcloud alpha storage ftp users` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud FTP user resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/users/create)`
     `(ALPHA)` Create a new Cloud FTP user. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/users/delete)`
     `(ALPHA)` Delete a Cloud FTP user. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/users/describe)`
     `(ALPHA)` Describe an existing Cloud FTP user. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/users/list)`
     `(ALPHA)` List Cloud FTP users. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/users/update)`
     `(ALPHA)` Update an existing Cloud FTP user. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
