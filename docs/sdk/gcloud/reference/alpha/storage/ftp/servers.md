NAME
    

gcloud alpha storage ftp servers - manage Cloud FTP server resources 
SYNOPSIS
    

`gcloud alpha storage ftp servers` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud FTP server resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/servers/create)`
     `(ALPHA)` Create a new Cloud FTP server. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/servers/delete)`
     `(ALPHA)` Delete a Cloud FTP server. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/servers/describe)`
     `(ALPHA)` Describe an existing Cloud FTP server. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/servers/list)`
     `(ALPHA)` List Cloud FTP servers. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/servers/start)`
     `(ALPHA)` Start a Cloud FTP server. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/servers/stop)`
     `(ALPHA)` Stop a Cloud FTP server. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/ftp/servers/update)`
     `(ALPHA)` Update an existing Cloud FTP server. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
