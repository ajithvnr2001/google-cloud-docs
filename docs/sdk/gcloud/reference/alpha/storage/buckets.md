#  gcloud alpha storage buckets Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha storage buckets - manage Cloud Storage buckets 
SYNOPSIS
    

`gcloud alpha storage buckets` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Storage buckets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[anywhere-caches](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/anywhere-caches)`
     `(ALPHA)` Manage Cloud Storage Anywhere Caches. 
`[notifications](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/notifications)`
     `(ALPHA)` Manage Cloud Storage bucket notifications. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a bucket. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/create)`
     `(ALPHA)` Create buckets for storing objects. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/delete)`
     `(ALPHA)` Deletes Cloud Storage buckets. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/describe)`
     `(ALPHA)` Describes Cloud Storage buckets. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a bucket. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/list)`
     `(ALPHA)` Lists Cloud Storage buckets. 
`[relocate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/relocate)`
     `(ALPHA)` Relocates bucket between different locations. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding from a bucket. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a bucket. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/update)`
     `(ALPHA)` Update bucket settings. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud storage buckets](https://docs.cloud.google.com/sdk/gcloud/reference/storage/buckets)
