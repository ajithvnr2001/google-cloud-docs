NAME
    

gcloud alpha storage operations - manage storage operations 
SYNOPSIS
    

`gcloud alpha storage operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage storage operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/operations/cancel)`
     `(ALPHA)` Cancel a storage operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/operations/describe)`
     `(ALPHA)` Get configuration and latest storage operation details. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/operations/list)`
     `(ALPHA)` List storage operations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud storage operations](https://docs.cloud.google.com/sdk/gcloud/reference/storage/operations)
