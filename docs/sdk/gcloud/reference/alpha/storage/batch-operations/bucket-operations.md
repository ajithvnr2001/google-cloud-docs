NAME
    

gcloud alpha storage batch-operations bucket-operations - manage Cloud Storage batch operations bucket operations 
SYNOPSIS
    

`gcloud alpha storage batch-operations bucket-operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Storage batch operations bucket operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/batch-operations/bucket-operations/describe)`
     `(ALPHA)` Describe a bucket operation for a batch operation job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/batch-operations/bucket-operations/list)`
     `(ALPHA)` List bucket operations for a batch operation job. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud storage batch-operations bucket-operations](https://docs.cloud.google.com/sdk/gcloud/reference/storage/batch-operations/bucket-operations)
