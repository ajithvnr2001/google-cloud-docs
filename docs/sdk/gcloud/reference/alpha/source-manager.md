NAME
    

gcloud alpha source-manager - manage Secure Source Manager resources 
SYNOPSIS
    

`gcloud alpha source-manager` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Secure Source Manager resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[branch-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/branch-rules)`
     `(ALPHA)` Manage Secure Source Manager branch rules. 
`[hooks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/hooks)`
     `(ALPHA)` Manage Secure Source Manager hooks. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/instances)`
     `(ALPHA)` Manage Secure Source Manager instances. 
`[issues](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues)`
     `(ALPHA)` Manage Secure Source Manager issues. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/locations)`
     `(ALPHA)` Manage Secure Source Manager locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/operations)`
     `(ALPHA)` Manage Secure Source Manager operations. 
`[pull-requests](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests)`
     `(ALPHA)` Manage Secure Source Manager pull requests. 
`[repos](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/repos)`
     `(ALPHA)` Manage Secure Source Manager repositories. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud source-manager](https://docs.cloud.google.com/sdk/gcloud/reference/source-manager)
    
    
    [gcloud beta source-manager](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager)
