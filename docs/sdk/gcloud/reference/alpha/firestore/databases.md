NAME
    

gcloud alpha firestore databases - manage Creation of Cloud Firestore in Native mode Database 
SYNOPSIS
    

`gcloud alpha firestore databases` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Creation of Cloud Firestore in Native mode Database. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[clone](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/clone)`
     `(ALPHA)` Clone a Google Cloud Firestore database from another. 
`[connection-string](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/connection-string)`
     `(ALPHA)` Prints the mongo connection string for the given Firestore database. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/create)`
     `(ALPHA)` Create a Google Cloud Firestore database via Firestore API. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/delete)`
     `(ALPHA)` Delete a Google Cloud Firestore database. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/describe)`
     `(ALPHA)` Describes information about a Cloud Firestore database. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/list)`
     `(ALPHA)` Lists all Firestore databases under the project. 
`[ping](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/ping)`
     `(ALPHA)` Times the connection and ping time for a Firestore with MongoDB compatibility database. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/restore)`
     `(ALPHA)` Restores a Cloud Firestore database from a backup. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases/update)`
     `(ALPHA)` Update the database configuration of a Cloud Firestore database. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud firestore databases](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/databases)
    
    
    [gcloud beta firestore databases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases)
