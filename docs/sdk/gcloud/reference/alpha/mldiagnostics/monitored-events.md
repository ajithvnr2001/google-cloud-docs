NAME
    

gcloud alpha mldiagnostics monitored-events - monitored Event resources 
SYNOPSIS
    

`gcloud alpha mldiagnostics monitored-events` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Monitored Event resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/mldiagnostics/monitored-events/describe)`
     `(ALPHA)` Display the details of a specific monitored event. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/mldiagnostics/monitored-events/list)`
     `(ALPHA)` List monitored events associated with a specific machine learning run. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
