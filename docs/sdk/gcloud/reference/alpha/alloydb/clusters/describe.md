NAME
    

gcloud alpha alloydb clusters describe - describe an AlloyDB cluster in a given project and region 
SYNOPSIS
    

`gcloud alpha alloydb clusters describe` `CLUSTER` `--region`=`REGION` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Describe an AlloyDB cluster in a given project and region. 
EXAMPLES
     To describe a cluster, run: 
    
    
    gcloud alpha alloydb clusters describe my-cluster --region=us-central1

POSITIONAL ARGUMENTS
    

`CLUSTER`
     AlloyDB cluster ID 
REQUIRED FLAGS
    

`--region`=`REGION`
     Regional location (e.g. `asia-east1`, `us-east1`). See the full list of regions at <https://cloud.google.com/sql/docs/instance-locations>.
