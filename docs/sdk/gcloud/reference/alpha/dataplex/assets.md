#  gcloud alpha dataplex assets Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha dataplex assets - manage Dataplex Asset resources 
SYNOPSIS
    

`gcloud alpha dataplex assets` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Asset resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[actions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/actions)`
     `(ALPHA)` Manage Dataplex asset resource actions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/add-iam-policy-binding)`
     `(ALPHA)` Adds IAM policy binding to a Dataplex asset resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/create)`
     `(ALPHA)` Create a Dataplex asset resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/delete)`
     `(ALPHA)` Delete a Dataplex asset resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/describe)`
     `(ALPHA)` Describe a Dataplex asset resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Dataplex asset resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/list)`
     `(ALPHA)` List Dataplex asset resources. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from a Dataplex asset resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/set-iam-policy)`
     `(ALPHA)` Set the IAM policy to a Dataplex asset as defined in a JSON or YAML file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets/update)`
     `(ALPHA)` Update a Dataplex asset resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex assets](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/assets)
