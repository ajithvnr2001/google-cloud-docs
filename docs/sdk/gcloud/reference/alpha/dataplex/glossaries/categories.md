#  gcloud alpha dataplex glossaries categories Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha dataplex glossaries categories - manage Dataplex glossary categories 
SYNOPSIS
    

`gcloud alpha dataplex glossaries categories` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` A glossary category represents a collection of glossary categories and glossary terms within a glossary that are related to each other. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/glossaries/categories/create)`
     `(ALPHA)` Creates a glossary category. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/glossaries/categories/delete)`
     `(ALPHA)` Deletes a glossary category. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/glossaries/categories/describe)`
     `(ALPHA)` Describes a glossary category. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/glossaries/categories/list)`
     `(ALPHA)` List glossary categories. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/glossaries/categories/update)`
     `(ALPHA)` Updates a glossary category. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex glossaries categories](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/glossaries/categories)
