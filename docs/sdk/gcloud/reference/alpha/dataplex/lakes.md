NAME
    

gcloud alpha dataplex lakes - manage Dataplex Lake resources 
SYNOPSIS
    

`gcloud alpha dataplex lakes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Lake resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[actions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/actions)`
     `(ALPHA)` Manage Dataplex lake resource actions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Dataplex lake resource. 
`[authorize](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/authorize)`
     `(ALPHA)` Authorize a service agent to manage resources. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/create)`
     `(ALPHA)` Create a Dataplex lake resource. 
`[deauthorize](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/deauthorize)`
     `(ALPHA)` Deauthorize a service agent from managing resources. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/delete)`
     `(ALPHA)` Delete a Dataplex lake resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/describe)`
     `(ALPHA)` Describe a Dataplex lake resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Dataplex lake resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/list)`
     `(ALPHA)` List Dataplex lake resources under a project. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from a Dataplex lake resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/set-iam-policy)`
     `(ALPHA)` Set the IAM policy to a Dataplex lake as defined in a JSON or YAML file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes/update)`
     `(ALPHA)` Update a Dataplex lake resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex lakes](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes)
