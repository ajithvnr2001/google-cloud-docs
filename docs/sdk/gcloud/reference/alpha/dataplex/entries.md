NAME
    

gcloud alpha dataplex entries - manage Dataplex Catalog Entries resources 
SYNOPSIS
    

`gcloud alpha dataplex entries` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Catalog Entries resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/create)`
     `(ALPHA)` Create a Dataplex Entry resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/delete)`
     `(ALPHA)` Delete a Dataplex entry. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/describe)`
     `(ALPHA)` Describe a Dataplex entry. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/list)`
     `(ALPHA)` List Dataplex entries. 
`[lookup](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/lookup)`
     `(ALPHA)` Lookup a Dataplex entry. 
`[modify](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/modify)`
     `(ALPHA)` Modify a Dataplex Entry. 
`[remove-aspects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/remove-aspects)`
     `(ALPHA)` Remove aspects from a Dataplex Entry. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/search)`
     `(ALPHA)` Searches for Dataplex entries. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/update)`
     `(ALPHA)` Update a Dataplex Entry. 
`[update-aspects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries/update-aspects)`
     `(ALPHA)` Add or update aspects for a Dataplex Entry. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex entries](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/entries)
