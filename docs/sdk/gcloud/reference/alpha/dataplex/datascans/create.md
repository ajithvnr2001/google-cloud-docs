NAME
    

gcloud alpha dataplex datascans create - manage Dataplex Datascans creation 
SYNOPSIS
    

`gcloud alpha dataplex datascans create` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Datascans creation. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[data-discovery](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/create/data-discovery)`
     `(ALPHA)` Create a Dataplex data discovery scan job. 
`[data-documentation](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/create/data-documentation)`
     `(ALPHA)` Create a Dataplex data documentation scan job. 
`[data-profile](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/create/data-profile)`
     `(ALPHA)` Create a Dataplex data profile scan job. 
`[data-quality](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/create/data-quality)`
     `(ALPHA)` Create a Dataplex data quality scan job. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex datascans create](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/datascans/create)
