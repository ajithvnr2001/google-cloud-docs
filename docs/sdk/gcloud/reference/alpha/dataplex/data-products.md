NAME
    

gcloud alpha dataplex data-products - manage Dataplex Data Product resources 
SYNOPSIS
    

`gcloud alpha dataplex data-products` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Data Product resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[data-assets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/data-assets)`
     `(ALPHA)` Manage Dataplex Data Asset resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Dataplex data product resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/create)`
     `(ALPHA)` Create a Dataplex data product resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/delete)`
     `(ALPHA)` Delete a Dataplex Data Product resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/describe)`
     `(ALPHA)` Describe a Dataplex Data Product resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Dataplex data product. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/list)`
     `(ALPHA)` List Dataplex Data Product resources. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from a Dataplex data product resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/set-iam-policy)`
     `(ALPHA)` Set the IAM policy to a Dataplex data product as defined in a JSON or YAML file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/update)`
     `(ALPHA)` Update a Dataplex data product resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex data-products](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products)
