NAME
    

gcloud alpha dataplex datascans - manage Dataplex Datascan 
SYNOPSIS
    

`gcloud alpha dataplex datascans` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Datascan. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/create)`
     `(ALPHA)` Manage Dataplex Datascans creation. 
`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/jobs)`
     `(ALPHA)` Manage Dataplex Datascan Jobs service. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/update)`
     `(ALPHA)` Manage Dataplex Datascans updation. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/delete)`
     `(ALPHA)` Delete a Dataplex Datascan resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/describe)`
     `(ALPHA)` Describe a Dataplex datascan resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Dataplex datascan resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/list)`
     `(ALPHA)` List Dataplex Datascan resources under a project. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/run)`
     `(ALPHA)` Run a Dataplex DataScan resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans/set-iam-policy)`
     `(ALPHA)` Set the IAM policy to a Dataplex datascan as defined in a JSON or YAML file. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex datascans](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/datascans)
