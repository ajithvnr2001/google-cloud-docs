NAME
    

gcloud alpha dataplex entry-links - manage Dataplex Catalog Entry Links resources 
SYNOPSIS
    

`gcloud alpha dataplex entry-links` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Catalog Entry Links resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-links/create)`
     `(ALPHA)` Create a Dataplex Entry Link. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-links/delete)`
     `(ALPHA)` Delete a Dataplex entryLink. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-links/describe)`
     `(ALPHA)` Describe a Dataplex entry link. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-links/update)`
     `(ALPHA)` Update a Dataplex Entry Link. 
`[update-aspects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-links/update-aspects)`
     `(ALPHA)` Add or update one aspect for a Dataplex Entry Link. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
