NAME
    

gcloud alpha dataplex entry-types - manage Dataplex Entry Types 
SYNOPSIS
    

`gcloud alpha dataplex entry-types` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Entry Types. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Dataplex Entry Type. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/create)`
     `(ALPHA)` Create a Dataplex Entry Type. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/delete)`
     `(ALPHA)` Delete a Dataplex Entry Type. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/describe)`
     `(ALPHA)` Describe a Dataplex Entry Type. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/get-iam-policy)`
     `(ALPHA)` Retrieve a Dataplex Entry Type IAM policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/list)`
     `(ALPHA)` List Dataplex Entry Types. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from a Dataplex Entry Type. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/set-iam-policy)`
     `(ALPHA)` Set an IAM policy binding for a Dataplex Entry Type as defined in a JSON or YAML file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types/update)`
     `(ALPHA)` Update a Dataplex Entry Type. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex entry-types](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/entry-types)
