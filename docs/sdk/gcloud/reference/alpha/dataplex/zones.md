NAME
    

gcloud alpha dataplex zones - manage Dataplex Zone resources 
SYNOPSIS
    

`gcloud alpha dataplex zones` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex Zone resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[actions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/actions)`
     `(ALPHA)` Manage Dataplex zone resource actions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Dataplex zone resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/create)`
     `(ALPHA)` Create a zone. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/delete)`
     `(ALPHA)` Delete a Dataplex zone resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/describe)`
     `(ALPHA)` Describe a Dataplex zone resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Dataplex zone resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/list)`
     `(ALPHA)` List Dataplex zone resources under a lake. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from a Dataplex zone resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/set-iam-policy)`
     `(ALPHA)` Set the IAM policy to a Dataplex zone as defined in a JSON or YAML file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/update)`
     `(ALPHA)` Update a Dataplex zone resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex zones](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/zones)
