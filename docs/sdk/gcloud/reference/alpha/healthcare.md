NAME
    

gcloud alpha healthcare - manage Cloud Healthcare resources 
SYNOPSIS
    

`gcloud alpha healthcare` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Healthcare resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[consent-stores](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/consent-stores)`
     `(ALPHA)` Manage Cloud Healthcare API consent stores. 
`[datasets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets)`
     `(ALPHA)` Manage Cloud Healthcare API datasets. 
`[dicom-stores](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/dicom-stores)`
     `(ALPHA)` Manage Cloud Healthcare API DICOM stores. 
`[fhir-stores](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/fhir-stores)`
     `(ALPHA)` Manage Cloud Healthcare API FHIR stores. 
`[hl7v2-stores](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/hl7v2-stores)`
     `(ALPHA)` Manage Cloud Healthcare API HL7v2 stores. 
`[nlp](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/nlp)`
     `(ALPHA)` Use and manage the Cloud Healthcare NLP service. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/operations)`
     `(ALPHA)` Manage Cloud Healthcare API operations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud healthcare](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare)
    
    
    [gcloud beta healthcare](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare)
