NAME
    

gcloud alpha bq - interact with and manage resources in Google BigQuery 
SYNOPSIS
    

`gcloud alpha bq` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Interact with and manage resources in Google BigQuery. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[datasets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/datasets)`
     `(ALPHA)` Manage Google BigQuery datasets. 
`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/jobs)`
     `(ALPHA)` Interact with and manage jobs in Google BigQuery. 
`[migration-workflows](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/migration-workflows)`
     `(ALPHA)` Manage Migration Workflow resources. 
`[tables](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/tables)`
     `(ALPHA)` Interact with and manage Google BigQuery tables. 
`[translation](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/translation)`
     `(ALPHA)` Manage BigQuery Migration Service translations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[query](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bq/query)`
     `(ALPHA)` Execute a BigQuery SQL query. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud bq](https://docs.cloud.google.com/sdk/gcloud/reference/bq)
    
    
    [gcloud beta bq](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bq)
