NAME
    

gcloud alpha dataproc - create and manage Google Cloud Dataproc clusters and jobs 
SYNOPSIS
    

`gcloud alpha dataproc` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud dataproc command group lets you create and manage Dataproc clusters and jobs. 

Dataproc is an Apache Hadoop, Apache Spark, Apache Pig, and Apache Hive service. It easily processes big datasets at low cost, creating managed clusters of any size that scale down once processing is complete. 

More information on Dataproc can be found here: <https://cloud.google.com/dataproc> and detailed documentation can be found here: <https://cloud.google.com/dataproc/docs/>

EXAMPLES
     To see how to create and manage clusters, run: 
    
    
    [gcloud alpha dataproc clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/clusters)

To see how to submit and manage jobs, run: 
    
    
    [gcloud alpha dataproc jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/jobs)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[autoscaling-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/autoscaling-policies)`
     `(ALPHA)` Create and manage Dataproc autoscaling policies. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/clusters)`
     `(ALPHA)` Create and manage Dataproc clusters. 
`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/jobs)`
     `(ALPHA)` Submit and manage Dataproc jobs. 
`[node-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/node-groups)`
     `(ALPHA)` Manage Dataproc node groups. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations)`
     `(ALPHA)` View and manage Dataproc operations. 
`[workflow-templates](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/workflow-templates)`
     `(ALPHA)` Create and manage Dataproc workflow templates. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud dataproc](https://docs.cloud.google.com/sdk/gcloud/reference/dataproc)
    
    
    [gcloud beta dataproc](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc)
