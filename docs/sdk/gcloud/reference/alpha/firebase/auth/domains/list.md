NAME
    

gcloud alpha firebase auth domains list - list Firebase Authentication authorized domains 
SYNOPSIS
    

`gcloud alpha firebase auth domains list` [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--sort-by`=[`FIELD`,…]] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Lists the domains that Firebase Authentication allows OAuth sign-in flows (such as Google Sign-In) to redirect to. Sign-in from a page served on any other domain fails with `auth/unauthorized-domain`. 

To authorize more domains for Google Sign-In, pass their URLs to `--redirect-uris` of `[gcloud alpha firebase auth providers enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/auth/providers/enable)`. 

EXAMPLES
     To list the authorized domains of the current project: 
    
    
    gcloud alpha firebase auth domains list

To print only the domain names, one per line: 
    
    
    gcloud alpha firebase auth domains list --format="value(domain)"

To check whether a Cloud Run service's domain is authorized: 
    
    
    gcloud alpha firebase auth domains list --filter="domain=my-service-123456789012.us-central1.run.app"
