NAME
    

gcloud alpha firebase test - interact with Firebase Test Lab 
SYNOPSIS
    

`gcloud alpha firebase test` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Explore devices and OS versions available as test targets, run tests, monitor test progress, and view detailed test results in the Firebase console. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[android](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test/android)`
     `(ALPHA)` Command group for Android application testing. 
`[ios](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test/ios)`
     `(ALPHA)` Command group for iOS application testing. 
`[ip-blocks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test/ip-blocks)`
     `(ALPHA)` Explore IP blocks used by Firebase Test Lab devices. 
`[network-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test/network-profiles)`
     `(ALPHA)` Explore network profiles available for testing. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud firebase test](https://docs.cloud.google.com/sdk/gcloud/reference/firebase/test)
    
    
    [gcloud beta firebase test](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test)
