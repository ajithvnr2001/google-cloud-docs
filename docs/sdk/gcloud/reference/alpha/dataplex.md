NAME
    

gcloud alpha dataplex - manage Dataplex resources 
SYNOPSIS
    

`gcloud alpha dataplex` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataplex resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[aspect-types](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/aspect-types)`
     `(ALPHA)` Manage Dataplex Aspect Types. 
`[assets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/assets)`
     `(ALPHA)` Manage Dataplex Asset resources. 
`[context](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/context)`
     `(ALPHA)` Manage Dataplex Context. 
`[data-products](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products)`
     `(ALPHA)` Manage Dataplex Data Product resources. 
`[datascans](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/datascans)`
     `(ALPHA)` Manage Dataplex Datascan. 
`[dbt](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/dbt)`
     `(ALPHA)` Ingest dbt-core metadata into Dataplex Knowledge Catalog. 
`[encryption-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/encryption-config)`
     `(ALPHA)` Manage Dataplex encryption configs. 
`[entries](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entries)`
     `(ALPHA)` Manage Dataplex Catalog Entries resources. 
`[entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-groups)`
     `(ALPHA)` Manage Dataplex Entry Groups. 
`[entry-links](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-links)`
     `(ALPHA)` Manage Dataplex Catalog Entry Links resources. 
`[entry-types](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/entry-types)`
     `(ALPHA)` Manage Dataplex Entry Types. 
`[glossaries](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/glossaries)`
     `(ALPHA)` Manage Dataplex glossaries. 
`[lakes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes)`
     `(ALPHA)` Manage Dataplex Lake resources. 
`[metadata-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/metadata-jobs)`
     `(ALPHA)` Manage Dataplex metadata jobs. 
`[tasks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/tasks)`
     `(ALPHA)` Manage Dataplex Task services. 
`[zones](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones)`
     `(ALPHA)` Manage Dataplex Zone resources. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud dataplex](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex)
