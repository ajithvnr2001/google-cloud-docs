NAME
    

gcloud alpha datalineage runs - manage Data Lineage runs 
SYNOPSIS
    

`gcloud alpha datalineage runs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for describing, listing, creating, and deleting Data Lineage runs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/runs/create)`
     `(ALPHA)` Create a data lineage run. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/runs/delete)`
     `(ALPHA)` Delete a Data Lineage run. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/runs/describe)`
     `(ALPHA)` Describe a Data Lineage run. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/runs/list)`
     `(ALPHA)` List Data Lineage runs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/runs/update)`
     `(ALPHA)` Update a data lineage run. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud datalineage runs](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/runs)
    
    
    [gcloud beta datalineage runs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datalineage/runs)
