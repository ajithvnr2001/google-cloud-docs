NAME
    

gcloud alpha datalineage processes - manage Data Lineage processes 
SYNOPSIS
    

`gcloud alpha datalineage processes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for describing, listing, creating, and deleting Data Lineage processes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/processes/create)`
     `(ALPHA)` Create a Data Lineage process. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/processes/delete)`
     `(ALPHA)` Delete a Data Lineage process. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/processes/describe)`
     `(ALPHA)` Describe a Data Lineage process. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/processes/list)`
     `(ALPHA)` List Data Lineage processes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/processes/update)`
     `(ALPHA)` Update a data lineage process. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud datalineage processes](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/processes)
    
    
    [gcloud beta datalineage processes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datalineage/processes)
