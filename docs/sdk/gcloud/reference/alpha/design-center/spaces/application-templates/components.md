#  gcloud alpha design-center spaces application-templates components Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha design-center spaces application-templates components - manage component resources 
SYNOPSIS
    

`gcloud alpha design-center spaces application-templates components` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage component resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[connections](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/components/connections)`
     `(ALPHA)` Manage connection resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/components/create)`
     `(ALPHA)` Create a component. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/components/delete)`
     `(ALPHA)` Delete a component. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/components/describe)`
     `(ALPHA)` Describe a component. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/components/list)`
     `(ALPHA)` List components. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/components/update)`
     `(ALPHA)` Update a component. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud design-center spaces application-templates components](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates/components)
