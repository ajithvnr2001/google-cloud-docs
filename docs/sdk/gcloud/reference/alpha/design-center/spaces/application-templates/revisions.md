NAME
    

gcloud alpha design-center spaces application-templates revisions - manage application template revision resources 
SYNOPSIS
    

`gcloud alpha design-center spaces application-templates revisions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage application template revision resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/revisions/delete)`
     `(ALPHA)` Delete an application template revision. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/revisions/describe)`
     `(ALPHA)` Describe an application template revision. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/revisions/export)`
     `(ALPHA)` Export IaC for an application template revision. 
`[generate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/revisions/generate)`
     `(ALPHA)` Generate IaC for an application template revision. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/revisions/list)`
     `(ALPHA)` List application template revisions. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud design-center spaces application-templates revisions](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates/revisions)
