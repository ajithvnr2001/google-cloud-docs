#  gcloud alpha design-center spaces applications Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha design-center spaces applications - manage application resources 
SYNOPSIS
    

`gcloud alpha design-center spaces applications` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage application resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/create)`
     `(ALPHA)` Create an application. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/delete)`
     `(ALPHA)` Delete an application. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/deploy)`
     `(ALPHA)` Deploy an application. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/describe)`
     `(ALPHA)` Describe an application. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/export)`
     `(ALPHA)` Export IaC for an application. 
`[generate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/generate)`
     `(ALPHA)` Generate IaC for an application. 
`[generate-assessment-report](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/generate-assessment-report)`
     `(ALPHA)` Generate an assessment report for a Design Center application. 
`[import-iac](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/import-iac)`
     `(ALPHA)` Import Infrastructure as Code (IaC) for an Application. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/list)`
     `(ALPHA)` List applications. 
`[preview](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/preview)`
     `(ALPHA)` Preview a Design Center application. 
`[recommend-iam-roles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/recommend-iam-roles)`
     `(ALPHA)` Get recommended IAM roles for a Design Center application. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/register)`
     `(ALPHA)` Register resources with a deployed application in App Hub. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications/update)`
     `(ALPHA)` Update an application. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud design-center spaces applications](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/applications)
