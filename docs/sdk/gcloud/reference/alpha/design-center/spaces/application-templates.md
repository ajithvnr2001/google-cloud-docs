#  gcloud alpha design-center spaces application-templates Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha design-center spaces application-templates - manage application template resources 
SYNOPSIS
    

`gcloud alpha design-center spaces application-templates` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage application template resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[components](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/components)`
     `(ALPHA)` Manage component resources. 
`[policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/policies)`
     `(ALPHA)` Manage policy resources. 
`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/revisions)`
     `(ALPHA)` Manage application template revision resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[commit](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/commit)`
     `(ALPHA)` Commit an application template. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/create)`
     `(ALPHA)` Create an application template. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/delete)`
     `(ALPHA)` Delete an application template. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/describe)`
     `(ALPHA)` Describe an application template. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/export)`
     `(ALPHA)` Export IaC for an application template. 
`[generate](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/generate)`
     `(ALPHA)` Generate IaC for an application template. 
`[generate-assessment-report](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/generate-assessment-report)`
     `(ALPHA)` Generate a best practice assessment report generator for an application template. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/import)`
     `(ALPHA)` Import to an application template. 
`[import-iac](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/import-iac)`
     `(ALPHA)` Import Infrastructure as Code (IaC) for an Application Template. 
`[ingest-iac](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/ingest-iac)`
     `(ALPHA)` Ingest Infrastructure as Code (IaC) for an application template. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/list)`
     `(ALPHA)` List application templates. 
`[snapshot](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/snapshot)`
     `(ALPHA)` Snapshot an application template. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates/update)`
     `(ALPHA)` Update an application template. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud design-center spaces application-templates](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates)
