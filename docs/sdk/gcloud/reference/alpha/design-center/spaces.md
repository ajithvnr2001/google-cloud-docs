#  gcloud alpha design-center spaces Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha design-center spaces - manage space resources 
SYNOPSIS
    

`gcloud alpha design-center spaces` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage space resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[application-templates](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/application-templates)`
     `(ALPHA)` Manage application template resources. 
`[applications](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/applications)`
     `(ALPHA)` Manage application resources. 
`[catalogs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/catalogs)`
     `(ALPHA)` Manage catalog resources. 
`[shared-templates](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/shared-templates)`
     `(ALPHA)` Manage shared template resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/create)`
     `(ALPHA)` Create a space. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/delete)`
     `(ALPHA)` Delete a space. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/describe)`
     `(ALPHA)` Describe a space. 
`[generate-terraform-assessment-report](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/generate-terraform-assessment-report)`
     `(ALPHA)` Generate a Terraform assessment report in a design center space. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Design Center space. 
`[infer-connections](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/infer-connections)`
     `(ALPHA)` Infer connections for a space. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/list)`
     `(ALPHA)` List spaces. 
`[register-deployed-resources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/register-deployed-resources)`
     `(ALPHA)` Register resources with a deployed application in App Hub. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a Design Center space as defined in a JSON/YAML file. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/test-iam-permissions)`
     `(ALPHA)` Test IAM permissions for a Design Center space. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces/update)`
     `(ALPHA)` Update a space. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud design-center spaces](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces)
