NAME
    

gcloud alpha apihub - manage Apihub resources 
SYNOPSIS
    

`gcloud alpha apihub` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Apihub resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[addons](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/addons)`
     `(ALPHA)` Manage Addon resources. 
`[api-hub-instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/api-hub-instances)`
     `(ALPHA)` Manage Api Hub Instance resources. 
`[apis](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis)`
     `(ALPHA)` Manage Api resources. 
`[attributes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/attributes)`
     `(ALPHA)` Manage Attribute resources. 
`[curations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/curations)`
     `(ALPHA)` Manage Curation resources. 
`[dependencies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/dependencies)`
     `(ALPHA)` Manage Dependency resources. 
`[deployments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/deployments)`
     `(ALPHA)` Manage Deployment resources. 
`[discovered-api-observations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/discovered-api-observations)`
     `(ALPHA)` Manage Discovered Api Observation resources. 
`[external-apis](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/external-apis)`
     `(ALPHA)` Manage External Api resources. 
`[host-project-registrations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/host-project-registrations)`
     `(ALPHA)` Manage Host Project Registration resources. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/locations)`
     `(ALPHA)` Location-scoped operations for API Hub. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/operations)`
     `(ALPHA)` Manage Operation resources. 
`[plugins](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins)`
     `(ALPHA)` Manage Plugin resources. 
`[runtime-project-attachments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/runtime-project-attachments)`
     `(ALPHA)` Manage Runtime Project Attachment resources. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud apihub](https://docs.cloud.google.com/sdk/gcloud/reference/apihub)
