NAME
    

gcloud alpha zone-management services enable - enable zonal service 
SYNOPSIS
    

`gcloud alpha zone-management services enable` `SERVICE_SELECTOR` `--location`=`LOCATION` [`--async`] [`--cluster`=`CLUSTER`] [`--id`=`ID`] [`--zone`=`ZONE`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Enables a zonal service. 
EXAMPLES
     To enable `vertex` service in location `us-central1` in `test-project` project and `test-zone` zone, run: 
    
    
    gcloud alpha zone-management services enable vertex --location=us-central1 --project=test-project --zone=test-zone

POSITIONAL ARGUMENTS
    

`SERVICE_SELECTOR`
     service name. 
REQUIRED FLAGS
    

Location resource - location. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--location` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`--location`=`LOCATION`
     ID of the location or fully qualified identifier for the location. 

To set the `location` attribute: 

  * provide the argument `--location` on the command line. 


OPTIONAL FLAGS
    

`--async`
     Return immediately, without waiting for the operation in progress to complete. 
`--cluster`=`CLUSTER`
     Cluster name. 
`--id`=`ID`
     Zonal service ID. 
`--zone`=`ZONE`
     Distributed Cloud Zone.
