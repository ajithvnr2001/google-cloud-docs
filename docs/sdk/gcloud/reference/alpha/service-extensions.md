NAME
    

gcloud alpha service-extensions - manage Service Extensions resources 
SYNOPSIS
    

`gcloud alpha service-extensions` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Service Extensions resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[cdn-edge-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/cdn-edge-extensions)`
     `(ALPHA)` Manage Service Extensions `CdnEdgeExtension` resources. 
`[extension-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings)`
     `(ALPHA)` Manage Extension Binding resources. 
`[lb-route-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/lb-route-extensions)`
     `(ALPHA)` Manage Service Extensions `LbRouteExtension` resources. 
`[lb-traffic-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/lb-traffic-extensions)`
     `(ALPHA)` Manage Service Extensions `LbTrafficExtension` resources. 
`[wasm-actions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-actions)`
     `(ALPHA)` Interact with and manage Service Extensions `WasmActions`. 
`[wasm-plugin-versions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-plugin-versions)`
     `(ALPHA)` Interact with and manage Service Extensions `WasmPluginVersions`. 
`[wasm-plugins](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/wasm-plugins)`
     `(ALPHA)` Interact with and manage Service Extensions `WasmPlugins`. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud service-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/service-extensions)
    
    
    [gcloud beta service-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions)
