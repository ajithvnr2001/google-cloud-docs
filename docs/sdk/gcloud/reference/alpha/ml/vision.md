NAME
    

gcloud alpha ml vision - use Google Cloud Vision to analyze images 
SYNOPSIS
    

`gcloud alpha ml vision` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Use Google Cloud Vision to analyze images. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/operations)`
     `(ALPHA)` Manage Google Cloud Vision operations. 
`[product-search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search)`
     `(ALPHA)` Uses Google Cloud Vision to analyze product in images. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[detect-document](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-document)`
     `(ALPHA)` Detect dense text in an image. 
`[detect-faces](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-faces)`
     `(ALPHA)` Detect faces within an image. 
`[detect-image-properties](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-image-properties)`
     `(ALPHA)` Detect general attributes of an image. 
`[detect-labels](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-labels)`
     `(ALPHA)` Detect broad sets of categories within an image. 
`[detect-landmarks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-landmarks)`
     `(ALPHA)` Detect popular natural and man-made structures within an image. 
`[detect-logos](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-logos)`
     `(ALPHA)` Detect popular product logos within an image. 
`[detect-objects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-objects)`
     `(ALPHA)` Detect and extract multiple objects in an image with object localization. 
`[detect-product](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-product)`
     `(ALPHA)` detect products within an image. 
`[detect-safe-search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-safe-search)`
     `(ALPHA)` Detect explicit content in an image. 
`[detect-text](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-text)`
     `(ALPHA)` Detect and extract text within an image. 
`[detect-text-pdf](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-text-pdf)`
     `(ALPHA)` Detect and transcribe text from PDF files stored in Google Cloud Storage. 
`[detect-text-tiff](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-text-tiff)`
     `(ALPHA)` Detect and transcribe text from TIFF files stored in Google Cloud Storage. 
`[detect-web](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/detect-web)`
     `(ALPHA)` Detect entities in an image from similar images on the web. 
`[suggest-crop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/suggest-crop)`
     `(ALPHA)` Suggest a bounding box in an image. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud ml vision](https://docs.cloud.google.com/sdk/gcloud/reference/ml/vision)
    
    
    [gcloud beta ml vision](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision)
