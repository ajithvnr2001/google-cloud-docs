NAME
    

gcloud alpha ml translate - cloud ML Translate command groups 
SYNOPSIS
    

`gcloud alpha ml translate` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Cloud ML Translate command groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[batch-translate-text](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/translate/batch-translate-text)`
     `(ALPHA)` Translates a large volume of text in asynchronous batch mode. 
`[detect-language](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/translate/detect-language)`
     `(ALPHA)` Use the Google Cloud Translation API to detect languages. 
`[get-supported-languages](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/translate/get-supported-languages)`
     `(ALPHA)` Returns a list of supported languages for translation. 
`[translate-text](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/translate/translate-text)`
     `(ALPHA)` Use the Google Cloud Translation API to translate between languages. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta ml translate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/translate)
