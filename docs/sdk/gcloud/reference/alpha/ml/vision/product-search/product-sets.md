NAME
    

gcloud alpha ml vision product-search product-sets - uses Google Cloud Vision to manipulate product sets 
SYNOPSIS
    

`gcloud alpha ml vision product-search product-sets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Uses Google Cloud Vision to manipulate product sets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-product](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/add-product)`
     `(ALPHA)` Add a product to the specified product set. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/create)`
     `(ALPHA)` Create a new product set. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/delete)`
     `(ALPHA)` Delete a product set. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/describe)`
     `(ALPHA)` Describe a product set. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/import)`
     `(ALPHA)` Import a list of reference images to specified product sets. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/list)`
     `(ALPHA)` List product sets in a location. 
`[list-products](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/list-products)`
     `(ALPHA)` List products in a product set. 
`[remove-product](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/remove-product)`
     `(ALPHA)` Remove a product from a product set. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets/update)`
     `(ALPHA)` Update a product set. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta ml vision product-search product-sets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets)
