NAME
    

gcloud alpha ml vision product-search images - use the Google Cloud Vision API to manipulate reference images 
SYNOPSIS
    

`gcloud alpha ml vision product-search images` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Use the Google Cloud Vision API to manipulate reference images. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/images/create)`
     `(ALPHA)` create a reference image. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/images/delete)`
     `(ALPHA)` delete a reference image. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/images/describe)`
     `(ALPHA)` descibe a reference image. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/images/list)`
     `(ALPHA)` list all reference images for a product. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta ml vision product-search images](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/images)
