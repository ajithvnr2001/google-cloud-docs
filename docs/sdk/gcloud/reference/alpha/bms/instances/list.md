NAME
    

gcloud alpha bms instances list - list Bare Metal Solution instances in a project 
SYNOPSIS
    

`gcloud alpha bms instances list` [`--region`=`REGION`] [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` List Bare Metal Solution instances in a project. 
EXAMPLES
     To list instances in the region within the project ``us-central1``, run: 
    
    
    gcloud alpha bms instances list --region=us-central1

Or: 

To list all instances in the project, run: 
    
    
    gcloud alpha bms instances list

FLAGS
    

Region resource - region. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--region` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 


`--region`=`REGION`
     ID of the region or fully qualified identifier for the region. 

To set the `region` attribute: 

  * provide the argument `--region` on the command line.

This flag interacts with other flags that are applied in this order: `--flatten`, `--filter`, `--limit`.
