NAME
    

gcloud alpha notebooks locations - view locations available for a project 
SYNOPSIS
    

`gcloud alpha notebooks locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` View locations available for a project. 

This command is deprecated. Please use `[gcloud notebooks](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/notebooks/locations/list)`
     `(ALPHA)` `(DEPRECATED)` Request for listing locations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud notebooks locations](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/locations)
    
    
    [gcloud beta notebooks locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/notebooks/locations)
