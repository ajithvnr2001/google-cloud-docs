NAME
    

gcloud alpha kms keyrings - create and manage keyrings 
SYNOPSIS
    

`gcloud alpha kms keyrings` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` A keyring is a toplevel logical grouping of keys. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/config)`
     `(ALPHA)` Manage Cloud KMS key ring configurations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding for a kms keyring. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/create)`
     `(ALPHA)` Create a new keyring. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/delete)`
     `(ALPHA)` Delete a keyring. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/describe)`
     `(ALPHA)` Get metadata for a keyring. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a keyring. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/list)`
     `(ALPHA)` List keyrings within a location. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding for a kms keyring. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keyrings/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a keyring. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud kms keyrings](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keyrings)
    
    
    [gcloud beta kms keyrings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keyrings)
