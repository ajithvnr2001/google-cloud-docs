NAME
    

gcloud alpha kms locations - view locations available for a project 
SYNOPSIS
    

`gcloud alpha kms locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` View locations available for a project. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/locations/list)`
     `(ALPHA)` List the project's locations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud kms locations](https://docs.cloud.google.com/sdk/gcloud/reference/kms/locations)
    
    
    [gcloud beta kms locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/locations)
