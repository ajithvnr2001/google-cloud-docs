NAME
    

gcloud alpha kms keys - create and manage keys 
SYNOPSIS
    

`gcloud alpha kms keys` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` A key represents a logical key that can be used for cryptographic operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/config)`
     `(ALPHA)` Manage Cloud KMS crypto key configurations. 
`[versions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions)`
     `(ALPHA)` Create and manage versions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding for a kms key. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/create)`
     `(ALPHA)` Create a new key. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/delete)`
     `(ALPHA)` Delete a key. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/describe)`
     `(ALPHA)` Get metadata for a given key. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a key. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/list)`
     `(ALPHA)` List the keys within a keyring. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding for a kms key. 
`[remove-rotation-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/remove-rotation-schedule)`
     `(ALPHA)` Remove the rotation schedule for a key. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a key. 
`[set-primary-version](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/set-primary-version)`
     `(ALPHA)` Set the primary version of a key. 
`[set-rotation-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/set-rotation-schedule)`
     `(ALPHA)` Update the rotation schedule for a key. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/update)`
     `(ALPHA)` Update a key. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud kms keys](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys)
