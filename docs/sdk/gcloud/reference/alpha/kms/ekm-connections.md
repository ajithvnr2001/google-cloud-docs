NAME
    

gcloud alpha kms ekm-connections - create and manage ekm connections 
SYNOPSIS
    

`gcloud alpha kms ekm-connections` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Ekm Connections are used to control the connection settings for an EXTERNAL_VPC CryptoKey. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding for a kms ekm connection. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/create)`
     `(ALPHA)` Create a new ekm connection. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/describe)`
     `(ALPHA)` Get metadata for an ekmconnection. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for an ekm connection. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/list)`
     `(ALPHA)` List ekmconnections within a location. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding for a kms ekm connection. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/set-iam-policy)`
     `(ALPHA)` Set the IAM policy binding for a KMS ekm connection. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections/update)`
     `(ALPHA)` Update an ekmconnection. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
