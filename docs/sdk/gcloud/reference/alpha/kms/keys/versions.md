NAME
    

gcloud alpha kms keys versions - create and manage versions 
SYNOPSIS
    

`gcloud alpha kms keys versions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` A version represents an individual cryptographic key and the associated key material. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/create)`
     `(ALPHA)` Create a new version. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/delete)`
     `(ALPHA)` Delete a key version. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/describe)`
     `(ALPHA)` Get metadata for a given version. 
`[destroy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/destroy)`
     `(ALPHA)` Schedule a version to be destroyed. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/disable)`
     `(ALPHA)` Disable a given version. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/enable)`
     `(ALPHA)` Enable a given version. 
`[export-trusted-key-wrapped](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/export-trusted-key-wrapped)`
     `(ALPHA)` Export a trusted key wrapped CryptoKeyVersion. 
`[get-certificate-chain](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/get-certificate-chain)`
     `(ALPHA)` Get a certificate chain for a given version. 
`[get-public-key](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/get-public-key)`
     `(ALPHA)` Get the public key for a given version. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/import)`
     `(ALPHA)` Import a version into an existing crypto key. 
`[import-trusted-key-wrapped](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/import-trusted-key-wrapped)`
     `(ALPHA)` Import a trusted key wrapped CryptoKeyVersion. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/list)`
     `(ALPHA)` List the versions within a key. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/restore)`
     `(ALPHA)` Restore a version scheduled for destruction. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions/update)`
     `(ALPHA)` Update a key version. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
