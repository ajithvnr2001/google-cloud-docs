NAME
    

gcloud alpha kms kaj-config show-effective-config - gets the effective KajPolicyConfig for a given project 
SYNOPSIS
    

`gcloud alpha kms kaj-config show-effective-config` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` gcloud alpha kms kaj-config show-effective-config can be used to get the effective KajPolicyConfig for a given project. 
EXAMPLES
     The following command retrieves the effective KajPolicyConfig for a given project `my-project`: 
    
    
    gcloud alpha kms kaj-config show-effective-config --project=my-project

If --project flag is not provided, then the current project will be used.
