NAME
    

gcloud alpha identity groups - manage Cloud Identity Groups 
SYNOPSIS
    

`gcloud alpha identity groups` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Cloud Identity Groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/config)`
     `(ALPHA)` Manage Cloud Identity group configurations. 
`[memberships](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships)`
     `(ALPHA)` Manage Cloud Identity Groups Memberships. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/create)`
     `(ALPHA)` Create a new group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/delete)`
     `(ALPHA)` Delete an existing group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/describe)`
     `(ALPHA)` Describe an existing group. 
`[preview](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/preview)`
     `(ALPHA)` Retrieve a list of users in a customer account using CEL query. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/search)`
     `(ALPHA)` Searches for Groups matching a specified query. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/update)`
     `(ALPHA)` Update a group. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud identity groups](https://docs.cloud.google.com/sdk/gcloud/reference/identity/groups)
    
    
    [gcloud beta identity groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/identity/groups)
