NAME
    

gcloud alpha identity groups memberships - manage Cloud Identity Groups Memberships 
SYNOPSIS
    

`gcloud alpha identity groups memberships` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Cloud Identity Groups Memberships. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/add)`
     `(ALPHA)` Create a new membership in an existing group. 
`[check-transitive-membership](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/check-transitive-membership)`
     `(ALPHA)` Check a potential member for transitive membership in a group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/delete)`
     `(ALPHA)` Delete a membership from an existing group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/describe)`
     `(ALPHA)` Describe a membership in a group. 
`[get-membership-graph](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/get-membership-graph)`
     `(ALPHA)` Get a membership graph of just a member or both a member and a group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/list)`
     `(ALPHA)` List memberships in an existing group. 
`[modify-membership-roles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/modify-membership-roles)`
     `(ALPHA)` Add/remove/modify membership roles of a membership in a group. 
`[search-transitive-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/search-transitive-groups)`
     `(ALPHA)` Search transitive groups of a member. 
`[search-transitive-memberships](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/identity/groups/memberships/search-transitive-memberships)`
     `(ALPHA)` Search transitive memberships of a group. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud identity groups memberships](https://docs.cloud.google.com/sdk/gcloud/reference/identity/groups/memberships)
