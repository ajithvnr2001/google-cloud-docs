NAME
    

gcloud alpha composer - create and manage Cloud Composer Environments 
SYNOPSIS
    

`gcloud alpha composer` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Cloud Composer is a managed Apache Airflow service that helps you create, schedule, monitor and manage workflows. Cloud Composer automation helps you create Airflow environments quickly and use Airflow-native tools, such as the powerful Airflow web interface and command line tools, so you can focus on your workflows and not your infrastructure. 
EXAMPLES
     To see how to create and manage environments, run: 
    
    
    [gcloud alpha composer environments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/composer/environments) --help

To see how to manage long-running operations, run: 
    
    
    [gcloud alpha composer operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/composer/operations) --help

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[environments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/composer/environments)`
     `(ALPHA)` Create and manage Cloud Composer environments. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/composer/operations)`
     `(ALPHA)` Manage Cloud Composer operations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud composer](https://docs.cloud.google.com/sdk/gcloud/reference/composer)
    
    
    [gcloud beta composer](https://docs.cloud.google.com/sdk/gcloud/reference/beta/composer)
