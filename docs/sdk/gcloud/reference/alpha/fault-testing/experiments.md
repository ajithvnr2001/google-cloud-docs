NAME
    

gcloud alpha fault-testing experiments - manage Experiment resources 
SYNOPSIS
    

`gcloud alpha fault-testing experiments` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Experiment resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[affected-resources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/affected-resources)`
     `(ALPHA)` Manage Affected Resource resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/create)`
     `(ALPHA)` Create an experiment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/delete)`
     `(ALPHA)` Delete an experiment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/describe)`
     `(ALPHA)` Describe a current or past experiment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/list)`
     `(ALPHA)` List current or past experiments. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/start)`
     `(ALPHA)` Start a new experiment run. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/stop)`
     `(ALPHA)` Cancel a running experiment. 
`[stop-all](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/fault-testing/experiments/stop-all)`
     `(ALPHA)` Cancel all experiments in a given location. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
