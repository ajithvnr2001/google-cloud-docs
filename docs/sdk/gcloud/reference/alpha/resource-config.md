NAME
    

gcloud alpha resource-config - commands for declarative management of Google Cloud Platform resources 
SYNOPSIS
    

`gcloud alpha resource-config` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for declarative management of Google Cloud Platform resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[terraform](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-config/terraform)`
     `(ALPHA)` The command group for Terraform provider configuration. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[apply](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-config/apply)`
     `(ALPHA)` Apply a KRM configuration to a Google Cloud Platform resource filename or stdin. 
`[bulk-export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-config/bulk-export)`
     `(ALPHA)` Export configurations for all assets within the specified project, organization, or folder. 
`[list-resource-types](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-config/list-resource-types)`
     `(ALPHA)` List all resources supported by bulk-export. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta resource-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/resource-config)
