NAME
    

gcloud alpha redis - manage Cloud Memorystore Redis resources 
SYNOPSIS
    

`gcloud alpha redis` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Memorystore Redis resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[acl-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/acl-policies)`
     `(ALPHA)` Manage ACL policies of Memorystore for Redis Cluster instances. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters)`
     `(ALPHA)` Manage Memorystore for Redis Cluster instances. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/instances)`
     `(ALPHA)` Manage Cloud Memorystore Redis instances. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/operations)`
     `(ALPHA)` Manage Cloud Memorystore Redis operations. 
`[regions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/regions)`
     `(ALPHA)` Manage Cloud Memorystore Redis regions. 
`[zones](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/zones)`
     `(ALPHA)` Manage Cloud Memorystore Redis zones. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud redis](https://docs.cloud.google.com/sdk/gcloud/reference/redis)
    
    
    [gcloud beta redis](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis)
