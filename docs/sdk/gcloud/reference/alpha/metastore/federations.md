NAME
    

gcloud alpha metastore federations - manage Dataproc Metastore federations 
SYNOPSIS
    

`gcloud alpha metastore federations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataproc Metastore federations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a federation. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/create)`
     `(ALPHA)` Create a Dataproc Metastore federation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/delete)`
     `(ALPHA)` Delete one or more Dataproc Metastore federations. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/describe)`
     `(ALPHA)` Describe a Dataproc Metastore federation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for the federation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/list)`
     `(ALPHA)` List Dataproc Metastore federations. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding from a federation. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for the federation. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations/update)`
     `(ALPHA)` Update a Dataproc Metastore federation. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
