NAME
    

gcloud alpha metastore services backups - manage backups under Dataproc Metastore services 
SYNOPSIS
    

`gcloud alpha metastore services backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage backups under Dataproc Metastore services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a backup. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/create)`
     `(ALPHA)` Backup a service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/delete)`
     `(ALPHA)` Delete a service backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/describe)`
     `(ALPHA)` Describe a backup. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for the backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/list)`
     `(ALPHA)` List backups under a Dataproc Metastore service. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding from a backup. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a backup. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud metastore services backups](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/backups)
