NAME
    

gcloud alpha metastore services databases - manage databases under Dataproc Metastore services 
SYNOPSIS
    

`gcloud alpha metastore services databases` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage databases under Dataproc Metastore services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[tables](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/databases/tables)`
     `(ALPHA)` Manage tables under databases. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/databases/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a database. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/databases/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for the database. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/databases/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding from a database. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/databases/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a database. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta metastore services databases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/databases)
