NAME
    

gcloud alpha metastore services migrations - manage the migration to a Dataproc Metastore service 
SYNOPSIS
    

`gcloud alpha metastore services migrations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage the migration to a Dataproc Metastore service. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations/cancel)`
     `(ALPHA)` Cancel the migration to Dataproc Metastore service. 
`[complete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations/complete)`
     `(ALPHA)` Complete the migration to Dataproc Metastore service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations/delete)`
     `(ALPHA)` Delete a migration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations/describe)`
     `(ALPHA)` Describe a migration. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations/list)`
     `(ALPHA)` List migrations for a Dataproc Metastore service. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations/start)`
     `(ALPHA)` Start the migration from a Dataproc Metastore service to Lakehouse runtime catalog(s). 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud metastore services migrations](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/migrations)
    
    
    [gcloud beta metastore services migrations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations)
