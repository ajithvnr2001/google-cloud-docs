NAME
    

gcloud alpha metastore operations - manage Dataproc Metastore operations 
SYNOPSIS
    

`gcloud alpha metastore operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataproc Metastore operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/operations/cancel)`
     `(ALPHA)` Cancel a Dataproc Metastore operation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/operations/delete)`
     `(ALPHA)` Delete one or more completed Dataproc Metastore operations. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/operations/describe)`
     `(ALPHA)` Show metadata for a Dataproc Metastore operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/operations/list)`
     `(ALPHA)` List Dataproc Metastore operations. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/operations/wait)`
     `(ALPHA)` Poll a long-running Dataproc Metastore operation until it completes. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud metastore operations](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/operations)
    
    
    [gcloud beta metastore operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/operations)
