NAME
    

gcloud alpha metastore locations - get information about Dataproc Metastore locations 
SYNOPSIS
    

`gcloud alpha metastore locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Get information about Dataproc Metastore locations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/locations/describe)`
     `(ALPHA)` Show metadata for a Dataproc Metastore location. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/locations/list)`
     `(ALPHA)` List Dataproc Metastore locations. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud metastore locations](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/locations)
    
    
    [gcloud beta metastore locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/locations)
