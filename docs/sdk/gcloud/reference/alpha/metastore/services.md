NAME
    

gcloud alpha metastore services - manage Dataproc Metastore services 
SYNOPSIS
    

`gcloud alpha metastore services` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Dataproc Metastore services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups)`
     `(ALPHA)` Manage backups under Dataproc Metastore services. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/databases)`
     `(ALPHA)` Manage databases under Dataproc Metastore services. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/export)`
     `(ALPHA)` Export metadata from a Dataproc Metastore service. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/import)`
     `(ALPHA)` Import metadata into a Dataproc Metastore service. 
`[imports](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/imports)`
     `(ALPHA)` `(DEPRECATED)` Manage metadata imports under Dataproc Metastore services. 
`[migrations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations)`
     `(ALPHA)` Manage the migration to a Dataproc Metastore service. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/add-iam-policy-binding)`
     `(ALPHA)` Add an IAM policy binding to a service. 
`[alter-metadata-resource-location](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/alter-metadata-resource-location)`
     `(ALPHA)` Alter metadata resource location. 
`[alter-table-properties](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/alter-table-properties)`
     `(ALPHA)` Alter metadata table properties. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/create)`
     `(ALPHA)` Create a Dataproc Metastore service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/delete)`
     `(ALPHA)` Delete one or more Dataproc Metastore services. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/describe)`
     `(ALPHA)` Describe a Dataproc Metastore service. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for the service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/list)`
     `(ALPHA)` List Dataproc Metastore services. 
`[move-table-to-database](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/move-table-to-database)`
     `(ALPHA)` Move table to another database. 
`[query-metadata](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/query-metadata)`
     `(ALPHA)` Execute a SQL query against a Dataproc Metastore Service's metadata. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/remove-iam-policy-binding)`
     `(ALPHA)` Remove an IAM policy binding from a service. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/restore)`
     `(ALPHA)` Restore a Dataproc Metastore service. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for the service. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/update)`
     `(ALPHA)` Update a Dataproc Metastore service. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud metastore services](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services)
    
    
    [gcloud beta metastore services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services)
