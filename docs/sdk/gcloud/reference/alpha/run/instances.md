NAME
    

gcloud alpha run instances - view and manage your Cloud Run instances 
SYNOPSIS
    

`gcloud alpha run instances` `GROUP` | `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` This set of commands can be used to view and manage your Cloud Run instances. 
EXAMPLES
     To list your existing instances, run: 
    
    
    [gcloud alpha run instances list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/list)

FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[dev](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/dev)`
     `(ALPHA)` Commands for development on Cloud Run Instances. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/logs)`
     `(ALPHA)` Read logs for Cloud Run instances. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Cloud Run instance. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/create)`
     `(ALPHA)` Create a Cloud Run instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/delete)`
     `(ALPHA)` Delete an instance. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/deploy)`
     `(ALPHA)` Deploy a Cloud Run instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/describe)`
     `(ALPHA)` Obtain details about instances. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Cloud Run instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/list)`
     `(ALPHA)` List instances. 
`[proxy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/proxy)`
     `(ALPHA)` Proxy an instance to localhost authenticating as the active account or with the specified token. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Cloud Run instance. 
`[replace](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/replace)`
     `(ALPHA)` Create or replace an instance from a YAML instance specification. 
`[restart](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/restart)`
     `(ALPHA)` Restart an instance. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a instance. 
`[ssh](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/ssh)`
     `(ALPHA)` SSH into an instance. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/start)`
     `(ALPHA)` Start a stopped instance. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/stop)`
     `(ALPHA)` Stop a running instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/instances/update)`
     `(ALPHA)` Update a Cloud Run instance. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta run instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/instances)
