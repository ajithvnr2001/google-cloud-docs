NAME
    

gcloud alpha run jobs logs - read logs for Cloud Run jobs 
SYNOPSIS
    

`gcloud alpha run jobs logs` `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Read logs for Cloud Run jobs. 
EXAMPLES
     To tail logs executions for a job, run: 
    
    
    [gcloud alpha run jobs logs tail](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/logs/tail) my-job

To read logs executions for a job, run: 
    
    
    [gcloud alpha run jobs logs read](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/logs/read) my-job

FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[read](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/logs/read)`
     `(ALPHA)` Read logs for Cloud Run jobs. 
`[tail](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/logs/tail)`
     `(ALPHA)` Tail logs for Cloud Run jobs. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud run jobs logs](https://docs.cloud.google.com/sdk/gcloud/reference/run/jobs/logs)
    
    
    [gcloud beta run jobs logs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/logs)
