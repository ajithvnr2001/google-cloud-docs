NAME
    

gcloud alpha run jobs - view and manage your Cloud Run jobs 
SYNOPSIS
    

`gcloud alpha run jobs` `GROUP` | `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` This set of commands can be used to view and manage your Cloud Run jobs. 
EXAMPLES
     To list your existing jobs, run: 
    
    
    [gcloud alpha run jobs list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/list)

FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[executions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/executions)`
     `(ALPHA)` View and manage your Cloud Run jobs executions. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/logs)`
     `(ALPHA)` Read logs for Cloud Run jobs. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Cloud Run job. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/create)`
     `(ALPHA)` Create a Cloud Run job. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/delete)`
     `(ALPHA)` Delete a job. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/deploy)`
     `(ALPHA)` Create or update a Cloud Run job. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/describe)`
     `(ALPHA)` Obtain details about jobs. 
`[execute](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/execute)`
     `(ALPHA)` Execute a job. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Cloud Run job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/list)`
     `(ALPHA)` List jobs. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Cloud Run job. 
`[replace](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/replace)`
     `(ALPHA)` Create or replace a job from a YAML job specification. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a job. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/update)`
     `(ALPHA)` Update a Cloud Run Job. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud run jobs](https://docs.cloud.google.com/sdk/gcloud/reference/run/jobs)
    
    
    [gcloud beta run jobs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs)
