#  gcloud alpha run worker-pools Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha run worker-pools - view and manage your Cloud Run worker pools 
SYNOPSIS
    

`gcloud alpha run worker-pools` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` This set of commands can be used to view and manage your Cloud Run worker pools. 
EXAMPLES
     To list your existing worker-pools, run: 
    
    
    [gcloud alpha run worker-pools list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/list)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/logs)`
     `(ALPHA)` Read logs for Cloud Run worker pools. 
`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/revisions)`
     `(ALPHA)` View and manage your Cloud Run WorkerPools revisions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a Cloud Run worker pool. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/delete)`
     `(ALPHA)` Delete a worker-pool. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/deploy)`
     `(ALPHA)` Create or update a Cloud Run worker-pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/describe)`
     `(ALPHA)` Obtain details about a given worker-pool. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a Cloud Run worker pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/list)`
     `(ALPHA)` List available worker-pools. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a Cloud Run worker pool. 
`[replace](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/replace)`
     `(ALPHA)` Create or replace a worker-pool from a YAML worker-pool specification. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for a worker pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/update)`
     `(ALPHA)` Update Cloud Run environment variables and other configuration settings. 
`[update-instance-split](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools/update-instance-split)`
     `(ALPHA)` Adjust the instance assignments for a Cloud Run worker-pool. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud run worker-pools](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools)
    
    
    [gcloud beta run worker-pools](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/worker-pools)
