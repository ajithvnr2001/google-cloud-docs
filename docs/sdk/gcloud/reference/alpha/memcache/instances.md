NAME
    

gcloud alpha memcache instances - manage Cloud Memorystore Memcached instances 
SYNOPSIS
    

`gcloud alpha memcache instances` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Memorystore Memcached instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/config)`
     `(ALPHA)` Manage Memcache instance configurations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[apply-parameters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/apply-parameters)`
     `(ALPHA)` Apply parameter update to nodes in a Memorystore Memcached instance. 
`[apply-software-update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/apply-software-update)`
     `(ALPHA)` Apply software update to nodes in a Memorystore Memcached instance. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/create)`
     `(ALPHA)` Create a Memorystore Memcached instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/delete)`
     `(ALPHA)` Delete a Memorystore Memcached instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/describe)`
     `(ALPHA)` Display metadata for a Memorystore Memcached instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/list)`
     `(ALPHA)` List Memorystore Memcached instances. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/reschedule-maintenance)`
     `(ALPHA)` Reschedule maintenance window for a Memcache instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/update)`
     `(ALPHA)` Update a Memorystore Memcached instance. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/instances/upgrade)`
     `(ALPHA)` Upgrade memcache instance to a newer memcached version. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud memcache instances](https://docs.cloud.google.com/sdk/gcloud/reference/memcache/instances)
    
    
    [gcloud beta memcache instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memcache/instances)
