NAME
    

gcloud alpha managed-kafka topics - administer Managed Service for Apache Kafka topics 
SYNOPSIS
    

`gcloud alpha managed-kafka topics` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Administer Managed Service for Apache Kafka topics. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/topics/create)`
     `(ALPHA)` Create a Managed Service for Apache Kafka topic. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/topics/delete)`
     `(ALPHA)` Delete a Managed Service for Apache Kafka topic. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/topics/describe)`
     `(ALPHA)` Describe a Managed Service for Apache Kafka topic. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/topics/list)`
     `(ALPHA)` List all Managed Service for Apache Kafka topics in a given cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/topics/update)`
     `(ALPHA)` Update a Managed Service for Apache Kafka topic. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud managed-kafka topics](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/topics)
    
    
    [gcloud beta managed-kafka topics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/topics)
