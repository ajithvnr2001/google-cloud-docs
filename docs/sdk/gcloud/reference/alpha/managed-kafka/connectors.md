NAME
    

gcloud alpha managed-kafka connectors - administer Managed Service for Apache Kafka connectors 
SYNOPSIS
    

`gcloud alpha managed-kafka connectors` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Administer Managed Service for Apache Kafka connectors. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/create)`
     `(ALPHA)` Create a Managed Service for Apache Kafka connector. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/delete)`
     `(ALPHA)` Delete a Managed Service for Apache Kafka connector. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/describe)`
     `(ALPHA)` Describe a Managed Service for Apache Kafka connector. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/list)`
     `(ALPHA)` List all Managed Service for Apache Kafka connectors for a given connect cluster. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/pause)`
     `(ALPHA)` Pauses operation of a Managed Service for Apache Kafka connector. 
`[restart](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/restart)`
     `(ALPHA)` Restarts a Managed Service for Apache Kafka connector. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/resume)`
     `(ALPHA)` Resumes operation of a stopped Managed Service for Apache Kafka connector. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/stop)`
     `(ALPHA)` Stops operation of a Managed Service for Apache Kafka connector. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors/update)`
     `(ALPHA)` Update a Managed Service for Apache Kafka connector. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud managed-kafka connectors](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/connectors)
    
    
    [gcloud beta managed-kafka connectors](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors)
