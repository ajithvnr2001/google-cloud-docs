NAME
    

gcloud alpha managed-kafka consumer-groups - administer Managed Service for Apache Kafka consumer groups 
SYNOPSIS
    

`gcloud alpha managed-kafka consumer-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Administer Managed Service for Apache Kafka consumer groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/consumer-groups/delete)`
     `(ALPHA)` Delete a Managed Service for Apache Kafka consumer group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/consumer-groups/describe)`
     `(ALPHA)` Describe a Managed Service for Apache Kafka consumer group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/consumer-groups/list)`
     `(ALPHA)` List all Managed Service for Apache Kafka consumer groups in a given cluster and location. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/consumer-groups/update)`
     `(ALPHA)` Update a Managed Service for Apache Kafka consumer group. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud managed-kafka consumer-groups](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/consumer-groups)
    
    
    [gcloud beta managed-kafka consumer-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/consumer-groups)
