NAME
    

gcloud alpha managed-kafka schema-registries - administer Managed Service for Apache Kafka schema-registries 
SYNOPSIS
    

`gcloud alpha managed-kafka schema-registries` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Administer Managed Service for Apache Kafka schema-registries. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[subjects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/schema-registries/subjects)`
     `(ALPHA)` Administer Managed Service for Apache Kafka schema-registries. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/schema-registries/create)`
     `(ALPHA)` Create a Managed Service for Apache Kafka schema registry. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/schema-registries/delete)`
     `(ALPHA)` Delete a Managed Service for Apache Kafka schema registry. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/schema-registries/describe)`
     `(ALPHA)` Describe a schema registry with all of its fields. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/schema-registries/list)`
     `(ALPHA)` List all Managed Service for Apache Kafka schema registries in a given location. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/schema-registries/update)`
     `(ALPHA)` Update the mode and compatibility of a schema registry. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta managed-kafka schema-registries](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/schema-registries)
