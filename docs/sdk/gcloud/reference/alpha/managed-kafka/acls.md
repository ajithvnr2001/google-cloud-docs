NAME
    

gcloud alpha managed-kafka acls - administer Managed Service for Apache Kafka acls 
SYNOPSIS
    

`gcloud alpha managed-kafka acls` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Administer Managed Service for Apache Kafka acls. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-acl-entry](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls/add-acl-entry)`
     `(ALPHA)` Add an acl entry to a Managed Service for Apache Kafka acl. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls/create)`
     `(ALPHA)` Create a Managed Service for Apache Kafka acl. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls/delete)`
     `(ALPHA)` Delete a Managed Service for Apache Kafka ACL. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls/describe)`
     `(ALPHA)` Describe a Managed Service for Apache Kafka acl. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls/list)`
     `(ALPHA)` List all Managed Service for Apache Kafka acls in a given cluster. 
`[remove-acl-entry](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls/remove-acl-entry)`
     `(ALPHA)` Remove an acl entry from a Managed Service for Apache Kafka acl. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls/update)`
     `(ALPHA)` Update a Managed Service for Apache Kafka acl. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud managed-kafka acls](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/acls)
