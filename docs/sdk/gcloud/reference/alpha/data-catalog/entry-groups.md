#  gcloud alpha data-catalog entry-groups Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha data-catalog entry-groups - manage entry groups in Data Catalog 
SYNOPSIS
    

`gcloud alpha data-catalog entry-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Manage entry groups in Data Catalog. 

This command is deprecated. Please use `[gcloud dataplex entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/entry-groups)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/add-iam-policy-binding)`
     `(ALPHA)` `(DEPRECATED)` Add an IAM policy binding to a Data Catalog entry group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/create)`
     `(ALPHA)` `(DEPRECATED)` Create a Data Catalog entry group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/delete)`
     `(ALPHA)` `(DEPRECATED)` Delete a Data Catalog entry group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/describe)`
     `(ALPHA)` `(DEPRECATED)` Describe a Data Catalog entry group. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/get-iam-policy)`
     `(ALPHA)` `(DEPRECATED)` Get the IAM policy for a Data Catalog entry group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/list)`
     `(ALPHA)` `(DEPRECATED)` List all entry groups in a Data Catalog location. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/remove-iam-policy-binding)`
     `(ALPHA)` `(DEPRECATED)` Remove an IAM policy binding from a Data Catalog entry group. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/set-iam-policy)`
     `(ALPHA)` `(DEPRECATED)` Set the IAM policy for a Data Catalog entry group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups/update)`
     `(ALPHA)` `(DEPRECATED)` Update a Data Catalog entry group. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud data-catalog entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/entry-groups)
    
    
    [gcloud beta data-catalog entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups)
