NAME
    

gcloud alpha data-catalog entries - manage entries in Data Catalog 
SYNOPSIS
    

`gcloud alpha data-catalog entries` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage entries in Data Catalog. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entries/create)`
     `(ALPHA)` `(DEPRECATED)` Create a Data Catalog entry. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entries/delete)`
     `(ALPHA)` `(DEPRECATED)` Delete a Data Catalog entry. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entries/describe)`
     `(ALPHA)` `(DEPRECATED)` Describe a Data Catalog entry. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entries/list)`
     `(ALPHA)` `(DEPRECATED)` List all entries in a Data Catalog entry group. 
`[lookup](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entries/lookup)`
     `(ALPHA)` `(DEPRECATED)` Lookup a Data Catalog entry by its target name. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entries/update)`
     `(ALPHA)` `(DEPRECATED)` Update a Data Catalog entry. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud data-catalog entries](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/entries)
    
    
    [gcloud beta data-catalog entries](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entries)
