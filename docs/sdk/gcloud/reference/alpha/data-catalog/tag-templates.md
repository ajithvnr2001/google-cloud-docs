#  gcloud alpha data-catalog tag-templates Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha data-catalog tag-templates - manage tag templates in Data Catalog 
SYNOPSIS
    

`gcloud alpha data-catalog tag-templates` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Manage tag templates in Data Catalog. 

This command is deprecated. Please use `[gcloud dataplex aspect-types](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/aspect-types)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[fields](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/fields)`
     `(ALPHA)` `(DEPRECATED)` Manage tag template fields in Data Catalog. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/add-iam-policy-binding)`
     `(ALPHA)` `(DEPRECATED)` Add IAM policy binding to a Data Catalog tag template. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/create)`
     `(ALPHA)` `(DEPRECATED)` Create a Data Catalog tag template. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/delete)`
     `(ALPHA)` `(DEPRECATED)` Delete a Data Catalog tag template. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/describe)`
     `(ALPHA)` `(DEPRECATED)` Describe a Data Catalog tag template. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/get-iam-policy)`
     `(ALPHA)` `(DEPRECATED)` Get the IAM policy for a Data Catalog tag template. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/remove-iam-policy-binding)`
     `(ALPHA)` `(DEPRECATED)` Remove IAM policy binding from a Data Catalog tag template. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/set-iam-policy)`
     `(ALPHA)` `(DEPRECATED)` Set the IAM policy for a Data Catalog tag template. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/update)`
     `(ALPHA)` `(DEPRECATED)` Update a Data Catalog tag template. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud data-catalog tag-templates](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/tag-templates)
    
    
    [gcloud beta data-catalog tag-templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/tag-templates)
