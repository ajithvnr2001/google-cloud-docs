NAME
    

gcloud alpha data-catalog tag-templates fields - manage tag template fields in Data Catalog 
SYNOPSIS
    

`gcloud alpha data-catalog tag-templates fields` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Manage tag template fields in Data Catalog. 

This command is deprecated. Please use `[gcloud dataplex aspect-types](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/aspect-types)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[enum-values](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/fields/enum-values)`
     `(ALPHA)` `(DEPRECATED)` Manage tag template enum values in Data Catalog. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/fields/create)`
     `(ALPHA)` `(DEPRECATED)` Create a Data Catalog tag template field. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/fields/delete)`
     `(ALPHA)` `(DEPRECATED)` Delete a Data Catalog tag template field. 
`[rename](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/fields/rename)`
     `(ALPHA)` `(DEPRECATED)` Rename a Data Catalog tag template field. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates/fields/update)`
     `(ALPHA)` `(DEPRECATED)` Update a Data Catalog tag template field. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud data-catalog tag-templates fields](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/tag-templates/fields)
    
    
    [gcloud beta data-catalog tag-templates fields](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/tag-templates/fields)
