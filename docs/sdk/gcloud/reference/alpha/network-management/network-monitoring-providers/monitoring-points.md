NAME
    

gcloud alpha network-management network-monitoring-providers monitoring-points - a Monitoring Point is an agent within your network or application infrastructure that sends probes and reports the results to AppNeta 
SYNOPSIS
    

`gcloud alpha network-management network-monitoring-providers monitoring-points` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The Monitoring Point can also be the target. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-management/network-monitoring-providers/monitoring-points/describe)`
     `(ALPHA)` Describe a Monitoring Point. 
`[download-install-script](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-management/network-monitoring-providers/monitoring-points/download-install-script)`
     `(ALPHA)` Download an installation script for a Monitoring Point. 
`[download-recreate-install-script](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-management/network-monitoring-providers/monitoring-points/download-recreate-install-script)`
     `(ALPHA)` Download an installation script for recreating a Monitoring Point. 
`[download-server-connect-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-management/network-monitoring-providers/monitoring-points/download-server-connect-config)`
     `(ALPHA)` Download the server connect configuration for a Network Monitoring Provider. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-management/network-monitoring-providers/monitoring-points/list)`
     `(ALPHA)` List Monitoring Points. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud network-management network-monitoring-providers](https://docs.cloud.google.com/sdk/gcloud/reference/network-management/network-monitoring-providers) monitoring-points
