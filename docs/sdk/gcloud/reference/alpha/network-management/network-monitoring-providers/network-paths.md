NAME
    

gcloud alpha network-management network-monitoring-providers network-paths - a Network Path represents the hop-by-hop route and active network delivery quality between a Monitoring Point (source) and a target destination 
SYNOPSIS
    

`gcloud alpha network-management network-monitoring-providers network-paths` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` A Network Path represents the hop-by-hop route and active network delivery quality between a Monitoring Point (source) and a target destination. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-management/network-monitoring-providers/network-paths/describe)`
     `(ALPHA)` Describe a Network Path. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-management/network-monitoring-providers/network-paths/list)`
     `(ALPHA)` List Network Paths. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud network-management network-monitoring-providers](https://docs.cloud.google.com/sdk/gcloud/reference/network-management/network-monitoring-providers) network-paths
