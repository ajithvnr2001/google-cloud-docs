NAME
    

gcloud alpha sql databases - provide commands for managing databases of Cloud SQL instances 
SYNOPSIS
    

`gcloud alpha sql databases` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Provide commands for managing databases of Cloud SQL instances, including creating, deleting, listing, patching, updating, and getting information about databases. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases/config)`
     `(ALPHA)` Manage Sqladmin database configurations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases/create)`
     `(ALPHA)` Creates a database for a Cloud SQL instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases/delete)`
     `(ALPHA)` Deletes a Cloud SQL database. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases/describe)`
     `(ALPHA)` Displays configuration and metadata about a Cloud SQL database. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases/list)`
     `(ALPHA)` Lists databases for a Cloud SQL instance. 
`[patch](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases/patch)`
     `(ALPHA)` Patches the settings of a Cloud SQL database. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud sql databases](https://docs.cloud.google.com/sdk/gcloud/reference/sql/databases)
    
    
    [gcloud beta sql databases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/databases)
