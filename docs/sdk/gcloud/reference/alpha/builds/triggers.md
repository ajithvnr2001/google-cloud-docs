NAME
    

gcloud alpha builds triggers - create and manage build triggers for Google Cloud Build 
SYNOPSIS
    

`gcloud alpha builds triggers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manage build triggers for Google Cloud Build. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/config)`
     `(ALPHA)` Manage Google Cloud Build trigger configurations. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/create)`
     `(ALPHA)` Create build triggers for Google Cloud Build. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/update)`
     `(ALPHA)` Update Triggers in Google Cloud Build. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/delete)`
     `(ALPHA)` Delete a build trigger. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/describe)`
     `(ALPHA)` Get information about a particular trigger. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/export)`
     `(ALPHA)` Export a build trigger. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/import)`
     `(ALPHA)` Import a build trigger. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/list)`
     `(ALPHA)` List Cloud Build triggers for a project. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/run)`
     `(ALPHA)` Run a build trigger. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud builds triggers](https://docs.cloud.google.com/sdk/gcloud/reference/builds/triggers)
    
    
    [gcloud beta builds triggers](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers)
