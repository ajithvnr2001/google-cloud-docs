NAME
    

gcloud alpha network-connectivity - manage Network Connectivity Center resources 
SYNOPSIS
    

`gcloud alpha network-connectivity` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Network Connectivity Center resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[hubs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/hubs)`
     `(ALPHA)` Manage Network Connectivity Center hubs. 
`[internal-ranges](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/internal-ranges)`
     `(ALPHA)` Manage internal ranges. 
`[policy-based-routes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/policy-based-routes)`
     `(ALPHA)` Manage Policy-based Routes. 
`[spokes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/spokes)`
     `(ALPHA)` Manage Network Connectivity Center spokes. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud network-connectivity](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity)
    
    
    [gcloud beta network-connectivity](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity)
