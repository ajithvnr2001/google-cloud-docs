NAME
    

gcloud alpha endpoints services - manage Services 
SYNOPSIS
    

`gcloud alpha endpoints services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to a service. 
`[check-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/check-iam-policy)`
     `(ALPHA)` Returns information about a principal's permissions on a service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/delete)`
     `(ALPHA)` Deletes a service from Google Service Management. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/deploy)`
     `(ALPHA)` Deploys a service configuration for the given service name. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/describe)`
     `(ALPHA)` Describes a service given a service name. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/get-iam-policy)`
     `(ALPHA)` Get the IAM policy for a service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/list)`
     `(ALPHA)` List services for a project. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding of a service. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services/undelete)`
     `(ALPHA)` Undeletes a service configuration that was previously deleted. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud endpoints services](https://docs.cloud.google.com/sdk/gcloud/reference/endpoints/services)
    
    
    [gcloud beta endpoints services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services)
