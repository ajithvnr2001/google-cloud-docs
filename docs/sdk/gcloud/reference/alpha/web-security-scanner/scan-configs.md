NAME
    

gcloud alpha web-security-scanner scan-configs - manage Cloud Web Security Scanner scan configs resources 
SYNOPSIS
    

`gcloud alpha web-security-scanner scan-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Google Cloud Web Security Scanner scan configs resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/web-security-scanner/scan-configs/create)`
     `(ALPHA)` Create a Web Security Scanner ScanConfig. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/web-security-scanner/scan-configs/delete)`
     `(ALPHA)` Delete a scan config. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/web-security-scanner/scan-configs/describe)`
     `(ALPHA)` Describe a scan config. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/web-security-scanner/scan-configs/list)`
     `(ALPHA)` List all scan configs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/web-security-scanner/scan-configs/update)`
     `(ALPHA)` Update a Web Security Scanner ScanConfig. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
