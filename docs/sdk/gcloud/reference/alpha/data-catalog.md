NAME
    

gcloud alpha data-catalog - manage Data Catalog resources 
SYNOPSIS
    

`gcloud alpha data-catalog` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Data Catalog resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[crawler-runs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/crawler-runs)`
     `(ALPHA)` Manage crawler runs in Data Catalog. 
`[crawlers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/crawlers)`
     `(ALPHA)` Manage crawler configurations in Data Catalog. 
`[entries](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entries)`
     `(ALPHA)` Manage entries in Data Catalog. 
`[entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups)`
     `(ALPHA)` `(DEPRECATED)` Manage entry groups in Data Catalog. 
`[tag-templates](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tag-templates)`
     `(ALPHA)` `(DEPRECATED)` Manage tag templates in Data Catalog. 
`[tags](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/tags)`
     `(ALPHA)` `(DEPRECATED)` Manage tags in Data Catalog. 
`[taxonomies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/taxonomies)`
     `(ALPHA)` Manage taxonomies in Data Catalog. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/search)`
     `(ALPHA)` `(DEPRECATED)` Search Data Catalog for resources that match a query. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud data-catalog](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog)
    
    
    [gcloud beta data-catalog](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog)
