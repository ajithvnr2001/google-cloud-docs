NAME
    

gcloud alpha functions - manage Google Cloud Functions 
SYNOPSIS
    

`gcloud alpha functions` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Google Cloud Functions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[event-types](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/event-types)`
     `(ALPHA)` List types of events that can be a trigger for a Google Cloud Function. 
`[local](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/local)`
     `(ALPHA)` Manage local instances of Google Cloud Functions. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/logs)`
     `(ALPHA)` Display log entries produced by Google Cloud Functions. 
`[regions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/regions)`
     `(ALPHA)` List regions available to Google Cloud Functions. 
`[runtimes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/runtimes)`
     `(ALPHA)` List runtimes available to Google Cloud Functions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/add-iam-policy-binding)`
     `(ALPHA)` Adds an IAM policy binding for a Google Cloud Function. 
`[add-invoker-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/add-invoker-policy-binding)`
     `(ALPHA)` Add an invoker binding to the IAM policy of a Google Cloud Function. 
`[call](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/call)`
     `(ALPHA)` Triggers execution of a Google Cloud Function. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/delete)`
     `(ALPHA)` Delete a Google Cloud Function. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/deploy)`
     `(ALPHA)` Create or update a Google Cloud Function. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/describe)`
     `(ALPHA)` Display details of a Google Cloud Function. 
`[detach](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/detach)`
     `(ALPHA)` Detach a Cloud Functions v2 function from its existing environment and make it a native Cloud Run function. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/get-iam-policy)`
     `(ALPHA)` Gets IAM policy for a Google Cloud Function. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/list)`
     `(ALPHA)` List Google Cloud Functions. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/remove-iam-policy-binding)`
     `(ALPHA)` Removes an IAM policy binding from a Google Cloud Function. 
`[remove-invoker-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/remove-invoker-policy-binding)`
     `(ALPHA)` Removes an invoker binding from the IAM policy of a Google Cloud Function. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/set-iam-policy)`
     `(ALPHA)` Sets IAM policy for a Google Cloud Function. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/functions/upgrade)`
     `(ALPHA)` Upgrade a 1st gen Cloud Function to the Cloud Run function. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud functions](https://docs.cloud.google.com/sdk/gcloud/reference/functions)
    
    
    [gcloud beta functions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/functions)
