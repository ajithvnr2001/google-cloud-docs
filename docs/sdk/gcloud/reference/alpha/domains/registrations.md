NAME
    

gcloud alpha domains registrations - manage Cloud Domains registrations 
SYNOPSIS
    

`gcloud alpha domains registrations` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing Cloud Domains registrations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[authorization-code](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/authorization-code)`
     `(ALPHA)` Manage Cloud Domains registration's authorization code. 
`[configure](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/configure)`
     `(ALPHA)` Configure Cloud Domains registrations' management, DNS or contact settings. 
`[google-domains-dns](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/google-domains-dns)`
     `(ALPHA)` Manage deprecated Google Domains DNS configuration. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/operations)`
     `(ALPHA)` Manage Cloud Domains operations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/delete)`
     `(ALPHA)` Delete a Cloud Domains registration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/describe)`
     `(ALPHA)` Describe an existing Cloud Domains registration. 
`[get-register-parameters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/get-register-parameters)`
     `(ALPHA)` Get register parameters (including availability) of a specific domain. 
`[initiate-push-transfer](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/initiate-push-transfer)`
     `(ALPHA)` Initiates the push transfer process. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/list)`
     `(ALPHA)` List Cloud Domains registrations. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/register)`
     `(ALPHA)` Register a new domain. 
`[renew-domain](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/renew-domain)`
     `(ALPHA)` Renew a recently expired Cloud Domains registration. 
`[search-domains](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/search-domains)`
     `(ALPHA)` Search for available domains. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/update)`
     `(ALPHA)` Update a Cloud Domains registration. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
