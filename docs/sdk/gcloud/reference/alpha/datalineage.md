NAME
    

gcloud alpha datalineage - manage Google Cloud Data Lineage resources 
SYNOPSIS
    

`gcloud alpha datalineage` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Data Lineage is a service that tracks the flow of data within Google Cloud. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/config)`
     `(ALPHA)` Manage Data Lineage configurations. 
`[lineage-events](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/lineage-events)`
     `(ALPHA)` Manage Data Lineage events. 
`[processes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/processes)`
     `(ALPHA)` Manage Data Lineage processes. 
`[runs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/runs)`
     `(ALPHA)` Manage Data Lineage runs. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud datalineage](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage)
    
    
    [gcloud beta datalineage](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datalineage)
