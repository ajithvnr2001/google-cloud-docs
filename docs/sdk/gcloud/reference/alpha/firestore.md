#  gcloud alpha firestore Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha firestore - manage your Cloud Firestore resources 
SYNOPSIS
    

`gcloud alpha firestore` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` export -- Export data to Google Cloud Storage 

import -- Import data from Google Cloud Storage 

bulk-delete -- Bulk delete documents from Cloud Firestore 

indexes -- Manage your Cloud Firestore indexes 

operations -- Manage Long Running Operations for Cloud Firestore 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/backups)`
     `(ALPHA)` The set of commands to manage backups for Cloud Firestore. 
`[change-streams](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/change-streams)`
     `(ALPHA)` Manage Cloud Firestore ChangeStreams. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases)`
     `(ALPHA)` Manage Creation of Cloud Firestore in Native mode Database. 
`[fields](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/fields)`
     `(ALPHA)` Manage field metadata for Cloud Firestore. 
`[indexes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/indexes)`
     `(ALPHA)` Manage indexes for Cloud Firestore. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/locations)`
     `(ALPHA)` The set of commands to manage Locations for Cloud Firestore. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/operations)`
     `(ALPHA)` Manage Long Running Operations for Cloud Firestore. 
`[user-creds](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/user-creds)`
     `(ALPHA)` Manage the user creds for a Cloud Firestore Database. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[bulk-delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/bulk-delete)`
     `(ALPHA)` bulk delete Cloud Firestore documents. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/export)`
     `(ALPHA)` export Cloud Firestore documents to Google Cloud Storage. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/import)`
     `(ALPHA)` import Cloud Firestore documents from Google Cloud Storage. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud firestore](https://docs.cloud.google.com/sdk/gcloud/reference/firestore)
    
    
    [gcloud beta firestore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore)
