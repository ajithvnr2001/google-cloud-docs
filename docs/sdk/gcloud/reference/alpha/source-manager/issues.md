NAME
    

gcloud alpha source-manager issues - manage Secure Source Manager issues 
SYNOPSIS
    

`gcloud alpha source-manager issues` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Secure Source Manager issues. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[comments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/comments)`
     `(ALPHA)` Manage Secure Source Manager issue comments. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[close](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/close)`
     `(ALPHA)` Close a Secure Source Manager issue. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/create)`
     `(ALPHA)` Create a Secure Source Manager issue. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/delete)`
     `(ALPHA)` Delete a Secure Source Manager issue. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/describe)`
     `(ALPHA)` Describe a Secure Source Manager issue. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/list)`
     `(ALPHA)` List Secure Source Manager issues under a repository. 
`[open](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/open)`
     `(ALPHA)` Open a Secure Source Manager issue. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/update)`
     `(ALPHA)` Update a Secure Source Manager issue. 
REGIONAL ENDPOINTS
     This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) regional/endpoint_mode regional-preferred`. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
