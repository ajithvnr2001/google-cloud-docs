NAME
    

gcloud alpha source-manager issues comments - manage Secure Source Manager issue comments 
SYNOPSIS
    

`gcloud alpha source-manager issues comments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Secure Source Manager issue comments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/comments/create)`
     `(ALPHA)` Create a Secure Source Manager issue comment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/comments/delete)`
     `(ALPHA)` Delete a Secure Source Manager issue comment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/comments/describe)`
     `(ALPHA)` Describe a Secure Source Manager issue comment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/comments/list)`
     `(ALPHA)` List Secure Source Manager comments under an issue. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/issues/comments/update)`
     `(ALPHA)` Update a Secure Source Manager issue comment. 
REGIONAL ENDPOINTS
     This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) regional/endpoint_mode regional-preferred`. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
