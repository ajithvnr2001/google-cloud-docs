NAME
    

gcloud alpha source-manager pull-requests comments - manage Secure Source Manager pull request comments 
SYNOPSIS
    

`gcloud alpha source-manager pull-requests comments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Secure Source Manager pull request comments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[batch-create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/batch-create)`
     `(ALPHA)` Batch create Secure Source Manager pull request comments. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/create)`
     `(ALPHA)` Create a Secure Source Manager pull request comment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/delete)`
     `(ALPHA)` Delete a Secure Source Manager pull request comment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/describe)`
     `(ALPHA)` Describe a Secure Source Manager pull request comment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/list)`
     `(ALPHA)` List Secure Source Manager comments under a pull request. 
`[resolve](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/resolve)`
     `(ALPHA)` Resolve Secure Source Manager pull request comments. 
`[unresolve](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/unresolve)`
     `(ALPHA)` Unresolve Secure Source Manager pull request comments. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments/update)`
     `(ALPHA)` Update a Secure Source Manager pull request comment. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
