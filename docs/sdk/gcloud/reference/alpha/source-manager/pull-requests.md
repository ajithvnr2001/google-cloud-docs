#  gcloud alpha source-manager pull-requests Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud alpha source-manager pull-requests - manage Secure Source Manager pull requests 
SYNOPSIS
    

`gcloud alpha source-manager pull-requests` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Secure Source Manager pull requests. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[comments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/comments)`
     `(ALPHA)` Manage Secure Source Manager pull request comments. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[close](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/close)`
     `(ALPHA)` Close a Secure Source Manager pull request. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/create)`
     `(ALPHA)` Create a Secure Source Manager pull request. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/describe)`
     `(ALPHA)` Describe a Secure Source Manager pull request. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/list)`
     `(ALPHA)` List Secure Source Manager pull requests under a repository. 
`[list-file-diffs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/list-file-diffs)`
     `(ALPHA)` List Secure Source Manager pull request file diffs. 
`[merge](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/merge)`
     `(ALPHA)` Merge a Secure Source Manager pull request. 
`[open](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/open)`
     `(ALPHA)` Open a Secure Source Manager pull request. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/pull-requests/update)`
     `(ALPHA)` Update a Secure Source Manager pull request. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
