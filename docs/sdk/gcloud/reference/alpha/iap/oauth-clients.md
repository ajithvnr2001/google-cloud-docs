NAME
    

gcloud alpha iap oauth-clients - manage IAP OAuth clients 
SYNOPSIS
    

`gcloud alpha iap oauth-clients` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` `(DEPRECATED)` Manage IAP OAuth clients. 

This command is deprecated and will be non-functional after the IAP OAuth Admin APIs are turned down. Jan 19, 2026: Google will discontinue support for the IAP OAuth Admin APIs. New projects will not be able to use these APIs. March 19, 2026: The IAP OAuth Admin APIs will be permanently shut down. Access to this feature will no longer be available. 

Manage OAuth clients that are used by Cloud Identity-Aware Proxy. Note this API cannot be used as a generic management API for all OAuth clients in your project. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/oauth-clients/create)`
     `(ALPHA)` `(DEPRECATED)` Create a Cloud IAP OAuth client in the project. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/oauth-clients/delete)`
     `(ALPHA)` `(DEPRECATED)` Delete a Cloud IAP OAuth client. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/oauth-clients/describe)`
     `(ALPHA)` `(DEPRECATED)` Describe a Cloud IAP OAuth client. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/oauth-clients/list)`
     `(ALPHA)` `(DEPRECATED)` List Cloud IAP OAuth clients in the Cloud OAuth brand. 
`[reset-secret](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/oauth-clients/reset-secret)`
     `(ALPHA)` `(DEPRECATED)` Reset a Cloud IAP OAuth client secret. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud iap oauth-clients](https://docs.cloud.google.com/sdk/gcloud/reference/iap/oauth-clients)
    
    
    [gcloud beta iap oauth-clients](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/oauth-clients)
