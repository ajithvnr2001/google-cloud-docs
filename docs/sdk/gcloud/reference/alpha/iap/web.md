NAME
    

gcloud alpha iap web - manage IAP web policies 
SYNOPSIS
    

`gcloud alpha iap web` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Cloud Identity-Aware Proxy (Cloud IAP) controls access to your cloud applications running on Google Cloud Platform. Cloud IAP works by verifying user identity and context of the request to determine if a user should be allowed to access the application. 

More information on Cloud IAP can be found here: <https://cloud.google.com/iap> and detailed documentation can be found here: <https://cloud.google.com/iap/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/web/add-iam-policy-binding)`
     `(ALPHA)` Add IAM policy binding to an IAP IAM resource. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/web/disable)`
     `(ALPHA)` Disable Cloud Identity-Aware Proxy (Cloud IAP) on an IAP resource. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/web/enable)`
     `(ALPHA)` Enable Cloud Identity-Aware Proxy (Cloud IAP) on an IAP resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/web/get-iam-policy)`
     `(ALPHA)` Get IAM policy for an IAP IAM resource. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/web/remove-iam-policy-binding)`
     `(ALPHA)` Remove IAM policy binding from an IAP IAM resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/web/set-iam-policy)`
     `(ALPHA)` Set the IAM policy for an IAP IAM resource. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud iap web](https://docs.cloud.google.com/sdk/gcloud/reference/iap/web)
    
    
    [gcloud beta iap web](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/web)
