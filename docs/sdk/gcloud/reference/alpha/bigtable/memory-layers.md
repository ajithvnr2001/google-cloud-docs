NAME
    

gcloud alpha bigtable memory-layers - manage Cloud Bigtable memory layers 
SYNOPSIS
    

`gcloud alpha bigtable memory-layers` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Manage Cloud Bigtable memory layers. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/memory-layers/describe)`
     `(ALPHA)` Describe a Bigtable memory layer. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/memory-layers/list)`
     `(ALPHA)` List Bigtable memory layers. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/memory-layers/update)`
     `(ALPHA)` Update a Bigtable memory layer. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available: 
    
    
    [gcloud beta bigtable memory-layers](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/memory-layers)
