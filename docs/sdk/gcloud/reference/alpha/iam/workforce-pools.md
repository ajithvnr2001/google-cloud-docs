NAME
    

gcloud alpha iam workforce-pools - create and manage workforce pools 
SYNOPSIS
    

`gcloud alpha iam workforce-pools` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` The gcloud alpha iam workforce-pools group lets you create and manage workforce pools for organizations on the Google Cloud Platform. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/operations)`
     `(ALPHA)` Manage IAM workforce pool long-running operations. 
`[providers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/providers)`
     `(ALPHA)` Create and manage workforce pool providers. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/create)`
     `(ALPHA)` Create a new workforce pool under an organization. 
`[create-cred-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/create-cred-config)`
     `(ALPHA)` Create a configuration file for generated credentials. 
`[create-login-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/create-login-config)`
     `(ALPHA)` Create a login configuration file to enable sign-in via a web-based authorization flow using Workforce Identity Federation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/delete)`
     `(ALPHA)` Delete a workforce pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/describe)`
     `(ALPHA)` Describe a workforce pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/list)`
     `(ALPHA)` List the workforce pools for an organization. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/undelete)`
     `(ALPHA)` Undelete a workforce pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools/update)`
     `(ALPHA)` Update a workforce pool. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud iam workforce-pools](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools)
    
    
    [gcloud beta iam workforce-pools](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools)
