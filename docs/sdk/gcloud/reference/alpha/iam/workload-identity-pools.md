NAME
    

gcloud alpha iam workload-identity-pools - manage IAM workload identity pools 
SYNOPSIS
    

`gcloud alpha iam workload-identity-pools` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Commands for managing IAM workload identity pools. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/operations)`
     `(ALPHA)` Manage IAM workload identity pool long running operations. 
`[providers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/providers)`
     `(ALPHA)` Manage IAM workload identity pool providers. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/create)`
     `(ALPHA)` Create a new workload identity pool. 
`[create-cred-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/create-cred-config)`
     `(ALPHA)` Create a configuration file for generated credentials. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/delete)`
     `(ALPHA)` Delete a workload identity pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/describe)`
     `(ALPHA)` Describe a workload identity pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/list)`
     `(ALPHA)` List workload identity pools. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/undelete)`
     `(ALPHA)` Undelete a workload identity pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/update)`
     `(ALPHA)` Update a workload identity pool. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud iam workload-identity-pools](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools)
    
    
    [gcloud beta iam workload-identity-pools](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools)
