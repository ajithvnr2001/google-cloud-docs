NAME
    

gcloud alpha iam roles - create and manipulate roles 
SYNOPSIS
    

`gcloud alpha iam roles` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(ALPHA)` Create and manipulate roles. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles/copy)`
     `(ALPHA)` Create a role from an existing role. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles/create)`
     `(ALPHA)` Create a custom role for a project or an organization. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles/delete)`
     `(ALPHA)` Delete a custom role from an organization or a project. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles/describe)`
     `(ALPHA)` Show metadata for a role. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles/list)`
     `(ALPHA)` List predefined roles, or the custom roles for an organization or project. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles/undelete)`
     `(ALPHA)` Undelete a custom role from an organization or a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles/update)`
     `(ALPHA)` Update an IAM custom role. 
NOTES
     This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available: 
    
    
    [gcloud iam roles](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles)
    
    
    [gcloud beta iam roles](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles)
