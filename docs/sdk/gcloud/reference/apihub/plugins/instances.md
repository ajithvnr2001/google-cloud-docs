NAME
    

gcloud apihub plugins instances - manage Plugin Instance resources 
SYNOPSIS
    

`gcloud apihub plugins instances` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Plugin Instance resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/instances/create)`
     Create a Plugin Instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/instances/delete)`
     Delete a Plugin Instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/instances/describe)`
     Describe a Plugin Instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/instances/list)`
     List Plugin Instances. 
`[manage-source-data](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/instances/manage-source-data)`
     manage pluginInstances. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/instances/update)`
     Update a Plugin Instance. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha apihub plugins instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins/instances)
