NAME
    

gcloud apihub plugins - manage Plugin resources 
SYNOPSIS
    

`gcloud apihub plugins` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Plugin resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/instances)`
     Manage Plugin Instance resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/create)`
     Create a Plugin. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/delete)`
     Delete a Plugin. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/describe)`
     Describe a Plugin. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/disable)`
     Disable a Plugin. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/enable)`
     Enable a Plugin. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins/list)`
     List Plugins. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha apihub plugins](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/plugins)
