NAME
    

gcloud apihub apis versions - manage Version resources 
SYNOPSIS
    

`gcloud apihub apis versions` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Version resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/operations)`
     Manage Api Operation resources. 
`[specs](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/specs)`
     Manage Spec resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/create)`
     Create a Version. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/delete)`
     Delete a Version. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/describe)`
     Describe a Version. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/list)`
     List Versions. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/update)`
     Update versions. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha apihub apis versions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/apis/versions)
