NAME
    

gcloud apihub runtime-project-attachments - manage Runtime Project Attachment resources 
SYNOPSIS
    

`gcloud apihub runtime-project-attachments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Runtime Project Attachment resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/runtime-project-attachments/create)`
     Create a Runtime Project Attachment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/runtime-project-attachments/delete)`
     Delete a Runtime Project Attachment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/runtime-project-attachments/describe)`
     Describe a Runtime Project Attachment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/runtime-project-attachments/list)`
     List Runtime Project Attachments. 
`[lookup](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/runtime-project-attachments/lookup)`
     Lookup a runtime project attachment. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha apihub runtime-project-attachments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apihub/runtime-project-attachments)
