NAME
    

gcloud logging - manage Cloud Logging 
SYNOPSIS
    

`gcloud logging` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Logging. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[buckets](https://docs.cloud.google.com/sdk/gcloud/reference/logging/buckets)`
     Manage Cloud Logging buckets. 
`[links](https://docs.cloud.google.com/sdk/gcloud/reference/logging/links)`
     Manage linked datasets. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/logging/locations)`
     Query Cloud Logging locations. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/logging/logs)`
     Manages your project's logs. 
`[metrics](https://docs.cloud.google.com/sdk/gcloud/reference/logging/metrics)`
     Manages logs-based metrics. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/logging/operations)`
     Manage long running operations. 
`[recent-queries](https://docs.cloud.google.com/sdk/gcloud/reference/logging/recent-queries)`
     Manage Cloud Logging recent queries. 
`[resource-descriptors](https://docs.cloud.google.com/sdk/gcloud/reference/logging/resource-descriptors)`
     Get information about resource descriptors. 
`[saved-queries](https://docs.cloud.google.com/sdk/gcloud/reference/logging/saved-queries)`
     Manage Cloud Logging saved queries. 
`[scopes](https://docs.cloud.google.com/sdk/gcloud/reference/logging/scopes)`
     Manages Cloud Logging log scopes. 
`[settings](https://docs.cloud.google.com/sdk/gcloud/reference/logging/settings)`
     Manages the org settings for the Cloud Logging Logs Router. 
`[sinks](https://docs.cloud.google.com/sdk/gcloud/reference/logging/sinks)`
     Manages sinks used to route logs to storage or export destinations. 
`[views](https://docs.cloud.google.com/sdk/gcloud/reference/logging/views)`
     Manage log views. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/logging/copy)`
     Copy log entries. 
`[read](https://docs.cloud.google.com/sdk/gcloud/reference/logging/read)`
     Read log entries. 
`[write](https://docs.cloud.google.com/sdk/gcloud/reference/logging/write)`
     Write a log entry. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha logging](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging)
    
    
    [gcloud beta logging](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging)
