NAME
    

gcloud pubsub topics - manage Cloud Pub/Sub topics 
SYNOPSIS
    

`gcloud pubsub topics` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Pub/Sub topics. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/add-iam-policy-binding)`
     Add IAM policy binding to a topic. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/create)`
     Creates one or more Cloud Pub/Sub topics. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/delete)`
     Deletes one or more Cloud Pub/Sub topics. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/describe)`
     Describes a Cloud Pub/Sub topic. 
`[detach-subscription](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/detach-subscription)`
     Detaches one or more Cloud Pub/Sub subscriptions. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/get-iam-policy)`
     Get the IAM policy for a Cloud Pub/Sub Topic. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/list)`
     Lists Cloud Pub/Sub topics within a project. 
`[list-subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/list-subscriptions)`
     Lists Cloud Pub/Sub subscriptions from a given topic. 
`[publish](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/publish)`
     Publishes a message to the specified topic. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/remove-iam-policy-binding)`
     Remove IAM policy binding of a topic. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/set-iam-policy)`
     Set IAM policy for a topic. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/topics/update)`
     Updates an existing Cloud Pub/Sub topic. 
NOTES
