NAME
    

gcloud pubsub lite-subscriptions - manage Pub/Sub Lite subscriptions 
SYNOPSIS
    

`gcloud pubsub lite-subscriptions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Pub/Sub Lite subscriptions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[ack-up-to](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/ack-up-to)`
     Acknowledge messages on a Pub/Sub Lite subscription. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/create)`
     Create a Pub/Sub Lite subscription. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/delete)`
     Delete a Pub/Sub Lite subscription. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/describe)`
     Describe a Pub/Sub Lite subscription. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/list)`
     List Pub/Sub Lite subscriptions. 
`[seek](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/seek)`
     Seek a Pub/Sub Lite subscription. 
`[subscribe](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/subscribe)`
     Stream messages from a Pub/Sub Lite subscription. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-subscriptions/update)`
     Update a Pub/Sub Lite subscription. 
NOTES
     These variants are also available:
