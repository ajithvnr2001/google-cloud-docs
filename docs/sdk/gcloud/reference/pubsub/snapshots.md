NAME
    

gcloud pubsub snapshots - manage Cloud Pub/Sub snapshots 
SYNOPSIS
    

`gcloud pubsub snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Pub/Sub snapshots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/snapshots/create)`
     Creates one or more Cloud Pub/Sub snapshots. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/snapshots/delete)`
     Deletes one or more Cloud Pub/Sub snapshots. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/snapshots/describe)`
     Describes a Cloud Pub/Sub snapshot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/snapshots/list)`
     Lists all the snapshots in a given project. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha pubsub snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/snapshots)
    
    
    [gcloud beta pubsub snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/snapshots)
