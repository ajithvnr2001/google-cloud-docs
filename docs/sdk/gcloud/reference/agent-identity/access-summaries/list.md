NAME
    

gcloud agent-identity access-summaries list - list access summaries 
SYNOPSIS
    

`gcloud agent-identity access-summaries list` `--location`=`LOCATION` [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     List access summaries in a given project and location. 
EXAMPLES
     To list access summaries in location 'us-central1' and project 'my-project', run: 
    
    
    gcloud agent-identity access-summaries list --location=us-central1 --project=my-project

REQUIRED FLAGS
    

Location resource - The parent resource where the search is performed. Format: projects/{project}/locations/{location} This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--location` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`--location`=`LOCATION`
     ID of the location or fully qualified identifier for the location. 

To set the `location` attribute: 

  * provide the argument `--location` on the command line.
