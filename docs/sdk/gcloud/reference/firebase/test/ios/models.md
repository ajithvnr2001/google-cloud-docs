NAME
    

gcloud firebase test ios models - explore iOS models available in the Test Environment catalog 
SYNOPSIS
    

`gcloud firebase test ios models` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Explore iOS models available in the Test Environment catalog. 
EXAMPLES
     To list all iOS models available for running tests, along with their model names and supported iOS versions, run: 
    
    
    [gcloud firebase test ios models list](https://docs.cloud.google.com/sdk/gcloud/reference/firebase/test/ios/models/list)

To view information about a single iOS model, run: 
    
    
    [gcloud firebase test ios models describe](https://docs.cloud.google.com/sdk/gcloud/reference/firebase/test/ios/models/describe) MODEL_ID

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/firebase/test/ios/models/describe)`
     Describe an iOS model. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/firebase/test/ios/models/list)`
     List all iOS models available for testing. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha firebase test ios models](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test/ios/models)
    
    
    [gcloud beta firebase test ios models](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/ios/models)
