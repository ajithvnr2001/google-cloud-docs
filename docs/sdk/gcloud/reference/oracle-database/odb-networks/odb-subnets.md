NAME
    

gcloud oracle-database odb-networks odb-subnets - manage Odb Subnet resources 
SYNOPSIS
    

`gcloud oracle-database odb-networks odb-subnets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Odb Subnet resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-subnets/create)`
     Create a new OdbSubnet. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-subnets/delete)`
     Delete an OdbSubnet. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-subnets/describe)`
     Get details of an OdbSubnet. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-subnets/list)`
     List all OdbSubnets. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/odb-networks/odb-subnets/update)`
     Update labels of an OdbSubnet.
