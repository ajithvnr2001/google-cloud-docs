NAME
    

gcloud oracle-database goldengate-connection-assignments - manage Goldengate Connection Assignment resources 
SYNOPSIS
    

`gcloud oracle-database goldengate-connection-assignments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Goldengate Connection Assignment resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/goldengate-connection-assignments/create)`
     Create a new GoldengateConnectionAssignment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/goldengate-connection-assignments/delete)`
     Delete a GoldengateConnectionAssignment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/goldengate-connection-assignments/describe)`
     Get details of a GoldengateConnectionAssignment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/goldengate-connection-assignments/list)`
     List all GoldengateConnectionAssignments. 
`[test](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/goldengate-connection-assignments/test)`
     Test a GoldengateConnectionAssignment. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/goldengate-connection-assignments/update)`
     Update labels of a GoldengateConnectionAssignment.
