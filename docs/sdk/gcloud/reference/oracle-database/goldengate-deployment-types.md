NAME
    

gcloud oracle-database goldengate-deployment-types - manage Goldengate Deployment Type resources 
SYNOPSIS
    

`gcloud oracle-database goldengate-deployment-types` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Goldengate Deployment Type resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/oracle-database/goldengate-deployment-types/list)`
     List all Goldengate deployment types.
