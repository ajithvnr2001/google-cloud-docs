NAME
    

gcloud compute instant-snapshot-groups - create, list and delete Compute Engine instant snapshot groups 
SYNOPSIS
    

`gcloud compute instant-snapshot-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create, list and delete Compute Engine instant snapshot groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/instant-snapshot-groups/create)`
     Create a Compute Engine consistency group of instant snapshots. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/instant-snapshot-groups/delete)`
     Delete a Compute Engine consistency group of instant snapshots. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/instant-snapshot-groups/describe)`
     Describe a Compute Engine consistency group of instant snapshots. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/instant-snapshot-groups/list)`
     List Google Compute Engine instant snapshot groups. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/compute/instant-snapshot-groups/set-iam-policy)`
     Set the IAM policy binding for a Compute Engine instant snapshot group. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/compute/instant-snapshot-groups/test-iam-permissions)`
     Test IAM permissions for a Compute Engine instant snapshot group. 
NOTES
     These variants are also available:
