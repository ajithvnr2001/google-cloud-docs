NAME
    

gcloud compute disks bulk - manipulate multiple Compute Engine disks with single command executions 
SYNOPSIS
    

`gcloud compute disks bulk` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manipulate multiple Compute Engine disks with single command executions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/disks/bulk/create)`
     Create multiple Compute Engine disks or a consistency group of instant snapshots. 
`[set-labels](https://docs.cloud.google.com/sdk/gcloud/reference/compute/disks/bulk/set-labels)`
     Add or remove labels on multiple Compute Engine disks. 
NOTES
     These variants are also available:
