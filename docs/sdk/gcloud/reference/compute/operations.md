NAME
    

gcloud compute operations - read and manipulate Compute Engine operations 
SYNOPSIS
    

`gcloud compute operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Read and manipulate Compute Engine operations. 

For more information about operations, see the [operations documentation](https://cloud.google.com/compute/docs/api/how-tos/api-requests-responses#handling_api_responses). 

See also: [Operations API](https://cloud.google.com/compute/docs/reference/rest/v1/regionOperations). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/operations/describe)`
     Describe a Compute Engine operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/operations/list)`
     List Google Compute Engine operations. 
NOTES
     These variants are also available:
