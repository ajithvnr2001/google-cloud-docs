NAME
    

gcloud compute advice - provides recommendation on optimal allocation of resources according to a flexible specifications 
SYNOPSIS
    

`gcloud compute advice` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Provides recommendation on optimal allocation of resources according to a flexible specifications. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[calendar-mode](https://docs.cloud.google.com/sdk/gcloud/reference/compute/advice/calendar-mode)`
     Recommends the optimal time window and zone for Future Reservations. 
`[capacity](https://docs.cloud.google.com/sdk/gcloud/reference/compute/advice/capacity)`
     Get capacity advice for Compute Engine resources. 
`[capacity-history](https://docs.cloud.google.com/sdk/gcloud/reference/compute/advice/capacity-history)`
     Show historical data on Spot VMs preemption and price. 
NOTES
     These variants are also available:
