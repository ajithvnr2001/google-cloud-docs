NAME
    

gcloud compute sole-tenancy node-groups describe - describe a Compute Engine node group 
SYNOPSIS
    

`gcloud compute sole-tenancy node-groups describe` `NAME` [`--zone`=`ZONE`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Describe a Compute Engine node group. 
EXAMPLES
     To describe a node group, run: 
    
    
    gcloud compute sole-tenancy node-groups describe my-node-group

POSITIONAL ARGUMENTS
    

`NAME`
     Name of the node group to operate on. 
FLAGS
    

`--zone`=`ZONE`
     Zone of the node group to operate on. If not specified and the ``compute/zone`` property isn't set, you might be prompted to select a zone (interactive mode only). 

To avoid prompting when this flag is omitted, you can set the ``compute/zone`` property: 
    
    
    [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) compute/zone ZONE

A list of zones can be fetched by running: 
    
    
    [gcloud compute zones list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/zones/list)

To unset the property, run: 
    
    
    [gcloud config unset](https://docs.cloud.google.com/sdk/gcloud/reference/config/unset) compute/zone

Alternatively, the zone can be stored in the environment variable ``CLOUDSDK_COMPUTE_ZONE``.
