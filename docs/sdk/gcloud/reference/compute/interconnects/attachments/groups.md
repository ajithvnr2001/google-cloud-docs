NAME
    

gcloud compute interconnects attachments groups - create or manipulate interconnect attachment groups 
SYNOPSIS
    

`gcloud compute interconnects attachments groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create or manipulate interconnect attachment groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-members](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/add-members)`
     Add member interconnect attachments to a Compute Engine interconnect attachment group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/create)`
     Create a Compute Engine interconnect attachment group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/delete)`
     Delete Compute Engine interconnect attachment groups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/describe)`
     Describe a Compute Engine interconnect attachment group. 
`[get-operational-status](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/get-operational-status)`
     Get the operational status of a Compute Engine interconnect attachment group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/list)`
     List interconnect attachment groups. 
`[remove-members](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/remove-members)`
     Remove member interconnect attachments from a Compute Engine interconnect attachment group. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/set-iam-policy)`
     Set the IAM policy for a Compute Engine interconnect attachment group. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/test-iam-permissions)`
     Test IAM permissions for a Compute Engine interconnect attachment group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/attachments/groups/update)`
     Update a Compute Engine interconnect attachment group.
