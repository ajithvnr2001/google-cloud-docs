NAME
    

gcloud compute interconnects wire-groups - create or manipulate wire groups 
SYNOPSIS
    

`gcloud compute interconnects wire-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create or manipulate wire groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-endpoint](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/add-endpoint)`
     Add endpoint to a Compute Engine wire group. 
`[add-interconnect](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/add-interconnect)`
     Add interconnect to a Compute Engine wire group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/create)`
     Create a Compute Engine wire group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/delete)`
     Delete Compute Engine wire groups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/describe)`
     Describe a Compute Engine wire group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/list)`
     List Google Compute Engine wire groups. 
`[remove-endpoint](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/remove-endpoint)`
     Remove endpoint from a Compute Engine wire group. 
`[remove-interconnect](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/remove-interconnect)`
     Remove interconnect from a wire group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/wire-groups/update)`
     Update a Compute Engine wire group.
