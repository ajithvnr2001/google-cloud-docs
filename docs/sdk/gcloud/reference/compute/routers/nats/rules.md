NAME
    

gcloud compute routers nats rules - list, create, update, describe, and delete Cloud NAT Rules 
SYNOPSIS
    

`gcloud compute routers nats rules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     List, create, update, describe, and delete Cloud NAT Rules. 

For more information about Cloud NAT, see the [Cloud NAT documentation](https://cloud.google.com/nat/docs/using-nat). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/routers/nats/rules/create)`
     Add a Rule to a Compute Engine NAT. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/routers/nats/rules/delete)`
     Delete a Rule in a Compute Engine NAT. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/routers/nats/rules/describe)`
     Describe a Rule in a Compute Engine NAT. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/routers/nats/rules/list)`
     Lists the NATs on a Compute Engine router. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/routers/nats/rules/update)`
     Update a Rule in a Compute Engine NAT.
