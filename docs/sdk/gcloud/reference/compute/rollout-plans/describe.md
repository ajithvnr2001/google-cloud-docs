NAME
    

gcloud compute rollout-plans describe - describe a rollout plan 
SYNOPSIS
    

`gcloud compute rollout-plans describe` `ROLLOUT_PLAN` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Describe a rollout plan. 
EXAMPLES
     To retrieve a single rollout plan and print its properties, run the following command: 
    
    
    gcloud compute rollout-plans describe my-rollout-plan

POSITIONAL ARGUMENTS
    

Rollout Plan resource - Name of the rollout plan you want to inspect. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `rollout_plan` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`ROLLOUT_PLAN`
     ID of the Rollout Plan or fully qualified identifier for the Rollout Plan. 

To set the `rollout_plan` attribute: 

  * provide the argument `rollout_plan` on the command line.
