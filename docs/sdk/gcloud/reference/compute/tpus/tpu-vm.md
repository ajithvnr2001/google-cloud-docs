NAME
    

gcloud compute tpus tpu-vm - list, create, and manage Cloud TPU VM nodes 
SYNOPSIS
    

`gcloud compute tpus tpu-vm` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     List, create, and manage Cloud TPU VM nodes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[accelerator-types](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/accelerator-types)`
     List or Describe Available Cloud TPU VM node accelerator types. 
`[service-identity](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/service-identity)`
     Commands for Cloud TPU VM service identity. 
`[versions](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/versions)`
     Explore available runtime versions for Cloud TPU VM nodes. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/create)`
     Create a new Cloud TPU VM node. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/delete)`
     Delete a Cloud TPU VM node. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/describe)`
     Describe a Cloud TPU VM node. 
`[get-guest-attributes](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/get-guest-attributes)`
     Retrieve the Guest Attributes for a Cloud TPU VM. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/list)`
     List Cloud TPU VM nodes. 
`[scp](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/scp)`
     Copy files to and from a Cloud TPU VM via SCP. 
`[ssh](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/ssh)`
     SSH into a Cloud TPU VM. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/start)`
     Start a Cloud TPU VM node. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/stop)`
     Stop a Cloud TPU VM node. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/tpus/tpu-vm/update)`
     Update a Cloud TPU VM node. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha compute tpus tpu-vm](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/tpus/tpu-vm)
