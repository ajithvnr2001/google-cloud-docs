NAME
    

gcloud compute storage-pools - read and manipulate storage pools 
SYNOPSIS
    

`gcloud compute storage-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Read and manipulate Compute Engine storage pools. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/create)`
     Create a storage pool. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/delete)`
     Delete a storage pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/describe)`
     Describe a storage pool. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/get-iam-policy)`
     Get the IAM policy of a storage pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/list)`
     View storage pools. 
`[list-disks](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/list-disks)`
     View the disks that are in a storage pool. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/set-iam-policy)`
     Set the IAM policy of the given storage pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/storage-pools/update)`
     Update a storage pool. 
NOTES
