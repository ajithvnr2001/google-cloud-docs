NAME
    

gcloud compute future-reservations - manage Compute Engine future reservations 
SYNOPSIS
    

`gcloud compute future-reservations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Compute Engine future reservations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/compute/future-reservations/cancel)`
     Cancel a Compute Engine future reservation. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/future-reservations/create)`
     Create a Compute Engine reservation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/future-reservations/delete)`
     Delete a Compute Engine future reservation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/future-reservations/describe)`
     Show details about a Compute Engine future reservation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/future-reservations/list)`
     List Compute Engine future reservations. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/future-reservations/update)`
     Update Compute Engine future reservations.
