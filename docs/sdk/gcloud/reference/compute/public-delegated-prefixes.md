NAME
    

gcloud compute public-delegated-prefixes - manage public delegated prefix resources 
SYNOPSIS
    

`gcloud compute public-delegated-prefixes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage public delegated prefix resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[delegated-sub-prefixes](https://docs.cloud.google.com/sdk/gcloud/reference/compute/public-delegated-prefixes/delegated-sub-prefixes)`
     Manage delegated sub prefixes. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/public-delegated-prefixes/create)`
     Creates a Compute Engine public delegated prefix. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/public-delegated-prefixes/delete)`
     Deletes a Compute Engine public delegated prefix. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/public-delegated-prefixes/describe)`
     Describes a Compute Engine public delegated prefix. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/public-delegated-prefixes/list)`
     List Google Compute Engine public delegated prefixes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/public-delegated-prefixes/update)`
     Updates a Compute Engine public delegated prefix. 
NOTES
     These variants are also available:
