NAME
    

gcloud compute reservations slots - manage Compute Engine reservation slots 
SYNOPSIS
    

`gcloud compute reservations slots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Compute Engine reservation slots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/slots/describe)`
     Describe a Compute Engine reservation slot. 
`[get-health](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/slots/get-health)`
     Get the health of a reservation slot. 
`[get-version](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/slots/get-version)`
     Get the version of a reservation slot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/slots/list)`
     List Compute Engine reservation slots.
