NAME
    

gcloud compute reservations sub-blocks - manage Compute Engine reservation sub blocks 
SYNOPSIS
    

`gcloud compute reservations sub-blocks` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Compute Engine reservation sub blocks. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/sub-blocks/describe)`
     Describe a Compute Engine reservation sub-block. 
`[get-version](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/sub-blocks/get-version)`
     Get the version of a reservation sub-block. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/sub-blocks/list)`
     List Compute Engine reservation sub-blocks. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/sub-blocks/perform-maintenance)`
     Perform maintenance on a reservation sub-block. 
`[report-subblock-as-faulty](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/sub-blocks/report-subblock-as-faulty)`
     Report a sub-block within a reservation as faulty. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/sub-blocks/set-iam-policy)`
     Set the IAM policy binding for a Compute Engine reservation sub-block. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/sub-blocks/test-iam-permissions)`
     Test IAM permissions on a Compute Engine reservation sub-block.
