NAME
    

gcloud compute os-config policy-orchestrators - manage VM Manager policy orchestrators 
SYNOPSIS
    

`gcloud compute os-config policy-orchestrators` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage VM Manager policy orchestrators. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config/policy-orchestrators/create)`
     Create a policy orchestrator. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config/policy-orchestrators/delete)`
     Delete a policy orchestrator. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config/policy-orchestrators/describe)`
     Describe a policy orchestrator. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config/policy-orchestrators/list)`
     List policy orchestrators. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config/policy-orchestrators/update)`
     Update a policy orchestrator. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha compute os-config policy-orchestrators](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config/policy-orchestrators)
