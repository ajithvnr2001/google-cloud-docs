NAME
    

gcloud builds - create and manage builds for Google Cloud Build 
SYNOPSIS
    

`gcloud builds` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage builds for Google Cloud Build. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[connections](https://docs.cloud.google.com/sdk/gcloud/reference/builds/connections)`
     Manage connections for Google Cloud Build. 
`[repositories](https://docs.cloud.google.com/sdk/gcloud/reference/builds/repositories)`
     Manage repositories for Cloud Build. 
`[triggers](https://docs.cloud.google.com/sdk/gcloud/reference/builds/triggers)`
     Create and manage build triggers for Google Cloud Build. 
`[worker-pools](https://docs.cloud.google.com/sdk/gcloud/reference/builds/worker-pools)`
     Manage worker pools for Google Cloud Build. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/builds/cancel)`
     Cancel an ongoing build. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/builds/describe)`
     Get information about a particular build. 
`[get-default-service-account](https://docs.cloud.google.com/sdk/gcloud/reference/builds/get-default-service-account)`
     Get the default service account for a project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/builds/list)`
     List builds. 
`[log](https://docs.cloud.google.com/sdk/gcloud/reference/builds/log)`
     Stream the logs for a build. 
`[submit](https://docs.cloud.google.com/sdk/gcloud/reference/builds/submit)`
     Submit a build using Cloud Build. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha builds](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds)
    
    
    [gcloud beta builds](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds)
