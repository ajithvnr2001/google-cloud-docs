NAME
    

gcloud backup-dr data-sources - view Backup and DR data sources 
SYNOPSIS
    

`gcloud backup-dr data-sources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     View Backup and DR data sources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/data-sources/describe)`
     Show details of the data source. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/data-sources/list)`
     List Data Sources. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha backup-dr data-sources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/data-sources)
