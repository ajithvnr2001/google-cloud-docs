NAME
    

gcloud storage - create and manage Cloud Storage buckets and objects 
SYNOPSIS
    

`gcloud storage` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     The gcloud storage command group lets you create and manage Cloud Storage resources such as buckets and objects. 

More information on Cloud Storage can be found here: https://cloud.google.com/storage, and detailed documentation can be found here: <https://cloud.google.com/storage/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[batch-operations](https://docs.cloud.google.com/sdk/gcloud/reference/storage/batch-operations)`
     Manage Cloud Storage batch operations. 
`[buckets](https://docs.cloud.google.com/sdk/gcloud/reference/storage/buckets)`
     Manage Cloud Storage buckets. 
`[folders](https://docs.cloud.google.com/sdk/gcloud/reference/storage/folders)`
     Manage Cloud Storage folders. 
`[hmac](https://docs.cloud.google.com/sdk/gcloud/reference/storage/hmac)`
     Manage Cloud Storage service account HMAC keys. 
`[insights](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights)`
     Manage Cloud Storage inventory reports. 
`[intelligence-configs](https://docs.cloud.google.com/sdk/gcloud/reference/storage/intelligence-configs)`
     Manage Cloud Storage Intelligence Configurations. 
`[intelligence-findings](https://docs.cloud.google.com/sdk/gcloud/reference/storage/intelligence-findings)`
     Findings for Cloud Storage usage. 
`[managed-folders](https://docs.cloud.google.com/sdk/gcloud/reference/storage/managed-folders)`
     Manage Cloud Storage managed folders. 
`[objects](https://docs.cloud.google.com/sdk/gcloud/reference/storage/objects)`
     Manage Cloud Storage objects. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/storage/operations)`
     Manage storage operations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[cat](https://docs.cloud.google.com/sdk/gcloud/reference/storage/cat)`
     Outputs the contents of one or more URLs to stdout. 
`[cp](https://docs.cloud.google.com/sdk/gcloud/reference/storage/cp)`
     Upload, download, and copy Cloud Storage objects. 
`[diagnose](https://docs.cloud.google.com/sdk/gcloud/reference/storage/diagnose)`
     Diagnose Google Cloud Storage. 
`[du](https://docs.cloud.google.com/sdk/gcloud/reference/storage/du)`
     Displays the amount of space in bytes used by storage resources. 
`[hash](https://docs.cloud.google.com/sdk/gcloud/reference/storage/hash)`
     Calculates hashes on local or cloud files. 
`[ls](https://docs.cloud.google.com/sdk/gcloud/reference/storage/ls)`
     List Cloud Storage buckets and objects. 
`[mv](https://docs.cloud.google.com/sdk/gcloud/reference/storage/mv)`
     Moves or renames objects. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/storage/restore)`
     Restore one or more soft-deleted objects. 
`[rm](https://docs.cloud.google.com/sdk/gcloud/reference/storage/rm)`
     Delete objects and buckets. 
`[rsync](https://docs.cloud.google.com/sdk/gcloud/reference/storage/rsync)`
     Synchronize content of two buckets/directories. 
`[service-agent](https://docs.cloud.google.com/sdk/gcloud/reference/storage/service-agent)`
     Manage a project's Cloud Storage service agent, which is used to perform Cloud KMS operations. 
`[sign-url](https://docs.cloud.google.com/sdk/gcloud/reference/storage/sign-url)`
     Generate a URL with embedded authentication that can be used by anyone. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha storage](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage)
