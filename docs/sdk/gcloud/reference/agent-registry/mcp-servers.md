NAME
    

gcloud agent-registry mcp-servers - manage Mcp Server resources 
SYNOPSIS
    

`gcloud agent-registry mcp-servers` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Mcp Server resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/mcp-servers/describe)`
     Get details of an MCP server. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/mcp-servers/list)`
     List registered MCP servers. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/mcp-servers/search)`
     Search MCP servers matching criteria. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha agent-registry mcp-servers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry/mcp-servers)
