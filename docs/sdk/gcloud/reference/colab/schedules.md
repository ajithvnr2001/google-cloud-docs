NAME
    

gcloud colab schedules - manage Colab Enterprise notebook execution schedules 
SYNOPSIS
    

`gcloud colab schedules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     For more information about schedules, see <https://cloud.google.com/colab/docs/schedule-notebook-run>. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/colab/schedules/create)`
     Create a schedule. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/colab/schedules/delete)`
     Delete a schedule. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/colab/schedules/describe)`
     Describe a schedule. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/colab/schedules/list)`
     List your Colab Enterprise notebook execution schedules. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/colab/schedules/pause)`
     Pause a schedule. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/colab/schedules/resume)`
     Resume a schedule. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/colab/schedules/update)`
     Update a schedule. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta colab schedules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/schedules)
