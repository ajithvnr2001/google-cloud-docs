NAME
    

gcloud network-services service-bindings - manage Network Services Bindings 
SYNOPSIS
    

`gcloud network-services service-bindings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Network Services Bindings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/service-bindings/create)`
     Create a service binding. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/service-bindings/delete)`
     Delete service binding. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/service-bindings/describe)`
     Describe a service binding. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/service-bindings/export)`
     Export a service binding. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/service-bindings/import)`
     Import a service binding. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/service-bindings/list)`
     List service bindings. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/service-bindings/update)`
     Update a service binding. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha network-services service-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/service-bindings)
    
    
    [gcloud beta network-services service-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/service-bindings)
