NAME
    

gcloud network-services agent-gateways import - import an AgentGateway 
SYNOPSIS
    

`gcloud network-services agent-gateways import` (`AGENT_GATEWAY` : `--location`=`LOCATION`) [`--async`] [`--source`=`SOURCE`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Import a agent gateway. 
EXAMPLES
     To import a agent gateway named 'my-agentgateway' from a YAML file, run: 
    
    
    gcloud network-services agent-gateways import my-agent-gateway --location=us-central1 --source=my-agentgateway.yaml

POSITIONAL ARGUMENTS
    

Agent gateway resource - Name of the agent gateway to import. The arguments in this group can be used to specify the attributes of this resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `agent_gateway` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`AGENT_GATEWAY`
     ID of the agent gateway or fully qualified identifier for the agent gateway. 

To set the `agent_gateway` attribute: 

  * provide the argument `agent_gateway` on the command line. 



This positional argument must be specified if any of the other arguments in this group are specified. 

`--location`=`LOCATION`
     The location Id. 

To set the `location` attribute: 

  * provide the argument `agent_gateway` on the command line with a fully specified name; 
  * provide the argument `--location` on the command line. 


FLAGS
    

`--async`
     Return immediately, without waiting for the operation in progress to complete. 
`--source`=`SOURCE`
     Path to a YAML file containing the configuration export data. The YAML file must not contain any output-only fields. Alternatively, you may omit this flag to read from standard input. For a schema describing the export/import format, see: $CLOUDSDKROOT/lib/googlecloudsdk/schemas/…
