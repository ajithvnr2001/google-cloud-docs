NAME
    

gcloud network-services agent-gateways - manage Network Services AgentGateways 
SYNOPSIS
    

`gcloud network-services agent-gateways` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Network Services AgentGateways. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/agent-gateways/delete)`
     Delete an AgentGateway. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/agent-gateways/describe)`
     Describe a Agent Gateway. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/agent-gateways/export)`
     Export an AgentGateway. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/agent-gateways/import)`
     Import an AgentGateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/agent-gateways/list)`
     List AgentGateways. 
NOTES
     These variants are also available:
