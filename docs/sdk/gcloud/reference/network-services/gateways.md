NAME
    

gcloud network-services gateways - manage Network Services Gateways 
SYNOPSIS
    

`gcloud network-services gateways` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Network Services Gateways. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/gateways/delete)`
     Delete a gateway. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/gateways/describe)`
     Describe a gateway. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/gateways/export)`
     Export the configuration for a gateway. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/gateways/import)`
     Import the configuration for a gateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/gateways/list)`
     List gateways. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha network-services gateways](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/gateways)
