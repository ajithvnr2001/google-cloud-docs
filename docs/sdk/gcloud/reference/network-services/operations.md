NAME
    

gcloud network-services operations - manage Network Services Operations 
SYNOPSIS
    

`gcloud network-services operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Network Services Operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/operations/cancel)`
     Cancel a Network Services long running operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/operations/describe)`
     Show details of a Network Services long running operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/operations/list)`
     List all Network Services long running operations. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/operations/wait)`
     Poll a Network Services long running operation. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha network-services operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/operations)
    
    
    [gcloud beta network-services operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/operations)
