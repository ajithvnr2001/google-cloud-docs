NAME
    

gcloud database-migration operations - manage Database Migration Service operations 
SYNOPSIS
    

`gcloud database-migration operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Database Migration Service operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/operations/delete)`
     Delete a Database Migration Service operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/operations/describe)`
     Show details about a operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/operations/list)`
     List operations. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha database-migration operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/operations)
