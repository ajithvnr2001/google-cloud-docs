NAME
    

gcloud database-migration connection-profiles - manage Database Migration Service connection profiles 
SYNOPSIS
    

`gcloud database-migration connection-profiles` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Database Migration Service connection profiles. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/connection-profiles/create)`
     Create Database Migration Service connection profiles. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/connection-profiles/delete)`
     Delete a Database Migration Service connection profile. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/connection-profiles/describe)`
     Show details about a Database Migration Service connection profile. 
`[fetch-static-ips](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/connection-profiles/fetch-static-ips)`
     List IPs used for static IP connectivity method. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/connection-profiles/list)`
     List Database Migration Service connection profiles. 
`[test](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/connection-profiles/test)`
     Test a Database Migration Service connection profile. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/database-migration/connection-profiles/update)`
     Update a Database Migration Service connection profile. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha database-migration connection-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/database-migration/connection-profiles)
