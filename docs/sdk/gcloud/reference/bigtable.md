NAME
    

gcloud bigtable - manage your Cloud Bigtable storage 
SYNOPSIS
    

`gcloud bigtable` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage your Cloud Bigtable storage. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[app-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/app-profiles)`
     Manage Cloud Bigtable app profiles. 
`[authorized-views](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/authorized-views)`
     Manage Cloud Bigtable Authorized Views. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/backups)`
     Manage Cloud Bigtable backups. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/clusters)`
     Manage Cloud Bigtable clusters. 
`[hot-tablets](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/hot-tablets)`
     Manage Cloud Bigtable hot tablets. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/instances)`
     Manage Cloud Bigtable instances. 
`[logical-views](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/logical-views)`
     Manage Bigtable logical views. 
`[materialized-views](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/materialized-views)`
     Manage Bigtable materialized views. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/operations)`
     Manage Cloud Bigtable operations. 
`[schema-bundles](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/schema-bundles)`
     Manage Bigtable schema bundles. 
`[tables](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/tables)`
     Query Cloud Bigtable tables. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha bigtable](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable)
    
    
    [gcloud beta bigtable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable)
