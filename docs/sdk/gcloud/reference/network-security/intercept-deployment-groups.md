NAME
    

gcloud network-security intercept-deployment-groups - manage Intercept Deployment Group resources 
SYNOPSIS
    

`gcloud network-security intercept-deployment-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     This class provides commands for managing Intercept Deployment Groups. 

Attributes: category (str): The category under which this command group falls. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/intercept-deployment-groups/create)`
     Create an Intercept Deployment Group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/intercept-deployment-groups/delete)`
     Delete an Intercept Deployment Group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/intercept-deployment-groups/describe)`
     Describe an Intercept Deployment Group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/intercept-deployment-groups/list)`
     List Intercept Deployment Groups. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/intercept-deployment-groups/update)`
     Update an Intercept Deployment Group.
