NAME
    

gcloud network-security backend-authentication-configs - manage Network Security BackendAuthenticationConfigs 
SYNOPSIS
    

`gcloud network-security backend-authentication-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Network Security BackendAuthenticationConfigs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/backend-authentication-configs/create)`
     Create a BackendAuthenticationConfig. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/backend-authentication-configs/delete)`
     Delete BackendAuthenticationConfig. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/backend-authentication-configs/describe)`
     Describe BackendAuthenticationConfig. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/backend-authentication-configs/export)`
     Export BackendAuthenticationConfig. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/backend-authentication-configs/import)`
     Import BackendAuthenticationConfigs. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/backend-authentication-configs/list)`
     List BackendAuthenticationConfigs.
