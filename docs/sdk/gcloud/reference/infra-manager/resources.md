NAME
    

gcloud infra-manager resources - list or describe resources under a Revision 
SYNOPSIS
    

`gcloud infra-manager resources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     List or describe resources under a Revision. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/resources/describe)`
     Describe resources. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/resources/list)`
     List resources.
