NAME
    

gcloud iap - manage IAP policies 
SYNOPSIS
    

`gcloud iap` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Cloud Identity-Aware Proxy (Cloud IAP) controls access to your cloud applications running on Google Cloud Platform. Cloud IAP works by verifying user identity and context of the request to determine if a user should be allowed to access the application. 

More information on Cloud IAP can be found here: <https://cloud.google.com/iap> and detailed documentation can be found here: <https://cloud.google.com/iap/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[oauth-brands](https://docs.cloud.google.com/sdk/gcloud/reference/iap/oauth-brands)`
     `(DEPRECATED)` Manage IAP OAuth brands. 
`[oauth-clients](https://docs.cloud.google.com/sdk/gcloud/reference/iap/oauth-clients)`
     `(DEPRECATED)` Manage IAP OAuth clients. 
`[settings](https://docs.cloud.google.com/sdk/gcloud/reference/iap/settings)`
     Manage IAP settings. 
`[tcp](https://docs.cloud.google.com/sdk/gcloud/reference/iap/tcp)`
     Manage IAP TCP resources. 
`[web](https://docs.cloud.google.com/sdk/gcloud/reference/iap/web)`
     Manage IAP web policies. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha iap](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap)
    
    
    [gcloud beta iap](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap)
