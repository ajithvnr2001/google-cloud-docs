NAME
    

gcloud deployment-manager operations - commands for Deployment Manager operations 
SYNOPSIS
    

`gcloud deployment-manager operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands to list, examine, and wait for long-running operations. 
EXAMPLES
     To view the details of an operation, run: 
    
    
    [gcloud deployment-manager operations describe](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/operations/describe) operation-name

To see the list of all operations, run: 
    
    
    [gcloud deployment-manager operations list](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/operations/list)

To wait for an operation to complete, run: 
    
    
    [gcloud deployment-manager operations wait](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/operations/wait) operation-name

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/operations/describe)`
     Provide information about an operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/operations/list)`
     List operations in a project. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/operations/wait)`
     Wait for all operations specified to complete before returning. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha deployment-manager operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/operations)
    
    
    [gcloud beta deployment-manager operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/operations)
