NAME
    

gcloud deployment-manager resources - commands for Deployment Manager resources 
SYNOPSIS
    

`gcloud deployment-manager resources` `COMMAND` [`--deployment`=`DEPLOYMENT`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands to list and examine resources within a deployment. 
EXAMPLES
     To view all details about a resource, run: 
    
    
    [gcloud deployment-manager resources describe](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/resources/describe) my-resource --deployment my-deployment

To see the list of all resources in a deployment, run: 
    
    
    [gcloud deployment-manager resources list](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/resources/list) --deployment my-deployment

FLAGS
    

`--deployment`=`DEPLOYMENT`
     Deployment name 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/resources/describe)`
     Provide information about a resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/resources/list)`
     List resources in a deployment. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha deployment-manager resources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/resources)
    
    
    [gcloud beta deployment-manager resources](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/resources)
