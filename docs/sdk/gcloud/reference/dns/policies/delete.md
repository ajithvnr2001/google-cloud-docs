NAME
    

gcloud dns policies delete - deletes a Cloud DNS policy 
SYNOPSIS
    

`gcloud dns policies delete` `POLICY` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Deletes a Cloud DNS policy. 
EXAMPLES
    

To delete a policy, run: 
    
    
    gcloud dns policies delete mypolicy

POSITIONAL ARGUMENTS
    

Policy resource - The name of the policy you want to delete. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `policy` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`POLICY`
     ID of the policy or fully qualified identifier for the policy. 

To set the `policy` attribute: 

  * provide the argument `policy` on the command line.
