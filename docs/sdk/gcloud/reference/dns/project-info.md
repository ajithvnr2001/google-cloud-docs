NAME
    

gcloud dns project-info - view Cloud DNS related information for a project 
SYNOPSIS
    

`gcloud dns project-info` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     View Cloud DNS related information for a project. 
EXAMPLES
     To display Cloud DNS related information for your project, run: 
    
    
    [gcloud dns project-info describe](https://docs.cloud.google.com/sdk/gcloud/reference/dns/project-info/describe)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/dns/project-info/describe)`
     View Cloud DNS related information for a project. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha dns project-info](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dns/project-info)
    
    
    [gcloud beta dns project-info](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/project-info)
