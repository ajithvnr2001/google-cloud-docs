NAME
    

gcloud kms keys versions - create and manage versions 
SYNOPSIS
    

`gcloud kms keys versions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     A version represents an individual cryptographic key and the associated key material. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/create)`
     Create a new version. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/delete)`
     Delete a key version. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/describe)`
     Get metadata for a given version. 
`[destroy](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/destroy)`
     Schedule a version to be destroyed. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/disable)`
     Disable a given version. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/enable)`
     Enable a given version. 
`[export-trusted-key-wrapped](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/export-trusted-key-wrapped)`
     Export a trusted key wrapped CryptoKeyVersion. 
`[get-certificate-chain](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/get-certificate-chain)`
     Get a certificate chain for a given version. 
`[get-public-key](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/get-public-key)`
     Get the public key for a given version. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/import)`
     Import a version into an existing crypto key. 
`[import-trusted-key-wrapped](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/import-trusted-key-wrapped)`
     Import a trusted key wrapped CryptoKeyVersion. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/list)`
     List the versions within a key. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/restore)`
     Restore a version scheduled for destruction. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions/update)`
     Update a key version.
