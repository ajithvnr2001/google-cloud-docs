NAME
    

gcloud kms inventory - manages the KMS Inventory and Key Tracking commands 
SYNOPSIS
    

`gcloud kms inventory` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manages the KMS Inventory and Key Tracking commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[get-protected-resources-summary](https://docs.cloud.google.com/sdk/gcloud/reference/kms/inventory/get-protected-resources-summary)`
     Gets the protected resources summary. 
`[list-keys](https://docs.cloud.google.com/sdk/gcloud/reference/kms/inventory/list-keys)`
     Lists the keys in a project. 
`[search-protected-resources](https://docs.cloud.google.com/sdk/gcloud/reference/kms/inventory/search-protected-resources)`
     Searches the resources protected by a key. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha kms inventory](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/inventory)
    
    
    [gcloud beta kms inventory](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/inventory)
