NAME
    

gcloud kms retired-resources - manage retired resources 
SYNOPSIS
    

`gcloud kms retired-resources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     A retired resource represents a deleted key version. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/kms/retired-resources/describe)`
     Get metadata for a given retired resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/kms/retired-resources/list)`
     List the retired resources within a location. 
NOTES
     These variants are also available:
