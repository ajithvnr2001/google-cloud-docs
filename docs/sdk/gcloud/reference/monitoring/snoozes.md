NAME
    

gcloud monitoring snoozes - manage Cloud Monitoring snoozes 
SYNOPSIS
    

`gcloud monitoring snoozes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Monitoring snoozes. 

More information can be found here: <https://cloud.google.com/monitoring/api/v3/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/snoozes/cancel)`
     Cancels a snooze. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/snoozes/create)`
     Create a new snooze. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/snoozes/describe)`
     Describe a snooze. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/snoozes/list)`
     List snoozes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/snoozes/update)`
     Updates a snooze.
