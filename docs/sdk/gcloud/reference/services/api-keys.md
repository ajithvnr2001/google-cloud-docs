NAME
    

gcloud services api-keys - manage API keys 
SYNOPSIS
    

`gcloud services api-keys` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage API keys. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/create)`
     Create an API key. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/delete)`
     Delete an API key. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/describe)`
     Describe an API key's metadata. 
`[get-key-string](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/get-key-string)`
     Get the key string of an API key. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/list)`
     Lists API keys. 
`[lookup](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/lookup)`
     Look up resource name of a key string. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/undelete)`
     Undelete an API key. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys/update)`
     Update an API key's metadata. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha services api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/api-keys)
    
    
    [gcloud beta services api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/api-keys)
