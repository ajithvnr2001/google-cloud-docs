#  gcloud dataplex Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud dataplex - manage Dataplex resources 
SYNOPSIS
    

`gcloud dataplex` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplex resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[aspect-types](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/aspect-types)`
     Manage Dataplex Aspect Types. 
`[assets](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/assets)`
     Manage Dataplex Asset resources. 
`[context](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/context)`
     Manage Dataplex Context. 
`[data-products](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products)`
     Manage Dataplex Data Product resources. 
`[datascans](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/datascans)`
     Manage Dataplex Datascan. 
`[dbt](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/dbt)`
     Ingest dbt-core metadata into Dataplex Knowledge Catalog. 
`[encryption-config](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/encryption-config)`
     Manage Dataplex encryption configs. 
`[entries](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/entries)`
     Manage Dataplex Catalog Entries resources. 
`[entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/entry-groups)`
     Manage Dataplex Entry Groups. 
`[entry-types](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/entry-types)`
     Manage Dataplex Entry Types. 
`[glossaries](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/glossaries)`
     Manage Dataplex glossaries. 
`[lakes](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes)`
     Manage Dataplex Lake resources. 
`[metadata-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/metadata-jobs)`
     Manage Dataplex metadata jobs. 
`[tasks](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/tasks)`
     Manage Dataplex Task services. 
`[zones](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/zones)`
     Manage Dataplex Zone resources. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex)
