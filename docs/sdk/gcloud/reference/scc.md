NAME
    

gcloud scc - manage Cloud SCC resources 
SYNOPSIS
    

`gcloud scc` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Google Cloud SCC (Security Command Center) resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[assets](https://docs.cloud.google.com/sdk/gcloud/reference/scc/assets)`
     Manage Cloud SCC (Security Command Center) assets. 
`[bqexports](https://docs.cloud.google.com/sdk/gcloud/reference/scc/bqexports)`
     Manage Cloud SCC (Security Command Center) BigQuery exports. 
`[custom-modules](https://docs.cloud.google.com/sdk/gcloud/reference/scc/custom-modules)`
     Manage Cloud SCC (Security Command Center) custom modules. 
`[findings](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings)`
     Manage Cloud SCC (Security Command Center) findings. 
`[iac-validation-reports](https://docs.cloud.google.com/sdk/gcloud/reference/scc/iac-validation-reports)`
     Manage Cloud SCC (Security Command Center) iac-validation-reports. 
`[manage](https://docs.cloud.google.com/sdk/gcloud/reference/scc/manage)`
     Manage Cloud SCC (Security Command Center) settings. 
`[muteconfigs](https://docs.cloud.google.com/sdk/gcloud/reference/scc/muteconfigs)`
     Manage Cloud SCC (Security Command Center) mute configs. 
`[notifications](https://docs.cloud.google.com/sdk/gcloud/reference/scc/notifications)`
     Manage Cloud SCC (Security Command Center) notifications. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/scc/operations)`
     Manage Cloud SCC (Security Command Center) operations. 
`[posture-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/scc/posture-deployments)`
     Manage Cloud Security Command Center (SCC) posture deployments. 
`[posture-operations](https://docs.cloud.google.com/sdk/gcloud/reference/scc/posture-operations)`
     Manage Cloud Security Command Center (SCC) posture operations. 
`[posture-templates](https://docs.cloud.google.com/sdk/gcloud/reference/scc/posture-templates)`
     Manage Cloud Security Command Center (SCC) posture templates. 
`[postures](https://docs.cloud.google.com/sdk/gcloud/reference/scc/postures)`
     Manage Cloud Security Command Center (SCC) postures. 
`[sources](https://docs.cloud.google.com/sdk/gcloud/reference/scc/sources)`
     Manage Cloud SCC (Security Command Center) finding sources.
