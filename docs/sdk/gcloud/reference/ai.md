NAME
    

gcloud ai - manage entities in Vertex AI 
SYNOPSIS
    

`gcloud ai` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage entities in Vertex AI. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[custom-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/ai/custom-jobs)`
     Manage Vertex AI custom jobs. 
`[endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/ai/endpoints)`
     Manage Vertex AI endpoints. 
`[hp-tuning-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/ai/hp-tuning-jobs)`
     Manage Vertex AI hyperparameter tuning jobs. 
`[index-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/ai/index-endpoints)`
     Manage Vertex AI index endpoints. 
`[indexes](https://docs.cloud.google.com/sdk/gcloud/reference/ai/indexes)`
     Manage Vertex AI indexes. 
`[model-garden](https://docs.cloud.google.com/sdk/gcloud/reference/ai/model-garden)`
     Interact with and manage resources in Vertex Model Garden. 
`[model-monitoring-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/ai/model-monitoring-jobs)`
     Manage Vertex AI model monitoring jobs. 
`[models](https://docs.cloud.google.com/sdk/gcloud/reference/ai/models)`
     Manage Vertex AI models. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/ai/operations)`
     Manage Vertex AI operations. 
`[persistent-resources](https://docs.cloud.google.com/sdk/gcloud/reference/ai/persistent-resources)`
     Create and manage Vertex AI persistent resources. 
`[semantic-governance-policies](https://docs.cloud.google.com/sdk/gcloud/reference/ai/semantic-governance-policies)`
     Manage Vertex AI Semantic Governance Policy resources. 
`[semantic-governance-policy-engine](https://docs.cloud.google.com/sdk/gcloud/reference/ai/semantic-governance-policy-engine)`
     Manage Vertex AI Semantic Governance Policy engine. 
`[tensorboards](https://docs.cloud.google.com/sdk/gcloud/reference/ai/tensorboards)`
     Manage Vertex AI Tensorboards. 
`[tuning-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/ai/tuning-jobs)`
     Manage Vertex AI tuning jobs. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha ai](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai)
    
    
    [gcloud beta ai](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai)
