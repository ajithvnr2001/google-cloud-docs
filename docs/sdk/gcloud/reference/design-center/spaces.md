#  gcloud design-center spaces Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud design-center spaces - manage space resources 
SYNOPSIS
    

`gcloud design-center spaces` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage space resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[application-templates](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates)`
     Manage application template resources. 
`[applications](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/applications)`
     Manage application resources. 
`[catalogs](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/catalogs)`
     Manage catalog resources. 
`[shared-templates](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/shared-templates)`
     Manage shared template resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/create)`
     Create a space. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/delete)`
     Delete a space. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/describe)`
     Describe a space. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/get-iam-policy)`
     Get the IAM policy for a Design Center space. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/list)`
     List spaces. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/set-iam-policy)`
     Set the IAM policy for a Design Center space as defined in a JSON/YAML file. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/test-iam-permissions)`
     Test IAM permissions for a Design Center space. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/update)`
     Update a space. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha design-center spaces](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/design-center/spaces)
