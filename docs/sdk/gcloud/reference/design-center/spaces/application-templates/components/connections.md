NAME
    

gcloud design-center spaces application-templates components connections - manage connection resources 
SYNOPSIS
    

`gcloud design-center spaces application-templates components connections` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage connection resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates/components/connections/create)`
     Create a connection. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates/components/connections/delete)`
     Delete a connection. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates/components/connections/describe)`
     Describe a connection. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates/components/connections/list)`
     List connections. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/application-templates/components/connections/update)`
     Update a connection. 
NOTES
     This variant is also available:
