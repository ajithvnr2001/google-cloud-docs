NAME
    

gcloud design-center spaces catalogs templates revisions - manage catalog template revision resources 
SYNOPSIS
    

`gcloud design-center spaces catalogs templates revisions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage catalog template revision resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/catalogs/templates/revisions/create)`
     Create a new catalog template revision. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/catalogs/templates/revisions/delete)`
     Delete a catalog template revision. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/catalogs/templates/revisions/describe)`
     Describe a catalog template revision. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/design-center/spaces/catalogs/templates/revisions/list)`
     List catalog template revisions.
