NAME
    

gcloud infra-manager - manage Infra Manager resources 
SYNOPSIS
    

`gcloud infra-manager` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Infra Manager resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[automigrationconfig](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/automigrationconfig)`
     Manage auto migration config resources. 
`[deployments](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/deployments)`
     Manage Deployment resources. 
`[previews](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/previews)`
     Manage Preview resources. 
`[resource-changes](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/resource-changes)`
     Manage resource change resources. 
`[resource-drifts](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/resource-drifts)`
     Manage resource drift resources. 
`[resources](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/resources)`
     List or describe resources under a Revision. 
`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/revisions)`
     Manage Revision resources. 
`[terraform-versions](https://docs.cloud.google.com/sdk/gcloud/reference/infra-manager/terraform-versions)`
     Manage Terraform version resources. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha infra-manager](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/infra-manager)
