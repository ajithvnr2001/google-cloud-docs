#  gcloud healthcare datasets Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud healthcare datasets - manage Cloud Healthcare API datasets 
SYNOPSIS
    

`gcloud healthcare datasets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Healthcare API datasets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/add-iam-policy-binding)`
     Add an IAM policy binding to a Cloud Healthcare API dataset. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/create)`
     Create a Cloud Healthcare API dataset. 
`[deidentify](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/deidentify)`
     Create a new Cloud Healthcare API dataset containing de-identified data from the source dataset. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/delete)`
     Delete a Cloud Healthcare API dataset. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/describe)`
     Describe a Cloud Healthcare API dataset. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/get-iam-policy)`
     Retrieve the IAM policy for a Cloud Healthcare API dataset. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/list)`
     List Cloud Healthcare API datasets. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/remove-iam-policy-binding)`
     Remove an IAM policy binding to a Cloud Healthcare API dataset. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/set-iam-policy)`
     Set the IAM policy for a Cloud Healthcare API dataset. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/datasets/update)`
     Update a Cloud Healthcare API dataset. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha healthcare datasets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/datasets)
    
    
    [gcloud beta healthcare datasets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/datasets)
