NAME
    

gcloud network-connectivity spokes - manage Network Connectivity Center spokes 
SYNOPSIS
    

`gcloud network-connectivity spokes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Network Connectivity Center spokes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[gateways](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/gateways)`
     Manage Gateway spokes. 
`[linked-interconnect-attachments](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/linked-interconnect-attachments)`
     Manage VLAN attachment spokes. 
`[linked-producer-vpc-network](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/linked-producer-vpc-network)`
     Manage Producer VPC spokes. 
`[linked-router-appliances](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/linked-router-appliances)`
     Manage Router appliance spokes. 
`[linked-vpc-network](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/linked-vpc-network)`
     Manage VPC spokes. 
`[linked-vpn-tunnels](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/linked-vpn-tunnels)`
     Manage VPN spokes. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/delete)`
     Delete a spoke. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/describe)`
     Describe a spoke. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/spokes/list)`
     List spokes. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha network-connectivity spokes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/spokes)
