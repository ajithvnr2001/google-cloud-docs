NAME
    

gcloud network-connectivity transports remote-profiles - manage Network Connectivity Center remote transport profiles 
SYNOPSIS
    

`gcloud network-connectivity transports remote-profiles` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Network Connectivity Center remote transport profiles. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/transports/remote-profiles/describe)`
     Describe a remote transport profile. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/transports/remote-profiles/list)`
     List remote transport profiles. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta network-connectivity transports remote-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/transports/remote-profiles)
