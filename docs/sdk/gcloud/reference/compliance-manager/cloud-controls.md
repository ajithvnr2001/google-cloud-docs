NAME
    

gcloud compliance-manager cloud-controls - manage Cloud Control resources 
SYNOPSIS
    

`gcloud compliance-manager cloud-controls` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Control resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/cloud-controls/create)`
     Create a cloud control. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/cloud-controls/delete)`
     Delete a cloud control. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/cloud-controls/describe)`
     Get a cloud control. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/cloud-controls/list)`
     List cloud controls.
