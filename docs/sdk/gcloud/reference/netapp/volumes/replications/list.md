NAME
    

gcloud netapp volumes replications list - list Cloud NetApp Volume Replications 
SYNOPSIS
    

`gcloud netapp volumes replications list` [`--location`=`LOCATION`] [`--volume`=`VOLUME`] [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Lists Cloud NetApp Volume Replications. 
EXAMPLES
     The following command lists all Replications in the given location and volume: 
    
    
    gcloud netapp volumes replications list --location=us-central1 --volume=vol1
