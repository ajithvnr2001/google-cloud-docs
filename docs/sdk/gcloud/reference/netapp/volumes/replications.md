NAME
    

gcloud netapp volumes replications - create and manage Cloud NetApp Volume Replications 
SYNOPSIS
    

`gcloud netapp volumes replications` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Cloud NetApp Volume Replications. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/create)`
     Create a Cloud NetApp Volume Replication. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/delete)`
     Delete a Cloud NetApp Volume Replication. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/describe)`
     Describe a Cloud NetApp Volume Replication. 
`[establish-peering](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/establish-peering)`
     Establish peering for Hybrid replication. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/list)`
     List Cloud NetApp Volume Replications. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/resume)`
     Resume a Cloud NetApp Volume Replication. 
`[reverse](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/reverse)`
     Reverse a Cloud NetApp Volume Replication's direction. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/stop)`
     Stop a Cloud NetApp Volume Replication. 
`[sync](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/sync)`
     Sync a Cloud NetApp Volume Replication. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications/update)`
     Update a Cloud NetApp Volume Replication. 
NOTES
     These variants are also available:
