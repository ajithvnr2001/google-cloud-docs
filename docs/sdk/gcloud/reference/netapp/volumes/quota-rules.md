NAME
    

gcloud netapp volumes quota-rules - create and manage Cloud NetApp Volume QuotaRules 
SYNOPSIS
    

`gcloud netapp volumes quota-rules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Cloud NetApp Volume QuotaRules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/quota-rules/create)`
     Create a Cloud NetApp Volume Quota Rule. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/quota-rules/delete)`
     Delete a Cloud NetApp Volume QuotaRule. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/quota-rules/describe)`
     Describe a Cloud NetApp Volume Quota Rule. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/quota-rules/list)`
     List Cloud NetApp Volume QuotaRules. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/quota-rules/update)`
     Update a Cloud NetApp Volume QuotaRule. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta netapp volumes quota-rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/volumes/quota-rules)
