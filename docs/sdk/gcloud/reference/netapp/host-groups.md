NAME
    

gcloud netapp host-groups - create and manage Cloud NetApp Host Groups 
SYNOPSIS
    

`gcloud netapp host-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Cloud NetApp Host Groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/host-groups/create)`
     Create a Cloud NetApp Host Group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/host-groups/delete)`
     Delete a Cloud NetApp Host Group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/host-groups/describe)`
     Describe a Cloud NetApp Host Group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/host-groups/list)`
     List Cloud NetApp Host Groups. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/host-groups/update)`
     Update a Cloud NetApp Host Group. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha netapp host-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/host-groups)
