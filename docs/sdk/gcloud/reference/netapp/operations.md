NAME
    

gcloud netapp operations - read and manage Cloud NetApp Files Operations 
SYNOPSIS
    

`gcloud netapp operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Read and manage Cloud NetApp Files Operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/operations/describe)`
     Describe a Cloud NetApp Files operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/operations/list)`
     List Cloud NetApp Files operations. 
NOTES
     These variants are also available:
