NAME
    

gcloud netapp storage-pools - create and manage Cloud NetApp Storage Pools 
SYNOPSIS
    

`gcloud netapp storage-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Cloud NetApp Storage Pools. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/create)`
     Create a Cloud NetApp Storage Pool. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/delete)`
     Delete a Cloud NetApp Storage Pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/describe)`
     Show metadata for a Cloud NetApp Storage Pool. 
`[execute](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/execute)`
     Execute an ONTAP CLI command. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/list)`
     List Cloud NetApp Storage Pools. 
`[list-backup-configs](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/list-backup-configs)`
     List backup configurations for all volumes in an ONTAP-mode Storage Pool. 
`[restore-volume](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/restore-volume)`
     Restore a backup to a volume in a specified ONTAP-mode Storage Pool. 
`[switch](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/switch)`
     Switch a Regional Cloud NetApp Flex Storage Pool zone. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/update)`
     Update a Cloud NetApp Storage Pool. 
`[update-backup-config](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/update-backup-config)`
     Update backup config of a volume in an ONTAP-mode Storage Pool. 
`[validate-directory-service](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/storage-pools/validate-directory-service)`
     Validate directory service for a Cloud Netapp storage pool. 
NOTES
     These variants are also available:
