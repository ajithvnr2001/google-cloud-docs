NAME
    

gcloud netapp volumes - create and manage Cloud NetApp Volumes 
SYNOPSIS
    

`gcloud netapp volumes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Cloud NetApp Volumes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[quota-rules](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/quota-rules)`
     Create and manage Cloud NetApp Volume QuotaRules. 
`[replications](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/replications)`
     Create and manage Cloud NetApp Volume Replications. 
`[snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/snapshots)`
     Create and manage Cloud NetApp Volume Snapshots. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/create)`
     Create a Cloud NetApp Volume. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/delete)`
     Delete a Cloud NetApp Volume. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/describe)`
     Show metadata for a Cloud NetApp Volume. 
`[establish-peering](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/establish-peering)`
     Establish peering for Cache Volumes. 
`[get-split-status](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/get-split-status)`
     Retrieves the split status of a Cloud NetApp clone volume. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/list)`
     List Cloud NetApp Volumes. 
`[restore-backup-files](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/restore-backup-files)`
     Restore specific files from a backup to a Volume. 
`[revert](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/revert)`
     Revert a Cloud NetApp Volume back to a specified Snapshot. 
`[start-split](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/start-split)`
     Starts splitting a Cloud NetApp clone volume from its source volume. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/volumes/update)`
     Update a Cloud NetApp Volume. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha netapp volumes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/volumes)
    
    
    [gcloud beta netapp volumes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/volumes)
