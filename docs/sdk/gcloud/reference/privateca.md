NAME
    

gcloud privateca - manage private Certificate Authorities on Google Cloud 
SYNOPSIS
    

`gcloud privateca` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     The privateca command group lets you create and manage private certificate authorities and certificates. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[certificates](https://docs.cloud.google.com/sdk/gcloud/reference/privateca/certificates)`
     Manage certificates. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/privateca/locations)`
     Manage locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/privateca/operations)`
     Manage operations. 
`[pools](https://docs.cloud.google.com/sdk/gcloud/reference/privateca/pools)`
     Manage CA pools. 
`[roots](https://docs.cloud.google.com/sdk/gcloud/reference/privateca/roots)`
     Manage root certificate authorities. 
`[subordinates](https://docs.cloud.google.com/sdk/gcloud/reference/privateca/subordinates)`
     Manage subordinate certificate authorities. 
`[templates](https://docs.cloud.google.com/sdk/gcloud/reference/privateca/templates)`
     Manage certificate templates.
