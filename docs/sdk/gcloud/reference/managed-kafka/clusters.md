NAME
    

gcloud managed-kafka clusters - administer Managed Service for Apache Kafka clusters 
SYNOPSIS
    

`gcloud managed-kafka clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Administer Managed Service for Apache Kafka clusters. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/clusters/create)`
     Create a Managed Service for Apache Kafka cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/clusters/delete)`
     Delete a Managed Service for Apache Kafka cluster. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/clusters/describe)`
     Describe a Managed Service for Apache Kafka cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/clusters/list)`
     List all Managed Service for Apache Kafka clusters in a given location. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/clusters/update)`
     Update a Managed Service for Apache Kafka cluster. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha managed-kafka clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/clusters)
    
    
    [gcloud beta managed-kafka clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/clusters)
