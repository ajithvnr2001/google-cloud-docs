NAME
    

gcloud audit-manager audit-schedules - command group for Audit Manager Audit Schedules 
SYNOPSIS
    

`gcloud audit-manager audit-schedules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Command group for Audit Manager Audit Schedules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/audit-manager/audit-schedules/create)`
     Create Audit Schedule. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/audit-manager/audit-schedules/list)`
     List Audit Schedules. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/audit-manager/audit-schedules/update)`
     Update Audit Schedule. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha audit-manager audit-schedules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/audit-manager/audit-schedules)
