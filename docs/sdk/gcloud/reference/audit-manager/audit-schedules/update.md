NAME
    

gcloud audit-manager audit-schedules update - update Audit Schedule 
SYNOPSIS
    

`gcloud audit-manager audit-schedules update` `AUDIT_SCHEDULE` `--state`=`STATE` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Update an Audit Schedule state. 
EXAMPLES
     To pause an Audit Schedule, run: 
    
    
    gcloud audit-manager audit-schedules update projects/123/locations/us-central1/auditSchedules/my-schedule --state=paused

POSITIONAL ARGUMENTS
    

`AUDIT_SCHEDULE`
     Full resource name of the audit schedule. 
REQUIRED FLAGS
    

`--state`=`STATE`
     State to update the audit schedule to. `STATE` must be one of: `active`, `paused`, `deleted`.
