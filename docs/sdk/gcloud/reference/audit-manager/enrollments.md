NAME
    

gcloud audit-manager enrollments - command group for Audit Manager Enrollments 
SYNOPSIS
    

`gcloud audit-manager enrollments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Command group for Audit Manager Enrollments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add](https://docs.cloud.google.com/sdk/gcloud/reference/audit-manager/enrollments/add)`
     Enroll a new scope. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha audit-manager enrollments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/audit-manager/enrollments)
