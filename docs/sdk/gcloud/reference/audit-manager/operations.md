NAME
    

gcloud audit-manager operations - check audit operation status 
SYNOPSIS
    

`gcloud audit-manager operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Check audit operation status. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/audit-manager/operations/describe)`
     Describe Audit operation. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha audit-manager operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/audit-manager/operations)
