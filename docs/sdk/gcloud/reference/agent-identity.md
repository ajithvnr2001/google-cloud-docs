NAME
    

gcloud agent-identity - manage Agent Identity resources 
SYNOPSIS
    

`gcloud agent-identity` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Agent Identity resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[access-summaries](https://docs.cloud.google.com/sdk/gcloud/reference/agent-identity/access-summaries)`
     Manage Access Summary resources. 
`[auth-providers](https://docs.cloud.google.com/sdk/gcloud/reference/agent-identity/auth-providers)`
     Manage Auth Provider resources. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha agent-identity](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity)
    
    
    [gcloud beta agent-identity](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity)
