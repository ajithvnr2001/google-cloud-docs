NAME
    

gcloud biglake iceberg catalogs - manage BigLake Iceberg REST catalogs 
SYNOPSIS
    

`gcloud biglake iceberg catalogs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage BigLake Iceberg REST catalogs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/create)`
     Create a BigLake Iceberg REST catalog. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/delete)`
     Delete a BigLake Iceberg REST catalog. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/describe)`
     Describe a BigLake Iceberg REST catalog. 
`[failover](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/failover)`
     Failover a BigLake Iceberg REST catalog. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/get-iam-policy)`
     Get the IAM policy for a BigLake Iceberg REST catalog. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/list)`
     List BigLake Iceberg REST catalogs. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/set-iam-policy)`
     Set the IAM policy for a BigLake Iceberg REST catalog. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/catalogs/update)`
     Update a BigLake Iceberg REST catalog.
