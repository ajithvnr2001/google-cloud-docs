NAME
    

gcloud deploy automations - manages Automations resources for Cloud Deploy 
SYNOPSIS
    

`gcloud deploy automations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manages Automations resources for Cloud Deploy. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/automations/delete)`
     Deletes a Cloud Deploy Automation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/automations/describe)`
     Show details for an Automation. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/automations/export)`
     Returns the YAML definition of the specified Automation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/automations/list)`
     List the Automations. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha deploy automations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deploy/automations)
    
    
    [gcloud beta deploy automations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/automations)
