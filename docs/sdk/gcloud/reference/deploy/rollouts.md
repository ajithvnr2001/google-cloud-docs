NAME
    

gcloud deploy rollouts - create and manage Rollout resources for Cloud Deploy 
SYNOPSIS
    

`gcloud deploy rollouts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Rollout resources for Cloud Deploy. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[advance](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/advance)`
     Advances a rollout. 
`[approve](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/approve)`
     Approves a rollout having an Approval state of "Required". 
`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/cancel)`
     Cancel a Rollout. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/describe)`
     Show details for a rollout. 
`[ignore-job](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/ignore-job)`
     Ignores a specified job and phase combination on a rollout. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/list)`
     List the rollouts. 
`[reject](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/reject)`
     Rejects a rollout having an Approval state of "Required". 
`[retry-job](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/rollouts/retry-job)`
     Retries a specified job, phase combination on a rollout. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha deploy rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deploy/rollouts)
    
    
    [gcloud beta deploy rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/rollouts)
