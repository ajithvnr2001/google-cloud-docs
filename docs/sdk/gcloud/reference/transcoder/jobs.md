NAME
    

gcloud transcoder jobs - manage Cloud Transcoder jobs 
SYNOPSIS
    

`gcloud transcoder jobs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Transcoder jobs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/transcoder/jobs/create)`
     Create Transcoder jobs. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/transcoder/jobs/delete)`
     Delete transcoder jobs. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/transcoder/jobs/describe)`
     Describe transcoder jobs. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/transcoder/jobs/list)`
     List transcoder jobs.
