NAME
    

gcloud cluster-director operations - manage Operation resources 
SYNOPSIS
    

`gcloud cluster-director operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Operation resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director/operations/describe)`
     Describe operations.
