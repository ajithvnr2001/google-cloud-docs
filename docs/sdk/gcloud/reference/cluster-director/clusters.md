NAME
    

gcloud cluster-director clusters - deploy and manage large-scale AI and high-performance computing clusters 
SYNOPSIS
    

`gcloud cluster-director clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Cluster Director is a unified management plane that simplifies deploying and running large-scale AI and high-performance computing (HPC) clusters. 

The service automates complex infrastructure setup by integrating compute, networking, and storage to maximize performance and minimize downtimes. 

If you have your own configuration already: 

  * Use `--config` to provide a complete JSON definition 



To start from a pre-configuration: 

  * Use `--quickstart-cluster` to create and connect a managed Slurm cluster with basic defaults 
  * Use `--reference-architecture` to choose from workload-optimized templates 



To fully customize: 

  * Run the 'clusters create' command for the most granular configuration options 

Learn more at <https://docs.cloud.google.com/cluster-director/>
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director/clusters/create)`
     Creates a Cluster Director resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director/clusters/delete)`
     Deletes a Cluster Director resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director/clusters/describe)`
     Gets details of a Cluster Director resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director/clusters/list)`
     List Cluster Director resources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director/clusters/update)`
     Updates a Cluster Director resource.
