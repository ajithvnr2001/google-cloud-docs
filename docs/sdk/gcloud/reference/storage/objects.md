#  gcloud storage objects Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud storage objects - manage Cloud Storage objects 
SYNOPSIS
    

`gcloud storage objects` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Storage objects. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[compose](https://docs.cloud.google.com/sdk/gcloud/reference/storage/objects/compose)`
     Concatenate a sequence of objects into a new composite object. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/storage/objects/describe)`
     Describe a Cloud Storage object. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/storage/objects/list)`
     Lists Cloud Storage objects. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/storage/objects/update)`
     Update Cloud Storage objects. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha storage objects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/objects)
