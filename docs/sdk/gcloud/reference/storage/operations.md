NAME
    

gcloud storage operations - manage storage operations 
SYNOPSIS
    

`gcloud storage operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage storage operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/storage/operations/cancel)`
     Cancel a storage operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/storage/operations/describe)`
     Get configuration and latest storage operation details. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/storage/operations/list)`
     List storage operations. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha storage operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/operations)
