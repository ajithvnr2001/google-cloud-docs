#  gcloud storage insights dataset-configs Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud storage insights dataset-configs - manage Cloud Storage Insights dataset configurations 
SYNOPSIS
    

`gcloud storage insights dataset-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Storage Insights dataset configurations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs/create)`
     Create a new dataset config for Insights. 
`[create-link](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs/create-link)`
     Create a link to a BigQuery instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs/delete)`
     Delete dataset config for Insights. 
`[delete-link](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs/delete-link)`
     Delete a link to a BigQuery instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs/describe)`
     Describe dataset config for Insights. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs/list)`
     List returns all the Insights dataset configs for given location. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs/update)`
     Updates a dataset config for Insights. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha storage insights dataset-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/insights/dataset-configs)
