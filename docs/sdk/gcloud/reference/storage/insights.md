NAME
    

gcloud storage insights - manage Cloud Storage inventory reports 
SYNOPSIS
    

`gcloud storage insights` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Storage inventory reports. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[dataset-configs](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/dataset-configs)`
     Manage Cloud Storage Insights dataset configurations. 
`[inventory-reports](https://docs.cloud.google.com/sdk/gcloud/reference/storage/insights/inventory-reports)`
     Manage Cloud Storage inventory report configurations. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha storage insights](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/insights)
