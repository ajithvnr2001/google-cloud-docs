#  gcloud storage buckets notifications Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud storage buckets notifications - manage Cloud Storage bucket notifications 
SYNOPSIS
    

`gcloud storage buckets notifications` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Storage bucket notifications. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/storage/buckets/notifications/create)`
     Create a notification configuration on a bucket. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/storage/buckets/notifications/delete)`
     Delete notification configurations from a bucket. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/storage/buckets/notifications/describe)`
     Show metadata for a notification configuration. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/storage/buckets/notifications/list)`
     List the notification configurations belonging to a given bucket. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha storage buckets notifications](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/storage/buckets/notifications)
