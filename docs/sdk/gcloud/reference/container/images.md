NAME
    

gcloud container images - list and manipulate Google Container Registry images 
SYNOPSIS
    

`gcloud container images` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     List and manipulate Google Container Registry images. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-tag](https://docs.cloud.google.com/sdk/gcloud/reference/container/images/add-tag)`
     Adds tags to existing image. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/container/images/delete)`
     Delete existing images. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/images/describe)`
     Lists information about the specified image. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/images/list)`
     List existing images. 
`[list-gcr-usage](https://docs.cloud.google.com/sdk/gcloud/reference/container/images/list-gcr-usage)`
     List Container Registry usage. 
`[list-tags](https://docs.cloud.google.com/sdk/gcloud/reference/container/images/list-tags)`
     List tags and digests for the specified image. 
`[untag](https://docs.cloud.google.com/sdk/gcloud/reference/container/images/untag)`
     Remove existing image tags. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha container images](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/images)
    
    
    [gcloud beta container images](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/images)
