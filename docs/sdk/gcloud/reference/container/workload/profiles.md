NAME
    

gcloud container workload profiles - quickstart engine for GKE workload optimization 
SYNOPSIS
    

`gcloud container workload profiles` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Quickstart engine for GKE workload optimization. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[manifests](https://docs.cloud.google.com/sdk/gcloud/reference/container/workload/profiles/manifests)`
     Generate optimized Kubernetes manifests.
