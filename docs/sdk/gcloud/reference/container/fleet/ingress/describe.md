NAME
    

gcloud container fleet ingress describe - describe the status of Multi-cluster Ingress Feature resource 
SYNOPSIS
    

`gcloud container fleet ingress describe` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     This command describes the status of Multi-cluster Ingress Feature resource in fleet. 
EXAMPLES
     To describe the Ingress Feature, run: 
    
    
    gcloud container fleet ingress describe
