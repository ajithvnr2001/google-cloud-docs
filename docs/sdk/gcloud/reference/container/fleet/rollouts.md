NAME
    

gcloud container fleet rollouts - manage rollouts 
SYNOPSIS
    

`gcloud container fleet rollouts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage rollouts. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/rollouts/cancel)`
     Cancel a rollout. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/rollouts/delete)`
     Delete a rollout resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/rollouts/describe)`
     Describe a fleet rollout. 
`[force-complete-stage](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/rollouts/force-complete-stage)`
     Force-complete a rollout stage. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/rollouts/list)`
     List all fleet rollouts. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/rollouts/pause)`
     Pause a rollout resource. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/rollouts/resume)`
     Resume a rollout resource. 
NOTES
     These variants are also available:
