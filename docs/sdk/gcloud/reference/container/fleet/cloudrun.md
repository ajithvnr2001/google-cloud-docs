NAME
    

gcloud container fleet cloudrun - manage the CloudRun feature 
SYNOPSIS
    

`gcloud container fleet cloudrun` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage the CloudRun feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[apply](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/cloudrun/apply)`
     Deploy or update the CloudRun feature. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/cloudrun/describe)`
     Describe the status of the CloudRun feature. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/cloudrun/disable)`
     Disable the CloudRun feature. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/cloudrun/enable)`
     Enable the CloudRun feature. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha container fleet cloudrun](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/cloudrun)
