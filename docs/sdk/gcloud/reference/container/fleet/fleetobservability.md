NAME
    

gcloud container fleet fleetobservability - manage Fleet Observability Feature 
SYNOPSIS
    

`gcloud container fleet fleetobservability` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Fleet Observability Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/fleetobservability/describe)`
     Describes the status of the Fleet Observability Feature resource. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/fleetobservability/disable)`
     Disables the Fleet Observability Feature. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/fleetobservability/enable)`
     Enables the Fleet Observability Feature. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/fleetobservability/update)`
     Updates the Fleet Observability Feature resource.
