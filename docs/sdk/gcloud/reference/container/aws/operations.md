NAME
    

gcloud container aws operations - manage Anthos Multi-Cloud long running operations for AWS 
SYNOPSIS
    

`gcloud container aws operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(DEPRECATED)` Manage Anthos Multi-Cloud long running operations for AWS. 

This command is deprecated. See <https://cloud.google.com/kubernetes-engine/multi-cloud/docs/aws/deprecations/deprecation-announcement> for more details. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/container/aws/operations/cancel)`
     `(DEPRECATED)` Cancel an operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/aws/operations/describe)`
     `(DEPRECATED)` Describe an operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/aws/operations/list)`
     `(DEPRECATED)` List operations. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/container/aws/operations/wait)`
     `(DEPRECATED)` Wait for an operation to complete. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha container aws operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/aws/operations)
