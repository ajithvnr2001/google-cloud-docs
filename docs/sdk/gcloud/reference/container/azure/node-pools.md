NAME
    

gcloud container azure node-pools - create and manage node pools in an Anthos cluster on Azure 
SYNOPSIS
    

`gcloud container azure node-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(DEPRECATED)` Create and manage node pools in an Anthos cluster on Azure. 

This command is deprecated. See <https://cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/deprecations/deprecation-announcement> for more details. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/node-pools/create)`
     `(DEPRECATED)` Create a node pool in an Anthos cluster on Azure. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/node-pools/delete)`
     `(DEPRECATED)` Delete a node pool in an Anthos cluster on Azure. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/node-pools/describe)`
     `(DEPRECATED)` Describe a node pool in an Anthos cluster on Azure. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/node-pools/list)`
     `(DEPRECATED)` List node pools in an Anthos cluster on Azure. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/node-pools/update)`
     `(DEPRECATED)` Update a node pool in an Anthos cluster on Azure. 
NOTES
     This variant is also available:
