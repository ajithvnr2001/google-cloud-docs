NAME
    

gcloud container azure clusters - create and manage Anthos clusters on Azure 
SYNOPSIS
    

`gcloud container azure clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(DEPRECATED)` Create and manage Anthos clusters on Azure. 

This command is deprecated. See <https://cloud.google.com/kubernetes-engine/multi-cloud/docs/azure/deprecations/deprecation-announcement> for more details. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/clusters/create)`
     `(DEPRECATED)` Create an Anthos cluster on Azure. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/clusters/delete)`
     `(DEPRECATED)` Delete an Anthos cluster on Azure. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/clusters/describe)`
     `(DEPRECATED)` Describe an Anthos cluster on Azure. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/clusters/get-credentials)`
     `(DEPRECATED)` Get credentials of an Anthos cluster on Azure. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/clusters/list)`
     `(DEPRECATED)` List Anthos clusters on Azure. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/container/azure/clusters/update)`
     `(DEPRECATED)` Update an Anthos cluster on Azure. 
NOTES
     This variant is also available:
