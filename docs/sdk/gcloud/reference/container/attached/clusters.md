NAME
    

gcloud container attached clusters - create and manage Attached clusters 
SYNOPSIS
    

`gcloud container attached clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Attached clusters. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/delete)`
     Delete a registered AttachedCluster resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/describe)`
     Describe an Attached cluster. 
`[generate-install-manifest](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/generate-install-manifest)`
     Generate Install Manifest for an Attached cluster. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/get-credentials)`
     `(DEPRECATED)` Get credentials of an Attached cluster. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/import)`
     Import fleet membership for an Attached cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/list)`
     List Attached clusters. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/register)`
     Register an Attached cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/container/attached/clusters/update)`
     Update an Attached cluster. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha container attached clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/attached/clusters)
