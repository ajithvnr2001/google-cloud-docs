NAME
    

gcloud container binauthz attestations - create and manage Google Binary Authorization attestations 
SYNOPSIS
    

`gcloud container binauthz attestations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Google Binary Authorization attestations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/container/binauthz/attestations/create)`
     Create a Binary Authorization attestation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/binauthz/attestations/list)`
     List Binary Authorization attestations. 
NOTES
