NAME
    

gcloud container hub config-management - use the Config Management feature 
SYNOPSIS
    

`gcloud container hub config-management` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage [Config Sync](https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/how-to/installing-config-sync) using the Config Management feature. 

To manage Policy Controller, use `[gcloud container fleet policycontroller](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/policycontroller)` instead. 

Hierarchy Controller is no longer available to install. If Hierarchy Controller is still configured, Config Sync upgrades are blocked. To upgrade Config Sync, disable Hierarchy Controller following <https://docs.cloud.google.com/kubernetes-engine/config-sync/docs/how-to/migrate-hierarchy-controller>. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/config-management/describe)`
     Describe the Config Management feature. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/config-management/disable)`
     Disable the Config Management feature. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha container hub config-management](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/config-management)
    
    
    [gcloud beta container hub config-management](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/config-management)
