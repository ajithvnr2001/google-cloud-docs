#  gcloud container hub policycontroller content templates Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud container hub policycontroller content templates - manage Policy Controller content templates 
SYNOPSIS
    

`gcloud container hub policycontroller content templates` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Policy Controller content templates. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/policycontroller/content/templates/disable)`
     Disable template installation for Policy Controller content. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/policycontroller/content/templates/enable)`
     Installs the template library for Policy Controller. 
NOTES
