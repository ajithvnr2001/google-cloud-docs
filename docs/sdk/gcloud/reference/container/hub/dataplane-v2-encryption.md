NAME
    

gcloud container hub dataplane-v2-encryption - manage Dataplane V2 Encryption Feature 
SYNOPSIS
    

`gcloud container hub dataplane-v2-encryption` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplane V2 Encryption Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/dataplane-v2-encryption/describe)`
     Describes the status of the Dataplane V2 Encryption Feature resource. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/dataplane-v2-encryption/disable)`
     Disables the Dataplane V2 Encryption Feature. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/dataplane-v2-encryption/enable)`
     Enables the Dataplane V2 Encryption Feature.
