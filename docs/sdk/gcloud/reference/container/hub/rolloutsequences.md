NAME
    

gcloud container hub rolloutsequences - create and manage rollout sequences 
SYNOPSIS
    

`gcloud container hub rolloutsequences` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage rollout sequences. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/rolloutsequences/create)`
     Create a rollout sequence resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/rolloutsequences/delete)`
     Delete a rollout sequence resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/rolloutsequences/describe)`
     Describe a rollout sequence. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/rolloutsequences/list)`
     List all rollout sequences. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/rolloutsequences/update)`
     Update a rollout sequence resource. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/rolloutsequences/upgrade)`
     Upgrade the clusters in a rollout sequence resource. 
NOTES
     These variants are also available:
