NAME
    

gcloud container hub identity-service disable - disable Identity Service Feature 
SYNOPSIS
    

`gcloud container hub identity-service disable` [`--force`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     This command disables the Identity Service Feature in a fleet. 
EXAMPLES
     To disable the Identity Service Feature, run: 
    
    
    gcloud container hub identity-service disable

FLAGS
    

`--force`
     Force disablement. Bypasses any prompts for confirmation. When disabling the entire feature, proceeds even if the feature is in use. Might result in unexpected behavior.
