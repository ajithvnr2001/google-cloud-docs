NAME
    

gcloud artifacts go - manage Artifact Registry Go modules 
SYNOPSIS
    

`gcloud artifacts go` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Artifact Registry Go modules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[auth](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/go/auth)`
     Print authentication commands for the GOAUTH environment variable. 
`[upload](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/go/upload)`
     Upload a Go module to an artifact repository. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha artifacts go](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/artifacts/go)
