#  gcloud artifacts files Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud artifacts files - manage Artifact Registry files 
SYNOPSIS
    

`gcloud artifacts files` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
EXAMPLES
     To list all files in the current project and `artifacts/repository` and `artifacts/location` properties are set, run: 
    
    
    [gcloud artifacts files list](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/list)

To list files under repository my-repo in the current project and location, run: 
    
    
    [gcloud artifacts files list](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/list) --repository=my-repo

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/delete)`
     Delete an Artifact Registry file. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/describe)`
     Describe an Artifact Registry file. 
`[download](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/download)`
     Download an Artifact Registry file. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/list)`
     List Artifact Registry files. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/update)`
     Update annotations on an Artifact Registry file. 
`[upload](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files/upload)`
     Uploads files to Artifact Registry. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha artifacts files](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/artifacts/files)
    
    
    [gcloud beta artifacts files](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/files)
