NAME
    

gcloud filestore - create and manipulate Filestore resources 
SYNOPSIS
    

`gcloud filestore` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     The gcloud filestore command group lets you create, configure and manipulate Filestore instances. 

With Filestore, you can take advantage of Google Cloud Platform's scale, performance, and value to create and run managed file systems on Google infrastructure. 

More information on Filestore can be found here: <https://cloud.google.com/filestore/> and detailed documentation can be found here: <https://cloud.google.com/filestore/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/backups)`
     Create and manage Filestore backups. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/instances)`
     Create and manage Filestore instances. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/locations)`
     List locations where Filestore is available. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/operations)`
     Read and manipulate Filestore operations. 
`[regions](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/regions)`
     List regions where Filestore is available. 
`[zones](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/zones)`
     List zones where Filestore is available. 
NOTES
     These variants are also available:
