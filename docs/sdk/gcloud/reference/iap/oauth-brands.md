NAME
    

gcloud iap oauth-brands - manage IAP OAuth brands 
SYNOPSIS
    

`gcloud iap oauth-brands` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(DEPRECATED)` Manage IAP OAuth brands. 

This command is deprecated and will be non-functional after the IAP OAuth Admin APIs are turned down. Jan 19, 2026: Google will discontinue support for the IAP OAuth Admin APIs. New projects will not be able to use these APIs. March 19, 2026: The IAP OAuth Admin APIs will be permanently shut down. Access to this feature will no longer be available. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/iap/oauth-brands/create)`
     `(DEPRECATED)` Create a Cloud OAuth brand for the project. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/iap/oauth-brands/describe)`
     `(DEPRECATED)` Describe a Cloud OAuth brand. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/iap/oauth-brands/list)`
     `(DEPRECATED)` List Cloud OAuth brands in the project.
