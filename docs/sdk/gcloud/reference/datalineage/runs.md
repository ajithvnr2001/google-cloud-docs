NAME
    

gcloud datalineage runs - manage Data Lineage runs 
SYNOPSIS
    

`gcloud datalineage runs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for describing, listing, creating, and deleting Data Lineage runs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/runs/create)`
     Create a data lineage run. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/runs/delete)`
     Delete a Data Lineage run. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/runs/describe)`
     Describe a Data Lineage run. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/runs/list)`
     List Data Lineage runs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/runs/update)`
     Update a data lineage run. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha datalineage runs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/runs)
    
    
    [gcloud beta datalineage runs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datalineage/runs)
