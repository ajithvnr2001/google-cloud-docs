NAME
    

gcloud datalineage processes - manage Data Lineage processes 
SYNOPSIS
    

`gcloud datalineage processes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for describing, listing, creating, and deleting Data Lineage processes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/processes/create)`
     Create a Data Lineage process. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/processes/delete)`
     Delete a Data Lineage process. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/processes/describe)`
     Describe a Data Lineage process. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/processes/list)`
     List Data Lineage processes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/processes/update)`
     Update a data lineage process. 
NOTES
     These variants are also available:
