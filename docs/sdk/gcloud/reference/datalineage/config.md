NAME
    

gcloud datalineage config - manage Data Lineage configurations 
SYNOPSIS
    

`gcloud datalineage config` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for describing and updating Data Lineage configurations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/config/describe)`
     Describe Data Lineage configuration. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/datalineage/config/update)`
     Update Data Lineage configuration. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha datalineage config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/datalineage/config)
    
    
    [gcloud beta datalineage config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datalineage/config)
