NAME
    

gcloud eventarc - manage Eventarc resources 
SYNOPSIS
    

`gcloud eventarc` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Eventarc resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[audit-logs-provider](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/audit-logs-provider)`
     Explore provider serviceNames and methodNames for event type `google.cloud.audit.log.v1.written` in Eventarc. 
`[channel-connections](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/channel-connections)`
     Manage Eventarc channel connections. 
`[channels](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/channels)`
     Manage Eventarc channels. 
`[enrollments](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/enrollments)`
     Manage Eventarc enrollments. 
`[google-api-sources](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/google-api-sources)`
     Manage Eventarc Google API sources. 
`[google-channels](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/google-channels)`
     Manage Eventarc Google channels. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/locations)`
     Explore locations available for Eventarc. 
`[message-buses](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses)`
     Manage Eventarc message buses. 
`[pipelines](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/pipelines)`
     Manage Eventarc pipelines. 
`[providers](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/providers)`
     Explore event providers available in Eventarc. 
`[triggers](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/triggers)`
     Manage Eventarc triggers. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta eventarc](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc)
