NAME
    

gcloud memorystore instances token-auth-users auth-tokens - manage Auth Token resources 
SYNOPSIS
    

`gcloud memorystore instances token-auth-users auth-tokens` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Auth Token resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/auth-tokens/delete)`
     Delete authTokens. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/auth-tokens/describe)`
     Describe authTokens. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/auth-tokens/list)`
     List authTokens. 
NOTES
     These variants are also available:
