NAME
    

gcloud memorystore instances token-auth-users - manage Token Auth User resources 
SYNOPSIS
    

`gcloud memorystore instances token-auth-users` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Token Auth User resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[auth-tokens](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/auth-tokens)`
     Manage Auth Token resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create-auth-token](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/create-auth-token)`
     create an auth token for a token auth user. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/delete)`
     Delete tokenAuthUsers. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/describe)`
     Describe tokenAuthUsers. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances/token-auth-users/list)`
     List tokenAuthUsers. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha memorystore instances token-auth-users](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances/token-auth-users)
    
    
    [gcloud beta memorystore instances token-auth-users](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/token-auth-users)
