#  gcloud memorystore acl-policies Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud memorystore acl-policies - manage Acl Policy resources 
SYNOPSIS
    

`gcloud memorystore acl-policies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Acl Policy resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/revisions)`
     Manage Acl Policy Revision resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/create)`
     Create aclPolicies. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/delete)`
     Delete aclPolicies. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/describe)`
     Describe aclPolicies. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/list)`
     List aclPolicies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/update)`
     Update aclPolicies. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha memorystore acl-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/acl-policies)
    
    
    [gcloud beta memorystore acl-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/acl-policies)
