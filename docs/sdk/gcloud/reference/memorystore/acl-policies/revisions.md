NAME
    

gcloud memorystore acl-policies revisions - manage Acl Policy Revision resources 
SYNOPSIS
    

`gcloud memorystore acl-policies revisions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Acl Policy Revision resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/revisions/describe)`
     Describe aclPolicyRevisions. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/acl-policies/revisions/list)`
     List aclPolicyRevisions.
