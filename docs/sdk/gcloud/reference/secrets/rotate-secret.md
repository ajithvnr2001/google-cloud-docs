NAME
    

gcloud secrets rotate-secret - rotate a secret 
SYNOPSIS
    

`gcloud secrets rotate-secret` `SECRET` `--location`=`LOCATION` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Rotate a secret and add a new version. 
EXAMPLES
     Rotate a secret named `my-secret` in `us-central1`: 
    
    
    gcloud secrets rotate-secret my-secret --location=us-central1

POSITIONAL ARGUMENTS
    

Secret resource - The secret to rotate secret and add a new version. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `SECRET` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`SECRET`
     ID of the secret or fully qualified identifier for the secret. 

To set the `secret` attribute: 

  * provide the argument `SECRET` on the command line.
