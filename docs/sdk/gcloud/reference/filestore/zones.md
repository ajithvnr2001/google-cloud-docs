NAME
    

gcloud filestore zones - list zones where Filestore is available 
SYNOPSIS
    

`gcloud filestore zones` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     List zones where Filestore is available. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/zones/list)`
     List all Filestore zones. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha filestore zones](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/filestore/zones)
