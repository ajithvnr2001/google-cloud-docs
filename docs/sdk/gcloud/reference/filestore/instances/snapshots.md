#  gcloud filestore instances snapshots Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud filestore instances snapshots - create and manage Filestore snapshots 
SYNOPSIS
    

`gcloud filestore instances snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Create and manage Filestore snapshots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/instances/snapshots/create)`
     Create a Filestore snapshot. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/instances/snapshots/delete)`
     Delete a Filestore snapshot. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/instances/snapshots/describe)`
     Display information about a Filestore snapshot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/instances/snapshots/list)`
     List Filestore snapshots. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/instances/snapshots/update)`
     Update the description or labels of a Filestore snapshot. 
NOTES
     This variant is also available:
