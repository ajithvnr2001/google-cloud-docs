NAME
    

gcloud filestore operations - read and manipulate Filestore operations 
SYNOPSIS
    

`gcloud filestore operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Read and manipulate Filestore operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/operations/cancel)`
     Cancel a Filestore operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/operations/describe)`
     Describe a Filestore operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/filestore/operations/list)`
     List all Filestore operations. 
NOTES
     These variants are also available:
