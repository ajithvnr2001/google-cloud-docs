NAME
    

gcloud anthos config controller - manage Anthos Config Controller instances 
SYNOPSIS
    

`gcloud anthos config controller` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Anthos Config Controller Instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/anthos/config/controller/create)`
     Create Anthos Config Controller instances. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/anthos/config/controller/delete)`
     Delete Anthos Config Controller instances. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/anthos/config/controller/describe)`
     Describe Anthos Config Controller instances. 
`[get-config-connector-identity](https://docs.cloud.google.com/sdk/gcloud/reference/anthos/config/controller/get-config-connector-identity)`
     Fetch default Config Connector identity. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/anthos/config/controller/get-credentials)`
     Fetch credentials for a running Anthos Config Controller. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/anthos/config/controller/list)`
     List Anthos Config Controller instances. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha anthos config controller](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/anthos/config/controller)
