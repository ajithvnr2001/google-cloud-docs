NAME
    

gcloud scc findings - manage Cloud SCC (Security Command Center) findings 
SYNOPSIS
    

`gcloud scc findings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud SCC (Security Command Center) findings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[bulk-mute](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/bulk-mute)`
     Bulk mute Security Command Center findings based on a filter. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/create)`
     Create a Security Command Center finding. 
`[export-to-bigquery](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/export-to-bigquery)`
     Export Security Command Center findings to bigquery. 
`[group](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/group)`
     Filter an organization or source's findings and groups them by their specified properties. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/list)`
     List an organization or source's findings. 
`[list-marks](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/list-marks)`
     List a finding's security marks. 
`[set-mute](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/set-mute)`
     Update a Security Command Center finding's mute state. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/update)`
     Update a Security Command Center finding. 
`[update-marks](https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/update-marks)`
     Update Security Command Center finding's security marks. 
NOTES
     These variants are also available:
