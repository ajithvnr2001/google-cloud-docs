NAME
    

gcloud agent-registry - manage Agent Registry resources 
SYNOPSIS
    

`gcloud agent-registry` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Agent Registry resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[agents](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/agents)`
     Manage Agent resources. 
`[bindings](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/bindings)`
     Manage Binding resources. 
`[endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/endpoints)`
     Manage Endpoint resources. 
`[mcp-servers](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/mcp-servers)`
     Manage Mcp Server resources. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/operations)`
     Manage Operation resources. 
`[services](https://docs.cloud.google.com/sdk/gcloud/reference/agent-registry/services)`
     Manage Service resources. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha agent-registry](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-registry)
