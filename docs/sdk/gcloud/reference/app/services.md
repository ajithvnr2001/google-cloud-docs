NAME
    

gcloud app services - view and manage your App Engine services 
SYNOPSIS
    

`gcloud app services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     This set of commands can be used to view and manage your existing App Engine services. 

To create new deployments, use `[gcloud app deploy](https://docs.cloud.google.com/sdk/gcloud/reference/app/deploy)`. 

For more information on App Engine services, see: <https://cloud.google.com/appengine/docs/python/an-overview-of-app-engine>

EXAMPLES
     To list your deployed services, run: 
    
    
    [gcloud app services list](https://docs.cloud.google.com/sdk/gcloud/reference/app/services/list)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[browse](https://docs.cloud.google.com/sdk/gcloud/reference/app/services/browse)`
     Open the specified service(s) in a browser. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/app/services/delete)`
     Delete services in the current project. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/app/services/describe)`
     Display all data about an existing service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/app/services/list)`
     List your existing services. 
`[set-traffic](https://docs.cloud.google.com/sdk/gcloud/reference/app/services/set-traffic)`
     Set traffic splitting settings. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/app/services/update)`
     Update service-level settings. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta app services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/services)
