NAME
    

gcloud api-gateway api-configs - manage Cloud API Gateway API Configs 
SYNOPSIS
    

`gcloud api-gateway api-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud API Gateway API Configs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/api-gateway/api-configs/create)`
     Add a new config to an API. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/api-gateway/api-configs/delete)`
     Deletes a config from an API. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/api-gateway/api-configs/describe)`
     Show details about a specific API config. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/api-gateway/api-configs/list)`
     List configs for an API. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/api-gateway/api-configs/update)`
     Update an API Gateway API config. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha api-gateway api-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/api-gateway/api-configs)
    
    
    [gcloud beta api-gateway api-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/api-configs)
