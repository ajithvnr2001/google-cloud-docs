NAME
    

gcloud edge-cache origins - interact with and manage EdgeCacheOrigin resources 
SYNOPSIS
    

`gcloud edge-cache origins` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Interact with and manage EdgeCacheOrigin resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins/create)`
     Create an EdgeCacheOrigin resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins/delete)`
     Delete an EdgeCacheOrigin resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins/describe)`
     Show details about an EdgeCacheOrigin resource. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins/export)`
     Export an EdgeCacheOrigin resource. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins/import)`
     Import an EdgeCacheOrigin resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins/list)`
     List all EdgeCacheOrigin resources in a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cache/origins/update)`
     Update an EdgeCacheOrigin resource. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha edge-cache origins](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cache/origins)
