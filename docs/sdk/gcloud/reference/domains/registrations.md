NAME
    

gcloud domains registrations - manage Cloud Domains registrations 
SYNOPSIS
    

`gcloud domains registrations` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Cloud Domains registrations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[authorization-code](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/authorization-code)`
     Manage Cloud Domains registration's authorization code. 
`[configure](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/configure)`
     Configure Cloud Domains registrations' management, DNS or contact settings. 
`[google-domains-dns](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/google-domains-dns)`
     Manage deprecated Google Domains DNS configuration. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/operations)`
     Manage Cloud Domains operations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/delete)`
     Delete a Cloud Domains registration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/describe)`
     Describe an existing Cloud Domains registration. 
`[get-register-parameters](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/get-register-parameters)`
     Get register parameters (including availability) of a specific domain. 
`[initiate-push-transfer](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/initiate-push-transfer)`
     Initiates the push transfer process. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/list)`
     List Cloud Domains registrations. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/register)`
     Register a new domain. 
`[renew-domain](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/renew-domain)`
     Renew a recently expired Cloud Domains registration. 
`[search-domains](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/search-domains)`
     Search for available domains. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/update)`
     Update a Cloud Domains registration. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha domains registrations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations)
    
    
    [gcloud beta domains registrations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/registrations)
