NAME
    

gcloud edge-cloud projects - google Distributed Cloud Connected Project gcloud commands 
SYNOPSIS
    

`gcloud edge-cloud projects` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Google Distributed Cloud Connected Project gcloud commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/projects/describe)`
     Describe a Google Cloud Platform project enabled on Google Distributed Cloud zone. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/projects/enable)`
     Enables a Google Cloud Platform project on Google Distributed Cloud zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/projects/list)`
     List the Google Cloud Platform projects enabled on Google Distributed Cloud zone. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha edge-cloud projects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/projects)
