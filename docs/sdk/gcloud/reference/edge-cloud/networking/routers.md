NAME
    

gcloud edge-cloud networking routers - manage Distributed Cloud Edge Network routers 
SYNOPSIS
    

`gcloud edge-cloud networking routers` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Distributed Cloud Edge Network routers. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-bgp-peer](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/add-bgp-peer)`
     Add a BGP peer to a Distributed Cloud Edge Network router. 
`[add-interface](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/add-interface)`
     Add an interface to a Distributed Cloud Edge Network router. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/create)`
     Create a Distributed Cloud Edge Network router. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/delete)`
     Delete a Distributed Cloud Edge Network router. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/describe)`
     Show details about the Distributed Cloud Edge Network router. 
`[get-status](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/get-status)`
     Get the status of a specified Distributed Cloud Edge Network router. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/list)`
     List Distributed Cloud Edge Network routers. 
`[remove-bgp-peer](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/remove-bgp-peer)`
     Remove a BGP peer from a Distributed Cloud Edge Network router. 
`[remove-interface](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/networking/routers/remove-interface)`
     remove an interface on a Distributed Cloud Edge Network router. 
NOTES
     This variant is also available:
