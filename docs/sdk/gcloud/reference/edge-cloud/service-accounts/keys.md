NAME
    

gcloud edge-cloud service-accounts keys - google Distributed Cloud Service Account Keys gcloud commands 
SYNOPSIS
    

`gcloud edge-cloud service-accounts keys` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Google Distributed Cloud Service Account Keys gcloud commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/service-accounts/keys/create)`
     Create service account key for a service account on a Google Distributed Cloud zone. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/service-accounts/keys/describe)`
     Describe a service account key for a service account on a Google Distributed Cloud zone. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/service-accounts/keys/disable)`
     Disable a service account key for a service account on a Google Distributed Cloud zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/edge-cloud/service-accounts/keys/list)`
     List service account keys for a service account on a Google Distributed Cloud zone. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha edge-cloud service-accounts keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud/service-accounts/keys)
