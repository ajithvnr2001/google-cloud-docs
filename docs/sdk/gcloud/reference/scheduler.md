NAME
    

gcloud scheduler - manage Cloud Scheduler jobs and schedules 
SYNOPSIS
    

`gcloud scheduler` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Scheduler jobs and schedules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[cmek-config](https://docs.cloud.google.com/sdk/gcloud/reference/scheduler/cmek-config)`
     Manage CMEK configuration for Cloud Scheduler. 
`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/scheduler/jobs)`
     Manage Cloud Scheduler jobs. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/scheduler/locations)`
     Get information about Cloud Scheduler locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/scheduler/operations)`
     Get information about Cloud Scheduler operations. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha scheduler](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scheduler)
    
    
    [gcloud beta scheduler](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler)
