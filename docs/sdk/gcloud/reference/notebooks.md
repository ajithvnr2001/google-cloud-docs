#  gcloud notebooks Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud notebooks - notebooks Command Group 
SYNOPSIS
    

`gcloud notebooks` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Notebooks Command Group. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[environments](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/environments)`
     Notebooks Environments Command Group. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/instances)`
     Notebooks Instances command group. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/locations)`
     View locations available for a project. 
`[runtimes](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/runtimes)`
     Notebooks Runtimes command group. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha notebooks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/notebooks)
    
    
    [gcloud beta notebooks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/notebooks)
