NAME
    

gcloud preview compute interconnects groups - create or manipulate interconnect groups 
SYNOPSIS
    

`gcloud preview compute interconnects groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Create or manipulate interconnect groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-members](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/add-members)`
     `(PREVIEW)` Add member interconnects to a Compute Engine interconnect group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/create)`
     `(PREVIEW)` Create a Compute Engine interconnect group. 
`[create-members](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/create-members)`
     `(PREVIEW)` Create new member interconnects in a Compute Engine interconnect group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/delete)`
     `(PREVIEW)` Delete Compute Engine interconnect groups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/describe)`
     `(PREVIEW)` Describe a Compute Engine interconnect group. 
`[get-operational-status](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/get-operational-status)`
     `(PREVIEW)` Get the operational status of a Compute Engine interconnect group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/list)`
     `(PREVIEW)` List interconnect groups. 
`[remove-members](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/remove-members)`
     `(PREVIEW)` Remove member interconnects from a Compute Engine interconnect group. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine interconnect group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups/update)`
     `(PREVIEW)` Update a Compute Engine interconnect group. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
