NAME
    

gcloud preview compute interconnects wire-groups - create or manipulate wire groups 
SYNOPSIS
    

`gcloud preview compute interconnects wire-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Create or manipulate wire groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-endpoint](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/add-endpoint)`
     `(PREVIEW)` Add endpoint to a Compute Engine wire group. 
`[add-interconnect](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/add-interconnect)`
     `(PREVIEW)` Add interconnect to a Compute Engine wire group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/create)`
     `(PREVIEW)` Create a Compute Engine wire group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/delete)`
     `(PREVIEW)` Delete Compute Engine wire groups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/describe)`
     `(PREVIEW)` Describe a Compute Engine wire group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/list)`
     `(PREVIEW)` List Google Compute Engine wire groups. 
`[remove-endpoint](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/remove-endpoint)`
     `(PREVIEW)` Remove endpoint from a Compute Engine wire group. 
`[remove-interconnect](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/remove-interconnect)`
     `(PREVIEW)` Remove interconnect from a wire group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups/update)`
     `(PREVIEW)` Update a Compute Engine wire group. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
