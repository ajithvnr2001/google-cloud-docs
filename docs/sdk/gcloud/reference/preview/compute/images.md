NAME
    

gcloud preview compute images - list, create, and delete Compute Engine images 
SYNOPSIS
    

`gcloud preview compute images` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Create and manipulate Compute Engine images. 

For more information about images, see the [images documentation](https://cloud.google.com/compute/docs/images). 

See also: [Images API](https://cloud.google.com/compute/docs/reference/rest/v1/images). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/add-iam-policy-binding)`
     `(PREVIEW)` Add IAM policy binding to a Compute Engine image. 
`[add-labels](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/add-labels)`
     `(PREVIEW)` Add labels to Google Compute Engine images. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/create)`
     `(PREVIEW)` Create Compute Engine images. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/delete)`
     `(PREVIEW)` Delete Compute Engine images. 
`[deprecate](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/deprecate)`
     `(PREVIEW)` Manage deprecation status of Compute Engine images. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/describe)`
     `(PREVIEW)` Describe a Compute Engine image. 
`[describe-from-family](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/describe-from-family)`
     `(PREVIEW)` Describe the latest image from an image family. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/export)`
     `(PREVIEW)` Export a Compute Engine image. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/get-iam-policy)`
     `(PREVIEW)` Get the IAM policy for a Compute Engine image. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/import)`
     `(PREVIEW)` `(DEPRECATED)` Import an image into Compute Engine. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/list)`
     `(PREVIEW)` List Google Compute Engine images. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/remove-iam-policy-binding)`
     `(PREVIEW)` Remove IAM policy binding from a Compute Engine image. 
`[remove-labels](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/remove-labels)`
     `(PREVIEW)` Remove labels from Google Compute Engine images. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine image. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine image. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/images/update)`
     `(PREVIEW)` Update a Compute Engine image. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
