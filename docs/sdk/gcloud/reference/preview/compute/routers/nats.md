NAME
    

gcloud preview compute routers nats - list, create, describe, and delete Cloud NAT 
SYNOPSIS
    

`gcloud preview compute routers nats` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` List, create, describe, and delete Cloud NAT. 

For more information about Cloud NAT, see the [Cloud NAT documentation](https://cloud.google.com/nat/docs/using-nat). 

See also: [Routers API](https://cloud.google.com/compute/docs/reference/rest/v1/routers). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[rules](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/routers/nats/rules)`
     `(PREVIEW)` List, create, update, describe, and delete Cloud NAT Rules. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/routers/nats/create)`
     `(PREVIEW)` Add a NAT to a Compute Engine router. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/routers/nats/delete)`
     `(PREVIEW)` Remove a NAT from a Compute Engine router. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/routers/nats/describe)`
     `(PREVIEW)` Describe a NAT in a Compute Engine router. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/routers/nats/list)`
     `(PREVIEW)` Lists the NATs on a Compute Engine router. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/routers/nats/update)`
     `(PREVIEW)` Update a NAT on a Compute Engine router. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
