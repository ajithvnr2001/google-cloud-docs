NAME
    

gcloud preview compute storage-pool-types - read storage pool types 
SYNOPSIS
    

`gcloud preview compute storage-pool-types` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read Compute Engine storage pool types. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/storage-pool-types/describe)`
     `(PREVIEW)` Describe a storage pool type. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/storage-pool-types/list)`
     `(PREVIEW)` View storage pools types. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
