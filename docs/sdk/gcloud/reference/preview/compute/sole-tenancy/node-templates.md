NAME
    

gcloud preview compute sole-tenancy node-templates - read and manage Compute Engine sole-tenancy node templates 
SYNOPSIS
    

`gcloud preview compute sole-tenancy node-templates` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Node templates are used to create the nodes in node groups. Nodes are Compute Engine servers that are dedicated to your workload. Node templates define either the node type or the requirements for a node in terms of vCPU, memory, and localSSD. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/add-iam-policy-binding)`
     `(PREVIEW)` Add IAM policy binding to a Compute Engine node template. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/create)`
     `(PREVIEW)` Create a Compute Engine node template. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/delete)`
     `(PREVIEW)` Delete a Compute Engine node template. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/describe)`
     `(PREVIEW)` Describe a Compute Engine node template. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/get-iam-policy)`
     `(PREVIEW)` Get the IAM Policy for a Compute Engine node template. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/list)`
     `(PREVIEW)` List Google Compute Engine node templates. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/remove-iam-policy-binding)`
     `(PREVIEW)` Remove IAM policy binding from a Compute Engine node template. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine node template. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-templates/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine sole-tenancy node template.
