NAME
    

gcloud preview compute sole-tenancy node-groups - read Compute Engine sole-tenancy node groups 
SYNOPSIS
    

`gcloud preview compute sole-tenancy node-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read Compute Engine sole-tenancy node groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/add-iam-policy-binding)`
     `(PREVIEW)` Add IAM policy binding to a Compute Engine node group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/create)`
     `(PREVIEW)` Create a Compute Engine node group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/delete)`
     `(PREVIEW)` Delete a Compute Engine node group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/describe)`
     `(PREVIEW)` Describe a Compute Engine node group. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/get-iam-policy)`
     `(PREVIEW)` Get the IAM policy for a Compute Engine node group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/list)`
     `(PREVIEW)` List Google Compute Engine node groups. 
`[list-nodes](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/list-nodes)`
     `(PREVIEW)` List Compute Engine sole-tenant nodes present in a nodegroup. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/perform-maintenance)`
     `(PREVIEW)` Perform maintenance on nodes in a Compute Engine node group. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/remove-iam-policy-binding)`
     `(PREVIEW)` Remove IAM policy binding from a Compute Engine node group. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine node group. 
`[simulate-maintenance-event](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/simulate-maintenance-event)`
     `(PREVIEW)` Simulate maintenance of a Compute Engine node group. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine node group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/sole-tenancy/node-groups/update)`
     `(PREVIEW)` Update a Compute Engine node group.
