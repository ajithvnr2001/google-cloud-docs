NAME
    

gcloud preview compute http-health-checks describe - display detailed information about an HTTP health check 
SYNOPSIS
    

`gcloud preview compute http-health-checks describe` `NAME` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` `gcloud preview compute http-health-checks describe` displays all data associated with a Google Compute Engine HTTP health check in a project. 
POSITIONAL ARGUMENTS
    

`NAME`
     Name of the HTTP health check to describe. 
GCLOUD WIDE FLAGS
