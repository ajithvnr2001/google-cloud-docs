NAME
    

gcloud preview compute public-delegated-prefixes - manage public delegated prefix resources 
SYNOPSIS
    

`gcloud preview compute public-delegated-prefixes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Manage public delegated prefix resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[delegated-sub-prefixes](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/public-delegated-prefixes/delegated-sub-prefixes)`
     `(PREVIEW)` Manage delegated sub prefixes. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/public-delegated-prefixes/create)`
     `(PREVIEW)` Creates a Compute Engine public delegated prefix. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/public-delegated-prefixes/delete)`
     `(PREVIEW)` Deletes a Compute Engine public delegated prefix. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/public-delegated-prefixes/describe)`
     `(PREVIEW)` Describes a Compute Engine public delegated prefix. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/public-delegated-prefixes/list)`
     `(PREVIEW)` List Google Compute Engine public delegated prefixes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/public-delegated-prefixes/update)`
     `(PREVIEW)` Updates a Compute Engine public delegated prefix. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
