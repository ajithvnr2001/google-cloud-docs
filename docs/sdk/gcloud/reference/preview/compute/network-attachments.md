NAME
    

gcloud preview compute network-attachments - manage Compute Engine network attachment resources 
SYNOPSIS
    

`gcloud preview compute network-attachments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` List, create, describe, update and delete network attachments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments/create)`
     `(PREVIEW)` Create a Google Compute Engine network attachment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments/delete)`
     `(PREVIEW)` Delete one or more Google Compute Engine network attachments. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments/describe)`
     `(PREVIEW)` Describes a Google Compute Engine network attachment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments/list)`
     `(PREVIEW)` List Google Compute Engine network attachments. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine network attachment. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine network attachment. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments/update)`
     `(PREVIEW)` Update a Google Compute Engine network attachment. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
