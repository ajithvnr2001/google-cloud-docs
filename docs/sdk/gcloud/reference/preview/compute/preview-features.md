NAME
    

gcloud preview compute preview-features - read and manipulate Compute Engine Preview Features 
SYNOPSIS
    

`gcloud preview compute preview-features` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate Compute Engine Preview Features. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/preview-features/describe)`
     `(PREVIEW)` Describe a preview feature. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/preview-features/list)`
     `(PREVIEW)` View preview features. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/preview-features/update)`
     `(PREVIEW)` Update a preview feature's activation status. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
