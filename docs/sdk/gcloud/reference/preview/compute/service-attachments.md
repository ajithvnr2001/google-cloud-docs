NAME
    

gcloud preview compute service-attachments - manage Compute Engine service attachment resources 
SYNOPSIS
    

`gcloud preview compute service-attachments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` List, create, describe, update and delete service attachments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/service-attachments/create)`
     `(PREVIEW)` Create a Google Compute Engine service attachment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/service-attachments/delete)`
     `(PREVIEW)` Delete one or more Google Compute Engine service attachments. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/service-attachments/describe)`
     `(PREVIEW)` Display details about a Google Compute Engine service attachment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/service-attachments/list)`
     `(PREVIEW)` List Google Compute Engine service attachments. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/service-attachments/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine service attachment. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/service-attachments/update)`
     `(PREVIEW)` Update a Google Compute Engine service attachment. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
