NAME
    

gcloud preview compute disk-types - read Compute Engine virtual disk types 
SYNOPSIS
    

`gcloud preview compute disk-types` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read Compute Engine virtual disk types. 

For more information disk types, see the [disk types documentation](https://cloud.google.com/compute/docs/disks/). 

See also: [Disk types API](https://cloud.google.com/compute/docs/reference/rest/v1/diskTypes). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/disk-types/describe)`
     `(PREVIEW)` Describe a Compute Engine disk type. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/disk-types/list)`
     `(PREVIEW)` List Google Compute Engine disk types. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
