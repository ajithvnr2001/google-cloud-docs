NAME
    

gcloud preview compute health-checks - read and manipulate health checks for load balanced instances 
SYNOPSIS
    

`gcloud preview compute health-checks` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate health checks for load balanced instances. 

For more information about health checks, see the [health checks documentation](https://cloud.google.com/load-balancing/docs/health-check-concepts). 

See also: [Health checks API](https://cloud.google.com/compute/docs/reference/rest/v1/healthChecks) and [Regional health checks API](https://cloud.google.com/compute/docs/reference/rest/v1/regionHealthChecks). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/create)`
     `(PREVIEW)` Create (non-legacy) health checks for load balanced instances. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update)`
     `(PREVIEW)` Update health checks for load balanced instances. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/delete)`
     `(PREVIEW)` Delete health checks. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/describe)`
     `(PREVIEW)` Display detailed information about a health check. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/list)`
     `(PREVIEW)` List Google Compute Engine health checks. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine health check. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
