NAME
    

gcloud preview compute snapshot-settings - describe and update Compute Engine snapshot settings 
SYNOPSIS
    

`gcloud preview compute snapshot-settings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Describe and update Compute Engine snapshot settings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshot-settings/describe)`
     `(PREVIEW)` Describe snapshot settings. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshot-settings/update)`
     `(PREVIEW)` Update snapshot settings. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
