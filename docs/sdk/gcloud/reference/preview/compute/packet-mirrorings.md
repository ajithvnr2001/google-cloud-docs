NAME
    

gcloud preview compute packet-mirrorings - manage Compute Engine packet mirroring resources 
SYNOPSIS
    

`gcloud preview compute packet-mirrorings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Manage Compute Engine packet mirroring resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/packet-mirrorings/create)`
     `(PREVIEW)` Create a Compute Engine packet mirroring policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/packet-mirrorings/delete)`
     `(PREVIEW)` Delete a Compute Engine packet mirroring policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/packet-mirrorings/describe)`
     `(PREVIEW)` Describe a Compute Engine packet mirroring policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/packet-mirrorings/list)`
     `(PREVIEW)` List Google Compute Engine packet mirroring policies. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/packet-mirrorings/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine packet mirroring policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/packet-mirrorings/update)`
     `(PREVIEW)` Update a Compute Engine packet mirroring policy. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
