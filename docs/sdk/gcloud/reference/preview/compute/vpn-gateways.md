NAME
    

gcloud preview compute vpn-gateways - read and manipulate Highly Available VPN Gateways 
SYNOPSIS
    

`gcloud preview compute vpn-gateways` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate highly available (HA) VPN gateways for Cloud VPN. 

For more information about HA VPN gateways, see [Cloud VPN overview](https://cloud.google.com//network-connectivity/docs/vpn/concepts/overview). 

See also: [VPN Gateways API](https://cloud.google.com/compute/docs/reference/rest/v1/vpnGateways). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/vpn-gateways/create)`
     `(PREVIEW)` Create a new Compute Engine Highly Available VPN gateway. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/vpn-gateways/delete)`
     `(PREVIEW)` Delete Compute Engine Highly Available VPN Gateways. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/vpn-gateways/describe)`
     `(PREVIEW)` Describe a Compute Engine Highly Available VPN Gateway. 
`[get-status](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/vpn-gateways/get-status)`
     `(PREVIEW)` Get status of a Compute Engine Highly Available VPN Gateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/vpn-gateways/list)`
     `(PREVIEW)` List Google Compute Engine Highly Available VPN Gateways. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/vpn-gateways/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine VPN gateway. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/vpn-gateways/update)`
     `(PREVIEW)` Update a Compute Engine Highly Available VPN gateway. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
