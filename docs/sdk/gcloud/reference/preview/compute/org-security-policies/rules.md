NAME
    

gcloud preview compute org-security-policies rules - read and manipulate Compute Engine organization security policy rules 
SYNOPSIS
    

`gcloud preview compute org-security-policies rules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate Compute Engine organization security policy rules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-preconfig-waf-exclusion](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/org-security-policies/rules/add-preconfig-waf-exclusion)`
     `(PREVIEW)` Add an exclusion configuration for preconfigured WAF evaluation into a security policy rule. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/org-security-policies/rules/create)`
     `(PREVIEW)` Create a Compute Engine organizationsecurity policy rule. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/org-security-policies/rules/delete)`
     `(PREVIEW)` Delete a Compute Engine organization security policy rule. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/org-security-policies/rules/describe)`
     `(PREVIEW)` Describe a Compute Engine organization security policy rule. 
`[remove-preconfig-waf-exclusion](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/org-security-policies/rules/remove-preconfig-waf-exclusion)`
     `(PREVIEW)` Remove an exclusion configuration for preconfigured WAF evaluation from a security policy rule. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/org-security-policies/rules/update)`
     `(PREVIEW)` Update a Compute Engine security policy rule. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
