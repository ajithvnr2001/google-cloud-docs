NAME
    

gcloud preview compute health-checks update - update health checks for load balanced instances 
SYNOPSIS
    

`gcloud preview compute health-checks update` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Update health checks for load balanced instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[grpc](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update/grpc)`
     `(PREVIEW)` Update a gRPC health check. 
`[grpc-with-tls](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update/grpc-with-tls)`
     `(PREVIEW)` Update a gRPC with TLS health check. 
`[http](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update/http)`
     `(PREVIEW)` Update a HTTP health check. 
`[http2](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update/http2)`
     `(PREVIEW)` Update a HTTP2 health check. 
`[https](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update/https)`
     `(PREVIEW)` Update a HTTPS health check. 
`[ssl](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update/ssl)`
     `(PREVIEW)` Update a SSL health check. 
`[tcp](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/health-checks/update/tcp)`
     `(PREVIEW)` Update a TCP health check. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
