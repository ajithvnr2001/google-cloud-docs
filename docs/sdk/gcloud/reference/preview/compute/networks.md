NAME
    

gcloud preview compute networks - list, create, and delete Compute Engine networks 
SYNOPSIS
    

`gcloud preview compute networks` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate VPC networks. 

For more information about networks, see the [networks documentation](https://cloud.google.com/vpc/docs/vpc). 

See also: [Networks API](https://cloud.google.com/compute/docs/reference/rest/v1/networks). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[peerings](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/peerings)`
     `(PREVIEW)` List, create, and delete, and update VPC Network Peering. 
`[subnets](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets)`
     `(PREVIEW)` List, describe, and delete, and update Compute Engine subnetworks. 
`[vpc-access](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access)`
     `(PREVIEW)` Manage VPC Access Service resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/create)`
     `(PREVIEW)` Create a Compute Engine network. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/delete)`
     `(PREVIEW)` Delete Compute Engine networks. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/describe)`
     `(PREVIEW)` Describe a Compute Engine network. 
`[get-effective-firewalls](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/get-effective-firewalls)`
     `(PREVIEW)` Get the effective firewalls of a Compute Engine network. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/list)`
     `(PREVIEW)` List Google Compute Engine networks. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/update)`
     `(PREVIEW)` Update a Compute Engine network. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
