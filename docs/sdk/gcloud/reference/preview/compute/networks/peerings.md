NAME
    

gcloud preview compute networks peerings - list, create, and delete, and update VPC Network Peering 
SYNOPSIS
    

`gcloud preview compute networks peerings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate VPC Network Peering connections. 

For more information about VPC Network Peering, see the [VPC Network Peering documentation](https://cloud.google.com/vpc/docs/vpc-peering). 

See also: [Network API](https://cloud.google.com/compute/docs/reference/rest/v1/networks). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/peerings/create)`
     `(PREVIEW)` Create a Compute Engine network peering. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/peerings/delete)`
     `(PREVIEW)` Delete a Compute Engine network peering. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/peerings/list)`
     `(PREVIEW)` List Google Compute Engine peerings. 
`[list-routes](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/peerings/list-routes)`
     `(PREVIEW)` List received or advertised routes for a VPC network peering. 
`[request-delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/peerings/request-delete)`
     `(PREVIEW)` Request deletion of a Compute Engine network peering. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/peerings/update)`
     `(PREVIEW)` Update a Compute Engine network peering. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
