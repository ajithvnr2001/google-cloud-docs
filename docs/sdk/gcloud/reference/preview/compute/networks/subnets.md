NAME
    

gcloud preview compute networks subnets - list, describe, and delete, and update Compute Engine subnetworks 
SYNOPSIS
    

`gcloud preview compute networks subnets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate VPC subnetworks. 

For more information about VPC, see the [VPC documentation](https://cloud.google.com/vpc/docs/vpc). 

See also: [Subnetworks API](https://cloud.google.com/compute/docs/reference/rest/v1/subnetworks). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/add-iam-policy-binding)`
     `(PREVIEW)` Add an IAM policy binding to a Compute Engine subnetwork. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/create)`
     `(PREVIEW)` Define a subnet for a network in custom subnet mode. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/delete)`
     `(PREVIEW)` Delete Google Cloud subnetworks. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/describe)`
     `(PREVIEW)` Describe a Compute Engine subnetwork. 
`[expand-ip-range](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/expand-ip-range)`
     `(PREVIEW)` Expand the IP range of a Compute Engine subnetwork. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/get-iam-policy)`
     `(PREVIEW)` Get the IAM policy for a Compute Engine subnetwork. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/list)`
     `(PREVIEW)` List Google Compute Engine subnetworks. 
`[list-usable](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/list-usable)`
     `(PREVIEW)` List Compute Engine subnetworks permitted for use. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/remove-iam-policy-binding)`
     `(PREVIEW)` Remove an IAM policy binding from a Compute Engine subnetwork. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine subnetwork. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine subnetwork. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/subnets/update)`
     `(PREVIEW)` Updates properties of an existing Compute Engine subnetwork. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
