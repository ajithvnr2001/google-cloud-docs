NAME
    

gcloud preview compute networks vpc-access connectors - manage Serverless VPC Access Service connectors 
SYNOPSIS
    

`gcloud preview compute networks vpc-access connectors` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Commands for managing connectors resource for VPC Access Service. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access/connectors/create)`
     `(PREVIEW)` Create a VPC Access connector. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access/connectors/delete)`
     `(PREVIEW)` Delete a VPC Access connector. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access/connectors/describe)`
     `(PREVIEW)` Show metadata for a VPC Access connector. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access/connectors/list)`
     `(PREVIEW)` List VPC Access connectors. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access/connectors/update)`
     `(PREVIEW)` Update a VPC Access connector. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
