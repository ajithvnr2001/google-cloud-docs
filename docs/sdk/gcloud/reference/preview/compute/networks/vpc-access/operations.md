NAME
    

gcloud preview compute networks vpc-access operations - manage operations resource for VPC Access Service 
SYNOPSIS
    

`gcloud preview compute networks vpc-access operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Commands for managing operations resource for VPC Access Service. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access/operations/describe)`
     `(PREVIEW)` Show metadata for a VPC Access Service operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/networks/vpc-access/operations/list)`
     `(PREVIEW)` List VPC Access Service operations. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
