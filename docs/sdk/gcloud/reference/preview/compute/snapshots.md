NAME
    

gcloud preview compute snapshots - list, describe, and delete Compute Engine snapshots 
SYNOPSIS
    

`gcloud preview compute snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` List, describe, and delete Compute Engine snapshots. 

For more information about snapshots, see the [snapshots documentation](https://cloud.google.com/compute/docs/disks/create-snapshots). 

See also: [Snapshots API](https://cloud.google.com/compute/docs/reference/rest/v1/snapshots). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/add-iam-policy-binding)`
     `(PREVIEW)` Add IAM policy binding to a Compute Engine snapshot. 
`[add-labels](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/add-labels)`
     `(PREVIEW)` Add labels to Google Compute Engine snapshots. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/create)`
     `(PREVIEW)` Create Compute Engine snapshots. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/delete)`
     `(PREVIEW)` Delete Compute Engine snapshots. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/describe)`
     `(PREVIEW)` Describe a Compute Engine snapshot. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/get-iam-policy)`
     `(PREVIEW)` Get the IAM policy for a Compute Engine snapshot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/list)`
     `(PREVIEW)` List Google Compute Engine snapshots. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/remove-iam-policy-binding)`
     `(PREVIEW)` Remove IAM policy binding from a Compute Engine snapshot. 
`[remove-labels](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/remove-labels)`
     `(PREVIEW)` Remove labels from Google Compute Engine snapshots. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine snapshot. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine standard or archive snapshot. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/update)`
     `(PREVIEW)` Update a Compute Engine snapshot. 
`[update-kms-key](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/snapshots/update-kms-key)`
     `(PREVIEW)` Update the KMS key of a Compute Engine standard or archive snapshot. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
