NAME
    

gcloud preview compute reservations - manage Compute Engine reservations 
SYNOPSIS
    

`gcloud preview compute reservations` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Manage Compute Engine reservations. 

For more information about reservations, see the [reservations documentation](https://cloud.google.com/compute/docs/instances/reserving-zonal-resources). 

See also: [Reservations API](https://cloud.google.com/compute/docs/reference/rest/v1/reservations). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[blocks](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/blocks)`
     `(PREVIEW)` Manage Compute Engine reservation blocks. 
`[slots](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/slots)`
     `(PREVIEW)` Manage Compute Engine reservation slots. 
`[sub-blocks](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/sub-blocks)`
     `(PREVIEW)` Manage Compute Engine reservation sub blocks. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/add-iam-policy-binding)`
     `(PREVIEW)` Add IAM policy binding to a Compute Engine reservation. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/create)`
     `(PREVIEW)` Create a Compute Engine reservation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/delete)`
     `(PREVIEW)` Delete a Compute Engine reservation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/describe)`
     `(PREVIEW)` Show details about a Compute Engine reservation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/get-iam-policy)`
     `(PREVIEW)` Get the IAM policy for a Compute Engine reservation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/list)`
     `(PREVIEW)` List Compute Engine reservations. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/perform-maintenance)`
     `(PREVIEW)` Perform maintenance on a reservation, only applicable to reservations with reservation blocks. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/remove-iam-policy-binding)`
     `(PREVIEW)` Remove IAM policy binding from a Compute Engine reservation. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/set-iam-policy)`
     `(PREVIEW)` Set the IAM policy for a Compute Engine reservation. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/test-iam-permissions)`
     `(PREVIEW)` Test IAM permissions for a Compute Engine reservation. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations/update)`
     `(PREVIEW)` Update Compute Engine reservations. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
