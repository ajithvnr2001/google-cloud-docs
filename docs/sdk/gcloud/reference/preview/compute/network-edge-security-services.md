NAME
    

gcloud preview compute network-edge-security-services - read and manipulate network edge security services 
SYNOPSIS
    

`gcloud preview compute network-edge-security-services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate network edge security services. 

Network edge security services are used to protect network load balancing resources and instances with external IPs. 

For example, to add advanced protection for a given region, create a network edge security service in that region and attach a security policy with ADVANCED DDoS protection enabled. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-edge-security-services/create)`
     `(PREVIEW)` Create a Compute Engine network edge security service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-edge-security-services/delete)`
     `(PREVIEW)` Delete network edge security services. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-edge-security-services/describe)`
     `(PREVIEW)` Describe a Compute Engine network edge security service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-edge-security-services/list)`
     `(PREVIEW)` List Google Compute Engine network edge security services. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-edge-security-services/update)`
     `(PREVIEW)` Update a network edge security service. 
NOTES
