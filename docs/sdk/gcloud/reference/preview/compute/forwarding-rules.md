NAME
    

gcloud preview compute forwarding-rules - read and manipulate traffic forwarding rules to network load balancers 
SYNOPSIS
    

`gcloud preview compute forwarding-rules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate traffic forwarding rules for load balancers, protocol forwarding, or Classic Cloud VPN. 

For more information about forwarding rules, see the [forwarding rules documentation](https://cloud.google.com/load-balancing/docs/forwarding-rule-concepts). 

See also: [Region forwarding rules API](https://cloud.google.com/compute/docs/reference/rest/v1/forwardingRules) and [Global forwarding rules API](https://cloud.google.com/compute/docs/reference/rest/v1/globalForwardingRules). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/create)`
     `(PREVIEW)` Create a forwarding rule to direct network traffic to a load balancer. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/delete)`
     `(PREVIEW)` Delete forwarding rules. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/describe)`
     `(PREVIEW)` Display detailed information about a forwarding rule. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/export)`
     `(PREVIEW)` Export a forwarding rule. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/import)`
     `(PREVIEW)` Import a forwarding rule. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/list)`
     `(PREVIEW)` List Google Compute Engine forwarding rules. 
`[set-target](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/set-target)`
     `(PREVIEW)` Modify a forwarding rule to direct network traffic to a new target. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/forwarding-rules/update)`
     `(PREVIEW)` Update a Compute Engine forwarding rule. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
