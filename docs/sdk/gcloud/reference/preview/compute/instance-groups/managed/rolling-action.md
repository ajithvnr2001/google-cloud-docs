NAME
    

gcloud preview compute instance-groups managed rolling-action - manipulate rolling actions on Compute Engine managed instance groups 
SYNOPSIS
    

`gcloud preview compute instance-groups managed rolling-action` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate Compute Engine managed instance groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[replace](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/instance-groups/managed/rolling-action/replace)`
     `(PREVIEW)` Replaces instances in a managed instance group. 
`[restart](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/instance-groups/managed/rolling-action/restart)`
     `(PREVIEW)` Restarts instances in a managed instance group. 
`[start-update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/instance-groups/managed/rolling-action/start-update)`
     `(PREVIEW)` Updates instances in a managed instance group. 
`[stop-proactive-update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/instance-groups/managed/rolling-action/stop-proactive-update)`
     `(PREVIEW)` Stop the proactive update process of managed instance group. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
