NAME
    

gcloud preview compute accelerator-interconnects member-instances list - list member VM instances of an accelerator interconnect 
SYNOPSIS
    

`gcloud preview compute accelerator-interconnects member-instances list` `--accelerator-interconnect`=`ACCELERATOR_INTERCONNECT` [`--endpoint-mode`=`ENDPOINT_MODE`] [`--zone`=`ZONE`] [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` `gcloud preview compute accelerator-interconnects member-instances list` lists the member VM instances participating in a specified accelerator interconnect. 
EXAMPLES
     To list member VM instances of accelerator interconnect `my-interconnect` in zone `us-central1-a`: 
    
    
    [gcloud preview compute accelerator-interconnects](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects) member-instances list --accelerator-interconnect=my-interconnect --zone=us-central1-a

REQUIRED FLAGS
    

`--accelerator-interconnect`=`ACCELERATOR_INTERCONNECT`
     Name of the accelerator interconnect to list member instances for.
