NAME
    

gcloud preview compute accelerator-interconnects member-instances - manage Compute Engine accelerator interconnect member instances 
SYNOPSIS
    

`gcloud preview compute accelerator-interconnects member-instances` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` This command group allows you to inspect member VM instances participating in an accelerator interconnect. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects/member-instances/list)`
     `(PREVIEW)` List member VM instances of an accelerator interconnect. 
REGIONAL ENDPOINTS
     This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) regional/endpoint_mode regional-preferred`. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
