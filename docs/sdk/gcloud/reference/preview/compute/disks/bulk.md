NAME
    

gcloud preview compute disks bulk - manipulate multiple Compute Engine disks with single command executions 
SYNOPSIS
    

`gcloud preview compute disks bulk` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Manipulate multiple Compute Engine disks with single command executions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/disks/bulk/create)`
     `(PREVIEW)` Create multiple Compute Engine disks or a consistency group of instant snapshots. 
`[set-labels](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/disks/bulk/set-labels)`
     `(PREVIEW)` Add or remove labels on multiple Compute Engine disks. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. These variants are also available:
