NAME
    

gcloud preview compute accelerator-interconnects - read and manipulate Compute Engine accelerator interconnects 
SYNOPSIS
    

`gcloud preview compute accelerator-interconnects` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate Compute Engine accelerator interconnects. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[member-instances](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects/member-instances)`
     `(PREVIEW)` Manage Compute Engine accelerator interconnect member instances. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects/create)`
     `(PREVIEW)` Create a Compute Engine accelerator interconnect. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects/delete)`
     `(PREVIEW)` Delete a Compute Engine accelerator interconnect. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects/describe)`
     `(PREVIEW)` Describe a Compute Engine accelerator interconnect. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects/list)`
     `(PREVIEW)` List Compute Engine accelerator interconnects. 
`[query-formability](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/accelerator-interconnects/query-formability)`
     `(PREVIEW)` Query formability for accelerator interconnects. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
