NAME
    

gcloud preview compute target-http-proxies - list, create, and delete target HTTP proxies 
SYNOPSIS
    

`gcloud preview compute target-http-proxies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` List, create, and delete target HTTP proxies. 

For more information about target HTTP proxies, see the [target HTTP proxies documentation](https://cloud.google.com/load-balancing/docs/target-proxies). 

See also: [Target HTTP proxies API](https://cloud.google.com/compute/docs/reference/rest/v1/targetHttpProxies) and [Regional target HTTP proxies API](https://cloud.google.com/compute/docs/reference/rest/v1/regionTargetHttpProxies). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/target-http-proxies/create)`
     `(PREVIEW)` Create a target HTTP proxy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/target-http-proxies/delete)`
     `(PREVIEW)` Delete target HTTP proxies. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/target-http-proxies/describe)`
     `(PREVIEW)` Display detailed information about a target HTTP proxy. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/target-http-proxies/export)`
     `(PREVIEW)` Export a target HTTP proxy. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/target-http-proxies/import)`
     `(PREVIEW)` Import a target HTTP proxy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/target-http-proxies/list)`
     `(PREVIEW)` List Google Compute Engine target HTTP proxies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/target-http-proxies/update)`
     `(PREVIEW)` Update a target HTTP proxy. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
