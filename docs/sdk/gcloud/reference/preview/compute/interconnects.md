NAME
    

gcloud preview compute interconnects - read and manipulate Compute Engine interconnects 
SYNOPSIS
    

`gcloud preview compute interconnects` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Read and manipulate Cloud Interconnect connections. 

For more information about Cloud Interconnect, see the [Cloud Interconnect documentation](https://cloud.google.com//network-connectivity/docs/interconnect/concepts/overview). 

See also: [Interconnects API](https://cloud.google.com/compute/docs/reference/rest/v1/interconnects). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[application-awareness](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/application-awareness)`
     `(PREVIEW)` Read and manipulate configuration for application awareness on Compute Engine interconnect. 
`[attachments](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/attachments)`
     `(PREVIEW)` Read and manipulate Compute Engine interconnect attachments. 
`[cross-site-networks](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/cross-site-networks)`
     `(PREVIEW)` Create or manipulate cross site networks. 
`[groups](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups)`
     `(PREVIEW)` Create or manipulate interconnect groups. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/locations)`
     `(PREVIEW)` Read and manipulate Compute Engine interconnect locations. 
`[macsec](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/macsec)`
     `(PREVIEW)` Read and manipulate Compute Engine interconnect MACsec configuration. 
`[remote-locations](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/remote-locations)`
     `(PREVIEW)` Read and manipulate Google Compute Engine interconnect remote locations. 
`[wire-groups](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/wire-groups)`
     `(PREVIEW)` Create or manipulate wire groups. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/create)`
     `(PREVIEW)` Create a Compute Engine interconnect. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/delete)`
     `(PREVIEW)` Delete Compute Engine interconnects. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/describe)`
     `(PREVIEW)` Describe a Compute Engine interconnect. 
`[get-diagnostics](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/get-diagnostics)`
     `(PREVIEW)` Get diagnostics of a Compute Engine interconnect. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/list)`
     `(PREVIEW)` List Google Compute Engine interconnects. 
`[set-name](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/set-name)`
     `(PREVIEW)` Set the name of a Compute Engine interconnect. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/update)`
     `(PREVIEW)` Update a Compute Engine interconnect. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
