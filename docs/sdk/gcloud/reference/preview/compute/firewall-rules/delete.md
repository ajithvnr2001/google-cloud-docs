NAME
    

gcloud preview compute firewall-rules delete - delete Compute Engine firewall rules 
SYNOPSIS
    

`gcloud preview compute firewall-rules delete` `NAME` [`NAME` …] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` `gcloud preview compute firewall-rules delete` deletes one or more Compute Engine firewall rules. 
EXAMPLES
     To delete a firewall rule, run: 
    
    
    gcloud preview compute firewall-rules delete my-firewall-rule

POSITIONAL ARGUMENTS
    

`NAME` [`NAME` …]
     Names of the firewall rules to delete.
