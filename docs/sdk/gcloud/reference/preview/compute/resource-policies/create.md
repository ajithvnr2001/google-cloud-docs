NAME
    

gcloud preview compute resource-policies create - create Compute Engine Resource Policies 
SYNOPSIS
    

`gcloud preview compute resource-policies create` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(PREVIEW)` Create Compute Engine Resource Policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[disk-consistency-group](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/resource-policies/create/disk-consistency-group)`
     `(PREVIEW)` Create a Compute Engine Disk Consistency Group resource policy. 
`[group-placement](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/resource-policies/create/group-placement)`
     `(PREVIEW)` Create a Compute Engine group placement resource policy. 
`[instance-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/resource-policies/create/instance-schedule)`
     `(PREVIEW)` Create a Compute Engine instance schedule resource policy. 
`[snapshot-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/resource-policies/create/snapshot-schedule)`
     `(PREVIEW)` Create a Compute Engine Snapshot Schedule Resource Policy. 
`[workload-policy](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/resource-policies/create/workload-policy)`
     `(PREVIEW)` Create a Compute Engine workload resource policy. 
NOTES
     This command is currently in DEVELOPER PREVIEW and may change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist.
