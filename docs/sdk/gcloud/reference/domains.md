NAME
    

gcloud domains - manage domains for your Google Cloud projects 
SYNOPSIS
    

`gcloud domains` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     The gcloud domains command group lets you view and manage your custom domains for use across Google projects. 
EXAMPLES
     To verify a domain you own, run: 
    
    
    [gcloud domains verify](https://docs.cloud.google.com/sdk/gcloud/reference/domains/verify) example.com

To list your verified domains, run: 
    
    
    [gcloud domains list-user-verified](https://docs.cloud.google.com/sdk/gcloud/reference/domains/list-user-verified)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[registrations](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations)`
     Manage Cloud Domains registrations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[list-user-verified](https://docs.cloud.google.com/sdk/gcloud/reference/domains/list-user-verified)`
     Lists the user's verified domains. 
`[verify](https://docs.cloud.google.com/sdk/gcloud/reference/domains/verify)`
     Verifies a domain via an in-browser workflow. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha domains](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains)
    
    
    [gcloud beta domains](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains)
