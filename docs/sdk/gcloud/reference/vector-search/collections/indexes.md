#  gcloud vector-search collections indexes Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud vector-search collections indexes - manage Index resources 
SYNOPSIS
    

`gcloud vector-search collections indexes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Index resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/indexes/create)`
     Create an index. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/indexes/delete)`
     Delete an index. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/indexes/describe)`
     Describe an index. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/indexes/list)`
     List indexes. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta vector-search collections indexes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/vector-search/collections/indexes)
