#  gcloud vector-search collections data-objects Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud vector-search collections data-objects - manage Vector Search data objects 
SYNOPSIS
    

`gcloud vector-search collections data-objects` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Vector Search data objects. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[aggregate](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/aggregate)`
     Aggregate data objects. 
`[batch-create](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/batch-create)`
     Create a batch of data objects. 
`[batch-delete](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/batch-delete)`
     Delete a batch of data objects. 
`[batch-search](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/batch-search)`
     Batch search data objects from a Vector Search collection. 
`[batch-update](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/batch-update)`
     Update a batch of data objects. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/create)`
     Create a data object. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/delete)`
     Delete a data object. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/describe)`
     Describe a data object. 
`[query](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/query)`
     Query data objects from a Vector Search collection. 
`[search](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/search)`
     Search data objects from a Vector Search collection. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/vector-search/collections/data-objects/update)`
     Update a data object. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta vector-search collections data-objects](https://docs.cloud.google.com/sdk/gcloud/reference/beta/vector-search/collections/data-objects)
