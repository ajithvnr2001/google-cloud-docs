NAME
    

gcloud compliance-manager - manage Compliance Manager resources 
SYNOPSIS
    

`gcloud compliance-manager` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Compliance Manager resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[cloud-control-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/cloud-control-deployments)`
     Manage Cloud Control Deployment resources. 
`[cloud-controls](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/cloud-controls)`
     Manage Cloud Control resources. 
`[framework-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/framework-deployments)`
     Manage Framework Deployment resources. 
`[frameworks](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/frameworks)`
     Manage Framework resources. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/compliance-manager/operations)`
     Manage Operation resources.
