NAME
    

gcloud run worker-pools - view and manage your Cloud Run worker pools 
SYNOPSIS
    

`gcloud run worker-pools` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     This set of commands can be used to view and manage your Cloud Run worker pools. 
EXAMPLES
     To list your existing worker-pools, run: 
    
    
    [gcloud run worker-pools list](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/list)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/logs)`
     Read logs for Cloud Run worker pools. 
`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/revisions)`
     View and manage your Cloud Run WorkerPools revisions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/add-iam-policy-binding)`
     Add IAM policy binding to a Cloud Run worker pool. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/delete)`
     Delete a worker-pool. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/deploy)`
     Create or update a Cloud Run worker-pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/describe)`
     Obtain details about a given worker-pool. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/get-iam-policy)`
     Get the IAM policy for a Cloud Run worker pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/list)`
     List available worker-pools. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/remove-iam-policy-binding)`
     Remove IAM policy binding of a Cloud Run worker pool. 
`[replace](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/replace)`
     Create or replace a worker-pool from a YAML worker-pool specification. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/set-iam-policy)`
     Set the IAM policy for a worker pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/update)`
     Update Cloud Run environment variables and other configuration settings. 
`[update-instance-split](https://docs.cloud.google.com/sdk/gcloud/reference/run/worker-pools/update-instance-split)`
     Adjust the instance assignments for a Cloud Run worker-pool. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha run worker-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/worker-pools)
    
    
    [gcloud beta run worker-pools](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/worker-pools)
