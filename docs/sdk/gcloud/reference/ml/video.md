NAME
    

gcloud ml video - cloud ML Video-Intelligence command groups 
SYNOPSIS
    

`gcloud ml video` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Cloud ML Video-Intelligence command groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/ml/video/operations)`
     Command group for working with Cloud Video Intelligence operations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[detect-explicit-content](https://docs.cloud.google.com/sdk/gcloud/reference/ml/video/detect-explicit-content)`
     Detect explicit content in videos. 
`[detect-labels](https://docs.cloud.google.com/sdk/gcloud/reference/ml/video/detect-labels)`
     Detect general labels for videos. 
`[detect-shot-changes](https://docs.cloud.google.com/sdk/gcloud/reference/ml/video/detect-shot-changes)`
     Detect shot changes in videos. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha ml video](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/video)
    
    
    [gcloud beta ml video](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/video)
