NAME
    

gcloud eventarc message-buses - manage Eventarc message buses 
SYNOPSIS
    

`gcloud eventarc message-buses` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Eventarc message buses. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses/create)`
     Create an Eventarc message bus. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses/delete)`
     Delete an Eventarc message bus. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses/describe)`
     Describe an Eventarc message bus. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses/list)`
     List Eventarc message buses. 
`[list-enrollments](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses/list-enrollments)`
     List Eventarc enrollments attached to an Eventarc message bus. 
`[publish](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses/publish)`
     Publish to an Eventarc message bus. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/message-buses/update)`
     Update an Eventarc message bus. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta eventarc message-buses](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/message-buses)
