NAME
    

gcloud eventarc enrollments - manage Eventarc enrollments 
SYNOPSIS
    

`gcloud eventarc enrollments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Eventarc enrollments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/enrollments/create)`
     Create an Eventarc enrollment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/enrollments/delete)`
     Delete an Eventarc enrollment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/enrollments/describe)`
     Describe an Eventarc enrollment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/enrollments/list)`
     List Eventarc enrollments. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/enrollments/update)`
     Update an Eventarc enrollment. 
NOTES
