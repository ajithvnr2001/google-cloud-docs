NAME
    

gcloud tasks queues - manage Cloud Tasks queues 
SYNOPSIS
    

`gcloud tasks queues` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Google Cloud Tasks queues. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/add-iam-policy-binding)`
     Add IAM policy binding for a tasks queue. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/create)`
     Create a Cloud Tasks queue. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/delete)`
     Delete a queue. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/describe)`
     Show details about a queue. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/get-iam-policy)`
     Get the IAM policy for a queue. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/list)`
     List all queues. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/pause)`
     Pause a queue. 
`[purge](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/purge)`
     Purge a queue by deleting all of its tasks. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/remove-iam-policy-binding)`
     Remove IAM policy binding of tasks queue. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/resume)`
     Request to resume a paused or disabled queue. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/set-iam-policy)`
     Set the IAM policy for a queue. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues/update)`
     Update a Cloud Tasks queue. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha tasks queues](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks/queues)
    
    
    [gcloud beta tasks queues](https://docs.cloud.google.com/sdk/gcloud/reference/beta/tasks/queues)
