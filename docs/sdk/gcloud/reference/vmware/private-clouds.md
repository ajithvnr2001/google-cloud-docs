#  gcloud vmware private-clouds Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud vmware private-clouds - manage private clouds in Google Cloud VMware Engine 
SYNOPSIS
    

`gcloud vmware private-clouds` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage private clouds in Google Cloud VMware Engine. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/clusters)`
     Manage clusters in Google Cloud VMware Engine. 
`[dns-forwarding](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/dns-forwarding)`
     Manage dns-forwarding in Google Cloud VMware Engine. 
`[external-addresses](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/external-addresses)`
     Manage external IP addresses in Google Cloud VMware Engine. 
`[hcx](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/hcx)`
     Manage HCX using Google Cloud VMware Engine. 
`[logging-servers](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/logging-servers)`
     Manage logging-server in Google Cloud VMware Engine. 
`[management-dns-zone-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/management-dns-zone-bindings)`
     Manage Management DNS zone bindings in Google Cloud VMware Engine. 
`[nsx](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/nsx)`
     Manage NSX using Google Cloud VMware Engine. 
`[subnets](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/subnets)`
     Manage vmware subnets in Google Cloud VMware Engine. 
`[upgrades](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/upgrades)`
     Manage upgrades in Google Cloud VMware Engine. 
`[vcenter](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/vcenter)`
     Manage vCenter resources in Google Cloud VMware Engine. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/create)`
     Create a VMware Engine private cloud. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/delete)`
     Delete a Google Cloud VMware Engine private cloud. 
`[delete-now](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/delete-now)`
     Permanent deletion of a Google Cloud VMware Engine private cloud currently in soft-deleted state. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/describe)`
     Describe a Google Cloud VMware Engine private cloud. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/list)`
     List Google Cloud VMware Engine private clouds. 
`[migrate-management-vms](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/migrate-management-vms)`
     Migrate the management VMs of a private cloud to a workload cluster. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/undelete)`
     Cancel deletion of a Google Cloud VMware Engine private cloud. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/update)`
     Update a Google Cloud VMware Engine private cloud.
