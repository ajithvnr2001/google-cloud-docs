NAME
    

gcloud vmware network-policies external-access-rules - manage VMware Engine external access firewall rules in Google Cloud VMware Engine 
SYNOPSIS
    

`gcloud vmware network-policies external-access-rules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage VMware Engine external access firewall rules in Google Cloud VMware Engine. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/network-policies/external-access-rules/create)`
     Create a VMware Engine external access firewall rule. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/network-policies/external-access-rules/delete)`
     Delete a VMware Engine external access rule. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/network-policies/external-access-rules/describe)`
     Describe a VMware Engine external access rule. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/network-policies/external-access-rules/list)`
     List VMware Engine external access rules. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/network-policies/external-access-rules/update)`
     Update a VMware Engine network policy.
