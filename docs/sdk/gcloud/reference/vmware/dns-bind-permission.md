NAME
    

gcloud vmware dns-bind-permission - manage DNS binding permission in Google Cloud VMware Engine 
SYNOPSIS
    

`gcloud vmware dns-bind-permission` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage DNS binding permission in Google Cloud VMware Engine. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/dns-bind-permission/describe)`
     Get all users and service accounts having bind permission. 
`[grant](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/dns-bind-permission/grant)`
     Grants a DNS Bind Permission. 
`[revoke](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/dns-bind-permission/revoke)`
     Revokes a DNS Bind Permission.
