NAME
    

gcloud vmware private-clouds logging-servers - manage logging-server in Google Cloud VMware Engine 
SYNOPSIS
    

`gcloud vmware private-clouds logging-servers` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage logging-server in Google Cloud VMware Engine. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/logging-servers/create)`
     Create a Google Cloud VMware Engine logging-server. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/logging-servers/delete)`
     Delete logging-server from a VMware Engine private cloud. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/logging-servers/describe)`
     Describe a Google Cloud VMware Engine logging-server. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/logging-servers/list)`
     List logging-server in a Google Cloud VMware Engine private cloud. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/logging-servers/update)`
     Update a Google Cloud VMware Engine logging-server.
