NAME
    

gcloud vmware private-clouds external-addresses - manage external IP addresses in Google Cloud VMware Engine 
SYNOPSIS
    

`gcloud vmware private-clouds external-addresses` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage external IP addresses in Google Cloud VMware Engine. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/external-addresses/create)`
     Create an external IP address. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/external-addresses/delete)`
     Delete external IP address from a VMware Engine private cloud. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/external-addresses/describe)`
     Describe an external IP address in a VMware Engine private cloud. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/external-addresses/list)`
     List external IP addresses in a VMware Engine private cloud. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/vmware/private-clouds/external-addresses/update)`
     Update an external IP address in a VMware Engine private cloud.
