NAME
    

gcloud beyondcorp security-gateways applications - manage Application resources 
SYNOPSIS
    

`gcloud beyondcorp security-gateways applications` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Application resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/add-iam-policy-binding)`
     Add an IAM policy binding to a security gateway application. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/create)`
     Create applications. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/delete)`
     Delete applications. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/describe)`
     Describe applications. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/get-iam-policy)`
     Get the IAM policy for a security gateway application. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/list)`
     List applications. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/remove-iam-policy-binding)`
     Remove an IAM policy binding from a security gateway application. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/set-iam-policy)`
     Set the IAM policy for a security gateway application. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways/applications/update)`
     Update applications. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta beyondcorp security-gateways applications](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/applications)
