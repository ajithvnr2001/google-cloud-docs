NAME
    

gcloud active-directory operations cancel - cancel a Managed Microsoft AD operation 
SYNOPSIS
    

`gcloud active-directory operations cancel` `NAME` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Cancel a Managed Microsoft AD operation. 
EXAMPLES
     The following command cancels an operation called `operation-1484002552235-425b144f8c3f8-81aa4b49-0830d1e9`: 
    
    
    gcloud active-directory operations cancel operation-1484002552235-425b144f8c3f8-81aa4b49-0830d1e9

POSITIONAL ARGUMENTS
    

Operation resource - The operation name to cancel. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `NAME` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`NAME`
     ID of the operation or fully qualified identifier for the operation. 

To set the `operation` attribute: 

  * provide the argument `NAME` on the command line.
