NAME
    

gcloud active-directory domains trusts - manage Managed Microsoft AD domains 
SYNOPSIS
    

`gcloud active-directory domains trusts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Managed Microsoft AD domains. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/active-directory/domains/trusts/create)`
     Create a Microsoft Active Directory Trust between a Managed Microsoft AD domain and another domain. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/active-directory/domains/trusts/delete)`
     Delete an Active Directory Trust between a Managed Microsoft AD domain and a target domain. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/active-directory/domains/trusts/update)`
     Update target DNS IP addresses for a Managed Microsoft AD trust. 
`[validate-state](https://docs.cloud.google.com/sdk/gcloud/reference/active-directory/domains/trusts/validate-state)`
     Validate the state of a Managed Microsoft AD trust.
