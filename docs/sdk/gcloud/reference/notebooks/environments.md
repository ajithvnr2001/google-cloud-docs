#  gcloud notebooks environments Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud notebooks environments - notebooks Environments Command Group 
SYNOPSIS
    

`gcloud notebooks environments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Notebooks Environments Command Group. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/environments/create)`
     Request for creating environments. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/environments/delete)`
     Request for deleting environments. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/environments/describe)`
     Request for describing environments. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/environments/list)`
     Request for listing environments. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha notebooks environments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/notebooks/environments)
    
    
    [gcloud beta notebooks environments](https://docs.cloud.google.com/sdk/gcloud/reference/beta/notebooks/environments)
