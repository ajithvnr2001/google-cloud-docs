NAME
    

gcloud transcoder - manage Transcoder jobs and job templates 
SYNOPSIS
    

`gcloud transcoder` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Transcoder jobs and job templates. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/transcoder/jobs)`
     Manage Cloud Transcoder jobs. 
`[templates](https://docs.cloud.google.com/sdk/gcloud/reference/transcoder/templates)`
     Manage Cloud Transcoder job templates.
