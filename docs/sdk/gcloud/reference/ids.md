NAME
    

gcloud ids - manage Cloud IDS 
SYNOPSIS
    

`gcloud ids` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     More information on Cloud IDS Endpoints can be found at <https://cloud.google.com/cloud-ids>
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/ids/endpoints)`
     Create and manage Cloud IDS Endpoints. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha ids](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ids)
    
    
    [gcloud beta ids](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ids)
