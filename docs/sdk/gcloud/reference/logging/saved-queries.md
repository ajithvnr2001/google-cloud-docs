NAME
    

gcloud logging saved-queries - manage Cloud Logging saved queries 
SYNOPSIS
    

`gcloud logging saved-queries` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Cloud Logging saved queries. A saved query describes a query that has been saved by a user. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/logging/saved-queries/create)`
     Create a Logging saved query. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/logging/saved-queries/delete)`
     Delete a Logging saved query. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/logging/saved-queries/describe)`
     A command that describes a Logging saved query. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/logging/saved-queries/list)`
     List Logging saved queries. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/logging/saved-queries/update)`
     Update Logging saved queries.
