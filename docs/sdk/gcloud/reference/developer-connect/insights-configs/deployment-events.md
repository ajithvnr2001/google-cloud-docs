NAME
    

gcloud developer-connect insights-configs deployment-events - manage Deployment Event resources 
SYNOPSIS
    

`gcloud developer-connect insights-configs deployment-events` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Deployment Event resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/deployment-events/describe)`
     Describe a deploymentEvent. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/deployment-events/list)`
     List deploymentEvents. 
NOTES
     This variant is also available:
