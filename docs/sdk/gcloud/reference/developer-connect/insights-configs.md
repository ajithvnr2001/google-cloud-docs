#  gcloud developer-connect insights-configs Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud developer-connect insights-configs - manage Insights Config resources 
SYNOPSIS
    

`gcloud developer-connect insights-configs` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Insights Config resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[deployment-events](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/deployment-events)`
     Manage Deployment Event resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/create)`
     Create an insight config. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/delete)`
     Delete insightsConfigs. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/describe)`
     Describe insightsConfigs. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/list)`
     List insightsConfigs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/insights-configs/update)`
     Update the configuration of an insight config. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha developer-connect insights-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/insights-configs)
    
    
    [gcloud beta developer-connect insights-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/insights-configs)
