NAME
    

gcloud sql import - provides commands to import Cloud SQL instances 
SYNOPSIS
    

`gcloud sql import` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Provides commands to import Cloud SQL instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[bak](https://docs.cloud.google.com/sdk/gcloud/reference/sql/import/bak)`
     Import data into a Cloud SQL instance from a BAK file. 
`[csv](https://docs.cloud.google.com/sdk/gcloud/reference/sql/import/csv)`
     Imports data into a Cloud SQL instance from a CSV file. 
`[sql](https://docs.cloud.google.com/sdk/gcloud/reference/sql/import/sql)`
     Imports data into a Cloud SQL instance from a SQL dump file. 
`[tde](https://docs.cloud.google.com/sdk/gcloud/reference/sql/import/tde)`
     Import TDE certificate into a Cloud SQL for SQL Server instance. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha sql import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/import)
    
    
    [gcloud beta sql import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/import)
