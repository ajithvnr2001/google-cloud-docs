NAME
    

gcloud sql ssl entraid-certs - provide commands for managing Entra ID certificates of Cloud SQL instances 
SYNOPSIS
    

`gcloud sql ssl entraid-certs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Provide commands for managing Entra ID certificates of Cloud SQL instances, including creating, listing, rotating in, and rolling back certificates. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/sql/ssl/entraid-certs/create)`
     Create an Entra ID certificate for a Cloud SQL instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/sql/ssl/entraid-certs/list)`
     List all Entra ID certificates for a Cloud SQL instance. 
`[rollback](https://docs.cloud.google.com/sdk/gcloud/reference/sql/ssl/entraid-certs/rollback)`
     Roll back to the previous Entra ID certificate for a Cloud SQL instance. 
`[rotate](https://docs.cloud.google.com/sdk/gcloud/reference/sql/ssl/entraid-certs/rotate)`
     Rotate in the upcoming Entra ID certificate for a Cloud SQL instance. 
NOTES
