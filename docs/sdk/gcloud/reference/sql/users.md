NAME
    

gcloud sql users - provide commands for managing Cloud SQL users 
SYNOPSIS
    

`gcloud sql users` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Provide commands for managing Cloud SQL users including creating, listing, and deleting users. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[assign-roles](https://docs.cloud.google.com/sdk/gcloud/reference/sql/users/assign-roles)`
     Updates a user's database roles in a given instance. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/sql/users/create)`
     Creates a user in a given instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/sql/users/delete)`
     Deletes a Cloud SQL user in a given instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/sql/users/describe)`
     Retrieves information about a Cloud SQL user in a given instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/sql/users/list)`
     Lists Cloud SQL users in a given instance. 
`[set-password](https://docs.cloud.google.com/sdk/gcloud/reference/sql/users/set-password)`
     Changes a user's password in a given instance. 
`[set-password-policy](https://docs.cloud.google.com/sdk/gcloud/reference/sql/users/set-password-policy)`
     Replaces a user's password policy in a given instance. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha sql users](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/users)
    
    
    [gcloud beta sql users](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/users)
