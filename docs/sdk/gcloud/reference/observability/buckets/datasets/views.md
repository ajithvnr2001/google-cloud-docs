NAME
    

gcloud observability buckets datasets views - commands to read Views within Datasets 
SYNOPSIS
    

`gcloud observability buckets datasets views` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     A view corresponds to a read-only representation of a subset of the data in a Dataset. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/observability/buckets/datasets/views/describe)`
     Describe views. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/observability/buckets/datasets/views/list)`
     List views. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta observability buckets datasets views](https://docs.cloud.google.com/sdk/gcloud/reference/beta/observability/buckets/datasets/views)
