NAME
    

gcloud tasks - manage Cloud Tasks queues and tasks 
SYNOPSIS
    

`gcloud tasks` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Cloud Tasks queues and tasks. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[cmek-config](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/cmek-config)`
     Get or change CMEK configuration for Cloud Tasks. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/locations)`
     Get information about Cloud Tasks locations. 
`[queues](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/queues)`
     Manage Cloud Tasks queues. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[buffer](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/buffer)`
     Buffers a task into a queue. 
`[create-app-engine-task](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/create-app-engine-task)`
     Create and add a task that targets App Engine. 
`[create-http-task](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/create-http-task)`
     Create and add a task that targets a HTTP endpoint. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/delete)`
     Delete a task from a queue. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/describe)`
     Show details about a task. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/list)`
     List tasks. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/tasks/run)`
     Force a task to run now. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha tasks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/tasks)
    
    
    [gcloud beta tasks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/tasks)
