NAME
    

gcloud metastore operations - manage Dataproc Metastore operations 
SYNOPSIS
    

`gcloud metastore operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataproc Metastore operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/operations/cancel)`
     Cancel a Dataproc Metastore operation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/operations/delete)`
     Delete one or more completed Dataproc Metastore operations. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/operations/describe)`
     Show metadata for a Dataproc Metastore operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/operations/list)`
     List Dataproc Metastore operations. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/operations/wait)`
     Poll a long-running Dataproc Metastore operation until it completes. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha metastore operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/operations)
    
    
    [gcloud beta metastore operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/operations)
