NAME
    

gcloud metastore services - manage Dataproc Metastore services 
SYNOPSIS
    

`gcloud metastore services` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataproc Metastore services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/backups)`
     Manage backups under Dataproc Metastore services. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/export)`
     Export metadata from a Dataproc Metastore service. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/import)`
     Import metadata into a Dataproc Metastore service. 
`[migrations](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/migrations)`
     Manage the migration to a Dataproc Metastore service. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/add-iam-policy-binding)`
     Add an IAM policy binding to a service. 
`[alter-metadata-resource-location](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/alter-metadata-resource-location)`
     Alter metadata resource location. 
`[alter-table-properties](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/alter-table-properties)`
     Alter metadata table properties. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/create)`
     Create a Dataproc Metastore service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/delete)`
     Delete one or more Dataproc Metastore services. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/describe)`
     Describe a Dataproc Metastore service. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/get-iam-policy)`
     Get the IAM policy for the service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/list)`
     List Dataproc Metastore services. 
`[move-table-to-database](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/move-table-to-database)`
     Move table to another database. 
`[query-metadata](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/query-metadata)`
     Execute a SQL query against a Dataproc Metastore Service's metadata. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/remove-iam-policy-binding)`
     Remove an IAM policy binding from a service. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/restore)`
     Restore a Dataproc Metastore service. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/set-iam-policy)`
     Set the IAM policy for the service. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/update)`
     Update a Dataproc Metastore service. 
NOTES
     These variants are also available:
