NAME
    

gcloud metastore services export - export metadata from a Dataproc Metastore service 
SYNOPSIS
    

`gcloud metastore services export` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Export metadata from a Dataproc Metastore service. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[gcs](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/export/gcs)`
     Export metadata from a Dataproc Metastore service to Google Cloud Storage. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha metastore services export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/export)
    
    
    [gcloud beta metastore services export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/export)
