NAME
    

gcloud emulators spanner - manage your local Spanner emulator 
SYNOPSIS
    

`gcloud emulators spanner` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     This set of commands allows you to start and use a local Spanner emulator. 
EXAMPLES
     To start a local Cloud Spanner emulator, run: 
    
    
    [gcloud emulators spanner start](https://docs.cloud.google.com/sdk/gcloud/reference/emulators/spanner/start)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[env-init](https://docs.cloud.google.com/sdk/gcloud/reference/emulators/spanner/env-init)`
     Print the commands required to export Spanner emulator's env variables. 
`[notices](https://docs.cloud.google.com/sdk/gcloud/reference/emulators/spanner/notices)`
     Print third-party notices for the local Cloud Spanner emulator. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/emulators/spanner/start)`
     Start a local Cloud Spanner emulator. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha emulators spanner](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/emulators/spanner)
    
    
    [gcloud beta emulators spanner](https://docs.cloud.google.com/sdk/gcloud/reference/beta/emulators/spanner)
