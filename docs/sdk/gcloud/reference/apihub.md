NAME
    

gcloud apihub - manage Apihub resources 
SYNOPSIS
    

`gcloud apihub` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Apihub resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[addons](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/addons)`
     Manage Addon resources. 
`[api-hub-instances](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/api-hub-instances)`
     Manage Api Hub Instance resources. 
`[apis](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis)`
     Manage Api resources. 
`[attributes](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/attributes)`
     Manage Attribute resources. 
`[curations](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/curations)`
     Manage Curation resources. 
`[dependencies](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/dependencies)`
     Manage Dependency resources. 
`[deployments](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/deployments)`
     Manage Deployment resources. 
`[discovered-api-observations](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/discovered-api-observations)`
     Manage Discovered Api Observation resources. 
`[external-apis](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/external-apis)`
     Manage External Api resources. 
`[host-project-registrations](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/host-project-registrations)`
     Manage Host Project Registration resources. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/locations)`
     Location-scoped operations for API Hub. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/operations)`
     Manage Operation resources. 
`[plugins](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/plugins)`
     Manage Plugin resources. 
`[runtime-project-attachments](https://docs.cloud.google.com/sdk/gcloud/reference/apihub/runtime-project-attachments)`
     Manage Runtime Project Attachment resources. 
NOTES
     This variant is also available:
