NAME
    

gcloud access-approval requests dismiss - dismiss an Access Approval request 
SYNOPSIS
    

`gcloud access-approval requests dismiss` `NAME` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Dismiss an Access Approval request. Note: this does not deny access to the resource if another request has been made and approved for the same resource. This will raise an error if the request does not exist. 
EXAMPLES
     To dismiss an approval request using its name (e.g. projects/12345/approvalRequests/abc123), run: 
    
    
    gcloud access-approval requests dismiss projects/12345/approvalRequests/abc123

POSITIONAL ARGUMENTS
    

`NAME`
     Name of the Access Approval request to invalidate
