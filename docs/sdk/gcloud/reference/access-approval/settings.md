#  gcloud access-approval settings Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud access-approval settings - manage Access Approval settings 
SYNOPSIS
    

`gcloud access-approval settings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Access Approval settings can be set on projects, folders, or organizations. The settings apply hierarchically. For example, enabling Access Approval at the organization level enables it for all folders and projects under the organization. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/access-approval/settings/delete)`
     Delete Access Approval settings. 
`[get](https://docs.cloud.google.com/sdk/gcloud/reference/access-approval/settings/get)`
     Get Access Approval settings. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/access-approval/settings/update)`
     Update Access Approval settings.
