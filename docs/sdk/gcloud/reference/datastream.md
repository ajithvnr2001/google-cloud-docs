NAME
    

gcloud datastream - manage Cloud Datastream resources 
SYNOPSIS
    

`gcloud datastream` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Commands for managing Cloud Datastream resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[connection-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/connection-profiles)`
     Manage Datastream connection profiles. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/locations)`
     Manage Datastream location resources. 
`[objects](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/objects)`
     Manage Datastream stream objects. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/operations)`
     Manage Datastream operations. 
`[private-connections](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/private-connections)`
     Manage Datastream private connections. 
`[routes](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/routes)`
     Manage Datastream routes. 
`[streams](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/streams)`
     Manage Datastream stream resources. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta datastream](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream)
