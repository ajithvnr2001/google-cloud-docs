NAME
    

gcloud parametermanager - parameter Manager is a single source of truth for your parameters 
SYNOPSIS
    

`gcloud parametermanager` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Parameter Manager stores, accesses, and manages the lifecycle of your application parameters. It aims to make management of sensitive application parameters effortless for customers without diminishing focus on security. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[parameters](https://docs.cloud.google.com/sdk/gcloud/reference/parametermanager/parameters)`
     Manage Parameter Manager parameter resources. 
`[templates](https://docs.cloud.google.com/sdk/gcloud/reference/parametermanager/templates)`
     Manage Parameter Manager template resources. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta parametermanager](https://docs.cloud.google.com/sdk/gcloud/reference/beta/parametermanager)
