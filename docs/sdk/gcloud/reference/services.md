NAME
    

gcloud services - list, enable and disable APIs and services 
SYNOPSIS
    

`gcloud services` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     The gcloud services command group lets you manage your project's access to services provided by Google and third parties. 
EXAMPLES
     To see how to enable a service, run: 
    
    
    [gcloud services enable](https://docs.cloud.google.com/sdk/gcloud/reference/services/enable) --help

To see how to list services, run: 
    
    
    [gcloud services list](https://docs.cloud.google.com/sdk/gcloud/reference/services/list) --help

To see how to disable a service, run: 
    
    
    [gcloud services disable](https://docs.cloud.google.com/sdk/gcloud/reference/services/disable) --help

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/services/api-keys)`
     Manage API keys. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/services/operations)`
     Manage Operation for various services. 
`[peered-dns-domains](https://docs.cloud.google.com/sdk/gcloud/reference/services/peered-dns-domains)`
     Peered DNS domains for various private service connections. 
`[vpc-peerings](https://docs.cloud.google.com/sdk/gcloud/reference/services/vpc-peerings)`
     VPC Peerings to various services. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/services/disable)`
     Disable a service for consumption for a project. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/services/enable)`
     Enables a service for consumption for a project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/services/list)`
     List services for a project. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services)
    
    
    [gcloud beta services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services)
