#  gcloud service-directory locations Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud service-directory locations - manage Service Directory locations 
SYNOPSIS
    

`gcloud service-directory locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Service Directory locations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/locations/describe)`
     Describes a location. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/locations/list)`
     Lists locations. 
NOTES
     These variants are also available: 
    
    
    [gcloud alpha service-directory locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/locations)
