NAME
    

gcloud service-directory namespaces - manage Service Directory namespaces 
SYNOPSIS
    

`gcloud service-directory namespaces` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Service Directory namespaces. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/add-iam-policy-binding)`
     Adds IAM policy binding to a namespace. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/create)`
     Creates a namespace. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/delete)`
     Deletes a namespace. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/describe)`
     Describes a namespace. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/get-iam-policy)`
     Gets IAM policy for a namespace. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/list)`
     Lists namespaces. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/remove-iam-policy-binding)`
     Removes IAM policy binding from a namespace. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/set-iam-policy)`
     Sets IAM policy for a namespace. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/namespaces/update)`
     Updates a namespace. 
NOTES
     These variants are also available:
