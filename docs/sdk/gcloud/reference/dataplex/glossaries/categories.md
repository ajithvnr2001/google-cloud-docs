#  gcloud dataplex glossaries categories Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud dataplex glossaries categories - manage Dataplex glossary categories 
SYNOPSIS
    

`gcloud dataplex glossaries categories` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     A glossary category represents a collection of glossary categories and glossary terms within a glossary that are related to each other. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/glossaries/categories/create)`
     Creates a glossary category. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/glossaries/categories/delete)`
     Deletes a glossary category. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/glossaries/categories/describe)`
     Describes a glossary category. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/glossaries/categories/list)`
     List glossary categories. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/glossaries/categories/update)`
     Updates a glossary category. 
NOTES
     This variant is also available:
