NAME
    

gcloud dataplex zones actions - manage Dataplex zone resource actions 
SYNOPSIS
    

`gcloud dataplex zones actions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplex zone resource actions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/zones/actions/list)`
     List Dataplex zone actions. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex zones actions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/zones/actions)
