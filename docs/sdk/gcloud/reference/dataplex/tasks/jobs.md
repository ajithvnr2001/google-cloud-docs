NAME
    

gcloud dataplex tasks jobs - manage Dataplex Jobs services 
SYNOPSIS
    

`gcloud dataplex tasks jobs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplex Jobs services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/tasks/jobs/cancel)`
     Cancel a Dataplex Job running a particular task. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/tasks/jobs/describe)`
     Describe a Dataplex job running a particular task. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/tasks/jobs/list)`
     List job runs of a Dataplex task resource. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex tasks jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/tasks/jobs)
