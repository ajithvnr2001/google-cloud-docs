NAME
    

gcloud dataplex lakes - manage Dataplex Lake resources 
SYNOPSIS
    

`gcloud dataplex lakes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplex Lake resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[actions](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/actions)`
     Manage Dataplex lake resource actions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/add-iam-policy-binding)`
     Add IAM policy binding to a Dataplex lake resource. 
`[authorize](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/authorize)`
     Authorize a service agent to manage resources. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/create)`
     Create a Dataplex lake resource. 
`[deauthorize](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/deauthorize)`
     Deauthorize a service agent from managing resources. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/delete)`
     Delete a Dataplex lake resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/describe)`
     Describe a Dataplex lake resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/get-iam-policy)`
     Get the IAM policy for a Dataplex lake resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/list)`
     List Dataplex lake resources under a project. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/remove-iam-policy-binding)`
     Remove IAM policy binding from a Dataplex lake resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/set-iam-policy)`
     Set the IAM policy to a Dataplex lake as defined in a JSON or YAML file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/lakes/update)`
     Update a Dataplex lake resource. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex lakes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/lakes)
