NAME
    

gcloud dataplex dbt metadata-jobs - manage Dataplex metadata jobs that ingest dbt-core metadata 
SYNOPSIS
    

`gcloud dataplex dbt metadata-jobs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplex metadata jobs that ingest dbt-core metadata. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/dbt/metadata-jobs/create)`
     Transform dbt-core artifacts and import them into Dataplex Catalog. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex dbt metadata-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/dbt/metadata-jobs)
