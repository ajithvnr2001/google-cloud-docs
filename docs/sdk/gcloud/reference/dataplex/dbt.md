NAME
    

gcloud dataplex dbt - ingest dbt-core metadata into Dataplex Knowledge Catalog 
SYNOPSIS
    

`gcloud dataplex dbt` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Ingest dbt-core metadata into Dataplex Knowledge Catalog. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[metadata-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/dbt/metadata-jobs)`
     Manage Dataplex metadata jobs that ingest dbt-core metadata. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex dbt](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/dbt)
