NAME
    

gcloud dataplex data-products - manage Dataplex Data Product resources 
SYNOPSIS
    

`gcloud dataplex data-products` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplex Data Product resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[data-assets](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/data-assets)`
     Manage Dataplex Data Asset resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/add-iam-policy-binding)`
     Add IAM policy binding to a Dataplex data product resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/create)`
     Create a Dataplex data product resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/delete)`
     Delete a Dataplex Data Product resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/describe)`
     Describe a Dataplex Data Product resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/get-iam-policy)`
     Get the IAM policy for a Dataplex data product. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/list)`
     List Dataplex Data Product resources. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/remove-iam-policy-binding)`
     Remove IAM policy binding from a Dataplex data product resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/set-iam-policy)`
     Set the IAM policy to a Dataplex data product as defined in a JSON or YAML file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/update)`
     Update a Dataplex data product resource. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex data-products](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products)
