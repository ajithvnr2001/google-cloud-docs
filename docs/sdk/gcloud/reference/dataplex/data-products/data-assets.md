NAME
    

gcloud dataplex data-products data-assets - manage Dataplex Data Asset resources 
SYNOPSIS
    

`gcloud dataplex data-products data-assets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Dataplex Data Asset resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/data-assets/create)`
     Create a Dataplex data asset resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/data-assets/delete)`
     Delete a Dataplex data asset resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/data-assets/describe)`
     Describe a Dataplex data asset resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/data-assets/list)`
     List Dataplex data asset resources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/data-products/data-assets/update)`
     Update a Dataplex data asset resource. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha dataplex data-products data-assets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataplex/data-products/data-assets)
