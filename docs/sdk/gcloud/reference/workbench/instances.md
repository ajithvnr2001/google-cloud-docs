#  gcloud workbench instances Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud workbench instances - workbench Instances command group 
SYNOPSIS
    

`gcloud workbench instances` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Workbench Instances command group. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/add-iam-policy-binding)`
     Adds IAM policy binding for a workbench instance. 
`[check-instance-upgradability](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/check-instance-upgradability)`
     Checks if a workbench instance is upgradeable. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/create)`
     Creates a workbench instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/delete)`
     Deletes a workbench instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/describe)`
     Describes a workbench instance. 
`[diagnose](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/diagnose)`
     Diagnoses a workbench instance. 
`[get-config](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/get-config)`
     Describes the valid configurations for workbench instances. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/get-iam-policy)`
     Gets IAM policy for a workbench instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/list)`
     Lists workbench instances. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/remove-iam-policy-binding)`
     Removes IAM policy binding for a workbench instance. 
`[reset](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/reset)`
     Resets a workbench instance. 
`[resize-disk](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/resize-disk)`
     Resizes the workbench instance's disk. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/restore)`
     Restores the workbench instance to a snapshot state. 
`[rollback](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/rollback)`
     Rolls back a workbench instance. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/set-iam-policy)`
     Sets the IAM policy for a workbench instance. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/start)`
     Starts a workbench instance. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/stop)`
     Stops a workbench instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/update)`
     Updates a workbench instance. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances/upgrade)`
     Upgrades a workbench instance.
