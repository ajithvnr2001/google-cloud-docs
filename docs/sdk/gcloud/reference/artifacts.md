NAME
    

gcloud artifacts - manage Artifact Registry resources 
SYNOPSIS
    

`gcloud artifacts` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Artifact Registry resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[apt](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/apt)`
     Manage Artifact Registry Debian packages. 
`[attachments](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/attachments)`
     Manage Artifact Registry attachments. 
`[docker](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/docker)`
     Manage Artifact Registry container images and tags. 
`[files](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/files)`
     Manage Artifact Registry files. 
`[generic](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/generic)`
     Manage Artifact Registry generic artifacts. 
`[go](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/go)`
     Manage Artifact Registry Go modules. 
`[image-streaming-cache](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/image-streaming-cache)`
     Manage Artifact Registry image streaming caches. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/locations)`
     Manage Artifact Registry resource locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/operations)`
     Manage Artifact Registry long-running operations. 
`[packages](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/packages)`
     Manage Artifact Registry packages. 
`[print-settings](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/print-settings)`
     Print snippets to add to native tools settings files. 
`[projects](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/projects)`
     Manage Artifact Registry project-level configurations for a specific location. 
`[repositories](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/repositories)`
     Manage Artifact Registry repositories. 
`[rules](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/rules)`
     Manage Artifact Registry rules. 
`[sbom](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/sbom)`
     Manage Artifact SBOMs. 
`[settings](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/settings)`
     Manage Artifact Registry project settings. 
`[tags](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/tags)`
     Manage Artifact Registry tags. 
`[versions](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/versions)`
     Manage Artifact Registry package versions. 
`[vpcsc-config](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/vpcsc-config)`
     Manage Artifact Registry VPC Service Controls configuration for remote repositories. 
`[vulnerabilities](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/vulnerabilities)`
     Manage Artifact Vulnerabilities. 
`[yum](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/yum)`
     Manage Artifact Registry RPM packages.
