NAME
    

gcloud beta services - list, enable and disable APIs and services 
SYNOPSIS
    

`gcloud beta services` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud services command group lets you manage your project's access to services provided by Google and third parties. 
EXAMPLES
     To see how to enable a service, run: 
    
    
    [gcloud beta services enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/enable) --help

To see how to list services, run: 
    
    
    [gcloud beta services list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/list) --help

To see how to disable a service, run: 
    
    
    [gcloud beta services disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/disable) --help

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[api-keys](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/api-keys)`
     `(BETA)` Manage API keys. 
`[groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/groups)`
     `(BETA)` View service group information. 
`[identity](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/identity)`
     `(BETA)` Manage service identity. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/operations)`
     `(BETA)` Manage Operation for various services. 
`[peered-dns-domains](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/peered-dns-domains)`
     `(BETA)` Peered DNS domains for various private service connections. 
`[policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/policies)`
     `(BETA)` Get/update consumer policies and get the effective policy. 
`[vpc-peerings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/vpc-peerings)`
     `(BETA)` VPC Peerings to various services. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/disable)`
     `(BETA)` Disable a service for consumption for a project, folder or organization. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/enable)`
     `(BETA)` Enables a service for consumption for a project, folder or organization. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/list)`
     `(BETA)` List services for a project, folder or organization. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud services](https://docs.cloud.google.com/sdk/gcloud/reference/services)
    
    
    [gcloud alpha services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services)
