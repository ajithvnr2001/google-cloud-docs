NAME
    

gcloud beta iam workload-identity-pools providers - manage IAM workload identity pool providers 
SYNOPSIS
    

`gcloud beta iam workload-identity-pools providers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing IAM workload identity pool providers. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/operations)`
     `(BETA)` Manage IAM workload identity pool provider long running operations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create-aws](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/create-aws)`
     `(BETA)` Create a new AWS workload identity pool provider. 
`[create-oidc](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/create-oidc)`
     `(BETA)` Create a new OIDC workload identity pool provider. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/delete)`
     `(BETA)` Delete a workload identity pool provider. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/describe)`
     `(BETA)` Describe a workload identity pool provider. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/list)`
     `(BETA)` List workload identity pool providers. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/undelete)`
     `(BETA)` Undelete a workload identity pool provider. 
`[update-aws](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/update-aws)`
     `(BETA)` Update an AWS workload identity pool provider. 
`[update-oidc](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers/update-oidc)`
     `(BETA)` Update an OIDC workload identity pool provider. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iam workload-identity-pools providers](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools/providers)
    
    
    [gcloud alpha iam workload-identity-pools providers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools/providers)
