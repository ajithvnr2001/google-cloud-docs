NAME
    

gcloud beta iam roles - create and manipulate roles 
SYNOPSIS
    

`gcloud beta iam roles` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manipulate roles. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles/copy)`
     `(BETA)` Create a role from an existing role. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles/create)`
     `(BETA)` Create a custom role for a project or an organization. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles/delete)`
     `(BETA)` Delete a custom role from an organization or a project. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles/describe)`
     `(BETA)` Show metadata for a role. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles/list)`
     `(BETA)` List predefined roles, or the custom roles for an organization or project. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles/undelete)`
     `(BETA)` Undelete a custom role from an organization or a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/roles/update)`
     `(BETA)` Update an IAM custom role. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iam roles](https://docs.cloud.google.com/sdk/gcloud/reference/iam/roles)
    
    
    [gcloud alpha iam roles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/roles)
