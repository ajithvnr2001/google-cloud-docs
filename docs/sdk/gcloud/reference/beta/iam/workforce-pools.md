NAME
    

gcloud beta iam workforce-pools - create and manage workforce pools 
SYNOPSIS
    

`gcloud beta iam workforce-pools` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud beta iam workforce-pools group lets you create and manage workforce pools for organizations on the Google Cloud Platform. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/operations)`
     `(BETA)` Manage IAM workforce pool long-running operations. 
`[providers](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers)`
     `(BETA)` Create and manage workforce pool providers. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/create)`
     `(BETA)` Create a new workforce pool under an organization. 
`[create-cred-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/create-cred-config)`
     `(BETA)` Create a configuration file for generated credentials. 
`[create-login-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/create-login-config)`
     `(BETA)` Create a login configuration file to enable sign-in via a web-based authorization flow using Workforce Identity Federation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/delete)`
     `(BETA)` Delete a workforce pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/describe)`
     `(BETA)` Describe a workforce pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/list)`
     `(BETA)` List the workforce pools for an organization. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/undelete)`
     `(BETA)` Undelete a workforce pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/update)`
     `(BETA)` Update a workforce pool. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iam workforce-pools](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools)
    
    
    [gcloud alpha iam workforce-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workforce-pools)
