NAME
    

gcloud beta iam service-accounts keys - manage service account keys 
SYNOPSIS
    

`gcloud beta iam service-accounts keys` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage service account keys. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/service-accounts/keys/create)`
     `(BETA)` Create a service account key. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/service-accounts/keys/delete)`
     `(BETA)` Delete a service account key. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/service-accounts/keys/disable)`
     `(BETA)` Disable a service account key. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/service-accounts/keys/enable)`
     `(BETA)` Enable a service account key. 
`[get-public-key](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/service-accounts/keys/get-public-key)`
     `(BETA)` Get the public key for a service account key pair. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/service-accounts/keys/list)`
     `(BETA)` List the keys for a service account. 
`[upload](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/service-accounts/keys/upload)`
     `(BETA)` Upload a public key for an IAM service account. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iam service-accounts keys](https://docs.cloud.google.com/sdk/gcloud/reference/iam/service-accounts/keys)
    
    
    [gcloud alpha iam service-accounts keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/service-accounts/keys)
