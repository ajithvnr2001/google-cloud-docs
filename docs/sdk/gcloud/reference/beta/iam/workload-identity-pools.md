NAME
    

gcloud beta iam workload-identity-pools - manage IAM workload identity pools 
SYNOPSIS
    

`gcloud beta iam workload-identity-pools` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing IAM workload identity pools. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/operations)`
     `(BETA)` Manage IAM workload identity pool long running operations. 
`[providers](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/providers)`
     `(BETA)` Manage IAM workload identity pool providers. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/create)`
     `(BETA)` Create a new workload identity pool. 
`[create-cred-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/create-cred-config)`
     `(BETA)` Create a configuration file for generated credentials. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/delete)`
     `(BETA)` Delete a workload identity pool. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/describe)`
     `(BETA)` Describe a workload identity pool. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/list)`
     `(BETA)` List workload identity pools. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/undelete)`
     `(BETA)` Undelete a workload identity pool. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workload-identity-pools/update)`
     `(BETA)` Update a workload identity pool. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iam workload-identity-pools](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workload-identity-pools)
    
    
    [gcloud alpha iam workload-identity-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iam/workload-identity-pools)
