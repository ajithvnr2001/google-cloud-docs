NAME
    

gcloud beta iam workforce-pools providers - create and manage workforce pool providers 
SYNOPSIS
    

`gcloud beta iam workforce-pools providers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud beta iam workforce-pools providers group lets you create and manage workforce pool providers. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[keys](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/keys)`
     `(BETA)` Create and manage IAM workforce pool provider keys. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/operations)`
     `(BETA)` Manage IAM workforce pool provider long-running operations. 
`[scim-tenants](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/scim-tenants)`
     `(BETA)` Manage IAM workforce identity pool provider SCIM tenants. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create-oidc](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/create-oidc)`
     `(BETA)` Create a new OIDC workforce pool provider. 
`[create-saml](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/create-saml)`
     `(BETA)` Create a new SAML workforce pool provider. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/delete)`
     `(BETA)` Delete a workforce pool provider. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/describe)`
     `(BETA)` Describe a workforce pool provider. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/list)`
     `(BETA)` List workforce pool providers. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/undelete)`
     `(BETA)` Undelete a workforce pool provider. 
`[update-oidc](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/update-oidc)`
     `(BETA)` Update an OIDC workforce pool provider. 
`[update-saml](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iam/workforce-pools/providers/update-saml)`
     `(BETA)` Update a new SAML workforce pool provider. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iam workforce-pools providers](https://docs.cloud.google.com/sdk/gcloud/reference/iam/workforce-pools/providers)
