NAME
    

gcloud beta developer-connect connections git-repository-links - manage git repository link resources 
SYNOPSIS
    

`gcloud beta developer-connect connections git-repository-links` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage git repository link resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links/create)`
     `(BETA)` Create a git repository link. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links/delete)`
     `(BETA)` Delete a single git repository link. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links/describe)`
     `(BETA)` Get details of a single git repository link. 
`[fetch-read-token](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links/fetch-read-token)`
     `(BETA)` Fetch the read token of a given gitRepositoryLink. 
`[fetch-read-write-token](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links/fetch-read-write-token)`
     `(BETA)` Fetch the read/write token of a given gitRepositoryLink. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links/list)`
     `(BETA)` List all git repository links in a connection. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections/git-repository-links/update)`
     `(BETA)` Update a git repository link to enable metrics collection. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud developer-connect connections git-repository-links](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect/connections/git-repository-links)
    
    
    [gcloud alpha developer-connect connections git-repository-links](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect/connections/git-repository-links)
