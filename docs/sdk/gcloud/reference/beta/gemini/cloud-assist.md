NAME
    

gcloud beta gemini cloud-assist - manage Gemini Cloud Assist 
SYNOPSIS
    

`gcloud beta gemini cloud-assist` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Gemini Cloud Assist. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[investigations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations)`
     `(BETA)` Create and manage Gemini Cloud Assist investigations. 
NOTES
     This command is currently in beta and might change without notice.
