NAME
    

gcloud beta gemini cloud-assist investigations - create and manage Gemini Cloud Assist investigations 
SYNOPSIS
    

`gcloud beta gemini cloud-assist investigations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Gemini Cloud Assist investigations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/add-iam-policy-binding)`
     `(BETA)` Adds an IAM policy binding for an investigation. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/create)`
     `(BETA)` Create a new investigation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/delete)`
     `(BETA)` Delete an Investigation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/describe)`
     `(BETA)` Show metadata for an investigation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/get-iam-policy)`
     `(BETA)` Get IAM policy for an investigation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/list)`
     `(BETA)` List Gemini Cloud Assist Investigations. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/remove-iam-policy-binding)`
     `(BETA)` Removes an IAM policy binding from an investigation. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/set-iam-policy)`
     `(BETA)` Sets IAM policy for an investigation. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/gemini/cloud-assist/investigations/update)`
     `(BETA)` Update an existing investigation. 
NOTES
     This command is currently in beta and might change without notice.
