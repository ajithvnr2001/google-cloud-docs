NAME
    

gcloud beta ai-platform jobs submit - AI Platform Jobs submit commands 
SYNOPSIS
    

`gcloud beta ai-platform jobs submit` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` AI Platform Jobs submit commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[prediction](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai-platform/jobs/submit/prediction)`
     `(BETA)` Start an AI Platform batch prediction job. 
`[training](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai-platform/jobs/submit/training)`
     `(BETA)` Submit an AI Platform training job. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud ai-platform jobs submit](https://docs.cloud.google.com/sdk/gcloud/reference/ai-platform/jobs/submit)
    
    
    [gcloud alpha ai-platform jobs submit](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai-platform/jobs/submit)
