NAME
    

gcloud beta ai-platform local - AI Platform Local commands 
SYNOPSIS
    

`gcloud beta ai-platform local` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` AI Platform Local commands. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[predict](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai-platform/local/predict)`
     `(BETA)` Run prediction locally. 
`[train](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai-platform/local/train)`
     `(BETA)` Run an AI Platform training job locally. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud ai-platform local](https://docs.cloud.google.com/sdk/gcloud/reference/ai-platform/local)
    
    
    [gcloud alpha ai-platform local](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai-platform/local)
