NAME
    

gcloud beta datapipelines pipeline job - manage Data Pipeline Jobs 
SYNOPSIS
    

`gcloud beta datapipelines pipeline job` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Job resources of Data Pipelines. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/job/list)`
     `(BETA)` List Jobs within a pipeline in a specific project and region. 
NOTES
     This command is currently in beta and might change without notice.
