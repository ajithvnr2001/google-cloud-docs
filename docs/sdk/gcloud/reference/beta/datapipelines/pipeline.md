NAME
    

gcloud beta datapipelines pipeline - manage Data Pipelines 
SYNOPSIS
    

`gcloud beta datapipelines pipeline` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Data Pipelines resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[job](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/job)`
     `(BETA)` Manage Data Pipeline Jobs. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/create)`
     `(BETA)` Creates Data Pipelines Pipeline. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/delete)`
     `(BETA)` Delete Data Pipelines Pipeline. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/describe)`
     `(BETA)` Describe Data Pipelines Pipeline. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/list)`
     `(BETA)` List Pipelines in a project and location. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/run)`
     `(BETA)` Run Data Pipelines Pipeline. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/stop)`
     `(BETA)` Stop Data Pipelines Pipeline. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datapipelines/pipeline/update)`
     `(BETA)` Updates a Data Pipelines Pipeline. 
NOTES
     This command is currently in beta and might change without notice.
