NAME
    

gcloud beta scc - manage Cloud SCC resources 
SYNOPSIS
    

`gcloud beta scc` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Google Cloud SCC (Security Command Center) resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[assets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/assets)`
     `(BETA)` Manage Cloud SCC (Security Command Center) assets. 
`[findings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/findings)`
     `(BETA)` Manage Cloud SCC (Security Command Center) findings. 
`[notifications](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/notifications)`
     `(BETA)` Manage Cloud SCC (Security Command Center) notifications. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/operations)`
     `(BETA)` Manage Cloud SCC (Security Command Center) operations. 
`[sources](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/sources)`
     `(BETA)` Manage Cloud SCC (Security Command Center) finding sources. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud scc](https://docs.cloud.google.com/sdk/gcloud/reference/scc)
    
    
    [gcloud alpha scc](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc)
