NAME
    

gcloud beta network-services multicast-group-consumer-activations - manage Network Services MulticastGroupConsumerActivations 
SYNOPSIS
    

`gcloud beta network-services multicast-group-consumer-activations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Services MulticastGroupConsumerActivations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-group-consumer-activations/create)`
     `(BETA)` Create a multicast group consumer activation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-group-consumer-activations/delete)`
     `(BETA)` Delete a multicast group consumer activation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-group-consumer-activations/describe)`
     `(BETA)` Describe a multicast group consumer activation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-group-consumer-activations/list)`
     `(BETA)` List multicast group consumer activations. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-group-consumer-activations/update)`
     `(BETA)` Update a multicast group consumer activation.
