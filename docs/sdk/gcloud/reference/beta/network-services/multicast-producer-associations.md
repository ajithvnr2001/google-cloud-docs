NAME
    

gcloud beta network-services multicast-producer-associations - manage Network Services MulticastProducerAssociations 
SYNOPSIS
    

`gcloud beta network-services multicast-producer-associations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Services MulticastProducerAssociations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-producer-associations/create)`
     `(BETA)` Create a multicast producer association. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-producer-associations/delete)`
     `(BETA)` Delete a multicast producer association. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-producer-associations/describe)`
     `(BETA)` Describe a multicast producer associations. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-producer-associations/list)`
     `(BETA)` List multicast producer associations. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/multicast-producer-associations/update)`
     `(BETA)` Update a multicast producer association. 
NOTES
