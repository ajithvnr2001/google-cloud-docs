NAME
    

gcloud beta network-services telemetry-policies - manage Network Services Telemetry Policies 
SYNOPSIS
    

`gcloud beta network-services telemetry-policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Services Telemetry Policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/telemetry-policies/delete)`
     `(BETA)` Delete a TelemetryPolicy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/telemetry-policies/describe)`
     `(BETA)` Describe a TelemetryPolicy. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/telemetry-policies/export)`
     `(BETA)` Export a TelemetryPolicy. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/telemetry-policies/import)`
     `(BETA)` Import a TelemetryPolicy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/telemetry-policies/list)`
     `(BETA)` List TelemetryPolicies. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha network-services telemetry-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/telemetry-policies)
