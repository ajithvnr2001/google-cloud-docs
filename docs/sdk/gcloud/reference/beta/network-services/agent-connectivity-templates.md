NAME
    

gcloud beta network-services agent-connectivity-templates - manage Network Services Agent Connectivity Templates 
SYNOPSIS
    

`gcloud beta network-services agent-connectivity-templates` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Services Agent Connectivity Templates. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/agent-connectivity-templates/delete)`
     `(BETA)` Delete an Agent Connectivity Template. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/agent-connectivity-templates/describe)`
     `(BETA)` Describe a Agent Connectivity Template. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/agent-connectivity-templates/export)`
     `(BETA)` Export an Agent Connectivity Template. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/agent-connectivity-templates/import)`
     `(BETA)` Import an Agent Connectivity Template. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/agent-connectivity-templates/list)`
     `(BETA)` List Agent Connectivity Templates. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud network-services agent-connectivity-templates](https://docs.cloud.google.com/sdk/gcloud/reference/network-services/agent-connectivity-templates)
    
    
    [gcloud alpha network-services agent-connectivity-templates](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-services/agent-connectivity-templates)
