NAME
    

gcloud beta network-security ull-mirroring-collectors - manage Ull Mirroring Collector resources 
SYNOPSIS
    

`gcloud beta network-security ull-mirroring-collectors` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Ull Mirroring Collector resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/ull-mirroring-collectors/rules)`
     `(BETA)` Manage Ull Mirroring Collector Rule resources. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-security ull-mirroring-collectors](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/ull-mirroring-collectors)
