NAME
    

gcloud beta network-security authz-policies - manage Network Security `AuthzPolicy` resources 
SYNOPSIS
    

`gcloud beta network-security authz-policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Security `AuthzPolicy` resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/authz-policies/delete)`
     `(BETA)` Delete an `AuthzPolicy` resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/authz-policies/describe)`
     `(BETA)` Describe an `AuthzPolicy` resource. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/authz-policies/import)`
     `(BETA)` Import an `AuthzPolicy` resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/authz-policies/list)`
     `(BETA)` List `AuthzPolicy` resources. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-security authz-policies](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/authz-policies)
