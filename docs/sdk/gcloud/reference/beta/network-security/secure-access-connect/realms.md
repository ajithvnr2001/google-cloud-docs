NAME
    

gcloud beta network-security secure-access-connect realms - manage Secure Access Connect realms 
SYNOPSIS
    

`gcloud beta network-security secure-access-connect realms` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Secure Access Connect realms. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/secure-access-connect/realms/create)`
     `(BETA)` Create a SAC realm. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/secure-access-connect/realms/delete)`
     `(BETA)` Delete a SAC realm. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/secure-access-connect/realms/describe)`
     `(BETA)` Describe a SAC realm. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/secure-access-connect/realms/list)`
     `(BETA)` List SAC realms. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-security secure-access-connect realms](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/secure-access-connect/realms)
