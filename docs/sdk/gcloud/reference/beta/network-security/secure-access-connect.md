NAME
    

gcloud beta network-security secure-access-connect - manage Secure Access Connect resources 
SYNOPSIS
    

`gcloud beta network-security secure-access-connect` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Secure Access Connect resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[attachments](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/secure-access-connect/attachments)`
     `(BETA)` Manage Secure Access Connect attachments. 
`[realms](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/secure-access-connect/realms)`
     `(BETA)` Manage Secure Access Connect realms. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-security secure-access-connect](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/secure-access-connect)
