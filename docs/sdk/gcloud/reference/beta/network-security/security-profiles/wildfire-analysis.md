NAME
    

gcloud beta network-security security-profiles wildfire-analysis - manage Security Profiles - WildFire Analysis Profile 
SYNOPSIS
    

`gcloud beta network-security security-profiles wildfire-analysis` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Security Profiles - WildFire Analysis Profile. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-inline-cloud-analysis-rule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/add-inline-cloud-analysis-rule)`
     `(BETA)` Add a WildFire inline cloud analysis rule to a WildFire Analysis Profile. 
`[add-inline-ml-exception](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/add-inline-ml-exception)`
     `(BETA)` Add a WildFire inline machine learning exception to a WildFire Analysis Profile. 
`[add-override](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/add-override)`
     `(BETA)` Add an override to a WildFire Analysis Profile. 
`[add-submission-rule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/add-submission-rule)`
     `(BETA)` Add a WildFire submission rule to a WildFire Analysis Profile. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/create)`
     `(BETA)` Create a new WildFire Analysis Profile. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/delete)`
     `(BETA)` Delete a WildFire Analysis Profile. 
`[delete-inline-cloud-analysis-rule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/delete-inline-cloud-analysis-rule)`
     `(BETA)` Delete a WildFire inline cloud analysis rule from a WildFire Analysis Profile. 
`[delete-inline-ml-exception](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/delete-inline-ml-exception)`
     `(BETA)` Delete a WildFire inline machine learning exception from a WildFire Analysis Profile. 
`[delete-override](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/delete-override)`
     `(BETA)` Delete an override from a WildFire Analysis Profile. 
`[delete-submission-rule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/delete-submission-rule)`
     `(BETA)` Delete a WildFire submission rule from a WildFire Analysis Profile.

     `(BETA)` Describe a WildFire Analysis Security Profile.

     `(BETA)` Update a WildFire Analysis Security Profile. 
`[update-override](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/security-profiles/wildfire-analysis/update-override)`
     `(BETA)` Update an override in a WildFire Analysis Profile.
