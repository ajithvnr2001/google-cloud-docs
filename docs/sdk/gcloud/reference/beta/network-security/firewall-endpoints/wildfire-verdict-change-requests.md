NAME
    

gcloud beta network-security firewall-endpoints wildfire-verdict-change-requests - manage WildFire Verdict Change Requests 
SYNOPSIS
    

`gcloud beta network-security firewall-endpoints wildfire-verdict-change-requests` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage WildFire Verdict Change Requests. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/firewall-endpoints/wildfire-verdict-change-requests/create)`
     `(BETA)` Create a WildFire Verdict Change Request. 
`[get](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/firewall-endpoints/wildfire-verdict-change-requests/get)`
     `(BETA)` Get a WildFire Verdict Change Request. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/firewall-endpoints/wildfire-verdict-change-requests/list)`
     `(BETA)` List WildFire Verdict Change Requests. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available:
