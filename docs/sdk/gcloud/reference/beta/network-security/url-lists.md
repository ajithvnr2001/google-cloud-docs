NAME
    

gcloud beta network-security url-lists - manage Network Security Url Lists 
SYNOPSIS
    

`gcloud beta network-security url-lists` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Security Url Lists. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/url-lists/delete)`
     `(BETA)` Delete Url List. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/url-lists/export)`
     `(BETA)` Export Url List. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/url-lists/import)`
     `(BETA)` Import Url List. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/url-lists/list)`
     `(BETA)` List Url Lists. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud network-security url-lists](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/url-lists)
    
    
    [gcloud alpha network-security url-lists](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/url-lists)
