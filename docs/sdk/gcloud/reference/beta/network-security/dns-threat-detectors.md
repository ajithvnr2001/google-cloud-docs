NAME
    

gcloud beta network-security dns-threat-detectors - manage Dns Threat Detector resources 
SYNOPSIS
    

`gcloud beta network-security dns-threat-detectors` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Dns Threat Detector resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/dns-threat-detectors/create)`
     `(BETA)` Create a DnsThreatDetector resource. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/dns-threat-detectors/delete)`
     `(BETA)` Delete a DnsThreatDetector resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/dns-threat-detectors/describe)`
     `(BETA)` Describe a DnsThreatDetector resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/dns-threat-detectors/list)`
     `(BETA)` List DnsThreatDetector resources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/dns-threat-detectors/update)`
     `(BETA)` Update a DnsThreatDetector resource. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud network-security dns-threat-detectors](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/dns-threat-detectors)
    
    
    [gcloud alpha network-security dns-threat-detectors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/dns-threat-detectors)
