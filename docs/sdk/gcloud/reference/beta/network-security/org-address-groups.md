NAME
    

gcloud beta network-security org-address-groups - manage Network Security AddressGroups 
SYNOPSIS
    

`gcloud beta network-security org-address-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Security AddressGroups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-items](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/add-items)`
     `(BETA)` Add items to an address group of organization. 
`[clone-items](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/clone-items)`
     `(BETA)` Clone items from source address group of organization. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/create)`
     `(BETA)` Create an address group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/delete)`
     `(BETA)` Delete address group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/describe)`
     `(BETA)` Describe an address group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/list)`
     `(BETA)` List address groups. 
`[list-references](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/list-references)`
     `(BETA)` Lists References of an Organization Address Group. 
`[remove-items](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/remove-items)`
     `(BETA)` Remove items from an address group of organization. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-security/org-address-groups/update)`
     `(BETA)` Update an address group. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud network-security org-address-groups](https://docs.cloud.google.com/sdk/gcloud/reference/network-security/org-address-groups)
    
    
    [gcloud alpha network-security org-address-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-security/org-address-groups)
