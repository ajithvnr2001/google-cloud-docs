NAME
    

gcloud beta model-armor - model Armor is a service offering LLM-agnostic security and AI safety measures to mitigate risks associated with the use of large language models (LLMs)
SYNOPSIS
    

`gcloud beta model-armor` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Model Armor is a service offering LLM-agnostic security and AI safety measures to mitigate risks associated with the use of large language models (LLMs). 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[floorsettings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/floorsettings)`
     `(BETA)` Manage FloorSettings resources. 
`[templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates)`
     `(BETA)` Manage Template resources. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud model-armor](https://docs.cloud.google.com/sdk/gcloud/reference/model-armor)
    
    
    [gcloud alpha model-armor](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/model-armor)
