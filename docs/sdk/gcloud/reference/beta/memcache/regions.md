NAME
    

gcloud beta memcache regions - manage Cloud Memorystore Memcached regions 
SYNOPSIS
    

`gcloud beta memcache regions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Memorystore Memcached regions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memcache/regions/describe)`
     `(BETA)` Display metadata for a Memorystore Memcached region. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memcache/regions/list)`
     `(BETA)` List Memorystore Memcached regions. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud memcache regions](https://docs.cloud.google.com/sdk/gcloud/reference/memcache/regions)
    
    
    [gcloud alpha memcache regions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memcache/regions)
