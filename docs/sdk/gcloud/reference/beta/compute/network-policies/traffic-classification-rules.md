NAME
    

gcloud beta compute network-policies traffic-classification-rules - read and manipulate Compute Engine network policy rules 
SYNOPSIS
    

`gcloud beta compute network-policies traffic-classification-rules` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate Compute Engine network policy rules. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-policies/traffic-classification-rules/create)`
     `(BETA)` Creates a Compute Engine network policy rule. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-policies/traffic-classification-rules/delete)`
     `(BETA)` Deletes a Compute Engine network policy rule. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-policies/traffic-classification-rules/describe)`
     `(BETA)` Describes a Compute Engine network policy rule. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-policies/traffic-classification-rules/update)`
     `(BETA)` Updates a Compute Engine network policy rule. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha compute network-policies traffic-classification-rules](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-policies/traffic-classification-rules)
