NAME
    

gcloud beta compute os-config - manage OS Config tasks for Compute Engine VM instances 
SYNOPSIS
    

`gcloud beta compute os-config` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage OS Config tasks for Compute Engine VM instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[guest-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/guest-policies)`
     `(BETA)` Manage guest OS policies for Compute Engine VM instances. 
`[patch-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/patch-deployments)`
     `(BETA)` Manage guest OS patch deployments for Compute Engine VM instances. 
`[patch-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/patch-jobs)`
     `(BETA)` Manage OS patches for Compute Engine VMs. 
`[policy-orchestrators](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/policy-orchestrators)`
     `(BETA)` Manage VM Manager policy orchestrators. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[os-upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/os-upgrade)`
     `(BETA)` Upgrade the instances OS version. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute os-config](https://docs.cloud.google.com/sdk/gcloud/reference/compute/os-config)
    
    
    [gcloud alpha compute os-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/os-config)
