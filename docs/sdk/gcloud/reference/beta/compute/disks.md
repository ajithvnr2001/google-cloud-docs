NAME
    

gcloud beta compute disks - read and manipulate Compute Engine disks 
SYNOPSIS
    

`gcloud beta compute disks` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate Compute Engine disks. 

For more information about disks, see the [disks documentation](https://cloud.google.com/compute/docs/disks/). 

See also: [Disks API](https://cloud.google.com/compute/docs/reference/rest/v1/disks). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[bulk](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/bulk)`
     `(BETA)` Manipulate multiple Compute Engine disks with single command executions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a Compute Engine disk. 
`[add-labels](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/add-labels)`
     `(BETA)` Add labels to Google Compute Engine persistent disks. 
`[add-resource-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/add-resource-policies)`
     `(BETA)` Add resource policies to a Compute Engine disk. 
`[convert](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/convert)`
     `(BETA)` Convert a Compute Engine Persistent Disk volume to a Hyperdisk volume. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/create)`
     `(BETA)` Create Compute Engine persistent disks. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/delete)`
     `(BETA)` Delete a Compute Engine disk. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/describe)`
     `(BETA)` Describe a Compute Engine disk. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Compute Engine disk. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/list)`
     `(BETA)` List Google Compute Engine disks. 
`[move](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/move)`
     `(BETA)` Move a disk between zones. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding from a Compute Engine disk. 
`[remove-labels](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/remove-labels)`
     `(BETA)` Remove labels from Google Compute Engine persistent disks. 
`[remove-resource-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/remove-resource-policies)`
     `(BETA)` Remove resource policies from a Compute Engine disk. 
`[resize](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/resize)`
     `(BETA)` Resize a disk or disks. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Compute Engine disk. 
`[snapshot](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/snapshot)`
     `(BETA)` Create snapshots of Compute Engine persistent disks. 
`[start-async-replication](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/start-async-replication)`
     `(BETA)` Start asynchronous replication on a Compute Engine persistent disk. 
`[stop-async-replication](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/stop-async-replication)`
     `(BETA)` Stop async replication on a Compute Engine persistent disk. 
`[stop-group-async-replication](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/stop-group-async-replication)`
     `(BETA)` Consistently stops a group of asynchronously replicating disks. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine disk. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/update)`
     `(BETA)` Update a Compute Engine persistent disk. 
`[update-kms-key](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disks/update-kms-key)`
     `(BETA)` Update the KMS key of a Hyperdisk or Persistent Disk.
