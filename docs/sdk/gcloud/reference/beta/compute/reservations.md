NAME
    

gcloud beta compute reservations - manage Compute Engine reservations 
SYNOPSIS
    

`gcloud beta compute reservations` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Compute Engine reservations. 

For more information about reservations, see the [reservations documentation](https://cloud.google.com/compute/docs/instances/reserving-zonal-resources). 

See also: [Reservations API](https://cloud.google.com/compute/docs/reference/rest/v1/reservations). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[blocks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/blocks)`
     `(BETA)` Manage Compute Engine reservation blocks. 
`[hosts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/hosts)`
     `(BETA)` Read Compute Engine reservation hosts. 
`[slots](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/slots)`
     `(BETA)` Manage Compute Engine reservation slots. 
`[sub-blocks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/sub-blocks)`
     `(BETA)` Manage Compute Engine reservation sub blocks. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a Compute Engine reservation. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/create)`
     `(BETA)` Create a Compute Engine reservation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/delete)`
     `(BETA)` Delete a Compute Engine reservation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/describe)`
     `(BETA)` Show details about a Compute Engine reservation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Compute Engine reservation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/list)`
     `(BETA)` List Compute Engine reservations. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/perform-maintenance)`
     `(BETA)` Perform maintenance on a reservation, only applicable to reservations with reservation blocks. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding from a Compute Engine reservation. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Compute Engine reservation. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine reservation. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/update)`
     `(BETA)` Update Compute Engine reservations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute reservations](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations)
    
    
    [gcloud alpha compute reservations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations)
    
    
    [gcloud preview compute reservations](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/reservations)
