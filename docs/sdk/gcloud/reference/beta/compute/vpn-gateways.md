NAME
    

gcloud beta compute vpn-gateways - read and manipulate Highly Available VPN Gateways 
SYNOPSIS
    

`gcloud beta compute vpn-gateways` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate highly available (HA) VPN gateways for Cloud VPN. 

For more information about HA VPN gateways, see [Cloud VPN overview](https://cloud.google.com//network-connectivity/docs/vpn/concepts/overview). 

See also: [VPN Gateways API](https://cloud.google.com/compute/docs/reference/rest/v1/vpnGateways). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-gateways/create)`
     `(BETA)` Create a new Compute Engine Highly Available VPN gateway. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-gateways/delete)`
     `(BETA)` Delete Compute Engine Highly Available VPN Gateways. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-gateways/describe)`
     `(BETA)` Describe a Compute Engine Highly Available VPN Gateway. 
`[get-status](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-gateways/get-status)`
     `(BETA)` Get status of a Compute Engine Highly Available VPN Gateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-gateways/list)`
     `(BETA)` List Google Compute Engine Highly Available VPN Gateways. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-gateways/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine VPN gateway. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/vpn-gateways/update)`
     `(BETA)` Update a Compute Engine Highly Available VPN gateway. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available:
