NAME
    

gcloud beta compute instances ops-agents policies - manage Google Cloud Observability agents policies that install, update, and uninstall agents for Compute Engine VM instances 
SYNOPSIS
    

`gcloud beta compute instances ops-agents policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Google Cloud Observability agents policies that install, update, and uninstall agents for Compute Engine VM instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instances/ops-agents/policies/create)`
     `(BETA)` Create a Google Cloud's operations suite agents (Ops Agents) policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instances/ops-agents/policies/delete)`
     `(BETA)` Delete a Google Cloud's operations suite agents (Ops Agents) policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instances/ops-agents/policies/describe)`
     `(BETA)` Describe a Google Cloud's operations suite agents (Ops Agents) policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instances/ops-agents/policies/list)`
     `(BETA)` List Google Cloud's operations suite agents (Ops Agents) policies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instances/ops-agents/policies/update)`
     `(BETA)` Update a Google Cloud operations suite agent (Ops Agent) policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available:
