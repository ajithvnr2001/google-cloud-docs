NAME
    

gcloud beta compute zones - list Compute Engine zones 
SYNOPSIS
    

`gcloud beta compute zones` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` List Compute Engine zones. 

For more information about zones, see the [zones documentation](https://cloud.google.com/compute/docs/regions-zones/). 

See also: [Zones API](https://cloud.google.com/compute/docs/reference/rest/v1/zones). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/zones/describe)`
     `(BETA)` Describe a Compute Engine zone. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/zones/list)`
     `(BETA)` List Google Compute Engine zones. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute zones](https://docs.cloud.google.com/sdk/gcloud/reference/compute/zones)
    
    
    [gcloud alpha compute zones](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/zones)
    
    
    [gcloud preview compute zones](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/zones)
