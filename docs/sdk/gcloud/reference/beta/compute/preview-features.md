NAME
    

gcloud beta compute preview-features - read and manipulate Compute Engine Preview Features 
SYNOPSIS
    

`gcloud beta compute preview-features` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate Compute Engine Preview Features. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/preview-features/describe)`
     `(BETA)` Describe a preview feature. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/preview-features/list)`
     `(BETA)` View preview features. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/preview-features/update)`
     `(BETA)` Update a preview feature's activation status. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute preview-features](https://docs.cloud.google.com/sdk/gcloud/reference/compute/preview-features)
    
    
    [gcloud alpha compute preview-features](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/preview-features)
    
    
    [gcloud preview compute preview-features](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/preview-features)
