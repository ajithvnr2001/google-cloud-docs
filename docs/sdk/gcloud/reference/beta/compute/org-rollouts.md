NAME
    

gcloud beta compute org-rollouts - read and manipulate Compute Engine organization rollouts 
SYNOPSIS
    

`gcloud beta compute org-rollouts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate Compute Engine organization rollouts. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/org-rollouts/cancel)`
     `(BETA)` Cancel an organization rollout. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/org-rollouts/delete)`
     `(BETA)` Delete an organization rollout. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/org-rollouts/describe)`
     `(BETA)` Describe an organization rollout. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/org-rollouts/list)`
     `(BETA)` List Google Compute Engine Organization Rollouts. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha compute org-rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/org-rollouts)
