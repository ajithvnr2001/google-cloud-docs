NAME
    

gcloud beta compute sole-tenancy node-types - read Compute Engine sole-tenancy node types 
SYNOPSIS
    

`gcloud beta compute sole-tenancy node-types` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Node types are the types of dedicated Compute Engine servers that are used for nodes in node groups. Node types will differ in the amount of vCPU, Memory, and local SSD space. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/sole-tenancy/node-types/describe)`
     `(BETA)` Describe a Compute Engine node type. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/sole-tenancy/node-types/list)`
     `(BETA)` List Google Compute Engine node types. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute sole-tenancy node-types](https://docs.cloud.google.com/sdk/gcloud/reference/compute/sole-tenancy/node-types)
