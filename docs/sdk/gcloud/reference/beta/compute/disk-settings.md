NAME
    

gcloud beta compute disk-settings - read Compute Engine disk settings 
SYNOPSIS
    

`gcloud beta compute disk-settings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Disks settings allows the configuration of various disk-related behavior. 

At this time, only the access location is allowed to be configured. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disk-settings/describe)`
     `(BETA)` Describe a Google Compute Engine disk setting. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/disk-settings/update)`
     `(BETA)` Update disk settings. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha compute disk-settings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/disk-settings)
