NAME
    

gcloud beta compute reservations hosts - read Compute Engine reservation hosts 
SYNOPSIS
    

`gcloud beta compute reservations hosts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read Compute Engine reservation hosts. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/hosts/describe)`
     `(BETA)` Describe a Google Compute Engine host in a reservation. 
`[get-version](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/hosts/get-version)`
     `(BETA)` Get software versions for a Compute Engine host in a reservation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/hosts/list)`
     `(BETA)` List Google Compute Engine hosts for a reservation. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute reservations hosts](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/hosts)
    
    
    [gcloud alpha compute reservations hosts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/hosts)
