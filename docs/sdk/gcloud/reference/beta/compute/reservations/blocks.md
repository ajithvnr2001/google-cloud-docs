NAME
    

gcloud beta compute reservations blocks - manage Compute Engine reservation blocks 
SYNOPSIS
    

`gcloud beta compute reservations blocks` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Compute Engine reservation blocks. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/blocks/describe)`
     `(BETA)` Describe a Compute Engine reservation block. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/blocks/list)`
     `(BETA)` List Compute Engine reservation blocks. 
`[perform-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/blocks/perform-maintenance)`
     `(BETA)` Perform maintenance on a reservation block within a reservation. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/blocks/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Compute Engine reservation block. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/reservations/blocks/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine reservation block. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute reservations blocks](https://docs.cloud.google.com/sdk/gcloud/reference/compute/reservations/blocks)
    
    
    [gcloud alpha compute reservations blocks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/reservations/blocks)
