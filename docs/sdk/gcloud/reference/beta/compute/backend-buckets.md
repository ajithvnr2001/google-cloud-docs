NAME
    

gcloud beta compute backend-buckets - read and manipulate backend buckets 
SYNOPSIS
    

`gcloud beta compute backend-buckets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate backend buckets. Backend buckets define Cloud Storage buckets that can serve content. URL maps define which requests are sent to which backend buckets. 

For more information about backend buckets, see the [backend buckets documentation](https://cloud.google.com/load-balancing/docs/https/ext-load-balancer-backend-buckets). 

See also: [Backend buckets API](https://cloud.google.com/compute/docs/reference/rest/v1/backendBuckets). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Compute Engine backend bucket. 
`[add-signed-url-key](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/add-signed-url-key)`
     `(BETA)` Add Cloud CDN Signed URL key to a backend bucket. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/create)`
     `(BETA)` Create a backend bucket. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/delete)`
     `(BETA)` Delete backend buckets. 
`[delete-signed-url-key](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/delete-signed-url-key)`
     `(BETA)` Delete Cloud CDN Signed URL key from a backend bucket. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/describe)`
     `(BETA)` Describe a backend bucket. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Compute Engine backend bucket. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/list)`
     `(BETA)` List Google Compute Engine backend buckets. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a Compute Engine backend bucket. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/set-iam-policy)`
     `(BETA)` Set the IAM policy binding for a Compute Engine backend bucket. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine backend bucket. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/backend-buckets/update)`
     `(BETA)` Update a backend bucket. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available:

    [gcloud alpha compute backend-buckets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/backend-buckets)
