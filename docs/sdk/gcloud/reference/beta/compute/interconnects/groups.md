NAME
    

gcloud beta compute interconnects groups - create or manipulate interconnect groups 
SYNOPSIS
    

`gcloud beta compute interconnects groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create or manipulate interconnect groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-members](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/add-members)`
     `(BETA)` Add member interconnects to a Compute Engine interconnect group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/create)`
     `(BETA)` Create a Compute Engine interconnect group. 
`[create-members](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/create-members)`
     `(BETA)` Create new member interconnects in a Compute Engine interconnect group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/delete)`
     `(BETA)` Delete Compute Engine interconnect groups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/describe)`
     `(BETA)` Describe a Compute Engine interconnect group. 
`[get-operational-status](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/get-operational-status)`
     `(BETA)` Get the operational status of a Compute Engine interconnect group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/list)`
     `(BETA)` List interconnect groups. 
`[remove-members](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/remove-members)`
     `(BETA)` Remove member interconnects from a Compute Engine interconnect group. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Compute Engine interconnect group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/interconnects/groups/update)`
     `(BETA)` Update a Compute Engine interconnect group. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute interconnects groups](https://docs.cloud.google.com/sdk/gcloud/reference/compute/interconnects/groups)
    
    
    [gcloud alpha compute interconnects groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/interconnects/groups)
    
    
    [gcloud preview compute interconnects groups](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/interconnects/groups)
