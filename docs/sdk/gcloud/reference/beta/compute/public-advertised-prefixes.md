NAME
    

gcloud beta compute public-advertised-prefixes - manage public advertised prefix resources 
SYNOPSIS
    

`gcloud beta compute public-advertised-prefixes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage public advertised prefix resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/public-advertised-prefixes/create)`
     `(BETA)` Creates a Compute Engine public advertised prefix. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/public-advertised-prefixes/delete)`
     `(BETA)` Deletes a Compute Engine public advertised prefix. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/public-advertised-prefixes/describe)`
     `(BETA)` Describes a Compute Engine public advertised prefix. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/public-advertised-prefixes/list)`
     `(BETA)` List Google Compute Engine public advertised prefixes. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/public-advertised-prefixes/update)`
     `(BETA)` Updates a Compute Engine public advertised prefix. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute public-advertised-prefixes](https://docs.cloud.google.com/sdk/gcloud/reference/compute/public-advertised-prefixes)
    
    
    [gcloud alpha compute public-advertised-prefixes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/public-advertised-prefixes)
    
    
    [gcloud preview compute public-advertised-prefixes](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/public-advertised-prefixes)
