NAME
    

gcloud beta compute network-attachments - manage Compute Engine network attachment resources 
SYNOPSIS
    

`gcloud beta compute network-attachments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` List, create, describe, update and delete network attachments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-attachments/create)`
     `(BETA)` Create a Google Compute Engine network attachment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-attachments/delete)`
     `(BETA)` Delete one or more Google Compute Engine network attachments. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-attachments/describe)`
     `(BETA)` Describes a Google Compute Engine network attachment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-attachments/list)`
     `(BETA)` List Google Compute Engine network attachments. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-attachments/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Compute Engine network attachment. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-attachments/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine network attachment. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-attachments/update)`
     `(BETA)` Update a Google Compute Engine network attachment. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute network-attachments](https://docs.cloud.google.com/sdk/gcloud/reference/compute/network-attachments)
    
    
    [gcloud alpha compute network-attachments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-attachments)
    
    
    [gcloud preview compute network-attachments](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/network-attachments)
