NAME
    

gcloud beta compute security-policies - read and manipulate Cloud Armor security policies 
SYNOPSIS
    

`gcloud beta compute security-policies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate Cloud Armor security policies. 

Security policies are used to control access to Google Cloud HTTP/HTTPS load balancers. 

For more information about security policies, see [Security policies for HTTPS load balancing](https://cloud.google.com/armor/docs/security-policy-concepts#security_policies_for_https_load_balancing). 

See also: [Security policies API](https://cloud.google.com/compute/docs/reference/rest/v1/securityPolicies). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/rules)`
     `(BETA)` Read and manipulate Compute Engine security policies rules. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-layer7-ddos-defense-threshold-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/add-layer7-ddos-defense-threshold-config)`
     `(BETA)` Add a layer7 ddos defense threshold config to a Compute Engine security policy. 
`[add-user-defined-field](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/add-user-defined-field)`
     `(BETA)` Add a user defined field to a Compute Engine security policy. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/create)`
     `(BETA)` Create a Compute Engine security policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/delete)`
     `(BETA)` Delete security policies. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/describe)`
     `(BETA)` Describe a Compute Engine security policy. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/export)`
     `(BETA)` Export security policy configs into YAML or JSON files. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/import)`
     `(BETA)` Import security policy configs into your project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/list)`
     `(BETA)` List security policies. 
`[list-preconfigured-expression-sets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/list-preconfigured-expression-sets)`
     `(BETA)` List all available preconfigured expression sets. 
`[remove-layer7-ddos-defense-threshold-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/remove-layer7-ddos-defense-threshold-config)`
     `(BETA)` Remove a layer7 ddos defense threshold config from a Compute Engine security policy. 
`[remove-user-defined-field](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/remove-user-defined-field)`
     `(BETA)` Remove a user defined field from a Compute Engine security policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/security-policies/update)`
     `(BETA)` Update a Compute Engine security policy.
