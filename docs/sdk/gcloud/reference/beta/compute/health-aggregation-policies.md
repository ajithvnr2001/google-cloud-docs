NAME
    

gcloud beta compute health-aggregation-policies - manage health aggregation policies 
SYNOPSIS
    

`gcloud beta compute health-aggregation-policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage health aggregation policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-aggregation-policies/create)`
     `(BETA)` Create a health aggregation policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-aggregation-policies/delete)`
     `(BETA)` Delete a health aggregation policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-aggregation-policies/describe)`
     `(BETA)` Describe a health aggregation policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-aggregation-policies/list)`
     `(BETA)` List health aggregation policies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-aggregation-policies/update)`
     `(BETA)` Update a health aggregation policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute health-aggregation-policies](https://docs.cloud.google.com/sdk/gcloud/reference/compute/health-aggregation-policies)
    
    
    [gcloud alpha compute health-aggregation-policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/health-aggregation-policies)
