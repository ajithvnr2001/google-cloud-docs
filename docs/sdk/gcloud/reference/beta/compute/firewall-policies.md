NAME
    

gcloud beta compute firewall-policies - manage Compute Engine organization firewall policies 
SYNOPSIS
    

`gcloud beta compute firewall-policies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Compute Engine organization firewall policies. Organization firewall policies are used to control incoming/outgoing traffic. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[associations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/associations)`
     `(BETA)` Read and manipulate Compute Engine organization firewall policy associations. 
`[mirroring-rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/mirroring-rules)`
     `(BETA)` Read and manipulate Compute Engine organization firewall policy packet mirroring rules. 
`[rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/rules)`
     `(BETA)` Read and manipulate Compute Engine organization firewall policy rules. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[clone-rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/clone-rules)`
     `(BETA)` Replace the rules of a Compute Engine organization firewall policy with rules from another policy. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/create)`
     `(BETA)` Create a Compute Engine organization firewall policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/delete)`
     `(BETA)` Delete a Compute Engine organization firewall policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/describe)`
     `(BETA)` Describe a Compute Engine organization firewall policy. 
`[export-rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/export-rules)`
     `(BETA)` Export Compute Engine organization firewall policy rules. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Compute Engine organization firewall policy. 
`[import-rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/import-rules)`
     `(BETA)` Import Compute Engine organization firewall policy rules. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/list)`
     `(BETA)` List Compute Engine organization firewall policies. 
`[list-rules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/list-rules)`
     `(BETA)` List the rules of a Compute Engine organization firewall policy. 
`[move](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/move)`
     `(BETA)` Move a Compute Engine organization firewall policy. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Compute Engine organization firewall policy. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine organization firewall policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/firewall-policies/update)`
     `(BETA)` Update a Compute Engine organization firewall policy. 
NOTES
