NAME
    

gcloud beta compute network-endpoint-groups - read and manipulate Compute Engine network endpoint groups 
SYNOPSIS
    

`gcloud beta compute network-endpoint-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate network endpoint groups. 

For more information about network endpoint groups, see the [network endpoint groups documentation](https://cloud.google.com/load-balancing/docs/negs/). 

See also: [Network endpoint groups API](https://cloud.google.com/compute/docs/reference/rest/v1/networkEndpointGroups). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-endpoint-groups/create)`
     `(BETA)` Create a Google Compute Engine network endpoint group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-endpoint-groups/delete)`
     `(BETA)` Delete a Compute Engine network endpoint group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-endpoint-groups/describe)`
     `(BETA)` Describe a Compute Engine network endpoint group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-endpoint-groups/list)`
     `(BETA)` List Google Compute Engine network endpoint groups. 
`[list-network-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-endpoint-groups/list-network-endpoints)`
     `(BETA)` List network endpoints in a network endpoint group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/network-endpoint-groups/update)`
     `(BETA)` Update a Compute Engine network endpoint group. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available:

    [gcloud alpha compute network-endpoint-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/network-endpoint-groups)
