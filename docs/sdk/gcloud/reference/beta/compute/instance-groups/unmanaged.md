NAME
    

gcloud beta compute instance-groups unmanaged - read and manipulate Compute Engine unmanaged instance group 
SYNOPSIS
    

`gcloud beta compute instance-groups unmanaged` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate Compute Engine unmanaged instance groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/add-instances)`
     `(BETA)` Adds instances to an unmanaged instance group by name. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/create)`
     `(BETA)` Create a Compute Engine unmanaged instance group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/delete)`
     `(BETA)` Delete Compute Engine unmanaged instance groups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/describe)`
     `(BETA)` Describe an instance group. 
`[get-named-ports](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/get-named-ports)`
     `(BETA)` Lists the named ports for an instance group resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/list)`
     `(BETA)` List Google Compute Engine unmanaged instance groups. 
`[list-instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/list-instances)`
     `(BETA)` List instances present in the instance group. 
`[remove-instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/remove-instances)`
     `(BETA)` Removes resources from an unmanaged instance group by instance name. 
`[set-named-ports](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/instance-groups/unmanaged/set-named-ports)`
     `(BETA)` Sets the list of named ports for an instance group. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute instance-groups unmanaged](https://docs.cloud.google.com/sdk/gcloud/reference/compute/instance-groups/unmanaged)
    
    
    [gcloud alpha compute instance-groups unmanaged](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/instance-groups/unmanaged)
    
    
    [gcloud preview compute instance-groups unmanaged](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/instance-groups/unmanaged)
