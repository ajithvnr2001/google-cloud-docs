NAME
    

gcloud beta compute project-views describe - describe the Compute Engine project-view resource 
SYNOPSIS
    

`gcloud beta compute project-views describe` `--region`=`REGION` [`--project`=`PROJECT`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` `gcloud beta compute project-views describe` displays all data associated with the Compute Engine project-view resource. 
EXAMPLES
     To describe the project-view resource for region `us-central1`: 
    
    
    gcloud beta compute project-views describe --region=us-central1

REQUIRED FLAGS
    

`--region`=`REGION`
     Region of the project view. 
OPTIONAL FLAGS
    

`--project`=`PROJECT`
     Project ID for this request.
