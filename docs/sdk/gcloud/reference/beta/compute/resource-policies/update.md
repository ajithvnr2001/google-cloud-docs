NAME
    

gcloud beta compute resource-policies update - update Compute Engine Resource Policies 
SYNOPSIS
    

`gcloud beta compute resource-policies update` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Update Compute Engine Resource Policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[instance-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/resource-policies/update/instance-schedule)`
     `(BETA)` Update a Compute Engine Instance Schedule Resource Policy. 
`[snapshot-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/resource-policies/update/snapshot-schedule)`
     `(BETA)` Update a Compute Engine Snapshot Schedule Resource Policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute resource-policies update](https://docs.cloud.google.com/sdk/gcloud/reference/compute/resource-policies/update)
    
    
    [gcloud alpha compute resource-policies update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/resource-policies/update)
    
    
    [gcloud preview compute resource-policies update](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/resource-policies/update)
