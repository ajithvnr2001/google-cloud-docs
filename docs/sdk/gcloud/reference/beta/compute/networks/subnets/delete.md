NAME
    

gcloud beta compute networks subnets delete - delete Google Cloud subnetworks 
SYNOPSIS
    

`gcloud beta compute networks subnets delete` `NAME` [`NAME` …] [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` `gcloud beta compute networks subnets delete` deletes one or more Google Cloud subnetworks. Subnetworks can only be deleted when no other resources, such as VM instances, refer to them.". 
EXAMPLES
     To delete the subnetwork subnet-1 in the us-central1, run: 
    
    
    gcloud beta compute networks subnets delete subnet-1 --region=us-central1

POSITIONAL ARGUMENTS
    

`NAME` [`NAME` …]
     Names of the subnetworks to delete. 
FLAGS
    

`--region`=`REGION`
     Region of the subnetworks to delete. If not specified, you might be prompted to select a region (interactive mode only). 

To avoid prompting when this flag is omitted, you can set the ``compute/region`` property: 
    
    
    [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) compute/region REGION

A list of regions can be fetched by running: 
    
    
    [gcloud compute regions list](https://docs.cloud.google.com/sdk/gcloud/reference/compute/regions/list)

To unset the property, run: 
    
    
    [gcloud config unset](https://docs.cloud.google.com/sdk/gcloud/reference/config/unset) compute/region

Alternatively, the region can be stored in the environment variable ``CLOUDSDK_COMPUTE_REGION``.
