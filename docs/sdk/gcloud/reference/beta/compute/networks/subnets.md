NAME
    

gcloud beta compute networks subnets - list, describe, and delete, and update Compute Engine subnetworks 
SYNOPSIS
    

`gcloud beta compute networks subnets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read and manipulate VPC subnetworks. 

For more information about VPC, see the [VPC documentation](https://cloud.google.com/vpc/docs/vpc). 

See also: [Subnetworks API](https://cloud.google.com/compute/docs/reference/rest/v1/subnetworks). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Compute Engine subnetwork. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/create)`
     `(BETA)` Define a subnet for a network in custom subnet mode. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/delete)`
     `(BETA)` Delete Google Cloud subnetworks. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/describe)`
     `(BETA)` Describe a Compute Engine subnetwork. 
`[expand-ip-range](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/expand-ip-range)`
     `(BETA)` Expand the IP range of a Compute Engine subnetwork. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Compute Engine subnetwork. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/list)`
     `(BETA)` List Google Compute Engine subnetworks. 
`[list-usable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/list-usable)`
     `(BETA)` List Compute Engine subnetworks permitted for use. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a Compute Engine subnetwork. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Compute Engine subnetwork. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine subnetwork. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/networks/subnets/update)`
     `(BETA)` Updates properties of an existing Compute Engine subnetwork. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available:
