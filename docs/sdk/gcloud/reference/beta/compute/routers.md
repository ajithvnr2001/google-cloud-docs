NAME
    

gcloud beta compute routers - list, create, and delete Compute Engine routers 
SYNOPSIS
    

`gcloud beta compute routers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` List, create, and delete Cloud Routers. 

For more information about Cloud Routers, see the [Cloud Router documentation](https://cloud.google.com//network-connectivity/docs/router/concepts/overview). 

See also: [Routers API](https://cloud.google.com/compute/docs/reference/rest/v1/routers). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[nats](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/routers/nats)`
     `(BETA)` List, create, describe, and delete Cloud NAT. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-bgp-peer](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/routers/add-bgp-peer)`
     `(BETA)` Add a BGP peer to a Compute Engine router. 
`[add-interface](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/routers/add-interface)`
     `(BETA)` Add an interface to a Compute Engine router.

`[add-named-set-element](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/routers/add-named-set-element)`
     `(BETA)` Adds an element to an existing named set of a Compute Engine router. 
`[add-route-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/routers/add-route-policy)`
     `(BETA)` Add an empty route policy to a Compute Engine router.

     `(BETA)` Adds a new term to an existing route policy of a Comute Engine router.
