NAME
    

gcloud beta compute packet-mirrorings - manage Compute Engine packet mirroring resources 
SYNOPSIS
    

`gcloud beta compute packet-mirrorings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Compute Engine packet mirroring resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/packet-mirrorings/create)`
     `(BETA)` Create a Compute Engine packet mirroring policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/packet-mirrorings/delete)`
     `(BETA)` Delete a Compute Engine packet mirroring policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/packet-mirrorings/describe)`
     `(BETA)` Describe a Compute Engine packet mirroring policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/packet-mirrorings/list)`
     `(BETA)` List Google Compute Engine packet mirroring policies. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/packet-mirrorings/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a Compute Engine packet mirroring policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/packet-mirrorings/update)`
     `(BETA)` Update a Compute Engine packet mirroring policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute packet-mirrorings](https://docs.cloud.google.com/sdk/gcloud/reference/compute/packet-mirrorings)
    
    
    [gcloud alpha compute packet-mirrorings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/packet-mirrorings)
    
    
    [gcloud preview compute packet-mirrorings](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/packet-mirrorings)
