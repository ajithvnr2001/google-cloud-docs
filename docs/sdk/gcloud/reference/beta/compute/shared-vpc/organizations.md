NAME
    

gcloud beta compute shared-vpc organizations - configure organizations for Shared VPC networking 
SYNOPSIS
    

`gcloud beta compute shared-vpc organizations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Configure organizations for Shared VPC networking. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list-host-projects](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/shared-vpc/organizations/list-host-projects)`
     `(BETA)` List shared VPC host projects in a given organization. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute shared-vpc organizations](https://docs.cloud.google.com/sdk/gcloud/reference/compute/shared-vpc/organizations)
    
    
    [gcloud alpha compute shared-vpc organizations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/shared-vpc/organizations)
    
    
    [gcloud preview compute shared-vpc organizations](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/shared-vpc/organizations)
