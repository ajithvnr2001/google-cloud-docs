NAME
    

gcloud beta compute recoverable-snapshots - recover, list, describe and delete Compute Engine recoverable snapshots 
SYNOPSIS
    

`gcloud beta compute recoverable-snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Recover, list, describe and delete Compute Engine recoverable snapshots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/recoverable-snapshots/delete)`
     `(BETA)` Delete Compute Engine recoverable snapshots. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/recoverable-snapshots/describe)`
     `(BETA)` Describe a Compute Engine recoverable snapshot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/recoverable-snapshots/list)`
     `(BETA)` List Google Compute Engine recoverable snapshots. 
`[recover](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/recoverable-snapshots/recover)`
     `(BETA)` Recovers a Compute Engine recoverable snapshot. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/recoverable-snapshots/set-iam-policy)`
     `(BETA)` Set the IAM policy binding for a Compute Engine recoverable snapshot. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/recoverable-snapshots/test-iam-permissions)`
     `(BETA)` Test the IAM permissions for a Compute Engine recoverable snapshot. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha compute recoverable-snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/recoverable-snapshots)
