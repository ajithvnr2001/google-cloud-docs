NAME
    

gcloud beta compute regions - list Compute Engine regions 
SYNOPSIS
    

`gcloud beta compute regions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` List Compute Engine regions. 

For more information about regions, see the [regions documentation](https://cloud.google.com/compute/docs/regions-zones/). 

See also: [Regions API](https://cloud.google.com/compute/docs/reference/rest/v1/regions). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/regions/describe)`
     `(BETA)` Describe a Compute Engine region. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/regions/list)`
     `(BETA)` List Google Compute Engine regions. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute regions](https://docs.cloud.google.com/sdk/gcloud/reference/compute/regions)
    
    
    [gcloud alpha compute regions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/regions)
    
    
    [gcloud preview compute regions](https://docs.cloud.google.com/sdk/gcloud/reference/preview/compute/regions)
