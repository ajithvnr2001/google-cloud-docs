NAME
    

gcloud beta compute health-sources - manage health sources 
SYNOPSIS
    

`gcloud beta compute health-sources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage health sources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-sources/create)`
     `(BETA)` Create a health source. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-sources/delete)`
     `(BETA)` Delete a health source. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-sources/describe)`
     `(BETA)` Describe a health source. 
`[get-health](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-sources/get-health)`
     `(BETA)` Get health status of a health source. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-sources/list)`
     `(BETA)` List health sources. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-sources/test-iam-permissions)`
     `(BETA)` Test IAM permissions for a health source. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/health-sources/update)`
     `(BETA)` Update a health source. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud compute health-sources](https://docs.cloud.google.com/sdk/gcloud/reference/compute/health-sources)
    
    
    [gcloud alpha compute health-sources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/compute/health-sources)
