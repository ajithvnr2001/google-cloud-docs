NAME
    

gcloud beta compute os-config guest-policies - manage guest OS policies for Compute Engine VM instances 
SYNOPSIS
    

`gcloud beta compute os-config guest-policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage guest OS policies for Compute Engine VM instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/guest-policies/create)`
     `(BETA)` Create a guest policy for a project. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/guest-policies/delete)`
     `(BETA)` Delete the specified guest policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/guest-policies/describe)`
     `(BETA)` Describe the specified guest policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/guest-policies/list)`
     `(BETA)` List guest policies in a project. 
`[lookup](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/guest-policies/lookup)`
     `(BETA)` Display the guest policies that are applied to an instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/compute/os-config/guest-policies/update)`
     `(BETA)` Update the specified guest policy for a project. 
NOTES
     This command is currently in beta and might change without notice.
