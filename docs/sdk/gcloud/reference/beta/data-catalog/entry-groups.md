#  gcloud beta data-catalog entry-groups Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta data-catalog entry-groups - manage entry groups in Data Catalog 
SYNOPSIS
    

`gcloud beta data-catalog entry-groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` `(DEPRECATED)` Manage entry groups in Data Catalog. 

This command is deprecated. Please use `[gcloud dataplex entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/entry-groups)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/add-iam-policy-binding)`
     `(BETA)` `(DEPRECATED)` Add an IAM policy binding to a Data Catalog entry group. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/create)`
     `(BETA)` `(DEPRECATED)` Create a Data Catalog entry group. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/delete)`
     `(BETA)` `(DEPRECATED)` Delete a Data Catalog entry group. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/describe)`
     `(BETA)` `(DEPRECATED)` Describe a Data Catalog entry group. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/get-iam-policy)`
     `(BETA)` `(DEPRECATED)` Get the IAM policy for a Data Catalog entry group. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/list)`
     `(BETA)` `(DEPRECATED)` List all entry groups in a Data Catalog location. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/remove-iam-policy-binding)`
     `(BETA)` `(DEPRECATED)` Remove an IAM policy binding from a Data Catalog entry group. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/set-iam-policy)`
     `(BETA)` `(DEPRECATED)` Set the IAM policy for a Data Catalog entry group. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups/update)`
     `(BETA)` `(DEPRECATED)` Update a Data Catalog entry group. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud data-catalog entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/entry-groups)
    
    
    [gcloud alpha data-catalog entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/entry-groups)
