#  gcloud beta data-catalog taxonomies Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta data-catalog taxonomies - manage taxonomies in Data Catalog 
SYNOPSIS
    

`gcloud beta data-catalog taxonomies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage taxonomies in Data Catalog. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[policy-tags](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/policy-tags)`
     `(BETA)` Manage policy tags in Data Catalog. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Policy Tag Taxonomy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/describe)`
     `(BETA)` Describe a Policy Tag Taxonomy. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/export)`
     `(BETA)` Export a list of taxonomies from a certain project. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Policy Tag Taxonomy. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/import)`
     `(BETA)` Export a file with serialized taxonomies to a certain project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/list)`
     `(BETA)` List Cloud Policy Tag Taxonomies. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a policy tag taxonomy. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Policy Tag taxonomy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud data-catalog taxonomies](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/taxonomies)
    
    
    [gcloud alpha data-catalog taxonomies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog/taxonomies)
