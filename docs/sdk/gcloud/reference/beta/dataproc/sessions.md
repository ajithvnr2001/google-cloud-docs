#  gcloud beta dataproc sessions Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta dataproc sessions - create and manage Dataproc sessions 
SYNOPSIS
    

`gcloud beta dataproc sessions` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Dataproc sessions. 

Create a session: 
    
    
    [gcloud beta dataproc sessions create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/create)

List all sessions: 
    
    
    [gcloud beta dataproc sessions list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/list)

List session details: 
    
    
    [gcloud beta dataproc sessions describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/describe) SESSION_ID

Delete a session: 
    
    
    [gcloud beta dataproc sessions delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/delete) SESSION_ID

Terminate an active session: 
    
    
    [gcloud beta dataproc sessions terminate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/terminate) SESSION_ID

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/create)`
     `(BETA)` Create a Dataproc session. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/delete)`
     `(BETA)` Delete a session. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/describe)`
     `(BETA)` Describe a session. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/list)`
     `(BETA)` List sessions in a project. 
`[terminate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions/terminate)`
     `(BETA)` Terminate an active session. 
NOTES
     This command is currently in beta and might change without notice.
