NAME
    

gcloud beta dataproc batches - submit Dataproc batch jobs 
SYNOPSIS
    

`gcloud beta dataproc batches` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Submit Dataproc batch jobs. 

Submit a job: 
    
    
    [gcloud beta dataproc batches submit](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/submit)

List all batch jobs: 
    
    
    [gcloud beta dataproc batches list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/list)

List job details: 
    
    
    [gcloud beta dataproc batches describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/describe) JOB_ID

Delete a batch job: 
    
    
    [gcloud beta dataproc batches delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/delete) JOB_ID

Cancel a running batch job without removing the batch resource: 
    
    
    [gcloud beta dataproc batches cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/cancel) JOB_ID

View job output: 
    
    
    [gcloud beta dataproc batches wait](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/wait) JOB_ID

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[submit](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/submit)`
     `(BETA)` Submit a Dataproc batch job. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/cancel)`
     `(BETA)` Cancel a batch job without removing batch resources. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/delete)`
     `(BETA)` Delete a batch job. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/describe)`
     `(BETA)` Describe a batch job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/list)`
     `(BETA)` List batch jobs in a project. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches/wait)`
     `(BETA)` View the output of a batch as it runs or after it completes. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud dataproc batches](https://docs.cloud.google.com/sdk/gcloud/reference/dataproc/batches)
