NAME
    

gcloud beta dataproc operations - view and manage Dataproc operations 
SYNOPSIS
    

`gcloud beta dataproc operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` View and manage Dataproc operations. 
EXAMPLES
     To cancel an active operation, run: 
    
    
    [gcloud beta dataproc operations cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/cancel) operation_id

To view the details of an operation, run: 
    
    
    [gcloud beta dataproc operations describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/describe) operation_id

To see the list of all operations, run: 
    
    
    [gcloud beta dataproc operations list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/list)

To delete the record of an inactive operation, run: 
    
    
    [gcloud beta dataproc operations delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/delete) operation_id

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/cancel)`
     `(BETA)` Cancel an active operation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/delete)`
     `(BETA)` Delete the record of an inactive operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/describe)`
     `(BETA)` View the details of an operation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/get-iam-policy)`
     `(BETA)` Get IAM policy for an operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/list)`
     `(BETA)` View the list of all operations. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations/set-iam-policy)`
     `(BETA)` Set IAM policy for an operation. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud dataproc operations](https://docs.cloud.google.com/sdk/gcloud/reference/dataproc/operations)
    
    
    [gcloud alpha dataproc operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataproc/operations)
