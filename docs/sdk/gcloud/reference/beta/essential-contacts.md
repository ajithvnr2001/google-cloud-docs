NAME
    

gcloud beta essential-contacts - manage Essential Contacts 
SYNOPSIS
    

`gcloud beta essential-contacts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Essential Contacts can be set on a Cloud resource to receive communications from Google Cloud regarding that resource. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[compute](https://docs.cloud.google.com/sdk/gcloud/reference/beta/essential-contacts/compute)`
     `(BETA)` Compute the essential contacts that are subscribed to the specified notification categories for a resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/essential-contacts/create)`
     `(BETA)` Create an essential contact. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/essential-contacts/delete)`
     `(BETA)` Delete an essential contact. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/essential-contacts/describe)`
     `(BETA)` Describe an essential contact. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/essential-contacts/list)`
     `(BETA)` List essential contacts for a resource. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/essential-contacts/update)`
     `(BETA)` Update an essential contact. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud essential-contacts](https://docs.cloud.google.com/sdk/gcloud/reference/essential-contacts)
    
    
    [gcloud alpha essential-contacts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/essential-contacts)
