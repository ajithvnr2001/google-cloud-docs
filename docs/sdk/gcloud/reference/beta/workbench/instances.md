NAME
    

gcloud beta workbench instances - workbench Instances command group 
SYNOPSIS
    

`gcloud beta workbench instances` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Workbench Instances command group. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/add-iam-policy-binding)`
     `(BETA)` Adds IAM policy binding for a workbench instance. 
`[check-instance-upgradability](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/check-instance-upgradability)`
     `(BETA)` Checks if a workbench instance is upgradeable. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/create)`
     `(BETA)` Creates a workbench instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/delete)`
     `(BETA)` Deletes a workbench instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/describe)`
     `(BETA)` Describes a workbench instance. 
`[diagnose](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/diagnose)`
     `(BETA)` Diagnoses a workbench instance. 
`[get-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/get-config)`
     `(BETA)` Describes the valid configurations for workbench instances. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/get-iam-policy)`
     `(BETA)` Gets IAM policy for a workbench instance. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/list)`
     `(BETA)` Lists workbench instances. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/remove-iam-policy-binding)`
     `(BETA)` Removes IAM policy binding for a workbench instance. 
`[reset](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/reset)`
     `(BETA)` Resets a workbench instance. 
`[resize-disk](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/resize-disk)`
     `(BETA)` Resizes the workbench instance's disk. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/restore)`
     `(BETA)` Restores the workbench instance to a snapshot state. 
`[rollback](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/rollback)`
     `(BETA)` Rolls back a workbench instance. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/set-iam-policy)`
     `(BETA)` Sets the IAM policy for a workbench instance. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/start)`
     `(BETA)` Starts a workbench instance. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/stop)`
     `(BETA)` Stops a workbench instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/update)`
     `(BETA)` Updates a workbench instance. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/instances/upgrade)`
     `(BETA)` Upgrades a workbench instance. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud workbench instances](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/instances)
