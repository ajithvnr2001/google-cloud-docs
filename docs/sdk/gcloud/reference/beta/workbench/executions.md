NAME
    

gcloud beta workbench executions - workbench executions command group 
SYNOPSIS
    

`gcloud beta workbench executions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Workbench executions command group. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/executions/create)`
     `(BETA)` Create a Workbench execution. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/executions/delete)`
     `(BETA)` Delete an execution. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/executions/describe)`
     `(BETA)` Describe an execution. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workbench/executions/list)`
     `(BETA)` List your notebook execution jobs. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud workbench executions](https://docs.cloud.google.com/sdk/gcloud/reference/workbench/executions)
