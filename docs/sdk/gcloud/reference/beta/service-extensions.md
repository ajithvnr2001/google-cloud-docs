NAME
    

gcloud beta service-extensions - manage Service Extensions resources 
SYNOPSIS
    

`gcloud beta service-extensions` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Service Extensions resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[authz-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/authz-extensions)`
     `(BETA)` Manage Service Extensions `AuthzExtension` resources. 
`[cdn-edge-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/cdn-edge-extensions)`
     `(BETA)` Manage Service Extensions `CdnEdgeExtension` resources. 
`[extension-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings)`
     `(BETA)` Manage Extension Binding resources. 
`[lb-edge-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/lb-edge-extensions)`
     `(BETA)` Manage Service Extensions `LbEdgeExtension` resources. 
`[lb-route-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/lb-route-extensions)`
     `(BETA)` Manage Service Extensions `LbRouteExtension` resources. 
`[lb-traffic-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/lb-traffic-extensions)`
     `(BETA)` Manage Service Extensions `LbTrafficExtension` resources. 
`[wasm-plugin-versions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/wasm-plugin-versions)`
     `(BETA)` Interact with and manage Service Extensions `WasmPluginVersions`. 
`[wasm-plugins](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/wasm-plugins)`
     `(BETA)` Interact with and manage Service Extensions `WasmPlugins`. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud service-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/service-extensions)
    
    
    [gcloud alpha service-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions)
