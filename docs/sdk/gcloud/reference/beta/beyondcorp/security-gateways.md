NAME
    

gcloud beta beyondcorp security-gateways - manage Security Gateway resources 
SYNOPSIS
    

`gcloud beta beyondcorp security-gateways` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Security Gateway resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[applications](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/applications)`
     `(BETA)` Manage Application resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a security gateway. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/create)`
     `(BETA)` Create securityGateways. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/delete)`
     `(BETA)` Delete securityGateways. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/describe)`
     `(BETA)` Describe securityGateways. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/get-iam-policy)`
     `(BETA)` Get the IAM policy for a security gateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/list)`
     `(BETA)` List securityGateways. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a security gateway. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/set-iam-policy)`
     `(BETA)` Set the IAM policy for a security gateway. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/beyondcorp/security-gateways/update)`
     `(BETA)` Update securityGateways. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud beyondcorp security-gateways](https://docs.cloud.google.com/sdk/gcloud/reference/beyondcorp/security-gateways)
