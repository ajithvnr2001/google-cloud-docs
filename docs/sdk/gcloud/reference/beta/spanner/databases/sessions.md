NAME
    

gcloud beta spanner databases sessions - manage the sessions for Cloud Spanner databases 
SYNOPSIS
    

`gcloud beta spanner databases sessions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage the sessions for Cloud Spanner databases. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/databases/sessions/delete)`
     `(BETA)` Delete a Cloud Spanner session. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/databases/sessions/list)`
     `(BETA)` List the Cloud Spanner sessions contained within the given database. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud spanner databases sessions](https://docs.cloud.google.com/sdk/gcloud/reference/spanner/databases/sessions)
    
    
    [gcloud alpha spanner databases sessions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/databases/sessions)
