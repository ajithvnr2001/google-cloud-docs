NAME
    

gcloud beta spanner instance-configs - manage Cloud Spanner instance configs 
SYNOPSIS
    

`gcloud beta spanner instance-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Spanner instance configs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instance-configs/create)`
     `(BETA)` Create a Cloud Spanner instance configuration. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instance-configs/delete)`
     `(BETA)` Delete a Cloud Spanner instance configuration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instance-configs/describe)`
     `(BETA)` Describe a Cloud Spanner instance configuration. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instance-configs/list)`
     `(BETA)` List the available Cloud Spanner instance configurations. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instance-configs/update)`
     `(BETA)` Update a Cloud Spanner instance configuration. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud spanner instance-configs](https://docs.cloud.google.com/sdk/gcloud/reference/spanner/instance-configs)
    
    
    [gcloud alpha spanner instance-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/instance-configs)
