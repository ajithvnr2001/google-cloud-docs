NAME
    

gcloud beta spanner backups - manage Cloud Spanner backups 
SYNOPSIS
    

`gcloud beta spanner backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Spanner backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a Cloud Spanner backup. 
`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/copy)`
     `(BETA)` Copies a backup of a Cloud Spanner database. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/create)`
     `(BETA)` Creates a backup of a Cloud Spanner database. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/delete)`
     `(BETA)` Delete an existing backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/describe)`
     `(BETA)` Retrieves information about a backup. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Cloud Spanner backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/list)`
     `(BETA)` List existing Cloud Spanner Cloud Spanner backups. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding of a Cloud Spanner backup. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Cloud Spanner backup. 
`[update-metadata](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups/update-metadata)`
     `(BETA)` Updates the metadata of a Cloud Spanner a backup. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud spanner backups](https://docs.cloud.google.com/sdk/gcloud/reference/spanner/backups)
    
    
    [gcloud alpha spanner backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner/backups)
