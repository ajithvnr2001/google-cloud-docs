NAME
    

gcloud beta support support-event-subscriptions - manage Support Event Subscription resources 
SYNOPSIS
    

`gcloud beta support support-event-subscriptions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Support Event Subscription resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/support/support-event-subscriptions/create)`
     `(BETA)` Create a support event subscription. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/support/support-event-subscriptions/delete)`
     `(BETA)` Delete supportEventSubscriptions. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/support/support-event-subscriptions/describe)`
     `(BETA)` Describe supportEventSubscriptions. 
`[expunge](https://docs.cloud.google.com/sdk/gcloud/reference/beta/support/support-event-subscriptions/expunge)`
     `(BETA)` expunge supportEventSubscriptions. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/support/support-event-subscriptions/list)`
     `(BETA)` List supportEventSubscriptions. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/support/support-event-subscriptions/undelete)`
     `(BETA)` undelete supportEventSubscriptions. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/support/support-event-subscriptions/update)`
     `(BETA)` Update supportEventSubscriptions. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud support support-event-subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/support/support-event-subscriptions)
