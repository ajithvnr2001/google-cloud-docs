NAME
    

gcloud beta model-armor templates - manage Template resources 
SYNOPSIS
    

`gcloud beta model-armor templates` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Template resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates/create)`
     `(BETA)` Create Model Armor Template. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates/delete)`
     `(BETA)` Delete Model Armor Template. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates/describe)`
     `(BETA)` Get Model Armor Template. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates/list)`
     `(BETA)` List Model Armor Templates. 
`[sanitize-model-response](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates/sanitize-model-response)`
     `(BETA)` Sanitize Model Response. 
`[sanitize-user-prompt](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates/sanitize-user-prompt)`
     `(BETA)` Sanitize User Prompt. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/model-armor/templates/update)`
     `(BETA)` Update Model Armor Template. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud model-armor templates](https://docs.cloud.google.com/sdk/gcloud/reference/model-armor/templates)
    
    
    [gcloud alpha model-armor templates](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/model-armor/templates)
