NAME
    

gcloud beta service-directory services - manage Service Directory services 
SYNOPSIS
    

`gcloud beta service-directory services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Service Directory services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/add-iam-policy-binding)`
     `(BETA)` Adds IAM policy binding to a service. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/create)`
     `(BETA)` Creates a service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/delete)`
     `(BETA)` Deletes a service. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/describe)`
     `(BETA)` Describes a service. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/get-iam-policy)`
     `(BETA)` Gets IAM policy for a service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/list)`
     `(BETA)` Lists services. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/remove-iam-policy-binding)`
     `(BETA)` Removes IAM policy binding from a service. 
`[resolve](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/resolve)`
     `(BETA)` Resolves a service. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/set-iam-policy)`
     `(BETA)` Sets IAM policy for a service. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services/update)`
     `(BETA)` Updates a service. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud service-directory services](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/services)
    
    
    [gcloud alpha service-directory services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/services)
