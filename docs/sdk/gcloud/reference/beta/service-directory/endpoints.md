NAME
    

gcloud beta service-directory endpoints - manage Service Directory endpoints 
SYNOPSIS
    

`gcloud beta service-directory endpoints` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Service Directory endpoints. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/endpoints/create)`
     `(BETA)` Creates an endpoint. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/endpoints/delete)`
     `(BETA)` Deletes an endpoint. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/endpoints/describe)`
     `(BETA)` Describes an endpoint. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/endpoints/list)`
     `(BETA)` Lists endpoints. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/endpoints/update)`
     `(BETA)` Updates an endpoint. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud service-directory endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory/endpoints)
    
    
    [gcloud alpha service-directory endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory/endpoints)
