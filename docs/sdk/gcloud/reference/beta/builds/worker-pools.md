NAME
    

gcloud beta builds worker-pools - manage worker pools for Google Cloud Build 
SYNOPSIS
    

`gcloud beta builds worker-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage worker pools for Google Cloud Build. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/worker-pools/create)`
     `(BETA)` Create a worker pool for use by Cloud Build. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/worker-pools/delete)`
     `(BETA)` Delete a worker pool from Google Cloud Build. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/worker-pools/describe)`
     `(BETA)` Describe a worker pool used by Cloud Build. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/worker-pools/list)`
     `(BETA)` List all worker pools in a Google Cloud project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/worker-pools/update)`
     `(BETA)` Update a worker pool used by Cloud Build. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud builds worker-pools](https://docs.cloud.google.com/sdk/gcloud/reference/builds/worker-pools)
    
    
    [gcloud alpha builds worker-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/worker-pools)
