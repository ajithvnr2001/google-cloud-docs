NAME
    

gcloud beta builds triggers update - update Triggers in Google Cloud Build 
SYNOPSIS
    

`gcloud beta builds triggers update` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Update Triggers in Google Cloud Build. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[bitbucket-cloud](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/bitbucket-cloud)`
     `(BETA)` Updates Bitbucket Cloud trigger used by Cloud Build. 
`[bitbucket-data-center](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/bitbucket-data-center)`
     `(BETA)` Updates Bitbucket Data Center trigger used by Cloud Build. 
`[bitbucketserver](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/bitbucketserver)`
     `(BETA)` Updates Bitbucket Server trigger used by Cloud Build. 
`[cloud-source-repositories](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/cloud-source-repositories)`
     `(BETA)` Updates Cloud Source Repositories trigger used by Cloud Build. 
`[developer-connect](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/developer-connect)`
     `(BETA)` Updates Developer Connect trigger used by Cloud Build. 
`[github](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/github)`
     `(BETA)` Update GitHub trigger used by Cloud Build. 
`[gitlab](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/gitlab)`
     `(BETA)` Updates GitLab trigger used by Cloud Build. 
`[manual](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/manual)`
     `(BETA)` Updates a manual trigger used by Cloud Build. 
`[pubsub](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/pubsub)`
     `(BETA)` Update a Pub/Sub trigger used by Cloud Build. 
`[webhook](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update/webhook)`
     `(BETA)` Update a Webhook trigger used by Cloud Build. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud builds triggers update](https://docs.cloud.google.com/sdk/gcloud/reference/builds/triggers/update)
    
    
    [gcloud alpha builds triggers update](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers/update)
