NAME
    

gcloud beta builds triggers - create and manage build triggers for Google Cloud Build 
SYNOPSIS
    

`gcloud beta builds triggers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage build triggers for Google Cloud Build. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/create)`
     `(BETA)` Create build triggers for Google Cloud Build. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/update)`
     `(BETA)` Update Triggers in Google Cloud Build. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/delete)`
     `(BETA)` Delete a build trigger. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/describe)`
     `(BETA)` Get information about a particular trigger. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/export)`
     `(BETA)` Export a build trigger. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/import)`
     `(BETA)` Import a build trigger. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/list)`
     `(BETA)` List Cloud Build triggers for a project. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/beta/builds/triggers/run)`
     `(BETA)` Run a build trigger. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud builds triggers](https://docs.cloud.google.com/sdk/gcloud/reference/builds/triggers)
    
    
    [gcloud alpha builds triggers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/builds/triggers)
