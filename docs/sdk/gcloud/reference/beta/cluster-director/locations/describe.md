NAME
    

gcloud beta cluster-director locations describe - describe locations 
SYNOPSIS
    

`gcloud beta cluster-director locations describe` `LOCATION` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Describe a location. 
EXAMPLES
     To describe the operation, run: 
    
    
    gcloud beta cluster-director locations describe us-central1

POSITIONAL ARGUMENTS
    

Location resource - The name of the location resource. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `location` on the command line with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 



This must be specified. 

`LOCATION`
     ID of the location or fully qualified identifier for the location. 

To set the `location` attribute: 

  * provide the argument `location` on the command line.
