NAME
    

gcloud beta cluster-director locations - view supported locations 
SYNOPSIS
    

`gcloud beta cluster-director locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` View supported locations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/cluster-director/locations/describe)`
     `(BETA)` Describe locations. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/cluster-director/locations/list)`
     `(BETA)` List locations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud cluster-director locations](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director/locations)
    
    
    [gcloud alpha cluster-director locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/cluster-director/locations)
