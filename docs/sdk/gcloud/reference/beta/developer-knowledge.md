NAME
    

gcloud beta developer-knowledge - manage Developer Knowledge resources and query knowledge base 
SYNOPSIS
    

`gcloud beta developer-knowledge` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Developer Knowledge resources and query knowledge base. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[documents](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-knowledge/documents)`
     `(BETA)` Explore and search Developer Knowledge documents. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[answer-query](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-knowledge/answer-query)`
     `(BETA)` Answer a natural language query using grounded generation. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud developer-knowledge](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge)
    
    
    [gcloud alpha developer-knowledge](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-knowledge)
