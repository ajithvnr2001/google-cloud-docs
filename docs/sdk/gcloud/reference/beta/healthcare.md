NAME
    

gcloud beta healthcare - manage Cloud Healthcare resources 
SYNOPSIS
    

`gcloud beta healthcare` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Healthcare resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[consent-stores](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/consent-stores)`
     `(BETA)` Manage Cloud Healthcare API consent stores. 
`[datasets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/datasets)`
     `(BETA)` Manage Cloud Healthcare API datasets. 
`[dicom-stores](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/dicom-stores)`
     `(BETA)` Manage Cloud Healthcare API DICOM stores. 
`[fhir-stores](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores)`
     `(BETA)` Manage Cloud Healthcare API FHIR stores. 
`[hl7v2-stores](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/hl7v2-stores)`
     `(BETA)` Manage Cloud Healthcare API HL7v2 stores. 
`[nlp](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/nlp)`
     `(BETA)` Use and manage the Cloud Healthcare NLP service. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/operations)`
     `(BETA)` Manage Cloud Healthcare API operations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud healthcare](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare)
    
    
    [gcloud alpha healthcare](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare)
