NAME
    

gcloud beta certificate-manager maps - manage Certificate Manager certificate maps 
SYNOPSIS
    

`gcloud beta certificate-manager maps` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing certificate maps. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[entries](https://docs.cloud.google.com/sdk/gcloud/reference/beta/certificate-manager/maps/entries)`
     `(BETA)` Manage Certificate Manager certificate map entries. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/certificate-manager/maps/create)`
     `(BETA)` Create a certificate map. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/certificate-manager/maps/delete)`
     `(BETA)` Delete a certificate map. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/certificate-manager/maps/describe)`
     `(BETA)` Describe an existing certificate map. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/certificate-manager/maps/list)`
     `(BETA)` List certificate maps. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/certificate-manager/maps/update)`
     `(BETA)` Update a certificate map. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud certificate-manager maps](https://docs.cloud.google.com/sdk/gcloud/reference/certificate-manager/maps)
    
    
    [gcloud alpha certificate-manager maps](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/certificate-manager/maps)
