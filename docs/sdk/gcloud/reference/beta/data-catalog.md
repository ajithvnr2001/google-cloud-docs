NAME
    

gcloud beta data-catalog - manage Data Catalog resources 
SYNOPSIS
    

`gcloud beta data-catalog` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Data Catalog resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[entries](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entries)`
     `(BETA)` Manage entries in Data Catalog. 
`[entry-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/entry-groups)`
     `(BETA)` `(DEPRECATED)` Manage entry groups in Data Catalog. 
`[tag-templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/tag-templates)`
     `(BETA)` `(DEPRECATED)` Manage tag templates in Data Catalog. 
`[tags](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/tags)`
     `(BETA)` `(DEPRECATED)` Manage tags in Data Catalog. 
`[taxonomies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/taxonomies)`
     `(BETA)` Manage taxonomies in Data Catalog. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[search](https://docs.cloud.google.com/sdk/gcloud/reference/beta/data-catalog/search)`
     `(BETA)` `(DEPRECATED)` Search Data Catalog for resources that match a query. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud data-catalog](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog)
    
    
    [gcloud alpha data-catalog](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/data-catalog)
