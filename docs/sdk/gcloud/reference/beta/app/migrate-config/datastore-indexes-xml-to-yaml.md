NAME
    

gcloud beta app migrate-config datastore-indexes-xml-to-yaml - translates a datastore-indexes.xml into index.yaml 
SYNOPSIS
    

`gcloud beta app migrate-config datastore-indexes-xml-to-yaml` `XML_FILE` [`--generated-indexes-file`=`GENERATED_INDEXES_FILE`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Convert a datastore-indexes.xml file to index.yaml. 
POSITIONAL ARGUMENTS
    

`XML_FILE`
     Path to the datastore-indexes.xml file. 
FLAGS
    

`--generated-indexes-file`=`GENERATED_INDEXES_FILE`
     If specified, include the auto-generated xml file too, and merge the resulting entries appropriately. Note that this file is usually named `WEB-INF/appengine-generated/datastore-indexes-auto.xml`.
