NAME
    

gcloud beta app regions - view regional availability of App Engine runtime environments 
SYNOPSIS
    

`gcloud beta app regions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This command can be used to view availability of App Engine standard and flexible runtime environments in all geographic regions. 
EXAMPLES
     To view regional availability of App Engine runtime environments, run: 
    
    
    [gcloud beta app regions list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/regions/list)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/regions/list)`
     `(BETA)` List the availability of flex and standard environments for each region. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud app regions](https://docs.cloud.google.com/sdk/gcloud/reference/app/regions)
