NAME
    

gcloud beta app versions - view and manage your App Engine versions 
SYNOPSIS
    

`gcloud beta app versions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This set of commands can be used to view and manage your existing App Engine versions. 

To create new deployments, use `[gcloud beta app deploy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/deploy)`. 

For more information on App Engine versions, see: <https://cloud.google.com/appengine/docs/python/an-overview-of-app-engine>

EXAMPLES
     To list your deployed versions, run: 
    
    
    [gcloud beta app versions list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/list)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[browse](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/browse)`
     `(BETA)` Open the specified versions in a browser. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/delete)`
     `(BETA)` Delete a specified version. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/describe)`
     `(BETA)` Display all data about an existing version. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/list)`
     `(BETA)` List your existing versions. 
`[migrate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/migrate)`
     `(BETA)` Migrate traffic from one version to another for a set of services. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/start)`
     `(BETA)` Start serving specified versions. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app/versions/stop)`
     `(BETA)` Stop serving specified versions. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud app versions](https://docs.cloud.google.com/sdk/gcloud/reference/app/versions)
