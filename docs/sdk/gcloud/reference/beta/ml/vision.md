NAME
    

gcloud beta ml vision - use Google Cloud Vision to analyze images 
SYNOPSIS
    

`gcloud beta ml vision` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Use Google Cloud Vision to analyze images. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/operations)`
     `(BETA)` Manage Google Cloud Vision operations. 
`[product-search](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search)`
     `(BETA)` Uses Google Cloud Vision to analyze product in images. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[detect-document](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-document)`
     `(BETA)` Detect dense text in an image. 
`[detect-faces](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-faces)`
     `(BETA)` Detect faces within an image. 
`[detect-image-properties](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-image-properties)`
     `(BETA)` Detect general attributes of an image. 
`[detect-labels](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-labels)`
     `(BETA)` Detect broad sets of categories within an image. 
`[detect-landmarks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-landmarks)`
     `(BETA)` Detect popular natural and man-made structures within an image. 
`[detect-logos](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-logos)`
     `(BETA)` Detect popular product logos within an image. 
`[detect-objects](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-objects)`
     `(BETA)` Detect and extract multiple objects in an image with object localization. 
`[detect-product](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-product)`
     `(BETA)` detect products within an image. 
`[detect-safe-search](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-safe-search)`
     `(BETA)` Detect explicit content in an image. 
`[detect-text](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-text)`
     `(BETA)` Detect and extract text within an image. 
`[detect-text-pdf](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-text-pdf)`
     `(BETA)` Detect and transcribe text from PDF files stored in Google Cloud Storage. 
`[detect-text-tiff](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-text-tiff)`
     `(BETA)` Detect and transcribe text from TIFF files stored in Google Cloud Storage. 
`[detect-web](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/detect-web)`
     `(BETA)` Detect entities in an image from similar images on the web. 
`[suggest-crop](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/suggest-crop)`
     `(BETA)` Suggest a bounding box in an image. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud ml vision](https://docs.cloud.google.com/sdk/gcloud/reference/ml/vision)
    
    
    [gcloud alpha ml vision](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision)
