NAME
    

gcloud beta ml vision product-search - uses Google Cloud Vision to analyze product in images 
SYNOPSIS
    

`gcloud beta ml vision product-search` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Uses Google Cloud Vision to analyze product in images. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[images](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/images)`
     `(BETA)` Use the Google Cloud Vision API to manipulate reference images. 
`[product-sets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets)`
     `(BETA)` Uses Google Cloud Vision to manipulate product sets. 
`[products](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/products)`
     `(BETA)` Uses Google Cloud Vision to manipulate products. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha ml vision product-search](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search)
