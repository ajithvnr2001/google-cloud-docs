NAME
    

gcloud beta ml vision product-search product-sets - uses Google Cloud Vision to manipulate product sets 
SYNOPSIS
    

`gcloud beta ml vision product-search product-sets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Uses Google Cloud Vision to manipulate product sets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-product](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/add-product)`
     `(BETA)` Add a product to the specified product set. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/create)`
     `(BETA)` Create a new product set. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/delete)`
     `(BETA)` Delete a product set. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/describe)`
     `(BETA)` Describe a product set. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/import)`
     `(BETA)` Import a list of reference images to specified product sets. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/list)`
     `(BETA)` List product sets in a location. 
`[list-products](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/list-products)`
     `(BETA)` List products in a product set. 
`[remove-product](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/remove-product)`
     `(BETA)` Remove a product from a product set. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision/product-search/product-sets/update)`
     `(BETA)` Update a product set. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha ml vision product-search product-sets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/vision/product-search/product-sets)
