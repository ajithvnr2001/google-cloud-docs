NAME
    

gcloud beta ml speech operations wait - poll long-running speech recognition operation until it completes 
SYNOPSIS
    

`gcloud beta ml speech operations wait` `OPERATION` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Poll a long-running speech recognition operation until it completes. When the operation is complete, this command will display the results of the transcription. 
EXAMPLES
     To wait for the result of operation '12345': 
    
    
    gcloud beta ml speech operations wait 12345

POSITIONAL ARGUMENTS
    

Operation resource - The ID of the operation to wait for. This represents a Cloud resource. 

This must be specified. 

`OPERATION`
     ID of the operation or fully qualified identifier for the operation. 

To set the `operation` attribute: 

  * provide the argument `operation` on the command line.
