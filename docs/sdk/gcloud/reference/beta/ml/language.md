NAME
    

gcloud beta ml language - use the Google Cloud Natural Language API to analyze text 
SYNOPSIS
    

`gcloud beta ml language` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` For more information, please see <https://cloud.google.com/natural-language/>. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[analyze-entities](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/language/analyze-entities)`
     `(BETA)` Use Google Cloud Natural Language API to identify entities in text. 
`[analyze-entity-sentiment](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/language/analyze-entity-sentiment)`
     `(BETA)` Use Google Cloud Natural Language API to identify entity-level sentiment. 
`[analyze-sentiment](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/language/analyze-sentiment)`
     `(BETA)` Use Google Cloud Natural Language API to identify sentiments in a text. 
`[analyze-syntax](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/language/analyze-syntax)`
     `(BETA)` Use Google Cloud Natural Language API to identify linguistic information. 
`[classify-text](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/language/classify-text)`
     `(BETA)` Classifies input document into categories. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud ml language](https://docs.cloud.google.com/sdk/gcloud/reference/ml/language)
    
    
    [gcloud alpha ml language](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml/language)
