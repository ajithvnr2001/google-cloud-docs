NAME
    

gcloud beta alloydb clusters - provide commands for managing AlloyDB clusters 
SYNOPSIS
    

`gcloud beta alloydb clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Provide commands for managing AlloyDB clusters including creating, configuring, restarting, and deleting clusters. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/create)`
     `(BETA)` Create a new AlloyDB cluster within a given project. 
`[create-secondary](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/create-secondary)`
     `(BETA)` Create a new AlloyDB SECONDARY cluster within a given project. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/delete)`
     `(BETA)` Delete an AlloyDB cluster in a given region. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/describe)`
     `(BETA)` Describe an AlloyDB cluster in a given project and region. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/export)`
     `(BETA)` Export data from an AlloyDB cluster to Google Cloud Storage. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/import)`
     `(BETA)` Import data to an AlloyDB cluster from Google Cloud Storage. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/list)`
     `(BETA)` List AlloyDB clusters in a given project and region. 
`[migrate-cloud-sql](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/migrate-cloud-sql)`
     `(BETA)` Migrate Cloud SQL instance to an AlloyDB cluster. 
`[promote](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/promote)`
     `(BETA)` Promote an AlloyDB SECONDARY cluster in a given project and region. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/restore)`
     `(BETA)` Restore an AlloyDB cluster from a given backup or a source cluster and a timestamp. 
`[switchover](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/switchover)`
     `(BETA)` Switchover an AlloyDB SECONDARY cluster in a given project and region. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/update)`
     `(BETA)` Update an AlloyDB cluster within a given project and region. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/clusters/upgrade)`
     `(BETA)` Upgrade an AlloyDB cluster within a given project and region. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud alloydb clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alloydb/clusters)
    
    
    [gcloud alpha alloydb clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/alloydb/clusters)
