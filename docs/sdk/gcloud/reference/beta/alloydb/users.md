NAME
    

gcloud beta alloydb users - provide commands for managing AlloyDB users 
SYNOPSIS
    

`gcloud beta alloydb users` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Provide commands for managing AlloyDB users including creating, configuring, getting, listing, and deleting users. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/users/create)`
     `(BETA)` Creates a user in a given cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/users/delete)`
     `(BETA)` Deletes an AlloyDB user in a given cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/users/list)`
     `(BETA)` Lists AlloyDB users in a given cluster. 
`[set-password](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/users/set-password)`
     `(BETA)` Update an AlloyDB user's password within a given cluster and region. 
`[set-roles](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/users/set-roles)`
     `(BETA)` Update an AlloyDB user's database roles within a given cluster and region. 
`[set-superuser](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/users/set-superuser)`
     `(BETA)` Update an AlloyDB user's superuser role within a given cluster and region. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud alloydb users](https://docs.cloud.google.com/sdk/gcloud/reference/alloydb/users)
    
    
    [gcloud alpha alloydb users](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/alloydb/users)
