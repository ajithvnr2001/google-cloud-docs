NAME
    

gcloud beta alloydb backups - provide commands for managing AlloyDB backups 
SYNOPSIS
    

`gcloud beta alloydb backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Provide commands for managing AlloyDB backups including creating, deleting, and listing backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/backups/create)`
     `(BETA)` Create a new AlloyDB backup within a given project. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/backups/delete)`
     `(BETA)` Deletes an AlloyDB backup within a given project. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/backups/describe)`
     `(BETA)` Describes an AlloyDB backup in a given project and region. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/backups/list)`
     `(BETA)` Lists AlloyDB backups in a given project. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud alloydb backups](https://docs.cloud.google.com/sdk/gcloud/reference/alloydb/backups)
    
    
    [gcloud alpha alloydb backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/alloydb/backups)
