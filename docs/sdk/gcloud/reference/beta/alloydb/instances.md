NAME
    

gcloud beta alloydb instances - provide commands for managing AlloyDB instances 
SYNOPSIS
    

`gcloud beta alloydb instances` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Provide commands for managing AlloyDB clusters including creating, configuring, restarting, and deleting instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/create)`
     `(BETA)` Creates a new AlloyDB instance within a given cluster. 
`[create-secondary](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/create-secondary)`
     `(BETA)` Creates a new AlloyDB SECONDARY instance within a given cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/delete)`
     `(BETA)` Deletes an AlloyDB instance within a given cluster. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/describe)`
     `(BETA)` Describes an AlloyDB instance within a given cluster. 
`[failover](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/failover)`
     `(BETA)` Failover an AlloyDB instance within a given cluster. 
`[inject-fault](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/inject-fault)`
     `(BETA)` Inject fault on an AlloyDB instance within a given cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/list)`
     `(BETA)` Lists AlloyDB instances in a given cluster. 
`[restart](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/restart)`
     `(BETA)` Restarts an AlloyDB instance within a given cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/alloydb/instances/update)`
     `(BETA)` Updates an AlloyDB instance within a given cluster. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud alloydb instances](https://docs.cloud.google.com/sdk/gcloud/reference/alloydb/instances)
    
    
    [gcloud alpha alloydb instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/alloydb/instances)
