NAME
    

gcloud beta policy-troubleshoot - troubleshoot Google Cloud Platform policies 
SYNOPSIS
    

`gcloud beta policy-troubleshoot` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Policy Troubleshooter troubleshoots policies for Google Cloud Platform resources. Policy Troubleshooter works by evaluating the user's current access to a resource. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[iam](https://docs.cloud.google.com/sdk/gcloud/reference/beta/policy-troubleshoot/iam)`
     `(BETA)` Troubleshoot the IAM Policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud policy-troubleshoot](https://docs.cloud.google.com/sdk/gcloud/reference/policy-troubleshoot)
    
    
    [gcloud alpha policy-troubleshoot](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/policy-troubleshoot)
