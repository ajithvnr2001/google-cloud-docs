NAME
    

gcloud beta domains - manage domains for your Google Cloud projects 
SYNOPSIS
    

`gcloud beta domains` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud domains command group lets you view and manage your custom domains for use across Google projects. 
EXAMPLES
     To verify a domain you own, run: 
    
    
    [gcloud beta domains verify](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/verify) example.com

To list your verified domains, run: 
    
    
    [gcloud beta domains list-user-verified](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/list-user-verified)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[registrations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/registrations)`
     `(BETA)` Manage Cloud Domains registrations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[list-user-verified](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/list-user-verified)`
     `(BETA)` Lists the user's verified domains. 
`[verify](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/verify)`
     `(BETA)` Verifies a domain via an in-browser workflow. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud domains](https://docs.cloud.google.com/sdk/gcloud/reference/domains)
    
    
    [gcloud alpha domains](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains)
