NAME
    

gcloud beta deployment-manager types - commands for Deployment Manager types 
SYNOPSIS
    

`gcloud beta deployment-manager types` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands to show available resource types. 
EXAMPLES
     To see the list of all available resource types, run: 
    
    
    [gcloud beta deployment-manager types list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/types/list)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/types/create)`
     `(BETA)` Create a type. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/types/delete)`
     `(BETA)` Delete a composite type. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/types/describe)`
     `(BETA)` Describe a type. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/types/list)`
     `(BETA)` Describe a type provider type. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/types/update)`
     `(BETA)` Update a composite type. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud deployment-manager types](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/types)
    
    
    [gcloud alpha deployment-manager types](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/types)
