NAME
    

gcloud beta deployment-manager manifests - commands for Deployment Manager manifests 
SYNOPSIS
    

`gcloud beta deployment-manager manifests` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands to list and examine manifests within a deployment. 
EXAMPLES
     To view all details about a manifest, run: 
    
    
    [gcloud beta deployment-manager manifests describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/manifests/describe) manifest-name --deployment my-deployment

To see the list of all manifests in a deployment, run: 
    
    
    [gcloud beta deployment-manager manifests list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/manifests/list) --deployment my-deployment

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/manifests/describe)`
     `(BETA)` Provide information about a manifest. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/manifests/list)`
     `(BETA)` List manifests in a deployment. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud deployment-manager manifests](https://docs.cloud.google.com/sdk/gcloud/reference/deployment-manager/manifests)
    
    
    [gcloud alpha deployment-manager manifests](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/manifests)
