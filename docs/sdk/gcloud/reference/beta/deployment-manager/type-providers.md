NAME
    

gcloud beta deployment-manager type-providers - commands for Deployment Manager type providers 
SYNOPSIS
    

`gcloud beta deployment-manager type-providers` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for Deployment Manager type providers. 
EXAMPLES
     To view the details of a type provider, run: 
    
    
    [gcloud beta deployment-manager type-providers describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/type-providers/describe) TYPE_NAME

To see the list of all type providers, run: 
    
    
    [gcloud beta deployment-manager type-providers list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/type-providers/list)

More information about type providers: <https://cloud.google.com/deployment-manager/docs/fundamentals#basetypes>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/type-providers/create)`
     `(BETA)` Create a type provider. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/type-providers/delete)`
     `(BETA)` Delete a type provider. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/type-providers/describe)`
     `(BETA)` Describe a type provider entry in Type Registry. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/type-providers/list)`
     `(BETA)` List type providers in a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deployment-manager/type-providers/update)`
     `(BETA)` Update a type provider. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha deployment-manager type-providers](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deployment-manager/type-providers)
