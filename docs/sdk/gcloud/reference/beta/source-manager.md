NAME
    

gcloud beta source-manager - manage Secure Source Manager resources 
SYNOPSIS
    

`gcloud beta source-manager` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Secure Source Manager resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/instances)`
     `(BETA)` Manage Secure Source Manager instances. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/locations)`
     `(BETA)` Manage Secure Source Manager locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/operations)`
     `(BETA)` Manage Secure Source Manager operations. 
`[repos](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos)`
     `(BETA)` Manage Secure Source Manager repositories. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud source-manager](https://docs.cloud.google.com/sdk/gcloud/reference/source-manager)
    
    
    [gcloud alpha source-manager](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager)
