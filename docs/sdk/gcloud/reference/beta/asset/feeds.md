#  gcloud beta asset feeds Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta asset feeds - manage Cloud Asset Inventory feeds 
SYNOPSIS
    

`gcloud beta asset feeds` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Asset Inventory feeds. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/asset/feeds/create)`
     `(BETA)` Create a Cloud Asset Inventory Feed. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/asset/feeds/delete)`
     `(BETA)` Delete a Cloud Asset Inventory Feed. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/asset/feeds/describe)`
     `(BETA)` Describe a Cloud Asset Inventory Feed. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/asset/feeds/list)`
     `(BETA)` List Cloud Asset Inventory Feeds. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/asset/feeds/update)`
     `(BETA)` Update an existing Cloud Asset Inventory Feed. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud asset feeds](https://docs.cloud.google.com/sdk/gcloud/reference/asset/feeds)
    
    
    [gcloud alpha asset feeds](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/asset/feeds)
