NAME
    

gcloud beta managed-kafka - administer Managed Service for Apache Kafka clusters, topics, and consumer groups 
SYNOPSIS
    

`gcloud beta managed-kafka` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Administer Managed Service for Apache Kafka clusters, topics, and consumer groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[acls](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls)`
     `(BETA)` Administer Managed Service for Apache Kafka acls. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/clusters)`
     `(BETA)` Administer Managed Service for Apache Kafka clusters. 
`[connect-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connect-clusters)`
     `(BETA)` Administer Managed Service for Apache Kafka connect-clusters. 
`[connectors](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors)`
     `(BETA)` Administer Managed Service for Apache Kafka connectors. 
`[consumer-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/consumer-groups)`
     `(BETA)` Administer Managed Service for Apache Kafka consumer groups. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/operations)`
     `(BETA)` View Managed Service for Apache Kafka operations. 
`[schema-registries](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/schema-registries)`
     `(BETA)` Administer Managed Service for Apache Kafka schema-registries. 
`[topics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/topics)`
     `(BETA)` Administer Managed Service for Apache Kafka topics. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud managed-kafka](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka)
    
    
    [gcloud alpha managed-kafka](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka)
