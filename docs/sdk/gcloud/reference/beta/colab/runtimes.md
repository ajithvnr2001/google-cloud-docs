NAME
    

gcloud beta colab runtimes - manage Colab Enterprise runtimes 
SYNOPSIS
    

`gcloud beta colab runtimes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` For more information about runtimes, see <https://cloud.google.com/colab/docs/runtimes#runtimes>
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtimes/create)`
     `(BETA)` Create a notebook runtime. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtimes/delete)`
     `(BETA)` Delete a runtime. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtimes/describe)`
     `(BETA)` Describe a runtime. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtimes/list)`
     `(BETA)` List your project's runtimes. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtimes/start)`
     `(BETA)` Start a stopped runtime. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtimes/stop)`
     `(BETA)` Stop a runtime. 
`[upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtimes/upgrade)`
     `(BETA)` Upgrade a runtime. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud colab runtimes](https://docs.cloud.google.com/sdk/gcloud/reference/colab/runtimes)
