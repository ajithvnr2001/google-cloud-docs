NAME
    

gcloud beta colab runtime-templates - manage Colab Enterprise runtime templates 
SYNOPSIS
    

`gcloud beta colab runtime-templates` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` For more information about runtime templates, see <https://cloud.google.com/colab/docs/runtimes#runtime-templates>
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Colab Enterprise runtime template. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/create)`
     `(BETA)` Create a runtime template. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/delete)`
     `(BETA)` Delete a runtime template. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/describe)`
     `(BETA)` Describe a runtime template. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/get-iam-policy)`
     `(BETA)` Get IAM policy for a Colab Enterprise runtime template. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/list)`
     `(BETA)` List your runtime templates. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a Colab Enterprise runtime template. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/colab/runtime-templates/set-iam-policy)`
     `(BETA)` Set IAM policy for a Colab Enterprise runtime template as defined in a JSON or YAML file. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud colab runtime-templates](https://docs.cloud.google.com/sdk/gcloud/reference/colab/runtime-templates)
