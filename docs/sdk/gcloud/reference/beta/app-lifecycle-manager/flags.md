#  gcloud beta app-lifecycle-manager flags Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta app-lifecycle-manager flags - manage App Lifecycle Manager Flags 
SYNOPSIS
    

`gcloud beta app-lifecycle-manager flags` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)`
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[attributes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/attributes)`
     `(BETA)` Manage App Lifecycle Manager Flags Attributes. 
`[releases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/releases)`
     `(BETA)` Manage App Lifecycle Manager Flags Releases. 
`[revisions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/revisions)`
     `(BETA)` Manage App Lifecycle Manager flags revisions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/create)`
     `(BETA)` Create Flag. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/delete)`
     `(BETA)` Delete Flag. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/describe)`
     `(BETA)` Describe Flag. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/list)`
     `(BETA)` List Flags. 
`[pull](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/pull)`
     `(BETA)` Create a JSON manifest file using the SaaS Flags API as the source of truth. 
`[push](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/push)`
     `(BETA)` Create Flags from a JSON manifest file. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/update)`
     `(BETA)` Update Flag. 
NOTES
     This command is currently in beta and might change without notice.
