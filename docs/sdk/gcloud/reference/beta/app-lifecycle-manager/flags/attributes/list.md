NAME
    

gcloud beta app-lifecycle-manager flags attributes list - list Flags Attributes 
SYNOPSIS
    

`gcloud beta app-lifecycle-manager flags attributes list` [`--location`=`LOCATION`] [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`--uri`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` List Flag Attributes available in a specific location for your SaaS offerings. 

Use this command to audit available attributes (such as `userID` or `tenantID`) used in feature flag evaluation specs to determine variant assignment. These attributes are typically defined in the `global` location and must exist before they can be referenced in a flag's evaluation criteria. 

EXAMPLES
     To list all Flag Attributes across all locations in the current project, run: 
    
    
    gcloud beta app-lifecycle-manager flags attributes list

To list Flag Attributes for a specific location (e.g., `global`), run: 
    
    
    gcloud beta app-lifecycle-manager flags attributes list --location=global

To find a specific attribute by its key (e.g., `userID`), run: 
    
    
    gcloud beta app-lifecycle-manager flags attributes list --filter="key:userID"

To get the full resource URIs for use in a flag's evaluation-spec JSON, run: 
    
    
    gcloud beta app-lifecycle-manager flags attributes list --location=global --uri

To list attributes and output in JSON format for automation/scripting, run: 
    
    
    gcloud beta app-lifecycle-manager flags attributes list --format=json

FLAGS
    

Location resource - Location in which to list Flag Attributes. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--location` on the command line with a fully specified name; 
  * if left empty, will use the wildcard '-' to list all locations with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 


`--location`=`LOCATION`
     ID of the location or fully qualified identifier for the location. 

To set the `location` attribute: 

  * provide the argument `--location` on the command line; 
  * if left empty, will use the wildcard '-' to list all locations. 


LIST COMMAND FLAGS
    

`--filter`=`EXPRESSION`
     Apply a Boolean filter `EXPRESSION` to each resource item to be listed. If the expression evaluates `True`, then that item is listed. For more details and examples of filter expressions, run $ [gcloud topic filters](https://docs.cloud.google.com/sdk/gcloud/reference/topic/filters). This flag interacts with other flags that are applied in this order: `--flatten`, `--sort-by`, `--filter`, `--limit`. 
`--limit`=`LIMIT`
     Maximum number of resources to list. The default is `unlimited`. This flag interacts with other flags that are applied in this order: `--flatten`, `--sort-by`, `--filter`, `--limit`. 
`--page-size`=`PAGE_SIZE`
     Some services group resource list output into pages. This flag specifies the maximum number of resources per page. The default is determined by the service if it supports paging, otherwise it is `unlimited` (no paging). Paging may be applied before or after `--filter` and `--limit` depending on the service. 
`--sort-by`=[`FIELD`,…]
     Comma-separated list of resource field key names to sort by. The default order is ascending. Prefix a field with ``~´´ for descending order on that field. This flag interacts with other flags that are applied in this order: `--flatten`, `--sort-by`, `--filter`, `--limit`. 
`--uri`
     Print a list of resource URIs instead of the default output, and change the command output to a list of URIs. If this flag is used with `--format`, the formatting is applied on this URI list. To display URIs alongside other keys instead, use the `uri()` transform.
