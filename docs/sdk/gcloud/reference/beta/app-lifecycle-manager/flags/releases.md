NAME
    

gcloud beta app-lifecycle-manager flags releases - manage App Lifecycle Manager Flags Releases 
SYNOPSIS
    

`gcloud beta app-lifecycle-manager flags releases` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)`
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/releases/create)`
     `(BETA)` Create Flag Release. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/releases/delete)`
     `(BETA)` Delete Flag Release. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/releases/describe)`
     `(BETA)` Describe Flag Release. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/releases/list)`
     `(BETA)` List Flag Releases. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/app-lifecycle-manager/flags/releases/update)`
     `(BETA)` Update a Flag Release. 
NOTES
     This command is currently in beta and might change without notice.
