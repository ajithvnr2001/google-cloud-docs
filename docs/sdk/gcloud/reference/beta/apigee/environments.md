NAME
    

gcloud beta apigee environments - manage Apigee environments 
SYNOPSIS
    

`gcloud beta apigee environments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Apigee environments. 
EXAMPLES
     To list all environments for the active Cloud Platform project, run: 
    
    
    [gcloud beta apigee environments list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/apigee/environments/list)

To get a JSON array of all environments in an Apigee organization called ``my-org``, run: 
    
    
    [gcloud beta apigee environments list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/apigee/environments/list) --organization=my-org --format=json

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/apigee/environments/describe)`
     `(BETA)` Describe an Apigee deployment environment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/apigee/environments/list)`
     `(BETA)` List Apigee deployment environments. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud apigee environments](https://docs.cloud.google.com/sdk/gcloud/reference/apigee/environments)
    
    
    [gcloud alpha apigee environments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/apigee/environments)
