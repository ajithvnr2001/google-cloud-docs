NAME
    

gcloud beta resource-manager capability-configs - manage Cloud Resource Manager CapabilityConfigs 
SYNOPSIS
    

`gcloud beta resource-manager capability-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` A CapabilityConfig allows managing experiences like applications and agents on a logical administrative perimeter of Projects (Boundary). 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/resource-manager/capability-configs/create)`
     `(BETA)` Create a CapabilityConfig under a parent Organization, Folder, or Project. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/resource-manager/capability-configs/delete)`
     `(BETA)` Delete a CapabilityConfig. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/resource-manager/capability-configs/describe)`
     `(BETA)` Describe a CapabilityConfig. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/resource-manager/capability-configs/list)`
     `(BETA)` List CapabilityConfigs that are direct children of a parent resource. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/resource-manager/capability-configs/update)`
     `(BETA)` Update a CapabilityConfig. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud resource-manager capability-configs](https://docs.cloud.google.com/sdk/gcloud/reference/resource-manager/capability-configs)
    
    
    [gcloud alpha resource-manager capability-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/resource-manager/capability-configs)
