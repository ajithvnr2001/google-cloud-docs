NAME
    

gcloud beta scheduler jobs - manage Cloud Scheduler jobs 
SYNOPSIS
    

`gcloud beta scheduler jobs` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Scheduler jobs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/create)`
     `(BETA)` Create Cloud Scheduler jobs for various types of targets. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/update)`
     `(BETA)` Update Cloud Scheduler jobs for various types of targets. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/delete)`
     `(BETA)` Delete a job. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/describe)`
     `(BETA)` Show details about a job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/list)`
     `(BETA)` List jobs. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/pause)`
     `(BETA)` Pause the execution of a job. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/resume)`
     `(BETA)` Resume execution of a paused job. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scheduler/jobs/run)`
     `(BETA)` Trigger an on-demand execution of a job. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud scheduler jobs](https://docs.cloud.google.com/sdk/gcloud/reference/scheduler/jobs)
    
    
    [gcloud alpha scheduler jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scheduler/jobs)
