NAME
    

gcloud beta device-run - manage automation sessions and jobs on devices 
SYNOPSIS
    

`gcloud beta device-run` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage automation sessions and jobs on devices. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[devices](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/devices)`
     `(BETA)` Manage Device Run devices. 
`[sessions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/sessions)`
     `(BETA)` Manage Device Run sessions. 
`[software-versions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/software-versions)`
     `(BETA)` Manage Device Run software versions. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha device-run](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run)
