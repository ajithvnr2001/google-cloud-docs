NAME
    

gcloud beta ml - use Google Cloud machine learning capabilities 
SYNOPSIS
    

`gcloud beta ml` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Use Google Cloud machine learning capabilities. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[language](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/language)`
     `(BETA)` Use the Google Cloud Natural Language API to analyze text. 
`[speech](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/speech)`
     `(BETA)` Use Google Cloud Speech to get transcripts of audio. 
`[translate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/translate)`
     `(BETA)` Cloud ML Translate command groups. 
`[video](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/video)`
     `(BETA)` Cloud ML Video-Intelligence command groups. 
`[vision](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ml/vision)`
     `(BETA)` Use Google Cloud Vision to analyze images. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud ml](https://docs.cloud.google.com/sdk/gcloud/reference/ml)
    
    
    [gcloud alpha ml](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ml)
