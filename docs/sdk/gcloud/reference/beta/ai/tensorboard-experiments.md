NAME
    

gcloud beta ai tensorboard-experiments - manage Vertex AI Tensorboard experiments 
SYNOPSIS
    

`gcloud beta ai tensorboard-experiments` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Vertex AI Tensorboard experiments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-experiments/create)`
     `(BETA)` Create a new Vertex AI Tensorboard experiment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-experiments/delete)`
     `(BETA)` Delete an existing Vertex AI Tensorboard experiment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-experiments/describe)`
     `(BETA)` Get detailed Tensorboard experiment information about the given Tensorboard experiment id. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-experiments/list)`
     `(BETA)` List the Tensorboard experiments of the given project, region, and Tensorboard. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-experiments/update)`
     `(BETA)` Update an existing Vertex AI Tensorboard experiment. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha ai tensorboard-experiments](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/tensorboard-experiments)
