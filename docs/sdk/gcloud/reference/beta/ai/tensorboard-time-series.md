NAME
    

gcloud beta ai tensorboard-time-series - manage Vertex AI Tensorboard time series 
SYNOPSIS
    

`gcloud beta ai tensorboard-time-series` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Vertex AI Tensorboard time series. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-time-series/create)`
     `(BETA)` Create a new Vertex AI Tensorboard time series. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-time-series/delete)`
     `(BETA)` Delete an existing Vertex AI Tensorboard time series. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-time-series/describe)`
     `(BETA)` Get detailed Tensorboard time series information about the given Tensorboard time series id. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-time-series/list)`
     `(BETA)` List the Tensorboard time series of the given project, region, and Tensorboard run. 
`[read](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-time-series/read)`
     `(BETA)` Read the Tensorboard time series data from the given Tensorboard time series id. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tensorboard-time-series/update)`
     `(BETA)` Update an existing Vertex AI Tensorboard time series. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha ai tensorboard-time-series](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/tensorboard-time-series)
