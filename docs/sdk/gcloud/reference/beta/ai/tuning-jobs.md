NAME
    

gcloud beta ai tuning-jobs - manage Vertex AI tuning jobs 
SYNOPSIS
    

`gcloud beta ai tuning-jobs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` A tuning job runs a supervised fine-tuning (SFT) operation on a base foundation model to create a tuned model customized for your use case. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tuning-jobs/cancel)`
     `(BETA)` Cancel a running tuning job. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tuning-jobs/create)`
     `(BETA)` Create a supervised fine-tuning job. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tuning-jobs/describe)`
     `(BETA)` Get detail information about the tuning job by given id. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/tuning-jobs/list)`
     `(BETA)` List existing tuning jobs. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud ai tuning-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/ai/tuning-jobs)
    
    
    [gcloud alpha ai tuning-jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/tuning-jobs)
