NAME
    

gcloud beta ai semantic-governance-policies - manage Vertex AI Semantic Governance Policy resources 
SYNOPSIS
    

`gcloud beta ai semantic-governance-policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Vertex AI Semantic Governance Policy resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/semantic-governance-policies/create)`
     `(BETA)` Create a new semantic governance policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/semantic-governance-policies/delete)`
     `(BETA)` Delete a semantic governance policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/semantic-governance-policies/describe)`
     `(BETA)` Describe a semantic governance policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/semantic-governance-policies/list)`
     `(BETA)` List semantic governance policies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/semantic-governance-policies/update)`
     `(BETA)` Update a semantic governance policy. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud ai semantic-governance-policies](https://docs.cloud.google.com/sdk/gcloud/reference/ai/semantic-governance-policies)
