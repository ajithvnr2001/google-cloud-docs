NAME
    

gcloud beta ai models - manage Vertex AI models 
SYNOPSIS
    

`gcloud beta ai models` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Vertex AI models. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/models/copy)`
     `(BETA)` Copy a model. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/models/delete)`
     `(BETA)` Delete an existing Vertex AI model. 
`[delete-version](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/models/delete-version)`
     `(BETA)` Delete an existing Vertex AI model version. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/models/describe)`
     `(BETA)` Get detailed model information about the given model id. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/models/list)`
     `(BETA)` List the models of the given project and region. 
`[list-version](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/models/list-version)`
     `(BETA)` List the model versions of the given region and model. 
`[upload](https://docs.cloud.google.com/sdk/gcloud/reference/beta/ai/models/upload)`
     `(BETA)` Upload a new model. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud ai models](https://docs.cloud.google.com/sdk/gcloud/reference/ai/models)
    
    
    [gcloud alpha ai models](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/ai/models)
