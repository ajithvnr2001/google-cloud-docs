NAME
    

gcloud beta developer-connect - manage Developer Connect resources 
SYNOPSIS
    

`gcloud beta developer-connect` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Developer Connect resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[account-connectors](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/account-connectors)`
     `(BETA)` Manage Account Connector resources. 
`[connections](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/connections)`
     `(BETA)` Manage connection resources. 
`[insights-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/insights-configs)`
     `(BETA)` Manage Insights Config resources. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/developer-connect/operations)`
     `(BETA)` Manage Operation resources. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud developer-connect](https://docs.cloud.google.com/sdk/gcloud/reference/developer-connect)
    
    
    [gcloud alpha developer-connect](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/developer-connect)
