NAME
    

gcloud beta monitoring - manage Cloud Monitoring dashboards and notification channels 
SYNOPSIS
    

`gcloud beta monitoring` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Monitoring dashboards and notification channels. 

More information can be found here: 

  * <https://cloud.google.com/monitoring/api/v3/>
  * <https://cloud.google.com/monitoring/alerts/using-channels-api>
  * <https://cloud.google.com/monitoring/dashboards/api-dashboard>


GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[alerts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/alerts)`
     `(BETA)` Manage Cloud Monitoring alerts. 
`[channel-descriptors](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/channel-descriptors)`
     `(BETA)` Read Cloud Monitoring notification channel descriptors. 
`[channels](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/channels)`
     `(BETA)` Manage Cloud Monitoring notification channels. 
`[dashboards](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/dashboards)`
     `(BETA)` Manage Cloud Monitoring dashboards. 
`[metrics-scopes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/metrics-scopes)`
     `(BETA)` Manage Cloud Monitoring Metrics Scopes. 
`[policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies)`
     `(BETA)` Manage Cloud Monitoring alerting policies. 
`[snoozes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/snoozes)`
     `(BETA)` Manage Cloud Monitoring snoozes. 
`[uptime](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime)`
     `(BETA)` Manage Cloud Monitoring uptime checks and synthetic monitors. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud monitoring](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring)
    
    
    [gcloud alpha monitoring](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring)
