NAME
    

gcloud beta workstations configs - manage Cloud Workstations configuration resources 
SYNOPSIS
    

`gcloud beta workstations configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Workstations configuration resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs/create)`
     `(BETA)` Create a workstation configuration. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs/delete)`
     `(BETA)` Delete a workstation configuration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs/describe)`
     `(BETA)` Describe a config. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs/get-iam-policy)`
     `(BETA)` Get the IAM policy for a configuration.. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs/list)`
     `(BETA)` List workstation configurations. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs/set-iam-policy)`
     `(BETA)` Set the IAM policy for a configuration. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/workstations/configs/update)`
     `(BETA)` Updates a workstation configuration. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud workstations configs](https://docs.cloud.google.com/sdk/gcloud/reference/workstations/configs)
    
    
    [gcloud alpha workstations configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/workstations/configs)
