NAME
    

gcloud beta redis - manage Cloud Memorystore Redis resources 
SYNOPSIS
    

`gcloud beta redis` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Memorystore Redis resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[acl-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/acl-policies)`
     `(BETA)` Manage ACL policies of Memorystore for Redis Cluster instances. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters)`
     `(BETA)` Manage Memorystore for Redis Cluster instances. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/instances)`
     `(BETA)` Manage Cloud Memorystore Redis instances. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/operations)`
     `(BETA)` Manage Cloud Memorystore Redis operations. 
`[regions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/regions)`
     `(BETA)` Manage Cloud Memorystore Redis regions. 
`[zones](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/zones)`
     `(BETA)` Manage Cloud Memorystore Redis zones. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud redis](https://docs.cloud.google.com/sdk/gcloud/reference/redis)
    
    
    [gcloud alpha redis](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis)
