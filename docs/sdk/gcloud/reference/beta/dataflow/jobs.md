NAME
    

gcloud beta dataflow jobs - a group of subcommands for working with Dataflow jobs 
SYNOPSIS
    

`gcloud beta dataflow jobs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` A group of subcommands for working with Dataflow jobs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[archive](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/archive)`
     `(BETA)` Archives a job. 
`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/cancel)`
     `(BETA)` Cancels all jobs that match the command line arguments. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/describe)`
     `(BETA)` Outputs the Job object resulting from the Get API. 
`[drain](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/drain)`
     `(BETA)` Drains all jobs that match the command line arguments. 
`[export-steps](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/export-steps)`
     `(BETA)` Exports information about the steps for the given job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/list)`
     `(BETA)` Lists all jobs in a particular project, optionally filtered by region. 
`[run](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/run)`
     `(BETA)` Runs a job from the specified path. 
`[show](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/show)`
     `(BETA)` Shows a short description of the given job. 
`[update-options](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs/update-options)`
     `(BETA)` Update pipeline options on-the-fly for running Dataflow jobs. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud dataflow jobs](https://docs.cloud.google.com/sdk/gcloud/reference/dataflow/jobs)
    
    
    [gcloud alpha dataflow jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataflow/jobs)
