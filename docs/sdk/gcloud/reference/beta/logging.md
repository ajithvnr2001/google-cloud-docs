NAME
    

gcloud beta logging - manage Cloud Logging 
SYNOPSIS
    

`gcloud beta logging` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Logging. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[buckets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/buckets)`
     `(BETA)` Manage Cloud Logging buckets. 
`[links](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/links)`
     `(BETA)` Manage linked datasets. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/locations)`
     `(BETA)` Query Cloud Logging locations. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/logs)`
     `(BETA)` Manages your project's logs. 
`[metrics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/metrics)`
     `(BETA)` Manages logs-based metrics. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/operations)`
     `(BETA)` Manage long running operations. 
`[resource-descriptors](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/resource-descriptors)`
     `(BETA)` Get information about resource descriptors. 
`[settings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/settings)`
     `(BETA)` Manages the org settings for the Cloud Logging Logs Router. 
`[sinks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/sinks)`
     `(BETA)` Manages sinks used to route logs to storage or export destinations. 
`[views](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/views)`
     `(BETA)` Manage log views. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/copy)`
     `(BETA)` Copy log entries. 
`[read](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/read)`
     `(BETA)` Read log entries. 
`[tail](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/tail)`
     `(BETA)` Tail log entries. 
`[write](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/write)`
     `(BETA)` Write a log entry. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud logging](https://docs.cloud.google.com/sdk/gcloud/reference/logging)
    
    
    [gcloud alpha logging](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging)
