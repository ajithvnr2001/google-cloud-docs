NAME
    

gcloud beta netapp backup-vaults backups - create and manage Cloud NetApp Backups 
SYNOPSIS
    

`gcloud beta netapp backup-vaults backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Cloud NetApp Backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/backups/create)`
     `(BETA)` Create a Cloud NetApp Backup. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/backups/delete)`
     `(BETA)` Delete a Cloud NetApp Backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/backups/describe)`
     `(BETA)` Describe a Cloud NetApp Backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/backups/list)`
     `(BETA)` List Cloud NetApp Backups. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/backups/update)`
     `(BETA)` Update a Cloud NetApp Backup. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud netapp backup-vaults backups](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/backup-vaults/backups)
