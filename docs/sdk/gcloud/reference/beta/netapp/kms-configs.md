NAME
    

gcloud beta netapp kms-configs - create and manage Cloud NetApp Volumes KMS Configs 
SYNOPSIS
    

`gcloud beta netapp kms-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Cloud NetApp Volumes KMS Configs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/kms-configs/create)`
     `(BETA)` Create a Cloud NetApp Volumes KMS Config. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/kms-configs/delete)`
     `(BETA)` Delete a Cloud NetApp Volumes KMS Config. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/kms-configs/describe)`
     `(BETA)` Show metadata for a Cloud NetApp Volumes KMS Config. 
`[encrypt](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/kms-configs/encrypt)`
     `(BETA)` Encrypt all existing volumes and storage pools in the same region with the desired Cloud NetApp Volumes KMS Config. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/kms-configs/list)`
     `(BETA)` List Cloud NetApp Volumes KMS Configs. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/kms-configs/update)`
     `(BETA)` Update a Cloud NetApp Volumes KMS Config. 
`[verify](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/kms-configs/verify)`
     `(BETA)` Verify that the Cloud NetApp Volumes KMS Config is reachable. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud netapp kms-configs](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/kms-configs)
