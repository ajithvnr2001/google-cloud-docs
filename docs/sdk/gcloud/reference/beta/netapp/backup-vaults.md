NAME
    

gcloud beta netapp backup-vaults - create and manage Cloud NetApp Backup Vaults 
SYNOPSIS
    

`gcloud beta netapp backup-vaults` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Cloud NetApp Backup Vaults. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/backups)`
     `(BETA)` Create and manage Cloud NetApp Backups. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/create)`
     `(BETA)` Create a Cloud NetApp Backup Vault. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/delete)`
     `(BETA)` Delete a Cloud NetApp Volumes Backup Vault. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/describe)`
     `(BETA)` Show metadata for a Cloud NetApp Volumes Backup Vault. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/list)`
     `(BETA)` List Cloud NetApp Volumes Backup Vaults. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/backup-vaults/update)`
     `(BETA)` Update a Cloud NetApp Volumes Backup Vault. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud netapp backup-vaults](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/backup-vaults)
