NAME
    

gcloud beta netapp active-directories - create and manage Cloud NetApp Active Directories 
SYNOPSIS
    

`gcloud beta netapp active-directories` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Cloud NetApp Active Directories. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/active-directories/create)`
     `(BETA)` Create a Cloud NetApp Active Directory. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/active-directories/delete)`
     `(BETA)` Delete a Cloud NetApp Active Directory. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/active-directories/describe)`
     `(BETA)` Show metadata for a Cloud NetApp Active Directory. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/active-directories/list)`
     `(BETA)` List Cloud NetApp Active Directories. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/netapp/active-directories/update)`
     `(BETA)` Update a Cloud NetApp Active Directory. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud netapp active-directories](https://docs.cloud.google.com/sdk/gcloud/reference/netapp/active-directories)
    
    
    [gcloud alpha netapp active-directories](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/netapp/active-directories)
