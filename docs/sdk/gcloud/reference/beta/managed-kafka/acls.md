NAME
    

gcloud beta managed-kafka acls - administer Managed Service for Apache Kafka acls 
SYNOPSIS
    

`gcloud beta managed-kafka acls` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Administer Managed Service for Apache Kafka acls. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-acl-entry](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls/add-acl-entry)`
     `(BETA)` Add an acl entry to a Managed Service for Apache Kafka acl. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls/create)`
     `(BETA)` Create a Managed Service for Apache Kafka acl. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls/delete)`
     `(BETA)` Delete a Managed Service for Apache Kafka ACL. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls/describe)`
     `(BETA)` Describe a Managed Service for Apache Kafka acl. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls/list)`
     `(BETA)` List all Managed Service for Apache Kafka acls in a given cluster. 
`[remove-acl-entry](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls/remove-acl-entry)`
     `(BETA)` Remove an acl entry from a Managed Service for Apache Kafka acl. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/acls/update)`
     `(BETA)` Update a Managed Service for Apache Kafka acl. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud managed-kafka acls](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/acls)
    
    
    [gcloud alpha managed-kafka acls](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/acls)
