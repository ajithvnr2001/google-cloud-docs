NAME
    

gcloud beta managed-kafka connectors - administer Managed Service for Apache Kafka connectors 
SYNOPSIS
    

`gcloud beta managed-kafka connectors` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Administer Managed Service for Apache Kafka connectors. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/create)`
     `(BETA)` Create a Managed Service for Apache Kafka connector. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/delete)`
     `(BETA)` Delete a Managed Service for Apache Kafka connector. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/describe)`
     `(BETA)` Describe a Managed Service for Apache Kafka connector. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/list)`
     `(BETA)` List all Managed Service for Apache Kafka connectors for a given connect cluster. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/pause)`
     `(BETA)` Pauses operation of a Managed Service for Apache Kafka connector. 
`[restart](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/restart)`
     `(BETA)` Restarts a Managed Service for Apache Kafka connector. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/resume)`
     `(BETA)` Resumes operation of a stopped Managed Service for Apache Kafka connector. 
`[stop](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/stop)`
     `(BETA)` Stops operation of a Managed Service for Apache Kafka connector. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connectors/update)`
     `(BETA)` Update a Managed Service for Apache Kafka connector. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud managed-kafka connectors](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/connectors)
    
    
    [gcloud alpha managed-kafka connectors](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connectors)
