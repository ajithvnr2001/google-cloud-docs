NAME
    

gcloud beta managed-kafka operations - view Managed Service for Apache Kafka operations 
SYNOPSIS
    

`gcloud beta managed-kafka operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` View Managed Service for Apache Kafka operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/operations/describe)`
     `(BETA)` Describe a Managed Service for Apache Kafka operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/operations/list)`
     `(BETA)` List all Managed Service for Apache Kafka operations in a given location. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud managed-kafka operations](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/operations)
    
    
    [gcloud alpha managed-kafka operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/operations)
