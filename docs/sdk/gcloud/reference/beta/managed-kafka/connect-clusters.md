NAME
    

gcloud beta managed-kafka connect-clusters - administer Managed Service for Apache Kafka connect-clusters 
SYNOPSIS
    

`gcloud beta managed-kafka connect-clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Administer Managed Service for Apache Kafka connect-clusters. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connect-clusters/create)`
     `(BETA)` Create a Managed Service for Apache Kafka connect cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connect-clusters/delete)`
     `(BETA)` Delete a Managed Service for Apache Kafka connect cluster. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connect-clusters/describe)`
     `(BETA)` Describe a Managed Service for Apache Kafka connect cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connect-clusters/list)`
     `(BETA)` List all Managed Service for Apache Kafka connect clusters in a given location. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/managed-kafka/connect-clusters/update)`
     `(BETA)` Update a Managed Service for Apache Kafka for BigQuery connect cluster. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud managed-kafka connect-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/managed-kafka/connect-clusters)
    
    
    [gcloud alpha managed-kafka connect-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/managed-kafka/connect-clusters)
