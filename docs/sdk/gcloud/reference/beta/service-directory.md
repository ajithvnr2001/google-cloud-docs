NAME
    

gcloud beta service-directory - command groups for Service Directory 
SYNOPSIS
    

`gcloud beta service-directory` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Command groups for Service Directory. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/endpoints)`
     `(BETA)` Manage Service Directory endpoints. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/locations)`
     `(BETA)` Manage Service Directory locations. 
`[namespaces](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/namespaces)`
     `(BETA)` Manage Service Directory namespaces. 
`[services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-directory/services)`
     `(BETA)` Manage Service Directory services. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud service-directory](https://docs.cloud.google.com/sdk/gcloud/reference/service-directory)
    
    
    [gcloud alpha service-directory](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-directory)
