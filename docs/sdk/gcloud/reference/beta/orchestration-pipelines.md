NAME
    

gcloud beta orchestration-pipelines - manage Orchestration Pipelines resources 
SYNOPSIS
    

`gcloud beta orchestration-pipelines` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Orchestration Pipelines resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[resource-types](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/resource-types)`
     `(BETA)` Discover supported orchestration pipelines resource types. 
`[runs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/runs)`
     `(BETA)` Manage Orchestration Pipelines runs. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/delete)`
     `(BETA)` Delete a pipelines bundle from a runner. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/deploy)`
     `(BETA)` Deploy a pipelines bundle. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/describe)`
     `(BETA)` Get details about an orchestration pipeline. 
`[info](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/info)`
     `(BETA)` Show info about an orchestration pipeline library. 
`[init](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/init)`
     `(BETA)` Initialize an orchestration pipeline. 
`[init-demo](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/init-demo)`
     `(BETA)` Initialize a demo orchestration pipeline project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/list)`
     `(BETA)` List orchestration pipelines in the environment. 
`[pause](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/pause)`
     `(BETA)` Pause an orchestration pipeline. 
`[trigger](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/trigger)`
     `(BETA)` Trigger an orchestration pipeline. 
`[unpause](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/unpause)`
     `(BETA)` Unpause an orchestration pipeline. 
`[validate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/orchestration-pipelines/validate)`
     `(BETA)` Validate orchestration pipeline configurations against schemas. 
NOTES
     This command is currently in beta and might change without notice.
