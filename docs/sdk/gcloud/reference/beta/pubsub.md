NAME
    

gcloud beta pubsub - manage Cloud Pub/Sub topics, subscriptions, and snapshots 
SYNOPSIS
    

`gcloud beta pubsub` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Pub/Sub topics, subscriptions, and snapshots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[lite-operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-operations)`
     `(BETA)` Manage Pub/Sub Lite operations. 
`[lite-reservations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-reservations)`
     `(BETA)` Manage Pub/Sub Lite reservations. 
`[lite-subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-subscriptions)`
     `(BETA)` Manage Pub/Sub Lite subscriptions. 
`[lite-topics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-topics)`
     `(BETA)` Manage Pub/Sub Lite topics. 
`[message-transforms](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/message-transforms)`
     `(BETA)` Manage Cloud Pub/Sub message transforms. 
`[schemas](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas)`
     `(BETA)` Manage Pub/Sub schemas. 
`[snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/snapshots)`
     `(BETA)` Manage Cloud Pub/Sub snapshots. 
`[subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions)`
     `(BETA)` Manage Cloud Pub/Sub subscriptions. 
`[topics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/topics)`
     `(BETA)` Manage Cloud Pub/Sub topics. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud pubsub](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub)
    
    
    [gcloud alpha pubsub](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub)
