NAME
    

gcloud beta metastore federations - manage Dataproc Metastore federations 
SYNOPSIS
    

`gcloud beta metastore federations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Dataproc Metastore federations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a federation. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/create)`
     `(BETA)` Create a Dataproc Metastore federation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/delete)`
     `(BETA)` Delete one or more Dataproc Metastore federations. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/describe)`
     `(BETA)` Describe a Dataproc Metastore federation. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/get-iam-policy)`
     `(BETA)` Get the IAM policy for the federation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/list)`
     `(BETA)` List Dataproc Metastore federations. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a federation. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/set-iam-policy)`
     `(BETA)` Set the IAM policy for the federation. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/federations/update)`
     `(BETA)` Update a Dataproc Metastore federation. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud metastore federations](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/federations)
    
    
    [gcloud alpha metastore federations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/federations)
