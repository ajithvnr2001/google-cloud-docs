NAME
    

gcloud beta metastore services - manage Dataproc Metastore services 
SYNOPSIS
    

`gcloud beta metastore services` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Dataproc Metastore services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups)`
     `(BETA)` Manage backups under Dataproc Metastore services. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/databases)`
     `(BETA)` Manage databases under Dataproc Metastore services. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/export)`
     `(BETA)` Export metadata from a Dataproc Metastore service. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/import)`
     `(BETA)` Import metadata into a Dataproc Metastore service. 
`[imports](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/imports)`
     `(BETA)` `(DEPRECATED)` Manage metadata imports under Dataproc Metastore services. 
`[migrations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations)`
     `(BETA)` Manage the migration to a Dataproc Metastore service. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a service. 
`[alter-metadata-resource-location](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/alter-metadata-resource-location)`
     `(BETA)` Alter metadata resource location. 
`[alter-table-properties](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/alter-table-properties)`
     `(BETA)` Alter metadata table properties. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/create)`
     `(BETA)` Create a Dataproc Metastore service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/delete)`
     `(BETA)` Delete one or more Dataproc Metastore services. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/describe)`
     `(BETA)` Describe a Dataproc Metastore service. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/get-iam-policy)`
     `(BETA)` Get the IAM policy for the service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/list)`
     `(BETA)` List Dataproc Metastore services. 
`[move-table-to-database](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/move-table-to-database)`
     `(BETA)` Move table to another database. 
`[query-metadata](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/query-metadata)`
     `(BETA)` Execute a SQL query against a Dataproc Metastore Service's metadata. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a service. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/restore)`
     `(BETA)` Restore a Dataproc Metastore service. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/set-iam-policy)`
     `(BETA)` Set the IAM policy for the service. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/update)`
     `(BETA)` Update a Dataproc Metastore service. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud metastore services](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services)
    
    
    [gcloud alpha metastore services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services)
