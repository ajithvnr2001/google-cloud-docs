NAME
    

gcloud beta metastore services backups - manage backups under Dataproc Metastore services 
SYNOPSIS
    

`gcloud beta metastore services backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage backups under Dataproc Metastore services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a backup. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/create)`
     `(BETA)` Backup a service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/delete)`
     `(BETA)` Delete a service backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/describe)`
     `(BETA)` Describe a backup. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/get-iam-policy)`
     `(BETA)` Get the IAM policy for the backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/list)`
     `(BETA)` List backups under a Dataproc Metastore service. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a backup. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/backups/set-iam-policy)`
     `(BETA)` Set the IAM policy for a backup. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud metastore services backups](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/backups)
    
    
    [gcloud alpha metastore services backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/backups)
