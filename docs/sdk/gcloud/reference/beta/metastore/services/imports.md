NAME
    

gcloud beta metastore services imports - manage metadata imports under Dataproc Metastore services 
SYNOPSIS
    

`gcloud beta metastore services imports` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` `(DEPRECATED)` Manage metadata imports under Dataproc Metastore services. 

This command has been deprecated. Please use `[gcloud metastore services import](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/import)` command group instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/imports/create)`
     `(BETA)` `(DEPRECATED)` Import metadata into a service. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/imports/describe)`
     `(BETA)` `(DEPRECATED)` Describe a metadata import. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/imports/list)`
     `(BETA)` `(DEPRECATED)` List metadata imports under a Dataproc Metastore service. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/imports/update)`
     `(BETA)` `(DEPRECATED)` Update a metadata import. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha metastore services imports](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/imports)
