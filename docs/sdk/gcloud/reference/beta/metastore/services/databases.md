NAME
    

gcloud beta metastore services databases - manage databases under Dataproc Metastore services 
SYNOPSIS
    

`gcloud beta metastore services databases` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage databases under Dataproc Metastore services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[tables](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/databases/tables)`
     `(BETA)` Manage tables under databases. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/databases/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a database. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/databases/get-iam-policy)`
     `(BETA)` Get the IAM policy for the database. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/databases/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a database. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/databases/set-iam-policy)`
     `(BETA)` Set the IAM policy for a database. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha metastore services databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/databases)
