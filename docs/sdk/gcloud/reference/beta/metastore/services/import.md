NAME
    

gcloud beta metastore services import - import metadata into a Dataproc Metastore service 
SYNOPSIS
    

`gcloud beta metastore services import` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Import metadata into a Dataproc Metastore service. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[gcs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/import/gcs)`
     `(BETA)` Import metadata into a Dataproc Metastore service from Google Cloud Storage. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud metastore services import](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/import)
    
    
    [gcloud alpha metastore services import](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/import)
