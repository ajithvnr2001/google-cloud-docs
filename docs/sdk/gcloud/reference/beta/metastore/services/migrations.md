NAME
    

gcloud beta metastore services migrations - manage the migration to a Dataproc Metastore service 
SYNOPSIS
    

`gcloud beta metastore services migrations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage the migration to a Dataproc Metastore service. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations/cancel)`
     `(BETA)` Cancel the migration to Dataproc Metastore service. 
`[complete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations/complete)`
     `(BETA)` Complete the migration to Dataproc Metastore service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations/delete)`
     `(BETA)` Delete a migration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations/describe)`
     `(BETA)` Describe a migration. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations/list)`
     `(BETA)` List migrations for a Dataproc Metastore service. 
`[start](https://docs.cloud.google.com/sdk/gcloud/reference/beta/metastore/services/migrations/start)`
     `(BETA)` Start the migration from a Dataproc Metastore service to Lakehouse runtime catalog(s). 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud metastore services migrations](https://docs.cloud.google.com/sdk/gcloud/reference/metastore/services/migrations)
    
    
    [gcloud alpha metastore services migrations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/metastore/services/migrations)
