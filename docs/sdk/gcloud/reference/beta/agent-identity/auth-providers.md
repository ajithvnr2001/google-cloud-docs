#  gcloud beta agent-identity auth-providers Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta agent-identity auth-providers - manage Auth Provider resources 
SYNOPSIS
    

`gcloud beta agent-identity auth-providers` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Auth Provider resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations)`
     `(BETA)` Manage Authorization resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to an Agent Identity authProvider. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/create)`
     `(BETA)` Create an auth provider. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/delete)`
     `(BETA)` Delete an auth provider. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/describe)`
     `(BETA)` Describe an auth provider. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/disable)`
     `(BETA)` Disable an auth provider. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/enable)`
     `(BETA)` Enable an auth provider. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/get-iam-policy)`
     `(BETA)` Get the IAM policy for an Agent Identity authProvider. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/list)`
     `(BETA)` List auth providers. 
`[query](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/query)`
     `(BETA)` Query auth providers used by a workload. 
`[query-workloads](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/query-workloads)`
     `(BETA)` Query workloads using an auth provider. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding from an Agent Identity authProvider. 
`[resolve-authorization](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/resolve-authorization)`
     `(BETA)` Resolve authorization for a user on an auth provider. 
`[revoke-authorization](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/revoke-authorization)`
     `(BETA)` Revoke authorization for a user on an auth provider. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/set-iam-policy)`
     `(BETA)` Set the IAM policy for an Agent Identity authProvider. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/test-iam-permissions)`
     `(BETA)` Test IAM permissions for an Agent Identity authProvider. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/undelete)`
     `(BETA)` Undelete an auth provider. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/update)`
     `(BETA)` Update an auth provider. 
NOTES
