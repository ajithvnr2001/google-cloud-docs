NAME
    

gcloud beta agent-identity auth-providers authorizations - manage Authorization resources 
SYNOPSIS
    

`gcloud beta agent-identity auth-providers authorizations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Authorization resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to an Agent Identity authorization. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/delete)`
     `(BETA)` Delete an authorization. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/describe)`
     `(BETA)` Describe an authorization. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/get-iam-policy)`
     `(BETA)` Get the IAM policy for an Agent Identity authorization. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/list)`
     `(BETA)` List authorizations. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding from an Agent Identity authorization. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/set-iam-policy)`
     `(BETA)` Set the IAM policy for an Agent Identity authorization. 
`[test-iam-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations/test-iam-permissions)`
     `(BETA)` Test IAM permissions for an Agent Identity authorization. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud agent-identity auth-providers authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/agent-identity/auth-providers/authorizations)
    
    
    [gcloud alpha agent-identity auth-providers authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/agent-identity/auth-providers/authorizations)
