NAME
    

gcloud beta agent-identity auth-providers authorizations get-iam-policy - get the IAM policy for an Agent Identity authorization 
SYNOPSIS
    

`gcloud beta agent-identity auth-providers authorizations get-iam-policy` (`AUTHORIZATION` : `--auth-provider`=`AUTH_PROVIDER` `--location`=`LOCATION`) [`--endpoint-mode`=`ENDPOINT_MODE`] [`--filter`=`EXPRESSION`] [`--limit`=`LIMIT`] [`--page-size`=`PAGE_SIZE`] [`--sort-by`=[`FIELD`,…]] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This command gets the IAM policy for an authorization. 
EXAMPLES
     To print the IAM policy for a given authorization, run: 
    
    
    [gcloud beta agent-identity auth-providers authorizations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/agent-identity/auth-providers/authorizations) get-iam-policy my-auth --auth-provider=my-auth-provider --location=LOCATION

     ID of the authorization or fully qualified identifier for the authorization.
