NAME
    

gcloud beta container backup-restore backup-plans - backup for GKE Backup Plans 
SYNOPSIS
    

`gcloud beta container backup-restore backup-plans` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Backup for GKE Backup Plans. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backup-plans/create)`
     `(BETA)` Create a backup plan. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backup-plans/delete)`
     `(BETA)` Delete a backup plan. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backup-plans/describe)`
     `(BETA)` Describe a backup plan. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backup-plans/get-iam-policy)`
     `(BETA)` Get the IAM policy for a backup plan. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backup-plans/list)`
     `(BETA)` List backup plans. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backup-plans/set-iam-policy)`
     `(BETA)` Set the IAM policy for a backup plan. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backup-plans/update)`
     `(BETA)` Update a backup plan. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha container backup-restore backup-plans](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backup-plans)
