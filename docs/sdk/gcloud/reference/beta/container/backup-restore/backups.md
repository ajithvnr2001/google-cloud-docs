NAME
    

gcloud beta container backup-restore backups - backup for GKE Backups 
SYNOPSIS
    

`gcloud beta container backup-restore backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Backup for GKE Backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/create)`
     `(BETA)` Creates a backup. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/delete)`
     `(BETA)` Delete a backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/describe)`
     `(BETA)` Describe a backup. 
`[get-backup-index-download-url](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/get-backup-index-download-url)`
     `(BETA)` Get a backup index download URL. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/get-iam-policy)`
     `(BETA)` Get the IAM policy for a backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/list)`
     `(BETA)` List backups. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/set-iam-policy)`
     `(BETA)` Set the IAM policy for a backup. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/backup-restore/backups/update)`
     `(BETA)` Update a backup. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha container backup-restore backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/backup-restore/backups)
