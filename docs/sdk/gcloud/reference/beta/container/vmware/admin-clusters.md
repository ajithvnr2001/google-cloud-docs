NAME
    

gcloud beta container vmware admin-clusters - create and manage admin clusters in Anthos on VMware 
SYNOPSIS
    

`gcloud beta container vmware admin-clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage admin clusters in Anthos on VMware. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/admin-clusters/describe)`
     `(BETA)` Describe an Anthos on VMware admin cluster. 
`[enroll](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/admin-clusters/enroll)`
     `(BETA)` Enroll an Anthos on VMware admin cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/admin-clusters/list)`
     `(BETA)` List Anthos on VMware admin clusters. 
`[unenroll](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/admin-clusters/unenroll)`
     `(BETA)` Unenroll an Anthos on VMware admin cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/admin-clusters/update)`
     `(BETA)` Update an Anthos on VMware admin cluster. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container vmware admin-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/container/vmware/admin-clusters)
    
    
    [gcloud alpha container vmware admin-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/admin-clusters)
