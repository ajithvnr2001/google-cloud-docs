NAME
    

gcloud beta container vmware node-pools - create and manage node pools in an Anthos cluster on VMware 
SYNOPSIS
    

`gcloud beta container vmware node-pools` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage node pools in an Anthos cluster on VMware. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/node-pools/create)`
     `(BETA)` Create a node pool in an Anthos cluster on VMware. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/node-pools/delete)`
     `(BETA)` Delete a node pool in an Anthos cluster on VMware. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/node-pools/describe)`
     `(BETA)` Describe a node pool in an Anthos cluster on VMware. 
`[enroll](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/node-pools/enroll)`
     `(BETA)` Enroll a node pool in an Anthos cluster on VMware. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/node-pools/list)`
     `(BETA)` List node pools in an Anthos cluster on VMware. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/vmware/node-pools/update)`
     `(BETA)` Update a node pool in an Anthos cluster on VMware. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container vmware node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/container/vmware/node-pools)
    
    
    [gcloud alpha container vmware node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/vmware/node-pools)
