NAME
    

gcloud beta container fleet packages - manage Fleet Packages resources 
SYNOPSIS
    

`gcloud beta container fleet packages` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Fleet Packages resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[resource-bundles](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/resource-bundles)`
     `(BETA)` Commands for managing Package Rollouts Resource Bundles. 
`[rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/rollouts)`
     `(BETA)` Commands for managing Rollouts. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/create)`
     `(BETA)` Create Package Rollouts Fleet Package. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/delete)`
     `(BETA)` Delete Package Rollouts Fleet Package. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/describe)`
     `(BETA)` Describe Package Rollouts Fleet Package. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/list)`
     `(BETA)` List Package Rollouts Fleet Packages. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/update)`
     `(BETA)` Update Package Rollouts Fleet Package. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container fleet packages](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/packages)
    
    
    [gcloud alpha container fleet packages](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/packages)
