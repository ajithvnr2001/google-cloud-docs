NAME
    

gcloud beta container fleet packages rollouts - commands for managing Rollouts 
SYNOPSIS
    

`gcloud beta container fleet packages rollouts` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` See `gcloud beta container fleet packages rollouts --help` for help. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[abort](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/rollouts/abort)`
     `(BETA)` Abort Rollout resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/rollouts/describe)`
     `(BETA)` Describe Rollout resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/rollouts/list)`
     `(BETA)` List Rollouts of a Fleet Package. 
`[resume](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/rollouts/resume)`
     `(BETA)` Resume suspended Rollout. 
`[suspend](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/packages/rollouts/suspend)`
     `(BETA)` Suspend in-progress Rollout. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container fleet packages rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/packages/rollouts)
    
    
    [gcloud alpha container fleet packages rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/packages/rollouts)
