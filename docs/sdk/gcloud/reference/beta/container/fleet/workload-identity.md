NAME
    

gcloud beta container fleet workload-identity - manage Workload Identity Feature 
SYNOPSIS
    

`gcloud beta container fleet workload-identity` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Workload Identity Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[scope-tenancy-pool](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/workload-identity/scope-tenancy-pool)`
     `(BETA)` Manage Workload Identity Feature scope tenancy pool. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/workload-identity/describe)`
     `(BETA)` Describe the status of Workload Identity Feature resource. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/workload-identity/disable)`
     `(BETA)` Disable Workload Identity Feature. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/workload-identity/enable)`
     `(BETA)` Enable Workload Identity Feature. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container fleet workload-identity](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/workload-identity)
    
    
    [gcloud alpha container fleet workload-identity](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/workload-identity)
