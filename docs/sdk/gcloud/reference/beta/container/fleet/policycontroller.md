NAME
    

gcloud beta container fleet policycontroller - manage Policy Controller Feature 
SYNOPSIS
    

`gcloud beta container fleet policycontroller` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Policy Controller Feature. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[content](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/content)`
     `(BETA)` Manage Policy Controller content. 
`[deployment](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/deployment)`
     `(BETA)` Configure Policy Controller component deployments. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/describe)`
     `(BETA)` Describe Policy Controller feature. 
`[detach](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/detach)`
     `(BETA)` Detach Policy Controller Feature. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/disable)`
     `(BETA)` Disable (Uninstall) Policy Controller. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/enable)`
     `(BETA)` Enable Policy Controller Feature. 
`[suspend](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/suspend)`
     `(BETA)` Suspend Policy Controller Feature. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/policycontroller/update)`
     `(BETA)` Updates the configuration of Policy Controller Feature. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container fleet policycontroller](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/policycontroller)
    
    
    [gcloud alpha container fleet policycontroller](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/policycontroller)
