#  gcloud beta container fleet memberships Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta container fleet memberships - manage memberships of all your GKE and other Kubernetes clusters with fleets 
SYNOPSIS
    

`gcloud beta container fleet memberships` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage memberships of all your GKE and other Kubernetes clusters with fleets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[bindings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/bindings)`
     `(BETA)` Membership Bindings for permissions. 
`[support-access](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/support-access)`
     `(BETA)` Membership used for support access. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/delete)`
     `(BETA)` Delete a membership. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/describe)`
     `(BETA)` Describe a membership. 
`[generate-gateway-rbac](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/generate-gateway-rbac)`
     `(BETA)` Generate RBAC policy files for connected clusters by the user. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/get-credentials)`
     `(BETA)` Fetch credentials for a fleet-registered cluster to be used in Connect Gateway. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/list)`
     `(BETA)` List memberships. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/register)`
     `(BETA)` Register a cluster with a fleet. 
`[unregister](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/unregister)`
     `(BETA)` Unregister a cluster from a fleet. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/fleet/memberships/update)`
     `(BETA)` Update a membership. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container fleet memberships](https://docs.cloud.google.com/sdk/gcloud/reference/container/fleet/memberships)
    
    
    [gcloud alpha container fleet memberships](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/fleet/memberships)
