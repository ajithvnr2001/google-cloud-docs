NAME
    

gcloud beta container bare-metal - deploy and manage Anthos clusters on bare metal for running containers 
SYNOPSIS
    

`gcloud beta container bare-metal` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Deploy and manage Anthos clusters on bare metal for running containers. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[admin-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters)`
     `(BETA)` Create and manage admin clusters in Anthos on bare metal. 
`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/clusters)`
     `(BETA)` Create and manage Anthos clusters on bare metal. 
`[node-pools](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/node-pools)`
     `(BETA)` Create and manage node pools in an Anthos cluster on bare metal. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/operations)`
     `(BETA)` Manage Anthos on bare metal long running operations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container bare-metal](https://docs.cloud.google.com/sdk/gcloud/reference/container/bare-metal)
    
    
    [gcloud alpha container bare-metal](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/bare-metal)
