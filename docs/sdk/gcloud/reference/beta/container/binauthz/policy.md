NAME
    

gcloud beta container binauthz policy - create and manage Google Binary Authorization policies 
SYNOPSIS
    

`gcloud beta container binauthz policy` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Google Binary Authorization policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a Binary Authorization policy. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/create)`
     `(BETA)` Create a Binary Authorization platform policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/delete)`
     `(BETA)` Delete a Binary Authorization platform policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/describe)`
     `(BETA)` Describe a Binary Authorization platform policy. 
`[evaluate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/evaluate)`
     `(BETA)` Evaluate a Binary Authorization platform policy. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/export)`
     `(BETA)` Export the Binary Authorization policy for the current project. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Binary Authorization policy. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/import)`
     `(BETA)` Import a Binary Authorization policy to the current project. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/list)`
     `(BETA)` List Binary Authorization platform policies. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding of a Binary Authorization policy. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Binary Authorization policy. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/binauthz/policy/update)`
     `(BETA)` Update a Binary Authorization platform policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container binauthz policy](https://docs.cloud.google.com/sdk/gcloud/reference/container/binauthz/policy)
