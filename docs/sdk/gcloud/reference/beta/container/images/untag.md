NAME
    

gcloud beta container images untag - remove existing image tags 
SYNOPSIS
    

`gcloud beta container images untag` `IMAGE_NAME` [`IMAGE_NAME` …] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The container images untag command removes the specified tag from the image. 
EXAMPLES
     Removes the tag from the input IMAGE_NAME: 
    
    
    gcloud beta container images untag <IMAGE_NAME>

POSITIONAL ARGUMENTS
    

`IMAGE_NAME` [`IMAGE_NAME` …]
     The fully qualified name(s) of image(s) to untag. The name(s) should be formatted as *.gcr.io/PROJECT_ID/IMAGE_PATH:TAG.
