NAME
    

gcloud beta container hub policycontroller content - manage Policy Controller content 
SYNOPSIS
    

`gcloud beta container hub policycontroller content` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Policy Controller content. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[bundles](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/policycontroller/content/bundles)`
     `(BETA)` Manage Policy Controller content bundles. 
`[templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/policycontroller/content/templates)`
     `(BETA)` Manage Policy Controller content templates. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container hub policycontroller content](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/policycontroller/content)
