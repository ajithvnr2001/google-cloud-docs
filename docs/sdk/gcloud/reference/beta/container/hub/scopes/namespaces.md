NAME
    

gcloud beta container hub scopes namespaces - fleet namespaces are the fleet equivalent of k8s cluster namespaces 
SYNOPSIS
    

`gcloud beta container hub scopes namespaces` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This command group allows for manipulation of fleet namespaces. 
EXAMPLES
     Manage fleet namespaces: 
    
    
    gcloud beta container hub scopes namespaces --help

Manage RBAC RoleBindings in a fleet namespace: 
    
    
    gcloud beta container hub scopes namespaces rbacrolebindings --help

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/namespaces/create)`
     `(BETA)` Create a fleet namespace. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/namespaces/delete)`
     `(BETA)` Delete a fleet namespace. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/namespaces/describe)`
     `(BETA)` Show fleet namespace info. 
`[get-credentials](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/namespaces/get-credentials)`
     `(BETA)` Fetch credentials for a membership with a particular namespace. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/namespaces/list)`
     `(BETA)` List fleet namespaces in a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/namespaces/update)`
     `(BETA)` Update a fleet namespace. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container hub scopes namespaces](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/scopes/namespaces)
    
    
    [gcloud alpha container hub scopes namespaces](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/scopes/namespaces)
