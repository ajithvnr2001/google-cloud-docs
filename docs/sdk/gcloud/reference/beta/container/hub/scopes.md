NAME
    

gcloud beta container hub scopes - manage scopes of all your GKE fleets 
SYNOPSIS
    

`gcloud beta container hub scopes` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage scopes of all your GKE fleets. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[namespaces](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/namespaces)`
     `(BETA)` Fleet namespaces are the fleet equivalent of k8s cluster namespaces. 
`[rbacrolebindings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/rbacrolebindings)`
     `(BETA)` Fleet scope RBAC RoleBindings for permissions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-app-operator-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/add-app-operator-binding)`
     `(BETA)` Add project-level and fleet scope-level IAM bindings and create a fleet scope RBAC role binding for an app operator principal. 
`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a Fleet Scope. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/create)`
     `(BETA)` Create a new fleet scope. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/delete)`
     `(BETA)` Delete a fleet scope. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/describe)`
     `(BETA)` Describe a fleet scope. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Fleet Scope. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/list)`
     `(BETA)` List fleet scopes in a project permitted to be viewed by the caller. 
`[list-app-operator-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/list-app-operator-bindings)`
     `(BETA)` List app operator principals corresponding to a fleet scope and their roles based on project-level IAM bindings, fleet scope-level IAM bindings, and fleet scope RBAC role bindings. 
`[list-memberships](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/list-memberships)`
     `(BETA)` List memberships bound to a fleet scope. 
`[remove-app-operator-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/remove-app-operator-binding)`
     `(BETA)` Remove project-level and fleet scope-level IAM bindings and delete a fleet scope RBAC role binding for an app operator principal. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding of a Fleet Scope. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/scopes/update)`
     `(BETA)` Update a scope. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container hub scopes](https://docs.cloud.google.com/sdk/gcloud/reference/container/hub/scopes)
    
    
    [gcloud alpha container hub scopes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/scopes)
