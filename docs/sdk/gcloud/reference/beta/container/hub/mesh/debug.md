NAME
    

gcloud beta container hub mesh debug - debug Service Mesh memberships 
SYNOPSIS
    

`gcloud beta container hub mesh debug` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Debug Service Mesh memberships. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[bug-report](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/mesh/debug/bug-report)`
     `(BETA)` Capture cluster information and logs into archive to help diagnose problems. 
`[proxy-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/mesh/debug/proxy-config)`
     `(BETA)` Retrieve a configuration summary for a given Envoy instance. 
`[proxy-status](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/hub/mesh/debug/proxy-status)`
     `(BETA)` Retrieve the envoy configuration sync status. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha container hub mesh debug](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/hub/mesh/debug)
