NAME
    

gcloud beta container bare-metal admin-clusters - create and manage admin clusters in Anthos on bare metal 
SYNOPSIS
    

`gcloud beta container bare-metal admin-clusters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage admin clusters in Anthos on bare metal. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters/create)`
     `(BETA)` Create an Anthos on bare metal admin cluster. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters/describe)`
     `(BETA)` Describe an Anthos on bare metal admin cluster. 
`[enroll](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters/enroll)`
     `(BETA)` Enroll an Anthos on bare metal admin cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters/list)`
     `(BETA)` List Anthos on bare metal admin clusters. 
`[query-version-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters/query-version-config)`
     `(BETA)` Query versions for creating or upgrading an Anthos on bare metal admin cluster. 
`[unenroll](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters/unenroll)`
     `(BETA)` Unenroll an Anthos on bare metal admin cluster so that it is no longer managed by the Anthos On-Prem API. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/container/bare-metal/admin-clusters/update)`
     `(BETA)` Update an Anthos on bare metal admin cluster. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud container bare-metal admin-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/container/bare-metal/admin-clusters)
    
    
    [gcloud alpha container bare-metal admin-clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/container/bare-metal/admin-clusters)
