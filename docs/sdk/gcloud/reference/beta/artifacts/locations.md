NAME
    

gcloud beta artifacts locations - manage Artifact Registry resource locations 
SYNOPSIS
    

`gcloud beta artifacts locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
EXAMPLES
     To list all supported locations, run: 
    
    
    [gcloud beta artifacts locations list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/locations/list)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/locations/list)`
     `(BETA)` List all Artifact Registry supported locations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud artifacts locations](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/locations)
    
    
    [gcloud alpha artifacts locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/artifacts/locations)
