NAME
    

gcloud beta artifacts vpcsc-config - manage Artifact Registry VPC Service Controls configuration for remote repositories 
SYNOPSIS
    

`gcloud beta artifacts vpcsc-config` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Artifact Registry VPC Service Controls configuration for remote repositories. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[allow](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/vpcsc-config/allow)`
     `(BETA)` Allow Artifact Registry remote repositories inside a service perimeter to retrieve data from their upstream sources outside of the perimeter. 
`[deny](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/vpcsc-config/deny)`
     `(BETA)` Deny access to upstream sources outside the service perimeter for Artifact Registry remote repositories inside the perimeter. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/vpcsc-config/describe)`
     `(BETA)` Describe the current Artifact Registry configuration for VPC Service Controls. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud artifacts vpcsc-config](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/vpcsc-config)
    
    
    [gcloud alpha artifacts vpcsc-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/artifacts/vpcsc-config)
