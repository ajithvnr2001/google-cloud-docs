NAME
    

gcloud beta artifacts yum - manage Artifact Registry RPM packages 
SYNOPSIS
    

`gcloud beta artifacts yum` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Artifact Registry RPM packages. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/yum/import)`
     `(BETA)` Import one or more RPM packages into an artifact repository. 
`[upload](https://docs.cloud.google.com/sdk/gcloud/reference/beta/artifacts/yum/upload)`
     `(BETA)` Upload an RPM package to an artifact repository. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud artifacts yum](https://docs.cloud.google.com/sdk/gcloud/reference/artifacts/yum)
    
    
    [gcloud alpha artifacts yum](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/artifacts/yum)
