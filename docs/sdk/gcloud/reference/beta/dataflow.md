NAME
    

gcloud beta dataflow - manage Google Cloud Dataflow resources 
SYNOPSIS
    

`gcloud beta dataflow` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud dataflow command group lets you manage Google Cloud Dataflow resources. 

Cloud Dataflow is a unified programming model and a managed service for developing and executing a wide range of data processing patterns including ETL, batch computation, and continuous computation. 

More information on Cloud Dataflow can be found here: <https://cloud.google.com/dataflow> and detailed documentation can be found here: <https://cloud.google.com/dataflow/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[flex-template](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/flex-template)`
     `(BETA)` A group of subcommands for working with Dataflow flex template. 
`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/jobs)`
     `(BETA)` A group of subcommands for working with Dataflow jobs. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/logs)`
     `(BETA)` A group of subcommands for working with Dataflow logs. 
`[metrics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/metrics)`
     `(BETA)` A group of subcommands for working with Dataflow metrics. 
`[snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/snapshots)`
     `(BETA)` A group of subcommands for working with Cloud Dataflow snapshots. 
`[yaml](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataflow/yaml)`
     `(BETA)` A group of subcommands for launching Beam YAML jobs on Dataflow. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud dataflow](https://docs.cloud.google.com/sdk/gcloud/reference/dataflow)
    
    
    [gcloud alpha dataflow](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dataflow)
