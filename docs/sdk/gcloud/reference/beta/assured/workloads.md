NAME
    

gcloud beta assured workloads - read and manipulate Assured Workloads resources 
SYNOPSIS
    

`gcloud beta assured workloads` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create, read, update, list and delete Assured Workloads resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[violations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/assured/workloads/violations)`
     `(BETA)` Read and list Assured Workloads Violations. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/assured/workloads/create)`
     `(BETA)` Create a new Assured Workloads environment. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/assured/workloads/delete)`
     `(BETA)` Delete Assured Workloads environment. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/assured/workloads/describe)`
     `(BETA)` Describe Assured Workloads environment. 
`[enable-resource-monitoring](https://docs.cloud.google.com/sdk/gcloud/reference/beta/assured/workloads/enable-resource-monitoring)`
     `(BETA)` Enables Resource Monitoring for an Assured Workloads environment. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/assured/workloads/list)`
     `(BETA)` List all Assured Workloads environments that belong to a given parent organization. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/assured/workloads/update)`
     `(BETA)` Update Assured Workloads environments. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud assured workloads](https://docs.cloud.google.com/sdk/gcloud/reference/assured/workloads)
    
    
    [gcloud alpha assured workloads](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/assured/workloads)
