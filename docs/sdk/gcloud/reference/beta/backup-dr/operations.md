NAME
    

gcloud beta backup-dr operations - manage Backup and DR operations 
SYNOPSIS
    

`gcloud beta backup-dr operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Backup and DR operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/operations/describe)`
     `(BETA)` Describe an operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/operations/list)`
     `(BETA)` List all operations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud backup-dr operations](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/operations)
    
    
    [gcloud alpha backup-dr operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/operations)
