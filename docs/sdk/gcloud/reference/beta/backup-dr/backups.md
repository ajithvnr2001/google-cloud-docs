NAME
    

gcloud beta backup-dr backups - manage Backup and DR backups 
SYNOPSIS
    

`gcloud beta backup-dr backups` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Backup and DR backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backups/restore)`
     `(BETA)` Manage restore operations for resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backups/delete)`
     `(BETA)` Delete the specified Backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backups/describe)`
     `(BETA)` Show details of the backup. 
`[fetch-for-resource-type](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backups/fetch-for-resource-type)`
     `(BETA)` Fetch Backups for a given resource type and location. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backups/list)`
     `(BETA)` List Backups. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backups/update)`
     `(BETA)` Update the specified Backup. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud backup-dr backups](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/backups)
    
    
    [gcloud alpha backup-dr backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/backups)
