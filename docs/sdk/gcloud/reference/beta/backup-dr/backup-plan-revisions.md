NAME
    

gcloud beta backup-dr backup-plan-revisions - view Backup and DR backup plan revisions 
SYNOPSIS
    

`gcloud beta backup-dr backup-plan-revisions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` View Backup and DR backup plan revisions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backup-plan-revisions/describe)`
     `(BETA)` Show details of the backup plan revision. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/backup-dr/backup-plan-revisions/list)`
     `(BETA)` List backup plan revisions. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud backup-dr backup-plan-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/backup-dr/backup-plan-revisions)
    
    
    [gcloud alpha backup-dr backup-plan-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/backup-dr/backup-plan-revisions)
