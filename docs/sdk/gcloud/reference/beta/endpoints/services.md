NAME
    

gcloud beta endpoints services - manage Services 
SYNOPSIS
    

`gcloud beta endpoints services` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Services. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a service. 
`[check-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/check-iam-policy)`
     `(BETA)` Returns information about a principal's permissions on a service. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/delete)`
     `(BETA)` Deletes a service from Google Service Management. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/deploy)`
     `(BETA)` Deploys a service configuration for the given service name. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/describe)`
     `(BETA)` Describes a service given a service name. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/get-iam-policy)`
     `(BETA)` Describes the IAM policy for a service. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/list)`
     `(BETA)` List services for a project. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding from a service. 
`[undelete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/endpoints/services/undelete)`
     `(BETA)` Undeletes a service configuration that was previously deleted. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud endpoints services](https://docs.cloud.google.com/sdk/gcloud/reference/endpoints/services)
    
    
    [gcloud alpha endpoints services](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/endpoints/services)
