#  gcloud beta memorystore backup-collections backups Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta memorystore backup-collections backups - manage Backup resources 
SYNOPSIS
    

`gcloud beta memorystore backup-collections backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Backup resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/backup-collections/backups/delete)`
     `(BETA)` Delete backups. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/backup-collections/backups/describe)`
     `(BETA)` Describe backups. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/backup-collections/backups/export)`
     `(BETA)` export backups. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/backup-collections/backups/list)`
     `(BETA)` List backups. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud memorystore backup-collections backups](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/backup-collections/backups)
    
    
    [gcloud alpha memorystore backup-collections backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/backup-collections/backups)
