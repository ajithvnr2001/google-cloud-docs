NAME
    

gcloud beta memorystore instances - manage Instance resources 
SYNOPSIS
    

`gcloud beta memorystore instances` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Instance resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[token-auth-users](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/token-auth-users)`
     `(BETA)` Manage Token Auth User resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[backup](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/backup)`
     `(BETA)` backup instances. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/create)`
     `(BETA)` Create a Memorystore instance. 
`[create-token-auth-user](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/create-token-auth-user)`
     `(BETA)` create token auth user for a Memorystore instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/delete)`
     `(BETA)` Delete a Memorystore instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/describe)`
     `(BETA)` Get details of a Memorystore instance. 
`[finish-migration](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/finish-migration)`
     `(BETA)` Finish migration for a Memorystore instance. 
`[get-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/get-certificate-authority)`
     `(BETA)` Get certificate authority details of a Memorystore instance. 
`[get-shared-regional-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/get-shared-regional-certificate-authority)`
     `(BETA)` Get the shared regional CA certificate bundle for Memorystore. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/list)`
     `(BETA)` List all Memorystore instances in a specified project and location. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/reschedule-maintenance)`
     `(BETA)` Reschedule maintenance window for an instance. 
`[start-migration](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/start-migration)`
     `(BETA)` Start migration for a Memorystore instance. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances/update)`
     `(BETA)` Update the configuration of a Memorystore instance. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud memorystore instances](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/instances)
    
    
    [gcloud alpha memorystore instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/instances)
