NAME
    

gcloud beta memorystore locations - manage Memorystore for Valkey locations 
SYNOPSIS
    

`gcloud beta memorystore locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Memorystore for Valkey locations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/locations/describe)`
     `(BETA)` Show metadata for a Memorystore for Valkey location. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/locations/list)`
     `(BETA)` List Memorystore for Valkey locations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud memorystore locations](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore/locations)
    
    
    [gcloud alpha memorystore locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore/locations)
