NAME
    

gcloud beta dns policies - manage your Cloud DNS policies 
SYNOPSIS
    

`gcloud beta dns policies` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage your Cloud DNS policies. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/policies/create)`
     `(BETA)` Creates a new Cloud DNS policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/policies/delete)`
     `(BETA)` Deletes a Cloud DNS policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/policies/describe)`
     `(BETA)` Describes a Cloud DNS policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/policies/list)`
     `(BETA)` View the list of all your Cloud DNS policies. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/policies/update)`
     `(BETA)` Update an existing Cloud DNS policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud dns policies](https://docs.cloud.google.com/sdk/gcloud/reference/dns/policies)
    
    
    [gcloud alpha dns policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dns/policies)
