NAME
    

gcloud beta dns record-sets changes describe - view the details of a change 
SYNOPSIS
    

`gcloud beta dns record-sets changes describe` `CHANGE_ID` `--zone`=`ZONE`, `-z` `ZONE` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This command displays the details of the specified change. 
EXAMPLES
     To display the details of a change, run: 
    
    
    gcloud beta dns record-sets changes describe change_id

POSITIONAL ARGUMENTS
    

`CHANGE_ID`
     The ID of the change you want details for. 
REQUIRED FLAGS
    

`--zone`=`ZONE`, `-z` `ZONE`
     Name of the managed zone whose record sets you want to manage.
