NAME
    

gcloud beta dns record-sets changes - view details about changes to your Cloud DNS record-sets 
SYNOPSIS
    

`gcloud beta dns record-sets changes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` View details about changes to your Cloud DNS record-sets. 
EXAMPLES
     To view the details of a particular change, run: 
    
    
    [gcloud beta dns record-sets changes describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/record-sets/changes/describe) CHANGE_ID --zone=MANAGED_ZONE

To view the list of all changes, run: 
    
    
    [gcloud beta dns record-sets changes list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/record-sets/changes/list) --zone=MANAGED_ZONE

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/record-sets/changes/describe)`
     `(BETA)` View the details of a change. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/record-sets/changes/list)`
     `(BETA)` View the list of changes that have been made to your record-sets. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud dns record-sets changes](https://docs.cloud.google.com/sdk/gcloud/reference/dns/record-sets/changes)
    
    
    [gcloud alpha dns record-sets changes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dns/record-sets/changes)
