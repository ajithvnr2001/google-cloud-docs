NAME
    

gcloud beta dns outbound-endpoints - manage your Cloud DNS outbound endpoints 
SYNOPSIS
    

`gcloud beta dns outbound-endpoints` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage your Cloud DNS outbound endpoints. Outbound endpoints allow Cloud DNS to forward DNS queries from a specific IP address within your VPC subnetwork. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/outbound-endpoints/create)`
     `(BETA)` Creates a new Cloud DNS outbound endpoint. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/outbound-endpoints/delete)`
     `(BETA)` Deletes a Cloud DNS outbound endpoint. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/outbound-endpoints/describe)`
     `(BETA)` Describes a Cloud DNS outbound endpoint. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/outbound-endpoints/list)`
     `(BETA)` Lists Cloud DNS outbound endpoints in a region. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dns/outbound-endpoints/update)`
     `(BETA)` Updates an existing Cloud DNS outbound endpoint. 
REGIONAL ENDPOINTS
     This command group supports regional endpoints. To use regional endpoints for this command, use the `--endpoint-mode=regional-preferred` flag. To use regional endpoints by default, run `$ [gcloud config set](https://docs.cloud.google.com/sdk/gcloud/reference/config/set) regional/endpoint_mode regional-preferred`. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha dns outbound-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/dns/outbound-endpoints)
