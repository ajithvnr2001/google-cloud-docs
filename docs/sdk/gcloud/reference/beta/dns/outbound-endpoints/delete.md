NAME
    

gcloud beta dns outbound-endpoints delete - deletes a Cloud DNS outbound endpoint 
SYNOPSIS
    

`gcloud beta dns outbound-endpoints delete` (`OUTBOUND_ENDPOINT` : `--location`=`LOCATION`) [`--async`] [`--endpoint-mode`=`ENDPOINT_MODE`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This command deletes a Cloud DNS outbound endpoint in a specified region. 
EXAMPLES
     To delete an outbound endpoint `my-endpoint` in `us-east1`, run: 
    
    
    gcloud beta dns outbound-endpoints delete my-endpoint --location=us-east1

POSITIONAL ARGUMENTS
    

Outbound endpoint resource - The outbound endpoint to delete. The arguments in this group can be used to specify the attributes of this resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `outbound_endpoint` on the command line with a fully specified name; 
  * set the property `core/project`. 



This must be specified. 

`OUTBOUND_ENDPOINT`
     ID of the outbound_endpoint or fully qualified identifier for the outbound_endpoint. 

To set the `outbound-endpoint` attribute: 

  * provide the argument `outbound_endpoint` on the command line. 



This positional argument must be specified if any of the other arguments in this group are specified. 

`--location`=`LOCATION`
     The Cloud location for the outbound_endpoint. 

To set the `location` attribute: 

  * provide the argument `outbound_endpoint` on the command line with a fully specified name; 
  * provide the argument `--location` on the command line. 


FLAGS
    

`--async`
     Return immediately, without waiting for the operation in progress to complete. 
`--endpoint-mode`=`ENDPOINT_MODE`
     Specifies endpoint mode for a given command. Regional endpoints provide enhanced data residency and reliability by ensuring your request is handled entirely within the specified Google Cloud region. This differs from global endpoints, which may process parts of the request outside the target region. Overrides the default `regional/endpoint_mode` property value for this command invocation. `ENDPOINT_MODE` must be one of: 

`global`
     (Default) Use global rather than regional endpoints. 
`regional`
     Only use regional endpoints. An error will be raised if a regional endpoint is not available for a given command. 
`regional-preferred`
     Use regional endpoints when available, otherwise use global endpoints. Recommended for most users.
