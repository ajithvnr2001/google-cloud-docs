NAME
    

gcloud beta secrets versions - manage secret versions 
SYNOPSIS
    

`gcloud beta secrets versions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage secret versions on Google Cloud. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[access](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions/access)`
     `(BETA)` Access a secret version's data. 
`[add](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions/add)`
     `(BETA)` Create a new version of an existing secret. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions/describe)`
     `(BETA)` Describe metadata about the secret version. 
`[destroy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions/destroy)`
     `(BETA)` Destroy a secret version's metadata and secret data. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions/disable)`
     `(BETA)` Disable the version of the provided secret. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions/enable)`
     `(BETA)` Enable the version of the provided secret. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions/list)`
     `(BETA)` List all versions for a secret. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud secrets versions](https://docs.cloud.google.com/sdk/gcloud/reference/secrets/versions)
    
    
    [gcloud alpha secrets versions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/secrets/versions)
