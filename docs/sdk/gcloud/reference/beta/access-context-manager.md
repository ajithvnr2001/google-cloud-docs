NAME
    

gcloud beta access-context-manager - manage Access Context Manager resources 
SYNOPSIS
    

`gcloud beta access-context-manager` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Policy API for configuring context aware access features and access zones. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[levels](https://docs.cloud.google.com/sdk/gcloud/reference/beta/access-context-manager/levels)`
     `(BETA)` Manage Access Context Manager levels. 
`[perimeters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/access-context-manager/perimeters)`
     `(BETA)` Manage Access Context Manager service perimeters. 
`[policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/access-context-manager/policies)`
     `(BETA)` Manage Access Context Manager policies. 
`[supported-permissions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/access-context-manager/supported-permissions)`
     `(BETA)` Retrieve VPC Service Controls Supported Permissions. 
`[supported-services](https://docs.cloud.google.com/sdk/gcloud/reference/beta/access-context-manager/supported-services)`
     `(BETA)` Retrieve VPC Service Controls Supported Services. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[lookup-configured-perimeter](https://docs.cloud.google.com/sdk/gcloud/reference/beta/access-context-manager/lookup-configured-perimeter)`
     `(BETA)` Look up the configured VPC Service Controls service perimeter for a resource. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud access-context-manager](https://docs.cloud.google.com/sdk/gcloud/reference/access-context-manager)
    
    
    [gcloud alpha access-context-manager](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/access-context-manager)
