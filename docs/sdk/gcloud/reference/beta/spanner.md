NAME
    

gcloud beta spanner - command groups for Cloud Spanner 
SYNOPSIS
    

`gcloud beta spanner` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Command groups for Cloud Spanner. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backup-schedules](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backup-schedules)`
     `(BETA)` Manage Cloud Spanner backup schedules. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/backups)`
     `(BETA)` Manage Cloud Spanner backups. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/databases)`
     `(BETA)` Manage Cloud Spanner databases. 
`[instance-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instance-configs)`
     `(BETA)` Manage Cloud Spanner instance configs. 
`[instance-partitions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instance-partitions)`
     `(BETA)` Manage Spanner instance partitions. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/instances)`
     `(BETA)` Manage Cloud Spanner instances. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/operations)`
     `(BETA)` Manage Cloud Spanner operations. 
`[rows](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/rows)`
     `(BETA)` Manage the rows in Cloud Spanner databases. 
`[samples](https://docs.cloud.google.com/sdk/gcloud/reference/beta/spanner/samples)`
     `(BETA)` Cloud Spanner sample apps. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud spanner](https://docs.cloud.google.com/sdk/gcloud/reference/spanner)
    
    
    [gcloud alpha spanner](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/spanner)
