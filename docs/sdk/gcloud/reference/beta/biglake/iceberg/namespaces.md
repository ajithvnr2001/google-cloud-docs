NAME
    

gcloud beta biglake iceberg namespaces - manage BigLake Iceberg REST catalog namespaces 
SYNOPSIS
    

`gcloud beta biglake iceberg namespaces` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage BigLake Iceberg REST catalog namespaces. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/namespaces/create)`
     `(BETA)` Create a BigLake Iceberg REST namespace. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/namespaces/delete)`
     `(BETA)` Delete a BigLake Iceberg REST namespace. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/namespaces/describe)`
     `(BETA)` Describe a BigLake Iceberg REST namespace. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/namespaces/get-iam-policy)`
     `(BETA)` Get the IAM policy for a BigLake Iceberg REST catalog namespace. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/namespaces/list)`
     `(BETA)` List BigLake Iceberg REST namespaces. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/namespaces/set-iam-policy)`
     `(BETA)` Set the IAM policy for a BigLake Iceberg REST catalog namespace. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/namespaces/update)`
     `(BETA)` Update a BigLake Iceberg REST namespace. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud biglake iceberg namespaces](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/namespaces)
    
    
    [gcloud alpha biglake iceberg namespaces](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/biglake/iceberg/namespaces)
