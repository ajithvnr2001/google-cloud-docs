NAME
    

gcloud beta biglake iceberg tables - manage BigLake Iceberg REST catalog tables 
SYNOPSIS
    

`gcloud beta biglake iceberg tables` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage BigLake Iceberg REST catalog tables. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/create)`
     `(BETA)` Create a BigLake Iceberg table. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/delete)`
     `(BETA)` Delete a BigLake Iceberg table. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/describe)`
     `(BETA)` Describe a BigLake Iceberg table. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/get-iam-policy)`
     `(BETA)` Get the IAM policy for a BigLake Iceberg REST catalog table. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/list)`
     `(BETA)` List BigLake Iceberg REST tables. 
`[register](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/register)`
     `(BETA)` Register a BigLake Iceberg table. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/set-iam-policy)`
     `(BETA)` Set the IAM policy for a BigLake Iceberg REST catalog table. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/biglake/iceberg/tables/update)`
     `(BETA)` Update a BigLake Iceberg table. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud biglake iceberg tables](https://docs.cloud.google.com/sdk/gcloud/reference/biglake/iceberg/tables)
