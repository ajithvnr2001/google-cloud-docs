NAME
    

gcloud beta sql - create and manage Google Cloud SQL databases 
SYNOPSIS
    

`gcloud beta sql` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud sql command group lets you create and manage Google Cloud SQL databases. 

Cloud SQL is a fully-managed database service that makes it easy to set up, maintain, manage, and administer your relational databases in the cloud. 

More information on Cloud SQL can be found here: <https://cloud.google.com/sql> and detailed documentation can be found here: <https://cloud.google.com/sql/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/backups)`
     `(BETA)` Provide commands for working with backups of Cloud SQL instances. 
`[blue-green-deployments](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/blue-green-deployments)`
     `(BETA)` Provide commands for managing Cloud SQL blue-green deployments. 
`[databases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/databases)`
     `(BETA)` Provide commands for managing databases of Cloud SQL instances. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/export)`
     `(BETA)` Provide commands to export Cloud SQL instances. 
`[flags](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/flags)`
     `(BETA)` Provide a command to list flags. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/import)`
     `(BETA)` Provides commands to import Cloud SQL instances. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances)`
     `(BETA)` Provide commands for managing Cloud SQL instances. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/operations)`
     `(BETA)` Provide commands for working with Cloud SQL instance operations. 
`[ssl](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/ssl)`
     `(BETA)` Provide commands for managing SSL certificates of Cloud SQL instances. 
`[ssl-certs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/ssl-certs)`
     `(BETA)` `(DEPRECATED)` Provide commands for managing SSL certificates of Cloud SQL instances. 
`[tiers](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/tiers)`
     `(BETA)` Provide a command to list tiers. 
`[users](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/users)`
     `(BETA)` Provide commands for managing Cloud SQL users. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[connect](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/connect)`
     `(BETA)` Connects to a Cloud SQL instance. 
`[generate-login-token](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/generate-login-token)`
     `(BETA)` Generate an IAM login token for Cloud SQL. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/reschedule-maintenance)`
     `(BETA)` Reschedule a Cloud SQL instance's maintenance. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud sql](https://docs.cloud.google.com/sdk/gcloud/reference/sql)
    
    
    [gcloud alpha sql](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql)
