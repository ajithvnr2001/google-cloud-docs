NAME
    

gcloud beta redis clusters backups - manage backups of Memorystore for Redis Cluster instances 
SYNOPSIS
    

`gcloud beta redis clusters backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage backups of Memorystore for Redis Cluster instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/backups/delete)`
     `(BETA)` Delete a Memorystore for Redis Cluster backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/backups/describe)`
     `(BETA)` Show metadata for a Memorystore for Redis Cluster backup. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/backups/export)`
     `(BETA)` Export a Redis cluster backup to a Google Cloud Storage bucket. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/backups/list)`
     `(BETA)` List backups under a backup collection in a region. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud redis clusters backups](https://docs.cloud.google.com/sdk/gcloud/reference/redis/clusters/backups)
    
    
    [gcloud alpha redis clusters backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters/backups)
