NAME
    

gcloud beta redis clusters - manage Memorystore for Redis Cluster instances 
SYNOPSIS
    

`gcloud beta redis clusters` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Memorystore for Redis Cluster instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[backup-collections](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/backup-collections)`
     `(BETA)` Manage backup collections of Memorystore for Redis Cluster instances. 
`[backups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/backups)`
     `(BETA)` Manage backups of Memorystore for Redis Cluster instances. 
`[token-auth-users](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/token-auth-users)`
     `(BETA)` Manage token auth users of Memorystore for Redis Cluster instances. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-cluster-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/add-cluster-endpoints)`
     `(BETA)` Add more cluster endpoints. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/create)`
     `(BETA)` Create a new Memorystore for Redis Cluster instance. 
`[create-backup](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/create-backup)`
     `(BETA)` Create a backup of a Redis cluster. 
`[create-token-auth-user](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/create-token-auth-user)`
     `(BETA)` Create a token auth user for a Redis cluster. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/delete)`
     `(BETA)` Delete a Memorystore for Redis Cluster instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/describe)`
     `(BETA)` Show metadata for a Memorystore for Redis Cluster instance. 
`[detach](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/detach)`
     `(BETA)` Detach a secondary cluster. 
`[detach-secondaries](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/detach-secondaries)`
     `(BETA)` Detach one or more secondary clusters from the primary cluster. 
`[get-cluster-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/get-cluster-certificate-authority)`
     `(BETA)` Get the certificate authority information for a Memorystore for Redis Cluster instance. 
`[get-shared-regional-certificate-authority](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/get-shared-regional-certificate-authority)`
     `(BETA)` Get the shared regional certificate authority certificates for Memorystore for Redis Cluster. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/list)`
     `(BETA)` List Memorystore for Redis Cluster instances. 
`[remove-cluster-endpoints](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/remove-cluster-endpoints)`
     `(BETA)` Remove existing Memorystore cluster endpoints. 
`[reschedule-maintenance](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/reschedule-maintenance)`
     `(BETA)` Reschedule maintenance window for a Memorystore for Redis Cluster instance. 
`[switchover](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/switchover)`
     `(BETA)` Switchover to a secondary cluster. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/redis/clusters/update)`
     `(BETA)` Update Memorystore Cluster for Redis instance. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud redis clusters](https://docs.cloud.google.com/sdk/gcloud/reference/redis/clusters)
    
    
    [gcloud alpha redis clusters](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/redis/clusters)
