NAME
    

gcloud beta run jobs executions tasks - view and manage your Cloud Run jobs tasks 
SYNOPSIS
    

`gcloud beta run jobs executions tasks` `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This set of commands can be used to view and manage your Cloud Run jobs tasks. 
EXAMPLES
     To list your existing tasks for an execution, run: 
    
    
    [gcloud beta run jobs executions tasks list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/tasks/list) --execution my_execution

FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/tasks/describe)`
     `(BETA)` Obtain details about tasks. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/tasks/list)`
     `(BETA)` List tasks. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud run jobs executions tasks](https://docs.cloud.google.com/sdk/gcloud/reference/run/jobs/executions/tasks)
    
    
    [gcloud alpha run jobs executions tasks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/executions/tasks)
