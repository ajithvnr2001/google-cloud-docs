NAME
    

gcloud beta run jobs executions logs - read logs for Cloud Run jobs executions 
SYNOPSIS
    

`gcloud beta run jobs executions logs` `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read logs for Cloud Run jobs executions. 
EXAMPLES
     To tail logs for a job execution, run: 
    
    
    [gcloud beta run jobs executions logs tail](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/logs/tail) my-job-execution

To read logs for a job execution, run: 
    
    
    [gcloud beta run jobs executions logs read](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/logs/read) my-job-execution

FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[read](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/logs/read)`
     `(BETA)` Read logs for Cloud Run job executions. 
`[tail](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/logs/tail)`
     `(BETA)` Tail logs for Cloud Run job executions. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha run jobs executions logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/executions/logs)
