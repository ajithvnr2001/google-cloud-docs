NAME
    

gcloud beta run jobs executions - view and manage your Cloud Run jobs executions 
SYNOPSIS
    

`gcloud beta run jobs executions` `GROUP` | `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This set of commands can be used to view and manage your Cloud Run jobs executions. 
EXAMPLES
     To list your executions for a job, run: 
    
    
    [gcloud beta run jobs executions list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/list) --job=my-job

FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/logs)`
     `(BETA)` Read logs for Cloud Run jobs executions. 
`[tasks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/tasks)`
     `(BETA)` View and manage your Cloud Run jobs tasks. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/cancel)`
     `(BETA)` Cancel an execution. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/delete)`
     `(BETA)` Delete an execution. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/describe)`
     `(BETA)` Obtain details about executions. 
`[describe-latest](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/describe-latest)`
     `(BETA)` Obtain details about the latest execution of a job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions/list)`
     `(BETA)` List executions. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud run jobs executions](https://docs.cloud.google.com/sdk/gcloud/reference/run/jobs/executions)
    
    
    [gcloud alpha run jobs executions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs/executions)
