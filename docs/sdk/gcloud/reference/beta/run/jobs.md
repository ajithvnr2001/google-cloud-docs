NAME
    

gcloud beta run jobs - view and manage your Cloud Run jobs 
SYNOPSIS
    

`gcloud beta run jobs` `GROUP` | `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This set of commands can be used to view and manage your Cloud Run jobs. 
EXAMPLES
     To list your existing jobs, run: 
    
    
    [gcloud beta run jobs list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/list)

FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[executions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/executions)`
     `(BETA)` View and manage your Cloud Run jobs executions. 
`[logs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/logs)`
     `(BETA)` Read logs for Cloud Run jobs. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a Cloud Run job. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/create)`
     `(BETA)` Create a Cloud Run job. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/delete)`
     `(BETA)` Delete a job. 
`[deploy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/deploy)`
     `(BETA)` Create or update a Cloud Run job. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/describe)`
     `(BETA)` Obtain details about jobs. 
`[execute](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/execute)`
     `(BETA)` Execute a job. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Cloud Run job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/list)`
     `(BETA)` List jobs. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding of a Cloud Run job. 
`[replace](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/replace)`
     `(BETA)` Create or replace a job from a YAML job specification. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/set-iam-policy)`
     `(BETA)` Set the IAM policy for a job. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/jobs/update)`
     `(BETA)` Update a Cloud Run Job. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud run jobs](https://docs.cloud.google.com/sdk/gcloud/reference/run/jobs)
    
    
    [gcloud alpha run jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/jobs)
