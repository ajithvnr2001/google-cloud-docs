NAME
    

gcloud beta run services logs - read logs for Cloud Run services 
SYNOPSIS
    

`gcloud beta run services logs` `COMMAND` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Read logs for Cloud Run services. 
FLAGS
    

`--region`=`REGION`
     Region in which the resource can be found. Alternatively, set the property [run/region]. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[read](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/services/logs/read)`
     `(BETA)` Read logs for a Cloud Run service. 
`[tail](https://docs.cloud.google.com/sdk/gcloud/reference/beta/run/services/logs/tail)`
     `(BETA)` Tail logs for a Cloud Run service. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud run services logs](https://docs.cloud.google.com/sdk/gcloud/reference/run/services/logs)
    
    
    [gcloud alpha run services logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/run/services/logs)
