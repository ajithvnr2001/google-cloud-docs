NAME
    

gcloud beta api-gateway apis - manage Cloud API Gateway APIs 
SYNOPSIS
    

`gcloud beta api-gateway apis` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud API Gateway APIs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a gateway. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/create)`
     `(BETA)` Create a new API. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/delete)`
     `(BETA)` Deletes an API. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/describe)`
     `(BETA)` Show details about a specific API. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/get-iam-policy)`
     `(BETA)` Get the IAM policy for an API. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/list)`
     `(BETA)` List APIs. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding to a gateway. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/api-gateway/apis/update)`
     `(BETA)` Update an API Gateway API. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud api-gateway apis](https://docs.cloud.google.com/sdk/gcloud/reference/api-gateway/apis)
    
    
    [gcloud alpha api-gateway apis](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/api-gateway/apis)
