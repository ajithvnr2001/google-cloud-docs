NAME
    

gcloud beta anthos auth - authenticate clusters using the Anthos client 
SYNOPSIS
    

`gcloud beta anthos auth` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Authenticate clusters using the Anthos client. 

For more details on Anthos, see <https://cloud.google.com/anthos/>. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[login](https://docs.cloud.google.com/sdk/gcloud/reference/beta/anthos/auth/login)`
     `(BETA)` Authenticate clusters using the Anthos client. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud anthos auth](https://docs.cloud.google.com/sdk/gcloud/reference/anthos/auth)
    
    
    [gcloud alpha anthos auth](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/anthos/auth)
