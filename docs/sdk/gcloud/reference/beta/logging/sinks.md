NAME
    

gcloud beta logging sinks - manages sinks used to route logs to storage or export destinations 
SYNOPSIS
    

`gcloud beta logging sinks` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manages sinks used to route logs to storage or export destinations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/sinks/create)`
     `(BETA)` Create a log sink. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/sinks/delete)`
     `(BETA)` Delete a sink. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/sinks/describe)`
     `(BETA)` Display information about a sink. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/sinks/list)`
     `(BETA)` List the defined sinks. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/sinks/update)`
     `(BETA)` Update a sink. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud logging sinks](https://docs.cloud.google.com/sdk/gcloud/reference/logging/sinks)
    
    
    [gcloud alpha logging sinks](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/sinks)
