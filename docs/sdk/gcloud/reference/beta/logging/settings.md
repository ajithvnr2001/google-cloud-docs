#  gcloud beta logging settings Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta logging settings - manages the org settings for the Cloud Logging Logs Router 
SYNOPSIS
    

`gcloud beta logging settings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manages the org settings for the Cloud Logging Logs Router. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/settings/describe)`
     `(BETA)` Display the settings for the Cloud Logging Logs Router. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/settings/update)`
     `(BETA)` Update the settings for the Cloud Logging Logs Router. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud logging settings](https://docs.cloud.google.com/sdk/gcloud/reference/logging/settings)
    
    
    [gcloud alpha logging settings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/settings)
