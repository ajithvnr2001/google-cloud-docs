NAME
    

gcloud beta logging metrics - manages logs-based metrics 
SYNOPSIS
    

`gcloud beta logging metrics` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manages logs-based metrics. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/metrics/create)`
     `(BETA)` Create a logs-based metric. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/metrics/delete)`
     `(BETA)` Delete a logs-based metric. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/metrics/describe)`
     `(BETA)` Display the definition of a logs-based metric. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/metrics/list)`
     `(BETA)` Display all logs-based metrics. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/metrics/update)`
     `(BETA)` Update the definition of a logs-based metric. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud logging metrics](https://docs.cloud.google.com/sdk/gcloud/reference/logging/metrics)
    
    
    [gcloud alpha logging metrics](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/metrics)
