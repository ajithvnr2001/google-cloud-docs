NAME
    

gcloud beta logging logs - manages your project's logs 
SYNOPSIS
    

`gcloud beta logging logs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manages your project's logs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/logs/delete)`
     `(BETA)` Delete all entries from a log in the global `_Default` log bucket. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/logs/list)`
     `(BETA)` List your project's logs. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud logging logs](https://docs.cloud.google.com/sdk/gcloud/reference/logging/logs)
    
    
    [gcloud alpha logging logs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/logs)
