NAME
    

gcloud beta logging links - manage linked datasets 
SYNOPSIS
    

`gcloud beta logging links` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing linked datasets. A linked BigQuery dataset contains log data for the linked dataset's parent log bucket. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/links/create)`
     `(BETA)` Create a linked dataset on an analytics log bucket. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/links/delete)`
     `(BETA)` Delete a linked dataset. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/links/describe)`
     `(BETA)` Display information about a linked dataset. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/logging/links/list)`
     `(BETA)` List created linked datasets on the specified bucket. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud logging links](https://docs.cloud.google.com/sdk/gcloud/reference/logging/links)
    
    
    [gcloud alpha logging links](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/logging/links)
