NAME
    

gcloud beta network-services - manage Network Services resources 
SYNOPSIS
    

`gcloud beta network-services` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Services resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[agent-connectivity-templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-services/agent-connectivity-templates)`
     `(BETA)` Manage Network Services Agent Connectivity Templates.
