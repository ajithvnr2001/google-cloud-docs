NAME
    

gcloud beta sql databases - provide commands for managing databases of Cloud SQL instances 
SYNOPSIS
    

`gcloud beta sql databases` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Provide commands for managing databases of Cloud SQL instances, including creating, deleting, listing, patching, updating, and getting information about databases. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/databases/create)`
     `(BETA)` Creates a database for a Cloud SQL instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/databases/delete)`
     `(BETA)` Deletes a Cloud SQL database. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/databases/describe)`
     `(BETA)` Displays configuration and metadata about a Cloud SQL database. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/databases/list)`
     `(BETA)` Lists databases for a Cloud SQL instance. 
`[patch](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/databases/patch)`
     `(BETA)` Patches the settings of a Cloud SQL database. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud sql databases](https://docs.cloud.google.com/sdk/gcloud/reference/sql/databases)
    
    
    [gcloud alpha sql databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/databases)
