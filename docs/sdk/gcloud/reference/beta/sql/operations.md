NAME
    

gcloud beta sql operations - provide commands for working with Cloud SQL instance operations 
SYNOPSIS
    

`gcloud beta sql operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Provide commands for working with Cloud SQL instance operations, including listing and getting information about instance operations of a Cloud SQL instance. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/operations/cancel)`
     `(BETA)` Cancels a Cloud SQL instance operation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/operations/describe)`
     `(BETA)` Retrieves information about a Cloud SQL instance operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/operations/list)`
     `(BETA)` Lists all instance operations for the given Cloud SQL instance. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/operations/wait)`
     `(BETA)` Waits for one or more operations to complete. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud sql operations](https://docs.cloud.google.com/sdk/gcloud/reference/sql/operations)
    
    
    [gcloud alpha sql operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/operations)
