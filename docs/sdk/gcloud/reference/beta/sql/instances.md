NAME
    

gcloud beta sql instances - provide commands for managing Cloud SQL instances 
SYNOPSIS
    

`gcloud beta sql instances` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Provide commands for managing Cloud SQL instances including creating, configuring, restarting, and deleting instances. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[clone](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/clone)`
     `(BETA)` Clones a Cloud SQL instance. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/create)`
     `(BETA)` Creates a new Cloud SQL instance. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/delete)`
     `(BETA)` Deletes a Cloud SQL instance. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/describe)`
     `(BETA)` Displays configuration and metadata about a Cloud SQL instance. 
`[execute-sql](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/execute-sql)`
     `(BETA)` Executes a statement on a Cloud SQL instance. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/export)`
     `(BETA)` `(DEPRECATED)` Exports data from a Cloud SQL instance. 
`[failover](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/failover)`
     `(BETA)` Causes a high-availability Cloud SQL instance to failover. 
`[get-latest-recovery-time](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/get-latest-recovery-time)`
     `(BETA)` Displays the latest recovery time to which a Cloud SQL instance can be restored to. 
`[get-storage-shrink-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/get-storage-shrink-config)`
     `(BETA)` Displays the minimum storage size to which a Cloud SQL instance can be decreased. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/import)`
     `(BETA)` `(DEPRECATED)` Imports data into a Cloud SQL instance from Google Cloud Storage. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/list)`
     `(BETA)` Lists Cloud SQL instances in a given project. 
`[patch](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/patch)`
     `(BETA)` Updates the settings of a Cloud SQL instance. 
`[perform-storage-shrink](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/perform-storage-shrink)`
     `(BETA)` Performs a storage size decrease of a Cloud SQL instance. 
`[point-in-time-restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/point-in-time-restore)`
     `(BETA)` Performs a point in time restore for a Cloud SQL instance managed by Google Cloud Backup and Disaster Recovery (DR) Service. 
`[pre-check-major-version-upgrade](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/pre-check-major-version-upgrade)`
     `(BETA)` Performs pre-checks for a major version upgrade of a Cloud SQL instance. 
`[promote-replica](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/promote-replica)`
     `(BETA)` Promotes Cloud SQL read replica to a stand-alone instance. 
`[reencrypt](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/reencrypt)`
     `(BETA)` Reencrypts a Cloud SQL CMEK instance. 
`[reset-ssl-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/reset-ssl-config)`
     `(BETA)` Reset SSL materials according to the reset SSL mode. 
`[restart](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/restart)`
     `(BETA)` Restarts a Cloud SQL instance. 
`[restore-backup](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/restore-backup)`
     `(BETA)` Restores a backup of a Cloud SQL instance. 
`[switchover](https://docs.cloud.google.com/sdk/gcloud/reference/beta/sql/instances/switchover)`
     `(BETA)` Switches over a Cloud SQL instance to one of its replicas. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud sql instances](https://docs.cloud.google.com/sdk/gcloud/reference/sql/instances)
    
    
    [gcloud alpha sql instances](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/sql/instances)
