NAME
    

gcloud beta pubsub snapshots - manage Cloud Pub/Sub snapshots 
SYNOPSIS
    

`gcloud beta pubsub snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Pub/Sub snapshots. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/snapshots/create)`
     `(BETA)` Creates one or more Cloud Pub/Sub snapshots. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/snapshots/delete)`
     `(BETA)` Deletes one or more Cloud Pub/Sub snapshots. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/snapshots/describe)`
     `(BETA)` Describes a Cloud Pub/Sub snapshot. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/snapshots/list)`
     `(BETA)` Lists all the snapshots in a given project. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud pubsub snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/snapshots)
    
    
    [gcloud alpha pubsub snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/snapshots)
