NAME
    

gcloud beta pubsub lite-reservations - manage Pub/Sub Lite reservations 
SYNOPSIS
    

`gcloud beta pubsub lite-reservations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Pub/Sub Lite reservations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-reservations/create)`
     `(BETA)` Create a Pub/Sub Lite reservation. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-reservations/delete)`
     `(BETA)` Delete a Pub/Sub Lite reservation. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-reservations/describe)`
     `(BETA)` Describe a Pub/Sub Lite reservation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-reservations/list)`
     `(BETA)` List Pub/Sub Lite reservations. 
`[list-topics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-reservations/list-topics)`
     `(BETA)` List Pub/Sub Lite topics for a given Lite reservation. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/lite-reservations/update)`
     `(BETA)` Update a Pub/Sub Lite reservation. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud pubsub lite-reservations](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/lite-reservations)
    
    
    [gcloud alpha pubsub lite-reservations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/lite-reservations)
