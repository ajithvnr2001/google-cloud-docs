NAME
    

gcloud beta pubsub schemas - manage Pub/Sub schemas 
SYNOPSIS
    

`gcloud beta pubsub schemas` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud beta pubsub schemas group lets you create and manage Pub/Sub schemas. These schemas can be attached to topics to enable validation of published messages. Commands to validate schemas and messages against schemas are also available. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[commit](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/commit)`
     `(BETA)` Commit a Pub/Sub schema revision. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/create)`
     `(BETA)` Create a Pub/Sub schema. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/delete)`
     `(BETA)` Delete a Pub/Sub schema. 
`[delete-revision](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/delete-revision)`
     `(BETA)` Delete a Pub/Sub schema revision. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/describe)`
     `(BETA)` Show details of a Pub/Sub schema. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/list)`
     `(BETA)` List Pub/Sub schemas. 
`[list-revisions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/list-revisions)`
     `(BETA)` List revisions of a Pub/Sub schema. 
`[rollback](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/rollback)`
     `(BETA)` Roll back a Pub/Sub schema to a specified revision. 
`[validate-message](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/validate-message)`
     `(BETA)` Validate a message against a Pub/Sub schema. 
`[validate-schema](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/schemas/validate-schema)`
     `(BETA)` Validate a Pub/Sub schema. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud pubsub schemas](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/schemas)
    
    
    [gcloud alpha pubsub schemas](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/schemas)
