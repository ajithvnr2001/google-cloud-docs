NAME
    

gcloud beta pubsub subscriptions - manage Cloud Pub/Sub subscriptions 
SYNOPSIS
    

`gcloud beta pubsub subscriptions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Pub/Sub subscriptions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[ack](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/ack)`
     `(BETA)` Acknowledges one or more messages on the specified subscription. 
`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a subscription. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/create)`
     `(BETA)` Creates one or more Cloud Pub/Sub subscriptions. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/delete)`
     `(BETA)` Deletes one or more Cloud Pub/Sub subscriptions. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/describe)`
     `(BETA)` Describes a Cloud Pub/Sub subscription. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Cloud Pub/Sub Subscription. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/list)`
     `(BETA)` Lists Cloud Pub/Sub subscriptions. 
`[modify-ack-deadline](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/modify-ack-deadline)`
     `(BETA)` `(DEPRECATED)` Modifies the ACK deadline for a specific Cloud Pub/Sub message. 
`[modify-message-ack-deadline](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/modify-message-ack-deadline)`
     `(BETA)` Modifies the ACK deadline for a specific Cloud Pub/Sub message. 
`[modify-push-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/modify-push-config)`
     `(BETA)` Modifies the push configuration of a Cloud Pub/Sub subscription. 
`[pull](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/pull)`
     `(BETA)` Pulls one or more Cloud Pub/Sub messages from a subscription. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding of a subscription. 
`[seek](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/seek)`
     `(BETA)` Resets a subscription's backlog to a point in time or to a given snapshot. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/set-iam-policy)`
     `(BETA)` Set IAM policy for a subscription. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/pubsub/subscriptions/update)`
     `(BETA)` Updates an existing Cloud Pub/Sub subscription. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud pubsub subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/pubsub/subscriptions)
    
    
    [gcloud alpha pubsub subscriptions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/pubsub/subscriptions)
