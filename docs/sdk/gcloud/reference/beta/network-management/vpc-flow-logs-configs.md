NAME
    

gcloud beta network-management vpc-flow-logs-configs - manage the VPC Flow Logs configurations 
SYNOPSIS
    

`gcloud beta network-management vpc-flow-logs-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The flag --location=global is required for all the commands. 

You can either specify resources for project-level configurations, or use the \--organization flag to apply organization-level configurations. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/vpc-flow-logs-configs/create)`
     `(BETA)` Creates a new VPC Flow Logs configuration. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/vpc-flow-logs-configs/delete)`
     `(BETA)` Deletes the specified VPC Flow Logs configuration. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/vpc-flow-logs-configs/describe)`
     `(BETA)` Describe the details of a specific VPC Flow Logs configuration. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/vpc-flow-logs-configs/list)`
     `(BETA)` List all VPC Flow Logs configurations. 
`[query-org-vpc-flow-logs-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/vpc-flow-logs-configs/query-org-vpc-flow-logs-configs)`
     `(BETA)` Fetch all organization-level VPC Flow Logs configurations associated with the project. 
`[show-effective-flow-logs-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/vpc-flow-logs-configs/show-effective-flow-logs-configs)`
     `(BETA)` Show all effective VPC Flow Logs configurations for a resource. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/vpc-flow-logs-configs/update)`
     `(BETA)` Updates one or more fields in an existing VPC Flow Logs configuration. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-management vpc-flow-logs-configs](https://docs.cloud.google.com/sdk/gcloud/reference/network-management/vpc-flow-logs-configs)
