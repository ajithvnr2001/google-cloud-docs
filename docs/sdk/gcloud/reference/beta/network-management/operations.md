NAME
    

gcloud beta network-management operations - manage Network Management operations 
SYNOPSIS
    

`gcloud beta network-management operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Management operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/operations/describe)`
     `(BETA)` Describe a Network Management operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/operations/list)`
     `(BETA)` List Network Management operations. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-management operations](https://docs.cloud.google.com/sdk/gcloud/reference/network-management/operations)
