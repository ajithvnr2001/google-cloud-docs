NAME
    

gcloud beta network-management connectivity-tests - manage Network Management ConnectivityTests 
SYNOPSIS
    

`gcloud beta network-management connectivity-tests` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Management ConnectivityTests. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/connectivity-tests/create)`
     `(BETA)` Create a new connectivity test. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/connectivity-tests/delete)`
     `(BETA)` Delete a connectivity test. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/connectivity-tests/describe)`
     `(BETA)` Describe a connectivity test. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/connectivity-tests/list)`
     `(BETA)` List connectivity tests. 
`[rerun](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/connectivity-tests/rerun)`
     `(BETA)` Rerun a connectivity test. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-management/connectivity-tests/update)`
     `(BETA)` Update an existing connectivity test. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-management connectivity-tests](https://docs.cloud.google.com/sdk/gcloud/reference/network-management/connectivity-tests)
