NAME
    

gcloud beta source repos - manage cloud source repositories 
SYNOPSIS
    

`gcloud beta source repos` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage cloud source repositories. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[clone](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/clone)`
     `(BETA)` Clone a cloud source repository. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/create)`
     `(BETA)` Create a cloud source repository. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/delete)`
     `(BETA)` Delete a cloud source repository. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/describe)`
     `(BETA)` Describe a cloud source repository. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/get-iam-policy)`
     `(BETA)` Get the IAM policy for the named cloud source repository. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/list)`
     `(BETA)` List the repositories the currently active project. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/set-iam-policy)`
     `(BETA)` Set the IAM policy for the named repository. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/repos/update)`
     `(BETA)` Update the configuration of a Cloud Source Repository. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud source repos](https://docs.cloud.google.com/sdk/gcloud/reference/source/repos)
    
    
    [gcloud alpha source repos](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source/repos)
