NAME
    

gcloud beta source project-configs - manage Cloud Source Repositories configuration of a project 
SYNOPSIS
    

`gcloud beta source project-configs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Source Repositories configuration of a project. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/project-configs/describe)`
     `(BETA)` Show details about the configuration of a project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source/project-configs/update)`
     `(BETA)` Update the Cloud Source Repositories configuration of the current project. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud source project-configs](https://docs.cloud.google.com/sdk/gcloud/reference/source/project-configs)
    
    
    [gcloud alpha source project-configs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source/project-configs)
