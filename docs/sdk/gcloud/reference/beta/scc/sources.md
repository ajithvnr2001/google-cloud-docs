NAME
    

gcloud beta scc sources - manage Cloud SCC (Security Command Center) finding sources 
SYNOPSIS
    

`gcloud beta scc sources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud SCC (Security Command Center) finding sources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/sources/describe)`
     `(BETA)` Describe a source given its display name or source id. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/scc/sources/list)`
     `(BETA)` List Cloud Security Command Center sources. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud scc sources](https://docs.cloud.google.com/sdk/gcloud/reference/scc/sources)
    
    
    [gcloud alpha scc sources](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/scc/sources)
