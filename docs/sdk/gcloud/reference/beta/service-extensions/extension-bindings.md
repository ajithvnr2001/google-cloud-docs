NAME
    

gcloud beta service-extensions extension-bindings - manage Extension Binding resources 
SYNOPSIS
    

`gcloud beta service-extensions extension-bindings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Extension Binding resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings/create)`
     `(BETA)` Create extensionBindings. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings/delete)`
     `(BETA)` Delete extensionBindings. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings/describe)`
     `(BETA)` Describe extensionBindings. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings/import)`
     `(BETA)` Import (create or update) extensionBinding from a file. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings/list)`
     `(BETA)` List extensionBindings. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/extension-bindings/update)`
     `(BETA)` Update extensionBindings. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha service-extensions extension-bindings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-extensions/extension-bindings)
