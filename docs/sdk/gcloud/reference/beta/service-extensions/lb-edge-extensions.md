NAME
    

gcloud beta service-extensions lb-edge-extensions - manage Service Extensions `LbEdgeExtension` resources 
SYNOPSIS
    

`gcloud beta service-extensions lb-edge-extensions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Service Extensions `LbEdgeExtension` resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/lb-edge-extensions/delete)`
     `(BETA)` Delete an `LbEdgeExtension` resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/lb-edge-extensions/describe)`
     `(BETA)` Describe an `LbEdgeExtension` resource. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/lb-edge-extensions/import)`
     `(BETA)` Import an `LbEdgeExtension` resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-extensions/lb-edge-extensions/list)`
     `(BETA)` List `LbEdgeExtension` resources. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud service-extensions lb-edge-extensions](https://docs.cloud.google.com/sdk/gcloud/reference/service-extensions/lb-edge-extensions)
