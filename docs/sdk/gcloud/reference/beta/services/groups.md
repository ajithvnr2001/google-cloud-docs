NAME
    

gcloud beta services groups - view service group information 
SYNOPSIS
    

`gcloud beta services groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` View service group information. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list-expanded-members](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/groups/list-expanded-members)`
     `(BETA)` List expanded members of a specific service and group. 
`[list-members](https://docs.cloud.google.com/sdk/gcloud/reference/beta/services/groups/list-members)`
     `(BETA)` List members of a specific service group. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha services groups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/services/groups)
