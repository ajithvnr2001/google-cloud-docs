NAME
    

gcloud beta memorystore - manage Memorystore resources 
SYNOPSIS
    

`gcloud beta memorystore` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Memorystore resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[acl-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/acl-policies)`
     `(BETA)` Manage Acl Policy resources. 
`[backup-collections](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/backup-collections)`
     `(BETA)` Manage Backup Collection resources. 
`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/instances)`
     `(BETA)` Manage Instance resources. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/locations)`
     `(BETA)` Manage Memorystore for Valkey locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/memorystore/operations)`
     `(BETA)` Manage Memorystore operations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud memorystore](https://docs.cloud.google.com/sdk/gcloud/reference/memorystore)
    
    
    [gcloud alpha memorystore](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/memorystore)
