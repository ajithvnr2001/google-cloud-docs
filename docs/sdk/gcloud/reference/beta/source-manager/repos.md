NAME
    

gcloud beta source-manager repos - manage Secure Source Manager repositories 
SYNOPSIS
    

`gcloud beta source-manager repos` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Secure Source Manager repositories. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Secure Source Manager repository. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/create)`
     `(BETA)` Create a Secure Source Manager repository. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/delete)`
     `(BETA)` Delete a Secure Source Manager repository. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/describe)`
     `(BETA)` Describe a Secure Source Manager repository. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Secure Source Manager repository. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/list)`
     `(BETA)` List all repositories under a Secure Source Manager instance. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a Secure Source Manager repository. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Secure Source Manager repository. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/source-manager/repos/update)`
     `(BETA)` Update a Secure Source Manager repository. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud source-manager repos](https://docs.cloud.google.com/sdk/gcloud/reference/source-manager/repos)
    
    
    [gcloud alpha source-manager repos](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/source-manager/repos)
