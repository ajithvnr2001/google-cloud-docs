#  gcloud beta composer environments snapshots Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta composer environments snapshots - save and load snapshots of environment 
SYNOPSIS
    

`gcloud beta composer environments snapshots` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud beta composer environments snapshots command group saves and loads snapshots of Cloud Composer environments. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[load](https://docs.cloud.google.com/sdk/gcloud/reference/beta/composer/environments/snapshots/load)`
     `(BETA)` Load a snapshot into the environment. 
`[save](https://docs.cloud.google.com/sdk/gcloud/reference/beta/composer/environments/snapshots/save)`
     `(BETA)` Save a snapshot of the environment. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud composer environments snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/composer/environments/snapshots)
    
    
    [gcloud alpha composer environments snapshots](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/composer/environments/snapshots)
