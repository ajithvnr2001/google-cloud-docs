NAME
    

gcloud beta secrets - manage secrets on Google Cloud 
SYNOPSIS
    

`gcloud beta secrets` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Google Secret Manager allows users to store and retrieve secrets such as API keys, certificates, passwords on Google Cloud. Google Secret Manager is integrated with Cloud IAM and Cloud Audit Logging so users can manage permissions on individual secrets and monitor how these are used. 

To learn more about Google Secret Manager, visit: 
    
    
    <https://cloud.google.com/secret-manager/>

To read API and usage documentation, visit: 
    
    
    <https://cloud.google.com/secret-manager/docs/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/locations)`
     `(BETA)` Manage locations of users' secrets. 
`[replication](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/replication)`
     `(BETA)` Manage secret replication. 
`[versions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/versions)`
     `(BETA)` Manage secret versions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to a secret resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/create)`
     `(BETA)` Create a new secret. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/delete)`
     `(BETA)` Delete a secret. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/describe)`
     `(BETA)` Describe a secret's metadata. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/get-iam-policy)`
     `(BETA)` Get the IAM policy of a secret. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/list)`
     `(BETA)` List all secret names. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding of a secret resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/set-iam-policy)`
     `(BETA)` Set the IAM policy for a secret. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/secrets/update)`
     `(BETA)` Update a secret's metadata. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud secrets](https://docs.cloud.google.com/sdk/gcloud/reference/secrets)
    
    
    [gcloud alpha secrets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/secrets)
