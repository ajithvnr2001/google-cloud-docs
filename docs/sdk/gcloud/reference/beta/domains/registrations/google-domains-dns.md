NAME
    

gcloud beta domains registrations google-domains-dns - manage deprecated Google Domains DNS configuration 
SYNOPSIS
    

`gcloud beta domains registrations google-domains-dns` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing DNS records and forwarding configuration of Cloud Domains registrations that use deprecated Google Domains DNS. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[export-dns-record-sets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/registrations/google-domains-dns/export-dns-record-sets)`
     `(BETA)` Export your registration's Google Domains DNS zone's record-sets into a file. 
`[get-forwarding-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/registrations/google-domains-dns/get-forwarding-config)`
     `(BETA)` Get forwarding configuration of a specific Cloud Domains registration. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud domains registrations google-domains-dns](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/google-domains-dns)
    
    
    [gcloud alpha domains registrations google-domains-dns](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/google-domains-dns)
