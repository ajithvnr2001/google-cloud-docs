NAME
    

gcloud beta domains registrations authorization-code - manage Cloud Domains registration's authorization code 
SYNOPSIS
    

`gcloud beta domains registrations authorization-code` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Cloud Domains registration's authorization code. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[get](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/registrations/authorization-code/get)`
     `(BETA)` Get authorization code of a specific Cloud Domains registration. 
`[reset](https://docs.cloud.google.com/sdk/gcloud/reference/beta/domains/registrations/authorization-code/reset)`
     `(BETA)` Resets authorization code of a specific Cloud Domains registration. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud domains registrations authorization-code](https://docs.cloud.google.com/sdk/gcloud/reference/domains/registrations/authorization-code)
    
    
    [gcloud alpha domains registrations authorization-code](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/domains/registrations/authorization-code)
