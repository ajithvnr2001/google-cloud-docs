NAME
    

gcloud beta dataproc - create and manage Google Cloud Dataproc clusters and jobs 
SYNOPSIS
    

`gcloud beta dataproc` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud dataproc command group lets you create and manage Dataproc clusters and jobs. 

Dataproc is an Apache Hadoop, Apache Spark, Apache Pig, and Apache Hive service. It easily processes big datasets at low cost, creating managed clusters of any size that scale down once processing is complete. 

More information on Dataproc can be found here: <https://cloud.google.com/dataproc> and detailed documentation can be found here: <https://cloud.google.com/dataproc/docs/>

EXAMPLES
     To see how to create and manage clusters, run: 
    
    
    [gcloud beta dataproc clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/clusters)

To see how to submit and manage jobs, run: 
    
    
    [gcloud beta dataproc jobs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/jobs)

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS

`[autoscaling-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/autoscaling-policies)`
     `(BETA)` Create and manage Dataproc autoscaling policies. 
`[batches](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/batches)`
     `(BETA)` Submit Dataproc batch jobs.

     `(BETA)` Create and manage Dataproc clusters. 
`[jobs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/jobs)`
     `(BETA)` Submit and manage Dataproc jobs. 
`[node-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/node-groups)`
     `(BETA)` Manage Dataproc node groups. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/operations)`
     `(BETA)` View and manage Dataproc operations. 
`[session-templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/session-templates)`
     `(BETA)` Create and manage Dataproc session templates. 
`[sessions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/sessions)`
     `(BETA)` Create and manage Dataproc sessions. 
`[workflow-templates](https://docs.cloud.google.com/sdk/gcloud/reference/beta/dataproc/workflow-templates)`
