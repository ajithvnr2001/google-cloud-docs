NAME
    

gcloud beta deploy - create and manage Cloud Deploy resources 
SYNOPSIS
    

`gcloud beta deploy` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Cloud Deploy resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[automation-runs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/automation-runs)`
     `(BETA)` Manages AutomationRuns resources for Cloud Deploy. 
`[automations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/automations)`
     `(BETA)` Manages Automations resources for Cloud Deploy. 
`[custom-target-types](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/custom-target-types)`
     `(BETA)` Create and manage Custom Target Type resources for Cloud Deploy. 
`[delivery-pipelines](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/delivery-pipelines)`
     `(BETA)` Create and manage Delivery Pipeline resources for Cloud Deploy. 
`[deploy-policies](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/deploy-policies)`
     `(BETA)` Create and manage Deploy Policy resources for Google Cloud Deploy. 
`[job-runs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/job-runs)`
     `(BETA)` Manages job runs resources for Cloud Deploy. 
`[releases](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/releases)`
     `(BETA)` Create and manage Release resources for Cloud Deploy. 
`[rollouts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/rollouts)`
     `(BETA)` Create and manage Rollout resources for Cloud Deploy. 
`[targets](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets)`
     `(BETA)` Create and manage Target resources for Cloud Deploy. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[apply](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/apply)`
     `(BETA)` Applies a yaml configuration containing Delivery Pipeline(s), Target(s), Custom Target Type(s), Deploy Policy(ies), and Automation(s) declarative definitions. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/delete)`
     `(BETA)` Deletes Delivery Pipeline(s), Target(s), Custom Target Type(s), and Automation(s) in a yaml configuration. 
`[get-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/get-config)`
     `(BETA)` Get the Cloud Deploy config for the provided region and project. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud deploy](https://docs.cloud.google.com/sdk/gcloud/reference/deploy)
    
    
    [gcloud alpha deploy](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deploy)
