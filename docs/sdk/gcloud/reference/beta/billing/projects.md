NAME
    

gcloud beta billing projects - manage the billing account configuration of your projects 
SYNOPSIS
    

`gcloud beta billing projects` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage the billing account configuration of your projects. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/billing/projects/describe)`
     `(BETA)` Show detailed billing information for a project. 
`[link](https://docs.cloud.google.com/sdk/gcloud/reference/beta/billing/projects/link)`
     `(BETA)` Link a project with a billing account. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/billing/projects/list)`
     `(BETA)` List all active projects associated with the specified billing account. 
`[unlink](https://docs.cloud.google.com/sdk/gcloud/reference/beta/billing/projects/unlink)`
     `(BETA)` Unlink the account (if any) linked with a project. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud billing projects](https://docs.cloud.google.com/sdk/gcloud/reference/billing/projects)
    
    
    [gcloud alpha billing projects](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/billing/projects)
