NAME
    

gcloud beta eventarc google-api-sources - manage Eventarc Google API sources 
SYNOPSIS
    

`gcloud beta eventarc google-api-sources` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Eventarc Google API sources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/google-api-sources/create)`
     `(BETA)` Create an Eventarc Google API source. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/google-api-sources/delete)`
     `(BETA)` Delete an Eventarc Google API source. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/google-api-sources/describe)`
     `(BETA)` Describe an Eventarc Google API source. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/google-api-sources/list)`
     `(BETA)` List Eventarc Google API sources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/google-api-sources/update)`
     `(BETA)` Update an Eventarc Google API source. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud eventarc google-api-sources](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/google-api-sources)
