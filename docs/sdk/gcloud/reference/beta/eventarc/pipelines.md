NAME
    

gcloud beta eventarc pipelines - manage Eventarc pipelines 
SYNOPSIS
    

`gcloud beta eventarc pipelines` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Eventarc pipelines. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/pipelines/create)`
     `(BETA)` Create an Eventarc pipeline. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/pipelines/delete)`
     `(BETA)` Delete an Eventarc pipeline. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/pipelines/describe)`
     `(BETA)` Describe an Eventarc pipeline. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/pipelines/list)`
     `(BETA)` List Eventarc pipelines. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/eventarc/pipelines/update)`
     `(BETA)` Update an Eventarc pipeline. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud eventarc pipelines](https://docs.cloud.google.com/sdk/gcloud/reference/eventarc/pipelines)
