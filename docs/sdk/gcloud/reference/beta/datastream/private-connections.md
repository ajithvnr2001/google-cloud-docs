NAME
    

gcloud beta datastream private-connections - manage Datastream private connections 
SYNOPSIS
    

`gcloud beta datastream private-connections` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Datastream private connections. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/private-connections/create)`
     `(BETA)` `(DEPRECATED)` Create a Datastream private connection. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/private-connections/delete)`
     `(BETA)` `(DEPRECATED)` Delete a Datastream private connection. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/private-connections/describe)`
     `(BETA)` `(DEPRECATED)` Show details about a Datastream private connection. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/private-connections/list)`
     `(BETA)` `(DEPRECATED)` List private connections. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud datastream private-connections](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/private-connections)
