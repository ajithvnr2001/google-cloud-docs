NAME
    

gcloud beta datastream streams - manage Datastream stream resources 
SYNOPSIS
    

`gcloud beta datastream streams` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Datastream stream resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/streams/create)`
     `(BETA)` `(DEPRECATED)` Creates a Datastream stream. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/streams/delete)`
     `(BETA)` `(DEPRECATED)` Delete a Datastream stream. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/streams/describe)`
     `(BETA)` `(DEPRECATED)` Show details about a Datastream stream resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/streams/list)`
     `(BETA)` `(DEPRECATED)` List Datastream stream resources. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/streams/update)`
     `(BETA)` `(DEPRECATED)` Updates a Datastream stream. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud datastream streams](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/streams)
