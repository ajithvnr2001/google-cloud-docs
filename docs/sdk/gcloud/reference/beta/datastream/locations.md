NAME
    

gcloud beta datastream locations - manage Datastream location resources 
SYNOPSIS
    

`gcloud beta datastream locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Datastream location resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/locations/describe)`
     `(BETA)` Show details about the location. 
`[fetch-static-ips](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/locations/fetch-static-ips)`
     `(BETA)` List Datastream static ips per location. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/locations/list)`
     `(BETA)` List Datastream locations. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud datastream locations](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/locations)
