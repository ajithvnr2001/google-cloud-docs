NAME
    

gcloud beta datastream connection-profiles - manage Datastream connection profiles 
SYNOPSIS
    

`gcloud beta datastream connection-profiles` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for managing Datastream connection profiles. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/connection-profiles/create)`
     `(BETA)` `(DEPRECATED)` Create a Datastream connection profile. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/connection-profiles/delete)`
     `(BETA)` `(DEPRECATED)` Delete a Datastream connection profile. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/connection-profiles/describe)`
     `(BETA)` `(DEPRECATED)` Show details about a Datastream connection profile. 
`[discover](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/connection-profiles/discover)`
     `(BETA)` `(DEPRECATED)` Discover a Datastream connection profile. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/connection-profiles/list)`
     `(BETA)` `(DEPRECATED)` List Datastream connection profiles. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/datastream/connection-profiles/update)`
     `(BETA)` `(DEPRECATED)` Update a Datastream connection profile. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud datastream connection-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/datastream/connection-profiles)
