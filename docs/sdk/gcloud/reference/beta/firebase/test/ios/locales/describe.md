NAME
    

gcloud beta firebase test ios locales describe - describe an iOS locale 
SYNOPSIS
    

`gcloud beta firebase test ios locales describe` `LOCALE` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Describe an iOS locale. 
EXAMPLES
     To describe an iOS locale, run: 
    
    
    gcloud beta firebase test ios locales describe es_419

To describe an iOS locale in JSON format, run: 
    
    
    gcloud beta firebase test ios locales describe es_419 --format=json

POSITIONAL ARGUMENTS
    

`LOCALE`
     The locale to describe, found using $ [gcloud beta firebase test ios locales list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/ios/locales/list).
