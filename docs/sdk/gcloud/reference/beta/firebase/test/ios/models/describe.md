NAME
    

gcloud beta firebase test ios models describe - describe an iOS model 
SYNOPSIS
    

`gcloud beta firebase test ios models describe` `MODEL_ID` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Describe an iOS model. 
EXAMPLES
     To describe an iOS model, run: 
    
    
    gcloud beta firebase test ios models describe iphone7

To describe an iOS model in JSON format, run: 
    
    
    gcloud beta firebase test ios models describe iphone7 --format=json

POSITIONAL ARGUMENTS
    

`MODEL_ID`
     ID of the model to describe, found using $ [gcloud beta firebase test ios models list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/ios/models/list).
