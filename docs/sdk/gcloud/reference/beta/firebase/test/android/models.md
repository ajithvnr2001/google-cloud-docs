#  gcloud beta firebase test android models Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta firebase test android models - explore Android models available in the Test Environment catalog 
SYNOPSIS
    

`gcloud beta firebase test android models` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Explore Android models available in the Test Environment catalog. 
EXAMPLES
     To list all Android models available for running tests, along with their basic characteristics and supported Android OS versions, run: 
    
    
    [gcloud beta firebase test android models list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/android/models/list)

To view more detailed information about a specific Android model, run: 
    
    
    [gcloud beta firebase test android models describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/android/models/describe) MODEL_ID

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/android/models/describe)`
     `(BETA)` Describe an Android model. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/android/models/list)`
     `(BETA)` List all Android models available for testing. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud firebase test android models](https://docs.cloud.google.com/sdk/gcloud/reference/firebase/test/android/models)
    
    
    [gcloud alpha firebase test android models](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test/android/models)
