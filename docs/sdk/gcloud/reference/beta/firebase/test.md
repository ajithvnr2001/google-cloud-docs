NAME
    

gcloud beta firebase test - interact with Firebase Test Lab 
SYNOPSIS
    

`gcloud beta firebase test` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Explore devices and OS versions available as test targets, run tests, monitor test progress, and view detailed test results in the Firebase console. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[android](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/android)`
     `(BETA)` Command group for Android application testing. 
`[ios](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/ios)`
     `(BETA)` Command group for iOS application testing. 
`[ip-blocks](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/ip-blocks)`
     `(BETA)` Explore IP blocks used by Firebase Test Lab devices. 
`[network-profiles](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firebase/test/network-profiles)`
     `(BETA)` Explore network profiles available for testing. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud firebase test](https://docs.cloud.google.com/sdk/gcloud/reference/firebase/test)
    
    
    [gcloud alpha firebase test](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firebase/test)
