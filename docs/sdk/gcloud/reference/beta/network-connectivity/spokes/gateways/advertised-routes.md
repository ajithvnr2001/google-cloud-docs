NAME
    

gcloud beta network-connectivity spokes gateways advertised-routes - manage gateway advertised routes 
SYNOPSIS
    

`gcloud beta network-connectivity spokes gateways advertised-routes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage gateway advertised routes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/spokes/gateways/advertised-routes/create)`
     `(BETA)` Create a new gateway advertised route. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/spokes/gateways/advertised-routes/delete)`
     `(BETA)` Delete a gateway advertised route. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/spokes/gateways/advertised-routes/describe)`
     `(BETA)` Describe a gateway advertised route. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/spokes/gateways/advertised-routes/list)`
     `(BETA)` List gateway advertised routes.
