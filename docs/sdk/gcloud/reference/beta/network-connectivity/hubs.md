#  gcloud beta network-connectivity hubs Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta network-connectivity hubs - manage Network Connectivity Center hubs 
SYNOPSIS
    

`gcloud beta network-connectivity hubs` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Connectivity Center hubs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups)`
     `(BETA)` Manage Network Connectivity Center groups. 
`[route-tables](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/route-tables)`
     `(BETA)` Manage Network Connectivity Center route tables. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[accept-spoke](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/accept-spoke)`
     `(BETA)` Accept a spoke into a hub. 
`[accept-spoke-update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/accept-spoke-update)`
     `(BETA)` Accept a proposal to update a spoke in a hub. 
`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to the IAM policy of a hub resource. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/create)`
     `(BETA)` Create a new hub. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/delete)`
     `(BETA)` Delete a hub. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/describe)`
     `(BETA)` Describe a hub. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/get-iam-policy)`
     `(BETA)` Get the IAM policy for a hub resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/list)`
     `(BETA)` List hubs. 
`[list-spokes](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/list-spokes)`
     `(BETA)` List hub spokes. 
`[reject-spoke](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/reject-spoke)`
     `(BETA)` Reject a spoke from a hub. 
`[reject-spoke-update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/reject-spoke-update)`
     `(BETA)` Reject a proposal to update a spoke in a hub. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from the IAM policy of a hub resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/set-iam-policy)`
     `(BETA)` Set the IAM policy of a hub resource. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/update)`
     `(BETA)` Update a hub. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud network-connectivity hubs](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/hubs)
    
    
    [gcloud alpha network-connectivity hubs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/network-connectivity/hubs)
