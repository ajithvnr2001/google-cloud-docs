NAME
    

gcloud beta network-connectivity hubs route-tables routes - manage Network Connectivity Center routes 
SYNOPSIS
    

`gcloud beta network-connectivity hubs route-tables routes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Connectivity Center routes. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/route-tables/routes/describe)`
     `(BETA)` Describe a route. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/route-tables/routes/list)`
     `(BETA)` List routes. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-connectivity hubs route-tables routes](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/hubs/route-tables/routes)
