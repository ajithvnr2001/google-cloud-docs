NAME
    

gcloud beta network-connectivity hubs groups - manage Network Connectivity Center groups 
SYNOPSIS
    

`gcloud beta network-connectivity hubs groups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Network Connectivity Center groups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to the IAM policy of a group resource. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups/describe)`
     `(BETA)` Describe a group. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups/get-iam-policy)`
     `(BETA)` Get the IAM policy for a group resource. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups/list)`
     `(BETA)` List groups. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from the IAM policy of a group resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups/set-iam-policy)`
     `(BETA)` Set the IAM policy of a group resource. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/network-connectivity/hubs/groups/update)`
     `(BETA)` Update a group. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud network-connectivity hubs groups](https://docs.cloud.google.com/sdk/gcloud/reference/network-connectivity/hubs/groups)
