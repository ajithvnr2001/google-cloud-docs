NAME
    

gcloud beta monitoring metrics-scopes - manage Cloud Monitoring Metrics Scopes 
SYNOPSIS
    

`gcloud beta monitoring metrics-scopes` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud beta monitoring metrics-scopes group lets you manage Monitoring metrics scopes. 

More information on managing metrics scopes can be found here: <https://cloud.google.com/monitoring/settings/manage-api>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/metrics-scopes/create)`
     `(BETA)` Create a monitored project in a metrics scope. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/metrics-scopes/delete)`
     `(BETA)` Delete a monitored project in a metrics scope. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/metrics-scopes/describe)`
     `(BETA)` Describe a Cloud Monitoring metrics scope. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/metrics-scopes/list)`
     `(BETA)` List the metrics scopes monitoring the specified monitored resource container. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha monitoring metrics-scopes](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/metrics-scopes)
