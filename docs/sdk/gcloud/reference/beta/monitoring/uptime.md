NAME
    

gcloud beta monitoring uptime - manage Cloud Monitoring uptime checks and synthetic monitors 
SYNOPSIS
    

`gcloud beta monitoring uptime` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Monitoring uptime checks and synthetic monitors. 

More information can be found here: <https://cloud.google.com/monitoring/api/v3/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime/create)`
     `(BETA)` Create a new uptime check or synthetic monitor. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime/delete)`
     `(BETA)` Delete an uptime check or synthetic monitor. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime/describe)`
     `(BETA)` Describe an uptime check or synthetic monitor. 
`[list-configs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime/list-configs)`
     `(BETA)` List uptime checks and synthetic monitors. 
`[list-ips](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime/list-ips)`
     `(BETA)` List uptime check server ips. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/uptime/update)`
     `(BETA)` Update an existing uptime check or synthetic monitor. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud monitoring uptime](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/uptime)
    
    
    [gcloud alpha monitoring uptime](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/uptime)
