NAME
    

gcloud beta monitoring policies - manage Cloud Monitoring alerting policies 
SYNOPSIS
    

`gcloud beta monitoring policies` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Monitoring alerting policies. 

More information can be found here: <https://cloud.google.com/monitoring/api/v3/>

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[conditions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies/conditions)`
     `(BETA)` Manage Cloud Monitoring alerting policy conditions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies/create)`
     `(BETA)` Create a new alerting policy. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies/delete)`
     `(BETA)` Delete a Cloud Monitoring alerting policy. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies/describe)`
     `(BETA)` Describe an alerting policy. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies/list)`
     `(BETA)` List alerting policies. 
`[migrate](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies/migrate)`
     `(BETA)` Migrate a Prometheus configuration file to Cloud Monitoring. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/monitoring/policies/update)`
     `(BETA)` Updates an alerting policy. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud monitoring policies](https://docs.cloud.google.com/sdk/gcloud/reference/monitoring/policies)
    
    
    [gcloud alpha monitoring policies](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/monitoring/policies)
