NAME
    

gcloud beta iap tcp - manage IAP TCP resources 
SYNOPSIS
    

`gcloud beta iap tcp` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage IAP TCP resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[dest-groups](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/tcp/dest-groups)`
     `(BETA)` Manage IAP TCP Destination Group resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/tcp/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding to an IAP TCP IAM resource. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/tcp/get-iam-policy)`
     `(BETA)` Get IAM policy for an IAP TCP IAM resource. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/tcp/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding from an IAP TCP IAM resource. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/tcp/set-iam-policy)`
     `(BETA)` Set the IAM policy for an IAP TCP IAM resource. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iap tcp](https://docs.cloud.google.com/sdk/gcloud/reference/iap/tcp)
    
    
    [gcloud alpha iap tcp](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/tcp)
