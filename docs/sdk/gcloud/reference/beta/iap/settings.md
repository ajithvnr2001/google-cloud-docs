NAME
    

gcloud beta iap settings - manage IAP settings 
SYNOPSIS
    

`gcloud beta iap settings` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage IAP settings. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[get](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/settings/get)`
     `(BETA)` Get the setting for an IAP resource. 
`[set](https://docs.cloud.google.com/sdk/gcloud/reference/beta/iap/settings/set)`
     `(BETA)` Set the setting for an IAP resource. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud iap settings](https://docs.cloud.google.com/sdk/gcloud/reference/iap/settings)
    
    
    [gcloud alpha iap settings](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/iap/settings)
