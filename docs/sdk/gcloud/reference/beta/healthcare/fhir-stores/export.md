NAME
    

gcloud beta healthcare fhir-stores export - manage Cloud Healthcare API FHIR store exports 
SYNOPSIS
    

`gcloud beta healthcare fhir-stores export` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Healthcare API FHIR store exports. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[bq](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/export/bq)`
     `(BETA)` Export Cloud Healthcare API FHIR resources to BigQuery. 
`[gcs](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/export/gcs)`
     `(BETA)` Export Cloud Healthcare API FHIR resources to Google Cloud Storage. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud healthcare fhir-stores export](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/fhir-stores/export)
    
    
    [gcloud alpha healthcare fhir-stores export](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/fhir-stores/export)
