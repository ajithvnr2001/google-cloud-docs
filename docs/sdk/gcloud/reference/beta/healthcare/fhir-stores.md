NAME
    

gcloud beta healthcare fhir-stores - manage Cloud Healthcare API FHIR stores 
SYNOPSIS
    

`gcloud beta healthcare fhir-stores` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Healthcare API FHIR stores. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/export)`
     `(BETA)` Manage Cloud Healthcare API FHIR store exports. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/import)`
     `(BETA)` Manage Cloud Healthcare API FHIR store imports. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Cloud Healthcare API FHIR store. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/create)`
     `(BETA)` Create a Cloud Healthcare API FHIR store. 
`[deidentify](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/deidentify)`
     `(BETA)` De-identify data from the source store and write it to the destination store. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/delete)`
     `(BETA)` Delete a Cloud Healthcare API FHIR store. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/describe)`
     `(BETA)` Describe a Cloud Healthcare API FHIR store. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/get-iam-policy)`
     `(BETA)` Retrieve the IAM policy for a Cloud Healthcare API FHIR store. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/list)`
     `(BETA)` List Cloud Healthcare API FHIR stores. 
`[metrics](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/metrics)`
     `(BETA)` Gets the metrics for a Cloud Healthcare API FHIR store. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a Cloud Healthcare API FHIR store. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Cloud Healthcare API FHIR store. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/healthcare/fhir-stores/update)`
     `(BETA)` Update a Cloud Healthcare API FHIR store. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud healthcare fhir-stores](https://docs.cloud.google.com/sdk/gcloud/reference/healthcare/fhir-stores)
    
    
    [gcloud alpha healthcare fhir-stores](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/healthcare/fhir-stores)
