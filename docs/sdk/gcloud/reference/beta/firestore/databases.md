NAME
    

gcloud beta firestore databases - manage Creation of Cloud Firestore in Native mode Database 
SYNOPSIS
    

`gcloud beta firestore databases` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Creation of Cloud Firestore in Native mode Database. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[clone](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/clone)`
     `(BETA)` Clone a Google Cloud Firestore database from another. 
`[connection-string](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/connection-string)`
     `(BETA)` Prints the mongo connection string for the given Firestore database. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/create)`
     `(BETA)` Create a Google Cloud Firestore database via Firestore API. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/delete)`
     `(BETA)` Delete a Google Cloud Firestore database. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/describe)`
     `(BETA)` Describes information about a Cloud Firestore database. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/list)`
     `(BETA)` Lists all Firestore databases under the project. 
`[ping](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/ping)`
     `(BETA)` Times the connection and ping time for a Firestore with MongoDB compatibility database. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/restore)`
     `(BETA)` Restores a Cloud Firestore database from a backup. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/firestore/databases/update)`
     `(BETA)` Update the database configuration of a Cloud Firestore database. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud firestore databases](https://docs.cloud.google.com/sdk/gcloud/reference/firestore/databases)
    
    
    [gcloud alpha firestore databases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/firestore/databases)
