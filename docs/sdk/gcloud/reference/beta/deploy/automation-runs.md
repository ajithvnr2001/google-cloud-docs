NAME
    

gcloud beta deploy automation-runs - manages AutomationRuns resources for Cloud Deploy 
SYNOPSIS
    

`gcloud beta deploy automation-runs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manages AutomationRuns resources for Cloud Deploy. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/automation-runs/cancel)`
     `(BETA)` Cancels a Cloud Deploy Automation Run. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/automation-runs/describe)`
     `(BETA)` Show details for an Automation Run. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/automation-runs/list)`
     `(BETA)` List the Automation Runs. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud deploy automation-runs](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/automation-runs)
    
    
    [gcloud alpha deploy automation-runs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deploy/automation-runs)
