NAME
    

gcloud beta deploy targets - create and manage Target resources for Cloud Deploy 
SYNOPSIS
    

`gcloud beta deploy targets` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Target resources for Cloud Deploy. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding for a Cloud Deploy target. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/delete)`
     `(BETA)` Deletes a Cloud Deploy target. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/describe)`
     `(BETA)` Describes details specific to the individual target, delivery pipeline qualified. 
`[export](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/export)`
     `(BETA)` Returns the .yaml definition of the specified target. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/get-iam-policy)`
     `(BETA)` Get the IAM policy for a Cloud Deploy target. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/list)`
     `(BETA)` List Cloud Deploy targets. 
`[redeploy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/redeploy)`
     `(BETA)` Redeploy the last release to a target. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding for a Cloud Deploy target. 
`[rollback](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/rollback)`
     `(BETA)` Rollbacks a target to a prior rollout. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/targets/set-iam-policy)`
     `(BETA)` Set the IAM policy for a Cloud Deploy target. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud deploy targets](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/targets)
    
    
    [gcloud alpha deploy targets](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deploy/targets)
