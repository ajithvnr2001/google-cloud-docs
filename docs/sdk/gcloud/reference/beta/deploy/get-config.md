NAME
    

gcloud beta deploy get-config - get the Cloud Deploy config for the provided region and project 
SYNOPSIS
    

`gcloud beta deploy get-config` [`--region`=`REGION`] [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Get the Cloud Deploy config for the provided region and project. 
EXAMPLES
     To get the config for project `test-project` in region `us-central1`: 
    
    
    gcloud beta deploy get-config --project=test-project --region=us-central1

FLAGS
    

Location resource - The Cloud region of {resource}. This represents a Cloud resource. (NOTE) Some attributes are not given arguments in this group but can be set in other ways. 

To set the `project` attribute: 

  * provide the argument `--region` on the command line with a fully specified name; 
  * set the property `deploy/region` with a fully specified name; 
  * provide the argument `--project` on the command line; 
  * set the property `core/project`. 


`--region`=`REGION`
     ID of the location or fully qualified identifier for the location. 

To set the `region` attribute: 

  * provide the argument `--region` on the command line; 
  * set the property `deploy/region`.
