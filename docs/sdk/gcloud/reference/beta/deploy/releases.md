NAME
    

gcloud beta deploy releases - create and manage Release resources for Cloud Deploy 
SYNOPSIS
    

`gcloud beta deploy releases` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Create and manage Release resources for Cloud Deploy. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[abandon](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/releases/abandon)`
     `(BETA)` Abandons a release. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/releases/create)`
     `(BETA)` Creates a new release, delivery pipeline qualified. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/releases/describe)`
     `(BETA)` Show details about a release. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/releases/list)`
     `(BETA)` List releases. 
`[promote](https://docs.cloud.google.com/sdk/gcloud/reference/beta/deploy/releases/promote)`
     `(BETA)` Promotes a release from one target (source), to another (destination). 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud deploy releases](https://docs.cloud.google.com/sdk/gcloud/reference/deploy/releases)
    
    
    [gcloud alpha deploy releases](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/deploy/releases)
