NAME
    

gcloud beta cluster-director - manage Cluster Director resources 
SYNOPSIS
    

`gcloud beta cluster-director` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Cluster Director is a unified management plane that simplifies deploying and running large-scale AI and high-performance computing (HPC) clusters. 

The service automates complex infrastructure setup by integrating compute, networking, and storage to maximize performance and minimize downtimes. 

If you have your own configuration already: 

  * Use `--config` to provide a complete JSON definition 



To start from a pre-configuration: 

  * Use `--quickstart-cluster` to create and connect a managed Slurm cluster with basic defaults 
  * Use `--reference-architecture` to choose from workload-optimized templates 



To fully customize: 

  * Run the 'clusters create' command for the most granular configuration options 

Learn more at <https://docs.cloud.google.com/cluster-director/>
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[clusters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/cluster-director/clusters)`
     `(BETA)` Deploy and manage large-scale AI and high-performance computing (HPC) clusters. 
`[locations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/cluster-director/locations)`
     `(BETA)` View supported locations. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/beta/cluster-director/operations)`
     `(BETA)` Manage Operation resources. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud cluster-director](https://docs.cloud.google.com/sdk/gcloud/reference/cluster-director)
    
    
    [gcloud alpha cluster-director](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/cluster-director)
