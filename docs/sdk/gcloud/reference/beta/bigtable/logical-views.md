NAME
    

gcloud beta bigtable logical-views - manage Bigtable logical views 
SYNOPSIS
    

`gcloud beta bigtable logical-views` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Bigtable logical views. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/logical-views/create)`
     `(BETA)` Create a new Bigtable logical view. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/logical-views/delete)`
     `(BETA)` Delete a Bigtable logical view. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/logical-views/describe)`
     `(BETA)` Describe an existing Bigtable logical view. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/logical-views/list)`
     `(BETA)` List existing Bigtable logical views. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/logical-views/update)`
     `(BETA)` Update a Bigtable logical view. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud bigtable logical-views](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/logical-views)
    
    
    [gcloud alpha bigtable logical-views](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/logical-views)
