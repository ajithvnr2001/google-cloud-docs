NAME
    

gcloud beta bigtable schema-bundles - manage Bigtable schema bundles 
SYNOPSIS
    

`gcloud beta bigtable schema-bundles` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Bigtable schema bundles. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Bigtable schema bundle. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/create)`
     `(BETA)` Create a new Bigtable schema bundle. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/delete)`
     `(BETA)` Delete a Bigtable schema bundle. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/describe)`
     `(BETA)` Describe a Bigtable schema bundle. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/get-iam-policy)`
     `(BETA)` Get an IAM policy on a Bigtable schema bundle. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/list)`
     `(BETA)` List all schema bundles of a Bigtable table. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a Bigtable schema bundle. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/set-iam-policy)`
     `(BETA)` Set an IAM policy on a Bigtable schema bundle. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/schema-bundles/update)`
     `(BETA)` Update an existing Bigtable schema bundle. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud bigtable schema-bundles](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/schema-bundles)
    
    
    [gcloud alpha bigtable schema-bundles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/schema-bundles)
