NAME
    

gcloud beta bigtable operations - manage Cloud Bigtable operations 
SYNOPSIS
    

`gcloud beta bigtable operations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Bigtable operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/operations/describe)`
     `(BETA)` Describe a Cloud Bigtable operation. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/operations/list)`
     `(BETA)` List Cloud Bigtable operations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud bigtable operations](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/operations)
    
    
    [gcloud alpha bigtable operations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/operations)
