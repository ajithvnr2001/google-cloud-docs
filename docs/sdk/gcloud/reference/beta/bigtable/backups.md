NAME
    

gcloud beta bigtable backups - manage Cloud Bigtable backups 
SYNOPSIS
    

`gcloud beta bigtable backups` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Cloud Bigtable backups. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/add-iam-policy-binding)`
     `(BETA)` Add an IAM policy binding to a Cloud Bigtable Backup. 
`[copy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/copy)`
     `(BETA)` Copy a Cloud Bigtable backup to a new backup. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/create)`
     `(BETA)` Creates a backup of a Cloud Bigtable table. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/delete)`
     `(BETA)` Delete an existing backup. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/describe)`
     `(BETA)` Retrieves information about a backup. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/get-iam-policy)`
     `(BETA)` Get an IAM policy on a Cloud Bigtable Backup. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/list)`
     `(BETA)` List existing Bigtable backups. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/remove-iam-policy-binding)`
     `(BETA)` Remove an IAM policy binding from a Cloud Bigtable Backup. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/set-iam-policy)`
     `(BETA)` Set an IAM policy on a Cloud Bigtable Backup. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/bigtable/backups/update)`
     `(BETA)` Update a backup, only supported for the following fields: \--expiration-date and --retention-period. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud bigtable backups](https://docs.cloud.google.com/sdk/gcloud/reference/bigtable/backups)
    
    
    [gcloud alpha bigtable backups](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bigtable/backups)
