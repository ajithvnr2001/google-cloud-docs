NAME
    

gcloud beta batch jobs - manage Batch job resources 
SYNOPSIS
    

`gcloud beta batch jobs` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` The gcloud batch jobs command group lets you submit, describe, list and delete Batch jobs. 

With Batch, you can utilize the fully managed service to schedule, queue, and execute batch jobs on Google's infrastructure. 

For more information about Batch, see the [Batch overview](https://cloud.google.com/batch) and the [Batch documentation](https://cloud.google.com/batch/docs/). 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/batch/jobs/cancel)`
     `(BETA)` Cancel a job. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/batch/jobs/delete)`
     `(BETA)` Delete a job. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/batch/jobs/describe)`
     `(BETA)` Show details of a job. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/batch/jobs/list)`
     `(BETA)` List jobs for a specified Batch project/location. 
`[submit](https://docs.cloud.google.com/sdk/gcloud/reference/beta/batch/jobs/submit)`
     `(BETA)` Submit a Batch job. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud batch jobs](https://docs.cloud.google.com/sdk/gcloud/reference/batch/jobs)
    
    
    [gcloud alpha batch jobs](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/batch/jobs)
