NAME
    

gcloud beta notebooks locations - view locations available for a project 
SYNOPSIS
    

`gcloud beta notebooks locations` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` `(DEPRECATED)` View locations available for a project. 

This command is deprecated. Please use `[gcloud notebooks](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/notebooks/locations/list)`
     `(BETA)` `(DEPRECATED)` Request for listing locations. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud notebooks locations](https://docs.cloud.google.com/sdk/gcloud/reference/notebooks/locations)
    
    
    [gcloud alpha notebooks locations](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/notebooks/locations)
