NAME
    

gcloud beta kms ekm-connections - create and manage ekm connections 
SYNOPSIS
    

`gcloud beta kms ekm-connections` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Ekm Connections are used to control the connection settings for an EXTERNAL_VPC CryptoKey. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding for a kms ekm connection. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/create)`
     `(BETA)` Create a new ekm connection. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/describe)`
     `(BETA)` Get metadata for an ekmconnection. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/get-iam-policy)`
     `(BETA)` Get the IAM policy for an ekm connection. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/list)`
     `(BETA)` List ekmconnections within a location. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding for a kms ekm connection. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/set-iam-policy)`
     `(BETA)` Set the IAM policy binding for a KMS ekm connection. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/ekm-connections/update)`
     `(BETA)` Update an ekmconnection. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud kms ekm-connections](https://docs.cloud.google.com/sdk/gcloud/reference/kms/ekm-connections)
    
    
    [gcloud alpha kms ekm-connections](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/ekm-connections)
