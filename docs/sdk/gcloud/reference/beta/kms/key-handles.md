NAME
    

gcloud beta kms key-handles - create and manage KeyHandle resources 
SYNOPSIS
    

`gcloud beta kms key-handles` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` A KeyHandle is a resource which contains a reference to a KMS CryptoKey resource that can be used through existing CMEK channels 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/key-handles/create)`
     `(BETA)` Create a new KeyHandle. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/key-handles/describe)`
     `(BETA)` Get metadata for a KeyHandle. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/key-handles/list)`
     `(BETA)` List KeyHandle resources within a project and location. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud kms key-handles](https://docs.cloud.google.com/sdk/gcloud/reference/kms/key-handles)
    
    
    [gcloud alpha kms key-handles](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/key-handles)
