NAME
    

gcloud beta kms keys - create and manage keys 
SYNOPSIS
    

`gcloud beta kms keys` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` A key represents a logical key that can be used for cryptographic operations. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[versions](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions)`
     `(BETA)` Create and manage versions. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[add-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/add-iam-policy-binding)`
     `(BETA)` Add IAM policy binding for a kms key. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/create)`
     `(BETA)` Create a new key. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/delete)`
     `(BETA)` Delete a key. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/describe)`
     `(BETA)` Get metadata for a given key. 
`[get-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/get-iam-policy)`
     `(BETA)` Get the IAM policy for a key. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/list)`
     `(BETA)` List the keys within a keyring. 
`[remove-iam-policy-binding](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/remove-iam-policy-binding)`
     `(BETA)` Remove IAM policy binding for a kms key. 
`[remove-rotation-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/remove-rotation-schedule)`
     `(BETA)` Remove the rotation schedule for a key. 
`[set-iam-policy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/set-iam-policy)`
     `(BETA)` Set the IAM policy for a key. 
`[set-primary-version](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/set-primary-version)`
     `(BETA)` Set the primary version of a key. 
`[set-rotation-schedule](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/set-rotation-schedule)`
     `(BETA)` Update the rotation schedule for a key. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/update)`
     `(BETA)` Update a key. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud kms keys](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys)
    
    
    [gcloud alpha kms keys](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys)
