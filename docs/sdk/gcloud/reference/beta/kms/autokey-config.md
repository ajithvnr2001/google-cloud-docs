NAME
    

gcloud beta kms autokey-config - update and retrieve the AutokeyConfig 
SYNOPSIS
    

`gcloud beta kms autokey-config` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Autokey config is a folder level resource which configures the key project for the folder and the resources inside it. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/autokey-config/describe)`
     `(BETA)` Describe the AutokeyConfig of a folder or project. 
`[show-effective-config](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/autokey-config/show-effective-config)`
     `(BETA)` Get the effective Cloud KMS AutokeyConfig for a given folder or project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/autokey-config/update)`
     `(BETA)` Update the AutokeyConfig for a folder or project. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud kms autokey-config](https://docs.cloud.google.com/sdk/gcloud/reference/kms/autokey-config)
    
    
    [gcloud alpha kms autokey-config](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/autokey-config)
