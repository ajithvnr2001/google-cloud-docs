NAME
    

gcloud beta kms keys versions - create and manage versions 
SYNOPSIS
    

`gcloud beta kms keys versions` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` A version represents an individual cryptographic key and the associated key material. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/create)`
     `(BETA)` Create a new version. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/delete)`
     `(BETA)` Delete a key version. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/describe)`
     `(BETA)` Get metadata for a given version. 
`[destroy](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/destroy)`
     `(BETA)` Schedule a version to be destroyed. 
`[disable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/disable)`
     `(BETA)` Disable a given version. 
`[enable](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/enable)`
     `(BETA)` Enable a given version. 
`[export-trusted-key-wrapped](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/export-trusted-key-wrapped)`
     `(BETA)` Export a trusted key wrapped CryptoKeyVersion. 
`[get-certificate-chain](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/get-certificate-chain)`
     `(BETA)` Get a certificate chain for a given version. 
`[get-public-key](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/get-public-key)`
     `(BETA)` Get the public key for a given version. 
`[import](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/import)`
     `(BETA)` Import a version into an existing crypto key. 
`[import-trusted-key-wrapped](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/import-trusted-key-wrapped)`
     `(BETA)` Import a trusted key wrapped CryptoKeyVersion. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/list)`
     `(BETA)` List the versions within a key. 
`[restore](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/restore)`
     `(BETA)` Restore a version scheduled for destruction. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/keys/versions/update)`
     `(BETA)` Update a key version. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud kms keys versions](https://docs.cloud.google.com/sdk/gcloud/reference/kms/keys/versions)
    
    
    [gcloud alpha kms keys versions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/kms/keys/versions)
