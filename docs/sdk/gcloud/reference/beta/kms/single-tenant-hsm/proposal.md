NAME
    

gcloud beta kms single-tenant-hsm proposal - commands for managing single tenant HSM instance proposals 
SYNOPSIS
    

`gcloud beta kms single-tenant-hsm proposal` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` single tenant hsm instance proposals represent a proposal to perform an operation on a single tenant HSM instance. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[approve](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/single-tenant-hsm/proposal/approve)`
     `(BETA)` Approve a single tenant HSM instance proposal. 
`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/single-tenant-hsm/proposal/create)`
     `(BETA)` Create a single tenant HSM instance proposal. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/single-tenant-hsm/proposal/delete)`
     `(BETA)` Delete a single tenant HSM instance proposal. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/single-tenant-hsm/proposal/describe)`
     `(BETA)` Get metadata for a single tenant HSM instance proposal. 
`[execute](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/single-tenant-hsm/proposal/execute)`
     `(BETA)` Executes a single tenant HSM proposal. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/kms/single-tenant-hsm/proposal/list)`
     `(BETA)` List single tenant HSM instance proposals within a single tenant HSM instance. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud kms single-tenant-hsm proposal](https://docs.cloud.google.com/sdk/gcloud/reference/kms/single-tenant-hsm/proposal)
