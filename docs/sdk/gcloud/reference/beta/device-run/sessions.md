NAME
    

gcloud beta device-run sessions - manage Device Run sessions 
SYNOPSIS
    

`gcloud beta device-run sessions` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage Device Run sessions. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[submit](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/sessions/submit)`
     `(BETA)` Submit automation sessions with different types of jobs via Device Run. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[cancel](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/sessions/cancel)`
     `(BETA)` Cancel a Device Run session. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/sessions/describe)`
     `(BETA)` Describe a Device Run session. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/sessions/list)`
     `(BETA)` List all Device Run sessions. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/beta/device-run/sessions/wait)`
     `(BETA)` Wait for a Device Run session to complete. 
NOTES
     This command is currently in beta and might change without notice. This variant is also available: 
    
    
    [gcloud alpha device-run sessions](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/device-run/sessions)
