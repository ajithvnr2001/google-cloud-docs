NAME
    

gcloud beta service-health - request events that are relevant to your project or organization 
SYNOPSIS
    

`gcloud beta service-health` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Request events that are relevant to your project or organization. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[artifacts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/artifacts)`
     `(BETA)` Represents a report for a Google Cloud outage. 
`[events](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/events)`
     `(BETA)` Represents events that may affect Google Cloud products. 
`[organization-events](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/organization-events)`
     `(BETA)` Represents events that may affect products used across the organization. 
`[organization-impacts](https://docs.cloud.google.com/sdk/gcloud/reference/beta/service-health/organization-impacts)`
     `(BETA)` Represents impact to assets at organizational level. 
NOTES
     This command is currently in beta and might change without notice. These variants are also available: 
    
    
    [gcloud service-health](https://docs.cloud.google.com/sdk/gcloud/reference/service-health)
    
    
    [gcloud alpha service-health](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/service-health)
