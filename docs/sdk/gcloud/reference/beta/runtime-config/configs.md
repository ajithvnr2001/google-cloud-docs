#  gcloud beta runtime-config configs Stay organized with collections  Save and categorize content based on your preferences. 

NAME
    

gcloud beta runtime-config configs - commands for RuntimeConfig configs 
SYNOPSIS
    

`gcloud beta runtime-config configs` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Commands for RuntimeConfig configs. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[variables](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/variables)`
     `(BETA)` Manage variable resources. 
`[waiters](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/waiters)`
     `(BETA)` Manage waiter resources. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/create)`
     `(BETA)` Create runtime-config resources. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/delete)`
     `(BETA)` Delete runtime-config resources. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/describe)`
     `(BETA)` Describe runtime-config resources. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/list)`
     `(BETA)` List runtime-config resources within the current project. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/update)`
     `(BETA)` Update runtime-config resources. 
NOTES
     This command is currently in beta and might change without notice.
