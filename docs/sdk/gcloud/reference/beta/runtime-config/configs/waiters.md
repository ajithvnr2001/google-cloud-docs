NAME
    

gcloud beta runtime-config configs waiters - manage waiter resources 
SYNOPSIS
    

`gcloud beta runtime-config configs waiters` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` Manage waiter resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/waiters/create)`
     `(BETA)` Create waiter resources. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/waiters/delete)`
     `(BETA)` Delete waiter resources. 
`[describe](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/waiters/describe)`
     `(BETA)` Describe waiter resources. 
`[list](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/waiters/list)`
     `(BETA)` List waiter resources within a configuration. 
`[wait](https://docs.cloud.google.com/sdk/gcloud/reference/beta/runtime-config/configs/waiters/wait)`
     `(BETA)` Wait for a waiter to end in success or failure. 
NOTES
     This command is currently in beta and might change without notice.
