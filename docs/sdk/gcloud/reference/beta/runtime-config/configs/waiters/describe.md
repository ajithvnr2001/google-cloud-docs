NAME
    

gcloud beta runtime-config configs waiters describe - describe waiter resources 
SYNOPSIS
    

`gcloud beta runtime-config configs waiters describe` `NAME` `--config-name`=`CONFIG_NAME` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(BETA)` This command displays information about the waiter resource with the specified name. 
EXAMPLES
     To describe a waiter named "my-waiter" within a configuration named "my-config", run: 
    
    
    gcloud beta runtime-config configs waiters describe my-waiter --config-name=my-config

POSITIONAL ARGUMENTS
    

`NAME`
     The waiter name. 
REQUIRED FLAGS
    

`--config-name`=`CONFIG_NAME`
     The name of the configuration resource to use.
