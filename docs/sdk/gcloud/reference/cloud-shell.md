NAME
    

gcloud cloud-shell - manage Google Cloud Shell 
SYNOPSIS
    

`gcloud cloud-shell` `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Interact with and connect to your Cloud Shell environment. 

More information on Cloud Shell can be found at <https://cloud.google.com/shell/docs/>. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

COMMANDS
     ``COMMAND`` is one of the following: 

`[get-mount-command](https://docs.cloud.google.com/sdk/gcloud/reference/cloud-shell/get-mount-command)`
     Prints a command to mount the Cloud Shell home directory via sshfs. 
`[scp](https://docs.cloud.google.com/sdk/gcloud/reference/cloud-shell/scp)`
     Copies files between Cloud Shell and the local machine. 
`[ssh](https://docs.cloud.google.com/sdk/gcloud/reference/cloud-shell/ssh)`
     Allows you to establish an interactive SSH session with Cloud Shell. 
NOTES
     The previous `gcloud alpha shell` command to launch an interactive shell was renamed to `[gcloud alpha interactive](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/interactive)`. 

These variants are also available: 
    
    
    [gcloud alpha cloud-shell](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/cloud-shell)
    
    
    [gcloud beta cloud-shell](https://docs.cloud.google.com/sdk/gcloud/reference/beta/cloud-shell)
