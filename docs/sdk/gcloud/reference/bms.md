NAME
    

gcloud bms - manage Bare Metal Solution resources 
SYNOPSIS
    

`gcloud bms` `GROUP` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     Manage Bare Metal Solution resources. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[instances](https://docs.cloud.google.com/sdk/gcloud/reference/bms/instances)`
     Manage bare metal instances in Bare Metal Solution. 
`[networks](https://docs.cloud.google.com/sdk/gcloud/reference/bms/networks)`
     Manage networks in Bare Metal Solution. 
`[nfs-shares](https://docs.cloud.google.com/sdk/gcloud/reference/bms/nfs-shares)`
     Manage NFS shares in Bare Metal Solution. 
`[operations](https://docs.cloud.google.com/sdk/gcloud/reference/bms/operations)`
     Manage operations in Bare Metal Solution. 
`[os-images](https://docs.cloud.google.com/sdk/gcloud/reference/bms/os-images)`
     Manage bare metal os images in Bare Metal Solution. 
`[ssh-keys](https://docs.cloud.google.com/sdk/gcloud/reference/bms/ssh-keys)`
     Manage SSH keys for Bare Metal Solution. 
`[volumes](https://docs.cloud.google.com/sdk/gcloud/reference/bms/volumes)`
     Manage bare metal volumes in Bare Metal Solution. 
NOTES
     This variant is also available: 
    
    
    [gcloud alpha bms](https://docs.cloud.google.com/sdk/gcloud/reference/alpha/bms)
