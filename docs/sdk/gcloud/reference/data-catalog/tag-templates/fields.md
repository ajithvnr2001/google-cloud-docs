NAME
    

gcloud data-catalog tag-templates fields - manage tag template fields in Data Catalog 
SYNOPSIS
    

`gcloud data-catalog tag-templates fields` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     `(DEPRECATED)` Manage tag template fields in Data Catalog. 

This command is deprecated. Please use `[gcloud dataplex aspect-types](https://docs.cloud.google.com/sdk/gcloud/reference/dataplex/aspect-types)` instead. 

GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[enum-values](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/tag-templates/fields/enum-values)`
     `(DEPRECATED)` Manage tag template enum values in Data Catalog. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[create](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/tag-templates/fields/create)`
     `(DEPRECATED)` Create a Data Catalog tag template field. 
`[delete](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/tag-templates/fields/delete)`
     `(DEPRECATED)` Delete a Data Catalog tag template field. 
`[rename](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/tag-templates/fields/rename)`
     `(DEPRECATED)` Rename a Data Catalog tag template field. 
`[update](https://docs.cloud.google.com/sdk/gcloud/reference/data-catalog/tag-templates/fields/update)`
     `(DEPRECATED)` Update a Data Catalog tag template field. 
NOTES
     These variants are also available:
