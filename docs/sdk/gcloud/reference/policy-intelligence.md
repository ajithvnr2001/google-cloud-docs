NAME
    

gcloud policy-intelligence - a platform to help better understand, use, and manage policies at scale 
SYNOPSIS
    

`gcloud policy-intelligence` `GROUP` | `COMMAND` [`GCLOUD_WIDE_FLAG …`]
DESCRIPTION
     A platform to help better understand, use, and manage policies at scale. 
GCLOUD WIDE FLAGS
     These flags are available to all commands: `[--help](https://docs.cloud.google.com/sdk/gcloud/reference#--help)`. 

Run `$ [gcloud help](https://docs.cloud.google.com/sdk/gcloud/reference)` for details. 

GROUPS
     ``GROUP`` is one of the following: 

`[simulate](https://docs.cloud.google.com/sdk/gcloud/reference/policy-intelligence/simulate)`
     Simulate changes to organization policies. 
`[troubleshoot-policy](https://docs.cloud.google.com/sdk/gcloud/reference/policy-intelligence/troubleshoot-policy)`
     Troubleshoot IAM policies. 
COMMANDS
     ``COMMAND`` is one of the following: 

`[query-activity](https://docs.cloud.google.com/sdk/gcloud/reference/policy-intelligence/query-activity)`
     Query activities on cloud resource. 
NOTES
     This variant is also available: 
    
    
    [gcloud beta policy-intelligence](https://docs.cloud.google.com/sdk/gcloud/reference/beta/policy-intelligence)
