## Paid Support

If you have a paid [Google Cloud support plan](https://docs.cloud.google.com/support) always open support cases through the support console, as described in the [create a support case documentation](https://docs.cloud.google.com/support/docs/customer-care-procedures#create_a_support_case).

## Get a Google Cloud support package

Google Cloud offers different support packages to meet different needs, such as 24/7 coverage, phone support, and access to a technical support manager. For more information, see [Cloud Customer Care](https://docs.cloud.google.com/support).

## File bugs or feature requests

You can suggest feature requests and report issues on our [public issue tracker](https://issuetracker.google.com/issues/new?component=187143). This is a great place for gcloud CLI team members and the developer community to discuss and track implementations of features or resolution of bug fixes, as well as share workarounds and patches to the gcloud CLI. Be sure to toggle the 'Type' field to reflect the nature of the issue you're filing (such as Bug or Feature Request) to help make responses more efficient.
